# 原始材料规则

<!-- 规则加载哨兵：NOTE_RAW_20260724 -->

本文件只规定 `raw/` 原件层的增量规则。

## 原件不可变

- 已有外部原件只能读取，禁止修改、覆盖、重命名或删除；纠错、解释和结构化整理写入 `wiki/`。新增前用 `fd` 和 DOI、arXiv、题名、作者等稳定信息去重，不为统一命名批量改旧原件。
- 新文件名优先使用可识别题名、作者或稳定标识，避免不利于链接和命令行的字符。原件不得包含账号、密码、令牌、Cookie、私有下载参数或其他凭据。

## 论文与外部资源入库

- 汇报中作为证据或有用候选提及的论文，须从作者、出版社、会议、期刊或预印本等合法可信来源取得全文并写入 `raw/papers/`；同时在 `wiki/papers/` 建立基于实际全文的结构化笔记并更新方向索引。只保存题名、摘要、搜索链接或 Zotero 条目不算完成。
- 遇到付费墙、机构登录或无合法公开全文时，不使用不可信镜像。在当前 `.Codex/docs/` 任务报告记录题名、作者、年份、稳定标识、出版社页、所需版本、建议文件名和阻塞，并明确请求用户补充；取得原文后继续全文核验和笔记。
- 模型权重页、代码仓库、数据集主页、标准和技术文档等非论文来源，在 `wiki/resources/` 建资源笔记，记录 URL、核验日期、版本或提交、许可证、实测事实和与课题关系；外部页面本身不等于论文全文证据。
- 使用 Zotero 时按 DOI、arXiv 或稳定 URL 导入，核对重复项并关联合法全文。Zotero 管理题录，不能替代仓库原件、全文笔记和页码核验。

## 数据集来源

- 数据集论文进入 `raw/papers/datasets/` 并在 `wiki/papers/datasets/` 建笔记；正式大体量数据按实验清单和运行路径管理，不为知识分层复制到 `raw/`。
- 引入数据集前核验官方发布者、论文、名称与版本、发布日期、许可证或使用条件、稳定 URL 或 DOI、获取日期和可用校验和。实验清单关联文件、版本、哈希、切分与来源。
- 版本、许可、标签来源或发布者无法确认时，只登记候选，不进入正式实验、论文证据或对外制品。

## PDF 与证据

- PDF 读取可使用 `pdf-converter` 或仓库可用的 PDF 技能；转换结果只作辅助。公式、定理、数字、消融和引用措辞必须回到原始 PDF 页码或章节复核。
- 转换中间文件写入 `/tmp/` 下任务目录，不进入 `raw/`、`wiki/`、`output/` 或恢复文档；分页文件名须含页段，禁止不同页段互相覆盖。
- 每个新增论文原件必须由 `wiki/papers/` 笔记的 `source_pdf` 显式关联。原件只证明来源内容，不自动成为本课题结论。
