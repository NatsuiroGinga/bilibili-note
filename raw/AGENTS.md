# 原始材料规则

<!-- 规则加载哨兵：NOTE_RAW_20260724 -->

本文件适用于 `raw/`，并继承仓库根规则。

## 不可变原件层（强制）

- `raw/` 是外部材料原件层，只能新增，禁止修改、覆盖、重命名或删除已有原件。需要纠错、解释或结构化整理时写入 `wiki/`，不得改原文件。
- 下载或新增前先用 `fd` 和明确书目信息检查同一论文是否已存在；已有原件时复用并补齐笔记，禁止重复保存。
- 文件名优先使用可识别的题名、作者或稳定标识，避免 `&` 等不利于链接和命令行处理的字符；不得为了统一命名批量改动既有原件。
- 原件不得包含账号、密码、令牌、Cookie、私有下载地址参数或其他凭据。

## 论文检索与落盘

- 联网检索后，只要根据题名、摘要、来源和当前研究问题判断论文**可能有用**，就继续核验真实性，并从作者主页、出版社、会议、期刊或预印本平台等合法可信来源取得全文。
- 优先用 DOI、arXiv 标识或出版社 URL 等稳定标识符识别和去重来源；文件名相似或题名翻译不同不能作为两篇材料的依据。
- 使用 Zotero 时，以 DOI、arXiv 标识或 URL 导入书目，导入后核对重复项并关联合法全文；Zotero 条目不能替代仓库内原件、结构化笔记和全文核验。
- 全文按研究方向写入 `raw/papers/` 的对应目录；随后基于全文在 `wiki/papers/` 创建或更新结构化阅读笔记，并更新对应方向索引。任务同时涉及笔记时必须读取 `wiki/AGENTS.md`。
- 禁止只保存搜索链接、摘要或搜索引擎结论来冒充全文入库或全文阅读。
- 遇到付费墙、机构登录或无公开 PDF 时，不使用非可信镜像。把题名、作者、年份、DOI 或 arXiv 标识、出版社原始页面、所需版本、建议文件名和访问阻塞记录到当前 `.Codex/docs/` 文献任务报告，并明确告知用户。
- 用户补充原文后，必须继续完成全文核验、结构化笔记和索引更新。

## 数据集来源管理

- 数据集论文放入 `raw/papers/datasets/`，并在 `wiki/papers/datasets/` 建立笔记；正式实验数据仍按实验项目的数据清单和运行路径管理，不为满足知识分层而复制大体量数据到 `raw/`。
- 引入数据集前核验官方发布页或可信仓库、数据集论文、名称与版本、发布日期、许可证或使用条件、稳定 URL 或 DOI、获取日期以及可用的校验和。
- 数据包、镜像或预处理副本不能取代来源记录。实验清单必须把所用文件、版本、校验和、划分与原始来源关联起来，避免同名异版和静默更新。
- 无法确认版本、许可、标签来源或正式发布者时，只能登记为候选，不得进入正式论文证据或对外发布制品。

## PDF 解析与证据核验

- 解析论文 PDF 时可使用 `pdf-converter`，技能文件为 `/Users/bilibili/.agents/skills/pdf-converter/SKILL.md`。
- 快速扫描默认用 `mineru-open-api flash-extract`；论文超过 20 页或需要保留公式、表格和版面时优先用 `extract`。认证不可用时回退到本地 `pdftotext` 并逐页核验。
- 转换结果只作阅读辅助。关键公式、定理、实验数字、消融结论和引用措辞必须回到原始 PDF 的页码或章节复核；不得只依据自动提取文本生成论文结论。
- PDF 转换中间文件统一写入 `/tmp/manifold-pdf-extract/` 等临时目录，不得写入 `raw/`、`wiki/`、`output/` 或默认恢复文档。
- 分页提取的文件名必须包含 `_p起始页-结束页`，不同页段不得写入同一路径造成覆盖。

## 与知识层的关系

- 每个新增论文原件都应有指向它的 `wiki/papers/` 笔记；笔记的 `source_pdf` 使用对应原件路径建立显式关联。
- 原始材料只证明来源内容，不自动成为本课题结论。论文原结论、本课题推论、可迁移机制和待验证假设必须在知识层中区分。
