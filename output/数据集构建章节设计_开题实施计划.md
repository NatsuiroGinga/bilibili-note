# 数据集构建 — 章节设计与实施计划

- **用途**：开题报告新增章节"数据集构建"的设计草案，供导师审阅后并入开题实施计划
- **日期**：2026-07-14
- **定位**：本章是 PINN 创新点与课程式 RL 创新点的**共同前置依赖**——必须先在数据上把"守恒不变量"定义清楚、验证可计算，PINN 章才有物理可依；课程章也依赖本章产出的难度标签。
- **核心命题**：把"网络流量的物理是什么"这一抽象争论，落到**可在测试床上计算、可被攻击打破**的具体不变量上。

---

## 1. 为什么需要独立的数据集构建章

公开数据集 CSE-CIC-IDS2018 单独不足以支撑本课题的两个创新点，三个硬障碍：

1. **守恒不变量不可观测**：IDS2018 是 CICFlowMeter 的端点侧**流级聚合特征**（持续时间、包数、字节数、标志位计数），没有包级时序、没有拓扑多节点视图。"节点流入=流出"这类守恒量在端点采集下不可计算——这是方案 B 落地的最大障碍，只能靠自构造测试床破。
2. **课程难度无标签**：课程式 RL 按"物理残差难度 + 决策方差难度"采样，这些不是 IDS2018 现成字段，必须自生成并标注。
3. **泛化声明无受控变种**：开题要证"捕捉攻击逻辑而非特征"，需分布外变种攻击，IDS2018 是 2018 年固定攻击集，变种得自己造。

> 因此本章不是附属说明，而是把方案 A/B 决策变成**可实验问题**的主战场：在测试床上试，哪个不变量能区分正常/攻击，就用哪个。

## 2. 数据集总体策略：公开 + 自构造 组合

| 数据集 | 角色 | 用途 |
|--------|------|------|
| CSE-CIC-IDS2018（已下，6.41GB） | 公开锚点 | 与文献基线可比；验证方法在标准基准上的表现 |
| 自构造测试床数据集 | 创新点支撑 | 提供守恒不变量可计算数据 + 课程难度标签 + OOD 变种 |

**不二选一**：纯自构造丢可比性且工作量爆炸；纯 IDS2018 撑不起创新点。组合是工程硕士最稳路径。

---

## 3. 公开数据集子节：CSE-CIC-IDS2018

- **选取理由**：业界主流入侵检测基准，覆盖 Brute Force / Heartbleed / Botnet / DoS / DDoS / Web Attack / Infiltration / PortScan 八类，与文献可比。
- **预处理**：去重、清洗 NaN/Inf、类别编码、流标签规范化；按攻击类型分层划分。
- **局限说明（引出自构造必要性）**：
  - 仅端点侧流级聚合，**无拓扑多节点视图**，守恒不变量不可算。
  - 无包级 TCP 状态/窗口，TCP 流体残差（方案 A）不可算。
  - 无难度标签，不能直接喂课程学习。
  - 攻击集固定，无 OOD 变种。
- **本章只用其做"可比基线 + 局限佐证"**，创新点验证主要落在自构造数据集。

## 4. 测试床方案

### 4.1 目标

构造一个**可控、可观测、可注入**的网络环境，使守恒不变量在多节点上可计算、攻击可注入、难度可标注。

### 4.2 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 拓扑仿真 | Mininet + Open vSwitch | 拓扑可控、交换机端口计数器可读、SDN 可编程 |
| SDN 控制器 | Ryu / ONOS | 读取交换机流表与 per-port/per-flow 字节计数 |
| 正常流量生成 | D-ITG + iperf3 + 真实 PCAP 回放 | 产生混合 TCP/UDP 的真实背景流 |
| 攻击注入 | Scapy + hping3 + nmap | SYN flood / UDP flood / 端口扫描 / 载荷注入 |
| 多点采集 | tcpdump（各交换机/主机镜像口）+ sFlow/NetFlow | 同时获取包级与流级、多节点视图 |
| 标注 | 攻击注入时间戳 + 类型 + 参数 | 自动产生 ground-truth 标签 |

### 4.3 拓扑（刻意保持小规模）

3-5 节点 SDN 小拓扑，够定义守恒量即可，不追求大规模：

```
 客户端区          核心交换机 S1          服务端区
 C1 ─┐          ┌──────────┐          ┌─ SV1 (Web)
 C2 ─┼──(链路)──│  S1 (核心) │──(链路)──┼─ SV2 (DB)
 C3 ─┘          └────┬─────┘          └─ SV3 (DNS)
                     │(镜像/采集点 T1)
                  采集器/控制器
```

- **核心交换机 S1** 是守恒不变量的计算节点：其所有端口可读 per-port 字节计数，`Σin ≈ Σout + dropped` 可算。
- **采集点 T1** 做镜像抓包，获包级 TCP 状态/窗口（供方案 A 残差作消融对比）。
- 客户端区发正常+攻击流，服务端区被动响应。

### 4.4 攻击场景（聚焦 3-4 类 + 1 变种）

| 场景 | 工具 | 打破的不变量（见 §5） |
|------|------|----------------------|
| DDoS（SYN flood / UDP flood） | hping3 / Scapy | I1 节点守恒、I2 双向比、I3 握手守恒 |
| 端口扫描 | nmap / Scapy | I2 双向比、I4 熵平稳 |
| 漏洞利用模拟 | Scapy 载荷注入 | I2 请求/响应比 |
| OOD 变种（协议混淆/速率调制） | Scapy 定制 | 全部不变量的鲁棒性测试 |

每场景含正常对照窗口，确保"正常成立、攻击打破"可对照验证。

## 5. 守恒不变量候选定义（核心）

按"物理合法性 × 可计算性 × 攻击可打破性"排序。**结论：以质量守恒（流量平衡）+ 协议状态守恒为主，TCP 流体 ODE 残差作消融**——这正是方案 B 的操作化，避开方案 A 的数据黑洞。

### I1. 节点流量守恒（质量守恒 / Kirchhoff 类比）★首选

对核心节点 $v$、时间窗 $\Delta$：

$$\mathcal{R}_{I1}(v,\Delta) = \sum_{i \in \text{in-ports}} B_i^{\text{in}} - \sum_{j \in \text{out-ports}} B_j^{\text{out}} - B^{\text{drop}} - B^{\text{consume}}$$

- 正常（纯转发节点）：$\mathcal{R}_{I1} \approx 0$（残差在 $\varepsilon$ 内），这是**真正的质量守恒**，最有资格称 physics-informed。
- DDoS 受害节点：流入 $\gg$ 流出（缓冲/丢弃），$\mathcal{R}_{I1}$ 显著为正。
- **可计算性**：需要多端口 per-port 字节计数 → **测试床可算，IDS2018 不可算**。
- **PINN 角色**：神经网络预测下一窗流量分布，I1 残差作为物理损失软约束；攻击使预测残差与 I1 残差同时升高。

### I2. 流双向守恒（请求/响应比）★次选，且可桥接 IDS2018

对一条双向流 $f$：

$$\mathcal{R}_{I2}(f) = \frac{B_{\text{req}}}{B_{\text{resp}} + \delta}, \quad \text{正常 } \mathcal{R}_{I2} \in [r_{\min}, r_{\max}]$$

- 正常服务：请求/响应字节比有界（服务端按请求响应）。
- DDoS/扫描：单向洪泛/探测，响应近零，$\mathcal{R}_{I2} \to \infty$。
- **可计算性**：方向性字节计数 → **测试床可算，IDS2018 的 `Tot Fwd/Bwd Pkts` 亦可近似算**。这条是把公开数据集和自构造数据集**桥接**的关键不变量。

### I3. TCP 状态守恒（握手一致性）

$$\mathcal{R}_{I3} = \#\{\text{SYN 无匹配 SYN-ACK}\} + \#\{\text{半开连接}\}$$

- 正常：未应答 SYN $\approx 0$。
- SYN flood：$\mathcal{R}_{I3}$ 暴涨。
- **可计算性**：需包级 TCP 标志 → 测试床可算。

### I4. 分布平稳性（熵界）— 较弱，作辅助

$$\mathcal{R}_{I4} = |H_{\text{src/dst}}(t) - \bar H|, \quad H \text{ 为目的端熵}$$

- DDoS：目的熵骤降（全部打一点）；扫描：目的熵骤升。
- 属"统计不变量"，物理性弱，但易算、跨数据集可用，作辅助特征。

### I5. TCP 流体 ODE 残差（方案 A）— 仅消融对比

Misra/Kelly 流体方程在窗口 $W$、队列 $q$、RTT $\tau$ 上的残差。**测试床可重建这些量**（包级窗口、交换机队列），故可算，但仅用于**与 I1-I3 对比消融**，证明守恒不变量优于 TCP 流体残差。预期结论：I1/I2 在非 TCP 攻击上显著优于 I5。

### 不变量→攻击 映射汇总

| 不变量 | 物理合法性 | 测试床可算 | IDS2018 可算 | DDoS | 扫描 | 漏洞利用 |
|--------|:---:|:---:|:---:|:---:|:---:|:---:|
| I1 节点守恒 | ★★★ | ✅ | ❌ | ✓✓ | ✓ | ✗ |
| I2 双向守恒 | ★★ | ✅ | ✅近似 | ✓✓ | ✓✓ | ✓ |
| I3 握手守恒 | ★★ | ✅ | ❌ | ✓✓ | ✗ | ✗ |
| I4 熵平稳 | ★ | ✅ | ✅ | ✓ | ✓ | ✗ |
| I5 TCP流体 | ★★★ | ✅ | ❌ | ✓ | ✗ | ✗（非TCP失效） |

**主用 I1+I2+I3，I4 辅助，I5 消融。**

## 6. 课程难度标注方案（供创新点 2）

创新点 2 的"双维度在线课程"需要每个样本带难度标签。本章离线生成初始难度，供课程采样预热与评测：

- **物理残差难度** $\sigma^2_{\text{phy}}$：样本在主用不变量（I1/I2/I3）上的归一化残差幅度。残差小→简单（正常或显性攻击），残差大→难（隐蔽攻击）。
- **决策方差难度** $\sigma^2_{\text{reward}}$：GRPO 组内奖励方差（在线计算），本章先用基模型离线推理得到初值。
- **合成难度**：$D = \alpha \cdot \hat\sigma^2_{\text{phy}} + (1-\alpha)\cdot \hat\sigma^2_{\text{reward}}$，分到三级课程区（熟练/困惑/噪声）。
- 难度标签与攻击类型、攻击参数（速率、混淆程度）联合记录，便于做"难度可控"的消融。

## 7. 数据集统计、划分与发布

- **规模目标**：正常流量窗口 ×N + 四类攻击 ×M 窗口 + OOD 变种 ×K，单拓扑够用即可（不追求 IDS2018 量级）。
- **划分**：训练 / 验证 / 测试 / OOD 变种测试（OOD 与训练攻击类型同族但参数混淆，专测泛化）。
- **字段**：每窗口含多端口字节计数（I1）、方向字节比（I2）、TCP 标志统计（I3）、熵（I4）、可选窗口/队列（I5）、攻击标签、难度标签。
- **发布**：若脱敏后无合规风险，可作论文附属数据集发布，作为"网络流量守恒不变量基准"——本身也是一个贡献点。

## 9. 风险与范围控制

| 风险 | 控制 |
|------|------|
| 测试床工作量爆炸 | 拓扑限 3-5 节点、攻击限 3-4 类 + 1 变种 |
| 守恒不变量区分力不足 | I1-I5 并行测，用消融选最强组合；I5 作兜底对比 |
| IDS2018 与自构造结果不可比 | 用 I2（双向守恒）作桥接不变量，两数据集都算 |
| OOD 变种过简被质疑 | 变种至少做协议层 + 速率层两种混淆 |
| 物理"合法性"被质疑 | I1 是严格质量守恒（Kirchhoff 类比），答辩质疑最弱；避免过度宣称 I4 为"物理" |
