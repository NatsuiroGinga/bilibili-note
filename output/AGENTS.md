# 高层交付与恢复文档规则

<!-- 规则加载哨兵：NOTE_OUTPUT_20260724 -->

本文件只规定 `output/` 的增量规则。

- `output/` 保存面向研究决策和论文写作的高层确定交付，不保存过程计划、长日志、逐轮审查或历史备份；这些材料写入 `.Codex/docs/` 并以相对链接引用。
- 只有用户明确指定高层交付物，或当前路线规则要求更新既有文件时才修改本目录。写入前核验原始实验制品、详细记录或全文来源；不得以旧摘要覆盖新证据，不得把计划写成事实。
- 每条状态写明事实、证据路径、裁决和下一门禁；无法核验的内容标为“待验证”。不得写入临时路径、凭据、认证参数或完整控制台输出。
- `开题改进交接文档.md` 与 `第一创新点实验总控.md` 属 PINN/R2 历史路线，只在用户明确绑定该路线时按其职责更新；当前 RWKV 路线的总控与章节状态留在 `.Codex/docs/RWKV/`。
- 同一路线文档冲突时先回到原始日志、制品和详细报告核验，再原子修正相关高层文件；禁止单改一份制造新的冲突。
