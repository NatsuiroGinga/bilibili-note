# 强化学习算法论文检索

## 范围与口径

- 原始算法论文不设时间限制。
- 改进论文集中在 2021—2026 年 7 月。
- 目录覆盖主要算法谱系，而非仅限 PPO、DPO、GRPO；应用型论文和仅改奖励函数的工程工作默认不纳入。

## 价值学习与策略梯度基础

| 算法 | 原始论文                                                                     | 代表性近期工作                                                                    |
| ---- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| DQN  | Mnih 等（2015），_Human-level control through deep reinforcement learning_。 | 重点延伸为分布式、分布式价值学习和离线 Q 学习；本次不把领域应用论文列为算法改进。 |
| A3C  | Mnih 等（2016），_Asynchronous Methods for Deep Reinforcement Learning_。    | 异步采样和并行学习仍是大规模在策略训练的重要实现方向。                            |
| TRPO | Schulman 等（2015），_Trust Region Policy Optimization_。                    | PPO 是其最具影响力的简化分支；近期工作多转向约束、多智能体和语言模型场景。        |
| PPO  | Schulman 等（2017），_Proximal Policy Optimization Algorithms_。             | CoPPO（2021）、P3O（2022）、BPPO（2023）、VinePPO（2024）。                       |

## 连续控制与最大熵强化学习

| 算法 | 原始论文                                                                                               | 代表性近期工作                                                            |
| ---- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| DDPG | Lillicrap 等（2015），_Continuous control with deep reinforcement learning_。                          | 后续关键纠偏路线是 TD3 与 SAC；近期研究主要在离线、鲁棒和安全控制中改造。 |
| TD3  | Fujimoto、van Hoof、Meger（2018），_Addressing Function Approximation Error in Actor-Critic Methods_。 | 双评论家、延迟策略更新仍是连续控制的基础设计。                            |
| SAC  | Haarnoja 等（2018），_Soft Actor-Critic_。                                                             | 最大熵目标继续用于离线、风险敏感和多智能体设置。                          |

| 算法 | 原始论文                                                                                     | 代表性近期工作                                                               |
| ---- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| CQL  | Kumar 等（2020），_Conservative Q-Learning for Offline Reinforcement Learning_。             | MCQ（2022）：减轻过度保守导致的泛化受限。                                    |

| BPPO | Zhuang 等（2023），_Behavior Proximal Policy Optimization_。                                 | 将 PPO 的保守性直接用于静态数据集学习。                                      |

## 建议阅读路径

1. 先建立共通基础：DQN → TRPO → PPO → DDPG/TD3/SAC。
2. 若做机器人或控制：继续读 CQL、IQL、DreamerV3、P3O。
3. 若做多智能体：读 MAPPO、CoPPO。
4. 若做大语言模型后训练：DPO → TDPO/ODPO/α-DPO/SimPO/ORPO → GRPO → REINFORCE++/TIC-GRPO。
