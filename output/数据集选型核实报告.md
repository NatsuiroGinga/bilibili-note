## 一、二轮修正核实详情

### CAIDA DDoS 2007 — ✅ 页面已定位（修正）

- 用户修正 URL `catalog.caida.org/dataset/ddos_attack_2007`：curl HTTP 200，命中 `dataset/ddos/trace`。
- **确认**：原 `/data/` 路径随官网改版废弃，数据集迁至 CAIDA Data Catalog，未下架。学术用途免费，**需注册账号 + 签数据使用协议（DUA）审核**，非即下即用。
- **课题定位**：真实骨干网 DDoS PCAP，TCP 字段完整，验 I5/包级 I3 的真实数据基准。但申请流程有延迟，**不作为核心实验主依赖**，作真实数据鲁棒性补充。

### MAWI / MAWILab — ✅ 主站已确认（修正）

- 用户修正：主站 `mawi.wide.ad.jp/mawi/` HTTP 200，命中 `backbone/trace`；异常标注子项目 `mawilab.wide.ad.jp/` 仍 HTTP 000（本环境连不上）。
- **确认**：原链接路径拼写有误（`/mawilab/` vs `/mawi/`）+ 日本学术站境外访问不稳，非下架。
- **课题定位**：长期真实骨干网采样 PCAP + 异常标签，验真实噪声鲁棒性。**若本地不通可直接弃用**，不影响严谨性。

### TUIDS — ❌ 放弃

- 无官方稳定下载渠道，Kaggle 第三方镜像失效（404），学术引用量低、认可度有限。
- **处理**：不作为核心实验数据集。其"TCP 时序"需求由 IDS2018 原始 PCAP + BoT-IoT 覆盖。

## 二、替代方案核实（用户推荐，已核实）

### IDS2018/IDS2017 原始 PCAP — ✅⭐⭐ 最优解

- **核实**：IDS2018 S3 桶 `Original Network Traffic and Log data/` 下每日有 `pcap.zip`（Friday-02-03 = 44.79GB），CIC 官网页面也确认配套原始 PCAP。IDS2017 同理。
- **关键意义**：**主数据集本身就配套完整原始 PCAP，不是只有 CSV**。可从原始 PCAP 提取 TCP 窗口、RTT、报文间隔、队列相关时序特征，用于 PINN 包级 I3（严格未应答 SYN）/部分 I5（W/RTT 时序）。
- **优势**：同一数据集同时支撑流级（CSV）与包级（PCAP）两级模块，**数据一致性最强**，无需引入异构数据集。
- **代价**：PCAP 极大（每日 40-59GB，全量 ~400GB）。**只需下载 1-2 日的 PCAP** 做包级实验即可。

### BoT-IoT — ✅⭐ 包级补充验证集

- **核实**：`research.unsw.edu.au/projects/bot-iot-dataset` HTTP 200，命中 `pcap/DDoS/download/dataset`。
- **确认**：UNSW 2018，完整原始 PCAP + 精细标注，覆盖 DDoS/DoS/侦察/数据窃取，TCP 特征完整，公开直下。
- **课题定位**：PINN 物理检测的补充验证集（异源泛化），同时支持大模型语义精判实验。

## 关键结论（修正后）

1. **包级需求最优解 = IDS2018 自带原始 PCAP**：不必依赖申请制的 CAIDA 或访问不稳的 MAWI。下载 1-2 日 IDS2018 PCAP（~45GB/日）即可做包级 I3/I5，且与流级 CSV 同源一致。这是最干净的选择。
2. **CTU-13 三模态坐实** → 两级架构（PINN 初筛 + LLM 精判）有多模态真实数据支撑。
3. **I1（节点守恒）仍必须自构造**：所有真实数据集都是单点采集（无拓扑），只有 ns-3/Mininet 能给多节点视图。测试床省不掉，但收窄到只做 I1。
4. **CAIDA 降级为可选补充**（DUA 申请制，真实骨干网，非核心）；**MAWI 可选**（本地不通则弃）；**TUIDS 放弃**。
