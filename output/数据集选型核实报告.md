## 已确认项详情（curl 实证）

### CIC-IDS2017 — ✅
- 官方页 `unb.ca/cic/datasets/ids-2017.html` HTTP 200；页面含 `packet`、`CICFlowMeter`、`public`、`License`。
- **确认**：PCAP 包级 + CICFlowMeter 流级 CSV，与 IDS2018 同格式同标注规范，公开下载（需遵守 License）。
- **课题用途**：跨数据集泛化验证（你声称 OOD 鲁棒，需跨集证明）；流级支撑 I2/I4，PCAP 支撑包级 I3。

### CIC-DDoS2019 — ✅
- 官方页 HTTP 200；含 `packet`、`flow`、`public`、`terms`。
- **确认**：PCAP + 流级，公开（terms）。12 类 DDoS 变种。
- **课题用途**：DDoS 强打破 I2，变种覆盖好；PCAP 可补包级 I3/部分 I5。

### UNSW-NB15 — ✅
- 官方页 `research.unsw.edu.au/.../unsw-nb15-dataset` HTTP 200；含 `pcap`、`CSV`、`download`、`terms`。
- **确认**：PCAP + CSV，公开。注：特征 schema 与 CICFlowMeter 不同（49 特征），需适配层。
- **课题用途**：第三泛化锚点（不同特征分布）。

### CTU-13 — ✅⭐
- 官方页 `stratosphereips.org/datasets-ctu13` HTTP 200；grep 命中 `log`×22、`NetFlow`×12、`pcap`×6、`bidirectional`×6、`public`、`terms`。
- **确认**：**PCAP + NetFlow + 攻击行为日志 + 双向流，公开**——清单里"完美匹配两级架构多模态"的声明**已坐实**。
- **课题用途**：PCAP 喂 PINN 物理初筛 + 日志喂 LLM 语义精判，两级架构的最佳真实数据支撑。

### ns-3 — ✅
- 官方页 `nsnam.org` HTTP 200；含 `Download`、`license`。
- **确认**：开源网络仿真器，公开下载。
- **课题用途**：Mininet 的替代/互补——I1（节点守恒）需拓扑，只有 ns-3/Mininet 能给；ns-3 对 TCP 状态/队列的物理控制更精细。

## 未能核实项（需人工确认）

### CAIDA DDoS 2007 — ⚠️ 官方页 404
- 你给的 URL `caida.org/data/ddos/ddos-2007/` 返回 404；我试的 `catalog/datasets/ddos-20070806/`、`data/ddos-20070806/` 也 404；仅 `caida.org/data/` 返回 302（目录存在但重定向）。
- **判断**：CAIDA 可能改版/下架了该数据集页。需你上 CAIDA catalog 搜确认是否仍可获取；CAIDA 数据通常需注册条款。
- **若可获取**：真实骨干网 PCAP，可重建 TCP 窗口/RTT，验证 I5 与包级 I3。

### MAWILab — ⚠️ 连接失败
- `mawi.wide.ad.jp/mawilab/` http/https 均返回 HTTP 000（连接失败）。
- **判断**：WIDE 服务器可能屏蔽本环境 IP/地区或 SSL 异常。需你本地浏览器确认能否打开。
- **若可获取**：长期真实骨干网流量 + 自然异常标注，验真实噪声鲁棒性。

### TUIDS — ⚠️ 官方下载页未定位
- Kaggle 页 404；未找到官方下载入口。该数据集出自 2021 IEEE 论文（Karabulut & Aygun, UBES 2021）。
- **判断**：需查论文原文/作者主页确认是否公开、"TCP 连接级时序"是否如备注所述。
- **若可获取**：PCAP + TCP 时序，直接支撑 I5 流体建模。

## 未独立核实项（据清单备注+场景判断，未 curl）

- **ADFA-LD**：清单备注为"主机系统调用序列"。**场景不符**——本课题是网络流量攻击检测，ADFA-LD 是 host-based 系统调用，scope 不同。除非扩展到主机侧，否则不用。
- **Locked Shields**：清单备注为"北约红蓝对抗演练"。该数据**多不公开**，需特殊渠道。除非你有访问权，否则仅在"展望"提一句。

## 关键结论（基于已核实部分）

1. **真实包级数据源已确认可用**：IDS2017 / DDoS2019 / UNSW-NB15 / CTU-13 四个都有 PCAP 且公开 → 包级 I3（严格未应答 SYN）和部分 I5（从包重建 W/RTT；队列 q 仍缺）**可用真实数据验证，不必全靠仿真**。
2. **CTU-13 三模态坐实** → 两级架构（PINN 初筛 + LLM 精判）有多模态真实数据支撑，是清单最大收获。
3. **I1（节点守恒）仍必须自构造**：四个已核实数据集都是单点采集（无拓扑），只有 ns-3/Mininet 能给多节点视图。测试床省不掉，但可缩小到只做 I1。
4. **CAIDA/MAWILab/TUIDS 三个"真实流量"候选暂无法证实**——若需真实骨干网流量验鲁棒性，得先人工确认这三个是否还能拿到。
