# output 层 — 查询产物

## 规则

**随时覆盖。** output/ 下的文件是 AI 生成的临时产物——分析报告、排查结论、问答记录。它们不沉淀知识（那是 wiki 的工作），用完即弃。

- ✅ AI 生成报告写入这里
- ✅ 随时覆盖、删除、重建
- ❌ 不要把 output 中的内容作为知识源
- ❌ 不要在其他笔记中引用 output/ 的内容

## 典型用途

- 批量 PDF 分析结果
- 一次性的排查报告
- AI 对话的总结输出
- 实验性的分析输出

如果需要长期保留，应该将其中的结论提炼后写入 `wiki/`，然后在 output 中删除原文件。
