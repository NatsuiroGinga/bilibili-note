# LAMDA 阶段 A：针对 Replay 安全保持—适应取舍的改造候选

**结论：当前值得研究的不是“让 Replay 更强地记住过去”，而是让有限记忆与更新规则区分三件事：保护旧的正确恶意识别、修复当前仍然漏判的恶意样本、限制修复过程新增的误报。**

标准 Replay 已经减少旧恶意样本负向翻转，并降低 FPR；如果只加强蒸馏、只挑难负例，或者只提高旧样本权重，可能进一步强化同一种保守取舍，而不解决 AP/FNR 的损失。**“双侧风险约束下的错误修复＋决策角色条件记忆”具有形成算法研究的空间；类别均衡、时间分层、普通多样性选择、MIR 或 PCT 单独接入，首先都应视为已有方法或工程对照，不能直接作为创新。**【推论／外部候选】

---

## 一、先把“病灶”限定在现有证据能够支持的范围内

### 1.1 已观察到的是取舍，不是 Replay 全面改善

下表只转换你提供的差值单位，**没有独立复算逐样本预测**。

| Replay 相对 Naive |                 差值 | 当前解释                       |
| ----------------- | -------------------: | ------------------------------ |
| AP                |  −0.0279375 个百分点 | 排序表现略差，尚无不确定性分析 |
| FPR               |  −0.0913050 个百分点 | 良性侧误报减少                 |
| FNR               | ＋0.1889074 个百分点 | 当前年份恶意漏报增加           |
| 旧恶意负向翻转率  |  −2.3743257 个百分点 | 旧的正确恶意识别更稳定         |

**【用户提供，未独立复算】**原来的 `screening_only` 资格成立于你给定的预注册门，不能将它改写为“AP、召回和校准均改善”。精确重复、重叠和标签冲突为零的审计结果，也不直接说明记忆覆盖是否充分、标签是否始终正确，或者差值是否具有统计稳定性。

**【推论】**以下三种机制都与现有聚合结果相容，但目前不能认定哪一种成立：

| 待检验机制                     | 为什么与结果相容                                                     | 区分它所需的训练侧观测                               |
| ------------------------------ | -------------------------------------------------------------------- | ---------------------------------------------------- |
| **记忆组成偏向容易保持的区域** | 有利于稳定旧预测，却可能没有保留可支持当前恶意识别的样本             | 缓冲区中的类别、年龄、正确性、margin 和覆盖分布      |
| **更新过于保守**               | 降低预测变化，同时妨碍原有错误被纠正                                 | 恶意样本正向翻转、负向翻转及教师错误保持率           |
| **跨年份分数尺度变化**         | pooled AP 将不同年度模型的分数放在一起排序，可能受年度间尺度偏移影响 | 逐年 AP、分数分布、Brier，以及预先固定的 pooled 汇总 |

这意味着：**不能根据 pooled AP 的下降，直接断定需要更复杂的特征学习；也不能根据旧恶意负向翻转下降，断定需要继续强化稳定性。**

### 1.2 必须同时看“减少旧错误新增”和“纠正已有错误”

Regression-aware 论文区分了负向翻转与正向翻转。其公式（2）—（7）显示：在**同一评价集合、同一前后模型、同一分母**上，错误率变化由两种翻转共同决定，而不是仅由负向翻转决定。([arXiv][1])

针对恶意类，可以写为：

$$
\Delta \mathrm{FNR}
=
\mathrm{NFR}_{\mathrm{mal}}
-
\mathrm{PFR}_{\mathrm{mal}},
$$

其中这里的两种翻转率均以该集合的**全部恶意样本**为分母。

**【推论】**一个几乎不更新的模型也可以具有很低的负向翻转率，但可能保留大量漏判。因此，新候选不能只验证“旧恶意负向翻转继续下降”，还要验证“该纠正的恶意错误是否得到纠正”。

这里有两个口径边界：

- 你现有负向翻转率的分母应保持不变；如果它以“旧模型已判对的恶意样本”为分母，就不能直接代入上式。
- `current_year` FNR 与旧恶意负向翻转来自不同集合，不能用二者直接做上述分解。

### 1.3 本任务不是原论文的静态 FAR 外推

LAMDA 附录 J 区分了年度 Domain-IL 与学习后对不同经验的评价；它们不等于仅用早期年份训练后进行静态 FAR 测试。附录 J.1 还存在“每个 experience 200”的文字，而你明确冻结的是**全程总容量 200**。本报告以你的合同为准，不借论文措辞扩大记忆。([arXiv][2])

**【推论】**高 `current_year` AP 不能据此认定长期静态漂移已经解决，也不能把原论文其他聚合方式的结果作为你这组数字的直接复现目标。已知的全期协变量预处理问题仍然使全部候选保留 `screening_only` 身份。

### 两个容易导致错误创新判断的细节

**第一，PCT 已经出现过与你相似的取舍。**Regression-aware 表 I 的 TESSERACT backward 结果中，Replay→PCT+Replay 的恶意负向翻转率由 **2.28±1.31%** 降至 **1.33±0.89%**，但 Recall 由 **85.67±3.84%** 降至 **81.40±2.85%**。因此，PCT 是必须比较的直接基线，不是“补回召回”的现成答案。([arXiv][1])

**第二，MADAR 的预算与指标都不能误读。**其算法 1 持续把新任务加入历史池，再选出回放子集；§IV-D 的 \(\overline{AP}\) 指**全局平均准确率**，不是你使用的 Average Precision。正式发表记录将题名改为 _Distribution-Aware Replay_；本报告的算法细节绑定已核对的 **arXiv v1**，不假定两个版本逐项一致。([arXiv][3])

## 三、候选一：只保护必要的旧正确决策，而不是保持全部旧分数

### 3.1 改造对象

**【推论／外部候选】**保持原 reservoir 和回放方式不变，先只改更新目标：

> 对旧模型已经判对的恶意记忆，约束其不要跌过决策边界；对旧模型已经漏判的恶意样本，不要求继续模仿旧模型，而允许其被纠正。

这是针对“安全保持已经有效，但修复能力可能受损”的最直接拆分。

PCT 的原式含对全部样本生效的基础蒸馏项，再额外加权旧模型判对的样本；它不是“只蒸馏旧正确样本”。([arXiv][1])

### 3.2 一个可检验的最小形式

令 \(z_\theta(x)\) 为恶意类 logit，\(a\) 为合同中固定分类阈值对应的 logit。年度更新开始前模型为 \(\theta^{-}\)，旧缓冲区为 \(B_{t-1}\)。

保护集合仅来自真实保存的旧记忆：

$$
P_t=
\{(x,y)\in B_{t-1}:y=1,\ z_{\theta^-}(x)\ge a\}.
$$

可以测试以下**单侧、截断 margin 保持项**：

$$
\ell_{\mathrm{protect}}(x;\theta)=
\left[
\min\{m,z_{\theta^-}(x)-a\}
-
\bigl(z_\theta(x)-a\bigr)
\right]_+,
\qquad x\in P_t.
$$

**【推论】**它与完整 logit 匹配的差别是：不要求新模型复制旧置信度，只要求保存一定的正确侧 margin；提高恶意分数不受该项惩罚，旧模型漏判样本不进入这个保护集合。

若该项在所有保护记忆上恰为零，则这些**记忆样本**不会因下降越过阈值而成为漏报。这个有限集合性质不等于测试分布保证；软惩罚训练也不保证该项能达到零。

### 3.3 针对取舍的作用及边界

**【推论】**它试图把“保持旧的正确决策”和“维持旧的分数形状”分开，为当前恶意样本修复留下更大空间。但它本身没有充分控制新增误报，因此只能作为组成部件，不能单独预设优于 Replay。

| 最小对照                                 | 应观察什么                                                                     | 失败门                                                         |
| ---------------------------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------- |
| Replay；Replay+原式 PCT；Replay+单侧保护 | 旧恶意负向翻转、当前恶意正向翻转、旧错样本被继续保持的比例、训练侧 margin 变化 | 负向翻转更低但修复能力继续下降；或改善完全来自更弱的总正则强度 |
| 固定同一缓冲区、同一回放暴露量           | 排除记忆组成变化                                                               | 更换采样器、额外训练或改阈值后才出现收益                       |

**创新判断：**“把 PCT 改成只作用于正确样本”或“换成 hinge”通常只是损失改造，尚不足以支撑独立框架。它的研究价值在于为后续**风险约束下的修复**提供更精确的保护对象。

## 四、候选二：因果的类别／时间条件覆盖记忆

### 4.1 改造对象

**【推论／外部候选】**标准单样本 reservoir 近似保存已经到达的样本分布，不保证每类、每个历史时间条件或每种决策区域获得充足代表。可以测试：

> 在总容量仍为 200 的条件下，将“保存多少”与“各条件内保存哪些”拆开。

第一层只用已到达数据确定类别及历史时间条件；第二层在各条件内保留代表性和边界区域，而非只保留最高损失样本。

CBRS 已研究类别平衡；MADAR 已研究家族内代表性与异常样本；GSS 已研究梯度多样性。因此这些都应成为明确先例，而不是新方法名的来源。([Proceedings of Machine Learning Research][7])

### 4.2 本合同下的实现边界

**【推论】**

- 只能在 \(B_{t-1}\) 与当前年度训练集 \(D_t^{\mathrm{train}}\) 之间进行保留或替换；被淘汰的过去样本不能从历史目录重新取回。
- 时间条件只能依赖当前已知的到达时间或相对年龄，不能按最终全部年份的频率配置份额。
- 不必一开始就使用家族。只有确认家族标签在相应时间可用时，才允许它进入记忆分配；未来完成的家族标注不能伪装成历史可观测量。
- 不承诺“每年×每类×每家族都有配额”。200 个槽位可能根本支持不了这样的交叉分层。

最小版本应先用**类别×粗时间条件**，避免引入额外家族信息条件。

### 4.3 为什么可能针对当前取舍

**【推论】**如果 reservoir 中能够支持恶意识别的关键历史区域不足，覆盖改造可能在不增加回放次数的情况下提供更有效的正类支持；同时保留良性边界区域，避免通过放宽恶意识别而丢掉 FPR 优势。

但相反也可能发生：类别均衡使恶意类在回放损失中获得更高权重，FNR 下降却 FPR 上升。这属于成本权重变化，不自动意味着覆盖机制有效。

| 最小对照                                                   | 应观察什么                                               | 失败门                                         |
| ---------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------- |
| 原 reservoir；类别／时间条件随机记忆；同配额条件内覆盖记忆 | 各条件占用数、覆盖距离或梯度角度、正类与负类实际回放权重 | 覆盖版不优于同配额随机版                       |
| 固定相同样本容量及损失归一化                               | 判断改善是覆盖还是类别权重造成                           | 只有增加恶意类训练暴露才能改善，且误报优势消失 |
| 不改变当前年度训练样本集合                                 | 观察是否影响旧恶意保持和当前恶意修复                     | 保留更多陈旧模式而阻碍新条件适应               |

**创新判断：**固定类别配额、时间配额、聚类中心、k-center、Isolation Forest、GSS 的直接接入，都首先属于已有方法实例化或工程设计。它们是必要的强对照，不宜单独成为第三章创新点。

## 五、候选三：区分“保护、修复、误报控制”的决策角色记忆

这是比“只选困难样本”更贴近当前结果的记忆改造。

### 5.1 三类角色，不等于三个固定类别桶

**【推论／外部候选】**

| 角色             | 只用当前允许信息定义                                                         | 对应的问题             |
| ---------------- | ---------------------------------------------------------------------------- | ---------------------- |
| **保护角色**     | 旧记忆中，旧模型已判对、但在当前更新下可能失去正确 margin 的恶意样本         | 旧恶意负向翻转         |
| **修复角色**     | 当前训练集或实际保留记忆中，真实标签为恶意、但当前仍漏判或 margin 不足的样本 | 当前 FNR、恶意排序错误 |
| **误报控制角色** | 已标注良性样本中，恶意分数较高、接近或越过阈值的样本                         | 修复恶意时新增的 FPR   |

另保留一部分一般覆盖，避免全部 200 条都被极端困难样本占满。角色可以变化，同一样本不应因落入多个角色而重复计入容量。

### 5.2 为什么不能只用 entropy 或 hard-negative

**【推论】**纯不确定性选择可能漏掉**高置信度漏判的恶意样本**；这些样本的预测熵低，但很需要修复。纯 hard-negative 选择则主要强化良性侧边界，可能进一步降低 FPR，却继续牺牲恶意召回。

MIR 提供了另一种信号：比较虚拟当前更新前后的旧样本损失，而不是仅看当前难度。其原始存储仍是 reservoir，变化发生在取样阶段。([arXiv][5])

因此，可借用的信号应分开：

$$
s_{\mathrm{interference}}(x)
=
\ell(x;\theta^{v})-\ell(x;\theta),
$$

用于识别受当前更新伤害的旧记忆；真实标签和 margin 则用于识别待修复恶意样本与危险良性边界。**一个标量“难度”不应替代三类决策角色。**【推论】

### 5.3 MIR 在本合同里有一个关键适用条件

**【推论】**若本地 Replay 的使用方式是“每年把全部 200 条旧记忆拼入当前训练集，再统一训练 10 轮”，则单纯从 200 条中选 top-200 的 MIR 没有选择作用。若改成每个 batch 反复抽取高干扰记忆，又改变了回放暴露量。

因此必须二选一地明确：

- 保持原回放使用方式，只把角色／干扰信息用于**下一次记忆保留**；
- 或研究回放取样，但增加**相同抽取次数、相同暴露预算的随机取样对照**。

不能将二者混在一起后把收益归因于“更智能的记忆”。

### 5.4 PBR 只能作为有边界的近邻

PBR 表 5 中，固定线性分类器时，随机记忆与 uncertainty 记忆的 Class-IL 准确率是 **33.21 与 33.66**；完整方法的更大收益还涉及 cosine classifier。不能据完整方法成绩，声称只换不确定性采样器就会产生同等收益；更不能为复现它而改掉当前统一 MLP 合同。([arXiv][6])

| 最小消融                                   | 应观察什么                                               | 失败门                                       |
| ------------------------------------------ | -------------------------------------------------------- | -------------------------------------------- |
| 单一难度选择；三角色选择                   | 记忆中高置信度漏判恶意是否被覆盖，三种角色各自的错误变化 | 改造仍主要保存难负例，修复角色实际上没有改善 |
| 相同角色配额随机选择；角色内干扰／覆盖选择 | 区分配额与选择规则的贡献                                 | 同配额随机版已解释全部收益                   |
| 完整角色；去掉修复角色                     | 当前恶意正向翻转、FNR、逐年 AP                           | 去掉修复角色无影响，说明“修复机制”解释不成立 |
| 完整角色；去掉误报控制角色                 | 修复带来的良性分数上移与 FP                              | 只有去掉良性控制才改善召回，且超出误报门     |

**创新判断：**固定的“三桶配额＋高损失选择”仍可能只是启发式工程。只有角色分配与实际约束、更新方向及有限记忆偏差建立明确关系，才更接近算法层面的贡献。

## 六、候选四：双侧风险约束下的修复式 Replay

### 6.1 与“继续加强记忆”的根本区别

**【推论／外部候选】**将目标从“尽量保持旧模型”改为：

> 在不破坏必要的旧恶意识别、不新增过多良性误报的条件下，尽可能修复当前可学习的恶意错误。

这是一个约束优化问题，而不是把所有目标合成一个固定权重的“更大 Replay loss”。

一个可供本地形式化的目标为：

$$
\begin{aligned}
\min_{\theta}\quad&
L_{\mathrm{current}}(\theta)
+\lambda_{\mathrm{replay}}L_{\mathrm{replay}}(\theta)
+\eta L_{\mathrm{repair}}(\theta),\\
\text{s.t.}\quad&
\widehat R_{\mathrm{FP}}(\theta)\le b_{\mathrm{FP},t},\\
&
\widehat R_{\mathrm{old\text{-}mal\text{-}flip}}(\theta)
\le b_{\mathrm{old},t}.
\end{aligned}
$$

其中：

- \(L_{\mathrm{repair}}\) 只使用当前训练集和现有记忆中的真实恶意标签，针对尚未修复的错误。
- 旧恶意风险可采用候选一的单侧保护代理。
- FP 风险代理使用已标注良性样本，不使用评价集 FPR。
- 两个预算的制定规则必须来自事先冻结的规则或允许的历史训练开发过程，不能用最终测试差值反推。

**这些是训练代理约束，不是对测试 FPR、测试负向翻转的形式化保证。**

### 6.2 AP 与 FNR 的修复必须区分

**【推论】**最小版本可以先使用面向漏判恶意样本的监督损失。若研究目标明确包含排序错误，再单独增加正负样本配对损失，例如：

$$
L_{\mathrm{rank}}
=
\mathbb E_{x^+\in R_t,\;x^-\in N_t}
\log\!\left(1+\exp\bigl[z_\theta(x^-)-z_\theta(x^+)\bigr]\right).
$$

它鼓励真实恶意分数高于危险良性分数，但**不等于直接优化 AP**，更不保证改善由多个年度模型分数组成的 pooled AP。排名项也可能损害校准，因此 Brier 仍须保留。

不建议第一轮同时加入类别配额、复杂干扰选择、蒸馏、排序损失和动态控制器；那样即便成绩变化，也难以识别原因。

### 6.3 为什么 A-GEM 是不可省略的近邻

A-GEM 用记忆参考梯度约束更新，目标是避免平均历史损失增加。([arXiv][8])

**【推论】**平均历史损失非增，仍可能由“良性改善抵消恶意损害”。本候选的实质差别必须是**把恶意旧正确决策与良性误报风险分别约束，同时允许修复原来的错误**，而不只是重新实现一次梯度投影。

可用有界乘子更新实现代理约束反馈，但若乘子只是对同一个 BCE 作动态重加权，没有独立风险观测和机制证据，仍不应包装为安全保证。

### 6.4 哪种组合才有希望形成真正的算法框架

**【推论】**较有研究价值的组合，是让记忆选择与风险约束共同工作：

- 当前更新暴露出哪一种风险约束不足，决定后续记忆需要保留哪类证据。
- 记忆不仅近似历史平均损失，还要覆盖**误报控制、旧恶意保护、当前恶意修复**的不同梯度或边界方向。
- 约束有余量时允许修复；接近违反时才增强相应保护，而不是始终提高所有稳定性惩罚。
- 反馈只能影响当前允许的训练过程和之后的记忆，不能回溯选择已删除的历史样本。

但这里必须正视先例：**GSS 已经把记忆视为约束压缩，ECBRS/PAPA 已经研究不平衡记忆与干扰估计。**所以“风险＋多样性＋Replay”这样的组合名称本身不能成立创新。需要证明你定义的**决策角色、修复可行性和记忆—更新耦合**具有这些近邻没有覆盖的作用。([arXiv][4])

## 七、最小消融：先拆记忆与更新，再谈框架

### 7.1 核心是一个 \(2\times2\) 因子实验

令：

- \(M\)：选定的一种有界记忆改造；
- \(O\)：选定的一种风险约束修复目标。

不要在同一轮同时比较许多 \(M\)、许多 \(O\)，然后根据最终测试选择组合。

| 实验臂       | 记忆                       | 更新目标    | 回答的问题                           |
| ------------ | -------------------------- | ----------- | ------------------------------------ |
| **ER**       | 原始 reservoir，总容量 200 | 原始 Replay | 固定基准                             |
| **ER＋M**    | 改造记忆，总容量 200       | 原始 Replay | 单独改记忆是否有增量                 |
| **ER＋O**    | 与 ER 相同的记忆规则       | 改造目标    | 单独改更新是否有增量                 |
| **ER＋M＋O** | 改造记忆                   | 改造目标    | 二者是否互补，而非某一个组件独自解释 |

**【推论】**这个四臂设计是机制识别的最低骨架，不足以独自证明创新。

### 7.2 再加入三个针对性对照

| 对照                                        | 必要性                             |
| ------------------------------------------- | ---------------------------------- |
| **ER＋PCT**                                 | 排除“只是已有回归约束”的解释       |
| **同类别／时间或角色配额的随机记忆**        | 排除“只是调了类别权重和配额”的解释 |
| **A-GEM，使用同容量记忆和统一模型训练合同** | 排除“只是已有平均风险投影”的解释   |

加上已有 Naive，形成**八臂完整比较，其中 Naive、ER 已有结果，新增六臂**。这不意味着现在就执行或用这些臂进行最终测试选优；它是固定一个候选机制之后，能够支持相应结论的比较集合。

若 \(M\) 的核心就是梯度多样性，GSS-Greedy 应成为其直接替代对照；若核心是 MIR 式取样，则必须有等暴露的随机取样及普通 MIR。**不必把所有文献都跑一遍，但不能跳过与你声称新增的机制最相近的方法。**

### 7.3 每个候选的最低“消融证据”

| 候选         | 必须被证明的机制，而非只看最终分数                                     |
| ------------ | ---------------------------------------------------------------------- |
| 单侧保护     | 比完整分数保持少抑制恶意错误修复，并维持必要的旧正确决策               |
| 条件覆盖记忆 | 同配额下，覆盖选择优于随机选择，而非仅靠增加恶意权重                   |
| 决策角色记忆 | 修复角色与良性控制角色各自有可分辨作用，不是角色名称不同、实际样本相同 |
| 风险约束修复 | 能在风险限制下提高修复能力，而不是以突破 FPR 或旧恶意保持为代价        |
| 联合框架     | 联合的机制收益不能完全被最好单组件或简单串联的已有方法解释             |

## 八、不接触未来标签的观测、预算与通过／失败门

### 8.1 允许的信息集合

**【推论／协议建议】**在年份 \(t\) 的更新阶段，方法只能使用：

$$
\mathcal I_t=
\left\{
D_t^{\mathrm{train}},
B_{t-1},
\theta_{t-1},
\text{已经允许保存的历史统计}
\right\}.
$$

当前年度训练标签在 Domain-IL 中是允许的；**当前年度测试标签、过去测试集作为调参反馈、未来年度标签及最终测试聚合成绩，都不能进入选择规则**。

如果需要训练内验证，其切分、时序和用途必须统一、事先固定；不能为某个新方法额外保留一个不计入预算的历史验证样本库。若现合同没有允许开发留出，则只能把它列作待批准的协议条件，不能默认为已经存在。

特别是，已知 2025 年只有 23 个恶意样本这一信息，**不能用于预先设计该年的配额、阈值或控制器策略**。到该年时，允许读取的仍然只是当时到达的训练分片。

### 8.2 200 容量与训练公平性

**【推论】**以下任一变化都会混淆“算法增量”与“资源增量”：

| 需要固定或单独记账的项目             | 原因                                                          |
| ------------------------------------ | ------------------------------------------------------------- |
| 总历史样本容量始终不超过 200         | 不能变成每年 200、每类 200，或外加未计数的 exemplar／验证缓存 |
| 入库计数按每个首次到达的训练样本推进 | 同一年度训练 10 轮不应把同一条样本当成 10 次独立入流          |
| 当前样本与回放样本的实际暴露次数     | 相同 epochs 不代表相同回放强度                                |
| buffer 更新时点                      | 不能从“年后入库”悄悄改成“年内反复优先使用新样本”              |
| 损失的求和／均值及类别权重           | 配额变化可能同时改变总正负梯度比例                            |
| 教师前向、虚拟更新、额外梯度计算     | 它们虽不增加 SGD 训练轮数，但增加计算和状态成本               |
| 被淘汰样本及其表征的保存             | 无限保存旧 embedding 也可能形成隐性记忆，而不是只存 200       |

MIR 虚拟更新如果被采用，应与现有 SGD 的实际更新定义相容；不能一边改变真实优化器，一边把变化归因于取样。

### 8.3 观测量：训练控制与最终评价必须分开

| 层次               | 可记录内容                                                         | 是否允许用于方法控制                                   |
| ------------------ | ------------------------------------------------------------------ | ------------------------------------------------------ |
| 当前训练与实际记忆 | 各角色数、margin、损失、虚拟干扰、梯度冲突、约束残差、正负修复变化 | 可以，在规则事先固定的条件下                           |
| 历史统计           | 已到达类别频率、记忆年龄、入库／淘汰计数                           | 可以，但不能恢复已删除数据                             |
| 冻结评价           | 逐年 AP/AUROC/FPR/FNR/Brier、旧样本翻转、最终 pooled 指标          | 只用于评价，不回灌选择                                 |
| 家族评价           | 已见／首次出现家族的错误分布                                       | 只有时间可用性已核准时才可进入训练；否则仅用于事后描述 |

**【推论】**还应保留两项防止“负向翻转被做低”的评价：

1. 每次更新前实际可被翻转的旧恶意正确样本数量，以及旧恶意整体 FNR。
2. 一个事先固定、各方法共同的旧恶意参考集合／参考正确性口径，仅用于最终评价。

这样能区分“确实保持旧能力”与“之前已漏掉很多，所以这次没有多少正确样本可被翻坏”。

### 8.4 通过／失败门：不替换现有资格门

**原门不变：**

$$
\mathrm{FPR}_{C}\le\mathrm{FPR}_{Naive},
\qquad
\mathrm{NF}^{old}_{C}<\mathrm{NF}^{old}_{Naive}.
$$

**【推论】**对于“补回 Replay 取舍”的新研究主张，可以另行事前冻结以下更强的增量检验，但不倒推修改原门：

| 层级             | 建议检验                                     | 失败含义                                 |
| ---------------- | -------------------------------------------- | ---------------------------------------- |
| 原资格           | 满足已有 FPR 与旧负向翻转门                  | 未满足则不能沿用现有资格                 |
| 保持 Replay 优势 | 相对 ER，FPR 和旧恶意负向翻转不劣            | 用安全保持损失交换召回，不是补回原取舍   |
| 修复原取舍       | 相对 ER，FNR 不劣、AP 不劣，且至少一项有改善 | 只继续降低翻转而没有修复，机制目标未达成 |
| 机制证据         | 优于同配额、同暴露和相近已有方法的解释       | 只能归因于工程因素或已有方法             |
| 资源合法性       | 200 总容量、统一模型训练合同、无评价反馈     | 超预算或信息越界则比较失效               |

“不劣”的容忍量必须来自**事前的任务要求**，不能用已经看到的 AP 差值或 FNR 差值恰好设置宽容边界。没有独立理由时，可以先报告零容忍的描述性比较，并把小差值标为不确定，而不是临时放宽门。

**【推论】**单 seed=42 不能说明跨初始化稳定性；83,420 条预测也不等于 83,420 个独立的年度模型实验。若之后报告区间，应保留年度结构和同一样本跨更新重复评价的相关性。2025 的小阳性计数应按实际评价分片报告，不能将发布全集的 23 个恶意样本直接当成测试阳性数量。

## 九、哪些可写成算法贡献，哪些目前只能算工程

| 做法                                             | 现阶段判断                                           |
| ------------------------------------------------ | ---------------------------------------------------- |
| reservoir 改成类别均衡、年份配额或近期加权       | **已有方法／工程设计**                               |
| 聚类、k-center、Isolation Forest、GSS 选代表样本 | **已有选择机制的应用**                               |
| 只保留高 entropy、高损失或 hard-negative         | **采样启发式**；且未必针对当前修复问题               |
| Replay 加 PCT、A-GEM 或普通蒸馏                  | **直接近邻基线，不是新框架**                         |
| 用家族／时间给固定损失权重                       | **任务化调参**，除非进一步提出新的可验证机制         |
| 单侧保护旧正确恶意决策                           | **有针对性的损失部件**，单独创新强度有限             |
| 决策角色条件记忆＋独立风险约束＋错误修复         | **具有算法研究潜力的外部候选**                       |
| 记忆选择由约束缺口反馈驱动，并证明与更新目标互补 | **较有可能形成框架级增量**，但尚未证实新颖性或有效性 |

**真正值得写入第三章的问题表述是：**

> 在全程仅保留 200 条历史样本的年度 Domain-IL 中，能否通过区分旧正确恶意决策、待修复恶意错误与良性误报边界，联合设计记忆和更新规则，使已有 Replay 的安全保持收益不再以当前恶意识别能力下降为主要代价？

这比“提出一个改进 Replay”更具体，也更容易被反例推翻。**【推论／外部候选】**

最后保留三个限制：MADAR 机制证据绑定已读 arXiv v1；PBR 的完整架构不能直接纳入冻结 MLP；本次方法构想已经受已公布的 2020—2025 聚合诊断启发，后续在同一批最终测试上迭代选优不能再宣称独立确认。即使新候选在这套发布特征上改善，也仍是 `screening_only`，不能自动获得严格历史预处理资格。

**本轮不判定任何候选有效，也不判定已经构成创新。最可检验的研究单位是“决策角色记忆 \(M\)”与“约束下修复目标 \(O\)”的分离及联合作用；PCT、条件随机记忆和 A-GEM 则是阻止把标准 Replay 改名当创新的关键对照。**
