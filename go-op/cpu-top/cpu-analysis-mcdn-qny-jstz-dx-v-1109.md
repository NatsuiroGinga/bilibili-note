## 四、根因判断

### 直接原因

CPU 暴冲**不是常驻业务进程导致的**。基线 4.4 核远没到饱和。暴冲的锯齿模式指向**周期性突发任务**。嫌疑最大：**7 个 python 瞬发实例**（合计 131%），配合 4~6 分钟的暴冲周期。
