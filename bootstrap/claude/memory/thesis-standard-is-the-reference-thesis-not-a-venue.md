**标准是「参照论文」，不是「顶会」。**

用户原话（2026-10-13）：

> 「我的目的不是投顶会，而是满足毕业论文要求即可，所以不用对齐顶会要求」
> 「把该写的写清楚、该标的标明白，达到他那个水准就够了」

**参照基准 = 朱焱雷第三章**。**他有什么，我有什么；他没有的，我不必有。**

**Why**：我在 2026-10-13 反复用「能否通过严格审稿」的尺子要求自己，因此空耗在四件事上——① 追求「唯一根治办法」这类排他性论证；② 追求「理论严格推出机制」的完全串联；③ 追求穷尽式文献检索；④ 追求顶会级可核差量。而参照论文本身**在实现层面就有缺口**（朱的 RGO 反应梯度 `dδ*/dθ = 0`，那一项恒为零，论文照样通过）。**不是说要学他的缺口，而是说不必为达到他不曾达到的标准而停滞。**

**How to apply**：

1. **判断「够不够」时先问**：参照论文有没有这一项？**没有 ⇒ 不必做。**
2. **不追求排他性论证**（「唯一」「必然」这类词）。给出**合理解释 + 可用近似 + 已标边界**即可。
3. **不追求把理论接到每一处**。**接不上的地方如实标出来，比硬接更有价值。**
4. **不因标准不够高而加码**——用户明确说「不用对齐顶会要求」时，**不要再拿顶会尺子量**。
5. **该做的两件事恒定**：**该写的写清楚**（机制/理论/算法/实验完整）、**该标的标明白**（证据状态、适用边界、近似与待证逐条标注）。
