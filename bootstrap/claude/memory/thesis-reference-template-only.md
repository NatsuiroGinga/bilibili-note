王童童的网络攻击检测大模型开题（PINN+课程式RL）写作中：同门或参考论文（如朱焱雷《加密流量博弈对抗防御》）只作**论文结构与组织模板**参考——章节安排、方法章模板（引言→问题定义→方法框架→算法实现→理论分析→实验→小结）、实验组织、原型系统架构形式。**方法、公式、创新点必须自主**，不得借用。

**Why:** 用户明确强调"不是抄袭他，而是作为模板，内容都是我自己的，创新点也是我自己的"。朱无 PINN/物理信息/守恒不变量/自构造测试床，开题的核心创新与之无重叠；"双维度难度"等形式相似只是课程学习通用范式，非借鉴。

**对标的是正结果标准（2026-08-07 用户纠正）**：朱的第三章是**正结果论文**——DS-RGO 相对最强外部基线 ET-BERT 提升 `+4.5～+5.1` 个百分点、BUPT-CNN `+3.3～+4.1`，其 2 个定理在证明**方法为何有效**，**全章没有负结果**。因此"对标朱论文"= 第三章必须交付一个**能跑赢基线的方法**。

**禁止擅自降标准。** 当实验连续失败时，不得把"负结果 + 诊断协议成章"当作退路提给用户——那是在用户未同意的前提下降低了目标。若判断现有资产做不出对标量级的正提升，**明说做不出并给证据**，交用户与导师决策（换数据、换任务或调整预期），而不是自行放低标准。给不出答案好过悄悄换一个更容易的答案。

**How to apply:** 写笔记/开题稿涉及参考论文时，用"结构同构（非内容借用）"而非"迁移/可复用/可借鉴"措辞；映射表只列结构对应，不暗示方法借用。开题的双维度难度公式（物理残差+决策方差）源自其 PINN+GRPO 设计，自行推导。相关笔记：[[朱焱雷-加密流量博弈对抗与高效训练]]。相关记忆：[[falsify-directions-with-experiments-not-speculation]]。
