用户 2026-09-03：「**禁止在本机执行实验，你的 agent 把本机搞死机了。**」

**Why**：我在两份子代理简报里写了「纯本机 CPU／MPS，不碰 GPU」，以为不占 GPU 就安全。
**错在把「不占 GPU」当成「不占资源」**——本机 CPU 与内存同样会被打满。当天三样叠加：
真实 FT-Transformer 多批次多精度前向反传、4 并发 MinerU 转换、
以及我停掉转换代理后**未确认子进程退出就重起的另一轮 4 并发**（实际翻倍），本机死机重启。

**How to apply**：
- 训练、评价、张量计算、梯度测量、多批次数值探针 → **一律服务器**。
- 本机只做：读文件、秒级配置校验、单次导入检查、文档与检索。
- 本机重任务并发不超过 2，合计并发度不超过 4；派发前 `pgrep` 确认无同类在跑。
- **`TaskStop` 只停代理，不停它启动的脚本与子进程**——停完必须核实进程真的没了，
  再起同类任务。
- 子代理简报里写死「不得在本机执行任何实验计算」，并指明该测量在服务器的哪个入口跑。

与 [[no-sleep-polling-use-background-tasks]] 同属「别把本机当算力」的一类；
那条管别空等，这条管别把本机跑垮。
