复现外部结果、设定字段预算与评价协议时，**照已发表论文怎么做就怎么做**，不要自己发明一套分类或理由去论证某个选择更合理。

用户在 2026-08-12 连续两次纠正："对齐论文，不要自己臆想"、"以后不要再自己臆想了，对齐已有论文"。

**2026-08-13 用户补充澄清：这条是"减少臆想"，不是"不许创新"。** 两者的区别不在于想法是不是自己的，而在于：

| | 臆想（禁止） | 创新（本职工作） |
| --- | --- | --- |
| 证据 | 无，靠语言合理性 | 有实测或文献支撑 |
| 用法 | 当成既定依据去做决策 | 当成待验证假设去设计实验 |
| 可证伪 | 通常不可 | 必须预先写出证伪条件 |

反例（臆想）：拿到"77 vs 83 字段"后自造「身份字段 vs 行为特征」分类学，论证端口该不该禁。
正例（创新）：2026-08-13 设计的因果前缀均值上下文 `ctx = cumsum(h)/cumsum(mask)`——
论文里没有，是自己想的，但它是受控消融的一档、有预注册判据，实测 AP `0.1590 → 0.2879`，
超过全量 XGBoost `0.2244` 与所有已发表序列模型。**这是创新，不是臆想。**

**触发情形**：当时实验测出本课题字段预算 77 维、Dijk 2026 用 83 维，差 6 个。我没有直接采用论文口径，而是自造了一套「身份字段 vs 行为特征」的分类学，论证端口和协议禁得过严、IP 类禁得对，还据此提议做字段泄漏审计。那套分类论文里没有、仓库规则里也没有，是我编的。

**为什么**：自创的分类和理由无法被审稿人核验，也无法追溯到任何来源。它看起来是分析，实际是把推测包装成依据——与[用实验反驳方向](falsify-directions-with-experiments-not-speculation.md)是同一类错误的不同表现：一个用推理代替实验，一个用自创框架代替文献。

**如何执行**：
- 复现外部基线时严格照论文参数，论文没写的标为「未在全文中定位」，不补猜。
- 字段或预处理无法等同时，按仓库规则标「论文约束独立复现」并单列差异，不混排、不用一条冒充另一条。
- 想改判据或边界时，先找已发表先例；找不到就如实说没有先例，而不是自己论证一套。
