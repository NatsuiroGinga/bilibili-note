# 可索引论文入库检查表

- [ ] 已读取根、`raw/`、`wiki/` 局部规则和 `SCHEMA.md`。
- [ ] 已按 DOI、arXiv、题名和双向链接查重。
- [ ] 原始 PDF 位于 `raw/papers/`，哈希与来源已记录。
- [ ] 全文已核验，题录与身份不是从正文首个 DOI 猜测。
- [ ] YAML 使用 `paper-note-search/v1`，列表字段类型正确。
- [ ] `source_pdf` 存在，`fulltext_verified: true`。
- [ ] 论文可以支持、论文不能支持、实验结果与负证据、与本课题的关系四个分区齐备。
- [ ] 公式、数值和关键论断带印刷页或 PDF 页锚点。
- [ ] 已更新唯一对应方向的 `INDEX.md`。
- [ ] Zotero 条目与附件已复用或明确记录阻塞。
- [ ] 严格 lint 已通过，没有自动批量改写旧笔记。
- [ ] 增量构建收据含复用与重嵌入计数。
- [ ] 预先冻结的检索意图能够命中正确论文和证据块。
