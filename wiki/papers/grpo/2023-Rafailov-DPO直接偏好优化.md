# DPO：把 RLHF 化成一个分类问题

> Rafael Rafailov 等（斯坦福大学），2023，arXiv:2305.18290v3 · 27 页 · 原件 `raw/papers/grpo/2023-Rafailov-DPO-Direct-Preference-Optimization.pdf`

## 证据等级

**E3 全文级**。原件已下载（arXiv 2305.18290v3，1.2 MB，27 页），正文与附录推导抽样读完；公式经 MinerU `extract` 模式转 LaTeX 后回原文页核对，页码锚点用逐页文本索引确认（`pypdf` 只读检索，2026-09-10）。

**收录理由与家族定位**：DPO **不是 GRPO 家族成员**——它是**离线偏好优化**范式，与在线 RL 范式并列，是任务书所指"基础范式"两支中的第二支。本目录收录它是为了给家族谱系提供**家族外直接对照**：GRPO 家族的"在线、组相对、需要 rollout"三条性质，恰好在 DPO 上全部相反。**引用时不得把 DPO 算作 GRPO 变体。**

## 一句话

RLHF 的目标函数可以被重新参数化，让"最优策略"直接由策略本身与参考策略的比值给出；于是不需要显式奖励模型，也不需要采样-评估-更新的 RL 循环，直接用偏好对做监督学习即可。

## 机制（§4–§5，p.4–7）

### 推导链（§4，式(5)–(7)，p.4）

1. **KL 约束的奖励最大化**（式(1)–(3)，p.2–4）：`max_π E[r(x,y)] − β·D_KL(π‖π_ref)`。
2. **闭式最优策略**（式(4)，p.4）：`π_r(y|x) = (1/Z(x)) · π_ref(y|x) · exp( (1/β)·r(x,y) )`，`Z(x) = Σ_y π_ref(y|x)exp((1/β)r(x,y))`。
3. **反解奖励**（式(5)，p.4）：`r(x,y) = β log( π_r(y|x)/π_ref(y|x) ) + β log Z(x)`——**奖励可用策略与参考策略的对数比表示**，配分函数只依赖 `x`。
4. **代入 Bradley-Terry**（式(6)，p.4）：`p(y_w ≻ y_l | x) = σ( r(x,y_w) − r(x,y_l) )`，**`log Z(x)` 在差值中被消掉**。
5. **DPO 损失**（式(7)，p.4）：`L_DPO(π_θ; π_ref) = −E_{(x,y_w,y_l)}[ log σ( β log(π_θ(y_w|x)/π_ref(y_w|x)) − β log(π_θ(y_l|x)/π_ref(y_l|x)) ) ]`

**梯度直觉**（§4，p.4）：损失对 `π_θ` 的梯度是"提高 `y_w` 似然、降低 `y_l` 似然"，且**权重由隐式奖励估计错得有多离谱决定**——`σ` 项的加大正好抑制已经分对的样本。

### 两条理论性质（§5，p.6–7）

| 性质 | 内容 | 位置 |
|---|---|---|
| 隐式奖励模型 | `r*(x,y) = β log(π_θ*(y|x)/π_ref(y|x))` 是 DPO 学到的策略对应的隐式奖励；**论文据此论证 DPO 能表达 RLHF 目标奖励类中的任意奖励**（在 BT 模型下唯一到常数项） | §5.1，p.6 |
| actor-critic 的不稳定性 | 作者论证在 KL 约束下，actor 与 critic 的参数化之间存在**耦合**，标准 actor-critic 需要同时拟合二者，容易不稳定；DPO 把问题变成单一策略的监督学习 | §5.2，p.6 |

**重要限定（§5.1，p.6）**：作者明确指出该等价性成立的前提是**偏好由 Bradley-Terry 模型生成**；在 Plackett-Luce 等更一般的偏好模型下需相应改写（附录 A.3）。

## 可迁移机制

1. **"奖励 = 策略与参考策略的对数比"是一条结构恒等式**（式(5)，p.4）：凡是"策略相对参考模型偏移多少"的量，都可以解释为隐式奖励。**这为"没有显式奖励时如何构造训练信号"提供了一个通用框架。**
2. **配分函数在成对差分中被消掉**（式(6)，p.4）：这是 DPO 实用的关键——`Z(x)` 不可计算，但因为只依赖 `x`，成对比较时自动消失。**凡"绝对量不可算、但差值可算"的场景，这都是一条可复用的技巧。**
3. **由损失权重反映"估计错得多离谱"**（p.4）：DPO 的梯度权重是隐式奖励的错误程度。**这与 GRPO 家族的"按优势大小加权"是同一种"难例加权"思想的不同实现**。
4. **把隐式奖励当作可读出的诊断量**（§5.1，p.6）：训练后可用 `β log(π_θ/π_ref)` 给任意样本打分。**在不允许单独训练奖励模型的场景下，这是一个近乎免费的评分器构造方法**。
5. **方法选择的前提条件写法**（§5.2，p.6）：作者用"actor 与 critic 的参数耦合"来论证一类方法的困难，而不是靠实验对比。**这种"结构论证 + 实验对照"的组合是本目录中最可借鉴的论证形态**。

## 不能直接声称内容

- **不能把 DPO 算作 GRPO 家族成员**：DPO 是**离线**偏好优化，无 rollout、无组相对基线、无重要性比率。它与 GRPO 是并列的两支范式。
- **不能把 DPO 的等价性写成"无条件成立"**：隐式奖励与 RLHF 目标的等价**依赖 Bradley-Terry 偏好模型**（§5.1，p.6）；偏好数据不完全符合 BT 时该等价性不成立。
- **不能声称 DPO 在所有任务上优于 PPO**：作者在部分任务上报告"相当或更好"，在受控情感与摘要上更好（§6）；这是 2023 年的实验规模。
- **不能忽略 DPO 的已知失效模式**：本文自身未系统研究 DPO 在分布外或奖励过度优化下的行为；后续文献（IPO／KTO／SimPO 等）正是针对这些缺口提出的，**引用 DPO 时必须把它与这些变体区分开**。
- **不能把"不需要奖励模型"写成"不需要任何偏好数据"**：DPO 需要的正是成对偏好数据；在没有偏好对的场景（如纯无标签适应）中它并不直接适用。
- **不能引用正文未列出的具体胜率数值**：部分结果以图呈现，本笔记不提供、也不得补造分数。

## 与课题的关系

- **对 DRIFT 第三章的"无标签适应"场景是一道边界**：DPO 需要**成对偏好数据**，而无标签适应场景没有偏好对。因此 DPO 及其变体（IPO／KTO／SimPO，题录已核验见索引，本轮未入库）在无标签场景中**不能直接使用**，只能作为"若有历史偏好或人工反馈时的基线"。
- **与本目录 critic-free 一线的关系**：DPO 用"不需要在线采样"换掉了 RL 循环；GRPO 用"不需要 critic"换掉了价值模型。**两条路线的取舍维度不同**，不能简单比较优劣。
- 作为家族外对照，它的价值在于**界定 GRPO 家族的适用范围**：GRPO 家族的前提是"能采样、能对样本打分"；当这两个前提不成立时，手段应是 DPO 式的离线方法或纯自监督适应，而不是 GRPO 变体。
