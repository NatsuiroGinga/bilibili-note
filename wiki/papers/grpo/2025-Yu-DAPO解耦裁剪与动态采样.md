# DAPO：解耦裁剪与动态采样

> Qiying Yu 等 35 人（ByteDance Seed、清华 AIR、HKU、SIA-Lab），2025，arXiv:2503.14476v2 · 16 页 · 原件 `raw/papers/grpo/2025-Yu-DAPO.pdf`

## 证据等级

**E3 全文级**。原件已下载（arXiv 2503.14476v2，826,801 字节，16 页），正文与附录逐页读完；公式经 MinerU `extract` 模式转 LaTeX 后回原文页核对。

**可精确引用**：表 1 的逐项增益、§4.1 的全部超参、式(10)(11)(12)(13) 的完整形式、DAPO-Math-17K 的构造方式。
**不可精确引用**：训练曲线（图 1–图 8）中的具体数值只在图内，正文未给数字。

## 一句话

DAPO 不提出新的优化目标，而是把 GRPO 在长思维链大规模训练中的四个具体失效（探索被压制、全对全错组零梯度、长响应 token 贡献被稀释、截断惩罚噪声）各配一个可独立开关的工程修正，并把增益逐项记账。

## 背景：问题的演进（§1–§2，p.1–4）

- **PPO**（§2.1，p.2）：actor-critic，价值模型与策略模型规模相当，显存与算力开销大，且价值估计的可靠性难保证。
- **GRPO**（§2.2，式(4)–(6)，p.3）：去掉价值模型，组内奖励归一化得相对优势 `Â_{i,t} = (r_i − mean({R_i}))/std({R_i})`；沿用 PPO 的对称裁剪，另加直接写进损失的 KL 惩罚项。**注意 GRPO 的损失是样本级（sequence-level）的**——先算每条生成序列内的均值再跨样本平均（p.3）。
- **去掉 KL 项**（§2.3，p.3）：长思维链训练中模型分布可与初始模型显著发散，KL 限制非必要，DAPO 直接删除。
- **规则化奖励**（§2.4，式(7)，p.4）：不用奖励模型（避免奖励作弊），直接用可验证任务的最终答案正确性给 `+1`／`−1`。
- **作者报告的两类病灶**（§1，p.1–2、§3.1，p.4）：熵坍塌（策略熵随训练迅速下降、同组响应近乎相同）与梯度信号衰减（全对组的优势为零）。

## 方法核心（§3，p.4–8）

### DAPO 目标（式(8)(9)，p.4）

`J_DAPO(θ) = E[ (1/Σ_i|o_i|) Σ_i Σ_t min( r_{i,t}(θ)Â_{i,t}, clip(r_{i,t}(θ), 1−ε_low, 1+ε_high)Â_{i,t} ) ]`，约束 `0 < |{o_i | is_equivalent(a,o_i)}| < G` …(8)

与 GRPO 的三处形式差异：①裁剪区间**上下解耦**；②归一化分母是**整批总 token 数**而非逐样本长度再平均；③约束条件把全对/全错组排除在外。优势仍为组内标准化（式(9)）。

### ① Clip-Higher（§3.1，式(10)，p.4–5）

- 诊断：上界裁剪限制探索——`ε=0.2` 时，`π_θold` 为 0.01 与 0.9 的两个动作，被增幅后的概率上界分别是 0.012 与 1.08，**高概率的「利用 token」几乎不受约束，低概率的「探索 token」却被卡死**（p.4）。
- 实证：被上裁剪 token 的平均概率 `π_θ(o_i|q) < 0.2`（图 3a，p.5）。
- 处置：**把 ε 拆成 ε_low 与 ε_high 并抬高 ε_high**；ε_low 保持不动，因为抬高它会把低概率 token 的概率压到 0，导致采样空间坍缩（p.5）。

### ② Dynamic Sampling（§3.2，式(11)，p.5）

- 诊断：GRPO 下若某 prompt 的 G 条输出全对或全错，组内优势为零、策略梯度为零；训练中准确率为 1 的样本数持续增加（图 3b），**每批有效 prompt 数不断下降**，梯度方差变大。
- 处置：**过采样并过滤掉准确率为 0 或 1 的 prompt**，直到凑满一整批；代价是每批采样量动态可变（训练前持续采样直到批被非零梯度样本填满）。
- 图 6（p.8）称收敛时间反而缩短，因为所需训练步数减少。

### ③ Token-Level Policy Gradient Loss（§3.3，式(12)，p.6）

- 诊断：GRPO 的样本级损失给每条样本**等权**，长响应里的 token 对总损失贡献被不成比例地压低。两个后果：高质量长样本中的推理模式学不到；含乱码/重复的低质量长样本惩罚不足，**熵与响应长度不健康地上升**（图 4a/4b）。
- 处置：改为 `1/Σ_{i=1}^{G}|o_i|` 归一化，**长序列对整体梯度的影响更大**；从单 token 视角看，某生成模式无论出现在多长的响应里都被同等强化或抑制（p.6）。

### ④ Overlong Reward Shaping（§3.4，式(13)，p.6–7）

- 诊断：默认给截断样本惩罚性奖励会把**本来合理的推理过程**因过长而惩罚，向训练注入奖励噪声。
- 两步处置：
  1. **Overlong Filtering**：屏蔽被截断样本的损失（图 5 显示显著稳定训练并提升表现）。
  2. **Soft Overlong Punishment**（式(13)，p.7），加在原始正确性奖励上：
     `R_length(y) = 0`，若 `|y| ≤ Lmax − Lcache`；`= ((Lmax − Lcache) − |y|) / Lcache`，若 `Lmax − Lcache < |y| ≤ Lmax`；`= −1`，若 `|y| > Lmax`。

- **算法 1**（p.7）给出完整流程：每步采样一批 → 更新旧策略 → 每问采 G 条 → 算奖励 → 按式(11)过滤进动态采样缓冲区 → 缓冲区不足则跳过该步 → 计算优势 → 做 μ 次策略更新。

### 数据集变换（§3.5，p.8）

答案统一转成**整数**以简化规则解析：例如原答案为 `(a+√b)/c` 形式时，改写问题使期望答案变为 `a+b+c`。变换后得到 **DAPO-Math-17K**：17K 条 prompt，每条配一个整数答案。

## 实验结果（§4，p.8–10）

**训练配置（§4.1，p.8）**：verl 框架；AdamW，常数学习率 `1e-6`，20 个 rollout step 线性 warmup；prompt batch 512，每 prompt 采 16 条响应；mini-batch 512（即每个 rollout step 做 16 次梯度更新）；Overlong Reward Shaping 的期望最大长度 16,384、软惩罚缓存 4,096，故最大生成长度 20,480 token；Clip-Higher `ε_low=0.2, ε_high=0.28`；AIME 评测重复 32 次报 avg@32，temperature 1.0、top_p 0.7。

**主结果（表 1，p.9）——逐项叠加的增益记账**：

| 配置 | AIME24 avg@32 |
|---|---|
| DeepSeek-R1-Zero-Qwen-32B（外部参照） | 47 |
| Naive GRPO | 30 |
| ＋ Overlong Filtering | 36 |
| ＋ Clip-Higher | 38 |
| ＋ Soft Overlong Punishment | 41 |
| ＋ Token-level Loss | 42 |
| ＋ Dynamic Sampling（即 DAPO） | 50 |

- 正文另有两条陈述（§4.2，p.8）：AIME 2024 准确率「从接近 0% 提升到 50%」，且**只用 DeepSeek-R1-Zero-Qwen-32B 所需训练步数的 50%**。
- token-level loss 的增益虽小，但作者称其**提升训练稳定性并使长度增长更健康**（p.9）。

## 可迁移机制

1. **失效分解 + 逐项记账的实验范式**（表 1，p.9）：把「一个改进的算法」拆成四个可独立开关的组件，逐项报告增量。这是本课题做机制消融时可直接照搬的报告结构（也提示：DAPO 的最终 50 分里有 6 分来自两个「奖励整形」类组件，而非优化器本身）。
2. **裁剪的非对称性**（p.4–5）：裁剪上下界对**低概率动作**与**高概率动作**的作用完全不同；对称裁剪会系统性抑制稀有事件的学习。任何带重要性比裁剪的在线更新都可套用这一诊断（先测被裁剪样本的分数分布，再决定是否解耦上下界）。
3. **零梯度组的过滤**（p.5）：当组内反馈全同（全对/全错）时组相对优势恒为零，该样本对本步无信息；**过滤而非加权**是处理它的最简手段。代价是采样成本可变。
4. **指标监测清单**（§4.3，p.9）：列表包括响应长度、训练奖励、actor 熵、生成概率——并给出两条反直觉观测：①长度并非单调上升，会长期停滞甚至下降，需**与验证集准确率联合判读**；②**训练集奖励与验证集准确率相关性很低**，即训练奖励升高不等于泛化变好（p.9）。后者对本课题的「验证集/训练集分离」有直接警示意义。
5. **可验证奖励的构造依赖答案规范化**（§3.5，p.8）：把答案强制转成整数是把解析误差降到最低的工程手段，但**改变了任务分布**。

## 不能直接声称内容

- **不能把 DAPO 的增益搬到本课题的任务上**：全部实验是数学推理（AIME24），奖励是**可验证的规则奖励**（答案等价性），本课题的检测指标不是可验证奖励，优势估计的噪声结构不同。
- **不能引用「准确率从 0% 到 50%」作为算法效率证据**：该句是图 1 的定性描述（§4.2，p.8），与表 1 的 30→50 不是同一对照；两者不可混用。
- **不能声称四项修正的增益可加性成立**：表 1 是**固定顺序的累积**（先 Overlong Filtering 再 Clip-Higher…），作者未做任意子集组合，顺序效应与交互效应未知。
- **不能把 DAPO-Math-17K 的整数答案构造当作通用做法**：它利用了数学答案可符号等价判定的特性；对开放式或连续值任务无对应形式。
- **不能声称「去掉 KL 项普遍安全」**（§2.3，p.3）：该结论的适用范围被作者限定在长思维链推理训练，理由是分布允许显著发散；对齐类任务（RLHF）明确被排除在外。
- **不能把 47 分当作「R1-Zero 方法」的严格基线**：表 1 中该行是引用外部结果，训练数据、步数与 DAPO 并非同预算。

## 与课题的关系

- 与 [[2025-Liu-DrGRPO无偏优化与R1-Zero再审视]] 的修正线**正交**：Dr. GRPO 修的是优势归一化中的两类偏置（除以 `|o_i|` 与除以 `std(R)`），DAPO 修的是裁剪区间、采样过滤与损失归约。同一现象（长度偏置/膨胀）在两条线上有不同归因，**引用时不得合并成同一结论**。
- 与 [[2025-Zheng-GSPO序列级重要性比率]] 的对照点：DAPO 把归一化分母改成**整批总 token 数**，GSPO 把重要性比率改成**序列级**；两者都在回应「token 级加权不当」，但落点一个是损失归约、一个是比率定义。
- **可迁移到本课题的形式**：机制消融表的记账结构（§4.2，表 1）与监测指标清单（§4.3）。

## 疑问 / 待验证

- 表 1 未给方差或种子数：单次运行的 6 分增量是否超出随机波动，论文未报告。
- Dynamic Sampling 的采样成本只有定性描述（「整体训练时间未显著受影响」，p.9），没有墙钟或 GPU 小时的量化对照。
- Clip-Higher 的 `ε_high=0.28` 是调参结果（p.8 称「有效平衡探索与利用」），论文未给出 ε_high 的敏感性扫描（正文只报告 ε 的图 2 对照）。
