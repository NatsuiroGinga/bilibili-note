## 一句话

GRPO 用固定区间的硬裁剪把越界 token 的梯度**清零**，SAPO 改成温度控制的 sigmoid 软门把它们**平滑压低**，从而在保持序列级一致性的同时不丢弃整条序列的学习信号。

## 机制（§2–§4，p.2–6）

### 目标与门函数（式(5)(6)，p.3）

`J(θ) = E[ (1/G) Σ_i (1/|y_i|) Σ_t f_{i,t}(r_{i,t}(θ)) · Â_{i,t} ]` …(5)

`f_{i,t}(x) = σ(τ_{i,t}(x−1)) · 4/τ_{i,t}`，`τ_{i,t} = τ_pos if Â>0 else τ_neg` …(6)

其中 `σ` 为 sigmoid，`r_{i,t}(θ)` 与 `Â_{i,t}` 与 GRPO 同定义（式(2)）。

### 梯度形式（式(7)(8)，p.3）

`∇J = E[ (1/G) Σ_i (1/|y_i|) Σ_t w_{i,t}(θ) · r_{i,t}(θ) · ∇logπ_θ(y_{i,t}|·) · Â_{i,t} ]` …(7)

`w_{i,t}(θ) = 4 p_{i,t}(1−p_{i,t})`，`p_{i,t} = σ(τ_{i,t}(r_{i,t}−1))` …(8)

- `w` 在 `r=1` 处取最大值 1，两侧近似指数衰减 → **连续信任域**，既防梯度消失也防更新过大（p.3）。
- 关键性质（p.3）：在 `r=1` 处软门梯度**等于未裁剪目标** `r·Â`，与 `τ` 无关，因此完全保留 on-policy 行为；`4/τ` 因子正是为此而设。

### 与 GSPO／GRPO 的等价与差异（§4，式(10)–(15)，p.4–6）

统一代理目标（式(10)，p.4）`J = E[(1/G)Σ_i (1/|y_i|)Σ_t f_{i,t}(r_{i,t})Â_{i,t}]`，三法只差 `f`：

| 算法 | 门函数 | 位置 |
|---|---|---|
| SAPO | `f = (4/τ_i)·σ(τ_i(r−1))`，`τ_i` 按优势符号取 | 式(12)，p.5 |
| GRPO | `f = min(r, 1+ε)` 或 `max(r, 1−ε)`（按优势符号） | 式(13)，p.5 |
| GSPO | 同上，但作用在序列比率 `s_{i,t}` 上，**序列内 token 不变** | 式(14)，p.5 |

- **序列级软门极限**（§4.1，p.5–6）：在"on-policy 小步长 + 序列内 token 对数比率低离散"假设下，token 门的平均收敛到 `g(log s_i) = sech²((τ_i/2)·log s_i)`。即 SAPO **既约化为 GSPO 型序列公式，又保留连续信任域**。
- **GSPO 的失效模式**（p.1、p.5–6）：一条序列里出现少数高度 off-policy token 时，GSPO 把整条序列梯度压掉；SAPO 只压低越界 token，保留近 on-policy token 的学习信号 → 样本效率更高。

### 为什么正负优势要用不同温度（§3，式(9)，p.3–4）

对 logits 求导（式(9)，p.3）：正优势抬高被采样 token 的 logit、压低全部未采样 logit；负优势反之，**抬高大量未采样 token 的 logit**。LLM 动作空间是几十万词表而每步合意动作极少，故负梯度会扩散到大量无关 token——提供一些正则但主要引入不稳定，off-policy 时更甚。故设 `τ_neg > τ_pos`，让负 token 的梯度衰减更快。

## 可迁移机制

1. **软门替代硬裁剪的结构判据**（式(8)，p.3）：只要门函数的一阶导在 `r=1` 处为 1、两侧单调衰减，就能同时保住 on-policy 梯度与信任域。该构造只依赖**重要性比率与优势符号**，不依赖奖励是否可验证——见下条。
2. **奖励不可验证时的可迁移性（本课题推论，非论文主张）**：SAPO 的门函数只读取 `r_{i,t}` 与 `sign(Â_{i,t})`，不读取奖励的内部结构，因此**机制上不要求奖励可被程序核验**。这为"非可验证奖励／无标签适应"场景提供了一个不需要改动奖励设计即可稳定训练的候选更新规则。**论文本身没有做非可验证奖励实验**，此条属本课题推论，须实测证伪（最小验证：在自有任务上把 GRPO 的硬裁剪替换为式(6) 软门，同预算对照）。
3. **正负不对称衰减**（式(9)，p.3–4）：负向更新会抬高大量未采样动作的概率，在**动作空间大而合意动作稀疏**时尤其有害。该论证不依赖 LLM，凡"输出空间远大于合意输出"的检测/分类式策略都可考虑对负优势设更快衰减。
4. **诊断法：区分"清零"与"压低"**（§4.1，p.5–6）：若一次批量里少数越界样本导致整组梯度被丢弃，说明采用的是硬裁剪；把该样本单独统计即可量化被浪费的学习信号。
5. **温度消融作为机制检验**（§5.1，p.7）：若把负优势温度调到比正优势更低会显著变差，则该任务的不稳定确实主要来自负向梯度——这是一个廉价的前置诊断，可用于决定是否采用不对称设计。

## 不能直接声称内容

- **不能声称 SAPO 支持非可验证奖励是被论文证明的**：SAPO 的受控实验全部是数学推理（可验证奖励），Qwen3-VL 实验是数学／代码／逻辑推理与多模态，**论文从未评测过不可验证奖励或人类偏好奖励**。"机制上不要求可验证奖励"只是从门函数形式做的推论。
- **不能引用具体基准分数**：图 4–图 6 内的数值正文未列出，本笔记不提供、也不得补造。
- **不能把"更稳定"写成已独立复现**：对照组超参沿用 GSPO 论文配置（§5.1，p.7），GRPO 侧还额外装了 routing replay；比较公平性未经第三方验证。
- **不能把 SAPO 与路由回放解耦的结论外推到无 MoE 结构的模型**：论文的动机段（p.1、§5.1）以 MoE 的 token 比率高方差为主要场景，dense 模型上的收益幅度论文未单列。
- **不能把 SAPO 的成功当作"软门控普遍优于硬裁剪"**：论文只对比了 GSPO／GRPO-R2 两条基线，未与 DAPO、GMPO、GTPO 等其它修正线同预算对照。

## 疑问 / 待验证

- 正文未报告：训练算力预算的具体数值、"同等预算"的判定口径、种子数、方差。
- 温度 `τ` 的最优值是否随模型规模／任务迁移，论文只给了 30B 级的三个点。
- §4.1 的序列级软门极限依赖"序列内 token 对数比率低离散"假设；在长序列、强 off-policy（如异步训练）下该假设是否成立，论文未给边界。
- SAPO 与 `2602.19345`（Smooth Gate Functions for Soft Advantage Policy Optimization）的关系：后者也提出用平滑门替代硬裁剪，是本笔记的**同题近邻**，本轮未取得全文，不作比较。
