# GMPO：用几何平均抑制 token 级异常值

> Yuzhong Zhao, Yue Liu 等（UCAS / CUHK / HKUST / Microsoft Research），2025，arXiv:2507.20673v3 · 16 页 · 原件 `raw/papers/grpo/2025-Zhao-GMPO-Geometric-Mean-Policy-Optimization.pdf`

## 证据等级

**E3 全文级**。原件已下载（arXiv 2507.20673v3，5.0 MB，16 页），正文与消融逐节读完；公式经 MinerU `extract` 模式转 LaTeX 后回原文页核对，页码锚点用逐页文本索引确认（`pypdf` 只读检索，2026-09-10）。

**机制矛盾的裁决**：任务书提到"GMPO 两份二手来源机制描述矛盾"。核验结论：**两份二手来源都不够准确**。原文的机制是**用几何平均替换算术平均作为 token 级奖励的聚合算子**（式(3)，p.3），并对聚合结果取绝对值后乘 `sgn(Â)` 以保留优势符号（式(4)，p.3）。它不是"优化重要性采样比率"，也不是"用几何平均做基线"。以本笔记为准。

## 一句话

GRPO 对 token 级奖励取算术平均，一个极端比率就能主导整个梯度；GMPO 取几何平均，单个异常值会被其余 token"拉平"，因此训练更稳、熵衰减更慢。

## 机制（§3，p.2–4）

### 目标（式(3)(4)，p.3）

GRPO 侧（式(2)，忽略裁剪项）等价于 `J_GRPO(π) = E[ (1/|o|) Σ_t ρ_t(θ)·Â ]`，即 token 级奖励的**算术平均**。

GMPO 侧取几何平均并保留符号：

`J_GMPO(π) = E[ { Π_{t=1}^{|o|} | min[ ρ_t(θ)Â , clip(ρ_t(θ), ε_low, ε_high)·Â ] | }^{1/|o|} · sgn(Â) ]` …(式(3)(4) 的合并形式，p.3)

- 几何平均对极端值的敏感度低于算术平均：任一 token 的极端比率被开 `|o|` 次方后被其余项稀释。
- `sgn(Â)` 保证优势符号不被乘积与绝对值操作抹掉。
- **插拔式**：只改聚合算子，组内优势定义、裁剪区间、KL 处理（跟随 Dr. GRPO 省略 KL）全部不变（p.2、§3.1）。

### 理论分析（§3.2，p.3–4）

对两目标求梯度，均为**生成 token 的策略梯度加权和**，差别只在权重：

| | token `o_{i,t}` 的梯度权重 | 位置 |
|---|---|---|
| GRPO | 含该 token **自己的**比率 `ρ_{i,t}(θ)`；单个极端 ρ 直接放大／缩小该 token 梯度 | p.4 |
| GMPO | 含**整条序列**所有比率的几何平均 `(Π_k ρ_{i,k}(θ))^{1/|o_i|}` | 式(15)，p.4 |

作者据此论证：GMPO 的权重更平衡、对异常值更鲁棒，目标值取值区间更窄（p.3–4），即优化目标方差更低。

## 可迁移机制

1. **换聚合算子而非换裁剪**（式(3)，p.3）：稳定性问题的来源可以是**聚合方式**而非裁剪区间。凡"多条局部信号聚合成一个目标"的设计，都应检验算术平均是否被极端分量主导；几何平均是一个无需额外超参的替代。
2. **权重来源的粒度判据**（§3.2，p.4）：GRPO 的 token 权重来自该 token 自身，GMPO 来自整条序列。这给出一个通用问题——**局部权重应当来自局部证据还是全局汇总**。在噪声大、单点不可靠的场景（如长序列中的个别异常 token、单个可疑样本），用全局汇总做权重更稳。
3. **"抑制异常值"与"扩大探索"可以同时达成**（§4.4，p.5）：作者观测到 GMPO 在抑制极端比率的同时**熵更高、KL 更低**。这提供了"稳定性不等于熵坍塌"的实证反例，可用于反驳"要稳就得牺牲探索"的默认假设。
4. **廉价诊断**：训练中直接画重要性比率 ρ_t 的分布宽度（图 1 右、图 2）。若分布持续变宽，说明聚合算子被异常值主导。

## 不能直接声称内容

- **不能把 GMPO 写成"用几何平均做优势基线"或"优化重要性采样比率"**：几何平均作用于**token 级奖励的聚合**，不是基线也不是比率本身。二手来源在此均有偏差。
- **不能声称 GMPO 在所有基准上一致优于 GRPO**：MATH500(7B) 82.0 vs GRPO 83.4、Minerva(7B) 33.5 vs 32.4 等条目存在互有胜负，`+4.1` 是最优情形而非全域结论。
- **不能把 GMPO 的结论外推到非 LLM 任务**：全部实验是 1.5B–32B 语言模型与 7B 多模态模型，**没有任何表格数据、二分类或小模型实验**。
- **不能把"几何平均更稳"当成无条件成立**：几何平均在任一项为 0 或符号翻转时会退化；本文靠 `|·|` 与 `sgn(Â)` 处理该问题（式(4)），改用到其它任务时该处理是否适用需重新验证。
- **不能引用消融表外的数字**：裁剪区间消融只在 7B 上做（表 4，p.5），1.5B 与 32B 上的裁剪敏感性未测。

## 与课题的关系

- 与 [[2025-Liu-DrGRPO无偏优化与R1-Zero再审视]] 的关系需要区分：Dr. GRPO 修的是**优势归一化里的除法**（去长度项、去组内 std），GMPO 修的是**token 级奖励的聚合算子**；GMPO 甚至在消融中验证"去掉 `1/|o|` 会掉 0.7"（p.5），与 Dr. GRPO 的主张方向相反——**两者对长度归一化的立场矛盾，引用时必须并列呈现，不得择一**。
- 对 DRIFT 第三章的可用形态是**聚合算子的稳定性判据**：若后续机制涉及"多路证据聚合成一个更新信号"（如三支路反事实），应检查算术平均是否被单路极端值主导。

## 疑问 / 待验证

- 论文未报告：训练算力预算、种子数、方差、基线的超参搜索范围。
- 式(3) 的 `|·|` 使目标在比率跨越 0 时产生不可导点；论文未讨论该点的数值行为。
- 在 R1-Distill 基座上 `+4.1` 远超其它基座（+1.4／+1.5／+2.1），作者未给出机理归因；是否为该基座与裁剪区间的交互，属未验证。
