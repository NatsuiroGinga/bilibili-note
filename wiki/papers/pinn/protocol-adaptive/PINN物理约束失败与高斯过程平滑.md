# PINN 物理约束失败与高斯过程平滑

> Bajaj、McLennan、Andeen、Roy，手稿日期 2022 年 11 月，arXiv v2 发布于 2023 年 1 月，PDF 31 页。

## 一句话

论文直接否定“物理残差更低就代表状态更正确”：错误边界条件可以把 PINN 推向满足守恒或接口连续性、但偏离真实解的局部最优。

## 论文原结论

- PINN 会过拟合带噪初始或边界测量，并沿已知 PDE 把误差传播到后续时空域。
- 额外施加子域接口连续性、通量连续性或守恒定律，不足以自动纠正错误数据；正则甚至可增加新的错误局部最优。
- 先用高斯过程平滑边界数据，再训练 PINN，可在多个合成 PDE 基准上接近无噪 PINN 的状态误差。
- 稀疏高斯过程能减少诱导点，但诱导点过少或采样未覆盖尖锐梯度时会欠拟合或过度平滑。

## 方法与方程语义

论文采用标准 PINN 标量化目标：

$$
L_{\mathrm{PINN}}
=\alpha_{BC}L_{BC}+\alpha_{PDE}L_{PDE}+\alpha_D L_D.
$$

其中 `L_BC` 约束边界，`L_PDE` 约束控制方程，`L_D` 是可选直接观测误差。cPINN 在子域接口上再约束函数与通量：

$$
L_I^j=\frac{1}{N_I^j}\sum_i
\left(
|\tilde u_j-\tilde u_{j+1}|^2+
|\nabla\tilde u_j\cdot n_j-\nabla\tilde u_{j+1}\cdot n_j|^2
\right).
$$

非线性 Schrödinger 基准还加入全局概率守恒。论文把守恒量时间导数离散成配点平均并最小化其平方。原 PDF 第 12、14 页明确显示，该损失让守恒曲线更接近平坦，但场解仍偏离解析解。

高斯过程方案不是修改 PDE 残差，而是把带噪边界 `U_B` 替换为平滑估计 `\hat U_B`：

$$
\tilde u(\vec x)=NN_\theta(\vec x;\hat U_B,U_C,U_D),
$$

$$
k(x_i,x_j)=A\exp\left(-\frac{|\vec x_i-\vec x_j|^2}{2l^2}\right)+\sigma^2\delta_{ij}.
$$

核参数由边际似然确定。该修正依赖“边界真函数局部平滑、噪声可由选定核描述”的先验，并不适用于任意离散协议字段。

## 实验结果

### 一维非线性 Schrödinger 方程

| 方法                             |      MSE |
| -------------------------------- | -------: |
| 无噪 PINN                        | `0.0105` |
| 带噪 PINN，`σ=0.1`               | `0.0289` |
| 两子域 cPINN，带噪               | `0.4782` |
| 三子域 cPINN，带噪               | `0.4178` |
| GP 平滑 PINN，50 个诱导点        | `0.0125` |
| SGP 平滑 PINN，29 与 20 个诱导点 | `0.0123` |

### 一维 Burgers 方程

| 方法                         |      MSE |
| ---------------------------- | -------: |
| 无噪 PINN                    | `0.0116` |
| 带噪 PINN，`σ=0.5`           | `0.1982` |
| Cole-Hopf 正则 PINN          | `0.1125` |
| 三子域 cPINN、Cole-Hopf 正则 | `0.0329` |
| GP 平滑 PINN，50 个诱导点    | `0.0384` |
| SGP 平滑 PINN，41 个诱导点   | `0.0080` |

表 3 中 L1/L2 行标为 `σ=0.1`，而主要带噪对比为 `σ=0.5`，不能把这些行当作同噪声水平的严格配对。论文也未报告多随机种子方差或显著性检验。

## 可观测字段与所需真值

- **模型输入**：空间与时间坐标。
- **训练可观测量**：初始或边界场值、边界条件、PDE 源项和随机配点。
- **潜在状态**：整个时空域的场解及其自动微分导数。
- **验证真值**：解析解或高密度参考解，用于独立 MSE；训练损失本身不充当真值。
- **噪声模型**：独立加性零均值高斯噪声，标准差由实验预设。
- **没有使用**：协议字段、协议置信度、攻击标签、分类输出或未知协议标记。

R2 若没有 ns-3 多协议状态真值，就无法执行本文要求的“残差之外独立状态误差”检查。GeNIS 和 TQH-C2 的检测标签不能替代队列、窗口、往返时延或在途字节真值。

## 假设与失败边界

- 已知 PDE 必须正确，噪声主要位于边界观测；论文不研究方程本身错误或协议路由错误。
- 子域接口位置是敏感超参数，在函数极值或尖锐梯度附近可制造错误局部最优。
- 守恒约束只限制解的一部分性质，不能保证唯一恢复真实状态。
- 高斯过程假设平滑性与核结构；核选择错误会过拟合或欠拟合。
- 均匀诱导点对激波前沿覆盖不足，导致尖锐转变被平滑掉。
- 所有任务均为已知 PDE 的合成基准，不提供恶意流量检测或跨协议泛化证据。

## 可迁移机制

- **可迁移**：物理残差、守恒违反率和独立状态误差必须分开报告。
- **可迁移**：错误或过强物理约束会产生“物理看似正确、任务状态错误”的解，必须设置未知回退与置信度衰减。
- **可迁移**：路由错误可视为把不适用方程施加到样本上，需通过硬掩码在结构上禁止。
- **可迁移**：稀有协议或突变区不能只靠总体平均采样，需按协议与状态转变分层验证。

## 本课题推论

- C 相对 A 的有效性不能只看物理损失下降；必须同时改善或至少不损害 ns-3 独立状态误差、检测指标与校准。
- 协议置信度低时，应降低专属残差强度并回退到共享守恒，避免错误专家把模型推向错误局部最优。
- TQH-C2 的协议标签捷径可能让分类指标改善，同时物理状态变差；分类梯度必须与路由器隔离。
- GeNIS 字段回接和 ns-3 多协议真值是验证路由适用性的前提，不是可由更强正则替代的实现细节。

## 本课题不能直接照搬之处

- 不能把高斯过程边界平滑直接用于离散协议类别或把平滑概率当作协议置信度。
- 不能把守恒损失降低写成真实队列或拥塞状态恢复。
- 不能用任意子域划分对应协议专家；论文正好表明分区位置错误会显著恶化解。
- 不能把合成高斯噪声结果外推到采集配置偏差、标签捷径或开放集协议。
- 不能用表 3 的非同噪声 L1/L2 行作严格公平排名。

## 对 A/B/C/D 合同的意义

- `C-A` 必须同时报告专属残差、共享残差和独立状态误差；只降低残差不构成物理路由贡献。
- `B-A` 可能仅反映协议信息对分类的直接帮助，本文不能把这种帮助解释为物理正确性。
- `D-B` 若提升但 C 不提升，最可能是额外信息或标签相关性帮助了任务头，仍应否决 R2。
- A、B、C、D 都应使用同一噪声、样本、参数预算和验证真值，避免表 3 式非同条件比较。

## 待验证假设

- 错误协议路由是否表现为“残差下降但状态误差上升”，并可据此触发回退。
- 协议置信度阈值能否在未知或模糊协议上抑制负迁移，而不让软强度吸收标签信息。
- 多协议 ns-3 是否能提供足够独立真值，区分错误方程、错误路由与数据噪声。

## 摘要要点（中文转述）

论文系统展示边界测量误差如何被 PINN 传播，并比较接口连续性、守恒正则与高斯过程边界平滑。主要结论是物理正则不能自动修复错误数据，独立真值验证不可省略。
