# 协议自适应多动力学 PINN 文献索引

本索引只收录已回到本地 PDF 全文核验、并记录页码或章节证据的论文。当前结论用于评审 R2 候选，不代表方法已经通过实验。

## 自适应域分解与物理专家

- **[[GatedPINN自适应域分解|GatedPINN 自适应域分解]]**：用 `(x,y,t)` 条件化的稀疏 Top-1 门控学习单一 PDE 的计算域分解；支持条件计算，不支持协议硬掩码或标签梯度隔离。
- **[[MoE-PINN稀疏专家选择|MoE-PINN 稀疏专家选择]]**：用坐标软门控组合多个 PINN 并尝试稀疏选择；专家数过多会退化，且印刷正则式存在归一化后为常数的复现风险。

## 首批综合边界

- 两篇论文的路由输入都是连续坐标，专家都服务于同一 PDE；没有论文把专家固定为 TCP、UDP、QUIC 或未知协议动力学。
- 两篇论文都让物理目标训练门控器，但没有分类损失、攻击标签或采集配置，因此不能为“允许分类损失训练协议路由器”提供证据。
- GatedPINN 的负载项鼓励均衡，MoE-PINN 的稀疏项鼓励舍弃弱专家；两者目标相反，均不能替代“固定硬适用掩码加协议置信度软强度”。

## 错误物理与部分观测

- **[[PINN物理约束失败与高斯过程平滑|PINN 物理约束失败与高斯过程平滑]]**：守恒或接口正则可让物理指标改善却仍得到错误状态；要求残差之外的独立状态真值和未知回退。
- **[[部分测量下物理信息神经ODE|部分测量下物理信息神经 ODE]]**：保留已知动力学并交替估计隐状态与未知参数；成功前提是隐状态可辨识，不提供多协议路由。

## 第二批综合边界

- 错误或不适用方程能把模型推向“低残差、错误状态”的解，因此协议专家必须由固定适用掩码约束，未知或低置信样本回退到共享守恒。
- 部分观测不等于隐状态可恢复；需要已知耦合、顺序测量和独立状态真值。当前 B0 无协议字段、ns-3 仅 UDP，尚不满足多协议可辨识验证。
- C 必须在独立状态误差、检测和校准上相对 A 提供增量。若只有 B/D 因协议直接信息改善，仍按合同否决 R2。

## 离散模式与专家方程混合

- **[[神经混合自动机离散模式恢复|神经混合自动机的离散模式恢复]]**：先分段再用重构自监督恢复离散动力学模式；软最大混合可拟合轨迹却不能恢复真实模式，但恢复的是 Reno TCP 内部模式而非跨协议路由。
- **[[LHM专家ODE与潜变量混合|LHM 专家 ODE 与潜变量混合]]**：把一个假定正确、自洽的专家 ODE 嵌入潜在神经 ODE；支持结构分责，不处理多专家适用域和错误专家。

## 第三批综合边界

- 若目标是恢复有稳定语义的动力学，独立模式或状态真值不可省；软混合的低任务误差不能证明专家正确。
- 分阶段训练可避免错误事件边界污染模式动力学，但 NHA 仍用重构梯度训练模式编码器；分类损失停止梯度需由本课题自行实现和消融。
- LHM 的收益依赖单个专家方程正确且覆盖充分，正好反证不能把多套协议方程无掩码地作用于全部样本。
- 两篇都要求顺序轨迹和隐藏状态结构；当前 B0 静态公共字段与 UDP-only ns-3 尚未达到计算图可验证门槛。

## 竞争门控与部分观测 PDE

- **[[NMOE竞争模式与合作物理专家|NMOE 竞争模式与合作物理专家]]**：上层按接触模式竞争，下层混合白盒和黑盒；可靠性软权重由预测误差自由学习，不是外部置信度或固定适用掩码。
- **[[RPLPO部分观测下重启PDE损失|RPLPO 部分观测下重启 PDE 损失]]**：从连续部分观测重建高分辨状态，并把两个 PDE 损失定向到编码和转移模块；同一 PDE 适用于全部轨迹，没有多专家路由。

## 第四批综合边界

- 物理模式、白盒可靠性和任务标签必须拆开：NMOE 的自由责任度不能直接作为协议置信度，分类损失也不能训练该权重。
- 共享守恒必须常开；NMOE 允许白盒权重接近零的结构只适合局部失配修正，不适合本课题的共享约束。
- RPLPO 的 Wave 结果显示部分观测预测误差可低至 `2.64e-2`，而隐藏高分辨状态误差仍为 `1.06`；独立状态真值必须成为 C 的通过门槛。
- 不准确 PDE 的连续扰动实验不能替代错误协议路由、未知协议回退和标签捷径负对照。

## QUIC 加密可观测性与漂移

- **[[QUIC加密流量被动分类与数据漂移|QUIC 加密流量被动分类与数据漂移]]**：预筛为 QUIC 的流可由包长、方向、包间隔和流统计进行闭集服务分类；握手证书与地址形成强捷径，并能在一周内导致显著性能漂移。
- **[[VisQUIC加密QUIC流量数据集|VisQUIC 加密 QUIC 流量数据集]]**：包到达时间、包长与方向可估计受控解密得到的 HTTP/3 响应数；`97%` 是允许 `±2` 个响应误差的容差指标，不是精确率或传输状态恢复率。

## 第五批综合边界

- 两篇都从已确定为 QUIC 的流开始，不解决普通 UDP 到 QUIC 的协议识别，也没有校准协议置信度或开放集未知协议回退。
- 可见包形态能支持服务或应用响应估计，但不提供拥塞窗口、真实往返时延、确认范围、在途字节、探测超时或瓶颈队列真值。
- QUIC 分类论文的证书尺寸漂移和 VisQUIC 的 URL、迹线、站点层级泄漏共同要求按时间、完整流、URL、采集配置和站点做确定性分组。
- TQH-C2 若要建立 QUIC 路由必须回到 PCAP 重建方向化包长与相对时间序列；`profile`、地址、服务名、URL、密钥和解密标签只允许作审计或真值生成。
- QUIC 专属专家在协议识别、置信度校准和独立状态真值齐备前不得进入第一轮 C；固定走未知回退并只启用共享守恒。

## QUIC 现行规范线图像

- **[[RFC8999-QUIC版本无关线图像|RFC 8999：QUIC 版本无关线图像]]**：跨版本只保证极小首部骨架；v1 位语义不能默认外推到未知版本。
- **[[RFC9000-QUIC传输与旋转位边界|RFC 9000：旋转位可观测边界]]**：旋转位可被任一端关闭，规范还要求随机禁用一部分连接；无有效翻转只能记为缺失。
- **[[RFC9001-QUIC加密与隐藏状态|RFC 9001：QUIC 加密与隐藏状态]]**：1-RTT 包号和载荷受保护，确认帧、丢包恢复与内部拥塞状态不是公共抓包字段。
- **[[RFC9287-QUIC固定位随机化|RFC 9287：QUIC 固定位随机化]]**：协商后固定值可随机化，固定值不能成为普通 UDP 与 QUIC 的硬判据。
- **[[RFC9312-QUIC被动管理边界|RFC 9312：QUIC 被动管理边界]]**：当前线图像不能被动测量丢包，往返时延也只有条件化的有限观测。

## 协议置信度校准

- **[[Guo-神经网络置信度校准|现代神经网络置信度校准]]**：温度缩放用留出验证集拟合单一温度且不改变类别预测，但其证据假定训练、验证和测试同分布。
- **[[Ovadia-分布漂移下不确定性失效|分布漂移下不确定性失效]]**：同分布上校准良好的置信度在轻微漂移下也可能失效，要求跨数据源留一评价与未知拒识。

## 外部补证后的冻结边界

- TQH 只能把无需密钥的包长、方向、相对时间、长/短首部形式、长首部版本和经质量掩码验证的旋转位作为公开可见候选。
- 固定位、注册端口、五元组和连接标识都不能单独成为 QUIC 硬标签；未知版本、无握手、固定位随机化和连接迁移必须进入负对照。
- `loss`、`retrans`、确认范围、拥塞窗口、在途字节与探测超时均不是普通 QUIC PCAP 的直接可见真值。
- 温度缩放只能作为同分布校准基线；软强度必须通过跨源 Brier 分数、负对数似然、期望校准误差、覆盖率-错误率与未知拒识共同验收。
- 现有 TQH 不具备独立 QUIC 状态真值，故外部补证没有解除 QUIC 未知回退门禁，也没有授权启动实验。

## R2 冻结判据

- C 是章级主方法；`C-A` 衡量物理路由贡献。
- `B-A` 衡量协议直接信息贡献；`D-B` 衡量同额外信息下的路由增量。
- 若只有 B/D 提升而 C 不提升，则否决 R2，不能把协议标签捷径解释为物理路由收益。
