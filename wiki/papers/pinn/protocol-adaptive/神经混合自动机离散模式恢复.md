# 神经混合自动机的离散模式恢复

> Poli 等，2021，NeurIPS 2021，PDF 13 页。

## 一句话

论文为“不同离散模式对应不同连续动力学”提供了直接架构先例，并证明软混合可隐藏错误模式语义；但其离散模式由轨迹重构自由发现，不能替代协议硬适用掩码，也不能证明攻击分类损失应训练路由器。

## 论文原结论

- NHA 将随机混合系统拆为模式条件连续动力学、离散潜在模式和事件模块，可在不知道模式数量与转移拓扑的情况下从轨迹学习。
- 训练先把完整轨迹分成单模式子轨迹，再用分类瓶颈和重构任务恢复模式；恢复的模式标签随后监督事件间隔分布与跳跃映射。
- 在 Reno TCP 系统上，NHA 的模式聚类优于通用聚类基线；给定多于真实数量的潜在模式反而提高稳定性。
- 在三模式切换线性系统上，软最大权重会混合多个向量场并拟合轨迹，却不能恢复各模式真实动力学；分类采样强制离散选择。

## 方法与计算图

模式 `z` 下的连续动力学为：

$$
\dot x_t=F_z(t,x_t,\omega),\qquad t\in[t_k,t_{k+1}).
$$

对每个可能转移 `(z,z')`，正规化流学习事件间隔分布 `p_{z\to z'}`。下一事件由最短采样间隔决定：

$$
t_{k+1}=t_k+\min_{z'}T(z,z',t_k),
$$

对应目标模式是取得最小值的 `z'`，到达事件时再应用跳跃映射 `\psi_{z\to z'}`。

模式恢复阶段使用：

$$
z\sim E(X,\theta),\qquad
\dot x=F_z(t,x_t,\omega),
$$

并最小化子轨迹重构损失。`z` 是分类分布的一热样本，采样反向传播采用直通估计。因此，物理轨迹重构损失同时更新模式编码器与模式动力学；论文没有阻断这条梯度。

事件模块不与完整轨迹端到端联合学习。模式恢复完成后，转移前后的聚类标签、事件间隔与跳跃状态对成为事件模块的监督数据。图 3 说明若事件时间估计过晚，完整轨迹联合损失会把属于下一模式的片段错误地用于更新当前模式，形成冲突梯度。

## 实验结果

### Reno TCP

| 模型        | 流重构测试 RMSE |
| ----------- | --------------: |
| NODE        |          `3.57` |
| DC-NODE     |          `1.46` |
| Latent NODE |          `1.55` |
| NHA-3       |          `1.66` |
| NHA-5       |          `1.21` |
| NHA-10      |          `0.56` |

NHA-3 并不优于两个带潜变量的神经 ODE 基线；更好的重构来自过聚类设置。因候选模式数与模型容量同时变化，不能把 NHA-10 的差值全部解释为正确模式恢复。表 1 的 v-measure 独立检查了聚类质量，因而比单独 RMSE 更接近“模式是否正确”的问题。

### 切换线性系统

图 7 没有给出汇总数值，但给出可视化消融：软最大选择器允许多个条件向量场在同一点共同贡献，得到看似良好的轨迹拟合，却不对应真实分段向量场。论文明确称，若目标是恢复真实模式动力学，分类瓶颈更合适；软混合只适合黑箱拟合。

## 可观测字段与所需真值

- **训练输入**：带时间戳的连续状态轨迹和外部分段得到的子轨迹。
- **模式编码输入**：整段子轨迹 `X_i`，不是单条静态流记录。
- **事件监督**：相邻子轨迹的恢复模式、事件间隔、跳跃前后状态。
- **评估真值**：Reno TCP 仿真中的真实模式、真实转移分布和完整内部状态；真实模式仅用于评价，不提供给自监督训练。
- **没有使用**：攻击标签、公开流量分类特征、协议置信度、未知协议拒识或固定协议适用表。

论文虽以 Reno TCP 为实验对象，恢复的是同一 Reno 控制器内部的三个动态模式，不是 TCP、UDP、QUIC 之间的协议选择。引言把通信协议变化列为随机混合系统应用背景，不能据此声称论文已经做过跨协议路由。

## 假设与失败边界

- 训练前必须获得近似单模式的子轨迹分段；分段错误会污染模式恢复和后续事件监督。
- 模式编码依赖完整子轨迹及足够的状态空间覆盖，无法直接应用于无顺序关系的独立聚合流。
- 分类模式编号只在置换意义下可识别，不带 TCP、UDP 或 QUIC 的先验语义。
- 过聚类可提升结果，但也增加模式和容量；需要独立模式真值与容量匹配基线。
- 软最大路由的轨迹误差可能很低而模式动力学错误，任务性能不能替代模式恢复评价。
- 当前 13 页 PDF 在正文中引用附录 A、B，但原件在参考文献和检查清单结束，未包含附录；梯度推导、噪声分段消融与完整训练细节不能从当前原件复核。

## 可迁移机制

- **可迁移**：共享状态可由离散模式选择不同连续动力学，模式切换与状态跳跃应显式分开。
- **可迁移**：先建立单模式证据，再训练转移模块，可减少错误路由产生的跨模式梯度污染。
- **可迁移**：必须用独立模式真值或状态真值评价路由；仅看最终重构或分类性能会掩盖软混合。
- **可迁移**：若要恢复具有稳定语义的动力学，分类选择或硬适用约束比自由软混合更可信。

## 本课题推论

- R2 的协议专家应先由固定适用表排除不可能专家，再让协议置信度只缩放已适用残差；这与 NHA 的分类模式不同，但能避免图 7 所示的跨动力学混合。
- 分类头不能反向训练协议路由器。NHA 的图 3 已说明错误模式边界会产生错误动力学梯度；TQH-C2 的标签捷径会进一步让边界按攻击标签而非协议形成。
- C 的评价必须包含协议模式准确性、隐藏状态误差或方程残差的独立真值，不能只报告检测指标。
- 当前 ns-3 只有 UDP，无法像论文的 Reno 仿真那样提供多模式真实标签；应先补多协议、事件与内部状态真值。

## 本课题不能直接照搬之处

- 不能把 Reno TCP 内部模式改名为 TCP、UDP、QUIC 协议专家。
- 不能用自由发现的一热模式替代固定协议适用掩码；模式置换和过聚类会破坏协议语义。
- 不能让攻击分类损失通过直通估计训练路由器；论文只有轨迹重构目标。
- 不能把事件间隔正规化流作为当前静态流分类的必要模块，除非数据先恢复时间顺序和事件真值。
- 不能以 NHA-10 的 RMSE 直接证明路由优于基线，因为候选模式数与容量没有固定。

## 对 A/B/C/D 合同的意义

- C 与 A 必须共享任务输入、参数预算和检测头；C 只额外引入由物理证据训练的协议路由与专家。
- B 的协议字段可直接进入普通分类基线，用于测量 `B-A`；C 不得获得这条分类捷径。
- D 与 B 使用同样额外字段，再测量路由增量 `D-B`；D 的分类损失仍不得训练路由器。
- `C-A` 至少要同时改善独立动力学真值和检测或校准指标。若只有 B/D 改善，NHA 不能为 R2 提供豁免。

## 待验证假设

- 固定协议掩码加共享守恒后，C 是否在容量匹配条件下改善隐藏状态误差。
- 只由协议置信度缩放残差时，是否会出现与软最大向量场混合相同的语义泄漏。
- 对 TQH-C2 打乱攻击标签或平衡协议—标签组合后，路由图是否保持协议语义。
