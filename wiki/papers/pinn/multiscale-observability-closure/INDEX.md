# 自适应多尺度与可观测性闭合 PINN 文献索引

本索引只收录已取得合法全文、完成逐页关键证据核验并建立 Zotero PDF 回链的一级文献。摘要级线索不进入纳入清单。

## 控制体与局部守恒

- **[[2022-Patel-cvPINN|Patel 等：cvPINN]]** — 时空控制体可联合学习状态与未知通量，但守恒残差和无约束黑箱闭合都存在非物理解。
- **[[2024-Cen-DFVM|Cen 与 Zou：DFVM]]** — 固定半径局部弱形式降低高阶微分成本；自适应采样不等于自适应尺度，重叠控制体也不自动提供细粗一致性。

## 多层尺度与自适应权重

- **[[2024-Dolean-Multilevel-FBPINN|Dolean 等：多层 FBPINN]]** — 固定粗细域分解通过全局通信改善高频拟合，但层级、窗口和重叠率均需预设，不能充当历史驱动尺度门。
- **[[2023-McClenny-SA-PINN|McClenny 与 Braga-Neto：SA-PINN]]** — 逐配点损失权重强调高残差难点；它不是尺度或置信度，且噪声观测加权仍是开放问题。

## 梯度流与量纲前沿

- **[[2021-Wang-Gradient-Pathologies|Wang 等：PINN 梯度病态]]** — 梯度统计退火可缓解损失幅值失衡，但不保证解决方向冲突；直接速度—压力形式的失败还证明优化重加权不能替代结构性硬约束。
- **[[2023-Rohrhofer-Apparent-Pareto-Front|Rohrhofer 等：表观 Pareto 前沿]]** — 域长度、特征时间和方程系数会移动训练可达前沿；无量纲化是比较多窗口的前提，但不能确定理想权重或闭合解。

## 时间推进与低残差结构边界

- **[[2021-Krishnapriyan-PINN-Failure-Modes|Krishnapriyan 等：PINN 失败模式]]** — 已知方程系数的课程热启动与固定短时间推进可缓解困难损失景观，但都不是观测驱动尺度发现，也不提供未知闭合可辨识性。
- **[[2024-Wang-Cauchy-PINN-Difficulty|Wang 等：柯西问题 PINN 困难性]]** — 紧致域内零方程残差和零初值误差仍可对应任意错误状态；缺失入流边界、域外信息、正则性及间断表示能力构成结构性否决门。

## 学习型域分解与尺度门边界

- **[[2023-Hu-APINN|Hu 等：APINN]]** — 坐标条件软门依赖人工分区预训练且受初始化捕获；专家非唯一和更多子域可能更差，不能支撑自由时间尺度发现。
- **[[2020-Stiller-GatedPINN|Stiller 等：GatedPINN]]** — Top-1 坐标路由主要减少条件计算；门控模型总损失更低但解析状态误差略差，低残差不能替代状态正确性。

## 部分可观测与显式闭合

- **[[2020-Raissi-HFM|Raissi 等：HFM]]** — 已知方程与具有充分梯度的时空被动标量可恢复速度和压力，但无边界条件时没有一般唯一性，压力还存在加性零空间。
- **[[2022-Taghizadeh-Explicit-Closure|Taghizadeh 等：显式闭合]]** — 微观真值监督的六维无量纲闭合网络有效，但依赖尺度分离、代表性几何和大规模直接数值模拟，且不是端到端残差 PINN。

## 含噪后验与缺测降级

- **[[2021-Yang-BPINN|Yang 等：B-PINN]]** — HMC 在已知独立高斯噪声尺度的小型合成 PDE 上给出较可靠后验；字段不存在与含噪观测不是同一数据模型，先验和大数据扩展仍是限制。
- **[[2023-Perez-Adaptive-BPINN|Perez 等：AW-HMC]]** — 任务级梯度方差权重可修复多势能采样失衡，并从稀疏 CFD 点插补完整场；其多尺度与缺测语义均不能直接替代时间窗门控和字段掩码。

## 网络队列与可辨识性

- **[[2010-Habib-Queue-Inferencing|Habib 与 Molle：输出链路队列反演]]** — 只有目标输出端口、容量、帧开销、先进先出工作守恒和忙期泊松合同同时成立，服务序列才支持条件期望时延；普通流统计不满足这些前提。
- **[[2025-Raghunathan-QuASI|Raghunathan 等：QuASI]]** — 粗粒度端口计数可严格限制相容队列轨迹集合，但存在性和集合极值都不是实际单轨迹真值；缺少发送、丢弃计数与设备语义时不能迁移。

## 到达过程反例与伪尺度

- **[[1995-Paxson-Poisson-Failure|Paxson 与 Floyd：广域流量泊松失效]]** — 只有固定小时内部分用户会话到达可近似泊松；包到达、机器生成连接和 FTP 数据连接簇在多个尺度显著更突发，高度复用也不能修复模型误设。
- **[[2003-Hohn-Cluster-Processes|Hohn 等：流量簇过程]]** — 小尺度流内结构和大尺度重尾可由簇过程解释，但简单更新过程也能产生有限尺度伪斜率，流内速率还会平移整个尺度轴；波谱膝点不是唯一物理尺度真值。

## 服务反演与到达异常降级

- **[[2008-Liebeherr-Bandwidth-Estimation|Liebeherr 等：系统论带宽估计]]** — 服务曲线可表示多时间尺度可用服务，但反演至少需要成对累计到达/离开、时间戳和包大小或主动探测；单边到达统计不足，非线性 FIFO 还会产生无用或偏乐观下界。
- **[[2012-Bouillard-Hidden-Anomaly|Bouillard 等：隐藏异常检测]]** — 只有有序消息到达时间时，可用仿射上下约束和逐层破约消息报告短期至长期到达率变化；该安全降级不能解释为队列、服务或容量恢复，且周期流可能不收敛。

## 网络状态控制与交界守恒

- **[[2025-Du-PRED|Du 等：PRED]]** — 基于 RTT 的快并发稳定器和较慢 A/B 队列调节器给出受限双时间尺度白盒控制，但直接依赖端口五元组、队列、吞吐、容量、RTT 与 DCTCP/DCQCN 状态，尺度既非学习所得也不能从当前共享字段恢复。
- **[[2022-Usama-Traffic-Network-PINN|Usama 等：道路交通网络 PINN]]** — 逐链接状态网络通过交界通量守恒耦合并学习两参数基本图；其成功需要完整拓扑、坐标与仿真真值，离散平均观测和点式交界守恒冲突会把最大误差推向节点。
