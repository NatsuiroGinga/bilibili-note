# 不确定性校准与网络演算边界 PINN 文献索引

本组文献用于判断 R3 是否能在 GeNIS、TQH-C2 和 ns-3 的共同条件下建立可辨识、可微且诚实校准的网络演算物理边界。

## 服务曲线与统计保证

- **[[Burchard-统计有效服务曲线|端到端统计有效服务曲线]]** — 用违约概率定义有效服务下界，但不解决部分观测下的服务反演。
- **[[Liebeherr-系统论带宽估计|最小加系统论带宽估计]]** — 服务反演需要主动包列或成对到达/离开观测，且真实 FIFO 网络并非普遍最小加线性。
- **[[Luebben-随机服务带宽估计基础|随机服务带宽估计基础]]** — 多档常速探测、重复测量和时间尺度共同决定有效服务界。
- **[[Luebben-随机服务统计带宽估计|随机服务统计带宽估计]]** — 平均带宽会系统性高估短时服务，必须报告分位数与置信区间。

## 可微运算与解析有效性

- **[[Cuturi-可微软最小动态规划|可微软最小动态规划]]** — 软最小提供端到端梯度，但引入温度偏差和二次复杂度。
- **[[Mensch-可微动态规划|可微动态规划]]** — 强凸平滑最大给出显式近似误差界，可用于有限窗口边界递推。
- **[[Geyer-DeepTMA网络演算模型选择|DeepTMA 网络演算模型选择]]** — 学习器只选择合法解析操作，保证仍来自网络演算而不是预测器。
- **[[Geyer-DeepTMA分布外稳健性|DeepTMA 分布外稳健性]]** — 规模外推仍发生在同一已知建模域，不能替代跨数据源验证。

## 不确定性与时序校准

- **[[Podina-共形物理信息网络|共形化物理信息网络]]** — 拆分共形可校准 PINN 点预测，但依赖独立校准集与交换性。
- **[[Yu-局部共形物理信息网络|局部共形物理信息网络]]** — 局部分位数适应异方差，尚未解决部分观测、时序和跨域漂移。
- **[[Stankeviciute-共形时间序列预测|共形时间序列预测]]** — 单条流内时间点不交换，必须按完整流或独立运行分区。
- **[[Gibbs-分布漂移下自适应共形推断|分布漂移下自适应共形推断]]** — 控制长期平均错覆盖，不等于逐场景条件保证。
- **[[Luebben-TAILING时延分位数预测|TAILING 时延分位数预测]]** — 历史时延可预测未来点式分位数，但要求到达－离开或往返时延观测，不提供样本路径保证。

## 异常检测与分组化边界

- **[[Bouillard-网络演算隐藏异常检测|自适应到达约束异常检测]]** — 服务不可辨识时，可退化为多尺度到达包络越界检测。
- **[[Jacobs-网络演算异常检测特征|网络演算异常检测特征]]** — 网络演算状态可连接安全特征，但原实验参数为预设示例。
- **[[Jiang-网络演算分组化重审|网络演算分组化重审]]** — 忽略最后一比特和分组语义可使最小加服务与时延界失效。
- **[[Jiang-分组化对网络演算影响|分组化对网络演算的影响]]** — 错误服务曲线会进一步污染输出、积压和串联边界。

## 当前总判断

完整 R3 只能在 ns-3 提供到达、离开、容量、队列和分组真值的条件下训练与验证。公共数据应采用不确定性门控；服务证据不足时退化为条件到达包络，不得声称确定性服务或最坏时延保证。
