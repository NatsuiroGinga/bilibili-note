## 一句话

用一个「单次前向即可算出」的逐样本梯度范数上界 `Ĝ_i` 构造采样分布 `p_i ∝ Ĝ_i`，并用「方差缩减等价于批大小增大 τ 倍」这一换算把「何时开重要性采样」变成一个有闭式表达的可判定条件。

## 核心定义与公式（§3.1，**逐式转写，均在 p.3**）

### 训练目标与采样式 SGD

式 (1)（p.3）：

```text
θ* = arg min_θ (1/N) Σ_{i=1}^N L(Ψ(x_i; θ), y_i)                              … (1)
```

其中 `x_i, y_i` 是第 i 个输入-输出对，`Ψ(·; θ)` 是以向量 θ 参数化的深度模型，`L(·,·)` 是损失，N 为训练集样本数。

式 (2)（p.3）：设第 t 步的采样分布为 `p^t_1, …, p^t_N`、缩放系数为 `w^t_1, …, w^t_N`，`I_t` 为该步采到的样本（`P(I_t = i) = p^t_i`），则

```text
θ_{t+1} = θ_t − η w_{I_t} ∇_{θ_t} L(Ψ(x_{I_t}; θ_t), y_{I_t})                  … (2)
```

论文注明：**均匀采样的普通 SGD 对应 `w^t_i = 1` 且 `p^t_i = 1/N`**（对一切 t 与 i）——这是本笔记中「均匀采样」对照的形式化定义。

### 收敛速度的定义与分解

式 (3)（p.3）：把收敛速度 S 定义为参数向量 θ 到最优参数 θ\* 的距离在相邻两步的缩减量（取期望）：

```text
S = − E_{P_t}[ ‖θ_{t+1} − θ*‖²₂ − ‖θ_t − θ*‖²₂ ]                              … (3)
```

式 (4)–(5)（p.3）：取 `w_i = 1/(N p_i)` 使得梯度估计**无偏**（原件把这一条等式印成两行、分别编号 (4) 与 (5)）：

```text
E_{P_t}[ w_{I_t} ∇_{θ_t} L(Ψ(x_{I_t}; θ_t), y_{I_t}) ]                          … (4)
   = ∇_{θ_t} (1/N) Σ_{i=1}^N L(Ψ(x_i; θ_t), y_i)                              … (5)
```

记 `G_i = w_i ∇_{θ_t} L(Ψ(x_i; θ_t), y_i)`，代入并展开后得式 (6)（p.3）：

```text
S = 2η (θ_t − θ*) E_{P_t}[G_{I_t}] − η² E_{P_t}[G_{I_t}]^T E_{P_t}[G_{I_t}]
    − η² Tr( V_{P_t}[G_{I_t}] )                                                … (6)
```

**论文对式 (6) 的读法（p.3，逐字转写）**：

> Since the first two terms, in the last expression, are the speed of batch gradient descent, we observe that it is possible to gain a speedup by sampling from the distribution that minimizes Tr(V_{P_t}[G_{I_t}]). Several works (Needell et al., 2014; Zhao & Zhang, 2015; Alain et al., 2015) have shown the optimal distribution to be proportional to the per-sample gradient norm. However, computing this distribution is computationally prohibitive.

论文另注：该推导是 Wang et al. (2016) 结果的另一种推导（p.3）。**注意式 (6) 的方差项是 `Tr(·)`（矩阵的迹）而不是范数**，这是后面所有推导的出发点。

## 关键公式：从最优分布到可算上界

### 最优采样分布（§3.1 末至 §3.2，p.3）

式 (7)（p.3）：

```text
arg min_P Tr( V_{P_t}[G_{I_t}] ) = arg min_P E_{P_t}[ ‖G_{I_t}‖²₂ ]                … (7)
```

即「最小化梯度估计的方差」等价于「最小化缩放后梯度的二阶矩」；该问题的解是 `p_i ∝ ‖G_i‖₂`（论文引 Needell et al. 2014 / Zhao & Zhang 2015 / Alain et al. 2015，p.3）。

### 用可算上界替换梯度范数（§3.2，p.3–4）

设 `Ĝ_i ≥ ‖∇_{θ_t} L(Ψ(x_i; θ_t), y_i)‖₂`，论文把式 (7) 的优化问题**松弛**为（式 (8)，p.3）：

```text
min_P E_{P_t}[ ‖G_{I_t}‖²₂ ] ≤ min_P E_{P_t}[ w²_{I_t} Ĝ²_{I_t} ]                … (8)
```

**论文明确**：「式 (8) 第二项的最小化元，与第一项类似，是 `p_i ∝ Ĝ_i`」（p.3 逐字：The minimizer of the second term of equation 8, similar to the first term, is `p_i ∝ Ĝ_i`）。因此下面全部工作只剩一件事：找一个「比逐样本梯度范数好算得多」的 `Ĝ_i`。

### 上界的推导（式 (9)–(20)，p.3–4）

记号（式 (9)–(12)，p.3）：`x^(0) = x`、`z^(l) = θ^(l) x^(l−1)`、`x^(l) = σ^(l)(z^(l))`、`Ψ(x; Θ) = x^(L)`；式 (13)：`Σ′_l(z) = diag(σ′^{(l)}(z_1), …, σ′^{(l)}(z_{M_l}))`；式 (14)：`∆^(l)_i = Σ′_l(z^(l)_i) θ^T_{l+1} … Σ′_{L−1}(z^{(L−1)}_i) θ^T_L`；式 (15)：`∇_{x^{(L)}_i} L = ∇_{x^{(L)}_i} L(Ψ(x_i; Θ), y_i)`。论文注明该记号虽只写无偏置的全连接网络，但分析对任何「仿射操作 + 斜率有界的非线性」（`|σ′(x)| ≤ K`）成立（p.3）。

式 (16)–(18)（p.3）给出逐层梯度范数：

```text
‖∇_{θ_l} L(Ψ(x_i; Θ), y_i)‖₂
  = ‖ ( ∆^(l)_i Σ′_L(z^{(L)}_i) ∇_{x^{(L)}_i} L ) ( x^{(l−1)}_i )^T ‖₂        … (16)(17)
  ≤ ‖∆^(l)_i‖₂ ‖Σ′_L(z^{(L)}_i) ∇_{x^{(L)}_i} L‖₂ ‖x^{(l−1)}_i‖₂              … (18)
```

式 (19)（p.3）取 `ρ := max_{l,i} ( ‖x^{(l−1)}_i‖₂ ‖∆^(l)_i‖₂ )`，得

```text
‖∇_{θ_l} L(Ψ(x_i; Θ), y_i)‖₂ ≤ ρ ‖Σ′_L(z^{(L)}_i) ∇_{x^{(L)}_i} L‖₂           … (19)
```

式 (20)（**p.4**）给出**最终上界**：

```text
‖∇_Θ L(Ψ(x_i; Θ), y_i)‖₂ ≤ L ρ ‖Σ′_L(z^{(L)}_i) ∇_{x^{(L)}_i} L‖₂  =  L ρ Ĝ_i   … (20)
```

论文对式 (20) 的解释（p.4）：各种权重初始化（Glorot & Bengio, 2010）与激活归一化（Ioffe & Szegedy, 2015；Ba et al., 2016）会让激活在各样本间趋于一致，因此**梯度范数的样本间变化主要由「损失对最后一层预激活输出的梯度」捕获**；该量只依赖 `z^{(L)}`，可以闭式算出，只比算损失略贵一点。论文同时强调「上界依赖时间步 t，因此不能一次性生成分布再采样 —— 每个样本的重要性随模型变化」（p.4）。附录 B（p.11–12）以更多细节重述了式 (37)–(51) 的同一推导。

## 关键结论：方差缩减何时可能（§3.3，p.4）

### 预采样带来的上界（p.4）

由于对全数据集算重要性分数不可行，论文的做法是**先采一个大批 B、在其中算采样分布、再按该分布有放回地重采一个小批 b**。论文给出该过程的上界（p.4）：

- 最大方差缩减为 `1/b − 1/B`；
- 最大加速为 `(B + 3b)/(3B)`，前提是反向传播耗时是前向的两倍。

### 方差缩减的闭式表达（式 (21)–(23)，p.4）

设 `g_i ∝ ‖∇_{θ_t} L(Ψ(x_i; θ_t), y_i)‖₂ = ‖G_i‖₂`、`u = 1/B` 为均匀概率：

```text
Tr(V_u[G_i]) − Tr(V_g[w_i G_i])                                            … (21)
  = E_u[ ‖G_i‖²₂ ] − E_g[ w²_i ‖G_i‖²₂ ]                                   … (22)
  = ( (1/B) Σ_{i=1}^B ‖G_i‖ )² · B ‖g − u‖²₂                                … (23)
```

**读法（论文原话，p.4）**：方差缩减**正比于采样分布 g 到均匀分布 u 的平方 L2 距离**（论文注明完整推导在补充材料，即附录 A，p.11 的式 (28)–(36)）。

### 换算为「等价批大小增量」τ（式 (24)–(27)，p.4）

论文指出直接对 `‖g−u‖²₂` 取阈值「既繁琐又不直观」，于是把方差缩减除以原方差，得到**达到等价方差缩减所需的批大小增量 τ**（即把批增大 τ 倍可把方差降到 1/τ）：

```text
[ (1/B Σ‖G_i‖)² B ‖g−u‖²₂ ] / Tr(V_u[G_i])  ≥                                  … (24)
[ (1/B Σ‖G_i‖)² B ‖g−u‖²₂ ] / [ (1/B) Σ‖G_i‖²₂ ]  =                            … (25)
( 1 / Σ_{i=1}^B g_i² ) · ‖g − u‖²₂  =  1 − 1/τ     ⟺                          … (26)

1/τ = 1 − ( 1 / Σ_{i=1}^B g_i² ) · ‖g − u‖²₂                                   … (27)
```

（**说明**：原件 p.4 的式 (24)–(27) 排版为跨行分式，`pypdf` 抽取后行列错位较严重；上面是按其数学含义与前后文一致性逐项复原的读法，与附录 A 的式 (33)/(35)/(36) 一致。**直接引用该式前应回原件 p.4 二次核对。**）

论文随即点明该式的用途（p.4）：`1/τ` 让阈值选择变得容易，且「当 `B + 3b < 3τb` 时我们有**有保证的**加速」。

### Algorithm 1（p.4，输入说明在 p.5）

```text
Inputs: B, b, τ_th, a_τ, θ_0
1: t ← 1 ; τ ← 0
2: repeat
3:   if τ > τ_th then
4:     U ← B 个均匀采样的数据点
5:     g_i ∝ Ĝ_i  (∀i ∈ U，按式 20)
6:     G ← 从 U 中按 g_i 采样 b 个数据点
7:     w_i ← 1/(B g_i)  (∀i ∈ G)
8:     θ_t ← sgd_step(w_i, G, θ_{t−1})
9:   else
10:    U ← b 个均匀采样的数据点
11:    w_i ← 1  (∀i ∈ U)
12:    θ_t ← sgd_step(w_i, U, θ_{t−1})
13:    g_i ∝ Ĝ_i  (∀i ∈ U)
14:  end if
15:  τ ← a_τ τ + (1 − a_τ)( 1 − (1/Σ_i g_i²)‖g − 1/|U|‖²₂ )^{−1}
16: until convergence
```

**行号说明（重要）**：上面的伪码是**本笔记按原件 p.4 的伪码复排的**，原始伪码把 `Inputs` 行计为第 1 行，因此**原件行号 = 本笔记行号 + 1**。原件的关键行是：第 15 行 = 本笔记第 14 行的下一行（即 `g_i ∝ Ĝ_i ∀i ∈ U`，在 else 分支内），第 17 行 = 本笔记第 15 行（τ 的更新式）。下面提到原件行号时一律按原件行号给出。

论文对算法的说明（p.4–5）：`B` 是预采样大小、`b` 是批大小、`τ_th` 是「方差缩减等价于批大小增大多少倍之后才开始重要性采样」的阈值、`a_τ` 是 τ 的指数滑动平均参数；**原件第 15 行（在 else 分支内计算 `g_i`）不需要额外代价，因为前向已在上一行做过**（p.5 逐字：in line 15 of the algorithm, we compute `g_i` for free since we have done the forward pass in the previous step）。唯一必须显式设定的参数是 `B`（p.5）。

**脚注 1（p.4，重要）**：论文自陈「在第一版中我们错误地假设了 `1/τ²`，这使算法不必要地保守。**所有实验都使用 Algorithm 1 第 17 行的平方根**。」——原件第 17 行即 τ 的更新式（上面的本笔记第 15 行），因此**实际实验使用的 τ 与式 (27) 之间存在一次开方关系**。

## 实验设置与读数

### 通用设置（p.5）

Keras + TensorFlow；Nvidia K80 GPU；报告的时间是把「一个 epoch 开始前」与「结束后」的时间戳相减，**因此包含 CPU↔GPU 的数据传输时间**（p.5）。三种采样方式的命名（p.5）：`uniform` 为常规均匀采样；`loss` 为同算法但采样分布正比于损失值；`upper-bound` 为本文方法（式 (8)(20)）。

### §4.1 消融：上界 vs 损失 vs 真实梯度范数（p.5–6）

设置（p.6）：在 CIFAR100 上训练一个宽残差网络（Zagoruyko & Komodakis, 2016），随后从数据集随机取 1,024 张图像；每 3,000 次更新，用 `uniform` / `loss` / `upper-bound` / `gradient-norm`（批大小 1 反传算得）从这 1,024 张中重采 128 张；为稳健起见采样重复 10 次取平均。

读数（p.6）：

- 本文上界与真实梯度范数的方差缩减**非常接近**，说明上界相对紧、产生的概率分布高度相关；
- 图 2（p.5）把 `loss` 与 `upper-bound` 产生的概率对理想概率（正比于梯度范数）作图：上界几乎完全相关，而损失只在「梯度非常小」的区域相关；
- **定量**：图 2 中 16,384 个点的误差平方和为 `0.017`（loss）与 `0.002`（本文上界）（p.6）；
- 反面结论：**按损失采高损失样本会增大方差，尤其在训练初期**（p.6 逐字：sampling hard examples (with high loss), increases the variance, especially in the beginning of training）。论文指出类似行为在嵌入学习中也被观察到（半困难样本挖掘优于按损失采样，引 Wu et al. 2017；Schroff et al. 2015）。

### §4.2 图像分类（p.6，图 3 在 p.7）

- 设置：CIFAR10/CIFAR100 上训练 wide resnet 28-2；batch size 128、weight decay 0.0005、momentum 0.9、初始学习率 0.1 并在第 20,000 与 40,000 次更新后除以 5；总迭代 50,000；为让基于历史的基线兼容数据增强，预先把两个数据集各增强到 `1.5×10⁶` 张（本文方法不受此限制，可真正在线）；比较采用**按墙钟时间的学习率调度**并固定总训练秒数；本文方法预采样大小 640、`τ_th = 1.5`；3 次独立运行取平均（p.6）。
- 读数（p.6）：CIFAR10 上训练损失低**一个数量级以上**，测试误差降低 8%（0.087 → 0.079）；CIFAR100 上训练损失约低 **3 倍**、测试误差降低 5%（0.34 → 0.32）。CIFAR10 上所有方法都相对均匀采样有加速，但 CIFAR100 上只有本文的梯度范数上界方法能降低梯度方差、加速收敛。CIFAR10 上前 4,000–8,000 秒本文方法是唯一显著改进测试误差的。
- 论文另注：在 CIFAR10 上，使用「新鲜」损失值配合 warmup（避免过早开启重要性采样）在 CIFAR10 上优于其他基线（p.6）。

### §4.3 微调（p.6–7，图 4 在 p.8）

- 设置：ImageNet 预训练的 ResNet-50，替换最后的分类层，端到端微调做 MIT Indoor 67 类分类；SGD，学习率 `10^{-3}`，momentum 0.9，batch size 16，预采样 48，`τ_th = 2`（按式 (27) 指定）；3 次独立运行取平均（p.7）。
- 读数（p.7）：半小时内重要性采样已收敛到接近该数据集在**无数据增强、无多裁剪**下可期望的最佳性能 `28.06%` 测试误差（引 Razavian et al., 2014），而 uniform 只到 `33.74%`；图 4 题注（p.8）把该差距写作「相对降低 17%」。

### §4.4 逐像素 MNIST（p.7–8，图 5 在 p.8）

- 设置：按 Le et al. (2015) 的随机置换 MNIST 逐像素分类，60,000 个样本、每样本 784 个时间步；LSTM 隐层 128 维、激活 `tanh`、循环激活 `sigmoid`，顶部线性分类器；Adam，学习率 `10^{-3}`，batch size 32，**梯度范数裁剪到 1**（论文称不裁剪训练会发散）；`τ_th = 1.8`、预采样大小 128（p.7–8）。
- 读数（p.8）：约 2,000 秒时两种重要性采样都启动；**按损失采样在此任务上反而损害收敛**；本文方法在给定时间预算内训练损失低 20%、测试误差低 7%（0.1055 vs 0.1139，图 5 题注 p.8）。论文另注按式 (27) 可取 `τ_th = 2.33`，那只会让算法更保守、更晚开启（p.8）。

## 可迁移机制

1. **「收敛速度 = 全批项 + 方差项」的分解**（式 (6)，p.3）是把「采样策略」与「优化进度」分离的通用工具：只要能把速度写成「与分布无关的项」+「依赖分布的方差项」，采样设计问题就退化为一个最小化方差的独立问题。这个分解是本论文全部结论的骨架。
2. **「用可算上界替换不可算量」的松弛路径**（式 (8)，p.3）：原问题的最优解是 `p_i ∝ ‖G_i‖`，把目标里的 `‖G_i‖` 换成上界 `Ĝ_i` 后，最优解仍是 `p_i ∝ Ĝ_i`。这条「换掉被优化的量、但保持解的**形式**不变」的松弛，是本笔记中最可直接复用的一步。
3. **方差缩减与批大小之间的换算**（式 (23)(27)，p.4）：把「方差降低多少」翻译成「相当于把批放大多少倍」的 τ，使阈值选择从「调一个无单位的距离」变成「说要等价于多大的批」。这是一个把抽象量变成可解释量的模板。
4. **工程上「不要为不可能赢的情况付代价」**：算法在 `τ ≤ τ_th` 时退回均匀采样，且**在均匀分支里顺手算好下次要用的 `Ĝ_i`（无需额外前向）**（p.4–5）。任何「按分数决定是否启用选择」的机制都需要这类「零额外成本地维持分数」的设计。
5. **经验参数的上界形式**：`B = kb, 2 < k < 6`（附录 D，p.12）是一个**范围**而非点值；论文同时说明无论 B 取多少，配合由分析指定的 τ_th 都能保证只在方差可大幅降低时才花时间做重要性采样。

## 不能直接声称内容

- 本文实验是**图像分类（CIFAR10/100）、图像微调（MIT Indoor 67）与序列分类（逐像素 MNIST）**（p.5–8）；**没有网络流量、加密流量或表格数据实验**，不能把其读数迁移到流量检测。
- 全文的**无偏性依赖 `w_i = 1/(N p_i)`**（式 (4)(5)，p.3）。算法实现中用的是 `w_i = 1/(B g_i)`（Algorithm 1 第 9 行），即相对**预采样大批**归一化，而非常数 N。不能把式 (4)(5) 的无偏性直接套到算法实现上而不检查这一步替换。
- **式 (20) 的 `Ĝ_i` 只是上界，不是梯度范数本身**；且论文的紧性证据只有 §4.1 的一个实验（1,024 张图、宽残差网、CIFAR100，p.6）。不能声称该上界在任何网络/任务上都紧。
- 论文的「保障加速」条件是 `B + 3b < 3τb`，且**推导时假设反向耗时是前向的两倍**（p.4）。不能把该条件当作与硬件无关的普适保证。
- 论文自己在 §4.1 报告**按损失采样会增大方差、尤其在训练早期**（p.6）。这是本文对该类方法的负面读数，不能被转述成「按损失/按困难程度采样能降低方差」。
- 论文未报告 τ 的实际取值分布、也未报告重要性采样开启的时间点（除 §4.4 提到约 2,000 秒）；「算法在训练中实际有多少步处于重要性采样分支」在原文中没有数据。
- 附录 C 的 SVRG 对比是**按原论文作者的调参范围**做的（学习率与 m，SCSG 另调大 batch 及其增长率，p.12），论文未给出这些基线的完整超参表；不能声称「SVRG 类方法在深度学习上普遍更差」。
- 附录 D 自陈是 **preliminary ablation**（p.12），且只在 CIFAR10 上做；`B = kb, 2<k<6` 是经验规则，不是定理。
- 禁止写「首次 / 首创」。论文在 §2 明确把重要性采样的理论渊源（Bordes et al. 2005；Richtárik & Takáč 2013；Zhao & Zhang 2015；Needell et al. 2014）与深度学习侧的历史（Bengio et al. 2009；Schaul et al. 2015 的优先经验回放；Loshchilov & Hutter 2015 的在线批选择）分列，并把本文定位为「在既有按损失/按排序采样之外，提供可单次前向计算的上界与可判定的加速条件」。可表述为「在本笔记检索范围内，未检得在深度网络上以『损失对最后一层预激活的梯度』作为逐样本梯度范数上界并据此构造采样分布的更早同构先例」。

## 与课题的关系

**以下为本课题的关联判断，不是原文主张。** 本课题的双侧组相对对抗训练需要「重要性采样与方差缩减的方差上界」这一推导支撑，本文给出的是**把采样分布的选择与梯度估计的方差显式联系起来**的那一套代数。逐条对照：

- **已占用（方差上界的推导骨架）**：`S = 全批项 − η²Tr(V[G])`（式 (6)，p.3）与 `argmin Tr(V) = argmin E[‖G‖²]`（式 (7)，p.3）这两步，把「如何采样」直接归约成「最小化缩放后梯度的二阶矩」。本课题若要论证「某种组内采样/加权降低梯度方差」，必须在这条链路上给出自己的推导，而不能把式 (7) 直接当作自己的结论。
- **已占用（最优分布的比例形式与它的松弛）**：`p_i ∝ ‖G_i‖`（p.3 末）与它的上界松弛 `p_i ∝ Ĝ_i`（p.3，式 (8) 后一句）都已被占用，并且是「形式不变、被优化的量被替换」这一松弛手法的标准表述。
- **已占用（方差缩减与批大小的换算）**：τ 的定义（式 (26)(27)，p.4）把方差降低换算为等价批大小增量，并给出「何时值得开启」的判定。本课题若要用「等价批大小」论证某个组内机制的收益，这条换算是必须对标的既有表述。
- **已占用（负面读数）**：按损失/按困难程度采样会**增大**方差（§4.1，p.6），且这一读数有定量支撑（图 2 的误差平方和 0.017 vs 0.002）。这意味着本课题若把「按损失选择」当作降低方差的机制，与本文的正面读数方向相反，必须显式说明差异（例如目标是收敛速度而非方差本身），否则会被本文的证据直接反驳。
- **未占用（组结构与组内相对量）**：本文的采样分布在**整个数据集（或其预采样大批）上**，权重 `w_i = 1/(B g_i)` 也按全批归一化；**没有「组」这一层**，也不存在「组间归一化」「组内相对排序」的结构（式 (2)、Algorithm 1，p.3–4）。以**组为单位的采样、或由组内相对信号驱动的加权**，在本文未被占用。
- **未占用（任务域）**：本文全部为图像与序列分类；**不涉及分布漂移、跨年度泛化、实体级聚合、类别不对称纠错或加密流量**。本文的「重要性」是**梯度量级**意义上的（对参数更新的贡献），不是「对某个评测指标更关键」意义上的。
- **可复用的对照设计**：§4.1 的四方对照（`uniform` / `loss` / `upper-bound` / `gradient-norm`，p.5–6）是一个把「替代量是否够紧」量化出来的模板——用真实梯度范数做参照，报一个标量误差（0.017 vs 0.002）。本课题的组内机制若有代理信号，也应设同口径的「真实量」参照。
- **可复用的成本账**：预采样带来最大方差缩减 `1/b − 1/B` 与最大加速 `(B+3b)/(3B)`（p.4）；这两条给出了「多算一次前向是否划算」的解析门槛。

一句话：本文占用了「把采样分布与梯度估计方差显式挂钩、并用可算上界替换梯度范数」这一整套推导，且给出了「按损失采样反而增大方差」的定量负面读数；它的采样单位是全数据集而非组，权重按全批归一化，因此「以组为单位、由组内相对信号驱动的重要性采样或加权」在该子空间仍未被本文占用。
