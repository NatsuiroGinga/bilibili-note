## 一句话

把「全部个体损失中最大的 k 个取平均」作为聚合损失，用一个带鞍点式标量 λ 的闭式重写证明它对个体损失凸，从而既能按 top-k 取舍、又能用常规梯度法优化。

## 核心定义与公式

### 三种已有聚合损失（p.1–2）

监督学习的目标写作 `min_f { Ł(L_z(f)) + Ω(f) }`，其中 `L_z(f) = {ℓ_i(f)}_{i=1}^n` 是个体损失集合。论文指出：与个体损失的繁多选择相比，**聚合损失只有很少几种**（第 1 页末至第 2 页）：

- **平均损失**：`Ł_avg(L_z(f)) = (1/n) Σ_{i=1}^n ℓ_i(f)`，即全部个体损失的均值（第 1 页）。
- **最大损失**：`Ł_max(L_z(f)) = max_{1≤i≤n} ℓ_i(f)`，即最大的那个个体损失（**第 2 页**）。
- **top-k 损失** [20]：`Ł_top-k(L_z(f)) = ℓ_[k](f)`，`1 ≤ k ≤ n`，即第 k 大的个体损失（**第 2 页**）；符号约定为 `s_[1] ≥ s_[2] ≥ … ≥ s_[n]`（第 2 页脚注 2）。

论文明说三者关系：`Ł_max = Ł_top-1`，即最大损失是 top-k 损失的特例（第 2 页）；而**top-k 损失一般不对全部个体损失凸**（第 2 页），这正是本文要修的问题。

### AT-k 的定义（式 (1)，p.2）

```text
Ł_avt-k(L_z(f)) = (1/k) Σ_{i=1}^k ℓ_[i](f)                                    … (1)
```

即「**最大的 k 个个体损失的平均**」。基于它的学习目标称为 MAT-k learning（第 2 页）。论文给出的两条基本关系（p.2）：

1. **两端退化**：`k = n` 时是平均损失，`k = 1` 时是最大损失（第 2 页）。
2. **与 top-k 损失的上下关系**：`Ł_avt-k(L_z(f)) ≥ Ł_top-k(L_z(f))`，且等号在 `k = 1` 或 `ℓ_i(f) = 常数` 时成立——即 AT-k 是 top-k 损失的**紧上界**（第 2 页）。论文同时给出 top-k 一般不凸的原因：`ℓ_[k](f) = k·Ł_avt-k(L_z(f)) − (k−1)·Ł_avt-(k−1)(L_z(f))`，两个凸函数之差一般不是凸的（第 2 页）。

### §2 Formulation：闭式重写（p.3）

原始定义含排序过程，不便使用，也不便与「最小化期望个体损失」的统计视角对接。论文用 Lemma 1 给出等价形式（第 3 页）：

**Lemma 1（引 Ogryczak & Tamir [16]）**（p.3）：`Σ_{i=1}^k x_[i]` 是 `(x_1,…,x_n)` 的凸函数；进一步，对 `x_i ≥ 0`、`i = 1,…,n`，

```text
Σ_{i=1}^k x_[i] = min_{λ≥0} { kλ + Σ_{i=1}^n [x_i − λ]_+ }       其中 [a]_+ = max{0, a}
```

据此得到 AT-k 的等价形式（**式 (2)，p.3**）：

```text
Ł_avt-k(L_z(f)) = (1/k) Σ_{i=1}^k ℓ_[i](f)
                ∝ min_{λ≥0} { (1/n) Σ_{i=1}^n [ℓ_i(f) − λ]_+ + (k/n) λ }      … (2)
```

论文对该重写的解释（p.3）：AT-k 等价于「把个体损失**平移**（shift down）并由 hinge 函数在 `λ` 控制下**截断**（truncate）后取平均」。在二分类的 margin 损失 `ℓ(f(x), y) = ℓ(yf(x))` 下论文给出直观解释（p.3，图 2 在 p.4）：0-1 损失对正确分类不给惩罚，而常用的凸代理损失对**正确分类但离边界较近**的样本仍给正惩罚，导致最小化平均损失时会牺牲这些靠近边界的稀有子群；`[ℓ(yf(x)) − λ]_+` 把个体损失整体下移并在 0 处截断，使「离边界足够远」的正确分类样本惩罚归零，从而降低稀有子群被牺牲的可能。

### 算法：随机（投影）梯度下降（式 (3)(4)，p.4）

参数化 `f(x; w)` 后目标为（**式 (3)，p.4**）：

```text
min_{w, λ≥0} { (1/n) Σ_{i=1}^n [ℓ(f(x_i; w), y_i) − λ]_+ + (k/n) λ + Ω(w) }      … (3)
```

论文指出：若 `ℓ(f(x;w), y)` 对 `w` 凸，则式 (3) 对 `(w, λ)` **联合凸**，可用随机（投影）梯度下降直接求解。取 `Ω(w) = (1/2C)‖w‖²` 后，第 t 次迭代的更新为（**式 (4)，p.4**）：

```text
w^(t+1) ← w^(t) − η_t ( ∂_w ℓ(f(x_{i_t}; w^(t)), y_{i_t}) · I[ ℓ(f(x_{i_t}; w^(t)), y_{i_t}) > λ^(t) ] + w^(t)/C )
λ^(t+1) ← [ λ^(t) − η_t ( k/n − I[ ℓ(f(x_{i_t}; w^(t)), y_{i_t}) > λ^(t) ] ) ]_+
```

（其中 `∂_w ℓ` 为次梯度，步长 `η_t ∼ 1/√t`。）

### ATk-SVM（式 (5)(6)，p.4）

把 AT-k 与 RKHS 中的个体 hinge 损失 `[1 − y_i f(x_i)]_+` 结合，得（**式 (5)，p.4**）：

```text
min_{f∈H_K, λ≥0} (1/n) Σ_{i=1}^n [ [1 − y_i f(x_i)]_+ − λ ]_+ + (k/n) λ + (1/2C)‖f‖²_K      … (5)
```

**Lemma 2（p.4）**：对 `a ≥ 0, b ≥ 0`，`[ [a − ℓ]_+ − b ]_+ = [a − b − ℓ]_+`，因此外层 hinge 可去掉。又由 `f = 0, λ = 1` 代入可得 `0 ≤ λ_z ≤ 1`，于是把 `ρ = 1 − λ` 代入并去掉外层 hinge 后（**式 (6)，p.4**）：

```text
min_{f∈H_K, 0≤ρ≤1} (1/n) Σ_{i=1}^n [ρ − y_i f(x_i)]_+ − (k/n) ρ + (1/2C)‖f‖²_K      … (6)
```

论文给出的关系（p.4）：`k = n` 时式 (6) 等于标准 **C-SVM**；当 `C = 1` 且对任意 i 有 `K(x_i, x_i) ≤ 1` 时，ATk-SVM 退化为 **ν-SVM**，且 `ν = k/n`（附录 B 的 Proposition 1 给出证明，p.14）。对偶形式是凸二次规划（对偶写法在 p.15：`0 ≤ α_i ≤ C/n`、`Σ α_i ≤ Ck/n`）。

**Choosing k（p.4）**：k 是整数、影响性能，论文建议按验证集网格搜索；同时指出 Theorem 1 给出 k 的理论**下界**，且若知道离群点比例可据此缩小搜索范围。

## 关键定理

### Theorem 1（分类校准，p.5）

**陈述（逐字转写，p.5）**：

> Theorem 1. Suppose the individual loss ℓ : R → R_+ is convex, differentiable at 0 and ℓ′(0) < 0. Without loss of generality, assume that ℓ(0) = 1. Let (f\*, λ\*) be defined in (7),
> (i) If ν > E\*_ℓ then the ATk loss is classification calibrated.
> (ii) If, moreover, ℓ is monotonically decreasing and the ATk aggregate loss is classification calibrated then ν ≥ ∫_{η(x)≠1/2} min(η(x), 1−η(x)) dp_X(x).

**条件与前置设定（p.5）**：

- 训练数据 `z = {(x_i, y_i)}_{i=1}^n` 是来自未知分布 p 的 i.i.d. 样本；`p_X` 是输入空间上的边缘分布；`η(x) = Pr(y = 1 | x)`；Bayes 规则 `f_c(x) = sign(η(x) − 1/2)`；Bayes 误差 `R* = inf_f R(f)`（p.5）。
- 代理损失 ℓ 凸且在 0 处可微、`ℓ′(0) < 0`，并上界 0-1 损失；`E_ℓ(f) = E[ℓ(yf(x))]` 为其风险，`E*_ℓ = inf_f E_ℓ(f)`（p.5）。
- **校准的定义（p.5）**：对任意 x，若最小化 `E_ℓ(f)` 的解 `f*_ℓ` 与 Bayes 规则的符号相同（当 `f_c(x) ≠ 0` 时 `sign(f*_ℓ(x)) = sign(f_c(x))`），则称 ℓ 关于分布 p 分类校准。
- **式 (7)（p.5）**：AT-k 的总体形式由式 (2) 的无穷极限给出——`(1/n)Σ[ℓ(y_i f(x_i)) − λ]_+ + (k/n)λ` 在 `k/n → ν, n → ∞` 时趋于 `E[[ℓ(yf(x)) − λ]_+] + νλ`；由此定义式 (7) 并说：当且仅当 `f*` 与 Bayes 规则同号时，称 AT-k 聚合损失关于 p 分类校准。

```text
(f*, λ*) = arg inf_{f, λ≥0} E[[ℓ(yf(x)) − λ]_+] + νλ                            … (7)
```

**论文对该定理的读法（p.5）**：

- (i) 与 (ii) 分别给出 ν 的**充分**与**必要**条件。
- 由于 ℓ 是 0-1 损失的（凸）上界，`E*_ℓ ≥ R*`；特别地当个体损失为 hinge 时 `E*_ℓ = 2R*`。
- 因此 **`k > n·E*_ℓ` 保证分类校准**，这给出 k 的**下界**。
- 该结果同时解释最大损失（AT-k 在 `k = 1`）对离群点的敏感性：若 `{x : η(x) = 1/2}` 的概率为 0，则 `R* = ∫_X min(η(x), 1−η(x)) dp_X(x)`；定理说明此时若最大损失校准，就必须有 `1/n ≈ ν ≥ R*`，即随着训练数据增多 Bayes 误差必须任意小。论文的解释是：这与「最大损失在可分数据上表现好、在离群点与非可分数据上敏感」的经验观察一致（p.5）。

**证明位置**：附录 A.2，p.10–11（证明骨架：先由 `f = 0, λ = 1` 得 `0 ≤ λ* ≤ 1`；令 `β = 1 − λ` 把式 (7) 等价改写为式 (13)；证 `β* ≥ (ν − E*_ℓ)/ν > 0`（当 `ν > E*_ℓ`）；再用 [1] 的 Theorem 2（凸、0 处可微且 `φ′(0) < 0` ⇒ 校准）应用到 `φ(t) = (ℓ(t) − λ*)_+`；第二部分分 `λ* = 0` 与 `λ* > 0` 两种情形讨论）。

### Theorem 2（ATk-SVM 的超出风险界，p.6）

**陈述（逐字转写，p.6；式中的分式 OCR 存在歧义，见「疑问待验证」）**：

> Theorem 2. Consider the ATk-SVM in RKHS (6). For any ε ∈ (0, 1] and µ ∈ (0, 1 − E_h(f_H)), choosing k = ⌈n(E_h(f_H) + µ)⌉. Then, it holds
> Pr{ R(sign(f_z)) − R\* ≥ µ + A(H) + ε + (1 + C_{κ,H})/(√n µ) } ≤ 2 exp( − nµ²ε² / (1 + C_{κ,H})² ), where C_{κ,H} = κ(2√(2C) + 4‖f_H‖_K).

**条件（p.6 正文）**：`(f_z, ρ_z)` 是式 (6) 在 RKHS 中的最小化元；`f_H = argmin_{f∈H_K} E_h(f)` 是 hinge 风险的 RKHS 最小化元，`E_h(f) = E[[1 − yf(x)]_+]`；假设 `E_h(f_H) < 1`（零分类器的风险恰为 1）；近似误差 `A(H_K) = inf_{f∈H_K} E_h(f) − E_h(f_c) = E_h(f_H) − E_h(f_c)`；`κ = sup_{x∈X} √(K(x,x))`。

**推论（p.6）**：若 K 是通用核则 `A(H_K) = 0`，取 `µ = ε ∈ (0, 1 − E_h(f_H))` 得 `Pr{R(sign(f_z)) − R* ≥ 2ε + (1 + C_{κ,H})/(√n ε)} ≤ 2 exp(−nε⁴/(1 + C_{κ,H})²)`；于是只要取 C 使得 `lim_{n→∞} C/n = 0`，`R(sign(f_z))` 可以以高概率任意接近 Bayes 误差 `R*`（n 足够大时）。论文强调该结果**不要求核是通用的**，与 Steinwart [22] 对 ν-SVM 的对应结果不同（p.11 附录 A.3 开头）。

**证明位置**：附录 A.3，p.11–14（依赖 McDiarmid 不等式（Lemma 3, p.11）、Rademacher 平均的压缩性质（Lemma 4, p.11）、一个 hinge 经验风险与总体风险的界（Lemma 5, p.12）、Hoeffding 不等式（Lemma 6, p.12）、以及 ρ_z 的下界（Lemma 7, p.12））。

论文的读法（p.7）：与分类情形类似，使用 AT-k 通常相对平均损失或最大损失有改进。

### 合成数据的行为（附录 C，p.15–17）

6 组 2D 合成数据（每组 200 样本、高斯分布），论文逐案报告：无离群点可分时所有聚合损失都完美（Case 1）；存在一个离群点时最大损失对之高度敏感、AT-k 在 `k ≥ 3` 时更稳（Case 2）；可分但 + 类含「典型 + 稀有」两个分布时，平均损失会牺牲稀有子群（Case 3）；同时存在多峰与离群点时只有一段 k 区间表现好（Case 4）；不平衡场景下平均损失牺牲掉全部或半数少数类样本，而 AT-k 在给定 k 区间内表现更好（Case 5、Case 6）（p.15–16）。附录 C 对每案都给出具体的 k 区间（例如 Case 3：logistic 下 `k ∈ [1, 18]`、hinge 下 `k ∈ [1, 50]`；Case 4：`k ∈ [4, 24]` 与 `k ∈ [3, 62]`）。

### 与既有聚合损失的关系（§5 Related Works，p.7–8）

- 排序驱动的聚合损失已有 curriculum learning [2] 与 self-paced learning [11, 9]；论文指出 self-paced learning 的每一轮等价于最小化「**最小的 k 个**个体损失的平均」（论文称之为 average bottom-k loss），与本文的 average top-k 相反；并指出 average bottom-k 与 top-k 一般都不对个体损失凸（p.8）。
- [20]（Shalev-Shwartz & Wexler, 2016）比较最大损失与平均损失的利弊并主张 top-k 损失 `ℓ_[k](f)`；论文指出与 AT-k 不同，该 top-k 损失一般不凸（p.8）。
- 多类分类中的 top-1 / top-k 损失（[6]、[12]、[13]）是**个体损失**层面的设计，与 AT-k 互补、可组合（p.8）。

## 可迁移机制

1. **「取最大的 k 个再平均」的凸化路径可以整条复用**：先用 Lemma 1 把「前 k 大之和」写成 `min_{λ≥0} { kλ + Σ[x_i − λ]_+ }`，再除以 k 归一化。任何需要「按值取前若干个再聚合」的目标，只要写成这个鞍点形式并对 λ 联合优化，就能保持凸性——这是本笔记最可迁移的一条。
2. **实现层面只需在个体损失上加一个可学的平移量 λ**：训练时每个样本要额外判断一次 `ℓ > λ`（式 (4) 中的指示函数），λ 本身也按同一批梯度更新；不需要排序，也不需要知道 k 对应的分位点。这与「每步对整批做排序」的朴素实现形成对照。
3. **k 的两个端点把「均值」与「最大值」统一为同一族的特例**，因此任何针对平均损失或最大损失的结论都可以作为 `k = n`、`k = 1` 的对照被纳入同一实验。这一点在做消融时特别有用：只需扫一个整数 k，就能同时覆盖两种极端聚合方式。
4. **k 的可验证下界**：Theorem 1 给出 `k > n·E*_ℓ` 的校准下界；hinge 时 `E*_ℓ = 2R*`，于是下界可直接用 Bayes 误差表示（p.5）。这是一个「用理论约束搜索空间」的可迁移做法，但注意它只保证**校准**，不保证泛化或收敛速度。
5. **与 ν-SVM / ν-SVR 的等价关系**（Prop. 1 p.14、Prop. 2 p.15）：在 `C = 1`、`K(x_i,x_i) ≤ 1` 的条件下 ATk-SVM 就是 `ν = k/n` 的 ν-SVM；个体绝对损失下 MAT-k 就是 `ν = k/n` 的 ν-SVR。这条等价把「k」的解释接到了 ν 的既有性质上（例如 k 是支持向量数的下界、间隔误差数的上界，p.15）。

## 不能直接声称内容

- 本文实验是**二分类与回归的表格基准**（UCI/KEEL 8 个分类集、4 个回归集，p.6–8）；**没有图像、序列、网络流量、加密流量或分布偏移实验**。不能把本文的误分类率/RMSE 数字迁移到流量检测任务。
- 本文的模型是**线性（齐次）预测函数 + Tikhonov 正则**（p.6），且分类实验中 C 与 k 都在验证集上网格搜索。**不能声称 AT-k 在深度网络上有效**——论文自己在 §6 Discussion 把「与深度学习结合」列为尚未研究的问题（p.8）。
- **AT-k 只做「选择」，不做「加权」。** 式 (1) 与式 (2) 中被选中的 k 个个体损失在目标里权重完全相同（各 1/k），未被选中的个体损失只在 `[ℓ_i − λ]_+` 里以截断形式贡献 `k/n·λ` 的常数项。不能把 AT-k 描述为「按损失大小给样本分配不同权重」的机制。
- **AT-k 读的是个体损失的绝对量级，不是组内相对量。** λ 是全局共享的标量阈值，不是「组均值」。不能把 AT-k 说成「按相对偏离组均值加权」。
- **Theorem 1 只保证分类校准（sign 一致），不保证泛化速度、不保证最小化风险收敛到 Bayes 误差。** 后者的界是 Theorem 2，且它针对的是 ATk-SVM（hinge + RKHS）这一特例，不是一般 MAT-k。不能把两个定理混用。
- Theorem 1 的条件包含「`ℓ` 在 0 处可微且 `ℓ′(0) < 0`、且 `ℓ(0) = 1`」（归一化后的无损假设）。**0-1 损失、以及未必在 0 处可微的个体损失不满足该条件**，不能把该定理套用到任意个体损失上。
- **论文没有对 k 做敏感性/稳定性分析**：表 1 与表 2 只报 `AT k*`（验证集选出的最优 k）的最终指标，**没有报告 k* 本身的取值分布或不同 k 下的方差**；图 3 只给四个数据集的曲线。不能声称「最优 k 有稳定的量级规律」。
- Proposition 1/2 的等价关系都带条件（Prop. 1：`C = 1` 且 `K(x_i,x_i) ≤ 1`；Prop. 2：无偏置项 b 的 ν-SVR 形式，p.14–15）。不能把「ATk-SVM ≈ ν-SVM」写成无条件等价。
- 合成数据（附录 C）是**论文自己生成、自己调参**的 2D 示例，用于定性说明分布形态的影响；不能当作独立证据支持机制主张。
- 禁止写「首次 / 首创」。论文在 §5（p.7–8）明确把 sorted/aggregate 损失的历史追溯到 curriculum learning 与 self-paced learning，并说明 top-k 损失的思想来自 [20]。可表述为「在本笔记检索范围内，未检得在 AT-k 之前给出『最大的 k 个损失取平均』这一聚合损失并证其凸性的更早同构先例」。

## 与课题的关系

**以下为本课题的关联判断，不是原文主张。** 本课题的双侧组相对对抗训练需要「按损失取 top-k / 组内选择」的形式化支撑，AT-k 提供的是**聚合目标层面的形式化**（把组内选择写进损失函数并保住凸性），OHEM 提供的是**执行层面**的对照（逐迭代在线选择）。逐条对照：

- **已占用（选择规则的目标层形式化）**：AT-k 已经占用了「取最大的 k 个、取其平均」这一聚合规则，并给出了闭式重写（式 (1)(2)，p.2–3）、凸性证明、可用的梯度更新式（式 (4)，p.4）、以及分类校准与误差界的理论（Theorem 1/2，p.5–6）。因此本课题若要在目标层形式化「组内 top-k」，必须显式说明与 AT-k 的差异，不能把它当作新目标。
- **已占用（k 的可调性与两端退化）**：「k 在 [1, n] 上扫、两端分别退化为最大与平均」这一实验设计已被本文占用（图 3，p.7）。
- **已占用（k 的下界论证形式）**：用 Bayes 误差/最优代理风险给出 k 下界的论证路径已被本文占用（Theorem 1，p.5）。本课题若要给「组内取多少个」的理论下界，需要在机制上另找依据。
- **未占用（信息源）**：AT-k 的 λ 是**全局标量**，对所有样本共享；选择判据是「个体损失是否超过 λ」，即**绝对量级**，不含任何组内相对量（式 (2)(3)，p.3–4）。以**组内相对/中心化信号**（相对组均值的偏离、方向符号、双侧结构）驱动的组内选择或加权，在本文未被占用。
- **未占用（分组结构）**：本文的选择跨**整个训练集**做（式 (1) 的下标 `k` 是全局的），**没有「分组」这一层**——不存在「每组内各自取 top-k 再组间合并」的结构。这一点是本课题与 AT-k 的最实质差异：本课题的组相对机制要求选择/加权发生在组内并对组间做比较，而 AT-k 的排序是全数据集排序。
- **未占用（任务域）**：本文全部为表格二分类/回归，无分布漂移、无跨年度泛化、无实体级聚合、无类别不对称纠错、无加密流量。
- **可复用的成本账与实现**：式 (4) 的形式说明「按损失取 top-k 的聚合目标**不需要每步排序**」——只需一个可学的标量阈值 λ 加一个指示函数。若本课题的组内选择要落到可训练的目标上，这是最省事的实现路径，同时也是必须与「真实排序取 top-k」区分开的地方（前者是 λ 阈值，后者是精确分位数）。
- **可复用的对照设计**：`k = 1`（最大）与 `k = n`（平均）是两个天然的同族对照端点，本课题做组内选择消融时应把这两个端点纳入，以说明收益来自「中间 k」而不是两端。

一句话：AT-k 占用了「全局按损失取 top-k 再平均」的目标层形式化与凸化路径；它的选择判据是全球共享的绝对阈值 λ，不含组内相对量与分组结构，因此「组内相对信号驱动、按组分层的选择/加权」在该子空间仍未被本文占用。

## 疑问待验证

- **Theorem 2 的界在原件 p.6 的排版存在分式歧义。** pypdf 抽取结果为 `R(sign(f_z)) − R* ≥ µ + A(H) + ε + (1 + C_{κ,H})/(√n µ)`，而附录 A.3 的证明末行（p.14）得到的是 `µ + 1/n + A(H) + ε + 2κR_{C,µ}/√n`，其中 `R_{C,µ} := (2√(2C) + 4‖f_H‖_K)/µ`。两者形式不同（正文以 `(1 + C_{κ,H})/(√n µ)` 表达，证明以 `2κR_{C,µ}/√n` 表达）。本笔记按原文分别逐字转写，**未擅自统一**；直接引用该界前应回原件 p.6 与 p.14 二次核对 LaTeX 源。
- Theorem 1 的 (ii) 依赖「ℓ 单调递减」这一额外条件（p.5）。常见个体损失里平方损失 `ℓ(t) = (1−t)²` 并不单调递减（附录 A.2, p.10 把它列为满足 `ℓ′(0) < 0` 与 `ℓ(0)=1` 的例子，但未讨论其单调性）。因此 (ii) 的必要性方向**不适用于平方损失**；本笔记未找到论文对此的说明。
- 论文把「最大损失对离群点敏感」归因于 `k=1` 时 `1/n ≈ ν ≥ R*` 要求 Bayes 误差随 n 增大而任意小（p.5）。这是理论论证，**与附录 C 的合成实验之间没有建立定量对应**；不能声称实验验证了该论证。
- 表 1 与表 2 未报告 `k*` 的取值，也未报告 k 在验证集上的选择曲线（除图 3 的四个数据集外）。因此「最优 k 与数据不平衡度/离群点比例的关系」在原文中没有直接证据。
- 论文未讨论 AT-k 与**随机梯度方差**的关系（式 (4) 中 λ 与 w 同时用单个样本的随机梯度更新，λ 的更新量是 `k/n − I[...]`，其方差行为未被分析）。若本课题要在组内用类似的阈值化参数做在线更新，这一点需要另行验证。
- 论文未报告计算成本对比（无训练时间、无内存表）。「无需显著增加计算」是论文在第 3 页贡献列表里的断言，**无配套读数**。
