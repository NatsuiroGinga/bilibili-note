# 注意力多示例学习池化（Ilse 等，2018）

**阅读状态**：全文已读（MinerU 转换，`70.2 KB`），公式逐条核对。
**在本课题中的角色**：第三章机制二（袋尺度不变实体聚合）的家族原点。

## 一、形式化框架

`【全文】§2.1`，引 Zaheer 等 2017 的形式：

> **定理 1**：实例集合 `X` 的打分函数 `S(X) ∈ ℝ` 是对称函数（对 `X` 中元素置换不变），
> 当且仅当可分解为 `S(X) = g( Σ_{x∈X} f(x) )`。

> **定理 2**：任给 `ε > 0`，Hausdorff 连续的对称函数可由 `g( max_{x∈X} f(x) )` 任意逼近。

两者共同给出三步法：**实例变换 `f` → 置换不变聚合 `σ` → 袋变换 `g`**。
定理 1 是普适分解，定理 2 是任意逼近。表达能力取决于 `f` 与 `g` 的函数类。

## 二、池化算子

`【全文】§2.3`：

- 式 (5) 取最大：`z_m = max_k { h_km }`
- 式 (6) 取均值：`z = (1/K) Σ_k h_k`
- 原文另列可用算子：**凸最大（log-sum-exp）**、ISR、noisy-or、noisy-and，
  「均可微，可直接作神经网络的池化层」。

**原文对这些算子的评价（§2.4 首段）**：它们「预定义、不可训练」；
取最大适合实例式，可能不适合嵌入式；**取均值「绝对是聚合实例分数的坏池化」**，
但用于算袋表示时可行。

## 三、注意力池化与袋尺度不变性

`【全文】§2.4`，式 (7)(8)：

```
z = Σ_{k=1..K} a_k · h_k

a_k = exp{ wᵀ tanh(V h_kᵀ) } / Σ_{j=1..K} exp{ wᵀ tanh(V h_jᵀ) }
```

`w ∈ ℝ^{L×1}`、`V ∈ ℝ^{L×M}` 为参数；`tanh` 逐元素，取其同时含正负值以利梯度流动。

> **本课题引用的关键句（原文 §2.4）**：「权重**必须和为 1** 才对袋的大小不变。」

式 (9) 为门控版本，加 `sigm(U h_kᵀ)` 逐元素相乘，理由是 `tanh(x)` 在 `x∈[−1,1]` 近似线性、
限制表达能力。

**原文自陈的开放问题**：注意力机制在实例间无序列依赖时是否会退化成取均值——原文说由实验回答。

## 四、与本课题的接口与差距

| 项 | Ilse 原文 | 本课题 |
| --- | --- | --- |
| 聚合对象 | 低维**嵌入** `h_k` | 标量**逐流 logit** `s_k` |
| 参数 | 需可学 `V, w` | 期望无参数（可迁移到任意骨干，加分项） |
| 袋大小范围 | 组织病理切片，量级稳定 | **正实体袋中位跨年 `112 → 15`**（本课题实测） |

**本课题的改造方向**：以流分数自身作注意力 logit，`a_k = softmax(τ·s_k)`。
保留「权重和为 1」这一不变性来源，去掉可学参数，并以单一温度 `τ`
连续插值式 (6)（`τ→0`）与式 (5)（`τ→∞`）。

**须注意的反例**：Peters & Farhat（arXiv:2311.12760）实测**权重和为 1 并不足够**——
袋极大时低注意力实例合计可占 `80%` 以上质量，须叠加 top-`k` 截断。
见 [2023-Peters-恶意软件多示例学习](2023-Peters-恶意软件多示例学习.md)。

## 五、可引用的论断与边界

- **可引用**：三步分解定理、权重和为 1 是袋尺度不变的来源、取均值不适合聚合实例分数。
- **不可引用**：原文实验在组织病理与 MNIST-bags 上，**未涉及跨年度分布漂移**，
  其性能数字不能作为本课题的效果预期。
