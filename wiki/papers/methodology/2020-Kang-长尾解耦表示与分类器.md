# 解耦表示与分类器：长尾识别的自然采样与分类器再平衡

> **证据等级**：本地全文（MinerU `extract`，`raw/papers/methodology/2020-Kang-Decoupling-Representation-Classifier.pdf`）。
> 页码为 PDF 物理页。

## 核心机制

1. **解耦框架**：把长尾识别拆成
   - 表示学习：用采样策略/损失训练编码器 \(f(x;\theta)\)；
   - 分类器学习：在表示之上构造分类器 \(g\)，可以重训、用非参数 NCM，或直接缩放权重。
   动机是：联合训练无法区分「表示更好」还是「决策边界被移动」（§1，第 1–2 页）。
2. **采样概率族**（§3，Eq. 1，第 3 页）：
   \[
   p_j=\frac{n_j^q}{\sum_{i=1}^{C}n_i^q},\qquad q\in[0,1].
   \]
   \(q=1\) 为实例平衡（自然）采样；\(q=0\) 为类平衡采样（先均匀选类，再类内均匀选样本）；
   \(q=1/2\) 为平方根采样；渐进平衡为 \(p_j^{PB}(t)=(1-t/T)p_j^{IB}+(t/T)p_j^{CB}\)（Eq. 2，第 4 页）。
   **注意：PAAT 的「正负各半回合」在二分类下就是 \(q=0\) 的类平衡采样**。
3. **分类器再平衡的四种做法**（§4，第 4 页）：
   - **cRT**：冻结表示，随机重初始化并在类平衡采样下重训分类器若干 epoch；
   - **NCM**：计算每类训练样本的均值表示，用余弦/欧氏距离做最近邻（即原型分类器）；
   - **τ-normalization**：按 \(\widetilde{w}_i=w_i/\|w_i\|^\tau\) 缩放分类器权重，\(\tau\in(0,1)\)；\(\tau=0\) 不缩放，\(\tau=1\) 为 L2 归一化；
   - **LWS**：学习每类缩放因子 \(f_i=1/\|w_i\|^\tau\)，表示与权重固定。
4. **关键发现**：联合训练时采样策略确实重要（渐进平衡最好）；但解耦后，**实例平衡采样学到的表示最有泛化性**，
   仅靠分类器再平衡就能超过精心设计的损失/采样/记忆模块（§5.2，第 6–7 页）。

| ImageNet-LT 消融（重训范围） | B+C / B+C(0.1×lr) / LB+C / C | `46.3` / `48.8` / `48.9` / `49.5` | Table 1，第 6 页 |

- **τ-normalization 的机制**：联合训练后分类器权重范数与类样本数正相关；类平衡重训后权重范数趋于接近。
  τ-normalization 直接压缩头部类的权重范数，从而把决策边界向尾部类移动（§4、Fig. 2，第 4、7 页）。
- **NCM 的竞争力**：非参数、无额外训练，在多数设置下接近 cRT（ImageNet-LT 47.3 vs 49.5；Places-LT 36.4 vs 36.7）。
  这与 ProtoNet 的类均值原型同源。

## 与 PAAT M2（正例稀缺的平衡回合训练）的可迁移点

- **对 M2 的最强反证/替代方案**：PAAT M2 在表示学习阶段就把采样分布改成 1:1（\(q=0\)）。
  本文的结论是：**表示学习阶段用自然分布（\(q=1\)）更好，类别不平衡应主要在分类器/决策边界层面处理**。
  若该结论迁移到 PAAT，M2 的默认位置应从「训练全程」改为「年度末分类器再平衡」，或至少增加「延迟 M2」臂。
- **可直接落地的低成本基线**：
  - **NCM on replay buffer**：对每个年度，用当前年 + 回放的表示计算正/负类均值，按余弦距离分类；
  - **τ-normalization**：只对最终分类器权重做一次缩放，单超参 \(\tau\)，不需要重训；
  - **cRT**：冻结编码器，用平衡采样的回合只重训最后分类器若干 epoch。
  这三者都比「正例有放回重复、全程平衡回合」更便宜，应作为 PAAT M2 的必选对照。
- **对 M1 的间接约束**：NCM 已经是一个强原型分类器。PAAT 的零训练原型诊断显示原型融合无独立增益，
  本文正好解释了原因：**在好的表示上，简单类均值已经很强；M1 若要证明价值，必须证明它改善了表示本身，
  而不是只加了一个可学习的原型头**。这与 SupCon 的「投影头在推理时丢弃」形成互补。
- **表示与分类器的分工**：PAAT 的年度循环底座可以保留「表示持续更新」，但在每个年度末增加一个分类器再平衡阶段；
  这与第三章「回放构成」的跨年构成不同，属于年度内的决策边界校正。

## 不可迁移边界

- **平衡测试集假设**：本文所有评测都在**类别平衡的测试/验证集**上（ImageNet-LT、Places-LT、iNaturalist 的验证集被设计为平衡）。
  PAAT 评测的是**自然年度分布**下的 F1（2024 年正例率 1.64%，2025 年 0.05%）。
  把分类器向 1:1 平衡会改变 0.5 阈值下的正例率，未必最大化 F1；这是目标函数层面的根本差异。
- **多类长尾 vs 二分类极端稀有**：本文的 few-shot 类仍有 ≥5 个训练样本（ImageNet-LT 最少 5），
  但类别数多达 1000；PAAT 的 2025 年正例只有 5 个且只有两类，NCM/cRT 的均值估计方差极大。
- **视觉骨干与大数据**：ResNet/ResNeXt + 数十万到百万图像；PAAT 是行为特征上的小模型。
  「自然采样学表示更好」的结论是否适用于表格/安全特征没有证据。
- **冻结表示的前提**：cRT/NCM/τ 都要求有一个冻结的、跨年度共享的表示。PAAT 的编码器按年度持续更新，
  每个年度的表示不同；「冻结哪一年的表示」本身就是一个新问题。
- **τ 的选择**：τ 通过验证集选择；PAAT 末期年度样本极少，若用末期年度选 τ 会接触目标标签，必须在训练区内冻结。
- **与 LDAM 的关系**：本文引用的 LDAM+DRW `68.0` 是原文报告值，本文自己未能复现（§5.4，第 8 页）；
  引用时应注明来源，不能把两个来源的数字混为同一实验。

## 与相关工作的关系

- 与 ProtoNet：NCM 就是 ProtoNet 的「类均值 + 距离分类」，但不做回合训练、不学习嵌入；
  本文证明它在长尾分类上是一个强基线，见 [[2017-Snell-原型网络少样本学习|ProtoNet]]。
- 与 LDAM：LDAM 主张延迟再平衡、早期 ERM 保护特征；本文把这一思想推进到「表示与分类器完全解耦」，
  并给出无需额外训练的 NCM/τ 方案，见 [[2019-Cao-LDAM标签分布感知间隔|LDAM]]。
- 与 Class-Balanced：本文把 CB-Focal 作为对比基线，并在 iNaturalist 上超过它，见 [[2019-Cui-有效样本数类平衡损失|Class-Balanced]]。

## 原始摘要要点

> "We decouple the learning procedure into representation learning and classification ... (1) data imbalance might not be an
> issue in learning high-quality representations; (2) with representations learned with the simplest instance-balanced
> (natural) sampling, it is also possible to achieve strong long-tailed recognition ability by adjusting only the classifier."
