## 一句话

把原始批复制 m 份、用一次联合设计（tLHS）给 m 个副本各自的初始扰动，过同一攻击得到 B_adv，再按原样本分组 `r_i = {x_i^(1), …, x_i^(m)}`，用三种**硬选择**规则挑出最终训练批——CP 每组恰取一个（误分类中取 ℓ∞ 距离最小者），GS 用绝对误分类谓词过滤（每组零个或多个），BG 把干净样本也纳入候选池。

## 机制

### 问题设定（第 5 页第 3 节）

样本集 `D = {(x_i, y_i)}`，`ℓ∞(ε) = {δ | ‖δ‖∞ ≤ ε}`。攻击目标是球内使损失最大者（第 5 页，式 (1)）：

```text
δ* = argmax_{δ ∈ ℓ∞(ε)} L( f_θ(x + δ), y )
```

对抗训练求鲁棒模型（第 5 页，式 (2)）：

```text
θ* = argmin_{θ ∈ Θ} E_{(x,y) ~ D}[ L( f_θ(x + δ*), y ) ]
```

单步法（N-FGSM）先对 `δ^0` 逐元素从 `U(−kε, kε)` 独立采样（`k ≥ 1` 为半径增广参数），再线性估计：

```text
δ̂ = δ^0 + ε · sign[ ∇_{δ^0} L( f_θ(x + δ^0), y ) ]
```

多步法（PGD-n）迭代更新（第 5 页）：

```text
δ̂ ≜ δ^{t+1} = Π[ δ^t + α · sign( ∇_{δ^t} L( f_θ(x + δ^t), y ) ) ],  t = 0, 1, …, n−1
```

其中 `Π(·)` 为到 `ℓ∞(ε)` 的投影。记 `x̂ = x + δ̂`。

### Batch-in-Batch 框架（第 6 页，Algorithm 1）

```text
input  : 原始批 B_ori，训练模型 f_θ，复制数 m，
         初始扰动函数 NOISE，对抗攻击函数 ADV，样本选择函数 SELECT
B_bgn = CONCATENATE(B_ori, B_ori, …, B_ori)          // m 份 B_ori
δ_0   = NOISE(B_ori, m)                              // 为 m 个副本联合设计
B_adv = ADV(B_bgn + δ_0, f_θ)
B_adv = CONCATENATE(B_adv, B_ori)                    // 可选步骤
B_f   = SELECT(B_adv, f_θ)                           // f_θ 用于预测 logits
output : 最终训练批 B_f
```

论文强调（第 6 页）：初始扰动、对抗攻击方法、选择过程三者在本框架内**均可任选**；「Conventional AT methods can be described with specific settings of ADV, m, NOISE and SELECT」。

### 初始扰动的联合设计：tLHS（第 7 页，Algorithm 2）

动机是让 m 个副本的初始扰动在原始样本邻域内**散布得更均匀**，而不是各自独立地随机。算法要点（第 7 页）：

```text
γ = (0, 1/m, 2/m, …, (m−1)/m)^T
δ = (δ_{i,j})_{m×d}
for j = 1, …, d do
    δ_{.j} = random shuffled γ            // 每列填 γ 的一个随机排列
τ = (τ_{i,j})_{m×d},  τ_{i,j} ~ U(0, 1/m)
δ_LHS = 2ε(δ + τ) − ε                     // 扰动并投到 (−ε, ε)
δ_f   = column_bind(δ_LHS, δ_LHS, …, δ_LHS)   // n 份 δ_LHS
reshape δ_f 至与 B_bgn 同尺寸
output: B_bgn 的初始扰动 δ_f
```

要点（第 7 页）：`δ_LHS` 的 m 行可视为某个原始样本的 m 个副本的初始扰动；为控制计算量，把 `δ_LHS` 复制 n 份后 reshape。论文说明这不会触发 R+FGSM 的「所有条目被投到极有限的 {−1, 1} 集合」问题——因为 tLHS 每个 epoch 重新分配全部初始位置，避免重复条目。图 6（第 15 页）用 `d_min`（3 个样本间的 ℓ2 最小距离）对比 tLHS 与简单均匀采样，显示 tLHS 的 `d_min` 更大。

### 分组定义（第 8 页第 4.3 节）

因为初始扰动与攻击都作用在由 m 份 `B_ori` 构成的 `B_bgn` 上，得到的对抗批 `B_adv` 也含 m 组。原文把它排成矩阵并把每一行定义为一个组（第 8 页）：

```text
B_adv = { B_adv^(1), …, B_adv^(m) }
      = { x_1^(1) … x_1^(m) ;
          x_2^(1) … x_2^(m) ;
          ⋮       ⋱   ⋮    ;
          x_n^(1) … x_n^(m) }
      = { r_1 ; r_2 ; … ; r_n }
```

原文定义：「`x_i^(j)` is the j-th adversarial sample of original sample `x_i ∈ B_ori`, and each row `r_i = {x_i^(1), …, x_i^(m)}` of `B_adv` includes all m adversarial samples related to `x_i`」（第 8 页）。

即：**组 = 同一条原样本的 m 个对抗变体**，与「一条干净样本 K 个同源扰动变体」在生成侧完全同构。

### 三种硬选择规则

**CP（Checkpoint 选择，源自 Kim 等 [15]）**（第 8 页，式 (3)）：

```text
SELECT_CP(r_i, f_θ) = { argmin_{j ∈ M_i}  ‖ x_i^(j) − x_i ‖_∞ ,   若 M_i ≠ ∅
                        argmax_{1 ≤ j ≤ m} ‖ x_i^(j) − x_i ‖_∞ ,   若 M_i = ∅

其中  M_i = { j | f_θ( x_i^(j) ) ≠ y_i }
```

原文说明：`M_i` 是 `r_i` 中**全部被误分类的对抗样本的下标集合**；对 `B_adv` 的每一行 `r_i` 施加 CP 即得 `B_f`。与 Kim 等原版的差别在于：本论文的对抗样本 `{x_i^(j), j = 1..m}` **不共线对齐**，候选池含多个位置的梯度信息（第 8 页）。

**GS（Greedy Selection，论文提出，基于 datum-wise 早停）**（第 8 页，式 (4)）：

```text
B_f = SELECT_GS( B_adv, f_θ ) = { x | x ∈ B_adv, x is misclassified by f_θ }
```

原文说明（第 8 页）：「One can notice that the major difference between CP and GS is that for each original sample `x_i`, `i = 1, 2, …, n`, **CP would select only one adversarial sample** from its m related adversarial samples `{x_i^(j), j = 1, …, m}` while **GS could select zero or multiple examples** from it.」直觉是：如果对某条原样本的所有对抗攻击尝试都失败了，继续在这些对抗样本上训练就是不必要。

**BG（Balanced Greedy）**（第 9 页，式 (5)）：

```text
B_S = { B_ori, B_adv }
```

把式 (4) 中的 `B_adv` 换成更大的集合 `B_S`，从而选择不仅来自对抗样本、也可来自干净原样本；复制数 m 因而可用于控制干净准确率与对抗准确率之间的权衡（第 9 页）。三种策略下若 `B_f` 为空则跳过该步训练（原文称「which rarely occurs」，第 9 页）。

### GS 是绝对谓词还是相对量 —— 明确回答

**GS 是绝对误分类谓词，不是相对量。** 式 (4) 的定义是一个**集合构造式**：`{x | x ∈ B_adv, x is misclassified by f_θ}`，判据是 `f_θ(x) ≠ y` 这一布尔谓词，**不涉及任何组内比较、不依赖其他变体的损失或距离、不产生连续分数**。它等价于对每条对抗样本施加一个 0/1 掩码。

**CP 同样不含相对量**：它用 `argmin`/`argmax` 在组内取极值，输出是**下标（硬选一个）**，而不是权重；比较的对象是「该变体到原样本的 ℓ∞ 距离」这一**绝对几何量**，不是「相对组内均值/基线的偏离」。

**三规则共同的形状**：全部是**集合 → 子集的硬映射**（CP 每组出 1 个，GS 每组出 0..m 个，BG 从并集里出子集）。**全文未出现连续权重、未出现减组均值或组内归一化、未出现可正可负的符号量。**

## 实验设置与读数

- **数据集与网络**（第 9 页第 5 节）：CIFAR-10、CIFAR-100、SVHN；PreActResNet18（PRN-18）与 WideResNet28-10（WRN-28）。

- **初始扰动方法对比**：Algorithm 2（tLHS，默认）与简单均匀采样。
- **优化**：SGD，学习率 0.01，momentum 0.9，weight decay 5e-4；学习率在第 28、56 epoch 乘 0.1；**训练 75 epoch**（论文说明因算力所限从 200 降到 75，第 9 页）。

## 可迁移机制

1. **「同源分组」的显式矩阵化定义**：`B_adv = {r_1; …; r_n}`，每行 `r_i = {x_i^(1),…,x_i^(m)}` 就是一条干净样本的全部同源变体（第 8 页）。这是本笔记所见四篇中最干净的分组形式化写法，可直接作为接口定义的参照。
2. **三种硬选择算子的完整谱系**：CP（每组恰取 1 个，按绝对几何量 argmin/argmax）、GS（每组取 0..m 个，按绝对布尔谓词）、BG（把干净样本并入候选池）。三者构成「每个变体的去留」这一维度上的硬选择家族，与 MMEL 的软权重形成互补。
3. **「每组恰选一个」vs「每组可变个数」的对照是最小差异实验**：CP 与 GS 只在这一点上不同（第 8 页原文明确点出），论文因此能在同一框架内给出干净的对照。任何新的选择规则都可以用 CP/GS 作为两端来做最小对照。
4. **初始扰动的联合设计（tLHS）**：把 m 个副本的初始扰动当作一个整体来设计（列用 γ 的随机排列 + 抖动），目的是让 m 个变体在邻域内散布更开（第 7 页；图 6 的 `d_min` 指标，第 15 页）。这条把「变体多样性」从随机性来源变成了可设计的对象，并提供 `d_min` 作为可测的多样性代理指标。
5. **框架的可替换插槽**：NOISE / ADV / SELECT 三者与 m 在 Algorithm 1 中被显式参数化（第 6 页），使不同选择策略可以在同一训练协议下比较。
6. **成本账**：训练时间随 m 的变化在第 15–17 页第 5.4.2 节给出，且论文声称即便 m 较大也成本可控（摘要第 1 页）。CP 对 m 最不敏感（第 15 页）。

## 与课题的关系

本课题关心的结构是「**每条干净样本 K 个同源扰动变体，按欺骗信号选择或加权**」。逐条对照本文已做 / 未做：

- **已占用（生成侧，最直接的同构）**：`B_bgn` 是 `B_ori` 复制 m 份，`B_adv` 按行分组 `r_i = {x_i^(1),…,x_i^(m)}`（第 8 页）。这与「一条干净样本 K 个同源变体」是**逐字同构**，且本文把它写成了显式的矩阵形式——是本课题定义接口时最直接的参照与前驱。
- **已占用（硬选择侧，三种规则）**：CP（每组恰 1 个，按 ℓ∞ 距离 argmin/argmax，第 8 页式 (3)）、GS（每组 0..m 个，按绝对误分类谓词，第 8 页式 (4)）、BG（并入干净样本，第 9 页式 (5)）。因此「从 K 个同源变体中硬选子集」这一子空间被本文**大面积占用**，且三种规则的关系（恰一个 / 可变个 / 并入干净样本）已被显式对照。
- **未占用（本文完全空白）**：本文**没有任何连续权重、没有组内归一化、没有减组均值、没有可正可负的符号量**。因此「以组内相对/中心化信号驱动变体选择或**加权**」这一子空间在本文未被占用；本文的三种规则也都不能作为它的先例或反例。
- **未占用（选择依据的信息源）**：本文的选择依据只有两类——**该变体到原样本的 ℓ∞ 距离**（CP）与**该变体自身的绝对误分类布尔值**（GS/BG）。**没有一种规则读取组内其他变体的任何信息**（无组均值、无组内排序归一化、无相对偏离）。若本课题的「欺骗信号」定义为组内相对量（中心化偏离、方向符号等），则与本文全部三种规则都不重合。
- **未占用（任务域）**：本文全部任务为 CIFAR/SVHN 对抗鲁棒性，**不涉及分布漂移、跨年度泛化、实体级聚合、类别不对称纠错或加密流量**。
- **可复用的接口与指标**：`r_i = {x_i^(1),…,x_i^(m)}` 的分组写法（第 8 页）可直接作为接口定义参照；`d_min`（变体间 ℓ2 最小距离）是可测的变体多样性代理指标（第 15 页图 6）。
- **可直接用作对照的两端**：CP（每组恰一个）与 GS（每组可变个数）是本文自己构造的最小对照（第 8 页原文明确点出这一点），可作为本课题选择规则实验的一对现成对照臂。
- **一条已登记的负结果**：GS 在每类样本少的数据集（CIFAR-100）上未能提升（第 11 页）。若本课题数据存在类别不均衡，这是必须一并检查的风险点。

一句话结论：Batch-in-Batch 与「每干净样本 K 个同源扰动变体」在生成侧逐字同构，并占用了三种硬选择规则（CP 恰一个 / GS 零个或多个 / BG 并入干净样本）；但三种规则的选择依据全部是变体自身的**绝对**量（ℓ∞ 距离或误分类布尔值），读取不到任何组内相对信息，因此「以组内相对/中心化信号驱动选择或加权」在该子空间仍未被本文占用。
