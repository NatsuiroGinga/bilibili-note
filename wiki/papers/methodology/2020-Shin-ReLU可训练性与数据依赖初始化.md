# ReLU 网络可训练性与数据依赖初始化

## 全文核验结论

- **核心结论（Abstract / §1 贡献，第 1 页）**：「若初始化后的 ReLU 网络不可训练，**无论选择哪种梯度优化方法，训练都不会成功**」——把成功性上界绑定到初始化，而非优化器。
- 死亡神经元两态：tentative（暂时）与 permanent（永久）死亡；可训练 = 永久死亡神经元数足够少（§3）。
- 过参数化既是必要也是充分条件（浅层情形）。
- **关键实测（§5.2，第 8–9 页）**：同一任务下训练后**平均死亡神经元数**：
  - `He 初始化（带偏置）`：`11`（f3）/ `12`（f4）；
  - `He 初始化（不带偏置）`：`0` / `0`；
  - `数据依赖初始化`：`0` / `0`。
  §4 的另一个算例为 `127`（He 带偏置）/ `3`（He 不带偏置）/ `17`（数据依赖）。
  ⇒ **对称权重 + 非零偏置初始化显著制造死亡神经元**；把偏置设为 0 即大幅减少。
- 数据依赖初始化（§4）**限定于过参数化设定**（宽度 ≥ 训练样本数），通过按数据定位每个神经元来同时缓解「神经元聚集」与「死 ReLU」，实测收敛最快、逼近误差最小。

## 对本课题的合法映射

- 为 2013 不收敛提供了**第二条更贴合本架构的机制**：PyTorch `nn.Linear` 默认用**非零偏置**（`U(−1/√fan_in, 1/√fan_in)`）——正是本文实测中死亡神经元最多的「He 带偏置」情形。这是**不改协议、只改初始化即可验证**的最小实验假设。
- 「可训练性是成功训练的必要条件」这句对**优化器路线**是强约束：若 2013 的病灶是初始化导致的不可训练，**换优化器（Q1）救不了**，必须先修初始化。

## 原创边界与不能直接声称

- 数据依赖初始化**要求宽度 ≥ 样本数**（本课题宽度 512 远小于年度样本量），**不满足其适用前提**，不能直接套用；可迁移的只是「把偏置初始化为 0 / 减小偏置」这一半。
- 实验为浅层/低维函数逼近，非 4561 维稀疏二值、非持续学习。
