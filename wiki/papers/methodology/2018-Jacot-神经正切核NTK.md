## 一句话

把网络参数空间的梯度下降翻译成函数空间的核梯度下降：核是网络输出对参数梯度的外积（NTK），在宽度趋于无穷时它退化为一个显式的、训练中保持不变的极限核，从而使「宽网络训练」可以用核方法（核回归、核主成分、正定性）来分析。

## 核心定义与公式

### 网络与参数化约定（§2，p.2–3）

全连接网络，层编号 0（输入）到 L（输出），各层宽度 `n_0, …, n_L`；非线性 `σ : R → R` 为 Lipschitz、二次可微、二阶导有界（第 2 页，脚注说明这些光滑性假设是为了简化证明，「看起来并非严格必需」）。参数空间维数 `P = Σ_{l=0}^{L−1} (n_l + 1)n_{l+1}`，参数由连接矩阵 `W^(l) ∈ R^{n_l × n_{l+1}}` 与偏置 `b^(l) ∈ R^{n_{l+1}}` 组成，**按 iid 高斯 `N(0,1)` 初始化**（p.2）。网络函数定义为（p.3）：

```text
α^(0)(x; θ) = x
ᾱ^(l+1)(x; θ) = (1/√n_l) W^(l) α^(l)(x; θ) + β b^(l)
α^(l)(x; θ) = σ(ᾱ^(l)(x; θ))
```

其中 `ᾱ` 称为预激活、`α` 称为激活，`σ` 逐元素作用，标量 `β > 0` 用于调节偏置在训练中的影响（p.3）。**Remark 1（p.3）**：该定义与经典定义略有差别——经典定义里没有 `1/√n_l` 因子与 β，而是用 LeCun 初始化（`W^(l)_{ij} ~ N(0, 1/n_l)`、`b^(l)_j ~ N(0,1)`）来补偿；两种参数化可表示的函数集相同，但**对连接与偏置的导数分别相差 `1/√n_l` 与 β 因子**。论文说明：`1/√n_l` 是让网络在隐藏层宽度 `n_1,…,n_{L−1} → ∞` 时有一致渐近行为的关键；其副作用是当 `n_l` 很大时连接权重在训练中的影响被大幅削弱，β 就是用来平衡偏置与连接权重的（p.3）。数值实验取 `β = 0.1`、学习率 `1.0`（论文自注该学习率比常用值大，其效果类似宽度 100 的经典网络配学习率 0.01，p.3）。

### 核梯度（§3，p.3–4）

多维系核 `K : R^{n_0} × R^{n_0} → R^{n_L × n_L}`，满足 `K(x,x') = K(x',x)^T`；它定义双线性形式 `⟨f,g⟩_K := E_{x,x'~p_in}[ f(x)^T K(x,x') g(x') ]`（p.3）。核 `K` 关于 `‖·‖_{p_in}` 正定，当且仅当 `‖f‖_{p_in} > 0 ⟹ ‖f‖_K > 0`（p.3）。核梯度定义为 `∇_K C|_{f_0}(x) = (1/N) Σ_{j=1}^N K(x, x_j) d|_{f_0}(x_j)`（p.4）。若 `f(t)` 满足

```text
∂_t f(t) = −∇_K C|_{f(t)}
```

则称为「关于 K 的核梯度下降」，且（p.4）

```text
∂_t C|_{f(t)} = −⟨ d|_{f(t)}, ∇_K C|_{f(t)} ⟩_{p_in} = −‖ d|_{f(t)} ‖²_K
```

论文由此给出收敛结论（p.4）：**若 K 关于 `‖·‖_{p_in}` 正定，则收敛到 C 的临界点是保证的**（代价严格递减，除非 `‖d|_{f(t)}‖_{p_in} = 0`）；若代价还凸且有下界，则 `f(t)` 当 `t → ∞` 时收敛到全局最小。**这是全文「正定性 ⇒ 收敛」这条链路的出处。**

### §3.1 线性随机函数模型的近似（p.4）

作为理解的起点，论文引入一个由 P 个随机函数 `f^(p)` 张成的**线性**参数化 `F_lin : R^P → F`，`f^lin_θ = (1/√P) Σ_p θ_p f^(p)`，其中 `f^(p)` 独立采样自协方差为 `K` 的分布（`E[f^(p)_k(x) f^(p)_{k'}(x')] = K_{kk'}(x,x')`）。论文证明：在该**线性**模型上做梯度下降，`f^lin_θ(t)` 的演化恰是核梯度下降，其切核为

```text
K̃ = Σ_{p=1}^P ∂_{θ_p}F_lin(θ) ⊗ ∂_{θ_p}F_lin(θ) = (1/P) Σ_{p=1}^P f^(p) ⊗ f^(p)
```

且当 `P → ∞` 时由大数定律 `K̃` 趋于固定核 `K`（p.4）。**注意这一节的模型是线性的**，它的作用是给出「切核 → 核梯度下降」的直觉；真正的网络是非线性的，见 §4。

### §4 NTK 的定义（**p.5**）

对用梯度下降训练 `C ∘ F^(L)` 的网络，训练中网络函数沿**负核梯度**演化（p.5）：

```text
∂_t f_θ(t) = −∇_{Θ^(L)} C|_{f_θ(t)}
```

其中核是**神经正切核（NTK）**：

```text
Θ^(L)(θ) = Σ_{p=1}^P ∂_{θ_p}F^(L)(θ) ⊗ ∂_{θ_p}F^(L)(θ)                            (§4, p.5)
```

论文紧接的关键限定（p.5 逐字）：与 `F_lin` 不同，ANN 的实现函数 `F^(L)` **不是线性的**，因此导数 `∂_{θ_p}F^(L)(θ)` 与 NTK 都依赖参数 θ——**NTK 在初始化时是随机的，并在训练中变化**，这使 `f_θ` 的收敛分析更微妙。随后两小节（§4.1、§4.2）的作用正是证明「在无限宽极限下，NTK 在初始化时确定化、并在训练中保持常数」。

（**转写提示**：原文第 2 页 §1.1 附近把 NTK 展开写作 `which we call the neural tangent network (NTK)`——即印作 network 而非 kernel。这是原文的用词不一致，本笔记按「neural tangent kernel（NTK）」引用。）

## 关键定理

### Proposition 1（初始化时的高斯过程极限，p.5；附录 A.1 重述于 p.11）

**陈述（逐字转写，p.5）**：

> Proposition 1. For a network of depth L at initialization, with a Lipschitz nonlinearity σ, and in the limit as n_1, …, n_{L−1} → ∞, the output functions f_{θ,k}, for k = 1, …, n_L, tend (in law) to iid centered Gaussian processes of covariance Σ^(L), where Σ^(L) is defined recursively by:
> Σ^(1)(x, x′) = (1/n_0) x^T x′ + β²
> Σ^(L+1)(x, x′) = E_{f∼N(0,Σ^(L))}[ σ(f(x)) σ(f(x′)) ] + β²,
> taking the expectation with respect to a centered Gaussian process f of covariance Σ^(L).

**Remark 2（p.5）**：严格说并不需要协方差为 `Σ^(L)` 的高斯测度的存在性——论文只关心 `f` 在 `x, x′` 处的取值（`(f(x), f(x′))` 的联合分布就是 2D 高斯向量），因此证明中「自由地使用高斯过程而不讨论其存在性」。

### Theorem 1（NTK 的极限核，**p.5**；附录 A.1 重述与证明于 p.12）

**陈述（逐字转写，p.5）**：

> Theorem 1. For a network of depth L at initialization, with a Lipschitz nonlinearity σ, and in the limit as the layers width n_1, …, n_{L−1} → ∞, the NTK Θ^(L) converges in probability to a deterministic limiting kernel:
> Θ^(L) → Θ^(L)_∞ ⊗ Id_{n_L}.
> The scalar kernel Θ^(L)_∞ : R^{n_0} × R^{n_0} → R is defined recursively by
> Θ^(1)_∞(x, x′) = Σ^(1)(x, x′)
> Θ^(L+1)_∞(x, x′) = Θ^(L)_∞(x, x′) Σ̇^(L+1)(x, x′) + Σ^(L+1)(x, x′),
> where
> Σ̇^(L+1)(x, x′) = E_{f∼N(0,Σ^(L))}[ σ̇(f(x)) σ̇(f(x′)) ],
> taking the expectation with respect to a centered Gaussian process f of covariance Σ^(L), and where σ̇ denotes the derivative of σ.

**Remark 3（p.5）**：由 Rademacher 定理，`σ̇` 除一个零 Lebesgue 测度集外处处有定义。论文强调（p.5）：极限核 `Θ^(L)_∞` **只依赖 `σ` 的选择、网络深度、以及初始化时参数的方差**（本文设定中该方差为 1）。

### Theorem 2（训练中 NTK 保持常数，**p.6**；附录 A.2 重述与证明于 p.13）

**设定（p.6）**：训练被推广为「按训练方向 `d_t ∈ F` 更新参数」：`∂_t θ_p(t) = ⟨∂_{θ_p}F^(L)(θ(t)), d_t⟩_{p_in}`。梯度下降的情形对应 `d_t = −d|_{f_θ(t)}`（见 §3）；方向也可以依赖另一个网络，例如 GAN。唯一的假设是积分 `∫_0^T ‖d_t‖_{p_in} dt` 在宽度趋于无穷时**随机有界**（论文指出最小二乘回归满足该条件，见 §5）。

**陈述（逐字转写，p.6）**：

> Theorem 2. Assume that σ is a Lipschitz, twice differentiable nonlinearity function, with bounded second derivative. For any T such that the integral ∫_0^T ‖d_t‖_{p_in} dt stays stochastically bounded, as n_1, …, n_{L−1} → ∞, we have, uniformly for t ∈ [0, T], Θ^(L)(t) → Θ^(L)_∞ ⊗ Id_{n_L}.
> As a consequence, in this limit, the dynamics of f_θ is described by the differential equation
> ∂_t f_θ(t) = Φ_{Θ^(L)_∞ ⊗ Id_{n_L}}( ⟨d_t, ·⟩_{p_in} ).

**Remark 4（p.6）**：定理的证明显示，隐藏层单个激活在训练中的变化随其宽度增大而缩小，但其**集体变化是显著的**，这正是下层参数能够学习的原因——在 `Θ^(L+1)_∞(x,x′) = Θ^(L)_∞(x,x′)·Σ̇^(L+1)(x,x′) + Σ^(L+1)(x,x′)` 中，**第二个求和项代表最后一层带来的学习，第一个求和项代表下层的贡献**（原件写作「the second summand Σ^(L+1) represents the learning due to the last layer, while the first summand represents the learning performed by the lower layers」，p.6）。

### Proposition 2（极限 NTK 的正定性，**p.6**；附录 A.4 重述与证明于 p.17–19）

**陈述（逐字转写，p.6）**：

> Proposition 2. For a non-polynomial Lipschitz nonlinearity σ, for any input dimension n_0, the restriction of the limiting NTK Θ^(L)_∞ to the unit sphere S^{n_0−1} = {x ∈ R^{n_0} : x^T x = 1} is positive-definite if L ≥ 2.

**条件**：非线性 `σ` **非多项式**且 Lipschitz；数据**支撑在单位球上**；深度 **`L ≥ 2`**。论文的证明路径（p.6 正文给出动机、p.18–19 给出完整证明）：`Θ^(L+1) = Σ̇^(L)Θ^(L) + Σ^(L+1)`，其中 `Σ̇^(L)Θ^(L)` 是两个半正定核之积故半正定，因此只要 `Σ^(L+1)` 正定即可；再由 `Σ^(L+1)(x,x′) = E[σ(f(x))σ(f(x′))] + β²` 的二次型表达式把正定性从 `Σ^(L)` 归纳到 `Σ^(L+1)`，最后只需证 `Σ^(2)` 在单位球上正定——用 Hermite 展开（引 Daniely et al. 的 Lemma 12(a)）与 Schöneberg 型定理（Theorem 3，p.18）完成。**Remark 5（p.19）**：用类似技术可以证明 Proposition 2 的逆命题——若 `σ` 是多项式，则对应 NTK `Θ^(2)` 对某些输入维数 `n_0` **不是**球面上的正定核。

附录 A（p.11）另有一处必须注意的**极限方式限定**：论文「按 `n_1 → ∞`、再 `n_2 → ∞`、… 的**依次极限**」研究 NTK，这一选择使证明大为简化，但论文自注「结果原则上可以加强到 `min(n_1,…,n_{L−1}) → ∞` 的更一般设定」。**Theorem 1 与 Theorem 2 的陈述文字写的是「as n_1, …, n_{L−1} → ∞」，而附录的证明是在依次极限下给出的**（p.11、p.12、p.13）。

## 无限宽极限下的核回归等价性（§5，p.6–7）

**代价与适用性（p.6）**：最小二乘回归代价 `C(f) = (1/2)‖f − f*‖²_{p_in} = (1/2) E_{x∼p_in}[‖f(x) − f*(x)‖²]`。论文指出 Theorem 1 与 Theorem 2 适用于该代价，因为训练方向的范数 `‖d(f)‖_{p_in} = ‖f* − f‖_{p_in}` 在训练中严格递减，从而给积分定了界。

**闭式解（p.6–7）**：对方程 `∂_t f_t = Φ_K(⟨f* − f, ·⟩_{p_in})`，解可写成 `f_t = f* + e^{−tΠ}(f_0 − f*)`，其中 `Π : f ↦ Φ_K(⟨f, ·⟩_{p_in})`、`e^{−tΠ} = Σ_{k=0}^∞ ((−t)^k/k!)Π^k`。若 `Π` 可被特征函数 `f^(i)` 与特征值 `λ_i` 对角化，则 `e^{−tΠ}` 有相同的特征函数、特征值为 `e^{−tλ_i}`（p.7）。

**有限数据集上的形式（p.7）**：对 N 个样本的数据集，

```text
Π(f)_k(x) = (1/N) Σ_{i=1}^N Σ_{k'=1}^{n_L} f_{k'}(x_i) K_{kk'}(x_i, x)
```

`Π` 至多有 `N·n_L` 个正特征函数，它们正是数据关于核 `K` 的**核主成分**，对应特征值即该成分捕获的方差（p.7）。把 `f* − f_0` 沿 `Π` 的特征空间分解为 `∆⁰_f + ∆¹_f + … + ∆^{Nn_L}_f`，轨迹为

```text
f_t = f* + ∆⁰_f + Σ_{i=1}^{Nn_L} e^{−tλ_i} ∆^i_f
```

（`∆⁰_f` 落在 `Π` 的零空间中、`∆^i_f ∝ f^(i)`）。**论文由此给出 early stopping 的动机（p.7）**：收敛在对应较大 `λ_i` 的特征空间上更快，因此早停把收敛聚焦在最相关的核主成分上，避免去拟合低特征值方向（这类方向通常更「噪」，例如 RBF 核下低特征值对应高频函数）。

**`t → ∞` 的极限（p.7）**：若核在数据上正定（`N n_L × N n_L` Gram 矩阵 `K̃` 可逆），则 `f_∞,k(x) = κ^T_{x,k} K̃^{−1} y* + ( f_0(x) − κ^T_{x,k} K̃^{−1} y_0 )`，其中 `κ_{x,k} = (K_{kk'}(x, x_i))_{i,k'}`、`y* = (f*_k(x_i))_{i,k}`、`y_0 = (f_{0,k}(x_i))_{i,k}`。论文给出两项的解释（p.7）：**第一项（均值）有重要的统计解释——它是给定函数上的高斯先验 `f_k ∼ N(0, Θ^(L)_∞)` 与条件 `f_k(x_i) = f*_k(x_i)` 下的最大后验（MAP）估计；等价地，它是正则化趋于零（`λ → 0`）时的核岭回归**；第二项是中心化高斯，其方差在数据集上的点处消失。

## 实验设置与读数（§6，p.7–9）

通用设定（p.7）：全连接网络，所有隐藏层宽度相同 `n := n_1 = … = n_{L−1}`，非线性取 ReLU `σ(x) = max(0,x)`；前两个实验 `n_0 = 2`、输入取在单位圆上（论文给出的动机是高维数据中心化后范数往往近似相同）；所有实验 `n_L = 1`；`β = 0.1`。

### §6.1 NTK 的收敛（p.8，图 1 在 p.8）

深度 `L = 4`、宽度 `n = 500` 与 `10000`；固定 `x_0 = (1,0)`、`x = (cos γ, sin γ)` 在单位圆上；每种宽度做 10 次独立初始化；在初始化（`t = 0`）与 200 步梯度下降后（学习率 1.0）分别作图；用最小二乘代价在 `N(0,1)` 随机输入上拟合 `f*(x) = x_1 x_2`。读数：更宽的网络 NTK 方差更小、更光滑；**两种宽度的 NTK 期望非常接近**；训练 200 步后 NTK 倾向于「膨胀（inflate）」，该效应在 `n = 10000` 时几乎不可见、在 `n = 500` 时明显。

### §6.2 核回归（p.8，图 2 在 p.8）

把 `t → ∞` 的理论高斯分布与有限宽网络在 `T = 1000` 时的函数分布对比：两种宽度 `n = 50, 1000`，各 10 次随机初始化，在单位圆的 4 个点上用最小二乘代价训练 1000 步、学习率 1.0；用 `n = 10000` 的网络近似核 `Θ^(4)_∞` 与 `Σ^(4)` 以计算 `t → ∞` 极限高斯分布的 10/50/90 百分位。读数：两种宽度的函数分布非常相似，均值与方差都接近极限分布；**即使宽度只有 `n = 50`，NTK 也能很好地指示 `f_θ(t)` 当 `t → ∞` 的分布**。

### §6.3 沿主成分的收敛（p.8–9，图 3 在 p.9）

MNIST（`n_0 = 784`）；用 `n = 10000` 的高宽网络（近似极限核）与幂迭代法，对 `N = 512` 张图的批次计算关于 NTK 的前 3 个主成分，特征值为 **`λ_1 = 0.0457`、`λ_2 = 0.00108`、`λ_3 = 0.00078`**；核 PCA 未中心化，因此第一主成分几乎等于常数函数，这解释了第一与第二特征值之间的巨大差距（p.8–9；该页脚注 3 另注：数值上若把 β 取 1.0 而非推荐的 0.1，第一与第二主成分的差距约大十倍，训练更难）。回归目标设为 `f* = f_θ(0) + 0.5 f^(2)`；把 `f_θ(t) − f*` 分解为与 `f^(2)` 成比例的 `g_t` 与正交的 `h_t`；无限宽极限下 `‖g_t‖_{p_in} = 0.5 e^{−λ_2 t}`、`h_t = 0`（沿直线收敛）。读数（宽度 100 / 1000 / 10000，每种宽度 2 次独立试验）：**网络越宽，偏离直线的程度越小**；沿第二主成分的轨迹随宽度增大收敛到理论极限。论文另报告一个意外的观察：**更小的网络看起来收敛更快**，其可能解释是 §6.1 观察到的 NTK 膨胀——把 NTK 乘 a 等价于把学习率乘 a；但论文随即提醒，由于大宽网络的 NTK 在训练中更稳定，原则上可以取更大的学习率，**因此在比较收敛速度时必须区分「步数」与「时间 t」，两种效应都要计入**（p.9）。

## 可迁移机制

1. **「参数空间优化 → 函数空间核梯度下降」的翻译模板**：NTK 的定义 `Θ^(L)(θ) = Σ_p ∂_{θ_p}F^(L)(θ) ⊗ ∂_{θ_p}F^(L)(θ)` 是「切核」的一般构造——任何把参数映射到函数、并用梯度下降优化的模型都可以写下它。可复用之处在于：一旦写出切核，收敛性问题就变成核的正定性问题（§3，p.4），可用核方法既有工具处理。
2. **极限核的递推结构 `Θ^(L+1)_∞ = Θ^(L)_∞·Σ̇^(L+1) + Σ^(L+1)`**（Theorem 1，p.5）把「深度」显式地编码进核，且 Remark 4（p.6）给出两项的**机制解释**：第二项 = 最后一层的学习，第一项 = 下层的学习。这是「深度如何贡献表达力」的一种可计算分解。
3. **用「是否正定」把收敛性从经验问题变成数学问题**：Proposition 2 的结论形式（「非多项式 + 球面数据 + `L ≥ 2` ⇒ 正定」，p.6）与 Remark 5 的逆命题（多项式 ⇒ 某些 `n_0` 下不正定，p.19）是一组可检验的充要型结果，可复用于判断某个新核是否保证收敛。
4. **early stopping 的核主成分解释**（p.7）：收敛沿特征值 `λ_i` 以 `e^{−tλ_i}` 进行，因此早停 = 只拟合大特征值方向。这条把「早停」翻译成「低通滤波/只取主成分」，是可迁移的分析视角。
5. **`t → ∞` 解的两项分解与 MAP 解释**（p.7）：`f_∞ = 核岭回归(MAP 均值) + 在数据点上方差为零的中心化高斯`。这条给「宽网络的极限预测器」一个明确的统计身份，是把深度网络与高斯过程/核岭回归对齐的关键接口。

## 不能直接声称内容

- 本文的定理全部是**极限陈述**：`n_1, …, n_{L−1} → ∞`（Theorem 1/2，p.5–6），且附录的证明是在**依次极限**（先 `n_1 → ∞`、再 `n_2 → ∞`、…）下给出的（p.11），论文自注尚未证明一般的 `min(… ) → ∞` 情形。**不能把 NTK 的常性与极限核当作有限宽网络的结论**；论文自己的数值实验正是用来度量「有限宽离极限有多远」（§6，p.8–9）。
- **`Θ^(L)` 在有限宽下是随机的、且随训练变化**（§4，p.5）。「NTK 不变」只在极限下成立。任何把 NTK 当作固定核来做有限宽分析的做法都需要单独论证。
- Proposition 2 的正定性**带三个条件**：非线性非多项式、数据支撑在单位球上、`L ≥ 2`（p.6）。不能把它说成「任意网络、任意数据的 NTK 都正定」。反方向（多项式非线性）由 Remark 5 给出，但它说的是「对某些输入维数 `n_0` 不正定」（p.19），**不是「一律不正定」**。
- 本文的理论针对**全连接网络**、`σ` 二次可微且二阶导有界、参数按 iid `N(0,1)` 初始化、以及论文的 `1/√n_l` 参数化（§2 与 Remark 1，p.2–3）。**ReLU 不满足「二阶导数有界」**（其分布意义下的二阶导几乎处处为零、在 0 处不可导）——论文的数值实验用的是 ReLU（§6，p.7），但定理的条件写的是「Lipschitz、twice differentiable、bounded second derivative」（Theorem 2，p.6）。**理论与实验之间在这一点上并不完全一致**，论文未在正文中处理该差异；引用时须注意。
- 本文**没有做到**「解释深度学习的泛化」。论文在 §1.1（p.2）把「NTK 对理解 ANN 如何泛化至关重要」列为定位，但正文给出的是**极限核回归的闭式解与正定性**，**没有给出泛化误差界**。不能把本文转述为「证明了宽网络泛化好」。
- §6 的数值实验规模很小：MNIST 只取 `N = 512` 张图、只算 3 个主成分、只做 2 次独立试验（§6.3，p.8–9）；前两节的合成数据只有单位圆上的 2D 输入（p.7–8）。不能把这些读数外推为「NTK 理论在大规模真实任务上已被验证」。
- §6.3 报告的「更小的网络收敛更快」是**论文自己标注为意外（surprising）的观察**，其解释（NTK 膨胀）是论文给出的**可能解释**（p.9 逐字为「This may be explained by…」）。不能当作已验证的结论。
- 论文的 `β = 0.1`、学习率 `1.0` 是**任务化设定**（Remark 1 与 §6，p.3、p.7），论文给出的说明是「类似宽度 100 的经典网络配学习率 0.01」的定性对照，**没有消融**（唯一定量说明是 p.9 脚注 3 关于 β 取 1.0 时主成分差距的数值观察）。
- 本文**没有对抗鲁棒性、分布漂移、或任何 OOD 设定下的分析**；`p_in` 全程是训练数据的经验分布（p.3）。不能把 NTK 的结论直接用于偏移或对抗场景。
- 禁止写「首次 / 首创」。论文在 §1（p.1–2）把「无限宽极限下网络等价于高斯过程」的来源逐条列出（Neal 1996；Daniely et al. 2016；Matthews et al. 2017；Lee et al. 2018 等），并说明本文是在同一极限下描述**训练动力学**。可表述为「在本笔记检索范围内，未检得以『网络输出对参数的梯度的外积』定义核并证明其在无限宽极限下确定化且在训练中保持常数的更早同构先例」。

## 与课题的关系

**以下为本课题的关联判断，不是原文主张。** 本课题的双侧组相对对抗训练需要「宽网络极限下的核回归/泛化」这一推导支撑，本文给出的是该方向的核心出处与它的适用边界。逐条对照：

- **已占用（宽网络极限 = 核方法这一整条链路）**：`NTK → 极限确定核 → 训练等价于核梯度下降 → 正定性给收敛 → 最小二乘的闭式解与核主成分展开`（p.5–7）是完整闭合的一条论证链，且每一环都有明确的定理编号与页码。本课题若要用「宽网络极限」为某个机制背书，必须在这条链之外找到自己的位置，而不能把链上的任一环当作本课题贡献。
- **已占用（正则化与早停的核解释）**：`t → ∞` 解的 MAP/核岭回归解释与「早停 = 只拟合大特征值主成分」（p.7）已被占用。本课题若涉及正则化或训练时长的论证，需要对标这两条。
- **已占用（收敛性的判据形式）**：把收敛保证归约为核的正定性、并用「非线性是否多项式 + 数据是否在球面上 + 深度」三个条件给出正定性的充分条件（Proposition 2，p.6；Remark 5 的逆命题，p.19），这一「条件 → 正定 → 收敛」的判据形式已被占用。
- **未占用（组结构与组内相对量）**：本文的核与核梯度下降在**整个输入分布 `p_in`（实际是训练集的经验分布）**上定义（§2–§3，p.2–4），**没有「组」这一层**；`Θ^(L)_∞` 的递推只依赖深度、非线性与初始化方差（Theorem 1，p.5），不含任何组内/组间的结构项。以**组为单位**定义核、或把组内相对信号编进核，属于本文未占用的方向。
- **未占用（对抗扰动与偏移）**：本文的 `p_in` 固定为训练分布，NTK 的输入空间只有 `x`，**没有扰动变量 δ、没有鞍点、没有偏移轴**（全文检索无 `adversar`、`perturbation`、`shift` 的机制设定）。「把对抗/偏移写进核的构造」在本文未被占用。
- **未占用（任务域）**：本文实验为 2D 合成数据与 MNIST 的**回归/主成分**实验（p.7–9），不是分类性能基准，也没有安全检查任务。
- **可复用的边界声明**：论文明确把「依次极限」与「一般极限」、「无限宽」与「有限宽」分开陈述（p.11、p.5–6），并在 §6 用有限宽数值实验度量差距（p.8–9）。**这套「把极限结论与有限规模读数的距离显式量出来」的做法**，是本课题在引用任何渐近结论时应当照搬的纪律。
- **可复用的成本账**：§6.2 显示 `n = 50` 的宽度已能较好接近极限分布（p.8）；§6.3 显示宽度从 100 到 10000 期间沿主成分的轨迹逐步逼近理论线（p.9）。这两条给出「极限理论在多宽的网络上已可用」的量级参照（但注意其任务极简，不可外推）。

一句话：本文占用了「宽网络极限下训练 = 核梯度下降、收敛取决于极限核的正定性、回归有核主成分闭式解」这一整套推导；它的核定义在整个输入分布上、且不含扰动与组结构，因此「以组为单位、把对抗或偏移写进核构造」的方向在该子空间仍未被本文占用。

## 疑问待验证

- **Theorem 1 / Theorem 2 正文陈述的极限方式与附录证明的方式不一致。** 正文（p.5、p.6）写 `as n_1, …, n_{L−1} → ∞`，而附录 A 开头（p.11）明确「我们按 `n_1 → ∞`、再 `n_2 → ∞`、… 的**依次极限**研究，这使证明大为简化，但结果原则上可加强到 `min(n_1,…,n_{L−1}) → ∞`」。引用时若涉及「是否已证一般极限」，**必须以附录的限定为准**。
- **定理条件要求在二阶导有界，而数值实验用的是 ReLU**（Theorem 2 条件见 p.6；§6 取 ReLU 见 p.7）。ReLU 不满足「二次可微且二阶导有界」。论文未在正文讨论这一理论与实验的错位，**本笔记未找到论文对该差异的说明**。
- Proposition 2 要求「非多项式 Lipschitz 非线性」。ReLU 是非多项式 Lipschitz，但**不满足 Proposition 1/Theorem 1 推导中对 σ 的可微性假设**（论文对 Proposition 1 只要求 Lipschitz，对 Theorem 1 也只写 Lipschitz；但对 Theorem 2 要求两次可微且二阶导有界，对附录 A.3 的 Lemma 1 的证明用到 `|σ̇| ≤ c`）。**不同定理对 σ 的正则性要求并不一致**，本笔记逐条转写但未做统一；引用具体定理时须逐条核对其自身条件。
- 论文 p.9 脚注 3 给出「把 β 从 0.1 改成 1.0，第一与第二主成分的差距约大十倍」这一数值观察，但**未给出来源**（是本文实验还是引用）；本笔记按原文转写并标为待核。
- 「NTK 在训练中膨胀」这一现象（§6.1，p.8）在正文只有图 1 的定性描述，**没有给出膨胀倍率的数值**；§6.3 用它解释「小网络收敛更快」属于**推测性解释**（原文用 may be explained）。
- 论文未报告 §6 实验的**计算成本**（训练时间、精确宽度）或随机种子；复现细节不完整。
- 论文未讨论 `n_L > 1`（多输出）的情形在数值上是否也符合「`n_L` 个标量输出网络独立训练」的断言（该断言在 §6 设定处以括号形式给出，p.7），**无配套实验**。
