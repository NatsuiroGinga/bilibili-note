# 面向群体移位的分布鲁棒神经网络

## 全文核验结论

本文是候选C训练期 M1 的直接理论来源。群体必须预先定义，目标是优化源群体混合不确定集中的最坏风险。作者同时强调朴素 GroupDRO 在过参数网络上不会自动获得良好最坏群体泛化，必须配合更强权重衰减或早停。证据位于 PDF 第1页摘要、第3页式(1)至(2)、第8至10页算法与实验讨论。

## 公式族

给定源时间环境 `e=1,…,E`，环境风险为 `R_e(θ)=E_{P_e}[ℓ_θ]`，核心目标为：

`min_θ max_{q∈Δ_E} Σ_e q_e R_e(θ) = min_θ max_e R_e(θ)`。

群体权重可用指数梯度更新：`q_e ← q_e exp(η_q R_e)` 后归一化。

## 组调整（式 5）——2026-09-04 补读，原笔记未覆盖

`【全文】§3.3`（正文第 5 页）：即使加了强正则，**各组的泛化间隙仍差异很大**——
Waterbirds 在强 `ℓ2` 下，最小组的训练-测试准确率差 `15.4%`，最大组只有 `1.0%`。
故直接最小化最坏组测试损失的估计上界：

```
θ̂_adj := argmin_θ  max_g { E_{P̂_g}[ℓ(θ;(x,y))] + C / √n_g }        …… 式 (5)
```

`n_g` 为组 `g` 的**样本数**，`C` 为模型容量常数（作超参）。
`1/√n_g` 的依据是「小组比大组更易过拟合」，取自基于模型复杂度的泛化界的一般规模依赖。

**原文明确的适用边界**：该 `1/√n` 代理**只在 Group DRO 设定下有效**——
若最小化平均训练损失（ERM），该项退化为常数、不影响优化。

**实测（表 2）**：Waterbirds（`λ=1.0`）最坏组测试准确率 `84.6% → 90.5%`（`+5.9`），
但平均准确率从 `96.6%` 降到 `93.7%`；CelebA（`λ=0.1`）最坏组 `86.7% → 87.8%`（`+1.1`）。
图 3 显示 `C` 过大会矫枉过正（`C=4` 时小组变好、大组变差）。

**算法 1 的精确形式**（正文第 6 页，原笔记只给了 `q` 的更新，此处补全）：

```
for t = 1..T:
    g ~ Uniform(1..m)                                  # 随机取一个组
    x, y ~ P_g
    q'_g ← q_g · exp(η_q · ℓ(θ; (x,y)));  q ← q'/Σq'   # 指数梯度上升后归一化
    θ ← θ − η_θ · q_g · ∇ℓ(θ; (x,y))                   # 用 q 加权更新 θ
```

原文自陈相对 Oren 等 (2019)「每步挑最坏组」的改进是 **`q` 用梯度更新**，
「对稳定性与收敛保证很重要」；运行时间与 SGD 相差不到 `5%`。
**命题 2**：损失非负、凸、`B_∇`-Lipschitz 且有界时，平均迭代点误差以 `O(1/√T)` 收敛。

**本课题可能的任务化改造（`【待验证】`，非原文内容）**：
把式 (5) 的 `n_g`（样本数）换为 `n_g⁺`（组内**正实体数**）。
依据是本课题实测评价方差由正例数决定——源年验证 `20` 个正实体时自助 CI 宽 `0.386`，
按 `1/√n⁺` 外推全年 `239` 个正实体为 `0.112`。
**函数形式沿用原文同一泛化界论证，只更换代入的量。**
**风险**：全年仅 `239` 个正实体，组数一多则每组 `n_g⁺ → 0`、该项发散，临界组数须先算。

## LSPR 可观测量

环境样本数、阳性率、环境风险、最大/平均风险比、群体权重熵、最高损失样本的攻击占比、时间前向源验证平均精确率和 LSPR24 冻结平均精确率。

## 最小证伪实验

保持 RWKV、批大小、训练步数与数据完全相同，比较经验风险与 GroupDRO；另加“打乱时间环境标签”对照。若真实时间群体不优于打乱群体，或只改善源最坏风险却降低跨年平均精确率，则否决该环境映射。

## 不能直接声称

本文没有给出未知目标年度的性能保证；群体最坏风险也不等同于条件风险价值。少数攻击、标签噪声和罕见协议可能主导权重，必须做样本构成诊断。
