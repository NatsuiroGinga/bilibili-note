# FOIL：用不变学习实现分布外时间序列预测

## 一句话

FOIL 是候选 C 的强机制近邻：它已经公开了“从时间序列训练集推断时间环境，再跨环境学习不变表示”的完整方法，因此候选 C 不能把这一抽象组合写成首创；候选 C 的可写边界只能落在网络检测任务、稳定／私有 RWKV 状态分解、严格源域冻结和最坏源环境告警校准的特定联合上。

## 方法与页级证据

- PDF 第 2 页式（1）把不变学习目标写为最小化最差环境的经验风险，并把季节、温度、政策等列为时间环境。这是“最坏环境训练风险”的先前工作，不等同于候选 C 的逐环境告警分位阈值。
- 第 3 页指出时间序列通常没有显式环境标签，且静态数据的环境推断方法忽略时间结构；作者同时讨论未观测核心变量会破坏传统充分性／不变性假设。
- 第 4 页图 2 与第 4.1 节给出三个组件：标签分解、时间序列环境推断模块和时间序列不变学习模块。训练时后两者交替更新，测试时只使用不变学习模块，不做目标测试时适应。
- 第 4 页式（2）—（4）以加性／乘性影响和单一预测窗内影响一致为附加假设，再用实例残差归一化构造代理损失。这些假设不自动适用于网络入侵标签或告警分数。
- 第 5 页式（5）—（8）在表示空间用多头回归器执行类似 EM 的环境重分配，并用时间邻域多数投票保持时间邻接；这直接覆盖候选 C“由源时间邻接形成环境”的通用思路。
- 第 5—6 页式（9）—（10）通过环境特定损失及其跨环境方差学习充分且不变的表示。实验缺少合适环境标签时，训练集先被切成 `k=2…10` 个等长时间段作为预定义环境。
- 第 7 页第 5.4 节分别移除代理损失、整个环境推断模块和时间邻接标签传播；图 3(a) 显示三个构件均被单独消融。该消融只证明 FOIL 在其时间序列预测设置中的内部作用，不能外推候选 C 的检测效果。
- 第 9 页讨论承认不变学习并非唯一方案，动态时间模式、额外信息和代表性不足子群的评估仍需研究。

## 与候选 C 的重叠矩阵

| 候选 C 构件 | FOIL 是否覆盖 | 判断 |
|---|---|---|
| 从源时间序列形成环境 | 是 | **强重叠**；FOIL 有等长时间段初始化、表示空间重分配和时间邻接传播 |
| 跨环境学习稳定表示 | 是 | **强重叠**；FOIL 明确优化跨环境不变性与损失方差 |
| 稳定／私有双状态分解 | 否 | FOIL 只有共享表示与环境特定回归器，没有候选 C 的 RWKV 状态拆分 |
| 目标域零适应、源域冻结 | 部分 | FOIL 测试时只用训练所得模块，但研究任务是预测而非网络告警；候选 C 必须把“零目标更新”写成实验合同，不写成新算法 |
| 最坏源环境告警分位阈值 | 否 | FOIL 的最差环境训练风险不是逐环境阈值校准，也没有误报率或告警覆盖保证 |
| 网络入侵检测与跨年度协议 | 否 | 数据、标签、指标和评价对象均不同 |

## 证据支持的构思四栏

| 可借鉴的机制／公式 | 不能再声称为本课题原创的部分 | 结合 LSPR 跨年度任务与 RWKV 后可形成的实质改造 | 最小可证伪消融与匹配强基线 |
|---|---|---|---|
| 表示空间环境重分配式（5）—（8）、时间邻接传播、跨环境损失方差式（9）—（10） | 从无环境标签的时间序列推断时间环境，并据此学习跨环境不变表示 | 在 LSPR23 内推断环境后，把 RWKV 状态拆成稳定状态与环境私有残差：仅稳定状态驱动攻击判别，私有状态只解释环境特定偏差；告警阈值取各源环境分位数的最保守值，整个 LSPR24 保持冻结。区分点是状态职责和告警合同，不是再次提出环境推断 | 同骨干比较普通经验风险、FOIL 式共享不变表示、稳定／私有双状态但无环境约束、完整双状态＋源环境阈值；强基线含 FOIL 适配版、组分布鲁棒训练和静态 RWKV。若稳定状态消融或环境阈值均无独立信号，否决该重构 |

## 允许主张

- 候选 C 将既有的时间环境推断／不变学习思想迁移到严格源域冻结的跨年度网络入侵检测，并提出稳定／私有 RWKV 状态与告警校准的特定组合。
- FOIL 说明时间环境不应只靠无结构聚类；候选 C 需要显式消融时间邻接、环境数、稳定／私有状态和最坏环境校准。

## 禁止主张

- 不得宣称首次用时间环境或跨环境不变学习应对时间序列分布外泛化。
- 不得把 FOIL 的最差环境训练风险等同于候选 C 的最坏源环境告警分位阈值。
- 不得从 FOIL 的预测实验推断候选 C 会提高 LSPR23→LSPR24 的检测指标。
- 不得在未满足论文附加假设时移植其理论措辞或保证。

## 论文结论、项目推论与待验证项

- **论文结论**：FOIL 在四个预测数据集、三个预测骨干上评估，并完成代理损失、环境推断和时间邻接传播的消融。
- **项目推论**：候选 C 与 FOIL 在“时间环境＋不变学习”层面强重叠，但在状态结构、告警校准和网络安全任务上仍有可区分边界。
- **待验证**：这种区分是否能带来跨年度检测收益，只能由共同预算基线、机制消融和多种子实验裁决。
