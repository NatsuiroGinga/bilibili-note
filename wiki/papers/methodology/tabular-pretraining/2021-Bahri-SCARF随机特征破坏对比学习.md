# SCARF：随机特征破坏的自监督对比学习

> Bahri, Jiang, Tay, Metzler（Google Research），ICLR 2022，arXiv:2106.15147 · 24 页

**核验范围声明**：本笔记基于 `mineru-open-api extract`（精度模式）对**第 1–10 页**的转写
（`2021-Bahri-SCARF-全文提取-mineru_p1-10.md`），定位到**章节号与算法号**。
原件 `12.7 MB` 超出 `flash-extract` 的 `10 MB` 上限，故改用精度模式。
**第 11–24 页（含完整消融表与附录）本次未核验**，涉及那部分的数字不得引用。

## 一、论文原结论

### 1.1 破坏算子（算法 1）

```
q = ⌊c · M⌋                                # M 为特征数，c 为破坏率
对每个样本 i：从 {1,…,M} 均匀采样大小为 q 的子集 I_i
x̃_j^(i) = x_j^(i)          若 j ∉ I_i
x̃_j^(i) = v,  v ~ X̂_j     若 j ∈ I_i
```

`X̂_j` 是第 `j` 个特征的**经验边缘分布**。§3 给出精确定义：
**「该特征在训练集上所取值域的均匀分布」**——即在该列的观测值上有放回重采样。

三条实现细节：

- **数值列与类别列同一处理**，不需要为数值列另定噪声尺度或分布假设。
- **边缘采样在独热编码之前**进行（消融中其他破坏法则作用在独热表示上）。
- 各字段的破坏**互不相关**（论文 §2 对比 Yao 等 2020 的相关掩码时明确这一点）。

### 1.2 训练管线（§3）

原视图 `x` 与破坏视图 `x̃` 分别过编码器 `f`，再过预训练头 `g`，得 `z` 与 `z̃`。
**预训练头对输出作 `L2` 归一化**，使表示落在单位超球面上——论文称这一点「在实践中被发现是关键的」。
损失为 InfoNCE：拉近 `z^(i)` 与 `z̃^(i)`，推远 `z^(i)` 与 `z̃^(j)`（`i ≠ j`）。

**微调阶段微调全部权重，包括编码器，且只用任务监督**。
§2 明确这是与 VIME 的关键差异之一（VIME 只微调任务头，并保留自编码重构损失）。

### 1.3 预训练的早停判据（§3）

用无标注验证数据**预先构造一组静态的 `(x, x̃)` 对**（循环若干轮生成），
预训练期间在该静态集上跟踪 InfoNCE 损失并据以早停。

### 1.4 超参（§4「Model architecture and training」）

| 项 | 值 |
| --- | --- |
| 破坏率 `c` | **`0.6`** |
| 温度 `τ` | **`1`** |
| 批量（预训练与微调） | `128` |
| 优化器 | Adam，学习率 `0.001` |
| 最大预训练轮 | `1000`；最大微调轮 `200` |
| 早停耐心 | `3`（预训练按验证损失，微调按分类错误率） |
| 编码器 `f` | 4 层 ReLU，隐藏维 `256` |
| 预训练头 `g`、分类头 `h` | 各 2 层 |
| 静态验证集构造 | `10` 轮 |

### 1.5 实验规模与主结论（摘要、§4）

- **69 个 OpenML-CC18 真实分类数据集**（原 72 个，剔除 MNIST、Fashion-MNIST、CIFAR10）。
- 每数据集 `70%/10%/20%` 训练／验证／测试划分，**每组重复 `30` 次**，每次重新划分。
- 总计约 **`100` 万 CPU 核时**。
- 摘要主结论：SCARF 预训练「不仅**在完全监督设定下**提升分类精度，
  在存在标签噪声时与只有一部分样本带标签的半监督设定下同样提升」；
  并「优于自编码器等替代方案」。
- 论文自陈对**批量、破坏率、softmax 温度**均稳定，且对特征缩放不敏感。

### 1.6 一个与本课题直接相关的消融基线：判别式 SCARF（§4）

> 「预训练目标是区分原始输入特征与用我们提出的技术破坏过的对应特征；
> 为此在预训练头上加一个最终线性投影，并把 InfoNCE 换成**二元逻辑损失**。
> 早停用分类错误率而非逻辑损失，因为我们发现前者略好。」

**这就是 TabTransformer 的替换标记检测（RTD）在数值列上成立的实现**——
TabTransformer 的 Transformer 只处理类别列，其 RTD 因而只定义在类别列上；
SCARF 的破坏算子对数值列同样有定义，故判别式变体给出了数值列 RTD 的替换分布。

## 二、可迁移机制（形式明确，可脱离本文实现）

1. **按列经验边缘分布的破坏算子**——上式，`c = 0.6`、`τ = 1`。
   不需要噪声尺度、不需要分布假设、数值与类别同一处理。
2. **预训练头的 `L2` 归一化**——论文称其为实践中的关键点。
3. **静态验证对上的 InfoNCE 早停**——预训练阶段的停机判据，形式与骨干无关。
4. **判别式变体**——把 InfoNCE 换成二元逻辑损失，即数值列可用的 RTD。
5. **微调全部权重（含编码器）、只用任务监督**——与从头训练的对照保持同一微调配方。

## 三、不可直接声称的内容

- **不得声称 SCARF 在千万行规模上有效**。论文用的是 OpenML-CC18，
  其中最大数据集远小于本课题的 `11,991,315` 条训练流；论文未做规模消融（至少 p1–10 未见）。
- **不得声称 SCARF 在极端类别不平衡任务上有效**。论文指标是分类精度（accuracy），
  不含 AP、pAUC 或稀有类指标；本课题源年验证集只有 `20` 个正实体。
- **不得引用 §4 的超参作为本课题的取值**。这些值出自 `256` 维 4 层 ReLU 编码器，
  不是 FT-Transformer；只有**形式**可迁移，**数值须在本数据上重新确定并登记**。
- **不得引用第 11–24 页的任何数字**——本次未核验。
- 论文的对比对象是自编码器与无预训练，**不含 GBDT 强基线**（Rubachev 2022 才做了这一比较）。

## 四、与本课题的关系（推论，未验证）

本课题第三章骨干是从头训练的 FT-Transformer（83 字段 = 81 数值 + 2 词表，
3 层、`d_token=192`、8 头、参数 `924,283`），训练有效流 `11,991,315` 条**全部带标签**，
检测在实体（源 IP）粒度。

1. **破坏算子与本课题字段口径直接相容**（推论，形式层面可机械核验）：
   `81` 个数值列与 `2` 个词表列在该算子下同一处理，不需要为数值列另设噪声模型。
   这正是 TabTransformer 的 RTD 在本课题留下的空缺。
2. **本文是「全标注下预训练有收益」的第三条独立证据**（另两条为 Rubachev 2022 与 XTab 附录 F），
   与 SAINT §5、TabTransformer §3 的反向自陈相冲突。
   该冲突的裁决见 [[2022-Rubachev-表格预训练目标再审视]]：
   反向自陈出自被 Rubachev 批评的半监督协议。
3. **预训练是独立阶段，不改变第三章两个机制的挂载点**（推论）：
   微调阶段的逐流分数、ETA 的顶-`k` 聚合、BER 的多预算 CVaR-pAUC 逐位不变；
   预训练阶段不含 BER 的全体实体同图反传，故不新增显存峰值，新增的是墙钟成本。

## 五、仍需实验验证的假设

- 在 `1199` 万行、极端不平衡、FT-Transformer 骨干的交叉设定下，
  SCARF 式预训练是否仍有正增益——**三篇预训练文献均未覆盖该交叉设定**。
- `c = 0.6` 在 `83` 个流级统计字段上是否仍是合适取值——须在本数据上重新登记依据。
- 判别式变体与 InfoNCE 变体在本课题的相对优劣——
  Rubachev 2022 的结论是自预测优于对比，SCARF 自身的结论是对比优于自编码重构，
  **两者的对照对象不同，不构成直接冲突，但也不能相互替代**。

## 六、相关工作中被点名的两条区别（§2）

- **对 VIME**：VIME 用同样的破坏技术，但以「掩码估计头 + 特征估计头」恢复二值掩码与原输入
  （去噪自编码路线）；SCARF 用对比损失，并微调全部权重。
- **对 Yao 等 2020（推荐系统）**：后者以**相关**方式掩码随机特征并对类别特征用 dropout；
  SCARF 按各字段**经验边缘分布、互不相关**地随机化。
