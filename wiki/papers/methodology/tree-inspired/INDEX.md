# 可微树启发表格神经模型索引

- **[[2024-Marton-GRANDE梯度树集成|GRANDE]]**：硬轴对齐树、直通梯度和样本依赖树权重，归纳偏置最接近 XGBoost，但缺少大规模证据。
- **[[2020-Popov-NODE可微遗忘树集成|NODE]]**：可微遗忘树与 entmax，已有 1050 万训练样本证据，但官方实现显存低效且跨数据集稳健性不足。
- **[[2024-Gorishniy-TabR检索增强表格网络|TabR]]**：以源训练标签近邻形成局部修正，数百万样本有效但当前预算下无法直接扩至 LSPR23。
- **[[2019-Ke-DeepGBM树蒸馏网络|DeepGBM]]**：大规模 GBDT 蒸馏神经网络，因官方代码许可证不明排除。
- **[[2020-Xu-LMA轻量多段激活|LMA]]**：误下载后保留的多段激活论文，与本次候选无关。
