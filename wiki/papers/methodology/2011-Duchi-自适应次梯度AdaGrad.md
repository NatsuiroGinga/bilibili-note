# 自适应次梯度方法（AdaGrad）

## 全文核验结论

- 更新：`w_t = w_{t−1} − (η/√(s_t+ε))·g_t`，`s_t = s_{t−1} + g_t²`；对角情形可线性时间完成，且**梯度稀疏时更新代价正比于梯度支撑集大小**（§1、§3，第 1、3 页）。
- **稀疏特征下非自适应方法的劣势（§1.2 例，第 2–3 页）**：设每轮特征 i 以概率 `p_i = min{1, c·i^{−α}}` 出现（`z_t ∈ {−1,0,1}^d`），则 AdaGrad 后悔为 `O(max{log d, d^{1−α/2}}·√T)`；而标准在线梯度下降（OGD）为 `O(√(dT))`——**稀疏重尾特征下 AdaGrad 的界在维数 d 上指数更小**。
- **「0/1 特征」明文情形（第 5 页）**：`logistic regression with 0/1-valued features` 时梯度同样稀疏，故 `∑‖g_{1:T,i}‖₂ << √T`；且「用同一学习率对待出现过数百次的特征与只出现过一两次的特征是很差的」——对稀有特征应给更高学习率。
- 实验（§6）：RCV1 文本 0/1 bigram 特征（约 2,000,000 维，**多数样本非零特征 < 5000**），AdaGrad 家族显著优于非自适应对照，并给出高度稀疏的解。

## 对本课题的合法映射

- 为「**稀疏特征下 SGD 收敛慢**」提供**公式级（后悔界）与实验级**证据：这正是「同一学习率对高频/低频特征一刀切」的失效。LAMDA 4561 维稀疏二值特征中，各枚举/权限位出现频率极不均匀，属该文的「稀疏重尾」情形。
- 直接支持 **AdaGrad/Adam 类逐坐标自适应优化器**作为 2013 首年学不动的候选解法。

## 原创边界与不能直接声称

- 理论与实验均为**线性/凸**模型（logistic regression、hinge）；**未验证**逐坐标自适应在小 MLP（非线性、ReLU）上的同等收益。
- 不涉及初始化/死 ReLU（不解释 `ln 2` 停滞本身，只解释稀疏特征下更新过慢）。
