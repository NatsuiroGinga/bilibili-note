# 归纳保形预测子的条件有效性

> Vovk, 2012, ACML / arXiv:1209.2673 · 23 页

## 一句话

把「无条件有效」的归纳保形预测推广为「条件有效」，给出两条互相独立的路径：按分类法分层的**类别条件**控制，和 PAC 式的**训练条件** `(ε, δ)` 控制。

## 全文核验结论

本笔记的公式、命题与页码均取自本地原件 `2012-Vovk-Conditional-Validity-Inductive-Conformal.pdf` 的物理页。

### 条件归纳保形预测（机制正源，物理第 7 页）

定义**归纳 m-分类法** `K : Z^m × Z → K`，把每个样例映到一个类别。条件 ICP 的 p 值改为在**同类别内**计算：

```
p_y := (|{i = m+1..l : κ_i = κ_y 且 α_i ≤ α_y}| + 1)
       / (|{i = m+1..l : κ_i = κ_y}| + 1)
```

即物理第 7 页式 (10)。类别由 `κ_i := K((z_1..z_m), z_i)` 给出。取 `K(·,(x,y)) := y` 即**标签条件 ICP**。

### Proposition 3（物理第 8 页）

在 `Z_{m+1},…,Z_{l+1}` 交换的前提下，给定 `Z_{l+1}` 的类别，错误概率不超过 `ε`，对任意 `ε` 与任意条件 ICP 成立。

这条命题是「按预设有限划分做组条件误差控制」的标准做法与保证形式。**注意它不含 `δ`**：给出的是类别条件下的边际误差界，不是有限样本置信证书。

### Proposition 2a：训练条件 (ε, δ) 有效性（物理第 5 页）

集合预测子 `Γ` 若满足

```
ε_E ≥ ε + sqrt( (−ln δ) / (2n) )        (物理第 5 页式 (5))
```

（`n := l − m` 为校准集大小），则 `Γ` 是 `(ε_E, δ)`-有效的，且该结论对**任意固定的真训练集**成立。

原文给出的配方：校准集规模 `n` 须显著超过 `N := (−ln δ)/(2ε²)`。修正项是 **Hoeffding 型**。

### Proposition 4：对象条件有效性的负面结果（物理第 8–9 页）

若集合预测子对**几乎所有非原子点 `x`** 都满足 `1−ε` 对象条件有效，则回归情形下预测区间的 Lebesgue 测度以概率 ≥ `1−ε` 为无穷（式 (12)）；分类情形下每个标签都以概率 ≥ `1−ε` 被纳入（式 (13)）。原文自述这是 Lei–Wasserman 2012 引理 1 的一个版本。

## 我的理解

三条命题划出一个清楚的可行边界：**按有限划分分层可行（Prop 3），按具体取值逐点条件不可行（Prop 4）**。二者的分界是条件事件的丰富程度，不是「条件」这个动作本身。

`δ` 与「组」在本文中出现在**两条不同的命题**里，从未合并：Prop 3 有组无 `δ`，Prop 2a 有 `δ` 无组。

## 与本课题的关系

- **机制来源**：第四章「长度分层证书」的分层动作，其标准形式就是 Prop 3 的条件 ICP，分类法取实体流数长度桶。
- **差量所在**：本文用**秩式 p 值**控制覆盖／误差；本课题用 **NP 次序统计量／单侧 Clopper–Pearson 精确二项上界**控制类型一错误，并为每桶签发带 `δ'` 的证书。CP 上界比本文 Prop 2a 的 Hoeffding 修正紧。
- **方向不对称的动机**：物理第 7 页 §4 引言明确提出「在不同区域可能想要不同的显著性水平」，并举垃圾邮件例（把正常邮件判为垃圾的代价远大于反向）。**这是动机陈述，本文未给出跨组×方向的 `δ` 分配定理。**
- **样本饥饿代价**：式 (5) 的 `sqrt(−ln δ / (2n))` 随组内样本量下降而增大，与本课题实测的「证书税」方向一致（`n=3949` → `0.83pt`；`n=486` → `2.35pt`）。

## 论文可以支持

- **组条件控制的标准做法**：按预设分类法在类别内计算 p 值（物理第 7 页式 (10)），得到类别条件误差 ≤ `ε`（Prop 3，物理第 8 页）。
- **分层机制并非新创**：第四章的分层动作有成熟来源，本课题不得声称分层本身是创新。
- **有限样本代价的方向**：Prop 2a（物理第 5 页）的修正项 `sqrt(−ln δ / (2n))` 随组样本量下降而增大，与本课题实测「证书税」方向一致。
- **方向不对称的动机**：物理第 7 页 §4 引言明确提出不同区域可要不同显著性水平（垃圾邮件例）。**仅是动机陈述，不是分配定理。**

## 论文不能支持

- 不能说本文提供了「实体级」或「路径最大统计量」的条件证书——本文的单元是样例。
- 不能说本文给出了 `δ` 在组×方向上的分裂方案——它没有。
- 不能把 Prop 3 的类别条件误差界当作带置信度的有限样本证书。
- 不能用 Prop 4 否决本课题的有限划分分层——Prop 4 针对的是对象条件（逐点条件），不是有限划分。

## 实验结果与负证据

- **负证据（Prop 4，物理第 8–9 页）**：若集合预测子对几乎所有非原子点满足 `1−ε` 对象条件有效，则回归情形预测区间测度以概率 ≥ `1−ε` 为无穷（式 (12)）；分类情形每个标签都以概率 ≥ `1−ε` 被纳入（式 (13)）。原文自述是 Lei–Wasserman 2012 引理 1 的一个版本。
- **该负证据的适用边界**：只针对对象条件，不针对预先固定的有限划分。Barber et al. 2021 物理第 11 页式 (7) 明确把有限划分列为可达情形。
- **§6 实验**：用垃圾邮件数据比较标签条件 ICP 与普通 ICP。**本笔记未逐项核验该节数值**，不引用其具体数字。

## 疑问 / 待验证

- Prop 2a 的 Hoeffding 修正若逐组施加，与本课题逐组 CP 上界的保守度差多少？可用本机精确二项直接比较。
- 本文 §6 实验用的是垃圾邮件数据的标签条件 ICP，与网络实体分层的样本量结构差异未核。
