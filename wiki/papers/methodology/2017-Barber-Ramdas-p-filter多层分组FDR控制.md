# p-filter：分组假设的多层错误发现率控制

> Barber & Ramdas, 2017, JRSS-B 79(4):1247–1268 · 22 页

## 一句话

桶级预算与池化预算可以并存且各按自己的水平同时受控——耦合靠联合阈值搜索实现，不靠预算分裂。

## 全文核验结论

页码取自本地原件 `2017-Barber-Ramdas-p-filter-Multilayer-FDR-Grouped-Hypotheses.pdf` 的物理页。

### 设定（物理第 1 页摘要）

输入 `n` 个 p 值与 `M ≥ 1` 个假设划分（称「层」）。两个端点是本课题最关心的：

- **最细划分**：`n` 个单点组，对应通常意义的 FDR。
- **最粗划分**：全部 `n` 个假设归为一组，**对应池化**。

`M=1` 取最细划分精确回收 BH；取最粗划分精确回收 Simes 全局检验。

### 两层情形：Theorem 1 与 Theorem 2（物理第 8 页）

拒绝集 `Ŝ(t̂_ov, t̂_grp)` 由「个体 p 值」与「组 Simes p 值」**双重过滤**得到——名字 p-filter 即由此而来（物理第 8 页）。

**假设**：

- 式 (5)：**PRDS**（正回归依赖），允许正相依而非仅独立。
- 式 (6)：零假设 p 值**超均匀**，`P{P_i ≤ t} ≤ t`。该条允许误指定的零分布与离散 p 值。

**Theorem 2**（物理第 8 页）：同时控制总体与组 FDR，界为 `α_ov · (H⁰/n)` 与 `α_grp · (H⁰_grp/G)`。

### 多层情形：Theorem 3 与 Theorem 4（物理第 11 页）

**Theorem 3**：可行域

```
T̂(α_1,…,α_M) = { (t_1,…,t_M) ∈ [0,1]^M : FDP̂_m(t_1,…,t_M) ≤ α_m , ∀m }
```

存在良定义的逐维最大点 `(t̂_1,…,t̂_M)`，方法由此定义。阈值取值在离散网格 `t̂_m ∈ {α_m·k/G_m}` 上，可高效求解而无需穷举（§5 算法）。

**Theorem 4（主定理）**：对每个 `m = 1,…,M`，

```
E[ FDP_m(t̂_1,…,t̂_M) ] ≤ α_m · (H⁰_m / G_m)
```

**即每层各按自己的 `α_m` 同时受控。**

### 划分无需嵌套（物理第 11 页，Theorem 4 之后）

原文明确：「in general the M partitions do not need to be nested; they are not constrained to form a hierarchy of partitions」。Theorem 1、2 是 Theorem 3、4 在「最细 + 分组」两层下的特例。

## 我的理解

这篇论文回答的正是「桶级预算与池化预算并存怎么办」。它的答案与直觉相反：**不需要把一个全局预算切开分给各层**。各层预算独立指定，代价体现在阈值上——联合可行域比任一单层的可行域小，因此每层的自适应阈值比单独运行该层时更保守，但**保守度是数据自适应的，不是先验的 `1/M` 折扣**。

## 与本课题的关系

- **束 B 的直接近邻**：第四章要同时约束「池化 FPR ≤ 0.04」与「各长度桶 FPR ≤ 桶级预算」，结构上就是 p-filter 的两层（最粗层 + 长度桶层）。
- **对当前做法的不利证据**：本课题现按「方向 × 层」把 `δ = 0.05` **均分**（Bonferroni）。p-filter 证明在 FDR 语义下多层预算**可以不经均分而同时成立**。因此 `δ` 均分这一维度上，本课题**弱于**已有理论，应写为局限或后续改进方向，**不得写成贡献**。
- **不能直接搬用**：本文控制的是 **FDR**（发现中假发现的期望比例），本课题控制的是 **FPR**（良性实体被告警的比例），且本课题要的是带 `δ` 的**有限样本证书**而非期望界。FPR／证书语义下是否有对应的「免均分」结果，本次检索所及**未找到**，须标为待验证。
- **假设可核**：PRDS（式 (5)）在本课题的实体级 p 值上是否成立需要单独论证；长度桶之间的实体互不重叠，独立性比一般基因组场景更可能成立，但**未验证**。

## 论文可以支持

- **「桶级 + 池化」并存有既有理论**：最粗层即池化，最细层即通常 FDR，二者是同一框架的两层（物理第 1 页）。
- **多层预算可免均分**：Theorem 4（物理第 11 页）证明各层按自身 `α_m` 同时受控，耦合靠联合阈值搜索。
- **划分不必嵌套**：原文明确「the M partitions do not need to be nested」（物理第 11 页）。
- **依赖假设可放宽**：式 (5) 只要求 PRDS（正相依）而非独立，式 (6) 只要求零假设 p 值超均匀，允许离散或误指定零分布。

## 论文不能支持

- 不能说 p-filter 给出了 FPR 或有限样本证书的多层分配方案——它是 FDR 的期望界。
- 不能说本课题的 `δ` 均分「有文献支持」——p-filter 恰恰说明存在更不保守的做法。
- 不能在未核 PRDS 假设的情况下声称可以直接套用。

## 实验结果与负证据

- **对本课题的不利证据**：本文是**反对现行 `δ` 均分**的直接证据。它证明在 FDR 语义下多层预算无需均分即可同时受控，因此本课题的 Bonferroni 均分在这一维度上**弱于**已有理论，应写为局限而非贡献。
- **§6 实测**：在 fMRI 数据上同时考虑三个划分，与「独立对每层跑 BH」的朴素做法比较。**本笔记未逐项核验该节数值**，不引用其具体数字。
- **特例回收（物理第 1 页）**：`M=1` 且最细划分精确回收 BH；最粗划分精确回收 Simes 全局检验。这说明框架是既有方法的严格推广，不是并行的新方法。
- **未解决的迁移问题**：FPR／`δ` 语义下是否存在对应的免均分结果，本文未涉及；本次检索所及亦未找到。

## 疑问 / 待验证

- FPR／`δ` 语义下的「免均分」多层结果是否存在？本次检索所及未找到。
- 若把长度桶层与池化层写成 p-filter 的两层，实体级 p 值能否满足 PRDS？
- 联合阈值搜索带来的保守度，与当前 Bonferroni 均分带来的「证书税」孰大？可用本机数值直接比较。
