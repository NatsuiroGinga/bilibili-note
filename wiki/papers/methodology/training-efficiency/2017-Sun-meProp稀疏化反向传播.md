# meProp：top-k 稀疏化反向传播

> Sun, Ren, Ma, Wang，ICML 2017，arXiv:1706.06197v5

> **入库缘由**：2026-09-04 第四章 EAS 家族谱系调研。
> **本条是 EAS 必须区分开的启发式反例**——EAS 文档 §3.1 所称「相对启发式加速方法的结构性优势」，
> 对位的正是本条与 Selective-Backprop。谱系定位见
> [[thesis/methods/第四章机制一-EAS家族谱系|第四章机制一-EAS家族谱系]]。

**本次核验范围**：MinerU 全文转换（同目录 `-全文.md`），
重点核验 §2.1 方法、§2.2 实现、§4.2 主结果与 §4.8 GPU 加速表。

## 一句话

反传时把梯度向量里幅值最小的那些分量直接扔掉，只留 top-`k`，
于是只有对应的 `k` 行权重需要更新——**这是有意为之的近似，不是精确等价**。

## 方法核心（原文出处标注）

- **top-k 稀疏化**（§2.1）：设 `top_k(v)` 保留 `v` 中绝对值最大的 `k` 个分量、其余置零。
  例：`v = ⟨1, 2, 3, −4⟩`，`top₂(v) = ⟨0, 0, 3, −4⟩`。
  对输出梯度 `∂L/∂y` 取 top-`k` 后再按链式法则往下传。
- **只改反传**（§2.1）：前向计算完全不变。
- **逐层重做**（§2.2.1）：稀疏梯度经过一层后重新变稠密，
  故**每个隐层输出都要重新做一次 top-`k`**。输出层的 `k` 可与隐层不同。
- **实现**（§2.2.2）：最小堆选 top-`k`，`O(n log k)` 时间、`O(k)` 空间，为内存复用做了微调。
- **GPU 实现**（§4.8）：把整个 mini-batch 当「一个大样本」，
  按批内均值做**统一 top-k**，使稀疏模式在样本间一致，从而可压缩成小稠密矩阵。

## 关键性质：**这是近似，不是精确**

- 原文在 §2.1、§2.2 反复使用 **“approximate gradient”**。
- **没有任何充分条件保证被丢弃的分量真为零**——纯粹按幅值排序取舍。
- 因此其正确性只能由**经验**支撑（准确率不掉），无法由数学论证支撑。
- §4.4 的 top-k 对 random 对照证明「按幅值选」确实优于随机选，但这仍是经验证据。

## 实验结果

- **任务**：POS-Tag（LSTM）、Transition-based Parsing、MNIST（MLP），隐层维度均为 500。
- **主结果**（摘要、§4.2）：只更新 `1–4%` 的权重，**不增加迭代次数**；
  **准确率不降反升**。作者归因：最小努力更新不修改弱相关参数，降低过拟合，效果类似 dropout。
- **GPU 加速，合成矩阵乘**（§4.8 表 7，`h = 8192`，batch 1024）：
  | 方法 | 反传时间 |
  | --- | ---: |
  | 基线 | `308.00 ms` |
  | `k = 8` | `8.37 ms`（`36.8×`） |
  | `k = 64` | `14.38 ms`（`21.4×`） |
  | `k = 512` | `69.95 ms`（`4.4×`） |
- **GPU 加速，MNIST 大隐层**（§4.8 表 8，`h = 8192`，整体反传时间）：
  `17,696.2 ms` → `k = 8` 时 `1,501.5 ms`（`11.8×`）。
- **加速的前提条件**（§4.8）：隐层维度小时 GPU 算力未被基线占满，**几乎没有加速**。
  作者实测 `h = 64` 与 `h = 512` 的前向时间几乎相同（`572 ms` 对 `644 ms`）。
  **故其加速数字只在重模型上成立。**

## 与本课题（第四章 EAS）的关系

### 论文原结论

- 在深度网络里稀疏化反传能带来**真实的 GPU 墙钟收益**（表 7、表 8）。
- 该收益以**改变梯度**为代价，正确性由经验准确率对照支撑。

### 本课题推论（原文未给出）

- **对照价值**：meProp 与 EAS 处在同一格的对立两端——
  同样削减反传，meProp 需要精度论证（且只能给经验证据），
  EAS-lite 的跳过是逐位精确的加零，**不需要任何精度论证**。
  这是 EAS 文档 §3.1「正确性风险与收益风险解耦」的对位参照。
- **加速前提可迁移**：meProp 关于「GPU 未被占满时加速消失」的观察，
  提示 EAS 的收益同样依赖排序阶段是否真正占满算力，
  **与 EAS 文档 §7「端到端加速比的分母尚未测」这一待办同向。**

### 不可直接声称的内容

- 不得把 `36.8×`、`11.8×` 一类数字与 EAS 的预期收益并列——
  那是合成矩阵乘与大隐层 MLP 的反传段加速，与本课题排序阶段的结构完全不同。
- 不得声称「精确方法优于近似方法」。**meProp 的准确率不降反升，
  该主张在本条证据下不成立**；EAS 的卖点只能落在工程确定性（无需精度论证），
  不能落在「更准」。

## 疑问 / 待验证

- 准确率提升的正则化解释只有经验支撑，全文无理论论证。
- 统一 top-k 的 GPU 实现改变了每样本的稀疏模式语义，
  与逐样本 top-k 的等价性未讨论。
