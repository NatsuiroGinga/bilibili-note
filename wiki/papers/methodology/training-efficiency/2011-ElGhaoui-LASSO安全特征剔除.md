# LASSO 的安全特征剔除（SAFE）

> El Ghaoui, Viallon, Rabbani，arXiv:1009.4219v2

> **入库缘由**：2026-09-04 第四章 EAS 家族谱系调研。本文是「安全筛除」这一整条家族线的**开山工作**，
> Ogawa 与 Mialon 均明确以它为出发点。谱系定位见
> [[thesis/methods/第四章机制一-EAS家族谱系|第四章机制一-EAS家族谱系]]。

**本次核验范围**：MinerU 全文转换（同目录 `2011-ElGhaoui-Safe-Feature-Elimination-LASSO-全文.md`），

## 一句话

把 LASSO 最优性条件里那个「要解完才知道」的对偶最优点，换成一个**能提前算出来、且保证包含它**的集合，
于是在真正求解之前就能证明某些特征的系数必然为零，把它们从设计矩阵里删掉。

## 方法核心（原文出处标注）

- **最优性条件**（§2.1，式 3）：`|θ*ᵀx_k| < λ ⟹ (w*)_k = 0`。困难在 `θ*` 未知。
- **基本思想**（§2.2）：找一个集合 `Θ` 满足 `θ* ∈ Θ`。
  若 `|θᵀx_k| < λ` 对**所有** `θ ∈ Θ` 成立，则 `(w*)_k = 0`。
  这一步把「需要精确解」换成了「只需要一个外包围」——**这是整个家族的公共骨架**。
- **构造 Θ**（§2.3）：`Θ = Θ₁ ∩ Θ₂`。
  - `Θ₁ := {θ | G(θ) ≥ γ}`，`γ` 是对偶目标在某个可行点处的取值（下界）。
    用对偶缩放 `θ_s := s·θ₀*` 求得闭式 `γ`（式 4）。
  - `Θ₂ := {θ | gᵀ(θ − θ₀*) ≤ 0}`，来自 `λ₀` 处的一阶最优性条件，`g := ∇G(θ₀*) = θ₀* + y`。
  - 默认参考点取 `λ₀ = max_j |yᵀx_j| = ‖Xᵀy‖_∞`，此时 `w₀* ≡ 0`，`θ₀* = −y`。
- **SAFE-LASSO 检验**（§2.4，式 5、6）：剔除条件为
  `λ > max(P(γ, x_k), P(γ, −x_k))`，其中 `P(γ, x_k) := max_θ {x_kᵀθ : G(θ) ≥ γ, gᵀ(θ − θ₀*) ≥ 0}`，
  该凸问题有闭式解（附录 A）。
- **几何直觉**（§2.3 图 1、图 2）：对偶可行域是 `n` 个 slab 的交；
  若 `θ*` 落在特征 `x_k` 的 slab 内部，则该特征的原始最优系数为零。

## 关键性质

- **可证明精确**：摘要与 §1 均明确——「不是启发式，只剔除保证在求解完整问题后必然缺席的特征」。
- **代价极低**：摘要称「大致等于一次梯度步」；剔除易并行，每个特征可独立检验。
- **保守性**：条件是**充分而非必要**，原文自称 “in general conservative”（§1）。
  **漏判只损失收益，不损害正确性**——这一取舍是整个家族共有的。
- **与相关性筛选的关系**（§2.4 末）：对已缩放数据，其产生的特征排序与相关性筛选完全相同；
  **区别在于它给出保证，而相关性筛选不给**。

## 与本课题（第四章 EAS）的关系

### 论文原结论

- 安全筛除的判据来自**对偶可行域的外包围**，与数据分布假设和经验调参无关。
- 该范式可推广到一般 `ℓ₁` 正则凸问题（§4），包括稀疏 SVM 与稀疏逻辑回归。

### 本课题推论（原文未给出）

- EAS-full 设想的「负实体分数全局上界 `Ŝ_n`」在结构上就是本文 `Θ` 的分数空间版本：
  都是用一个**保守的外包围**替代未知量，再由包围推出「某些候选必不活动」。
  **这是 EAS 自称属于本家族的最强形式依据。**
- 「可靠但不必完备」在本文中体现为「保守条件只影响筛除率」，与 EAS 文档 §3.1 的表述一致。

### 不可直接声称的内容

- **本文全部依赖凸性与强对偶。** `Θ₁` 直接由对偶目标值构造，
  深度网络**没有可用的对偶目标**，式 (4)–(6) 无一可以搬用。
- 不得声称本文的筛除率或「一次梯度步」的代价可迁移到本课题。
- 本文未涉及神经网络、非凸损失或成对／排序损失，**任何该方向的外推都是本课题推论**。
