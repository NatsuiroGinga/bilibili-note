# ERM 中经椭球区域与安全损失的数据点筛除

> Mialon, d'Aspremont, Mairal，AISTATS 2020，arXiv:1912.02566v3

> **入库缘由**：2026-09-04 第四章 EAS 家族谱系调研。本文是安全筛除家族**抽象程度最高**的一条，
> 其「安全损失＝有平坦区」的刻画是判断 BER 的 CVaR-pAUC 合页型损失是否属于本家族的直接依据。
> 谱系定位见 [[thesis/methods/第四章机制一-EAS家族谱系|第四章机制一-EAS家族谱系]]。

**本次核验范围**：MinerU 全文转换（同目录 `-全文.md`），
重点核验 §2.3 安全损失、§3.1–3.2 筛除规则与椭球构造、§5.1 实验与两张表。
**§4 的安全损失构造、附录 A 各证明只做结构核对，未逐式验算。**

## 一句话

把安全筛除从「特定模型（LASSO／SVM）」抽象到「任何损失有平坦区的凸 ERM」，
用椭球法而不是对偶间隙来圈定最优解的位置，因此**不需要强凸假设**。

## 方法核心（原文出处标注）

### 部件一：安全损失函数（§2.3）

- **Definition 2.3**：连续凸损失 `f`，`inf_t f(t) = 0`，若存在**非退化非空区间** `T ⊂ ℝ`
  使 `f` 在其上取到下确界，则称 `f` 为安全损失。
- **Remark 2.5**：对偶解的稀疏性来自损失的**平坦区**（即 `0 ∈ ∂f'(t)`）。
  没有平坦区就没有对偶稀疏，也就无从筛除。
- **Assumption 3.1**：回归取 `T = [−μ, μ]`，分类取 `T = [μ, +∞)`，覆盖多数常用情形。
- §4 给出把一般凸损失正则化成安全损失的方法（Fenchel 共轭 ＋ 下确界卷积），例如 safe logistic。

### 部件二：椭球测试域（§3.2）

- 若测试域 `X` 是椭球（中心 `z`、矩阵 `E`），则 `max a_iᵀx` 有**闭式解**（Lemma 3.3）；
  再加一条在中心处求得的次梯度线性约束，**把椭球体积切掉约一半**。
- **Algorithm 1**：椭球法迭代——在当前椭球中心算次梯度，选含最优解的半椭球，
  取包含它的最小体积椭球，重复。每步秩一更新可存储。
- **初始化**（§3.2 末）：需要一个含最优解的初始椭球。若目标 `κ`-强凸可用
  `κ/2·‖x₀ − x*‖² ≤ F(x₀) − F*`；若有范数约束可用包含约束集的球；
  也可用正则化路径上前一个 `λ` 的解。**作者承认部分情形要靠启发式猜量级，再事后检查筛除是否安全。**

### 复杂度（§3.2 末）

- `k` 步椭球法：`O(k²p + npk)`；测试全部数据点：`O(npk)`。
- 总筛除代价 `O(npk)`，对比不筛除求解的 `O(npT)`（`T ≫ k`）。
- **椭球法本身需 `O(p² log(RL/ε))` 次迭代，作者明写「对高维问题精确求解不实用」。**

## 实验结果

- **区间回归**（§5.1）：合成数据 `n = 20`、`p = 2`，20 步椭球迭代后大部分「容易」区间被安全丢弃，
  剩余点给出与全量训练相同的最优解。
- **分类，`ℓ₁` safe logistic**（Table 1，筛除百分比）：随初始化 epoch 与 `λ` 变化剧烈。
  MNIST 在 `λ = 10⁻⁵`、30 epoch 下为 `65`；`λ = 10⁻³` 时多数为 `0`。
  **该损失非强凸，作者称此情形「据我们所知没有基线」。**
- **分类，`ℓ₂` 平方合页**（Table 2，椭球／对偶间隙对照）：
  MNIST `λ = 1.0` 为 `89 / 89`，`λ = 10⁻¹` 为 `95 / 95`；SVHN `λ = 10⁻¹`、20 epoch 为 `11 / 47`。
  **结论是「性能与基线相当，但方法更一般」，不是更强。**
- **适用场景的自我限定**（§5.1 末）：两种方法都要等求解器已到达较好迭代点后才开始筛除，
  故**筛除更适合正则化路径计算或计算预算宽松的场景**。

## 与本课题（第四章 EAS）的关系

### 论文原结论

- 安全筛除的可行性条件被抽象为两条：**损失有平坦区**（对偶稀疏）＋ **能圈出最优解的区域**。
- 椭球构造不依赖强凸，是本文相对既有样本筛除方法的主要一般性收益。

### 本课题推论（原文未给出）

- BER 的 CVaR-pAUC 排序损失在**违序为零处确有平坦区**，
  故在「损失侧条件」上，本课题符合 Definition 2.3 描述的那一类。
  **这是 EAS 自称属于安全筛除家族的最强形式依据。**
- 但第二条件（圈出最优解的区域）在本课题**不成立**：深度网络参数 `p` 为百万级，
  椭球法的 `O(p²)` 迭代与秩一更新在算术上直接不可行，且初始化所需的强凸常数或对偶间隙均不可得。

### 不可直接声称的内容

- 不得声称 Table 1／Table 2 的筛除率（`0`–`98`）可迁移到本课题估计活动集稀疏比例——
  这些是特定数据集、特定 `λ`、特定初始化 epoch 下的凸 ERM 结果。
- 不得声称本文方法可直接用于深度网络；全文的 `x` 始终是线性模型参数向量。
- 作者「筛除更适合正则化路径」的限定，**恰好指向本课题的困难**：
  EAS 面对的是单次训练而非路径计算，没有天然的「前一个解」可用作参考。

## 疑问 / 待验证

- 安全损失的刻画是否能推广到**成对／排序损失**，全文未涉及。
  成对损失的平坦区是候选对集合的联合性质，不是逐点性质，**这一推广非平凡。**
- 本文与 Shibagaki (2016)、Ndiaye (2016) 的定量对比只在两张表内，未做系统性基准。
