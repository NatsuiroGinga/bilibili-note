## 一句话

把「按当前损失排序、只取损失最大的 B 个样本走反向」做成纯在线 SGD 形式，从而在不冻结模型、不增加反向代价的前提下，替掉 Fast R-CNN 里若干手设启发式（bg_lo 阈值与 1:3 前景背景比例）。

## 核心定义与选择规则

### 候选集合与两条「困难」定义（第 3 页 §3.1）

Fast R-CNN 的 mini-batch 是分层构造的：每批先采 N 张图，再每图采 B/N 个 RoI；论文实测设定 N=2、B=128（第 3 页 §3.1，引用 [14]）。RoI 标签规则（第 3 页 §3.1）：

- **前景（fg）**：与某个真值框的 IoU 至少 0.5。
- **背景（bg）**：与真值的最大 IoU 落在区间 `[bg_lo, 0.5)`，论文与 SPPnet 都用 `bg_lo = 0.1`，并在 [14] 中被猜测为「粗略近似困难负样本挖掘」。
- **前景-背景平衡**：[14] 通过随机欠采背景把每批前景占比压到 25%（比例 1:3）。论文报告：去掉该比例（即随机采 RoI）或提高该比例会使 mAP 掉约 3 点；而换成 OHEM 后该比例超参数可一并移除且无副作用（第 4 页首段）。

### 选择规则（**这是本笔记最需要精确转写的部分**）

**注意：论文没有为该规则给出编号公式，只有一段文字描述。** 逐字转写（§4.1, p.4）：

> Hard examples are selected by sorting the input RoIs by loss and taking the B/N examples for which the current network performs worst.

同页给出的去重步骤（§4.1, p.4）：

> To deal with these redundant and correlated regions, we use standard non-maximum suppression (NMS) to perform deduplication (the implementation from [14]). Given a list of RoIs and their losses, NMS works by iteratively selecting the RoI with the highest loss, and then removing all lower loss RoIs that have high overlap with the selected region. We use a relaxed IoU threshold of 0.7 to suppress only highly overlapping RoIs.

因此该选择算子在本笔记中的可核对形式为：对候选集 R 的逐 RoI 损失排序 → 取损失最高的若干个 → 对高度重叠者做 NMS 去重（IoU 阈值 0.7）→ 得到 `R_hard-sel`，规模为 B。论文给出的去重理由是同页的：重叠 RoI 损失高度相关，且由于分辨率差异可能投影到 conv 特征图同一区域，导致**损失被重复计入**。

### 为什么不需要冻结模型：与「交替式」自举的对照（§4.1, p.4）

传统自举是两段交替：(a) 用固定模型找新样本加入活动训练集；(b) 在固定活动集上训练到收敛。论文指出该模板套到 FRCN 上会拖慢学习，因为「在选择来自数十或上百张图的样本期间模型完全不被更新」。OHEM 的关键观察是：**每次 SGD 迭代虽然只采少量图像，但每张图含上千个候选 RoI，可以直接在其中选困难样本而不是启发式采样一个子集**，从而把交替模板压缩成「只冻结一个 mini-batch」。原文（p.4）：

> This strategy fits the alternation template to SGD by "freezing" the model for only one mini-batch. Thus the model is updated exactly as frequently as with the baseline SGD approach and therefore learning is not delayed.

### 不需要 fg-bg 比例的论证（§4.1, p.4）

> We note that the procedure described above does not need a fg-bg ratio for data balancing. If any class were neglected, its loss would increase until it has a high probability of being sampled. There can be images where the fg RoIs are easy (e.g. canonical view of a car), so the network is free to use only bg regions in a mini-batch; and vice-versa when bg is trivial (e.g. sky, grass etc.), the mini-batch can be entirely fg regions.

这段是「按损失选择会自动恢复被忽略类别」的机制论证，是本笔记中与「按损失选择」最直接相关的原文主张。

## 实现细节（§4.2, p.4–5）

论文先给一个直白但低效的实现：直接改损失层，对全部 RoI 算损失、排序、把非困难 RoI 的损失置 0。论文指出该实现在现有深度学习工具箱里仍然会为全部 RoI 分配内存并跑反向（尽管大多数 ROI 损失为 0、无梯度更新），因而低效。

实际采用的结构（第 5 页图 2；说明文字在 p.4–p.5）：**维持两份 RoI 网络副本，其中一份只读**。

- 只读 RoI 网络（图 2(a)）只对全部 RoI 分配前向所需内存；对一次 SGD 迭代，它在 conv 特征图上对全部输入 RoI（R）前向并算出每个 RoI 的损失；
- 困难 RoI 采样模块按 §4.1 的规则选出 `R_hard-sel`；
- 常规 RoI 网络（图 2(b)）只对 `R_hard-sel` 做前向与反向、累积梯度并传回 conv 网络。

论文明确：全部 N 张图的所有 RoI 都作为 R，因此只读 RoI 网络的有效批大小为 `|R|`，常规 RoI 网络的有效批大小仍是 §3.1 的标准 B（p.4 末）。Caffe 实现要点（p.5）：用 N 次单图 mini-batch 的前向-反向做梯度累积，N=2（得 `|R| ≈ 4000`）、B=128；在此设定下该结构的内存占用与前述直白实现相近，但**快 2 倍以上**。

## 实验设置与读数

### 实验设置（第 5 页 §5.1）

两个骨干：VGG CNN M 1024（VGGM，[5]）与 VGG16 [28]；数据集 PASCAL VOC07（trainval 训练、test 测试）；SGD 训练 80k 次 mini-batch 迭代，初始学习率 0.001，每 30k 迭代乘 0.1。论文说明表 1 第 1–2 行的基线数字是用该训练计划复现的，且略高于 [14] 的报告值。

### 训练损失读数（§5.5 与图 3，p.6）

论文为规避采样方式对损失的干扰，每 20k 步取一次快照并在**整个 VOC07 trainval** 上算所有 RoI 的平均损失。结论：`bg_lo=0` 训练损失最高、`bg_lo=0.1` 显著更低、`B=2048` 加学习率调整后低于 `bg_lo=0.1`，而 OHEM 在全部方法中训练损失最低（p.6）。

## 可迁移机制

1. **「按损失排序取前若干个」可以做成逐迭代在线算子，而不必是两段交替的离线自举。** 关键在于候选池的规模：单次迭代的输入（这里是图像）内部就含大量候选（这里是上千 RoI），于是「评分-选择-更新」可以在同一迭代内完成，模型只「冻结」一个 mini-batch。
2. **选择只需一次前向即可支撑，反向代价与基线相同。** 双副本结构（只读副本算全量分数 + 常规副本只对选中子集做前后向）是本论文把「多算一次前向」与「不增加反向」分开记账的具体工程手段，第 5 页报告该结构比「把所有非选中样本损失置 0」的朴素实现快 2 倍以上。
3. **去掉启发式的论证是可复用的机制论证模板**：不用手设比例的理由不是「调参麻烦」，而是「被忽略的类损失会升高、从而采样概率变大」——这是一个**由损失驱动的自校正反馈**论证（第 4 页 §4.1）。该论证只覆盖「类别被忽略」的情形，不覆盖「组内相关性与重复计入」的情形（后者由 NMS 单独处理）。
4. **同口径消融的设计**：表 1 同时给出 `bg_lo=0`、`N=1`、`B=2048 + 调学习率` 三组对照，把「机制收益」与「启发式被去掉」「批大小变化」「学习率变化」分开。§5.4 的 `B=2048, bg_lo=0` 尤其关键——它是「用全部样本」与「只选困难样本」在近似同等计算下的对照。

## 与课题的关系

**以下为本课题的关联判断，不是原文主张。** 本课题的双侧组相对对抗训练需要「按损失在组内取 top-k / 做组内选择」的形式化支撑，OHEM 是该形式化最直接的可引先例。逐条对照：

- **已占用（选择规则的形态）**：OHEM 已经占用了「对一批候选按当前损失排序、取损失最大的若干、只有被选中的样本进入梯度更新」这一整类规则（§4.1, p.4），并且证明了它在**在线 SGD** 下可行、不拖慢更新频率。因此「按损失取 top-k 参与训练」这一机制本身不是空白。
- **已占用（选择的单位是「同一输入内部的候选集合」）**：OHEM 的候选池是**单张（或两张）图像内部**的上千 RoI，这与本课题「同一实体/同一样本的 K 个变体构成一组」在**结构上同构**——都是「一个容器内部先全量评分再做组内取舍」。这条相似性意味着本课题在同一容器内做组内选择时，需要显式说明与 OHEM 的差异，而不能把它当作新机制。
- **未占用（信息源）**：OHEM 的选择只读**样本自身的绝对损失**，不含任何组内相对量——无减组均值、无中心化、无符号、无负值。以**组内相对/中心化信号**（例如相对组均值的偏离、方向符号、双侧结构）驱动组内选择或加权，在本文未被占用，本文既非其先例也非其反例。这是本笔记对本课题最重要的一条判据。
- **未占用（硬选择 vs 软加权）**：OHEM 是**硬选择**（取 top-B，未被选中的 RoI 该迭代完全不参与），不做权重分配；与组内连续重加权（如 MMEL 的 softmax 权重）形成不同族。本课题若同时涉及「选」与「权」，需要分别对标。
- **未占用（任务域与信号）**：本文全部在图像检测上，且「困难」由分类+定位损失定义；**不涉及分布漂移、跨年度泛化、实体级聚合、类别不对称纠错或加密流量**。OHEM 也未在任何偏移设定下评估。
- **可复用的对照设计**：§5.4 的 `B=2048, bg_lo=0`（用全部 RoI、学习率相应调整、近似同等算力）是本论文区分「选择机制收益」与「批大小/算力收益」的关键对照（表 1 第 7–10 行与第 11–13 行）。本课题做组内选择时应设置同口径的「全组参与」对照。
- **可复用的成本账**：表 2（p.6）把「多一次全量前向」的代价量化为约 +0.09 s/迭代（VGGM）与 +0.43 s/迭代（VGG16），并说明反向代价不变。这为「组内选择需要额外几次前向」的成本论证提供了量级参照。

一句话：OHEM 占用了「容器内全量评分 + 按绝对损失取 top-k + 硬选择」这一形式化，并给出了在线可行的工程实现；它与「组内相对/中心化信号驱动选择」在信息源上是两类不同机制，因此后者在该子空间仍未被本文占用。

## 疑问待验证

- 论文§4.1 断言「被忽略的类损失会升高直到被采样到的概率变大」（p.4），但**没有任何实验验证**该自校正行为在训练中确实发生。引用该论证时必须标为机制论证。
- 表 1 中 OHEM 在 VGG16 + N=1 + bg_lo=0 的 69.7 与 VGG16 + N=2 + bg_lo=0 的 69.9 差异很小，论文据此称 N=1 下「mAP 基本不变」，但这是**单次运行**的数字，论文未报告重复运行或方差。不能据此宣称 OHEM 对批内相关性免疫。
- NMS 的 IoU 阈值 0.7 未见消融（§4.1, p.4）。论文把它描述为「宽松」，但未给出「更严格/更宽松会怎样」的证据。
- 论文未讨论当候选池远小于批大小时（例如本课题中组内变体数 K 很小，如 K=4 或 K=8）该选择规则是否仍然有意义；OHEM 的候选池量级是 2000–4000（p.4–5），与小组场景差距较大。
- 论文未报告被选中 RoI 的**变化率**（例如同一个 RoI 是否长期居于 top-B），因此「选择是否导致少数样本被反复训练」在原文中没有证据。
