# 分层纽曼—皮尔逊分类

> Wang, Wang, Li, Tong, 2024, JASA 119(545):39–51 · 79 页（含附录）

## 一句话

Tong 伞形算法的多约束版本：`I−1` 个欠分类错误各自带 `(α_i, δ_i)`，靠序贯条件化而非 Bonferroni 均分来协调。

## 全文核验结论

页码取自本地原件 `2024-Wang-Hierarchical-Neyman-Pearson-Classification.pdf` 的物理页。

### 问题设定（物理第 8 页）

类别有自然优先级序。**第 `i` 个欠分类错误**定义为「把类 `i` 的个体误分到任意 `j > i` 类」的概率 `R_i*(φ)`。H-NP 目标是

```
IP( R_i*(φ̂) > α_i ) ≤ δ_i ,   i ∈ [I−1]
```

原文明确 `(δ_1, …, δ_{I−1})` 是**a vector of tolerance parameters**——**逐约束容差**，不是一个全局 `δ` 的均分。

### Proposition 1：单约束的次序统计量界（物理第 10 页）

对类 `i` 的留出样本分数集 `T_i`（基数 `n_i`），`t_{i(k)}` 为第 `k` 个次序统计量：

```
IP( P_i(T_i(X) < t_{i(k)}) > α ) ≤ v(k, n_i, α) := Σ_{j=0}^{k−1} C(n_i, j) α^j (1−α)^{n_i−j}
```

原文注明这是 Tong et al. 2018 Proposition 1 的对应推广，证明在补充材料 B.1。

### Theorem 1：条件化后的更宽搜索域（物理第 11 页）

给定前序阈值 `t_1,…,t_{i−1}`，定义条件化子集 `T_i' = {T_i(X) : X ∈ S_i^t, T_1(X) < t_1, …, T_{i−1}(X) < t_{i−1}}`，令 `n_i' = |T_i'|`。取

```
p̂_i = n_i'/n_i ,  p_i = p̂_i + c(n_i) ,  α_i' = α_i / p_i ,  δ_i' = δ_i − exp{−2 n_i c²(n_i)}
```

其中 `c(n) = O(1/√n)`。原文说明 Theorem 1 相比 Proposition 1 给出**更宽的阈值搜索域**与**更紧的界**（物理第 11 页前后）。

## 我的理解

这篇论文回答的正是「多个 NP 证书如何同时成立」。它的答案有两层：

1. **每个约束自带 `(α_i, δ_i)`**，不需要先有一个全局 `δ` 再切开；
2. **约束之间的协调靠序贯条件化**——第 `i` 个阈值在「前 `i−1` 个阈值已生效」的子样本上选，代价是一个 `O(1/√n)` 的集中不等式修正，而不是 `δ/I` 的均分。

但这套机制**依赖类别的优先级序**：`T_i'` 的定义要求前序阈值有明确的先后。没有这个序，条件化无从谈起。

## 与本课题的关系

- **机制 1 第 ② 层的 NP 侧最近邻**：本课题的「六方向同模型交叉校准」也是**多个 NP 约束同时成立**的问题，H-NP 是 NP 谱系内最直接的先例。
- **本课题不得声称「多约束 NP」是新的**——H-NP 已在 JASA 发表。
- **差量在结构**：H-NP 的多约束是**有序嵌套**（类别优先级），本课题的六方向是**角色互换 × 折外模型**的组合，**不具备天然的先后序**。因此 H-NP 的序贯条件化技巧**不能直接搬用**，Bonferroni `δ/6` 是没有序结构时的合法退路。
- **但这也说明 `δ/6` 是保守默认而非最优**：与 p-filter（FDR 语义）一起，构成**两条独立证据**表明多约束预算分配可以优于均分。本课题的 `δ/6` 应写为局限与后续改进方向。

## 论文可以支持

- 多个 NP 证书同时成立是既有做法，且已推广到多类有序设定。
- 逐约束容差向量 `(δ_1,…,δ_{I−1})` 是比全局均分更细的既有表述方式。
- Tong 式次序统计量证书可以推广，`v(k, n, α)` 的二项形式在多约束下保持。

## 论文不能支持

- 不能把 H-NP 的序贯条件化直接用于本课题的六方向——后者无天然优先级序。
- 不能声称本文处理了路径极值或序贯观测上的 NP 控制——它的单元仍是单个观测。
- 不能把 Theorem 1 的修正项 `exp{−2 n_i c²(n_i)}` 直接搬到本课题，须先建立对应的条件化结构。

## 实验结果与负证据

- **动机侧的负证据（物理第 8 页附近）**：原文指出既有 NP 程序「either restricted to binary classification or did not provide high-probability control」，即多类高概率控制此前是空白。
- **朴素做法失效（物理第 7 页附近）**：原文记录常见多类方法的欠分类错误「有非平凡的概率超出目标水平」，这与 Tong 2018 对经验阈值的批评同源。
- **COVID-19 应用**：在患者严重程度分类上验证 H-NP 一致控制欠分类错误。**本笔记未逐项核验其数值**，不引用具体数字。
- **对本课题的结构性限制**：H-NP 的优势依赖有序类别；本课题的方向集合若无序，该优势不可得——这是**限制而非支持**。

## 疑问 / 待验证

- 本课题六方向是否可以人为赋予一个合法的先后序，从而套用 H-NP 的条件化以避免 `δ/6`？须先确认赋序不引入选择偏倚。
- H-NP 的 `c(n) = O(1/√n)` 修正在本课题样本量（数千）下的实际代价是多少？可用本机数值直接算。
