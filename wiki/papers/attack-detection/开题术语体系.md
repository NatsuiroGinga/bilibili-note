# 开题术语体系与命名决策

> 王童童·网络攻击检测大模型开题。本文是论文写作的**单一术语来源**：两个创新点的命名、各模块命名、命名原则与被否候选。所有命名对应真实改进增量，经无重名核实，区别于现有方法，避免"换名不换核"。
> 相关：[[GRPO变体群-方法选型]]、[[数据集构建章节设计_开题实施计划]]、[[IDS2018字段普查报告]]、[[朱焱雷-加密流量博弈对抗与高效训练]]（仅结构模板参考）。

## 两个创新点与命名总览

| 层级 | 命名 | 全称 | 状态 |
|------|------|------|------|
| 创新点1·第一级检测器 | **CI-PRD** | Conservation-Invariant Physics Residual Detector（守恒不变量物理残差检测器） | ✅ 定 |
| 创新点2·第二级算法 | **PIC-GRPO** | Physics-Informed Curriculum GRPO（物理信息课程式 GRPO） | ✅ 定 |
| 整体架构（可选） | **PhyS-TSDA** | Physics-Semantic Collaborative Two-Stage Detection Architecture | △ 待删越界句后可用 |
| 跨级联动机制（可选） | **R-AAM** | Residual-Guided Attention Anchoring Mechanism | △ 待确认可实现 |
| 训练稳定辅助 | （不命名） | Stiefel 流形正交正则 | 降级，不作创新命名 |

## 1. CI-PRD — 第一级 PINN 检测器（创新点1）

- **全称**：Conservation-Invariant Physics Residual Detector（守恒不变量物理残差检测器）
- **含义**：以**网络流量守恒不变量**（节点流量守恒 I1、流双向守恒 I2、TCP 状态守恒 I3、熵平稳 I4）为物理约束的 PINN 检测器，输出逐时刻物理残差作异常得分，无监督初筛。
- **与通用 PINN 的区别**：通用 PINN 解 PDE 正/逆问题；CI-PRD 把 PINN 改造为异常检测器，以**残差幅值**直接作判定依据，是 PINN 在入侵检测场景的专用化。
- **命名依据**：走**方案 B（守恒不变量）**而非方案 A（TCP 流体）——IDS2018 字段普查证实 TCP 流体残差不可算（无 W(t)/q(t) 时序，19% UDP 不服从 TCP 方程），守恒不变量可算且攻击可打破。
- **适用位置**：第 3 章（创新点1）模块详解、消融、PINN 实验。

## 2. PIC-GRPO — 第二级算法（创新点2）

- **全称**：Physics-Informed Curriculum Group Relative Policy Optimization（物理信息课程式组相对策略优化）
- **PIC = Physics-Informed Curriculum**：物理残差驱动 + 课程式，覆盖创新点2 双核心。
- **与 PINN 术语一致**：PINN（物理信息神经网络，第一级）+ PIC-GRPO（物理信息课程式，第二级），两级统一"物理信息"口径。
- **"Informed" 优于 "Aware"**：物理残差是**驱动**课程难度与奖励，不只是感知。
- **无重名核实**：arXiv 精确短语检索 PIC-GRPO=0（PhyC/PAC/PI-GRPO 亦 0），已知 16 个 GRPO 变体无重名；Google Scholar 全网待人工兜底。
- **差异化句（必配）**：PIC-GRPO 与 Feng-RCS（基于奖励的课程式 GRPO）的区别在于——其课程难度维度与可验证奖励**均由 PINN 物理残差驱动**，并与第一级 CI-PRD 跨级耦合。
- **成立前提**：实现中物理残差必须真驱动课程采样 + 奖励 + 跨级耦合，不可沦为"GRPO+采样器+奖励项"换名。
- **详见**：[[GRPO变体群-方法选型]] 的"算法命名决策"节。

## 3. PhyS-TSDA — 整体两级架构（可选，待修正）

- **全称**：Physics-Semantic Collaborative Two-Stage Detection Architecture（物理-语义协同两级检测架构）
- **含义**：物理先验与语义知识协同的两级检测，物理残差引导语义推理。
- **⚠️ 待删越界句**：原描述"语义结论反向优化物理基线"是范围蔓延——当前两级是单向（物理残差→语义精判），无反向通路。**删此句**，或真设计双向闭环再写。
- **缩写偏拗口**，可考虑简化。采纳与否待定。

## 4. R-AAM — 跨级联动机制（可选，待确认可实现）

- **全称**：Residual-Guided Attention Anchoring Mechanism（残差引导注意力锚定机制）
- **含义**：第一级 CI-PRD 输出的逐时刻物理残差序列→注意力权重掩码→引导第二级 LLM 聚焦异常峰值区段。
- **价值**：比"残差值+特征拼接输入 LLM"更精细的跨级耦合，同时提推理效率与异常定位精度。
- **⚠️ 新增设计**：不在当前方案中。**采纳前需确认可实现**（残差序列对齐到 LLM attention）。可实现则用，否则退回简单拼接。

## 5. 流形约束（不命名，降级处理）

- Stiefel 流形正交约束（原 SM-CH 提案）**不作创新点命名**。
- 原因：创新点二已是 PIC-GRPO（课程式 RL），流形约束已**降级为训练稳定正则项**（见改进素材诊断 1）。把它重新包装为创新点会重犯初版"流形约束当核心创新"的概念混淆。
- 处理：第 4 章"训练稳定辅助"一笔带过，引用 [[Stiefel流形LoRA黎曼优化]]、[[mHC-流形约束超连接]]，不配专属创新命名。

## 命名原则（贯穿全部）

1. **对应真实增量**：每个命名必须对应实际实现的改进，不"换名不换核"。
2. **无重名核实**：arXiv 精确检索确认不与现有变体撞名（PIC-GRPO 已核；CI-PRD/R-AAM/PhyS-TSDA 待同样核实后再写入论文）。
3. **配差异化句**：每个命名必配一句"与最近先例的区别"，把新意钉死（如 PIC-GRPO vs Feng-RCS）。
4. **术语一致**：两级统一"物理信息(Physics-Informed)"口径。
5. **参考边界**：同门/参考论文（如朱焱雷）仅作结构模板，命名与创新均自主（见记忆 `thesis-reference-template-only`）。

## 关键方向决策（命名的前提）

| 决策 | 结论 | 依据 |
|------|------|------|
| 物理"方程"选 A 还是 B | **方案 B（守恒不变量）** | [[IDS2018字段普查报告]]：方案 A 的 TCP 流体残差在 IDS2018 不可算 |
| 第一级检测器命名 | CI-PRD（非 TD-PRD） | TD-PRD 硬编码方案 A，与方向冲突 |
| 创新点2 是什么 | PIC-GRPO（课程式 RL） | 非流形约束；流形已降级 |
| 流形约束地位 | 训练稳定辅助，非创新点 | 改进素材诊断 1 |
| 数据集策略 | IDS2018(CSV+原始PCAP) + 自构造测试床(只做 I1) | [[数据集选型核实报告]] |

## 被否候选（存档，避免再用）

| 被否命名 | 否决原因 |
|---------|---------|
| PhyC-GRPO | 缩写略勉强（Phy+C）；改用 PIC-GRPO |
| PAC-GRPO | "Aware"偏弱、与 PINN 术语脱钩 |
| PI-GRPO | 缺 Curriculum |
| TD-PRD | 硬编码已否决的方案 A（TCP 流体） |
| SM-CH 作创新点2 | 创新点2 是 PIC-GRPO；流形已降级，重包装会犯概念混淆 |
