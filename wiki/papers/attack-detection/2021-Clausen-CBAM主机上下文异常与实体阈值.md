# 定位

这篇论文是第四章双机制查重中的安全领域强边界：它同时具备主机实体键、短期上下文序列、每主机分位阈值、非重叠时间段评价和长时间误报稳定性分析。它证明“按实体冻结分位阈值”和“实体短期上下文”均已有直接网络入侵检测先例，但不能证明 DTEP 或 PBC 的完整合同已经发表。

# 任务、输入与判定单元

- 任务是以严格良性流量自监督训练上下文异常模型，检测低流量远程访问攻击；论文覆盖 CICIDS-17、LANL-15 和 UGR-16（物理第9至12页）。
- 物理第4页第3.1节先按主机 IP 汇集出入流，再按时间切会话：相邻流启动间隔小于 `α=8 s` 则属于同一会话；会话超过 `β=25` 个事件即切开。作者把同一会话视为强短期依赖。
- 物理第5至6页把每条流表示为协议、服务器端口、方向构成的符号状态，以及由训练分布等频分箱得到的流量大小组；另输入人工标记的主机功能组。会话含 3 至 27 个符号项。
- 模型输出是会话级异常分数，阈值则按“数据集×主机”分别确定。因此训练共享主机组信息，但最终决策单元是某台主机的一次会话，不是逐流，也不是跨全年实体总分。

# 模型、时间尺度与因果性

## 短期上下文模型

- 物理第6至7页第3.4节使用两层双向 LSTM；状态、大小组和主机组先分别嵌入，再拼接进入双向层，最后由两个 softmax 头预测流状态与大小组。
- 物理第8页给会话异常分数：将每条流的状态与大小预测似然取平均后从 1 中扣除，因而分数不随会话长度机械增长。原式为

  `AS_j = 1 - Σ_i (exp(lh_x^{i,j}) + exp(lh_s^{i,j})) / N_j`。

- 双向 LSTM 明确同时利用某条流之前和之后的同会话事件。它适合离线会话完成后的判定，但不满足 DTEP“每个时点只读因果前缀”的要求。
- `α=8 s` 与 `β=25` 是固定的会话切分参数。物理第4至5页说明 `α` 来自所选主机约 90% 流间隔分位，`β` 由经验估计；它们没有通过源实体分组折外预测选取。

## 训练与超参数选择

- 物理第8至9页把可用训练数据再拆成较大训练集和较小验证集，比较不同模型容量，并以验证损失是否随训练损失下降作为选择依据；学习率、权重衰减、词表大小和大小组数也按类似实验过程确定。
- 最终配置为状态词表 `M=200`、流大小组 `S=7`、主机功能组 `C=4`，每个数据集的主机组由人工标记。没有 GroupKFold、留一主机或实体 OOF 选择。
- 物理第13页说明三个数据集分别训练模型，但复用同一组已选超参数。

# 实体专属阈值与误报预算

- 物理第9页第3.6节从训练期良性会话为每台主机分别估计 99.9% 分位数阈值：

  `T_c : P(AS_j^c ≤ T_c) ≤ 0.999`。

- 论文把该阈值解释为控制测试期预期假阳率的操作点。它直接构成“实体专属分位阈值＋固定误报率目标”的安全领域先例。
- 阈值来自训练期而不是目标年度先导段；没有目标无标签预测、少量合法标签、类别先验、BBSE 条件诊断或失配回退。
- 论文没有给不同实体分配总告警数量预算，也没有把每实体阈值向总体阈值收缩；数据稀少主机的阈值稳定性仍是问题。

# 切分合同与泄漏边界

- 物理第11至12页称训练与测试使用非重叠时间段。UGR-16 是严格向前：首月训练，随后两个月为测试集1，隔一个月后的最后两个月为测试集2。
- CICIDS-17 因五天跨度短，训练使用五天中的良性流量，测试段围绕攻击时刻，不能据此认定严格的先导—后段冻结合同。
- LANL-15 更是反向时间：前13天测试、后14天训练。作者只以区间不重叠论证稳健评价，但这违反真实部署的因果时序。
- 因而本文可以支持“参数和阈值不在相同测试会话上重选”，不能支持“源训练→目标因果先导段标定→冻结后段”的联合算法。

# 结果、分面与消融

- 物理第13至14页用攻击类检测率、假阳率、ROC 曲线和 AUC，而不是只报告受类别比例影响的精确率或 F1。CICIDS-17 在阈值 `T=0.77` 下，Heartbleed、FTP、SSH 和 SQL 注入的会话检测率分别为 1.00、0.91、0.74 和 0.75；Web 暴力破解、渗透和 XSS 分别为 0.66、0.41 和 0。
- 物理第16页在 UGR-16 的两个远期测试段上报告五台主机的分数分位变化小于 0.03，平均少于 0.15% 良性会话超过阈值，折合四个月每台同活跃度主机少于十条假警；这只是同数据源时间稳定性，不是跨年度目标先导适应。
- 物理第17至18页显示数据少的主机假阳显著更高：LANL 主机 C13845 与 CICIDS 主机 `192.168.10.51` 分别约 0.40% 和 0.42%，而平均约 0.1%；把训练会话从约10,000降到3,000或1,000会进一步提高假阳。该结果提示 PBC 必须显式处理稀疏实体，而不是无条件为每个实体独立估分位。
- 物理第22页表6是关键结构消融：双向层相对单向层把总体假阳率在 UGR-16 从 0.31% 降到 0.12%、在 CICIDS-17 从 0.37% 降到 0.18%；不足5条流的短会话分别从 1.6% 降到 0.09%、从 1.7% 降到 0.13%。该增益依赖未来同会话上下文，不能直接外推到因果 DTEP。
- 物理第22至23页还比较浅层 LSTM，说明第二层 LSTM 与线性层改善复杂会话预测；表7给浅层 LSTM、马尔可夫链和非确定有限自动机的分数分布与平均 AUC，但没有“全历史通道／近期通道”的消融。

| 对象 | 等级 | 可以支持 | 不能支持 |
| --- | --- | --- | --- |
| PBC（A） | D2／E3 | 网络安全中已有按主机分别从良性训练期取固定分位阈值，并以低假阳率评价远期时段；稀疏主机假阳更高 | 不是目标年度先导段；无合法标签／无标签双支路、先验校正、BBSE 失配门、回退或独立最终后段 |
| DTEP（B） | D1／E3 | 按主机形成固定上界短会话；短期上下文能降低远程访问攻击的逐会话假阳 | 无未衰减全历史通道；双向层非因果；会话参数不由源实体 OOF 选择；未研究长实体假阳 |
| 联合算法（C） | D1／E3 | 部分数据集使用不重叠训练／测试时间段，模型和主机阈值在测试前确定 | LANL 反向时间，CIC 时序隔离不严格；无源实体 OOF、目标先导标定、诊断回退和独立冻结后段 |

# 对技术设计与原创边界的影响

- “实体专属分位阈值”“低假阳操作点”和“实体短期上下文”都不能作为原创主张。
- PBC 的可区分点必须写成：仅用目标年度因果先导段、在稀疏实体时采用预注册的全局收缩或回退、条件性估计先验并在独立后段冻结；不能只复现 CBAM 的逐主机训练分位。
- DTEP 应保留单一因果模型的全历史与有界近期双通道，不应因 CBAM 的双向 LSTM 消融而改成读取未来会话的双向模型。
- 快速实验至少应加入“源期每实体99.9%分位阈值”或同预算收缩版本作为 PBC 的直接基线，并按实体训练样本量分面报告假阳；否则无法证明目标先导适应超过既有实体阈值做法。
- 本文未出现 DTEP 与 PBC 的完整同现，不能据其反推完整组合新颖，也不能据连续未命中宣称不存在。
