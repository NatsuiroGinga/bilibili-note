- **[[2026-El-Hajj-多尺度主机行为与LOEO嵌套选择|El-Hajj：多尺度主机行为与 LOEO 嵌套选择]]** — 先按虚拟机聚合每秒系统状态，再并行计算1、5、10、30秒滚动统计，并在104次留一实验外层评价内做嵌套特征选择；强占用多尺度近期表示与源侧嵌套选择，但选择的是混合多窗特征而非单一窗长，内层也不是实体分组折外。

- **[[2019-Cotter-Proxy-Lagrangian约束优化|Proxy-Lagrangian：不可微速率约束]]** — FPR 等速率约束的双玩家理论来源。
- **[[2019-Cotter-独立验证集约束泛化|独立验证集约束泛化]]** — 训练玩家与独立约束验证玩家分离的理论来源。
- **[[2021-Kumar-固定FPR约束FNR|固定 FPR 下的 FNR 优化]]** — 固定 FPR operating point 的目标近邻。
- **[[2025-Ghiani-Regression-aware持续学习安全回归|Regression-aware Continual Learning]]** — 用 NFR/PFR 分解安全回归并以 PCT 约束旧正确样本；是 LAMDA 安全回归候选的直接基线，不能直接当作新算法。
- **[[2025-Mohamed-MADAR多样性感知回放|MADAR]]** — 用家族预算、代表性与异常样本做恶意软件多样性感知回放；历史池与 LAMDA 全程 200 容量不同。
- **[[2019-Wei-GSS梯度样本选择在线持续学习|GSS]]** — 将记忆选择视为梯度约束压缩；梯度多样性记忆的直接先例。
- **[[2019-Aljundi-MIR最大干扰检索|MIR]]** — 用虚拟更新估计受干扰样本并优先检索；改变回放取样，不等于新样本入库。
- **[[2024-Park-PBR先验无关平衡回放|PBR]]** — 用不确定性引导长尾回放，并结合原型约束与余弦分类器；完整收益不能归因于采样器单独。
- **[[2020-Chrysakis-CBRS不平衡在线持续学习|CBRS]]** — 类别平衡 reservoir 的基础先例；需与类别配额和损失混合分开消融。
- **[[2019-Chaudhry-AGEM高效终身学习|A-GEM]]** — 用记忆平均梯度投影约束更新；不是恶意／良性双侧风险保证。
- **[[2023-Amalapuram-ECBRS-PAPA网络入侵持续学习|ECBRS/PAPA]]** — 以全局类别不平衡扩展 CBRS，并用 PAPA 近似 MIR 虚拟更新；NIDS 近邻，不能直接外推到 LAMDA。
- **[[2017-Schulman-PPO-自适应KL惩罚系数|PPO 自适应 KL]]** — 把固定 KL 惩罚系数换成实测/目标比值驱动的在线闭环（§4 式 8 后：`d<d_targ/1.5→β←β/2；d>1.5d_targ→β←β×2`）；缺陷 A「一次性标定→闭环」的最简先例，不处理凸映射放大。
- **[[2019-Tessler-奖励约束策略优化-对偶梯度下降|RCPO 对偶梯度下降]]** — 乘子由实测约束违反量驱动做对偶上升、投影有界化（§3 式 4–5）；对偶变量闭环的理论支柱。
- **[[2020-Stooke-PID拉格朗日方法-约束RL安全|PID-Lagrangian]]** — 诊断纯积分控制的 90° 相位滞后振荡，给出比例/微分阻尼更新式（式 13/16）；闭环移植的低频阻尼件。
- **[[2018-Espeholt-IMPALA-V-trace重要性权重截断|V-trace 截断]]** — ρ̄ 决定收敛不动点、c̄ 是方差缩减不改不动点（§4.1 式 1）；给 m_cap 的理论身份：截断=方差缩减器，不是不变量恢复器。
- **[[2021-Gibbs-自适应保形推断-分布漂移在线标定|ACI 自适应保形推断]]** — 分布漂移下标定量在线闭环 `α_{t+1}=α_t+γ(α−err_t)`（§2 式 2），无分布假设长期覆盖率保证；与缺陷 A 同构度最高。
- **[[2023-Zhang-PPO任务反馈动态截断|Pb-PPO 动态截断界]]** — 用 UCB bandit 按 Return 反馈在候选界集合中选截断界；证明「界可闭环」活跃，但反馈信号不同构，仅作存在性引用。
- **[[2026-Asadi-FreeMOCA无记忆恶意代码持续学习|FreeMOCA]]** — 用 warm-start 与逐层参数插值替代回放；使用 EMBER/AZ，不是 LAMDA 同协议结果。

## LAMDA 第三章：等字节/比特预算对照的奠基与反例（2026-10-14 新增）

为回答「固定存储预算下，样本侧与参数侧如何分配」而核验的两篇**等字节对照**基础文献。两篇都**不在 LAMDA 上做实验**；它们的用途分别是「口径先例」与「反面约束」，不是结论依据。

- **[[2023-Zhou-MEMO-模型还是一条样本-全文|MEMO（ICLR 2023）]]** — 把模型缓冲与样本缓冲折算到**同一字节预算**后比较：1×ResNet32 ≡ **603 张 CIFAR 图**（ImageNet 上 1×ResNet18 ≡ 297 张）。**该换算嵌了编码不对称**（模型按 fp32 4 B/参数、图按 int8 1 B/像素，图若也按 fp32 则为 ≈151 张）。结论是**存在交叉点**：预算受限时样本侧胜、充裕时模型侧胜（§1、§4.2、§A.1）。其坐标轴**不含计算成本**，量化/压缩被显式排除（§C.5、§D.4）。
- **[[2025-Cho-遗忘遗忘-充裕记忆-全文|Forget Forgetting（ICLR 2026）]]** — 直接质疑「死守极小回放容量」：主流基准的 20 条/类（≈4%）**既不现实也非必要**，真实瓶颈是 GPU 时间而非存储（§1、§3.1）。充裕记忆下**朴素 Replay 即追平 SOTA**、扩模型法训练时间是它的 4–5 倍（§5.2 Table 2）；且**遗忘被解决后转为可塑性丧失**，梯度对齐 `ρ_t→1` 使有效步长随 `λ→0` 收缩到 0（§3.2 Eq. 10–13）——这是「往历史侧加大暴露」的直接反例，须与「$m$ 杠杆」正面划界。

同批核验的第三篇不属等字节对照，但直接约束「回放预算—效果」这一维度的**可引用边界**：

- **[[2022-Rahman-持续学习在恶意软件上的局限-全文|Rahman 2022：持续学习在恶意软件分类上的局限（CoLLAs 2022）]]** — 11 种 CL 方法 × 3 情景 × Drebin/EMBER，全部弱于 naive Joint 回放（Abstract 第 1 页）；**正则化类（EWC/EWC-O/SI）在 Domain-IL 与 Class-IL 上贴住甚至低于 None**（Table 1 第 7–8 页：Domain-IL `92.8/93.1/93.0` vs None `93.1`），仅 Task-IL 部分有效（Drebin SI `90.7`、EMBER EWC `85.9`）——**「参数法失效」不可去掉情景限定**。原文「随预算单调上升」的曲线主语是 **Partial Joint Replay**（**无上限存储**下回放历史池的 1%–50%：`93.0→93.9→94.5→94.7→95.0→95.4`，20% 时距 Joint 仅 1.4%，第 9 页 Fig. 6），**不是 ER**；ER 在 Domain-IL 上只有 `75.9`（Table 1 第 8 页），低于 None 17.2 个百分点。**原文未述每样本复用次数**，也未披露 ER/A-GEM/iCaRL 的绝对缓冲容量。详见笔记 §0、§2、§3、§4、§5。

## 判定单元与实体粒度（2026-08-18 新增）

原件在 `raw/papers/attack-detection/entity-granularity/`。回答「逐流判定与实体（主机、主机对、资产）判定有何区别」。

- **[[entity-granularity/2012-Dainotti-流量分类的流对象粒度与开放问题|Dainotti 2012：流对象粒度五级划分]]** — 把「流对象粒度」列为使不同方法无法系统比较的方法论差异，给出 TCP 连接、流、双向流、服务（IP-端口对）、主机五级；并指出基于双向流的方法不能原样搬到单向流，因为分类特征会变。判定单元术语的规范出处。
- **[[entity-granularity/2024-Li-端到端对比学习入侵检测的IP对粒度|Li 2024：IP 对（主机对）作为检测对象]]** — 把 Dainotti 的主机粒度细化为「通信双方 IP 对」，理由是 IP 对含多个会话因而能表达流间特征；PortScan 与 DoS 的**流内特征接近正常流量，流间特征才显异常**（每条流都是 SYN→ACK/RST，IP 对粒度上则是短时大量连续 SYN）。论文自述 IP 对是流与会话粒度的补充而非替代。
- **[[entity-granularity/2023-Garcia-网络安全数据集标注流程与流到IP的判定转换|Garcia 2023：流→IP 的判定转换与两套指标（预印本）]]** — 明确指出多数方法判定流、多数防护手段按 IP/域名封禁，因此必须做流到 IP 的转换；同一攻击的多条流告警还须合成为一条高层告警，与告警疲劳直接相关。**同时警告流级指标与 IP 级指标不可互推**，给出算例：流层面 TPR 60%、FPR 10% 的检测器在 IP 层面仍可计为正确检出。arXiv 预印本，无同行评议出处。
