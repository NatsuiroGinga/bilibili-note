# 恶意软件分类模型的概念漂移检测与自适应重训

> Berruz Chungata、Jureček、Potika、Andreopoulos、Stamp，2026-08-14 · arXiv 2608.13465v1 · 39 页 · San Jose State University ＋ 布拉格捷克理工大学 · SHA-256 `851ff060009a02077d9e445218897282c16826e4ad8ad0a333e6222e8f3b31bb`

## 证据等级

**E3 全文级**。原件已下载（HTTP 200，778,879 字节），39 页读完（§1–§5 正文 33 页＋参考文献；附录图 14–19 为分家族条形图与小提琴图，文本层无数值）。

**一条必须随引用披露的方法学缺陷**（见 §3.3.1 与下文「与本课题的关系」）：全篇的分类器超参数**在测试集上调优**，作者自己写明这是 oracle 式上界而非真实部署流程。因此本篇的绝对精度不可作为基线数字，只有**三种场景之间的相对关系**可引。

## 一句话

把「漂移应对」问题重述为一个二目标权衡：在不看模型性能、只看数据分布的前提下判断何时重训，用帕累托前沿在「精度相对静态基线的增量」与「省下的重训次数」之间取折中；实测三种无监督检测器都能逼近周期重训的精度，其中 OCSVM 综合最优。

## 背景：问题的演进（§1、§2.1、§2.2）

漂移分类（引 Bayram et al. 2022, KBS 245:108632）分四类：**数据分布式、性能式、混合式、上下文式**。论文指出性能式方法通常被认为更可靠（因为它直接盯着模型表现变差的地方），但它**依赖可测量的性能指标（准确率、精确率、召回率、F1）**；而在恶意软件分类的真实部署中这类信息一般缺失。因此本文只走**数据分布式**路线——检测器直接分析数据，不依赖任何模型性能度量（§2.1 末）。

§2.2 定位相关工作：`[31]` 从控制流图学所谓漂移不变特征；`[1]` 即 MORPH（NDSS 2024）用伪标签做神经网络漂移适应；`[25]` DREAM 是半监督漂移检测增强。作者的差异化理由是「使用更快、更简单、更易实现的无监督机器学习技术」，方法论承自 `[36]`。

§2.2 还区分了两个易混概念：**恶意软件演化研究**关心变化本身，**概念漂移研究**关心这些变化如何影响机器学习模型性能。

## 方法核心

### 三种漂移检测器（§2.3、§3.2.2）

**MK-Means（Minibatch K-Means，§2.3.1）**：目标仍是最小化簇内平方和

```
argmin_{S_1..S_K} Σ_{i=1}^{K} Σ_{x∈S_i} ||x − µ_i||²
```

用轮廓系数衡量聚类质量：

```
s(i) = ( b(i) − a(i) ) / max( a(i), b(i) )        簇内合理时 s(i) = 1 − a(i)/b(i)
s = (1/n) Σ s(i)
```

漂移判据：令 `ℬ0 = {B_0, B_1}`、`ℬ1 = {B_1, B_2}`，分别聚类得平均轮廓系数 `s_0`、`s_1`；若 `|s_1 − s_0| > 𝒯_mk-means` 则判定批 `B_1` 处发生漂移，随后对连续批对重复。

**OCSVM（§2.3.2）**：论文**自称首次把 OCSVM 用于概念漂移检测**（"As far as the authors are aware, this is the first time that OCSVM has been used for concept drift detection"）。正则参数 `ν ∈ (0,1)` 限定训练数据中被视为离群的比例上界。定义

```
r = n_outliers / n_inliers        式 (1)
```

判据：在 `B_0` 上训 OCSVM 得 `r_0`，**复用同一模型**在 `B_1` 上算 `r_1`；若 `|r_1 − r_0| > 𝒯_ocsvm` 判定漂移。**检出漂移才在 `B_1` 上重训 OCSVM**，未检出则不重训——这是它比另两者省时的直接原因（§4.5）。

**MMD（§2.3.3）**：核方法两样本检验，检验 `H_0: p(x) = q(x')` 对 `H_A: p(x) ≠ q(x')`。

```
MMD(ℋ, p, q) = ||µ_p − µ_q||_ℋ

MMD² = (1/n²) Σ_{i≠j} k(x_i,x_j) − (2/nm) Σ_i Σ_j k(x_i,x'_j) + (1/m²) Σ_{i≠j} k(x'_i,x'_j)
```

高斯核 `k(x,x̃) = e^{−||x−x̃||²/σ}`，`σ` 取所有点对距离的中位数。用置换检验算 `p` 值；`p ≤ 𝒯_mmd = α` 判为漂移。实现用 Alibi Detect。判据是 `B_ref = B_{i−1}` 与 `B_new = B_i` 的两样本检验。

### 三个场景与效率定义（§3.2.4–§3.2.7）

```
A_static   = Σ_i M_0(D_i^test)      / Σ_i |D_i^test|         式 (2)   只训第 0 批
A_periodic = Σ_i M_i(D_i^test)      / Σ_i |D_i^test|         式 (3)   每批都重训
A_drift    = Σ_j Σ_{k=i_j+1}^{i_{j+1}} M_{i_j+1}(D_k^test) / Σ_i |D_i^test|   式 (4)
```

效率定义（`ℓ` 为检出的漂移点数，`N` 为批数）：

```
ℰ = 1 − ℓ/(N−2)   （MK-Means，因用批对，可能漂移点少一个）
ℰ = 1 − ℓ/(N−1)   （其他）                                    式 (5)
```

即**效率就是省下的重训比例**，static 恒为 1，periodic 最差。

### 帕累托前沿（§3.4、§3.5）

二目标为 `(Δ_drift, ℰ)`，其中 `Δ_drift = A_drift − A_static`（用增量而非绝对值，因为优化目标是相对静态基线的改进）。用 Paretoset 包的 Skyline Query 算子求非支配集。

由于检测器超参有整片网格，论文定义了四种汇总精度：全网格平均 `𝒜_drift`、两种帕累托限定平均 `𝒜^{x*}_drift` 与 `𝒜^{y*}_drift`（求和次序不可交换，故两者一般不等）、以及**代表性「中位」点 `𝒜^{m*}_drift`**。中位点定义（§3.5.4）：取帕累托前沿上 ΔAccuracy 最小点 `(x_min,y_min)` 与最大点 `(x_max,y_max)`，令 `x_a=(x_min+x_max)/2`、`y_a=(y_min+y_max)/2`，作过原点直线 `y = (y_a/x_a)x`（式 13），取前沿上距该直线最近的点。论文强调 `𝒜^{m*}` 与 `ℰ^{m*}` 最贴近真实选参情形，比较时以它为准。

## 数据集与实验设置（§3.1、§3.3、§3.6）

- **数据集**：KronoDroid（Guerra-Manzanares 等），含 `41,382` 个 Android 恶意样本、`240` 个家族；**只用 real 样本，不用 emulated**。每样本 `200` 个静态特征（权限、意图、软硬件需求）＋ `289` 个动态特征（系统调用）＝ `489`。
- **时间戳**：原论文称有 4 个时间戳，但 GitHub 发布版只有 `EarliestModDate` 与 `HighestModDate`；本文用 `HighestModDate`（无效样本最少）。
- **预处理**：用 Polars 去掉全部非数值特征，剩 **`470` 维**；只保留 `MM/DD/YYYY` 格式且年份在 `2000`–`2025` 的样本。
- **家族与批（表 1，精确抄录）**：

| 家族 | 样本数 | 批数 | 最早日期 | 最晚日期 |
| --- | --- | --- | --- | --- |
| Agent | 2,826 | 56 | 2008-02-28 | 2020-07-17 |
| Airpush | 7,760 | 155 | 2008-02-29 | 2018-06-15 |
| Boxer | 3,597 | 71 | 2005-01-01 | 2018-06-15 |
| Malap | 4,018 | 80 | 2008-02-29 | 2020-11-11 |
| SMSreg | 4,989 | 99 | 2008-02-29 | 2020-11-09 |
| **合计** | **23,190** | **461** | 2005 | 2020 |

- **任务构造**：二分类，`F_d`（漂移家族）对 `F_c`（对照家族），五家族两两组合得 `|ℱ| = 20` 对。
- **批切分**：批大小 `b = 50`，每批前 `t = 30` 训练、后 `20` 测试。作者说明批越小越早发现漂移但方差越大；小规模测试显示 `b` 更大无显著改善、更小则方差不利。
- **实验规模**：`80` 静态 ＋ `80` 周期 ＋ `240` 漂移感知（每个检测器 80）＝ **`400` 个实验**。
- **超参搜索**：Optuna TPE，每模型 `100` trials；组合数 `4 · 4 · 461 = 7,376`，总计 `100 · 7,376 = 737,600`。分类器搜索空间（表 2）：SVM `c ∈ (e^{-4}, e^4)`、核固定 rbf；RF `n_estimators ∈ (10,500)`、`max_depth ∈ (5,100)`；XGB `n_estimators ∈ (10,300)`、`max_depth ∈ (5,15)`、`learning_rate ∈ {0.01,0.05,0.1,0.2,0.3}`；MLP `n_units ∈ (8,256)`、激活 `{relu,tanh,logistic}`、优化器 `{adam,sgd}`。
- **检测器网格（表 3）**：MK-Means `clusters ∈ {2,4,6,8}` × `𝒯 ∈ {0.01,…,0.6}` = `4·60 = 240`；OCSVM `ν ∈ {0.1,…,0.9}` × `𝒯 ∈ {0.01,…,0.6}` = `9·60 = 540`；MMD `α ∈ {0.001,…,0.1}` = `100`。Step 4 共运行 `4 · 20 · (540+240+100) = 70,400` 次。
- **可复现性**：全部随机种子固定为 `420`；**全 CPU 运行，未使用 GPU**；Optuna trial 信息存 Docker 内 PostgreSQL，最佳模型存 `.pkl`。

## 主要数字结果（§4，精确抄录）

### 静态与周期基线（图 1，各模型在 20 组家族对上的平均准确率）

| 模型 | Static | Periodic |
| --- | --- | --- |
| MLP | 0.8248 | **0.9666** |
| RF | 0.8152 | 0.9529 |
| SVM | **0.8416** | 0.9500 |
| XGB | 0.7578 | 0.9334 |

**静态场景最好的 `0.8416`（SVM）低于周期场景最差的 `0.9334`（XGB）**——这是论文用来论证「必须应对漂移」的核心对比。另注：静态场景下 SVM 在 `8/20 = 40%` 的家族组合上最优，MLP 与 RF 各 `25%`，XGB 占余下 `10%`；但在周期场景下 MLP 在 `65%` 的组合上最优，SVM `25%`、RF `10%`，XGB 只在 1 组最优。

### 三种检测器在 MLP 上的中位帕累托结果（§4.2–§4.4，原文算式）

| 检测器 | `𝒜^{m*}_drift`(MLP) | 相对 static 提升 | 距 periodic 差距 | `ℰ^{m*}`(MLP) | 全网格平均效率 |
| --- | --- | --- | --- | --- | --- |
| MK-Means | 0.9480 | `(0.9480−0.8248)/0.8248 = 14.94%` | `(0.9666−0.9480)/0.9666 = 1.92%` | > 58% | > 80% |
| **OCSVM** | **0.9486** | `15.01%` | **`1.86%`** | **> 65%** | > 77% |
| MMD | 0.9380 | `13.72%` | `2.96%` | > 69% | > 64% |

OCSVM 各模型的其他中位精度（图 7）：RF `0.9434`、SVM `0.9368`、XGB `0.8888`；MMD 对应（图 10）：RF `0.9240`、SVM `0.9166`、XGB `0.8831`。

### 三者的差异结构（§4.4 末、§4.5）

- 对 MK-Means 与 OCSVM，把超参限制到帕累托前沿后**平均效率明显下降**，说明二者有大量超参取值根本检不出漂移；而 MMD 的效率在限不限制前沿下都很一致（`ℰ` 四个口径都在 `0.64`–`0.70` 区间）。论文据此建议**可以显著缩小 MK-Means 与 OCSVM 的超参搜索空间**。
- **检测器自身耗时**（图 13，每组 `(F_d,F_c)`）：**OCSVM 用时最少且优势明显，MK-Means 用时最多且劣势明显**，MMD 居中；MK-Means 的最大值达 `7.71` 秒。根本原因是 **OCSVM 只在检出漂移时才重训自己，而 MK-Means 与 MMD 每批都必须更新**。
- 综合结论（§4.5、§5）：OCSVM 在多数指标上优于 MK-Means 与 MMD，是三者中最优选择；效率上 OCSVM 与 MMD 几乎相同；MK-Means 在精度、效率、耗时三方面普遍最差。作者对「机器学习方法（OCSVM）胜过统计方法（MMD）」的解释是：MMD 对底层统计变化更敏感，而 OCSVM 更善于只检出**真正会影响机器学习模型的那些变化**。

## 与本课题的关系

### ① 它的漂移应对机制放在哪一层？

**训练流程层。** 全部三种检测器输出的都是同一个决策：**这一批要不要触发重训**。模型结构、特征表示、打分方式与告警阈值都不变；变的只有「模型生命周期中重训发生在哪些时刻」。

需要区分清楚的一点：检测器计算的是数据侧统计量（离群内点比、轮廓系数、核均值差），形式上像「决策层统计量」，但它的**决策对象是重训调度，不是样本是否告警**。因此不能把它归到决策层。

### ② 对「实体级聚合在训练层＋因果前缀统计量在决策层」是支持、矛盾还是无关？

**整体正交；但含一条可引用的正面论证与一条必须避开的方法学反例。**

**正交的依据**：Android APK 样本之间无实体归属，无实体级聚合；批内不做任何时序建模，`B_i` 内部 30 训 20 测的划分只是批内切分，不是因果前缀；重训后模型对整批测试样本一视同仁。两个机制维度均为空。

**可引用的正面论证（§2.1）**：论文明确论证「在恶意软件域，性能式漂移检测不可用，因为可靠的性能指标一般拿不到，只能用直接分析数据的分布式方法」。本课题在决策层使用**因果前缀统计量**（一种纯数据侧、可在线计算、不需要标签的量）与这一论证方向一致，可作为「为什么决策层的量必须是无标签可算量」的文献依据。注意这只是**方法选择的合理性依据**，不能被当作本课题机制有效的证据。

**必须避开的方法学反例（§3.3.1，本篇对本课题最有价值的一段）**：论文承认，因样本量小而无法留出独立验证集，于是**直接在测试集上调超参**，并写明：

> 「测试集调参是有意为之，可以理解为性能的 oracle 式上界，而非真实部署流程。」

其自辩是三个场景（static / periodic / drift-aware）都用同样方式调参，因此漂移感知场景的精度变化仍可归因于漂移检测机制。这个自辩对**场景间相对比较**成立，对**绝对数字**不成立。

对本课题的直接后果：

1. 本篇的 `0.8248 / 0.9666 / 0.9486` 等绝对准确率**不得**作为本课题的基线参照或效果量级对标。
2. 可以引用的只有其**相对结论**：漂移感知重训能逼近周期重训（差距 `1.86%`–`2.96%`），同时省下 `58%`–`69%` 的重训次数。
3. 本课题的最终测试隔离规则（根 `AGENTS.md`「不得看过最终测试后选择数据、字段、候选、超参数或门槛」）正是为了避免这一情形。**本篇可作为负面对照写进方法学论述**：即便作者主动披露，测试集调参仍使绝对数字失去部署意义。

**一条可借鉴的评价设计**：本篇用**帕累托前沿在「精度增量」与「资源效率」二维上选点**，并定义了一个可复现的「中位」代表点（式 13）以避免只挑最好点。本课题 X4 已在用帕累托前沿做共同预算裁决（N-16 的「目标年共同首次告警子向量上保持非支配」），本篇提供了同一做法在漂移文献中的独立先例，可在第三章方法学处引用为设计依据，而非效果依据。

## 疑问 / 待验证

- OCSVM 检出漂移才重训自己，这带来两个耦合效应：耗时优势（§4.5 已量化）与**参考点自我漂移**（`r_0` 的参考批随检出结果变化）。后者未被消融，若阈值过高导致长期不重训，参考点会持续陈旧。
- 批大小固定 `b = 50`，作者在 §5 承认应探索更小的可行窗口，并提出用 LSTM 作漂移检测器以动态学习最优窗口。
- 全部实验是**家族对家族的二分类**（`F_d` vs `F_c`），不是恶意 vs 良性检测。这与真实恶意软件检测任务不同，论文未讨论该代理任务与真实任务的差距。
- 附录图 14–19（分家族条形图、小提琴图）在 PDF 文本层无数值，无法核验分家族细节。
