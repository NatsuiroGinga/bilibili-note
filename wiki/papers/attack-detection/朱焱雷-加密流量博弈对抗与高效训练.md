## 贡献 1：DS-RGO（Ch3）——动态难度调度 + 二阶反应梯度

### 威胁建模：Stackelberg 主从博弈
- 防御者=Leader（先部署模型 θ），攻击者=Follower（观测 θ 后设计扰动 δ）——**防御者有先发优势**，区别于传统 Min-Max 的纳什均衡。
- 双层优化：外层 min_θ E[L(f(x+δ*(θ)),y)]，内层 δ*=argmax L(f(x+δ),y)。δ*(θ) 是 θ 的隐函数。

### DS 模块：三维课程难度调度（由弱到强平滑过渡）
1. **扰动半径 ε(t)**：热身阶段线性增长（ε≈0，近似良性样本，先学显性特征）→ 强化阶段达 ε_max（强伪装，逼学深层抗扰特征）。
2. **攻击步数 K(t)**：阶梯式——初期 K=1（≈FGSM，廉价正则，快更新）→ 后期 K=K_max（多步精细攻击，含二阶信息）。
3. **攻击步长 α(t)=ε(t)/K(t)**：自适应缩放。
- 效果：把非凸优化转为**难度递增子问题序列**，平滑损失曲面，解大模型对抗训练梯度爆炸。**这正是开题"在线课程采样"的同类机制，但调度的是对抗强度而非样本难度。**

### RGO 模块：二阶反应梯度（展开优化）
- 传统对抗训练用 Danskin 近似，把 δ* 当常数，只算**直接梯度** ∂L/∂θ，丢失二阶交互。
- DS-RGO 用展开优化算**全导数 = 直接梯度 + 间接(反应)梯度** (∂L/∂δ*·dδ*/dθ)——捕捉"θ 微变如何诱导攻击者改变策略"，这是抗逃逸预判的关键。
- 理论(3.5)：课程平滑非凸曲面 + Stackelberg 均衡收敛 + 平坦极小值→泛化。

## 贡献 2：DF-ACR（Ch4）——动态流过滤 + 自适应缓存复用

### DF 模块（空间维）：动态重要性过滤
- **双维度重要性评分** $S(x)=\gamma\cdot\hat S_{loss}+(1-\gamma)\cdot\hat S_{grad}$（归一化加权和，γ≈0.5）：
  - $S_{loss}$=分类损失（**难易度**，置信度低→难样本）
  - $S_{grad}$=输入梯度范数 ‖∇_h L‖₂（**鲁棒敏感度**，决策边界近→微扰即误判）
- 按动态阈值 Top-k 划分 **关键集 D_crit / 冗余集 D_redund**。
- 两种模式：**软过滤**（冗余样本跳过对抗攻击、保留干净训练，防遗忘）/**硬过滤**（物理剔除，I/O+浮点双重加速）。
- 前紧后松：初期多数样本关键（全量训练）→ 后期多数冗余（稀疏训练），契合"先简后难"。

### ACR 模块（时间维）：扰动缓存复用
- **慢变性假设**：训练中后期 θ 更新步长小 → 最优扰动 δ* 时间连续 → 上一轮扰动对当前轮仍是好近似。
- 外部记忆库 M（键值对 id→δ_cache），更新周期 T_c：t%T_c==0 才重算 PGD-K（Update），否则读缓存跳过 PGD（Reuse）。
- 变长序列静态存储+动态对齐（ET-BERT padding 适配）。
- 结果：**4.6× 端到端加速，复杂度降 78%**，峰值显存显著降。

## 关键启示

1. **"双维度难度"有同门先例**：DF-ACR 的 S(x)=loss+梯度范数 正是开题"物理残差+决策方差"双维度的同构实现，且 4.2-8.6% 鲁棒性提升是可比量级。开题创新点2 的双维度公式有直接参照。
2. **课程调度的"调度对象"可迁移**：朱调度对抗强度（ε/K/α），开题调度样本难度（残差/方差权重）——机制同构。
3. **原型系统四层是现成范本**：同校答辩过的 B/S 四层架构，开题原型章可对照升级。
4. **场景差异要写清**：朱=加密流量分类+对抗防御（抗逃逸）；开题=网络攻击检测+PINN 物理信息。迁移方法学（课程+双维度+高效训练+博弈），非场景。

## 局限 / 疑问

- 朱用 Stackelberg 博弈，开题用 GRPO——都是 RL/优化框架，反应梯度能否并入 GRPO 优势函数待研究。
- 朱无 PINN/物理信息——开题的物理约束是本文没有的增量。
- 数据集（ET-BERT/CNN on 加密流量 ISCXVPN/USTC 等）与 IDS2018 不同，迁移时注意特征空间差异。
- DS-RGO 的展开优化计算开销大，DF-ACR 正是为此设计——若开题用 GRPO（无展开优化），可能不需要 DF-ACR 的全部复杂度。
