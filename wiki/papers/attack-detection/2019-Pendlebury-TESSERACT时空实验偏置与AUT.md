# TESSERACT：跨空间与时间消除恶意软件分类的实验偏置

## 一句话

论文把“评价设置本身”当成研究对象：只要训练集含有未来知识（时间偏置）或测试集恶意占比不真实（空间偏置），报告出的 F1 就会被系统性抬高；作者给出三条可执行约束（C1–C3）、一个时间感知指标 AUT，以及一个只用训练信息调整训练正例比例的调参算法。

## 数据与设置（页级证据）

- 数据集来自 AndroZoo，最终 129,728 个 Android 应用（116,993 良性 + 12,735 恶意），时间跨度 2014-01 至 2016-12，月度恶意占比控制在 8%–12%，整体均值 10%（第 3 页正文与图 1 说明）。
- 良恶标签阈值：VirusTotal 报毒数 `p = 0` 记为良性、`p ≥ 4` 记为恶意，`0 < p < 4` 的约 13% 灰件被排除（第 3 页）。
- 所有时间感知实验统一为“训练 2014、测试 2015–2016”（第 3 页图 1 说明、第 4 页）。
- 被测算法：ALG1 = 线性 SVM 静态特征（Drebin 系），ALG2 = 随机森林 + API 马尔可夫链（MaMaDroid 系），DL = 与 ALG1 同输入特征的深度网络（第 2 页 2.1 节）。

## 核心方法

### 三条约束（第 6 页 4.1 节）

- **C1 训练时间一致性**：`time(s_i) < time(s_j), ∀ s_i ∈ Tr, ∀ s_j ∈ Ts`（式 1）。违反即把未来知识注入训练。
- **C2 良/恶时间窗一致性**：同一测试时隙内所有样本必须来自同一时间窗（式 2）。作者指出 ALG2 的原始设置违反此条——良性与恶意来自不同时期，模型可能学到“区分年代”而非“区分善恶”，例如靠新 API 方法这类伪特征（第 4 页第三行实验、第 6 页）。
- **C3 测试集真实恶意占比**：`δ ≈ σ̂`（式 3），Android 场景取 `σ̂ ≈ 10%`（第 2–3 页 2.2 节，来源含 AndRadar 约 8%、Google 2017 报告 6–10%、AndroZoo 元数据 18.8%）。

### AUT 指标（第 7 页式 4）

`AUT(f, N) = 1/(N-1) · Σ_{k=1}^{N-1} [f(x_{k+1}) + f(x_k)] / 2`，即性能-时间曲线下的梯形面积，归一化到 `[0,1]`，完美抗漂移分类器 AUT = 1。默认用逐时隙点估计而非累计估计；用累计估计时须显式记为 `AUT_cml`（第 7 页）。

### 训练比例调参（第 8 页算法 1）

在训练集内部再切出时间靠后的验证集（同样满足 C1–C3），网格搜索训练恶意占比 `ϕ ∈ [σ̂, 0.5]`，以 AUT 为目标、以 `E ≤ E_max` 为约束。**不使用任何测试信息**，最优 `ϕ*` 只由 1 年训练数据中的 4 个月验证集选出（第 10 页图 6 说明）。

## 反直觉结论（第 9–10 页）

- 在有偏设置下 ALG2 看起来最好（原论文报 99% F1，对应 86% 恶意占比 + 10 折 CV，第 4 页）；施加 C3 后 DL 与 ALG1 看起来接近；再施加 C1+C2 后，**DL 才是最抗时间衰减的那个**（第 9–10 页）。
- 作者明确不宣称深度学习普遍更抗漂移，只说在这个具体设置下 TESSERACT 揭示了这一点，代价是可解释性更低、训练更慢（第 10 页）。
- 调参算法的收益取决于 `ϕ*` 是否远离 `σ̂`：ALG1 的 `ϕ* ≈ 15%` 接近 10%，收益小；ALG2 的 `ϕ* ≈ 50%` 远离 10%，收益显著（第 12 页）。

## 与本课题（LSPR23→LSPR24 跨年度零样本迁移）的关系

**可直接支撑的三点**：

1. **属于“分布漂移下模型退化的受控测量”的范式源头**。本课题的 LSPR23→LSPR24 划分天然满足 C1（训练严格早于测试）；C2 提醒我们检查 LSPR23 与 LSPR24 的良性流与恶意流是否来自同一采集窗口——若两年的良性背景流量来自不同采集条件，模型可能在学“年份指纹”而非“恶意行为”，这会同时抬高同年基线并压低跨年迁移，与今晚观察到的“同年天花板高、跨年 AP 低”现象方向一致（**此为本课题推论，尚未用 LSPR 数据验证**）。
2. **C3 与 AP 指标选择直接相关**。论文证明测试集正例比例被人为抬高会同时抬高 Precision 与 F1，而 Recall 不变（第 5–6 页图 2 的机制推导）。本课题报告的逐流 AP（XGBoost 0.2244、MLP 0.1590）与实体级 AP（0.5233–0.5475）之所以差距巨大，**部分来自正例基率的改变**（实体级聚合把 2-IP 无向对作为样本单位，正例比例与逐流不同）。因此两级 AP 不能直接相互比较，报告时必须同时给出各自的正例基率——这是本论文的直接方法学推论。
3. **AUT 是可移植的汇报格式**。如果后续把 LSPR24 按月或按周切成多个测试时隙，可用 AUT(AP, N) 或 AUT(DR@4%FPR, N) 汇总一条曲线为一个数，用于比较“逐流 XGBoost / 因果前缀均值 / RWKV-7 完整状态”三条路线的抗漂移能力，而不是只报全量单点 AP。

**关于“简单聚合胜过复杂序列模型”**：本文**不是**直接先例。它比较的是 SVM / RF / DL 三类模型的抗漂移性，结论是 DL 更稳（第 9–10 页），方向上与本课题“RWKV-7 完整状态递归反而更差”相反。引用时不得把 TESSERACT 当作“复杂模型更差”的证据。

**关于“决策层聚合成功”**：论文第 11 页表 3 的拒识与主动学习属于决策层缓解手段，且都需要额外的标注成本 L 或隔离成本 Q。它证明了“决策层机制能显著抬升 AUT”（ALG1 0.577 → 0.717 仅靠拒识，无标注成本但 Q = 10,283），可作为本课题实体级聚合（决策层）优于逐流表示改造的**类比背景**，但不是同一机制——本课题的实体级聚合不消耗任何标注或隔离预算。这一区别必须写清楚。

## 局限（论文自述，第 12–13 页）

- 方法论通用但需要域特定参数：时间粒度 `Δ`、测试时长、真实恶意占比 `σ̂`。经验法则是每个时隙至少 1000 个样本，本文因此选月粒度。
- 只在 Android 域验证；推广到 Windows 恶意软件、代码漏洞等域“需要进一步实验才能得出科学结论”（第 13 页）。
- 假设数据集标签正确；依赖 AndroZoo 时间戳的正确性，作者呼吁社区向数据集维护者报告日期不一致。
- 对抗性机器学习不在范围内（第 13 页起）。
