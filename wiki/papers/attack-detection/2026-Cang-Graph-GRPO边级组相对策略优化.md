# Graph-GRPO：边级组相对策略优化

> 页码锚点：本地 PDF 共 10 页。方法总览见 §3（p.3）；组采样见 §3.2.1（**p.5**）；边际成功率见 §3.2.2（**p.5**）；相对优势与目标见 §3.2.3（**p.5**）；推理见 §3.3（p.6）；主结果 Table 1 与消融 Table 2 见 §4.2–§4.3（**p.6–7**）。

## 一句话

这是"**GRPO 的组相对优势可以直接搬到多智能体系统**"的一篇明确先例，且它给出了一个对本课题有价值的**消融级证据**：把信用分配的粒度从整图降到逐边，同一机制的收益从"被平均掉"变成"可测的 +1.82%"。

## 与 P4 的距离（通用 MARL 方法论文，不属安全域四级表）

| 层级 | 学习关系 | 典型 |
| --- | --- | --- |
| 1 | 固定/算法攻击 + 学习检测器 | CharBot / MaskDGA / Drichel |
| 2 | 学习型攻击者 + 固定目标检测器 | MAB-Malware |
| 3 | 学习型攻击者 + 学习 surrogate | MalGAN / IDSGAN |
| 4 | attacker + 实际 defender 共演化 | RELEVAGAN / 2026 bilevel |

**本文不属四级表任何一层**：它是 LLM 多智能体**推理任务**的方法论文（MMLU/GSM8K/HumanEval 等），没有攻击者—防守者结构。它在 report (8) 中的角色是 **"GRPO × MARL 不能声称新"的锚点**——即"多智能体 + 组相对优势"这一组合在 2026 年已有发表工作，**本课题不得把"把 GRPO 用到多智能体"本身作为创新主张**。

## 机制（§3.2，p.4–5）

**问题动机**（p.4）：标准策略梯度给图里**所有边**分配同一个奖励，形成粗粒度反馈——成功图里的冗余边被错误强化，失败图里的关键边被错误惩罚。

**算法 1**（p.5）：每个 epoch / 每个 batch：算概率矩阵 $P_\theta$ → **采样一组 K 个拓扑** → 每个拓扑用 LLM 智能体执行得奖励 $\{r_1,\dots,r_K\}$ → 对该组内每条唯一现存边算条件成功率 $S_{ij}$ → 由全体 $\{S_{ij}\}$ 得组均值 $\mu_S$、组标准差 $\sigma_S$ → 算优势 $A_{ij}$ → 最小化 $\mathcal{L}(\theta)$ 更新。

**组采样**（§3.2.1，式(3)，p.5）：边的存在性由以预测概率为参数的**独立 Bernoulli 采样**决定，把连续概率矩阵变成离散图结构；随机性使同一组内能探索不同连接模式，**从而用组自身统计量构造局部基线**。

**边际成功率**（§3.2.2，式(4)，p.5）：

$$S_{ij} = \frac{\sum_{k=1}^{K}\mathbb{I}((i,j)\in\mathcal{G}_k)\cdot r_k}{\sum_{k=1}^{K}\mathbb{I}((i,j)\in\mathcal{G}_k)+\epsilon}$$

即 $P(\text{Success}\mid e_{ij}\in\mathcal{G})$ 的经验估计；高 $S_{ij}$ 是关键通路，随机 $S_{ij}$ 约等于组平均。

**相对优势**（§3.2.3，式(5)，p.5）：$A_{ij} = (S_{ij}-\mu_S)/(\sigma_S+\epsilon)$，其中 $\mu_S,\sigma_S$ 取自**当前组内所有活跃边**的得分。**只对高于组平均的边给正强化。**

**目标**（式(6)，p.5）：$-\frac{1}{|\mathcal{E}_{batch}|}\sum (-A_{ij}\log\pi_\theta(e_{ij}|\mathcal{Q}) + \beta D_{KL}(\pi_\theta||\pi_{ref}))$；$\pi_{ref}$ 为冻结的 SFT 参数，KL 项用于防止偏离初始分布与 reward hacking。

**推理**（§3.3，式(7)，p.6）：硬阈值 $\tau=0.5$ 出确定拓扑。

## 实验结果（§4，p.6–7）

- **主结果**（Table 1，p.6）：六个基准平均准确率 **92.45%**，超过前 SOTA EIB-LEARNER（91.38%）**1.07 个百分点**；GSM8K +0.9%、HumanEval +2.1%（p.6）。固定拓扑平均约 84%，Complete Graph（82.16%）**低于**更简单的结构，作者称为"信息过载与噪声传播"。
- **消融（本笔记最看重的一条）**（Table 2，§4.3，p.7）：**边级 vs 整图级**，平均 **+1.82%**（MMLU −1.58、GSM8K −1.70、HumanEval −2.18，为整图级相对边级的下降）。作者解释：整图级奖励会强化成功拓扑中的"搭便车"边，长期导致更稠密、更嘈杂的图。
- 超参（§4.1，p.6）：组大小 K=16，GPT-3.5-Turbo 为骨干，智能体数 N=6/5/4，最多 3 轮通信，Adam lr=1e-4。

## 非平稳性处理方式

**本文不处理对抗性非平稳**——其"组"是**同一策略在同一个 query 下的多样本**，不是对手种群；没有对手建模、没有 replay、没有种群。其"稳定性"主张指的是**训练稳定性与信用分配噪声**，不是对手变化带来的非平稳。**这一点必须在引用时说清，不可与双侧博弈的 non-stationarity 混为一谈。**

## 可迁移机制

1. **组相对优势的"组"可以不是轨迹组**（§3.2.1，p.5）：本文的组是"同一输入下采样的 K 个结构"，优势来自组内统计——**这与把"同一样本下的 K 个扰动变体"作为组是同构的**，为单步离散扰动场景提供了直接的形式对应。
2. **信用分配粒度决定弱信号能否显形**（§4.3，Table 2，p.7）：同一目标、同一数据，只把归因从整图降到逐边，就得到 **+1.82%** 的可测差异。**这是"弱增量在粗粒度上被平均掉、在细粒度上可见"的直接先例**，对"组相对增量在小病灶上是否可测"这一疑问有方法论参考价值（但不构成对本课题增量的预测）。
3. **条件成功率是无 critic 的信用估计器**（式(4)，p.5）：用"该元素出现条件下的经验成功率"替代价值函数，**不训练 critic**，且天然给出每个元素的边际贡献。
4. **整组均匀奖励会强化"搭便车"元素**（§4.3，p.7）：反过来说明**若对一组扰动变体给统一奖励，冗余/无关的改动会被一起强化**——这是在离散扰动场景设计组相对权重时应当规避的失败模式。
5. **KL 项用于防偏离与防 reward hacking**（式(6)，p.5）：与 GRPO 原式一致，可作为"训练动态受控"的实现参考。

## 不能直接声称内容

- **不能把它算作 P4 的近邻**：任务域是 LLM 多智能体推理，无攻击者—防守者结构。
- **不能把 +1.82% 当作本课题的预期增益**：其任务、指标（准确率）、粒度（边 vs 图）与本课题完全不同。
- **不能声称它解决了 MARL 非平稳性**：它处理的是信用分配噪声与训练稳定性，**不是对手策略随训练变化**。
- **不能把它当作"组相对优势用于安全对抗"的先例**：全文无安全任务、无对抗样本、无 DGA。
- **它是 2026 年的预印本**，证据权重低于已正式发表的同类方法（report (8) 亦明确此点）。
