# EATA：无遗忘的高效测试时适应

> Shuaicheng Niu 等 7 人，2022，ICML 2022（arXiv:2204.02610v2）· 17 页（正文 p.1–9，参考文献 p.10–11，补充材料 p.12–17）· 原件 `raw/papers/attack-detection/2022-Niu-EATA-Efficient-Test-Time-Model-Adaptation-Without-Forgetting.pdf`

## 一句话

测试时适应有两个独立代价：**效率**（每个样本都要反向传播）与**遗忘**（适应到分布外数据后，原本分布的样本被判错）；EATA 用「只让部分样本参与更新」处理前者，用「按参数重要性加惩罚」处理后者。

## 背景：问题的演进（§1、§2、§3，p.1–4）

- 已有 TTA 方法（Tent 等）在测试时对整个模型做梯度更新，代价是**每个测试样本一次反向传播**（p.1–2）。
- 同时，在线适应会**破坏原分布（ID）上的性能**——即灾难性遗忘；这在持续/终身适应下尤其严重（p.2、§5.2，p.7）。
- 论文把两者作为同一方法要同时解决的问题，并给出「效率—遗忘」两条独立的度量轴：OOD 错误率、ID 干净准确率、前向/反向传播次数（§5「Evaluation Metrics」，p.6）。

## 方法核心（§4，p.4–5）

### ① 样本高效熵最小化（§4.1，p.4）

**总目标**（式(2)）：`min_Θ̃ S(x)·E(x;Θ) = −S(x) Σ_{y∈C} f_Θ(y|x) log f_Θ(y|x)`，其中熵损失**在一个批上计算**（与 Tent 相同，用于避免「把全部概率押给最可能类」的平凡解）；更新对象是**所有归一化层的仿射参数**。

**先导实验（图 2，p.4）**：把测试样本按熵排序，只用最高熵或最低熵的前 p% 做适应，再在全测试集上评价——**低熵样本的贡献更大，而熵非常高的样本会损害适应**（理由：高熵样本预测不确定，其熵梯度有偏不可靠）。这就是「熵陷阱」的最早实证之一。

**可靠样本识别**（式(3)，p.4）：
`S^ent(x) = 1/exp[E(x;Θ) − E_0] · I_{E(x;Θ) < E_0}(x)`
——高于阈值直接排除；低于阈值的按熵大小加权，熵越低权重越大。该权重的计算**不需要反向传播**。

**不冗余样本识别**（式(4)(5)，p.4）：两个相似且都低熵的样本会产生近似相同的梯度，重复反传是浪费。做法是用**模型输出的指数移动平均**追踪已见样本的输出中心：
`m^t = ȳ^1`（t=1）；`m^t = αȳ^t + (1−α)m^{t−1}`（t>1）…(4)
再算新样本预测与该中心的余弦相似度：`S^div(x) = I_{cos(f_Θ(x), m^{t−1}) < ε}(x)` …(5)

**合成分数**（式(6)，p.4）：`S(x) = S^ent(x) · S^div(x)`，只对 `S(x) > 0` 的样本做反向传播。

**算法 1（p.4）**：逐批执行——算预测 → 按式(6) 算 S(x) → 用式(2) 或式(8) 更新 `Θ̃ ⊆ Θ`。

### ② 抗遗忘的 Fisher 正则（§4.2，p.5）

**正则项**（式(7)，p.5）：`R(Θ̃, Θ̃^o) = Σ_{θ_i ∈ Θ̃} ω(θ_i)(θ_i − θ_i^o)²`——对分布内重要参数施加二次惩罚（风格同 EWC）。

**最终目标**（式(8)，p.5）：`min_Θ̃ S(x)E(x;Θ) + βR(Θ̃, Θ̃^o)`，β 是权衡系数；作者强调该正则只改损失、**不增加额外计算开销**。

**重要性 ω 的估计**（式(9)，p.5）：无法取得带标签的训练数据，因此**先收集一小组无标签 ID 样本**（可用现成的 OOD 检测技术收集），用**原始训练模型**给它们打硬伪标签 `D_F = {(x_q, ŷ_q)}`，再用对角 Fisher 信息
`ω(θ_i) = (1/Q) Σ_{x_q ∈ D_F} ( ∂/∂θ_i^o · L_CE(f_{Θ^o}(x_q), ŷ_q) )²` …(9)
**只需在适应开始前计算一次**，之后固定并用于任何类型的分布偏移（p.5）。论文称 **500 个样本对 ImageNet-C 已经够用**，不需要太多。

### 超参（§5「Implementation Details」，p.6）

| 项 | 值 |
|---|---|
| 更新规则 | SGD，momentum 0.9 |
| 批大小 | 64 |
| 学习率 | CIFAR-10 0.005／ImageNet 0.00025 |
| **熵阈值 E_0** | **0.4 × ln C**（C 为类别数） |
| 冗余阈值 ε | CIFAR-10 0.4／ImageNet 0.05 |
| Fisher 权衡 β | CIFAR-10 1／ImageNet 2,000（使两项损失量级相当） |
| Fisher 样本数 Q | 2,000（另需 2,000 次额外前向+反向） |
| 移动平均因子 α | 0.1 |

> **跨论文数值冲突（必须登记）**：[[2023-Niu-SAR动态环境稳定测试时适应]] 的附录 C.2（p.19）把 EATA 的熵常数记为 **0.1·ln 1000**，而 EATA 本文（p.6）写的是 **0.4 × ln C**、且其自身消融（图 4(a)，p.8）报告「E_0 落在 [0.4, 0.5] 时表现最好」。两者不一致。**以 EATA 本文为 EATA 的权威取值**；SAR 附录的 0.1 疑为笔误或另一实现配置。复现 EATA 时不得直接采信 SAR 附录的该数字。

## 实验结果

**ImageNet-C（severity 5，ResNet-50，腐蚀误差 %↓，表 2，p.6）**：

| 方法 | 平均腐蚀误差 | 前向次数 | 反向次数 |
|---|---|---|---|
| Base model | — | 50,000 | 0 |
| Tent | 71.6 | 50,000 | 50,000 |
| Tent（episodic，每批后重置） | 85.4 | 100,000 | 50,000 |
| **ETA**（只筛样本，无正则） | **64.9** | 50,000 | **26,031** |
| **EATA** | **65.0** | 50,000 | **25,150** |
| EATA（lifelong，从不重置） | 65.0 | 50,000 | 28,243 |

- 单看高斯噪声一列：Tent 71.6 → ETA 65.0（p.6 正文指标）。
- **ImageNet-R（表 3，p.6）**：Base 63.8 → Tent 57.7 → **ETA 54.5**（反向 14,847）。
- **CIFAR-10-C（表 4，p.6）**：ResNet-26（BN）Base 28.4 → Tent 20.2 → **ETA 19.4**（反向 8,192 对 10,000）。
- **抗遗忘对照（图 3，p.7）**：终身适应下 **Tent 的干净准确率与腐蚀准确率在前三种腐蚀之后就快速下降到 0%**；EATA（lifelong）在整个过程维持腐蚀准确率，且干净准确率接近未适应模型。

**消融（§5.3，p.8）**：

| 设置（ImageNet-C 高斯噪声，ResNet-50） | Level 3 误差／反向 | Level 5 误差／反向 |
|---|---|---|
| 基线 `S(x)=1`（等价 Tent） | 45.3／50,000 | 71.6／50,000 |
| ＋可靠筛选 `S^ent`（式(3)） | 43.0／37,943 | 65.7／26,694 |
| ＋完整 `S(x)`（式(6)） | **42.6／29,051** | **65.0／19,121** |

- **E_0 的敏感性（图 4(a)，p.8）**：在 `{0.20…0.55}×ln 10³` 中扫描，**E_0 落在 [0.4, 0.5] 最好**；太小则筛掉过多样本、学不到东西；太大则让不可靠的高熵样本参与、带来有害梯度。
- **Fisher 样本数 Q 的敏感性（图 4(b)，p.8）**：`Q ≥ 300` 即稳定，OOD 性能与无正则版相当而 ID 干净准确率显著更高。

**更多讨论（§5.4，p.8–9）**：

- **批大小=1 时直接应用 Tent 与 ETA 都会失败**（表 6，p.9：两者准确率均为 0.1%）；用**长度为 L 的滑动窗口**（含先前 L 个样本）即可修复——L=32 时 Tent-wnd 28.1／ETA-wnd 30.8，L=64 时 29.5／32.4。
- **15 种腐蚀混合**（表 7，p.9）：Base 18.0 → Tent **2.3（−15.7，即坍塌）** → **EATA 26.6（+8.6）**。
- **骨干替换**（表 8，p.9）：ResNet-50/101/152 上 EATA 腐蚀准确率 35.0／38.8／40.2，均高于 Tent 的 28.4／32.5／33.7。

## 可迁移机制

1. **按熵阈值筛选参与更新的样本**（式(3)、图 2，p.4）：提供「熵陷阱」的正面证据与最简处置——**高熵样本的熵梯度不可靠，应排除而非降权**。阈值形式 `E_0 = 常数 × ln C` 使该规则可跨类别数迁移。
2. **用输出空间的余弦相似度去冗余**（式(4)(5)，p.4）：只保留「能产生不同梯度」的样本，用**指数移动平均**以 O(1) 状态近似「全部历史输出」，避免存储全部历史。这是一条与熵筛选正交的效率机制。
3. **加权 Fisher 正则实现抗遗忘**（式(7)–(9)，p.5）：在无法访问训练数据时，用一小组无标签 ID 样本＋伪标签估计对角 Fisher 权重，代价是一次性计算，且**正则本身不增加每步计算**。
4. **「效率」与「遗忘」是两条独立轴**（表 2 与图 3，p.6–7）：ETA（无正则）与 EATA 的 OOD 误差几乎相同（64.9 vs 65.0），差别只在 ID 保持。**这提示任何适应机制的评价都应同时报告「目标域获益」与「原域损失」两个方向**——与本课题「适应后 FPR 不得恶化」的判据形式同构。
5. **滑动窗口解决小批量失效**（表 6，p.9）：批大小=1 时熵最小化类方法全崩，用含先前样本的滑窗即可恢复。**这是在线单样本场景的一条低成本修复路径**。
6. **筛选不改变损失函数形式**（式(2)，p.4）：S(x) 只做乘性门控，因此该筛选可与任何以熵为基础的更新规则组合（SAR 就沿用了这一形式，见 [[2023-Niu-SAR动态环境稳定测试时适应]]）。

## 不能直接声称内容

- **不能声称 EATA 的 OOD 性能优于其自身的无正则版**：表 2 中 ETA 64.9 与 EATA 65.0 基本持平，作者的表述是「comparable OOD performance（but prevent the forgetting）」（p.6）。EATA 的增益在 ID 保持与终身稳定性上，不在 OOD 指标上。
- **不能把 `E_0 = 0.4·ln C` 当作已验证的通用常数**：这是 ImageNet（1000 类）上的扫描结果（图 4(a)，p.8），且 [0.4, 0.5] 区间内均可；搬到二分类任务时必须重做源期标定。
- **不能引用「500 个 ID 样本足够」作为通用结论**：该句（p.5）针对 ImageNet-C 而言；正文实验用的是 Q=2,000（p.6），敏感性实验（图 4(b)）给出的稳定下限是 Q≥300。
- **不能忽略「需要一小组无标签 ID 样本」这一前置条件**：作者在 §5.1（p.6）明确指出 SAR 类方法不需要这类样本，而 EATA 需要；把 EATA 描述为「完全无额外数据需求」是错的。
- **不能把单样本适应（批大小=1）的结果当作 EATA 可用**：表 6（p.9）显示 ETA 在批大小=1 时准确率 0.1%，与 Tent 同样失效；可用的只是加滑窗后的 ETA-wnd。
- **不能把 ImageNet-C 上与 Tent 的比较外推到「EATA 在所有 TTA 设定下优于 Tent」**：全部证据是图像分类（CIFAR-10-C／ImageNet-C／ImageNet-R），且 EATA 沿用 Tent 的参数集合（归一化层仿射）与在线协议。

## 与课题的关系

- **「熵陷阱」先例**：本课题把「适应后 FPR 恶化」预注册为熵陷阱；EATA 的图 2（p.4）与 §5.4 表 7（混合腐蚀下 Tent 从 18.0 掉到 2.3）是这一现象在图像域最早的系统证据之一，可作为失败判据的先例来源。
- **样本筛选是「保留最小改动面」之外的第二条控制手段**：本课题若在 TENT-LN 最小臂上引入筛选，EATA 的式(3) 提供了可直接引用的形式（阈值随类别数缩放），但**二分类下的常数需自行标定**，且须先证明筛选不是靠减少更新量取得的表面收益。
- 与 [[2023-Niu-SAR动态环境稳定测试时适应]]：SAR 沿用并简化了 EATA 的筛选形式（去掉加权、只保留指示函数），并指出 EATA 需要预采集 2,000 张分布内样本这一实践负担。

## 疑问 / 待验证

- 正文把 EATA 记为 `E_0 = 0.4 ln C`，而 SAR 附录 C.2（p.19）把 EATA 的该常数记为 `0.1 ln 1000`；两处冲突未在任何一篇中得到说明，复现时需以 EATA 本文为准并留意该差异。
- 表 2 中 ETA/EATA 的逐腐蚀类型数字来自 HTML 表格转换，本笔记只复核了「Average 列」与正文引用的数字（65.0、71.6、26,031、25,150）。
- 「Fisher 权重只算一次即固定」（p.5）这一省算设计的效果只在 ImageNet-C 上验证，论文未给出「随适应重新估计」的对照。
