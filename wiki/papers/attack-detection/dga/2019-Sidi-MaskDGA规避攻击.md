# MaskDGA

> 页码锚点：本地 PDF 共 12 页。威胁模型见 §3（**p.3**）；攻击四步与 JSM 见 §4.1–§4.5（**p.3–4**）；被评测模型见 §5.4（**p.6**）；主结果与表 2–3 见 §5.6（**p.7**）；对抗防御评价与表 5 见 §6（**p.8–9**）；结论见 §8（p.10），实用实现见 §7（p.9）。
> 本笔记于 2026-09-10 依本地 PDF 全文重写，补入攻击机制原式、威胁模型、被评测模型清单与对抗训练消融原始数字（题录经 arXiv API 与 PDF 元数据复核，见 `.Codex/docs/2026-09-10-DGA对抗文献入库/notes.md`）。

## 一句话

MaskDGA 用**代理模型的梯度显著性**选择字符位置并替换其中一半，把四个字符级 DGA 检测器的平均 F1 近乎砍半（0.977→0.495）；其自带的两种对抗防御都不能真正修复。

## 攻击机制（§4，p.3–4）

四步流水线（§4.1，p.3；图 2 在 p.4）：

1. **训练代理模型**：攻击者取得**公开 AGD 样本数据集**，训练一个区分 AGD 与良性域名的判别模型（§4.1–§4.2，p.3–4）。代理模型输入是字符级 one-hot 表示，须支持前向与反向传播以取得梯度。
2. **生成 AGD 域名**：用**已有 DGA + 随机种子**产生一批算法生成域名（§4.3，p.4）。作者讨论两个取舍：平均长度（越短越可读→越易规避，但越可能已被合法注册）与生成数量（越多越抗关停，但整体噪声大、越易识别）。
3. **构造雅可比显著性图（JSM）**（§4.4，p.4）：对每个 AGD 做**一次前向**得到预测分布，对**良性类** $Y^*$ 计算目标损失 $\mathcal{L}(F(X), Y^*)$，再做**一次反向传播**得到每个输入特征的梯度：

$$S = \left[ \frac{\partial \mathcal{L}(F(X), Y^*)}{\partial X_{i,j}} \right]_{i,j}$$

即在"字符位置 × 字符表"矩阵上，每个位置对应一个梯度值；梯度越大表示该位置的改动对"被判为良性"越关键。
4. **按 JSM 加扰动**（§4.5，p.4，算法 1）：对每一列取最大显著度 $S^i_{j^*}=\max_j S_{i,j}$；令 $\Theta$ 为**这些列最大值的**中位数**；仅当该列 argmax 位置的值 $\ge \Theta$ 时把该字符替换为对应符号。**因此恰好一半字符被替换**，且每个字符只替换一次（保证输出集合中碰撞少、域名数量接近原集合）。

**算子集（精确形式，供复现引用）**：

| 算子 | 本文是否使用 | 精确形式 |
| --- | --- | --- |
| 替换 substitution | **是，唯一算子** | 仅当该位置最大显著度 ≥ Θ（各列最大值的**中位数**）时替换，故**恰好替换一半**位置；替换目标为该位置 JSM argmax 对应的符号 |
| 插入 insertion | **否** | §9（p.10）明确：`deleting or inserting characters is forbidden`，理由是会产生过长域名（易被检出）或过短域名（昂贵且不可得） |
| 删除 deletion | **否** | 同上 |
| 相邻交换 swap | **否** | 未出现 |
| 字符重复 repetition | **否** | 未出现 |

- **每位置只替换一次**（§9，p.10：`every character is replaced once, in order to preserve a unique set of generated domains`）→ **每输入域名恰好产生 1 个对抗域名**，用以保持输出集合规模、避免碰撞。
- **Θ 的定义使其不依赖手调阈值**：以"各列最大显著度的中位数"为界，数学上保证恰好一半位置被选中（§4.5，p.4）。
- **硬编码约束**（§5.3，p.6）：禁止把非点字符改成点，以避免二级域被缩短（如 `example.com` 变成 `exa.mple.com`）。
- 字符表为大小写不敏感英文字母、数字、连字符、下划线与点，共 39 个符号；DMD-2018 中最长 AGD 为 65 字符。
- **不是 MCMC、也不是遗传算法**：选择完全由代理模型的反向梯度决定，评估方式仅是"**每域名一次**前向 + 一次反向"。若需按其复现，必须用梯度显著度而非随机采样。

**与原 JSMA 的区别**（§1，p.1）：MaskDGA 额外限制为 ① 只产生合法字符级改动、② 改动数恒定、③ 同一特征只改一次。
**与 HotFlip 的区别**（§9，p.10）：HotFlip 是白盒、且总是改梯度最高的字符（可反复改同一位置）；MaskDGA 黑盒、固定改一半且每个只改一次，目的是防止输出域名碰撞、保持输出集合规模，使攻击者难以被"逐域名封堵"。

## 威胁模型（§3，p.3）

| 维度 | 设定 |
| --- | --- |
| 模型知识 | **黑盒**：目标检测模型对僵尸网络操作者不可用，攻击者不能依赖目标模型的架构知识；但**可以**用公开 AGD 数据集与已发表架构训练代理模型 |
| 攻击目标 | **定向误分类到良性类**：目标是多类 DGA 分类器，输出为各 DGA 家族与良性的概率分布，取最大概率类为预测类；**DGA 家族之间的误分类仍算被检出，视为攻击失败** |

即：这是**黑盒 + 定向（targeted）**规避，不是白盒、也不是无目标误分类。

## 被评测模型与数据（§5.2–§5.4，p.5–6）

四个目标模型（§5.4，p.6，均按已发表源码在 TensorFlow 上重实现）：

- **LSTM[Endgame]**：单层 LSTM
- **biLSTM[CMU]**：前向 + 后向 LSTM
- **CNN[Invincea]**：并行 CNN 层
- **CNN+LSTM[MIT]**：堆叠 CNN + 单层 LSTM

代理模型（§5.3，p.6）**被刻意做得比目标模型弱**：一维 CNN（核尺寸 2、3、4、5）+ 最大池化（长度减半）+ 两层全连接；5 个 epoch、批 128、Adam、学习率 0.01；共 160,853 个参数，序列化为 10 MB HDF5。

数据 **DMD-2018**（表 1，p.5）：100,000 条良性 + 297,777 条 AGD（20 个 DGA 家族均分）。划分为：代理模型训练 113,335 条（28.9%）、目标模型训练 264,456 条（67.6%，**刻意给分类器优势**）、测试 9,986 条（3.3%，每条都被扰动后评测）。

对照攻击（§5.1，p.5）：① **Random**——随机选一半字符替换为均匀采样的英文字母/数字/连字符/下划线；② **DeepDGA**（作者复现，遇 mode collapse，通过预训练判别器绕过）。

指标（§5.5，p.6）：precision / recall / F1，其中"正确"定义为**任意 DGA 类**（而不是具体家族），与威胁模型一致。

## 主结果（§5.6，表 2–3，p.7）

无攻击时四模型平均 precision / recall / F1 均为 **0.977**（p.7）。加攻击后（表 2，p.7）：

| 目标模型 | NoAttack F1 | Random F1 | DeepDGA F1 | **MaskDGA F1** |
| --- | --- | --- | --- | --- |
| CNN[Invincea] | 1.00 | 0.73 | 0.84 | **0.39** |
| LSTM[Endgame] | 0.98 | 0.78 | 0.74 | **0.53** |
| biLSTM[CMU] | 0.98 | 0.81 | 0.78 | **0.55** |
| CNN+LSTM[MIT] | 0.95 | 0.77 | 0.74 | **0.51** |

- **平均 F1 由 0.977 降至 0.495**（摘要 p.1 与 §1 p.2 原话："the average F1-score of the classifiers degrades from 0.977 to 0.495"）。
- MaskDGA **平均召回 0.575**，即平均分类器漏掉 **42.5%** 的 AGD，而无攻击时仅漏 2.5%（p.7）。
- Random 攻击使平均 precision −19%、recall −26%、F1 −26.5%（p.7）；DeepDGA 平均 F1 为 **0.780**（§1，p.2），且比 Random 更易被检出。
- 分家族（表 3，p.7）：字典型 DGA **Suppobox** 上四模型平均 F1 为 **0.495**；较难的 **Corebot**（长随机域名）为 **0.7725**。

作者由 Random 攻击也有效这一点推论：字符级分类器**记忆了已知 DGA 的特定词法模式**，因而对字符扰动极为脆弱（§8，p.10）。

## 论文自身的对抗训练消融（§6，表 5，p.8–9）——本课题的直接对照

**这是本笔记的核心。** 论文评测了三种防御：

**① MaskDGA 重训**（§6.2，p.8）：从 20 个家族各随机取 100 条 AGD（共 **2,000 条**），施加 MaskDGA，然后把原训练集与这 2,000 条对抗样本合并，**再训练 2 个 epoch**。
**② DeepDGA 重训**（§6.2，p.8）：按 Anderson et al. 的做法训练 DeepDGA GAN（50 万良性域名），产出 **63,500 条**伪随机域名，标为"良性"并入训练集。
**③ 蒸馏**（§6.2，p.8）：温度 $T=10$（论文说明"$T>40$ 在 DGA 检测上不收敛，因为类样本重叠更多"）。

平均 F1 结果（表 5，p.9）：

| 防御 \ 攻击 | CNN[Invincea] 无/DD/Mask | LSTM[Endgame] 无/DD/Mask | biLSTM[CMU] 无/DD/Mask | CNN+LSTM[MIT] 无/DD/Mask |
| --- | --- | --- | --- | --- |
| **无防御** | 1.00 / 0.84 / **0.39** | 0.98 / 0.74 / **0.53** | 0.98 / 0.78 / **0.55** | 0.95 / 0.74 / **0.51** |
| 蒸馏 | 1.00 / 0.85 / 0.42 | 0.98 / 0.74 / 0.52 | 0.98 / 0.86 / 0.51 | 0.58 / 0.45 / 0.58 |
| DeepDGA 重训 | 0.87 / 0.97 / 0.40 | 0.96 / 0.88 / 0.57 | 0.94 / 0.48 / 0.54 | 0.91 / 0.92 / 0.49 |
| **MaskDGA 重训** | 0.96 / 0.72 / **0.96** | 0.95 / 0.77 / **0.91** | 0.93 / 0.64 / **0.85** | 0.91 / 0.54 / **0.80** |

可直接引用的读数：

1. **同攻击恢复有效但非无损**：MaskDGA 重训后对 MaskDGA 的平均 F1 恢复到 0.80–0.96，但**干净数据上的 F1 同步下降**（1.00→0.96、0.98→0.95、0.98→0.93、0.95→0.91）——存在可测的鲁棒性—性能张力，尽管论文未受此困扰地讨论。
2. **交叉攻击迁移差**：MaskDGA 重训后对 **DeepDGA** 攻击只有 0.54–0.77，其中 biLSTM[CMU] 的 0.64、CNN+LSTM[MIT] 的 0.54 甚至**低于对应的无防御水平**（0.78、0.74）。论文原话："the effectiveness of the defense against the DeepDGA attack has an average F1-score of 0.6675, which is better than the effectiveness of the DeepDGA retrain defense against the MaskDGA evasion technique"（p.9）。
3. **DeepDGA 重训对 MaskDGA 几乎无效**：0.40/0.57/0.54/0.49，且以降低非对抗 AGD 检出为代价。
4. **蒸馏基本无效**：对定向误分类无效——作者解释蒸馏是为**一般**误分类设计的，而本威胁模型是**定向**误分类（p.9）。注意 MIT 模型蒸馏后干净 F1 从 0.95 崩到 0.58。
5. **论文总判断**："the defenses do not fully prevent general adversarial attacks against DGA classifiers"（p.9）。

## 实用实现需求（§7，表 6，p.9）

机器人端需 TensorFlow Lite（<300 KB）、10 MB 代理模型、每 AGD 输入表示 2.4 KB、JSM 表示 38.4 KB。每个 AGD 只需一次前向 + 一次反向，计算量可忽略（无需训练）。作者据此论证该攻击对资源受限设备（IoT、POS 机）可行。

## 可迁移机制

1. **黑盒梯度的来源是"公开数据 + 公开架构"，不是目标模型**（§3，p.3）：攻击者不需要目标模型的参数，只需训练一个**代理模型**并利用可迁移性。这对防御方的含义是——**"模型未公开"不构成安全性假设**。
2. **固定改动比例 + 每位置只改一次**（§4.5，p.4）：以中位数为阈值保证"恰好一半"被改，同时避免重复改同一位置造成输出碰撞。**若方案要对离散序列施加有预算的定向扰动，这是"预算可控 + 输出多样"的具体构造**。
3. **定向误分类改变了防御的适配性**（§6.3，p.9）：蒸馏这类为"一般误分类"设计的防御在定向设定下失效。**防御评价必须与被防御的威胁模型同型**。
4. **对抗重训的两个可分离读数**：同攻击恢复（0.80–0.96）与跨攻击迁移（0.54–0.77）必须分开报告——只报前者会高估防御。本课题的组相对对抗优化若采用生成式对抗样本，应同时报告这两项。
5. **代理模型可以比目标模型弱仍然有效**（§5.3，p.6）：MaskDGA 的代理模型被刻意设计得更弱，攻击仍成功——**攻击不需要与目标同容量**。

## 不能直接声称内容

- **不能说 MaskDGA 是白盒攻击**：威胁模型明写黑盒（§3，p.3）；它借助代理模型的梯度，不是目标模型梯度。
- **不能把其防御结论外推到本课题模型**：被评测的只有 LSTM[Endgame]、biLSTM[CMU]、CNN[Invincea]、CNN+LSTM[MIT] 四个字符级二/多分类器，数据只有 DMD-2018（20 家族、固定划分）；与本课题的流量字段、双分支或条件记忆无实验交集。
- **不能把 "0.495" 当作四模型的"整体最优/最差值"**：0.495 是四模型逐模型 F1（0.39/0.53/0.55/0.51）的均值，也是 Suppobox 家族的均值；两者数值巧合相同，引用时须指明是哪一个。单模型最差为 CNN[Invincea] 的 0.39。
- **不能说本文做了迭代式对抗训练**：其重训是"一次性取 2,000 条对抗样本 + 加训 2 个 epoch"（§6.2，p.8），不迭代、不随训练过程重生成。
- **不能说蒸馏在本设定下被证明普遍无效**：无效是在本文的定向误分类设定与 DGA 数据上测得，作者给出的解释是机制不匹配。
- **本地 PDF 是 arXiv 预印本（acmart 排版）**：与 2020 年 IEEE Access 版（8:161580–161592）可能存在措辞与编号差异；本笔记的页码一律指本地 PDF 的物理页码，引用正式版时须回核。

## 与本课题的关系

- 最低比较表应至少包含 CharBot 或 MaskDGA 之一作为黑盒规避检查；只在干净域名上报告机制短训结果不构成鲁棒性证据。
- 该文给出了"**同攻击恢复 ↑ 但跨攻击迁移 ↓、且干净性能同时下降**"的三元读数，是本课题设计对抗鲁棒判据时的直接对照形态。
- 其代理模型 + 显著图 + 固定比例扰动的构造，可作为**对手模型**纳入本课题的压力测试，而不必自行发明规避攻击。
