# 联合选择性状态空间模型与去趋势的稳健时间序列异常检测

## 一句话

JSSM 是候选 B 的直接任务近邻：选择性状态空间模型已经用于异常检测，傅里叶峰值也已用于适配分解尺度，因此候选 B 不能把“状态空间异常检测”或“频谱辅助抗非平稳”写成首创；其区分性必须限定为真实时间间隔驱动的 RWKV-7 广义 Delta 连续化、非扩张约束以及因果有界频谱证据融合。

## 方法与页级证据

- PDF 第 1 页把长程正常行为建模和非平稳趋势引起的重建误报列为两项问题，提出 S6 选择性状态空间重建器与多阶段去趋势。
- 第 2 页式（1）—（2）给出 S6 状态更新。参数 `Δ` 随输入和时刻变化，但它是网络从输入生成的离散化参数，并不是观测的物理时间间隔；因此不能把该式视为候选 B 连续时间机制的同构证据。
- 第 2 页式（3）用 Hodrick–Prescott 滤波提取趋势；图 2 先做全局趋势分解，再通过多个 DMamba 块细化季节项和趋势项。
- 第 3 页式（4）—（7）是标准 Mamba/S6 块。式（8）用状态输出傅里叶变换的功率峰位置自适应选择移动平均核宽，式（9）汇总各层趋势，式（10）以重建均方误差训练并在推理时作为异常分数。
- 第 3—4 页在 NASA、SMD、SWaT 上与 12 个方法比较，使用 POT 选择阈值和基于事件关联的指标；这些结果不涉及网络流 2-IP、跨年度冻结或不规则时间间隔。
- 第 4 页表 3 只消融 HP 滤波与自适应移动平均。单独使用任一模块并非总能提升，联合使用才在三个数据集平均最好；论文没有单独消融 S6，也没有连续时间、频谱支路或信任界消融。
- 论文没有独立限制章节；第 4 页结论只总结 S6 与去趋势，未给出因果在线性、跨域泛化或阈值稳定性的保证。

## 与候选 B 的重叠矩阵

| 候选 B 构件 | JSSM 是否覆盖 | 判断 |
|---|---|---|
| 选择性状态空间模型用于异常检测 | 是 | **强重叠**；S6/Mamba 重建器直接用于 TSAD |
| 抗非平稳状态／分解 | 是 | **中高重叠**；HP＋多层自适应移动平均缓解趋势变化 |
| 频谱信息参与机制 | 是，但较弱 | **中等重叠**；傅里叶峰值只决定移动平均核宽，不形成独立频域异常证据 |
| 真实时间间隔连续化 | 否 | S6 的 `Δ` 是输入依赖离散化参数，不等于观测 `Δt` |
| RWKV-7 广义 Delta 定向移除／写入 | 否 | 使用标准 S6/Mamba 状态，不是 RWKV-7 矩阵 Delta 更新 |
| 因果滚动频谱与有界信任残差 | 否 | 没有前缀因果合同、零初始化残差幅度界或谱支路信任门 |
| 跨年度网络入侵检测 | 否 | 数据与任务是通用传感器／服务器 TSAD |

## 允许主张

- 候选 B 在既有 SSM-TSAD 和频谱辅助分解上，研究真实时间间隔驱动的 RWKV-7 状态与受限频谱证据融合。
- 必须设置 JSSM 式“离散 SSM＋去趋势”强基线，区分改进来自连续时间状态、普通去趋势还是频谱残差。

## 禁止主张

- 不得宣称首次将选择性状态空间模型用于异常检测，或首次结合频谱信息与状态空间异常检测。
- 不得把 S6 学习得到的 `Δ` 解释为物理时间间隔，也不得据此声称候选 B 的连续时间机制已有实验支持。
- 不得把三套通用 TSAD 数据结果外推为 LSPR23→LSPR24 的检测收益。

## 论文结论、项目推论与待验证项

- **论文结论**：S6 重建器与两阶段去趋势被联合用于三套 TSAD 数据；HP 与自适应移动平均的组合在其消融中优于单独使用。
- **项目推论**：候选 B 的大部分上层叙事已有近邻，只有连续时间广义 Delta、明确因果性和有界融合的精确定义仍可能形成组合边界。
- **待验证**：真实时间间隔是否提供额外信号、频谱支路是否优于普通去趋势、两者是否有组合收益，都必须由候选 B 的四格消融裁决。
