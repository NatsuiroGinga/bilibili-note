# 多任务梯度冲突方法论文索引

本索引覆盖多任务学习中处理梯度冲突/失衡的四篇经典方法论文，按提出时间排列。当前课题（跨年度加密恶意流量检测，第三章 FT-Transformer 骨干 + 逐流 BCE + 多预算 CVaR-pAUC 排序损失）只有**两个损失（$K=2$）共享同一套骨干参数、无独立任务头**，与四篇论文默认的"编码器 + 多个独立任务解码器"或"$K$ 个任务并行训练"场景存在结构差异，引用时须逐条核对该差异是否影响可迁移性。

## 四篇方法笔记

- **[[2018-Sener-MGDA多目标优化视角|MGDA / MGDA-UB（Sener & Koltun, 2018）]]** — 把多任务学习建模为多目标优化，求解满足 KKT 条件的帕累托驻点公共下降方向；提出表征空间上界近似 MGDA-UB 把开销从 $T$ 次反向传播降到 1 次。两任务时有闭式解（式 4），与本课题 $K=2$ 场景天然契合。
- **[[2018-Chen-GradNorm梯度范数自适应平衡|GradNorm（Chen 等, 2018）]]** — 用额外的 $L_1$ 损失把各任务梯度范数动态拉向"平均范数 × 相对训练速度的 $\alpha$ 次方"，只调节幅值、不触碰方向；全文没有收敛性定理，是纯经验方法，且自陈存在"分类器提前收敛到多数类时权重失控增长"的未解决失效模式。
- **[[2020-Yu-PCGrad梯度手术|PCGrad（Yu 等, 2020）]]** — 提出"悲剧三要素"（梯度冲突、幅值主导、高曲率）假说，用梯度手术把冲突梯度投影到另一任务梯度的法平面上，同时改变方向与幅值。全部严格收敛定理限定在两任务凸/强凸情形，与本课题 $K=2$ 场景理论适配度最高；论文 2.3 节散文公式与 Algorithm 1 第 7 行的投影分母写法不一致（$\|g_i\|^2$ vs $\|g_j\|^2$），笔记中已如实记录。
- **[[2021-Liu-CAGrad冲突规避梯度下降|CAGrad（B. Liu 等, 2021）]]** — 在平均梯度 $g_0$ 周围的局部球内求解"最大化最差任务局部改进量"，证明可控收敛到平均损失 $L_0$ 的驻点（$c\in[0,1)$ 时），并把 GD（$c=0$）与 MGDA（$c\to\infty$）纳为连续插值的两个特例。收敛定理对任意 $K\ge2$ 成立，不像 PCGrad 那样局限于两任务专门推导。

## 各方法处理"幅值"还是"方向"

| 方法 | 调节幅值 | 调节方向 | 机制归类与依据 |
| --- | --- | --- | --- |
| GradNorm | 是（唯一调节对象，通过可学习权重 $w_i(t)$） | 否（不改变各任务梯度的方向，只重新加权后再求和） | 纯幅值再平衡；论文用批归一化类比自我定位（引言部分） |
| MGDA / MGDA-UB | 隐式（凸组合权重 $\alpha_i$ 决定各任务贡献比例） | 是（合成的公共方向 $\sum\alpha_ig_i$ 一般不同于简单平均方向） | 求解凸包内最小范数点，方向与幅值同时由权重方程决定，属于"权重法"而非逐对投影法 |
| PCGrad | 是（投影后范数通常减小，是投影的副产品） | 是（核心机制：逐对检测冲突并投影到法平面） | 论文自身消融（Fig. 3 最右图）证实：只调方向的变体明显优于只调幅值的变体，后者与 GradNorm 表现相近，说明方向修正是主要贡献 |
| CAGrad | 是 | 是 | 显式统一处理：局部球约束同时限定方向偏移和幅值偏移；$c=0$ 时退化为不做任何调节的纯梯度下降，$c\to\infty$ 时逼近以方向为主的 MGDA |

## 当前课题的证据分工

| 文献 | 可直接承担的角色 | 不能直接声称 |
| --- | --- | --- |
| MGDA / MGDA-UB | 两损失（$K=2$）公共下降方向的闭式求解基线（式 4 无需 Frank-Wolfe 迭代）；"共享中间表征 $\mathbf Z$"的近似思路可作为降低反向传播次数的候选设计 | 论文默认的编码器+独立任务头架构与本课题单头多损失结构完全等价；Table 2 的 40%/25× 加速比可直接套用到 FT-Transformer 规模 |
| GradNorm | BCE 与 CVaR-pAUC 损失尺度失衡的诊断工具（$\tilde L_i(t)$ 相对下降曲线）与幅值再平衡基线，工程实现成本最低 | 解决两损失间的方向冲突（论文完全不处理方向）；论文"$r_i(t)$ 代理训练速度"依赖的二次损失前提在本课题（对数似然 + 排序损失）成立 |
| PCGrad | 理论覆盖最完整的两任务方向冲突消解基线；Theorem 2 的"悲剧三要素"诊断协议（冲突程度、曲率下界、学习率）可直接迁移为训练动态的可证伪实验 | 深度非凸 FT-Transformer 上的收敛保证（Theorem 1/2/4 均需凸性或强凸性）；排序损失（CVaR-pAUC）组合下的效果无实验先例 |
| CAGrad | 显式优化组合目标 $L_0=(\text{BCE}+\text{CVaR-pAUC})/2$ 驻点收敛的基线，语义上最贴合本课题"训练目标就是两损失之和"的设定；$c$ 作为连续插值旋钮，提供 GD↔MGDA 的一维消融维度 | $c\in[0,1)$ 的免调参默认值（论文靠网格搜索，监督任务集中在 $0.2\sim0.6$，RL 任务用到 $0.9$，无通用公式）；$H$-Lipschitz 光滑性假设在 FT-Transformer + CVaR-pAUC 上自动成立 |

## 与既有相关笔记的关系

- **[[Nash-MTL-多任务对称议价训练|Nash-MTL 对称议价训练]]**：与本索引的 MGDA 同属"求解凸组合权重"一类方法，但 Nash-MTL 用纳什议价（对数效用和最大化）替代 MGDA 的最小范数准则，对任务尺度更不敏感；两者可作为"权重法"内部的横向对照。
- **[[ConFIG-PINN多目标无冲突训练|ConFIG PINN 多目标无冲突训练]]**：面向三个及以上损失（生成、状态、物理）的场景，强调与每个损失梯度均保持正投影；本索引四篇方法中与 ConFIG 机制最接近的是 PCGrad（都做逐对/逐个投影运算），但 ConFIG 针对 PINN 场景，本索引针对通用多任务分类/回归/强化学习场景，证据来源不同，不可交叉引用实验结论。
- **[[Recon从结构根源减少梯度冲突|Recon 从结构根源减少梯度冲突]]**：与本索引四篇方法路线不同——Recon 不在优化器层面处理已产生的冲突梯度，而是把高冲突共享层结构性地改为任务专用层，是"结构诊断+架构改造"方法，可与本索引的"梯度手术"类方法（PCGrad、CAGrad）互补：先用 Recon 式的分层冲突分数诊断本课题骨干各层的冲突集中位置，再决定是否需要在优化器层面叠加 PCGrad/CAGrad。

## 阅读与实验顺序建议

1. 先读 MGDA，建立"公共下降方向"求解的基础框架和两任务闭式解（式 4），这是本课题 $K=2$ 场景最直接可用的起点。
2. 再读 PCGrad，获取"悲剧三要素"诊断协议，在真实训练轨迹上测量 BCE 与 CVaR-pAUC 的梯度余弦相似度、幅值比、曲率估计，判断本课题是否真的存在方向冲突。
3. 若诊断显示方向冲突不显著、只是尺度失衡，转向 GradNorm 式的幅值再平衡；若方向冲突显著，再评估 CAGrad 相对 PCGrad/MGDA 的 $c$ 超参数扫描是否值得额外的调参成本。
4. 四篇论文均未在排序损失（CVaR-pAUC）组合场景下提供实验证据，任何迁移结论在写入正文前都必须先有本课题的最小可证伪实验支持，不得直接引用论文的视觉/强化学习数字。
