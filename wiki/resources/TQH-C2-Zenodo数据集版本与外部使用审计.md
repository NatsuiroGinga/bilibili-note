# TQH-C2 Zenodo 数据集版本与外部使用审计

## 来源

- 正式题名：TQH-C2: An Encrypted Command-and-Control Traffic Dataset Across Protocols and Encryption Layers
- 作者：Deokjo Jeon、DongGue Park
- 概念 DOI：<https://doi.org/10.5281/zenodo.21330094>
- 最新核验版本：v1.2.0，<https://doi.org/10.5281/zenodo.21523144>
- 许可：CC BY 4.0
- 本地官方制品：`raw/datasets/TQH-C2-v1.2.0/`

## 核验结论

- 概念记录下共有 v1.0.0、v1.0.1、v1.0.2、v1.1.0、v1.2.0 五版。五版题名相同，必须用 DOI、文件名、校验和、B 方向性或 D 成员判版。
- v1.0.x 的 B 存在单向 C2 流生成缺陷；v1.1.0 重采 B；v1.2.0 在相同 A/B/C 包上新增 D（Merlin HTTP/2-over-TLS/TCP）。
- v1.2.0 实际有 4 个测试床、48 个捕获单元、152,765 条逐流记录和相同 27 列 Parquet 模式。README 中的部分“36 单元”与标签统计未同步 D/当前小包，实验必须以已校验制品为准。
- v1.2.0 实际标签为 `benign=124,295`、`benign_external=460`、`malicious_c2=27,130`、`malicious_recon=880`；`malicious_lateral=0`、`unknown=0`。`unknown` 的历史语义是传输/基础设施噪声，不是未知攻击。
- v1.1.0 和 v1.2.0 README 的引用块仍给出 v1.0.0 DOI `10.5281/zenodo.21330095`。因此引用该 DOI 不能单独证明实际使用 v1.0.0；只引概念 DOI 也不能自动归到最新版。

## 外部引用与实际使用

截至 2026-08-12，对概念 DOI、5 个版本 DOI、完整题名和 `TQH-C2` / `TQHC2` / `TQH C2` 变体的两轮检索没有得到精确候选：

- **A 类（正文/代码明确实验使用）：0。
- **B 类（仅引用/讨论）：0。
- 语义搜索器返回约 195 个原始噪声行（含重复），均因早于数据集发布、DOI/题名不匹配或主题无关而批次排除。
- 获取论文全文：0；原因是没有 A/B 类作品，不是全文下载失败。

这个结论只能表述为“截止日可达来源未发现”，不能表述为全球绝对“无人使用”。Semantic Scholar 题名查询受 HTTP 429 限制，Scite 有 4 个对象因月度额度未查，GitHub 匿名代码 API 也被限流；这些均不记为 0。

## 任务能力边界

- **可直接构造**：完整 capture 分组的封闭集检测、跨成员泛化、选择性预测、概率校准/告警预算、捷径/去混杂审计。
- **只能弱构造**：留一成员的开放集代理、工程/版本偏移代理、人工删除/投毒、PCAP 流前缀早识别、模拟标注预算。
- **当前不支持**：原生未知攻击类、杀伤链阶段识别与溯源、现实人类个人隐私主张。

前三个建议研究单元为：① A/B/D→C 跨成员泛化；② 跨域校准、告警预算与选择性拒识；③ B/D 协议异构下的流前缀早识别小实验。第三项为弱构造，必须先用最小前缀实验否决。
