## 2026-08-19 追记：图 3-6 的两轮处置

图 3-6 前后出现过三个版本，**当前正式版是上级目录里的「图3-6-双机制消融交互」（2026-08-19 重绘）**。

第一版「图3-6-双机制消融交互」（2026-08-18 以前）已从本目录移除。它画的是 2×2 四格，
但图内写有「判据一 通过（超可加）」，该论断已在正文 R17 中撤下，且四格值取自另一次运行，
与表 3-3 对不上。两处问题都无法靠调版面解决，只能重画；文件本身仍可从 `git` 历史取回。
本轮重绘沿用同一落盘名，是覆盖而不是新增，故本目录不再保留同名旧件，避免一名两物。

第二版「图3-6-跨骨干机制增益与判读带宽」（2026-08-18）即本目录现存的这三个文件。
撤下原因是画错了对象，不是画错了数：正文对图 3-6 的唯一引用在 3.6.4 节第 192 行，
要的是式 (3-30) 在多层感知机骨干上的 2×2 交互分解（5.10、7.35、12.45、18.34、5.89），
该图给的却是五个骨干的并用增量。**跨骨干那五行读数已由表 3-2 逐行承载，正文别处没有
引用这张图**，因此不另行重绘；跨骨干比较若要配图，应另编图号并先在正文建立引用。

附带一处口径问题也记在这里：该图把 11.59 个百分点的判读带宽与并用增量画在同一根横轴上，
但带宽取自完整方法三次重复训练的**逐流**平均精确率极差，增量是**实体**平均精确率的增量，
两者不是同一个量，不应共用一根轴。重绘后的第三版据此不再画带宽线。
