# 第三章图件说明

本目录保存第三章正式图件。机制图不使用尚未冻结的实验数据，也不把当前 E2 候选结构表述为已经冻结的最终算法。

## 生成命令

```bash
uv lock --project thesis/figures/第三章
uv run --project thesis/figures/第三章 python thesis/figures/第三章/绘制第三章机制图.py
```

## 文件合同

- `绘制第三章机制图.py`：可重复执行的唯一绘图源码。
- `*.svg`：保留文本和矢量对象的可编辑版。
- `*.pdf`：论文排版优先引用版，宽度固定为 180 mm。
- `*.png`：300 dpi 预览与 Markdown 内联版。
- `图件清单.json`：生成时环境、尺寸和输出文件清单。

## 视觉规范

- 中文字体：`/System/Library/Fonts/Hiragino Sans GB.ttc`。
- 数学字体：STIX。
- 主文字颜色：深灰。
- 公共观测与主前向：蓝色实线。
- 队列状态与物理条件：青绿色实线。
- 生成梯度与有界修正：朱红。
- 训练期特权监督：金色虚线。
- 冻结参数：中性灰并显式标注“冻结”。

## 证据边界

1. 图 3-1 至图 3-5 是方法与协议图，不承载实验结果。
2. 图 3-2 中队列图标不表示实际数值或轨迹。
3. 图 3-3 按当前 $L^+=0$ 正式矩阵画制，不暗示非零出队后丢弃契约已解决。
4. 依赖实验制品的结果图只能在相应门槛通过后由已核验数据生成。
5. 截至 2026-07-24，E2 的三随机种子检测门槛均通过，但种子 43、44 的物理门槛未通过；图 3-1 至图 3-5 只描述候选机制与运行协议，不表示该候选已通过最终裁决。
