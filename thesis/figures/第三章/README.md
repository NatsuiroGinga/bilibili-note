# 第三章图件说明

本目录保存第三章的正式图件与可重复执行的生成源码。规格以 `thesis/figures/AGENTS.md`
的学位论文图件合同为准；本文件只说明本章的生成方式、数据来源与证据边界。

> **本章已重锚到 LAMDA 年度序列。** 旧线（流量检测宿主）的 11 幅图与两个生成脚本已于
> 2026-10-14 移入 `作废/`，撤下理由登记在该目录的 `README.md` 与 `图件清单.json` 的
> `withdrawn` 段。图号 3-1 至 3-11 现由下列新图占用，图号 3-12 暂空。

## 生成命令

```bash
uv lock --project thesis/figures/第三章
# 机制与理论图（图 3-1 至图 3-4），不使用实验数据
uv run --project thesis/figures/第三章 python thesis/figures/第三章/绘制第三章LAMDA机制图.py
# 实验结果图（图 3-5 至图 3-11），只从权威制品取数
uv run --project thesis/figures/第三章 python thesis/figures/第三章/绘制第三章LAMDA结果图.py
```

两个脚本的执行顺序不影响产物；`图件清单.json` 的两种重建顺序结果相同，已实测。

结果图依赖的制品在 `thesis/experiments/llm_probe/runs/` 下，受 Git 忽略。本机缺失时，
`resultdata_lamda.py` 会报出精确路径而不会静默改用旧数据。

## 源码分工

| 文件 | 职责 |
| --- | --- |
| `figstyle.py` | 字体解析、版面换算、绘图原语、逐字字形断言。本章两个生成脚本共用，是字体的唯一来源。 |
| `resultdata_lamda.py` | **本章**结果图取数层：定位制品、按键路径取字段、按本章报告口径重算跨年平均 F1。 |
| `绘制第三章LAMDA机制图.py` | 产出图 3-1 至图 3-4，不承载实验数据。 |
| `绘制第三章LAMDA结果图.py` | 产出图 3-5 至图 3-11。 |
| `图件清单.json` | 按生成器分段登记环境、字体、尺寸、实测分辨率，逐图登记数据来源键路径，并在 `withdrawn` 段登记撤下图。 |
| `resultdata.py` | 旧线取数层，**已停用但保留作追溯**，不再是任何图的取数来源。 |

## 文件合同

- `*.svg`：保留文本与矢量对象的可编辑源。
- `*.pdf`：矢量版，供放大核查与排版引用。
- `*.png`：400 ppi 提交版与 Word 插入版。
- 三种格式在每次生成后由脚本核对：SVG 可解析、PDF 文件头有效、PNG 实测 ppi 不低于 300；
  另用 `pdffonts` 核验内嵌字体只含 `SimHei`、`TimesNewRomanPSMT`、`CambriaMath`。

## 视觉规范

规格全部取自 `thesis/figures/AGENTS.md`，此处只记录本目录的实际取值：

- 页面 A4；本章图件宽 130～150 mm，高 88～96 mm，均在合同上限 165 mm × 140 mm 之内。
  实测分辨率 399.8～400.0 ppi。
- 中文黑体按 `figstyle.resolve_cjk_font()` 逐字面核验后选中，优先 `SimHei`。集合字体
  （`.ttc`）必须指定 face 索引——不指定会解析到繁体字面，2026-08-26 审查已实测到该缺陷，
  现由统一走 `figstyle.py` 关闭。
- 西文 Times New Roman；数学符号 Cambria Math。`\mathcal` 的字面由本目录脚本显式设置
  `mathtext.cal`，否则会回退到系统字体，2026-10-14 已实测并修正。
- 最小字号 8 pt，主标注 9 pt；主线 1.0 pt，辅助线 0.5 pt。
- 彩色只作辅助：各系列先用填充图案与线型区分，灰度打印仍可读。

## 数据来源与证据边界

1. **图 3-1 至图 3-4 是方法与理论示意图，不承载实验数据**，也不表示任何配置已通过实验裁决。
   - 图 3-2 与图 3-3 直接绘制式 (3.5) 与式 (3.17) 的解析曲线，不含拟合。
   - **图 3-4 中保持项的形状是示意**：3.5 节只给出「上升且饱和」及上界 $\varepsilon(N)$，
     未给出封闭形式。绘制时取 $R(\lambda)=1-\exp(-\lambda/\tau)$、$\tau=0.35$，
     两个参数在图内与题注中均标为示意，**非拟合值**。若正文需要精确 $\lambda^*$，
     须先给出 $\varepsilon(N)$ 的实测刻度。
   - 图 3-2 的当年训练分片条数取 3.3.3 节所述的约 80,000 条；制品不含逐年分片条数。

2. **图 3-5 至图 3-11 只从下列权威制品取数**，每个数字可在图件清单的 `data_keys` 中指回字段：
   `thesis/experiments/llm_probe/runs/diagnostics/ch3-lamda-domain-il-e4-replication-v1/`
   （官方 Domain-IL 协议在 12 个年度上的复现与配置对照）。

3. **图 3-9 的审计数值是外部给定常数**（主代理在不训练的条件下直接运行官方抽样过程所得），
   该制品不含对应字段。已在图内、`data_keys` 与 `external_constants` 三处标明来源。

4. **报告口径**：跨年平均 F1 取最后一个 experience（2025）对全部 12 个年度测试分片的
   backward 记录平均值。2025 年度测试分片仅含 5 条正例，该年度读数不作配置优劣依据，
   逐年图中已注明。

5. 全部结果图为**单种子 seed42** 的单次运行，图内不写多种子误差。

6. 正文只引用本目录下的图件，不引用 `runs/`、`output/` 或任何临时目录中的图片。
