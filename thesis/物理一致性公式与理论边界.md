# 物理一致性公式与理论边界

本文档记录第三章当前可用的物理公式和写作边界。正式正文以 `chapters/03-基于队列物理约束与有界条件注意力的恶意流量检测方法.md` 为准。

## 1. 有限队列控制体

对窗口 \(k\) 的到达量 \(R_k\)、成功离开量 \(D_k\)、入队前丢弃量 \(L_k^-\)、出队后丢弃量 \(L_k^+\) 和边界队列状态 \(Q_k\)，守恒关系为

\[
Q_{k+1}-Q_k=R_k-D_k-L_k^- -L_k^+.
\]

该关系在正常与攻击状态下都应成立。攻击改变到达率、积压、服务裕度和丢包，不“打破”完整守恒律。

## 2. 模型预测状态

模型对四窗口序列预测五个非负归一化队列锚点 \(\hat q_0,\ldots,\hat q_4\)。定义公共字节尺度

\[
S_i=\max_k B_{i,k}.
\]

预测字节存储变化为

\[
S_i\left(\hat q_{i,k+1}-\hat q_{i,k}\right).
\]

同一序列必须使用公共尺度，不能对相邻状态分别使用不同窗口尺度。

## 3. 当前物理残差

\[
r_{i,k}=
\frac{
S_i\left(\hat q_{i,k+1}-\hat q_{i,k}\right)
-R_{i,k}+D_{i,k}+L^-_{i,k}+L^+_{i,k}
}{B_{i,k}},
\qquad B_{i,k}>0.
\]

物理损失为有效窗口上的残差平方均值。必须遵守以下规则：

1. 分母严格使用 \(B_{i,k}\)，不添加任意小常数。
2. \(B_{i,k}=0\) 的窗口不进入残差。
3. 保存的真值残差只用于数据审计，不作为训练损失。
4. 残差必须依赖模型预测状态，并对共享可训练参数具有非零梯度。

## 4. 边界锚定

只约束相邻差分时，\(\hat q_k+c\) 与 \(\hat q_k\) 产生相同物理残差，因此存在常数平移零空间。每条序列必须监督绝对边界锚点 \(q_0\)，用于固定状态轨迹的绝对位置。

## 5. 已淘汰公式与表述

- 不再使用将星形拓扑映射到一维连续空间的连续性偏微分方程作为主公式。
- 不再把输入端双向字节比、熵或 TCP 标志统计统一称为基本物理守恒律。
- 不再把物理残差幅值直接作为独立攻击分数。
- 不再使用“正常流量满足守恒、攻击流量打破守恒”的表述。
- TCP/AQM 流体方程缺少公开数据中的队列与丢包概率观测，不进入当前主方法。

## 6. 证据状态

- 密集状态监督下，当前残差没有提供稳定新增信息。
- 20% 与 40% 稀疏状态监督均证明物理项显著改善未观测状态和物理残差。
- 两组实验也证明固定权重联合训练持续损害生成目标。
- 当前残差和边界条件保留；目标协调实现已被同协议实验淘汰。第二结构候选已改为有界物理条件交叉注意力，其最终冻结仍取决于三种子验收、同分区物理复核和外部验证。
