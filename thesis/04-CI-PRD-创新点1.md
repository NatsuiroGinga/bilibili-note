# 第4章 CI-PRD：守恒不变量物理残差检测器（创新点1）

> 状态：⬜ 待写 ｜ 术语见 [[开题术语体系]] ｜ 模板参考朱焱雷 Ch3（仅结构）
> 命名：CI-PRD = Conservation-Invariant Physics Residual Detector（守恒不变量物理残差检测器），**非 TD-PRD**（TD-PRD 硬编码已否决的方案 A TCP 流体）。

## 4.1 引言
- 网络攻击检测为何需要物理信息：纯数据驱动在小样本/分布外攻击上泛化弱；物理约束减少标注依赖。
- 本章贡献定位：把 PINN 改造为攻击检测器，以守恒不变量残差作异常得分。

## 4.2 问题定义与威胁模型
- 检测任务数学描述（流/包级输入 → 攻击/正常判定）
- 威胁模型：DDoS / 端口扫描 / 漏洞利用 / 变种（OOD）
- **方案 A/B 决策回顾**：TCP 流体（A）在 IDS2018 不可算 → 选守恒不变量（B），依据 [[IDS2018字段普查报告]]

## 4.3 守恒不变量定义（核心）
- I1 节点流量守恒（质量守恒，需测试床拓扑）
- I2 流双向守恒（请求/响应比，IDS2018 可算）
- I3 TCP 状态守恒（握手一致，包级严格）
- I4 熵平稳性
- I5 TCP 流体 ODE 残差（消融对比）
- 各不变量→攻击映射表，见 [[数据集构建章节设计_开题实施计划]]

## 4.4 CI-PRD 方法框架
- 4.4.1 总体结构：NN 逼近流量场 + 守恒残差作物理损失
- 4.4.2 物理残差计算（自动微分）
- 4.4.3 LLM 辅助不变量提取（借鉴 [[INVARLLM-物理不变量提取]]：LLM 从协议规范提取候选不变量 + 数据因果验证）
- 4.4.4 与通用 PINN 的区别：残差幅值直接作判定，非解 PDE

## 4.5 算法实现与模型适配
- 流级（CSV）与包级（PCAP）两种输入适配
- 不变量在不同数据形态下的可计算性（见普查报告）

## 4.6 理论分析

- 小样本优势论证（参考 [[PIGCRN-化工过程攻击检测]]、[[INVARLLM-物理不变量提取]]）
