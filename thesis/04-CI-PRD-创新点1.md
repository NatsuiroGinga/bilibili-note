## 4.1 引言
- 网络攻击检测为何需要物理信息：纯数据驱动在小样本/分布外攻击上泛化弱；物理约束减少标注依赖。
- 本章贡献定位：把 PINN 改造为攻击检测器，以守恒不变量残差作异常得分。

## 4.2 问题定义与威胁模型
- 检测任务数学描述（流/包级输入 → 攻击/正常判定）
- 威胁模型：DDoS / 端口扫描 / 漏洞利用 / 变种（OOD）
- **方案 A/B 决策回顾**：TCP 流体（A）在 IDS2018 不可算 → 选守恒不变量（B），依据 [[IDS2018字段普查报告]]

## 4.3 守恒不变量定义（核心）

CI-PRD 的"物理"由一组**守恒不变量**构成。按物理合法性分两层：I1 为基本物理律（质量守恒，连续性方程），I2–I4 为领域/协议不变量，I5 仅作消融对比。网络流量被建模为图 $G=(V,E)$ 上的连续流，对链路 $e$ 定义流量密度 $\rho_e(x,t)$、传播速度 $u_e(x,t)$、通量 $J_e=\rho_e u_e$。

### 4.3.1 I1 节点流量守恒（质量守恒，连续性方程）

流量连续性方程（质量守恒）为：
$$\frac{\partial \rho_e}{\partial t} + \frac{\partial J_e}{\partial x} = s_e(x,t) \tag{4.1}$$
其中 $s_e$ 为源/汇（流量产生/丢弃）。该式与流体力学中 PINN 所解的连续性方程同构，是 CI-PRD 物理合法性最强的约束。在节点 $v$ 处离散为 Kirchhoff 电流定律，对时间窗 $\Delta$：
$$\mathcal{R}_{I1}(v,\Delta) = \sum_{i \in \mathrm{in}(v)} B_i^{in}(\Delta) - \sum_{j \in \mathrm{out}(v)} B_j^{out}(\Delta) - B^{drop}(v,\Delta) - \Delta q(v,\Delta) \tag{4.2}$$
正常稳态转发节点 $\mathcal{R}_{I1}\approx 0$；DDoS 受害节点流入 $\gg$ 流出，$\mathcal{R}_{I1}$ 显著为正。**可算性**：需多节点 per-port 字节计数，自构造测试床可算，IDS2018 端点不可算。

### 4.3.2 I2 流双向守恒（协议交互不变量）

对客户端-服务端流 $f$，请求-响应字节应满足协议规定的有界比：
$$\mathcal{R}_{I2}(f) = \frac{B_{fwd}(f)}{B_{fwd}(f) + B_{bwd}(f) + \varepsilon} \in [r_{\min}, r_{\max}] \tag{4.3}$$
正常服务双向交互，$\mathcal{R}_{I2}\in[r_{\min},r_{\max}]$（协议相关，如 HTTP 约 $[0.3,0.7]$）；单向洪泛/扫描 $B_{bwd}\approx 0$，$\mathcal{R}_{I2}\to 1$，违反区间。残差 $\mathrm{res}_{I2}(f)=\max(0,\,r_{\min}-\mathcal{R}_{I2},\,\mathcal{R}_{I2}-r_{\max})$。**可算性**：`TotLen Fwd/Bwd Pkts`、`Down/Up Ratio`，IDS2018 流级可算。**实验已证**：对单向 DDoS 洪泛（HOIC/LOIC-UDP）召回 76–100%、误报 0.6%（见 [[experiments/README|实验 v3]]）。

### 4.3.3 I3 TCP 状态守恒（协议状态机不变量）

TCP 连接须遵循状态机：每个 SYN 应有匹配 SYN-ACK 完成握手。对时间窗 $\Delta$：
$$\mathcal{R}_{I3}(\Delta) = \frac{\#\mathrm{SYN}_{unanswered}(\Delta)}{\#\mathrm{SYN}(\Delta) + \varepsilon} \tag{4.4}$$
正常 $\mathcal{R}_{I3}\approx 0$；SYN flood / Slowloris 半开 $\mathcal{R}_{I3}\to 1$。**可算性**：严格形式需逐包 TCP 标志，PCAP 可算（已从 IDS2018 截断包恢复真实 pcap）；流级弱近似用 `SYN Flag Cnt` 与反向包数。

### 4.3.4 I4 熵平稳性（统计不变量）

对窗口 $\Delta$ 的目的端口/IP 分布熵：
$$H_{dst}(\Delta) = -\sum_{p} P(p|\Delta)\log P(p|\Delta), \quad \mathcal{R}_{I4}(\Delta) = \frac{|H_{dst}(\Delta) - \bar H_{dst}|}{\bar H_{dst} + \varepsilon} \tag{4.5}$$
正常 $H_{dst}$ 平稳；DDoS 目的集中→$H_{dst}$ 骤降，端口扫描目的分散→$H_{dst}$ 骤升，均使 $\mathcal{R}_{I4}$ 增大。**可算性**：`Timestamp`+`Dst Port`，IDS2018 可算。

### 4.3.5 I5 TCP/AQM 流体 ODE 残差（消融对比，方案 A）

Misra 型流体方程：
$$\dot W(t) = \frac{1}{R(t)} - \frac{W(t)W(t-R)}{2R(t-R)}p(t-R), \quad \dot q(t) = N\frac{W(t)}{R(t)} - C \tag{4.6}$$
残差为模型预测与该 ODE 的偏差（自动微分）。**可算性**：$W$ 可由 seq/ack 推断、$R$ 可观测，但 $q(t)$、$p(t)$ 为路由器内部状态，端点 PCAP 不可观测 → IDS2018 不可算，仅测试床消融，用于证明守恒不变量（I1–I4）优于 TCP 流体残差。

### 4.3.6 不变量→攻击映射与适用边界

| 不变量 | 物理定位 | 可算数据 | 有效攻击 |
|--------|---------|---------|---------|
| I1 节点守恒 | 基本物理（质量守恒） | 测试床 | DDoS（节点失衡） |
| I2 流双向守恒 | 协议交互不变量 | IDS2018 流级 | 单向洪泛/扫描（实验背书） |
| I3 TCP 状态守恒 | 协议状态机不变量 | PCAP | SYN flood/半开 |
| I4 熵平稳 | 统计平稳性 | IDS2018 | DDoS/扫描 |
| I5 TCP 流体 ODE | 动力学律（TCP专属） | 仅测试床 | （消融） |

**适用边界（诚实）**：守恒不变量对**传输层洪泛/扫描**有效；对**应用层 DoS**（如 HTTP 洪水 GoldenEye、慢速 Slowloris，完成握手、双向交互，不打破传输层守恒）无效——此类交由第二级 PIC-GRPO 语义精判（两级分工，见 [[05-PIC-GRPO-创新点2]]）。该边界已由 [[experiments/README|实验 v3]] 跨攻击类型对比验证。

## 4.4 CI-PRD 方法框架

### 4.4.1 总体结构

CI-PRD 以神经网络 $\hat\rho_\theta$ 逼近流量场，将 4.3 节可计算的不变量残差作为物理损失软约束，联合数据拟合损失训练。攻击流量打破守恒律，使模型预测的物理残差升高，残差幅值即异常得分。结构上分三路：流量场预测主干、不变量残差计算（自动微分）、异常得分输出。

### 4.4.2 物理残差计算（自动微分）

对每个可算不变量，由 $\hat\rho_\theta$ 的输出经自动微分求残差：I1 由时空导数按式 (4.1) 求；I2–I4 由流/窗口统计按式 (4.3)–(4.5) 求。残差汇总为物理损失项。

### 4.4.3 CI-PRD 联合损失

$$\mathcal{L}_{CI\text{-}PRD} = \mathcal{L}_{data} + \lambda_1 \mathrm{res}_{I1} + \lambda_2 \mathrm{res}_{I2} + \lambda_3 \mathrm{res}_{I3} + \lambda_4 \mathrm{res}_{I4} \tag{4.7}$$
测试床数据启用 I1（连续性方程，强物理）；IDS2018 启用 I2/I3/I4（协议/统计不变量）。$\lambda_1$–$\lambda_4$ 为平衡系数。异常得分 $s = \|\mathrm{res}\|$，超阈则判可疑并送第二级。

### 4.4.4 LLM 辅助不变量提取

借鉴 [[INVARLLM-物理不变量提取]]：用大模型从协议规范（RFC）、部署文档中提取候选守恒不变量的假设形式，再用历史数据做因果验证（PCMCI+ 启发的统计检验）剔除幻觉不变量，保留数据支持的不变量注入式 (4.7)。这使不变量集可随协议/场景自适应，而非全靠人工预设。

### 4.4.5 与通用 PINN 的区别

通用 PINN 解 PDE 的正/逆问题，目标是拟合解函数；CI-PRD 把 PINN 改造为**异常检测器**——以残差幅值直接作判定依据，物理律作软约束把模型限制在"物理一致"子空间，攻击打破物理 → 残差升高。这一改造参考 [[PIGCRN-化工过程攻击检测]]（PINN-IDS 专用化）与 [[INVARLLM-物理不变量提取]]（不变量残差检测）。
