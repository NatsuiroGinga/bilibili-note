## 研究主线

```text
TQH-C2 v1.2.0 分组隔离的共同检测字段
    → E2：编码器候选与共同预算强基线
    → E2-A/S/P/X：普通监督、状态监督、共享守恒 PINN、置换物理
    → E3：仅在共享 PINN 通过后验证协议专家、有界路由和 B↔D 迁移
    → 第四章：沿用冻结基座与协议开展困难样本、长尾和课程优化训练
    → 第五章：实现同一冻结检测与分析流水线
```

## 当前冻结边界

### 已固定

- 第三章保留 PINN，先验证共享守恒约束是否产生独特检测收益。
- TQH-C2 v1.2.0 是第三、四章唯一正式公开检测数据集；最终测试在方案冻结前不可见。
- E2 使用共同字段、组级隔离和共同预算，比较编码器候选、强基线及 `E2-A/S/P/X` 因果对照。
- E2 不启用 TCP、QUIC 或未知协议路由；协议专家与有界路由仅在共享 PINN 通过后进入 E3。
- Qwen3-0.6B 与 ET-BERT 均后置，不阻塞 E2 路线冻结。

- 第三、四章正式标题、算法名称、缩写、公式、命题和最终结果。
- 多种子、效率、受控迁移、跨基座验证和一次性最终测试结论。

## 写作纪律

1. 区分已验证结果、实验候选和最终贡献，禁止把计划写成实验结论。
2. 攻击改变流量状态，不改变完整守恒关系本身。
3. 物理残差必须依赖模型预测状态并具有非零梯度路径。
4. 传统分类器用于建立已见、困难域和误报率门槛，不得描述为无效。
5. 第四章必须承接第三章冻结后的模型、任务、数据划分和评价协议。
6. 所有算法先通过共同预算对照与消融，再确定方法名称和缩写。
7. 所有引用回到原论文或出版社页面核验，不引用未经验证的自动生成条目。
