## 设计原则

- **分章独立文件**：每章一个 `.md`，按需单独读取，避免一次性加载全文撑爆上下文。
- **本索引是入口**：先读本 README 了解全局与各章状态，再按需读单章。
- **术语统一**：所有章节命名/术语以 [[开题术语体系]] 为唯一来源（CI-PRD / PIC-GRPO 等）。
- **参考边界**：同门朱焱雷等参考论文仅作结构模板，方法/创新自主（见记忆 `thesis-reference-template-only`）。
- **引用必核实**：参考文献以 PDF 实际为准，见 [[参考文献核验报告_开题报告改进素材]] 与 [[GRPO变体群-方法选型]] 的勘误。
