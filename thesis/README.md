## 第三章当前冻结边界

### 已冻结

- 主实验基座：官方后训练版 `Qwen/Qwen3-0.6B`；`Qwen3-1.7B` 只作方法冻结后的规模提升验证。
- 连续队列状态头：每条四窗口序列预测五个非负归一化状态锚点。
- 物理关系：有限队列控制体守恒残差。
- 可辨识性条件：每条序列必须具有绝对边界锚点 `q0`。
- 监督方式：稀疏状态监督用于检验物理项对未观测状态的增量信息。
- 数据分工：公开数据负责检测与跨域，`ns-3` 负责物理真值与受控因果。

## 数据证据分工

| 数据            | 论文角色                             |
| --------------- | ------------------------------------ |
| GeNIS 2025      | 域内多分类、时间前向和未知攻击主证据 |

## 写作纪律

1. 区分已验证结果、实验候选和最终贡献，禁止把计划写成实验结论。
2. 不再出现“攻击打破守恒律”的表述；攻击改变流量状态，完整守恒关系仍应成立。
3. 物理残差必须依赖模型预测状态并具有非零梯度路径。
4. 不把传统分类器描述为无效；其作用是建立已见、未知和误报率门槛。
5. 第四章必须承接第三章的模型、任务、数据划分和评价协议。
6. 所有算法先通过对照和消融，再确定方法名称与缩写。
7. 所有引用回到原论文或出版社页面核验，不引用未经验证的自动生成条目。
