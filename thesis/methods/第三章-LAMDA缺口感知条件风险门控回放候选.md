# 第三章候选：LAMDA 缺口感知条件风险门控回放

**状态：源年筛选候选，未验证，不能作为论文结论。**

## 动机与作用面

阶段 C 的等单位风险损失扩大良性误报，双风险投影又提高当前恶意漏判。候选将两种作用拆开：第一项只定位当前训练区中上一冻结模型漏判的恶意样本，第二项只在候选更新与安全参考梯度冲突时约束更新。

## 机制一：缺口感知恶意修复

设上一冻结模型的 logit 为 (z_{	heta^-}(x))，分类阈值对应的 logit 为 (a)。当前年度真实恶意样本的修复集合为：

\[
R_t=\{(x,1)\in D_t^{train}:z_{\theta^-}(x)<a\}.
\]

其 margin 缺口为：

\[
d(x)=[a-z_{\theta^-}(x)]_+.
\]

修复损失为：

\[
L_{repair}=\frac{\sum_{(x,1)\in R_t}d(x)\,\operatorname{BCE}(z_\theta(x),1)}{\sum_{(x,1)\in R_t}d(x)}.
\]

分母为零时跳过该项。该定义不使用未来标签，不使用固定前 (K) 个样本，也不把所有当前恶意样本重复加权。

## 机制二：冲突触发双侧风险门控

保护参考集合和良性误报参考集合分别为：

\[
P_t=\{(x,1)\in B_{t-1}:z_{\theta^-}(x)\ge a\},
\]

\[
N_t=\{(x,0)\in D_t^{train}:z_{\theta^-}(x)\ge a\}.
\]

先由当前监督、回放和缺口修复项得到候选梯度 (g)，再计算参考梯度 (g_P,g_N)。只有发生冲突时才执行投影：

\[
g'=\begin{cases}
\Pi_{g_N}(\Pi_{g_P}(g)),&g^\top g_P<0\ \text{或}\ g^\top g_N<0,\\
g,&\text{否则}.
\end{cases}
\]

投影顺序、集合构造和阈值均在源年筛选前冻结。它与始终执行双风险投影的差别是：无安全冲突时不阻塞恶意修复梯度。

## 联合训练问题

\[
L_{base}=L_{cur}+L_{replay}+\lambda_{repair}L_{repair},
\]

先对 (L_{base}) 求梯度，再按机制二的冲突条件得到 (g') 并更新参数。\(\lambda_{repair}\) 必须在来源／开发期按预注册规则确定，禁止使用封印年结果回调。

## 最小四臂与裁决

| 实验臂 | 缺口修复 | 条件风险门控 |
| --- | ---: | ---: |
| ER | 否 | 否 |
| ER＋缺口修复 | 是 | 否 |
| ER＋条件风险门控 | 否 | 是 |
| ER＋两者联合 | 是 | 是 |

固定 LAMDA 发布特征视图、总容量 `200`、模型、训练预算、阈值和年度顺序；只用 `2013/2014` 来源年与 `2016/2017` 开发年进行筛选。通过条件是相对 ER 不增加 FPR 与旧恶意负向翻转，并在 AP、FNR 或当前恶意正向修复率至少一项改善。联合臂只有在两个单臂均有独立信号且联合不劣于最好单臂时才保留。

## 证据边界

A-GEM、回归感知持续学习、困难样本回放和不平衡持续学习只提供方法家族来源。该组合是否适用于 LAMDA，必须由本项目源年真实制品决定；在实验完成前不得称为有效方法或创新结论。
