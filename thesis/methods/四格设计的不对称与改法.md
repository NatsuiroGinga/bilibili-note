# 四格设计的不对称：根源与改法

<!-- RESEARCH_ROUTE=RWKV -->

- 日期：2026-09-02
- 状态：**设计推理，零实验验证**
- 触发：交互项 `I` 被实测判定无判别力，且换机制解决不了

---

## 一、问题重述

预注册判据的第四条 `I = C11 − C10 − C01 + C00 > 0` **已被证明无判别力**：
`z1′`（ETA）的训练通道按构造只存在于 `z2=1` 的两格，故
`I = (C11−C01) − (C10−C00) = [训练＋评价效应] − [仅评价效应]`，
**只要训练通道有任何非零效应 `I>0` 就近乎必然成立，换任何聚合算子结论相同**。

而候选清单第五节指出：候选 2、3、4 都作用于梯度合成，**合成只在 `z2=1` 时有意义**，
同样面临这个问题。**换机制解决不了它。**

---

## 二、与参照论文的结构对比（原件核实）

参照论文表 3-7（印刷页 42）的四格：

| 变体 | 组件 |
| --- | --- |
| Baseline | **PGD-AT** |
| DS-AT | PGD ＋ DS |
| RGO-AT | PGD ＋ RGO |
| DS-RGO | DS ＋ RGO |

**关键：Baseline 不是「什么机制都没有」，而是 PGD 对抗训练。**

| | 参照论文 | 本课题 |
| --- | --- | --- |
| Baseline | **PGD-AT**（已含对抗训练） | **裸 FT**（纯逐流 BCE） |
| 机制一作用于 | PGD 的参数（`ε(t)`、`K(t)`、`α(t)`） | 实体聚合 |
| **Baseline 是否已含该作用对象** | **含** | **不含** |
| 机制一能否在 Baseline 上独立开 | **能** | **不能** |

DS 与 RGO **都依赖 PGD 这个共同底座，但彼此独立**——故在纯 PGD 的 Baseline 上，
两个机制各自可单独开关，四格天然对称。

本课题的 C00 训练损失是纯逐流 BCE，**其中根本没有实体聚合这一步**，
故 ETA 在 `z2=0` 时无处附着，只能做零训练重聚合
（[C10 路线裁决](../../.Codex/docs/RWKV/2026-09-01-C10路线裁决.md)：
`z2=0` 时训练损失是逐流 BCE、尾部聚合不进训练图）。

**结论：不对称不是 ETA 的缺陷，是 Baseline 缺了一层。**

---

## 三、改法：补上共同底座

给本课题补上参照论文的 PGD 所对应的那一层——**实体级损失**：

| 格 | 训练损失 |
| --- | --- |
| C00 | 逐流 BCE ＋ **实体级 BCE（max 聚合）** |
| C10 | 逐流 BCE ＋ **实体级 BCE（ETA 聚合）** |
| C01 | 逐流 BCE ＋ 实体级 BCE（max）＋ BER |
| C11 | 逐流 BCE ＋ 实体级 BCE（ETA）＋ BER |

**得到的性质**：

- ETA 在 `z2=0` 与 `z2=1` **两侧都有训练通道**，`C10−C00` 不再只是评价口径差
- 交互项 `I` 恢复「两个各自有独立训练效应的机制之间的交互」这一原义
- 与参照论文同构：共同底座始终在场，变的只是两个机制的开关

## 四、待验证与代价

**待验证（全部零证据）**：

1. **实体级 BCE 用什么形式**？正实体推高、负实体压低的二分类损失？
   其与 BER 的排序目标是否重复？若重复，`C01−C00` 的增益会被稀释。
2. **三项损失的权重**？现在是两项（逐流 ＋ 排序），加第三项后权重是新的魔法数字，
   且梯度合成从两目标变三目标——**现有控制器与 CAGrad 的两任务分析都要重做**。
3. **是否会削弱 BER 的独立贡献**？实体级 BCE 已经在优化实体分数，
   BER 的边际贡献可能下降，使 `C01−C00` 变小。
4. **C00 不再是「裸 FT」**，与已发表方法池的对比口径需要重新说明。

**代价**：C00 定义改变 ⇒ **四格全部重跑**，且需重开冻结合同、重新预注册判据。
单卡约 20 小时，三卡并行约 8.7 小时。

## 六、正式方案与裁决条件（2026-09-03 用户要求写定）

### 6.1 为什么此前没有推进——如实记录

第三节的改法在 2026-09-01 就写出来了，此后一直没动，**真实原因是代价，不是判断**：
按当时的全容量估算要重跑 `20` 小时，而第五节的替代方案代价为零。
主代理默认走了零代价那条，**没有把这当成一个需要用户裁决的选择摆出来**，
只在进度卡里记了一句「二选一」。这是拿省事冒充判断，本节予以纠正。

### 6.2 缩容档改变了代价账（实测，非估算）

2026-09-02 用户裁定「今后机制候选实验一律在缩容档 `width_profile=half` 上做」，
第四节按全容量写的 `20` 小时已经**过时**。缩容档实测：

| 格 | 单轮实测 | 20 轮 | 依据 |
| --- | ---: | ---: | --- |
| C00-half | `5.6` 分钟（`3.403` 步/秒） | `1.9` 小时 | 已跑满，收据在案 |
| C10-half | 同 C00（训练图相同，见下） | `1.9` 小时 | 推算 |
| C01-half | `14.7` 分钟（`1.19` 步/秒） | `4.9` 小时 | 2026-09-03 实测 |
| C11-half | 约同 C01 | 约 `4.9` 小时 | 推算 |
| **四格串行合计** | — | **约 `13.6` 小时** | — |

补底座后 C00／C10 会增加实体级 BCE 的开销，但那一项只在实体分数上算、
不新增前向，**增幅应远小于 BER**。**故缩容档下改 Baseline 重跑四格约 `14`–`16` 小时，
不是全容量的 `20` 小时；若三卡并行则约 `5`–`6` 小时。**

### 6.3 一个必须先关的疑虑：会不会把 BER 的增益吃掉

第四节第 1、3 条待验证指向同一件事：**实体级 BCE 已经在优化实体分数，
BER 的边际贡献可能因此下降，使 `C01 − C00` 变小。**

这不是可以事后解释的风险，而是**这个改法的主要代价**：
补底座换来了 `I` 的判别力，可能同时削弱两个单机制格的增益幅度。

**处置**：先用现有数据估这个稀释有多大——C01-half 与 C11-half 跑完后，
读它们收据里 `gradient_control` 的 `grad_norm_flow` 与 `grad_norm_rank` 比值，
判断排序损失在总梯度中的份额。份额越小，被实体级 BCE 稀释的风险越高。
**该诊断零成本，数据由已排的运行产出。**

### 6.4 第三项损失带来的连锁问题

加实体级 BCE 后训练目标从两项变三项，**这不是加一行损失那么简单**：

- 三项的权重是**新的魔法数字**，须按根 `AGENTS.md` 的魔法数字门禁登记依据
- 梯度合成从两目标变三目标，**现有控制器（≡ CAGrad 的 `c=1` 边界）
  与全部两任务分析都要重做**——CAGrad 定理 3.2 本就要求全部损失 `H`-Lipschitz，
  而 `L_rank` 非光滑，前提已经不成立；再加一项只会让分析更远
- `C00` 不再是「裸 FT」，与已发表方法池的对比口径要重新说明

**其中第二条最重**：它意味着补底座不只是改 Baseline，**还要重新裁决梯度控制器**。

### 6.5 用户裁决：立即启动（2026-09-03）

**用户在读过 6.3（可能稀释 BER 增益）与 6.4（三项损失的连锁问题）后，
明确指令「立刻修复 Baseline 缺一层的问题」。本改法即刻启动，不等四格数据。**

主代理原先的建议是等 C01-half／C11-half 出数后按下方条件裁决；
用户知情后作出了不同决定，**按用户决定执行**。原建议保留在下方作为记录，
其中的判据仍用于**解释结果**，但不再作为启动闸门。

**随之而来、必须同时处理的三件事**（来自 6.3、6.4，不因加速启动而豁免）：

1. 实体级 BCE 的三项权重是新魔法数字，**须按根 `AGENTS.md` 的门禁登记依据**，
   不得随手取 `1.0`。
2. 梯度合成由两目标变三目标，**现有控制器与全部两任务分析失效**，须重新裁决。
3. 补底座可能压小 `C01 − C00`，**这是已知代价，不是实施缺陷**；
   结果变小时按 6.3 的诊断解释，不得回头削弱实体级 BCE 来把数字做回去。

**正在跑的 C01-half 不停**——它按旧 C00 定义训练，产出仍是有效的对照证据，
且能提供 6.3 所需的梯度份额诊断。新旧两套四格在文档中分别标注，不得混用。

### 6.6 原裁决条件（保留为结果解释依据）

原文如下，**其启动闸门作用已被 6.5 的用户裁决取代**：

1. **若 `C01-half > C00-half` 不成立**——BER 在缩容档上没有正增益，
   整个缩容筛选路线要先重新考虑，补底座无意义。**停，不改。**
2. **若 `I > 0` 且量级足以支撑「两机制互补」的正文主张**——现有四格够用，
   按第五节的耦合观测量补机制解释即可。**不改。**
3. **若 `I > 0` 但量级小到没有说服力，或 `I ≤ 0`**——这是补底座的充分理由，
   **启动本改法**，按 6.2 的代价账重跑四格，并同时处理 6.4 的三项连锁问题。
4. **若 6.3 的诊断显示排序梯度份额已经很小**——提高警惕：
   补底座很可能把 `C01 − C00` 压到不显著。此时应先做单臂预实验
   （只改 C00 加实体级 BCE，与现 C00 比），再决定是否全面重跑。

**判据 3 中「量级小到没有说服力」的机械化定义须在 C11-half 出数前冻结**，
否则本条不得用于裁决。**当前未冻结，记为待补。**
