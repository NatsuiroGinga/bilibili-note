# 四格设计的不对称：根源与改法

<!-- RESEARCH_ROUTE=RWKV -->

- 日期：2026-09-02
- 状态：**设计推理，零实验验证**
- 触发：交互项 `I` 被实测判定无判别力，且换机制解决不了

---

## 一、问题重述

预注册判据的第四条 `I = C11 − C10 − C01 + C00 > 0` **已被证明无判别力**：
`z1′`（ETA）的训练通道按构造只存在于 `z2=1` 的两格，故
`I = (C11−C01) − (C10−C00) = [训练＋评价效应] − [仅评价效应]`，
**只要训练通道有任何非零效应 `I>0` 就近乎必然成立，换任何聚合算子结论相同**。

而候选清单第五节指出：候选 2、3、4 都作用于梯度合成，**合成只在 `z2=1` 时有意义**，
同样面临这个问题。**换机制解决不了它。**

---

## 二、与参照论文的结构对比（原件核实）

参照论文表 3-7（印刷页 42）的四格：

| 变体 | 组件 |
| --- | --- |
| Baseline | **PGD-AT** |
| DS-AT | PGD ＋ DS |
| RGO-AT | PGD ＋ RGO |
| DS-RGO | DS ＋ RGO |

**关键：Baseline 不是「什么机制都没有」，而是 PGD 对抗训练。**

| | 参照论文 | 本课题 |
| --- | --- | --- |
| Baseline | **PGD-AT**（已含对抗训练） | **裸 FT**（纯逐流 BCE） |
| 机制一作用于 | PGD 的参数（`ε(t)`、`K(t)`、`α(t)`） | 实体聚合 |
| **Baseline 是否已含该作用对象** | **含** | **不含** |
| 机制一能否在 Baseline 上独立开 | **能** | **不能** |

DS 与 RGO **都依赖 PGD 这个共同底座，但彼此独立**——故在纯 PGD 的 Baseline 上，
两个机制各自可单独开关，四格天然对称。

本课题的 C00 训练损失是纯逐流 BCE，**其中根本没有实体聚合这一步**，
故 ETA 在 `z2=0` 时无处附着，只能做零训练重聚合
（[C10 路线裁决](../../.Codex/docs/RWKV/2026-09-01-C10路线裁决.md)：
`z2=0` 时训练损失是逐流 BCE、尾部聚合不进训练图）。

**结论：不对称不是 ETA 的缺陷，是 Baseline 缺了一层。**

---

## 三、改法：补上共同底座

给本课题补上参照论文的 PGD 所对应的那一层——**实体级损失**：

| 格 | 训练损失 |
| --- | --- |
| C00 | 逐流 BCE ＋ **实体级 BCE（max 聚合）** |
| C10 | 逐流 BCE ＋ **实体级 BCE（ETA 聚合）** |
| C01 | 逐流 BCE ＋ 实体级 BCE（max）＋ BER |
| C11 | 逐流 BCE ＋ 实体级 BCE（ETA）＋ BER |

**得到的性质**：

- ETA 在 `z2=0` 与 `z2=1` **两侧都有训练通道**，`C10−C00` 不再只是评价口径差
- 交互项 `I` 恢复「两个各自有独立训练效应的机制之间的交互」这一原义
- 与参照论文同构：共同底座始终在场，变的只是两个机制的开关

## 四、待验证与代价

**待验证（全部零证据）**：

1. **实体级 BCE 用什么形式**？正实体推高、负实体压低的二分类损失？
   其与 BER 的排序目标是否重复？若重复，`C01−C00` 的增益会被稀释。
2. **三项损失的权重**？现在是两项（逐流 ＋ 排序），加第三项后权重是新的魔法数字，
   且梯度合成从两目标变三目标——**现有控制器与 CAGrad 的两任务分析都要重做**。
3. **是否会削弱 BER 的独立贡献**？实体级 BCE 已经在优化实体分数，
   BER 的边际贡献可能下降，使 `C01−C00` 变小。
4. **C00 不再是「裸 FT」**，与已发表方法池的对比口径需要重新说明。

**代价**：C00 定义改变 ⇒ **四格全部重跑**，且需重开冻结合同、重新预注册判据。
单卡约 20 小时，三卡并行约 8.7 小时。

## 五、替代方案（未展开）

**保留现有四格，放弃 `I` 的判别力**，改用独立于四格构造的耦合证据——
即[机制耦合观测预注册](../../.Codex/docs/RWKV/2026-09-01-机制耦合观测预注册.md)
冻结的三个观测量（`ξ` 轮内变异系数、活动集跨轮 Jaccard、两层活动集嵌套一致性）。

**该方案的代价为零**（观测量已预注册、数据由现有运行产出），
**但其中两项的门槛与方向声明仍标为「待定」**，须在 C11 启动前补齐冻结，
否则结果不得用于支撑耦合主张。
