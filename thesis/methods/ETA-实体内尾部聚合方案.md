## 一、要解决的问题

一个实体（源 IP）在一段时间内产生多条流。检测器逐流打分后，必须把这些分数聚合成
一个实体级分数，才能在实体粒度作告警决策。

现状取 `S_e = max_t l_{e,t}`。最大值聚合有一个直接后果：**任何单条流的高分都足以
把整个实体推上告警**。在跨年度场景下这尤其危险——目标年出现的新型良性流量只要
有一条被误判，该实体即产生误报，而低误报正是本课题的核心目标。

实测支持这个担忧的量级：源年数据中 `52.05%` 的实体拥有两条以上的流，承载 `99.56%`
的流量；恶意实体流链长度中位数 `112`，良性实体仅 `2`
（[LSPR23 实体历史可用性诊断](../../.Codex/docs/RWKV/2026-08-28-LSPR23实体历史可用性诊断.md)）。
即多数流量来自多流实体，而 max 只看其中一条。

## 二、形式化定义

设实体 `e` 的有效逐流 logit 为 `l_{e,1}, …, l_{e,m_e}`，降序排列记作 `l_(1) ≥ … ≥ l_(m_e)`。

**定义（尾部聚合）**

```
S_e = (1 / k_e) · Σ_{t=1}^{k_e} l_(t) ,    k_e = max(1, ⌈α · m_e⌉)
```

`α ∈ (0, 1/2]` 是尾部水平，**本课题冻结 `α = 0.5`**（依据见第四节）。

### 2.1 与经验条件风险价值的关系

当 `β · m_e` 为整数时，水平 `β` 的经验 CVaR 恰为 top-`(β m_e)` 均值。因此

```
S_e = 水平 β_e 的经验 CVaR ,   β_e = k_e / m_e
```

**这里有一处必须写准的偏差**：由于 `k_e = ⌈α m_e⌉` 取整，`β_e` 逐实体不同，
**并不恒等于 `α`**。真实数据实测（源年验证袋 `13529` 个实体）：

| 量 | 实测值 |
| --- | ---: |
| `β_e` 精确等于 `0.5` 的实体 | `4927 / 13529 = 36.42%` |
| `β_e > 0.5` 的实体 | `63.58%` |
| `β_e` 均值 | `0.7509` |
| `β_e` 中位数 | `0.6667` |

训练截断袋（`121501` 实体）上的对应比例为 `36.43%`，`β_e` 均值 `0.7499`、中位 `0.6667`。

**故「`S_e` 是袋内上半均值」这一表述对 `63.58%` 的实体字面不成立**，正文须改为
「`S_e` 是水平 `β_e = k_e/m_e` 的经验 CVaR，`β_e ≥ α` 且随袋大小取整浮动」。

同一批样本上 `top-⌈αm⌉ 均值 − 精确 CVaR_α` 的偏差恒为负，随袋变小而放大：
`m=3` 时 `−0.1416`（重尾 t3 分布下 `−0.2079`），`m=5` 时 `−0.1107`，
`m=9` 时 `−0.0725`，`m=101` 时 `−0.0077`。按真实袋分布加权，非零偏差比例 `17.5%`，
`|差|` 均值 `0.0178`、最大 `0.495`。

### 2.2 机制作用的刻画：落差恒等式

以下恒等式说明 ETA 相对 max 究竟做了什么。

**命题**　对任意实数序列与任意 `k_e ≥ 1`，

```
S_e = l_(1) − D_e ,    D_e = (1 / k_e) · Σ_{t=1}^{k_e} ( l_(1) − l_(t) ) ≥ 0
```

**证明**　直接展开右式：`l_(1) − (1/k)(k·l_(1) − Σ_{t≤k} l_(t)) = (1/k) Σ_{t≤k} l_(t) = S_e`。∎

这是**精确恒等式**，不依赖降序排列的具体数值、不依赖 `α`、不依赖数据分布。

**推论**

- `D_e = 0` 的充要条件是前 `k_e` 个元素全部并列于最大值；`k_e = 1`（含 `m_e = 1`）时 `D_e ≡ 0`。
- `D_e ≤ l_(1) − l_(m_e)`，即袋内极差。

**机制含义（单侧）**　`D_e` 度量袋内前 `k_e` 条流相对最大值的平均落差。
由 `D_e ≥ 0` 知 `S_e ≤ max_t l_{e,t}` 恒成立，**故 ETA 相对 max 是单侧的：
只惩罚孤立尖峰，不奖励一致可疑**。若多条流同时接近最高分，`D_e → 0`，`S_e` 退化为约等于 max；
若只有个别流冲高，`D_e` 大，`S_e` 被拉低。

**措辞禁令**：不得写成「奖励一致可疑」——恒等式中不存在使 `S_e` 超过 `l_(1)` 的项。

### 2.3 数值验证

恒等式与实现的一致性已核验（`/opt/miniconda3/envs/rwkv/bin/python`，CPU）：

| 检查 | 规模 | 最大相对误差 |
| --- | --- | ---: |
| 恒等式 vs 定义（float64） | 1600 组，`m ∈ {1,2,3,5,10,50,448,10000}` | `1.32e-14` |
| 恒等式 vs 定义（float32） | 同上 | `7.09e-06` |
| 恒等式 vs 真实实现 `tail_aggregate` | 9 实体，含并列与 `1e5` 量级 | `5.18e-16` |
| `tail_scores` vs `tail_aggregate` | 训练侧 `(B,T)` 入口 | `0.00e+00` |

边界情形：`m_e = 1` 与全等袋两类，`D_e` 恒为 `0`，两种精度下均严格通过。
`D_e ≤ 极差` 在 1400 组随机袋中无一违反（最大差值精确为 `0`）。

## 三、数学性质

### 3.1 正仿射等变

top-`k` 的选择集对正仿射变换 `l ↦ a·l + b`（`a > 0`）不变，均值等变，故

```
S_e(a·l + b) = a · S_e(l) + b ,   实测 |误差| < 1e-12
```

**意义**：跨年度特征尺度漂移不改变聚合语义。这是 ETA 相对温度型软聚合（LSE）的
关键差异——后者的温度 `τ` 与 logit 尺度精确混淆（实测恒等式
`S_τ(c·l) = c·S_{cτ}(l)` 误差 `4.4e-16`），尺度一漂聚合锐度即变。

### 3.2 梯度支撑

反向传播时梯度支撑恰为被选中的 `k_e` 条流，闭式为

```
∂S_e / ∂l_{e,t} = (1 / k_e) · 1[ t ∈ top-k_e ]
```

实测：`α = None` 时非零梯度流数为 `66`（逐实体恒为 `1`）；`α = 0.5` 时为 `5403`
（逐实体恒为 `k_e`），支撑身份逐位等于该实体有效流的 top-`k_e`，闭式与 autograd 偏差 `0.000e+00`。
两种 `α` 的逐流梯度余弦仅 `0.111650`——**`α` 确实进入训练图，组合格不会退化为单机制格**。

### 3.3 不具备的性质（归属须写准）

- **非光滑**：在 top-`k` 并列边界处含凹折点，既非光滑亦非弱凸。
- **收敛率不可证**：SOPA 要求光滑、NSWC-FCCO 要求弱凸，两者双双出界。
- **泛化界不可证**：SoRR 原文（物理页 14）自陈单层顶-`k` 的超额泛化关系「很难建立」，两级更难。

**归属更正（2026-09-02）**：上述凹折点**在 `max` 聚合（`z1′ = 0`）下同样存在，不是 ETA 引入的**。
`L_pn = softplus(S_n − S_p)` 在 top-k 并列处的方向导数和 `L'(d) + L'(−d) < 0`，
而弱凸要求处处 `≥ 0`——**BER 本身、不依赖 ETA，就已落在非弱凸的问题类之外**。
ETA 的作用只是使折点集更密，**不改变问题类归属**。
详证见 [BER 方案](BER-预算感知实体排序方案.md) 第 3.3 节。

因此正文写边界时，**收敛率与泛化界不可证应归于两级复合目标整体（主要由 BER 决定），
不得写成「引入尾部聚合导致不可证」**——那会把一个既有性质记在本机制头上。

正文按此写死边界，**不得引用 FCCO／SOX 的收敛结论支撑本方法**。

## 四、参数登记：`α = 0.5`

| 登记项 | 内容 |
| --- | --- |
| 用途和值 | 尾部水平 `α = 0.5`；`k_e = max(1, ⌈m_e/2⌉)` |
| 文献依据 | **无直接文献依据**（任务化设定）。同族算子已发表：ATk（Fan 2017，arXiv:1705.08826，全文已入库）以验证集调参定 `k`、无推荐值；max 与均值为同族两端（Gulcehre 2014 式(3)，物理页 3，全文核验）；经验 CVaR 的 R-U 形式（Zhu 2022 物理页 4，全文核验） |
| 数学推导 | 可行区间由防饱和给出：`⌈αm⌉ < m` 对一切 `m ≥ 2` 成立 ⟺ `α ≤ 1/2`（`m=2` 给必要性；`⌈m/2⌉ ≤ (m+1)/2 < m` 给充分性；穷举 `m ∈ [2, 1e5]` 实测）。取值由机制目的给出：`k_e` 关于 `α` 单调不减，梯度支撑最大化 ⇒ 取可行区间最大元 `1/2` |
| 真实数据诊断 | 袋分布精确复算（16 锚点逐位一致）；中位袋 `2.0`；作用面 `31.63%`（训练截断侧 `32.19%`）；饱和实体 `0`；`y23` 零读取 |
| 适用边界 | 仅两处挂载点——BER 排序损失内的 `S_e`、评价期实体得分；不进入其他模型、损失或阈值。「中位袋退化为 max」依赖本数据中位袋 `=2`，跨数据集不保证；**无饱和条件与分布无关** |
| 接触最终目标标签 | 否（推导只用 `E23`／`T23`／`M23` 与掩码，LSPR24 与 `y23` 均零接触） |
| 核验状态 | 结构性质已实测；**有效性实验待证** |

**该值不依赖任何 AP 读数。** 即使先导实验从未运行，上述两条约束也给出同一个值。

## 五、已知局限

| 局限 | 实测依据 |
| --- | --- |
| **小袋无自由度**：`m_e = 2` 时 `k_e = ⌈0.5×2⌉ = 1`，逐位退化为 max。要 `k_e = 2` 需 `α > 0.5`，而那会使 `m=2` 变整袋平均即 mean-pooling，失去尾部含义 | 源年验证侧中位袋 `m = 2`；`m ≤ 2` 的实体占 `68.4%`（`9250/13529`） |
| **名义水平与实现水平不符** | 见 2.1 节，`β_e` 均值 `0.7509` 而非 `0.5` |
| **取整偏差随袋变小放大** | 见 2.1 节，`m=3` 时偏差 `−0.1416` |
| **训练截断袋、评价完整袋** | 训练用 `truncate_length = 8192` 因果前缀截断，评价用完整袋；偏差符号随袋内漂移方向翻转，无假设不可定界 |

**小袋无自由度是离散取整的数学边界，不是设计疏忽**——两条流的袋，要么取最大的那条、
要么取两条平均，中间没有第三个选项。唯一出路是连续加权（LSE 软聚合），
已按预注册降为退路（四条理由见[尾部聚合参数裁决](../../.Codex/docs/RWKV/2026-09-01-尾部聚合参数裁决/裁决报告.md)第四节）。

## 六、实现

- 训练侧：`tools/ch3_ft_entity_ranking_loss.py` 的 `tail_scores`（约第 289 行）
  与 `tail_aggregate`（约第 149 行）。
- 评价侧：宿主 `tools/ch3_ft_c00_dual_selection.py` 的 `validation_metrics`
  在 `z1′ = 1` 时调用同一实现，**两处必须是同一函数**。
- 形式：静态 ATk——降序 `sort(stable=True)` 加 `arange < k` 权重，
  **无动态 topk、无布尔索引**，`fullgraph=True` 编译零图断裂。
- 并列处置：stable 排序给出确定性子梯度，与既有 max 的 argmax+gather 纪律对齐。
- 自检断言：`k ≡ 1` 与 max 逐位相等（`assert_tail_aggregation_degenerates_to_max`，约第 383–424 行）。

**开关命名（强制）**：代码中 `z1` 已被因果实体记忆 CEM 占用（该候选已否决），
尾部聚合的开关是 **`z1′`**。两者的运行键必须区分，
**否则两代机制一会落在同一个科学身份上**（宿主第 143–154 行）。

四格为 `z1′ × z2`（不是 CEM 那组）：

| 格 | `z1′` | `z2` | 产生方式 |
| --- | :---: | :---: | --- |
| C00 | 0 | 0 | 从头训练，max 聚合选轮 |
| C10 | 1 | 0 | **零训练重聚合**——复用 C00 权重，按 `α=0.5` 独立选轮 |
| C01 | 0 | 1 | 从头训练，BER 损失内用 max |
| C11 | 1 | 1 | 从头训练，BER 损失内用 `S^{(0.5)}` |

## 八、正文可写与不可写

**可以写**

- 尾部聚合的定义、与经验 CVaR 的关系（**须限定 `β_e ≠ α`**）
- 落差恒等式及其单侧惩罚含义
- `α ≤ 1/2` 的充分必要性论证与其在本数据袋分布下的后果
- 正仿射等变性及其对跨年度尺度漂移的意义
- 梯度支撑闭式与作用面实测
- 非光滑、收敛率与泛化界不可证的边界声明

**不可以写**

- 「首次提出」顶-`k` 聚合、两层结构或耦合复合优化——ATk 与 SoRR 已占用
  「顶-k 即 CVaR」「比例式 k」「天花板取整」「两级顶-k」四项主张
- 「`S_e` 是袋内上半均值」不加限定——对 `63.58%` 的实体字面不成立
- 「奖励一致可疑」——恒等式是单侧惩罚，无奖励项
- 引用 FCCO／SOX 的收敛结论支撑本方法
- **四格完成前**：任何「组合优于单机制」的结论，以及交互项 `I` 的符号或幅度

**保留的可主张差量**：实体袋内的具体聚合形式（尾部聚合与预算匹配的组合）、
跨年度封印协议、运营语义的六档预算、时间因果边界。
