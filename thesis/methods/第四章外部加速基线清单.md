### 2.1 本线索的第一个零结果

**检索式**：`safe screening rules pairwise learning AUC maximization exact solution discard samples`；
`safe screening rule CVaR superquantile top-k loss exact equivalence training acceleration`。

**零结果（如实登记）**：**未检索到任何「针对成对 AUC／pAUC 损失推导精确安全筛除规则」的工作。**
检索返回明确给出两点结构性原因：
1. 成对学习必须处理样本对之间的统计依赖，**筛掉一个样本会消掉 `O(n)` 个对**，
   因此 LASSO／SVM 的筛除规则不能直接迁移；
2. 现有安全筛除规则（静态／动态／序贯三类）全部建立在**凸问题的 KKT 条件 ＋ 对偶可行域**上。

**措辞限制（强制）**：零结果来自本次两条英文检索式，**不构成穷尽性证明**；

### 2.3 本次最重要的发现：深度网络里已有「精确零梯度 → 跳过反传」的先例

**这一条修正既有文件的一个隐含前提。** `第四章外部基线清单.md` 把安全筛除族
全部判为不可比，理由是「判据结构依赖凸性，深度网络非凸」。
该理由对**基于对偶可行域的筛除**成立，但它**不等于**
「深度网络里不存在可证明精确的反传剔除」——**存在，且是另一条机理**。

| 字段 | 内容 |
| --- | --- |
| **方法名与出处** | **implicit negative mining（隐式难负样本挖掘）**：Schultheis E, Babbar R, *Towards Memory-Efficient Training for Extremely Large Output Spaces — Learning with 670k Labels on a Single Commodity GPU*，**ECML PKDD 2023**，DOI `10.1007/978-3-031-43418-1_41`（arXiv:2306.03725，机制量化在 **§4.4**）；同作者线 *Speeding-up One-vs-All Training for Extreme Classification via Smart Initialization*，arXiv:2109.13122 |
| **证据等级** | `在线摘要`，**且带一处已知的二手归属风险**（见下方警告） |
| **家族** | **A 精确等价类·安全筛除**，且是**深度学习**设置而非凸优化设置 |
| **机制一句话** | 平方合页损失 `ℓ(y,ŷ)=max(0,1−yŷ)²` 的导数 `∂ℓ/∂ŷ=−2y·max(0,1−yŷ)` 在 `yŷ≥1` 时**恒为零**，故越过间隔的易负样本其反传信号**精确为零**，可在反向 kernel 中直接跳过——**梯度逐位相同，不是近似** |
| **是否可移植到本设置** | **机理高度相关，但不作可运行基线，应作「最近先例」引用**。（1）**可迁移的核心**：与本课题候选二 ASR／候选五 VFP **同一机理**——都由损失的解析结构推出「这部分梯度恰为零」再把零跳过，而非按重要性猜测。这是本课题在**深度学习**范围内能找到的**最近家族先例**；（2）**不可直接移植**：它的零梯度来自**逐点 margin 损失**在标签维度上的稀疏，本课题的零梯度来自**成对／CVaR-pAUC 排序损失**在实体维度上的活动集结构，零的来源不同，判据须独立推导；（3）**一条工程教训必须继承**：原文指出收益要在**反向 kernel 内部**跳过（连操作数加载与结果写回一并省掉）才拿得到，**框架层乘零掩码不省任何事**，因为稀疏矩阵运算是访存瓶颈。这对候选二／五的实现路线是直接约束 |
| **报告加速比** | §4.4：同配置下平方合页损失（SQH）相对 BCE **每轮训练时间降约 `1/3`**，且 P@k 略好、所需轮数更少；arXiv:2109.13122 报**约 `3×`**（一部分来自该效应，一部分来自初始化更接近解）。测量条件：极端多标签分类（XMC），最高 `670k` 标签，单张 `4GB` 商用 GPU，自定义 CUDA 实现 |
| **可用实现** | 作者线有公开代码，**仓库地址与许可证本次未核验** |
| **复现成本** | **高**：要拿到论文级收益须写自定义 CUDA 反向 kernel |

### 2.4 这一发现对第四章立论的影响（必须调整措辞）

**本课题不能声称「首次在深度网络里做可证明精确的反传剔除」**——
implicit negative mining 已经做了，且有 ECML PKDD 2023 的发表记录。
本课题仍可主张的是**更窄但仍成立**的三条：

1. 该先例的零梯度来自**逐点 margin 损失**；本课题来自**成对／CVaR-pAUC 排序损失**，

### 4.1 关键结构性发现：`O(n²)` 规避分两条路线，数值语义完全不同

## 七、判断一：哪些是「同类可比」，哪些只是「正交叠加」

### 7.1 判别标准

一条外部方法与本课题**同类可比**，当且仅当它与本课题机制**争夺同一份计算**——
即两者都在回答「这一步该不该为这个实体建图／反传」。
若它回答的是「同一份计算怎么跑得更快」，则是**正交叠加**。

**可操作化**：设本课题机制为 `M`、外部方法为 `X`。
若两者同时开启时收益**不可加**（互相吃掉对方的收益空间），则同类可比；
若收益近似可乘（`speedup(M+X) ≈ speedup(M)×speedup(X)`），则正交。

### 7.2 分类结论

| 类别 | 成员 | 在第四章实验表中的位置 |
| --- | --- | --- |
| **同类可比（真对手）** | InfoBatch(N3)、Selective-Backprop(既有 E3)、MIDAM(既有 E5)、ContAccum(既有 E4) | **主表**：与本课题候选 ASR／VFP 同表比端到端加速比 |
| **正交叠加（共同底座）** | torch.compile(N10)、FlashAttention(N9)、AMP(N11)、梯度检查点(既有 E1)、meProp(N2)、SparseProp(N13)、激活稀疏(N14) | **不进主表**。写入「实验设置－公共训练配置」，**所有臂统一开启或统一关闭**，并在表注声明 |
| **论述参照（不可运行）** | implicit negative mining(N12)、SOLAM(N15)、安全筛除族(N1、既有 E6/E7)、CRAIG/GradMatch(N4/N5)、Toneva(N6)、Checkmate/DTR(既有 E8/E9)、Inf-CL(既有 E10) | **不进任何表**。写入「相关工作」或「为什么不比 X」的排除段 |
| **内部标定点** | C00 速度上界 `475` s／轮、C01 速度下界 `1181` s／轮 | 主表首尾两行，对位参照论文的 Standard／PGD-AT 角色 |

### 7.3 第四章实验表应该怎么摆（具体建议）

**一张主表，三个分区，外加一条公共配置声明。**

```
表 4-X  训练效率对比（公共底座：torch.compile 全臂同配置，fp32，同一数据成员与切分）
├─ 分区一 端点标定
│   C00（无 BER 排序损失）        475 s/轮   —          ← 速度上界，对位 Standard
│   C01（BER 全量重计算，现状）  1181 s/轮   1.00×      ← 速度下界／归一化锚点，对位 PGD-AT
├─ 分区二 外部基线（★数值语义改变，须单列）
│   ★ InfoBatch 式实体级无偏剪枝           待测        ← 对位 DF-ACR 的「空间维筛选」

│   ★ MIDAM 式袋内随机池化                 待测

    ASR-保形（逐位不变）             待测   上限 1.31–2.05×

    VFP（约 8 ulp）                  待测   上限 1.31–2.05×
```

**四条不可让渡的摆法约束**：
1. **分区二与分区三不得混排比大小**。既有文件与调研 6.5 节均已给出此约束：
   改变数值语义的方法与逐位不变的方法**不在同一档**，须在共同预算下重跑并单列差异。
   建议把「数值语义」独立成列（`不变`／`≈8 ulp`／`有偏`），
   让读者一眼看到代价，而不是只看加速比。
2. **正交项不得作为「被超越的对手」出现**。若第四章写「本方法优于 FlashAttention」，
   属类别错误——两者可同时开启。
3. **加速比必须声明归一化锚点**。参照论文以 PGD-AT 为 `1.0×`；
   本课题应以 **C01 现状**为 `1.0×`，并同时给出**相对 C00 的剩余差距**，
   因为 `2.49` 是算术上限，读者需要知道候选离上限还有多远。
4. **公共底座必须两臂同配置**。尤其 AMP：一旦开启，`8 ulp` 的等价性讨论失去意义，
   故**等价性验证在 fp32 下做、效率验证若开 AMP 则全臂同开**，两者分开报告。

**`6` 个基线里，`2` 个（角色）可直接对位到本课题已有实测，`0` 个（方法）可照搬，

**因此第四章不能靠照搬参照论文的基线立章**，必须自建基线池——
