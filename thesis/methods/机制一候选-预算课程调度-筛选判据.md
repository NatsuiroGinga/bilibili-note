## 二、观测量的精确定义与出处

全部观测量来自既有收据，**不需要新埋点**。

### O1（主观测）各档活动率对 `β_K` 的对数偏离度 `D`

对第 `t` 轮、第 `k` 档（`k = 1..6`，`K_k ∈ {121, 606, 1213, 2426, 4853, 9706}`）：

```
β_k   = K_k / N⁻ ,  N⁻ = 121336（训练角色负实体池规模，冻结配置 budgets_evidence）
a_k(t)= receipts/entity-ranking-diagnostics-<t>.json
        → falsifiable_observables.per_budget_active_rate_epoch_mean
        按键（K_eff = 64·β_k）升序取第 k 项
ρ_k(t)= a_k(t) / β_k
D(t)  = (1/6) · Σ_{k=1..6} |log10 ρ_k(t)|
```

`β_k` 实测值：`0.000997 / 0.004994 / 0.009997 / 0.019994 / 0.039996 / 0.079993`。

**为什么是 `|log10 ρ|` 的六档均值，不是「更接近 1」的朴素说法**：

1. 偏差是**乘性**的。`4.1` 倍过量与 `0.24` 倍不足同样严重，而 `|ρ − 1|` 会把过量惩罚得
   远重于不足（`3.1` 对 `0.76`）。`|log10 ρ|` 对称。
2. 六档**必须合成为一个数**才可机械判定。实测第 10 轮低档过量、高档不足，
   方向相反——「六档都更接近 1」在这种形态下无法裁决。
3. 取均值而非最大值：最大值恒由档 1 决定，判据会退化成单档判据。

**主判据口径**：`D̄ = mean(D(4), D(5), D(6))`，与已冻结的实体 AP 读数窗口一致。

### O2（辅证）`‖g_r‖` 的窗内变异系数

`CV_g = std(g(4..6)) / mean(g(4..6))`，`g(t) = gradient_control.grad_norm_rank_median`。

**必须用逐轮中位数，不得用 `last_step_snapshot.grad_norm_rank`。**
后者是每轮一个末步快照，恢复卡误判登记已有同型教训（「用 20 个末步快照外推全步统计，
末步快照有偏」）。候选文档第二节「`‖g_r‖` 跨三万倍」的七个数正是末步快照，见第五节。

### O3（辅证）被上限卡住的步占比

方向：候选若使 `ξ` 校准更好，`‖g_r‖` 更小更稳，则 `c = 1` 的步应**增多**。

## 三、冻结的裁决规则（三值，**不对称**）

记对照臂为 `A`（C01-half 前 6 轮），候选臂为 `B`（C01-half ＋ 预算课程调度，6 轮）。

```
Δ_D  = 0.1564
Δ_AP = 0.0604

if   D̄_B ≤ D̄_A − Δ_D  and  AP_B > AP_A − Δ_AP :   结论 = 有快速信号
elif D̄_B ≥ D̄_A + Δ_D  or   AP_B ≤ AP_A − Δ_AP :   结论 = 明确反向
else                                             :   结论 = 无快速信号
```

代入对照臂实测：

| 结论 | 机械条件 | 后续动作 |
| --- | --- | --- |
| **有快速信号** | `D̄_B ≤ 0.444159` 且 `AP_B > 0.678293` | 执行任务三（文献 ＋ 机制文档 ＋ 正式实验方案） |
| **无快速信号** | 其余情况 | **不执行任务三**。记为「6 轮缩容档未测出信号，候选降级待议」 |
| **明确反向** | `D̄_B ≥ 0.756955` 或 `AP_B ≤ 0.678293` | 候选降级；理由写回统一评估 |

### 三条必须一并冻结的解释规则

1. **辅证 O2、O3 不参与三值裁决**，只写进报告作机理描述。
   理由：O1、O2、O3 由同一底层量驱动（`ξ` 校准 → 活动集大小 → `‖g_r‖` → `c`），
   **不是独立证据**；把它们并入「全部满足」会制造虚假的多重确认。
   `n = 3` 的 CV 本身也不足以支撑显著性主张。

   **但两条辅证仍各自写死阈值，避免事后按结果选口径**：

   | 辅证 | 同向（记一条支持性描述） | 反向（记一条反对性描述） | 对照臂实测 |
   | --- | --- | --- | ---: |
   | O2 `CV_g` | `CV_g,B ≤ 0.6415` | `CV_g,B ≥ 1.9204` | `0.9602` |
   | O3 `c_eq1` | `c_eq1,B ≥ 356` | `c_eq1,B ≤ 157` | `256.67` |

   `CV_g` 两阈的依据：同向阈取**对照臂平台期（第 8–10 轮）的 CV `0.6415`**——
   窗口 CV `0.9602` 与平台 CV `0.6415` 之差即瞬态对变异的贡献，
   B 臂若把瞬态贡献完全消除即达该值，是「更平稳」的自然上界。
   反向阈取窗口 CV 的 `2` 倍（`1.9204`），为**任务化设定，无文献依据**。
   `c_eq1` 两阈的依据：对照臂窗口均值 `256.67` ± `3` 倍窗内标准差 `33.08`
   （`+99.24 → 355.9`，取 `356`；`−99.24 → 157.4`，取 `157`），
   `3σ` 为**任务化设定，无文献依据**。

   **落在两阈之间者记为「无判别力」，不得解释为任一方向的证据。**

2. **「无快速信号」不等于「机制无效」。** 6 轮缩容档的截断只在 BER 的大效应量级上
   验证过；参照论文的 DS 单独增益仅 `+0.90%`／`+2.70%`（E4），**那种量级在 6 轮缩容档上
   很可能测不出**。故本判据只能筛掉「在本预算下无可见信号者」，
   **不得据此写成「预算课程调度无效」或「该机制被实验否决」**。
   正式实验若另有理由启动，本结论不构成阻断。

3. **「明确反向」才是否决。** 只有 `D̄` 反向超阈或 AP 越过损害门，才允许写「候选被降级」，
   且须同时给出是哪一侧触发。

## 五、一条削弱本候选原动机的实测发现（**冻结前必须记录**）

候选文档第二节的动机是「`‖g_r‖` 在 `0.026`–`825` 之间跳**三万倍**，
活动集在『空』与『过大』之间振荡」。

**该表的七个数出自全容量运行 `ch3-ft-c01-ranking-eager-formal-v2` 的
`last_step_snapshot.gradient_control.grad_norm_rank`——每轮一个末步快照。**

对照臂 C01-half 的**轮级统计量**（每轮 1000 步的中位数）是：

```
889.46 / 216.86 / 112.52 / 42.13 / 16.16 / 3.39 / 0.536 / 0.470 / 0.311 / 0.0964
```

**九个相邻差全部为负，单调下降，无一次反转。** `D(t)` 同样第 1–9 轮单调下降。

**结论**：「`ξ` 在空与过大之间振荡」在轮级统计上不成立；末步快照的跳动是单步抽样噪声。
这与恢复卡误判登记中已有的一条同型教训完全一致。

**但一个真实且已量化的问题仍在**：`ξ` 收敛了，却没有收敛到 `β_K`。
第 10 轮六档比值 `4.136 / 1.666 / 1.105 / 0.690 / 0.454 / 0.318`——
**小预算档系统性过量激活、大预算档系统性不足，跨档相差 `13.0` 倍，方向在十轮中不变。**
这是六个 `ξ` 之间**间距被压缩的系统性偏置**，不是收敛失败。

**这改变了本候选要回答的问题**：作用对象从「让 `ξ` 收敛」变为「让 `ξ` 收敛到各自的 `β_K`」。
前者已经成立，后者才待验证。**逐档引入能否纠正跨档压缩，没有先验理由保证**——
这正是本判据要裁决的，也是它可能失败的主要方式。

**按根 `AGENTS.md`「被否决实现的读数隔离」**：本节纠正的是**读数口径**（末步快照 vs 轮级统计），
不是实现更替；上述轮级统计全部出自当前子梯度 SGD 实现的 C01-half 运行，来源单一、可追溯。

1. **六档的 `per_budget_active_rate_epoch_mean` 必须逐轮全部记录**，含尚未引入的档。
   比较窗口（第 4–6 轮）六档已齐，不受影响；但第 1–3 轮缺失会使机理描述无法写。
2. **`ξ` 的继承规则**：档 `k` 首次参与损失的那一步，若该正实体行的 `ξ[k]` 仍等于
   `init_value`（`0.0`）且 `ξ[k+1] ≠ init_value`，令 `ξ[k] ← ξ[k+1]`。
   `ξ` 表按「正实体 × 档」**惰性初始化**（`tools/ch3_ft_entity_ranking_loss.py:576-580`），
   故继承须按实体行、按步执行，不能只在轮边界做一次全表扫描。
   **若不做继承，本机制退化为「延迟启动」**——严格档只是少训几轮，
   按对照臂的单调收敛曲线必然更差。**继承是机制的作用点，不是实现细节。**
3. **开关默认关闭**；关闭时 `M(t) ≡ {1..6}`，须与改动前逐位相同。
   按恢复卡 L2，做逐位比较前必须先重置全局 RNG，否则骨干的
   `attention_dropout = 0.2`／`ffn_dropout = 0.1` 会给出假阳性失败。

## 七、裁决前必须先核对的两项运行有效性

- **对照臂前 6 轮可直接用作 6 轮预算的对照**：C01-half 配置为 20 轮、第 10 轮停止，
  但优化器无学习率调度器（恢复卡 I／L6，`lr = 1e-4` 常数），
  故「跑 6 轮」与「跑 20 轮取前 6 轮」训练轨迹逐位相同。**无需重跑对照臂。**
- **`budget.epochs` 不进 `science_identity_sha256`**（恢复卡 I，实测改 20→10 后逐位不变），
  故 B 臂设 `epochs = 6` 不改变科学身份，与对照臂仍属同一科学定义族。
