## 一、判据（先于测量冻结，测量结果不得回改本节）

### 1.1 测量一：$w_e$ 的“同量级”判据

**测量对象**：在同一组固定权重（未经优化器更新的初始化权重）下，对 ≥10 个独立采样批次，
分别计算逐流 BCE 梯度 $g_f$ 与实体级 BCE 梯度 $g_e$（按 4.5 节修正后的归一化口径，
即两者都取"均值"口径，一个是逐流均值，一个是逐实体均值），记录比值
$r_i = \lVert g_f\rVert_i / \lVert g_e\rVert_i$（$i$ 为批次编号）。

**登记程序**（照录设计文档 5.2 节）：取其中第一个批次的比值作为 $w_e$ 的登记值，
即 $w_e = r_1$（对应"第一个有效批之后，优化器尚未更新时"的声明步点）。

**判据**：其余 ≥9 个批次的比值 $r_i$（$i \ge 2$）若落在 $[w_e/2,\ 2w_e]$ 区间内
（即 $r_i/w_e \in [0.5, 2]$，$\log_2$ 意义下与 1 的偏差不超过 1），记为
"该批次与登记值同量级"。若 ≥9 个批次中至少 80%（即至少 8 个）落在该区间内，
判定"$w_e$ 的单点登记对同权重、不同批次是稳健的、同量级的"；否则判定"批次间波动超出
同量级范围，$w_e$ 的单点登记存在批次敏感性，须在正文注明该边界"。

**判据来源与理由**：$[0.5, 2]$（即因子 2 以内）是工程上"同一数量级"的常见约定，
本任务在观测任何比值数据前预先选定，不依据测量结果调整。选择它而非更紧的区间
（如 $[0.8, 1.25]$），理由是 $w_e$ 的作用是把 $\rho=w_e\lVert g_e\rVert/\lVert g_f\rVert$
稳定在 $O(1)$ 量级而非精确到个位数（5.2 节：$w_e$ 是方向参数，允许 $\rho$ 漂移），
故判据只需确认量级正确，不要求精确复现单批次比值。

**maximum 与 tail_mean 两种聚合分别独立测量、独立登记 $w_e$**（两者聚合算子不同，
不假定共享同一登记值）。

### 1.2 测量二：埋点方案成本的“可接受”判据

**测量对象**：同一批数据、同一组权重下，方案 A（合并反传）、B（分开反传后相加）、
C（合并反传+每轮一次分开反传）三者的单步相对开销与峰值内存。A 为基线（相对开销定义为 0）。

**判据（分级，非单一阈值，测量前冻结）**：

| 方案 | 单步耗时相对 A 的额外开销 | 判定 |
| --- | --- | --- |
| B | < 20% | 工程可接受，无需与用户核实即可采用 |
| B | 20%–50% | 有代价但可接受，需在正文注明并计入总训练预算 |
| B | > 50% | 代价显著，需报告给用户，由用户决定是否仍按 B 执行或改选 C |
| C | < 5% | 符合"接近 A"的预期（设计文档 7.4 节原话），判定相符 |
| C | ≥ 5% | "接近 A"的预期不成立，须在正文更正该判断 |

峰值内存判据：额外峰值内存相对 A 的增幅 < 10% 记为"可忽略，无需为诊断预留额外设备内存
预算"；≥ 10% 记为"需要报告绝对增量供后续 GPU 显存规划参考"。

**判据来源与理由**：B 是设计文档已给出的推荐方案，其代价是否可接受不改变"S1 需要逐步
样本、C 的每轮 20 个样本无法承载比率比较"这条方法论理由（7.4 节），故本判据不用于否决 B，
只用于量化"代价有多大、是否需要用户在预算层面知情"。20%／50% 两档分界的依据是：
四格串行训练预算约 14–16 小时（[四格设计的不对称与改法](四格设计的不对称与改法.md) 6.2 节），
20% 额外开销意味着增加不到 3.2 小时，属于常规工程余量；50% 意味着增加 7 小时以上，
属于须让用户知情后再决定的量级。C 的 <5% 判据直接取自设计文档 7.4 节对 C 方案的原始
定性描述"接近 A"，本任务把它转成可验证的数值判据。

**如实测某方案在本机测不出有意义的区分度**（例如相对标准差同量级或大于均值差），
按任务要求如实报告为"本机测量噪声下不可区分"，不编造区分度，也不据此断言目标 GPU 上
同样不可区分（本机 CPU 与目标 CUDA 设备的相对开销结构可能不同，见下方环境声明）。

**环境声明（贯穿全文）**：本机测得的是 CPU 后端的相对开销，**未在目标 GPU（RTX 5090，
CUDA 13.0）上验证**。CPU 与 GPU 的前向／反向相对耗时结构、算子并行度和显存带宽特征不同，
本文档的绝对秒数与相对百分比不得直接套用为服务器结论；只有"额外一次反传是否会带来
非平凡的、方向明确的开销"这一定性判断可以跨设备参考，量级须服务器实测复核。
