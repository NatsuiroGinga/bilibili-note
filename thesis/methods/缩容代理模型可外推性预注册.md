# 缩容 FT 能否作为机制筛选的代理模型：预注册判据

<!-- RESEARCH_ROUTE=RWKV -->

- 日期：2026-09-02
- 状态：**预注册**。写于任何缩容运行之前，冻结后不得按结果修改
- 裁决对象：假设 P——「在缩容 FT 上观察到的机制效应方向，可外推到全容量 FT」
- 用途：若 P 成立，后续候选可用缩容模型快速筛选，只把入选者放到全容量上出正文数字

---

## 一、为什么需要这个实验

「小模型有效 ⇒ 大模型有效」**无法事先验证**——要验证它就得把大模型也跑一遍，
筛选即失去意义。但**回溯验证可行**：在同一组机制上分别跑两种容量，比较效应方向。
该实验的产出是可复用的方法学结论，不是机制结论。

**本仓库现有的两条「不可外推」先例均不适用于本问**：

| 先例 | 变化的是什么 | 是否适用 |
| --- | --- | --- |
| 梯度控制器在 MLP 上不压制、在 FT 上归一化 | **架构**（MLP vs Transformer） | **不适用** |
| X23 显存占比本机 M1 `36.8%`、服务器 `1.3%` | **硬件** | **不适用** |
| 本问 | **容量**（同架构、同硬件） | 本仓库**无证据** |

主代理此前曾用前两条论证本问，属不同类证据混用，已更正。

## 二、缩容方案与其登记

**只改宽度，不改深度与头数**：`D_TOKEN: 192 → 96`，`d_ffn_hidden` 按原式联动
`int(96 × 1.333333333333333) = 127`；`N_LAYERS = 3`、`N_HEADS = 8` 保持不变。

| 登记项 | 内容 |
| --- | --- |
| 用途和值 | 代理模型宽度 `d = 96`，为全容量 `192` 的一半 |
| 文献依据 | **无直接文献依据**（任务化设定）。全容量的 `192/3/8` 出自 FT-Transformer 官方默认配方（代码第 99 行注明「官方 TOML 段逐字」），缩容值不属该配方 |
| 数学推导 | 注意力与 FFN 参数量均为 `O(d²)`，宽度减半使参数量约降至 `1/4`。选改宽度而非层数，是因为改深度会同时改变表示的层次结构，可能与机制的作用方式交互；改宽度是更纯粹的容量变化 |
| 适用边界 | 仅用于本外推性实验与后续可能的筛选；**不得进入正文正式结果** |
| 是否接触目标标签 | 否，`target_reads = 0` |
| 核验状态 | **待实验** |

**实现要求**：以**配置项**方式引入（如 `model.width_profile: full｜half`），
默认 `full` 保持现状。**不得直接修改模块常量**，否则会污染正在运行的四格。
配置改变会自动改变 `science_identity_sha256`，运行身份天然隔离。

## 三、实验设计

**最小可比对**：在缩容模型上跑 C00 与 C01 两格，与全容量的同两格比较。

选 C00／C01 而非 C00／C10，理由：C10 是零训练重聚合，其差值只反映评价口径变化；
而 C01 与 C00 的差值反映**真实训练效应**，正是筛选要预测的那类量。

| 运行 | 容量 | `z1′` | `z2` |
| --- | --- | :---: | :---: |
| 全容量 C00 | `d=192` | 0 | 0 |
| 全容量 C01 | `d=192` | 0 | 1 |
| 缩容 C00 | `d=96` | 0 | 0 |
| 缩容 C01 | `d=96` | 0 | 1 |

**除宽度外全部一致**：同代码提交、同数据版本、同种子、同轮数、同即时执行、
同 `float32_matmul_precision = highest`。

## 四、判据（冻结）

记全容量的机制效应 `Δ_full = AP(C01) − AP(C00)`，缩容的 `Δ_half` 同理，
均取源年验证集实体 AP。

**轮数口径（因时间约束而定，2026-09-02）**：筛选实验**不跑满 20 轮**。
取**前 `N` 轮内的实体口径最佳轮**，`N` 对两种容量必须一致。
`N` 的取值由缩容模型的实测单轮墙钟决定——先跑 `1` 轮测速，
使两格合计墙钟落在 `1` 小时以内，再据此定 `N` 并**在启动完整筛选前写回本文件冻结**。

**该口径的已知代价**：全容量 C00 的实体口径最佳轮实测为第 `17` 轮
（旧 C00、旧 C01、旧 C10 亦均为第 17 轮），`N < 17` 时两侧都取不到各自的真实最佳点。
**但本判据比较的是两种容量的效应方向是否一致，不是绝对最优值**——
只要 `N` 两侧一致，截断带来的偏差对双方同向，不破坏方向比较。
**该论证属推论，未经验证**；若 `Δ_full` 在前 `N` 轮内与其全 20 轮的符号相反，
本实验作废并须改用完整轮数重做。此项须在裁决时核对。

### 4.1 主判据

- **支持 P（可外推）**：`Δ_full` 与 `Δ_half` **同号**，且 `Δ_half` 的绝对值
  `> 0.02`（即缩容上的信号本身可辨识，不是噪声）。
- **否决 P**：两者**异号**，且 `|Δ_half| > 0.02`（缩容给出了方向相反的明确信号——
  这是最坏情形，说明缩容筛选会主动误导）。
- **证据不足**：`|Δ_half| ≤ 0.02`（缩容上无可辨识信号，既不能支持也不能否决）。

**`0.02` 的依据**：与[梯度压缩瓶颈判据](梯度压缩瓶颈判据预注册.md)同源——
旧 C00 后十轮实体 AP 标准差实测 `0.0843`，取其约四分之一作为在 `20` 个正实体
验证集上可辨识的最小变化量级。**无文献依据，属任务化设定。**

### 4.2 辅助观测（不参与主判据）

- `Δ_half / Δ_full` 的比值——即使同号，量级差异也影响筛选阈值的可迁移性。
- 缩容模型的单轮墙钟与全容量的比值——**回答「加速比是多少」这个尚无实测的问题**。
- 两种容量下的梯度范数比与余弦序列——检验梯度尺度关系是否随容量变化。

### 4.3 禁止事项

- 不得因结果不利而调整 `0.02` 或改变最佳轮的选取规则。
- **单次运行、单种子，属筛选级证据**；即使支持 P，也只支持「本任务、本机制、本容量比」
  下的外推，不得推广为一般结论。
- 缩容运行的任何指标**不得进入正文正式结果**，`run_tier` 须标 `screening_only`。

## 五、裁决后的用法（写于裁决前）

| 裁决 | 后续 |
| --- | --- |
| **支持 P** | 后续机制候选可先在缩容模型上筛，只把入选者放到全容量出正文数字。**但每次仍须在全容量上复现**，缩容结果不作最终依据 |
| **否决 P** | 缩容筛选**主动误导**，一律不用。所有候选直接在全容量上跑 |
| **证据不足** | 不得据此启用缩容筛选；可考虑增大容量差（如 `d=48`）重试，但那是另一次实验、须另行预注册 |
