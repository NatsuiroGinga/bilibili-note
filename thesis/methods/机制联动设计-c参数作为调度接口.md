## 一、与参照论文的结构对位

参照论文第三章的真实结构（原件行 813–830、901–939 核实，见
[朱焱雷第三章机制组织理解](../../.Codex/docs/RWKV/2026-09-01-朱焱雷第三章机制组织与消融的完整理解.md)
第 4.3 节）：**DS 不是双层博弈的任何一层，而是调度该博弈参数的外部课程机制；
RGO 是博弈内部计算梯度的技术。二者是嵌套关系——DS 为 RGO 所在的博弈供参数。**

本课题现有严格对位物：

| | 参照论文 | 本课题 |
| --- | --- | --- |
| 被调度的「博弈」 | Stackelberg 内层 PGD | **两目标梯度合成**（逐流 BCE vs 排序 CVaR-pAUC） |
| 调度的参数 | `ε(t)`、`K(t)`、`α(t)` | **`c`——CAGrad 的平衡参数** |
| 参数的作用 | 决定内层攻击强度与求解步数 | **决定排序梯度以多大比例进入参数更新** |
| 机制二的位置 | RGO 在博弈内算全导数 | BER 在合成前产出排序梯度 |
| 机制一的位置 | DS 逐轮下发课程参数 | **机制一 = `c` 的课程调度** |

**这个对位的意义**：机制一不再是「另一个作用在别处的模块」，而是**直接调节机制二的
作用强度**。因果链与参照论文同构——调度器给合成过程供参数，合成过程决定机制二的实际影响力。

## 二、`c` 是现成的接口，只是当前被写死

**现有梯度控制器等价于 CAGrad 的 `c = 1` 边界**（文献调研 1.6 节算术核验，
见[多目标梯度冲突文献调研](多目标梯度冲突文献调研.md)）：
它做的是「PCGrad 式投影 ＋ 重归一化到 `‖g_f‖`」。

实测印证（C01 收据 `entity-ranking-diagnostics-{1,2}.json`）：
`controlled_rank_step_norm` 与 `grad_norm_flow` **逐位相等**
（`1.2866296768188477`），幅值比 `1.000000`。

**即：排序梯度被归一化到与逐流梯度同等幅值，`c` 恒为 1。**

CAGrad 的 `c` 在 `[0, ∞)` 上连续可调：`c = 0` 退化为普通梯度下降（完全不管冲突），
`c → ∞` 退化为 MGDA（原文 3.1 节 Remark），`0 ≤ c < 1` 是有收敛保证的中间地带。
**本课题正停在 `c = 1` 这个边界点上，一步未动。**

**⚠️ 方向必须写准（2026-09-02 由文献调研更正）**：**调大 `c` 是朝 MGDA 移动，
即朝「排序目标被删除」移动，不是朝「排序目标获得更大幅值」移动。**
实测依据：把本课题的梯度数字代入 MGDA 的凸包最小范数解，排序目标权重在 epoch 1
被截断为 `0`、epoch 2 为 `0.031%`——极端范数差下最小范数点必然倒向小梯度一侧
（文献调研 1.4 节，算术核验）。

故若目标是**让排序项更强**，该走的不是调大 `c`，而是把全局尺度 `α` 从 `min` 换成 `max`
（DB-MTL 式 2，文献调研 1.5 节）。**但那一项须先核实本课题优化器**——
若是 Adam 一类，全局尺度会被逐坐标二阶矩大部分吸收，实际效果可能远小于表面量级差。

**本节原文未写错但易误读**（「`c` 可调」暗示调大即加强排序），特此标明方向。

## 三、障碍：CAGrad 定理的前提在本课题不成立

**定理 3.2 的假设**（本地全文核验，笔记
`wiki/papers/multi-task-gradient/2021-Liu-CAGrad冲突规避梯度下降.md` 第 110、126、134 行）：

> 假设 `L_0, L_1, …, L_K` 可微，梯度 `∇L_i(θ)` **对所有 `i = 0,1,…,K`** 都是 `H`-Lipschitz，
> `L_0^* > −∞`；取 `0 < α ≤ 1/H`，则 `0 ≤ c < 1` 时
> `Σ_t ‖∇L_0(θ_t)‖² ≤ 2(L_0(θ_0) − L_0^*) / (α(1−c²))`

**关键**：`H`-Lipschitz 要求**对所有 `K+1` 个损失同时成立**，不只是主目标 `L_0`。

本课题的 `L_rank` **非光滑**——`L_pn` 在 top-k 并列边界含凹折点，非光滑亦非弱凸
（[BER 方案](BER-预算感知实体排序方案.md)第 3.3 节，已证）。**故定理前提不成立。**

**一个曾被误判的方向**：CAGrad 原文 3.1 节写明「also applies when `g_0` is the gradient
of some other user-specified objective」，紧接着是「We leave exploring this possibility
as a future direction」。本课题恰好需要 `g_0 = g_f`（逐流损失作主目标），
一度被认为是可重推定理的创新空间。**但重推解决不了问题**——堵路的不是 `g_0` 的选择，
而是 `L_rank` 自身非光滑，它无论如何都在 `L_1…L_K` 里。

## 四、由此指向的路径：光滑化 `L_rank`

若把 `L_rank` 光滑化，定理前提即满足。**现成手段是 LSE 软聚合**——
已实测其梯度良态：max-shift 后 logsumexp 在 logit 幅度 `{1,30,100}` × `τ {1e-3,1,1e3}`
九格值与梯度全部有限，gradcheck 双精度通过，闭式 `dS/dτ = KL(w‖unif)/τ²`
与 autograd 相对差 `≤ 2.5e-14`，`fullgraph` 编译零图断裂
（[尾部聚合参数裁决](../../.Codex/docs/RWKV/2026-09-01-尾部聚合参数裁决/裁决报告.md)第四节）。

**链条**：LSE 光滑化 `L_rank` → CAGrad 定理前提成立 → `c` 调度获得主目标收敛保证
→ 机制一 = `c` 的课程调度，与机制二构成有理论支撑的联合算法。

**这给 LSE 一个全新的启用理由。** LSE 当初被降为预注册退路，四条理由是：
定值问题在硬门处回归、尺度混淆、尾部语义稀释、训练互作风险。
**「满足 CAGrad 光滑性前提」不在这四条之列**，且它是理论性理由而非效果猜测。
按该裁决报告第 142–144 行，退路启用条件原本限定为「ATk 在 CUDA inductor 集成中出现
无法排除的编译断裂或数值不一致」——**本理由属新增，须另行裁决方可启用，
不得直接套用原退路条款。**

## 五、必须先证伪的三条

1. **光滑性是否真能满足**。LSE 本身光滑，但 `L_rank = softplus(S_n − S_p)` 的复合、
   以及外层 CVaR 的 `[·]_+` 是否引入新的不可微点？`[x]_+` 在零点不可微——
   **这一条可能直接推翻整条路径**，须先算清楚。
2. **`c(t)` 的调度函数是新魔法数字**。能否像 `α = 0.5` 那样由不依赖 AP 读数的结构约束
   定死？若只能调参，该候选的登记质量低于 ETA。同理 LSE 的 `τ` 也是新魔法数字，
   且与 logit 尺度精确混淆（实测恒等式 `S_τ(c·l) = c·S_{cτ}(l)` 误差 `4.4e-16`）。
3. **`c = 1` 已是当前有效运行点**。C01 在此点上源年实体 AP `0.9537273846736761`
   对 C00 `0.7887951742121221`。**动 `c` 是否更好毫无证据，甚至可能更差。**
