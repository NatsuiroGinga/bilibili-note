# 第三章联合框架提案台账（逐个排除）

**用途**：2026-09-04 一天内提出了八个「让 ETA 与 BER 联合起来」的方案，
七个已被排除。**本台账是唯一的存废记录，防止重复提出已死方案。**

**排除标准**：只有实测、精确推导或已核验文献可以排除一个提案；
「看起来不对」不构成排除。每条给出证据路径，可复核。

## 零、先摆四个不动的实测事实

所有提案都必须与这四条相容。源年 LSPR23 验证集实体 AP，第 `8`–`10` 轮均值，缩容档：

| 配置 | `max` 读数 | `tail` 读数 |
| --- | ---: | ---: |
| C00（仅共同底座） | `0.691031` | `0.719218` |
| C10（＋ETA，无 BER） | `0.698327` | `0.796184` |
| **C01（＋BER，无 ETA）** | **`0.918431`** | `0.940104` |
| C11（两条通路都开） | `0.751672` | `0.888374` |
| 尾部底座（只开底座通路） | `0.844815` | `0.913744` |

1. **BER 单机制是训练侧最优**：`0.918431`，四个含 ETA 的臂全部低于它。
2. **ETA 单独有效**：C10 对 C00，`max` 口径 `+0.007296`，`tail` 口径 `+0.076966`。
3. **尾部读数一致优于 max**：`5/5` 个臂成立，**包括用纯 `max` 训练的 C00 与 C01**。
4. **ETA 使活动率下降**：C11 对 C01 逐档 `0.63`–`0.77`，六档方向一致。

## 一、已排除的七个提案

### 提案 1：对 ETA 输出作标量尺度校正

**主张**：ETA 压窄了实体分数分布，乘一个校正因子即可恢复 BER 的工作点。

**排除依据**`【实测】`：`ξ` 取的是配对损失的**分位数**，而分位数**对单调缩放不变**。
合成检验中 `max`／`tail` 原始／`tail` 校正后三者的最高档活动率**同为 `0.0859`**。
**原理上无效**，不是参数没调好。

### 提案 2：提高 `xi_learning_rate`

**主张**：`ξ` 的子梯度追踪滞后（空步每步只降 `8.33e-6`），调大步长即可跟上。

**排除依据**`【实测】`：模拟显示方向相反——`lr = 1e-4` 时空步率 `0.043`，
`1e-3` 升至 `0.391`，`3e-3` 升至 `0.402`。低档 `K_eff < 1` 使一个活动对就令 `ξ` 猛跳，
步长越大过冲越狠。

> **该排除的效力有限**：所用模拟复现不了真实基线（模拟末段空步率上限 `0.112`，
> 实测 C01 第 8 轮 `0.395`）。**若要复活本提案，须先在真实收据上重做。**

### 提案 3：裁掉 `K_eff < 1` 的低三档

**主张**：低三档在 `n_neg = 64` 的批里数学上无法表示，去掉即可消除 bang-bang。

**排除依据**`【文献】`：已发表判据（arXiv:2108.04081）为
「测试集规模 × 目标 FPR 若少于 `100` 样本则读数不可靠」。
代入 `N_pop × β = K` 得 `121 … 9706`，**六档全部 `≥ 100`，不支持砍掉任何一档**。
`【实测】`模拟另显示只留后三档空步率反升（`0.043 → 0.112`）。

### 提案 4：活动集门控交替（两机制在时间上不相交）

**主张**：上一步活动集为空时底座用尾部聚合，否则用 `max`；两机制永不同时工作。

**排除依据**`【实测】`：正实体采样器用**不放回轮转**
（`_draw_positive_entities:173-195`，池 `239`、每步取 `2`）。真实采样器重放 `10000` 步：
相邻步共享正实体率 `0.0001`，**比独立抽取还低 `167` 倍**——采样器在结构上反聚集。
第 `8` 轮 `P(空转 | 门开) = 0.392` 对无条件 `0.395`，**门控携带的信息量为零**；
且 `23.98%` 的步会在 BER 活动时误切聚合，**正是方案声称要消除的干扰**。
`【文献】`另：MTL 的 task grouping（SON-GOKU）已有「每步只激活一个色类」的先例，
**「取消同时性」的新颖性亦不成立**。

### 提案 5：可学 `α` 作为联合参数

**主张**：`α` 由 BER 的梯度决定，两机制经同一参数耦合。

**排除依据**`【实测】`：`ch3_ft_entity_ranking_loss.py:245` 为
`k_per_entity = torch.ceil(alpha * m_per_entity).clamp(min=1.0)`，
而 `torch.ceil` 的反向导数在 PyTorch 中**定义为恒零**。
主代理独立复核：`α.grad = tensor(0.)`（**不是 `None`**，不报错、不告警、
优化器照常 `step()`），Adam `lr=1e-2` 跑 `200` 步位移 `0.000000e+00`。
把活动率调到 `100%` 后 `α.grad` 仍精确为零——**症结在聚合算子内部，不在活动集**。

### 提案 6：`ξ` 随 `α` 重新标定，使活动率回到设计值 `β`

**主张**：ETA 使活动率降到设计值以下，重标定 `ξ` 即可补回 BER 的信号。

**排除依据**`【实测】`（第 `8` 轮活动率对设计 `β` 之比）：

| 档 | `C01/β` | `C11/β` | `C11/C01` |
| ---: | ---: | ---: | ---: |
| `121` | `4.21` | `2.71` | `0.64` |
| `606` | `1.92` | `1.48` | `0.77` |
| `1213` | `1.35` | **`1.00`** | `0.74` |
| `2426` | `0.96` | `0.65` | `0.67` |
| `4853` | `0.72` | `0.45` | `0.63` |
| `9706` | `0.53` | `0.34` | `0.64` |

**两处致命**：

1. **C01 自己就不在设计值上**（低档超 `4.21` 倍、高档只有 `0.53` 倍），
   **没有可回归的「正确基准」**。
2. **C11 在低三档反而更接近设计**（最低档 `2.71 < 4.21`，第三档恰为 `1.00`），
   **却表现更差**。故「回到设计活动率 ⟹ 恢复信号 ⟹ 变好」这条因果链被直接否掉。

**连带更正**：「ETA 使活动率下降」成立（`C11/C01` 逐档 `0.63`–`0.77`）；
但**「因此 BER 被饿到设计值以下」不成立**——那是把「相对 C01 下降」
偷换成了「相对设计值不足」。**该错误表述已进入多份文档，须逐一更正。**

### 提案 7：训练侧 BER ＋ 打分侧尾部聚合

**主张**：两机制作用于不同阶段（训练／打分），互不干扰，故可并存增益。

**排除依据**`【实测】`：**它不是联合框架，是两个独立改动**。

| 臂 | `tail − max` |
| --- | ---: |
| C00（**完全没有 BER**） | `+0.028187` |
| C01（有 BER） | `+0.021673` |

**尾部读数的优势在没有 BER 时反而更大**，故它不由 BER 产生、也不增强 BER，
两者之间**没有交互（正负皆无）**。称其为「联合框架」是给加法关系套乘法的名字。

> **本条不否定其价值**：两个独立为正的改动仍可同时采用；
> 但**不得以「联合」「协同」表述**，且尾部打分的跨年度有效性须由目标年评价判定。

## 二、唯一存活的提案

### 提案 8：两级风险聚合（软算子 ＋ 分档软化）

**主张**：级一 ETA（水平 `α`）与级二 BER（水平 `β_K`）需相容；
把硬 top-`k` 与硬 hinge 换为连续算子，使相容点可达。

**状态**：`.Codex/docs/RWKV/2026-09-04-两级风险聚合框架审核.md` 判
**「没有致命项，但现形态不该开工」**。四项阻断、三项须改：

| # | 阻断项 | 等级 |
| --- | --- | --- |
| A1 | `t` 两侧 clamp 打平点漏梯度，`α·m = m` 处 `∂S/∂α` **符号为正**、违反闭式；两种等价写法在打平点差 `2` 倍，**证明该梯度是实现产物** | 阻断 |
| A2 | 判据 2 无法把「换软算子」与「`α` 可学」两个变量分开归因 | 阻断 |
| A3 | `α` 未注册进 `model.parameters()` 时 `optimizer.step()` 静默跳过 | 阻断 |
| A4 | `α` 若用消耗 RNG 的方式初始化，`z1=0` 臂逐位断言以无关原因失败 | 阻断 |
| **A9** | **`α` 会落进 AdamW 的 `with_decay` 组；仅权重衰减一项即产生 `5`–`32` 倍于判据 3 证伪线的位移，方向恒为趋零**——判据 3 会被零学习信号满足，判据 2 会把优化器伪影读成「相容点在 ETA 关闭处」 | 阻断 |

## 三、不依赖任何机制故事的验证路径

**审核给出且主代理核实**：`α` 本就是配置键
`mechanism.entity_aggregation.alpha`，`tail_aggregate` 接受 `(0,1]` 任意浮点。
**改配置即可跑定值扫描，零新代码、零实现风险、不暴露 A1／A3／A4／A9。**

| `α` | 相对 `α=0.5` 的行为改变面 |
| ---: | ---: |
| `0.2` | `0.3219` |
| `1/3` | `0.2696` |
| `0.4` | `0.1485` |

**它直接判本章的核心主张**：「存在某个 `α` 使 ETA 与 BER 的组合优于 BER 单机制」。

- 某个 `α` 使读数 `> 0.918431` ⟹ 联合成立，`α` 是耦合参数
- 三个都不过 ⟹ ETA 在任何聚合水平上都补不回其造成的信号损失，
  **第三章为 BER 单机制，ETA 进消融表**

**代价**：三臂串行，缩容档各约 `77` 分钟。

## 四、七次排除的共同失败模式

| 模式 | 出现于 | 机械修法 |
| --- | --- | --- |
| **没核对算子可微性就在阈值控制器周围找解** | 提案 1、2、3、4、5 | 任何「学一个参数」的方案，提出前先跑该参数的梯度连通性检验（`requires_grad=True`，反传看 `.grad`），十秒 |
| **自建模拟复现不了真实基线，却据以证伪** | 提案 2、3 | 模拟结论只作设计依据，**不作实验证据**；优先真实收据 |
| **把「相对某个臂」偷换成「相对设计值」** | 提案 6 | 引用比值前先核对分母是什么 |
| **凭空推演未查文献** | 提案 8 的手推软 top-`k` | 提出算子前先查文献 |
| **把加法关系说成联合** | 提案 7 | 声称「联合」前，先测两者的交互项是否非零 |
