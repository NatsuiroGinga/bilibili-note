## §2 攻击者最优预算 q*(θ) 的严格定义

### 2.1 设计空间：三个候选定义，两个淘汰

攻击者在离散编辑空间的最优反应，有三个可设想的定义。逐个检验
well-definedness（存在性 / 唯一性 / 可计算性），**不硬造**：

**候选 D1（argmax 版）**：`q̃*(θ;x,y) ∈ argmax_{q ∈ {0..n}} ℓ(f_θ(x^{(q)}), y)`。

**【本文推论】D1 被淘汰，两个独立理由。**

**反例 1（唯一性失败 + 高估门槛）**。设二分类模型在某输入的链上损失轨迹为
`(0.9, 0.1, 0.9)`（`q=0,1,2`）。则 `argmax = {0, 2}` 并列，`q̃*` 不唯一；
且 `q=1` 时损失 0.1 对应的预测已接近随机——若攻击成功判据是置信度跌破阈值，
攻击者用 **1 位**编辑已达成目的，而 argmax 版给出 2。
**argmax 度量的是「哪一档损失最大」，攻击者的实际目标是「哪一档开始成功」——两个目标在
离散空间错位**。错位的根源是层-8 反例揭示的事实：链上损失关于 `q` 非单调
（`loss` 序列可回落），argmax 抓的是峰，攻击者要的是**首次跨越**。∎

（与[文献核查](第三章-离散反应项文献核查.md) §4.4 的裁定一致：若 `q*` 暗含
「`q` 越大越难、反应项方向单一」，与 E2 直接冲突。D1 正是这种暗含。）

**候选 D2（argmin-loss 版）**：`q̂* = argmin_q ℓ`——这是防御者视角的量，不是攻击者反应，
与「调度为何有效」无关，不取。

**候选 D3（最小成功预算，本文主定义）**。见 §2.2。

### 2.2 主定义：评价链上的最小成功预算

**定义 1（成功谓词）**【本文推论】。给定模型 `f_θ`、输入 `x`、标签 `y`、链
`N'(x;n)`，取以下两种口径之一（评价协议用 O1，训练诊断可用 O2）：

- **O1（0-1 口径）**：`succ(q) := 1[ argmax f_θ(x^{(q)}) ≠ y ]`；
- **O2（损失阈值口径）**：`succ(q) := 1[ ℓ(f_θ(x^{(q)}), y) > τ ]`（`τ` 预先冻结，如 `τ = log 2`）。

**定义 2（攻击者最优预算 q*(θ)）**【本文推论】。

```
q*(θ; x, y) := min{ q ∈ {0, 1, …, n} : succ(q) = 1 }，   约定 min ∅ = n + 1。
```

即**使攻击成功的最小编辑预算**；若链上所有档都失败，取 `n+1`（哨兵值，表示
「预算内不可攻破」）。`q*` 依赖 `θ`、`x`、`y`、成功口径与确定性流 `τ(x)`；当语境明确时简写 `q*(θ)`。

**命题 2.1（well-definedness 三关）**【本文推论】。

1. **存在性**：`{0,…,n} ∪ {n+1}` 是有限非空全序集，其任意子集的 `min` 存在。
   （`min ∅ = n+1` 的约定使成功集合为空时仍有定义。）∎
2. **唯一性**：数的最小值唯一。∎
3. **可计算性**：链由确定性流唯一确定（合同裁决 §十二），逐档前向 `q = 0..n`，
   遇首个成功即停；最坏 `n+1` 次前向，`n ≤ 42`（实测 `n_e` 上限 42，[M]），
   故至多 43 次前向可精确计算。∎

**命题 2.2（不需要难度单调假设）**【本文推论】。
`min{q : succ(q)=1}` 的定义**不要求** `succ` 关于 `q` 单调——`succ` 是任意二值序列
（如 `0,1,0,1,1`），`min` 依然良定义。∎

**这是定义选择的关键收益**：草案 E2 与续篇层-8 已证**难度（损失/成功事件）关于预算不单调**
（反例：二元字母表 `loss` 序列 `(1,0)` 型）。任何依赖「`q` 增大 ⇒ 更难」的定义
（如 D1 的 argmax-损失、或把 `q*` 解释为「单调难度轴上的位置」）都被 E2 威胁；
**最小成功预算绕开了这一威胁**。E2 仍然存在，但它的破坏对象从「定义」降级为
「`q*` 的语义解释」（见 §2.4 的结构对位表）。

### 2.3 训练核侧的对位量：层成功率剖面（不强行造链）

**结构缺口**：`q*(θ)` 挂在**评价链**上；训练核（`perturb2`/复合核）不支持链——
它给出的是**层上的均匀采样**（B 核固定层 2，复合核层混合 `{1,2,3,4}`）。
若把定义 2 原样搬到训练核，第 `q` 档对应层 `S_H(body;q)`，成功概率为
`E_{x'~Unif(S_H(x;q))}[succ(x')]`，而层的基数 `C(n,q)·36^q` 是指数级——
**逐档精确计算不可行**。

**【本文推论】定义 3（训练侧层成功率剖面）**。对训练核输入 `x`（body 长 `L_body ≥ 4`）与
预算 `q ∈ {1,…,L_body}`：

```
s_q(θ; x, y) := P_{x' ~ Unif(S_H(x;q))}[ succ(x') ]        （层成功率）
qᵣ*(θ; x, y) := min{ q : s_q(θ;x,y) > ρ }                  （层口径最小成功预算，阈值 ρ 预冻结）
```

- **存在性 / 唯一性**：同命题 2.1（`min` over 有限集，哨兵 `L_body+1`）。∎
- **可计算性（降级为可估计）**：`s_q` 精确计算需遍历指数级层，**不可行**；
  蒙特卡洛估计：每档抽 `K` 个样本，标准误差 `≤ 1/(2√K)`（Hoeffding：`K=400` 时
  误差 `≤ 0.05`，置信 95%）。**逐档 K 次前向 × L_body 档 ⇒ 成本 O(K·L_body) 次前向/样本**，
  离线诊断可行，训练循环内不可行。∎

**【待证假设 H-B（层-点桥）】** 评价链点 `x^{(q)}` 的成功性与训练层均值成功性同序：
对同一 `(x,y)` 与同一预算 `q`，`succ(x^{(q)}) ≈ s_q(θ;x,y)`（不系统性偏离）。
**证伪方式**：源成员上同时测 `succ(x^{(q)})`（链，精确）与 `ŝ_q`（层，蒙特卡洛 K=400），
比较二者在 `q = 1..b_h` 上的相关与均值差；若点质量系统性偏易/偏难（这正是
续篇层-H3 的怀疑），H-B 被证伪。**成本**：零训练、CPU/一次前向批量，~小时级。
**若 H-B 被证伪**：训练侧与评价侧的 `q*` 必须各自报告，不得互换解读——
这正是草案缺口一（训练核 ≠ 评价算子）在 `q*` 语言下的精确形态；
**本文不假设 H-B 成立**，下文所有跨侧推断都标注以 H-B 为条件。

### 2.4 q*(θ) 的性质与语义边界

**【本文推论】命题 2.3（q* 是 θ 的阶梯函数）**。
`θ` 连续、`f_θ` 连续 ⇒ `succ(q)` 只在决策面跨越处翻转 ⇒ `q*(θ)` 是
`θ` 空间上的**局部常值函数**（分段常值），**不连续、不可微**。
（固定 `q`，`{θ : argmax f_θ(x^{(q)}) ≠ y}` 是开集的有限并，`q*(θ)` 在其上取值 `≤ q`。）∎

**与朱焱雷 δ*(θ) 的结构对位**（【沿用原文】朱焱雷全文式 3.7、3.12，行 921、973；
只参照结构，不搬公式——离散梯度处处为零，见[文献核查](第三章-离散反应项文献核查.md) §3.3）：

### 2.5 长度条件化：q*(θ; L) 与作用面边界

**【本文推论】定义 4（按长度桶的条件期望门槛）**。对长度 `L`：

```
q̄*(θ; L) := E[ q*(θ; x, y) | |x| = L ]        （对该长度桶的经验分布取均值）
```

**为什么必须显式带 `L`**（两条实测事实，[M] 复算确认）：

1. **预算的长度依赖**：评价预算 `b_h = max(1,⌊n/2⌋)` 随可编辑位数 `n` 缩放；
   长度 6 的成员 `n ≈ 6` ⇒ `b_h ≈ 3`；长度 26 的成员 `b_h ≈ 13`。
   **同一调度 `q_t` 在不同长度桶里落在完全不同的相对位置**（对短域名是「满档」，
   对长域名是「欠档」）。E3（预算实体依赖）在长度维度上是**系统性的**，不是噪声。
2. **门槛的长度依赖**：`q*` 的上限是 `n+1`（哨兵），而 `n` 随 `L` 增长
   ⇒ 长域名的门槛天花板天然更高。跨长度比较「训练把门槛推高了多少」必须桶内比较。

**【待证假设 H-L（短域名作用面边界）】** 存在长度阈值 `L₀`（预计 `L₀ ∈ {6,7}`），
使得长度 `< L₀` 的实体上，课程调度与全程强核的可区分效应**消失**
（两臂在该桶内的 FNR 差落在噪声带内）。
**证伪方式**：EDIT4/CURRICULUM 运行的检查点，按长度桶分层评价
（评价算子 v2 各档 + 按桶统计 DGA FNR）；若短桶内两臂差与长桶内同量级，H-L 被证伪。
**成本**：训练结束后对已有检查点做分桶前向评价，零训练、CPU/GPU 单次批量，~小时级。
**注意**：H-L 不是「短域名上课程无效」的断言，是**可证伪的作用面假设**；
若被证伪，作用面边界从「长度」改写为「`q*` 与训练核上限的相对位置」
（这个更弱的表述在 §4.3 的窗口语言下自动成立）。

## §4 机制串联：这一环接得上的部分

### 4.1 梯度信号窗口（可证）

**【本文推论】命题 4.1（softmax-CE 梯度范数由 (1−p) 控制）**。
设 logits `z(x')`，`p = p_θ(y|x')`（softmax 概率），`K` 分类，最后一层线性参数 `W`
（`z = W h`），损失 `ℓ = −log p`。则

```
∇_W ℓ = (softmax(z) − e_y) hᵀ，   ‖∇_W ℓ‖₂ ≤ ‖h‖₂ · √2 · (1 − p)。
```

**证明**：`∇_W ℓ = (softmax(z) − e_y) hᵀ`（softmax-CE 标准恒等式）；其向量因子模
`‖softmax(z) − e_y‖² = (p−1)² + Σ_{j≠y} p_j²`；由 `Σ_{j≠y} p_j = 1−p` 与
`p_j² ≤ p_j·max_j p_j`，用 `Σ_{j≠y} p_j² ≤ (Σ_{j≠y} p_j)² = (1−p)²`（因各 `p_j ≥ 0` 且和为 `1−p`，
平方和不超过和的平方）⇒ 总模 `≤ √2·(1−p)`。∎

**推论（两个失效区）**【本文推论】：

- **无信号区**：`p ≥ 1 − ε` ⇒ 梯度范数 `≤ √2·ε·‖h‖` ⇒ 轻松样本梯度任意小，
  该训练对 (x, x^{(q)}) 几乎不贡献参数更新。
- **高损区**：`ℓ = −log p ≥ η`（即 `p ≤ e^{−η}`）⇒ 梯度范数大（≥ `√2(1−e^{−η})‖h‖`）；
  固定学习率下大幅更新对应朱焱雷描述的「严重的梯度震荡甚至模型崩溃」
  （【沿用原文】朱焱雷全文行 847——**只作现象参照**，其表述针对连续空间，
  我们不引用其定量机制）。

**⇒ 单样本梯度信号的有效区是中间置信带**；训练预算 `q_t` 是把训练点
`(x, x^{(q_t)})` 置于哪个置信带的**唯一杠杆**（在核形式固定后）。
**这就是「调度是一个有内容的旋钮」的最小论证**：若不存在置信带结构
（如损失与预算无关），调度无从起效。

### 4.2 调度与门槛：跟踪窗口条件

**【本文推论】定义 5（跟踪窗口）**。给定窗宽 `m ≥ 0`，称调度 `q_t` **m-跟踪**实体
`(x,y)` 的门槛，若

```
q*(θ_t; x, y) ≤ q_t ≤ q*(θ_t; x, y) + m        （对所有 t 与该实体）
```

（训练核侧用定义 3 的 `qᵣ*` 替换，以 H-B 为条件。）

**【本文推论】命题 4.2（跟踪的机制收益，非泛化界）**。若 `q_t` m-跟踪门槛，则：

1. **下界侧**（`q_t ≥ q*`）：训练点 `x^{(q_t)}` 满足 `succ = 1` ⇒ `p < 1/2`（O1 口径）
   ⇒ 训练点**不在无信号区**（`1−p > 1/2`）⇒ 每步有非平凡梯度信号。
2. **上界侧**（`q_t ≤ q* + m`）：训练点至多越过门槛 `m` 档；
   由命题 4.1，训练点损失被 `m` 窗口间接控制（**注意**：由层-8，损失不随越过档数单调，
   此处只能给「越过档数有限」这一弱控制，**不能**给损失上界——除非 H-2 成立，而 H-2 未证）。
3. **否则**：`q_t < q*(θ_t)` ⇒ 训练点落入无信号区（预算不足，浪费核算力）；
   `q_t ≫ q* + m` ⇒ 训练点深入高损区（震荡风险）。

**命题 4.2 是「课程调度为何有效」的机制解释**：
**课程 = 在门槛随训练上移的过程中，让预算序列 `q_t` 尽量留在窗口内**。
弱核先行对应「早期门槛低，小预算已在窗口内」；强核后期对应「门槛被推高后，
小预算跌出窗口（无信号），须加大预算维持信号」。

**【待证假设 H-T（门槛上移）】** 源期训练有效时，`E_x[q*(θ_t; x, y)]` 关于 `t` 非降。
**证伪方式**：在 EDIT4/CURRICULUM 的逐 epoch 检查点上，对固定成员抽样
（如 1,000 成员）离线计算 `q*`（O1 口径，链上逐档前向，≤43 次前向/成员），
检验跨 epoch 的桶内非降性。**成本**：训练结束后单次批量前向，约每 epoch 4.3 万次前向/千成员，
GPU 批量 ~分钟级；**不做 MPS 前向（训练占用中），训练结束后执行**。
**若 H-T 被证伪**（门槛不升或震荡）：命题 4.2 的机制解释不成立，
课程增益只能来自别处（如正则化效应），「跟踪」叙事应否决。

### 4.3 CURRICULUM 臂的现状判定（在窗口语言下）

**【本文推论】** 把运行中的 CURRICULUM 臂（epoch 1 弱核 `q≈2`、epoch 2–3 强核
实际 `q≈3.63`，[M]）放进窗口语言：

- 若 `q*(θ_t)` 轨迹满足 `q*(θ_1) ≤ 2` 且 `q*(θ_2..3) ≤ 3.63 ≤ q*(θ_2..3) + m`（某小 `m`），
  则 CURRICULUM 在跟踪；否则它可能全程在无信号区（若 `q*` 全程 > 4）或全程高损区。
- **对照臂的窗口刻画**：B 臂全程 `q=2`——若门槛上移快于 B 臂预算，B 臂后期落入无信号区
  ⇒ **B 与 CURRICULUM 的差异 = 后期是否维持信号**；D/F 臂全程 `q≈3.63`——若早期门槛低，
  D/F 早期在高损区 ⇒ **D/F 与 CURRICULUM 的差异 = 早期是否避开高损区**。
- 这两条把 D-7 的三条判据（[机制方案](第三章-编辑预算课程调度机制方案.md) §四）
  翻译成机制语言：**「curriculum 优于 D/F」对应「早期高损区有可测代价」；
  「curriculum 优于 B」对应「后期无信号区有可测代价」**。若两者都观测不到，
  窗口机制在本任务上无实证支撑，机制解释应随 D-7 否决而否决。

### 4.4 反应事件：dq*/dθ 的离散对位（可测不可用）

**【本文推论】定义 6（门槛上移事件）**。`R_t := 1[ q*(θ_{t+1}; x, y) > q*(θ_t; x, y) ]`。

朱焱雷的反应梯度 `dδ*/dθ`（式 3.12 的 Indirect 项）在离散对位上是**事件指示**，
对 `θ` 无梯度（命题 2.3）⇒ **不能进入参数更新式**——这正是文献核查 §3.3 的结论
（离散梯度处处为零，需估计器，且估计器给出的是偏差而非恒等式）。
**`q*` 的正确用法是观测量**：`R_t` 的频率与 `q*` 轨迹是「训练把门槛推高多少」的
直接度量，可作为 D-7 附加证据中 `k_t` 代理量之外的**第二个机制诊断量**
（两者互补：`k_t` 代理量测分布漂移，`q*` 轨迹测门槛位置）。

### 4.5 Wasserstein 单调前提的按档维持（对 Shi & Liu 框架的可用部分）

**【本文推论】** Shi & Liu 原文依赖「`W(P̂^adv_t, P̂)` 关于 `t` 非降」的经验观察
（物理页 14978）。在层参数化下（续篇层-13 + 本文 §3 按档裁定）：

- 若调度 `q_t` 非降（课程），则各档 `W_1` 的**上界序列** `q̄_t` 非降；
- **等号**在 B 核档（q=2）近似成立（§3），在评价档只得上界；
- ⇒ **式(16) 的单调性前提在「上界意义」下由构造保证**；但「J 小 ⇒ 泛化好」的
  离散重证缺失（§6.1），故本节只支持**控制律的启发式形式保留**（草案 §4.1），
  不支持任何泛化增益断言。

## §5 q*(θ) 的可用估计器（近似层）

**本章目标（2026-10-13 主代理改向）**：不再要求「推导定理」，改为给出**可用的近似形式
+ 误差量级 + 可用性裁定**。先分清三个被混淆的目标对象——「估计 `q*`」在文献里有三种
不同含义，混用会导致给错估计器：

| 目标对象 | 记号 | 朱焱雷对位 | 用途 |
| --- | --- | --- | --- |
| (i) 门槛对参数的敏感度 | `dq*/dθ` | `dδ*/dθ`（式 3.12 反应项） | 进模型参数更新式 |
| (ii) 门槛位置本身 | `q*(θ_t)` | `δ*(θ;t)` 本身 | 调度控制 |
| (iii) 一次更新对门槛的影响 | `Δ_q(g) = q*(θ+ηg) − q*(θ)` | 朱无对应（朱调 `ε(t)` 预定轨迹） | 在线机制诊断 |

### 5.1 straight-through 对位（BiGrad 式(9) 移植）＝ 现状实现

**【沿用原文】** BiGrad（AAAI 2023，ar5iv 全文已核）式(9)：
`∇_z L = −A∇_x L`，`∇_w L = −C∇_y L`——原文明写「等价于在式(2)中取 `∇_z x = ∇_w y = −I`
且 `∇_y x = 0`，等价于式(7)但不需要重解求解器」；单层情形即 Bengio et al. 2013 的
straight-through，代理梯度 `∇_z x = −I`。BiGrad §3.2 开篇承认「离散变量梯度几乎处处为零，
须 resort to estimating gradients」。

**【本文推论】** 把式(9) 移植到本课题的双层（外层 θ、下层解 = 攻击者反应）：
代理梯度 `∂(攻击者反应)/∂θ = −I` 型代理，等价于**把对抗样本与预算当常数**，
反应项恒零。**含义两条**：

1. **本课题当前实现 = 式(9) 的对位**。主代理核实（2026-10-13）：朱焱雷算法 3.1 的实现
   （外层把 `δ*` 当常数）在实现层与式(9) 等价——朱式 3.12 宣称的反应梯度项在其实现里
   不产生梯度。⇒ **实现层不落后于参照论文**；差异只在理论叙事。
2. **理论叙事上不以反应梯度为卖点**：它在我们的实现里为零，在参照论文的实现里也为零。
   我们的可用产出必须来自 §5.3–§5.5 的估计器，不是「补上朱的公式」。

### 5.2 Pogančić 差分对位（BiGrad 式(7)(8) 移植）与误差量级

**【沿用原文】** BiGrad 式(7a)：`∇_z L ≈ (1/τ)[x(z + τA∇_x L, y) − x(z,y)]`
（对黑箱组合求解器的差分）；式(8) 为其双层整体版 `s(v) = (z,w) ↦ (x,y)`。
移植到本课题：

```
∇_θ F ≈ (1/τ)[ F(θ + τA·g; q*(θ + τA·g)) − F(θ; q*(θ)) ]
```

其中 `F` 为外层目标、`q*` 对扰动后参数**重解**（每次重解 ≤43 次前向/成员）。
**训练轨迹上的免费变体**【本文推论】：

```
Δ_q(t) := q*(θ_{t+1}) − q*(θ_t)          （相邻检查点各算一次 q*，差分免费）
```

（检查点粒度免费，单步粒度需额外重解。）

**【近似 E-1（轨迹差分估计器）】** `Δ_q(t)` 作为「训练把门槛推高多少」的观测量：
来源 BiGrad 式(7)（黑箱解映射差分）；适用条件：检查点间隔足够小（门槛变化不超过
线性区）；**已知误差：量级给不出**。原因如实登记两条：

1. **比较对象缺失**：真值 `dq*/dθ` 几乎处处为零、翻转处无定义（命题 2.3）
   ⇒ 「估计误差」没有标准对象；
2. **文献无界**：BiGrad/Pogančić 原文未给出适用于「解映射为整数标量、解空间 43 个点」
   的误差界条款（式(7)(8)(9) 均无；Pogančić 2019 的界针对连续松弛惩罚形式，不是此设定）。

**能给的信噪描述**【待证假设 H-S】：`Δ_q(t) ∈ {−n,…,+n}` 整数值脉冲，非零当且仅当
该方向的更新跨越某决策面（跳变事件）；跳变概率未测。
**证伪方式**：在 EDIT4/CURRICULUM 检查点上测 `Δ_q` 的经验分布（0 的占比、±1 的占比）。
**成本**：训练结束后批量前向，~小时级。

### 5.3 q* 的严格侧界与廉价估计器（本文主要可用产出）

**【本文推论】命题 5.1（单点侧界，零误差）**。O1 口径下，对任意档 `q ∈ {0..n}`：

```
p_θ(y|x^{(q)}) < 1/2   ⟺   q* ≤ q
```

**证明**：`q* = min{q' : succ(q')=1}`、`succ(q) ⟺ p < 1/2`（O1 定义）。
若 `succ(q)=1`，成功集非空 ⇒ `min ≤ q`；若 `succ(q)=0`，`q` 不在成功集 ⇒ `min > q`。∎

**【本文推论】命题 5.2（两点夹逼）**。测两档 `q_a < q_b`：若 `q_a` 失败且 `q_b` 成功，
则 `q_a < q* ≤ q_b`（区间宽度 `q_b − q_a` **确定**）；两端同态各给半平面信息。∎

### 5.4 反馈控制器（「跟踪 q*」的可实现形式）

**【近似 F-1（bang-bang 反馈调度）】** 基于命题 5.1 的单点侧界，调度不再按预定时间表
（epoch 1 弱、epoch 2–3 强），改为按实体当前门槛反馈：

```
p_t := p_θ(y | x^{(q_t)})                          （训练前向的副产品，零额外成本）
若 p_t ≥ 1 − ε   （无信号区 ⇒ q* > q_t） ⇒ q_{t+1} ← min(q_t + 1, q_cap(x))
若 p_t ≤ p_lo    （高损区   ⇒ q* ≤ q_t 且深入） ⇒ q_{t+1} ← max(q_t − 1, q_min)
否则保持 q_t
```

- **近似来源与依据**：命题 5.1（严格侧界）保证控制量的语义——`p_t` 高 ⇔ 当前预算
  低于门槛（应升），`p_t` 低 ⇔ 当前预算不低于门槛且深入（应降）。
  控制器**不需要显式估计 `q*`**：`p_t` 是训练循环已有的量。
- **适用条件**：逐 batch 反馈粒度过细（噪声大），应在 batch/epoch 聚合级更新
  （如桶内平均 `p_t`）；`q_cap(x)` 受实体可编辑位数约束（`n`），对长度 6 实体
  `q_cap ≈ 3`——**作用面边界被 `q_cap` 自动处理**（H-L 语义）。
- **已知误差与边界（如实）**：由层-8/P0 剖面，`p` 关于 `q` 非单调 ⇒ 控制器可能
  升降抖动（振荡）；稳态窗口宽度 `(p_lo, 1−ε)` 是设计参数；
  **无收敛性保证**——θ 非平稳 + 离散控制，控制理论的标准工具（需 Lipschitz/凸性）
  不适用，本文不给收敛证明。∎
- **与固定课程的关系**：反馈调度把「调度」从**时间维**（epoch 1 弱、epoch 2 强）改为
  **实体维**（按实体当前门槛反馈）。若 H-L 成立（短域名上固定课程无差别），
  反馈调度在该桶自动退化到对应档——**作用面边界从「披露义务」变成「机制内建」**。
  这是反馈调度区别于固定课程的**唯一实质增量主张**，且它本身是待证假设【待证假设 H-F】：
  **证伪方式**：同预算下反馈臂 vs CURRICULUM 臂的分桶 FNR 对比；
  若两臂差异与噪声不可分，H-F 被证伪。**成本**：一个筛选臂（约与 D-7 同量级）；
  可先在 D-7 检查点上离线模拟反馈轨迹（零训练）预筛。

   ⇒ 等号破裂。∎

## §8 总裁决：这一环能否接上

**分层回答。**

**机制解释层：能接上**（本文推论，推导完整）：

1. `q*(θ)` **定义得出**——最小成功预算（定义 2），存在性 / 唯一性 / 可计算性三关全过，
   且**不依赖难度单调假设**（命题 2.2，绕开 E2/层-8 威胁）。
   淘汰的 argmax 版定义附完整反例（§2.1）。
2. 「课程调度 = 对 `q*(θ_t)` 的跟踪」**有严格的可检验形式**——跟踪窗口条件（定义 5）
   + 窗口的机制收益（命题 4.2：下界侧保梯度信号、上界侧限越过档数）。
   朱焱雷「调度改可行域 ⇒ 改最优反应」的结构在本课题的离散对位即此。
3. 调度作为旋钮的**最小论证**成立：CE 梯度范数 `∝ (1−p)`（命题 4.1，纯代数）
   ⇒ 存在无信号区与高损区 ⇒ 预算是唯一杠杆 ⇒ 调度有内容。
4. 作用面边界显式化：`q*` 必须按长度桶条件化（定义 4）；
   「预算极小区」的主体是**评价侧 `q ≤ 3` 的 28.5% 成员**（复算修正：
   训练核零层退化仅 0.09%，不是四分之一）。

**估计器层（§5）：有可用产出，按估计器分级**：

1. **零误差可用**：单点侧界（命题 5.1）与两点夹逼（命题 5.2）——严格命题、
   训练循环免费或 +1 前向、与调度控制的接口直接（控制器状态量就是 `p_t`）。
2. **可进训练循环的近似**：反馈调度 F-1（§5.4）——把「调度」从时间维改为实体维，
   状态量零额外成本，作用面边界内建于 `q_cap(x)`；**无收敛保证（如实声明），
   增益主张（H-F）待实验**。
3. **只可离线诊断**：轨迹差分 E-1 与 Pogančić 差分——误差量级**给不出**
   （真值缺失 + 文献无界，§5.2 两条原因如实登记）；
   straight-through 对位 = 现状实现，无新信息。
4. **P0 剖面是现成的实证支点**：对抗训练臂在紧误报工作点的成功率剖面反向单调
   （§5.3 表），既实证支撑层-8/E2，也直接排除二分/跳步类估计器，
   并给「固定课程隐含非单调难度轴」提供数据。

**泛化界层：接不上**（§6.1，如实声明）：

- 朱焱雷式的「反应梯度直接推出机制为何有效」依赖两个本课题不具备的条件：
  连续反应变量的可微性（离散下是阶梯函数）与离散版泛化界（未重证）。
- 本文的替代品是**机制解释 + 可用近似 + 可测判据**：`q*` 轨迹（H-T）、跟踪三态占比、
  分桶作用面（H-L）、层-点桥（H-B）、反馈调度（H-F）。
  它们把「调度为何有效」从「理论叙事」变成**可以在 D-7 结束后被数据回答的问题清单**——
  这是本课题在离散空间能诚实拿到的最强形式。

**能否支撑「方法的第二组件」（如实裁定）**：

- **作为「可检验机制组件」：能。** 反馈调度（§5.4）具备组件资格的四要素：
  严格侧界支撑（命题 5.1，零误差）、零额外成本的状态量、可证伪的增量主张（H-F）、
  与固定课程的实质差异（实体维适配，作用面边界内建）。
- **作为「已验证组件」：不能（现在就说）。** 增益存在性完全取决于实验：
  D-7 若否决固定课程，反馈调度作为「更好的调度」也失去前提；
  即使 D-7 通过，反馈 vs 固定的增量是又一轮实验问题。
  **且有一个共同失效模式**：若 D-7 逐轮 loss 轨迹显示弱核与强核 epoch 的 loss 几乎不变
  （门槛没被训练移动），窗口机制、反馈机制同时失据——这条可用 D-7 已有的
  逐轮 loss 轨迹直接查，是**所有调度机制的第一道经验门**。
  （机制方案 §六.4 反例义务继续有效：不得因理论漂亮而保留机制。）
- **定位**：反馈调度若成立，它的表述不是「理论推出的新机制」，
  而是「**同一编辑算子底座上，把固定课程的时间维调度推广到实体维**」——
