## 二、机制一：ETA

**定义**：`S_e = (1/k_e)·Σ_{top-k_e} l_{e,t}`，`k_e = max(1, ⌈0.5·m_e⌉)`。

| 项 | 状态 |
| --- | --- |
| 形式化 | **完成**，六项公式与性质（定义、CVaR 等价、`α` 充要性、等变性、梯度支撑、落差恒等式） |
| `α = 0.5` 的登记 | **完成**，两条不依赖 AP 读数的结构约束唯一确定 |
| 机制作用刻画 | **完成**——落差恒等式 `S_e = max − D_e`，对位参照论文式(3.25)，且是恒等式而非近似 |
| 效果 | **未验**。源年 `C10 > C00`（`+0.0714`）已过判据第一条，目标年门未测 |
| **已知弱点** | 对照组 C01 的内层已是经验 CVaR，机制一只是移动尾部水平；交互项无判别力 |

## 三、机制二：BER

**定义**：多预算 CVaR-pAUC，六档预算，`ξ` 子梯度 SGD。

| 项 | 状态 |
| --- | --- |
| 形式化 | **完成**，含无偏引理、非 FCCO 命题、非弱凸证明、收敛与泛化不可证的边界 |
| 效果 | **旧编译路径下**源年实体 AP `0.9537` 对 C00 `0.7888`、目标年 `+0.0567`；**须在冻结合同下重跑方可计入正式四格** |
| 梯度行为 | 七轮实测：`‖g_r‖` 跨四个数量级（`0.026`–`825`），与活动率强相关；余弦震荡无稳定趋势 |
| **已知弱点** | 低三档 `K_eff < 1` 超出 SOPA 整数假设；`ξ` 收敛不到正确分位数、活动集时空时溢 |

## 四、联合框架

**当前形态**：两机制通过 `S_e` 串联——ETA 产出实体分数，BER 在其上做多预算排序。

| 项 | 状态 |
| --- | --- |
| 形式对位 | **成立**：内层实体内聚合 ＋ 外层实体间排序，同属容量帽单纯形／R-U 对偶族 |
| **耦合强度** | **弱**。「嵌套 CVaR」只在负实体分支成立（`∂L/∂S_p ≤ 0` 是 MIL 语义）；对照组内层已是 CVaR |
| **交互项判别力** | **无**。`z1′` 训练通道按构造只在 `z2=1` 存在，`I>0` 近乎必然，换任何聚合算子同理 |
| 联合算法伪代码 | **缺**——参照论文有算法 3.1，本课题尚未写 |
| 独立耦合证据 | 三个观测量已预注册，但**两项门槛待冻结**，须在 C11 启动前补齐 |

**根源诊断（已定位）**：参照论文的 Baseline 是 **PGD-AT**（共同底座已在场），DS 与 RGO
都依赖它但彼此独立，故四格天然对称；本课题 C00 是**纯逐流 BCE**，训练损失里没有实体聚合，
ETA 无处附着。**不对称是 Baseline 缺一层，不是机制的毛病。**
