## 二、跨篇观察（**我方推论，非论文自述**）

### 2.1 决定性的一条：**没有一篇处理「标签本身随年份退化」**

SEED 明确**把标签噪声排除在建模范围之外**（§1，见上表）；ADAPT、LFreeDA、MORPH 用伪标签但**都假定源侧标签干净**。
⇒ **标签可靠性建模（本课题 C2）在 9 篇近邻中是系统性缺席的。**
**但**：这与我方 C2 的**评价循环性风险**是同一枚硬币——他们不做，可能正是因为**没有独立锚**。
**⇒ 该缺口是真空，但「无人做」不等于「做得成」，必须先解决锚的问题。**

### 2.2 类别不对称漂移下的工作点控制，被承认但无人系统做

- ADAPT 自述固定阈值因**良性/恶意漂移模式不同**而受限（ADAPT:168）
- MADCAT 实测**恶意侧偶尔不如基线**（MADCAT:221）——即「TTA 的收益偏向良性侧」
- SEED **只在 BODMAS 单数据集**做了 `FPR = 10⁻¹–10⁻⁴` operating point，**未作主指标**
- 本地 **E1 已实测**：源标定阈值在目标年**过保守迁移**（A 组 FPR 远低于预算），
  自校准阈值把 FNR 降 11–30 点**但仍高**（2016 甚至变差）

**⇒ 三条独立证据指向同一个未解问题：决策边界的迁移与两类漂移速率不匹配。**
**但本地 E1 已裁定「残余失败在排序质量层」** ⇒ 纯阈值机制**不足以**单独成章，
只能作为**表征侧机制的配套项**。

### 2.3 对抗 × 漂移：两篇把「对抗」列为未处理的局限

ADAPT §X 明写「**we do not explicitly address adversarial examples**」；
LFreeDA §7 只「outline」未实测。
⇒ **交叉点在近邻中确实空着**（与本路线 C4 查证代理的四问互相印证，待其回收）。

### 2.4 ⚠️ 特征空间**不是**分离的（本节 2026-10-14 更正）

**本节初稿写「没有一篇使用稀疏二值词袋」——该论断错误，已作废。** 结构化笔记的逐篇字段表显示：

| 论文 | 特征表示 |

| MORPH | **稀疏二值**（16,978 / 2,381 维） |
| Dream | **稀疏二值** / MaMaDroid 包对 / Damd opcode |
| ADAPT | **稀疏二值**（16,978 / 1,159 / 2,381 / 950 维） |
| DRMD | **稀疏二值**（Drebin 10k / Ramda 379 维） |
| **SEED** | **DREBIN 特征**（1,150 / 2,381 维）——原文 §Experimental Setup：「we used **DREBIN features** for training」 |
| LFreeDA | 图像 ＋ CFG |
| HYDRA | 分层图 CFG+FCG（对照 Drebin 静态特征） |
| Sabbah | 静态 ＋ 动态特征 |

**⇒ 8 篇中 5 篇使用同一族表示（稀疏二值静态特征）。**
LAMDA 的 4,561 维只是同族中的另一个维度，**不构成技术差异化**。
**⇒「表示独有性」这条论据作废，C1 的剩余差量进一步收缩为「LAMDA 数据集本身」**——
这是比初稿判断**更严重**的结论，不是更轻。

### 2.5 作用层分布：策略层拥挤，表征层稀疏

9 篇中作用于「**更新策略 / 伪标签选择 / 记忆 / RL 控制器**」的占 8 篇；
只有 **MADCAT** 明确作用于**表征**（TTA 微调编码器），而**它自己的弱项就在恶意侧**（§2.2）。
本地 **E1 实测损伤是全局表征漂移**（良性 P90 `0.025→0.844`）、且本课题**九个被否决实现全部作用于策略层**。
⇒ **表征层仍是证据最少、本课题最少失败过的作用面**——这与 2026-10-14 综述的原有判断**(b)** 一致。

### 2.6 其余可攻点（较小）

| 点 | 出处 | 可攻性 |
| --- | --- | --- |
| 缓冲区内存无界增长 | SEED §8 | 工程型改进，创新强度低 |
| 成本用「样本数」代理 | HYDRA §Results | 度量学贡献，非算法贡献 |
| 「没有确定性规则全局最优」 | self-sup+RL §Results | 可导向自适应选择，但需新证据支撑因果 |
