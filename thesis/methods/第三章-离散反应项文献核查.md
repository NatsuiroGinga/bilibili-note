### 2.1 C1 细节（子问题 1 的核心命中，本地全文）

`wiki/papers/attack-detection/2026-Jureckova-恶意软件检测双层共演化.md`；
原件 `raw/papers/attack-detection/2026-Jureckova-Bilevel-Malware-CoEvolution.pdf`；
Zotero 全文 key `SYD8BRPX`（已逐条核对）。

- **显式写出离散空间的双层与最优反应**（§5.1，p.5）：

```
min_{θ∈Θ} (1/|D^train|) Σ_{(x,y)∈D^train} L( f_θ(x + δ*(θ)), y )          —— (2)
s.t.  δ*(θ) ∈ arg max_{δ ∈ S(x)} L_atk( f_θ(x + δ), y )                    —— (3)
```

  原文原句：「The **inner problem** represents the attacker's best response `δ*(θ)` to a fixed model `θ`,
  while the **outer problem** represents the defender's quest for parameters `θ` that are robust to that
  optimal response.」（§5.1，p.5）
- `S(x)` 是**离散变换集**：`δ ∈ S(x)`，`Sem(x) = Sem(x_adv)`（式(1)，§3.1，p.3，PE 空间
  functionality-preserving 变换）。
- **关键限定**：**它不用隐函数定理或展开优化求 `dδ*/dθ`**，而用**迭代最优响应（IBR）**近似
  （算法 1，§5.3）：防御者用「原始训练集 ∪ 历轮全部对抗样本」**累积重训**（式(5)，p.6），
  攻击者每轮对**最新**模型从头重搜（式(4)，p.5）。原文把原因归给离散性：
  「Given the **discrete nature** of the PE file transformation space `S(x)`, we monitor convergence
  through the stability of the evasion rate across successive iterations.」（§5.3，p.5）
- **不能外推**：对象是 Windows PE 二进制 + EMBER 2018 特征 + Random Forest，**无 DGA/域名实验**、
  无时间轴；每家族仅 500 条平衡子集（§6.1，p.6）；作者把结论限定回该特征集与架构（§6.8，p.9）。

### 2.2 C2 细节（子问题 3 的核心命中，在线全文已核）

`arXiv:2302.14473`，Francesco Alesiani，**AAAI 2023**（arXiv API `arxiv:comment` 核验：
"Accepted for presentation at AAAI23"；正式出处 DOI `10.1609/aaai.v37i12.26716`）。全文经 curl 取
`https://ar5iv.labs.arxiv.org/html/2302.14473` 正文核对。

- **把双层当隐层 + 用隐函数定理**（§3 上文）：`H(x,y,z)=0`，`(x,y)=Solve_H(z)`；
  前向用现成双层求解器，反向用**隐函数定理/灵敏度分析**，不下传穿过求解器。
- **含交互项的主结果（Thm 3，式(6)）**：

```
d_z L = ∇_z L + [∇_x L + ∇_y L · ∇_x y] ∇_z x            —— (6a)
d_w L = ∇_w L + [∇_x L · ∇_y x + ∇_y L] ∇_w y            —— (6b)
```

  原文：「The `∇_x y, ∇_y x` terms **capture the interaction between outer and inner problems**.」
  ⇒ **式(6) 的交叉项就是「反应项」的离散对位形态**。
- **离散（组合）情形需梯度估计**（§3.2）：「When we consider discrete variables, the gradient is
  **zero almost everywhere**.」给出两类估计器：式(7)(8) 借 Pogančić et al. 2019 的黑箱组合求解器
  差分 `∇_z L ≈ (1/τ)[x(z+τA∇_x L,y) − x(z,y)]`；式(9) straight-through 形式
  `∇_z L = −A∇_x L`（`∇_z x = −I` 代理梯度）。
- **离散对抗实验（§5.2，式(13)）**：

```
min_{x∈Q} max_{y∈B} ⟨z + x, y⟩                            —— (13)
```

  其中 `x` 是攻击者（可切换 `Q` 个离散变量）、`y` 是离散层输出、`z` 为待学参数；实验为
  CIFAR-10 离散特征对抗（`Q=10`，表 2），对比 vanilla CNN / 单层 max / 双层 min-max，
  并报告「min-max 网络对对抗攻击更鲁棒」。⇒ **离散空间的「攻击者反应」在可微框架下已被实现，
  不是空白。**
- **局限（原文自陈）**：未探索混合整数（mixed-variable）问题；依赖现成求解器给双层解。

### 2.3 C3 细节（离散空间约束形式化，本地全文）

- 问题空间（离散）攻击的四类约束 `Γ = {可用变换 T、保持语义 Υ、合理性 Π、预处理鲁棒性 Λ}`
  （定义 8–12，p.7–8）；`Γ ⊢ Ω`。
- **副效应特征 `η`**（定义 13，p.8–9）：为满足离散约束附带产生、**不沿梯度方向**的特征改动。
- **投影单调性**（p.9）：特征空间攻击投影到问题空间后，攻击置信度**必然不高于**原特征空间攻击。
- ⇒ 这是「离散空间不能纯梯度搜索」的权威出处（定义 14，式(5)，p.10），但**不是反应项模型**。

## §3 明确裁决

### 3.1 子问题 1：**有现成答案（形式化层面已存在，求解层面被离散性绕开）**

**有。** 离散动作空间上的双层 + 攻击者最优反应 `δ*(θ)` 已被显式写出：

- **Jurečková 2026 式(2)(3)**（**本地全文**，已回原件）：`S(x)` 为离散变换集，
  `δ*(θ) ∈ arg max_{δ∈S(x)} L_atk(f_θ(x+δ),y)`。
  **但其求解走 IBR，不求 `dδ*/dθ`**——原文明确以离散性为由放弃梯度路线（§5.3，p.5）。
- **BiGrad §5.2 式(13)**（**在线全文**）：`min_{x∈Q} max_{y∈B} ⟨z+x,y⟩`，
  攻击者切换 `Q` 个离散变量，**反应项经 Thm 3 式(6) 的交互项 + 式(7)(8)(9) 梯度估计器求**。
- 邻接：BETA（在线摘要）把离散/0-1 目标改写为可微规划；悲观双层战略对手（在线摘要，文本分类）
  用下层 `argmin` 作为对手反应；FAST-BAT（仅题录）处理符号离散操作的双层化。

**结论**：本课题「离散双层 + 攻击者最优反应」**不是空白**。可借用工具见 §3.3。

### 3.2 子问题 2：**检索未发现离散/DGA 空间的 `q*(θ)` 现成答案**

- **连续 `l_p` 空间有近似答案**（**在线摘要级**）：**DES**（arXiv:2506.04263）逐样本、逐迭代自适应
  调 `ε`，线索含到决策边界的距离、softmax 熵置信度、MC-dropout 不确定度——即**预算＝模型状态的
  函数**；**SAAT**（arXiv:2210.01288）「perturbation budget will be **adaptively adjusted according
  to the training state**」。二者已把预算写成 `ε(θ, x, t)`。
- **DGA/离散侧只有「随机预算」，没有 `q*(θ)`**：Drichel AsiaCCS'24（**本地全文**，§4.4.1，p.7）
  在 DGA 离散域对抗训练中把预算**随机采样**（`ε~U`、HotFlip 翻转数 `n ~ U{1,…,10}`），
  理由是引 Kurakin「单一预算训练不能泛化到其他预算」；**不是模型参数的函数**。
- A³（**本地全文**）是**评价侧**按在线统计重分配攻击迭代预算，对象仍是白盒 PGD，不是 DGA 离散。

**结论**：在**离散/DGA 空间**，把 `q` 显式建模为模型参数函数 `q*(θ)` **本轮检索未发现**。
已覆盖的检索面见 §5；**不主张「无人做过」**。连续空间的 DES/SAAT 是最接近的可迁移范式。

> **须登记的核验纠正**：在线检索摘要曾把 arXiv `2506.12733` 标为「Learnable Dynamic Epsilon
> Scheduling (ADES)」。经 **arXiv API 核验**，`2506.12733` 实为
> 「Learning to Fuse: Modality-Aware Adaptive Scheduling for Robust Multimodal Foundation Models」，
> **与对抗训练预算无关**。⇒ 该「ADES」条目**不采信、不引用**。

### 3.3 子问题 3：**有可借用的替代工具，但没有「离散隐函数定理」这样的定理**

**有替代工具，形态是「隐层 + 梯度估计器」，不是「离散 IFT」。**

- **BiGrad（arXiv:2302.14473，AAAI 2023）**（**在线全文**）：把双层（含**离散**下层）建模为
  隐层 `H(x,y,z)=0`；连续变量用隐函数定理 + 向量-雅可比积（式(5)）；离散变量因「梯度几乎处处为零」
  改用**一类梯度估计器**（Thm 3 式(6)，含交互项；式(7)(8) 差分、式(9) straight-through）。
- **底层工具链**（**在线摘要**）：Pogančić et al. 2019（DBB，黑箱组合求解器差分）、
  Berthet et al. 2020（可微扰动优化器，随机平滑）、Vlastelica et al.（分段线性插值）、
  Niepert et al. 2021（I-MLE，perturb-and-MAP）。
- **负结论（在线摘要级检索）**：常规 `implicit function theorem` / hypergradient 文献集
  （AID/ITD、Non-Convex Bilevel Games、amortized implicit differentiation 等）
  **只覆盖连续双层，不覆盖组合/离散**。⇒ 离散对位**不能直接用经典 IFT**，
  必须走 §3.3 的估计器路线。

**结论**：离散空间**没有**「隐函数定理」的定理级对位；**有**工程可用的替代——把离散下层当隐层，
用差分/平滑类梯度估计器（BiGrad 式(7)(8)(9)）求反应项。**展开优化在离散下对应「对求解器做差分」**
（Pogančić/Vlastelica），而非对迭代轨迹反传。

## §4 对本课题的直接含义：`q*(θ)` 这条路是否值得继续推

**判定：值得推，但必须改换形式；直接照搬「连续反应项」不可行。**

1. **不算空白，但空位真实存在。** 离散双层 + 攻击者最优反应**已被形式化**（C1 式(2)(3)；
   C2 式(13)），所以**不能把「离散空间做双层/反应项」本身当作创新**。真正的空位是
   **把「编辑预算 `q`」当作可学的反应变量**（子问题 2 在 DGA/离散空间检索未发现）——这正好是本课题
   `q` 的位置。
2. **技术路径已现成，不必自创。** 用 BiGrad 式(9)（straight-through，`∇_z x = −I`）或式(7)(8)
   （差分）即可把「选 `q`」写成可微层；无需重新证明离散 IFT。
3. **两条既有解的代价对比（用于选型）**：
   - **IBR（C1 路线）**：不学反应项，只做「攻击者每轮重搜 + 防御者累积重训」。
     实现最省、**已有离散 PE 实证**（ER 90% → 0–1.89%），**但没有 `q*(θ)`**。
   - **可微反应项（C2 路线）**：能给出 `dq*/dθ` 一类的反应信号，**但有离散梯度估计器的偏差/方差代价**，
     且 **C2 的实验仅 CIFAR 离散特征（`Q=10`）**，未在域名/编辑空间验证。
4. **与本课题已有的硬约束冲突点（必须先解决，否则 `q*(θ)` 前提不成立）**：
   - `第三章-受限期编辑集的泛化界形式化草案.md` **§4.2 E2** 已写死：**难度不保证关于 `q` 单调**
     （预算 `q` 控制的是链上固定点 `x^{(q)}`，不是球上的 max；合同裁决 §十二 明写「攻击成功事件
     不因位置嵌套自动单调」）。而 §4.2 H-2「难度单调性」是**待证假设**。
     ⇒ **若 `q*(θ)` 暗含「`q` 越大越难、故反应项方向单一」，将直接与 E2 冲突**；
     必须先用 H-2 的零训练证伪实验（源年成员上测 `loss(f(x^{(q)}),y)` 对 `q` 是否单调）确定
     `q` 与难度的关系，再决定 `q*(θ)` 是否定义良好。
   - 形式化草案 §8「缺口一」：**理论/评价算子是共享前缀确定性流 `N'`，而训练核是随机位置的
     `perturb2`**。`q*(θ)` 若挂在评价算子上，对训练无用；挂在训练核上，则需先补两算子同构证据。
5. **建议的最小下一步（零训练、CPU、可证伪）**：
   先做形式化草案 §7 已列的 **H-2**（`loss` 关于 `q` 的单调性），它同时是 `q*(θ)` 是否成立的**前置门**；
   若 H-2 被证伪，`q*(θ)` 这一支应**否决或改写成「按分面/分实体条件化」**，而不是继续推连续类比。

**一句话**：`q*(θ)` 值得继续推，但**先做 H-2**；技术形式应借 BiGrad 的离散梯度估计器，
而**不是**照搬朱焱雷的连续展开优化。
