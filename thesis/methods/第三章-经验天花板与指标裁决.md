# 第三章：经验天花板与指标裁决

<!-- RESEARCH_ROUTE=RWKV -->

- **状态日期**：2026-09-07
- **对象**：DRIFT-DGA 2026 作为第三章候选主数据时的经验天花板、主目标、指标层级和正式 `2×2` 报告合同。
- **证据状态**：设计可行、实验待证。本文件不填本课题结果，不修改 Goal、恢复卡、实验代码或当前运行。
- **关联台账**：[第三章数据、模型与机制统一候选筛选台账](第三章-数据模型机制统一候选筛选台账.md)。

## 一、核心裁决

**DRIFT 的非饱和不能定义为“总体 F1 必须达到 99%”。** 原论文报告 2020--2025 微平均 F1 为 `0.964630`、2025 FPR 为 `0.096520`、测试独有 83 个家族的 FNR 为 `0.143913`。这些数字只证明未来良性误报和未见家族漏检仍有候选错误余量，不证明该余量能被本课题机制稳定降低。

经验天花板当前仍是**未完全确认**，理由是：

1. 截至 2026-09-07，真正引用 DRIFT 的 A 类论文为 `0`，使用数据但未规范引用的 B 类工作为 `0`；没有第三方复现或同协议改进结果。
2. 原论文没有给固定低 FPR 下的完整检出曲线、部分 AUC、置信区间或配对检验。
3. 原论文不报告随机种子、训练重复、方差或训练随机性区间。
4. 原论文没有报告训练年与未来年相同有效二级域的严格排除结果。
5. 总体微平均 F1 会被高支持家族和特定工作点主导，不能替代未来良性 FPR、未见家族 FNR 与跨家族宏平均。

因此，第三章当前只能提出可证伪问题：**在相同信息权限、相同阈值选择合同和相同评价成员上，候选机制能否改善低误报区域与未见家族的绝对检测性能，同时守住总体、已见家族和资源指标。**

## 二、经验天花板的判定对象

### 2.1 不是单个总体 F1

经验天花板不是有界指标到 `1.0` 的剩余距离，也不是人为指定的 `0.99`。它应由现实协议下最强可复现 C00 的错误类型、运营代价和测量精度共同决定。

DRIFT 当前的三个已发表锚点承担不同角色：

| 锚点 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| 总体 F1 `0.964630` | 原方法在 2020--2025 混合评价上的总体判别较强 | 低误报区域饱和、未见家族饱和、本课题 C00 可复现 |
| 2025 FPR `0.096520` | 原论文选定工作点的未来良性误报仍高 | 固定低 FPR 曲线形状、源阈值迁移后的 FPR、最优可达 FPR |
| 未见家族 FNR `0.143913` | 测试独有家族仍有漏检 | 该漏检能由任一候选机制修复、区间不跨零、训练随机性可忽略 |

### 2.2 经验天花板确认门

只有以下证据同时就绪，才允许把“有候选错误余量”升级为“本课题存在可检测经验余量”：

1. 在冻结数据版本、成员、预处理、训练预算和信息合同下复现共同 C00。
2. 输出未来年份和未见家族的完整低误报曲线或经依据冻结的运营区间，而不是只报一个总体 F1。
3. 对相同域名的固定预测生成配对区间，证明预期最小实际效应不小于测量不确定性。
4. 报告跨年份与跨家族宏平均，避免高支持年份或家族掩盖困难分面。
5. 报告源/训练域、已见家族、总体 F1 和资源护栏，排除以牺牲基础性能换取表面保持率。

若共同 C00 在现实低误报区、未见家族和跨年份/跨家族宏平均上均已接近不可分辨区，且错误数量或运营代价不足以支持预注册最小实际效应，则将 DRIFT 标为 `已否决`，停止昂贵机制搜索。不得删除强字段、减少 C00 预算或改弱基线制造余量。

## 三、主目标与阈值合同

### 3.1 主目标

主目标按优先顺序定义为：

1. 在相同信息合同和冻结阈值选择规则下，于固定 FPR 或完整低误报曲线上降低未见家族 FNR，即提高未见家族 TPR。
2. 或在相同未见家族/未来年检出水平下，降低未来良性 FPR。
3. 同时保持总体 F1、已见家族性能和资源护栏。

总体 F1 是护栏和背景指标，**不是 `99%` 硬目标，也不是唯一冠军指标**。

### 3.2 “同一阈值”的可执行含义

- 部署表使用同一冻结的阈值构造与校准信息合同。若各格分数刻度可直接共享，使用同一数值阈值；否则各格只能在相同源侧校准成员上按同一算法各自产生阈值。
- 目标年或未见家族标签不得用于选择阈值、FPR 点、模型、检查点或曲线截断范围。
- 排序表可报告各格在固定 FPR 上的 TPR/FNR，但阈值搜索只能作为评价函数；必须与源侧冻结阈值搬移后的实际 `(FPR, TPR, FP, FN)` 分表，不能把目标标签确定的工作点伪装成部署阈值。
- 具体 FPR 点、部分 AUC 上限、运营预算和非劣容差必须由全文、实际运营预算或源侧数据分辨率冻结。当前没有充分依据时统一写“待依据冻结”，不得填习惯值或从结果反推能过门的数字。

## 四、指标层级

### 4.1 一级主指标：低误报与未见家族

| 指标 | 评价单位 | 用途 | 当前数值状态 |
| --- | --- | --- | --- |
| 未见家族 `TPR@FPR` / `FNR@FPR` | 域名，按未见家族分面 | 直接衡量低误报区的未来家族检出 | FPR 点待全文或运营预算冻结 |
| 未见家族低误报部分 AUC | 域名 | 避免单一工作点偶然性 | 积分范围待依据冻结 |
| 完整低误报预算曲线 | 域名；良性侧提供 FPR，DGA 侧提供 TPR/FNR | 主展示；检查候选是否只在局部点有利 | 预算网格待依据冻结，不预填 |
| 同检出水平下的未来良性 FPR | 域名 | 直接比较减少误报的能力 | 检出水平待依据冻结 |

### 4.2 二级泛化指标

| 指标 | 聚合规则 | 作用 |
| --- | --- | --- |
| 2020--2025 各年 FPR/FNR | 每年单列，不先微平均 | 识别 2024--2025 等困难未来年份 |
| 跨年份宏平均 | 每个未来年份等权 | 防止样本量最大的年份主导结论 |
| 已见/未见家族分表 | 家族身份来自冻结 raw/family 合同 | 分离时间变化与组合/家族外推 |
| 跨家族宏平均 TPR/FNR | 每个合法家族等权；零支持家族按预注册规则处理 | 防止头部家族掩盖长尾失败 |
| 家族最坏组或低分位表现 | 仅在支持量门通过后报告 | 发现严重家族失败；分位点需依据冻结 |

### 4.3 三级护栏

| 护栏 | 必报内容 | 失败含义 |
| --- | --- | --- |
| 总体 F1 | 2020--2025 总体及逐年值 | 候选不能以显著总体退化换局部分面收益 |
| 已见家族 | TPR/FNR、低误报曲线和宏平均 | 未见家族收益不能由破坏已见家族取得 |
| 训练/源域 | 与目标同粒度指标、损失和校准表现 | 防止压低训练域性能制造更好保持率 |
| 资源 | 参数、激活参数、峰值显存、墙钟、吞吐、额外内存/状态 | 性能收益必须与新增成本并列 |
| 机制活动 | 各机制特有活动量与直接近邻差量 | 非零活动不等于有效，但零活动直接否决机制实现 |

## 五、防止“压低源域刷保持率”

设 C00 为共同基线，候选格为 `c`，训练/源域指标为 `S`，未见域绝对指标为 `U`。对“越大越好”的指标报告：

```text
Delta_source(c) = S_c - S_00
Delta_unseen(c) = U_c - U_00
```

对 FNR/FPR 等“越小越好”的指标，统一先转为收益方向或同时给原值与差值，禁止混用符号。

候选获得支持必须满足：

1. `Delta_unseen(c)` 在预注册主指标上为严格正，且达到预先冻结的最小实际效应与配对区间要求。
2. 训练/源域、总体 F1 和已见家族不越过预注册非劣护栏。
3. 跨年保持率或退化差只能作辅助描述。若保持率改善来自 `Delta_source(c)<0`，必须单独列出源域损失，不得把它计为全部抗漂移收益。
4. 未见域绝对值没有提升时，即使保持率、相对下降比例或归一化指标更好，也不通过主门。

## 六、统计与单种子边界

- 所有训练只使用一个预先冻结的随机种子；四格共享初始化规则、数据顺序、预算和选模权限。
- 域名级指标在相同域名的四格预测上做配对 bootstrap 或配对置换。不得把各格独立区间是否重叠当作配对检验。
- 跨家族宏平均以家族为自然聚合单位；可对家族级配对差重采样，或在家族内域名重采样后再对家族等权汇总。具体层级须在结果前冻结。
- 跨年份宏平均保留年份层；不得把六个年份或同一家族的多个域名当作训练随机种子。
- 重采样次数、置信水平、同时区间和多重比较方法须由蒙特卡洛误差目标、主张族和研究把握度登记；当前无依据不填数。
- 上述区间只量化**固定种子、固定模型、固定评价成员**下的评价不确定性，不覆盖训练随机性，不得写成多次训练稳定性或总体训练分布推断。

## 七、先复现 C00，再确认余量

执行顺序固定为：

1. 冻结 DRIFT 数据 revision、训练/验证/未来年份、跨年重复处理、家族身份、信息权限、C00 结构、训练预算和阈值规则。
2. 用唯一冻结种子复现 C00，保存模型、配置、日志、数据清单、指标程序和资源收据。
3. 对 C00 生成完整低误报曲线、未来年逐年 FPR/FNR、未见家族曲线、跨年份/跨家族宏平均和配对评价区间。
4. 将本项目 C00 与原论文 `0.964630/0.096520/0.143913` 只作协议差异明确的复现核查；字段、成员、阈值或预算不同时不得直接判胜负。
5. 依据现实运营差值与测量精度登记最小实际效应。若指标已在不可分辨的饱和区，淘汰 DRIFT；若存在可检测余量，才允许单机制短训。

当前正式 T17→T25 零训练探针只回答输入病灶和数据资格，不是 C00 复现，也不能确认经验天花板。

## 九、可写与禁写主张

### 9.1 当前可写

- “DRIFT 原论文在 2020--2025 报告微平均 F1 `0.964630`，但 2025 FPR 为 `0.096520`，未见家族 FNR 为 `0.143913`。”
- “这些数字表明低误报和未见家族存在候选错误余量；本课题是否存在可检测改进余量仍需同协议 C00、完整曲线和评价区间确认。”
- “总体 F1 是护栏，第三章主目标是固定信息与阈值合同下的未见家族绝对检出和未来良性低误报表现。”
- “单冻结种子的域名/家族配对重采样只量化固定预测集的评价不确定性。”
- “若现实低误报和未见家族指标也进入不可分辨饱和区，则淘汰 DRIFT，不弱化基线制造空间。”

### 9.2 当前禁写

- “DRIFT F1 没到 99%，所以一定非饱和”或“必须把 F1 做到 99%”。
- “F1 `0.964630` 已证明经验天花板”或“2025 FPR/未见家族 FNR 保证候选机制能提升”。
- “第三方已复现 DRIFT”或把 `A=0/B=0` 写成“全世界没有后续工作”。
- 在没有依据时写具体 FPR 点、部分 AUC 上限、效应阈值、置信水平、重采样次数或资源上限。
- 用目标年/未见家族标签选择阈值或模型，再称为源侧冻结评价。
- 只报告保持率或相对下降，隐藏训练域绝对性能下降和未见域绝对值未提升。
- 把单种子配对区间称为训练随机性、多种子稳定性或普遍泛化证明。
- 预填 C00/C10/C01/C11 的提升、冠军、交互或有效性。
