- 恶意侧候选按 `fooled = 1[p_cand < 0.5]` 二值化，组内计算 `fooled - mean(fooled)`，跨组统一降序取前 `64` 个；实现位置为 `official_p2p3.py` 第 408–445 行，核心选择位于第 431–441 行。该实现没有 `A > 0` 资格门，并列由 Python 稳定排序及生成顺序处理。

### 3.2 可保留的最小原创差量

1. **实现层最小差量只能写成任务化组合**：在 DGA 同源字符候选池上，以二值规避状态构造留一组中心分数，按该分数让不同源组竞争一个固定全局配额，再对入选候选用 CE 更新；同时对当前误报的真良性样本作三倍 CE 加权。Batch-in-Batch 已覆盖同源多候选与误分类过滤，RLOO／GRPO 已覆盖组基线，GFPO 已覆盖“多采样—按外部度量过滤 top-`k`—以策略目标更新”，Selective Adversarial Training 已覆盖“跨样本固定预算—按 margin／梯度相似度选择—以对抗 CE 训练”，ESAT 已覆盖“全训练集跨源排序—固定源样本预算—平均熵选择／交叉熵训练分离”，Seesaw 已覆盖当前误分类触发的逐样本负类补偿。现阶段只剩**每源多候选的二值留一组分数用于批内跨源候选统一配额，并形成可变组份额，再与真良性固定三倍 CE 组合**这一完整运算链尚未被已取得全文逐式覆盖；只能称“任务化组合差量”，不能称新理论或首次方法。
2. **可送外部复核的最小数学差量**：优先保留 `1A` 的当前无门实现三层填充律、`F16` 的 `top-A≠top-CE` 显式反例、`F18/3A` 的全局有符号组重加权修正式。三者直接解释当前算法实际选择什么、与理想鲁棒 max 差在哪里，且不依赖渐近外推。
3. **只宜放附录的条件推导**：`1B`、`3C`、`3D` 依赖独立同分布、固定或联合增长预算、内部成功率与严格排序等强条件，不适用于当前 `K=4,Q=64`，不应承担第三章主原创性。
4. 上述任何差量都只说明结构或恒等关系。**是否提高检测与鲁棒表现仍是实验待证**，不得用排重结果代替共同预算基线、消融与统计实验。

### 3.3 必须降级或删除的主张

- 删除“分布级攻击比点级攻击更强／更新颖”：`T1` 表明纯支持分布族与点上确界等价。
- 删除“对称双侧最坏分布已实现”：当前良性侧没有扰动生成和内层最大，只是原始真良性样本的状态依赖加权。
- 删除“组相对优势、留一基线、误分类过滤、top-`q` 或困难样本选择本身原创”：这些分别被 RLOO／GRPO、Batch-in-Batch、GFPO、SoRR／Selective Backprop 覆盖。
- 删除“当前选择器是最大 CE 的 Monte Carlo 估计器”：`F16` 给出反例，准确表述只能是“按 `A` 排名、以 CE 评价”的预算代理。
- 降级 `F6/2A`：四篇 P0-A 原始全文已经确认代价敏感负类权重、当前输出驱动的负类非对称和误分类触发补偿均有先例；当前固定工作点、真良性掩码与常数 `3` 只能算任务化设定。即使尚未检得逐式同构，也不能写“首次”，作用仍须单因素实验。
- 将 `F20–F23` 从当前方法机制删除，至多移入明确标注的“第二阶段未实现扩展”。尤其 `T3/T4` 对当前实现不适用：真实 T17 三档同时满足共享前缀与 Hamming 界为 **`0/30,000`**，只能作为未来**新显式共享编辑算子**的条件命题。
- `T5` 是三角不等式与柯西不等式导出的标准路径能量下界；不得写成新的最优运输定理。
