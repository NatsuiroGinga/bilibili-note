T17→T18→T19 只构成源期筛选代理：T17 用于筛选训练，T18 用于一次开发反馈，T19 用于一次冻结确认；任何读数只决定止损，不进入正式表。正式训练仍严格使用官方 T17–T19 `train+test` 合并集，并用 T17–T19 `val` 验证与选轮。T20–T25 必须在全部合同冻结后整批一次开启；不得逐年查看、按单年结果修改设计，再继续下一年。

T25 不弃用、不隐藏：它必须与 T20–T24 一起进入正式主结果表，并作为最新年份列完整报告。此前误先读取的 T25 标签分面只隔离为探索证据，不得决定候选存废、调参、阈值、C00、公式、参数、检查点或代码；正式方案须在源期重新裁决后冻结。T25 正式结果无论方向一致或相反均完整报告，不反馈设计。

- **候选设计提示**：恶意侧关注未见家族 FNR，良性侧关注未来 FPR；双侧漂移只提示设计方向，不据此冻结具体机制。

## 五、低误报评价的两种口径

### 5.1 源冻结阈值迁移

- 阈值只由源验证数据确定，随后不变地应用到未来年份。
- 该口径回答“源侧部署决策迁移到未来年后实际误报与检出如何变化”。
- 阈值选择规则、源验证成员、并列处理和跨年报告程序必须在读取未来年结果前冻结。
- **主口径**：低误报正式结果以源验证阈值迁移为主。

### 5.2 目标 ROC 排序上界

- 使用目标年标签绘制 ROC，并在目标曲线上读取对应排序能力。
- 该口径是 `target_informed` 的逐年排序上界或诊断，不是源冻结部署阈值性能。
- 它不得用于反向选择模型、机制、超参数或正式阈值，也不得与源冻结阈值迁移混成同一主指标。
- **辅助口径**：目标 ROC 只作明确标注为 `oracle` 的排序上界。

**数值门暂不冻结**：本文件不写具体低误报预算。待全文依据、统计支持量和文献代理回复齐备后，主代理再登记数值、推导、适用边界与失败条件。

## 六、当前阻断项

1. **家族到 eSLD 映射阻断**：官方 README 只说明 `test.py` 所需的按家族拆分数据未公开，不等于发布数据没有家族字段。主代理已实测 `raw_including_TLD/*.parquet` 含 `domain,family,label`：T17 DGA 有 `58` 个家族、`16,981,076` 行，T25 有 `143` 个家族、`26,882,985` 行，交集 `54` 个，T25-only 为 `89` 个家族、`10,282,823` 行，且 `family` 无空值。但 raw 完整域名的 `family` 尚未与官方 eSLD 模型输入建立确定性映射、去重和冲突收据，不能把 raw 家族标签直接连接到 eSLD 预测。
2. **家族口径阻断**：上述 `58/143/54/89` 只证明发布文件模式与计数，不是正式“未见家族”结果。论文的 `65/83` 口径比较 T17–T19 与 T20–T25，且共享生成器可能制造伪未见；正式分面必须在六年角色、生成器等价和 raw→eSLD 映射核验后重算。
3. **跨年重复去重阻断**：官方加载器只在源合并集和各未来年内部调用 `unique()`，未执行源年与未来年之间的实体互斥。当前建议剔除源侧已见 eSLD 后的新实体集为主、官方全量年度集为辅，但必须先完成只读重叠与生成器等价审计再冻结。共享生成器可能制造伪“未见”家族，不能只凭家族名称或字符串差异判定新颖性。
4. **良性污染阻断**：进入训练或评价前须核验良性集合的污染清理规则及其实现收据；未经核验的良性标签不得支撑低误报结论。
5. **阈值阻断**：低误报数值预算、源阈值选择程序和目标 ROC 上界报告规则尚缺全文与数据支持量依据。
