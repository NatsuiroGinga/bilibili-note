# 第三章候选方案：LAMDA 双玩家安全约束回放

**候选状态：资料库审查支持、尚未在 LAMDA 上验证。** 本方案服务于候选台账的逐项筛选；缺口修复、条件风险门控和 PCT 预筛已完成且未通过，本方案尚未写入正式训练入口。资料库审查报告将其列为下一优先级，但没有替代本地实验。

## 1. 研究问题与边界

LAMDA 的可观测信息是按年份到达的 APK 特征、标签、时间戳、家族字段、历史模型输出和历史记忆。数据没有攻击者动作、响应、反事实收益或策略选择，因此不能把本问题叙述成攻击者—防守者博弈。

本候选把训练过程写成一个**模型玩家与安全约束玩家的双玩家约束优化**：

- 模型玩家选择参数更新，目标是修复当前恶意漏判并保持基础分类性能；
- 安全约束玩家选择非负拉格朗日乘子，惩罚相对旧模型的良性误报风险和历史恶意回归风险。

“博弈”只描述这两个优化角色的交替更新，不声称存在攻击者纳什均衡。

## 2. 因果信息集合

在年度 (t) 的更新开始时，允许使用：

- 当前年度已到达且已确认的训练标签 (D_t^{train})；
- 上一冻结模型 (f_{\theta^-}) 及其在历史样本上的输出；
- 历史训练记忆 (B_{t-1})；
- 已冻结的阈值和风险统计。

禁止使用：

- 年度 (t) 测试标签参与参数更新；
- `2018--2025` 封印年标签参与筛选；
- 未来家族计数、未来 FPR/FNR 或目标年结果；
- 尚未人工确认的伪标签。

## 3. 两个优化角色

### 3.1 模型玩家：缺口感知修复

设旧模型 logit 为 (z_{\theta^-}(x))，分类阈值对应的 logit 为 (a)。当前真实恶意且旧模型漏判的集合为：

\[
R_t=\{(x,1)\in D_t^{train}:z_{\theta^-}(x)<a\}.
\]

对每个样本定义 margin 缺口：

\[
d_i=[a-z_{\theta^-}(x_i)]_+.
\]

缺口修复损失为：

\[
L_{mal\text{-}FN}(\theta)=
\frac{\sum_{i\in R_t}d_i\,\operatorname{BCE}(f_\theta(x_i),1)}
{\sum_{i\in R_t}d_i},
\]

当 (R_t) 为空或权重和为零时跳过该项。模型玩家的基础目标为：

\[
L_M(\theta)=L_{cur}(\theta)+L_{replay}(\theta)
+\lambda_r L_{mal\text{-}FN}(\theta).
\]

该项只使用当前已到达的真实恶意标签，目标是提高恶意正向修复率，而不是无差别提高所有恶意样本分数。

### 3.2 安全约束玩家：双侧风险乘子

保护集合取历史记忆中上一冻结模型正确判恶意的样本：

\[
P_t=\{(x,1)\in B_{t-1}:z_{\theta^-}(x)\ge a\}.
\]

良性约束集合 (G_t^0) 必须取自历史年度已经到达并确认的训练分片中的良性样本，即 `G_t^0 ⊂ ⋃_{s<t}D_s^{train}`；它们在当前年度只作为安全玩家的代理参考，不重复进入模型玩家的基础梯度。不得从任何年度 `test` 分片读取标签构造该集合。首次年份没有历史良性集合时，安全玩家不更新乘子，只保留模型玩家。

为避免把不可微的二值 FPR 直接放入梯度，训练阶段使用两个代理风险：

\[
\widehat R_F(\theta)=
\frac{1}{|G_t^0|}\sum_{x\in G_t^0}\sigma(z_\theta(x)),
\]

\[
\widehat R_P(\theta)=
\frac{1}{|P_t|}\sum_{x\in P_t}
\operatorname{softplus}(a-z_\theta(x)).
\]

旧模型风险基准在更新开始时冻结：

\[
\rho_F=\widehat R_F(\theta^-),\qquad
\rho_P=\widehat R_P(\theta^-).
\]

约束残差为：

\[
c_F(\theta)=\widehat R_F(\theta)-\rho_F,
\qquad
c_P(\theta)=\widehat R_P(\theta)-\rho_P.
\]

安全玩家的策略是非负乘子

\[
\lambda_F,\lambda_P\ge0,
\]

并最大化约束违反程度。对应的拉格朗日目标为：

\[
\min_\theta\max_{\lambda_F,\lambda_P\ge0}
L_M(\theta)+\lambda_Fc_F(\theta)+\lambda_Pc_P(\theta).
\]

参数和乘子的交替更新为：

\[
\theta_{k+1}=\theta_k-\eta_\theta
\nabla_\theta\left[L_M+\lambda_Fc_F+\lambda_Pc_P\right],
\]

\[
\lambda_{j,k+1}=\left[\lambda_{j,k}+\eta_\lambda c_j(\theta_k)\right]_+,
\qquad j\in\{F,P\}.
\]

这里的“安全玩家”不是新增攻击者模型，而是对训练更新施加风险预算的约束角色。

## 4. 真实 FPR 验收与训练代理的区别

训练代理 (widehat R_F) 不能被解释为真实 FPR 保证。训练代理只使用历史训练良性集合；每个 checkpoint 仍必须在独立、时间一致且不参与参数更新的良性 gate 集合上计算二值 FPR：

\[
\operatorname{FPR}_{gate}(\theta)=
\frac{\operatorname{FP}_{gate}(\theta)}
{\operatorname{FP}_{gate}(\theta)+\operatorname{TN}_{gate}(\theta)}.
\]

只有满足

\[
\operatorname{FPR}_{gate}(\theta)
\le \operatorname{FPR}_{gate}(\theta^-)
\]

的 checkpoint 才有资格按 FNR、恶意正向修复率和 AP 排序。gate 集合标签不得参与参数更新、乘子更新或候选选择；测试分片只允许在运行结束后用于描述性验收。该 gate 是部署验收条件，不是对未知未来年份 FPR 的数学保证。

## 5. 与已有方法的区别

| 方法 | 本方案中的位置 | 不能声称的内容 |
| --- | --- | --- |
| TFCO／Cotter 数据依赖约束 | 双玩家乘子更新的理论来源 | 不能声称 TFCO 已在 LAMDA 上有效 |
| PCT／Focal Distillation | 旧正确决策保护的直接基线 | 不能把 PCT 改名为新机制 |
| A-GEM | 历史梯度投影直接对照 | 平均历史梯度不等于 FPR 保证 |
| 当前条件双风险投影 | 本方案的非博弈筛选对照 | 条件投影结果不能当作双玩家结果 |
| Nash-MTL／AuxiNash | 非对称任务权重与梯度议价的理论边界 | 没有 LAMDA 的 hard FPR 速率约束，不能替代安全玩家 |
| SCORER | 双时间尺度主从更新的理论边界 | 没有 FPR 约束；当前方案不称为 Stackelberg |
| 攻击者—防守者博弈 | 排除 | LAMDA 没有双方动作和收益 |

本方案的潜在任务化增量是：把模型玩家限定为 LAMDA 的恶意漏判修复，把安全玩家限定为良性误报与历史恶意回归，并将二者放入时间有序经验回放中。该增量只有在 LAMDA 源年实验支持后才能成立。

## 6. 最小实验矩阵

只使用来源年 `2013/2014` 和项目开发层 `2016/2017`，封印年 `2018--2025` 不参与选择：

| 实验臂 | 缺口修复 | 双玩家安全约束 | 目的 |
| --- | ---: | ---: | --- |
| ER | 否 | 否 | 共同基线 |
| ER＋缺口修复 | 是 | 否 | 判断恶意修复独立信号 |
| ER＋双玩家约束 | 否 | 是 | 判断安全玩家独立信号 |
| ER＋缺口修复＋双玩家约束 | 是 | 是 | 判断是否互补 |

直接对照按资源允许程度追加：PCT、阈值匹配、始终双风险投影和 A-GEM。所有对照保持相同模型、回放容量、训练轮数、阈值和样本暴露量。

## 7. 评价指标与失败门

每个年度和合并开发层报告 AP、AUROC、F1、FPR、FNR、Brier、旧恶意负向翻转率、当前恶意正向修复率、良性新增误报、乘子轨迹、约束代理残差和资源开销。

候选通过必须同时满足：

1. 独立 FPR gate 不高于 ER；
2. 旧恶意负向翻转率不高于 ER；
3. AP、FNR 或恶意正向修复率至少一项改善；
4. 联合臂不劣于最好单臂，并且乘子或约束残差显示安全玩家确实触发。

以下任一情况立即否决该实现：

- 约束只在训练代理上满足，真实 gate FPR 上升；
- 通过放大 (lambda_F) 只保持旧预测，却没有恶意正向修复；
- 双玩家臂与简单阈值匹配或始终投影无差异；
- 乘子发散、长期为零且约束从未触发，或更新依赖未来标签；
- 联合臂没有超出单臂的可解释收益。

## 8. 实施顺序与当前状态

1. 缺口修复与条件风险门控四臂已经完成；具体实现未通过开发期门槛，不能把其结果当作双玩家结果。
2. PCT/FPR gate 四臂本机预筛也已完成；PCT 保留为直接基线，未通过开发期门槛。
3. 若继续本方案，先核验 TFCO/Cotter 原件和现代实现接口，冻结乘子更新、独立良性 gate 与历史恶意保护集合，再只用来源／项目开发层运行最小四臂。
4. 只有双玩家单臂通过真实 FPR gate、旧恶意保持和恶意修复门槛，联合臂才有资格进入一次 `2018--2025` 封印评价；当前方案状态仍为 `external_pending`。

## 9. 资料库审查后的更新（2026-09-09）

资料库审查报告《LAMDA 第三章候选方法源年筛选审查：以“修复恶意漏判且不提高 FPR”为硬约束》给出以下与本方案直接相关的判断，原始制品已回收至[本地记录](../chatgpt-handoffs/inbox/LAMDA-2026-源年筛选审查-资料库回收.md)：

- **方法依据：** Cotter／TFCO 的 proxy-Lagrangian 适合表达不可微速率约束；Kumar 等人的 ICO 将“固定 FPR 下最小化 FNR”列为典型目标；A-GEM 只提供条件冲突投影的局部几何对照。
- **任务化差量：** 模型玩家只修复当前已到达真实恶意中的旧模型漏判，安全玩家只更新良性 FPR 与旧恶意回归的长期约束乘子；不叙述为攻击者—防守者博弈。
- **信息边界：** 代理良性集合只能来自历史已到达训练分片；独立 gate 集合不参与参数或乘子更新；封印年标签、未来漂移统计和测试标签不得进入训练或候选选择。
- **与 PCT 的边界：** PCT 只作为保护旧模型正确决策的公开直接基线，不把它改名为本方案，也不把 PCT 的其他数据集数值解释成 LAMDA 结果。
- **后续方法边界：** MIR 只在历史参考代表性被本地证据指认为瓶颈时引入；GSS 只能在固定角色内部使用；TERM 只能作为已有安全层后的风险加权对照；课程学习、DGR 和固定标签合同下的主动学习不进入当前直接臂。

资料库报告的优先级是外部设计依据，不是 LAMDA 支持结论；本候选是否进入正式实验仍由下述四臂源年结果裁决。
