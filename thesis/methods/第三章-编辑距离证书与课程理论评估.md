## 一、论文 A：RS-Del 的证书形式（问题 1）

**引用**：Huang, Marchant, Lucas, Bauer, Ohrimenko, Rubinstein. *RS-Del: Edit Distance Robustness Certificates for Sequence Classifiers via Randomized Deletion*. NeurIPS 2023（本地 PDF 为 arXiv:2302.01757v3 相机就绪版）。下文锚定章节号/式号/表号；物理页码仅在可确证处标注。

### 1.1 三层结构

RS-Del 的证书由「平滑分类器定义 → 充分条件 → 邻域最小化」三步得到。

**(1) 平滑分类器与可调阈值**（§3.1，式 2、3）
$$f(x) := \arg\max_{y\in Y}\{p_y(x; f_b, \phi) - \eta_y\},\qquad p_y(x;f_b,\phi)=\Pr_{z\sim\phi(x)}[f_b(z)=y]$$
`η = {η_y}` 为**实数可调决策阈值**（原文强调此为新增自由度；此前随机平滑隐含 `η = 0`，Remark 1）。

**(2) 充分条件**（Proposition 3，§4.2，式 9、10）：`ρ(x, μ_y) ≥ ν_y(η)`，其中
$$\rho(x,\mu_y) := \min_{\bar x\in N_r(x)}\min_{h\in\mathcal F(x,\mu_y)}p_y(\bar x; h)\quad(9)$$
为类别 `y` 置信度的紧下界，`ν_y(η)` 为阈值（多类分支 `ν_y = ½ + η_y − min_{y'≠y}η_{y'}`）。

**(3) LCS 参照点与邻域最小化**（§4.2–4.3）

- **Lemma 4（等价编辑）**：设 `z* = LCS(x̄, x)`，则存在双射 `m: 2^{ε̄*} → 2^{ε*}` 使 `apply(x̄,ε̄)=apply(x,ε)`，且两侧概率 `s(·)` 成比例。
- **Theorem 5**（式 14）：`ρ(x̄,x,μ_y) ≥ p_del^{|x̄|−|x|}·μ_y − 1 + p_del^{½(dist_LCS(x̄,x)+|x|−|x̄|)}`，`dist_LCS(x̄,x) = |x̄|+|x|−2|z*|`。
- **在编辑球 `N_r(x)` 上取 min**，得主证书（Table 1）：

| 允许编辑操作 O | 认证半径 `r*` |
| --- | --- |
| {del} | `log((1−μ_y)/(1−ν_y)) / log p_del` |
| {ins} | `log(ν_y/μ_y) / log p_del` |
| {del, ins} | `log(ν_y/μ_y) / log p_del` |
| {del, ins, sub}（及含 sub 的其余组合） | `⌊log(1+ν_y−μ_y) / log p_del⌋` |

- **Theorem 7（Levenshtein 证书，§4.3）**：`O={del,ins,sub}` 时 `ρ̃(x;μ_y) = μ_y − 1 + p_del^r`，认证半径 `r* = ⌊log(1+ν_y(η)−μ_y)/log p_del⌋`；「对任意 O 的适配是直接的」，全部组合见 Table 1。
- **块级编辑**（§3.3）：把序列重解释为块序列（整条机器指令等），半径 `r`（块）下 `ρ̃ = μ_y − 1 + C(|x|−r,k(|x|))/C(|x|,k(|x|))`。

> 表内 `{del,ins}` 一行在 PDF 抽取中与 `{ins}` 一行同为 `log(ν_y/μ_y)/log p_del`；若正文需精确引用该行，**须回原件 Table 1 复核**（已在笔记登记）。

### 1.2 所需假设（逐一列出）

| # | 假设 | 出处 |
| --- | --- | --- |
| A1 | **随机删除平滑**：每个序列元素以概率 `p_del` **独立**删除；机制 `φ` 与威胁模型操作集 **不必对齐**（Remark 2 明确为「误解」） | §3.2（含 Remark 2） |
| A2 | **LCS 参照结构**：证明围绕 `z* = LCS(x̄,x)` 组织，依赖 `dist_LCS = |x̄|+|x|−2|z*|` 与 Lemma 4 的双射；**刻意不用 Neyman-Pearson**（该设定下不可解） | §1、§4.2 |
| A3 | **证书对基分类器架构无关**：只依赖 `x`、预测 `ŷ`、置信度 `μ_y`、阈值 `η_y` 与机制 `φ`，**不含 `f_b` 架构**；故可黑盒（仅推理 API） | §3.3 末、Figure 1 说明 |
| A4 | **Monte-Carlo + 下置信界**：`μ_y` 精确枚举随 `|x|` 指数增长不可行，改用采样 + `BinLCB`（含显著性水平 `α`、`n_pred`/`n_bnd`），置信度 `1−α` | §3.3、Figure 1、Appendix A |
| A5 | **基分类器须专门训练**：随机平滑对常规训练分类器效果差；作者**用从 `φ` 采样的删除扰动序列替换原序列**训练基分类器 | §3.3「Training」 |
| A6 | 认证覆盖任意 `O ⊆ {del, ins, sub}`；案例中 FPR 由**基模型阈值校准到 0.5%** | Table 1；Appendix D.3 |

**注意 A1 与「替换型编辑距离」的关系**：RS-Del 的**平滑算子是删除**，而**被认证的威胁模型操作集 `O` 可以是纯替换**（`O={sub}` 即 Hamming 证书）。**「删除平滑」与「替换型邻域」在 RS-Del 中本就是分离的两件事**——这是后文问题 2 的关键。

## 二、问题 2：RS-Del 是否支持或挑战本课题机制方案

### 2.1 共享前缀替换 vs 随机删除：能否结合？证书是否适用于「替换型」编辑距离？

**分两层回答。**

**(a) 证书层面：适用于纯替换邻域，但本课题的邻域不是标准球。**
- RS-Del 的 Table 1 明确覆盖 `O={sub}`（纯替换，对应 Hamming 距离）——**对「纯替换型编辑距离」本身，RS-Del 有证书**（全文级，Table 1）。
- **但本课题的编辑算子不是标准 Hamming/Levenshtein 球**。按 [v2 规格 §十二](第三章-正式攻击与目标抽样合同裁决.md)：算子**冻结域名的点号位置、只改可编辑位、保持共享前缀**。这是一个**受限编辑集 `N'`**，而 RS-Del 的 `N_r(x)` 是**无约束的标准球**（任意位置任意操作）。**`N' ⊊ 标准球`，且不是任何标准球的平移。**
- ⇒ **RS-Del 的闭式半径不能原样套到本课题算子上**。要用它的证书语言，须重做 §4.3 的**邻域最小化**：把 `min` 取在**本课题的受限邻域 `N'`** 上（或证明 `N' ⊆ N_r(x)` 从而得到一个**保守**半径）。**原文没有做这一步，本课题也没做——这是「设计可行、推导待证」的缺口。**

**(b) 机制层面：平滑算子与认证邻域可解耦——概念上可结合，但要补推导。**
- Remark 2 的核心观念（**「平滑机制无需与威胁模型操作集完全对齐」**）在**概念上支持**「本课题的编辑算子（共享前缀替换）与随机删除平滑可以并存」：认证只要求机制对邻域内两输入返回**统计接近**的分布。
- 因此**原则上可结合**：本课题可以用任意平滑算子（包括随机删除）为「共享前缀替换」邻域做认证，关键是 §4.3 的 `min` 落在**本课题邻域**上。
- **但有一个本课题特有的、原文未覆盖的障碍（未验证）**：RS-Del 面向**恶意软件字节序列**，删除字节后输入仍是「不完整文件」，MalConv 可读；而本课题对象是**域名字符串**，**删除字符会破坏「合法域名」语义**。本课题基分类器**能否接受被删除/截断的不完整域名**、以及删除平滑是否仍满足 A3，**均无证据**。⇒ 迁移前须先做一个**可行性核对**，不得默认成立。

**(c) 结论（问题 2.1）**：**证书不直接适用于本课题算子**（邻域几何不匹配，属须补推导的缺口）；**「可结合」只是概念层推论（证据等级：推论）**，且受「域名合法性」这一未验证障碍限制。

### 2.2 推理时认证 vs 训练方法：竞争还是互补？

- **RS-Del 双重性质**：① **推理时认证**（逐样本给出 `r*`，A4/A3）；② **附带训练做法**——基分类器必须**用删除扰动序列训练**（A5），否则平滑失效。
- **本课题方案是训练方法**（对抗训练 + 课程调度，产出模型；无逐样本证书）。
- **不在同一层，故互补而非竞争**：
  - RS-Del 属**评价/证书层**（「在编辑距离 `r` 内预测不可变」的可证明保证）；本课题属**训练机制层**（如何训练出更鲁棒的模型）。
  - 本课题**不能**用 RS-Del 替代其训练机制；RS-Del **也不构成**对本课题训练机制的竞争证据（它没做 DGA、没做低误报、没做课程调度）。
- **正文层次表述建议**：若第三章使用「编辑距离有界」措辞，应把 RS-Del 放在**威胁模型/认证工具**一节，与本课题**训练方法**分层陈述，并显式声明「RS-Del 认证的是**标准编辑球**，本课题算子生成的是**受限共享前缀替换集**，二者不等同；本课题**未**给出此类证书」。**在补出 §2.1(a) 的邻域最小化之前，禁止写「本课题鲁棒性有编辑距离证书」。**
- **一个正向可用的连接**：RS-Del 的「用删除扰动训练基分类器」（A5）是**数据增广式**训练，可作本课题候选核设计的一个**对照臂候选**（与 B/D/F/UQ 的同预算比较）——但这是**新实验假设**，须走正常筛选门，不得据文献直接采用。

### 2.3 非对称证书（偏向恶意类）与低误报工作点

- **RS-Del 的做法**：`η` 可在类间权衡**错误率与认证半径**；案例中固定 FPR = 0.5%，调小 `η₁` 使**恶意类**中位认证半径升高（`η₁=5%` 时达 **582 字节**，某些情形提升至 **4 倍**），代价是**良性类半径下降**（Appendix D.3、E.1，Table 8 在物理页 27）。
- **与低误报的相关性（须精确表述）**：
  - **相关**：它**证明「低误报工作点下仍可获得可观认证半径」**（FPR 校准到 0.5%、FNR ≈ 7%、恶意类 CR 最多 582 字节）——为本课题「低误报 + 编辑鲁棒」的**联合目标**提供了一个**存在性先例**（全文级）。
  - **不相关**：非对称证书放大的是**恶意类的可证明鲁棒半径**，**不是**「降低良性误报」。`η` 的调节是在**已校准 FPR 的前提**下做的类间重分配。**不得把 RS-Del 的非对称证书写成低误报方法。**
  - **口径差异**：本课题主指标是**低误报（0.1%/1% 源预算）下未见家族检出**；RS-Del 的 0.5% 是**基模型阈值校准的目标 FPR**，二者工作点定义不同，**不可互推**。

## 三、问题 3：Curriculum as Transport 对本课题课程调度方案的意义

**引用**：Shin, C. & Alvarez-Melis, D. *Curriculum Learning as Transport: Understanding Curricula with Wasserstein Geodesics*. COLM 2026（arXiv:2609.09099）。**全文无定理**（Theorem/Proposition 检索零命中），结论来自**校准合成套件**（12 任务、33 难度轴）的受控实验。

> 说明：本报告同时**完成**了 [课程式对抗训练笔记](wiki/papers/attack-detection/课程式对抗训练-在线视角.md) 末「题录核验登记」要求的入库——「运输几何／课程路径」框架的规范出处（Shin & Alvarez-Melis）现已进 `wiki/`（`raw/` 副本待补）。**引用纪律不变**：运输几何表述须引本篇，不得归因 Shi & Liu AAAI-24；反之亦然。

### 3.1 「easy-to-hard 排序确有增益」对 D-7 判据的影响

- 本文的核心结论：**在「等曝光」对照下，easy-to-hard 在困难层仍有增益，且 hard-to-easy 常常有害**（§4.2–4.3；困难桶上 Wasserstein 的曝光校正准确率在 **99/99** 条件下高于线性，最难层上 forward 在 **92/99** 条件下优于 reverse）。
- **这条结论与 D-7 的对照设计同构**：D-7 的判据是「`curriculum` 与 D/F **在同样最终核强度下**比较」（机制方案 §四）——即「**只差排序、不差最终强度**」，正是本文用来证明「排序有独立作用」的**等曝光对照形态**。⇒ **本文支持 D-7 是一个有效的证伪实验**，且**支持「课程调度可能是独立机制」这一假设的合理性**。
- **但本文同时给出强负面边界（Appendix D）**：**在带预训练模型、真实数据、难度标签更噪的 SFT 上，多数课程效应减弱，静态 i.i.d. 反成最强汇总基线，easy-to-hard 排序不再稳定分离**；残余差异主要在「曝光校正的数据效率」。**本课题 D-7 恰属这一类「高现实性、低预算」设定**（3 个 epoch、源年训练）。
- **⇒ 对判据的影响：判据不用改**（D-7 的等最终强度对照本就正确），**但先验必须收紧**——**不得**据本文断言「课程调度必然带来增益」。本文**降低而非提高**了课程增益的先验。

### 3.2 「端点平滑度 / 节奏」是否给出比「epoch1 弱、epoch2–3 强」更细的调度建议？

- 本文的参数：**`τ`（端点平滑度，`(P_1)_l ∝ exp(l/τ)`）**、**`γ`（遍历节奏，`t_k = (k/T)^γ`）**，以及 **L 个难度层的中间层质量分配**。定性结论：**「中等节奏 + 平滑端点」好；极尖锐端点 × 过激或过保守节奏会崩**（§5，9×9 网格，`τ,γ ∈ {0.1,…,10.0}`）。
- **粒度不匹配（关键）**：D-7 是**极粗粒度离散三档**（epoch1 = `q`约 2 位；epoch2–3 = `q`约 4 位）——**只有端点与一次硬阶跃，没有中间难度层**（实际只用到 2 个难度档）。本文的 `γ`/`τ` 精细化**不能直接落到 D-7**。
- 本文**间接指向**的改进方向（**均为新候选，需独立证伪，非对现有 D-7 的建议**）：
  1. **增加难度层数**（真正的多档 `q`，而非 2 档），使路径有「中间层质量」；
  2. **把切换做平滑**（避免 epoch1→2 的硬阶跃，对应本文`τ`的「平滑端点」）；
  3. **调切换时机/节奏**（对应 `γ`）。
- **纪律**：**在 D-7 结果出来前，不得据本文修改 D-7 或新增课程臂**；上述方向只能作为 D-7 **之后**的候选，且须走正常的最小证伪门。
- **另一处接口缺口（推论）**：本文的「难度层」是**预先给定的有序轴**，本课题的「难度」是**编辑预算 `q`**；把 `q` 映射成 L 层难度（存在性与单调性依据）是迁移前必须先固定的接口。

## 四、问题 4：明确裁决

### 4.1 对 RS-Del

**裁决：层次修正——既非强化、也非推翻，而是「互补但有一个必须补的缺口」。**

| 维度 | 裁定 | 理由（原文位置） |
| --- | --- | --- |
| 能否认证本课题算子 | **否（未做）** | 本课题 `N'`（共享前缀替换）≠ RS-Del 的标准编辑球（Table 1、§4.3）；须重做邻域最小化 |
| 是否与本课题训练机制竞争 | **否** | RS-Del 是**推理时认证**（§3.1、Figure 1）；本课题是**训练方法**。层次不同 |
| 是否提供正向可迁移物 | **有（有限）** | ①「平滑算子 ≠ 威胁模型操作集」观念（Remark 2）支持二者解耦；②「删除扰动训练」（§3.3 Training）可作候选对照臂；③低误报下认证半径存在性先例（Appendix D.3/E.1） |
| 是否可写进正文 | **仅限威胁模型/认证层** | 且必须显式声明「本课题未给出此类证书、邻域不等同」 |

**一句话**：RS-Del 与本课题机制**不冲突**（不在同一层），**不是竞争证据**；但**不能**据它为「共享前缀替换」背书——那是一个**未补的推导缺口**。

### 4.2 对 Curriculum as Transport

**裁决：修正——把课程调度的先验「调低」而非「调高」，不改变 D-7 判据。**

| 维度 | 裁定 | 理由（原文位置） |
| --- | --- | --- |
| 是否支持「排序有独立作用」 | **支持（文献层）** | 等曝光对照下 easy-to-hard 在困难层有增益（§4.2–4.3） |
| 是否支持「本课题课程必然有增益」 | **否，且相反** | 预训练/真实数据 SFT 上效应大幅减弱（Appendix D） |
| D-7 判据是否需改 | **否** | D-7 已是「等最终核强度」对照，匹配本文证伪形态 |
| 是否给出更细调度 | **方向有、粒度不合** | `γ`/`τ` 需 L 层连续路径；D-7 仅 2 档硬阶跃（§5） |

**一句话**：它**加强了 D-7 作为有效证伪实验的地位**，但**削弱了「课程应有增益」的先验**；**不得**据它预告正增益。

### 4.3 总裁决

- **两篇都不推翻机制方案。**
- **RS-Del**：**层次不同（认证 vs 训练），互补但需补缺口**；不作竞争证据，也不作证书背书。
