## 五、参照论文第四章的组织模式与手段类型

**边界声明**：本节按 `thesis/AGENTS.md` 只提取**单章单问题的组织模式、手段类型与工作量尺度**，
不复制其机制、公式、算法、数据、数值、图表、结论或连续表述。
下文出现的数字仅为**节数、图表数、公式编号上界**等篇幅计量，不是其实验数值。
唯一引用的实验量级是主代理简报已给出的端到端加速比 `4.6` 倍，只作工作量尺度锚点。

来源：`wiki/papers/attack-detection/朱焱雷-全文提取-mineru.md`（MinerU `extract` 全文提取），
第四章位于行 `1556–2330`；原件 `raw/papers/attack-detection/朱焱雷.pdf`。
证据等级：`本地全文`。

### 5.1 章节骨架（七节，逐节功能）

| 节 | 标题类型 | 该节承担的功能 |
| --- | --- | --- |
| 4.1 | 引言 | 承接上一章的机制，把**上一章机制自身造成的开销**声明为本章的唯一问题；随后**主动缩小研究对象**，说明为什么两个骨干里只保留计算密集的那一个 |
| 4.2 | 问题定义与优化目标（3 个子节） | 4.2.1 对开销做**代价模型**（把单轮成本拆成可计数的单位）；4.2.2 把问题写成**受约束优化**（固定预算下最大化效果，或固定效果下最小化预算），并**显式否决一类替代路线**并给出否决理由；4.2.3 引入指示变量把机制形式化为一个联合优化问题 |
| 4.3 | 方法框架设计（3 个子节） | 4.3.1 总体结构（一张框架图 + 级联两级的分工）；4.3.2、4.3.3 每个子机制一节 |
| 4.4 | 算法实现与模型适配（2 个子节） | 4.4.1 一段**编号伪代码**（算法 4.1）给出训练流程；4.4.2 针对具体骨干的落地细节 |
| 4.5 | 理论分析（2 个子节） | 4.5.1 **复杂度推导 + 理论加速比闭式公式 + 极限情况分析**；4.5.2 **近似计算的收敛性定性分析**，逐一列出引入的误差来源并为每种给出有界性论证 |
| 4.6 | 实验评估与分析（8 个子节） | 见 5.3 |
| 4.7 | 本章小结 | 中性收束，导向后续章节 |

**组织模式的三条要点**：

1. **效率章的问题来源必须是上一章机制自身**，不是外部引入的新问题。
   引言第一段就把因果链写死：上一章的机制 → 开销 → 本章。
2. **代价模型（4.2.1）与理论分析（4.5.1）是两处独立的推导，不是同一段**。
   前者用于**定义问题**（说明开销从哪来、哪几个旋钮能拧），后者用于**证明收益**
   （给出加速比闭式解并分析极限）。两者共用一套单位符号。
3. **主动缩小研究对象并给出理由，写在引言而非局限性小节**。
   其理由是「效率瓶颈具有模型特异性」——轻量骨干上瓶颈不突出、强行加机制反增调度开销。
   这是本仓库「非正面结果的呈现」规则所说的**中性归因**的范例：不写「本方法在 CNN 上无效」，
   而写「该瓶颈的作用面在计算密集模型上」。

### 5.2 手段类型（只列类型，不含机制细节）

其第四章把效率问题拆成**两个正交维度的级联**，每个维度一类手段：

| 维度 | 手段类型 | 稀疏性来源 |
| --- | --- | --- |
| 空间维 | **样本级筛选**——按重要性评分剔除一部分样本不参与昂贵的那一路计算 | 样本对目标的贡献不均匀 |
| 时间维 | **跨轮次复用**——把昂贵计算的结果缓存，按周期懒惰更新，其余轮次直接复用 | 被缓存量在相邻轮次间慢变 |

两者**乘性叠加**，级联为「先粗筛、再精简」。

**对本课题的手段类型对位**：

| 参照论文的手段类型 | 本课题四个候选中的对应者 | 对应关系 |
| --- | --- | --- |
| 空间维·样本级筛选 | **候选一 ASB**、**候选二 ASR** | 同为「只对一部分对象付昂贵计算」，但**稀疏性的合法性来源不同**：参照论文是**启发式**（重要性评分是设计出来的，故需 4.5.2 的收敛性论证）；本课题候选一、二的稀疏性是**损失函数与聚合算子的恒等性质**（梯度精确为零），故可用 `torch.equal` 断言而非收敛性论证。**这是本课题相对该手段类型的强化点，不是照搬** |
| 时间维·跨轮次复用 | **四个候选均无对应** | 本课题四个候选全部是**单步内**的优化，没有跨步复用维度。这是一个**空缺的设计维度**，是否存在可复用的慢变量（如 ξ、活动集成员、argmax 位置）尚未评估 |
| —（参照论文未用） | **候选三 HSE**（主机同步消除） | 参照论文没有这一类手段；它属于运行时工程优化，其基线 ME-AT 一类才涉及 |
| —（参照论文未用，但作为基线出现） | **候选四 SAC**（选择性激活重计算） | 参照论文把「梯度检查点 + 片段式反向传播」放在**对比基线**位置（ME-AT），不是自己的手段。**含义：该类手段在参照论文的体例中被定位为「已有工作」而非「本章创新」** |

### 5.3 实验组织模式（八个子节的功能分工）

| 子节 | 功能 | 产出形式 |
| --- | --- | --- |
| 4.6.1 实验设置 | 数据集与预处理、**骨干选型策略**（含为何只留一个）、**对比基准方法**、评价指标与参数设定 | 2 张表（软硬件环境、训练参数） |
| 4.6.2 综合效率与性能对比 | 效率与效果**分两张表**呈现，正文把两表**联读**下结论 | 2 张表 + 1 张 Pareto 前沿图 |
| 4.6.3 资源消耗与显存优化分析 | 峰值显存对比 + **单轮耗时的细粒度成分分解** | 2 张图 |
| 4.6.4 消融实验 | 两个子机制单开、全开、全关的四格 | 1 张双轴图（加速比与效果同图） |
| 4.6.5 参数敏感性分析 | 两个旋钮各扫一遍，**每个旋钮单独一张图** | 2 张图 |
| 4.6.6 过程可视化 | 机制在训练全周期的行为演变（不是最终指标） | 1 张堆叠面积图 + 1 张表 |
| 4.6.7 扩展性分析 | **批量规模扫描下的吞吐量**，并记录哪些基线在大批量下 OOM 中断 | 1 张图 |
| 4.6.8 工程综合收益评估 | 把前面的分项收益汇总成一张工程口径的收益表 | 1 张表 |

**规模计量**：第四章共 `17` 张图、`8` 张表、编号公式至 `(4.30)`，正文约 `775` 行提取文本。

**五条可直接迁移的组织判断**：

1. **效率章的主表是「效率」与「效果」两张分开的表，正文联读**。
   不把两类指标塞进一张表，也不用单一综合分。
2. **必须有一张耗时成分分解图**。它是「省的是哪一部分」这一论断的唯一直接证据。
   对应本课题的待测项 T3——**T3 不是可选诊断，是效率章的必备图件**。
3. **消融图用双轴同时画加速比与效果**，让「有没有以效果换速度」一眼可判。
   本课题候选一、二的 `off`/`ASB`/`ASR-保形` 三档效果**必须逐位相同**，
   故本课题的对应图在这三档上是一条水平线——这比参照论文的形态更强，应当明确画出并说明。
4. **扩展性分析要记录基线的失败模式（OOM 中断），不只记录成功点**。
   本课题已有 `6403` 序列首步 OOM 的实测现场，天然适合这一子节。
5. **过程可视化子节（4.6.6）的对象是机制的行为量，不是最终指标**。
   本课题的对应量是候选一的 `m/M` 与 `|A|/N_n` 逐轮曲线、候选二的选中流占比逐轮曲线。
   这些正是候选文档 0.2 节列为「尚未看过、可用于验证」的量。

### 5.4 结果表述模式

- **加速比以最慢基线为 `1.0×` 锚点**，所有方法相对它报告倍数。
- **承认某基线在单一维度上更强，再用第二张表说明其代价**（如某基线加速更高但效果下降）。
  即：**不回避不利对照，用联读化解**。这与本仓库「非正面结果的呈现」的第一条底线一致。
- **消融段落显式给出两个子机制的单开数字与全开数字**，并指出全开是否超过单开之和。
- **章末小结中性收束**，把边界写成作用条件而非「局限」。
  全章检索无「局限性」「不足」「未达预期」字样（与第三章一致）。

### 5.5 工作量尺度锚点

| 项 | 参照论文第四章 | 本课题当前状态 |
| --- | --- | --- |
| 自有机制数 | `2` 个正交子机制，级联叠加 | 候选池 `4` 个，其中候选四被自评为「不独立立章」 |
| 理论产出 | 复杂度推导 + 加速比闭式公式 + 极限分析 + 收敛性定性分析 | 候选文档已有 `4M → M+3m` 一类的单位记法与加速比表达式；**收敛性论证在本课题不需要**（梯度精确相等，不是近似） |
| 对比基线数 | `6` 个（含速度上界、速度下界与 `3` 个前沿加速方法） | **当前为 `0`**——候选文档未列任何外部加速基线 |
| 实验子节数 | `8` | 未定 |
| 图 / 表 | `17` / `8` | 未定 |
| 端到端加速比 | `4.6` 倍（主代理简报给出，本文只作尺度锚点） | 候选二理论上限 `4` 倍（受 Pass 1 全批前向下界约束）；候选四硬上限 `1.33` 倍 |

**两处必须报告的缺口**：

1. **对比基线为零是最大缺口。** 参照论文用 `6` 个基线撑起效率章的可比性，
   其中至少 `3` 个是同期加速方法。本课题候选文档只有「现状 vs 候选」的自我对照，
   没有任何外部加速基线。**这是第四章立章的硬缺口，不是可选项。**
   本文第一、二、四节给出的方法即是候选基线来源。
2. **候选二的理论上限 `4` 倍低于参照论文的 `4.6` 倍。**
   候选二的上限由「Pass 1 必须完整跑一遍无梯度全批前向」这一结构性下界决定，
   逼近上限时 Pass 1 独占全部时间。若第四章需要达到同级量级，
   **要么增加一个参照论文式的「跨轮次复用」维度以摊薄 Pass 1，要么接受较低的量级并另立论证重心**。
   本文只报告该缺口，不裁决走向。

### 5.6 不可迁移边界

| 差异项 | 参照论文第四章 | 本课题第四章 |
| --- | --- | --- |
| 开销来源 | 多步对抗扰动生成（`K` 步迭代，每步一次前反向） | 排序损失要求全体实体同图，批规模比逐流批大两个量级 |
| 稀疏性性质 | **启发式**——重要性评分是设计量，故必须论证收敛性 | **恒等性质**——非活动集梯度精确为零，可断言逐位相等 |
| 数值语义 | 引入采样偏差与梯度陈旧性两类**近似误差**，只能定性论证有界 | 候选一、三与 ASR-保形**无近似误差**；只有 ASR-重打包引入浮点重结合律差异 |
| 任务与骨干 | 加密流量分类，Transformer 预训练骨干，`FP32` | 加密恶意流量检测，RWKV/FT 路线，排序与逐流联合训练 |
| 硬件 | `24 GB` 单卡 | `31.36 GiB` 可用 |
| 是否需要重跑上一章 | 其机制改变优化轨迹，效果需重新验证 | 候选一、三与 ASR-保形**要求第三章结果逐位不变**，任何指标差异判为实现错误 |

**最重要的一条**：参照论文的效率手段**改变了数值语义**（近似计算），所以它必须付出
「收敛性分析 + 效果损失需实验确认」的代价；本课题候选一、三与 ASR-保形**不改变数值语义**，
因此**不能照搬 4.5.2 那种收敛性论证结构**——本课题在该位置应当放的是
**等价性证明与逐位断言**，这是一种更强、也更短的论证。照搬会把强论断写弱。
