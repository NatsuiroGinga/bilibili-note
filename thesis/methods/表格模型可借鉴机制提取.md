## 一、族 C：架构提案（TabTransformer、SAINT）

这一族本来就是「架构 ＋ 在目标表自身数据上的自监督目标」，不依赖跨表权重，
故 **M1 天然通过**，是三族中最可能有直接可用机制的一族。

### 1.1 TabTransformer 的替换标记检测

`[本地全文]` Huang、Khetan、Cvitkovic、Karnin（Amazon AWS），
*TabTransformer: Tabular Data Modeling Using Contextual Embeddings*，arXiv:2012.06678v1，2020-12-11。
原件 `raw/papers/2012.06678v1.pdf`（17 页）；转写 `.Codex/docs/2026-09-02-表格模型机制提取/md/TabTransformer.md`。
**定位到章节与表号，非印刷页码。**

#### 机制形式化（§2「Pre-training the Embeddings」）

给定类别特征向量 `x_cat = {x_1, …, x_m}`：

- **RTD**：把原特征值替换为**该特征自身取值域内的一个随机值**，
  训练一个二分类器判断「该位置是否被替换过」。
- **MLM**：随机选 `k%` 个特征置为缺失，训练多分类器还原其原值。

三处实现细节是论文明确写死的，且都有消融支撑：

| 细节 | 取值与理由 | 消融证据 |
| --- | --- | --- |
| **不用 ELECTRA 的辅助生成器** | 理由有二：类别特征的类数有限；且**每列一个独立二分类器**，不是共享分类器——因为每列有自己的嵌入查找表 | 见下行 |
| **每列独立分类器 ＋ 动态替换** | 「动态」指每个 epoch 重新随机替换 | 表 7（256 个标注点，3 数据集）：动态＋独立 `+0.81 ± 0.19` 相对 AUC；静态＋独立 `−0.33 ± 0.15`；静态＋共享 `−0.49 ± 0.11` |
| **替换比例 `k = 30`** | 论文自陈「最终微调精度对 `k` 不甚敏感」 | 表 6，网格 `{15, 30, 50}` |

RTD 与 MLM 的对比（半监督，标注点 50／200／500）：

| 设定 | RTD | MLM |
| --- | --- | --- |
| 表 3（6 个 >30K 数据点的数据集） | `66.6 / 70.9 / 73.1` | `66.8 / 71.0 / 72.9` |
| 表 4（9 个较小数据集） | `78.6 / 81.6 / 83.4` | `78.5 / 81.0 / 82.4` |

论文归因：无标注数据较少时 RTD 优于 MLM，因为「二分类比多分类是更容易的预训练任务」，与 ELECTRA 一致。

#### 两条对本课题的阻断

**阻断 A：RTD 的定义域是类别列，而本课题 81/83 是数值列。**

这是架构层面的事实，不是实现选择。论文 §2 定义 `x ≡ {x_cat, x_cont}`，
其中 Transformer **只处理 `x_cat`**；`x_cont ∈ R^c` **完全绕过 Transformer**，
在 MLP 入口处与上下文嵌入拼接成 `(d × m + c)` 维向量。
故 RTD 与 MLM 在原论文中**只定义在类别列上**。

本课题 83 字段 = 81 数值 + 2 词表，**字面 RTD 只覆盖 2/83 个字段**。

**须同时记录一处对本课题有利的差异**：本课题骨干是 FT-Transformer，
其 FeatureTokenizer 把**数值字段也变成 Token**（每个数值字段一行 weight + 一行 bias）。
即架构上不存在 TabTransformer 的那道墙，把 RTD 推广到数值列在结构上是自然的。
**但那是改编，不是论文的形式**——TabTransformer **没有提供任何数值字段 RTD 的证据**，
数值列的「随机替换」还需定义替换分布（经验边缘分布？高斯噪声？），论文对此无话可说。

**该空缺已由 SCARF 原文关闭，见 §2.5**——SCARF 的 "Discriminative SCARF" 消融正是
数值列可用的 RTD 形式，且给出了替换分布的精确定义。

**阻断 B：全标注下预训练收益，论文自陈「不明显」。**

§3「Setup」原文方向：预训练**只在半监督场景下使用**，
作者明确写「**当全部数据都有标注时，我们没有发现使用它有多少收益**」。

本课题训练有效流 `11,991,315` 条**全部带标签**。这条自陈直接落在本课题的设定上。

### 1.2 SAINT 的样本间注意力与对比预训练

`[本地全文]` Somepalli、Goldblum、Schwarzschild、Bruss、Goldstein，
*SAINT: Improved Neural Networks for Tabular Data via Row Attention and Contrastive Pre-Training*，
arXiv:2106.01342，2021。原件 `raw/papers/methodology/tabular-pretraining/2106.01342.pdf`（18 页）。

#### 机制一：样本间注意力（intersample attention，MISA）

**形式化（§3.1 式(1)(2)、§3.2 算法 1）**。单层管线：

```
z_i^(1) = LN(MSA(E(x_i))) + E(x_i)          # 字段间自注意力
z_i^(2) = LN(FF_1(z_i^(1))) + z_i^(1)
z_i^(3) = LN(MISA({z_i^(2)}_{i=1}^b)) + z_i^(2)   # 样本间注意力
r_i     = LN(FF_2(z_i^(3))) + z_i^(3)
```

MISA 的实现（算法 1，PyTorch 伪代码）是一个**三行改写**：

```python
def intersample_attention(x):   # x 是 b×n×d
    b, n, d = x.shape
    x = reshape(x, (1, b, n*d))     # 把每个样本的全部字段嵌入拼成一个 token
    x = self_attention(x)           # 在「样本」这一轴上做标准自注意力
    out = reshape(x, (b, n, d))
    return out
```

即**把整行拼成一个向量，然后在行之间做标准自注意力**。
论文强调它与轴向注意力（Axial Transformer、MSA Transformer、TABBIE）的差别：
后者是同一字段跨行通信，而 MISA「允许不同样本的**全部**字段互相通信」；
其层次是先字段内交互、再整行之间交互。论文另给一个等价视角：
MISA 可看作在**所有行两两相连的完全图**上的图注意力。

**论文报告的三条经验性质**：

| 性质 | 证据 |
| --- | --- |
| 参数多但更快 | 表 1：SAINT-s（仅自注意力）`L=6`、`91.6M` 参数、`1759` 秒；SAINT-i（仅样本间）`L=1`、`352.7M` 参数、`123` 秒；SAINT（两者）`L=1`、`347.3M`、`144` 秒。**SAINT-i 参数是 SAINT-s 的 3.8 倍，耗时却只有 1/14** |
| 字段多时优势明显 | §5：SAINT-i「在字段数大时一致优于其他变体」，尤其「样本少而字段多」（Arcene `200×783`、Arrhythmia `452×226`） |
| 注意力稀疏 | §6：「一个批次中极少的点获得注意力」；稀疏度随数据集难度下降（MNIST 稀疏、Volkert 稠密） |
| 批大小不敏感 | §5 与附录 E：批大小 `32`–`256` 之间 SAINT-i 的性能变化「很小」 |

#### 机制二：对比 ＋ 去噪预训练

**增广（§4 式(3)(4)）**：

```
x_i' = x_i ⊙ m + x_a ⊙ (1 − m)          # CutMix，在原始数据空间
p_i' = α · E(x_i') + (1 − α) · E(x_b')   # mixup，在嵌入空间
```

`m ~ Bernoulli(p_cutmix)`，`x_a`、`x_b` 是当前批内随机样本，`x_b'` 是 `x_b` 的 CutMix 版本。
**先给批内每个点随机选伙伴做 CutMix，嵌入后再重新选伙伴做 mixup**——两次伙伴不同。

**损失（式(5)）**：InfoNCE 对比项 ＋ `λ_pt` × 逐字段重构项，
重构对类别字段用交叉熵、对连续字段用均方误差，**每个字段一个单隐层 MLP 头**（共 `n` 个）。

冻结参数（§5）：`p_cutmix = 0.3`、`α = 0.2`、`λ_pt = 10`、`τ = 0.7`。

**表 9 消融（50 个标注点，14 数据集平均 AUC）——这是本节最关键的一张表**：

| 研究 | 变体 | SAINT-s | SAINT-i | SAINT |
| --- | --- | ---: | ---: | ---: |
| 1 投影头 | 无投影头 | `84.26` | `83.56` | `84.90` |
| | 共享权重投影头 | `85.31` | `85.20` | `86.89` |
| | **两个不同投影头** | `86.02` | `85.26` | `86.96` |
| 2 预训练损失 | **无预训练** | `85.14` | `83.93` | `85.78` |
| | 仅对比 | `85.40` | `84.42` | **`85.58`** |
| | 仅去噪 | `84.74` | `84.93` | `86.21` |
| | 仅余弦相似 | `85.03` | `84.35` | `85.70` |
| | **对比 ＋ 去噪** | `86.02` | `85.26` | `86.96` |
| 3 增广 | 仅 CutMix | `82.80` | `84.61` | `85.37` |
| | 仅 mixup | `86.01` | `84.41` | `86.45` |
| | **CutMix ＋ mixup** | `86.02` | `85.26` | `86.96` |

三条读数须一并记录：

1. **仅对比预训练在完整 SAINT 上低于不预训练**（`85.58 < 85.78`）。
   即「对比学习本身」不是增益来源，**对比与去噪的组合**才是（`86.96`，`+1.18`）。
   引用 SAINT 支持「加对比损失」时若不带这一条，属选择性引用。
2. 增广也必须成对：仅 CutMix `85.37` 低于不预训练的 `85.78`。
3. 以上全部在**只有 50 个标注点**的设定下测得。

**同一篇的全标注自陈（§5「Semi-supervised setting」）**：
「当全部训练样本都有标注时，我们注意到预训练的贡献不明显，
有无预训练的结果相当接近。」——与 TabTransformer §3 的自陈方向一致，**两篇独立同向**。

#### M2、M3：三处结构性冲突

**（1）时间因果边界（M2 冲突，须核验）**。本课题训练用 `truncate_length = 8192` 的
**因果前缀**截断。袋内全连接注意力允许一条流 attend 到**同实体内更晚发生的流**，
这与因果前缀协议方向相反。ETA 是对已产生的逐流分数做 top-`k` 聚合，不引入时序反向依赖；
袋内注意力**会**引入。是否构成实质违规，取决于评价协议是否要求逐流分数只依赖该流的历史前缀——
**本次未核验该协议原文，标为待验证**。

**（2）逐流分数不再是该流自身的函数（M3 影响 ETA 的语义，不影响可微性）**。
ETA 的挂载点是逐流 logit `l_{e,t}`，聚合式 `S_e = (1/k_e)·Σ_{top-k_e} l_(t)` 与梯度支撑闭式
`∂S_e/∂l_{e,t} = (1/k_e)·1[t ∈ top-k_e]` **不依赖 `l_{e,t}` 如何产生**，
故**端到端可微性不受影响，ETA 仍能挂载**。但 `l_{e,t}` 变成袋内全体流的函数后，
ETA 方案第五节已登记的「训练截断袋、评价完整袋、偏差符号随袋内漂移方向翻转、无假设不可定界」
这条局限会**从聚合层扩散到打分层**，不确定性放大而非缩小。

**（3）作用面被袋分布压到与 ETA 同一区间**。源年验证侧中位袋 `m = 2`，
`m ≤ 2` 的实体占 `68.4%`（`9250/13529`）。在 `m = 2` 的袋上，袋内注意力是一个 `2×2` softmax；
在 `m = 1` 的袋上完全退化为恒等。故该机制的**结构作用面上界与 ETA 相同（约 `31.6%`）**，
而代价高出若干数量级。

**一处与 SAINT 原设定相反的、对本课题有利的差异**：SAINT 的 MISA 在**任意小批次**上做注意力，
故推断时一行的预测依赖于恰好同批的其他行——这是该设计的已知弱点。
本课题若改为在**实体袋**上做，袋是协议定义的单元而非随机批次，**该弱点消失**。
这是把 MISA 迁到本课题的唯一实质动机，也是它值得进「需前置验证」而非直接出局的理由。

### 1.3 族 C 的档位判定

| 机制 | M1 | M2 | M3 | M4 | 档位 |
| --- | :-: | :-: | :-: | :-: | --- |
| **RTD／MLM 自监督预训练**（作为独立预训练阶段） | `○` | `○` | `○` | `○` | **需前置验证** |
| **对比 ＋ 去噪预训练**（CutMix + mixup + InfoNCE + 逐字段重构） | `○` | `○` | `○` | `○` | **需前置验证** |

| **流间注意力（CLS-only 改编，袋内）** | `○` | `△` | `○` | `△` | **需前置验证** |

四行的判定理由：

- **两个预训练目标 M3 天然通过**：预训练是**独立阶段**，只改变微调阶段的初始化，
  微调阶段的损失、逐流分数、ETA 与 BER 的挂载**逐位不变**。M4 亦无新增峰值——
  预训练阶段不含 BER 的全体同图反传，其峰值不高于当前 C01 的 `30,470 MiB`。
  它们落「需前置验证」而非「可直接借鉴」的唯一理由是**收益存疑**：
  两篇论文各自自陈全标注下预训练贡献不明显，而本课题是 `11,991,315` 条全标注流。
- **SAINT 字面式 M4 不通过**：单层 `1,040,449,536` 参数 = 骨干的 `1125.7` 倍；
  即便退到附录 C 的降维式仍是 `35.7` 倍。M2 记 `△` 是因时间因果边界待核。
- **CLS-only 改编 M4 记 `△`**：参数量 `147,456`（`0.16×` 骨干）可接受，
  但注意力矩阵在完整袋下为 `22.3 TiB`，**必须先给出袋大小上限或线性化方案**才能通过。

## 二、族 B：跨表预训练 ＋ 梯度微调（XTab、TransTab）

这一族的**权重**不可迁移（见可行性调研），但它的**预训练目标与结构分离设计**与本课题同构——
它们和本课题一样用标准小批量梯度微调，故 M3 天然通过。

### 2.1 XTab 的三种预训练目标与破坏视图

`[本地全文]` Zhu、Shi、Erickson、Li、Karypis、Shah，*XTab: Cross-table Pretraining for
Tabular Transformers*，ICML 2023，arXiv:2305.06090。
原件 `raw/papers/methodology/tabular-pretraining/2305.06090.pdf`（24 页）。
**定位到章节与表号，非印刷页码。**

#### 破坏视图的定义——这一条直接补上了族 C 留下的空缺

§4「Table corruption」原文方向：随机选取每行的一部分字段，
**从该列的经验边缘分布中重采样**来破坏它们；
**破坏比例对所有数据集统一设为 `60%`**，援引 SCARF（Bahri 等 2021）的建议。
即每个样本 `x` 与其破坏视图 `x̃` 之间，`60%` 的条目被重采样、`40%` 保持不变。

**这是本次调研对本课题最直接有用的一条形式**：TabTransformer 的 RTD 只定义在类别列上，
数值列如何「随机替换」它无话可说（族 C 阻断 A）。
XTab 给出的「**从该列经验边缘分布重采样**」对数值列与类别列**一视同仁**，
不需要噪声尺度、不需要分布假设，且**与本课题 81 数值 + 2 词表的混合字段直接相容**。
本课题若实现自监督预训练，破坏算子可直接采用这一形式，比例 `60%` 有 SCARF 与 XTab 两处来源。

#### 三种目标的形式与实测排序

| 目标 | 形式（§3.1.3） | 是否用标签 |
| --- | --- | :-: |
| **重构** | 破坏视图 `x̃` 过骨干与投影头得 `x̂`，与原样本 `x` 比较；**类别列用交叉熵、数值列用均方误差** | 否 |
| **对比** | `(x, x̃)` 为正对，同批其他样本为负对；InfoNCE；投影头同 SimCLR | 否 |
| **监督** | 投影头直接预测该表预定义的标签列（论文称 target-aware pretraining／pre-finetuning） | 是 |

**实测排序（图 3，FT-Transformer 骨干，2000 预训练步）**：
重构 > 对比 > 监督。重构目标 light 微调（固定 3 epoch）胜率 `71.0%`，
heavy 微调（早停耐心 3）**只剩 `56.1%`**。

XTab 对这一衰减给出的**自己的**归因值得原样记录：
「差异由深度模型的**灾难性遗忘**引起。由于表格 transformer 相对较小
（FT-Transformer 骨干 `<1M` 参数），它们在微调阶段更易受灾难性遗忘影响。」

**本课题骨干正是 `924,283` 参数，落在这句话所指的量级内，且训练预算远超 heavy。**

#### 可共享组件的识别（附录 B「Identifying the shareable components in XTab」）——一条可直接照搬的设计规则

XTab 做了一个消融：把 FT-Transformer 的不同部分标为「可共享（被预训练）」，其余标为数据专属。
结论有二：

1. **最有利的划分是「预训练全部 Transformer 块、但不含 `[CLS]` Token」。**
2. **预训练 `[CLS]` Token 不带来改进**，因为「`[CLS]` Token 直接关系到下游预测，
   因而高度数据专属」。

这条规则**不需要任何外部权重即可采用**：本课题若做自预训练，
预训练阶段应覆盖三个 Transformer 块，而 `[CLS]` Token 与预测头在微调阶段重新初始化。

#### 附录 F 表 2：自预训练与跨表知识的分离——本次调研的核心读数

**先纠正一处极易读错的表头。** 表 2 的行标是
「win rate (**against w/o external task**)」，即三列胜率**全部以「无外部任务」为对手**：

| 对手＝「无外部任务」（自预训练） | 胜率 |
| --- | ---: |
| `w/o external task`（自预训练，与自己比） | `50%` |
| `baseline`（完全不预训练） | **`35.2%`** |
| `w/ external tasks`（XTab 跨表初始化 ＋ 自预训练） | **`55.7%`** |

三个臂的定义（附录 F 原文）：

- `w/o external task`：随机初始化 → **在下游任务自己的训练集上预训练** → 微调
- `baseline`：随机初始化 → 直接微调
- `w/ external tasks`（XTab）：XTab 初始化（用外部表）→ 在下游数据上预训练 → 微调

**正确读法**：完全不预训练的 baseline 对自预训练只赢 `35.2%`，即**输 `64.8%`**——
自预训练相对不预训练有实质优势；而跨表外部知识相对自预训练只多赢 `5.7` 个百分点（`50% → 55.7%`）。

**结论方向**：增益的大头来自「**在自己的数据上先做自监督**」，而非「跨表外部知识」。
**这正是本课题可做而无需任何外部权重的部分**——用 LSPR23 自己的 `11,991,315` 条流，不碰 LSPR24。

**须同时记录的三条限制**：

1. 该表在 **heavy 设定、重构损失**下测得。本课题预算远超 heavy，处在图 3 那条下降曲线更右端，
   **该区间无实验**。
2. 胜率是**跨 84 个下游任务的比例**，不是效应量。`64.8%` 的胜率不等于任何具体的指标提升幅度。
3. 附录 C：「XTab 的优势并不随微调数据减少而更显著」，原因是 featurizer 与投影头仍需足够数据
   从头训练，「因此 XTab 不兼容零样本学习」。

#### 一处与族 C 直接冲突的证据，须如实记录

**族 C 两篇独立自陈「全标注下预训练贡献不明显」**（SAINT §5、TabTransformer §3）。
**XTab 附录 F 的下游任务是 AMLB 的全标注表格任务，自预训练仍取得 `64.8%` 的胜率。**

**这是文献内部的实质冲突，不是措辞差异**，本文件不作调和。
两处可能的差异来源（**均为推论，未验证**）：族 C 把预训练当作**半监督手段**测（少标注 + 多无标注），
XTab 把它当作**初始化与正则手段**测（全标注）；两者的对照臂与预算设定不同。
Rubachev 等 2022（arXiv:2207.03208，XTab 与 TransTab 均引用）正是研究全标注下预训练目标的工作，
是裁决该冲突的首选核验对象，见 §2.3。

**在该冲突关闭前，任何「自预训练能提升本课题指标」的主张只能标为「实验待证」。**

### 2.2 TransTab 的垂直分区对比学习

`[本地全文]` Wang & Sun，*TransTab: Learning Transferable Tabular Transformers Across Tables*，
NeurIPS 2022，arXiv:2205.09328。
原件 `raw/papers/methodology/tabular-pretraining/2205.09328.pdf`（19 页）。

#### 机制形式化（§2.3 式(4)(5)）

把样本 `x_i` 的列**垂直切成 `K` 个分区** `x_i = {v_i^1, …, v_i^K}`，相邻分区**可以重叠**
（重叠比例按分区列数的百分比确定）。每个分区独立过编码器，取其 `[CLS]` 嵌入 `z^[cls]`
的线性投影 `ẑ^[cls]`；`ψ(·,·)` 是余弦相似度。

**自监督 VPCL（式 4）**——同一样本的不同分区互为正对，其他样本的分区为负对：

```
ℓ(X) = − Σ_{i=1}^{B} Σ_{k=1}^{K} Σ_{k'≠k}
        log [ exp ψ(v_i^k, v_i^{k'}) / Σ_{j=1}^{B} Σ_{k'} exp ψ(v_i^k, v_j^{k'}) ]
```

**监督 VPCL（式 5）**——正对放宽为**同类别**的任意样本的任意分区：

```
ℓ(X, y) = − Σ_i Σ_j Σ_k Σ_{k'} 1{y_j = y_i}
          log [ exp ψ(v_i^k, v_j^{k'}) / Σ_{j'} Σ_{k'} 1{y_{j'} ≠ y_i} exp ψ(v_i^k, v_{j'}^{k'}) ]
```

计算约定：`K > 2` 时**随机抽两个分区**，故每步前向代价为 `2×`，与 `K` 无关。

论文对监督 VPCL 相对「普通监督预训练」的论证：普通监督预训练用任务专属预测头，
微调时丢弃换新头，会使编码器偏向主要任务与主要类别，且超参区间跨数据集差异大；
VPCL 借用监督对比学习（Khosla 等）的形式，论文称其「对噪声与超参更鲁棒」。

#### 实测（表 6，临床试验五数据集，AUROC）

| 设定 | N00041119 | N00174655 | N00312208 | N00079274 | N00694382 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Supervised（不预训练） | `0.6313` | `0.8348` | `0.7444` | `0.6885` | `0.7293` |
| Transfer（普通迁移） | `0.6424` | `0.8183` | `0.7458` | `0.6928` | `0.7239` |
| Self-VPCL | `0.6412` | `0.8577` | `0.7486` | `0.7069` | `0.7348` |
| **VPCL（监督）** | `0.6405` | `0.8583` | **`0.7517`** | `0.7063` | **`0.7392`** |

论文自陈：普通迁移策略**在两个数据集上损害了性能**（`0.8183 < 0.8348`、`0.7239 < 0.7293`），
而 VPCL 「总是带来正效应」。分区数增加时 VPCL 对 Self-VPCL 的优势扩大（图 4）。

**同一篇的一条独立负面证据**（与可行性调研的跨表结论同向）：
在公开数据集上预训练时（表 12），「在**不相关**的表格数据上预训练通常对微调收益甚微，
因为这些表定义了完全不同的列和目标任务」。

#### 为什么 VPCL 对本课题特别相关

**三条结构性契合，均可机械核验**：

1. **不需要定义数值字段的破坏分布**。VPCL 的视图来自**列子集**而非**值扰动**，
   故它绕过了族 C 阻断 A 与 XTab 破坏算子都必须回答的「数值列怎么加噪」问题。
2. **不需要改动骨干**。本课题 FeatureTokenizer 逐字段产出一个 Token（83 字段 + `[CLS]` = 84 Token），
   一个「垂直分区」就是**一个 Token 子集**；Transformer 对变长 Token 序列天然支持。
   **注意**：TransTab 自身的变长列能力依赖「把列名当文本 Token」，
   而本课题**不需要这条**——FT-Transformer 的 Token 已经逐字段独立参数化，删掉一部分 Token 即得一个视图。
   即 **VPCL 的目标可以脱离 TransTab 的输入处理器单独移植**。
3. **监督 VPCL 与本课题的全标注设定一致**。本课题 `11,991,315` 条流全部带标签。
   在族 C 两篇自陈「无标注预训练在全标注下收益不明显」的背景下，
   **用标签构造正对的监督 VPCL 恰好落在证据缺口的另一侧**。

**须同时记录的三条风险**：

- **M2**：监督 VPCL 使用源年标签 `y23`。这不触碰最终测试隔离（`y23` 已被 C00 的逐流 BCE 使用），
  但 ETA 参数登记表中「接触最终目标标签：否」的口径**只覆盖 ETA 的 `α`**，
  新增机制须另立登记项，不得沿用。
- **分区方案是一个未定的魔法数字**：`K`、重叠比例、以及**按什么切分 83 个字段**（随机？按语义组？）
  论文未给本课题可直接采用的值，须自行确定并登记依据。
- 表 6 是**五个数据集的单点数值，无种子方差**；差量最大处为 `+0.0235`（N00174655，VPCL vs Supervised），
  最小处为 `−0.0008`（N00041119，VPCL vs Self-VPCL）。**不得当作效应量引用。**

- **数据专属 featurizer ＋ 共享骨干**：该设计存在的唯一目的是**让不同 schema 的表共用骨干**。
  本课题只有一个表、一套 83 字段口径。任务简报提出的「跨年度可视为两个 schema 相同的表」
  **不成立于本课题的合同**：LSPR24 已封印，只作一次性描述评价，
  **不得进入训练**（M2）；且两年 schema **相同**，正是该机制不需要解决的情形。
- **联邦式 FedAvg**：其目的是让多个表的数据专属组件分布在多客户端上，
  以控制随表数线性增长的时空开销。本课题单表单机，无此问题。
  （附录 D 另有一条与本课题无关但方向明确的实测：本地步数 `N` 越大下游性能越差，`N = 1` 最好。）

**M3 对全部预训练目标一致通过**：预训练是**独立阶段**，只改变微调阶段的初始化；
微调阶段的逐流分数、ETA 的 top-`k` 聚合、BER 的多预算 CVaR-pAUC 与六档预算**逐位不变**。
**M4 亦无新增峰值**：预训练阶段不含 BER 的全体实体同图反传，
其峰值不高于当前 C01 的 `30,470 MiB`；新增成本是**时间**（一个额外的预训练阶段），不是显存。

**一条可降低重跑成本的实测（Rubachev §5.2 表 5）**：从**同一个预训练检查点**出发、
只改微调随机种子得到的「高效集成」，与每次独立重新预训练的「标准集成」性能相近
（如 GE `0.702` vs `0.709`、CA `0.411` vs `0.414`、CO 两者同为 `0.969`）。
**即预训练只需做一次，多种子只重跑微调阶段**；若本课题采纳预训练，
多种子成本按微调阶段计，不按「预训练 + 微调」全流程计。

### 2.4 族 B 无法核实的条目

- **全标注下预训练是否有收益**——族 B 与族 C 的证据方向相反，见 §2.1，待 B-V1 关闭。
- **分区方案（`K`、重叠比例、切分依据）**——TransTab 未给本课题可直接采用的值。
- **XTab 图 3 的胜率对应的效应量**——论文只给胜率与秩，未给指标绝对差量。
- **`τ`、`λ` 等对比损失超参**——XTab 未在正文给出，TransTab 的默认值未核。
  **`τ` 已由 SCARF 原文关闭，见 §2.5。**

### 2.5 破坏算子的原始出处：SCARF 原文核验（关闭两条待核项）

XTab 与 Rubachev 都把破坏算子归功于 SCARF，但两者都是**转述**。
按证据纪律，正式采用该算子前须回原文核对。**本节已完成该核验。**

`[本地全文]` Bahri、Jiang、Tay、Metzler（Google Research），
*SCARF: Self-Supervised Contrastive Learning using Random Feature Corruption*，
ICLR 2022，arXiv:2106.15147。
原件 `raw/papers/methodology/tabular-pretraining/2106.15147.pdf`（24 页）。
**该文件 `12.7 MB`，超出 MinerU `flash-extract` 的 `10 MB` 上限，本次改用精度模式
`mineru-open-api extract --pages 1-10`**，转写落
`wiki/papers/methodology/tabular-pretraining/2021-Bahri-SCARF-全文提取-mineru_p1-10.md`。

#### 算子的精确形式（算法 1）

```
q = ⌊c · M⌋                                  # M 为特征数，c 为破坏率
对每个样本 i：从 {1,…,M} 均匀采样大小为 q 的子集 I_i
x̃_j^(i) = x_j^(i)            若 j ∉ I_i
x̃_j^(i) = v,  v ~ X̂_j       若 j ∈ I_i
```

**`X̂_j` 是第 `j` 个特征的经验边缘分布，§3 给出其精确定义：
「该特征在训练集上所取值域的均匀分布」**——即在该列的观测值上有放回重采样。
**数值列与类别列同一处理**；论文另注明 SCARF 的边缘采样**在独热编码之前**进行。

#### 关闭的两条待核项

1. **破坏率 `60%` 的原始出处**：§4「Model architecture and training」原文——
   「除另有说明外，SCARF 类方法我们使用破坏率 `c = 0.6` 与温度 `τ = 1`」。
   **`60%` 确认，且同时给出 XTab 未在正文给出的 `τ = 1`。**
2. **数值字段 RTD 的替换分布**（§1.4 阻断 A 留下的空缺）：
   SCARF 的消融基线 **"Discriminative SCARF"** 正是数值列可用的 RTD——
   「预训练目标是区分原始输入特征与用我们提出的技术破坏过的对应特征；
   为此在预训练头上加一个最终线性投影，并把 InfoNCE 换成**二元逻辑损失**」。
   **即 TabTransformer 的 RTD 思路在 SCARF 中已有对数值列成立的实现，
   替换分布就是上式的 `X̂_j`。** §1.4 的「无文献依据」不再成立。

#### 第三条独立的全标注证据

摘要原文方向：SCARF 在 OpenML-CC18 的 **69 个真实表格分类数据集**上，
「不仅**在完全监督设定下**提升分类精度，在标签噪声存在时与半监督设定下同样提升」。
实验规模：每个数据集 `70%/10%/20%` 划分、**重复 30 次**、约 `100` 万 CPU 核时。

**故「全标注下预训练有收益」现有三条独立来源**：Rubachev 2022（15 种子 + Tukey HSD）、
XTab 附录 F（FT-Transformer 骨干）、SCARF（69 数据集 × 30 重复）。
§4.3 的裁决方向由此加强，**族 C 的反向自陈是三对一的少数方**。

#### 另外两条可直接采用的实现纪律

- **微调全部权重**：§2 明确 SCARF 与 VIME 的关键差异之一是
  「预训练后我们微调**全部**模型权重，**包括编码器**（不同于 VIME 只微调任务头），
  且只用任务监督」。**这与本课题现行的全模型微调一致，无需改动。**
- **预训练的早停判据**：§3 提出在**验证集 InfoNCE 损失**上早停——
  预先用无标注验证数据构造一组静态的 `(x, x̃)` 对，预训练期间跟踪该静态集上的损失。
  其余超参：批量 `128`、Adam 学习率 `0.001`、最多 `1000` 个预训练轮、早停耐心 `3`。
  **这些值出自 `256` 维 4 层 ReLU 编码器，不是 FT-Transformer，不得直接沿用，
  但早停判据的形式可采用。**

## 三、族 A：先验拟合网络与上下文学习（TabPFN 系）

这一族的**权重**已在可行性调研中因 G1（无可训练 `θ`）与 G2（行数上限）双双出局。
本节只问它的**机制**能否借鉴。任务提出三个具体候选，逐个核验。

两篇原件均已入库：

- `[本地全文]` Müller、Hollmann、Pineda Arango、Grabocka、Hutter，
  *Transformers Can Do Bayesian Inference*，ICLR 2022，arXiv:2112.10510。
  原件 `raw/papers/methodology/tabular-pretraining/2112.10510.pdf`（24 页）。
- `[本地全文]` Hollmann、Müller、Eggensperger、Hutter，
  *TabPFN: A Transformer That Solves Small Tabular Classification Problems in a Second*，
  arXiv:2207.01848。原件 `raw/papers/methodology/tabular-pretraining/2207.01848.pdf`（37 页）。

### 3.1 候选 A-1：合成先验预训练

#### 机制形式化（PFN §3、TabPFN §4）

定义一个数据集层面的先验 `p(D)`，从中采样合成数据集，训练 Transformer 最小化
**先验数据负对数似然** `ℓ_θ`。论文的两条结论给出该目标的意义：

- **Insight 1**：`ℓ_θ = E_{x,D∼p(D)} [ H( p(·|x,D), q_θ(·|x,D) ) ]`，
  即该目标等于真实后验预测分布与其近似之间交叉熵的期望。
- **推论 1.1**：`ℓ_θ` 等于期望 KL 散度 `E_{D,x}[ KL( p(·|x,D), q_θ(·|x,D) ) ]`，**至多相差一个可加常数**。

**该方法的唯一要求是「能够从 `p(D)` 高效采样」**（PFN §3 与 TabPFN §4.3 各自明写）。

TabPFN 的先验是**结构因果模型（SCM）先验与贝叶斯神经网络（BNN）先验的混合**，
训练时以等概率从两者之一采样数据集。三条设计要点：

1. **对先验超参用分布而非点估计**（§4.1），例如数据生成 SCM 的平均节点数取对数尺度均匀分布；
   由此近似出的后验预测分布**同时对超参空间与权重空间积分**。
2. **奥卡姆剃刀式的简单性偏好**（§4.2）：节点与参数更少的 SCM／BNN 有更高先验概率。
3. **SCM 采样过程**（§4.3）：每个数据集对应一个随机采样的 SCM（含 DAG 结构与确定性函数 `f_i`）；
   从图中选一组节点 `z_X` 作特征、一个节点 `z_y` 作目标，采样噪声变量并沿图传播。
   由此得到的特征与目标**通过生成 DAG 相关联**，目标既可能是特征的因、也可能是果。

#### 判定：M2 不通过，且是仓库边界层面的不通过

**要在本课题实现合成先验预训练，必须先有一个能采样加密恶意流量流级统计量的生成模型。**
这与仓库根 `AGENTS.md` 的研究边界直接冲突：
「研究对象固定为加密恶意流量检测的训练方法及训练系统，**不得转为流量生成**或传统分类器论文」。

即该机制的前置条件本身就是一个被边界排除的研究问题，**不是可借用的机制，而是另一个课题**。
这不是代价问题，也不是效果问题，是范围问题。

**另有一条独立的方向性理由**：合成先验的存在目的是**在真实数据稀缺时替代真实数据**。
本课题有 `11,991,315` 条真实标注流。动机方向与本课题相反，与可行性调研 §4.1 第 1 条同源。

**档位：不可借鉴。**

**须记录的一条相邻可用物**：Rubachev 2022 的「从**目标条件**经验分布 `p(x^j | ŷ)` 采样替换值」
（见 §4）是一个**留在真实数据内部**的数据构造手段，不是合成先验。
若「让模型见到更多样本组合」这一动机需要落地，它是可借鉴的形式，而合成先验不是。

### 3.2 候选 A-2：上下文学习的注意力结构

#### 机制形式化（PFN 图 1b、图 2a 与 §3；TabPFN §3）

- Transformer **编码器，无位置编码**——由此对数据集 `D` 中样本的排列**不变**。
- **每个「特征向量 ＋ 标签」对编码为一个 Token**。
- **注意力掩码是非对称的**：训练样本 Token **互相**注意；
  测试样本 Token **只注意训练样本**，彼此之间不注意。
- TabPFN 相对原始 PFN 的两处修改：调整注意力掩码以缩短推断时间；用**零填充**支持不同特征数。

#### 判定：类比在承重点上不成立

任务简报提出的类比是「本课题的实体正是一组流，与 ICL 的一组样本结构上相似」。
**该类比在最关键的一点上不成立**：

**ICL 的非对称掩码之所以存在，是为了把支持集的「标签」注入查询样本的预测**——
支持集 Token 编码的是 `(x_i, y_i)` **对**，标签是这条边的全部内容。
而在本课题的一个实体袋内部，**推断时没有任何一条流带已知标签**——
实体标签正是待预测量。**袋内不存在支持集／查询集的划分。**

去掉「带标签的支持集」之后，剩下的就是**排列不变的行间集合注意力**，
即 SAINT 的样本间注意力，已在 §1.2 判定（字面式代价不可接受，CLS-only 改编须先定袋大小上限）。
**故 A-2 不含独立于 §1.2 的可借鉴内容。**

**两条方向相反的结构性观察，须一并记录**：

1. **PFN 刻意去掉位置编码以获得排列不变性**（§3「An Efficient Architecture」）。
   本课题的协议是**时间上的因果前缀**，排列不变性恰恰是协议**不要**的性质。
   这是设计对照，不是可借鉴项。
2. **PFN／TabPFN 把整个特征向量编码为一个 Token**，**完全没有字段级注意力**。
   本课题骨干是 84 个 Token 的字段级注意力，且第三章的既有实测方向是「**字段交互是主信号**」。
   照搬 TabPFN 的 Token 化等于**删掉字段级注意力**，与骨干设计方向相反。

**档位：不可借鉴**（M3 在语义层不通过：袋内不存在带标签支持集；余下部分与 §1.2 重复）。

### 3.3 候选 A-3：行间注意力

族 A 中带行注意力的成员（TabICL 等）与 SAINT 的样本间注意力**同型**。
本次未取这些成员的全文，故**不作独立形式化**；其可借鉴性由 §1.2 的判定覆盖。

**档位：与 §1.2 重复，不单列。**

### 3.4 族 A 的一条次要候选（记录但不推荐）

TabPFN §3 的**推断期集成**：对同一数据集做 `32` 次前向，每次以概率 `0.5` 施加幂变换，
并**轮换特征列的索引与类别标签**，再集成。

其中「轮换特征列索引」**依赖列语义可互换**——TabPFN 的列经零填充后是通用槽位，本无固定语义；
而本课题的 `83` 个字段各有固定语义，**该增广在本课题无定义**。
余下的幂变换部分与本课题既有的封存输入变换（`sealed-input-transform.pkl`）功能重叠。

**档位：不可借鉴**（前半在本课题无定义，后半与既有实现重复）。

## 四、关闭 §2.1 记录的族 B／族 C 冲突

§2.1 记录了一处实质冲突：族 C 两篇自陈「全标注下预训练贡献不明显」，
而 XTab 附录 F 在全标注下游任务上测得自预训练相对不预训练有 `64.8%` 的胜率。
B-V1 指定 Rubachev 2022 为裁决对象。**该文已取全文，冲突可以关闭。**

`[本地全文]` Rubachev、Alekberov、Gorishniy、Babenko，
*Revisiting Pretraining Objectives for Tabular Deep Learning*，arXiv:2207.03208v2，2022-07-12。
原件 `raw/papers/methodology/tabular-pretraining/2207.03208.pdf`（17 页）。

### 4.1 该文正是为解决这一冲突而写

§1 原文方向：「与之相对，本文**聚焦于全标注表格数据集的设定**，
以理解预训练在完全监督设定下是否有助于表格深度学习，并**与强监督基线比较**。」

同一段还给出对族 C 那类协议的**方法学批评**：
「某些评价协议假设无标注数据充足，但在微调评价时只用每个数据集的一小部分标签——
这展示了预训练的有效性，却**在一定程度上限制了监督基线的性能**。」

**这直接指出了冲突的来源**：族 C 的「全标注下无收益」是在**半监督协议**中作为旁注得出的，
而该协议本身被 Rubachev 判为对监督基线不公平。

### 4.2 该文的实验强度高于冲突双方

| 项 | 设定 |
| --- | --- |
| 数据集 | 11 个中到大规模数据集，训练行数 `6,318`（GE）到 `723,412`（MI，MSLR-WEB10K） |
| 标注 | **全标注** |
| 超参 | **对基线与每个预训练方法都用 Optuna 逐数据集调参** |
| 种子 | **15 个随机种子**，报告测试集平均 |
| 显著性 | **Tukey HSD 检验** |
| 预训练数据 | 「预训练**始终直接在目标数据集上**进行，不使用额外数据」 |
| 破坏算子 | **随机特征重采样**（援引 SCARF 与 VIME），与 XTab §4 同一形式 |
| 预训练预算 | 每数据集最多 `100k` 次迭代，每 `10k` 次早停检查 |

冲突双方（SAINT 表 9、TabTransformer 表 3/4）均为**单一设定、无逐方法调参**，
且 SAINT 表 9 全部在 `50` 个标注点下测得。**证据强度不对等。**

### 4.3 裁决结果

**§3.2 主结论原文方向**：「基于自预测的简单预训练策略，
相比**调参后的、从头训练的监督基线**，在不同表格深度模型与数据集上
带来**显著的下游精度提升**。」

**表 3 平均秩（MLP，11 数据集，秩越低越好）**：

| 方法 | 平均秩 |
| --- | ---: |
| **不预训练** | **`5.5 ± 1.4`** |
| mask（掩码预测） | `3.8 ± 1.4` |
| rec（重构） | `3.6 ± 1.5` |
| rec + target | `3.7 ± 1.9` |
| sup（带增广的监督） | `3.0 ± 1.0` |
| mask + target | `2.9 ± 1.3` |
| mask + sup | `2.7 ± 1.2` |
| **rec + sup** | **`2.6 ± 1.5`** |

**不预训练在八个方法中排名最末，且与次末位差 `1.7` 个秩位。**

**冲突关闭方向：全标注下预训练有收益，族 C 的「无明显收益」不成立于严格对照下。**
族 B（XTab 附录 F）与 Rubachev 同向，族 C 反向且证据较弱。

**§2.5 补入第三条独立同向证据**：SCARF 在 69 个 OpenML-CC18 数据集、每个重复 `30` 次的条件下，
摘要即声明「**在完全监督设定下**提升分类精度」。**该项现为三对一。**

### 4.4 该文另外三条直接作用于本课题的结论

**（1）对比目标不是最优——这一条与 SAINT 表 9 独立同向。**
§3.2「Contrastive is not superior」：重构与掩码预测**都优于**对比目标；
且自预测目标「概念更简单、更易实现、资源消耗更低（每批不需要第二个增广视图、损失函数更简单）」。
论文建议把自预测目标作为表格预训练的实用方案。

**回看 SAINT 表 9**：仅对比 `85.58` < 不预训练 `85.78`，仅去噪 `86.21` > 不预训练。
**两篇独立工作在「对比不如重构／去噪」这一点上方向一致。**

**（2）目标感知目标优于其无监督对应版本，且本课题全标注。**
§4 定义两种引入标签的方式：

- **`+ sup`**：预训练阶段并联一个监督头，两个损失**等权相加**，用**不同的预测头**；
  两个损失都在破坏后的输入上计算，微调阶段在未破坏的完整数据上进行。
- **`+ target`**：修改预训练任务本身，两处改动——
  其一，把骨干输出 `z = f(x̂)` 与目标表示**拼接**后再送入预训练头：`p = h(concat[z, y])`
  （分类用独热编码）；
  其二，**改变破坏采样分布**：给定 `(x_i, y_i)`，先从 `{y | y ≠ y_i}` 上均匀采样一个新目标 `ŷ_i`，
  再把每个特征 `x^j` 替换为从**目标条件分布 `p(x^j | ŷ_i)`** 的采样，而不是无条件的 `p(x^j)`。
  直觉是「把样本朝着与原目标不同的方向破坏，使预训练任务与下游目标预测更相关」。

§4.1 的分目标结论：**掩码预测的目标感知改造带来显著提升，而重构的目标感知改造没有超过无监督重构**；
故实践建议是**重构配 `+ sup`、掩码预测配 `+ target`**。

**（3）机制解释（§4.2，合成数据受控实验）**：用可控特征重要度的合成数据训练，
再用一个独立 MLP 从冻结表征回归各特征的取值。结论是目标感知预训练比无监督预训练、
尤其比从头训练，**保留了更多关于信息量特征的信息**；
从头训练「成功捕获了最重要的那个特征，却**压制了次要但仍显著的特征**」。

**这条机制解释对本课题特别相关**：本课题源年验证集只有 `20` 个正实体，
且第三章的既有方向是「字段交互是主信号」。「从头训练压制次要但显著的特征」
若在本课题成立，正是一条可证伪的假设——**但它出自合成数据的受控实验，不是真实表格数据，
且未在类别极不平衡的任务上验证，标为待验证。**

### 4.5 冲突关闭后仍未消除的三条距离

1. **规模**。Rubachev 最大数据集 `723,412` 训练行，本课题 `11,991,315` 条，**大 `16.6` 倍**。
   **该文数据集跨度内已出现一处方向性信号**：§4.3 与 GBDT 的比较中，
   「结合数值特征嵌入后，预训练使模型在**多数**数据集上优于 GBDT，
   **两处例外是 WE 与 MI**」——而 WE（`296,554` 行）与 MI（`723,412` 行）
   **恰是全部 11 个数据集中最大的两个**。
   论文未把这一点归因于规模，**本推论由本文件提出，属未验证假设**；
   但它与 XTab「light `71.0%` → heavy `56.1%`」的预算衰减同向，
   构成「收益随规模／预算增大而衰减」这一方向的**两条独立风险**。
2. **类别不平衡与指标**。Rubachev 的指标是准确率、ROC-AUC、RMSE、对数损失；
   本课题主指标是实体级 AP 与多预算 CVaR-pAUC，源年验证集只有 `20` 个正实体。
   **该文没有任何极端不平衡任务的证据。**
3. **骨干**。表 2、表 3 的模型是 MLP、MLP-PLR、MLP-T-LR，**不含 FT-Transformer**。
   XTab 用的是 FT-Transformer，但只报告胜率与秩、不报告效应量。
   **「FT-Transformer 骨干上、全标注、千万行、极不平衡」这个交叉设定，三篇都没有覆盖。**

### 5.2 卡二：目标条件破坏算子（与本课题全标注设定最贴合的单点改动）

```md
## Research Question Card

Question:
  把预训练的破坏采样分布从无条件的 p(x^j) 换成目标条件的 p(x^j | ŷ)（ŷ ≠ y），
  是否比无条件破坏带来额外提升？

Type: applied（破坏算子的形式选择）

Hypothesis:
  H0——目标条件破坏相对无条件破坏无额外提升。
  H1——有额外提升，且提升来自「预训练任务与下游目标预测更相关」这一机制。

Why it matters:
  这是三族中唯一一条「显式利用全标注这一事实」的自监督形式。
  本课题 1199 万条流全部带标签，而族 C 的反向自陈恰恰是「全标注下无监督预训练无用」。
  若增益确实来自标签的利用，则本课题的全标注不再是预训练的不利条件，而是前提。

Current evidence:
  - [本地全文] Rubachev §4 形式：给定 (x_i, y_i)，从 {y | y ≠ y_i} 均匀采样 ŷ_i，
    再把每个特征替换为 p(x^j | ŷ_i) 的采样；并把预训练头条件化为 p = h(concat[z, y])。
  - [本地全文] Rubachev 表 3（MLP）：mask+target 2.9±1.3 优于 mask 3.8±1.4；
    §4.1 明确「掩码预测的目标感知改造带来显著提升，
    而重构的目标感知改造没有超过无监督重构」。
  - [本地全文] Rubachev §4.2 合成数据受控实验给出机制解释：
    目标感知预训练比从头训练保留更多「次要但仍显著」特征的信息。
  - [本地全文] TransTab 式(5) 监督 VPCL 是同一思路的另一实现
    （用同类别构造正对），表 6 五数据集上「总是带来正效应」，
    而普通迁移在其中两个数据集上损害性能。

Missing evidence:
  - 二分类且极端不平衡时，{y | y ≠ y_i} 退化为单一类别，
    目标条件破坏是否仍有区分度——三篇均无此设定的证据。
  - p(x^j | ŷ) 在本数据上的估计方式与代价（须按类别分桶存列的经验分布）。
  - 该算子与 §4.4 记录的「机制解释出自合成数据」之间的距离。

What would support it:
  在卡一确立正基线之后，同一配方下「无条件破坏」与「目标条件破坏」两臂，
  后者在既有选轮指标上占优且多种子方向一致。

What would falsify it:
  两臂无差异；或二分类退化使目标条件破坏等价于「总是替换为反类样本」
  而产生可识别的分布伪影。

Minimal next action:
  先做只读诊断：按源年标签分桶，计算 83 个字段各自的类条件经验分布与
  无条件经验分布的距离（如 Wasserstein 或 KS）。
  若绝大多数字段两者几乎重合，则该算子在本数据上无区分度，可零成本否决。

Decision: read more → 只读诊断（本卡的最小下一步不需要任何训练）
```

**卡二的最小下一步是零训练成本的**，且**逻辑上先于卡一的实验**——

## 六、三档汇总

### 6.1 可直接借鉴（M1–M4 全过）

**这一档只收「形式」，不收「收益主张」**——即这些形式可以直接采用，
但采用它们能否提升本课题指标，仍属实验待证。

| # | 机制 | 出处 | 形式 |
| --- | --- | --- | --- |
| 1 | **按列经验边缘分布重采样的破坏算子** | **SCARF 算法 1 与 §4（原文已核，见 §2.5）**；XTab §4 与 Rubachev §3.1 转述同一形式 | `q = ⌊c·M⌋`，均匀选 `q` 个字段，各自从该列**训练集观测值上的均匀分布**重采样；破坏率 `c = 0.6`、温度 `τ = 1`；数值列与类别列同一处理，边缘采样在独热编码之前 |
| 2 | **可共享组件划分规则** | XTab 附录 B | 预训练覆盖全部 Transformer 块，**排除 `[CLS]` Token**；`[CLS]` 与预测头在微调阶段重新初始化 |
| 3 | **自预测优先于对比** | Rubachev §3.2；SAINT 表 9 独立同向 | 重构与掩码预测均优于对比；自预测每批不需要第二个增广视图，代价更低 |
| 4 | **预训练与微调的两阶段纪律** | Rubachev §3.1、§4 | 预训练在破坏输入上进行，**微调在未破坏的完整数据上**；学习率与权重衰减两阶段共享 |

第 3、4 条是**设计规则**而非算子，采用它们不增加任何实现成本。

### 6.3 不可借鉴

| 机制 | 首个不通过的判据 | 关键理由 |
| --- | --- | --- |
| **合成先验预训练（SCM ＋ BNN）** | **M2** | 前置条件是构造加密恶意流量的生成模型，属仓库根 `AGENTS.md` 明确排除的「流量生成」；且动机方向（替代稀缺真实数据）与本课题 `1199` 万条真实标注流相反 |
