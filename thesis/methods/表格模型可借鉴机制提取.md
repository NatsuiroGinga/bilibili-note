## 一、族 C：架构提案（TabTransformer、SAINT）

这一族本来就是「架构 ＋ 在目标表自身数据上的自监督目标」，不依赖跨表权重，
故 **M1 天然通过**，是三族中最可能有直接可用机制的一族。

### 1.1 TabTransformer 的替换标记检测

`[本地全文]` Huang、Khetan、Cvitkovic、Karnin（Amazon AWS），
*TabTransformer: Tabular Data Modeling Using Contextual Embeddings*，arXiv:2012.06678v1，2020-12-11。
原件 `raw/papers/2012.06678v1.pdf`（17 页）；转写 `.Codex/docs/2026-09-02-表格模型机制提取/md/TabTransformer.md`。
**定位到章节与表号，非印刷页码。**

#### 机制形式化（§2「Pre-training the Embeddings」）

给定类别特征向量 `x_cat = {x_1, …, x_m}`：

- **RTD**：把原特征值替换为**该特征自身取值域内的一个随机值**，
  训练一个二分类器判断「该位置是否被替换过」。
- **MLM**：随机选 `k%` 个特征置为缺失，训练多分类器还原其原值。

三处实现细节是论文明确写死的，且都有消融支撑：

| 细节 | 取值与理由 | 消融证据 |
| --- | --- | --- |
| **不用 ELECTRA 的辅助生成器** | 理由有二：类别特征的类数有限；且**每列一个独立二分类器**，不是共享分类器——因为每列有自己的嵌入查找表 | 见下行 |
| **每列独立分类器 ＋ 动态替换** | 「动态」指每个 epoch 重新随机替换 | 表 7（256 个标注点，3 数据集）：动态＋独立 `+0.81 ± 0.19` 相对 AUC；静态＋独立 `−0.33 ± 0.15`；静态＋共享 `−0.49 ± 0.11` |
| **替换比例 `k = 30`** | 论文自陈「最终微调精度对 `k` 不甚敏感」 | 表 6，网格 `{15, 30, 50}` |

RTD 与 MLM 的对比（半监督，标注点 50／200／500）：

| 设定 | RTD | MLM |
| --- | --- | --- |
| 表 3（6 个 >30K 数据点的数据集） | `66.6 / 70.9 / 73.1` | `66.8 / 71.0 / 72.9` |
| 表 4（9 个较小数据集） | `78.6 / 81.6 / 83.4` | `78.5 / 81.0 / 82.4` |

论文归因：无标注数据较少时 RTD 优于 MLM，因为「二分类比多分类是更容易的预训练任务」，与 ELECTRA 一致。

#### 两条对本课题的阻断

**阻断 A：RTD 的定义域是类别列，而本课题 81/83 是数值列。**

这是架构层面的事实，不是实现选择。论文 §2 定义 `x ≡ {x_cat, x_cont}`，
其中 Transformer **只处理 `x_cat`**；`x_cont ∈ R^c` **完全绕过 Transformer**，
在 MLP 入口处与上下文嵌入拼接成 `(d × m + c)` 维向量。
故 RTD 与 MLM 在原论文中**只定义在类别列上**。

本课题 83 字段 = 81 数值 + 2 词表，**字面 RTD 只覆盖 2/83 个字段**。

**须同时记录一处对本课题有利的差异**：本课题骨干是 FT-Transformer，
其 FeatureTokenizer 把**数值字段也变成 Token**（每个数值字段一行 weight + 一行 bias）。
即架构上不存在 TabTransformer 的那道墙，把 RTD 推广到数值列在结构上是自然的。
**但那是改编，不是论文的形式**——TabTransformer **没有提供任何数值字段 RTD 的证据**，
数值列的「随机替换」还需定义替换分布（经验边缘分布？高斯噪声？），论文对此无话可说。

**阻断 B：全标注下预训练收益，论文自陈「不明显」。**

§3「Setup」原文方向：预训练**只在半监督场景下使用**，
作者明确写「**当全部数据都有标注时，我们没有发现使用它有多少收益**」。

本课题训练有效流 `11,991,315` 条**全部带标签**。这条自陈直接落在本课题的设定上。

### 1.2 SAINT 的样本间注意力与对比预训练

`[本地全文]` Somepalli、Goldblum、Schwarzschild、Bruss、Goldstein，
*SAINT: Improved Neural Networks for Tabular Data via Row Attention and Contrastive Pre-Training*，
arXiv:2106.01342，2021。原件 `raw/papers/methodology/tabular-pretraining/2106.01342.pdf`（18 页）。

#### 机制一：样本间注意力（intersample attention，MISA）

**形式化（§3.1 式(1)(2)、§3.2 算法 1）**。单层管线：

```
z_i^(1) = LN(MSA(E(x_i))) + E(x_i)          # 字段间自注意力
z_i^(2) = LN(FF_1(z_i^(1))) + z_i^(1)
z_i^(3) = LN(MISA({z_i^(2)}_{i=1}^b)) + z_i^(2)   # 样本间注意力
r_i     = LN(FF_2(z_i^(3))) + z_i^(3)
```

MISA 的实现（算法 1，PyTorch 伪代码）是一个**三行改写**：

```python
def intersample_attention(x):   # x 是 b×n×d
    b, n, d = x.shape
    x = reshape(x, (1, b, n*d))     # 把每个样本的全部字段嵌入拼成一个 token
    x = self_attention(x)           # 在「样本」这一轴上做标准自注意力
    out = reshape(x, (b, n, d))
    return out
```

即**把整行拼成一个向量，然后在行之间做标准自注意力**。
论文强调它与轴向注意力（Axial Transformer、MSA Transformer、TABBIE）的差别：
后者是同一字段跨行通信，而 MISA「允许不同样本的**全部**字段互相通信」；
其层次是先字段内交互、再整行之间交互。论文另给一个等价视角：
MISA 可看作在**所有行两两相连的完全图**上的图注意力。

**论文报告的三条经验性质**：

| 性质 | 证据 |
| --- | --- |
| 参数多但更快 | 表 1：SAINT-s（仅自注意力）`L=6`、`91.6M` 参数、`1759` 秒；SAINT-i（仅样本间）`L=1`、`352.7M` 参数、`123` 秒；SAINT（两者）`L=1`、`347.3M`、`144` 秒。**SAINT-i 参数是 SAINT-s 的 3.8 倍，耗时却只有 1/14** |
| 字段多时优势明显 | §5：SAINT-i「在字段数大时一致优于其他变体」，尤其「样本少而字段多」（Arcene `200×783`、Arrhythmia `452×226`） |
| 注意力稀疏 | §6：「一个批次中极少的点获得注意力」；稀疏度随数据集难度下降（MNIST 稀疏、Volkert 稠密） |
| 批大小不敏感 | §5 与附录 E：批大小 `32`–`256` 之间 SAINT-i 的性能变化「很小」 |

#### 机制二：对比 ＋ 去噪预训练

**增广（§4 式(3)(4)）**：

```
x_i' = x_i ⊙ m + x_a ⊙ (1 − m)          # CutMix，在原始数据空间
p_i' = α · E(x_i') + (1 − α) · E(x_b')   # mixup，在嵌入空间
```

`m ~ Bernoulli(p_cutmix)`，`x_a`、`x_b` 是当前批内随机样本，`x_b'` 是 `x_b` 的 CutMix 版本。
**先给批内每个点随机选伙伴做 CutMix，嵌入后再重新选伙伴做 mixup**——两次伙伴不同。

**损失（式(5)）**：InfoNCE 对比项 ＋ `λ_pt` × 逐字段重构项，
重构对类别字段用交叉熵、对连续字段用均方误差，**每个字段一个单隐层 MLP 头**（共 `n` 个）。

冻结参数（§5）：`p_cutmix = 0.3`、`α = 0.2`、`λ_pt = 10`、`τ = 0.7`。

**表 9 消融（50 个标注点，14 数据集平均 AUC）——这是本节最关键的一张表**：

| 研究 | 变体 | SAINT-s | SAINT-i | SAINT |
| --- | --- | ---: | ---: | ---: |
| 1 投影头 | 无投影头 | `84.26` | `83.56` | `84.90` |
| | 共享权重投影头 | `85.31` | `85.20` | `86.89` |
| | **两个不同投影头** | `86.02` | `85.26` | `86.96` |
| 2 预训练损失 | **无预训练** | `85.14` | `83.93` | `85.78` |
| | 仅对比 | `85.40` | `84.42` | **`85.58`** |
| | 仅去噪 | `84.74` | `84.93` | `86.21` |
| | 仅余弦相似 | `85.03` | `84.35` | `85.70` |
| | **对比 ＋ 去噪** | `86.02` | `85.26` | `86.96` |
| 3 增广 | 仅 CutMix | `82.80` | `84.61` | `85.37` |
| | 仅 mixup | `86.01` | `84.41` | `86.45` |
| | **CutMix ＋ mixup** | `86.02` | `85.26` | `86.96` |

三条读数须一并记录：

1. **仅对比预训练在完整 SAINT 上低于不预训练**（`85.58 < 85.78`）。
   即「对比学习本身」不是增益来源，**对比与去噪的组合**才是（`86.96`，`+1.18`）。
   引用 SAINT 支持「加对比损失」时若不带这一条，属选择性引用。
2. 增广也必须成对：仅 CutMix `85.37` 低于不预训练的 `85.78`。
3. 以上全部在**只有 50 个标注点**的设定下测得。

**同一篇的全标注自陈（§5「Semi-supervised setting」）**：
「当全部训练样本都有标注时，我们注意到预训练的贡献不明显，
有无预训练的结果相当接近。」——与 TabTransformer §3 的自陈方向一致，**两篇独立同向**。

#### M2、M3：三处结构性冲突

**（1）时间因果边界（M2 冲突，须核验）**。本课题训练用 `truncate_length = 8192` 的
**因果前缀**截断。袋内全连接注意力允许一条流 attend 到**同实体内更晚发生的流**，
这与因果前缀协议方向相反。ETA 是对已产生的逐流分数做 top-`k` 聚合，不引入时序反向依赖；
袋内注意力**会**引入。是否构成实质违规，取决于评价协议是否要求逐流分数只依赖该流的历史前缀——
**本次未核验该协议原文，标为待验证**。

**（2）逐流分数不再是该流自身的函数（M3 影响 ETA 的语义，不影响可微性）**。
ETA 的挂载点是逐流 logit `l_{e,t}`，聚合式 `S_e = (1/k_e)·Σ_{top-k_e} l_(t)` 与梯度支撑闭式
`∂S_e/∂l_{e,t} = (1/k_e)·1[t ∈ top-k_e]` **不依赖 `l_{e,t}` 如何产生**，
故**端到端可微性不受影响，ETA 仍能挂载**。但 `l_{e,t}` 变成袋内全体流的函数后，
ETA 方案第五节已登记的「训练截断袋、评价完整袋、偏差符号随袋内漂移方向翻转、无假设不可定界」
这条局限会**从聚合层扩散到打分层**，不确定性放大而非缩小。

**（3）作用面被袋分布压到与 ETA 同一区间**。源年验证侧中位袋 `m = 2`，
`m ≤ 2` 的实体占 `68.4%`（`9250/13529`）。在 `m = 2` 的袋上，袋内注意力是一个 `2×2` softmax；
在 `m = 1` 的袋上完全退化为恒等。故该机制的**结构作用面上界与 ETA 相同（约 `31.6%`）**，
而代价高出若干数量级。

**一处与 SAINT 原设定相反的、对本课题有利的差异**：SAINT 的 MISA 在**任意小批次**上做注意力，
故推断时一行的预测依赖于恰好同批的其他行——这是该设计的已知弱点。
本课题若改为在**实体袋**上做，袋是协议定义的单元而非随机批次，**该弱点消失**。
这是把 MISA 迁到本课题的唯一实质动机，也是它值得进「需前置验证」而非直接出局的理由。

### 1.3 族 C 的档位判定

| 机制 | M1 | M2 | M3 | M4 | 档位 |
| --- | :-: | :-: | :-: | :-: | --- |
| **RTD／MLM 自监督预训练**（作为独立预训练阶段） | `○` | `○` | `○` | `○` | **需前置验证** |
| **对比 ＋ 去噪预训练**（CutMix + mixup + InfoNCE + 逐字段重构） | `○` | `○` | `○` | `○` | **需前置验证** |
| **样本间注意力（SAINT 字面式，`n·d` 拼接）** | `○` | `△` | `○` | **`×`** | **不可借鉴** |
| **流间注意力（CLS-only 改编，袋内）** | `○` | `△` | `○` | `△` | **需前置验证** |

四行的判定理由：

- **两个预训练目标 M3 天然通过**：预训练是**独立阶段**，只改变微调阶段的初始化，
  微调阶段的损失、逐流分数、ETA 与 BER 的挂载**逐位不变**。M4 亦无新增峰值——
  预训练阶段不含 BER 的全体同图反传，其峰值不高于当前 C01 的 `30,470 MiB`。
  它们落「需前置验证」而非「可直接借鉴」的唯一理由是**收益存疑**：
  两篇论文各自自陈全标注下预训练贡献不明显，而本课题是 `11,991,315` 条全标注流。
- **SAINT 字面式 M4 不通过**：单层 `1,040,449,536` 参数 = 骨干的 `1125.7` 倍；
  即便退到附录 C 的降维式仍是 `35.7` 倍。M2 记 `△` 是因时间因果边界待核。
- **CLS-only 改编 M4 记 `△`**：参数量 `147,456`（`0.16×` 骨干）可接受，
  但注意力矩阵在完整袋下为 `22.3 TiB`，**必须先给出袋大小上限或线性化方案**才能通过。

## 二、族 B：跨表预训练 ＋ 梯度微调（XTab、TransTab）

这一族的**权重**不可迁移（见可行性调研），但它的**预训练目标与结构分离设计**与本课题同构——
它们和本课题一样用标准小批量梯度微调，故 M3 天然通过。

### 2.1 XTab 的三种预训练目标与破坏视图

`[本地全文]` Zhu、Shi、Erickson、Li、Karypis、Shah，*XTab: Cross-table Pretraining for
Tabular Transformers*，ICML 2023，arXiv:2305.06090。
原件 `raw/papers/methodology/tabular-pretraining/2305.06090.pdf`（24 页）。
**定位到章节与表号，非印刷页码。**

#### 破坏视图的定义——这一条直接补上了族 C 留下的空缺

§4「Table corruption」原文方向：随机选取每行的一部分字段，
**从该列的经验边缘分布中重采样**来破坏它们；
**破坏比例对所有数据集统一设为 `60%`**，援引 SCARF（Bahri 等 2021）的建议。
即每个样本 `x` 与其破坏视图 `x̃` 之间，`60%` 的条目被重采样、`40%` 保持不变。

**这是本次调研对本课题最直接有用的一条形式**：TabTransformer 的 RTD 只定义在类别列上，
数值列如何「随机替换」它无话可说（族 C 阻断 A）。
XTab 给出的「**从该列经验边缘分布重采样**」对数值列与类别列**一视同仁**，
不需要噪声尺度、不需要分布假设，且**与本课题 81 数值 + 2 词表的混合字段直接相容**。
本课题若实现自监督预训练，破坏算子可直接采用这一形式，比例 `60%` 有 SCARF 与 XTab 两处来源。

#### 三种目标的形式与实测排序

| 目标 | 形式（§3.1.3） | 是否用标签 |
| --- | --- | :-: |
| **重构** | 破坏视图 `x̃` 过骨干与投影头得 `x̂`，与原样本 `x` 比较；**类别列用交叉熵、数值列用均方误差** | 否 |
| **对比** | `(x, x̃)` 为正对，同批其他样本为负对；InfoNCE；投影头同 SimCLR | 否 |
| **监督** | 投影头直接预测该表预定义的标签列（论文称 target-aware pretraining／pre-finetuning） | 是 |

**实测排序（图 3，FT-Transformer 骨干，2000 预训练步）**：
重构 > 对比 > 监督。重构目标 light 微调（固定 3 epoch）胜率 `71.0%`，
heavy 微调（早停耐心 3）**只剩 `56.1%`**。

XTab 对这一衰减给出的**自己的**归因值得原样记录：
「差异由深度模型的**灾难性遗忘**引起。由于表格 transformer 相对较小
（FT-Transformer 骨干 `<1M` 参数），它们在微调阶段更易受灾难性遗忘影响。」

**本课题骨干正是 `924,283` 参数，落在这句话所指的量级内，且训练预算远超 heavy。**

#### 可共享组件的识别（附录 E）——一条可直接照搬的设计规则

XTab 做了一个消融：把 FT-Transformer 的不同部分标为「可共享（被预训练）」，其余标为数据专属。
结论有二：

1. **最有利的划分是「预训练全部 Transformer 块、但不含 `[CLS]` Token」。**
2. **预训练 `[CLS]` Token 不带来改进**，因为「`[CLS]` Token 直接关系到下游预测，
   因而高度数据专属」。

这条规则**不需要任何外部权重即可采用**：本课题若做自预训练，
预训练阶段应覆盖三个 Transformer 块，而 `[CLS]` Token 与预测头在微调阶段重新初始化。

#### 附录 F 表 2：自预训练与跨表知识的分离——本次调研的核心读数

**先纠正一处极易读错的表头。** 表 2 的行标是
「win rate (**against w/o external task**)」，即三列胜率**全部以「无外部任务」为对手**：

| 对手＝「无外部任务」（自预训练） | 胜率 |
| --- | ---: |
| `w/o external task`（自预训练，与自己比） | `50%` |
| `baseline`（完全不预训练） | **`35.2%`** |
| `w/ external tasks`（XTab 跨表初始化 ＋ 自预训练） | **`55.7%`** |

三个臂的定义（附录 F 原文）：

- `w/o external task`：随机初始化 → **在下游任务自己的训练集上预训练** → 微调
- `baseline`：随机初始化 → 直接微调
- `w/ external tasks`（XTab）：XTab 初始化（用外部表）→ 在下游数据上预训练 → 微调

**正确读法**：完全不预训练的 baseline 对自预训练只赢 `35.2%`，即**输 `64.8%`**——
自预训练相对不预训练有实质优势；而跨表外部知识相对自预训练只多赢 `5.7` 个百分点（`50% → 55.7%`）。

**结论方向**：增益的大头来自「**在自己的数据上先做自监督**」，而非「跨表外部知识」。
**这正是本课题可做而无需任何外部权重的部分**——用 LSPR23 自己的 `11,991,315` 条流，不碰 LSPR24。

**须同时记录的三条限制**：

1. 该表在 **heavy 设定、重构损失**下测得。本课题预算远超 heavy，处在图 3 那条下降曲线更右端，
   **该区间无实验**。
2. 胜率是**跨 84 个下游任务的比例**，不是效应量。`64.8%` 的胜率不等于任何具体的指标提升幅度。
3. 附录 C：「XTab 的优势并不随微调数据减少而更显著」，原因是 featurizer 与投影头仍需足够数据
   从头训练，「因此 XTab 不兼容零样本学习」。

#### 一处与族 C 直接冲突的证据，须如实记录

**族 C 两篇独立自陈「全标注下预训练贡献不明显」**（SAINT §5、TabTransformer §3）。
**XTab 附录 F 的下游任务是 AMLB 的全标注表格任务，自预训练仍取得 `64.8%` 的胜率。**

**这是文献内部的实质冲突，不是措辞差异**，本文件不作调和。
两处可能的差异来源（**均为推论，未验证**）：族 C 把预训练当作**半监督手段**测（少标注 + 多无标注），
XTab 把它当作**初始化与正则手段**测（全标注）；两者的对照臂与预算设定不同。
Rubachev 等 2022（arXiv:2207.03208，XTab 与 TransTab 均引用）正是研究全标注下预训练目标的工作，
是裁决该冲突的首选核验对象，见 §2.3。

**在该冲突关闭前，任何「自预训练能提升本课题指标」的主张只能标为「实验待证」。**

#### 一条与本文件主题无关但已实测的副产品

XTab §4 的模型配置原文：「与 Gorishniy 等（2021）相同，3 个 transformer 块、
特征嵌入 `192`、8 个注意力头。**前馈网络有两层，尺寸与嵌入相同**」，
即 `ffn_hidden = 192`。本课题合同是 `int(192 × 4/3) = 255`。
**这直接关闭了可行性调研 §4.2 列为「无法核实」的第一条**：
XTab 与本课题的 FFN 宽度不等，其 `96.01%` 的权重迁移比例**不成立，须重估**。

### 2.2 TransTab 的垂直分区对比学习

`[本地全文]` Wang & Sun，*TransTab: Learning Transferable Tabular Transformers Across Tables*，
NeurIPS 2022，arXiv:2205.09328。
原件 `raw/papers/methodology/tabular-pretraining/2205.09328.pdf`（19 页）。

#### 机制形式化（§2.3 式(4)(5)）

把样本 `x_i` 的列**垂直切成 `K` 个分区** `x_i = {v_i^1, …, v_i^K}`，相邻分区**可以重叠**
（重叠比例按分区列数的百分比确定）。每个分区独立过编码器，取其 `[CLS]` 嵌入 `z^[cls]`
的线性投影 `ẑ^[cls]`；`ψ(·,·)` 是余弦相似度。

**自监督 VPCL（式 4）**——同一样本的不同分区互为正对，其他样本的分区为负对：

```
ℓ(X) = − Σ_{i=1}^{B} Σ_{k=1}^{K} Σ_{k'≠k}
        log [ exp ψ(v_i^k, v_i^{k'}) / Σ_{j=1}^{B} Σ_{k'} exp ψ(v_i^k, v_j^{k'}) ]
```

**监督 VPCL（式 5）**——正对放宽为**同类别**的任意样本的任意分区：

```
ℓ(X, y) = − Σ_i Σ_j Σ_k Σ_{k'} 1{y_j = y_i}
          log [ exp ψ(v_i^k, v_j^{k'}) / Σ_{j'} Σ_{k'} 1{y_{j'} ≠ y_i} exp ψ(v_i^k, v_{j'}^{k'}) ]
```

计算约定：`K > 2` 时**随机抽两个分区**，故每步前向代价为 `2×`，与 `K` 无关。

论文对监督 VPCL 相对「普通监督预训练」的论证：普通监督预训练用任务专属预测头，
微调时丢弃换新头，会使编码器偏向主要任务与主要类别，且超参区间跨数据集差异大；
VPCL 借用监督对比学习（Khosla 等）的形式，论文称其「对噪声与超参更鲁棒」。

#### 实测（表 6，临床试验五数据集，AUROC）

| 设定 | N00041119 | N00174655 | N00312208 | N00079274 | N00694382 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Supervised（不预训练） | `0.6313` | `0.8348` | `0.7444` | `0.6885` | `0.7293` |
| Transfer（普通迁移） | `0.6424` | `0.8183` | `0.7458` | `0.6928` | `0.7239` |
| Self-VPCL | `0.6412` | `0.8577` | `0.7486` | `0.7069` | `0.7348` |
| **VPCL（监督）** | `0.6405` | `0.8583` | **`0.7517`** | `0.7063` | **`0.7392`** |

论文自陈：普通迁移策略**在两个数据集上损害了性能**（`0.8183 < 0.8348`、`0.7239 < 0.7293`），
而 VPCL 「总是带来正效应」。分区数增加时 VPCL 对 Self-VPCL 的优势扩大（图 4）。

**同一篇的一条独立负面证据**（与可行性调研的跨表结论同向）：
在公开数据集上预训练时（表 12），「在**不相关**的表格数据上预训练通常对微调收益甚微，
因为这些表定义了完全不同的列和目标任务」。

#### 为什么 VPCL 对本课题特别相关

**三条结构性契合，均可机械核验**：

1. **不需要定义数值字段的破坏分布**。VPCL 的视图来自**列子集**而非**值扰动**，
   故它绕过了族 C 阻断 A 与 XTab 破坏算子都必须回答的「数值列怎么加噪」问题。
2. **不需要改动骨干**。本课题 FeatureTokenizer 逐字段产出一个 Token（83 字段 + `[CLS]` = 84 Token），
   一个「垂直分区」就是**一个 Token 子集**；Transformer 对变长 Token 序列天然支持。
   **注意**：TransTab 自身的变长列能力依赖「把列名当文本 Token」，
   而本课题**不需要这条**——FT-Transformer 的 Token 已经逐字段独立参数化，删掉一部分 Token 即得一个视图。
   即 **VPCL 的目标可以脱离 TransTab 的输入处理器单独移植**。
3. **监督 VPCL 与本课题的全标注设定一致**。本课题 `11,991,315` 条流全部带标签。
   在族 C 两篇自陈「无标注预训练在全标注下收益不明显」的背景下，
   **用标签构造正对的监督 VPCL 恰好落在证据缺口的另一侧**。

**须同时记录的三条风险**：

- **M2**：监督 VPCL 使用源年标签 `y23`。这不触碰最终测试隔离（`y23` 已被 C00 的逐流 BCE 使用），
  但 ETA 参数登记表中「接触最终目标标签：否」的口径**只覆盖 ETA 的 `α`**，
  新增机制须另立登记项，不得沿用。
- **分区方案是一个未定的魔法数字**：`K`、重叠比例、以及**按什么切分 83 个字段**（随机？按语义组？）
  论文未给本课题可直接采用的值，须自行确定并登记依据。
- 表 6 是**五个数据集的单点数值，无种子方差**；差量最大处为 `+0.0235`（N00174655，VPCL vs Supervised），
  最小处为 `−0.0008`（N00041119，VPCL vs Self-VPCL）。**不得当作效应量引用。**

其峰值不高于当前 C01 的 `30,470 MiB`；新增成本是**时间**（一个额外的预训练阶段），不是显存。
