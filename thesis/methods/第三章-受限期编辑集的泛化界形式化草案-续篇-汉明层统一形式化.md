## §1 层的形式化，与两条算子的**实际层支持**（含源码核对）

### 1.1 层及其基数

**定义 层-0（汉明层）。** 对输入 `x`（长度 `L`，字母表 `A`）与整数 `q ∈ [0, L]`，

```
S_H(x; q) := { x' : d_H(x, x') = q } ,   B_H(x; q) = ⊔_{j=0}^{q} S_H(x; j) .
```

**【本文推论】层-1（基数）**：
在**全串**上是 `|S_H(x;q)| = C(L,q)·(A−1)^q`；
在**算子可达空间**（可编辑位 `E(x)`，`n = |E(x)|`，逐位合法替换数 `a_i ≤ A−1`）上是
`|S'_H(x;q)| = Σ_{Q⊆E, |Q|=q} Π_{i∈Q} a_i ≤ C(n,q)·(A−1)^q`。

> **纠正（对照主代理给的 `|S_H(x,q)| = C(L,q)`）**：该式**缺字母因子 `(A−1)^q`**，
> 只在二元字母表（`A = 2`）或「只数位置集合、不计替换字符」时成立。
> 本课题 `A = 37`（`ALPHA = "abcdefghijklmnopqrstuvwxyz0123456789-"`，
> `official_p2p3.py` L69；逐位替换排除恒等 ⇒ 每位 `A−1 = 36` 个选择），
> 故 `|S_H(x;q)| = C(L,q)·36^q`，**字符因子支配**。这个纠正对 §2 的结论有实质影响。

**阶梯关系（本文其余部分的骨架）**【本文推论】：
`S_H(x;0) = {x}`；`B_H(x;q) = ⊔_{j≤q} S_H(x;j)`；`N'(x;q) = ⊔_{j≤q} {x^{(j)}}`（草案 §1.2），
即**链是「每层恰好取一个点」的选择函数**。

### 1.2 两条算子的**实际层支持**（源码核对，非推测）

**（a）训练核 `perturb2`** ——【沿用原文：`official_p2p3.py` L231–242】
```python
def perturb2(domain, rng):
    body = domain.rsplit(".", 1)[0];  tail = "." + ... if "." in domain else ""
    if len(body) < 4: return domain            # ← 短 body 原样返回：零编辑
    b = list(body)
    for i in rng.sample(range(len(body)), 2):  # ← 无放回抽样：2 个不同位置
        c = rng.choice(ALPHA)
        while c == b[i]: c = rng.choice(ALPHA) # ← 排除恒等替换
        b[i] = c
    return "".join(b) + tail
```

**【本文推论】层-2（训练核 = 层上的均匀采样，但含零层退化）**：
- 对 `len(body) ≥ 4` 的输入，`perturb2` 的输出与输入**恰好差 2 个位置**（`rng.sample` 无放回 ⇒
  位置互异；`while` 排除恒等 ⇒ 每位置确被改变），且位置与字符**均匀随机**
  ⇒ **`perturb2` 是 `S_H(body; 2)` 上的均匀采样**（样本数 `C(|body|,2)·36^2`，等概率）。
- 对 `len(body) < 4` 的输入，`perturb2` **返回原串**，即落在 **`S_H(x;0) = {x}`**。
- ⇒ **训练核的支持是层混合 `{0, 2}`，不是单层**；零层分量为短域名的确定性退化。
- **操作对象是 `body`（末点号之前），不是 `E(x)`**；也不受 §十二 的点号冻结／IDNA 冻结／
  预留 `--` 限制约束（§十二 已声明 `perturb2/perturb_half` 是**另一套历史生成器**）。

**（b）复合核（D／F／UQ 臂）** ——【沿用原文：`official_p2p3.py` L226–227；UQ 日志 §一】
`base = perturb2(orig)`，再 `adv_cache[i] = [perturb2(base, rng) for _ in range(4)]`。
**【本文推论】层-3**：每支候选与 `orig` 的编辑位数 = 「首 2 位」与「次 2 位」在**位置上的并集大小**，
取值 ∈ `{2,3,4}`（两次抽样若命中同一位置则并集变小），再叠 `len(body)<4` 的零层退化
⇒ **复合核的支持是层混合 `{0,2,3,4}`（近似），且各层权重由位置碰撞概率决定**，
**不是「恰好 4 位」**。⇒ 草案 §7 表「训练核实际编辑位数是否恒 = 名义值」的答案是：
**否**（名义 4，实际集中在 3–4，且短域名退化为 0）。**逐条可零训练复算**（对源年成员跑
`perturb2` 的样本重复率统计）。

**（c）评价算子 `shared_prefix_edit_v2`** ——【沿用原文：合同裁决 §十二】
支持集是**单点** `{x^{(q)}} ⊂ S_H(x; q)`，`q = min(b_t, n)`；
`b_1 = 1`、`b_2 = 2`、`b_h = max(1, ⌊n/2⌋)`；`n = 0` 时生成失败。

### 1.3 层视角下的统一陈述

**【本文推论】层-4（统一）**：两条算子都是**「层上的测度」**：

| 算子 | 层支持 | 层上分布 | 备注 |
| --- | --- | --- | --- |
| 训练核 `perturb2` | `{0, 2}` | 条件于 `q=2` 时 **= `Unif(S_H(body;2))`**；`q=0` 为短域名原子 | 均匀采样 |
| 复合核 | `{0,2,3,4}` | 层权由位置碰撞决定；层内近均匀 | 层混合 |
| 评价算子 v2 | `{q}`（逐实体 `q = min(b,n)`） | **点质量 `δ_{x^{(q)}}`** | 确定性流 |

**⇒ 训练与评价在同一「层族」上，差别不在支持空间而在层分布（uniform vs point mass）。**
这正是主代理指出的统一底座。**代价（必须并列披露）**：评价算子是**点质量**，
它只考察层的**一个点**；训练核均匀考察整层。**两者的层内覆盖不对等**（见 §6）。

## §2 问题一：层上的基数——「`N'` 指数小」这个卖点在层上还成立吗？

**答：不成立，而且必须换一个完全不同的说法。** 逐层看：

**【本文推论】层-5**：
1. `N'(x;q) ∩ S_H(x;q) = {x^{(q)}}` ——**恰好一个点**（链在第 `q` 层只取一点）。
2. 而 `|S_H(x;q)| = C(n,q)·36^q` ——**指数级**。
⇒ **「受限集很小」这个事实在层上不但成立，而且更极端（1 vs 指数）**，
**但它的意义变了**：在草案里它是「`N'` 相对球小」；在层上它是
**「两条算子对层的覆盖都极小」**——
  - 评价算子覆盖 **1 点**（点质量）；
  - 训练核覆盖**整层**（均匀），但**只覆盖层 `q=2`**，且其**期望损失/距离**是层平均。

**正确的表述（替换草案 §2.3 的卖点）**：
> 层的价值**不是「小」**（`N'` 的小在草案里是拿来对抗标准球的），
> 而是**「距离精确」**：层上每点到 `x` 恰为 `q` 步 ⇒ 距离-预算对应**无条件成立**（§4），
> 且层序 `q` 给出一维、全局、与实体无关的难度坐标（§3 用它换单调性）。

**【本文推论】层-6（层的代价）**：层是**指数大**的，而评价算子是**点质量**。
⇒ 评价只测层上的**一个点**。若真实最坏点在层的别处（§3 的反例正是如此），
则**评价算子的读数系统性地不同于「层上最坏」**。
**这是「受限集」的固有 fidelity 问题，不是实现缺陷**；草案 §8 缺口一（理论对象≠实验对象）
在层语言下被**精确化**为：**同一层上的两个不同层内分布**。

## §3 问题二：难度关于 `q` 的单调性——层上比链上更容易吗？

**答：不一定更容易，实际上更难；但把难度定义在「球」上时，单调性是免费的。**

### 3.1 三个难度量的单调性（逐一定性）

**【本文推论】层-7**：
定义 `D_q(x) := max_{x'∈S_H(x;q)} loss(f(x'), y)`（层极大）、
`B_q(x) := max_{x'∈B_H(x;q)} loss(f(x'), y)`（球极大）、
`Ā_q(x) := E_{x'~Unif(S_H(x;q))} loss(f(x'), y)`（层均值）。则

1. **`B_q` 关于 `q` 单调不减，恒成立。** 证明：`B_H(x;q) ⊆ B_H(x;q+1)` ⇒ 在更大集合上取 max ≥ 更小集合。∎
2. **`D_q` 关于 `q` 不单调**（反例见 3.2）。
3. **`Ā_q` 关于 `q` 不单调**（反例同源）。

**关键**：`B_q = max_{j≤q} D_j`，故 `D_q ≤ B_q`；`B_q` 单调**不蕴含** `D_q` 单调。

### 3.2 反例（层极大不单调）

**【本文推论】层-8（反例）**：取二元字母表 {a,b}，`x = "aaaa"`（`L=4`），
分类器损失取二元错分损失，设 `loss = 1` 恰当前串含**恰好一个** `b`，否则 `0`。则
- `D_1 = 1`（`S_H(x;1)` 全是被误分的「一 b」串）；
- `D_2 = 0`（`S_H(x;2)` 全是「二 b」串，未被误分）。
⇒ `D_2 < D_1`，**层极大不单调**。而 `B_1 = B_2 = 1`（球极大单调，此例中为常数）。∎
（该分类器是合法的二元分类器；该反例同时说明：**层是「等距面」，但「等距」≠「等难」**。）

**与草案 E2 的关系**：草案的 E2（链上难度非单调，依据 §十二「攻击成功不因位置嵌套自动单调」）
**在层上不消失，反而更强**——链只取每层一点，层要取整层的 max，
**在更大的集合上取 max 更容易出现非单调**。

### 3.3 充分条件（层均值单调）

**【待证假设 层-H1（坐标单调损失）】** 若存在**单调细化映射** `R: S_H(x;q) → S_H(x;q+1)`
使 `loss(R(x')) ≥ loss(x')` 对层上所有 `x'` 成立，则 `D_{q+1} ≥ D_q`。

**但该假设很强且一般不成立**（`loss` 关于字符替换无单调性；
`R` 还须是**单射**才能把 max 传上去）。
**【本文推论】** ⇒ **不建议**把难度单调性押在层极大上。

### 3.4 推荐：把难度定义在**球**上，两条算子作为「采样器」测量保真度

**【本文推论】层-9**：定义课程难度坐标为**球极大** `B_q`。则
- 单调性**免费**（层-7.1）；
- 两条算子都是 `B_q` 的**近似采样器**，其**保真度**
  `φ_train(q) := Ā_q / B_q`、`φ_eval(q) := loss(f(x^{(q)}), y) / B_q` 均 ≤ 1，**可测**。

**代价（诚实披露）**：`B_q` 在 `q ≈ 7.7`、`n ≈ 8–22`、`A = 37` 下**不可精确计算**
（球内元素数 `Σ_{j≤q} C(n,j)36^j` 是指数级），只能由攻击近似。
⇒ `B_q` 是**理论理想量**，不是可观测量；`φ` 只能近似测。

**【本文推论】层-10（把 E2 换成可执行的判据）**：
课程前提「难度随 `q` 递增」在**算子层面**的可检验形式是
**`Ā_q` 关于 `q` 非减**（训练核的平均难度）与 **`loss(x^{(q)})` 关于 `q` 非减**
（评价算子的点难度）。二者**都不是定理**，须实测；若普遍非单调，则课程的「难度递增」前提在本任务上
**不自动成立**，须显式验证。

## §4 问题三：距离-预算对应在层上是否更干净？

**答：是，明显更干净——`W_1 = q` 无条件成立（在自然配对上），且给出了可核验的充分条件。**

**【本文推论】层-11**：层上每点到 `x` **恰为 `q` 步**：`∀x' ∈ S_H(x;q), d_H(x,x') = q`。
⇒ 只要采样器支持落在 `S_H(x;q)` 上，逐样本代价**恒为 `q`**：
由草案命题 3.1 的原文恒等式 `W_1 = (1/N)Σ_i d_H(x_i, x_i^adv)`（Shi & Liu 物理页 14979），
**配对耦合**给出 `W_1 ≤ q`，且**与采样器在层内的具体分布无关**。

**【本文推论】层-12（充分条件：配对耦合最优 ⇒ `W_1 = q`，且条件可核验）**：
若源成员**两两汉明距离 ≥ 2q**（`∀i≠j, d_H(x_i,x_j) ≥ 2q`），
则任意**跨样本**配对 `i→j, j≠i` 的代价 `≥ d_H(x_i,x_j) − q ≥ q`，不优于配对 `i→i` 的代价 `q`
⇒ **配对耦合最优** ⇒ `W_1 = (1/N)Σ_i q = q` **精确成立**。

**这是本文最有操作价值的新结论**：它把草案 §8 缺口二（「耦合最优」未证）转成
**一个零训练、CPU 只读、可机械核验的数据条件**（统计源成员的两两汉明距离分布，
特别是 `P(d_H(x_i,x_j) < 2q)` 的比例）。若该比例接近 0，则 `W_1 = q` 成立；
否则只剩上界 `W_1 ≤ q`。

**【本文推论】层-13（两条算子的 `W_1`，逐算子）**：
| 算子 | 层支持 | `W_1`（条件：层-12） |
| --- | --- | --- |
| `perturb2`（长 body） | `q = 2` | **= 2** 精确 |
| 复合核 | `{2,3,4}` | `= E[q_actual] ∈ [2,4]` |
| 评价算子 v2 | `{q}` | `= q̄ := E[min(b, n)]`（D-5 实测均值 7.708） |

**相对草案的净改进**：
1. **草案 E3（预算是实体依赖的、课程非全局旋钮）在层上消失**——层坐标 `q` 是**全局**的，
   `d_H = q` 对所有实体同一；实体依赖只进入**层选择的分布** `q_i = min(b, n_i)`，不再是距离参数。
2. **原文依赖的「`W(P̂^adv_t,P̂)` 关于 `t` 非降」在层上由构造保证**——`W_1 = q` 关于 `q` 严格增
   ⇒ 只要层序列 `q_t` 非降，距离序列非降，**原文式 (16) 的单调性前提被补齐**。
3. **草案 §8 缺口二被一个可核验条件替换**（层-12）。

## §5 问题四：RS-Del 的 LCS 证书在 `S_H` 上的保守界——层上更强还是更弱？

**答：既不更强也不更弱——层、链、标准球三者的 RS-Del 证书下界完全同值。**

**【本文推论】层-14**：设同长替换（`|x̄| = |x| = L`），RS-Del 物理页 7 式 (14)：
`ρ̃(x̄,x,μ_y) = p_del^{|x̄|−|x|}(μ_y − 1 + p_del^{½(dist_LCS(x̄,x)+|x|−|x̄|)}) = μ_y − 1 + p_del^{dist_LCS/2}`；
而 `dist_LCS(x̄,x) = 2(L − |z*|)`，且层上 `|z*| ≥ L − q` ⇒ **`dist_LCS ≤ 2q`**，
`p_del < 1` ⇒ `ρ̃` 关于 `dist_LCS` **递减** ⇒
```
min_{x̄∈S_H(x;q)} ρ̃ = μ_y − 1 + p_del^{q}   （最坏点在 dist_LCS = 2q 处取到）.
```
**同一个值**在标准球 `N_q(x) = B_H(x;q)` 的邻域最小化（RS-Del Theorem 7，
`ρ̃ = μ_y − 1 + p_del^r`，物理页 7）与**链端点 `x^{(q)}`**（草案命题 1.4，`dist_LCS ≤ 2q` 同法）上取得。

**【本文推论】层-15（为什么相同——对路线 B 的负面结论）**：
RS-Del 的下界**只通过 `dist_LCS(x̄,x)` 依赖 `x̄`**；而 `dist_LCS` 在层上**取最大值 `2q`**，
且链端点**已经取到这个最大值**。⇒
**层不提供比链更强的「更坏点」；RS-Del 的证书语言对「受限（层/链）vs 标准球」不敏感。**
⇒ **路线 B（LCS 证书）在本课题上买不到额外的东西**——它既不能认证更宽的半径，
也不能区分我们是否真的在受限集上。

**推论（对裁决的建议）**：层-15 与草案 §5.1 的取舍建议**一致并加强**：
路线 A（Wasserstein/层）作主，路线 B 只在 §2 的**邻域几何刻画**上有用，
**在证书上无用**（因为认证量对层内选择不敏感）。
**前提仍是**：该结论条件于 RS-Del 的 A1–A6，**本课题不采用该平滑路径**（草案 §6.1）。

**注意一处反转风险**【待证假设 层-H2】：若链端点发生**意外交叉匹配**
（`x^{(q)}[π_k] = x[j]`，`j ≠ π_k`），则 `|z*| > L − q`，`dist_LCS < 2q`，该点 `ρ̃` **更大**（更松），
但**层上总存在无交叉匹配的最坏点**，故 **min** 仍为 `μ_y − 1 + p_del^q`。
⇒ 结论对链端点的匹配细节**不敏感**（这正是层-15 的稳健性来源）。

## §6 问题五：训练核与评价算子作为 `S_H` 的子集，排序一致的条件

**答：距离/预算部分**按层-11–13 **天然一致**；**难度/损失部分需要三个条件，且当前第三个不满足**。

设理论预测量 `g(μ)` 依赖扰动分布 `μ`。训练用 `μ_train`（`Unif(S_H(body;2))` 或复合核的层混合），
评价用 `μ_eval = δ_{x^{(q)}}`（点质量）。**排序一致性**＝「按 `g(μ_train)` 排序的方法，
按 `g(μ_eval)` 排序相同」。

**【本文推论】层-16（一致性的充分条件）**：
**(C1) 层充分性**：`g` 只通过层号 `q` 依赖 `μ`——对所有支持在同一层的 `μ` 同值。
  - **距离部分满足**（层-11：`W_1 = q` 与层内分布无关）⇒ **距离/预算排序天然一致**（严格结论）。
  - **难度部分不满足**（`Ā_q ≠ D_q ≠ loss(x^{(q)})`，见 §3）。
**(C2) 难度一致性**：评价的点质量 `δ_{x^{(q)}}` 的难度与层分布 `Unif(S_H(body;q))` 的**层均值**同序
（即共享前缀点不是系统性地更易/更难）。**待证假设 层-H3**。
  **证伪方式**：同一批源成员上，比较 `loss(x^{(q)})` 与 `Ā_q` 的相关性/均值差；
  若点质量**系统性偏离**层均值（例如恒偏易），则 C2 不成立，训练结论**不可**直接迁移到评价。
  **成本**：零训练、CPU 只读。
**(C3) 层可比性**：训练覆盖的层 ⊇ 评价覆盖的层（或理论在被跨越的层区间上可外推）。
  **当前不满足（这是决定性缺口）**：
  - 训练：`{0,2}`（`perturb2`）或 `{0,2,3,4}`（复合）；
  - 评价：`q = min(b, n)`，评测档 `random_half` 的实测均值 **7.708**、max 22（草案 §3.2，D-5 制品）。
  ⇒ **训练在层 2–4，评价在层 ~7.7，两段基本不重叠** ⇒
  「训练结论迁移到评价」是**跨层外推**，需要 §3 的难度单调性（层-7：只有球极大免费，
  层极大与层均值**不保证**）。

**【本文推论】层-17（当前状态下的一致性判定）**：
- **距离/预算层面：一致（严格）**。
- **难度层面：不一致，除非** (i) 层-H3 成立（点质量 ≈ 层均值），且
  (ii) 层-10 的「`Ā_q`/`loss(x^{(q)})` 关于 `q` 非减」成立（或采用球极大定义并以 `φ` 度量保真度）。
- **最强结论只能是**：「**在教学预算层上，两条算子的距离-预算对应一致**；
  难度排序的一致性**取决于层-H3 与层-10，二者均未验证**。」

**【本文推论】层-18（设计含义，供主代理参考；非实验建议）**：
若要让训练结论**可迁移**，最直接的结构性办法是**让训练核覆盖评价所在层**
（即训练预算 `q_train` 与评价 `q_eval` 同段）。这**不是**定理，是一条**可检验的设计假设**：
可由现有臂的层覆盖直接判定。**在 D-7 结果出来前不据此改臂**（草案纪律不变）。

| 4. RS-Del 证书在 `S_H` 上的保守界 | **层 = 链 = 标准球，三者同值 `μ_y − 1 + p_del^q`**；证书语言对受限/标准**不敏感** ⇒ **路线 B 买不到额外东西** | 【本文推论】层-14、层-15 |

## §8 本文**仍然证不出来**的东西（如实列出，不粉饰）

1. **层极大/层均值的难度单调性**：**证不出来**，且本文给出**反例**（层-8）。
   只有球极大的单调性可证（层-7.1）。
2. **`W_1 = q` 的无条件成立**：**证不出来**。层-12 给的是**充分条件**
   （两两汉明 ≥ 2q），它是**数据条件**，须实测；不满足时只剩 `W_1 ≤ q`。
3. **训练→评价的难度排序迁移**：**证不出来**，因 C3（层不重叠）在当前核设计下**失败**
   （训练层 2–4 vs 评价层 ~7.7）。这是**结构性缺口**，不是措辞问题。
4. **层-H3（点质量 ≈ 层均值）**：**未证**，且**有理由怀疑**——
   评价算子的共享前缀流是**确定性**的，而训练核是**均匀随机**的，
   两者在层内的分布形态差异很大；点质量是否系统性偏易/偏难**须实测**。
5. **`B_q` 的精确值**：**不可计算**（指数级球），只能近似；故层-9 的保真度 `φ` 只能近似测。
6. **离散空间的泛化界重证**：草案缺口四**仍然存在**——本文只做**层参数化**，
   **未重证** Shi & Liu 的序贯 Rademacher／discrepancy 界在有限编辑空间上的形式。
