# 第三章 LAMDA 经验回放与安全回归约束研究卡

## 状态与证据边界

- **章级主目标是产出一个完整的第三章算法/框架**：它必须有明确的漂移病灶、训练目标、公式、在线更新流程和真实实验支持。两个机制融合只是增强创新性、因果解释和工作量的一种可选构造，不是必须凑齐的模块数量。

- 当前阶段 A 已完成标准经验回放资格筛查，阶段 B 已完成安全回归候选筛查；两者都不宣称机制有效。
- 数据采用发布的 `4561` 维特征空间。该特征空间使用未来年份训练分片的协变量建立全局词表和方差选择，因此本阶段身份固定为 `screening_only`，不能称为无泄漏正式基线或独立最终测试。
- 机制数量不是硬门槛。第三章需要避免把已知方法改名冒充创新，因此优先寻找作用面不同、能够被任务化改造并由数据支持的机制；若两个机制各自有独立源年信号且联合关系可解释，可用融合方式形成主算法。若只有一个机制有证据，或联合不成立，就围绕该机制构造完整算法/框架，不得为了凑数机械拼接 `2×2`。阶段 B 的安全回归约束只是并行筛查候选，是否保留由实验决定。
- 路线公共边界见 [LAMDA 路线总控](../../.Codex/docs/LAMDA/LAMDA路线总控.md)，当前章节状态见 [LAMDA 第三章恢复卡](../../.Codex/docs/LAMDA/LAMDA第三章恢复卡.md)。

## 章级创新边界

标准固定容量经验回放属于已发表的持续学习基线，阶段 A 只用于确认它在 LAMDA 上是否提供可复现的正锚点，不能作为第三章创新或最终主方法。若阶段 A 证实真实遗忘/退化，再从可观测病灶中选择一个或多个任务化差量：覆盖记忆可处理历史分布保留，安全记忆可处理更新后恶意样本转为良性的回归风险。只有当这些差量在 LAMDA 上各自有独立源年信号、作用面清楚且联合关系可解释时，才采用两个机制融合为统一算法；若只有一个差量有证据，就以该差量为核心构造完整算法/框架，不能用标准回放或空想模块补足数量。公式、约束预算和在线算法均须由真实制品及已核验近邻共同冻结。

## 基线层级与比较合同

LAMDA 原论文的静态监督表比较 `LightGBM`、`MLP`、`SVM` 和 `XGBoost`；其持续学习附录在统一 MLP 上比较 `Naive`、`Joint` 和 `Replay`。两组结果不能直接拼成一个排行榜，且论文表 15 的前向/后向平均 F1 与本研究的逐年风险向量不等价。

本研究最终主表按研究问题分层：

1. **静态参考层**：`LightGBM`、`XGBoost` 和原论文静态 `MLP`，用于说明不更新模型的跨年退化；`SVM` 保留在扩展附录以复现原论文比较集。
2. **持续学习因果层**：冻结源模型（不更新）、`Naive`、`Joint/Cumulative` 和标准 `Replay`。`Joint` 是访问全部历史数据的资源上界，不冒充在线部署方法；`Naive` 是无回放对照；`Replay` 是阶段 A 的成熟机制锚点。
3. **第三章主方法层**：只有 `Replay` 通过阶段 A 资格门后，才把有独立信号的任务化差量升级为主方法候选。每个差量必须与 `Replay` 使用相同网络、年度顺序、标签到达、优化预算和记忆容量；标准 `Replay` 本身不计作创新机制。若加入直接近邻 `Regression-aware Continual Learning` 或主动学习方法，另列标签预算表，不与无额外标签的持续学习结果混比。
4. **必要控制层**：同容量随机回放或类别均衡回放只用于判断水库抽样是否是收益来源；`URLDomainList` 移除属于数据捷径诊断，不是主方法基线。

所有主表基线都在同一 LAMDA 特征版本和逐年合同下重跑。主指标不只用 F1，还包括逐年 AP、AUROC、FPR、FNR、Brier、旧恶意负向翻转率、最坏年份和资源代价。原论文的 `47.59` 等表 7 数字只作为文献参照，不作为本研究基线读数。

## 阶段 A 研究问题

在完全相同的数据顺序、模型、初始化、优化预算和评价合同下，全程总容量为 `200` 的标准单样本水库经验回放，能否相对朴素逐年更新减少晚期年份的遗忘或检测退化，同时不提高假阳性率？

## 冻结实验合同

| 项目 | 冻结值 |
| --- | --- |
| 持续学习协议 | Domain-IL，年份顺序为 `2013, 2014, 2016, 2017, 2018, 2019, 2020, 2021, 2022, 2023, 2024, 2025` |
| 年内划分 | 每年 `train/test = 80/20` |
| 比较臂 | 同一起点的 `Naive` 与 `Replay` 两臂 |
| 输入 | 发布的 `4561` 维未来协变量特征，仅用于 `screening_only` |
| 主干网络 | `D -> 512 -> 384 -> 256 -> 128` |
| Domain 头 | `128 -> 100 -> 100 -> 1` |
| 非线性与正则 | 隐层使用 `ReLU`；Domain 头前两处隐藏层后使用 `dropout=0.2` |
| 输出与损失 | `Sigmoid` 与 `BCELoss` |
| 年度训练预算 | 每年 `10` 轮，`batch_size=1024` |
| 优化器 | `SGD(lr=0.01, momentum=0.9, weight_decay=1e-6)` |
| Replay 缓冲区 | 全程总容量 `200` 的单样本 reservoir |
| Replay 年度训练集 | 当前年份训练样本与当时全部缓冲样本 |
| Replay 更新时间 | 当前年份训练和测试完成后再更新缓冲区 |
| 随机性 | `seed=42`，固定全部随机源 |

两臂必须从相同初始化出发，并共享除回放机制外的全部冻结条件。不得复用论文中混合前向与后向结果的平均 F1，因为该统计量不对应本研究卡的逐年顺序评价合同。

## 评价与持久化

每个年份训练完成后，分别评价三个互不混合的评价面：

1. `current_year`：刚完成训练的当年测试集，用于评价当年适应结果。
2. `next_year`：紧接着的下一年份测试集，用于评价一步前向迁移；最后一年明确记为不适用。
3. `backward`：所有更早年份的测试集，用于评价遗忘与旧恶意负向翻转。

每个评价切片报告 `AP`、`AUROC`、`F1`、`FPR`、`FNR`、`Brier`、旧恶意样本负向翻转率、墙钟时间和峰值显存。旧恶意负向翻转指此前被模型判为恶意、在后续年度训练后转为良性的旧恶意样本比例；实现时须持久化逐样本身份、年度与预测，以便机械复算。

真实断点必须按“实验臂／年份／轮次”保存，包含模型、优化器、随机源、Replay 缓冲区及完成状态，使中断后可从同一身份继续而不重跑已完成轮次。

## 阶段 A/B 结果与阶段 C 候选

- 阶段 A `ch3-lamda-domain-il-naive-replay-screening-seed42-v1` 的本地复算见 `.Codex/docs/2026-09-08-LAMDA回放安全回归/stage-a-qualification-reanalysis.md`：Replay 只在 FPR 与旧恶意负向翻转率上取得筛查信号，AP/FNR 略差。
- 阶段 B `ch3-lamda-security-regression-ablation-seed42-v1` 的本地复算见 `.Codex/docs/2026-09-08-LAMDA回放安全回归/stage-b-analysis/analysis-report.md`：联合臂 pooled FNR 和回溯翻转率略降，但 FPR、AP、AUROC、F1 未全面占优。
- 阶段 B 代码在当前年度训练和评价后用当前模型分数筛选安全记忆，与配置所写的上一冻结模型保护集合不一致；该运行不能作为严格 PCT 复现。
- 阶段 C 候选计划见 `.Codex/docs/2026-09-09-LAMDA决策角色记忆双侧修复/task_plan.md`：`M` 为总容量 200 的决策角色条件记忆，`O` 为双侧风险约束修复更新；按数据清单使用来源年 `2013/2014`、开发年 `2016/2017`，封印年 `2018--2025`。
- 阶段 C 筛查结果见 `.Codex/docs/2026-09-09-LAMDA决策角色记忆双侧修复/analysis/analysis-report.md`：四臂中 `ER` 为开发期锚点，`ER+M`、`ER+O`、`ER+M+O` 均筛查否决；否决的是“固定角色轮转＋等单位风险损失”的具体实现，不是所有后续任务化机制。

## 预注册资格门

资格汇总只拼接 `2020-2025` 六个 `current_year` 测试集的逐样本预测；每个样本在汇总中只出现一次。AP、FPR 和 FNR 均由拼接后的预测重新计数，不对逐年指标再取平均。旧恶意负向翻转率则按 `2020-2025` 六次年度更新中的翻转事件合并计数，同时保留每次更新的分表。

`Replay` 相对 `Naive` 必须同时满足：

1. 汇总 `FPR` 不提高。
2. 在汇总 `AP` 更高、汇总 `FNR` 更低、合并旧恶意负向翻转率更低三项中，至少一项严格改善。

两条同时成立时，标准经验回放获得资格，随后才依据真实病灶设计并筛选任务化创新差量；不要求机械凑成两个机制。任一条不成立时，标准经验回放不获资格，停止把它作为创新前提并如实记录否决结果。不得依据结果事后改变年份范围、指标方向或通过条件。
