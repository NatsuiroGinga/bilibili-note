## §1 算子与邻域的精确形式化

### 1.1 我们的算子（精确定义）

**【沿用原文】** 以下定义逐条对应
[`第三章-正式攻击与目标抽样合同裁决.md`](第三章-正式攻击与目标抽样合同裁决.md) §十二
（该节已于 2026-10-13 冻结）：

- 输入 `x` 为剥离后缀的 exact eSLD（域名注册实体），字符集为 `A = {小写字母, 数字}`（标签首尾）与
  内侧可含连字符；点号位置**冻结**；`xn--` 开头或所属标签第 3、4 位同时为连字符的 IDNA／预留标签
  **整标签冻结**。
- `L = |x|`；`E(x) ⊆ {1,…,L}` 为**可编辑位置集**（非点号、非冻结标签、且存在合法非恒等替换的位），
  `n := |E(x)|`。
- **确定性流**：由「版本化命名空间 + 数据修订 + 原串」派生确定性随机源，对 `E(x)` **无放回洗牌**
  得排列 `π = (π_1,…,π_n)`，并为每位选一个合法替换字符 `c_k ≠ x[π_k]`（不含恒等替换）。
  记该流为 `τ(x) = ((π_1,c_1),…,(π_n,c_n))`。
- **应用前 `q` 项**：`apply(x, q) := x[π_k] ← c_k, k=1..q`，记作 `x^{(q)}`（`x^{(0)} := x`）。
- **共同前缀条件**（原文 §十二）：`q_a ≤ q_b` 时，小档的改动位置与替换字符**逐项等于**大档的前 `q_a` 项
  ⇒ 改动位置集**嵌套**，且各输出与原串的**汉明距离恰等于预算**。
- **实际预算**：`q_t = min(b_t, n)`，三档名义预算 `b_1 = 1`、`b_2 = 2`、`b_h = max(1, ⌊n/2⌋)`；
  `n = 0` 时生成失败并阻断（不把干净原串计作攻击）。

### 1.2 本文的邻域定义

**定义 1（受限编辑邻域 `N'`）。** 对输入 `x` 与预算 `q ∈ {0,1,…,n}`，

```
N'(x; q) := { x^{(0)}, x^{(1)}, …, x^{(q)} } ⊂ X .
```

**【本文推论】** `|N'(x;q)| = q + 1`。推导：`x^{(0)},…,x^{(q)}` 两两不同——
因为 `x^{(j)}` 与 `x^{(k)}`（`j<k`）在位置 `π_{j+1}` 上取值 `x[π_{j+1}]` 与 `c_{j+1}`，而
`c_{j+1} ≠ x[π_{j+1}]`（算子排除恒等替换）⇒ 二者在 `π_{j+1}` 处不同 ⇒ `x^{(j)} ≠ x^{(k)}`。∎

**关键结构事实（本文其余部分的支点）**：`N'(x;q)` 不是「球」，而是一条**链**——一个在置换坐标下
逐位递增的**嵌套序列**。`x^{(j)}` 恰在 `{π_1,…,π_j}` 上偏离 `x`，在其余位置与 `x` 一致。

## §2 问题一：`N'` 与 RS-Del 标准编辑球的关系

### 2.1 三个度量与三个集合

- `d_H(·,·)`：汉明距离（同长字符串上不同位置的个数）。
- `d_L(·,·)`：Levenshtein 编辑距离（允许删、插、替换）。
- `dist_LCS(x̄,x) := |x̄| + |x| − 2|LCS(x̄,x)|`
  ——**【沿用原文】** RS-Del 脚注 2：LCS 距离 ≡ 操作集 `O={del,ins}` 的广义编辑距离
  （RS-Del 物理页 7 脚注 2）。
- `B_H(x,q)`：汉明球（半径 `q`，逐位替换）；`N_q(x)`：**标准 Levenshtein 球**
  ——**【沿用原文】** RS-Del 物理页 6：`N_r(x) = {x̄ ∈ X : dist_O(x̄,x) ≤ r}`。

### 2.2 命题 1.1（包含关系）：`N'(x;q) ⊆ B_H(x,q) ⊆ N_q(x)`

**【本文推论】**
**证明。**
(i) 对任意 `j ≤ q`，`x^{(j)}` 恰在 `j` 个位置偏离 `x`（§1.1 共同前缀条件 + §1.2 两两不同）
⇒ `d_H(x, x^{(j)}) = j ≤ q` ⇒ `x^{(j)} ∈ B_H(x,q)`。
(ii) 汉明距离是最小的编辑距离（逐位替换是合法编辑序列）
⇒ `d_H(x,y) ≤ d_L(x,y)` ⇒ `B_H(x,q) ⊆ N_q(x)`。
合并即得。∎

**这是本文唯一关于「受限集 vs 标准球」的硬结论，方向为「受限 ⊆ 标准」。**
[`第三章-编辑距离证书与课程理论评估.md`](第三章-编辑距离证书与课程理论评估.md) §2.1(a) 陈述
「`N' ⊊ 标准球`」——**本命题给出其完整证明，并把它精确化为
`N' ⊆ B_H ⊆ N_q`（汉明球是中间层）**。

### 2.3 命题 1.2（真包含，且规模指数级更小）

**【本文推论】** 设 `A` 为字母表大小（本课题 `A = 36` 或按含连字符计更多；只要 `A ≥ 3`），则

```
|B_H(x,q)| = Σ_{j=0}^{q} C(n, j)·(A−1)^j ,      |N'(x;q)| = q + 1 .
```

**推导。** 汉明球内元素由「选 `j` 个位置 × 每位置选一个非原字符」给出；链长由命题 1.1 前的计数给出。∎

**量级**：`q ≪ n` 时 `|B_H(x,q)| = Θ(n^q (A−1)^q / q!)`，而 `|N'| = q+1 = O(q)`。
以本课题评价档 `q ≈ 8`、`n ≈ 8–22`（D-5 实测 `q_actual` 均值 7.708、max 22，
见[机制方案](第三章-编辑预算课程调度机制方案.md) §3.2）为例，`N'` 内含 ≤ 23 个串，
而 `B_H` 内含 10 的十几次方量级的串（`A−1 = 35`）。⇒ **`N'` 是球内的一个测度零链。**

### 2.4 命题 1.3（`N'` 不是任何标准球、不是球的平移、不是少量球的并/交）

**【本文推论】**
**(a) 不是半径 `≥1` 的球，也不是球的平移**（平移 `B_H(y,s)` 仍是球，故 (a) 蕴含 (b)）。
**证明。** 设 `q ≥ 1`。任取链上一点 `x^{(j)}`（`0 ≤ j ≤ q`）。
- 若 `n > q`，则存在位置 `ℓ ∉ {π_1,…,π_q}`；把 `x^{(j)}[ℓ]` 换成任意第三字符得 `y`，
  `d_H(x^{(j)}, y) = 1`，但 `y` 在 `{π_1,…,π_q}` 外偏离 `x` ⇒ `y ∉ N'(x;q)`。
- 若 `n = q`，则 `x^{(j)}` 至少有一个非零字符可改为第三字符（`A ≥ 3`），同样得到
  `d_H = 1` 而 `∉ N'(x;q)` 的点。

两种情形下 `B_H(x^{(j)},1) ⊄ N'(x;q)`。若某球 `B_H(z,s) ⊆ N'(x;q)`（`s ≥ 1`），
则其内 `B_H(x^{(j)},1)` 也须 ⊆ `N'`，矛盾 ⇒ `N'` 不含任何半径 `≥ 1` 的球
⇒ `N'` 不等于任何半径 `≥ 1` 的球（球包含自身为中心、半径 1 的球）。∎

**(c) 作为球的并**：一个并集 `⋃_α B_H(z_α, s_α) = N'` 要求每个 `B_H(z_α,s_α) ⊆ N'`；
由 (a) 所有 `s_α = 0`，即**只能写成本身 q+1 个退化单点球的并**（恒真但无信息）。
**任何非退化的并/交描述都需要 `Ω(n)` 个球**，因为链与球的基数差距是指数级（命题 1.2）。

**(d) 作为球的交**：`N'(x;q) = B_H(x,q) ∩ S` 对 `S = N'(x;q) ∪ B_H(x,q)^c` 恒成立（平凡刻画）。
**非平凡刻画**（本文给出，供后续使用）：记 `C_j := { y : y[π_k] = c_k (k ≤ j), y[π_k] = x[π_k] (k > j) }`
为固定 `n` 个坐标的**子立方体**（subcube）。则

```
N'(x; q) = B_H(x, q) ∩ ( ⋃_{j=0}^{q} C_j ) .
```

即**「汉明球 ∩（q+1 个子立方体之并）」**。这是一个**精确**表达式，但它是「球 ∩ 结构集」，
不是「球」；它刻画了链相对于球的**结构赤字**。

### 2.5 命题 1.4（证书继承：标准球证书对受限集保守有效）

**【本文推论】**（条件：RS-Del 假设 A1–A6 成立，见
[评估报告](第三章-编辑距离证书与课程理论评估.md) §1.2；**这是「若采用 RS-Del 平滑」的条件命题，
不是本课题对自身方法的结论**。）

设 `ρ(x,μ_y) := min_{x̄∈N_r(x)} min_{h∈F(x,μ_y)} p_y(x̄;h)`（RS-Del 物理页 6 式 9）。
若在半径 `r = q` 处 `ρ(x,μ_y) ≥ ν_y(η)`（RS-Del Proposition 3），则对受限邻域 `N'(x;q)` 亦有
`min_{x̄∈N'(x;q)} min_h p_y(x̄;h) ≥ ν_y(η)`。

**证明。** 由命题 1.1，`N'(x;q) ⊆ N_q(x)`；**在子集上取 min 不小于在全集上取 min**，故
受限集中的置信度下界 `≥ ρ(x,μ_y) ≥ ν_y(η)`。∎

**配 RS-Del 闭式（纯替换锥）**：**【本文推论】** 链上每点是**纯替换**（`n_ins = n_del = 0`，
`n_sub = j`）。由 RS-Del §4.3 式 (16)（`ρ̄(x;μ_y) = min_{n_sub,n_ins,n_del∈C_r}
p_del^{n_del−n_ins}(μ_y − 1 + p_del^{n_sub+n_ins})`，RS-Del 物理页 7）把 `min` 限制到
`C_r ∩ {(n_sub,0,0)}`，得 `ρ̄ = μ_y − 1 + p_del^{q}`，与 Theorem 7 的 `ρ̃ = μ_y − 1 + p_del^r`
在 `r = q` 处一致。

**另证（走 Theorem 5）**：链上 `|x̄| = |x| = L`，`dist_LCS(x, x^{(q)}) = L + L − 2|z*| ≤ 2q`
（`z*` 至少包含全部未改动位置，故 `|z*| ≥ L − q`）。代入式 (14)：
`ρ̃ ≥ p_del^{0}(μ_y − 1 + p_del^{½·dist_LCS}) ≥ μ_y − 1 + p_del^{q}`（因 `p_del < 1` 且
`dist_LCS ≤ 2q`）。∎

**结论（问题一）**：`N' ⊊ B_H(x,q) ⊆ N_q(x)` **成立且可证**；`N'` **不是**任何标准球、球的平移、
或非平凡意义的球的并/交，而是「汉明球 ∩（q+1 个子立方体之并）」。**标准球证书在半径 `q` 处
对 `N'` 是保守有效的**——但它认证的是 **RS-Del 的平滑分类器**，且需随机删除平滑与相应训练
（A1、A5），**本课题不采用该路径**（见 §6）。

## §3 问题二：距离-预算对应（原命题 P1 的修正）

### 3.0 先纠正一处原文核对结论：`W` 量在**输入空间**，不在特征空间

**【沿用原文】** Shi & Liu, AAAI-24, **物理页 14979（§5.2）** 明确写出其 Wasserstein 距离的
可计算形式：

```
W_1( P̂^adv(h), P̂ ) = (1/n) Σ_{i=1}^{n} || x_i^adv − x_i ||        （原文 §5.2，物理页 14979）
```

其中 `||·||` 是**输入空间**（图像 `ℓ_p`）范数，`x_i^adv` 是 `x_i` 的对抗样本。
原文并说明该式成立是因为 `T_h`（`x ↦ x^adv` 的映射）**就是** `P̂` 与 `P̂^adv(h)` 之间的最优传输。

**这条核对的后果（必须写入）**：
[机制方案](第三章-编辑预算课程调度机制方案.md) §3.2 的 P1 把 `c` 定义为
「单次替换在**特征空间**中的平均位移」。**这与原文不符**——原文的 `W_1` 是**输入空间**平均扰动范数。
⇒ **P1 的陈述必须改写**，否则会把「输入空间距离」与「特征空间距离」混为一谈。

### 3.1 命题 3.1（Hamming 度量下，对应关系是**精确**的而非 `c·q`）

**【本文推论】** 在本课题的**输入空间取汉明度量** `d_H` 时，若**诱导耦合最优**
（即配对 `(x_i, x_i^{adv})` 是最优传输，对应原文 `T_h` 最优的断言），则

```
W_1( P̂^adv_q , P̂ ) = (1/N) Σ_{i=1}^{N} d_H( x_i , x_i^{adv} ) = (1/N) Σ_i q_{actual,i} = q̄ ,
```

其中 `q_{actual,i} = min(b, n_i)`，`q̄ := (1/N) Σ_i q_{actual,i}` 为**平均实际编辑位数**。

**推导。** ① 原文给出 `W_1 = (1/N)Σ||x_i^adv − x_i||`（物理页 14979），把输入空间范数换成
本课题的输入空间度量 `d_H`；② 算子保证 `d_H(x_i, x_i^{(q)}) = q_{actual,i}`（§1.1 共同前缀条件
的「汉明距离恰等于预算」；亦见 §十二 验收项 `Hamming == q_t`）；③ 代入求和。∎

**⇒ 在本课题的输入空间（汉明）里，`c ≡ 1`，不需要任何「平均位移常数」。**
参数不是名义预算 `b`，而是**平均实际编辑位数** `q̄`——这恰好是
[机制方案](第三章-编辑预算课程调度机制方案.md) §3.2 所设想的修正方向
（「P1 须改写为以**期望编辑位数**而非预算为参数」），但**修正的理由是精确推导，不是「弥散」**：
`q_{actual,i}` 的分散来自 `n_i = |E(x_i)|` 的分布，是**确定量的散布**，不是随机未用满预算。

**待核项（可证伪，成本极低）**：`q_{actual}` 的**分布**。D-5 已记录其均值 7.708、min 1、max 22、
p50 7、p90 13（[机制方案](第三章-编辑预算课程调度机制方案.md) §3.2）。若 `n_i` 的分布已知，
`q̄` 可直接由 `E[min(b,n)]` 算出，**不需要新实验**。

### 3.2 命题 3.2（把 `c·q` 搬到特征空间，需要额外假设）

**【待证假设 H-1（特征空间线性）】** 设 `φ: X → R^d` 为模型输入表示（如字符嵌入／one-hot）。
称 **H-1** 成立，若存在常数 `c > 0` 使对几乎所有 `x` 与 `j ≤ q`，

```
|| φ(x^{(j)}) − φ(x^{(j−1)}) || ≈ c   （逐位替换在特征空间中的位移近似恒定）.
```

若 H-1 成立，则 `W_1^{φ}(P̂^adv_q, P̂) = (1/N)Σ_i Σ_{j=1}^{q_i} ||φ(x_i^{(j)}) − φ(x_i^{(j−1)})|| ≈ c·q̄`。

**证伪方式**：在**源年训练/验证成员**上，对固定 `φ`（避免读目标年；用冻结骨干的输入嵌入或
标准 one-hot）测**逐位位移** `δ_{i,j} := ||φ(x^{(j)}) − φ(x^{(j−1)})||` 的经验分布。
判据：若 `δ` 的**变异系数** `CV(δ) = sd(δ)/mean(δ)` 高（例如 `> 0.5`）或 `δ` 与位置/字符类别
强相关，则 **H-1 被证伪**，`c·q` 形式不成立，须改用**路径长度**参数化

```
ℓ(x; q) := Σ_{j=1}^{q} || φ(x^{(j)}) − φ(x^{(j−1)}) ||        （链的累计步长）
```

**成本**：**零训练**、CPU 只读、可复用现有 v2 审计流（`shared_prefix_edit_v2`）；只需前向嵌入一次。
**这条是可证伪的核心，且成本极低——应优先做。**

### 3.3 命题 3.3（原文桥梁本身是近似；我们继承其「近似」地位）

**【沿用原文】** Shi & Liu 从 J（物理页 14978）到式 (16) 用了两步近似：
① 经验观察 `||x − x^adv||_p ≈ δ`（对抗样本落在扰动集**边界**）；
② 由 Tu, Zhang, Tao (2019) Lemma 2 得 `W_p(P̂^adv_δ(h), P̂) ≈ δ_t`。原文用 `≈`，不是等号。

**【本文推论】** 对我们的算子，「落在边界」是**构造性保证**而非经验观察：
算子恰施加 `q` 次替换且排除恒等替换 ⇒ `d_H(x, x^{(q)}) = q` **恒成立**（在汉明度量下）。
因此**步骤 ① 在本课题下比原文更强（精确）**；
**但步骤 ②「W ≈ 该距离」仍需命题 3.1 的「诱导耦合最优」前提**——
原文以 `T_h` 最优断言实现，**本课题未证 `(x_i, x_i^{adv})` 耦合最优**（见 §8 最薄弱环节）。

**⇒ 结论：P1 的**正确形式**是「`W_1 = q̄`（汉明度量，条件：耦合最优）」，
`c·q` 形式只在特征空间且仅在 H-1 成立时成立。**

## §4 问题三：课程控制律的离散形式

### 4.1 形式上的保留（条件性推论）

**【本文推论】** 把 `δ_t ↦ q̄_t`（§3.1，条件：命题 3.1 的耦合最优）代入 Shi & Liu 式 (16)
（**【沿用原文】** 物理页 14978）：

```
J ≈ δ_T + (1/T)Σ_{t=1}^{T-1} ((t+1)k_t + t) δ_t + (1/T) k_0 δ_0
  ↦ J ≈ q̄_T + (1/T)Σ_{t=1}^{T-1} ((t+1)k_t + t) q̄_t + (1/T) k_0 q̄_0  （c ≡ 1，汉明度量）.
```

系数符号 `sign((t+1)k_t + t)` 不变 ⇒ **控制律形式保留**：
`k_t > −t/(t+1)`（系数正）⇒ 减小 `q̄_t`；`k_t < −t/(t+1)`（系数负）⇒ 增大 `q̄_t`。
**但「形式保留」只说明符号结构不变，不说明结论增强。** 原文该式是 `≈`，故本节一切仍是启发式。

### 4.2 离散化引入的四条原框架没有的边界效应

**(E1) 量化与下限饱和（`q_t ∈ Z_{≥1}`，min = 1）。**
原框架 `δ_t ∈ [0, δ_max]` 连续，可 `δ_t → 0`（等价无攻击）。
本课题 `q_t ≥ 1` ⇒ **早期「约束」最多到「1 次替换」，无法更低**（除非允许 `q = 0`＝干净训练）。
⇒ 「减小 `q_t`」这一分支在 `q_t = 1` 处**饱和**；调度只能取 `{1, …, b_max}` 中**极少数几档**
（D-7 实际只用 2 档：`q ≈ 2`（B 核）与 `q ≈ 4`（D/F 核），见
[机制方案](第三章-编辑预算课程调度机制方案.md) §四）。
**「早期约束到什么程度」的答案是：最多约束到 1 次替换，动态范围 = `b_max : 1`。**

**(E2) 难度轴**不保证单调**（结构性，非实现问题）。**
原框架：`δ_1 < δ_2 ⇒ B_{δ_1} ⊂ B_{δ_2} ⇒ max_{x̄∈B} loss` 关于 `δ` **单调不减**
（对抗者的最优损失随球扩大而增大）。
本课题：预算 `q` 控制的是**链上的一个固定点** `x^{(q)}`，**不是球上的 max**。
[合同裁决 §十二](第三章-正式攻击与目标抽样合同裁决.md) 已明写：
「**攻击成功事件不因位置嵌套自动单调**」。
⇒ **`q` 增大不保证攻击更难**（某次替换可能恰好落在分类器的安全侧）。
**这是与原框架最本质的差异**：我们的「难度旋钮」调的是**路径端点**，原文调的是**球半径**。
课程理论的「难度递增」前提在本课题**不是自动成立的**，是**待证假设**。

**【待证假设 H-2（难度单调性）】** 存在单调映射使「编辑预算 `q`」↔「难度」。
**证伪方式**：在源年成员上，对每个 `x` 与 `q = 1..b_h` 计算 `loss(f(x^{(q)}), y)`，
检验 `loss` 关于 `q` 是否单调不减。若大量样本**非单调**（尤其 `loss(q+1) < loss(q)`），则 H-2 被证伪。
**成本**：零训练、CPU 只读（固定骨干前向），可复用现有缓存流。

**(E3) 预算是实体依赖的，课程不是全局旋钮。**
`q_t = min(b_t, n_i)` 逐实体不同（`n_i = |E(x_i)|`；实测 `q_actual` 跨度 1–22）。
原框架的 `δ_t` 对所有样本**同一**；本课题同一 `b_t` 在不同实体上给出**不同实际预算**。
⇒ 部分实体「无课程」（`n_i ≤ b_1 = 1` 时三档退化为同一档），部分实体被**截断**。
**「课程」在实体层面是异质的**，这会使 §4.1 的 `q̄_t` 成为**分布的均值**，
而其**方差**（`Var(q_actual)`）在原文框架里没有对应物。
**【待证假设 H-3（均值充分）】** `q̄_t` 足以参数化 J，`Var(q_actual)` 可忽略。
**证伪方式**：比较用 `q̄_t` 计算的 J 代理量与直接逐样本计算的 J 的距离，若差异随 `Var` 增大，H-3 被证伪。

**(E4) 终端预算与测试预算不可同时对齐。**
原框架要求 `δ_T = δ_test`（物理页 14978：「`δ_T` is fixed to be the perturbation radius
`δ_test` of the test stage」）。本课题**训练核**与**评价算子**是**两套算子**：
训练用 `perturb2`（**随机位置**，名义 2／4 位），评价用 §十二 的**共享前缀确定性流**
（`b_h = max(1,⌊n/2⌋)`，逐实体）。两者**不在同一动作空间**，
故「终端训练预算 = 测试预算」这一条件**在本课题无法按原义满足**。
这既是边界效应，也是 §8 的首要缺口。

### 4.3 命题 4.1（离散控制律的**可检验**形式，非定理）

**【本文推论】** 在 E1–E4 下，离散控制律只能表述为：

> **在 `q_t` 可取的整数档位上，按 `sign((t+1)k_t + t)` 选择「在可行集内减小或增大 `q̄_t`」；
> 可行集为 `{1, …, b_max}` 且 `q̄_t` 受 `E[min(b_t, n)]` 约束。**

它的**唯一可检验内容**是：`k_t` 的经验轨迹是否如原文那样「早期接近 +1、后期降低」；
以及据此产生的调度是否**优于等最终预算的静态调度**（＝D-7 的判据）。

## §5 两条候选路线

### 路线 A：Wasserstein／OT 改造（把 `δ_t` 换成 `q̄_t`）

| 项 | 内容 |
| --- | --- |
| **前提** | 接受 Shi & Liu 的在线视角框架；以**汉明度量**为输入空间度量；命题 3.1 的**诱导耦合最优**成立；`k_t` 可估（或代理量） |
| **做法** | 用 §3.1 的精确恒等式 `W_1 = q̄`（而非 `c·q`）替换原文的 `W ≈ δ`；式 (16) 与 Theorem 4.13 的形式原样保留，只换参数 |
| **可得的结论强度** | **中**。可把 Theorem 4.13 的 `O((1/T)Σ t·Δ_{t-1,t})` 项在离散参数下**并列陈述**；给出「课程调度＝最小化相邻迭代漂移」的任务化解释。**但 Theorem 4.13 本身是原论文对图像 `ℓ_p` 的结果**，我们只做**参数替换**，**不重新证明**——故我们的结论只能是「**原文结论在参数替换下的任务化对应**」，证据等级【本文推论】+ 条件 |
| **与算子定义的兼容性** | **高**。OT 恒等式只需输入空间有度量；汉明度量与算子天然吻合；且「恰好用满预算」由算子构造保证 |
| **主要弱点** | 依赖(i)耦合最优、(ii)`q_t` 单调（原文依赖 `W(P̂^adv,P̂)` 关于 `t` 非降的经验观察，物理页 14978；本课题由 E2 不保证）、(iii)`k_t` 不可直接计算 |

### 路线 B：LCS／链结构改造（用 `N'` 的链与 RS-Del 的计数参数化）

| 项 | 内容 |
| --- | --- |
| **前提** | 需要「可认证」语境（RS-Del 式证书）；采用随机删除平滑（A1）与相应训练（A5） |
| **做法** | ① 用命题 1.1–1.4 刻画 `N'`（链 / 子立方体 / 证书继承）；② 用 RS-Del 的**编辑操作计数参数化**（Corollary 6、式 (16)）把 `min` 限制到**纯替换锥** `C_r ∩ {(n_sub,0,0)}`，得 `ρ̄ = μ_y − 1 + p_del^q`，与 Theorem 7 一致；③ 证书半径由 `r* = ⌊log(1+ν_y−μ_y)/log p_del⌋` 给出，并因 `N'(x;q) ⊆ N_q(x)` 而**对受限集保守成立** |
| **可得的结论强度** | **强（但错位）**。它给出**推理时认证半径**的闭式，是「紧」的；但**认证对象是平滑分类器**，不是我们的训练方法 |
| **与算子定义的兼容性** | **中**。计数参数化与纯替换锥**天然兼容**（我们的算子就是纯替换）；但**平滑算子（删除）与域名语义冲突**——删除字符会破坏「合法域名」，本课题基分类器能否接受删除/截断域名**无证据**（[评估报告](第三章-编辑距离证书与课程理论评估.md) §2.1(b)） |
| **主要弱点** | 证书是**推理时**的，与「训练机制」不同层；需重做邻域最小化并在**受限集**上取 min；引入删除平滑后本课题的输入合法性存疑 |

### 5.1 取舍建议（本文推荐）

**推荐：路线 A 作主（承载 §3–§4 的课程／泛化叙事），路线 B 作辅（只承载 §2 的邻域刻画与
「保守上界」）。** 理由：

1. **层次匹配**：本课题是**训练方法**；路线 A 直接给出训练侧（泛化界、调度）的对应；
   路线 B 给出的是**推理时证书**，与本课题不同层（[评估报告](第三章-编辑距离证书与课程理论评估.md) §2.2）。
2. **算子兼容**：路线 A 的度量可自由选汉明，与 §十二 算子零冲突；路线 B 的删除平滑与
   「必须是合法域名」冲突。
3. **结论诚实性**：路线 A 的结论上限是「原文结果的参数替换」（明确不外推）；
   路线 B 若被误用会诱导「本课题有认证证书」的错误主张——**这正是必须避免的**。

**两条路线的交汇点**（可作为 §2 的收尾）：命题 1.4 显示，
**若**将来本课题要做认证，标准球证书在半径 `q` 处对 `N'` **保守有效**——
这为「受限集与标准球」提供了唯一的桥，但**桥的另一端需要删除平滑，本课题不采用**。

1. **我们不给编辑距离的认证证书。** RS-Del 是**推理时认证**（逐样本 `r*`），且其闭式半径
   （Theorem 7、Table 1）是**标准球**的；把它套到 `N'` 上需重做邻域最小化，且需删除平滑与
   相应训练（A1、A5），本课题**均未做**。

   **但不补删除平滑与训练**，故该禁令仍然有效。）
2. **我们不给 `W_p(P̂^adv_q, P̂) = c·q` 的证明。** 我们给的是**汉明度量下的精确恒等式
   `W_1 = q̄`**（条件：耦合最优）；**特征空间的 `c·q` 是待证假设 H-1**。
3. **我们不给「难度关于预算单调」的保证。** §十二 明写攻击成功不因位置嵌套单调（E2）；H-2 待证。
4. **我们不给「控制律是定理」的结论。** 原文式 (16) 本身是 `≈`（依赖边界经验观察 +

5. **我们不把「早期约束、后期放开」当作被证明的调度。** 原文的控制律是
   「按**经验** `k_t` 轨迹自适应调半径」（物理页 14978），「早小后大」是 `k_t` 轨迹的结果，
   不是被证明的最优调度。本课题 `k_t` 只有代理量。
6. **我们不声称 D-7 训练算子 = 本文理论算子。** 见 §8 缺口一。

## §8 最薄弱环节（如实说，不粉饰）

**缺口一（最严重）：理论对象与实验对象不是同一个算子。**
本文与 §十二 的形式化对象是**共享前缀确定性流** `N'`（评价算子）；
而 D-6／D-7 的调度作用在**训练核 `perturb2`**（**随机位置**，非共享前缀）上。
⇒ §4 的「离散课程控制律」若要与 D-7 挂钩，**必须额外假设训练核与评价算子同构或可互换**，
**这个假设目前既无证明也无实验**。
**这正是 E4 的内容，也是本文最不能自我修复的缺口。** 补法只有两条：
(a) 另做一版**共享前缀的训练生成器**（§十二 已列为「尚未关闭的硬门」），或
(b) 证明 `perturb2` 与共享前缀算子在**分布意义**上等价（当前无证据）。

**缺口二：命题 3.1 依赖「诱导耦合最优」，本文未证。**
原文以 `T_h` 最优断言（物理页 14979）绕过；对本课题，配对 `(x_i, x_i^{adv})` 最优
**既未证也未测**。若耦合非最优，则 `W_1 < q̄`，§3.1 的**等号**退化，只剩 `≤ q̄` 的上界。
**后果**：`c·q`／`q̄` 的对应从「精确」降为「上界」，§4.1 的控制律推导随之从「精确代入」
降为「按上界代入」——**结论方向不变，但强度明显下降**。

**缺口三：`k_t` 不可计算，只能代理。**
原文的 `k_t` 定义为相邻迭代对抗分布的 Wasserstein 距离（物理页 14978）；
本课题无逐迭代分布，只能以「相邻轮次对抗样本表征漂移」代理——
**代理量与原文定义的差距未被度量**，故 §4 的「控制律保留」在实证上**无法直接验证**。

**缺口四：路线 A 的结论上限是「参数替换」。**
Theorem 4.13 是对**图像 `ℓ_p`、FC 网络**的证明（物理页 14978–14979）；
把它数到离散编辑空间需要重证序贯 Rademacher 复杂度与 discrepancy 界，
本文**只做参数替换，不重证**。⇒ 路线 A 给出的**不是本课题的定理**，
最多是「任务化对应」的叙述框架。**在补出离散版重证之前，不能写成「本课题的泛化界」。**

**缺口五：文献面窄。** 本地 Zotero 对「非球状受限邻域的认证」**零相关命中**；
本地混合索引需重建未能查询；在线检索只到**摘要级**（一条指向「Δ-扰动分层约束框架」的候选，
WebFetch 被阻断，**未取得全文，不得引用**）。
⇒ 「是否已有工作处理受限邻域」**本文不主张已穷尽检索**。
