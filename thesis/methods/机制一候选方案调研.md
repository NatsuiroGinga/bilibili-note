## 一、为什么考虑替换机制一

现机制一 ETA（实体内尾部聚合）经独立证伪审计暴露三个问题，**均有实测支撑**：

| 问题 | 实测 |
| --- | --- |
| **对照组已含嵌套结构**：`k ≡ 1` 就是 `β_e = 1/m_e` 的经验 CVaR，与 max 差恒为 `0.00e+00`。故嵌套 CVaR 结构在 C01 上已完整存在，`z1′` 只是移动内层尾部水平 | 探针实测 |
| **交互项无判别力**：C10 是零训练重聚合（`z2=0` 时尾部聚合不进训练图），`z1′` 的训练通道按构造只存在于 `z2=1` 的两格。故 `I = (C11−C01) − (C10−C00)` 中只要训练通道有任何非零效应，`I>0` 就近乎必然成立——**换任何聚合算子结论相同** | 代码结构 ＋ `C10路线裁决.md:43-47` |
| **嵌套仅单侧成立**：`∂L/∂S_p ≤ 0`（正实体侧是 MIL 语义，推高分数），`∂L/∂S_n ≥ 0`；且外层对正实体是 `mean_p` 而非 CVaR | 梯度实测 |

对照参照论文：其两机制的交互项 `+3.80/+3.30` 有判别力，是因为两者**各自都有独立训练效应**。

## 二、结构线索：参照论文的机制一是调度器，不是层

原件核对（`wiki/papers/attack-detection/朱焱雷-全文提取-mineru.md` 行 813–830、901–939、962、982–996）：

- 图 3-1 的「外层循环／内层循环」指**训练控制流层级**，与 Stackelberg 双层优化的
  Outer(Leader)／Inner(Follower) 是**两套不同的层概念，用词碰巧重叠**。
- **DS 不是该双层博弈的任何一层**，而是**调度博弈参数的外部课程机制**：
  只有 `ε(t)` 进入约束集定义式(3.8)，`K(t)`、`α(t)` 是内层求解器的迭代步数与步长。
- RGO 是博弈内部 leader 对 follower 解做隐式微分的梯度技术，跨越 inner/outer 两侧；
  且 `dδ*/dθ` **无解析解，实现为单步截断近似**（式 3.13–3.15），非精确雅可比。
- 二者是**嵌套关系：DS 为 RGO 所在的博弈供参数**。

**推论（设计方向）**：BER 是本课题的「博弈」，机制一应当调度 BER 的运行参数，
而非替换博弈内部的算子。ETA 由此降为**被调度的执行单元**。

## 三、BER 的可调度参数与已实测约束

| 参数 | 现状 | 可调度性 | 硬约束 |
| --- | --- | --- | --- |
| 六档预算 `K` | 全程六档同时优化 | 高 | 由标称比例 `0.1%–8%` 投影到 `N_pop = 121336`；**标称比例本身的出处未登记**（配置只写「既有」） |
| 尾部水平 `α` | 冻结 `0.5` | 中 | ETA 的作用对象 |
| 负实体采样分布 | 均匀 | 高 | `n_neg = 64` 受显存硬约束 |
| `ξ` 学习率 | 定值 `1e-4` | 低 | 工程参数，非机制 |

### 3.1 低三档的真实症结（订正）

**此前流传的「低三档活动率 `0/0/0`、从头到尾没有梯度」出自被否决的水库分位数实现，
不是当前性质。** 当前实现（子梯度 SGD）在 C01 正式运行上的实测：

| `K_eff` | 期望活动数 | epoch 1 | epoch 2 |
| ---: | ---: | ---: | ---: |
| `0.063823` | `0.064` | `0.031250` | `0.070313` |
| `0.319641` | `0.320` | `0.031250` | `0.109375` |
| `0.639810` | `0.640` | `0.039063` | `0.132813` |

**低三档活动率非零，且以绝对数计远超期望**（`K_eff=0.0638` 期望 `0.064` 个，实测 `2` 个）。
收据 `per_budget_subunit` 对低三档标 `True`，即代码显式标记其不足一个采样单位。

**故症结是 `ξ` 收敛不到正确分位数、活动集系统性偏大，不是「选不出样本」。**
这直接改变了两个候选的设计前提，见下。

### 3.2 双损失的梯度失衡与方向冲突

C01 实测（`entity-ranking-diagnostics-{1,2}.json`）：排序与逐流梯度的范数比从 `22` 倍
扩大到 `641` 倍；余弦从 `+0.181525` 翻负为 `−0.197056`；投影控制器在 epoch 2 触发。
现有控制器同时约束幅值与方向（`controlled_rank_step_norm` 恰等于 `grad_norm_flow`）。

**任何新增损失项或可学参数的候选，必须在设计时就规定量级控制方式**，
不能事后补——新项与既有两项的量级差可能立即达到数百倍。

## 四、候选一：预算课程调度

**形式**：不再六档同时优化，而是按训练进度逐档收紧——早期只开宽松档，
随分离度提高逐步引入严格档。对位参照论文调度 `K(t)` 的做法。

**与 BER 的耦合**：调度器决定每轮优化哪些档 → 直接改变外层活动集构成 → 内层输入分布随之变化。

**致命疑问（待验证，优先级最高）**：`K_eff = K·n_neg/N_pop` 是**算术事实，与训练轮次无关**。
第 20 轮引入严格档，`K_eff` 依然是 `0.0638`。**课程调度救不回低三档。**

**但 3.1 的订正改变了这条判断的意义**：低三档的问题本来就不是「无梯度」，而是「阈值不准」。
所以正确的问题变成：**课程能否改善 `ξ` 的收敛精度？** 这需要重新论证，
不能沿用「解决低三档无梯度」的原始动机。

**待验证**：
1. 逐步引入严格档，`ξ` 的收敛精度是否优于全程同时优化？
2. 引入时机如何确定？这是新的魔法数字，能否由不依赖 AP 读数的约束定死？
3. 该候选在四格中是否重蹈 ETA 覆辙（`I>0` 由构造保证）？

## 五、候选二：尾部偏置采样 ＋ 重要性修正

**形式**：机制一 = 负实体采样器，按与当前模型分数相关的分布采样而非均匀。

**推导起点**：`K_eff` 恒定的前提是均匀采样——64 个负实体从 `121336` 均匀抽，
落进真实 top-121 的概率就是 `0.1%`。改变采样分布即改变有效尾部密度，**批量大小不变**，
绕开显存墙（要 `K_eff ≥ 1` 需 `n_neg ≥ 121336/121 = 1003`，是当前的 15.7 倍，不可行）。

**与 BER 的耦合**：采样器直接决定外层 CVaR 活动集的**候选空间**。

**三条生死线（全部待验证）**：

1. **无偏性是否被破坏**：两级复合误差分析的三行无偏引理建立在「固定 `(θ,ξ)` 时对负实体
   **均匀**抽样」之上。有偏采样后该引理失效，需重要性权重修正；
   而**重要性采样在极端尾部常有方差爆炸**，修正后可能比原来更差。
2. **严格过去性是否被违反**：BER 的纪律是本步阈值只来自更早步骤的 `commit`。
   若采样依据当前模型分数，等于让本步信息进入本步选择。能否改用上一步或滑动窗口分数？
3. **是否已被占用**：难负样本挖掘、重要性采样、CVaR 自适应采样在排序与检测中均有大量工作。

**3.1 的订正对本候选是负面的**：原推导默认「批内难以命中尾部」，
而实测显示活动集**本来就偏大**。提高尾部采样密度**可能加剧而非缓解问题**。
本候选的动机因此需要重新论证。

## 六、代价评估（2026-09-02 环境）

**环境变化**：5090 已不可用，当前为**多块 4080 SUPER**。

| 事实 | 值 |
| --- | --- |
| C00 训练（一次服务 C00 与 C10 两格） | `2.64` 小时 |
| C01 训练 | `26` 分钟/轮，20 轮约 `8.7` 小时 |
| C01 当前状态 | epoch 4 停止，断点完好，**不跨卡续训** |
| 四格所需训练次数 | **三次，且互不依赖** |

**多卡并行**：三臂可全并行，总墙钟约 `8.7` 小时（等于最慢的单臂）。
一行代码不用改，`CUDA_VISIBLE_DEVICES` 隔离即可。**两个前提**：
C01 峰值显存实测 `30470 MiB`、4080 SUPER 仅 `32760 MiB`，每卡必须独占一臂；
`X23.npy` 是 `5.43 GB` 的 mmap 随机读，多进程争 IO，实测时长须标 `resource_contention=true`。

**换机制一的代价**：C00／C10 与 C01 不受影响（`z1′=0` 的两格与机制一形式无关），
**只需重跑 C11**，约 `8.7` 小时单卡、多卡并行下不增加总墙钟。

## 七、当前结论

**三个候选都未达到可采纳标准**，各自缺口如下：

| 候选 | 缺口 |
| --- | --- |
| 维持 ETA | 交互项无判别力的问题不因维持而消失；但形式已冻结、实验在跑，切换成本最低 |
| 预算课程调度 | 原始动机（救低三档无梯度）已被 3.1 的订正推翻，需重新论证；引入时机是新魔法数字 |
| 尾部偏置采样 | 原始动机（批内难命中尾部）已被 3.1 的订正削弱；无偏性与严格过去性两条生死线未验 |

**共同的未决问题**：无论选哪个，都要回答「该候选在四格中如何获得判别力」——
ETA 的教训是，若机制的训练通道只存在于某几格，交互项就由设计而非机理决定。

**下一步的最小动作**：先验证 3.1 订正后两个候选各自的新动机是否成立，
再谈形式化。**不得在动机未立时先设计公式**——这正是 ETA 那轮的教训：
用未经验证的优势（共享框架）做候选选择的决定性理由。
