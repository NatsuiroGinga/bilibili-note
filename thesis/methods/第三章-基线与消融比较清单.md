## 一、裁决摘要

### 1.1 一句话决定

第三章的最小完整比较不是“尽量多跑架构”，而是：**在 DRIFT 与 B-ResNet 两个骨干内，先完成非防御 A、正确的朴素随机编辑增广 B、完整候选 F；用 D/G、全局交叉熵 top-`q`、固定良性类权重和源侧重阈值作机制归因；再用恒定 `1:1` 随机离散增广 C′、ESAT 式任务化迁移和 Drichel 离散域对抗训练任务化迁移构成同任务近邻。** Drichel 联合对抗训练只有在嵌入空间与离散空间攻击接口均完成后才进入扩展主比较；原生 32 攻击只作强攻击参照，不能与固定编辑预算主任务混成同一排名。

### 1.3 立即可跑与当前阻塞

**主代理源码核验补充（2026-09-13）**：历史B从原域名直接做一次`perturb2`；D/F先做一次`perturb2`得到共享base，再从base各做一次`perturb2`生成四候选。因此D−B同时涉及候选核、候选数量和选择方式，不能直接命名为“纯组中心化效应”。保留B作为基本防御参照，并增加“同复合候选核、同入批配额的均匀随机选择（Uniform-q）”作为选择归因对照；与CE-top-q一起隔离提议核和排序规则。候选评分的额外计算如实记录，不为假称等计算而让随机基线执行无用前向。

1. **立即准备的顺序仍是每个骨干 A→B→D/G/F。** 该顺序沿用既有批准接口，不因本清单增加近邻而改写；本文件建议的排序和新增对照也不自动变更既有 A/B/D/F/G 语义。
2. **B-ResNet 的 B 当前不能直接跑正式结果。** 现有 `bresnet_p2p3.py` 的模块说明和 `train_arm()` 只定义 A/D/F/G（L2、L250–252），增广分支只在 `arm in ("D", "F")` 时执行（L282）；命令行又不校验臂名（L381–386）。因此若传入 `B`，会落入与 A 相同的无增广路径。既有“B”读数的运行源码身份未闭合，必须先显式实现并断言 B 语义，再以新身份重跑。旧读数不得作正式 B。
3. **DRIFT 侧已有 B 的历史实现，但也不能直接冒充新正式接口。** `official_p2p3_full.py` 明确允许 A/B/D/F/G（L51），各臂加载同一官方检查点（L277–280），B 对批内恶意样本追加一个缓存的 `perturb2` 变体（L321–323）。这证明“朴素随机编辑增广”实现存在；新正式运行保留已冻结训练增强语义，评价改用共享编辑、固定成员和源阈值。不能把评价算子的升级静默反写为训练算子变更。
4. **全局交叉熵 top-`q` 与固定良性类权重目前没有等价既有臂。** 历史 C 是全候选入批，N 是逐组选择，D 是二值组中心化后跨组配额；三者都不是“同候选池、同配额、按未中心化交叉熵全局排序”。G/F 又只给当前误报的真良性样本加权，并非所有真良性的固定类权重。必须新增有意义的展示名，但不改变 D/G/F。
5. **源侧重阈值不需要新训练臂。** 它对已保存的 A/B/D/G/F 等模型分数做源验证集阈值曲线分析；禁止用 T20–T25 标签选阈值。

## 二、骨干与比较对象的角色

### 2.1 骨干不是训练机制基线

| 对象 | 角色 | 初始化合同 | 本章用途 |
| --- | --- | --- | --- |
| **DRIFT** | 主骨干 | 各臂从同一个已冻结官方检查点开始；检查点、分类头状态与可训练参数集合相同 | 检验机制在强时序 DGA 表示上的主效果 |
| **B-ResNet** | 第二骨干 | 各臂使用同一确定性随机初始化；架构、词表、输入预处理与参数预算相同 | 检验职责方向是否依赖 DRIFT 预训练与双分支结构 |

“F 在 DRIFT 上更好”与“DRIFT 架构强于 B-ResNet”是两个不同命题。两骨干的 A/B/D/G/F 链用于检验机制迁移性；不能把一次骨干替换计作一种训练机制基线，也不能用 B-ResNet 未全面更好的结果删掉第二骨干反例。

### 2.2 非防御参照与同任务防御必须分开

- **A 是非防御干净微调参照。** 它给出干净判别上限附近的位置与攻击下的脆弱性，不承担“最强防御基线”角色。
- **B 是基本同任务防御基线。** 它必须真实加入与本任务相同来源的随机编辑恶意变体；若只走 A 的代码路径，不能记为 B。
- **C′、ESAT 式迁移和 Drichel 式迁移是近邻比较。** 它们与 F 的差量必须落在训练策略，而不是数据、攻击强度、初始化或阈值上。
- **D/G 是 F 的组件消融，不是为了增加“外部方法数量”。** D 只开恶意侧组相对选择，G 只开良性误报条件加权，F 同时开启两者。

朱焱雷表 3-5（印刷 p.39）给出一个合规的论证结构：ET-BERT 移动端 Standard 的干净准确率为 `96.50%`、PGD-20 为 `0.05%`，DS-RGO 分别为 `94.50%` 与 `74.90%`。这说明**非防御 A 的干净指标更高，可以与其攻击崩溃和防御收益同时如实报告；不能把任一干净指标不及 A 自动设成科学否决。** 但朱文同时用五种防御方法比较增量；本课题也必须相对 B 与强近邻证明增量，不能只靠 A 在攻击下失败立论。当前没有预定干净代价容差，故只报原值、差值、区间和适用范围，不发明“可接受下降”。

## 四、公平性与计算预算合同

### 4.1 每个骨干内不可变项

1. **初始化**：DRIFT 各臂从同一官方检查点与同一分类头状态开始；B-ResNet 各臂从同一确定性随机初始化开始。ESAT 的选择器是额外制品，不得改变待评主模型的初始权重。
2. **数据角色**：静态权重训练、训练期攻击生成和源阈值冻结只使用已冻结源侧角色；T20–T25 不参与静态训练、早停或源阈值。按上位合同，它们可用于已披露的目标知情候选、配置与基线比较；据此作出的选择须保留所见结果及新运行身份，不再宣称独立最终测试，不能用目标结果修改固定成员或把失败基线删出已报告比较集。
3. **成员与编辑**：同一源成员、同一目标固定哈希成员、同一合法字符编辑规则、同一共享评价流。方法原生威胁若不同，另开“原生参照层”，不改主任务成员。
4. **阈值**：每臂只用共同源良性成员冻结既有主、辅工作点；不得新增“未来每年 FPR 必须低于某值”的自动淘汰门，也不得把旧筛选容差转移到正式结果。
5. **训练资源**：同层主比较先匹配源成员、优化器和训练更新上限。既有 A/B/D/F/G 的方法内候选数、实际入批对抗数与损失质量不由本文件改写，但必须作为“有效训练暴露”逐臂报告；当结论要把差异归于选择分数时，D 与 CE-top-q 必须严格匹配候选池和配额。模型固有的候选评分、选择器预训练、白盒攻击生成等额外计算允许存在，但必须同时报告训练时间、峰值显存、攻击生成数、前向/反向次数和总更新。用户允许增加成本不等于可以用更大预算而不提供公平参照。
6. **预算双视图**：主表给“共同更新／共同攻击暴露”结果；若某原方法依赖额外计算，再给其原生预算结果及等计算 B。不得把原生更大预算的提升全部归因于机制，也不得为了强行同墙钟删掉方法定义所需步骤。
7. **结果身份**：迁移实现都必须登记原论文保留项、替换项、代码来源、许可证和运行身份；只能称“任务化迁移”，除非模型、数据、威胁、训练和实现均按原论文复现。

### 4.2 预登记比较问题

| 比较 | 唯一主要问题 | 合规结论边界 |
| --- | --- | --- |
| F−A | 防御相对非防御的主任务收益及干净代价 | A 干净更高不自动否决 F；须并列报攻击收益与干净代价 |
| F−B | 完整机制相对基本同任务防御的增量 | 这是最低限度增量证据；B 必须真实实现 |
| D−B | 候选生成与组相对选择这一机制包相对基本随机增广的增量 | 候选核和候选数量也不同，不能单独归因于组中心化；不解释良性侧组件 |
| D−Uniform-q | 同复合候选核、同训练配额下，状态依赖选择相对随机选择的增量 | 保持提议核不变并单列评分成本，不能把B单次二位核代入 |
| F−D、G−A | 良性误报条件加权的职责 | 若检出回退，如实限定为误报保护，不写“无代价” |
| F−D−G+A | 所测指标上的组件交互 | 只有区间和方向支持时才能写“所测点正交互”；不能从边际错误率声称机制已证互补 |
| D−CE-top-q | 组中心化是否超过普通全局难例挖掘 | 若无增量，组中心化独立贡献不成立；不得用其他指标转移主张 |
| F−(D+ConstBenign) | 条件误报门是否超过固定类代价 | 若无增量，只能收缩为静态类重加权可解释 |
| F 与 D 的 Source-Rethreshold 曲线 | 完整错误—检出关系能否由固定模型阈值移动复现 | 若可复现，不能写训练学得了独立表示；解释不能擦掉主任务核心失败 |
| F−ESAT式迁移 | 动态候选组选择相对训练前固定原样本子集选择 | 迁移接口不同于原图像 PGD 时须限定 |
| F−Drichel式离散 AT | 组相对固定配额相对已发表 DGA 离散 AT 的增量 | 只在共同固定编辑预算层比较；原生 32 攻击另报 |
| 联合−离散、联合−嵌入 | 两攻击空间组合效果 | 两个单臂与联合臂齐全才允许讨论；边际改善不自动证明互补机制 |

当前**未设定**主任务最小改善值、干净代价容差、计算代价容差、跨骨干非劣界和近邻胜出阈值。正式报告应给绝对值、成对差值、评价区间、反向年份和适用范围；不得在看到结果后补写“可接受”阈值。

最小执行顺序：

1. **P0 身份修复**：只补 B-ResNet 明确 B 分支与臂名校验；在两骨干统一训练入口中机械断言初始化、数据、编辑、候选池、配额和阈值来源。
2. **P0 基线先行**：每骨干先 A/B；合法完成后再 D/G/F。A/B 若在主面板已无可辨剩余错误，只能收缩“仍有显著提升空间”的主张，不能削弱 B。
3. **P0 归因**：用同批候选实现 CE-top-q；加入 D+ConstBenign；对已保存分数执行 Source-Rethreshold。三者完成前，不写“组中心化优于普通难例”“条件门优于类权重”或“不是阈值移动”。
4. **P1 外部效度**：冻结 C′ 分子分母后运行；再完成 ESAT 离散攻击接口与 Drichel 白盒离散攻击接口。两种任务化迁移均须先有小规模真实数据入口检查，再进入正式预算。
5. **P1 扩展**：只有联合 AT 的嵌入/离散接口都合法后，成套运行嵌入、离散、联合三臂；否则在限制中明示未比较。
6. **P2 压力与连续性**：不延迟 P0/P1 的前提下，按需要追加 Drichel 原生强攻击和 M-ResNet+B-cos 同协议 A；不重跑 DRIFT 表 VI 全部架构。

## 七、主代理需裁决的未关闭项

1. **C′ 的精确定义**：Drichel 图示 `1:1` 已有依据，但本课题“干净半批”是否只含真良性、原始恶意是否另保留尚未冻结；定义不清前不可运行。
2. **ESAT 选择预算**：须从既有训练暴露预算派生固定子集大小，还是另给原生预算；当前没有获批新数值，本文件不代填。
3. **Drichel 任务化攻击集**：哪些真实白盒离散攻击能在固定编辑预算和两骨干上合法实现；随机编辑流不能代替这一裁决。
4. **DRIFT 嵌入攻击位置**：字符分支、子词分支或双分支的攻击/回映合同未定义；未关闭前不能运行或命名“联合 AT”。
5. **等计算参照**：ESAT 选择器和白盒攻击生成带来额外成本；须决定以共同更新/暴露为唯一主层，还是再追加等墙钟 B。无论选择哪种，都必须同时报告真实成本。
6. **M-ResNet+B-cos 是否追加同协议 A**：本文件建议默认只引用 DRIFT 表 VI 历史锚点；只有论文准备作“同协议超过原文最强外部架构”主张时才运行。
