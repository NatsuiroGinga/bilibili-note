## 一、要解决的问题（全部为实测）

### 1.1 `【实测】`朴素组合是负收益

源年 LSPR23 验证集实体 AP，第 `8`–`10` 轮均值，`screening_only`：

| 格 | 主读数 | 对 C00 |
| --- | ---: | ---: |
| C00（仅共同底座） | `0.691031` | — |
| C10（＋ETA） | `0.796184` | `+15.22%` |
| **C01（＋BER）** | **`0.918431`** | **`+32.91%`** |
| C11（两条通路都开） | `0.888374` | `+28.56%` |

同口径核对排除读数 artifact：统一 `max` 为 `0.751672 < 0.918431`，
统一 `tail` 为 `0.888374 < 0.940104`。**两条口径一致指向 C11 低于 C01。**

### 1.2 `【实测】`干扰源：ETA 与 BER 的阈值控制器争同一份稀疏性

- C11 第 `8` 轮 `c_scaling_median = 0`。按 `c = min(1, ‖g_f‖/‖g_r^+‖)`，
  `‖g_r^+‖ = 0` 时 `c = 0`——**超过一半的步里 BER 对参数更新贡献为零**
  （同轮 C01 为 `0.00492`）。
- 六档活动率 C11 逐档只有 C01 的约 `62%`；空活动集占比第 `8` 轮 C11 `0.559`、C01 `0.395`。
- 低三档 `K_eff = [0.0638, 0.3196, 0.6398] < 1`，`n_neg = 64` 的批**在数学上无法表示**
  （判定出自 `.Codex/docs/RWKV/2026-09-01-BER水库分位数修法裁决.md` §四，非本文档新提）。
- `ξ` 子梯度更新强不对称：空活动集每步降 `8.33e-6`，一个活动对上跳 `1.22e-4`
  （`14.7` 倍），全活动 `1002` 倍——bang-bang。

**结论：干扰不发生在「ETA 与 BER 之间」，而发生在「ETA 与 BER 的阈值控制器之间」。**

### 1.3 `【实测】`被浪费的计算量

C01 逐轮空活动集占比：
`0.000 / 0.003 / 0.056 / 0.133 / 0.176 / 0.230 / 0.347 / 0.395 / 0.354 / 0.272`，
**全程均值 `0.1966`**，第 `8` 轮峰值 `0.395`。这些步的排序阶段照常前向、反传，
**输出可证明为零**。

## 二、机制定义

**核心思想：让两个机制在时间上不相交。**

```
第 t 步：
  g_t ← （第 t−1 步的排序阶段活动集是否为空）
  若 g_t 为真：   共同底座的实体聚合取 ETA 的尾部均值（α = 0.5 冻结）
  否则：          共同底座的实体聚合取 maximum
  排序阶段的 S_e 恒取 maximum，不受 g_t 影响
```

**两条硬约定**：

1. **排序期通路永久关闭。** `S_e^{(rank)}` 恒为 `maximum`，与 C01 逐字相同。
   ETA 只经共同底座作用。
2. **门控用上一步状态。** 底座在阶段一计算、排序在阶段二计算，
   决定聚合口径时本步活动集尚不可知；空活动集有强自相关（成串出现），
   一步滞后是可接受的近似。**该滞后是实现约束，须在正文如实说明。**

## 三、下界论证及其边界

**逐步论证**：

- **BER 活动的步**（`g_t` 假）：底座取 `maximum`，**与 C01 该步逐字相同**；
  ETA 在这些步上完全不参与，故**不可能扰动 BER 的 `ξ` 动力学**。
- **BER 空转的步**（`g_t` 真）：BER 该步贡献为零（`c = 0`，§1.2 实测），
  底座改用尾部聚合是**在零之上添加**，不减少任何既有信号。

**边界（必须一并陈述，不得省略）**：

该论证是**逐步成立**的。模型参数在两条轨迹上会分叉，故
**「不低于 C01」是结构性论证，不是数学保证**。正文不得写成「可证明不劣于」。

## 四、与三个已证伪假设的区别

| 已证伪假设 | 证伪方式 | 本方案为何不同 |
| --- | --- | --- |
| 对 ETA 输出作标量尺度校正 | `ξ` 取分位数，**对单调缩放不变**；三种缩放下最高档活动率同为 `0.0859` | 本方案不改分数尺度 |
| 提高 `xi_learning_rate` | 模拟：`1e-4` 空步率 `0.043` → `1e-3` 升至 `0.391` | 本方案不动 `ξ` 的任何超参 |
| 裁掉 `K_eff < 1` 的低三档 | 模拟：后三档空步率反升至 `0.112` | 本方案不动预算档，六档合同保持冻结 |

**三者共同的失败模式是「让两机制同时作用再设法调和」。本方案取消同时性本身。**

**另需声明**：上述模拟复现不了真实基线（模拟末段上限 `0.112`，实测 C01 第 8 轮 `0.395`），
**故那三条证伪本身也只有有限效力**；本方案不依赖它们成立，只依赖 §1 的实测。

## 五、实现范围

**要改**：`ch3_ft_c00_dual_selection.py` 中——

1. 新增一个跨步状态变量，记录上一步排序阶段的活动集是否为空
   （排序阶段已有 `empty_active_step_frac` 的统计入口，取同一判定）。
2. 共同底座的聚合口径由该状态选择，而非由配置常量固定。

**不得改**：`ch3_ft_entity_ranking_loss.py` 的任何算术、六档预算、
`xi_learning_rate`、梯度控制器、评价口径、数据合同。

**新增配置键**：`mechanism.entity_bce.aggregation_gate`，取值
`always_max`（退化为 C01）／`always_tail`（退化为当前的 tailbase 臂）／
`gated_by_prev_empty_active`（本方案）。**默认 `always_max`，不改变任何既有运行。**

## 七、风险

1. `【假设】`一步滞后可能使门控在活动集状态快速切换时失准。缓解：判据 2 直接监测触发率。
2. `【假设】`底座聚合口径在训练中切换，可能引入自身的不稳定。
   缓解：判据 3 监测控制器、判据 1 监测最终指标。
3. **本方案不解决 §1.2 的根因**（`K_eff < 1` 的阈值控制器缺陷），
   只是绕开它。根因的处置有赖于
   [极端分位数 CVaR 估计文献核查](第三章-极端分位数CVaR估计文献核查.md)（进行中）。
   **正文不得把本方案表述为对该缺陷的修复。**

## 八、与第四章的关系

第四章候选 EAS 的动机是把空活动集步**跳过**以省算力；本方案把同一批步**用起来**。
两者对同一实测事实（空步占 `19.66%`）给出相反处置，**不可同时采用**。
若本方案成立，第四章需另择机制；该冲突须在两章定稿前裁决。
