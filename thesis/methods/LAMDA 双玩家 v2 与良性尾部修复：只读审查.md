## 一、结论

**当前最值得检验的，不是继续增加乘子压力，而是“相同良性训练预算下，保护样本的选择是否与实际损伤位置匹配”。** 但现有探针只能把“作用面错位”提升为有针对性的假设，尚不能证明它是主因，更不能把“双玩家单臂修复候选为零”作为该假设的证据。

建议先完成零训练诊断，再考虑**两个匹配的新训练臂：缺口修复＋当前年随机良性推回，对比缺口修复＋当前年高分良性推回**。两臂只改变良性样本选择，其余损失、样本数、训练预算与信息集合相同。第一轮不要同时重新引入乘子、投影、动态课程或新输出头，否则无法判断改善来自哪里。

需要先修正四个解释：

| 待审查解释                         | 本次审查                                      |
| ----------------------------- | ----------------------------------------- |
| 损伤扩散到了 ER 原本判对的良性             | **本地摘要支持。** 同年跨模型配对和良性分位数位移共同支持这一描述。      |
| 损伤发生在“当年训练分区”的高分良性，因此历史保护集合选错 | **尚未证明。** 补充探针来自开发年评价分数，不是训练参考集合的覆盖分析。    |

| 尾锚仍失败，就能证明同一输出头不可分            | **不能。** 还需排除选样覆盖不足、损失尺度、更新方向、有限步长及代理失配。   |

## 二、探针支持什么，以及尚不能支持什么

### 2.1 “漏判没有埋在良性低分区”成立，但不等于“容易与危险良性分开”

【本地转述：L5，发现一、二】漏判恶意相对**全部良性**的 hard-pair AUC 为 0.903／0.830，且多数漏判分数高于良性中位数。这支持“漏判恶意仍保留部分排序信号”。

但这里的负例包含大量容易区分的低分良性。真正妨碍低 FPR 修复的是**良性上尾**，因此：

$$
\operatorname{AUC}(\text{漏判恶意},\text{全部良性})
$$

不能代替

$$
\operatorname{AUC}(\text{漏判恶意},\text{良性上尾})。
$$

**应补的是尾部条件排序诊断，而不是据总体 hard-pair AUC 宣称可分。** Partial AUC 文献正是把目标限制到指定 FPR 区域，而非用整体 AUC 代替低误报区表现。【文献：Narasimhan–Agarwal，ICML 2013，§2，PDF 第 2–3 页。】

“阈值路径无解”也应收窄：现有数字证明了**修回一半或全部漏判的所述阈值方案会增加大量误报**，并未枚举证明任何微小修复都必须增加误报。合同固定阈值为 0.5，不应把这一点转化为调阈值方案；它只影响对病灶的表述。

### 2.2 必须分开两种“新增误报”

【本地转述：L2 配对翻转表；L5 发现三】

已有两个不同的配对对象：

| 指标               | 配对对象                       |
| ---------------- | -------------------------- |
| 缺口臂“良性新增误报 3257” | **缺口臂自己的上一冻结模型 → 本年度缺口模型** |
| 补充探针中的 2009／1748 | **本年度 ER → 本年度缺口模型**       |

它们不应相等，也不能混用。

另外，`2009/2282` 与 `1748/1823` 的分母按所附数字是**缺口模型全部 FP**，不是“相对 ER 新增的 FP”。更准确的名称是：

> **候选模型全部误报中，由 ER 原本正确良性转入的比例。**

如果分母本来就定义为“ER 正确、候选错误”的新增 FP，那么其中“ER 原本正确”的比例必然为 100%，指标将成为定义上的重复。

令同年、同一良性评价集合上：

$$
n_+=\#\{y=0,h_{\mathrm{ER}}=0,h_A=1\},
$$

$$
n_-=\#\{y=0,h_{\mathrm{ER}}=1,h_A=0\}.
$$

则有精确的计数恒等式：

$$
FP_A-FP_{\mathrm{ER}}=n_+-n_-。
$$

按所给数字，缺口臂的跨 ER 新增伤害是 \(2009+1748=3757\)，而总 FP 增加是 \(4105-377=3728\)，因而对应的 ER 旧误报修正数为 29。**这是对所给摘要的代数展开，不是对原始预测的复算。**

这一分解比“88%／96%”更适合后续机制分析：它同时显示**制造了多少新错误、修掉了多少原错误、净误报是否增加**。

### 2.3 “波及”成立，但“不是代价交换”不宜作为严格结论

【推论，依据 L2、L5】“波及”是合理的描述性用语：缺口训练使大量 ER 原本判对的良性越过阈值。但它仍然可能是共享参数更新造成的安全—修复取舍，不能据此排除“代价交换”。

更重要的是，缺口臂不仅 FPR 上升，**AP 与 AUROC 也明显下降**。严格单调的全局分数变换不会改变样本排序，因此这些结果不支持“只有统一阈值偏移或全局 logit 平移”的解释。至少还可能存在排序扰动、表征更新不均匀、修复权重过度集中等因素。

同时，pooled 改善掩盖了年度异质性：所附数据中，2017 缺口臂 FN 为 451，ER 为 238。不能将 pooled FNR 改善解释成每个开发年都受益。【本地转述：L2 pooled 表、L5 发现三。】

### 2.4 “当前训练尾部没有被保护”仍缺少直接证据

补充探针尚未回答三个问题：

1. 当前**已获准使用的训练良性**是否出现同样的高分尾部？
2. 历史良性参考在该尾部是否确实覆盖不足？
3. 后来被推错的良性，在更新开始时是否已经处于冻结模型的高分尾部？

第三点尤其关键。如果大量受损样本起初分数很低，随后因表征更新跨越多个分位区间，**冻结 Top-K 也可能捕获不到它们**。

此外，L1 写的是“历史训练良性参考”，补充解释强调的是“上一模型判对良性”。这两种集合不相同，不能未经本地核对就统一成同一个保护对象。

## 三、双玩家单臂：先诊断集合、计数和梯度通路，再讨论更新频率

### 3.1 修复候选为零的最小成因链

【外部候选诊断】年度开始时，用冻结模型 \(z_t^-\) 和当前已揭示的训练标签，定义原始修复资格集合：

$$
R_t^0=
\{x\in D_t^{\mathrm{train,available}}:
y=1,\ z_t^-(x)<0\}。
$$

其中恶意 logit 的阈值为 0，对应概率阈值 0.5。

至少应区分以下计数：

| 计数        | 含义                | 为零可能表示什么            |               |                  |
| --------- | ----------------- | ------------------- | ------------- | ---------------- |
| 原始资格数 (   | R_t^0             | )                   | 冻结模型漏判的当前真实恶意 | 资格集合确实为空，或集合构造错误 |
| 激活数       | 仍满足当前 margin 触发条件 | 当前模型已越过修复目标，或触发条件过严 |               |                  |
| 正权重数      | 修复权重实际大于零         | 权重公式、截断或归一化问题       |               |                  |
| 实际使用数     | 修复项进入训练损失的样本      | 分支关闭、采样未命中或损失未接入    |               |                  |
| 末 epoch 数 | 最后一次统计的状态         | 不能代表整个年度始终为零        |               |                  |

**纯双玩家臂没有开启额外缺口修复时，“实际修复使用数＝0”完全可能符合四臂设计。** 此时应记录为“修复项关闭”，而不是解释成“安全机制没有介入”。

事实上，所附双玩家单臂已有 **2680 个实际恶意正向翻转**。在该臂内部：

$$
3222-2680+267=809，
$$

即：

$$
FN_{\mathrm{new}}
=
FN_{\mathrm{old}}
-\text{正向修复数}
+\text{旧正确恶意负向翻转数}。
$$

因此，零候选不能解释成“没有发生恶意修复”；普通 ER 损失本身也会修复错误。【本地转述：L3，`dual_player.transitions` 与 `pooled.FN`；其余为计数恒等式。】

**最低成本的本地核对顺序**是：先确认日志字段是否受 `enable_repair` 控制，再核对资格谓词是否使用冻结模型、训练标签及正确阈值，最后检查候选损失是否进入计算图。无需先重跑整轮 GPU。

需要排除的具体错误包括：将“旧漏判恶意”和“旧正确恶意保护”取交集；把概率阈值 0.5 用到 logit 上；用当前模型替代冻结模型定义原始资格；仅在回放集合中找当前修复样本；以及将未到达的标签当作当前可用标签。以上都是待排除原因，不是对当前实现的事实指控。

### 3.2 每年三至四次更新：值得审查，但次数少不等于机制失效

【本地转述：L1 每年 10 轮；L2 `dual_updates_total=3/4`】首先必须解释“更新次数”究竟统计：

* 调度器应调用次数；
* 实际执行次数；
* 残差为正的次数；
* 还是乘子数值发生变化的次数。

若每个 epoch 都评估一次，只在三次评估中出现正残差，不能称为“只执行三次”。反之，若确实训练十轮但只执行三次更新，则需要解释未执行的原因及最后一次更新之后是否还有模型训练步。

**乘子峰值小也不代表作用小。** 更直接的诊断量是模型实际收到的安全梯度，例如：

$$
q_B=
\frac{\|\lambda_B\nabla_\theta\widetilde c_B\|}
{\|\nabla_\theta L_{\mathrm{base}}
+\rho\nabla_\theta L_{\mathrm{repair}}\|+\varepsilon}。
$$

应检查它是否有限、非零，以及在约束违反期间是否持续存在。仅看 \(\lambda_B=0.082\) 无法判断这些问题。

【外部候选修订】只有确认“约束违反时实际漏掉了应有的 epoch 更新”，才值得进行**修复调度后的单变量对照**。不建议同时把更新频率提高、学习率放大、参考集替换和代理函数改写。若更新确实发生、安全梯度确实生效，而损伤主要落在参考外，继续增加频率并不能回答覆盖问题。

### 3.3 v2 有成熟框架依据，但不能直接继承 Cotter 的保证

Cotter 的原始 proxy-Lagrangian 明确区分模型侧可微代理与约束侧原始速率。JMLR 2019 **§4.2、Eq. (15)、第 21 页**还规定了包含目标权重的概率单纯形；ALT 2019 的算法采用相应 regret 更新，理论结果涉及随机化解。它不等同于“无上限非负乘子＋hard 残差加法上升＋最后一个模型”。

因此，本地实现宜称为：

> **受 proxy-Lagrangian 启发、训练代理与 hard 反馈分离的原始—对偶实现。**

不能仅因完成这种分工，就称为原论文算法的等价实现或获得其可行性保证。TFCO 官方 README 也明确区分 additive Lagrangian optimizer 与 proxy-Lagrangian optimizer。

### 3.4 三项比“继续加大乘子”更优先的代理核对

**第一，文档中的良性代理不一致。** 计划出现 `mean(sigmoid(logit))`，笔记又称 v2 改为 `softplus(logit)`；实际执行的是哪一种，本次无法从白名单报告确定。【本地转述：L1“数值依据”、证据笔记“v1 失败与 v2 修订”。】

**第二，代理下降不能替代 hard FPR 下降。** 对恶意 logit \(z\)：

$$
\frac{\operatorname{softplus}(z)}{\log 2}
\geq \mathbf 1[z\geq0]。
$$

但“候选平均代理不超过旧模型平均代理”仍不推出“候选 hard FPR 不超过旧模型 hard FPR”，因为两端的代理松弛量可能不同。`mean(sigmoid(z))` 本身也不是 hard FPR 上界。这是数学关系，不是 LAMDA 效果保证。

**第三，核对条件集合与基准的分母。** 如果旧恶意保护集合确实只含“冻结模型判对的恶意”，其年度开始时 hard 回归率应为零。不能直接把另一报告的总体负向翻转锚点填进这个条件集合的约束。

另一个值得优先排除的风险是方向错误：在“较大 \(z\) 表示恶意”的约定下，良性项 \(+\lambda_B\operatorname{softplus}(z)\) 对单个 \(z\) 的下降方向是向下。v1“良性乘子很大但全恶意”的现象，除了数值发散，也应触发对标签、损失符号和梯度通路的检查；目前不能据结果认定具体是哪一种原因。

## 四、区分作用面错位与不可分性的零训练诊断

以下均为**外部候选诊断设计**，本次未执行。只使用合同允许的来源年／开发年信息；训练机制诊断不得把评价标签送入训练分支。

| 成本顺序        | 诊断                                                   | 可证伪的问题                     | 不能据此推出什么           |
| ----------- | ---------------------------------------------------- | -------------------------- | ------------------ |
| 1：既有分数与计数   | 将跨 ER 的 \(n_+,n_-\) 按冻结良性分数区间分解，并分别列年度结果             | 损伤是否集中于冻结高分尾部，还是大量来自原低分区？  | 不能证明训练参考缺失或特征不可分   |
| 2：训练集合的冻结前向 | 对历史训练参考、当前可用训练良性，在同一冻结评分尺度下比较尾部占比、阈值距离与分位区间覆盖        | 历史参考是否低估当前良性尾部风险？          | 不证明换成当前样本后训练必然成功   |
| 3：尾部条件排序    | 在预先固定的训练尾部切片上，计算漏判恶意对尾部良性的 pairwise AUC，并与全良性 AUC 对照 | “总体排序不错”是否只是容易良性贡献？        | 一维分数重叠不代表完整特征不可分   |
| 4：固定特征分析    | 查当前允许训练特征中的异标签完全碰撞；再做预先固定度量下的近邻类别混合诊断                | 是否存在该特征视图无法区分的样本，以及尾部局部混杂？ | 近邻混杂不是 Bayes 不可分证明 |
| 5：前向／反向但不更新 | 分组测量修复、当前尾部、历史参考的梯度方向与范数；检查局部 logit 敏感性              | 安全梯度是否接入？冲突发生在哪些层和样本群？     | 单个负余弦不代表不存在共同改善方向  |

**“零训练”不等于“零计算”。** 前三类多依赖已允许的分数或冻结前向；第五类需要反向计算，但不需要完整训练。不能把它们混称成纯预测统计。

对分布比较，首先报告效应量和区间覆盖，不建议只用一个显著性检验的 \(p\) 值作机制判决。开发样本量较大时，微小差异也可能显著；而同一条年度训练轨迹产生的多个分数并不是多个独立训练重复。

## 五、尾锚推回：先把它作为困难良性重加权基线

### 5.1 必须先确定保护的是哪一种良性

“当前年 Top-K 良性”至少有两种定义：

$$
T_{\mathrm{all}}
=
\operatorname{TopK}_{x\in D_t^{\mathrm{train}},\,y=0}
z_t^-(x),
$$

$$
T_{\mathrm{keep}}
=
\operatorname{TopK}_{x\in D_t^{\mathrm{train}},\,y=0,\,z_t^-(x)<0}
z_t^-(x)。
$$

前者优先处理最高分良性，可能包含大量旧模型已经误报的样本；后者针对**旧模型尚判对、但接近恶意边界的良性**。

【外部候选】针对本次“原本正确良性被推过阈值”的具体病灶，优先考虑 \(T_{\mathrm{keep}}\)，并把同一资格集合中的均匀抽样作为对照。**这属于对“全部良性 Top-K”方案的明确细化，不能把两种集合混写。** 已被旧模型误报的良性仍由基础监督损失训练，不应通过蒸馏把其错误输出固定下来。

选样必须使用年度开始时的冻结模型及当时可用训练标签，而不是用“本年度训练完的 ER 在开发集上的错误”选择训练锚点。

### 5.2 第一种推回形式：普通良性 BCE

为先检验选样机制，最简单的附加项是：

$$
L_{\mathrm{tail}}
=
\frac1{|T|}
\sum_{b\in T}\operatorname{softplus}(z_\theta(b)),
$$

$$
L=
L_{\mathrm{ER}}
+\rho L_{\mathrm{repair}}
+\beta L_{\mathrm{tail}}。
$$

这是**定向困难负例重加权**，不是新的双玩家博弈。按损失选取困难样本已有 OHEM 先例；在同为良性标签时，高恶意分数与高良性 BCE 损失的排序一致。OHEM 原论文为 CVPR 2016，**§4.1、PDF 第 4 页**；它原本面向目标检测，不能把该论文结果迁写为 LAMDA 结果。

此外，“对旧正确样本增加 CE 权重”已经是 PCT 原文 **§4.1、Eq. (6)** 的 Naive baseline。因而：

> **“旧正确良性筛选＋额外 BCE”本身不能作为充分的新颖性主张。**

可检验的任务化差量是当前到达标签、良性上尾定位、非对称修复目标及固定 FPR 下的配对损伤控制，而不是 BCE、旧模型筛选或重加权本身。【文献：PCT，arXiv:2011.09161v3，§4.1，PDF 第 4 页。】

### 5.3 K 与强度：没有可直接搬来的 LAMDA 最优值

【外部候选起始形式】

**K 先由预算确定，不由开发集最佳结果确定。** 优先令 \(K_0\) 等于现有安全分支已登记的良性参考样本预算，取 \(K=\min(K_0,|B_t^{\mathrm{eligible}}|)\)。若现有实现没有这样的预算，需由本地先登记一个固定值；这里不凭文献图像实验臆造“K＝某数”或“K＝200”。

总回放容量 200 仍然有效。当前训练分区的索引选择不应被包装成额外历史回放空间；跨年保留任何锚样本都必须计入既有容量。

**强度只给一个透明起点，不做组合搜索。** 保持修复项定义及其权重不变，将附加良性损失按所选样本均值归一化；若没有可复用的已登记系数，可将 \(\beta=1\) 作为单一、未验证的起始配置。它不是文献推荐的 LAMDA 最优值。均值归一化也不等于梯度范数已经平衡，仍须通过零训练梯度诊断排除严重尺度错误。

### 5.4 若要“锚定”而不只是推回，采用单侧形式更贴近保护目标

在 \(T_{\mathrm{keep}}\) 上可定义：

$$
L_{\mathrm{anchor}}
=
\frac1{|T_{\mathrm{keep}}|}
\sum_{b\in T_{\mathrm{keep}}}
[z_\theta(b)-\operatorname{stopgrad}(z_t^-(b))]_+。
$$

这是**外部候选定义，不是 PCT 原公式**：只惩罚良性恶意分数上升，允许它下降。它与 FD-LM 的双向 logit matching 不同；后者还会惩罚离开旧输出的有益变化。PCT 的 FD-LM 是 **Logit Matching**，不是“Large Margin”。【文献：PCT v3，§4.2、Eq. (9)，PDF 第 4 页。】

但有限权重的单侧损失仍不是 hard FPR 保证，且在尚无上移时可以没有惩罚梯度。建议把它放在**选样假设获得支持之后**，作为单个后续对照，而不是第一轮就同时增加推回、锚定、乘子和投影四种机制。

纯排序目标也不宜直接替代推回：它约束恶意与良性的相对次序，却不限制两者一起越过 0.5。Kumar 等的 **§5.2、PDF 第 7 页**已经列出对 Top-\(\beta\) 负例的 pairwise loss 基线，因此“漏判恶意对良性尾部排序”也必须与该成熟近邻明确区分。

## 七、尾锚失败后，何时才有理由改变问题表述

### 7.1 单个尾锚臂失败，不足以证明同头不可分

【推论】至少需要排除：

* 锚点根本没有包含后来受损的良性；
* 只保护了训练锚点，未泛化到同分布的其他良性；
* 锚定梯度未接入或被修复梯度尺度淹没；
* 初始局部方向可行，但实际步长、后续表征变化使其失效。

尤其是，**负梯度余弦不等于没有共同改善方向**。设两个非零梯度归一化后为 \(u,v\)，且 \(u^\top v>-1\)，则方向

$$
d=-(u+v)
$$

满足

$$
u^\top d=v^\top d=-(1+u^\top v)<0。
$$

因此，两目标冲突但未完全反向时，仍可存在同时下降的局部方向。多约束情形需要更完整的局部可行性检查，而不能用一张梯度夹角图宣布不可分。

### 7.2 三种更窄、可证伪的替代表述

| 外部候选表述                     | 来源年需要出现的证据                               | 合适的下一步                                 | 不能声称               |
| -------------------------- | ---------------------------------------- | -------------------------------------- | ------------------ |
| **当前良性尾部覆盖不足导致修复外溢**       | 同预算尾部选择比随机良性更能降低配对新增伤害                   | 继续研究风险定位／采样覆盖                          | “提出全新采样范式”         |
| **低 FPR 区域的局部排序不足，而非单纯遗忘** | 全良性 AUC 较好，但尾部 pairwise AUC 或低 FPR 区域排序差 | 与 partial-AUC／困难负例排序直接对照，同时保留固定阈值 gate | “排序目标自动保证 FPR”     |
| **当前冻结表征下，修复与保护缺少足够可行方向**  | 覆盖、梯度通路与尺度已排除；固定表征的局部头部可行性仍受限，或出现异标签特征碰撞 | 再考虑头部／表征解耦                             | “同一输出头在全局数学上不可能成功” |

Partial-AUC 和当前高分负例排序已有直接先例；A-GEM、MIR、GSS则分别处理局部梯度保护、干扰检索与记忆梯度多样性，不能互相替代成 FPR 保证。

**课程学习、强化学习与 MIR／GSS建议暂缓。** 这不是对方法本身的否决，而是实验排序建议：当前尚未说明独立于修复缺口的难度顺序，也未定义需要强化学习才能解决的状态—动作—奖励问题。加入它们会增加自由度，却不能优先回答“为什么当前良性被推错”。

## 八、下一步最小实验矩阵与硬门槛

### 8.1 不建议立即做正式 GPU 有效性确认

【外部候选建议】现有材料足以提出局部机制问题，但不足以建议大规模、跨种子或正式泛化确认。更节省实验成本的顺序是：

**先核对集合与计数 → 检查训练尾部覆盖 → 检查冻结梯度通路 → 至多增加两个匹配训练臂。**

这不是替本地作停止裁决；是否执行仍由本地按冻结合同决定。

### 8.2 两个新臂即可检验“尾部定位是否有独立贡献”

| 臂            | 作用                      | 唯一新增因素       |
| ------------ | ----------------------- | ------------ |
| ER           | 固定主对照                   | 无            |
| ER＋原缺口修复     | 既有机制对照                  | 原有修复项        |
| **外部候选 R＋U** | 缺口修复＋当前可用、旧正确良性中的均匀样本推回 | 增加固定预算良性 BCE |
| **外部候选 R＋T** | 与 R＋U 完全相同，但选冻结高分 Top-K | **只改变样本选择**  |

R＋U 与 R＋T 必须使用相同的资格集合、K、附加样本曝光次数、\(\beta\)、优化器步数与损失归一化。不加入双玩家、不改变修复权重、不改阈值。

这个比较能够检验**当前良性中的尾部定位**，但不能单独证明“历史参考换成当前参考”就是全部收益来源。若要进一步分离时间来源，还需匹配的历史良性／当前良性对照；不建议在第一批一并扩展。

既有 ER 和缺口结果仅在执行实现、配置和随机流可比时作为匹配对照。若新增选样改变了数据顺序、随机数消耗或训练入口，就不能假定旧读数可直接复用。主训练与额外选样的随机流应隔离，避免“种子都为 42”却改变了基础训练序列。

### 8.3 原硬门保持不变

令 \(A\) 为候选，\(E\) 为**同运行口径 ER**：

$$
\mathrm{FPR}_A\leq \mathrm{FPR}_E,
$$

$$
\mathrm{Flip}^{M}_A\leq\mathrm{Flip}^{M}_E,
$$

$$
\mathrm{FNR}_A<\mathrm{FNR}_E
\quad\text{或}\quad
\mathrm{Repair}^{M}_A>\mathrm{Repair}^{M}_E。
$$

对本次 v2 的同一 pooled 集合，第一条对应 **FP 不超过 377**；若靠 FNR 改善通过第三条，则 FN 必须低于 736。**不能换回上一工具版本的 0.013148／0.059478 锚点。**【本地转述：L2、L3。】

旧恶意翻转集合的分母随各臂冻结旧模型而变，不能把 ER 的 180 次翻转直接改造成所有臂共同的绝对上限。为机制归因，可以补充使用共同冻结前驱的匹配诊断，但不能暗中替换原合同指标。

### 8.4 新增 FP 溯源比例如何使用才不重复

建议新增**诊断报表**而不是擅自新增门槛：

$$
H_B=\frac{n_+}{N_B},
\qquad
G_B=\frac{n_-}{N_B},
$$

于是

$$
\Delta\mathrm{FPR}=H_B-G_B。
$$

FPR 门已经控制净伤害；再加一次 \(n_+\leq n_-\) 只是重复。另一方面，

$$
q=\frac{n_+}{FP_A}
$$

可能因为分母变小而上升，不能单独用来判断候选更危险。

**不改合同的使用方式**：原硬门负责资格判断；\(H_B,G_B,q\) 以及尾部分位数负责解释和通过者之间的比较。若本地以后要增加“良性毛损伤上限”，那将是一个真正更强、但不同的规则，应另行预登记，不能在看过本轮结果后追认成旧合同。

P90／P99同样只宜作机制指标。分位数升高但未增加错误，与少数极端样本越阈值，是不同情形；既不能用分位数代替 FPR，也不能因分位数仍有位移就宣布不可分。

### 8.5 机制特异的停止条件建议

| 情况                           | 外部建议                       |
| ---------------------------- | -------------------------- |
| 候选集合、字段含义或实际 epoch 更新次数仍解释不清 | 先完成本地接口核对，不扩大训练            |
| R＋T 与 R＋U 没有可区分的损伤改善         | 暂无证据支持“尾部定位”的独立贡献          |
| R＋T 减少了误报，但仍违反既有硬门           | 不能用“比缺口单臂好”替代“满足 ER 安全要求”  |
| 锚点自身被有效保护，但非锚点尾部继续受损         | 优先解释为覆盖或约束泛化问题，不判同头不可分     |
| 代理改善而 hard FPR 不改善           | 将其记录为代理—目标失配，不以训练损失收敛作通过依据 |
| 唯一改善依赖更大回放、修改阈值或评价标签反馈       | 已超出当前比较条件，不能并入本轮结论         |
