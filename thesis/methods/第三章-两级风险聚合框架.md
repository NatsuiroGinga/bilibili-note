## 一、框架的结构

第三章的两个机制在同一个对象上取风险，但**取的层级不同**：

| 层级 | 对什么取风险 | 水平参数 | 机制 |
| --- | --- | --- | --- |
| 级一（实体内） | 一个实体袋内的逐流分数 | `α` | ETA |
| 级二（实体间） | 跨负实体的成对损失 | `β_K`（六档） | BER |

**级一产出实体分数 `S_e`，级二消费它。** 这是数据流上的相邻两步，
已由代码核实（`ch3_ft_c00_dual_selection.py:2787-2789` 注释：
「训练侧挂载点：`α` 非 `None` 时 `S_e` 改由 `tail_scores` 给出」）。

### 1.1 联合的实质是**相容性**，不是「互为前提」

**不再声称两机制互为前提**——该主张已被两次独立否决（软化不能解锁 `α`；
解锁 `α` 也不需要 BER）。

**本框架的联合主张改为一条可实测的相容性命题**：

> `α` 与 `β_K` 必须相容。固定 `α = 0.5` 与冻结的六档 `β_K` **不相容**，
> 有实测证据；`α` 连续可学后，模型可在区间内找到相容点。

`【实测】`不相容的证据：C11（`α = 0.5`）相对 C01（`α → 0`，即 max）——
六档活动率逐档只有 C01 的约 `62%`，第 `8` 轮 `c_scaling_median = 0`（**过半的步 BER 贡献为零**），
源年实体 AP `0.888374 < 0.918431`。

`【实测】`四格只测了区间的**两个端点**（`α = 0.5` 与 `α → 0`），中间未测。

**⚠️ 明确不作的声称**：不得以「两级都是 CVaR、构成嵌套 CVaR 共享框架」为卖点。
根 `AGENTS.md` 载明 2026-09-01 曾以此为候选选择的决定性理由，
其三个组成部分有两个撑不住，机制冻结后才发现。**结构同源是代价不是卖点。**

## 二、使框架可行的零件：插值式软 top-`k`

`【实测】`现行 `k_e = ⌈α·m_e⌉`（`ch3_ft_entity_ranking_loss.py:245`）用 `torch.ceil`，
其反向导数在 PyTorch 中**定义为恒零**，故 `α.grad = tensor(0.)`（**不是 `None`**，
不报错不告警），Adam 跑 `200` 步位移 `0.000000e+00`。**`α` 在当前实现下学不动。**

**替代算子**：设 `t = clamp(α·m_e, 1, m_e)`，`k = ⌊t⌋`，`f = t − k`，逐流分数降序排列为 `s`，

```
S_e = ( Σ_{i<k} s_i  +  f · s_k ) / t
```

即在相邻顺序统计量之间线性插值。

`【实测】`本机核验三条（`soft_k.py`，合成输入，CPU）：

| 性质 | 结果 |
| --- | --- |
| `α` 的梯度非零 | `α = 0.50/0.30/0.12` 时 `α.grad = −2.010896/−1.533531/−5.424150` |
| 整数点上与硬 top-`k` **逐位相同** | `α·m = 1/3/5/9` 四点全部 `float` 相等 |
| `α·m = 1` 时与 `max` **逐位相同** | `1.540996108244043` 对 `1.540996108244043` |

**第三条决定了兼容性**：`z1 = 0` 臂的硬断言
`assert_tail_aggregation_degenerates_to_max` **不受威胁，且是精确而非渐近**——
这是本算子相对 RU 松弛（只能渐近逼近，偏差在 `α = 0.002` 处仍有 `2.17e-2`）的关键优势。

### 2.1 实现范围（**新增，不替换**）

- **新增**一个算子，`tail_aggregate` 一行不动 ⟹ 既有四格与其逐位断言全部不受影响。
- 新增配置键选择聚合实现，**默认取现行硬 top-`k`**。
- `α` 由常量改为可训练标量**仅在新键开启时生效**。

## 三、预注册判据（写于本框架任何实验之前）

对照 C01：`0.918431`（`max` 口径，第 `8`–`10` 轮均值）；C10：`0.796184`。

| # | 判据 | 支持 | 证伪 |
| --- | --- | --- | --- |
| 1 | 不劣于 BER 单机制 | `≥ 0.918431` | `< 0.900` |
| 2 | **相容点存在**（框架的核心主张） | `> 0.918431` | `≤ 0.918431` |
| 3 | `α` 确实移动 | 末轮 \|`α − 0.5`\| 超过其步长噪声 | 位移 `< 1e-6` |
| 4 | 相容性可观测 | 六档活动率轮均对 `β_K` 的比值较 C11 上升 | 不升或更低 |

**读数口径硬约定**：C01 的 `max` 为 `0.918431`、`tail` 为 `0.940104`，两条恒算；
**判据一律 `max` 对 `max`**，报错口径即凭空造出 `+2.36%`。

**判据 2 的解释**：若 `α` 学到 `→ 0`（即退化为 max ＝ C01），判据 2 不成立，
框架的相容性主张被证伪，但**这是一个诚实且有信息量的结果**：
说明在本数据上 ETA 与 BER 的相容点就在 ETA 关闭处。**不得把它改写成正收益。**

## 四、开工前必须核验（审核负责）

1. `α` 在**生产代码路径**（非本机合成脚本）下梯度非零。
2. 新算子接入后，`z1 = 0` 四格配置的输出与现有运行**逐位一致**。
3. `α` 作为可训练参数时，其与骨干参数共用优化器是否会被梯度控制器 `c` 缩放——
   **若 `α` 的梯度也被 `c` 乘上，则 `c = 0` 的步上 `α` 同样学不动**，
   这是与已证伪方案同型的风险，须单独核实。
4. 插值算子在 `m_e = 1`、`m_e = 0`、`α·m_e` 恰为整数等边界上的数值行为。
