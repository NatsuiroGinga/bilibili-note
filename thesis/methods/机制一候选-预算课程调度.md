## 一、为什么把它捡回来

该候选此前被排到最低优先级，理由是**原动机被推翻**——它本要解决「低三档 `K_eff < 1`
从头到尾没有梯度」，而那组 `0/0/0` 读数出自**被否决的水库分位数实现**；当前子梯度 SGD
的实测是活动率非零且高于期望。

**但结构上它是唯一对的那个。**

| | 参照论文 | 本课题各候选 |
| --- | --- | --- |
| 机制一的位置 | **调度博弈的参数**（`ε(t)`、`K(t)`、`α(t)`），在 RGO 的计算之外 | — |
| ETA | — | **在 BER 的计算图之内**，是它的输入来源 |
| `c` 课程调度 | — | 在梯度合成处调度，结构对但**生死线甲不通过** |
| **预算课程调度** | — | **调度 BER 的预算档 `K`，在 BER 的计算之外** ✓ |

参照论文的 DS 调度 `K(t)`——攻击步数，逐轮下发给 PGD。
本候选调度 `K` 档的引入顺序——逐轮下发给 BER。**这是同构的。**

而 ETA 只是把一个已存在结构的参数从 `β_e = 1/m_e` 移到 `⌈m_e/2⌉/m_e`
（C01 的内层实测已经是经验 CVaR，与 max 差恒为 `0.00e+00`），**不构成调度**。

## 二、新动机（有实测支撑，但未验证因果）

C01 前七轮实测（收据 `entity-ranking-diagnostics-{1..7}.json`）：

| ep | `‖g_r‖` | 余弦 | `c_scaling` | 低三档活动率 |
| ---: | ---: | ---: | ---: | --- |
| 1 | 94.58 | +0.182 | 0.045147 | `0.031 / 0.031 / 0.039` |
| 2 | **825.01** | −0.197 | 0.001591 | `0.070 / 0.109 / 0.133` |
| 3 | 1.40 | −0.501 | 1.000000 | `0 / 0.008 / 0.008` |
| 4 | 209.41 | −0.205 | 0.013743 | `0.023 / 0.031 / 0.039` |
| 5 | **0.115** | +0.513 | 1.000000 | `0 / 0 / 0` |
| 6 | **0.026** | +0.066 | 1.000000 | `0 / 0 / 0` |
| 7 | 36.75 | −0.104 | 0.007805 | `0.008 / 0.016 / 0.023` |

**两个事实**：`‖g_r‖` 在 `0.026` 与 `825` 之间跳动，**跨三万倍**；
且与活动率强相关（活动率全零时 `‖g_r‖` 近乎消失，活动率最高时达 `825`）。

**推论（未验证）**：`ξ` 未收敛到正确分位数，导致活动集在「空」与「过大」之间振荡；
而 RU 变分式中的 `1/β` **只有在活动集占比恰为 `β` 时才相消**，故活动集一偏离，
梯度范数即被放大或压没。

**新动机**：**逐档引入能否让 `ξ` 的收敛更稳？** 早期只开可估的宽松档，
`ξ` 在样本充足处先收敛；待正负分数分离度提高后再引入严格档，
使其 `ξ` 从一个更合理的起点出发，而非全程在样本稀疏处震荡。

**这个动机比原动机更贴合实测**，但**因果尚未验证**——活动率震荡与引入顺序之间
是否有因果关系，须实验裁决。

## 三、形式化（待定，先给骨架）

六档预算 `K ∈ {121, 606, 1213, 2426, 4853, 9706}`（已冻结，不改动其值）。
引入一个逐轮的档位掩码 `M(t) ⊆ {1..6}`，损失变为

```
L_rank(t) = mean_{K ∈ M(t)} R_K
```

`M(t)` 由课程函数给出，**从宽松档（大 `K`）向严格档（小 `K`）逐步扩张**。

**注意方向**：`K` 大 ⇒ `β_K = K/N⁻` 大 ⇒ 活动集大、样本充足 ⇒ `ξ` 易收敛。
故课程应**从大 `K` 开始**，与参照论文 DS 从弱攻击开始同向。

**待定项**：扩张的时机与步长——这是新的魔法数字，见第五节。

## 四、为什么它可能恢复交互项的判别力

ETA 的困境是：`z1′` 的训练通道按构造只在 `z2=1` 存在，故 `I > 0` 必然。

**预算课程调度同样只在 `z2=1` 有意义**（`z2=0` 时没有预算档可调），
**所以它不能自动解决这个问题**。

**但有一处不同**：ETA 在 `z2=0` 时只改评价口径，而课程调度在 `z2=0` 时
**完全无定义**——这使四格的第二行（`z1′=1, z2=0`）需要重新定义或取消。
**这可能反而迫使四格设计被修正**，而那正是
[四格设计的不对称与改法](四格设计的不对称与改法.md)指出的方向。

**此项属推论，未验证。**

## 五、必须验证的四条

1. **动机的因果**：逐档引入是否真能改善 `ξ` 的收敛？
   **判据须在实验前冻结**，见第六节。
2. **课程函数的魔法数字**：何时引入下一档？按轮次、按 `ξ` 收敛判据、还是按分离度？
   能否由不依赖 AP 读数的结构约束定死？**若只能调参，登记质量低于 `α = 0.5`。**
3. **四格如何定义**：`z2=0` 时本机制无定义，第二行怎么办？
4. **是否削弱 BER 本身**：早期只开部分档，等于削弱了训练早期的排序信号，
   可能反而不如全程六档。
