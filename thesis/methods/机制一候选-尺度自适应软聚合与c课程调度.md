| # | 已知缺点 | 证据 | 改造 |

## 二、形式化

### 2.1 内层：尺度自适应软聚合（替换 ATk）

实体 `e` 的袋内逐流 logit 为 `l_{e,1..m_e}`。取

```
μ_e = mean(l_e),  σ_e = std(l_e),  τ_e = c₀ / σ_e

S_e = (σ_e/c₀)·log( (1/m_e)·Σ_t exp( c₀·(l_{e,t} − μ_e)/σ_e ) ) + μ_e
```

**正仿射等变**（待验证）：`σ` 平移不变、正齐次，故 `l ↦ a·l+b` 时 `τ_e ↦ τ_e/a`，
代入得 `S_e ↦ a·S_e + b`。这消除缺点 2。

**光滑**：LSE 关于 `l` 为 `C^∞`，已实测梯度良态（gradcheck 双精度通过、
闭式 `dS/dτ = KL(w‖unif)/τ²` 与 autograd 相对差 `≤ 2.5e-14`、`fullgraph` 零图断裂）。
这消除缺点 1。

### 2.2 外层：BER 不变

多预算 CVaR-pAUC、六档预算、`n_neg = 64`、`ξ` 子梯度 SGD **全部不动**。
`S_e` 的来源对 BER 透明——BER 方案第二节已写明「其数学结构与 `S_e` 的具体聚合算子无关」。

### 2.3 合成：`c` 课程调度（机制一的调度器角色）

两目标梯度 `g_f`（逐流 BCE）与 `g_r`（排序）按 CAGrad 形式合成，
主目标取 `g_0 = g_f`（缺点 4 的改造），偏离半径由 `c(t)` 逐轮给定：

```
d* = argmax_d min_{i∈{f,r}} ⟨g_i, d⟩   s.t.  ‖d − g_f‖ ≤ c(t)·‖g_f‖
```

`c(t)` 是机制一的输出，对位参照论文 DS 逐轮下发 `ε(t)`／`K(t)`／`α(t)`。

**方向必须写准**：调大 `c` 是朝 MGDA 移动，即朝**排序目标被删除**移动
（实测代入本课题数字，MGDA 权重把排序项截断为 `0` 与 `0.031%`）。
故 `c(t)` 的课程方向应是**从大到小或维持小值**，不是从小到大。

## 三、与参照论文的结构对位

| | 参照论文 | 本候选 |
| --- | --- | --- |
| 被调度的博弈 | Stackelberg 内层 PGD | 两目标梯度合成 |
| 调度参数 | `ε(t)`、`K(t)`、`α(t)` | `c(t)` |
| 机制二位置 | RGO 在博弈内算全导数 | BER 在合成前产出 `g_r` |
| 耦合因果链 | 内层解越稳定，外层反应梯度估计越准 | **`c(t)` 直接决定 `g_r` 以多大偏离进入更新；`g_r` 的质量又取决于内层聚合的尺度稳健性** |

**相对 ETA 的改进**：ETA 与 BER 的耦合只是「都用了 CVaR」，且对照组 C01 的内层
已经是经验 CVaR（`k≡1` 即 `β_e = 1/m_e`），机制一只是移动尾部水平。
本候选中，机制一**直接决定机制二的梯度如何进入参数更新**，耦合是操作性的。

## 四、必须验证的六条（按优先级）

1. **光滑性是否真的达成**。LSE 本身光滑，但 `L_pn = softplus(S_n − S_p)` 的复合、
   以及外层 CVaR 的 `[·]_+` 在零点不可微——**这一条可能直接推翻整条链**。
   须先算清 `[·]_+` 的不可微点是否落在 CAGrad 定理要求的范围内。
2. **`g_0 = g_f` 时定理 3.2 能否重推**。CAGrad 的证明依赖 `g_0 = (1/K)Σg_i` 的结构，
   换成任意指定目标后是否仍成立，**须自行推导，不得直接引用**。
3. **正仿射等变性的数值验证**。含 bf16 精度下——本课题训练用 bf16，
   理论等变而低精度不等变等于没有。
4. **`c₀` 与 `c(t)` 的调度函数是新魔法数字**。能否由不依赖 AP 读数的结构约束定死？
   只能调参的话，登记质量低于 `α = 0.5`。
5. **尾部语义是否被稀释**。LSE 的权重弥散到整袋（实测 logit 尺度 3、`τ≤1` 时
   1000/1000 条流权重非零），与「低误报只看尾部」的叙事冲突。
   **标准差自适应是否缓解此项未验证。**
6. **`c = 1` 已是有效运行点**。C01 在此点上源年实体 AP `0.9537273846736761`
   对 C00 `0.7887951742121221`。**动 `c` 是否更好毫无证据。**

## 六、与既有裁决的关系

LSE 曾被降为预注册退路，四条理由是：定值问题在硬门处回归、尺度混淆、
尾部语义稀释、训练互作风险。本候选的处置：

| 原否决理由 | 本候选的应对 |
| --- | --- |
| 定值问题（`τ₀` 须冻结且无结构推导） | **未解决**，`c₀` 同样是待冻结的魔法数字（第四节第 4 条） |
| 尺度混淆 | **已解决**（标准差自适应，待数值验证） |
| 尾部语义稀释 | **未解决**（第四节第 5 条） |
| 训练互作风险 | **未解决**，且 `c(t)` 调度引入新的非平稳源 |

**四条中解决一条。** 但新增了原四条之外的理由——**满足 CAGrad 光滑性前提**，
这是理论性理由而非效果猜测。原退路启用条件限定为「ATk 在 CUDA inductor 集成中
出现无法排除的编译断裂或数值不一致」，**本理由属新增，须另行裁决方可启用**。
