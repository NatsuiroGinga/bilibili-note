### 0.2 当前候选核、缓存与前向状态

令 `P_2(.|x)` 表示一次 `perturb2` 调用诱导的字符编辑核。当前生产候选的支持集合由复合核

```text
P_comp(dx_tilde|x) = integral P_2(dx_tilde|z) P_2(dz|x),
Delta_prod(x) = supp P_comp(.|x)                                  (0.1)
```

给出。标准鲁棒参照可写为 `E_{(x,y)}[sup_{x_tilde in Delta_prod(x)} ell_y(x_tilde)]`；这是 F1/F4 的威胁集合与背景目标，不是新理论。当前实现只在有限随机候选池上按另一二值分数选择，不能宣称精确求解该上确界。

对每个恶意源样本 `x_i`，生产实现先生成共享基础样本，再从该基础样本生成四个候选：

```text
base_i = perturb2(x_i, rng)
x_tilde_{i,j} = perturb2(base_i, rng),  j=1,...,4.                 (0.2)
```

因此候选是**共享基础样本的两阶段复合**。相对原样本的净编辑数会受重叠、重改和回改影响，不能写成“四个候选分别从原串独立做一次二位编辑”。仅条件于原样本时，共享随机 `base_i` 使同组候选相关；条件于已经固定的 `base_i` 后，若另加独立抽样假设，才可讨论第二阶段的独立同分布模型。生产事实本身不提供该独立性证明。

候选按原样本索引缓存，训练期间不是每步重新采样。筛选时模型切换到 `eval` 模式并关闭梯度；筛选结束后切回 `train` 模式计算交叉熵。候选依次写入列表，Python 稳定排序在同分时保留生成顺序。涉及局部值函数的快照至少固定：参数、候选池、`eval` 模式前向状态、随机状态和稳定并列顺序；涉及训练损失时还须另行声明 `train` 模式状态。

实现锚点：`official_p2p3.py` 第 190–196 行（随机流与缓存）、第 408–442 行（F 候选生成与筛选）、第 491–560 行（训练模式交叉熵与良性加权）。

### 0.3 生产分数与留一参照必须区分

固定组大小 `K`。令恶意候选被当前模型误判为良性的状态为

```text
u_{i,j} = 1[p_mal(x_tilde_{i,j}) < 1/2],
M_i = sum_j u_{i,j},
u_bar_i = M_i/K.
```

生产分数是

```text
a_{i,j} = u_{i,j} - u_bar_i.                                    (0.3)
```

留一分数仅作已有工具与附录参照：

```text
A_{i,j} = u_{i,j} - (M_i-u_{i,j})/(K-1)
        = K/(K-1) * (u_{i,j}-u_bar_i).                            (0.4)
```

同一 `K` 下，`A=K/(K-1)a`，二者排序、并列和入选集合相同；但分数数值与选择器值函数不同。当前 `K=4` 时，生产分数的值域是

```text
{-3/4, -1/2, -1/4, 0, 1/4, 1/2, 3/4},                           (0.5)
```

留一分数的值域才是 `{-1,-2/3,-1/3,0,1/3,2/3,1}`。若组大小不同，比例因子随组变化，跨组排序也不能由式 (0.4) 自动推出等价。

## 一、主文性质

### 1A：固定有限池的三层分配律

本节只固定候选池和筛选快照，不要求候选独立。由式 (0.3)：

```text
             { (K-M_i)/K,   u_{i,j}=1,
a_{i,j} =    {
             { -M_i/K,      u_{i,j}=0.                            (1.1)
```

当 `0<M_i<K` 时，成功候选为正、失败候选为负；全成功组和全失败组的全部候选均为零。正分层与负分层内部都按 `M_i` 递增排序。因此全局排序的精确结构为：

```text
混合组成功候选 > 全成功组或全失败组的零分候选 > 混合组失败候选。   (1.2)
```

令 `C_+、C_0、C_-` 为三层容量，实际有效配额为 `q`，且 `1≤q≤nK`。稳定降序取前 `q` 时：

```text
q_+ = min(q,C_+),
q_0 = min(C_0,max(q-C_+,0)),
q_- = max(q-C_+-C_0,0).                                          (1.3)
```

三层总填充数与同分规则无关，具体组份额 `N_i` 依赖稳定生成顺序。当前实现没有 `a>0` 资格门；当正分容量不足时，会继续取零分，再取负分。逐组加常数后再中心化会抵消该常数，但先改变概率或 logit 再阈值化可能改变 `u`，故不能由此宣称对校准或难度变化不敏感。

**状态**：`当前新推导但待外部复核`。它是当前有限池的代数性质，不证明该分配优于直接近邻。

### 合并 2A：良性硬权重的局部等价与更新边界

令真良性样本的恶意概率为 `p_theta(x)`，交叉熵为

```text
ell_0(x;theta) = -log(1-p_theta(x)),
c = log 2,
h_x(theta) = 1[p_theta(x)>=1/2].
```

当前扩展批总数记为 `D=B_0+q`。代码实际计算的良性部分是

```text
W_b(theta) = (1/D) sum_{x in B_b} [1+2h_x(theta)] ell_0(x;theta). (2.1)
```

连续超额交叉熵参照为

```text
H_b(theta) = (1/D) sum_{x in B_b}
              [ell_0(x;theta)+2(ell_0(x;theta)-c)_+].             (2.2)
```

在固定训练前向状态、所有良性样本均离开阈值且掩码不变的邻域内，二者梯度相同：普通良性样本系数为 `1/D`，当前误报的真良性样本系数为 `3/D`。但函数值不同：

```text
W_b(theta)-H_b(theta) = (2c/D) sum_x h_x(theta).                 (2.3)
```

在阈值点，式 (2.2) 的次梯度系数区间为 `[1,3]`；只有选上端 `3` 才与代码的 `>=` 掩码逐点对应，普通 ReLU 的默认零点导数不保证这一点。因此只允许写“阈值外局部梯度相同、数值函数不同”，不能写成全局同一损失，也不能推出 FPR 或 FNR 必然改善。

选择器边界还要固定候选、参数、评估模式前向状态、随机状态和并列顺序。若所有候选的评估模式预测都离开 `1/2`，连续性保证存在邻域使二值状态、生产分数和稳定入选集合不变，选择器值函数局部常值；训练模式下所选候选的交叉熵梯度通常仍非零。只有再假设阈值等值集测度为零，才能把“局部常值”扩写为“几乎处处”。

训练目标在筛选集合固定后为主批样本、入选恶意候选以及式 (2.1) 良性权重的条件交叉熵；实际优化器是分层学习率的 `Adam`。该更新是**停梯度的条件代理更新**，不是二值选择器值函数的梯度，也不存在本包已经证明的二阶攻击响应项。

**状态**：`F6` 为 `任务化组合差量`；`F7、F15、2A、2C` 均为 `已有数学工具`。合并呈现不重复计作原创性质。

### F16：生产排序与交叉熵不等价

取 `K=4,q=1`，两组恶意候选的预测恶意概率分别为

```text
组 1：(0.01,0.01,0.01,0.01)，
组 2：(0.49,0.90,0.90,0.90)。                                   (2.4)
```

组 1 全部被误判为良性，生产分数全为零，单个恶意标签交叉熵为 `-log(0.01)=4.605170...`。组 2 只有首个候选被误判，其生产分数为 `3/4`，交叉熵为 `-log(0.49)=0.713349...`。全局 top-1 因而选择组 2 的首个候选，却排除池内交叉熵更大的组 1 候选。

该反例只证明当前排序量与训练交叉熵可能反序，否定“生产 top-`a` 精确求解池内最大交叉熵”。它不证明真实训练必然出现同一构型，不判断效果优劣，也不能单独推出任何渐近不一致性。

**状态**：`当前新推导但待外部复核`。

### 合并 3A：等组参照与实际组份额恒等式

前提必须同时满足：`n≥1`、`q≥1`；候选提议支持属于合法集合；有关上确界有限；损失非负；`N_i>0` 时 `Lhat_i` 是第 `i` 组入选候选的平均交叉熵，`N_i=0` 时约定 `Lhat_i=0`。空组取零只为记账，不表示该组安全；`q=0` 时本式不定义。

记合法编辑集合上的损失上确界为 `L*_{i,Delta}`，提议分布本质上确界为 `L*_{i,P}`，固定候选池内最大损失为 `Z_i`，并定义

```text
C_i = L*_{i,Delta} - L*_{i,P},
E_i = L*_{i,P} - Z_i,
T_i = Z_i - Lhat_i.                                              (3.1)
```

在支持关系、同一提议核采样、入选均值不超过池内最大值和有限性前提下，三项非负，且有逐组望远镜恒等式

```text
C_i+E_i+T_i = L*_{i,Delta}-Lhat_i.                               (3.2)
```

令等组参照风险与实际入选变体均值为

```text
R*  = (1/n) sum_i L*_{i,Delta},
R_S = sum_i (N_i/q)Lhat_i.
```

则直接加减 `(1/n)sum_i Lhat_i` 得

```text
R*-R_S
= (1/n)sum_i(C_i+E_i+T_i)
  + sum_i(1/n-N_i/q)Lhat_i.                                      (3.3)
```

最后一项是等组权重与实际组份额之差，符号不定。式 (3.3) 是计算口径恒等式，不是总体鲁棒风险上界、泛化界或更一般风险，也不控制各项大小。实际变体损失在扩展批总损失中另乘 `q/(B_0+q)`；主批与良性项不属于该等组变体参照。

**状态**：合并的 `F17、F18、3A` 均为 `已有数学工具`，只呈现一次，不计作原创定理。

## 二、附录候选：强条件推论与诊断工具

### 2.1 1B：固定配额的条件集中

设内部组集合 `I={i:0<p_i<1}` 非空、组数有限固定、参数与 `p_i` 固定，组内样本独立同分布为 `Bernoulli(p_i)`，固定正整数 `Q`，内部最小成功率由唯一组 `i_*` 取得，记为 `p_*`。边界组 `p=0` 或 `p=1` **允许存在**，但不能作为该结论的目的组。

若内部组多于一个，令 `Delta_p` 为 `p_*` 到其余内部成功率的最小间隔；选择

```text
0<epsilon<min(p_*,1-p_*,Delta_p/2),
Q/K <= p_*-epsilon.                                              (A.1)
```

只有一个内部组时删除 `Delta_p/2` 条件。逐组 Hoeffding 界与并集界给出

```text
Pr(N_{i_*}=Q) >= 1-2|I|exp(-2K epsilon^2).                       (A.2)
```

组间独立不是该并集界的必要条件。若没有内部组，全池分数为零，由稳定并列顺序决定；若内部最小成功率并列，也不能保证配额集中到指定单组。当前 `K=4,Q=64` 至少需要 16 个组才有足够容量，单组集中推论不直接适用。

**状态**：`当前新推导但待外部复核`，只宜附录。

### 2.2 3C：充分计数事件及选择偏置反例

取两组损失构造：第一组的 `v=1-s` 均匀分布于 `(0.8,0.9)`，第二组均匀分布于 `(0,0.6)`。第一组全成功且生产分数全零；第二组成功概率为 `1/6`，令 `M_2~Binomial(K,1/6)`。充分计数事件

```text
E={Q<=M_2<=K-1}                                                  (A.3)
```

的概率恰为

```text
Pr(E)=sum_{m=Q}^{K-1} C(K,m)(1/6)^m(5/6)^(K-m).                 (A.4)
```

在 `E` 上，全部 `Q` 个入选候选来自第二组，因此式 (A.4) 在一般固定并列规则下只是相应选择事件概率的下界。只有另行冻结“第一组候选全部先于第二组候选”的稳定顺序且 `Q≤K`，零分并列情形才由第一组优先，此时选择事件与 `E` 相同。适用条件还包括 `Q/K<1/6`；在 `E` 上可得等组参照与入选风险之差至少为 `log 2`。

当前两组、`K=4,Q=64` 时总候选只有 8 个，实际会全部选择，该反例不直接适用。它不构成对当前训练效果的否决。

**状态**：`当前新推导但待外部复核`，只宜附录。

### 2.3 3D：配额极限分配

设组数 `n` 固定有限，各组共享一条无限候选序列并在预算 `K` 时使用其前 `K` 项；参数固定，组内独立同分布，且

```text
0<p_1<...<p_n<1,
Q_K/K -> beta,
0<beta<n.                                                        (A.5)
```

令 `P=sum_i p_i`，并定义

```text
r_i^+(beta)=min{p_i,(beta-sum_{h<i}p_h)_+},
r_i^-(beta)=min{1-p_i,(beta-P-sum_{h<i}(1-p_h))_+}.              (A.6)
```

在上述条件下，大数律使各组最终为混合组且成功计数次序稳定，从而几乎必然有

```text
N_i/K -> r_i^+(beta)+r_i^-(beta),
N_i/Q_K -> [r_i^+(beta)+r_i^-(beta)]/beta.                       (A.7)
```

若成功率并列、含边界组、组数随 `K` 变化、候选不是共享无限序列的前缀，或 `beta` 不在 `(0,n)`，式 (A.7) 不能直接沿用。本结果称为**配额极限分配**，不把它写成当前有限预算发生的经验现象，也不推出性能提升。

**状态**：`当前新推导但待外部复核`，只宜附录。
