## 一、定理 1：预算重分配收益与中心化选择损失的精确分解

### 一.1 数学对象与编号假设（照录，式号沿用原文）

固定检测器参数 `θ`，**只分析这一次候选生成与选择**，不先推断后续训练效果。

- **T1.1 共同候选池**：`n` 个干净恶意样本、每个生成 `K ≥ 2` 个变体，违规量 `u_ik ∈ [0,1]`；以固定阈值 `t` 定义骗过指示 `Z_ik = 1{u_ik > t}`、`S_i = Σ_k Z_ik`、`S = Σ_i S_i`。
- **T1.2 对齐选择预算**：取整数 `r ∈ {1,…,K}`，总预算 **`q = nr`**。四算子共用同一候选池：`U_r`（每组无放回均匀取 `r`）、`P_r`（每组按原始 `u` 取 top-`r`）、`A_q`（**按中心化优势跨组排序**至多取 `q`）、以及必要参照 **`R_q`（按原始 `u` 在全部 `nK` 个候选中取全局 top-`q`）**。
  > **纪律**：`R_q ≠ A_q`——全局大损失选择**已有成熟的 top-k 聚合目标研究**，不能仅凭出现全局排序主张首创。
- **T1.3 中心化规则**：`A_ik = u_ik − (1/(K−1))Σ_{ℓ≠k} u_iℓ = K/(K−1)·(u_ik − ū_i)`。
  > **资格条件**：原文**先采用正优势资格 `A_ik > 0`**；**若本地实现没有该条件，资格集合需相应修改，不能直接套用 1B 的二点分数闭式**——本课题 D 臂**正是无门实现**（见 §一.4 双版本登记）。
- 记 `H = Σ_{i,k} Z_ik·1{A_ik > 0}`（**有资格**的被骗过候选数）；`C_U, C_P, C_R, C_A` 为四算子**实际捕获**的被骗过候选数。两个选择损失：
  `L_elig = min(q,S) − min(q,H)`（**资格剔除损失**），`L_rank = min(q,H) − C_A`（**排序损失**），均非负。
  > 若实现先过滤 `Z=1` 再对正优势候选排序，则 `L_rank = 0`，但 `L_elig` 仍可能非零。

### 一.2 定理 1A：任意候选池上的精确分解（式 1–4）

逐组缺额与溢出：`D = Σ_i (r − S_i)_+`，`E = Σ_i (S_i − r)_+`。则对任意固定候选池：

```
E[C_U | S_1,…,S_n] = (r/K)·S                                         (1)
C_P = q − D,        C_R = C_P + min(D,E)                             (2)
C_A − C_P = min(D,E) − L_elig − L_rank                               (3)

E C_A > E C_P  ⟺  E min(D,E) > E L_elig + E L_rank                  (4)
```

**式(4) 是「中心化跨组配额严格优于逐组选择」的精确充要条件，不是无条件优势声明。**

**解释**：某些组没有足够的被骗过候选、留下**缺额 `D`**；另一些组超出逐组配额、形成**溢出 `E`**；取消逐组配额**最多可利用 `min(D,E)`**。但**中心化不是免费附加项**——它可能剔除有用候选，也可能把尚未骗过的「组内相对异常值」排在已骗过候选之前。

### 一.3 定理 1B：两类型模型下的闭式期望（式 9–14）

**T1.4 两类型独立候选**：`n_h = πn` 个高骗过率组、`n_l = (1−π)n` 个低骗过率组，条件于组类型 `Z_ik ~ ind Bernoulli(p_h / p_l)`，`0 ≤ p_l ≤ p_h ≤ 1`。
**T1.5 二点分数模型**：`u_ik = a + (b−a)Z_ik`，`0 ≤ a < t < b ≤ 1`。

- **有限样本判定式（式 9）**：`E C_U < E C_P < E C_A` 当且仅当 `∃i: 0 < p_i < 1` **且**
  `T_q[H_{p_h}^{n_h} H_{p_l}^{n_l}] > n[πβ_r(p_h) + (1−π)β_r(p_l)]`（`T_q` 为 top-`q` 截断和算子）。
  > 原文提醒：**一般情形不应编造简单的单调 `π` 阈值**——截断与组内零优势会使参数关系更复杂。
- **显式阈值的严格优势区域（`n=2, K=4, r=1, q=2`，一组骗过率 `p`、另一组 `0`）**：

```
E C_A − E C_P = p²(p² − 8p + 6)                                      (10)

0 < p < 4 − √10   ⟹   E C_U < E C_P < E C_A                          (11)
4 − √10 ≈ 0.83772
```

  **边界处中心化与逐组选择期望相等；超过边界后中心化反而更差。**
- **可直接复核的解析值（原文声明「不是本次运行得到的实验数值」）**：

| 高率组 `p` | Uniform | Per-group top-1 | 中心化配额 `A` | 原始全局配额 `R` |
| ---: | ---: | ---: | ---: | ---: |
| `0.5` | `0.5` | `0.9375` | **`1.5`** | `1.625` |
| `0.9` | `0.9` | `0.9999` | **`0.6840`** | `1.9962` |

  第一行＝**严格优势实例**，第二行＝**明确失败实例**；优势对概率参数连续，故不只存在于边界点。

- **大组数界与混合比例阈值（式 12）**：记 `a(p) = K(p − p^K)`、`μ_A = πa(p_h) + (1−π)a(p_l)`，则
  `|E C_A / n − min(r, μ_A)| ≤ (K−1)/(2√n)`；在原文给定参数下给出 **混合比例阈值 `π < 13/29`**。

## 二、定理 2：加权 Gram 条件下的双风险共同下降（条件性机制解释）

### 二.1 数学对象（式 15–17）

分数特征梯度 `φ(x) = ∇_θ s_{θ₀}(x)`；`Φ_m = [φ(x_i)]_{i∈M}`、`Φ_b = [φ(x_j)]_{j∈B}`；系数 `a_i = w_i / s_{θ₀}(x_i)`、`b'_j = v_j / (1 − s_{θ₀}(x_j))`。则

```
g_m = −Φ_m a,      g_b = Φ_b b'                                     (15)–(16)
Gram 块：G_mm = Φ_mᵀΦ_m,  G_bb = Φ_bᵀΦ_b,  G_mb = Φ_mᵀΦ_b            (17)
```

> **本课题对应**：`w_i` 即**组件 1**（组相对过滤入选样本的权重），`v_j` 即**组件 2**（良性误报加权，`ψ_b` 形式）。

### 二.2 定理 2 陈述（式 18–21）

记 `m = ‖g_m‖`、`b = ‖g_b‖`、`c = g_mᵀg_b`。**联合方向 `d = g_m + λg_b` 是两个风险的严格一阶共同下降方向，当且仅当**

```
m² + λc > 0,    c + λb² > 0                                          (18)
```

- `c ≥ 0` 时，任意 `λ > 0` 均满足；
- `c < 0` 时等价于 **`−c/b² < λ < m²/(−c)`**（式 19），**该区间非空当且仅当 `c > −mb`**。
- 若式(18) 成立且步长满足 **`0 < η < (2/‖d‖²)·min{(m²+λc)/L_m, (c+λb²)/L_b}`**（式 20），则
  **`R_m(θ⁺) < R_m(θ₀)` 且 `R_b(θ⁺) < R_b(θ₀)`**（式 21）。

### 二.3 从代理风险到 FPR/FNR（式 26–27，强得多）

在分数仿射近似下，`Δs_m = η(G_mm a − λG_mb b')`、`Δs_b = η(G_bm a − λG_bb b')`（式 26）。**若满足逐元素条件**

```
G_mm a ≥ λ G_mb b',      G_bm a ≤ λ G_bb b'                          (27)
```

则线性化模型中**每个恶意样本分数不降低、每个良性样本分数不升高**；在固定阈值下可推出**该固定样本集合**上 **FNR、FPR 均不增加**（严格改善还需至少一个样本跨阈值）。

> **原文强调**：**式(27) 比平均风险共同下降（式 21）强得多**，**不能用式(21) 直接替代 FPR/FNR 的实验门**。

### 二.4 定位与边界（强制）

- **定位＝条件性机制解释**：共同下降与梯度几何**已有成熟先例**（Sener & Koltun 2018 的支配／共同下降／Pareto 驻点区分；Yu 等 2020 的冲突—尺度—曲率边界）；本课题的贡献只可写为**针对两侧损失的精确系数、Gram 条件、实现诊断与反例边界**，**不宜称「首次证明双侧梯度正交」**。
- **原文给出三类反例**：① **任意接近正交仍不支配单臂**；② **即使精确正交，也不能忽略二阶项**；③ **正交性退化到完全冲突**的分类器反例。⇒ 近正交**不构成**「联合更新在两个指标上均优于单独更新」的充分条件。
- **本课题的数值验证**：方案 §5.13 `V2` 为**部分支持（组均值余弦 `0.3726`、单样本中位 `0.1345`）⇒ 降级为附录观察**；正文**不得**据其论证「双侧可解耦」。

## 三、定理 3：有限上端点下的搜索预算—缺口收缩（预算语义引理）

### 三.1 陈述（式 29–33）

设 `Δ_K` 为 `K` 个候选最优分数对**有限上端点** `b` 的缺口（`T3.x` 假设见原文 §4.1）。则对任意 `0 < ε ≤ b`：

```
Pr(Δ_K ≥ ε) = F(b−ε)^K = [1 − H(ε)]^K                               (29)
E Δ_K = ∫₀^b F(b−t)^K dt                                             (30)
```

在正则尾假设下：

```
E Δ_K ≤ Γ(1+1/τ)/(c₋K)^{1/τ} + (b−ε₀)·e^{−K c₋ ε₀^τ}                (31)
E Δ_K ≥ ½ (2c₊K)^{−1/τ}      （对 (2c₊K)^{−1/τ} ≤ ε₀ 的 K）           (32)
E Δ_K = Θ(K^{−1/τ})                                                  (33)
```

### 三.2 尾部类型必须重新命名（照录 §4.5）

原计划的「指数尾 `O(1/K)`／重尾 `O(K^{−1/τ})`」**不适合直接用于 `U ∈ [0,1]`**：

| 情形 | 正确结论 |
| --- | --- |
| 有限端点、端点处密度 `f(b) ∈ (0,∞)` | `H(ε) ~ f(b)ε` ⇒ 缺口 `O(1/K)` |
| 有限端点、`H(ε) ≍ ε^τ` | 缺口 `Θ(K^{−1/τ})` |
| 端点存在概率原子 `p_* = Pr(U=b) > 0` | `E Δ_K ≤ b(1−p_*)^K`，**指数收缩** |
| **无界**指数分布 | supremum 为 ∞，最大值按 `log K` 尺度增长，**不存在本文的有限缺口** |
| **无界** Pareto 分布 | supremum 为 ∞，最大值按幂次尺度增长，**同样不适用** |

⇒ 对**有限离散字符扰动空间**，若最优候选在提议分布下具有正概率，最终更接近**第三种（原子）情形**；连续端点模型可以是近似，**但不能省略这一差别**。**没有端点质量下界时不存在通用多项式收缩率。**

### 三.3 定位与边界（强制）

- **定位＝预算语义引理／辅助定理**：主要价值是把 `K`、提议分布支撑、端点质量与最终选择误差**分开**；**不宣称重新建立次序统计学**（有限样本与渐近分布已有系统理论）。
- **明确禁止的外推**（原文 §五 表）：定理 3 **不能**替代「中心化入选风险逼近全局最坏攻击」「鲁棒准确率按同速率提高」这类实验结论；**最大值收缩 ≠ 所选训练风险收缩**（`§4.6`：固定比例 top-`r` 均值不是 maximum；实际方法存在**三种不同缺口**；独立性失败有反例）。
- **本课题的数值验证**：方案 §5.13 `V3` 为**闭式通过 ＋ 真实方向一致**；真实 `K'=4` 缺口 `0.2978`。

## 四、口径纠错层（2026-09-11，强制，适用于全部关联文档）

### 四.1 Danskin 纠错（撤回此前对「传统 AT 遗漏响应梯度」的表述）

**此前跟随参照叙事的表述「传统 min-max 对抗训练把 `δ*` 当常数、遗漏攻击响应的诱导梯度是理论缺陷」——撤回。**

**Danskin 定理**：在满足条件且**内层最大解唯一**时，外层梯度正是

```
∇_θ max_δ L(θ, δ) = ∇_θ L(θ, δ*)                                   （无额外响应链式项）
```

依据：**Madry 等 ICLR 2018 §3.3 与附录 A Theorem A.1**（外部稿自报已全文核对；**本地尚未入库，见 §五**）。**有限步展开目标与精确内层最大值目标是不同对象。**

**参照（朱焱雷 RGO）问题的重新定位**：其**声明**（计算有限轨迹的反应梯度）与**实现**（`requires_grad=False` 切断轨迹）之间的**对应断裂**——**仅此**。**不得**据此对**所有 stop-gradient AT** 提出同一种理论缺陷指控。

**受影响的表述**：方案文档、命题包、恢复卡中一切「传统 AT 遗漏诱导梯度／响应梯度是缺陷」措辞**一律作废**；改写口径为「**有限步展开目标与精确内层最大值是不同对象；参照方法的可议之处在其声明与实现的对应关系**」。

### 四.2 Pareto 措辞纠错

**「检出大增但 FPR 支付可控代价」不等于 FPR—检出率两目标上的 Pareto 支配**。支配要求**至少一轴严格改善、另一轴不劣**；**若 FPR 上升，应称「权衡移动」**。

## 附录 A：背景层（原 P1–P4，内容完整保留，降为背景）

### A.1 P1：留一基线下的组相对优势是 REINFORCE 梯度的无偏估计

**陈述**：固定 `x`，`a_1,…,a_K ~i.i.d. π_θ(·|x)`，`R_i = R(x,a_i;θ)`；`b₋ᵢ = (1/(K−1))Σ_{j≠i}R_j`，`A_i = R_i − b₋ᵢ`。则
`E[A_i·∇_θ log π_θ(a_i|x)] = E[R_i·∇_θ log π_θ(a_i|x)]`。

**前提（编号，缺一不成立）**：**(A.1-①)** 基线只用组外样本（`b₋ᵢ` 不含 `R_i`）；**(A.1-②)** 组内 i.i.d.（`a_j` 与 `a_i` 条件独立 ⇒ `b₋ᵢ` 与 `∇log π(a_i|x)` 条件独立）；**(A.1-③)** 正则性（`∇_θ` 与对动作空间求和可交换）。

**证明（一步）**：`E[b₋ᵢ∇log π] = E[b₋ᵢ]·E[∇log π] = E[b₋ᵢ]·∇_θ Σ_a π_θ(a|x) = E[b₋ᵢ]·∇_θ 1 = 0`。∎

**适用边界**：只对 **policy gradient** 成立（当前 D／I／J 各臂的 `A_i` 用于检测器**样本选择**，P1 对这些臂**既不被使用也不被违反**）；**不延伸**至 detector 的 top-q 截断（见 A.3）；**不承诺方差缩减**（`Var[(R−b)G]` 展开表明须 `b` 与 `R` 相关性足够，留一基线是组内噪估计）；前提被破坏即失效（without-replacement／后一扰动依赖前一扰动／整组共享约束／共享强相关随机变量）；**确定性算子下无指称对象**（无 `π_φ` 则「无偏」无对象）。

**数值验证状态**：**待执行**（精确枚举 27 组／机器精度，与 A.2 同批）。

**引用纪律**：RLOO（`2402.14740`）**不得作为本命题的证成者**（无编号命题、无证明）；Williams 1992 与 Kool et al. 2019 **不在本仓库**，正文若指名引用须先入库。

### A.2 P2：全组均值基线的 `(1−1/K)` 缩放

**陈述**：若基线换成含 `i` 的全组均值 `R̄`，则 `E[(R_i − R̄)∇log π] = (1 − 1/K)·E[R_i ∇log π]`（`K = 4` 时 `0.75×`）。

**证明**：由 `Σ_{j≠i}R_j = K R̄ − R_i` 得 `(K−1)A_i = (K−1)R_i − (K R̄ − R_i) = K(R_i − R̄)` ⇒ `A_i = K/(K−1)(R_i − R̄)` ⇒ `R_i − R̄ = (1 − 1/K)A_i`；两边取期望并用 A.1 即得。∎

**设计依据（为什么用留一而非全组均值）**：① 避免与 `K` 耦合的有效步长（缩放因子 `1−1/K` 随 `K` 变，`K=2→0.5`、`K=4→0.75`）；② 缩放来源是 `R̄` 对 `R_i` 的**自包含**（因子分解不可用），不是噪声；③ 留一基线既无自包含也无缩放，是 P1 能成立的最简构造。

**适用边界**：同 A.1（只对 policy gradient）；`(1−1/K)` 是常数因子，**不改变固定点**但改变有效步长 ⇒ **跨 `K` 比较须重标定**；前提 `K ≥ 2`。

**数值验证状态**：**待执行**（与 A.1 同一枚举脚本，加一行对照）。

### A.3 P3：top-q 截断的偏差界、排序等价与本实现的免疫性／脆弱性

**(a) 截断偏差界**：`M_i = 1{A_i > 0 且 i ∈ TopQ(A)}`，`g_trunc = E[M_iA_iS_i]`，`g = E[A_iS_i]`，则 `Bias = g_trunc − g = −E[(1−M_i)A_iS_i]`，由 Cauchy–Schwarz
`‖Bias‖ ≤ sqrt(E[(1−M_i)A_i²])·sqrt(E[(1−M_i)‖S_i‖²])`；再设 `|A_i| ≤ A_max`、`‖S_i‖ ≤ G` 得 **`‖Bias‖ ≤ A_max·G·Pr(M_i=0)`**（原文自述该界**很松**）。必须同写：**负优势动作不是无用动作**（它们负责降低坏动作概率）；**确定性 top-Q 不能用重要性加权修回无偏**（被排除项 `P(M=1|A)=0`，HT 分母为零）。

**(b) 排序等价（代数事实）**：`A_i = K/(K−1)(R_i − R̄)` ⇒ `rank(A) = rank(R)`（含并列结构）、`A_i > 0 ⟺ R_i > R̄`、`Σ_i A_i = 0` ⇒ **`TopQ(A) = TopQ(R)`：留一基线对 top-q 成员选择没有任何作用**，`A_i>0` 门是其唯一新增作用。本课题实现以 `R := fooled`（二值被骗指示）套用，可分辨性后果见 notes §J.2 性质 2（正优势仅 `K−1 = 3` 个取值）。

**(c) 本实现的免疫性与脆弱性**：**免疫性**——外部稿最强反例是「全组齐平高危组在 `A_i > 0` 硬门下被整组丢弃」；**本实现无该硬门**（`official_p2p3.py` L211–L217 按 `a` 降序取全局 top-`64`，**不要求 `a > 0`**，2026-09-11 只读核验）⇒ **反例不直接命中本实现**。**脆弱性**——由 notes §J.2 性质 2／3：全组被骗（`c_i = K`）的**被骗者**与全组未被骗（`c_i = 0`）的**未被骗者** `a = 0`，**两类语义相反的候选落入同一 `0.0` 并列簇**；实现用 Python `list.sort`（**稳定排序**）⇒ 并列按**候选生成顺序**裁决、与机制语义无关；配额 `Q = 64` 与批内恶意数 `N ≈ 64` 同量级 ⇒ 切进该簇概率不低。⇒ **免疫性成立于「不整组丢弃」层，未解决「选择由任意破法决定」层**。

**算法定位（2026-09-11 更新）**：P3 **不再是「为偏差辩护」**，而是**「算法为什么必须把 RLOO policy update 与 detector top-q 解耦」的理论动机**——攻击器侧**全 `K` 样本参与**（无偏），检测器侧才用**跨源配额 hard selection**（有意有偏但预算导向）。

**适用边界**：P3(a) 否决「截断估计量＝无偏内层 max」；**不否决**有意有偏的硬截断作为启发式。当前各臂把 top-q 样本送进检测器 CE，**不存在「截断后的 policy gradient」对象** ⇒ P3(a) 在当前臂**不直接适用**；它在**方向 a 阶梯 3** 才成为必答项。

**数值验证状态**：**待执行**（`TopQ(A)` vs `TopQ(u)` 逐样本核对；手工组 `G_A/G_B/G_C` 只跑 selector）。P3(b) 的代数部分已由 notes §J.3 的等价域分析完成。

### A.4 P4：有限 `K` 内层最大值的单调性与收敛

**陈述**：`R_1,…,R_K ~i.i.d. π_φ(·|x)`，`M_K = max_{k≤K}R_k`。① **单调性**（逐点，无需分布假设）：`M_{K+1} ≥ M_K` ⇒ `E[M_{K+1}] ≥ E[M_K]`；② **收敛**（需两条前提）：若 (i) `R` **有上界**（本课题 `r = 1 − p_θ ∈ [0,1]` 天然满足）、(ii) `π_φ` 对「最优 reward 邻域」**具有正概率质量**，则 `M_K → ess sup R` 几乎必然。

**证明**：① `M_{K+1} = max(M_K, R_{K+1}) ≥ M_K`，取期望即得；② `M_K` 单调不减且被 `ess sup R` 上界控制 ⇒ 极限存在；前提 (ii) 下样本序列以正概率无穷多次落入最优邻域（Borel–Cantelli）⇒ 极限达到 `ess sup R`。∎

**含义与边界**：`K` 可**明确解释为「inner adversary 的搜索预算」**（方向单向：只增不减期望）；**只给单调性与极限，不给收敛速率**；**不得**把 `best-of-K` 写成真实 inner `max`（只能称 `K`-sample approximation to local adversarial risk）；前提 (ii) **未验证**（熵正则的作用之一即防止质量塌缩使其失效）；**本命题不承担「组相对」的差量**。

**数值验证状态**：**待执行**（合成分布演示 `E[M_K]` 单调上升并逼近 `ess sup R`）。
