## 一、P1：留一基线下的组相对优势是 REINFORCE 梯度的无偏估计

### 一.1 陈述

固定 clean 样本 `x`。设攻击动作 `a_1,…,a_K ~i.i.d. π_θ(·|x)`，奖励 `R_i = R(x, a_i; θ)`（在 P1 中 `θ` 视为给定常数，不对其求导）。定义**留一基线**与**组相对优势**

```
b₋ᵢ = 1/(K−1) · Σ_{j≠i} R_j        A_i = R_i − b₋ᵢ
```

则

```
E[ A_i · ∇_θ log π_θ(a_i|x) ]  =  E[ R_i · ∇_θ log π_θ(a_i|x) ]
```

即：**留一基线不改变攻击策略 score-function 梯度的期望**。

### 一.2 前提（编号；缺一不成立）

- **(P1-①) 基线只用组外样本**：`b₋ᵢ` 是 `{R_j}_{j≠i}` 的函数，**不含 `R_i`**。
- **(P1-②) 组内 i.i.d.**：`a_1,…,a_K ~i.i.d. π_θ(·|x)`，从而 `a_j (j≠i)` 与 `a_i` 条件独立、`b₋ᵢ` 与 `∇_θ log π_θ(a_i|x)` 条件独立。
- **(P1-③) 正则性**：`π_θ` 对 `θ` 可微，且 `∇_θ` 与对动作空间求和可交换（有限动作空间，或标准正则条件）。

**证明（一步）**：

```
E[b₋ᵢ ∇_θ log π_θ(a_i|x)]   =   E[b₋ᵢ] · E[∇_θ log π_θ(a_i|x)]        （由 ① ② 的因子分解）
                              =   E[b₋ᵢ] · ∇_θ Σ_a π_θ(a|x)
                              =   E[b₋ᵢ] · ∇_θ 1  =  0
```

故 `E[A_i ∇log π] = E[R_i ∇log π] − 0`，即所求。∎

（全部工具只有 `E_{a~π_θ}[∇_θ log π_θ(a|x)] = 0`，即对 `Σ_a π_θ(a|x) = 1` 求导；不引入任何未验证假设。）

### 一.3 适用边界

1. **只对攻击策略成立**：P1 的对象是**存在可学习 `π_φ` 且 `A_i` 进入 `φ` 的更新**时的 score-function 梯度。**本课题当前 D／I／J 各臂的 `A_i` 用于检测器训练样本选择，不是 policy gradient** ⇒ 对这些臂的检测器更新，P1 **既不被使用也不被违反**，不得引作其依据。
2. **不延伸至 detector 的 top-q 截断**（见 §三）——「baseline 无偏」推不出「截断后整体无偏」。
3. **只保证期望无偏，不承诺方差缩减、不承诺收敛率**（notes §I.5 的边界声明）。
4. **前提被破坏即失效**：候选 **without-replacement**、后一扰动依赖前一扰动、整组满足共同约束、或共享一个诱发强相关的随机变量 ⇒ 因子分解不成立（报告「留一均值什么时候确实是无偏 baseline」节明列）。
5. **确定性算子下无对象**：若候选由固定算子生成（如 CharBot 2 位替换的确定性实现），则不存在 `π_φ`，「无偏」无指称对象。**这一条决定了 P1 只在方向 a（可学习攻击策略）下有实质意义。**

## 二、P2：全组均值基线的 `(1−1/K)` 缩放

### 二.1 陈述

同 P1 记号。若把基线换成**含 `i` 的全组均值** `R̄ = (1/K) Σ_{j=1}^K R_j`，则

```
E[ (R_i − R̄) · ∇_θ log π_θ(a_i|x) ]   =   (1 − 1/K) · E[ R_i · ∇_θ log π_θ(a_i|x) ]
```

即全组均值基线把 REINFORCE 梯度的期望**系统性缩小 `(1−1/K)` 倍**（`K = 4` 时为 `0.75×`，缩 `25%`）。

### 二.2 证明

先取**精确代数恒等式**（不需要概率）：由 `Σ_{j≠i} R_j = K R̄ − R_i`，

由 `Σ_{j≠i} R_j = K R̄ − R_i`，

```
(K−1)·A_i  =  (K−1)R_i − Σ_{j≠i} R_j  =  (K−1)R_i − (K R̄ − R_i)  =  K·(R_i − R̄)

⇒  A_i = K/(K−1) · (R_i − R̄)        （即报告给出的恒等式）
⇒  R_i − R̄ = (K−1)/K · A_i = (1 − 1/K) · A_i
```

两边同乘 `∇log π` 取期望，再用 P1 得

```
E[(R_i − R̄)∇log π] = (1 − 1/K) · E[A_i ∇log π] = (1 − 1/K) · E[R_i ∇log π].   ∎
```

### 二.3 设计依据（为什么用留一而非全组均值）

1. **避免与 `K` 耦合的有效步长**：全组均值把该分支的梯度整体乘 `(1−1/K)`，等价于对这部分更新使用一个更小的学习率，且**缩放因子随 `K` 变化**（`K = 2 → 0.5`、`K = 4 → 0.75`）⇒ 改变 `K` 会同时改变有效步长，破坏跨 `K` 的可比性。
2. **缩放的来源是自包含而非噪声**：`R̄` 含 `R_i` 本身，因而它与 `∇log π_θ(a_i|x)` **不独立**，因子分解不可用；P1 的证明结构在留一基线下才成立。
3. 留一基线不含 `i`，**既无自包含也无缩放**，是 P1 能成立的最简构造。

### 二.4 适用边界

同 P1（只对 policy gradient 有意义；不延伸至 detector 截断）。补充：`(1−1/K)` 是**常数因子缩放**，在固定学习率下**不改变固定点**（对凸问题），但改变有效步长 ⇒ **跨 `K` 比较超参数时须重新标定**。`K ≥ 2` 为前提。

### 二.5 数值验证状态

**待执行。** 与 P1 同一枚举脚本，加一行「全组均值基线 vs 留一基线」的期望对照即可（预期比值恰为 `1−1/K`）。

## 三、P3：top-q 截断的偏差界、排序等价与本实现的免疫性／脆弱性

### 三.1 三件互相独立的结果

- **P3(a)**：截断估计量的偏差有界（Cauchy–Schwarz）；
- **P3(b)**：留一基线与原违规量**排序完全等价**（代数事实）；
- **P3(c)**：本课题实现**无正优势硬门**（故不中报告的「整组丢弃」反例），代价是**并列簇由破法决定**。

### 三.2 P3(a) 截断偏差界

**陈述**：设选择变量 `M_i = 1{ A_i > 0 且 i ∈ TopQ(A) }`，截断估计量 `g_trunc = E[M_i A_i S_i]`（`S_i = ∇_θ log π_θ(a_i|x)`），`g = E[A_i S_i]`。则

```
Bias = g_trunc − g = −E[ (1 − M_i) A_i S_i ]
```

由 Cauchy–Schwarz：

```
||Bias||  ≤  sqrt( E[(1−M_i) A_i²] ) · sqrt( E[(1−M_i) ||S_i||²] )
```

再设 `|A_i| ≤ A_max`、`||S_i|| ≤ G`，则

```
||Bias||  ≤  A_max · G · Pr(M_i = 0)
```

**推导核对（本地逐式复核，2026-09-11）**：`Bias = E[M A S] − E[A S] = −E[(1−M) A S]`；对 `(1−M)A` 与 `(1−M)S` 用 Cauchy–Schwarz 即得上界；末式中 `sqrt(E[(1−M)A²]) ≤ A_max·sqrt(Pr(M=0))`、`sqrt(E[(1−M)||S||²]) ≤ G·sqrt(Pr(M=0))`，相乘得 `A_max·G·Pr(M=0)`。**报告自述该界「很松」——本包照录该限定。**

**必须与结论同写的两点**（报告同节）：

1. **负优势动作不是无用动作**：在 policy gradient 中它们负责**降低坏动作概率**，全部删除即改变了优化目标；
2. **确定性 top-Q 不能用重要性加权修回无偏**：被完全排除的项有 `P(M_i = 1 | A_{1:K}) = 0`，普通 Horvitz–Thompson 的分母为零；若要可校正，须让所有样本具有非零选择概率（soft／randomized selection）。

### 三.3 P3(b) 排序等价（代数事实）

**陈述**：对同一组 `K` 个候选，

```
A_i = R_i − 1/(K−1) Σ_{j≠i} R_j = K/(K−1) · (R_i − R̄)

⇒  rank(A) = rank(R)（严格保持，含并列结构）
⇒  A_i > 0  ⟺  R_i > R̄        （「高于本组均值」准入）
⇒  Σ_i A_i = 0
```

**直接推论**：若下游只做 `TopQ(A)` 选择，则 `TopQ(A) = TopQ(R)`——**留一基线对 top-q 的成员选择没有任何作用**；`A_i > 0` 门是它唯一的新增作用。

**与本课题实现的对齐**：本课题 D 臂的选择信号是**二值被骗指示** `f ∈ {0,1}` 的组内中心化 `a = f − f̄`（回代码核验，`official_p2p3.py` L207–L215；详见 notes §J.1），故本命题以 `R := f` 直接套用。其可分辨性后果见 notes §J.2 性质 2：`a` 只有 `2K` 个可能取值，**正优势仅 `K−1 = 3` 个不同取值**。

### 三.4 P3(c) 本实现的免疫性与脆弱性

**免疫性（对报告最强反例）**：报告给出的最强机制反例是——全组齐平的高危组（如 `u = (0.99,0.99,0.99,0.99)` ⇒ `A = (0,0,0,0)`）在 **`A_i > 0` 硬门**下被**整组丢弃**。**本实现没有该硬门**：`official_p2p3.py` L211–L217 按 `a` 降序取**跨组全局 top-64**，**不要求 `a > 0`**（L211–L217 只读核验，2026-09-11）⇒ 报告反例不直接命中本实现，`a = 0` 的候选**仍可凭剩余配额入选**。

**脆弱性（同源代价，必须登记）**：

1. 由 notes §J.2 性质 2／3：**全组被骗**（`c_i = K`）的**被骗者** `a = 0`，**全组未被骗**（`c_i = 0`）的**未被骗者** `a = 0`——两类**语义相反**的候选落入**同一个 `0.0` 并列簇**。
2. 实现使用 Python `list.sort`（**稳定排序**，L216）⇒ 并列**按候选生成顺序**裁决；生成顺序 = 批内原样本顺序（已 shuffle）⇒ **与机制语义无关**。
3. 配额 `Q = 64` 与批内恶意数 `N ≈ 64` **同量级** ⇒ 配额切进 `0.0` 簇的概率**不低**。

**结论（精确到层）**：免疫性成立于「**不整组丢弃**」这一层；但它**没有**解决「**选择由任意破法决定**」这一层。**结构不可约成立，可分辨性不成立**（notes §J.4 同判）。修复方向已在 notes §J.6 登记（连续信号、显式登记破法、`Q` 与正优势候选数挂钩）。

### 三.5 适用边界

**P3 的算法定位（2026-09-11 更新）**：P3 因此**不再是「为偏差辩护」**，而是**「算法为什么必须把 RLOO policy update 与 detector top-q 解耦」的理论动机**——攻击器侧**全 `K` 样本参与**（无偏 RLOO），检测器侧才用**跨源配额 hard selection**（有意有偏、但属固定 adversarial budget 下的 hard-example allocation）。**正文照此写**：不是「top-q 以后仍然无偏」，而是「**两层的无偏性要求不同，所以必须分开**」。

P3(a) 是**对「把截断估计量当作无偏内层 max」这一主张的否决**；它**不否决**「有意有偏的硬截断」作为检测器训练启发式。本课题**当前各臂**把 top-q 选中的样本送进检测器 CE，**不存在「截断后的 policy gradient」对象** ⇒ P3(a) 在当前臂中**不直接适用**；它在**方向 a 阶梯 3**（`A_i` 进入 `φ` 的 policy gradient 且仍施加 top-q）时才成为必须处理的偏差项。

### 三.6 数值验证状态

## 四、P4：有限 `K` 内层最大值的单调性与收敛（2026-09-11 替换）

> **替换说明**：原 P4（batch-CVaR 偏差）因良性侧 CVaR 化已由 I／J 两臂**双重否决**（见 §四附），按方法升级调研建议**降为备查**；P4 改立**有限 `K` inner-max 近似**——它直接服务方向 a（`K` 是内层对手的**搜索预算**，不是纯经验超参）。依据：[方法升级调研报告](../../.Codex/docs/chatgpt-handoffs/inbox/deep-research-report%20(13).md)（**外部候选**，主代理裁决采纳）；**本命题为初等结果，本地独立复核**。

### 四.1 P4 陈述与证明

**陈述**：设 `R_1,…,R_K ~i.i.d. π_φ(·|x)`，`M_K = max_{k≤K} R_k`。则

1. **单调性（逐点，不需要任何分布假设）**：`M_{K+1} ≥ M_K`（逐样本路径成立）⇒ `E[M_{K+1}] ≥ E[M_K]`；
2. **收敛（需两条前提）**：若 (i) `R` **有上界**（本课题 `r = 1 − p_θ ∈ [0,1]` 天然满足），且 (ii) `π_φ` 对「最优 reward 的邻域」**具有正概率质量**，则 `M_K → ess sup R`（`K → ∞`）**几乎必然**。

**证明**：① 逐点：`M_{K+1} = max(M_K, R_{K+1}) ≥ M_K`，取期望即得。② `M_K` 随 `K` 单调不减、且被 `ess sup R` 从上界控制 ⇒ 极限存在且 `≤ ess sup R`；在前提 (ii) 下，样本序列以正概率落在最优邻域内的次数无穷多（Borel–Cantelli），故极限达到 `ess sup R`。∎

**含义**：`K` 因此可被**明确解释为「inner adversary 的搜索预算」**——`K` 越大，内层 `max` 的 Monte Carlo 近似越紧，而这一方向是**单向的**（只增不减期望）。

### 四.2 P4 适用边界

1. **只给单调性与极限**，**不给收敛速率**，也不给 `K` 的最优取值；
2. **不得**把 `best-of-K` 写成真实 inner `max`——`E[max_{i≤K} u(a_i)] ≤ sup_a u(a)`，除非攻击分布几乎总能命中强扰动，否则只能称 **`K`-sample approximation to local adversarial risk**；
3. 前提 (ii) 在本课题**未验证**：策略是否对最优扰动邻域保持正概率质量，是一个**实验问题**（熵正则的作用之一即是防止质量塌缩使 (ii) 失效）；
4. 本命题**不承担**「组相对」的差量——它只说明 `K` 的语义，**不是**机制创新点。

## 四附、备查：batch-CVaR 的偏差、方差与全数据 CVaR 的关系（原 P4）

> **定位**：本节**不再是 P4**，只作**备查**——其价值在于**为 I／J 两臂的失败提供数学解释**（`1/α` 放大器、batch vs 全数据 CVaR 的非线性、CE 无界）。**正文不引**；若 b 方向日后翻案，再将其升回命题。**小节编号保留 `四.1–四.5`（原样，避免引用错位）**。
> **来源**：ChatGPT 数学审查报告（2026-09-10，外部候选）「对 Q3 的审查」节；推导已本地逐式复核（见下文各小节的「推导核对」行）。

> **记号约定（强制）**：本包 `α` 指**最坏 `α` 比例**（upper-tail mass），如 `α = 0.05` 表示最坏 `5%`；**不得**与「`α = 0.95` confidence level」的另一套记法混用。良性损失随机变量记 `L`，`q_α = VaR_{1−α}(L)`，upper-tail `CVaR_α(L) = q_α + (1/α)E[(L−q_α)_+] = min_τ [τ + (1/α)E(L−τ)_+]`。

### 四.1 P4(a) 渐近方差

**陈述**：在一阶 influence function `IF(L) = (1/α)[(L−q_α)_+ − E(L−q_α)_+]` 下，

```
Var(Ĉ_α)  ≈  (1/(n_b α²)) · Var[(L−q_α)_+]
```

令尾部 excess `Z = L − q_α | L > q_α`，`μ₊ = E[Z|L>q_α]`、`σ₊² = Var(Z|L>q_α)`，则

```
Var[(L−q_α)_+] = α σ₊² + α(1−α) μ₊²        ⇒        Var(Ĉ_α) ≈ (σ₊² + (1−α) μ₊²) / (n_b α)
```

**推导核对（本地逐式复核）**：`(L−q_α)_+ = Z·1{L>q_α}`，故 `E[(L−q_α)_+] = αμ₊`、`E[(L−q_α)_+²] = α(σ₊²+μ₊²)`，相减得 `ασ₊² + α(1−α)μ₊²`；除以 `α²n_b` 得末式。∎

**量级含义**：`n_b = 512`、`α = 0.05` ⇒ `n_b α = 25.6`，`SE ≈ (1/√25.6)·sqrt(σ₊² + 0.95 μ₊²)`，`1/√25.6 ≈ 0.198`。⇒ **单批 CVaR 的采样噪声是「二十几个有效尾部样本」的量级，不是「512 个样本均值」的量级**。报告同时声明：**不能由此给出具体误差百分比**，还取决于实际 CE 尾部的 `μ₊`、`σ₊` 与尾厚度。

### 四.2 P4(b) batch 均值 ≠ 全数据 CVaR（算术反例）

**陈述**：`(1/M) Σ_b CVaR_α(B_b) ≠ CVaR_α(∪_b B_b)`。

**反例（本文件内可逐步复算，已手算复核）**：良性损失 `(100, 99, 98, 0)`，分两批 `B₁ = (100,99)`、`B₂ = (98,0)`，取 `α = 0.5`（每批 top-1）：

```
批平均   = (100 + 98)/2 = 99
合并后   = (100 + 99)/2 = 99.5         ⇒  99 ≠ 99.5
```

**原因不是代码误差**，而是 `TopTail` 是**非线性算子**。⇒ 每批独立抽样时，batch top-k SGD 更准确对应 `E_B[ĈVaR_α(B;θ)]`，**不是**有限训练集上的 `CVaR_α({ℓ_i(θ)})`；不得写「每个 batch 的 top 5% 给出全数据 CVaR 的无偏 stochastic gradient」。

**同节登记备查（不进命题）**：

- **边界定义误差**：`α n_b = 25.6` ⇒ 「top-25 均值」实为 `25/512 = 4.883%`、top-26 为 `5.078%`；严格经验 `5%` CVaR 应为 fractional boundary `(Σ_{j≤25} L_[j] + 0.6 L_[26]) / 25.6`。批内良性数只「约等于 512」时须用该批实际 `n_b^{(t)}`，不得固定 `k = 25`。
- **有限样本乐观偏差**：`E[min_τ f_n(τ)] ≤ min_τ E[f_n(τ)]` ⇒ `E[Ĉ_n] ≤ C`；同一批样本既定尾部阈值又估尾部均值。消失速率**须附加光滑密度／有限矩条件**，不得无条件下写 `O(1/n)`。
- **非光滑**：`L_[25] ≈ L_[26]` 时参数微扰即交换尾部集合 ⇒ hard CVaR 对 `θ` **分段光滑**，在排名交换边界非光滑 ⇒ **不得声称「CVaR branch provides a smooth safety constraint」**。
- **RU τ-形式更干净**：`J_ben(θ,τ) = τ + (1/α)E_ben[(ℓ_θ(x)−τ)_+]` 在**固定 `(θ,τ)`** 时其样本平均是总体期望的标准无偏 MC；与「每批自算 top-5% 阈值再只反传该 25 个样本」有本质区别。**本课题 J 臂即采用 RU τ-形式**（见 §五）。
- **CVaR 不保证 FPR**：报告的反例——初始 100 个良性中 4 个 `p = 0.99`（`FPR = 4%`），更新后 5 个变成 `0.60`、原 `0.99` 的显著下降：**尾部平均 CE 可下降而 `FPR` 升至 `5%`** ⇒ `ΔCVaR_CE < 0` **不推出** `ΔFPR ≤ 0`。CVaR 只能称 **FPR-oriented differentiable tail surrogate**，**不得**称 FPR safety guarantee；最终 FPR 仍须独立实证门。**本条与本课题 E／I 两臂实测同向**（E 拒、I 训崩），登记为理论侧支持。

### 四.3 P4(c) CE 无上界与 logit clipping 缺失（登记）

**陈述**：二分类真良性 `y = 0`、模型给 DGA 概率 `p` 时 `ℓ_CE = −log(1−p) → ∞`（`p → 1`）⇒ **不能在不加条件的情况下使用「损失有界 ⇒ concentration 成立」这类证明**。

**本课题实现登记（回代码核验，2026-09-11）**：`official_p2p3.py` L281 与 `official_p2p3_full.py` L215 均为

```
ce = torch.nn.functional.cross_entropy(logits2, sub_y, reduction="none")
```

**对输入 logits 与概率均无 clip／clamp**（脚本内仅见 `tau_val.clamp_(0.0, 20.0)`（J 臂 τ）与 `_p.clamp_min(1e-9)`，二者**均不作用于 CE 的输入**）⇒ **无 logit clipping 属实现事实**。据此，理论口径只能是**有限样本经验风险**，**不得**给 distribution-free bounded-loss guarantee。

### 四.4 适用边界

P4 只针对**良性侧 batch-CVaR（top-k 形式）**。**J 臂的 RU τ-形式不适用 P4(a) 的方差结论**——对固定 `(θ,τ)` 其 MC 估计无偏，其风险源是 **τ 的学习动态**（nested optimization），属另一问题。P4(b) 的「batch ≠ 全数据」对两种形式都成立（都是按批定义的风险）。

- `α n_b = 25.6`、`1/√25.6 ≈ 0.198`：**算术已核**。
