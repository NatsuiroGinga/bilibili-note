## 0. 统一定义（照录外部稿 §0，后文全部依赖）

固定一次更新前的参数快照 `θ̄`。主批 `B`，大小 **`B₀ = 128`**；真良性子集 `B_b`、真恶意子集 `B_m`；用于产生扰动的干净恶意样本 `n` 个、每组 `K ≥ 2` 个候选 `x̃_ij`。

```
u_ij(θ̄) = 1[ s_θ̄(x̃_ij) < 1/2 ]，      M_i = Σ_j u_ij
A_ij = u_ij − (1/(K−1))Σ_{r≠j} u_ir = K/(K−1)·(u_ij − ū_i)            (0.1)
q = min(Q, nK)，  Q = 64，  D = B₀ + q                                (0.2)
```

**选择集合 `S(θ̄)` ＝ 按 `A_ij` 降序取前 `q` 个候选，没有 `A > 0` 资格门**；`N_i = |{j : (i,j) ∈ S}|`，`Σ_i N_i = q`，`0 ≤ N_i ≤ K`。**并列由固定规则 `T` 处理**（稳定排序的原始候选顺序，或外生随机规则）——除专门注明处，结果**不依赖**选用哪一种 `T`。

`ℓ_1 = −log s_θ(x)`、`ℓ_0 = −log(1 − s_θ(x))`；真良性误报掩码 `h_x(θ̄) = 1[s_θ̄(x) ≥ 1/2]`。**与实现一致的、冻结选择状态后的条件代理损失**为

```
R(θ | θ̄) = (1/D)·[ Σ_{B_m} ℓ_1 + Σ_{B_b} ℓ_0 + Σ_{(i,j)∈S(θ̄)} ℓ_1 + 2·Σ_{B_b} h_x(θ̄)·ℓ_0 ]   (0.3)
```

实际送入优化器的梯度是 `∇_θ R(θ|θ̄)|_{θ=θ̄}`。

> **无门定义带来的重要简化（强制登记）**：**给定候选数量后，`q` 与 `D` 不随当前排序结果变化** ⇒ **不能**再把「正优势不足导致训练样本数减少」的分析套到当前实现（这与 v2 有门版本的设定**不同**，见附录 A.0）。

## 形式化链条层（F1–F23 ＋ T1–T5，2026-09-11 集成）

> **来源**：[deep-research-report (14)](../../.Codex/docs/chatgpt-handoffs/inbox/deep-research-report%20(14).md)（自报 `GPT-5.5`，**外部候选**）。**本地已全文精读并逐式核对**；与报告首尾结论的差异见 §七「集成登记」。

> **三处强制口径（不得违反）**：① `F15` 与参照式 3.11–3.12 是**严格负对应**（**不得仿造二阶反应项**）；② 参照式 3.15 在本方法**明确无对应组件**；③ `F20–F23` 是**第二阶段课程扩展／待实现组件**（**L 臂只实现三档离散调度，连续插值与课程优化问题未实现**）。

### 链条层.1 推荐的链条与必须避免的链条

**推荐（照录报告）**：`允许编辑集合 → 理想鲁棒母目标 → 随机候选生成 → binary-centered 配额 follower → 条件 CE 外层更新 → 覆盖/搜索/保留/重加权误差 → 预算分布课程路径`。

**必须避免**：`分布级攻击者 ⟹ max_Q Eℓ ⟹ top-q ⟹ 无偏/一致估计`——**这条链在当前定义下是假的**。

**双层表述（论文应保留两层）**：

```
理想母问题：  min_θ { malicious robust risk + λ·benign robust/pressure risk }   （说明「希望防什么」）
实现问题：    θ_{t+1} = θ_t − η_t ∇_θ R̂(θ | θ̄_t)|_{θ=θ_t}                    （说明「代码实际优化什么」）
```

⇒ **「实现是理想 min–max 的精确求解」不得写**；应写成**目标问题与可计算近似的区分**（成熟鲁棒优化的写法）。

### 链条层.2 五段链条（逐段要点）

**第一段 `F1`–`F5`：威胁集合与理想鲁棒母问题**

- `F1` **允许编辑集合** `Δ_B(x) = { x̃ ∈ V(x) : d_edit(x,x̃) ≤ B }`——**RFC／语法有效性、长度边界、允许字符与本地威胁合同的条件统一封装进 `V(x)`**，**不得**把未实现的恶意语义条件偷偷写进数学定义。
- `F2` **支持约束概率族** `Q_B(x) = { Q ∈ P(X) : Q(Δ_B(x)) = 1 }`。
- `F3` `ρ_B^mal(θ;x) = sup_{Q∈Q_B(x)} E_Q[ℓ_1]`。
- **`T1` Dirac 坍缩（严格证明）**：`sup_{Q∈Q_B(x)} E_Q[ℓ_1] = sup_{x̃∈Δ_B(x)} ℓ_1(x̃;θ)`（`Δ_B` 有限时为 max）。
  ⇒ **不能把理论差量写成「从样本级攻击升级到分布级攻击」——两者数学上完全等价**；「黑盒＋离散 ⇒ 只能分布化」**不是成立的推论**（CharBot／MaskDGA 本身就是点级黑盒算法）。**推荐措辞**：「分布符号用于统一表示**随机扰动提议核、有限候选采样与课程分布路径**；在纯支持约束族上 worst-case distributional risk 与 pointwise robust risk 等价」。若未来要非退化分布级 follower，**须额外限制 `Q`**（生成器族／熵／覆盖／密度比／参考分布 Wasserstein 球），**这些约束目前不在锁定实现中，不得加入当前方法定义**。
- `F4` 恶意侧总体鲁棒风险 `R_mal^rob(θ;B) = E_{x~P_mal}[ sup_{x̃∈Δ_B(x)} ℓ_1(x̃;θ) ]`（Madry 型 `E[max]` 的离散字符域任务化版本）。
- `F5` **概念性双侧母问题** `J_sym = F_mal(θ) + λ·F_ben(θ)`（良性侧最大化 `ℓ_0` ⇒ 把良性样本推向更大 DGA score ＝ FP-pressure）；**`T2` 可分离性（严格证明）**：可行集为笛卡尔积、无共享预算/耦合约束、`λ ≥ 0` 时 `sup_{Q_m,Q_b}[F+λG] = sup F + λ sup G`（**若未来加入共享攻击预算或同一生成器参数服务两侧，可分离性立即失效**）。
- **当前组件二不是良性侧内层 max**：代码**没有**从 `Δ_B^ben(x_b)` 生成良性扰动求内层最大值；锁定实现的良性侧是**在原始真良性样本上用误报状态做三倍 CE 权重** ⇒ `F5` 只能作「对称威胁母问题」，**不能声称当前方法同时数值求解了两个内层 max**。
  - `F6` `ψ_b(ℓ) = ℓ + 2(ℓ − c_t)_+`（`c_t = log 2`）；`F7` 梯度 `∇ψ_b(ℓ_0)|_{θ̄} = [1 + 2h_θ̄(x)]∇ℓ_0(x;θ̄)`（**阈值外**）；`F8` 分布重解释：`E_{P_ben}[(1+2h)ℓ_0] = Z(θ̄)·E_{Q_FP,θ̄}[ℓ_0]`，但 **`Q_FP,θ̄` 是误报掩码「确定出来的 reweighting distribution」，不是被 `max_Q` 优化出来的对抗分布**。

**第二段 `F9`–`F14`：有限候选离散 follower ＋ 条件代理外层**

- `F9` `x̃_ij ~approx-iid P_B(·|x_i)`（`K = 4`）——「**近似 iid 必须继续标为实现理想化**」：`perturb2` 使用**共享随机流顺序采样、无去重**，**未提供独立性的数学保证**。
- `F10` `u_ij(θ̄_t) = 1[s_θ̄_t(x̃_ij) < 1/2]`；`F11` `A_ij = u_ij − (1/(K−1))Σ_{r≠j}u_ir = K/(K−1)(u_ij − ū_i)`——**组内与 `u_ij` 排序一致，但跨组比较时 `ū_i` 改变组间相对尺度**（这正是对象一分配律分析真正有意义之处）。
- `F12` **离散 follower** `w*_t ∈ argmax_{w} Σ w_ij A_ij(θ_t)` s.t. `Σ w_ij = q`、`w_ij ∈ {0,1}`；**命题 B（top-`q` 最优性，严格证明）**：按 `A` 降序取前 `q` 个是 `F12` 的**精确解**（同值并列有多个最优解）。
  ⇒ **准确表述**：「当前攻击 follower 不是在域名空间直接最大化 CE，而是在随机候选池上**最大化组内中心化 binary violation 的固定总配额得分**」——**比硬写成 GRPO 或 `max_Q Eℓ` 更准确**。
- `F13` 条件代理 `R̂_t(θ|θ_t)`（与锁定实现逐项对齐：主批 CE ＋ 入选变体 CE ＋ `2·h_{θ_t}(x)·ℓ_0`，分母 `D_t = B_0 + q`）；`F14` 一步更新。
  - **边界**：若使用动量／自适应优化器，**`F14` 只是「有效的一阶梯度输入」而非完整优化器状态递推**；**算法框须按真实优化器补齐状态变量**。

**第三段 `F15`：selector 局部常值（与参照式 3.11–3.12 的严格负对应）**

- 因 `u_ij(θ)` 是阶跃函数，**只要候选未跨阈值，`u`、`A`、`w*` 在参数局部邻域内均为常数** ⇒ selector value `V_A(θ) = max_{w} Σ w_ij A_ij(θ)` 满足 **`F15`：`∇_θ V_A(θ) = 0` a.e.**（除阈值切换与排序切换边界）；而入选样本 CE 梯度一般非零 ⇒ **`∇V_A ≠ ∇[Σ_{S(θ)} ℓ_1]` 一般成立**。
- **Madry §3.3／Danskin 不能迁移**：Madry 的思路是**内层最大化的正是外层 adversarial loss**时在 maximizer 上算外层梯度；**本方法 inner objective 是 `A`、outer evaluation 是 CE** ⇒ **不得声称 `F14` 是 `V_A` 的梯度，更不得构造不存在的 `∂w*/∂θ` 二阶反应项**。
- **准确定位**：**「离散状态选择 ＋ stop-gradient 条件代理下降」**——**这不是形式化「少一层」，而是算法结构本来就不同**。

**第四段 `F16`–`F19`：误差链（理想 max 与实现之间的差距）**

- `F16` **`TopQ_A ≠ TopQ_ℓ`（严格反例）**：`K = 4, q = 1`；第一组 `s = (0.01,0.01,0.01,0.01)` ⇒ `u = (1,1,1,1)`、`A = (0,0,0,0)`，其恶意 CE ≈ `4.605`；第二组 `s = (0.49,0.9,0.9,0.9)` ⇒ 唯一成功候选 `A = 1`、CE ≈ `0.713`。**global top-1 按 `A` 选第二组的 `0.49`，而池中真正最大 CE 是第一组的 `0.01`。**
  ⇒ **「`K = 4` ＋ 中心化 ＋ top-`q` 是 `max_Q Eℓ` 的 Monte Carlo 一致估计器」不可证明**。最严谨表述：**`w*` 是 `A` 的 top-`q` 次序统计选择器，最终训练量是「按 `A` 排名、以 CE 评价」（rank-by-A, evaluate-by-ℓ）的伴随统计量**；当前实现是**有偏、预算受限、异质组竞争代理**。
- `F17` **三缺口恒等式（严格恒等式）**：`L_{i,Δ}* − L̂_i = (L_{i,Δ}* − L_{i,P}*) + (L_{i,P}* − M_{i,K}) + (M_{i,K} − L̂_i)` ＝ **coverage／search／retention** 三项；含义分别见报告（**增加 `K` 救不了覆盖缺口**；`F16` 反例说明**搜索充分时保留缺口仍可很大**）。
- `F18` **全局四项（严格恒等式）**：`R_Δ* − R_S = (1/n)Σ_i[C_i + E_{i,K} + T_{i,K,Q}] + Σ_i(1/n − N_i/q)·L̂_i`；**最后一项是有符号的组重加权差**（**不是自动非负的误差界**）⇒ **论文应把这种偏置写成机制本身，而不是藏在「Monte Carlo max approximation」一句话里**。
- `F19` **搜索预算语义（iid 条件下严格）**：`Pr(L_{i,P}* − M_{i,K} > ε) = [1 − ξ_i(ε)]^K ≤ e^{−Kξ_i(ε)}`；仅有下界 `ξ_i(ε) ≥ cε^τ` 时只能得 `E[E_{i,K}] = O(K^{−1/τ})`；**要写成 `Θ(K^{−1/τ})` 必须同时给出两侧尾质量条件（`c_1ε^τ ≤ ξ_i(ε) ≤ c_2ε^τ`）与正则条件**——否则理论上最多支持 `O(·)`。

**第五段 `F20`–`F23`：预算课程路径（第二阶段扩展／待实现组件）**

- `F20` 真实恶意增广联合分布 `G_{π_t}(dx,dx̃) = P_mal(dx)·Σ_{m∈M} π_t(m)P_m(dx̃|x)`（`M = {m_1,…,m_L}` 为难度层，本课题对应「1 位／2 位／半替换」；`F21` 单调度 `B(t) = m_t` 只是 `π_t = δ_{m_t}` 的**退化情形**）。
- **`T3` 嵌套 Hamming 耦合下的 `W_1` 上界（条件严格）**：在**两预算由同一随机编辑序列耦合**（`X_m` 用前 `m` 次操作、`X_{m'}` 在其前缀上续做）时 `W_1(P_m,P_{m'}) ≤ |m − m'|/ℓ_x`。
  > **必须写进假设**：`supp P_m ⊆ Δ_m, supp P_{m'} ⊆ Δ_{m'}` **本身并不推出该界**（无共享前缀时只能得 `d_H ≤ m + m'` 的松量级）⇒ **nested/shared-randomness coupling 是假设，不是无条件结论**。
- `F22` 层间成本 `c̄(m,m') = E_{x~P_mal}[ |m(x) − m'(x)| / ℓ_x ]`；**`T4` contraction（条件严格）**：若每对层存在满足 `T3` 的条件 coupling，则 `W_1(G_π, G_π') ≤ W_{1,c̄}(π, π')` ⇒ **只要预算层分布路径足够平滑，就能在耦合条件下控制输入增广分布相邻阶段的漂移上界**（不必在模型参数空间讨论难度连续性）。
- `F23` **课程优化问题** `min Σ_t W²_{1,c̄}(π_t,π_{t+1})` s.t. `π_t ∈ Δ^{L−1}`、`E_{π_{t+1}}[m] ≥ E_{π_t}[m]` 与**预注册的 exposure／endpoint 约束**；**`T5`（严格证明）**：`Σ_t d_t² ≥ (1/T)·W²_{1,c̄}(π_0,π_T)`（存在常速 geodesic 且各阶段等距时可达）。
- **强制标注（照录报告的边界）**：**「课程 = 难度层分布路径 ＋ schedule」的运输几何框架来自 Shin & Alvarez-Melis；把「最小化相邻漂移」写成显式最优化目标是本方法的进一步构造，不是该原文已证明的 DGA 定理**。**当前交接包只说明已有三档攻击层，未说明代码已实现动态课程调度** ⇒ `F20–F23` **若尚未存在于实际训练中，必须标为「第二阶段课程扩展／待实现组件」，不得写成已实现的方法机制**（**本课题 L 臂只实现了三档离散调度，连续 `π_t` 插值与 `F23` 优化未实现**）。

## 一、对象一：中心化预算选择的分配律与条件方差

### 一.1 编号假设（照录 §1.1）

- **A1 固定快照与候选池**：本节代数恒等式均在固定 `θ̄` 与候选池下成立，**不要求候选独立**。
- **A2 理想化采样模型**：涉及**集中极限与概率界**时额外假设 `u_i1, u_i2, … ~iid Bernoulli(p_i)`，且 `n, p_i, θ̄` **不随 `K` 改变**；**组内独立是必要的**，组间独立不是联合上界的必要条件。
- **A3 并列规则**：并列由固定规则 `T` 处理，**不把未声明的 CE 二次排序加入算法**。
- **A4 条件梯度模型**：协方差部分**另加随机效应假设**，**不能从 A2 自动推出**。

> **边界**：实际 `perturb2` 的顺序伪随机采样**只能作为 A2 的近似依据，不能视为已证明独立性**。

### 一.2 定理 1A：平移不变性与无门成功计数律

```
A_ij(u_i1+c_i, …, u_iK+c_i) = A_ij(u_i1, …, u_iK)                      (1.1)

        ⎧ (K − M_i)/(K − 1),   u_ij = 1
A_ij =  ⎨                                                              (1.2)
        ⎩ −M_i/(K − 1),        u_ij = 0
```

**全局排序的精确结构（式 1.3，修正此前「零优势簇垫底」的模糊表述）**：

```
混合组中的成功候选  >  全成功组与全失败组的零优势候选  >  混合组中的失败候选     (1.3)
```

⇒ **零优势簇位于正优势与负优势之间**（**不是垫底**）；在正优势层内部、负优势层内部，均为 **`M_i` 越小、分数越高**。

**无门情况下的精确填充数（式 1.4）**：记 `C_+`／`C_0`／`C_-` 为三类候选的容量，则

```
q_+ = min(q, C_+)，   q_0 = min{C_0, (q − C_+)_+}，   q_- = (q − C_+ − C_0)_+     (1.4)
```

**这三个量与并列规则无关**；各组具体拿到多少零优势配额则**依赖 `T`**。若并列在同分候选之间**均匀随机**处理，则 `E[N_i | M_1…M_n] = Σ_{a:H(a)>0} T(a)·c_i(a)/H(a)`（式 1.5）。
> **实现边界**：**本实现是稳定排序 ⇒ 不能使用式(1.5) 代替真实分配。**

**平移不变性的边界（照录 §1.2 末）**：平移不变性只保证**组内相对**结构不受逐组常数影响，**不**保证配额分配、并列裁决或最终入选集合在其它变换下不变。

### 一.3 定理 1B：无门固定预算的集中极限

**结论（式 1.8）**：在 A1–A3 下，**集中目的地是 `(0,1)` 内部组中 `p` 最小者 `i_*`（非含边界组 `p = 0` 或 `p = 1`）**：

```
Pr(N_{i*} = Q) ≥ 1 − 2|I| e^{−2Kε²}                                     (1.8)
```

（在事件 `max_{i∈I} |M_i/K − p_i| ≤ ε` 上，`i_*` 是混合组、拥有至少 `Q` 个成功候选、且成功数严格小于其他内部组。）

**必须保留的边界（§1.3 末）**：① 该结论是**条件性下界**，依赖 A2 的理想化采样与 `p` 的**唯一最小内部值**；② **边界组（`p = 0`／`1`）不参与集中极限的目的地**——**含边界组时结论不适用**；③ 它是**固定 `Q`、`K` 增大**的渐近陈述，**不能**直接用于 `K = 4, Q = 64` 的当前设定。

### 一.4 定理 1C：组相关性、集中度与偏置—方差

**条件梯度模型（§1.4）** 下：

```
Cov(ĝ_S | F) = (Σ_i N_i² / q²)·Σ_grp + (1/q)·Σ_ind                        (1.10)

配额集中度 H_S = Σ_i (N_i/q)²，   max{1/n, 1/q} ≤ H_S ≤ min{1, K/q}      (1.11)

E[‖ĝ_S − μ_pool‖² | F] = ‖B_S‖² + H_S·tr Σ_grp + (1/q)·tr Σ_ind          (1.14)

MSE_S − MSE_T = (‖B_S‖² − ‖B_T‖²) + (H_S − H_T)·tr Σ_grp                 (1.15)
```

**这才是可支持的「集中度—偏置—方差权衡」**：**集中度增加会增加该模型下的组相关噪声项；是否值得要看对指定目标的偏置变化，而不是自动获得方差优势。**

**可核查推论表（照录 §1.5）**：

| --- | --- |

## 二、对象二：良性风险等价式、共同下降条件与条件代理

### 二.1 定理 2A：与实现一致的良性超额风险

**（离开阈值点时）梯度等价（式 2.3）**：

```
∇_θ H_b(θ̄) = (1/D)·Σ_{x∈B_b} [1 + 2 h_x(θ̄)]·∇_θ ℓ_0(x; θ̄)             (2.3)
```

⇒ 上一轮的人口风险形式 `R_b(θ) = E_b[ρ(ℓ_0)]` 对应的是**类条件良性风险**；在当前批损失中它的系数是 **`b/D`，不是 `1`**。

**数值差（式 2.4，不可混同）**：记同一批上的数值加权损失 `W_b(θ̄) = (1/D)Σ_{B_b}[1+2h_x(θ̄)]ℓ_0`，则

```
W_b(θ̄) − H_b(θ̄) = (2 c_t / D)·Σ_{x∈B_b} h_x(θ̄)                        (2.4)
```

**在掩码不变的区域该差是常数；跨越阈值后不再是全局常数** ⇒ **不能把「硬掩码加权损失的数值」与「连续超额风险」写成同一个函数**，也不得不加说明地对前者的总体期望求导而忽略边界项。（`q = 64, D = 192` 时：普通良性样本的 CE 梯度系数 `1/192`、误报样本 `3/192`；若某批 `b = 64`，则类条件良性风险整体系数 `1/3`——**这些不同层次的系数必须分开**。）

**阈值点必须单独处理**：`ℓ_0 = c_t` 时 `ρ` 的次梯度区间为 **`[1, 3]`**；实现用 `s ≥ 1/2` ⇒ **对应选择上端点 `3`**。若用普通 ReLU 且约定零点导数为 0，则该点返回系数 `1`，**并非逐点完全一致**。⇒ **严格说法**：「**离开阈值点时梯度完全相同；在阈值点，使用上端次梯度可与实现一致。**」

### 二.2 定理 2B：双风险共同下降区间

设两非零梯度 `g_1, g_2`，记 `a = ‖g_1‖²`、`b = ‖g_2‖²`、`c = g_1ᵀg_2`，方向 `d = g_1 + λg_2`（`λ > 0`），则一阶共同下降条件为

```
a + λc > 0,   c + λb > 0                                               (2.5)
```

`c < 0` 时等价于 **`−c/b < λ < a/(−c)`**（式 2.6）；**区间非空当且仅当 `c > −√(ab)`**（式 2.7；有限步保证见式 2.8）。

### 二.3 三倍权重在实际损失中的正确映射（关键修正）

按当前快照把损失拆为

```
R_m = (1/D)[Σ_{B_m} ℓ_1 + Σ_S ℓ_1],   R_b0 = (1/D)Σ_{x∈B_b, h_x=0} ℓ_0,
R_b1 = (1/D)Σ_{x∈B_b, h_x=1} ℓ_0                                      (2.9)

实际损失 R = R_m + R_b0 + 3·R_b1；对应梯度 d = m + b_0 + 3·b_1         (2.10)
```

⇒ **正确分解是 `r = m + b₀`、`f = b₁`**（即「**恶意项 ＋ 未误报良性项**」与「**误报良性项**」两组），**不是**「恶意 ＋ 三倍全部良性」——**共同下降条件式(2.5) 必须用式(2.10) 的分解代入**。§2.4 同时给出**与该分解一致的数值实例**与**固定三倍权重的反例**（证明位置：原文 §2.4，本地行 846–996）。

### 二.4 定理 2C：选择器值函数与 CE 更新不同

选择器值函数 `V(θ) = max_{0≤w≤1, Σw=q} Σ w_ij A_ij(θ)`（式 2.12）。在**所有候选预测都没有恰好位于 `1/2`** 的参数点，若 logits 连续，则存在邻域使全部二值 `u_ij` 不变 ⇒ `A_ij` 与 `V` 均为常数：

```
∇_θ V(θ) = 0                                        (2.13)
而入选候选的 CE 梯度一般不为零：(1/D)Σ_{(i,j)∈S} ∇_θ ℓ_1(x̃_ij; θ) ≠ 0   (2.14)
```

⇒ **二值选择器的值函数在指示不变的区域内梯度为零，而 CE 更新可非零**——**不能用选择器值函数的梯度解释训练更新**。

## 三、对象三：搜索—保留双预算误差分解

### 三.1 定理 3A：逐组三缺口分解与实际训练的第四项

**逐组精确恒等式（式 3.2）**：

```
L_{i,Δ}* − L̂_i = (L_{i,Δ}* − L_{i,Q}*) + (L_{i,Q}* − Z_{i,K}) + (Z_{i,K} − L̂_i)
                 └── C_i：覆盖缺口 ──┘  └─ E_{i,K}：搜索缺口 ─┘  └ T_{i,K,Q}：保留缺口 ┘  (3.2)
```

在**非负损失**下三项几乎必然非负。

**实际跨组训练不能只写这三项（式 3.3）**：等组理想鲁棒风险 `R* = (1/n)Σ_i L_{i,Δ}*`，实际入选变体均值 `R_S = Σ_i (N_i/q)·L̂_i`，则

```
R* − R_S = (1/n)Σ_i (C_i + E_{i,K} + T_{i,K,Q}) + Σ_i (1/n − N_i/q)·L̂_i    (3.3)
```

最后一项是**组重加权差异**，**可以为正也可以为负**。⇒ **逐组风险可用三缺口分解；对应到全局入选均值时必须再加有符号的组重加权项。**
> 补充：实际总损失中变体项为 `(q/D)R_S`；**若比较时 `q` 改变，主批项也被不同的 `D` 缩放** ⇒ **不能把所有差异都归因于排序**。

### 三.2 定理 3B：搜索预算界只控制搜索项

记**近最坏损失区域的概率质量** `ξ_i(ε) = Pr_{δ~Q_i}(L_i(δ) ≥ L_{i,Q_i}* − ε)`——**它不是 `fooled` 成功概率 `p_i`**。组内独立同分布时

```
Pr(E_{i,K} > ε) = [1 − ξ_i(ε)]^K ≤ e^{−K ξ_i(ε)}                        (3.4)
```

⇒ **搜索界只控制搜索缺口 `E_{i,K}`**，**不控制**覆盖缺口与保留缺口，也不控制组重加权项。

### 三.3 定理 3C：二值化后系统性丢弃反例仍成立

**陈述**：固定 `Q`，`K → ∞` 时以趋于 1 的概率**全部 `Q` 个保留候选来自第二组、第一组完全未被保留**；**尽管两组搜索最大值都逼近各自最坏值，所选训练风险与等组理想鲁棒风险仍存在至少 `log 2` 的缺口**。

**证明要素**：第一组 `v > 1/2` ⇒ `p_1 = 1`、`M_1 = K`、**`A_1j = 0`**；第二组 `p_2 = (0.6−0.5)/0.6 = 1/6` ⇒ `M_2 ~ Binomial(K, 1/6)`。事件 `N_1 = 0, N_2 = Q` 的概率为

```
Σ_{m=Q}^{K−1} C(K,m)(1/6)^m (5/6)^{K−m}                                 (3.7)
≥ 1 − e^{−2K(1/6 − Q/K)²} − (1/6)^K      （当 Q/K < 1/6）               (3.8)
```

两组最坏 CE 分别为 `L_1* = log 10`、`L_2* = log(5/2)`（差 **`log 4 = 2 log 2`**）。

> **要点**：**这是二值选择下的系统性丢弃反例，不是连续域特有现象**（§3.4 末）；与当前 `K = 4, Q = 64` 的边界见 §3.4 末（**当前设定下该渐近反例不直接适用**）。

### 三.4 定理 3D：`K` 与 `Q` 的联合分配相变

定义 `P = Σ_i p_i`、

```
r_i⁺(β) = min{ p_i, (β − Σ_{h<i} p_h)_+ }                               (3.10)
r_i⁻(β) = min{ 1 − p_i, (β − P − Σ_{h<i}(1 − p_h))_+ }                  (3.11)
```

则几乎必然

```
N_i/K → r_i⁺(β) + r_i⁻(β)          (3.12)
N_i/q → [r_i⁺(β) + r_i⁻(β)]/β      (3.13)
```

（证明由大数定律与严格概率间隔：充分大的 `K` 下各组均为混合组，且成功计数顺序与 `p_i` 顺序相同。）

**可核查推论表（照录 §3.6）**：

| 核查对象 | 数学预言 |
| --- | --- |
| 每组覆盖／搜索／保留量 | 式(3.2) 逐次运行应**精确相等** |
| 全局入选均值 | **必须加上式(3.3) 的组重加权项**；仅三项通常对不上 |
| 近最坏候选命中率 | 独立模型下满足式(3.4)，**与二值成功概率不是同一量** |
| 二值化后的两组反例 | 全配额流入第二组的事件概率为式(3.7) |
| 联合改变 `K, Q` | `Q_K/K → β` 时组比例应趋向式(3.13) |
| 当前 `K = 4` 的重放 | **应先检查候选容量、同分规则与零优势填充**，**不能直接套渐近单组集中** |

**审稿攻击线（照录）**：「你的算法本来就不优化真实内层 max，这个缺口分解有什么意义？」**应对边界**：**它用于界定算法与理想鲁棒风险之间的差异、解释 `K, Q` 的含义，不用于证明算法必须逼近该理想目标**；若方法选择的是训练效率或泛化代理，**就应明确承认「选择保留」与「组重加权」是有意或无意引入的偏置**。

## 五、口径纠错层（强制，适用于全部关联文档）

### 五.1 Danskin 纠错（撤回）

**此前跟随参照叙事的表述「传统 min-max AT 把 `δ*` 当常数、遗漏攻击响应的诱导梯度是理论缺陷」——撤回。** **Danskin 定理**：满足条件且内层最大解唯一时 `∇_θ max_δ L(θ,δ) = ∇_θ L(θ,δ*)`，**不需要额外的攻击响应链式项**（依据 Madry ICLR 2018 §3.3 与附录 A Theorem A.1；**本地尚未入库**）。**有限步展开目标与精确内层最大值是不同对象。** 参照（朱 RGO）问题的重新定位：**其「计算有限轨迹反应梯度」的声明与「`requires_grad=False` 切断」的实现之间的对应断裂——仅此**；**不得**推广为「所有 stop-gradient AT 有同一种理论缺陷」。本方案不采用展开优化属**任务化选择**，**不是「修正了某个理论缺陷」**。

### 五.2 Pareto 措辞纠错

**FPR 上升时只能称「权衡移动」**（支配要求至少一轴严格改善、另一轴不劣）：**DRIFT 骨干 F vs B 是真支配**（`0.0184 < 0.0197` 且三面板检出更优）；**B-ResNet 上只算权衡移动**（`@1e-3` `0.0459 > 0.0356`）——**两处分别表述**。

- **T1.2 对齐预算**：`q = nr`；四算子 `U_r`（逐组均匀）、`P_r`（逐组按 `u` 取 top-`r`）、`A_q`（**按中心化优势跨组排序**）、参照 `R_q`（全局按 `u` 取 top-`q`）。
  > **纪律**：`R_q ≠ A_q`；**全局 top-k 聚合目标已有成熟研究，不能仅凭出现全局排序主张首创**。
- **T1.3 中心化**：`A_ik = u_ik − (1/(K−1))Σ_{ℓ≠k}u_iℓ = K/(K−1)(u_ik − ū_i)`；`H = Σ_{i,k} Z_ik·1{A_ik > 0}`；`L_elig = min(q,S) − min(q,H)`、`L_rank = min(q,H) − C_A`。
- **定理 1A（任意候选池精确分解）**：`E[C_U|S_1…S_n] = (r/K)S`；`C_P = q − D`、`C_R = C_P + min(D,E)`；**`C_A − C_P = min(D,E) − L_elig − L_rank`**；**`E C_A > E C_P ⟺ E min(D,E) > E L_elig + E L_rank`**（`D = Σ_i(r−S_i)_+`、`E = Σ_i(S_i−r)_+`）。
- **定理 1B（两类型闭式）**：T1.4 两类型独立候选 ＋ T1.5 二点分数模型 `u_ik = a + (b−a)Z_ik`；有限样本判定式 `T_q[H_{p_h}^{n_h}H_{p_l}^{n_l}] > n[πβ_r(p_h) + (1−π)β_r(p_l)]`；`n=2,K=4,r=1,q=2` 时 **`E C_A − E C_P = p²(p² − 8p + 6)`** ⇒ **`0 < p < 4−√10 ≈ 0.83772` 时 `E C_U < E C_P < E C_A`**；大组数界 `|E C_A/n − min(r, μ_A)| ≤ (K−1)/(2√n)` 与 **混合比例阈值 `π < 13/29`**。
- **解析值表**（原文声明「不是实验数值」）：`p = 0.5` ⇒ `U 0.5 / P 0.9375 / A 1.5 / R 1.625`（**严格优势实例**）；`p = 0.9` ⇒ `0.9 / 0.9999 / 0.6840 / 1.9962`（**明确失败实例**）。
- **解释**：缺额 `D` 与溢出 `E` 的交换最多贡献 `min(D,E)`；**中心化不是免费附加项**（可能剔除有用候选、或把未骗过的组内异常值排在已骗过候选之前）。

### A.1 P1：留一基线下的组相对优势是 REINFORCE 梯度的无偏估计

**陈述**：`a_1…a_K ~iid π_θ(·|x)`、`R_i = R(x,a_i;θ)`、`b₋ᵢ = (1/(K−1))Σ_{j≠i}R_j`、`A_i = R_i − b₋ᵢ` ⇒ `E[A_i ∇log π(a_i|x)] = E[R_i ∇log π(a_i|x)]`。
**前提（缺一不成立）**：① 基线**只用组外样本**；② **组内 iid**（`b₋ᵢ` 与 `∇log π(a_i|x)` 条件独立）；③ 正则性（`∇_θ` 与求和可交换）。
**证明（一步）**：`E[b₋ᵢ∇log π] = E[b₋ᵢ]·E[∇log π] = E[b₋ᵢ]·∇_θ Σ_a π_θ(a|x) = 0`。∎
**边界**：只对 **policy gradient**（当前各臂的 `A_i` 用于**样本选择**，P1 既不被使用也不被违反）；**不延伸**至 top-q 截断；**不承诺方差缩减**；前提被破坏即失效；**确定性算子下无指称对象**。
**引用纪律**：RLOO（`2402.14740`）**不得作为证成者**；Williams 1992 与 Kool et al. 2019 **不在本仓库**。

### A.2 P2：全组均值基线的 `(1−1/K)` 缩放

**陈述**：`E[(R_i − R̄)∇log π] = (1 − 1/K)·E[R_i∇log π]`（`K = 4` 时 `0.75×`）。
**证明**：`(K−1)A_i = (K−1)R_i − (K R̄ − R_i) = K(R_i − R̄)` ⇒ `R_i − R̄ = (1 − 1/K)A_i`，取期望并用 A.1。∎
**设计依据**：避免与 `K` 耦合的有效步长（`1−1/K` 随 `K` 变）；缩放来源是**自包含**而非噪声；留一基线是 P1 成立的最简构造。
**边界**：同 A.1；常数因子**不改变固定点**但改变有效步长 ⇒ **跨 `K` 比较须重标定**；前提 `K ≥ 2`。

### A.3 P3：top-q 截断的偏差界、排序等价与本实现的免疫性／脆弱性

- **(a) 偏差界**：`Bias = −E[(1−M_i)A_iS_i]` ⇒ `‖Bias‖ ≤ sqrt(E[(1−M_i)A_i²])·sqrt(E[(1−M_i)‖S_i‖²])` ≤ **`A_max·G·Pr(M_i = 0)`**（原文自述**很松**）；**负优势动作不是无用动作**；**确定性 top-Q 不能用重要性加权修回无偏**。
- **(b) 排序等价**：`rank(A) = rank(R)`、`A_i > 0 ⟺ R_i > R̄`、`Σ_i A_i = 0` ⇒ **`TopQ(A) = TopQ(R)`：留一基线对 top-q 成员选择没有作用**，`A_i > 0` 门是唯一新增作用（本实现以 `R := fooled` 套用）。
- **(c) 免疫性与脆弱性**：**无门实现**（L211–L217 降序取 top-64，**不要求 `a > 0`**）⇒ 外部稿「整组丢弃」反例**不直接命中**；但**全组被骗者的 `a = 0` 与全组未被骗者的 `a = 0` 落入同一并列簇**，实现用**稳定排序** ⇒ 并列**按生成顺序**裁决、与机制语义无关（**immune 于「整组丢弃」，未解决「破法主导」**）。
- **算法定位**：P3 是**「为什么必须把 RLOO policy update 与 detector top-q 解耦」的理论动机**（攻击器侧全 `K` 参与、检测器侧有意有偏但预算导向）。

### A.4 P4：有限 `K` 内层最大值的单调性与收敛

**陈述**：`M_K = max_{k≤K}R_k` ⇒ ① `M_{K+1} ≥ M_K`（逐点，无需分布假设）⇒ `E[M_{K+1}] ≥ E[M_K]`；② 若 `R` **有上界**且 `π_φ` 对最优 reward 邻域**具有正概率质量**，则 `M_K → ess sup R` 几乎必然。
**边界**：只给单调性与极限、**不给速率**；**不得**把 `best-of-K` 写成真实 inner max；前提 (ii) **未验证**；**不承担「组相对」的差量**。

### A.4-附 备查：batch-CVaR 的偏差、方差与全数据 CVaR 的关系（原 P4）

> **定位**：**不是命题**，只作**备查**（为 I／J 两臂的失败提供数学解释）；**正文不引**。
