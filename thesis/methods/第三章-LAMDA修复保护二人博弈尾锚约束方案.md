## 1. 研究问题

在 LAMDA 年度到达流、固定回放预算（容量 200，原论文协议）下：把"修复当前恶意漏判"与"不抬良性误报、不翻转旧正确判定"表述为**二人约束博弈**——模型玩家最小化含修复项的训练目标，安全玩家持有对**良性高分位尾部风险**的非负乘子约束——是否存在使联合臂同时通过开发层硬门的约束对象与更新动力学，使固定容量回放的学习曲线逼近 Joint 而不牺牲 Naive 级算力。

## 3. 框架定义

记年度 t、旧冻结模型 θ⁻、当年训练分片 D_t、回放池 B（|B|=200）、判定 logit 阈值 a（sigmoid 0.5）、良性标尺 b 与尾大小 K（§5 登记）。

**模型玩家**（继承 L11 §3.1，不变）：

```
L_M(θ) = L_cur(θ; D_t) + L_replay(θ; B) + λ_r · L_mal-FN(θ; R_t)
R_t = {(x,1) ∈ D_t : z_θ⁻(x) < a}，  d_i = [a − z_θ⁻(x_i)]₊
L_mal-FN = Σᵢ d_i·BCE(f_θ(xᵢ),1) / Σᵢ dᵢ
```

**安全玩家——尾锚约束（本方案唯一新部件）**：保护参考不再取全量历史良性均值，而取当年已到达良性中旧模型分数最高的尾集：

```
A_t(K) = TopK_{x ∈ G_t^benign}  σ(z_θ⁻(x))          # 只依赖 θ⁻，因果合法
尾风险（分位数代理）：  R̂_tail(θ) = (1/K) Σ_{x∈A_t} softplus(z_θ(x) − b)
基准（年初冻结）：      ρ_tail = R̂_tail(θ⁻)
约束残差：              c_tail(θ) = R̂_tail(θ) − ρ_tail
乘子更新（每 epoch，v2 已验形态）： λ_tail ← [λ_tail + η_λ · c_tail]₊
```

**联合目标**：`min_θ L_M + λ_tail·c_tail`，s.t. 独立 hard FPR gate（沿用 L11 §4，测试标签不入梯度）。旧恶意回归约束 c_P 保留 L11 定义。两变体成臂：

- **V1（直接尾损失）**：去乘子，`L_M + β·R̂_tail`，β 固定登记值——检验"作用面对"是否足以过门；
- **V2（乘子尾约束）**：完整二人博弈形式——检验自适应强度是否优于固定 β（对位 v2 单臂"无介入"与联合臂"欠抑制"两极之间的中点）。

与近邻的区别（查重义务不变，冻结前联网核）：PBR/CBRS 推回类用随机或全部旧任务样本；A-GEM/L6 用梯度投影保均值参考；本方案的约束对象是**当年已到达数据内旧模型最高分良性尾＋分位数代理**，与修复候选 R_t 对偶构造（同一 θ⁻、互补标签）。此区别须在实现前文献查重确认未被覆盖。

## 7. 通过 / 失败门（看到数据前冻结）

**主判据（统一指标，开发面板 2016–2018 pooled，相对同流 ER 锚）：**
1. ΔFPR ≤ 0 且 旧恶意负向翻转率增量 ≤ 0；
2. ΔFNR < 0 或 恶意正向修复率 > ER，且 ΔAP ≥ −0.002；
3. V2 另加机制有效性门：λ_tail 轨迹非平凡（年更新次数 ≥ 5 且对 A_t 扰动响应），乘子发散（任一年 λ > 10）即刻失败（P9 防线）。

**机制诊断（必报不判门）**：新增 FP 溯源比例（P6 口径）、尾内/尾外 FP 分解、修复样本与尾集的分数重叠带。

**停止条件**：
- E1 oracle 覆盖不足（任何 K ≤ 2000 裁剪后 FPR 不过 ER）→ V1/V2 不跑，转约束对象下一候选（分位数投影 / 自适应 K），仍在本骨架内；
- V1、V2 同败且良性高分区仍被抬穿 → "分数层固定参考约束"范式证伪，负结论入章，转表述层（分离输出头/排序目标），需重新过 `research-ideation` 链并用户裁决；
- 通过 → 冻结为算法 3-1，进入正式化前置（源期特征视图重建——发布 4561 维视图含未来协变量，正式主张前必须换，独立工程任务）。

## 9. 风险与边界声明

- 本方案的全部"空间"论据在 P1/P2（封印年与 Joint 间隙）；开发面板 2016–2018 仍可能过窄——若 ER2018 锚在 2018 年 AP 崩落（P1 外推），面板获得分辨率但也可能使"ΔFPR≤0"在崩盘年份变严。T1 原件逐年读数先于开跑登记。
- oracle E1 是必要非充分：train 尾与 test 尾同源性未证；若 V2 通过而覆盖曲线显示 train 尾对 test 新 FP 覆盖 <50%，须补"尾外波及"归因后才能晋级。
- 单一种子、screening_only、发布视图未来协变量披露，全部沿用台账统计边界。
