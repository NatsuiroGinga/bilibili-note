## 3. 框架定义

记年度 t、旧冻结模型 θ⁻、当年训练分片 D_t、回放池 B（|B|=200）、判定 logit 阈值 a（sigmoid 0.5）、良性标尺 b 与尾大小 K（§5 登记）。

**模型玩家**（继承 L11 §3.1，不变）：

```
L_M(θ) = L_cur(θ; D_t) + L_replay(θ; B) + λ_r · L_mal-FN(θ; R_t)
R_t = {(x,1) ∈ D_t : z_θ⁻(x) < a}，  d_i = [a − z_θ⁻(x_i)]₊
L_mal-FN = Σᵢ d_i·BCE(f_θ(xᵢ),1) / Σᵢ dᵢ
```

**安全玩家——尾锚约束（本方案唯一新部件）**：保护参考不再取全量历史良性均值，而取当年已到达良性中旧模型分数最高的尾集：

```
A_t(K) = TopK_{x ∈ G_t^benign}  σ(z_θ⁻(x))          # 只依赖 θ⁻，因果合法
尾风险（分位数代理）：  R̂_tail(θ) = (1/K) Σ_{x∈A_t} softplus(z_θ(x) − b)
基准（年初冻结）：      ρ_tail = R̂_tail(θ⁻)
约束残差：              c_tail(θ) = R̂_tail(θ) − ρ_tail
乘子更新（每 epoch，v2 已验形态）： λ_tail ← [λ_tail + η_λ · c_tail]₊
```

**联合目标**：`min_θ L_M + λ_tail·c_tail`，s.t. 独立 hard FPR gate（沿用 L11 §4，测试标签不入梯度）。旧恶意回归约束 c_P 保留 L11 定义。两变体成臂：

- **V1（直接尾损失）**：去乘子，`L_M + β·R̂_tail`，β 固定登记值——检验"作用面对"是否足以过门；
- **V2（乘子尾约束）**：完整二人博弈形式——检验自适应强度是否优于固定 β（对位 v2 单臂"无介入"与联合臂"欠抑制"两极之间的中点）。

与近邻的区别（查重义务不变，冻结前联网核）：PBR/CBRS 推回类用随机或全部旧任务样本；A-GEM/L6 用梯度投影保均值参考；本方案的约束对象是**当年已到达数据内旧模型最高分良性尾＋分位数代理**，与修复候选 R_t 对偶构造（同一 θ⁻、互补标签）。此区别须在实现前文献查重确认未被覆盖。

**E1 判决（2026-09-09）：尾锚 T 形态取消，机制假说改述。** E1 oracle 尾锚上界检验（修正版，响应[只读审查报告](LAMDA 双玩家 v2 与良性尾部修复：只读审查.md) §2.4 的未答问题）已完成，制品与脚本见 §2 P11。结果：被打坏的良性（n₊）不在冻结高分尾内——T_keep 覆盖 n₊ 仅 8.8%/2.9%（K=500，2016/2017）、34%/11.8%（K=2000）；即使 oracle 完美保护（尾集预测钉回 ER 判定），裁剪后 FPR 仍 0.12–0.16，远超 ER 当年 FPR（0.0215/0.0066），任何 K 都过不了 ER 门。判读：损伤形态是**全局表征漂移**（与 P6"良性 P90 整体 0.025→0.844"读数一致），不是"薄尾被穿"。按 §7 停止条件第一行，**尾锚 V1/V2 不跑**。机制假说改述为：**修复损伤以全局表征漂移为主，局部尾保护（对冻结高分尾的分位数约束）上界不足**——候选方向从"约束谁"（安全玩家作用面）转为"限制修复的参数作用范围与深度"（受限参数修复 head-only，见 §8 L29）。

## 7. 通过 / 失败门（看到数据前冻结）

**主判据（统一指标，开发面板 2016–2018 pooled，相对同流 ER 锚）：**
1. ΔFPR ≤ 0 且 旧恶意负向翻转率增量 ≤ 0；
2. ΔFNR < 0 或 恶意正向修复率 > ER，且 ΔAP ≥ −0.002；
3. V2 另加机制有效性门：λ_tail 轨迹非平凡（年更新次数 ≥ 5 且对 A_t 扰动响应），乘子发散（任一年 λ > 10）即刻失败（P9 防线）。

**机制诊断（必报不判门）**：新增 FP 溯源比例（P6 口径）、尾内/尾外 FP 分解、修复样本与尾集的分数重叠带。

- **CUR 部件止损（槽位专用，P10）**：CUR 臂相对固定 margin 加权（现行 `L_mal-FN`）对照，若"新 FP 溯源比例"未降、或恶意修复率下降 >1pp，即摘除 CUR 部件；该止损不改变 §7 主判据与停止条件。

**停止条件**：
- **（已触发 2026-09-09，E1）** E1 oracle 覆盖不足——T_keep 对 n₊ 覆盖 8.8%/2.9%（K=500）、34%/11.8%（K=2000），oracle 裁剪后 FPR 0.12–0.16 仍不过 ER 门（0.0215/0.0066）→ V1/V2 不跑；判读为全局表征漂移而非薄尾被穿，原"分位数投影 / 自适应 K"同属尾内 K 形态候选一并停止，转向**受限参数修复（head-only，L29，见 §8）**；
- V1、V2 同败且良性高分区仍被抬穿 → "分数层固定参考约束"范式证伪，负结论入章，转表述层（分离输出头/排序目标），需重新过 `research-ideation` 链并用户裁决；
- 通过 → 冻结为算法 3-1，进入正式化前置（源期特征视图重建——发布 4561 维视图含未来协变量，正式主张前必须换，独立工程任务）。

## 8. 实验臂与验收（L29 受限参数修复，2026-09-09 定批）

**机制依据**：E1（§3）表明修复损伤为全局表征漂移——被打坏的良性不在冻结高分尾、oracle 尾保护上界不足，候选从"约束谁"（安全玩家作用面）转为**限制修复的参数作用范围与深度**：head-only 冻结骨干、仅更新分类头，使修复项无法在骨干层继续扰动全局表征。

四臂共享预算：

| 臂 | 内容 | 作用 |
| --- | --- | --- |
| ER2018 | D1 面板（2016–2018）首跑锚 | 共同基线，不做创新主张 |
| ER2018+修复 | 缺口修复（L3 形态）全参数更新 | 全参数历史对照（修复+表征漂移） |

## 9. 风险与边界声明

- 本方案的全部"空间"论据在 P1/P2（封印年与 Joint 间隙）；开发面板 2016–2018 仍可能过窄——若 ER2018 锚在 2018 年 AP 崩落（P1 外推），面板获得分辨率但也可能使"ΔFPR≤0"在崩盘年份变严。T1 原件逐年读数已核验并登记（见 [T1 核验登记](../../.Codex/docs/2026-09-09-LAMDA方案表格核验-T1/lamda-table7-table15-verification.md)）：表 7 无逐年分解（FAR 聚合 2018–2025）；表 15（Domain-IL CL F1 口径）2018 相对 2017 仅降 ≤2 点、不构成"2018 已明显退化"的表格级证据——面板在 2018 的分辨率收益须由 ER2018 实际运行验证，不得引用 P1 外推冒充实测。
- P10 的穿越代价只是**几何必要条件代理**：桶内单调上升部分是恒真性（缺口越深跨越良性分数带越难），信息量在量级与密度形态（91→5292 的跨度），不得写成"发现波及归因"或逐样本因果结论。
- P10 的 2017 分桶样本小（各桶 n=32–43），其证据力主要在 2016 与未来并入的 2018，不得单凭 2017 趋势作结论。
- **反课程现状**：现行 `L_mal-FN` 权重正比于缺口深度 d_i（§3 式 3-3），深度越大权重越大——与 CUR"浅缺口优先暴露"方向相反。CUR 若成臂，其干预内容就是把该加权方向反转（以 s_e 分位推进暴露顺序），臂描述必须写明这一现状对照，避免把"换权重方向"误写成"新增独立机制"。
- oracle E1 是必要非充分：train 尾与 test 尾同源性未证；若 V2 通过而覆盖曲线显示 train 尾对 test 新 FP 覆盖 <50%，须补"尾外波及"归因后才能晋级。
- 单一种子、screening_only、发布视图未来协变量披露，全部沿用台账统计边界。
