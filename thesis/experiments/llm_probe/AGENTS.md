# llm_probe 实验工程规则

<!-- 规则加载哨兵：NOTE_LLM_PROBE_20260724 -->

本文件只规定 `thesis/experiments/llm_probe/` 的实验工程增量。当前数据、候选、服务器、运行身份和数值合同从路线总控、章节恢复卡、冻结配置与制品读取，不复制进长期规则。

## 按需合同

- 修改、同步或运行 `scripts/` 前读取其 `AGENTS.md`。
- GPU、服务器、任务放置、容量、数据热路径、资源监测、下载、镜像、物化和检查工具读取 `.Codex/docs/agents-split/llm-probe-operational-contract.md` 的匹配章节。
- 修改神经模型、训练循环、精度、显存、`DataLoader`、推理或检查点时，先读 `$pytorch-patterns`、核验目标版本接口，再读 `.Codex/docs/agents-split/llm-probe-neural-training-contract.md`；同族比较使用同一冻结 profile。
- 外部制品、冲突、SwanLab、枚举、恢复、包哈希、冻结合同、模型视图和历史故障读取 `.Codex/docs/agents-split/llm-probe-failure-prevention-handbook.md`；事故反例不在本文件重复。
- 新增需注册的机器学习组件才用 `architecture-design`。同一问题连续两次无进展即停止同类补丁，改核验目标版本官方文档、源码和问题记录。

## 数据合同与最终测试隔离

- 划分须按主体和真实泛化轴互斥，时间仅在其为泛化轴时使用；标签只取冻结字段，特征、路径、提示、元数据和后处理不得泄露标签、攻击名或切分身份。
- 最终测试在方案、字段、解析器、阈值、批量、停止条件和超参数冻结前不可见，不得用于选择、诊断或修复。阈值须按可观测的并列概率组整体选择，并在源验证重新计数假阳性。
- 新增或修改数据视图、物化器、加载器或模型适配器前，冻结生产端与全部消费者共享的模式版本、主键、切分、标签连接、字段、历史表示、制品清单和兼容策略；统一清单与加载器服务传统模型、神经基线和候选，禁止模型专用重复物化。
- 阈值冻结的源验证须持久化逐样本概率、样本键、序列位置和哈希；双池或配对合同记录池规模和每轮抽取量。
- 正式比较、候选与消融遵守共同预算、字段权限、精度、主体和泛化轴隔离。`engineering_only`/`screening_only` 仅用于实现、速度或信号，仍须遵守数据标签合法性、真实性、唯一身份和原子恢复；结果不得进入论文、表格、帕累托或优劣主张，拟晋级结论必须以独立正式身份按冻结公平合同重跑，且不得削弱正式基线。

## 数据集－模型适配硬门

- 新骨干、机制或适配器在编码前冻结“数据集－模型适配表”，登记可用字段、训练区拟合变换、因果与主体边界、标签/损失、模型接口、参数量和版本哈希；表未完成不得启动正式身份。
- 适配、拟合、候选选择和封印只能使用冻结训练与开发区，最终评价零参与；模型和表示须适应真实数据，不得用默认扁平输入或削弱强基线绕过接口缺口。无法冻结字段处理、因果或接口合同即停在适配阶段。

## 实现验证与真实运行

- 不创建或运行人工夹具、单元/集成/独立冒烟实验，也不用合成数据或真实最小子集判断性能；生产代码经相关语法、导入、静态或 CLI 检查即进入冻结开发区真实实验，禁止 `black` 和未经当轮授权的自动格式化。可用有构造真值或解析解的合成输入检验公式与指标性质，但不得创建 SwanLab 或正式编号，产物放临时目录并清理，不进论文。
- **本机唯一实验环境**是 `/opt/miniconda3/envs/rwkv/bin/python`：所有实验、Parquet 扫描、训练、评价、数值诊断与 MPS 均只用它。禁止 `/opt/miniconda3/bin/python`、系统 `python`/`python3` 和项目 `.venv` 用于本机实验。实测版本为 Python `3.14.5`、torch `2.12.0`、numpy `2.4.6`、scipy `1.18.1`、scikit-learn `1.9.0`、pyarrow `25.0.1`、pandas `3.0.5`、polars `1.44.1`、transformers `5.16.1`、tokenizers `0.23.2`、swanlab `0.9.0`，沙箱外 MPS 可用；另有 `tqdm`、`torchinfo`、`matplotlib`、`seaborn`。依赖只用 `uv pip install --python /opt/miniconda3/envs/rwkv/bin/python` 补齐并记录版本收据，不新建第二实验环境。
- 服务器正式训练、评价和物化仍按服务器合同，以 `source tools/env/activate.sh` 后的 `uv run --no-sync` 运行；本地文献混合检索的 uv 项目仅作检索工具，不得与本机实验环境混用。两端工具、公式、接口、指标和检查点模式一致，MPS 权重不得续训或冒充正式 CUDA 权重。
- 正式入口对代码、数据、配置、哈希、设备、跟踪平台、标签和运行目录作运行时断言；失败保留脱敏日志和原退出码。相互独立变体在只读数据、独立输出与跟踪身份、资源安全时默认并行；共享可变制品、资源或 I/O 不足时才串行并记录原因。
- 并发条件下的性能与工程指标可进入正式实验表，但收据须记录并发对象、时间窗口、`resource_contention=true` 与采样来源，时间、吞吐和峰值资源标为“并发条件实测”，不得冒充独占效率或用于严格效率支配；确认无数值漂移者可作正式值，资源公平比较须在正文加脚注说明并发条件或补做独占复测。本规则不削弱数据隔离、结果真实性、唯一运行身份和原子断点恢复。
- 长任务使用唯一运行身份、持久状态、检查点、原始日志和幂等完成判断；删除运行制品按根规则列出精确路径、确认可恢复并取得用户明确授权，禁止通配符递归删除和删除唯一证据。

## 门禁密度与恢复

- 只有数据或标签合法性（含泄漏、主体与泛化轴隔离、最终测试隔离）、代码与配置身份、硬资源安全，或原子断点恢复不能成立时，门禁才可阻断实验。不得以本节任何条款削弱这些硬门。
- **默认不新增阻断门。** 新增任何 `raise` 或非零 `exit` 前，先证明它防止的是会使结果无效的真实失败，并在实施计划或故障手册写明该失败、权威输入（冻结配置、身份清单、资源实测或已发布断点）、正式入口的验收位置和失败后的保留恢复行为。证明不成立即改为披露；独立静态门、历史数值一致性和未验证推测不得充当阻断依据。
- **同一门连续两次拦下本可正常进行的实验，即判为冗余，立即废弃或降级为披露，不必复审。**
- **禁止用多个门检查同一件事。** 新增前核对既有门是否已覆盖，重复的一律不加；具体事故与处置只读故障手册。
- **披露优先于阻断。** 并发、资源争用、非独占、重复静态检查、格式检查、非关键诊断、归档和非阻断复审只写收据并打印，不阻塞已通过硬门的实验。并发或资源门须按实际子进程、进程组或运行身份排除自身启动器与监控进程，不依赖 `ALLOW_CONCURRENT` 放行。
- **三类不可废弃，因为它们是事实记录而非门禁**：主体与泛化轴隔离及最终测试隔离、`training-identities.json` 的训练身份漂移检查、`code_sha256` 等代码身份冻结。删除它们不会让实验更顺，只会让结果无法解释。
- 优先执行能证伪假设的最小真实实验并以最小实现推进，不为未证实的收益预建体系；新增抽象、配置或制品须说明相对复杂度的具体收益与权威依据。
- 同一门在同一动作中最多执行一次；中断后由同身份原子断点恢复，不重跑已完成阶段来重复门禁。已封印清单登记的用途令牌由正式入口注入，禁止要求操作者重复配置或回显令牌。

## SwanLab、日志与写回

- 正式 GPU 实验用 SwanLab 在线模式，项目和运行身份来自总控或冻结配置。任何上报入口在创建运行、启动持久会话或读数据前机械断言工作区与项目名等于用户本轮授权，不一致即停止并用新身份修正。
- 唯一运行目录保存配置、环境、数据摘要、控制台与 SwanLab 日志、逐步指标、结果、预测和制品清单；失败也保留状态和原因。云端日志不能替代本地原始日志。
- 预计超过 1 分钟的构建、物化、训练、评估、下载和启动器记录各阶段开始、结束、跳过与状态转换；限频心跳含已处理量、总量、吞吐、耗时和剩余时间估计。超周期无进度时记录阻塞阶段、等待和恢复动作，不逐样本刷屏，不记录凭据或敏感载荷。
- 交付前用真实运行或最小命令入口确认关键阶段日志、心跳或快速完成记录、持久化路径和失败保留行为；每次运行核对云端指标与图表，记录服务端路径、本地回收路径和运行地址。
- 新裁决、确定结果、路径和错误先写 `.Codex/docs/` 详细记录，再按当前路线规则更新总控或章节恢复卡；可复用故障模式写入既有故障手册，不扩写本文件。
