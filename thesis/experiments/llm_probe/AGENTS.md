# llm_probe 实验工程规则

<!-- 规则加载哨兵：NOTE_LLM_PROBE_20260724 -->

## 按需合同入口

- 修改、同步或运行 `scripts/` 前读取 `scripts/AGENTS.md` 和 `.Codex/docs/agents-split/remote-script-execution-contract.md`，正式远程操作只用统一启动器。
- 服务器切换、硬件降级、下载、镜像、资源监测、Rust 物化、生成评测和检查工具读取 `.Codex/docs/agents-split/llm-probe-operational-contract.md` 的匹配章节。
- 外部制品、远程载荷、任务冲突、SwanLab 故障、包哈希、冻结合同、模型视图、PINN 指标、TCP 配对或 ns-3 故障读取 `.Codex/docs/agents-split/llm-probe-failure-prevention-handbook.md` 的匹配章节。
- 新增需注册的机器学习组件才使用 `architecture-design`；版本控制任务才使用 Git 技能。
- 同一缺陷、协议合同或外部依赖连续两次修复无可验证进展时，停止同类补丁并核验版本匹配的官方规范、文档、源码和问题记录；第三次修复必须基于新证据形成单一可证伪假设，且不阻塞无关实验。

## 服务器、GPU 与凭据（强制）

- 当前服务器和凭据键只从所属路线总控读取；密码、令牌、连接地址及解析值不得打印、回显或写入配置、日志、URL、清单、文档和汇报。
- 服务器离线、切换或回收后停止自动重试且不计为科学失败；新环境先只读核验身份、根目录、磁盘、依赖、源码锁、数据和制品，不沿用旧进程假设。
- GPU 训练、推理、生成评测、显存兼容或加速测试前，告知用户任务、预计时长、显卡与卡数、显存、开机和费用需求，确认可用后才执行。
- 默认本机执行 CPU 开发、复审、物化、哈希、统计、报告和传统基线，服务器只执行 GPU 工作及必要加载和日志；例外须获用户明确许可。
- 磁盘达到 80% 或可用不足 10 GiB 时通知用户；达到 90% 或不足 5 GiB 时停止新增大型文件和下载。

## 数据与最终测试隔离（强制）

- 冻结划分按样本、会话、时间或场景验证互斥，标签只取自冻结字段；提示、特征、路径、元数据和后处理不得泄露标签、攻击名或划分身份。
- 最终测试在方案、字段、提示、解析器、阈值、批大小、停止条件和超参数冻结前完全不可见，不得用于选择或修复方案。
- 数据路径、样本数、模型和物化语义以当前路线总控、冻结合同、配置与制品收据为准，不复制到长期规则。

## 正式运行、同步与复审

- 精确目标测试通过后，不以无关完整测试、重复检查、格式化或非阻断复审延迟正式实验；审查并行并标记 `review_pending`，发现影响有效性的严重或重要问题时立即停止并作废结果。
- 正式包装器必须对代码、数据、配置、哈希、设备、SwanLab、标签和运行目录执行运行时断言；失败即保留日志并结束。
- 远程同步只允许白名单相对路径并核对 SHA-256，禁止 `rsync --delete`；服务器不得保存唯一代码、数据合同或结果副本。
- 长任务使用唯一运行身份、持久状态、检查点和原始日志恢复；阶段门禁完成后及时回收源码、配置、清单、日志、检查点和结果。
- 删除前列出精确路径并确认已有本机、可重下或私有备份；原始或冻结数据、检查点和日志必须另获用户明确授权，禁止通配符、上级递归和删除唯一证据。

## SwanLab、日志与结果写回（强制）

- 正式 GPU 实验使用 SwanLab 在线模式，项目与运行身份从当前路线总控或冻结配置读取；唯一运行目录保存配置、环境、数据摘要、控制台与 SwanLab 日志、逐步指标、结果、预测和制品清单，失败也保留状态与原因。
- 每次运行核对云端运行、指标点和图表，记录服务端路径、本地回收路径和运行地址；云端日志不能替代本地原始日志。
- 新裁决、确定结果、路径和错误先写 `.Codex/docs/` 详细记录，再只更新当前路线总控；不得跨路线写入另一套恢复文档。
- 完成根因定位和最小验证后，把可复用触发条件、根因、检查与验证写入故障手册，但不得阻塞已通过门禁的实验。
