# 远程启动与脚本规则

<!-- 规则加载哨兵：NOTE_LLM_PROBE_SCRIPTS -->

本文件只规定 `scripts/` 的增量规则。修改、同步或运行前读取 `.Codex/docs/agents-split/remote-script-execution-contract.md` 的匹配章节。

- 远程操作可用 SSH、持久化脚本或现有启动器，以步骤少、保留退出码、状态和日志为准；复杂多行任务写入项目内脚本，避免不可复现的多层引号。
- 明确同步源与目标，禁止 `rsync --delete`；状态、检查点、日志和制品须持久化，不依赖 `screen` 套接字，也不把唯一辅助脚本或清单放入 `/tmp`。
- 管道前创建日志目录；关闭 `errexit` 时立即保存完整 `PIPESTATUS`，分别检查主命令和 `tee`，失败保留原始退出码与脱敏日志。
- 正式训练、评估和物化使用 `uv run --no-sync`；依赖变更在启动前单独完成并核验，禁止正式进程自动解析环境或让并行运行争用同一虚拟环境。
- Shell 脚本只在交付、审查或提交前集中一次运行 `bash -n`；`0644` 包装器用 `bash` 启动。
