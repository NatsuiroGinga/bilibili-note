## 3.5 理论分析

本节分析 3.3 节所给两个配置量在预算约束下的性质。记 $G(N, B_\theta)$ 为保留 $N$ 条历史样本并给参数侧分配 $B_\theta$ 比特时，模型在末年对全部已到达年度测试分片的平均 F1。

### 3.5.1 预算分配的最优性条件分析

两个配置方向的第一条性质来自预算约束的形式。将式 (3-1) 与目标 $G$ 合写为约束优化问题：

$$\max_{N,\,B_\theta}\; G(N, B_\theta) \quad \text{s.t.} \quad dN + B_\theta \le B,\;\; N \in \mathbb{Z}_{\ge 0},\;\; B_\theta \ge 0 \tag{3-7}$$

分析需要两条关于 $G$ 的假设。第一条是单调性：$G$ 对 $N$ 与 $B_\theta$ 均不减。第二条是凹性：$G$ 沿每一维近似凹，即边际增益递减。两条假设在实测曲线上均有对应，其适用范围由 3.6 节的对照实验界定。

**命题 3-1（等边际条件）** 设 $G$ 在最优解处连续可微，且最优解位于可行域内部。则必然有 $dN^{*} + B_\theta^{*} = B$，且存在乘子 $\mu \ge 0$ 使

$$\frac{1}{d}\frac{\partial G}{\partial N}(N^{*}, B_\theta^{*}) \;=\; \frac{\partial G}{\partial B_\theta}(N^{*}, B_\theta^{*}) \;=\; \mu \tag{3-8}$$

**证明** 约束不取等时，因 $G$ 沿两条方向均不减，可增加任一变量而不违反约束，与最优性矛盾，故预算耗尽。取拉格朗日函数 $L(N, B_\theta, \mu) = G - \mu(dN + B_\theta - B)$，在内点处的驻条件为 $\partial G/\partial N = \mu d$ 与 $\partial G/\partial B_\theta = \mu$，消去 $\mu$ 即得式 (3-8)。$\square$

式 (3-8) 的读法是每单位比特在两条通路上的边际收益相等。$N$ 为整数时，以连续化解取相邻两个整数中较优者，凹性保证该取整损失的绝对值不超过一段边际差。

**命题 3-2（角点条件）** 若在样本侧用尽预算的状态下，参数侧的单位比特边际收益不超过样本侧，则 $B_\theta^{*} = 0$ 为最优解，即预算全部投给样本侧。

当参数侧只能以量化后的完整权重块为最小粒度时，上述条件退化为一条更简单的判据。记参数侧的可用粒度集合为 $\mathcal{Q}$，对应包价为 $|\theta| q$ 比特，其中 $|\theta|$ 为参数量。若预算低于最小包价，参数侧无法形成任何可用增量，此时全给样本侧是唯一非零解，无需比较边际。

**命题 3-2 的意义**在于它把「要不要给参数侧分配预算」这个问题转成了两个可实测量的比较：样本侧的单位比特边际，与参数侧单位比特的边际。3.6 节给出这两者的实测比值。

### 3.5.2 有限容量下正例覆盖的概率界

第二条性质来自缓冲构成的随机性。官方协议采用全局蓄水池抽样：每年度样本到达时，缓冲未满则直接收入，已满则以等概率决定是否替换某个已有槽位。设到第 $t$ 个年度末已见 $M_t = \sum_{s \le t} n_s$ 条训练样本。

**引理 3-1（份额期望）** 缓冲中第 $s$ 个年度的样本数 $N_s$ 满足

$$\mathbb{E}[N_s] = n_s \cdot \frac{N}{M_t} \tag{3-9}$$

**证明** 蓄水池抽样下每条流样本最终留在缓冲内的概率均为 $\min(1, N/M_t)$，同年度样本相互独立，故期望为样本数与保留概率之积。$\square$

**⇒ 引理的形式确立了 3.3.2 节所述现象**：按样本量成比例的抽样使各年度的期望份额与其样本量成正比，与类别比例无关。

**命题 3-3（正例覆盖的缺失概率）** 设第 $s$ 个年度的训练正例率为 $p_s$，年度样本量占比为 $\pi_s = n_s / M_{12}$。缓冲中该年度样本数近似服从参数为 $N\pi_s$ 的 Poisson 分布，正例数因而近似服从

$$\Lambda_s(N) \sim \text{Poisson}\big(\lambda_s(N)\big), \qquad \lambda_s(N) = N\,\pi_s\,p_s \tag{3-10}$$

缓冲完全不含该年度正例的概率为

$$\Pr[\Lambda_s(N) = 0] = e^{-\lambda_s(N)} \tag{3-11}$$

由式 (3-11)，使某一年度正例的期望数量达到 1 所需的容量为

$$N_c(s) = \frac{1}{\pi_s\, p_s} \tag{3-12}$$

**式 (3-12) 给出了本章最直接的一条容量判据。** 由于正例率在末期年度急剧下降而年度样本量占比变化有限，$N_c$ 在末期年度上迅速增大。当某年度的 $p_s$ 小到使 $N_c(s)$ 超过预算所允许的容量上限时，该年度的正例在缓冲中期望数量低于 1，其表示在该预算下不可恢复。

式 (3-12) 同时给出容量作用的边界。容量增加至 $N_c$ 之前，$\lambda_s$ 低于 1，正例数量波动的相对幅度很大；容量超过 $N_c$ 之后，正例数量才进入相对稳定的区间。因此容量的边际收益在 $\lambda_s$ 跨越 1 的邻域内变化最快。

### 3.5.3 末年缺口的两级分解与幂律特征

**定理 3-1（缺口的精确分解）** 末年缺口可按年度集合精确分解。记九年集合为 2013 至 2022，三年集合为 2023 至 2025，二者基数分别为 9 与 3。以 $G_9$ 与 $G_3$ 分别表示模型在这两个集合上测试分片的平均 F1，则

$$\underbrace{G_{\text{Joint}} - G(N)}_{\text{总缺口}} = \frac{9}{12}\underbrace{\big(G_9^{J} - G_9(N)\big)}_{\text{漂移负迁移缺口}} + \frac{3}{12}\underbrace{\big(G_3^{J} - G_3(N)\big)}_{\text{枯竭年覆盖缺口}} \tag{3-13}$$

**证明** 末年平均为 12 个年度 F1 的算术平均，按集合分组即得该恒等式。$\square$

**定理 3-1 的价值在于把总缺口拆成两个可在数据上分别追踪的通道。** 实测两者的行为差异显著：九年通道在容量由 0 增至 50 条时即大幅收窄，而三年通道在容量增加约两个数量级后仍仅收窄过半。前者对应漂移年份上决策边界的负迁移，后者对应末期年度正例的物理稀缺，与式 (3-12) 的描述一致。

**命题 3-4（缺口的幂律特征）** 总缺口随容量的下降可由幂律拟合：

$$G_{\text{Joint}} - G(N) \;\approx\; a\,N^{-\alpha} \tag{3-14}$$

在实测的六个容量点上，该拟合给出 $\alpha$ 约在 0.23 至 0.24 之间，其取值明显低于独立同分布条件下估计误差的 $N^{-1/2}$ 速率。

**该指数的读法需要谨慎。** $\alpha < 1/2$ 说明缺口的下降慢于统计估计误差的下降速率，与「缺口由结构性覆盖缺失主导而非由估计误差主导」相容；但它并不排斥其他来源，例如两个通道的加权合成本身也会产生偏离单一速率的整体指数。因此本章把式 (3-14) 作为描述性刻画，而非作为机制判定依据。

### 3.5.4 复用配置的保持与适应权衡分析

第三条性质来自式 (3-6) 中权重 $\lambda$ 的作用。对每轮更新取梯度，得

$$g = (1-\lambda)\,g_{\text{new}} + \lambda\,g_{\text{mem}} \tag{3-15}$$

**命题 3-5（有效适应步长）** 记 $g_{\text{new}}$ 与 $g_{\text{mem}}$ 的余弦相似度为 $\rho$，二者范数之比为 $\kappa$。梯度沿新年度下降方向的投影为

$$\langle -\Delta\theta,\, g_{\text{new}} \rangle = \eta\,\|g_{\text{new}}\|^2\,\big[(1-\lambda) + \lambda\,\rho\,\kappa\big] \tag{3-16}$$

定义有效适应步长为括号内的量：

$$a(\lambda) = (1-\lambda) + \lambda\,\rho\,\kappa \tag{3-17}$$

**证明** 一次更新给出 $\Delta\theta = -\eta[(1-\lambda)g_{\text{new}} + \lambda g_{\text{mem}}]$，与新梯度作内积并按 $\rho$ 与 $\kappa$ 的定义整理即得式 (3-16)。$\square$

**式 (3-17) 说明适应能力随 $\lambda$ 的走向取决于两个梯度是否同向。** 当 $\rho\kappa < 1$ 时，$a(\lambda)$ 随 $\lambda$ 递减：历史梯度对新年度更新的抵消作用超过其助推作用，模型对新数据的适应能力随历史权重上升而下降。

**命题 3-6（保持能力的上界）** 记 $R(\lambda)$ 为模型在历史年度上的检测能力。当 $\lambda$ 增大时 $R$ 单调不减，但其上界受缓冲样本量的限制：

$$R(1) - R(0) \;\le\; \varepsilon(N) \qquad \varepsilon(N) = O\!\left(\sqrt{\frac{d}{N}}\right) \tag{3-18}$$

**证明思路** 缓冲上的经验损失是其年度真实损失的有限样本估计。取 $\lambda = 1$ 时模型收敛到该经验损失的最小点，其与真实损失最小点的距离由一致收敛界控制，该界随 $N$ 以 $O(\sqrt{d/N})$ 收缩，将两者代入真实损失即得式 (3-18) 的形式。$\square$

**命题 3-7（内部最优与最优复用倍数）** 由命题 3-5 与命题 3-6，目标随 $\lambda$ 的变化由两项合成：保持项 $R(\lambda)$ 在 $\lambda$ 增大时上升并趋于饱和，适应项由式 (3-17) 在 $\rho\kappa < 1$ 时随 $\lambda$ 下降。两者方向相反且一者饱和、一者不饱和，故存在内部最优点 $\lambda^{*} \in (0, 1)$，满足一阶条件

$$\frac{dR}{d\lambda}\bigg|_{\lambda^{*}} = -\frac{dA}{d\lambda}\bigg|_{\lambda^{*}} \tag{3-19}$$

代入式 (3-5) 的 $\lambda(m, N) = mN / (n_t + mN)$，其关于 $m$ 单调递增且以 1 为上界，故最优复用倍数

$$m^{*} = \frac{\lambda^{*}\, n_t}{(1-\lambda^{*})\, N} \tag{3-20}$$

**式 (3-20) 给出本节最具判别力的一条推论：最优复用倍数与缓冲容量成反比。** 缓冲中互不相同的样本越少，需要越高的重复次数才能把历史权重抬到同一水平；反之，容量充足时最优复用倍数应接近 1。该推论同时解释了两条通路为何不能独立看待——它们通过 $\lambda$ 共同决定历史信息的有效强度。

式 (3-20) 也给出容量的第二重作用。由命题 3-6，容量不仅决定保持能力的上界，还决定达到最优历史权重所需的复用倍数。容量越小，为使 $\lambda$ 达到 $\lambda^{*}$ 所需的 $m$ 越大，而由命题 3-5，过大的 $m$ 又会使适应能力下降更快。两条作用合成后，容量存在一个使配置效率最高的区间，该区间的实测位置由 3.6 节的对照实验确定。
