# 正式论文章节规则

本文件只规定 `thesis/chapters/` 的正文写作和定稿增量，不裁决研究路线、数据合同、候选存废或实验状态。

## 文件与范围

- 本目录是正式章节唯一目录；文件使用 `NN-中文章节名.md`，范围为 `00-摘要.md` 至 `06-总结与展望.md` 及 `参考文献.md`。不得在 `thesis/` 根或其他目录创建第二份正式正文。
- 历史草稿迁入或目录调整不等于采纳其研究路线。写作前按根规则恢复当前路线，只从对应总控、章节恢复卡和冻结合同确定内容。
- Claude Scholar 等技能只提供写作和证据治理，不得重排中文学位论文章节、改变论断状态或套用 Nature、会议 LaTeX 等英文投稿模板；明确英文投稿或真实审稿任务除外。

## W0-W5 写作门禁

1. `W0 范围恢复`：读取当前路线总控、章节恢复卡、数据合同和本次章节边界；将内容标为“设计可行、实验待证、实验支持、实验否决”。
2. `W1 论断台账`：每个主张登记允许表述、禁止强化、证据状态、配置或制品、图表和引用；无证据时保留待证占位，不润色成有效。
3. `W2 结构论证`：`paper-miner` 只提取已读全文的结构与论证模式；全局写作记忆不能充当本论文证据。
4. `W3 方法协议`：只依据冻结接口写问题、输入输出、算法、假设和边界；方法图只说明结构，不暗示性能。
5. `W4 结果接入`：按“问题、原始表图、指标口径、可支持解释、适用边界”写作；只有正式实验制品满足门禁后才写“实验支持”。
6. `W5 引用语言`：反向核验正文、图表、制品和限定词后再修订语言；`writing-anti-ai` 只能删冗余和改句法，不得改变术语、数值、引用、限制或论断状态。

## 写作链与图表

- 结果写作顺序为 `results-analysis`、`results-report`、`paper-miner`、`ml-paper-writing`、`citation-verification`、`writing-anti-ai`、`paper-self-review`。前两步没有分析制品时，结果只能标“实验待证”。
- 图型与配套表先用 `publication-chart-skill`，渲染、命名、落点和 `图件清单.json` 按 `thesis/AGENTS.md` 的学位论文图件合同，不在本层另设宽度、分辨率或字体。
- 写作、引文整理和排版不得阻塞已满足门禁的真实实验；正文只链接或概述核验结果，不复制长日志。

## 章节定稿自审

每章写完、进入下一章、合稿或交付前必须执行 `paper-self-review`，报告写入 `.Codex/docs/`。六项逐项给出通过或不通过，阻断项关闭后才算定稿：

1. 结构完整性：小节齐备、层级符合规范、编号连续。
2. 逻辑一致性：问题与方法匹配，实验支撑假设，结论不越出实验范围。
3. 论断审计：按 `Claim Audit` 将主张裁为保留、弱化、改写或删除；无法指向制品或全文证据的一律弱化或删除。
4. 引用完整性：正文序号与参考文献一一对应，无占位残留；本项不替代题录与原文核验。
5. 图表质量：题注、正文引用、编号、目录、图件清单和父级图件合同一致。
6. 写作质量：按章节规范检查段落、肯定性断言和禁止项。

自审以学校排版模板和中文学位论文为准，不要求独立“局限性”小节；边界用中性措辞写入本章小结。自审不能替代统计分析或引用核验。
