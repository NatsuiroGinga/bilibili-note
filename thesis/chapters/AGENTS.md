# 正式论文章节规则

本目录是论文正式章节的唯一目录，继承 `thesis/AGENTS.md` 与仓库根规则。本文件只规定正文写作、证据和图表边界，不裁决研究路线、数据合同、候选存废或实验状态。

## 章节与历史边界

- 正式章节文件使用 `NN-中文章节名.md`：`00-摘要.md` 至 `06-总结与展望.md`，以及 `参考文献.md`。不得在 `thesis/` 根或其他目录创建第二份正式章节正文。
- 当前第三、四章文件是从历史 PINN 草稿原样迁入的工作稿。目录迁移不等于采纳 PINN 路线，也不替代 RWKV 总控、候选登记册或后续实验裁决。
- 朱焱雷论文第三、四、五章只作章级组织参照：单章单问题、章内多机制协同、理论与实验共同支撑，以及篇幅、公式、算法、图表和实验论证的工作量尺度。不得复制其机制、公式、算法、数据、数值、图表、结论或连续表述。
- Claude Scholar 只提供写作工具链和证据治理，不得重排既定中文学位论文章节，也不得套用 Nature 或会议投稿模板。

## W0-W5 写作门禁

1. `W0 范围恢复`：读取当前路线总控、候选登记册、数据合同和本次章节边界。将内容标为“设计可行、实验待证、实验支持或实验否决”。
2. `W1 论断台账`：每个主张必须对应允许表述、禁止强化、证据状态、配置/日志/制品、图表/表格和引用。无证据时保留待证占位，不得润色为有效。
3. `W2 结构与论证`：可用 `paper-miner` 仅提取全文论文的结构与论证模式。当前不使用禁用的 `/mine-writing-patterns` 入口；全局写作记忆不能充当本论文证据。
4. `W3 方法与协议`：只依据冻结接口写问题定义、输入输出、算法、假设和边界。方法图只能说明结构与协议，不得暗示性能。
5. `W4 结果接入`：按“问题、原始表图、指标口径、可支持解释、限制”写作。快速筛选只能进入过程记录；只有正式实验制品满足门禁后才可写“实验支持”。
6. `W5 引用与语言`：先反向核验正文、图表、制品和限定词，再进行语言修订。`writing-anti-ai` 只能删冗余和改句法，不得改动术语、数值、引用、限制或论断状态。

## 证据、引用与图表

- 证据路径固定为：`raw/` 原件 → `wiki/` 全文笔记与核验 → 本目录正文。引用需同时核验书目信息与该句主张的原文支撑位置；未核验的引用使用占位，不从记忆生成条目。
- 正文只能吸收配置、数据版本、原始日志、指标程序和正式制品支持的结论。实验待证、候选机制、快速筛选、方法示意图和历史结果不得写成方法有效。
- 最终图件与可编辑源统一存放在 `../figures/第N章/`，命名为“图N-M-中文说明”。正文从该目录引用最终图件，不引用 `runs/`、`output/` 或临时目录图片。
- 图题和结果段必须说明数据版本、切分、比较对象、指标口径、样本量或统计口径及适用边界。

## 工具顺序与不阻塞原则

- 完整链路为：`results-analysis` → `results-report` → `paper-miner`（仅提取结构与论证模式）→ `ml-paper-writing` 的论断门与证据优先原则 → `citation-verification` 核验 → `writing-anti-ai` → `paper-self-review`。前两步未产出分析制品时，结果只能写「实验待证」，不得写入 `W4 结果接入`。
- 图件与结果表先用 `publication-chart-skill` 定图型、信息密度与配套表，渲染规格按根 `AGENTS.md` 的「学位论文图件合同」执行：最大宽 `155 mm`、中文黑体、图内最小 `8 pt`、`PDF` + `PNG` 600 dpi、灰度可读、重写 `图件清单.json`。历史 `180 mm` 与 Hiragino Sans GB 已判定为缺陷，不再沿用。落点与命名仍为 `../figures/第N章/` 与「图N-M-中文说明」。
- `nature-writing`、`nature-polishing`、`nature-response`、`nature-data` 和会议 LaTeX 模板当前不用于中文学位论文正文。仅在明确的英文投稿或真实审稿场景下按需启用。
- 写作、引用整理和图表排版不得阻塞已满足数据与运行门禁的真实实验；正文只记录已核验结论，不复制长日志。
- **每章定稿后必须执行 `paper-self-review`，这是链路的最后一步，也是硬门禁。** 未出自审报告的章节记为「未定稿」，不得据其内容更新路线总控，不得作为后续章节的既定前提，也不得进入合稿。六项检查内容、与上游技能的三处差异、以及报告落点见根 `AGENTS.md`「章节定稿自审门禁」。其中论断审计一项最关键：**凡无法指向具体制品路径或已核验文献的主张，一律弱化或删除**。
