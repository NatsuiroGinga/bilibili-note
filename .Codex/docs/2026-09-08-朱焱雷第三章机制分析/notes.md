## 原文证据摘要

### 问题链

- 第二章先把传统 `Min-Max` 的病灶拆为收敛震荡、鲁棒性与自然准确率失衡、计算开销三项；第三章只承接前两项，第四章处理开销。证据：印刷第 16 页，全文第 585 至 595 行；第三章印刷第 23 页，全文第 760 至 766 行。
- 第三章把防御者先部署、攻击者后响应映射为 Stackelberg 时序，并令最优扰动成为参数的隐函数。证据：印刷第 24 页，全文第 806 至 822 行。

### 方法家族与任务化改造

- DS 来源于课程学习与课程对抗训练；论文明确引用 Bengio、Cai、Zhang，并沿用“早期小扰动或少步数、后期增强”的家族思想。证据：印刷第 18 页，全文第 660 至 675 行。
- DS 的任务内改造是同时调度扰动半径、攻击步数与步长，并将其解释为流量伪装强度。公式（3.4）至（3.6），印刷第 26 至 27 页，全文第 843 至 904 行。
- RGO 来源于 Stackelberg 双层优化、展开优化和 Hessian 向量积家族。论文把反应函数、全导数和内层展开称为第三章核心支撑。证据：印刷第 16 至 18 页，全文第 615 至 658 行。
- RGO 的任务内改造是把分类器设为领导者、流量伪装扰动设为跟随者，并在嵌入空间或像素空间适配扰动约束。证据：印刷第 24、31 至 32 页，全文第 806 至 822、1080 至 1172 行。
- 参考文献 [60] 的题名是生成对抗网络正则化，并非题名上可识别的 Stackelberg 展开优化论文；因此原文对 RGO 家族的直接来源标注不足。证据：全文第 629、658、2830 行。

### 两组件与联合方式

- 两者针对不同子病灶：DS 限制早期攻击强度以缓和起步震荡；RGO 修改外层更新方向以纳入攻击反应。原文把 DS 称控制模块、RGO 称核心计算引擎。证据：印刷第 25 页，全文第 835 至 849、906 至 910 行。
- 不是简单相加：公式（3.7）至（3.10）令 DS 输出的 `epsilon(t)` 进入 RGO 内层可行域；公式（3.13）至（3.14）令 `K(t)` 决定被展开并求导的攻击轨迹；算法 3.1 先算课程参数，再生成扰动和反应梯度。证据：印刷第 27 至 31 页，全文第 914 至 1077 行。
- 也不是逻辑上不可拆：作者明确构造 DS-AT 与 RGO-AT 两个单组件臂。因此更准确的描述是“共享同一双层攻击轨迹、存在定向依赖的可分组件”。证据：印刷第 42 页，全文第 1460 至 1476 行。
- 四格交互按百分点计算：BUPT-CNN 为 `64.9-56.5-60.2+55.6=+3.8`，ET-BERT 为 `75.8-66.2-69.8+63.5=+3.3`。作者只显式陈述 ET-BERT 总增益 `12.3` 超过单组件增益和 `9.0`。证据：印刷第 42 页，全文第 1476 至 1485 行。

### 创新声明主语

- 摘要将创新条目写成一个整体方法 DS-RGO，RGO 与 DS 是其内部动作。证据：摘要印刷第 I 页，全文第 88 至 90 行。
- 第一章研究内容仍以 DS-RGO 为单一主语。证据：印刷第 8 页，全文第 373 至 381 行。
- 章首提出整体 DS-RGO；方法节称两个核心功能模块；只有反应梯度路径 B 被字面称为“核心创新点”。证据：印刷第 23、25、29 页，全文第 760 至 766、835 至 841、985 至 989 行。
- 实验节以 DS-RGO 整体为主语，同时称 DS/RGO 为核心组件并检验独立贡献和相互作用。证据：印刷第 39 至 42 页，全文第 1404 至 1485 行。
- 章末仍以一个 DS-RGO 方法总结，先后叙述 RGO 与 DS；未把二者列为两个并列创新点。证据：印刷第 48 页，全文第 1561 至 1565 行。

### 支撑与弱项

- 主对比使用两个骨干、两个子集、干净准确率、PGD-20 鲁棒准确率和宏平均 F1；另给收敛曲线、长期鲁棒轨迹、四格消融、可视化、扰动强度与物理填充分析。证据：印刷第 36 至 48 页，全文第 1326 至 1559 行。
- DS 在 BUPT-CNN 上仅提升 `0.90` 个百分点，作者改写为“显著模型特异性”，并用 ET-BERT 的 `2.70` 支撑该归因。证据：印刷第 42 页，全文第 1476 至 1485 行。
- DS-RGO 的干净准确率低于 Standard：ET-BERT 两子集分别低 `2.0/2.1` 个百分点，BUPT-CNN 低 `1.7/1.9`；作者表述为损失控制在 `2.1%` 内。证据：印刷第 39 至 40 页，全文第 1410 至 1424 行。
- DS-RGO 前 8 个训练轮次因扰动受限而滞后，作者随后强调无回落与持续收敛。证据：印刷第 41 至 42 页，全文第 1454 至 1458 行。
- 章末承认计算开销巨大，并把该问题导向第四章。证据：印刷第 48 页，全文第 1563 至 1565 行。
- 摘要和章末的“较前沿基线提升 4.2% 至 8.6%”无法由表 3-5、3-6 的逐格最强基线差值直接复算；后者实际为 `3.3` 至 `4.8` 个百分点。缺少统计检验、置信区间和多次运行信息。

### 公式与实现内在矛盾

- 公式（3.12）至（3.15）和算法 3.1 要求保留 `theta -> delta* -> loss` 的反向路径；但 ET-BERT 适配段写内层冻结全部模型参数，外层又把 `delta*` 当常数。按字面执行时 `d delta*/d theta=0`，反应梯度不存在。原始 PDF 印刷第 28 至 32 页已目视核对，不是转换错误；全文第 970 至 1017、1067 至 1072、1120 至 1126 行。
- 公式（3.5）有 `1 -> floor(Kmax/2) -> Kmax` 三档攻击步数，算法 3.1 只有 `1 -> Kmax` 两档；原始 PDF 印刷第 26 与第 30 页已目视核对。全文第 869 至 881、1048 至 1053 行。
- 公式（3.6）用超参数 `eta`，算法输入写 `alpha_0`，执行却固定成 `2.5*epsilon_t/K_t`；三处参数定义未统一。全文第 890 至 898、1037 至 1053 行。
- 公式（3.27）含扰动 Hessian 逆，公式（3.15）直接换成带 `xi` 的混合导数项；论文只笼统称截断反传或一阶泰勒近似，未给出等价条件或误差界。全文第 991 至 1017、1238 至 1266 行。

## 对当前 Goal 的初步裁决

- 若“两个任务化算子 + 严格四格”被当作所有第三章候选的先验结构，属于误读。朱论文的创新主语是整体方法，组件数量来自其问题分解，不是章法硬指标；四格是对已有两组件的验证设计，不是产生创新的规则。
- 应保留：强基线病灶先行、成熟家族溯源、任务化差量、最终多组件的独立开关、共同底座消融、联合项优于单项的证据要求。
- 应改写：允许一个不可约任务机制独立成章；只有最终方法确有两个可独立开关因素时才要求 `2x2`；“两个机制”从数量硬门改为条件性实验合同。
- 应进入 RWKV 规则：不得机械凑两个机制；创新主语按整体方法裁决；先核对公式、算法与实际梯度路径一致；消融形状由真实可开关因素决定。
