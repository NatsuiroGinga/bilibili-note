# E2-A/S/P/X 种子 42 路线裁决

## 1. 当前结论

**状态：实验已裁决。唯一最终裁决为「进入唯一一次 E4」。** 四个变体已于 2026-08-07 全部完成 `200` 优化步，有效性门禁全部通过，因此结果有效、可以比较；但核心最低门禁失败。

- `ΔP,A = 0`、`ΔP,X = 0`、`ΔP,S = 0`。目标 C 的宏平均 F1、捕获组等权 F1、最差捕获组 F1、恶意召回率和良性误报率在 A/S/P/X 四个变体上**逐位相同**（`TP=8`、`TN=455`、`FP=52`、`FN=2437`）。真实共享守恒物理监督没有带来任何检测增益。
- 最差组非退化与源域非退化通过，`P` 的守恒残差和约束违反率也低于 `S`，因此可写「物理一致性改善」，**不得写「检测增益」**。
- 关键机制诊断：`E2-P` 与 `E2-X` 的物理目标差异比「是否启用守恒项」本身小约四个数量级（`physics/residual` 的 P−X 逐步平均绝对差 `5.15e-05`，而 P−S 为 `1.616`；`train/conservation_loss` 的 P−X 平均相对差 `0.105%`，`200` 步中仅 `1` 步完全相等）。置换对照在技术上是活的，但守恒残差几乎完全由模型自身预测状态与方程形式决定，与「哪条物理记录配给哪条流样本」基本无关，因此当前设计下的「真实物理 vs 置换物理」几乎没有因果分辨力。这是 E4 诊断必须优先解释的现象。

本报告在读取 S/P/X 结果前已固定比较指标和裁决规则，本次只填入既有制品结果，未改变数据、阈值、指标、门槛或评价样本。本轮只有种子 `42`，不运行种子 `43`、`44`，也不宣称统计显著性。

## 2. 比较问题

1. 真实共享物理约束 E2-P 是否优于无物理监督 E2-A？
2. E2-P 是否优于置换物理监督 E2-X，从而排除普通辅助正则化解释？
3. E2-P 是否优于仅状态监督 E2-S，从而证明守恒残差与边界项具有额外检测价值？
4. E2-P 是否保持源域表现，并在最差捕获组、校准、物理误差和训练成本上不存在关键退化？

## 3. 结果有效性门禁

四个变体必须同时满足：

- 使用同一运行根、输入绑定、种子 `42`、面板 `abd_to_c` 和七字段输入；
- `final_test_visible=false`，目标 C 不参与阈值选择或训练；
- 使用相同初始权重摘要、参数形状、可训练参数、优化步、检测批量和物理批量；
- 每个变体均有 `finished` 摘要、`200` 条优化指标、最终检查点、源域校准预测和目标 C 预测；
- 源域校准预测为 `22407` 条，目标 C 预测为 `2952` 条，四组样本顺序和标签一致；
- E2-X 具有合法的分层置换收据，且置换后物理监督确实改变；
- 指标均为有限数，阈值只由源域校准集按冻结网格确定。

任一项失败时，唯一裁决为 **结果无效**，不得比较方法优劣。

## 5. 冻结裁决规则

定义目标 C 宏平均 F1 差值：

\[
\Delta_{P,A}=F1_P-F1_A,\qquad
\Delta_{P,X}=F1_P-F1_X,\qquad
\Delta_{P,S}=F1_P-F1_S.
\]

### 5.1 核心最低门禁

- 必须同时满足 `ΔP,A > 0` 和 `ΔP,X > 0`。
- 任一差值不大于 `0`，不得宣称真实物理具有独特检测增益。

### 5.2 守恒增益

- `ΔP,S > 0` 才能宣称守恒残差与边界项相对单纯状态监督产生额外检测收益。
- 同时检查 P 的守恒残差与约束违反率是否低于 S；若检测不提升但物理指标改善，只能写“物理一致性改善”，不能写“检测增益”。

### 5.3 最差组与源域非退化

- P 的目标 C 最差捕获组宏平均 F1 不得低于 A 和 X。
- P 的源域校准宏平均 F1 与最差捕获组宏平均 F1不得低于 A。
- 若 P 仅提高目标总分但牺牲源域或最差捕获组，则不直接进入 E3，转入唯一一次 E4 诊断。

### 5.4 校准、误报和效率

- 并列报告 P 相对 A/S/X 的 ECE、良性误报率、恶意召回率和 PR-AUC，禁止只报告有利指标。
- P 的步数、参数量或批量与其他变体不一致时结果无效。
- 指标时间跨度只作同机同入口成本诊断；单次时间不用于统计显著性结论。

### 5.5 唯一最终裁决

- **支持继续 E3**：结果有效，核心最低门禁成立，守恒增益成立，且最差组与源域非退化检查通过。
- **进入唯一一次 E4**：结果有效，但核心门禁、守恒增益、最差组或源域非退化至少一项失败。
- **结果无效**：数据、划分、标签、指标、阈值、预算或运行完整性门禁失败。
