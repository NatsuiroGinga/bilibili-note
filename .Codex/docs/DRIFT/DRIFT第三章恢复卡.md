**由此产生的表述纪律（强制）**：正文的**正式威胁模型**写成「攻击者诱发 false positives 造成检测系统 availability failure」（第 1 层），把「假告警洪泛掩护真实入侵」写成**运营动机／可能后果**（第 3 层）。**三层不得合并成一条引证**——它们的攻击后果链不同（ML 侧污染 ∕ 自动签名系统 ∕ SOC 流程 ∕ 社会—技术动力学）。

**一条必须先说清的重叠**：**Newsome 2006 的 Correlated Outlier attack（p.13）已经给出「投毒使检测器被迫在误报与漏报之间二选一」的形式化先例**。本课题的「双侧错误风险」**因此不得写成本课题首创**；差量只能落在**把该威胁结构反用为训练信号**（未检得同构先例）。

**二、组相对近邻碰撞表（四篇全部入库全文）**

| 方法 | 同一原样本多变体 | 组内比较 | 选择／加权规则 | 与「每干净样本 K 个同源扰动变体、按欺骗信号选择」的碰撞 |
| --- | --- | --- | --- | --- |
| Tramèr & Boneh, NeurIPS 2019（arXiv:1904.13000） | 是 | 是 | 组内 **max loss** 或 **avg**（不同 perturbation type） | 中高：确立「同源多攻击组内 max」 |
| MaxUp, arXiv 2020（arXiv:2002.09024） | 是 | 是 | **组内 worst loss**（同一生成机制多次采样） | 中高：同一 generator 多采样 ＋ 组内 hardest copy |

**三、窄差量重定位（本方向唯一仍可主张的结构）**

宽口径作废后，**未检得同构先例**的只剩一个更窄的结构：

> **显式 centered sibling advantage**（`A_ij = r_ij − 组均值` 或 leave-one-out 基线）**且符号／排序／幅度驱动选择**，**并与 DGA 的恶意侧漏检压力（FN）＋ 良性侧误报压力（FP）的双侧对称构造**结合。

**表述纪律**：一律写「**未检得同构先例**」，**禁「首次」**（术语高度不统一，「未检得」不是不存在证明）。

**四、对 H 臂设计的修正（决定 H 臂写法，见 [h-arm-research-question-card.md](../2026-09-10-DGA对抗鲁棒组相对方案/h-arm-research-question-card.md) 新增节）**

本地已回代码核验：**D 臂实际就是显式 centered advantage**（`official_p2p3.py` L201–L211：二值 `fooled` 减组均值后**跨组全局 top-64**）。据此完成动作等价性分析（[notes.md](../2026-09-10-DGA对抗鲁棒组相对方案/notes.md) §J），要点：

- **组内序不变**：逐组常数减除**不可能**改变组内优先级，中心化的唯一作用面是**跨组配额分配**；
- **值域极小**：二值信号经中心化后只有 `K−1 = 3` 个正优势取值，且 `c_i = 0` 与 `c_i = K` 的候选**优势都恰为 0.0**——0.0 并列簇跨两类相反语义，**入选由候选生成顺序决定**；
- **等价域**：与 BB-GS 全等需 `|{fooled}| = Q` 且无全骗组；与 MaxUp 全等需 `c_i ≡ 1` 且 `N = Q`；**与 MMEL 无集合等价域**（支撑集与竞争结构均不同）；
- **判定**：**结构上不可约（三个近邻都没有「跨组配额竞争」这一运算），但信号脆弱**——「不可约」成立的是运算结构，不是可分辨性。

**五条修正建议（H 臂须照此调整实现与表述）**：① 选择信号由二值 `fooled` 换成**连续兄弟分数**后再中心化；② 显式登记并列破法；③ 显式登记配额 `Q` 与 `N` 的关系（当前 `Q` 固定 64、`N` 随批波动）；④ 把「**跨组配额竞争**」写成机制的显式组成部分而非实现细节；⑤ 差量表述须同时给出等价域边界（承认 `c_i ≡ 1` 且 `N = Q` 时与 MaxUp 等价）。

**口径声明**：本节为**文献排重与设计分析**，不构成已支持机制、已批准方向或已冻结判据；窄差量是否成立**仍须由 H 臂实验裁决**。§J 的等价域/差异域是**代数结论**，实际运行落在哪个域**尚无制品可查**（`official_p2p3.py` 未落盘逐候选分数），**属证据缺口，须另行取数**。

### 对标朱第三章的证据结构裁决（2026-09-12，长期有效）

**我们对标的是朱第三章的证据结构，不是虚构的“全指标碾压”。** 朱的组件消融只在
`PGD-20` 鲁棒准确率上证明两个单组件相对共同基线均有正点增益，联合方法在两个骨干上最好，
并呈正交互；它没有证明每个单组件在干净准确率、宏平均 F1 和所有攻击条件下都领先。
完整 DS-RGO 虽在防御方法中领先，但相对未做对抗训练的 Standard 仍有约
`1.7–2.1pp` 的干净准确率代价。**朱没有把该读数作为未解释的失败**：第二章先以
“鲁棒性与自然准确率存在内生矛盾”建立问题背景；第三章再将 DS 解释为由弱到强调度攻击、
保护早期特征学习，并据此表述为“将干净样本准确率损失控制在 `2.1%` 内，缓解鲁棒性与精度之间矛盾”；
同时以鲁棒宏平均 F1 与整体准确率差值较小、训练轨迹更平稳作为旁证。该解释有完整方法的主表和曲线支持，
但组件消融只报告 `PGD-20` 鲁棒准确率，没有单独报告 DS 对干净准确率的因果增量，
所以可复用的是“报告代价并用机制与旁证解释”的论证方式，不能把归因升级为组件级严格证明。
此外，原实验没有多种子、置信区间或显著性检验。
事实与复算见[朱焱雷第三章工作量与指标体系对位](../2026-09-10-DGA对抗鲁棒组相对方案/zhuh-ch3-benchmark.md)
和[朱焱雷第三章机制构思与创新声明分析](../../../thesis/methods/第三章-朱焱雷第三章机制构思与创新声明分析.md)。

本课题按任务结构采用等价而非机械复制的对标标准：共同强基线；真实组件开关消融；
每个组件在预登记职责指标上有独立正贡献且通过另一轴护栏；联合方法相对两个单组件最好
或在 `干净 FPR × 对抗 FNR` 双主轴上非支配，并报告交互量；完整方法再与直接近邻、
两个异构骨干及正式年份面板比较。不得为了制造“全面领先”而事后合成总分、修改指标、
隐藏干净 AP／FPR 代价或要求职责不同的组件在每个原始指标上同时改善。

**当前差距**：筛选证据已支持组件 1 主要降低攻击 FNR、组件 2 主要降低干净 FPR，
联合 F 在 DRIFT 骨干上对朴素增广 B 构成判据相关双轴支配；但该支配在 B-ResNet 上
不成立，正式多种子和 T20–T25 证据尚未完成。因此当前只能写“组件职责与组合取舍获筛选支持”，
不能写“跨骨干全面领先”或“已达到朱式完整实验结论”。
