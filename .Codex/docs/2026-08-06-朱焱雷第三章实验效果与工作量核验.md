# 朱焱雷论文第三章实验效果与工作量核验

## 1. 结论

朱焱雷论文第三章可为本课题提供**效果提升量级和章内论证密度参照**，不能提供必须达到的数值门槛，也不能迁移其方法。

- 按“同一数据集、同一基座、同一攻击条件、同一指标、同一表内最高非本文方法”选择最强可比基线，DS-RGO 在 PGD-20 下的主表增益为：
  - **ET-BERT：鲁棒准确率提升 4.5～4.8 个百分点，鲁棒宏平均 F1 提升 4.9～5.1 个百分点；相对增幅为 6.22%～7.57%。**
  - **BUPT-CNN：鲁棒准确率提升 3.3～3.6 个百分点，鲁棒宏平均 F1 提升 4.1 个百分点；相对增幅为 5.45%～7.18%。**
- 上述鲁棒收益伴随干净性能代价：ET-BERT 的干净准确率下降 2.0～2.1 个百分点，BUPT-CNN 下降 1.7～1.9 个百分点。不能只摘录鲁棒收益而省略代价。
- 消融中，完整方法相对最强单模块变体 RGO-AT 在 ET-BERT、BUPT-CNN 上分别提升 **6.0、4.7 个百分点**，相对增幅分别为 **8.60%、7.81%**。表 3-7 另列的 `+12.30%`、`+9.30%` 实为相对 PGD-AT 基准的**绝对百分点差**，不是按基线作分母的相对百分比。
- 原文小结称“对抗鲁棒性提升 4.2%～8.6%”，但未交代比较对象、指标聚合方式以及绝对百分点/相对百分比口径，无法由表 3-5、表 3-6 的最强同条件基线直接复算，因此**不把该标题区间作为本课题参照值**。
- 对本课题，唯一可复用的粗粒度参照是：在冻结协议下，相对最强同条件基线的主要困难/鲁棒指标出现约 **3～5 个百分点**的绝对改善，或约 **5%～8%**的相对改善，属于这篇论文所呈现的同一量级。该区间不是验收门槛；低于或高于该区间都必须由多种子区间、误报、校准、效率、消融与防泄漏证据共同裁决。
- **明确禁止**为了接近该量级而挑选种子、削弱基线、删除困难样本、改变测试集、改变类别比例、切换指标、调最终测试阈值或在看到最终测试后修改方法。

## 2. 来源、页码和计算口径

- 原始来源：`raw/papers/attack-detection/朱焱雷.pdf`。
- 定位线索：`wiki/papers/attack-detection/朱焱雷-加密流量博弈对抗与高效训练.md`。该笔记未被当作数字证据。
- PDF 共 111 个物理页。第三章位于**物理页 39～64、印刷页 23～48**；3.6 节位于**物理页 52～64、印刷页 36～48**。第三章内物理页码始终比印刷页码大 16。
- 核验方式：先用 `pdftotext -layout` 逐页定位，再将物理页 52～64 以及工作量计数所需的物理页 39、46、49、50 渲染为页面图像逐页复核。`mineru-open-api extract` 因本机无认证令牌未执行成功；所有核心数值均已回到原始 PDF 页面核验。
- 最强可比基线规则：只在同一张表、同一数据集、同一基座、同一攻击或测试条件、同一指标内，从非 DS-RGO 方法中选取最高值；不跨表挑选，不把不同输入模态或不同数据划分混为同一比较。
- 计算公式：
  - 绝对提升（百分点）=`DS-RGO 指标值 - 最强可比基线指标值`。
  - 相对增幅（%）=`(DS-RGO 指标值 - 最强可比基线指标值) / 最强可比基线指标值 × 100%`。
  - 负值表示性能代价。准确率或 F1 本身以百分数报告时，二者不能混称为“提升百分比”。

## 7. 消融提升的精确复算

| 基座 | 变体 | PGD-20 RA 原值 | 相对 PGD-AT 绝对差 | 相对 PGD-AT 相对增幅 |
| --- | --- | ---: | ---: | ---: |
| BUPT-CNN | PGD-AT 基准 | 55.60% | 0 | 0 |
| BUPT-CNN | DS-AT | 56.50% | +0.90 个百分点 | +1.62% |
| BUPT-CNN | RGO-AT | 60.20% | +4.60 个百分点 | +8.27% |
| BUPT-CNN | DS-RGO | 64.90% | +9.30 个百分点 | +16.73% |
| ET-BERT | PGD-AT 基准 | 63.50% | 0 | 0 |
| ET-BERT | DS-AT | 66.20% | +2.70 个百分点 | +4.25% |
| ET-BERT | RGO-AT | 69.80% | +6.30 个百分点 | +9.92% |
| ET-BERT | DS-RGO | 75.80% | +12.30 个百分点 | +19.37% |

证据位置：表 3-7，物理页 58/印刷页 42；图 3-6，物理页 59/印刷页 43。

- 与最强单模块变体 RGO-AT 相比，完整 DS-RGO 在 BUPT-CNN 上提升 `64.90-60.20=4.70` 个百分点，相对增幅 `4.70/60.20=7.81%`。
- 与最强单模块变体 RGO-AT 相比，完整 DS-RGO 在 ET-BERT 上提升 `75.80-69.80=6.00` 个百分点，相对增幅 `6.00/69.80=8.60%`。
- 相对 PGD-AT，完整模型的绝对增益大于两个单模块绝对增益之和：BUPT-CNN 多出 `9.30-(0.90+4.60)=3.80` 个百分点；ET-BERT 多出 `12.30-(2.70+6.30)=3.30` 个百分点。这只能支持**该次实验中存在非加性组合收益**，不能据此声称两个模块是鲁棒性的“充分必要条件”。

## 8. 其他实验分别能支持什么

### 8.1 训练稳定性与所谓“泛化”

- 图 3-4 显示 DS-RGO 在两种基座上的训练损失曲线更平滑、终值更低；差异在 ET-BERT 上更明显。该图没有误差带，只支持所示运行轨迹的定性比较。
- 图 3-5 的正文记录：ET-BERT 上 PGD-AT 与 FreeLB 在第 10～12 轮达到峰值后回落 5～8 个百分点；DS-RGO 后续无明显回落，RA 稳定在约 74.9%。BUPT-CNN 的正文只给出“上限提升约 6%”的近似描述。
- 这些曲线可以支持“所示训练运行中震荡和后期回落较小”，不能支持统计意义上的稳定性；没有多种子方差、置信区间或显著性检验。
- CP-Mobile 与 CP-Desktop 均采用集合内部随机分层划分，不能支持未见平台、未见采集组或严格跨域泛化。对本课题尤其不能替代按完整采集单元、会话或条件留组的外推实验。

### 8.2 机理可视化

- 图 3-7 只随机抽取 6 个类别并用 t-SNE 二维投影展示类簇；它提供“表征分离更清晰”的可视化线索，但 t-SNE 受随机性和超参数影响，不能证明二阶反应梯度导致平坦极小值。
- 图 3-8 只展示 1 个 TLS 1.3 Client Hello 样本。它可说明该样本上的注意力区域差异，不能证明模型总体依赖语义不变特征，也不能单独证明因果机理。

### 8.3 攻击强度敏感性

图 3-9 在 ET-BERT 上报告 DS-RGO 的精确标注点：

| 扰动半径 `ε` | DS-RGO RA | 相对 `ε=0.05` 的绝对下降 | 相对下降 |
| ---: | ---: | ---: | ---: |
| 0.05 | 75.80% | 0 | 0 |
| 0.10 | 65.40% | -10.40 个百分点 | -13.72% |
| 0.15 | 56.20% | -19.60 个百分点 | -25.86% |
| 0.20 | 45.80% | -30.00 个百分点 | -39.58% |

原文另明确 Adv-LoRA 在 `ε=0.15` 时为 28.5%。其余基线点只存在于折线图中，没有表格或逐点标签，因此本核验不把目测值用于精确相对增幅。该实验支持“超过训练半径后仍保持较高的相对排序和非零识别率”，不能支持对任意攻击、任意范数或物理合法攻击的普遍鲁棒性。

### 8.4 细粒度类别

图 3-10 的 10 个对角召回率依次为：WhatsApp 92%、Telegram 90%、Signal 93%、YouTube 89%、Netflix 88%、Vimeo 94%、Spotify 91%、AppleMusic 92%、Facebook 93%、Instagram 94%。

- 可支持：在选定的 10 个高混淆类别上，DS-RGO 的对角召回率为 88%～94%。
- 不可支持：全部 60 类均达到该范围、长尾类别总体改善、相对其他防御方法更优。该图没有给出基线混淆矩阵、每类样本量或全部 60 类结果。
- 原文正文称 Facebook 与 Instagram “召回率超 93%”，但矩阵原值为 93% 和 94%。严格表述应为“分别为 93% 和 94%”或“均不低于 93%”。

### 8.5 物理受限填充模拟

## 9. 哪些数字不能迁移到本课题

1. **任务不同**：原文是 App60 加密应用 60 类分类与对抗逃逸；本课题是 TQH-C2 加密恶意流量检测、分组外推和困难域检测。准确率、Macro-F1 与类别结构不可直接对应。
2. **数据和划分不同**：原文采用集合内部 8:1:1 随机分层划分；本课题必须按完整采集单元、会话或条件留组，并报告困难域、B↔D 迁移和最差条件。
3. **输入与基座不同**：原文的 ET-BERT 使用应用层载荷 Token，BUPT-CNN 使用 784 字节灰度图；本课题的结构化输入编码器、原始字节 ET-BERT 强基线和物理状态专家承担不同信息角色。
4. **攻击定义不同**：主结果来自连续词嵌入/像素空间的 PGD-20；本课题的物理状态、残差、协议栈变化、间隔与抖动不是相同扰动空间。
5. **统计证据不足**：原文未报告种子数、均值、标准差、置信区间或显著性；任何单点增益都不能直接充当本课题的预期均值或下限。
6. **外部基线适配细节不足**：主表未在表内报告各基线的搜索预算、最佳超参数、训练成本和方差，不能据此假定同名方法在本课题上会有相同强弱排序。
7. **压力测试差距会随基线崩溃放大**：图 3-11 中 +18.7 个百分点来自高强度填充下其他方法显著退化，不应作为常规主性能目标。
8. **可视化不是量化机制证据**：t-SNE、单样本注意力和局部混淆矩阵不能迁移为本课题的因果结论或数值门槛。
9. **工作量数字不是配额**：26 页、33 个公式、11 幅图和 7 张表只表明章内论证密度；不得拆公式、重复绘图或制造定理来凑数。

## 10. 本课题的使用规则

### 10.1 只作量级参照

- 主参照：同协议、同数据、同基座、同测试条件下，相对最强可比基线的主困难/鲁棒指标约 **+3～+5 个百分点**，相对约 **+5%～+8%**。
- 组件参照：完整方法相对最强单组件约 **+5～+6 个百分点**，只提示完整方法应优于删减版本；本课题不预注册这一数值。
- 权衡参照：原文用约 **1.3～2.1 个百分点**的干净指标代价换取鲁棒收益。本课题必须独立预注册非劣界、良性误报、校准和最差域条件，不能照搬该代价。
- 压力测试：物理填充下 **+2.9～+18.7 个百分点**只作攻击强度增加时差距可能放大的案例，不进入本课题主效果区间。

### 10.2 冻结和报告纪律

1. 先冻结数据、字段、组级划分、基座、强基线、指标、阈值、停止条件和最终测试不可见协议，再运行正式矩阵。
2. 种子 42、43、44 均按预注册规则报告，不挑最好种子；必须给出均值、离散程度或置信区间。
3. 强传统基线、编码基线和原生输入 ET-BERT 基线使用各自合理预算，不能少训、少调或删除其有利输入来制造差距。
4. 不删除困难样本，不改变测试来源、类别比例或条件构成，不从最终测试反向选择阈值和模型。
5. 完整方法必须与无物理、真实物理、置换物理、随机物理和独立移除组件比较；先验证机制方向，再讨论幅度。
6. 即使提升小于 3 个百分点，只要多种子区间、困难域、误报、校准、效率和物理特异性证据成立，仍可构成有效结果；即使提升大于 5 个百分点，也必须优先排查泄漏、基线欠拟合、测试变更和样本选择。
