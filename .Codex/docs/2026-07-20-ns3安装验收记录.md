## 问题与处理

### root 防护

首次运行时，ns-3 包装器检测到 `USER=root` 并拒绝执行，尚未进入 CMake。服务器只提供 root 用户，包装器对应版本只检查 `USER` 环境变量，因此后续命令使用 `env USER=ns3builder ./ns3 ...`。未修改 ns-3 上游源码。

首次失败日志保留为：

`/root/autodl-tmp/thesis/ns3/ns-3.48-build.failed-root-guard.log`

### CMake 版本

绕过 root 防护后，配置因系统 CMake 3.22.1 低于 ns-3.48 要求的 3.25 而失败。该日志保留为：

`/root/autodl-tmp/thesis/ns3/ns-3.48-build.failed-cmake-3.22.1.log`

未替换系统 CMake。使用服务器已有的 `uv 0.11.29` 创建隔离环境，并安装 CMake 3.25.2：

```bash
/root/.local/bin/uv venv \
  --python /usr/bin/python3 \
  /root/autodl-tmp/thesis/ns3/.tools/ns3-cmake-3.25.2
/root/.local/bin/uv pip install \
  --python /root/autodl-tmp/thesis/ns3/.tools/ns3-cmake-3.25.2/bin/python \
  'cmake==3.25.2'
```

## 配置与编译

构建在独立 `screen` 会话 `ns3-3.48-build` 中运行，使用 8 个并发任务。核心命令如下：

```bash
cd /root/autodl-tmp/thesis/ns3/ns-3.48
export PATH=/root/autodl-tmp/thesis/ns3/.tools/ns3-cmake-3.25.2/bin:$PATH
env USER=ns3builder ./ns3 configure \
  --build-profile=default \
  --disable-examples \
  --disable-tests
env USER=ns3builder ./ns3 build -j 8
env USER=ns3builder ./ns3 run scratch-simulator
```

配置结果包括：

- CMake 3.25.2 配置和生成成功。
