# 任务十一：边界锚定的稀疏状态监督 PINN 实施计划

> **2026-07-21 用户加速授权：**任务十一不采用测试驱动开发，直接实现后执行一次必要的后置契约验证，尽快同步服务器并启动 S1/S2。

**目标：**判定队列守恒残差在状态标签稀缺时能否提供独立训练信息，而不是在密集五锚点监督上重复约束。

**核心设计：**每条四窗口序列始终监督绝对边界 `q0`，消除相邻差分残差的整体平移零空间。20% 方案只监督 `q0`；40% 方案监督 `q0` 与一个由 `group_id + seed` 决定的内部锚点。相同标签比例下，无物理与有物理组必须共用完全一致的遮罩、初始化、数据顺序和训练步数。

## 四个对照

| 组别 | 状态标签 | 物理损失 | 对应变体 |
| --- | --- | --- | --- |
| S1 | 仅 `q0`，20% | 无 | M1 |
| S2 | 仅 `q0`，20% | 有，`lambda_physics=0.01` | M2 |
| S3 | `q0` + 1个内部锚点，40% | 无 | M1 |
| S4 | `q0` + 1个内部锚点，40% | 有，`lambda_physics=0.01` | M2 |

## 不可变约束

- 基座模型为 `/root/autodl-tmp/thesis/models/Qwen3-1.7B`，随机种子为42，训练步数为202。
- 物理训练与验证数据分别使用任务四正式制品的 `train.jsonl` 与 `validation.jsonl`，各807条。
- 生成任务、LoRA 配置、学习率、批量、样本顺序、状态损失权重和残差公式与任务九一致。
- 验证集的所有锚点真值只用于评估，不得进入训练损失。
- 40% 方案的内部锚点位置按训练集唯一 `group_id` 的确定性哈希排名循环分配到 `q1-q4`，使计数差不超过1；S3/S4 的遮罩哈希必须相同。
- 本轮只用随机种子42做机制门禁，不做显著性和稳定增益声称。
- 同比例的两个实验可双进程并行；并行时间不进入论文效率表。

**必须新增的接口：**

- `masked_state_target_loss(predicted, target, mask) -> torch.Tensor`

1. `anchor0_only` 对每条记录返回 `[1,0,0,0,0]`。
2. `anchor0_plus_one` 每条记录恰好包含 `q0` 和一个内部锚点；同 `group_id` 位置相同；四个内部位置的组计数差不超过1。
3. 遮罩损失只对观测锚点求均值，未观测锚点的任意误差不改变训练损失。
4. S1/S2 遮罩哈希相同，S3/S4 遮罩哈希相同，两对的物理样本顺序哈希一致。
5. `dense` 模式重现既有任务九行为，不修改已有 M0/M1/M2 语义。

## 裁决门禁

对 S2 对 S1、S4 对 S3 分别裁决：

- 未观测锚点状态均方误差至少降低10%。
- 物理残差均方误差至少降低10%。
- GeNIS 生成验证损失的恶化不超过5%。
- 若只降低残差而不改善未观测绝对状态，仍判定失败。
