# 流形约束与物理表征耦合文献补检索计划

## 目标

建立能够裁决第三章第二理论支柱的可核验文献证据集。目标不是证明流形约束必然有效，而是回答物理状态如何显式进入生成表征、约束应施加在哪里、如何优化、是否存在负面结果以及仿真监督如何迁移到真实流量。

## 文献范围

- [ ] Stiefel、Grassmann 与正交低秩适配：2 至 3 篇。
- [ ] mHC、Hyper-Connections 与 Birkhoff 约束：2 篇。
- [ ] 物理状态或潜在动力学表征的显式融合：3 至 4 篇。
- [ ] 共享—私有子空间、多任务负迁移与结构隔离：2 至 3 篇。
- [ ] 仿真到真实的物理表征迁移与状态可辨识：2 至 3 篇。

## 强制证据门禁

1. 每篇论文必须从 DOI、出版社、会议论文集或 arXiv 原始页面核验题名、作者、年份和标识符。
2. PDF 下载到 `raw/papers/manifold/`，只增不改；相同论文已有原件时不得重复下载。
3. 阅读笔记写入 `wiki/papers/manifold/`，必须满足 `SCHEMA.md` 的论文笔记字段并使用有效 `source_pdf`。
4. 不能只读摘要。核心公式、算法、实验增益、负面结果和本课题映射必须记录 PDF 页码或章节。
5. 纯博客、无法核验的人工智能报告、只使用“流形”修辞但没有约束集合的材料不得进入证据集。
6. 论文只支持通用参数高效微调时，必须标为背景证据，不得直接宣称支持物理表征耦合。
