# 物理状态路由适配专家备选路线

- **状态**：未验证备选，不是当前冻结算法
- **记录日期**：2026-07-22
- **适用章节**：第三章第一创新点
- **当前主线关系**：不替换正在执行的非对称单私有物理适配器实验，不得自动启动

## 1. 路线定位

本路线研究在冻结检测适配器之外配置多个物理私有低秩专家，并依据流量序列的动力学状态稀疏激活少量专家。其目标是把不同队列演化状态对应的物理梯度隔离到不同参数子空间，降低检测生成目标与物理目标之间的负迁移。

该方案只借鉴混合专家的条件计算形式，不等同于 DeepSeekMoE，也不能把通用 Top-K 路由本身作为创新。论文能够主张的新增机制必须来自**物理状态定义、物理语义路由、任务级参数隔离和有限队列约束之间的协同设计**。

## 2. 推荐结构

### 2.1 序列级物理路由

队列状态对应完整四窗口观测，而不是单个文本词元。因此主路由器读取四窗口公共字段的序列表示与任务表示：

\[
\boldsymbol\pi^{\mathrm{seq}}
=\operatorname{TopK}
\left[
\operatorname{softmax}
\left(R(\boldsymbol z_{\mathrm{obs}},\boldsymbol z_{\mathrm{task}})/\tau\right)
\right].
\]

其中，\(\boldsymbol z_{\mathrm{obs}}\) 只能由公开数据推理时可获得的包数、字节数、包长、到达间隔和速率等字段构成。队列长度、链路容量、丢弃量和 ns-3 场景编号只能作为训练监督或审计真值，禁止进入公开数据推理输入。

不采用完全自由的词元级 Top-K 路由。若后续证据支持词元修正，只允许在序列级路由先验上施加有界的小幅修正，避免字段名、数值和输出标签被无物理语义地分配给不同专家。

### 2.2 共享检测分支与物理私有专家

大类检测使用冻结的检测适配器：

\[
\boldsymbol h^{F}_{l,t}
=\boldsymbol h_{l,t}
+\Delta^{\mathrm{det}}_l(\boldsymbol h_{l,t}).
\]

子类与开放集任务允许激活物理专家：

\[
\boldsymbol h^{S}_{l,t}
=\boldsymbol h_{l,t}
+\Delta^{\mathrm{det}}_l(\boldsymbol h_{l,t})
+g_{\mathrm{task}}
\sum_{k\in\mathcal K}
\pi^{\mathrm{seq}}_k
\Delta^{\mathrm{phys}}_{l,k}(\boldsymbol h_{l,t}).
\]

大类任务固定令 \(g_{\mathrm{task}}=0\)，检测适配器保持冻结。由此得到的大类分支不变性来自结构隔离，不依赖软惩罚近似维持。未知攻击标签不得进入训练或阈值校准；开放集只表示推理任务类型，不表示已知未知类别。

### 2.3 专家物理语义

首个有界验证最多使用三个物理专家，不进行专家数量扫描：

1. **平稳传输专家**：到达量与服务量接近平衡，队列变化较小。
2. **队列累积专家**：突发到达主导，队列在连续窗口中增长。
3. **容量饱和专家**：服务受限并伴随溢出或丢弃行为。

专家不得按攻击名称或数据集标签划分。每个专家必须通过路由分布、分状态残差和专家移除实验验证其物理专门化，不能仅凭可视化或参数名称宣称形成分工。

## 3. 候选训练目标

候选总目标为：

\[
\mathcal L
=\mathcal L_{\mathrm{gen}}
+\lambda_a\mathcal L_{\mathrm{anchor}}
+\lambda_p\sum_k\pi_k\mathcal L_{\mathrm{queue}}^{(k)}
+\lambda_s\mathcal L_{\mathrm{specialize}}
+\lambda_b\mathcal L_{\mathrm{balance}}.
\]

- \(\mathcal L_{\mathrm{gen}}\)：分层生成式检测损失。
- \(\mathcal L_{\mathrm{anchor}}\)：双锚点稀疏状态监督，消除差分守恒的状态平移自由度。
- \(\mathcal L_{\mathrm{queue}}^{(k)}\)：由第 \(k\) 个专家预测状态构成的有限队列守恒残差，必须对专家参数可微。
- \(\mathcal L_{\mathrm{specialize}}\)：约束路由与物理演化状态相符，并要求专家移除后只在对应物理状态上产生选择性退化。
- \(\mathcal L_{\mathrm{balance}}\)：仅防止专家完全闲置，不能强迫所有专家平均使用，否则可能破坏真实状态分布。

正式实现前必须重新完成量纲、梯度路径、极端条件和公开字段可观测性审计。上述公式是候选设计，不得直接写成已经成立的论文公式。

## 4. 理论来源与自主修改边界

1. 门控物理信息网络支持利用可训练门控完成软区域分解和参数共享，但其对象是偏微分方程求解，不能直接证明网络流量路由有效。
2. 物理硬约束混合专家支持把大型物理约束分解给局部专家，但其局部求解机制不能照搬为生成式恶意流量检测。
3. LoRA 混合专家证明在冻结稠密基座上使用多个低秩专家和稀疏路由具有工程可行性，但通用多任务增益不能作为本课题效果证据。
4. 本课题的实质修改应是：以有限队列状态而非文本主题定义专家，以序列公共观测而非攻击标签形成路由，以任务门控保证大类分支不变，并用双锚点和守恒残差共同约束专家专门化。

组合已有模块本身不构成创新。只有上述自主接口获得同预算消融和跨域证据后，才能进入第三章最终方法。

## 5. 启用条件

同时满足以下条件后，才可以提交用户决定是否启动；任何代理不得自动继续：

1. 当前非对称单私有物理适配器实验完成，且不能同时满足预注册检测、开放集和物理门槛，或者结果明确显示单一专家在不同物理状态间存在相反增益。
2. 文献核验确认物理门控、低秩专家和负迁移隔离的引用链真实，并明确本课题相对已有工作的实质差异。
3. 能从现有 ns-3 制品建立不依赖攻击标签的平稳、累积和饱和状态监督，并保留独立拓扑外测。
4. 路由器的公开推理输入与 GeNIS 等公开数据字段一致，不依赖队列真值、链路容量、场景编号或未知攻击标签。
5. 用户明确批准把该路线提升为正式候选。

## 6. 有界实验协议

若获批准，只进行一次固定结构验证，不扫描专家数量、Top-K、秩或路由器深度：

- **对照一**：冻结检测适配器，不增加物理分支。
- **对照二**：一个单私有物理适配器。
- **对照三**：三个物理专家的静态同权组合，用于区分参数扩容与有效路由。
- **候选方法**：三个物理专家、序列级 Top-1 路由和固定任务门控。

对照二、对照三和候选方法必须保持相同总低秩参数预算；候选方法还应报告实际激活参数、训练吞吐量、峰值显存和推理延迟。数据、切分、随机种子、训练步数、批次顺序、生成协议和评测脚本均保持不变。

候选方法必须同时满足：

- 大类自由生成宏平均 F1 相对冻结检测适配器下降不超过 `0.01`。
- 子类自由生成宏平均 F1 不低于单私有适配器。
- 未知攻击平均召回率相对冻结检测适配器至少提高 `0.10`。
- 未知攻击评测中的良性误报率至少降低 `0.05`。
- 未观测状态误差和物理残差至少改善 `10%`。
- 子类预期校准误差增量不超过 `0.02`。
- 每个专家至少在一种预定义物理状态上获得可复核的选择性优势，且优势不能由攻击标签或数据集来源解释。

## 7. 永久停止条件

出现任一条件即否决该备选，不增加第四个专家或继续扫描：

1. 大类检测下降超过 `0.01`。
2. 同总秩预算下不优于单私有适配器。
3. 路由主要由攻击标签、字段位置、数据集来源或 ns-3 场景编号决定。
4. 专家坍缩为单专家独占，或多个专家没有选择性物理优势。
5. 物理指标改善但检测、开放集或校准指标未形成联合收益。
6. 动态路由带来的效率代价明显超过检测收益，无法满足论文中的训练与推理成本论证。

## 8. 对第三章的潜在影响

只有通过有界实验后，本路线才可能替换第二理论支柱。届时章节可围绕“有限队列物理约束”和“物理状态路由专家”组织，候选标题为：
