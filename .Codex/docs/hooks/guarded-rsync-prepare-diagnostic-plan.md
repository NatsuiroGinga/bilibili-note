# Guarded Rsync 准备阶段诊断计划

日期：2026-07-30

## 边界

- 仅修复 `guarded_rsync.py` 在远端父目录准备失败时丢失子进程诊断的问题。
- 新增受管的“仅准备父目录”模式，不执行 `rsync`、模型下载或远端阶段脚本。
- 诊断必须限制长度并脱敏环境凭据；底层失败退出码不得被覆盖。
- 修复后更新 `scripts/AGENTS.md`，不修改实验模型、配置或正式运行目录。

## 步骤

1. 在 `guarded_rsync.py` 中抽取准备步骤和脱敏诊断，保留退出码、标准输出、标准错误。
2. 为受管命令增加 `--prepare-only`，将成功或失败结果写入唯一收据。
3. 增加本地伪进程测试，覆盖输出保留、凭据脱敏、长度限制和不触发传输。
4. 运行格式化、语法检查和完整钩子回归，再执行一次受管仅准备诊断以取得真实根因。

## 阻塞条件

- 若一次受管仅准备诊断仍没有有效脱敏输出，停止远程尝试并重新检查 Expect 包装器的输出合同。
- 若诊断显示凭据缺失或登录失败，不重试下载；先由控制代理修复登录环境。
- 若连续三次最小修复失败，停止补丁并讨论入口架构。
