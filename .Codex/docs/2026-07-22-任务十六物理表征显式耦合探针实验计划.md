# 任务十六：物理表征显式耦合探针实验计划

## 目标

验证预测物理状态能否通过可微前向通路影响恶意流量生成表征，并裁决 Stiefel 约束是否在普通门控融合之上提供独立增益。PINN、双锚点和有限队列残差保持不变；本任务不再扫描博弈权重。

## 核心判据

当前失败结构满足生成输出不依赖预测状态。新结构必须通过自动微分和扰动实验同时证明：

\[
\frac{\partial \mathcal L_{gen}}{\partial \hat q}\neq 0,
\qquad
\hat y(\hat q+\delta)\neq \hat y(\hat q).
\]

仅有物理损失反向到共享 LoRA 不算显式连接。

## 候选结构

- B0：普通可靠性门控物理表征融合，不加流形约束。
- B1：在 B0 的物理投影矩阵上施加 Stiefel 正交约束。
- mHC/Birkhoff 多流连接只作为文献候选，不在首轮直接改造完整 Qwen 残差拓扑。

## 执行阶段

- [x] 阶段一：审计 GeNIS 与 ns-3 输入字段、提示模板、隐藏状态形状和可共享表征接口。
- [x] 阶段二：确定单次前向或双次前向原型，记录推理成本和真实数据无队列标签时的状态来源。
- [x] 阶段三：实现最小 B0/B1 原型与前向依赖诊断，不改变既有 G0 至 G5 结果。
- [x] 阶段四：服务器运行最小行为测试和两步在线冒烟。
- [x] 阶段五：若冒烟通过，以相同种子、样本顺序和预算运行 B0/B1 的 50 步探索实验。
- [x] 阶段六：按生成、物理、已观测状态、未观测状态、梯度通路、显存和吞吐共同裁决是否进入 202 步正式实验。

## 实验纪律

1. 禁止使用测试驱动开发。
2. 首轮只比较无流形 B0 与 Stiefel B1；不得同时加入 mHC、域对抗或新的损失权重扫描。
3. B0 必须先证明显式连接本身有效，B1 才能被解释为流形约束增量。
4. 真实数据没有队列标签时，推理路径必须仍可执行；不得要求推理时运行 ns-3 或读取队列真值。
5. 所有服务器运行使用 `uv`、SwanLab 在线模式和唯一输出目录，保留逐步日志与制品路径。
6. 两步冒烟未通过时不得启动 50 步实验；50 步只用于方向裁决，不直接写成正式性能结论。
7. 202 步正式实验必须等待文献门禁、结构接口和 50 步证据共同通过。
