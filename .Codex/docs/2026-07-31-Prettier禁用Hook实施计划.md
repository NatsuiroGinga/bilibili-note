# Prettier 禁用 Hook 实施计划

## 目标

在本仓库的命令执行前确定性阻止 Prettier 调用，同时允许普通文本提及、历史文档读取和含 `prettier` 的文件名。

## 边界

- 只修改项目 Hook、对应最小测试、实验局部规则和本任务报告。
- 不恢复已暂停的其他项目执行门禁。
- 不修改论文、实验源码、配置、数据或运行制品。
- 不运行 Prettier、其他格式化工具或抽象语法树解析。

## 阶段

- [x] 核对项目规则、Hook 技能、现有 Hook 配置与启用状态。
- [x] 实现独立的 Prettier 命令守卫并注册项目 `PreToolUse`。
- [x] 更新实验局部规则，删除任何允许 Prettier 的例外。
- [x] 运行最小允许/拒绝样例和配置解析验证。
- [x] 记录生效边界、验证证据与剩余风险。

## 验收

- 直接 `prettier` 及 `npx`、`npm exec`、`pnpm`、`yarn`、`bunx` 包装调用被拒绝。
- 常见 `sh -c`、`bash -lc` 和管道中的调用被拒绝。
- `rg`、`cat`、`printf` 等普通文本提及不被拒绝。
- 拒绝输出使用当前 Codex `PreToolUse` 支持的结构化合同，并给出简体中文原因。
- `.codex/hooks.json` 可被标准 JSON 解析器读取。
