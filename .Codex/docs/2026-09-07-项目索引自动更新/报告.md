# 项目索引自动更新报告

## 实现

- 新增 `tools/update_project_index.py`：只扫描受管文档根，排除 `raw`、`runs`、缓存、归档、敏感路径及自身输出。
- 生成器用内容清单 SHA-256、`flock`、临时文件原子替换和内容不变跳过写入，Markdown 只刷新生成标记之间的内容，JSON 保留 `manual` 字段。
- 支持 `--mark-dirty`、`--refresh-if-dirty`、`--force`；脏标记与互斥锁均在 `.Codex/docs/`，可在中断后恢复。
- 更新仓库 `.Codex/hooks.json`：编辑后只异步标脏；`Stop` 和 `SessionEnd` 强制刷新兜底。
- 未修改用户级 `~/.codex/hooks.json`：避免影响其他仓库，也无需备份或全局信任变更。
- 在第三章恢复卡顶部加入项目 Markdown/JSON 链接，明确项目导航、第三章状态和候选存废的职责分界。

## 触发与边界

- 项目 Hook 生效后：编辑后标脏，当前轮 `Stop` 或会话结束时自动刷新；不需人工提醒。
- 近实时防抖子进程在当前工具宿主中未能可靠保活，未作为已验收行为启用；不得宣称编辑后立即刷新。
- 手动恢复入口：`/opt/miniconda3/envs/rwkv/bin/python tools/update_project_index.py --refresh-if-dirty --force`。
- 停用：从仓库 `.Codex/hooks.json` 删除本任务新增的 `PostToolUse`、`Stop`、`SessionEnd` 三个区块；生成器和现有索引保留，不会自动执行。

## 验证

- `py_compile` 通过；初次生成成功，无变更第二次运行输出“内容未变”，`PROJECT_INDEX.md` mtime 保持不变。
- 临时 `.Codex/docs/000-index-probe.md` 已验证被 JSON 收录，删除后再次刷新不再出现；探针文件已清理。
- 持有 `.project-index.lock` 时并发刷新返回 `75`；JSON 和仓库 Hook 配置均可由 `jq empty` 解析。
- Markdown 保留生成标记和人工区块；未检出 `.env`、`.pem`、`config.yaml`、`/tmp`、`raw/`、`runs/` 或凭据键进入索引。
- `PROJECT_INDEX.md` 为 `5,125` 字节，JSON 为 `6,533` 字节；恢复卡中的 Markdown/JSON 链接与职责说明存在；`git diff --check` 通过。
