## 实际运行中的两个修正

### 1. TCP 行的 UDP 积压适用字段为空

首次真实物化在读取 TCP 行时停止。根因是 v2 源合同对 TCP 的 `truth_udp_backlog_applicable` 使用空值表达“不适用”，而初版适配器误要求所有行均为 0/1。

修正后：

- TCP 行只接受空值并物化为 `False`；
- UDP 行仍严格接受 0/1；
- TCP 行如携带非空 UDP 积压适用值会被拒绝。

失败阶段目录保留为：

`thesis/experiments/llm_probe/runs/data-prepared/r2-final-tcp-udp-physics-v2.partial.failed-udp-backlog-mask-v1/`

### 2. 已发布目录的状态文件仍声明原子发布未完成

第二次运行的数据、数量和哈希均正确，但 `run-state.json` 中的 `atomic_publication_completed=false` 与实际已完成的目录重命名矛盾。该版本未被接纳，原样保留为：

`thesis/experiments/llm_probe/runs/data-prepared/r2-final-tcp-udp-physics-v2.invalid-atomic-state-v1/`

最终版本将状态改为 `atomic_publication_ready=true`，并显式记录发布方法 `same_filesystem_rename_no_overwrite`。正式目录由第三次实际运行重新生成，数据制品哈希与第二次一致，仅状态文件和载荷 Merkle随之更新。
