# R2 可辨识修正性能保护设计任务计划

## 目标

在不恢复不可辨识 `sender_index`、不读取最终测试集、不削弱基线的边界内，设计保留发送者级 TCP 原始方程且保护检测性能的唯一方案。

## 阶段

- [x] 读取 TCP 修正计划和种子 42 物理诊断。
- [x] 核对物理专家、分类探针和损失的实际接口。
- [x] 核验本地 PINN 笔记与特权信息学习、知识蒸馏的一手证据。
- [x] 比较零初始化门控残差、特权物理教师蒸馏和网络级聚合辅助头。
- [x] 冻结唯一推荐、损失公式、接口草图、种子 42 验收与失败切换条件。
- [x] 完成并自检设计文档。

## 硬边界

- 旧 F-P 种子 42 开发宏平均 F1 `0.9406325189504068` 是性能参考。
- 只用训练划分和开发验证划分做方案选择。
- 推理只使用公开数据可获得观测。
- 不修改生产代码，不启动实验。

## 当前状态

已完成。唯一推荐为“一级网络级方案优先、二级特权物理蒸馏补强、三级冻结旧 F-P 锚点与零门保性能”的条件冻结合同。

## 错误记录

- 自检命令在 zsh 中误用特殊数组名 `path` 作循环变量，短暂覆盖 `PATH`，导致同一 shell 中后续命令不可见；改用 `file_path` 后重跑。
