# 研究问题卡：方法与数据实验裁决

## 研究问题

在统一的流量序列表示、生成式输出格式和单卡 RTX 5090 预算下，哪一种 3B 至 4B 基座及训练机制，能够在企业、物联网和加密攻击数据上同时改善域内检测、未见攻击和跨数据集泛化？

## 可证伪假设

### 假设 H1：生成式检测任务可学

1.7B 探针模型在三个主数据集的平衡小样本上均显著超过多数类基线，并能稳定输出合法结构。

**否证条件**：任一主数据集的宏平均 F1 不超过多数类基线 5 个百分点，或结构化输出合法率低于 95%。

### 假设 H2：候选基座存在稳定优胜者

在相同参数高效微调预算下，某个 3B 至 4B 基座在三个主数据集的平均秩和跨数据集性能上稳定领先。

**否证条件**：不同数据集的优胜基座完全相反，或领先幅度落入三个随机种子的置信区间。

### 假设 H3：第一创新点的两个机制都有效

物理一致性约束与约束可靠性调节的组合，相对普通 QLoRA、单独物理约束和单独可靠性调节，在至少两个主数据集及跨数据集测试中稳定提高宏平均 F1，并降低物理约束违反率。

**否证条件**：完整组合未超过最佳单机制，或增益只存在于一种攻击、一个数据集或一个随机种子。

### 假设 H4：性能收益与计算成本同时可接受

第三章候选方法在推理时不引入额外模型前向，并在训练 GPU 小时、峰值显存与跨数据集性能之间位于帕累托前沿。第四章候选方法通过识别无优势信号样本并自适应分配组内生成预算，在固定计算预算下改善困难与未见攻击性能，或在性能基本不降的条件下减少至少 25% 的 GPU 小时。

**否证条件**：第三章增益仅来自明显更高的训练预算；第四章既没有在同预算下提高性能，也没有在性能基本不降时减少成本；或同一基座上的推理 P95 延迟稳定增加超过 10%。

## 当前证据

- IDS2018 小模型实验提示物理不变量对不同攻击类型的有效性差异很大，固定约束可能产生负迁移。
- GeNIS、CICIoT2023 和 HIKARI 提供不同采集环境，可检验机制是否只适用于旧数据或 DDoS。
- GRPO-RCS 论文提示强化学习可能改善未见类别泛化，但它不是第一创新点成立的证据。

## 缺失证据

- 三个主数据集的统一包/流序列表示与标签映射。
- 1.7B 探针的可学性结果。
- 3B 至 4B 基座的同预算比较。
- 第一创新点四组消融及三个随机种子结果。
- 跨数据集与未见攻击测试。
- 每个基座和候选方法在同一 RTX 5090 上的训练 GPU 小时、峰值显存、生成令牌数、吞吐率与推理延迟。
- 同性能成本对比与同预算性能对比，以及多个随机种子的帕累托前沿。
