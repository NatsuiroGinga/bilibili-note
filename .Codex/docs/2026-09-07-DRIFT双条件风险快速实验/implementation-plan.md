## 预定公式与阻塞

令 `R_g^+` 与 `R_m^-` 分别为正、负类别内的源冻结形态组平均交叉熵。C00 应保留两个类别的普通平均风险；C10/C01 仅替换对应类别内部的聚合。

当前 N02 唯一可微单机制目标为 `L_A=L_0+lambda_+ Delta_+`。`Delta_+` 需要组质量 `w_g` 与温度 `tau_+`。方案明确规定不能用经验频率或未经支持审计的均匀质量，且 `w_g`、支持收缩/组合并、`tau_+` 和 `lambda_+` **均待源侧统计推导**（`第三章-DRIFT双侧漂移风险候选方案.md:263-289`）。

当前 N09 只定义 `sup_{q^- in U_shape} sum_m q_m^- R_m^-`，但没有冻结 `U_shape` 的半径或质量约束；方案还明确组交叉、支持收缩、半径与损失权重均未冻结（同文件:339-351）。统一方案进一步明确 `rho`、`lambda_+`、`lambda_-`、温度、组支持阈值和训练轮数均未冻结（同文件:405-412、485-487）。

因此，不得把均匀组质量、温度、半径或任意系数当作这些未冻结对象的替代。经构思流程，允许主代理裁决一个明确降级为标准最坏组近邻的无参数资格探针；它不得被表述为最终 N02/N09 或原创算法。
