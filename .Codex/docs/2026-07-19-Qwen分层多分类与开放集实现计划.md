# Qwen 分层多分类与开放集实现计划

> **执行要求：** 逐任务使用测试驱动开发；每个生产函数必须先有失败测试。当前计划只实现 M0-G 种子 42，M0-C 在探针结果验收后单独规划。

**目标：** 在 GeNIS v2 固定清单上完成一个共享 QLoRA 适配器的家族/子类生成式训练、严格自由生成评估和仅用域内验证校准的未知攻击拒识。

**架构：** 数据打包器负责确定性合并家族与子类任务；纯函数模块负责解析、候选分数归一化、阈值和指标；GPU 运行器只负责模型加载、批量生成与候选完成前向计算；现有跟踪层负责 SwanLab 和制品清单。

**技术栈：** Python 3.10、PyTorch、Transformers、TRL、PEFT、scikit-learn、SwanLab、uv。

## 全局约束

- 使用 `Qwen/Qwen3-1.7B`、4 位 NF4、BF16、秩 16 QLoRA和关闭思考模式。
- 只使用 `flow_probe_hierarchical_sample_v2`。
- 未知攻击不进入训练；阈值只使用域内子类验证集。
- 正式运行使用 SwanLab 在线模式并保存本地完整制品。
- 服务器命令由交互式 Bash 加载 `~/.bashrc`，同时允许用 `/root/.local/bin/uv` 作为防护路径。
- 不覆盖 v1、v2 或任何已有运行目录。

- 设计中的 v2 数据契约、单适配器多任务、严格生成、候选概率、5% 阈值预算、开放集指标、成本和 SwanLab 分步记录均有对应任务。

- 计划无待定占位项；所有新增接口、文件和验证命令已明确。
