# 第一创新点收敛实验计划

## 目标

通过可复现的分阶段实验，将“PINN 用于生成式恶意流量模型训练”收敛为一个具有明确数学对象、可微梯度路径、有效机制增量、跨数据集证据和成本边界的具体方法，并据此冻结第三章的算法名称、核心公式、理论命题、算法流程和实验结论。

## 当前判断

- HIKARI 与 GeNIS 的短训练只证明 Qwen3-1.7B 可以学习统一流量文本并生成合法标签，不能证明 PINN 创新成立。
- 当前 H1 计划只负责建立可信数据协议、传统基线和生成式基线，本身不足以确定第一创新点。
- 正式任务采用分层多分类：良性/恶意检测是一级安全指标，良性/暴力破解/拒绝服务是二级主任务，已见攻击子类分类与未见攻击拒识是三级泛化任务。不得用单一二分类满分替代多分类和未知攻击证据。
- 第一创新点最终必须至少包含一个作用于模型预测状态的物理残差，以及一个解决恶意流量观测不完整、时间尺度不一致或约束权重冲突的自主机制。
- 方法名称、缩写、定理表述和最终贡献句必须在正式消融完成后确定。

## 候选方法最小矩阵

候选方法暂不命名，按机制编号管理：

| 编号 | 训练配置                    | 目的                                           |
| ---- | --------------------------- | ---------------------------------------------- |
| M0   | 生成式监督微调              | 基础对照                                       |
| M1   | 监督微调 + 连续状态辅助头   | 区分多任务监督增益与物理残差增益               |
| M2   | M1 + 固定权重单尺度物理残差 | 建立最小有效 PINN 基线                         |
| M3   | M2 + 多时间尺度离散残差     | 验证攻击在不同时间尺度上的一致性破坏           |
| M4   | M3 + 观测可靠性门控         | 处理公开数据缺少队列、丢包或拓扑真值的问题     |
| M5   | M4 + 自适应约束权重         | 处理分类目标、状态拟合和物理约束之间的梯度冲突 |

如果 M3、M4 或 M5 没有独立增益，则不纳入最终算法。Stiefel-LoRA 和 mHC 只在主 PINN 机制确定后作为训练稳定性候选消融，不得替代物理约束成为第一创新点。

## PINN 数学裁决要求

每个候选公式进入 GPU 实验前必须满足：

1. 状态量由模型连续输出头预测，并与分类头共享可训练参数。
2. 物理残差对共享参数的自动微分梯度范数大于零。
3. 方程两侧量纲一致，离散时间步长和归一化方式有明确含义。
4. ns-3 提供队列、到达、离开、丢弃和容量真值，用于监督状态头并验证残差单调性。
5. 公开数据缺少真值时使用显式观测掩码或可靠性权重，不能把缺失值静默填零。
6. 正常高负载、容量突变、随机丢包和攻击流量必须分开验证，防止把所有高负载误判为攻击。

## 正式效果裁决

最终方法必须同时报告：

- 检测指标：一级恶意召回率与误报率、家族宏平均 F1、已见子类宏平均 F1、未知攻击召回率、开放集分类率、精确率-召回率曲线下面积和严格 JSON 有效率。
- 泛化指标：GeNIS 未见攻击场景、DEDALE 时间外推及少样本比例下的性能变化。
- 机制指标：状态预测误差、物理残差分布、残差与错误样本的关系及正常高负载反例。
- 稳定性指标：至少随机种子 42、43、44 的均值、标准差和逐次运行数据。
- 效率指标：可训练参数、峰值显存、训练时长、单样本推理时延和吞吐量。
- 消融矩阵：M0 至最终最小有效组合，以及时间尺度、门控和约束权重的敏感性。

## 跨基座可移植性验证门

- 跨基座验证是阶段 E 的必做项，但不得与阶段 C、D 的公式和机制筛选并行。
- 先在 Qwen3-1.7B 上完成 M0 至 M5，删除无稳定增益的组件并冻结最终方法、状态定义、物理残差和损失权重。
- 再选择一个非 Qwen、1B 至 3B、可访问共享隐藏表示且能在单块 RTX 5090 上训练的开放权重解码器。
- 第二个基座至少运行监督基线、连续状态辅助和最终 PINN 方法，不必机械重复全部 M0 至 M5；若种子 42 方向合理，再补种子 43、44。
- 两个基座必须复用相同数据清单、序列表示、输出协议、物理公式和评价指标。仅允许为显存适配调整批量大小、梯度累积等工程参数，任何方法超参数重调必须单独披露。
- 若第二个基座未复现方向一致的增益，论文贡献边界必须收缩为 Qwen3-1.7B 或 Qwen 类小型解码器，不得声称一般模型可移植性。

## 论文可立即撰写的内容

在方法尚未冻结时，可以正式撰写：

- 第三章研究问题、应用场景和现有监督训练的局限。
- 基座模型、流量序列表示、任务定义和符号系统。
- PINN 基本原理、物理约束必须作用于可微预测状态的理论说明。
- 数据集角色、防泄漏划分、评价指标、效率指标和实验环境。
- 公式证据台账中已经核验的基础守恒律及其不适用于原始流级字段的原因。

暂不定稿：

- 新算法名称和缩写。
- 最终连续状态向量、核心残差和自适应权重公式。
- 定理、引理及其成立条件。
- “优于现有方法”或“提升多少”的结果性贡献句。
