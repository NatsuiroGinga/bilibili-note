## 唯一生产阻断与最小修复

v3 `artifact-manifest.json` 是 3147 项文件清单，每项仅含 `logical_path`、`sha256` 和 `size_bytes`，不能从中严格推导场景、合同和冻结清单身份。`matrix-summary.json` 已真实登记 `scenario_source_sha256`、`contract_sha256` 和 `manifest_sha256`，是现有 v3 制品中唯一完整的顶层来源身份载体。

最小修复应只修改 `scripts/r2_final_tcp_udp_physics_v2_materialize.py` 的顶层合同校验：对 v3 配置直接从已按 SHA-256 绑定的 `matrix-summary.json` 校验上述三个字段，不再要求不存在的 `ns3_source_lock` 输入；旧 v2 配置仍沿用旧 `source-lock.json` 分支。修复不得生成事后占位来源锁，也不得放宽逐运行收据、CSV 哈希、512 项覆盖、方向字段和最终测试隔离门禁。
