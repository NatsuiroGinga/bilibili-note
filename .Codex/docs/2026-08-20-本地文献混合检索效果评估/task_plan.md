# 本地文献混合检索效果评估计划

## 目标

在不修改生产代码、`raw/`、`wiki/`、Zotero、论文和实验的前提下，用离线缓存模型严格评估本地词法、向量和混合文献检索的实际表现。

## 边界

- 只读输入：`wiki/papers/**/*.md`、现有任务证据矩阵、检索工具代码与说明。
- 可再生输出：`.cache/literature-search/index.sqlite3`。
- 独占提交范围：`.Codex/docs/2026-08-20-本地文献混合检索效果评估/`。
- 禁止修改或暂存：`scripts/literature_search/`、`raw/`、`wiki/`、`thesis/`、`output/`和 Zotero。
- 禁止联网下载或更换向量模型；索引构建和评测必须加 `--offline`。

## 评估合同

- 评估单元：一条冻结查询。
- 比较方法：`lexical`、`vector`、`hybrid`，共用同一索引、查询集和返回深度。
- 主指标：`Recall@5`、`Recall@10`、`MRR@10`、首个相关结果排名和端到端查询延迟。
- 辅助指标：逐查询混合增益、持平或退化，中位延迟和第 95 百分位延迟。
- 相关性真值：必须由既有证据矩阵、全文笔记或已知题录人工冻结，不允许用本次检索输出反向定义。
- 查询覆盖：不少于 12 条，含中文、英文、同义表达、公式或机制描述、作者或题名、跨领域近邻和无结果负例。
- 推断边界：查询集是目的性小样本，不做显著性检验，不宣称全局性能提升。
