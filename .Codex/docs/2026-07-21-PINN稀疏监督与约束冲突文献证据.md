# PINN 稀疏监督与约束冲突文献证据

- **日期**：2026-07-21
- **问题背景**：任务九中，Qwen3-1.7B 的 M2 在完整覆盖 807 条物理训练序列后，生成验证损失、状态均方误差和物理残差均方误差均劣于 M1。
- **资料范围**：先回读 `raw/papers/pinn/` 中的原始 PINN、综述和本地结构化笔记，再核验论文原文、会议论文集、出版社或 arXiv。一手来源链接见文末。
- **边界**：本文提炼建模原则和实验假设，不把道路车辆交通公式移植为互联网分组队列公式，不修改实验代码和实验总控。

## 1. 结论

**当前 M2 的负结果更像“密集状态监督使守恒残差只剩误差整形作用，并引入多目标优化冲突”，而不是“Qwen3-1.7B 太强所以无法提升”。**

理由有四点：

1. 当前状态损失逐点监督全部五个绝对队列锚点；守恒残差只使用这些锚点的相邻差分。真值守恒时，物理残差完全由状态预测误差的差分决定，没有新增目标信息。
2. 当前物理残差看不到五个锚点的共同平移。没有至少一个绝对边界锚点时，即使残差为零，绝对队列状态也可能全部偏移。
3. 本地梯度诊断已显示生成与物理梯度在 `20/20` 个真实批次中方向冲突；固定权重和只保护生成目标的 M2P 均已失败。
4. PINN 文献中最可靠的数据效率证据来自“状态观测稀疏但方程、通量与初边界条件足以闭合”的场景，而不是把物理损失重复施加到每个已有精确标签的位置。

因此，下一项机制实验应先把物理约束放到它有机会提供新增信息的条件下：**边界锚定的部分状态监督**。只有该实验显示物理项能恢复未标注状态，才值得继续测试三目标梯度协调。

## 2. 问题一：密集状态监督下物理残差是否冗余

### 2.1 当前任务的结构性推导

设五个真实队列锚点为 `q`，预测为 `q_hat`，误差为 `e=q_hat-q`。设 `D` 是计算四个相邻差分的算子，`W` 是由公共尺度和每窗容量组成的对角归一化。由于 ns-3 真值已经通过守恒复算，当前预测残差可等价写成：

```text
预测物理残差 = W × D × 状态误差
```

这是对当前实现的自主推导，不是照抄论文公式。它给出三个直接结论：

- 当五锚点状态误差为零时，物理残差必然为零。
- 物理项不增加新的监督目标，只额外惩罚相邻锚点误差的变化。
- `D` 对常数向量的输出为零，所以五个预测锚点共同上移或下移时，物理残差不变。

因此，密集状态监督下的物理项并非数学上“完全无作用”，但其作用是改变损失面的曲率和不同误差方向的权重，而不是补充新标签信息。它可能平滑相邻状态，也可能因与生成任务争用共享表示而恶化训练。

该推导与本地测试一致：`test_uniform_state_shift_exposes_physics_null_space` 已证明整体平移不改变残差；任务九又证明完整覆盖并不能逆转负结果。

### 2.2 文献证据

- [Krishnapriyan 等，NeurIPS 2021](https://proceedings.neurips.cc/paper_files/paper/2021/file/df438e5206f31600e6ae4af72f2725f1-Paper.pdf)表明，把微分算子作为软正则会使问题更病态，失败不一定来自网络表达能力；课程正则和序列学习能缓解部分失败，但不是普遍保证。
- [Rohrhofer 等，Data vs. Physics](https://arxiv.org/abs/2105.00862)把数据与物理训练明确视为受系统尺度影响的多目标问题。量纲和参数化会移动梯度训练能够达到的表观 Pareto 前沿，因此固定权重并非稳定解法。
- [Wang、Yu、Perdikaris，Journal of Computational Physics 2022](https://doi.org/10.1016/j.jcp.2021.110768)从神经切线核角度显示不同损失分量可能具有显著不同的收敛速率。
- [Wang、Teng、Perdikaris，SIAM Journal on Scientific Computing 2021](https://doi.org/10.1137/20M1318043)指出 PINN 复合损失的反向梯度可能存在数值刚性和严重失衡。

### 2.3 适用边界

不能把“目标信息冗余”扩大成“物理约束永远无用”。在以下条件下，相同守恒关系仍可能有用：

- 部分队列锚点没有状态标签，但相邻通量可观测。
- 状态标签含噪，而守恒关系和通量测量更可靠。
- 测试工况偏离训练标签覆盖，但控制关系仍成立且工况变量已显式输入。
- 物理约束采用硬结构缩小输出空间，而不是继续增加软损失竞争。

## 3. 问题二：稀疏或部分标签 PINN 的有效条件

### 3.1 必要条件

| 条件               | 当前任务中的含义                             | 缺失后的失败方式                       |
| ------------------ | -------------------------------------------- | -------------------------------------- |
| 约束正确           | 到达、出队、两类丢弃和窗口边界完整记账       | 错误通量把模型推向错误状态             |
| 至少一个绝对锚点   | 每条四窗口序列保留 `q0` 或等价边界           | 整体平移零空间导致绝对状态不可辨识     |
| 残差覆盖未标注位置 | 在 `q1` 至 `q4` 无标签处仍计算守恒           | 物理项只重复已有标签，无法证明数据效率 |
| 动力学条件显式输入 | 当前容量起止值、容量积分和到达量继续作为输入 | 跨容量或跨负载变化无法由模型辨别       |
| 完整工况留出       | 按场景或容量变化留出，不在同场景随机抽窗     | 只测插值，不是跨工况泛化               |
| 绝对状态评价       | 单独报告未标注锚点均方误差                   | 低残差掩盖整体偏移或平凡解             |

### 3.2 文献证据与限制

- Raissi 等本地原文 `raw/papers/pinn/1711.10561.pdf` 和 `raw/papers/pinn/1711.10566.pdf` 的核心设定是少量观测配合大量方程配点、初值和边界条件。可迁移的是“物理约束在无标签位置提供信号”，不是其连续偏微分方程形式。
- [Mishra、Molinaro](https://arxiv.org/abs/2007.01138)的逆问题误差分析依赖底层问题的条件稳定性，说明“稀疏数据加物理”只有在问题可辨识时才有理论依据。
- [Wang 等，L4DC 2024](https://proceedings.mlr.press/v242/wang24b.html)进一步表明，在其柯西问题中，仅最小化二范数残差和初值误差不足以保证真实解。对本任务而言，低残差不能替代未标注绝对状态误差。
- [Usama 等，Algorithms 2022](https://doi.org/10.3390/a15120447)在道路交通网络中用稀疏传感状态、路段动力学和交叉口守恒联合估计完整状态；论文也报告实际数据与理想交叉口守恒不一致时误差增大。
- [Huang、Agarwal，2023](https://arxiv.org/abs/2302.12336)同样把守恒用于低数据量下未观测区域重建。两篇道路交通论文只能支持稀疏状态重建的实验动机，不能作为互联网队列性能证据。

### 3.3 不成立的实验设计

- 随机删除整条序列的全部五个锚点，却只用差分残差评价成功。
- 保留全部五锚点状态监督，只把训练样本从 807 增加到更多曝光次数。
- 在同一场景内随机分窗口，再把测试结果称为未见负载或未见容量外推。
- 使用测试场景标签决定保留哪些状态锚点或调节权重。
- 只报告残差下降，不报告未标注锚点绝对误差和生成损失。

## 4. 问题三：数据损失与物理损失梯度冲突

### 4.1 当前证据已经排除什么

| 方法               | 当前证据                                             | 裁决               |
| ------------------ | ---------------------------------------------------- | ------------------ |
| 固定物理权重       | `0.001`、`0.01`、`0.03`、`0.1` 均未通过综合门槛      | 不再扫描           |
| 只增加物理样本覆盖 | 202 步完整覆盖后三项均恶化                           | 不再靠延长曝光解释 |
| 两目标生成锚定投影 | M2P 改善生成和残差，但状态误差相对 M1 恶化 `119.20%` | 不再扩展同类投影   |
| 单纯梯度范数平衡   | 当前物理梯度并未压倒生成梯度，主要现象是方向冲突     | 不是首选           |

### 4.2 文献中的可用路线

1. **梯度统计或动态缩放**：适合损失尺度差异，但不保证解决持续负夹角。[MultiAdam](https://proceedings.mlr.press/v202/yao23c.html)在偏微分方程基准上取得显著改善，但没有生成式大模型证据。
2. **课程或分阶段训练**：先学习较易边界或短时动力学，再逐步施加复杂物理项。NeurIPS 2021 的结果支持这一方向，但当前残差本身不复杂，若密集监督下仍使用它，课程只可能延缓而非消除冗余。
3. **三目标共同下降**：[ConFIG，ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/94e85561a342de88b559b72c9b29f638-Paper-Conference.pdf)为每个损失构造正投影的共同更新方向，并在三个以上损失时区别于简单两目标正交投影。这直接对应当前生成、状态、物理三个共享目标。
4. **二阶或准二阶梯度对齐**：[Wang 等，2025 预印本](https://arxiv.org/abs/2502.00604)报告准二阶优化在十个 PINN 基准上的改善，但其 39 页预印本尚不能为 Qwen 低秩适配提供充分迁移证据，计算和实现成本也明显更高。

### 4.3 为什么不能立即把 ConFIG 当成最终方案

- ICLR 论文的主要 PINN 证据来自四类偏微分方程的小型坐标网络，不是 Transformer。
- 论文中的 CelebA 只证明方法可迁移到一般多任务学习，不等于生成式恶意流量检测有效。
- 完整 ConFIG 需要分别计算各损失梯度；动量加速版本会在损失数量增加时受梯度陈旧影响。
- 当三个目标不存在共同下降方向时，共同更新可能趋近于零；这应作为停止信号，而不是继续加入权重。
- 若物理目标在密集监督下没有新增信息，成功协调其梯度也不构成有意义的方法增量。

## 5. 问题四：队列守恒与跨工况外推

### 5.1 可迁移的队列建模原则

当前离散控制体思路是合理的：队列边界状态由窗口内进入、离开和丢弃通量连接，且使用容量预算无量纲化。队列流体模型文献也把队列长度视为受零边界反射的净输入过程；例如 [Honnappa、Jain、Ward](https://arxiv.org/abs/1206.0720)明确区分自由演化、反射和零过程等运行区间。

对当前任务，守恒约束只有同时满足以下语义才可靠：

- 队列为空时不能通过负队列“解释”过量服务。
- 队列接近容量时，溢出必须进入丢弃通量，而不是凭空消失。
- 容量切换窗口必须使用同一时间边界和同一积分口径。
- 到达、出队、队列规则丢弃和设备或链路层丢弃不能跨层混算。
- 场景标签不进入状态头输入，避免把攻击类别当作动力学捷径。

### 5.2 跨工况外推不能由守恒自动推出

本地 Evo-PINN 综述原文已经提醒：普通 PINN 多针对一个物理实例训练，并不天然泛化到变化的方程参数、初值或边界条件。[2024 年训练域外研究](https://link.springer.com/article/10.1007/s00521-024-10178-2)也显示，增加配点超过足够覆盖后未必继续改善域外表现，网络更深也可能使域外预测变差。

因此，跨工况证据应采用完整场景留出，而不是继续使用当前按随机种子划分但场景齐全的协议。当前七场景中，除 `benign-random-loss` 外多项轨迹在三个随机种子下实际上完全相同，跨种子不等于跨工况。

优先留出建议：

- **容量变化留出**：训练不含 `benign-capacity-shift` 和 `dos-udp-capacity-shift`，测试只使用这两类完整场景。
- **负载强度留出**：训练低、中负载，测试 `dos-udp-high`，且不得在测试标签上调参。
- **随机损失留出**：训练无链路误码场景，测试 `benign-random-loss`，检查物理项是否把非攻击损失误判为攻击机制。

如果现有 21 组数据不足以支持稳定留出，应先扩展 ns-3 工况网格，而不是用同一轨迹的更多重叠四窗口代替工况覆盖。

## 6. 最值得验证的两个机制

### P0：边界锚定的部分状态监督

**目的**：直接检验物理残差能否在状态标签稀缺时提供新增信息。

建议最小对照：

| 变体 | 状态监督                                   | 物理残差       |
| ---- | ------------------------------------------ | -------------- |
| S1   | 每条序列只监督 `q0`                        | 无             |
| S2   | 每条序列只监督 `q0`                        | 四窗口全部启用 |
| S3   | 监督 `q0`，并按固定掩码监督 25% 的内部锚点 | 无             |
| S4   | 与 S3 相同                                 | 四窗口全部启用 |

控制要求：

- 掩码按 `group_id` 和随机种子预先生成，M1/M2 完全共用。
- 状态标签掩码只作用于绝对锚点损失；通量真值仍只用于物理残差。
- 先用随机种子 42 做短预算机制筛选；通过后再做 42、43、44 三种子和完整场景留出。
- 同时保留现有密集 M1/M2 作为“物理信息冗余时的负对照”，无需为相同配置重新扫权重。

主要指标：

- 未标注 `q1` 至 `q4` 的绝对状态均方误差。
- 全五锚点状态均方误差和物理残差均方误差。
- GeNIS 生成验证损失。
- 按七场景、负载区间、队列是否为空和容量是否切换分层的误差。

预注册通过条件建议：相对状态掩码完全一致的无物理基线，未标注锚点误差和物理残差均至少下降 `10%`，生成验证损失恶化不超过 `5%`；通过短预算后还须在三种子或完整工况留出中保持同向。阈值是当前实验的工程门槛，不是文献定理。

可证伪结果：

- 只降低残差但未标注绝对状态不改善，说明模型落入平移零空间或平凡解。
- 稀疏监督下仍三项同时恶化，说明当前通量残差或生成任务配对不能提供有用增量。
- 只在同场景插值有效、容量变化留出失败，说明约束没有形成跨工况能力。

### P1：三目标共同下降，仅在 P0 通过后测试

**目的**：若 P0 已证明物理项包含新增信息，但仍与生成和状态目标冲突，再检验同时保护三个共享目标是否优于 M2P。

最小机制：

- 共享低秩适配参数同时计算生成、状态和物理三个梯度。
- 合成更新必须与三个梯度均为非负内积，而不是只把物理梯度投影到生成梯度的正交面。
- 状态头只处理状态和物理两个目标，但必须记录最终更新与二者的点积。
- 第一轮只实现完整三目标共同下降，不引入动量近似、权重搜索或二阶优化。

验证指标：

- 每步最终共享更新与三个原始梯度的内积及余弦。
- 无共同下降方向或更新范数接近零的步数。
- 与同一稀疏掩码 S2/S4 的生成、未标注状态和物理指标严格比较。
- 单步训练时间、峰值显存和额外反向传播次数。

通过条件：生成损失不超过匹配无物理基线 `5%`，同时未标注状态误差和物理残差均优于该基线；如果只有残差下降、状态或生成退化，则删除该机制。

**前置门禁**：P0 不通过时不实现 P1。这样可避免把优化复杂度用于一个已经证明不含新增监督信息的目标。

## 7. 不建议现在做的实验

- 更换为更弱基座来人为制造提升空间。
- 继续扫描固定 `lambda_physics`。
- 继续增加同一 807 条物理序列的曝光次数。
- 在密集五锚点监督下直接加入多尺度残差。
- 直接采用完整二阶优化、进化权重搜索或动量 ConFIG。
- 只看物理残差，不评价未标注绝对状态。

## 8. 证据强度与局限

- **强证据**：当前残差的差分零空间来自实现和测试，可直接验证；任务七至任务九的冲突与负结果来自真实运行。
- **中等证据**：PINN 软约束病态、损失收敛速率失衡和多目标冲突已有多篇一手论文支持，但其理论假设和模型规模与 Qwen 不同。
- **类比证据**：道路交通 PINN 支持“守恒帮助稀疏状态重建”的动机，不是互联网恶意流量证据。
- **待验证假设**：边界锚定稀疏监督会改善生成式恶意流量检测，或三目标共同下降适用于低秩适配训练。目前没有直接论文证据。

最重要的论文解释边界是：**物理约束只有在减少未标注状态的不确定性时才可能提供新增信息；能降低残差，不等于能恢复正确绝对状态，更不等于能提高攻击分类。**
