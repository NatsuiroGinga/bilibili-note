# DRIFT 正式攻击与目标抽样合同裁决计划

## 一、任务与边界

本任务只冻结正式评价合同，不改变训练方法、模型、候选臂或既有筛选结论。需要裁决三项：

1. 历史 `krand` 键当前重复调用 `perturb2`，正式实验应改为真实随机编辑数、固定强度阶梯，还是仅作为重复流重命名。
2. T20–T25 目标知情逐年面板应全量评价，还是使用有统计与资源依据的固定抽样；若抽样，必须冻结成员发现、样本量、随机性、指标和不允许的论断。
3. 当前正式脚本用固定概率阈值 `0.5` 计算全部 FPR/FNR/F1；需要冻结与低误报问题一致的源验证阈值工作点，并区分阈值无关指标、源冻结评价和目标年重标阈值。
4. 当前正式脚本只在 T18 生成攻击，T20–T25 只评价干净成员；必须裁决是否在六个目标年同一固定 DGA 成员上生成三档攻击，才能回答跨年对抗保持。

本任务属于 **architectural**：它改变正式评价接口与数值合同。研究问题、证据、备选设计与用户审批已经完成；用户于 2026-09-13 批准实施，并于14:37重申禁止新增物化。当前按已修订计划实现现有Parquet直读和运行时编辑；历史训练脚本及MP运行保持原身份，正式新入口须经对应真实数据与恢复验证。

## 三、验收

- 每个数值都有统计推导、数据规模、适用边界和是否接触目标标签的登记。
- 攻击面板不能重复测量同一个二位替换分布并使用不同名称。
- 目标抽样不能依赖模型输出或最终目标指标选择成员；必须跨臂共享同一成员清单。
- 明确区分源冻结阈值 FPR、目标 ROC 上界、FNR/TPR、AP/F1 的样本比例语义。
- 对抗纯 DGA 面板必须用源验证良性分数冻结的阈值报告 FNR，不能在攻击面板内部重标阈值。
- 书面设计必须列出保留、废弃和迁移兼容策略；用户批准前不实现。
