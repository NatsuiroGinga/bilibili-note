# B-ResNet B 臂实现修复报告

日期：2026-09-13

## 结论

已完成已批准 B 臂的最小实现修复。B 现在对应“朴素随机编辑增广（B）”，但本轮未启动训练、评价或数据物化，因此尚无新的 B 效果结果。

## 修改内容

- 在 `bresnet_p2p3.py` 的训练循环中新增 B 分支：每个主批内的恶意成员生成一个 `official_p2p3.perturb2` 变体，并按原样本索引缓存；追加变体及恶意标签 `1`。
- 追加样本后继续使用既有子批梯度累积，损失分母使用扩展批总数 `n_tot`，尾部子批仍按同一分母归一化。
- D/F 的四候选组相对筛选、G 的良性误报加权，以及 A/D/F/G 的随机种子、初始化、数据成员、学习率、批量、轮数、旧筛选面板和 `0.5` 阈值路径均未改动。
- CLI 现在只接受 `A/B/D/F/G`，未知臂、重复臂和空臂返回码均为 `2`，合法臂保持用户给定顺序；B 的首条训练日志和结果 `spec.arm_display_names` 标明“朴素随机编辑增广（B）”。
- 结果 `spec` 新增 `implementation_version`、在 `main` 数据/模型加载前冻结的 `code_sha256` 和臂展示名；未覆盖既有 `bresnet-p2p3-result.json`。
