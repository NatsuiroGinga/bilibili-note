# 任务计划：加密恶意流量检测论文实验论证综述

## 目标

基于可核验全文与官方数据集记录，判断第三章是否应把“跨加密条件”设为核心研究问题，并给出更稳妥的单数据集研究问题及最小实验论证路径；同时裁决是否把 TQH-C2 v1.2.0 冻结为唯一公开检测数据集，以及 GeNIS 在正式协议中的角色。

## 研究问题卡

- **问题**：TQH-C2 单数据集上的第三章，最适合以跨加密、域内检测、跨场景/跨时间、少样本/开放集、解释性或效率中的哪一类为核心？
- **类型**：应用型与验证型。
- **假设**：只有在训练与测试间系统改变加密协议或传输栈、且控制工具家族、攻击行为、采集环境和时间等混杂因素时，才能把性能差异归因于“跨加密”；TQH-C2 的 B/D 受控对照更可能支持配对协议栈迁移或鲁棒性证据，而不足以单独支撑普遍的跨加密泛化。
- **重要性**：决定第三章主问题、数据划分、基线和可允许的论文措辞。
- **已核验证据**：8 篇核心论文全文、4 篇支撑论文全文、TQH-C2 v1.2.0 官方记录与轻量制品、Testbed D 字段和标签，以及截至 2026-08-06 的外部使用检索结果。
- **仍有限的证据**：未下载并重解析约 39.86 GB 的全部 PCAP；匿名 GitHub 代码搜索受接口鉴权限制；未获得作者缺失的 `extract_features.py` 与 D 采集脚本。
- **支持条件**：跨条件论文普遍以协议/加密条件为显式独立变量；B/D 的样本单位、标签语义与行为匹配可形成无泄漏的成组划分；跨条件主张有独立测试和适当基线。
- **证伪条件**：B/D 除协议栈外存在不可控的工具、场景、时间或实现差异；或现有全文显示单数据集研究更常以时间、场景、家族、开放集等问题构造并获得更强论证。
- **最小下一步**：完成六阶段检索与全文证据矩阵，随后冻结第三章主问题和最小对照实验。
- **决策状态**：检索后裁决。

## 范围与标准

- **时间**：优先 2022—2026 年；经典关键论文可前溯。
- **纳入**：恶意加密流量或命令与控制流量检测；全文可得；数据划分、比较实验或消融足以核验。
- **排除**：只做普通应用分类；仅摘要或搜索片段；无法核验实验协议；与检测问题无关的流量生成、纯密码学或流量测量工作。
- **优先来源**：原论文、出版商、arXiv、DOI、数据集官方记录、官方代码；二手网页仅用于发现。
- **证据位置**：每条关键论断记录 PDF 页码、章节、表号或官方记录字段。
- **停止条件**：至少 8 篇高相关全文；至少 4 篇明确划分/消融/外部比较；TQH-C2 使用情况完成官方引用、题名、DOI/Zenodo 引用与代码搜索；缺失结果只表述为“截至检索日未检得”。
- **禁止事项**：不得伪造全文阅读、引用、下载、Zotero 状态或论文不存在结论；不得运行或干扰 GPU 实验。
