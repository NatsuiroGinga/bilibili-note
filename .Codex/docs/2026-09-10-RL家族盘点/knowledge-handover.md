### 1. SAPO — `2511.20347`（Qwen Team，9 页）

- **机制**：目标式(5)(6)（p.3）`J = E[(1/G)Σ_i(1/|y_i|)Σ_t f_{i,t}(r_{i,t})Â_{i,t}]`，门函数 `f(x)=σ(τ(x−1))·4/τ`，正负优势取不同温度；梯度式(7)(8)（p.3）：`w=4p(1−p)` 在 `r=1` 取 1、两侧近似指数衰减 → **连续信任域**。§4 给出统一门控视角（式(10)–(15)，p.4–5），SAPO 在小步长假设下收敛为序列级软门 `sech²((τ/2)log s_i)`。
- **读数**：受控实验 Qwen3-30B-A3B-Base 冷启动，`τ_pos=1.0`／`τ_neg=1.05`（§5.1，p.7）；温度消融三档 `(1.05,1.0)` 最稳、`(0.95,1.0)` 显著不稳；**GSPO 与 GRPO-R2 早期即坍塌，SAPO 不需 routing replay**（图 4）。**正文无任何最终基准数值表**，只在图内。
- **可迁移点**：门函数**只读重要性比率与优势符号，不读奖励内部结构** → 机制上不要求奖励可验证。**这是本课题推论，论文无该场景实验**（论文全部是数学推理与 Qwen3-VL 多模态）。另：负向梯度经式(9)（p.3）论证会抬高大量未采样 token 的 logit，是"动作空间远大于合意输出"场景的通用诊断。

### 2. GMPO — `2507.20673`（UCAS/CUHK/HKUST/MSRA，16 页）

- **机制**：只换聚合算子——算术平均 → 几何平均，`J_GMPO = E[{Π_t |min(ρ_tÂ, clip(ρ_t)Â)|}^{1/|o|}·sgn(Â)]`（式(3)(4)，p.3）。理论（§3.2，p.4）：两者都是策略梯度加权和，**GRPO 的 token 权重含该 token 自己的 ρ_{i,t}，GMPO 含整条序列全部比率的几何平均**。
- **读数**：R1-Distill-Qwen-7B 五基准平均 Pass@1 **63.4 vs GRPO 59.3（+4.1）**；Qwen3-32B（MoE）MATH500 **96.7 vs 94.6**；Qwen2.5-VL-7B Geometry3K **54.7 vs 53.3**（表 1–2，p.5）。消融：去掉 `1/|o|` 归一化降 0.7（p.5）——**与 Dr. GRPO 主张方向相反，引用须并列**。
- **可迁移点**：**§4.4（p.9）是熵坍缩的直接证据链**——"加宽裁剪区间只能暂时鼓励探索，熵随后仍快速下降"，原因是算术平均对异常值敏感 → 激进更新急剧压熵。同节 p.6 用**梯度范数稳定 + 低 KL** 作稳定训练的联合判据，并指出 GRPO 侧"梯度范数不稳、KL 大"。**该文外部二手来源对其机制描述均不准确**，以原文为准。

### 3. GFPO — `2508.09726`（Microsoft Research / UW-Madison，29 页）

- **机制**：每问题采样更大的组 G，按度量（长度／token 效率=奖励/长度）排序取 top-k，**优势的 μ_S、σ_S 只在保留子集 S 内计算**，被拒样本优势置零（式(2)，p.3–4；算法 1）。**干预只在优势估计层**，可与 DAPO／Dr. GRPO 叠加（p.4）。自适应难度版用 t-digest 按难度分档给 k=4/6/8（16 采样中选，算法 2，p.4）。
- **读数**：Phi-4-reasoning 上把 GRPO 的长度膨胀削减 **46–71%**（长度过滤）／**71–85%**（token 效率过滤），**准确率保持**（摘要，p.1）。代价是训练时采样开销更高——**引用削减比例必须同时给这个代价**。
- **可迁移点**：① 把数据过滤当作**隐式奖励塑形**，是"多目标难加权求和"时的替代路径（作者原话 p.3）；② 基线的作用域可以收窄，"只在已满足目标属性的子集内比较"是一个**与奖励函数正交**的干预点；③ 难度信号用**组内平均奖励**，不需要额外难度模型。

### 4. LitePPO — `2508.08221`（Alibaba 等，25 页）

- **机制**：统一框架内**隔离评测**每个技巧后，只剩两项稳健：① 优势归一化用**组级均值 + 批次级标准差**（Takeaway 3，§4.1.2，p.7）；② **token 级损失聚合**（Takeaway 7）。两者配 vanilla PPO 损失、无 critic 即 Lite PPO（§5，p.11–12）。
- **读数**：Qwen3-4B/8B-Base 上稳定超越 GRPO 与技巧堆叠的 DAPO（图 15，p.11–12）——**正文无最终数值表**。Takeaway 2（§4.1.1，p.4–6）：奖励分布高度集中时 `std` 趋小，**除以 std 会把梯度异常放大**（"难度偏置"），去掉 std 反而更稳。作者在结论中明确限定**只用 Qwen3 系列**，结论可能不跨模型族成立（§6，p.12）。
- **可迁移点**：① **"技巧不是普适的"是可迁移的方法论**——同一技巧在 Base 与对齐模型、易与难数据上方向可相反，本课题引入任何技巧前应先做**隔离评测**；② 小分母诊断（训练中奖励 std 曲线）是一条廉价前置检查；③ 超长过滤会削弱长尾复杂样本学习（Takeaway 8）——引 DAPO 时必须并列此反证。

### 5. GTPO／GRPO-S（Tan） — `2508.04349`（22 页）

- **机制**：Dynamic Entropy Weighting（§2.1，p.2）——成功序列的**高熵** token 给奖励加成，失败序列的**低熵** token 加重惩罚；GTPO 是 token 级实现（式(7)，p.4，分母为批次 token 总数），GRPO-S 是序列级（式(10)，p.4）。
- **读数（表 1，p.6，Qwen2.5-7B）**：AIME24 Mean@32／Pass@32：GRPO 28.36／46.01、DAPO 21.2／35.51、GTPO **34.23／64.89**、GRPO-S 34.67／64.76。作者自述增益随规模递减（7B +29.4 → 32B +9.9）。DAPO 在 7B 上低于 GRPO 属异常，作者未解释。
- **理论（§2.4，p.5–6）**：命题 2.2 **正奖励质量守恒**（`α₁+α₂=1` 时每步塑形正奖励之和 = 原始二值奖励之和）；命题 2.3 渐近无偏**依赖"熵巩固条件"**（后期成功路径间 token 熵差异趋于 1）；定理 2.4 与 DAPO 共享全局最优。**式(14)（p.6）`E[∇J⁺] = E[∇J_GRPO] + E[Cov(Δ_entropy, ∇logπ_θ)]`**。
- **可迁移点**：**这是全库中最接近"相对熵构造"的东西**——熵以**零和再分配**的协方差项进入，目标对绝对熵水平不变。守恒性是一条可复用的设计纪律。

### 6. GTPO（Simoni） — `2508.03772`（20 页）

- **机制**：两病灶（§4，p.2–3）：① token 级惩罚导致同位置共享 token（**首尾格式标签**）收到方向相反的梯度；② 策略坍塌。对策一：冲突掩码**只覆盖首个与末个连续冲突跨度**、不动中段，`λ=0`（冲突且负）／`1`（非冲突）／`2`（冲突且正）（式(8)(9)，p.4），并用 `Σ_{G⁺}|A_i| = Σ_{G⁻}|A_i|` 论证**总信号幅度守恒**。对策二：熵控制（§5.2，p.5）——**先测训练前平均熵 `<H>_ini`**；`>ln2` 不过滤，`<ln2` 则丢弃平均熵超 ln2 的完成项优势信号（式(10)）；式(11) 的熵项取**最小化**（`−γ·<H>_i`，γ=0.1）。**不用 KL、不需参考模型**。
- **读数**：LLaMA 8B、Qwen2.5 3B，GSM8K/MATH 训练，AIME24/25、AMC2023 分布外评测；**单次迭代设置**（`π_θ=π_θold`，裁剪不生效，§6 p.6）；2×A100。分布外结果以图呈现，**正文无数值表**。
- **可迁移点**：**`<H>_ini < ln2` 门槛是我读到的唯一"低熵模型上的显式前置门"**，且其方向是**削减更新**而非加强；其对低熵模型的论断原句是"施加梯度有放大不确定性、加速坍塌的风险"。冲突检测按位置对齐即可实现，无需额外模型。

### 7. P-GRPO／ReCode — `2508.05170`（浙江大学，19 页）

- **机制**：`R_i = R_fmt + R_out + I(R_out=1)·R_proc`（式(1)，p.3）——**用执行结果硬门控神经过程奖励**。副产品：标准 GRPO 全对组优势为零，门控项在功能正确的解之间因推理质量差异**引入非零方差**（p.3）。配套 CRPL 用"优化／退化"合成变体训练奖励模型（§2.1），LCB-RB 基准用 880 个 LiveCodeBench 问题构 187 对偏好（§3）。
- **读数**：7B 相对基座 **+16.1%**，相对 outcome-only RL **+4.5%**（两个数字参照系不同，**不可混用**）；LiveCodeBench 50.4→57.4；数学域外推相对 +7.3%（§5）。
- **可迁移点**：**"可验证信号做硬门、神经信号做细粒度区分"**——把不可靠的神经网络奖励放在可靠信号的**下游**而非并列相加。**对本课题的无标签适应场景要警惕**：门控项 `I(R_out=1)` **要求存在可验证硬信号**，本文**没有**解决"硬信号完全不存在"的情形。

### 8. VAPO — `2504.05118`（ByteDance Seed，13 页）

- **机制**：**保留价值模型**（与全库其余 critic-free 路线相反）。三病灶（§3.1，p.2–3）：价值模型偏置、序列长度异质、奖励稀疏。七项技术：Value-Pretraining、Decoupled-GAE（来自 VC-PPO）、**Length-Adaptive GAE**（本文）、Token-level Loss、Clip-Higher、Positive Example LM Loss、Group-Sampling。
- **读数（表 1，p.6，AIME24 avg@32）**：Vanilla PPO 5、R1-Zero-32B 47、DAPO 50、**VAPO 60.4**；消融落差：去掉 Value-Pretraining → **11**（最大落差 49.4），去掉 Decoupled-GAE → 33，去掉 Length-Adaptive GAE → 45，其余三项 53–55。
- **可迁移点**：① **Length-Adaptive GAE 的论证是一个可直接复用的诊断式**——固定 `λ=0.95` 时长度 `l>100` 的序列中奖励对应 TD 系数 `0.95^100≈0.006`，实际趋零、优势被有偏自举项主导（p.3）；② **消融落差可作优先级排序**，引用"某技术有效"必须带落差量级；③ 它**反证"critic-free 必然更优"**——但这只说明理由不成立，不构成改用价值模型的依据。

### 9. SRPO — `2504.14286`（快手 Kwaipilot，17 页）

- **机制**：① 两阶段跨域课程：先数学（长 CoT 反思式推理）、后掺代码（§3.2，p.7）；② **History Resampling**：训练中近 **50%** 的组奖励完全相同、优势为零（图 8），故按 epoch 重建数据集——**全对组剔除**（无对比信号）、混合与全错组保留（有正方差），全错难题也留（更新后可能变易，思想与课程学习一致）（§3.3，p.7）。
- **读数**：同基座 Qwen2.5-32B、约 R1-Zero-32B **1/10 训练步数**，AIME24 与 LiveCodeBench 超过 R1-Zero-32B（摘要、图 1，**数值只在图内**）。
- **可迁移点**：① "全对组无梯度"可用一条曲线诊断（组内奖励方差为零的比例），**与任务无关**；② 取舍不对称——**剔除太容易的、保留全错的**，不要因为当前太难就丢弃（可能是下一轮课程）；③ HR 是**离线（epoch 级）重建** vs DAPO 的在线过滤，采样成本高时更划算。

### 10. PPO — `1707.06347`（12 页，2017）

- **机制**：`L^CLIP = Ê[min(r_t Â_t, clip(r_t,1−ε,1+ε)Â_t)]`（式(7)，p.3）；替代方案自适应 KL 惩罚（式(8)，p.4）；完整目标含价值函数损失与熵奖励（式(9)，p.4）；Algorithm 1（p.5）**同一批数据多轮 minibatch 更新**。
- **读数**：全部实验是 **Atari 与 MuJoCo 连续控制／人形机器人**，**无任何语言模型实验**。
- **可迁移点**：① `min` 的不对称性——只惩罚"朝有利方向走得太远"，反向不设限，**这是后来 DAPO 认为会压制低概率 token、导致熵坍塌的结构根源**；② 多轮 minibatch 是 off-policy 比率问题的**最上游来源**；③ 信任域的两条实现路径（裁剪 vs KL 惩罚）是家族后续每次"裁剪修正"的选点空间。

### 11. DPO — `2305.18290`（斯坦福，27 页）

- **机制**：KL 约束奖励最大化 → 闭式最优策略式(4) → 反解奖励式(5)（p.4）`r = β log(π_r/π_ref) + β log Z(x)` → 代入 Bradley-Terry 后 **`logZ(x)` 在成对差分中消掉** → DPO 损失式(7)（p.4）。梯度权重由隐式奖励估计错误的程度决定。
- **读数**：TL;DR／Anthropic-HH／IMDB／Reddit 上与 PPO 相当或更好（§6，p.6–7）；**部分结果在图内**。
- **可迁移点**：① **"奖励 = 策略与参考策略的对数比"是结构恒等式**，为"无显式奖励时如何构造训练信号"提供通用框架；② 配分函数在差分中消掉是"绝对量不可算、差值可算"场景的可复用技巧；③ **对无标签适应是一道边界**——DPO 需要成对偏好数据，无标签场景无偏好对，**不能直接使用**。

### 12. REINFORCE++ — `2501.03262`（v9，16 页）

- **机制**：`A^norm = (A − mean(A|D_batch)) / (std(A|D_batch)+ε)`（式(5)，p.3）；批次≥1024 时均值/std 收敛为稳定常数，估计随批量增大渐近无偏。k=1 通用版与 k>1 组采样版（§3.2）。
- **读数**：通用 RLHF 上 k=1 得 **46.7 vs GRPO(k=4) 46.8**，但回答更短（832 vs 860 token）；GRPO 奖励上升快但 **KL 同步快速上升**（作者判为破解奖励模型）。**30 题过拟合对照（§4.2.1，p.5–6）：GRPO 训练集 95.0 但 AIME-25 Pass@1 = 0.0；REINFORCE++ 训练集 71.0、AIME-25 Pass@1 2.5／Pass@16 40.0**。K&K 难题切片：GRPO 坍塌，REINFORCE++ 平均 62.1 vs 55.7。
- **可迁移点**：① **统计量的作用域是独立自由度**，样本量决定估计方差；② 小分母与过拟合的联系（组内方差极小时噪声被放大为巨幅梯度）；③ **KL 散度作"奖励破解"的在线指示器**（奖励与 KL 同时快速上升）；④ **只在平均指标上比较会掩盖方法差异**——GRPO 在简单题不输、难题坍塌。

### 13. RLOO — `2402.14740`（28 页）

- **机制**：`(1/k)Σ_i[R(y_(i),x) − (1/(k−1))Σ_{j≠i}R(y_(j),x)]∇logπ`（§2.3，p.5）——同 prompt 其余 k−1 条构成无偏基线，是**无需参数的价值函数**，每步在线重建。
- **读数**：① **裁剪很少必要**——实测损失被裁比例**平均 <5% per batch**，完全去掉裁剪乃至去掉比率（退化为 Vanilla PG）性能不降反略升（§3.2，p.8）；② **建模部分完成序列不必要**——LLM 生成环境确定、奖励只在 `<EOS>`，可归约为 bandit（§3.3，p.8）；③ RLOO 一致优于所有对照；k=2 的 RLOO 超过／持平 k=4 的 RAFT（图 2–3，p.9）。
- **可迁移点**：① **"裁剪使用率"是可机械测量的诊断量**，长期很低说明裁剪近乎空转；② 作者把 REINFORCE 类的成功**明确归因于 SFT 初始化强**（§6，p.14）——**这是一个可证伪的前提**，弱初始化场景下结论可能反转，引用前必须检查该前提；③ 内禀指标（训练奖励）与外禀指标（胜率）分开报的双指标结构。**作者自陈限制**：未研究奖励模型过优化、胜率是 GPT-4 模拟非真人（§7，p.14）。

## 三、设计咨询答复核心（熵坍缩问题）

**问 1：家族文献里的熵坍缩机制**

- **GMPO §4.4 p.9**（最关键）：原文"applying a wider clipping range for GRPO temporarily encourages exploration, but entropy still declines quickly"——**放宽信任域不治本**，因为病因是**聚合算子对异常值敏感 → 激进更新急剧压熵**。**对 TENT 的映射**：TENT 的熵最小化是**主动压熵**，熵=0 就是目标下确界，坍缩不是副作用而是**目标的直接解**。
- **DAPO §3.1 p.4–5**：Clip-Higher 机理——`ε=0.2` 时 `π_old` 为 0.01 与 0.9 的动作被增幅后的上界是 0.012 与 1.08，即**高概率"利用 token"几乎不受约束、低概率"探索 token"被卡死**；且 **ε_low 必须不动，抬高它会把低概率 token 压到 0、导致采样空间坍缩**（p.5）。
- **DAPO Dynamic Sampling 不能借到熵目标上**：它解决的是**全对/全错组优势为零**（p.5），改变"哪些样本产生梯度"，**不改变目标吸引子**。
- **SAPO §4.2 p.6–7**：硬裁剪是二元信任域 `f'∈{0,1}`（式(24)），越界即零梯度 → "brittle and unstable"；图 4 显示 GSPO 与 GRPO-R2 早期坍塌。
- **Simoni GTPO §4.2 p.3**：策略坍塌 = 负奖励完成惩罚高置信 token、把决策推向低概率 token。

**问 2：低熵模型上做在线适应的前提条件**

- **唯一显式前置门**：Simoni GTPO **式(10) p.5** 的 `<H>_ini < ln2`，且**方向是削减更新**（丢弃高熵完成项的优势信号）。原句论证："对自然呈现低平均熵的模型，施加梯度有放大不确定性、加速坍塌的风险"。
- **DAPO §5 p.9–10 是定性区间描述**：熵过低=分布过尖、丧失探索；熵过高=乱码重复等过度探索；"维持熵的**缓慢上升趋势**有利性能"（p.10）。**无数值门槛。**
- **"多少犹豫样本才够"在已读文献中无答案——明确未读到。** 最接近的定量诊断是 LitePPO Takeaway 2（§4.1.1 p.4–6）的"奖励高度集中时除 std 会异常放大梯度"，但那是**优势归一化的分母问题，TENT 的熵梯度不含 std 分母，机理不同，不能直接类比**。
- **附加警告**：DAPO §5 p.9–10 与 GMPO §4.4 p.9 都表明**熵不是越低越好、也不是越高越好**，存在"适当区间"——熵最小化目标本身没有这个区间概念。

**问 3：批内相对熵替代绝对熵**

- **最接近的构造：Tan GTPO**——式(14) p.6 `E[∇J⁺] = E[∇J_GRPO] + E[Cov(Δ_entropy, ∇logπ_θ)]`，熵以**协方差项**进入且 `Δ_entropy` 是**零和再分配**；命题 2.2 p.5 正奖励质量守恒 ⇒ **目标对绝对熵水平不变**，正是"批内相对"要的性质。**稳定性有条件**：命题 2.3 p.5 的渐近无偏依赖作者写明的**"熵巩固条件"**。
- **同族构造**：GFPO §3 p.3–4（优势 μ/σ 只在保留子集内算，"使比较只发生在已满足目标属性的响应之间"）；Simoni 式(9) p.4 的 `Σ_{G⁺}|A_i| = Σ_{G⁻}|A_i|` 总信号守恒。
- **守恒性构造在本轮两篇里独立出现两次**（Tan 命题 2.2 / Simoni p.4）——可视为该族的一条**设计纪律候选**：奖励／梯度重塑不得改变总质量。
- **没有任何一篇把"批内相对熵下降"直接作为 TTA/在线适应目标——明确未读到。**

**三条建议（本课题推论，非文献结论）**：① 先做前置门（借 Simoni 式(10) 的机械开关形式），门槛须在自有源年数据标定（文献 `ln2` 是二分类最大熵，与 AP 0.997 场景不可比）；② "熵压到 ~0 但梯度范数不衰减"与 GMPO p.6 的稳定判据形态不符，提示**梯度可能不来自熵项本身**，建议先做梯度来源分解；③ 两次干跑方向相反已落在既有"符号在重跑间翻转的读数不得进入候选排序"纪律的适用范围内。

## 五、可直接复用/不可直接声称的速查

**最可能被误用的四条**：

1. **SAPO 的"非可验证奖励支持"是推论不是主张**——论文全部实验是可验证奖励（数学推理）与 Qwen3-VL 多模态，从未评测非可验证奖励。
2. **ReCode 的 `16.1%`（相对基座）与 `+4.5%`（相对 outcome-only RL）参照系不同，不可混用**。
3. **GMPO 的 `+4.1` 是最优情形非全域结论**（MATH500(7B) 82.0 vs GRPO 83.4 为负项）；且 GMPO 消融"去掉 `1/|o|` 降 0.7"与 Dr. GRPO 主张**方向相反**，引用须并列。
4. **单篇结论不得跨模型族外推**——LitePPO 明确限定只用 Qwen3 系列（作者自陈）；GMPO／GSPO／SAPO／GFPO／SRPO／VAPO 的实验**全部是 LLM 推理任务，均无表格数据或分类任务证据**。

**最可能被漏掉的两条**：

1. **裁剪使用率 <5%（RLOO §3.2 p.8）与"加宽裁剪不治坍缩"（GMPO §4.4 p.9）**——两者合起来说明：在以熵为目标的适应里，调裁剪/信任域宽度不是有效杠杆。
2. **"策略初始化强"是 REINFORCE 类方法成功的前提**（RLOO §6 p.14），是一个**可证伪条件**而非普适结论。
