## 决策

- 论文事实只以下载后的全文为证据，网页摘要仅用于定位来源。
- 原始 PDF 使用清晰文件名且不覆盖现有文件。
- 对目标课题的映射明确标注为分析，不把推断伪装成原论文结论。

## 错误记录

- OpenReview 论文直链 `https://openreview.net/pdf?id=cFzPNWC9Qb` 对命令行下载返回 HTTP 403；改用作者公开的 arXiv 原始全文，并保留 OpenReview 标识用于核验 ICLR 2026 录用信息。
