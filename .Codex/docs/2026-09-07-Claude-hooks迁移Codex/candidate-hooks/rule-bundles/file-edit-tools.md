【按需注入·文本修改规范】本条规则被 hook 检测到文本替换行为时注入，仅约束本次相关动作。

- 查找替换优先用 `sd`（已全局安装）：`sd '旧文本' '新文本' 路径/文件`，默认原地修改，macOS/Linux 行为一致，无需 `-i ''`；严禁 `sed -i ''`
- 禁止 sed 做跨多行、复杂缩进、含大量特殊字符的替换；sed 仅限单行、字面量、无歧义替换，且执行前确认匹配唯一
- 修改点超过 3 行或涉及复杂逻辑块时，改用重写整个文件的工具，而不是拼复杂正则
- 批量修改后必须：按语言跑格式化（Go→gofmt -w，Python→black，TS/JSON→prettier --write）+ 语法/编译检查；报错立即 `git checkout -- <file>` 回滚改用精确方式重改
- 普通文本修改禁止用 bash 跑 python/awk 脚本，优先内置 Edit/Write 工具
