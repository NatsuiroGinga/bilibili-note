## 已确认边界

- LSPR24 已被访问，任何后续使用都必须披露 `target_informed=true`，不得冒充独立终测。
- 旧 CPA-ELP、CEM-BER、ETA-BER 结果只用于解释旧实现为何被否决，不迁移为新候选性质。
- DeepEmbedAttention 官方 `rwkv7b` 实现包含 DeepEmbed，不能与 DeepEmbed同时登记为两个独立机制；若登记，只能作为 DeepEmbed 家族的替代分支或消融定义。
- ROSA、DeepEmbed、DeepEmbedAttention 的文献与官方源码目前只支持可试性，未支持本课题有效性。
- DRIFT-DGA 2026 数据公开可访问且可固定版本；总体 OOV、后缀覆盖、跨年重复和家族隔离仍需完整分片扫描，当前未计算。
- DRIFT 可行性报告中的“跨年域名后缀集合命中”与官方 ROSA 不同：前者是跨域集合统计，后者是单一因果序列内对当前查询做在线最长历史后缀匹配并读取后继值。DRIFT 必须逐域名重置，跨域名共享状态没有自然顺序；因此原 ROSA 覆盖探针定义待修，跨年完整域名交集仅作泄漏审计。

## 候选统一映射

### 数据集

- `D01 LSPR23→24`：安全语义、实体低误报和历史证据最贴合；但当前 `dijk-repro/cache` 缺逐流完成时刻消费证据，严格源前向数据门未通过，LSPR24 还必须标 `target_informed=true`。
- `D02 DRIFT-DGA 2026`：固定版本公开可访问，字符序列和未见家族轴清晰；短域名不支持跨域长期状态，四类总体统计尚未完成。
- `D03 CESNET-TLS-Year22`：真实骨干 TLS、周级漂移和已发表时间退化；客户端键稳定性、采集器第 10 周变化与 SNI 泄漏需门禁。
- `D04 CIC-YNU-IoTMal 2026`：系统调用和事件序列适合 RWKV-8 机制移植；跨架构强基线、公平主体隔离和生成良性混杂尚未核实。
- `D05 CESNET-QUICEXT-25`：现代 QUIC 外部表示候选；无恶意标签、无客户端键，正式强时间基线和许可仍待补。
- `D06 CESNET-TimeSeries24`：长状态链和合法实体键最强；缺攻击真值，只能承担自监督或无监督机制验证。
- `D07 CipherSpectrum`、`D08 EMBER2024`、`D09 HiGraph`：分别适合受控跨密码套件、静态时间漂移、图结构漂移；不能直接证明 RWKV 长状态。
- `D10 LSPR25`：实际不可获取，按当前合同已否决。

### 基础模型

- `B01 强树模型`：XGBoost/随机森林是直接 LSPR 强基线，不能因神经主线省略。
- `B02 FT-Transformer`：表格字段强、无可靠历史增量时优先；当前工程复用便利不构成科研选择依据。
- `B03 独立 CUDA 融合 RWKV`：唯一允许的 RWKV 训练路径；必须从零训练，先过自然因果序列、状态边界、历史增量和资源门。
- `B04 标准序列基线`：卷积、LSTM/GRU、Transformer 与适合具体数据的强近邻，用于判定 RWKV 是否必要。
- `B05 字段编码+RWKV`：仅当字段编码和历史状态分别有独立增量时考虑，不作为默认起点。
- `B06 Mamba/NetMamba`：可作同预算流式序列竞争骨干，既有旁证不能直接证明本任务收益。

### RWKV 与 RWKV-8 机制

- `R01 ROSA`：官方工程原型，需单序列内离散因果后缀与合法重置；慢参考不能证明线性吞吐，本课题效果待证。
- `R02 DeepEmbed`：逐层 token 条件 FFN 通道调制；需稳定离散词表和跨域 OOV 诊断，禁止身份字段捷径。
- `R03 DeepEmbedAttention/DEA`：官方 `rwkv7b` 已包含 DeepEmbed，作为 DeepEmbed 家族替代分支登记，不与 R02 同时占两个独立机制开关。
- `R04 原生 TimeMix/状态连续与衰减`：共同底座和反事实基线，不得把正确使用原生状态包装成创新。
- `R05 额外多尺度/选择性证据记忆` 与 `R06 时间间隔/漂移条件遗忘`：只有分别超越原生状态与原生衰减、且 R06 在 R05 关闭时仍非惰性，才可组成双机制。

### 非 RWKV 机制

- `N01 有序源环境稳态表示`：先做 V-REx 轻参照和顺序反事实；Sol 的完整稳定/私有公式未获放行。
- `N02 实体均匀低误报排序`：须拆分实体重加权、普通实体 AUC、低 FPR 排序与阈值校准，旧 BER 不自动继承有效性。
- `N03 未见家族域泛化`：以家族隔离和未来家族 FNR 为主，不允许同域重复泄漏。
- `N04 跨架构稳健表示`：面向 IoT 执行轨迹，须控制架构、沙箱和家族共变。
- `N05 开放集拒识与校准`：只移动决策或拒识工作点时不冒充表示机制；目标标签参与时改变信息预算。
- `N06 目标适应/漂移重训`：MADCAT、潜空间对齐、漂移触发重训只作不同信息权限的竞争路线。
- `N07 字段/Token 语义适配`：可服务任意骨干；输入适配是否构成机制贡献须由独立消融裁决。

### 联合配对

- `J01 N01+N02`：LSPR+FT 条件方案，仅待证；C11 只能两项相加，不得加入私有分支、动态权重或第三控制器。
- `J02 R05+R06`：RWKV“记忆+遗忘”条件方案；原生状态与衰减始终作为 C00 共同底座。
- `J03 R01+R02`：离散因果序列上的 ROSA+DeepEmbed；DRIFT 只能在单域名内评价 ROSA，短序列可能直接否决其长期价值。
- `J04 R02+N03`：DeepEmbed+未见家族稳健目标；两个开关必须各自独立改变共享骨干且不能用同一 OOV 处理拆成两个机制。
- `J05 N04+N05`：跨架构表示+开放集拒识，适合 CIC-YNU 条件候选；需保证第二开关不是只在第一开关开启后才有输入。

## 状态映射

- 当前新候选总体均未获本课题正式实验支持，默认状态为 `待证`。
- LSPR 严格源前向数据资格正在补证，可记 `进行中`，但不是机制实验进行中。
- LSPR25 的主数据资格为 `已否决`。
- CPA-ELP、CEM-BER、ETA-BER 及旧 mean-max、TL1、GeNIS、角色分离物理时间、C12 等历史实现只按各自合同记录 `已否决`；不得把读数外推到新候选。
- `通过` 必须在相邻裁决字段写明通过的阶段，例如“P0 门通过”；状态列本身只写精确词 `通过`。后续阶段仍需排队，不等于论文有效。

## 唯一队列草案

1. `P0` 数据资格与可获取性：逐个候选完成官方版本、许可、时间、主体、标签、强基线、余量和资源门；同一时刻只处理队首。
2. `P1` 零训练数据病灶：只在 P0 通过的数据上验证 OOV、重复/泄漏、家族/架构隔离、历史增量、状态重置和低误报支持量。
3. `P2` 缩容短训单机制：一个冻结种子，共同 C00，逐项做直接近邻和必要反事实。
4. `P3` 固定分布外开发：固定开发池、候选总预算和反馈次数，记录目标知情程度。
5. `P4` 单种子联合先导：只将两个 P3 通过的独立机制组成完整四格。
6. `P5` 正式单种子 `2×2`：同一冻结种子完成正式四格、强基线、原组件差量、资源和配对重采样；配对区间不覆盖训练随机性。

## 2026-09-07 新增证据

### DRIFT 全文与引用版图

- [DRIFT 引用与方法前沿综述](../2026-09-07-DRIFT引用与方法前沿/文献综述.md)完成全文核验：截至 2026-09-07，真正引用原论文的 A 类为 `0`，使用数据但未规范引用的 B 类为 `0`。该零结果只适用于当前日期和已核索引，不能推出机制原创或全球不存在未索引工作。
- 原论文 2020--2025 微平均 F1 为 `0.964630`；2025 FPR 为 `0.096520`；83 个测试独有家族 FNR 为 `0.143913`。总体 F1 较高，但未来良性误报和未见家族仍有可观察病灶，不能宣称达到经验天花板。
- DRIFT 已占用字符/子词双分支、最大/平均池化融合、MTP、TPP、TOV、2017--2019 多年预训练，以及读取新年标签的分类头持续学习。后续不能把混合 token、池化融合、遮蔽/位置/顺序预训练或带标签持续学习重新包装为第三章机制。

### Engram、DeepEmbed 与 mHC

- Engram 是 DeepEmbed 的强直接近邻和替代实现：压缩 n-gram、多头确定性哈希、上下文门控、局部因果卷积，并有等参数/等 FLOPs 对照。两者只能占一个“条件记忆”机制轴，不能形成两个独立开关。
- 条件记忆在 DRIFT 上剩余的任务化差量仅限：训练年份构建的安全局部模式键、碰撞/低支持门控、身份键禁入，以及普通嵌入/等参数 FFN/随机哈希或 token 破坏的等容量负控。直接查表、逐层 token 调制、通用 n-gram 和上下文门控已被近邻占用。
- mHC 只解决多流残差与梯度传播稳定性。DRIFT 全文和现有 pilot 均未报告损失尖峰、梯度放大、激活异常或深度退化，因此 mHC 当前没有进入实验的病灶资格；只能等待普通骨干逐层传播诊断。

## 2026-09-07 经验天花板与指标裁决

- 新增长期方法文档：`thesis/methods/第三章-经验天花板与指标裁决.md`。
- DRIFT 的 F1 `0.964630`、2025 FPR `0.096520`、未见家族 FNR `0.143913` 只证明候选错误余量。因为没有第三方复现、完整低 FPR 曲线、置信区间和训练随机性证据，经验天花板仍未完全确认。
- 总体 F1 是护栏，不设 `99%` 硬目标。主目标为在同一信息与冻结阈值合同下，提高固定 FPR/完整低误报曲线上的未见家族 TPR、降低 FNR，或在同检出水平下降低未来良性 FPR。
- 指标顺序固定为：未见家族低误报主指标；未来年 FPR/FNR、跨年份与跨家族宏平均；总体 F1、已见家族、源域和资源护栏。
- 任何 FPR 点、部分 AUC 上限、最小效应、置信水平和重采样次数都须由全文、运营预算、源侧诊断或蒙特卡洛误差依据冻结；当前不填数字。
- 保持率不能替代未见域绝对值。候选必须改善未见域绝对主指标，并披露训练/源域性能变化，禁止压低源域刷保持率。
- 所有训练维持一个冻结种子；域名/家族配对 bootstrap 或置换只量化固定预测集的评价不确定性。
- 依赖顺序增加一道经验余量门：正式零训练探针完成后，先同协议复现 C00 并生成低误报曲线和评价区间；现实指标也饱和则淘汰 DRIFT，不进入机制短训。
- 本轮没有预填任何四格提升、阈值、曲线或置信区间，没有修改正在运行的 `formal-v1`。
- 工具错误：本轮首个并行读取脚本因变量声明语法错误在执行前终止；固定命令重试成功，文件和实验均未受影响。
