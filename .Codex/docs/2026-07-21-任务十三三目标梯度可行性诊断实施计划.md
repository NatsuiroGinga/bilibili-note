## 目标

在不更新 Qwen3-1.7B 参数的前提下，使用真实 GeNIS 与 ns-3 批次回答四个问题：

1. 生成、稀疏状态和物理三个共享 LoRA 梯度是否存在严格共同下降方向。
2. 无保护的共同方向是否会牺牲超过 5% 的归一化生成一阶进展。
3. 保留至少 95% 生成一阶进展时，状态与物理目标能否同时有效参与。
4. 独立生成验证批次对状态与物理跟随更新的 G5 一阶反应代理是否非零。

## 数学契约

令三个目标的单位梯度为 u_g、u_s、u_p，Gram 矩阵为 C，单纯形权重为 alpha。聚合方向的一阶下降边际为 m = C alpha。

- 无保护解：在分辨率 0.02 的确定性整数单纯形网格上最大化三个边际的最小值。
- 严格共同下降：最优最小边际大于 1e-8。
- 生成保护解：只保留生成边际不小于 0.95 的候选，再最大化状态与物理边际的最小值。
- 生成否决：无保护解的生成边际小于 0.95。
- 双辅助有效参与：保护解的状态与物理权重均为正，且两者边际均大于 0。
- G5 反应代理：独立验证生成梯度分别与状态、物理训练梯度计算归一化点积；绝对值大于 1e-6 记为非零。

网格通过 units = round(1 / resolution) 的整数三元组枚举，要求 resolution 乘 units 与 1 的误差不超过 1e-12。并列结果采用固定排序，保证可复现。

## 裁决规则

1. 若严格共同下降率接近 0，G2-G4 不直接进入训练，优先考虑松弛、分阶段或 G5。
2. 若共同下降率高但生成否决率高，说明 G4 的主目标保护是必要机制。
3. 若保护解的双辅助有效参与率高，G4 进入任务十四最小训练对照。
4. 若两类 G5 反应代理均接近零，必须重新定义主导变量或外层效用。
5. 一阶诊断只负责筛选方向；最终去留仍由任务十四的三项实测门槛决定。
