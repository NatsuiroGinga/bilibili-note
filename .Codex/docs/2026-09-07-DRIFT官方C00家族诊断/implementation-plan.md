# DRIFT 官方 C00 家族诊断实施计划

## 范围

- 新增官方检查点源期只读诊断、配置与远程启动器。
- 仅读取 T17/T18/T19 raw DGA 和已冻结官方模型、tokenizer、源阈值结果。
- 对首个点前标签形成 eSLD 键；多 family 键隔离，非歧义键每年只评价一次。

## 实现

1. 运行时核对固定 revision、输入、模型、tokenizer、阈值制品和禁止 T20--T25。
2. 以 Polars 在内存构建 eSLD 到 family 映射，年度读取时先过滤歧义键；不写逐样本分数。
3. 按年份原子状态文件保存聚合结果和资源收据；`--resume` 只跳过身份一致的完成年度。
4. 汇总 family 支持、默认阈值与源低 FPR 阈值的 FNR/TPR、分数均值、新增 family 和支持变化。

## 验收

- `py_compile`、`--help`、配置 JSON 解析和真实输入发现。
- 不运行人工数据测试、正式服务器实验或自动格式化。

## 运行修订

8192 实测显存约 7784MB、15 秒 SM 均值约 68% 且有空档；固定深度 1 的单 CPU 编码预取，使下一批编码与当前批 GPU 前向重叠，不改变输入顺序、模型公式、聚合或年度断点。

后续实测否决该路径：8192+预取约5986/s且SM均值约37%，低于1024同步约9000/s。恢复1024同步编码，按年三进程并发；各年只写自己的原子状态，完成后单进程 resume 汇总。

并发由远端 Python 父进程而非本地 launcher 编排：父进程等待三个年度子进程均成功后才汇总，任一失败即非零退出并保留已完成年度状态供 resume。
