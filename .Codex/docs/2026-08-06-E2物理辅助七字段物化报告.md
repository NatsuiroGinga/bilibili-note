# E2 物理辅助七字段物化报告

## 结论

E2 物理辅助物化器已经落盘。现有 `r2-final-tcp-udp-physics-v2` 能提供窗口时长、队列状态、守恒通量和边界真值，但只保存无方向聚合的包数与三层字节数，不能合法恢复发起方向和响应方向的六个字段。因此本轮状态是**物化器完成、真实方向源缺失、辅助表尚未发布**。

实现不会按比例拆分总量，不会把 TCP 已确认字节或 UDP 应用发送量当作响应流量，也不会按行号关联 TQH-C2 与 ns-3。缺源时只生成结构化阻断收据，不生成可被任务 4 误用的 Parquet。

## 已实现合同

### 输入与字段

- 物理真值表必须包含复合样本键 `sequence_id + window_index_in_sequence + physics_group_sha256`。
- `duration` 只从 `truth_window_duration_s` 精确映射。
- 其余六字段只接受显式方向源：`orig_bytes`、`resp_bytes`、`orig_pkts`、`resp_pkts`、`orig_ip_bytes`、`resp_ip_bytes`。
- 方向源和物理真值表的复合键集合必须完全相同；关联按键执行并保持物理真值表稳定顺序。
- 包数和 IP 字节数必须是非负整数，IP 字节数不得小于同方向传输层载荷字节数。
- 任一来源声明 `final_test_visible=true` 时立即拒绝。

### 真值与绑定

输出表保留两个队列状态通道的起点、终点、到达、离开和入队前后丢弃真值。发布收据分别记录：

- 复合样本键与稳定顺序语义哈希；
- 七字段语义哈希；
- 状态真值语义哈希；
- 守恒真值语义哈希；
- 边界真值语义哈希；
- 两份来源文件 SHA-256；
- 汇总绑定 SHA-256。

正式输出目录固定为 `runs/data-prepared/e2-physics-auxiliary-v1/`，成功时主表名为 `e2-physics-auxiliary-v1.parquet`。

## 本机现有数据审计

### 可以直接使用

- `truth_window_duration_s`：可精确映射为秒制 `duration`。
- 队列三层字节起点与终点。
- 队列包数起点与终点。
- 接收、离开、入队前丢弃和出队后丢弃的包数与三层字节数。
- 复合样本键、协议、场景、划分、稳定顺序和最终测试不可见标志。

### 不能直接使用

- `public_total_packets` 和 `public_total_l3_bytes` 是合计观测，不能唯一拆成两个方向。
- TCP `acked_bytes` 和 `acked_segments` 表示发送数据被累计确认，不等于反向 ACK 包数、反向 IP 字节或响应载荷。
- UDP `truth_udp_actual_send_*` 只描述应用发送结果，不提供响应方向，也不能推出 IP 首部开销。
- 本机回收的正式矩阵只有 `main.csv`、`tcp-sender-windows.csv` 和 `receipt.json`，没有 PCAP。

因此当前真实缺失字段为：

1. `orig_bytes`
2. `resp_bytes`
3. `orig_pkts`
4. `resp_pkts`
5. `orig_ip_bytes`
6. `resp_ip_bytes`

## 最小数据补充

若服务器仍保留与正式 512 项配置完全对应的双向 PCAP，只需按 `physics_group_sha256 + transport_family + source_window_index` 回收 PCAP 和逐运行收据，再在原 0.1 秒窗口内解析六个方向字段。

若没有 PCAP，必须修改 `thesis/experiments/llm_probe/ns3/r2_protocol_dynamics_v2_scenario.cc`：在固定观测点将发起端到响应端定义为 `orig`，反向定义为 `resp`，分别累计传输层载荷字节、IP 包数和包含 IP 首部的 IP 字节数。随后按原冻结 512 项配置重跑，并至少回收：

- 每个运行新增方向字段后的 `main.csv`；
- 每个运行的 `receipt.json`；
- `matrix-state.json`；
- `matrix-summary.json`；
- `source-lock.json`；
- `artifact-manifest.json`。

新方向表必须先转换为复合样本键并通过本物化器发布，不能直接替换现有物理真值表。

## 验证

目标测试覆盖以下合同：

1. 缺少方向源时生成阻断收据且不生成 Parquet。
2. 方向源乱序时仍按复合样本键正确关联并保持物理表顺序。
3. 方向源键集合不一致时拒绝物化。

按任务约束未在本机运行 `pytest`、格式化、完整检查、远程同步或服务器实验。实际执行了一次 Python 语法级最小验证：

```bash
PYTHONPYCACHEPREFIX=/tmp/e2-physics-aux-pycache python3 -m py_compile \
  src/flow_probe/e2_physics_auxiliary.py \
  tests/test_e2_physics_auxiliary.py
```

结果为退出码 `0`。

随后真实运行物化入口。入口以预期退出码 `2` 返回 `blocked_missing_directional_source`，并写出：

- `thesis/experiments/llm_probe/runs/data-prepared/e2-physics-auxiliary-v1/missing-source-report.json`；
- `thesis/experiments/llm_probe/runs/data-prepared/e2-physics-auxiliary-v1/run-state.json`。

收据确认 `duration` 可从 `truth_window_duration_s` 精确映射，六个方向字段缺失，`final_test_visible=false`，且没有生成 `e2-physics-auxiliary-v1.parquet`。
