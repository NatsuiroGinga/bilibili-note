## 关键问题

1. TQH-C2 v1.2.0 是否足以独立承担第三章和第四章的全部公开检测证据？
2. 主问题应是困难域检测、受控协议栈迁移，还是间隔与抖动稳健性？
3. 编码模型、Qwen 或双阶段系统中，哪一种在相同开发协议下取得最佳性能、成本和物理接入平衡？
4. UDP 守恒应作为独立专家，还是成为 QUIC 专家的底层物理项？
5. PINN 改善的是检测性能、跨条件稳定性还是校准，哪一种有真实实验支持？

## 已作决策

- PINN 仍是第三章必须保留的研究方向，但具体基座、注入结构和收益主张重新开放。
- 不再为保留“生成式”题目预设 Qwen 优先级；课题定位可随证据修改。
- 当前推荐 TQH-C2 v1.2.0 作为唯一正式公开检测数据集，须等待全文综述和文件审计后冻结。
- 当前推荐以困难域 C 为主要难题，以 B/D 为受控协议栈迁移，以间隔和抖动为稳健性面板。
- 当前推荐把 UDP 守恒内嵌 QUIC 专家，独立 UDP 只作 ns-3 机制消融；该结构尚未冻结。
- 旧 GeNIS/TQH 混合实验、DistilBERT 和 Qwen 结果保留为历史先导证据，不进入新协议正式主表。

## 错误与风险

- TQH-C2 v1.2.0 README 同时存在 36/48 单元、26/27 特征等不一致，正式协议只能依据实际压缩包、清单和模式审计。
- TQH 的 `unknown` 主要是握手失败和基础设施噪声，不能当作未知攻击。
- ET-BERT 使用原始字节 BURST 与专用预训练，不能和结构化字段序列化的 DistilBERT 当作同一种输入。
- 当前 Qwen 与 DistilBERT 物理旁路均未超过无物理基线，不能把现有 R2 写成有效方法。
