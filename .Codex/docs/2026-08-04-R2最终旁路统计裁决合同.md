## 2. 路线与组别冻结

| 组别 | 冻结定义 | 必须排除的替代解释 |
|---|---|---|
| `F-A` | 关闭协议专家；以等参数量统一支路替代物理旁路 | 不能把参数量差异解释为物理收益 |
| `F-H` | 输入与 `F-P` 同时间范围、同可观测性约束的原始因果历史 | 不得包含未来字段、真值状态、残差、标签或标签派生量 |
| `F-P` | 共享守恒层、协议动力学专家、协议适用掩码、未知回退和停止梯度路由组成的真实物理旁路 | 协议标识只能控制物理路由，不得成为检测捷径 |
| `F-S` | 在数据分割完成后，对物理历史和适用掩码按整段共同置换 | 不得按标签、预测、难度或单字段分别置换 |
| `F-R` | 仅从当前开发训练池采样形状与合法字段块匹配的随机物理历史 | 不得从校准池、验证池、最终测试或其统计量采样 |

共同冻结规则：

- `F-S` 与 `F-R` 在训练前一次性物化并记录哈希；训练过程中不得按轮次重新生成。
- `F-S` 保持物理段内部结构、掩码与协议适用关系共同移动；其置换不得使用标签或模型输出。
- `F-R` 的采样池、字段块、掩码规则及随机种子派生方法必须在首个运行前固化。随机值只能来自对应开发训练池允许的字段支持域。
- 五组必须使用完全相同的样本标识、拆分、文本字段、标签、批次顺序规则、训练轮数上限、优化器、早停规则、模型选择规则和可调参数预算。仅允许改变本节定义的旁路输入或结构。
- 任何仿真真值、未来窗口、标签、标签派生量、检测模型预测或全数据统计量均不得进入可见输入、缩放器、随机池、置换规则或路由器。

## 3. 开发边界

| 数据区 | 允许用途 | 明确禁止 |
|---|---|---|
| 开发训练区 | 拟合模型参数、缩放器、编码器统计量；建立 `F-R` 采样池 | 查看校准区、验证区或最终测试统计量后回写训练规则 |
| 开发校准区 | 按预先固定规则选择检查点、拟合已声明校准器、检查数值稳定性 | 更新模型权重；根据表现新增面板、改变阈值或切换主指标 |
| 开发验证区 | 一次性计算冻结指标并执行本文裁决 | 调参、补种子、换检查点、改变分类阈值或挑选有利子集 |
| 最终测试 | 候选级阶段无任何用途 | 读取样本、标签、指标、元数据、目录内容或派生统计量 |

- 二分类决策阈值固定为 `0.5`，多分类决策固定为最大概率类别。若正式配置声明概率校准，校准方法必须在运行前冻结，且只能在开发校准区拟合。
- 同一会话、连接、捕获、仿真运行及其重叠窗口不得跨开发训练、校准和验证边界。ns-3 以仿真运行或拓扑实例为分割单位；qlog 以连接或采集会话为分割单位。
- 在生成任何预测前，每条样本必须具有稳定的 `sample_id` 和 `evaluation_cluster_id`。统计重采样以独立会话、连接、捕获或仿真运行为簇，不把同簇窗口当作独立重复。
- 五组在每个数据源上必须具有相同的有效样本集合和顺序。任何组独有的缺失、过滤或回退都必须先修复后重跑对应完整矩阵，不允许只删除不利样本。
- 检测指标与物理指标分开裁决，不构造可由权重调节的总分。

## 4. 冻结评价面板

### 4.1 常规检测面板

- GeNIS 二分类验证面板。
- TQHC2 二分类验证面板。
- 两个数据源分别计算、分别过门，不合并样本或先平均后遮蔽单源失败。

### 4.2 困难检测面板

| 数据源 | 预先声明的困难分区 |
|---|---|
| GeNIS | 时间前推；留一攻击子类型；长尾子类型；部分字段缺失 |
| TQHC2 | 留一捕获条件；加密迁移；协议标签匹配；未知协议回退 |

- 每个困难分区内部的预先声明折等权汇总，不按样本数、效果大小或结果好坏加权。
- 困难面板主指标为宏平均 F1。未知回退面板同时报告未知类召回率，但不得以次指标替换宏平均 F1 门槛。
- 面板只有在至少包含 `30` 个独立评估簇，且二分类每类至少包含 `10` 个独立簇时才进入硬裁决；不足时标记为 `DESCRIPTIVE_ONLY`。该下限只是避免明显无效裁决，不代表统计功效已充分。
- “至少一个困难分区成功”必须在全部已冻结且合格的困难面板上同时校正后判断，不得先查看结果再指定面板。

### 4.3 协议与物理面板

- 检测结果按 TCP、UDP、已核验 QUIC、其他或未知协议分别报告；进入硬裁决的协议层同样需满足独立簇下限。
- 物理真值面板固定为 ns-3 成对 TCP/UDP，包含容量或 RTT 迁移、突发流量和跨拓扑条件。
- qlog QUIC 只有在来源、字段语义、连接级分割、时间因果性和真值映射均通过审计后才能进入硬裁决；否则标记为 `NOT_EVALUABLE`，不得用近似标签补齐。
- 每个进入物理硬裁决的协议至少需要 `30` 个独立仿真运行或连接。训练拟合度、训练内残差或无真值代理量不能替代物理验证面板。

QUIC 统计单元另作如下不可变限定：

- 现有 `59` 条 qlog 连接只用于字段、掩码、路由、残差计算和未知回退的机制检查，不能进入硬门槛、置信区间或 QUIC 效果主张。
- 新采集的 `600` 条连接若通过来源与真值审计，必须使用冻结清单中的完整连接集合；不得在查看结果后挑选连接或把现有 `59` 条混入扩大样本量。
- 新 `600` 条连接以独立 `connection_id` 作为 `evaluation_cluster_id`。数据包、时间窗口、流片段和同一连接的多种视图均属于同一统计簇，不能分别计入置信区间样本量。
- 在生成预测前，按客户端或服务端实现及冻结配置形成 `implementation_config_group`。连接只属于一个组；组定义、连接数和排除原因必须随清单固化。
- QUIC 自助法先保持实现与配置分组，再在每组内以独立连接做五组共同的配对重采样。组级指标等权汇总；禁止让连接数最多的实现或配置主导总体结论。
- QUIC 分组结果必须逐组报告。只有全部预声明且合格的实现与配置组均满足对应方向门槛，才能使用“跨实现与配置稳定”的表述；否则只能准确限定到通过的组，且不得把分组失败藏在总体均值中。

## 5. 指标与效应量冻结

### 5.1 主指标

| 目标 | 主指标 | 效应量方向 |
|---|---|---|
| 常规检测 | 宏平均 F1 | `Δ(P,C) = F1(P) - F1(C)`，越大越好 |
| 困难检测 | 分区宏平均 F1 | `Δ(P,C) = F1(P) - F1(C)`，越大越好 |
| 未见状态估计 | 训练区统计量归一化后的状态均方误差 | `I(P,C) = 1 - E(P) / E(C)`，越大越好 |
| 物理一致性 | 无量纲守恒残差均方误差 | `I(P,C) = 1 - E(P) / E(C)`，越大越好 |

其中 `P` 表示 `F-P`，`C` 表示某一对照组。检测效应量使用绝对百分点差对应的小数值；例如 `0.03` 表示 3 个绝对百分点。物理效应量使用相对误差降低比例；`0.10` 表示误差降低 10%。

- 状态量只使用开发训练区均值与尺度归一化，再对预先声明的状态维度等权汇总。
- 守恒残差先按训练前冻结的物理尺度无量纲化，再对方程、时间点和协议等权汇总。不得依据验证结果改变权重或删去不利方程。
- 对照误差为零、非有限值或指标无法定义时，对应比较标记为 `NOT_EVALUABLE`，不得临时切换指标、加常数或删除样本。
- 两项物理主指标必须分别通过门槛，不能先平均成单一物理分数。

### 5.2 次指标

- 检测次指标：平衡准确率、恶意类召回率、各类别 F1、良性误报率、Brier 分数、15 个固定等宽概率区间的期望校准误差。
- 困难与开放集次指标：攻击族或子类型召回率、未知类召回率、已知类宏平均 F1、协议分层结果。
- 物理次指标：各状态维度误差、各守恒项残差、掩码覆盖率、专家使用率、未知回退覆盖率。
- 成本次指标：同硬件、同批量、同测量窗口下的训练时间、峰值显存、推理延迟和参数量。
- 次指标只能解释主结果，不能挽救未通过的主门槛。若关键安全次指标的置信区间显示明确恶化，报告必须写明权衡，禁止表述为“全面优于”。

## 6. 配对统计程序冻结

### 6.1 报告单位

- 三个训练种子不是足以支持正态性检验、配对 t 检验、方差分析或 Wilcoxon 检验的独立总体。本文不使用这些检验给出主裁决。
- 必须逐一报告种子 `42/43/44` 的原始指标与配对效应量，并报告三种子等权平均、样本标准差、置信区间和方向一致性。
- 同一会话、连接、捕获或仿真运行产生的多条窗口不能视作独立重复；困难折也不能替代训练种子。

### 6.2 两层配对自助法

- 重采样次数固定为 `10,000`，分析随机种子固定为 `20260804`。
- 第一层从三个训练种子中有放回抽取三个种子位置。
- 第二层在每个被抽中的种子内，以 `evaluation_cluster_id` 为单位有放回抽样；在冻结的数据源、标签、协议和困难分区层内保持配对重采样。
- 每次重采样对五个组使用完全相同的种子位置和评估簇索引，再重新计算指标与效应量。禁止分别重采样各组后再比较。
- 每次重复先计算各被抽中种子的指标，再对三个种子位置等权汇总；样本数较多的数据源或种子不得获得更高权重。
- 硬门槛使用单侧 95% 同时置信下界；完整报告另给双侧百分位 95% 置信区间。原始三个种子的方向条件直接依据实际观测值判断，不由自助样本替代。
- 若有效评估簇不足、某次指标无法定义或组间样本不一致，不得静默丢弃重采样重复；应标记对应面板不可硬裁决并调查数据完整性。

### 6.3 多重比较

主裁决分为三个比较族：

1. 常规检测族：两个常规数据源中 `F-P` 对四个对照，共 `8` 个比较。
2. 困难检测族：全部合格困难面板中 `F-P` 对四个对照的所有比较，包括协议标签匹配面板。
3. 物理族：两项物理主指标中 `F-P` 对四个对照的所有比较。

- 每个比较族使用同一批联合配对自助样本，通过最大偏差法构造族内单侧 95% 同时置信下界，控制族错误率为 `0.05`。
- 三个比较族在最终裁决中是“同时满足”的关系，不以跨族放宽门槛抵消任何一族失败。
- “至少一个困难面板”仍须把全部合格困难面板纳入困难检测族校正，禁止按最优面板使用未校正区间。
- 次指标若给出推断性结论，在各自预先声明的指标族内使用 Holm 方法校正；否则只作描述性报告。
- 鉴于训练种子仅有三个，置信区间只量化当前冻结数据与训练随机性的有限不确定性，不得外推为任意数据集或任意训练流程的普遍显著性。

## 7. 硬门槛与裁决顺序

所有门槛按 `G0 → G1 → G2 → G3 → 异常增益审计` 顺序执行。前一门槛未通过时，后续统计可以报告但不能据此升级。

### G0：完整性与可比性

以下条件必须全部成立：

- `15` 个运行全部成功结束，并能由冻结配置、代码版本、数据清单和随机种子唯一复现。
- 每个数据源、分区和种子上，五组的 `sample_id`、`evaluation_cluster_id`、标签、可见基础字段和评估顺序完全一致。
- `F-A` 参数预算等价；`F-H` 满足等信息与因果边界；`F-S` 未使用标签或预测；`F-R` 只使用开发训练池；`F-P` 路由停止梯度并具有未知回退。
- 所有缩放器、采样池、字段支持域和校准器只由允许的开发区拟合。
- 困难面板、协议面板、指标、阈值、重采样种子及哈希均能证明在查看验证结果前冻结。
- 最终测试无读取痕迹，运行制品不含最终测试派生字段或统计量。

运行缺失或制品不全记为 `NOT_READY`；确认泄漏、拆分污染、组间样本不一致或对照定义被破坏记为 `INVALID`。`INVALID` 必须修复根因并重跑受影响数据源的完整五组、三种子矩阵，不能只补跑 `F-P`。

### G1：常规检测非劣

对 GeNIS、TQHC2 两个常规面板，并对每个 `C ∈ {F-A, F-H, F-S, F-R}`，必须同时满足：

- 三个实际种子的 `Δ(P,C)` 均严格大于 `-0.021`。
- 三种子等权汇总的 `Δ(P,C)` 严格大于 `-0.021`。
- 常规检测族校正后的单侧 95% 同时置信下界严格大于 `-0.021`。

任一数据源、任一对照未满足即 `G1` 失败。不得用另一数据源的增益、物理收益或次指标抵消。

### G2：困难泛化与协议标签捷径排除

至少一个预先声明且合格的**同一困难面板**必须对全部四个对照同时满足：

- 三个实际种子的 `Δ(P,C)` 均严格大于 `0`。
- 三种子等权汇总的 `Δ(P,C)` 严格大于 `0`。
- 困难检测族校正后的单侧 95% 同时置信下界严格大于 `0`。

不得在不同困难面板上分别挑选一个有利对照后拼接为成功。除此之外，TQHC2 协议标签匹配面板必须合格，且 `F-P` 相对 `F-A` 的三个实际种子、等权汇总和族校正同时下界均严格大于 `0`。该附加条件失败表示物理旁路收益不能排除协议标签捷径，`G2` 失败；面板因制品不足而无法评估时记为 `NOT_READY`，不按零收益处理。

### G3：物理改善幅度与真实物理归因

在 ns-3 成对 TCP/UDP 物理真值面板上，未见状态误差和无量纲物理残差必须**分别**通过以下条件：

1. 相对 `F-A`，三个实际种子的 `I(P,A)` 均严格大于 `0`。
2. 相对 `F-A`，三种子等权汇总的 `I(P,A)` 不小于 `0.10`。
3. 相对 `F-A`，物理族校正后的单侧 95% 同时置信下界严格大于 `0`。
4. 相对 `F-H`、`F-S`、`F-R` 中每一个对照，三个实际种子及三种子等权汇总的 `I(P,C)` 均严格大于 `0`，且物理族校正后的单侧 95% 同时置信下界严格大于 `0`。

`10%` 是相对 `F-A` 的预先冻结幅度门槛，置信下界要求确认改善方向而非要求下界也达到 `10%`。这种写法同时避免只凭点估计宣布成功，也不把事先未声明的更严门槛事后加入裁决。

- 未见状态误差与物理残差是“同时满足”关系；任一失败即 `G3` 失败。
- TCP 与 UDP 必须分别达到物理面板独立簇下限。对每个协议分别报告三个种子、等权效应量和同时置信下界。
- “跨协议稳定”只在 TCP 与 UDP 的两项物理指标相对 `F-A` 均满足三个实际种子为正、等权汇总为正且同时置信下界为正时成立。否则即使汇总 `G3` 通过，也只能陈述汇总物理收益，不得声称跨协议稳定。
- QUIC 不可评估不阻断 TCP/UDP 候选裁决，但最终状态必须带 `TCP_UDP_ONLY` 限定，且论文不得声称已验证 QUIC。以后加入 QUIC 必须按新版本合同重跑完整五组、三种子矩阵。
- 若 `F-H` 有收益而 `F-P` 不能稳定胜过 `F-S` 或 `F-R`，只能说明历史或附加输入有用，不能归因为真实物理旁路。

## 8. 异常增益与泄漏审计

在任一常规、困难或协议分层检测面板上，若 `F-P` 相对任一对照的三种子等权宏平均 F1 增益严格大于 `0.10`，立即进入 `AUDIT_REQUIRED`。这不是自动否决，也不是自动成功；审计结束前禁止升级实验规模或形成效果结论。

审计至少包含：

- 以原始文件哈希、会话标识、连接标识、捕获标识和近重复指纹检查跨分割重复与近重复。
- 证明分割组标识、`sample_id` 和 `evaluation_cluster_id` 在模型预测前生成，且没有依据结果重新分组。
- 逐字段核对未来信息、仿真真值、标签、标签派生量、全数据统计量和模型预测未进入输入、缩放器、随机池或路由。
- 核对协议路由停止梯度；在协议标签匹配面板重新计算结果，确认收益不是协议标签捷径。
- 核对 `F-S` 置换未看标签或预测，`F-R` 仅使用开发训练池，所有缩放器和校准器只使用允许数据区。
- 核对五组参数量、训练预算、早停、检查点规则和调参次数，排除故意或意外弱化对照。
- 由独立分析入口根据冻结预测与清单重算主指标、配对效应量、置信区间和门槛，并核对运行制品与 SwanLab 记录的哈希和时间线。

审计不得通过增加有利种子、改变分类阈值、删除异常样本、重定义困难面板或改换主指标来“解释”异常增益。审计通过后保留原始异常效应并继续裁决；发现泄漏、污染或不公平对照则记为 `INVALID`，修复后按新运行标识重跑受影响数据源的完整矩阵。

## 9. 最终状态与升级条件

最终报告只能使用以下互斥状态之一：

| 状态 | 条件 | 允许结论与动作 |
|---|---|---|
| `NOT_READY` | 运行、样本、面板或必要制品不完整，尚不能合法裁决 | 补齐同版缺失制品；不得宣布成败 |
| `AUDIT_REQUIRED` | 触发异常增益线且审计未完成 | 只执行冻结审计；不得升级规模 |
| `INVALID` | 泄漏、拆分污染、组间不公平或合同被破坏 | 废止受影响结果，修复后重跑完整矩阵 |
| `NO_GO` | `G0` 有效，但 `G1`、`G2`、`G3` 或协议标签匹配附加条件任一失败 | 不进入 59,656 样本与后续 Qwen 正式 R2 |
| `GO_TO_FORMAL_R2_NARROW` | `G0` 至 `G3` 全部通过且无未决审计，但常规检测未达到下述全面优胜条件 | 允许进入正式 R2；结论仅限困难泛化和真实物理收益 |
| `GO_TO_FORMAL_R2_BROAD` | 窄口径条件全部通过，且两个常规面板相对四个对照均满足三个种子为正、等权汇总为正、常规族同时下界为正 | 允许进入正式 R2；可预注册常规检测、困难泛化与物理收益的联合主张 |

补充限制：

- 通过 `G1` 与 `G3` 但未通过 `G2` 时，可以把“检测非劣且有物理或成本收益”作为窄口径研究发现如实报告，但候选实验状态仍是 `NO_GO`，不能据此升级到正式 R2。
- 仅物理残差改善、仅未见状态改善、仅 `F-H` 改善，或 `F-P` 未稳定胜过 `F-S/F-R`，均不能获得 R2 升级。
- `GO` 只是允许支付正式实验成本，不是论文最终结论。正式 R2 仍须使用独立冻结计划，并在候选裁决后才允许解封相应后续阶段。
- 缺少合格 QUIC 时，两个 `GO` 状态都必须附加 `_TCP_UDP_ONLY`；不得省略限定。

## 10. 强制交付制品

候选裁决包必须同时包含：

- 本合同、正式配置、代码版本、数据清单和拆分清单的内容哈希。
- `15` 个运行的唯一标识、状态、种子、检查点、日志和资源记录。
- 各数据源的 `sample_id`、`evaluation_cluster_id`、标签、协议、困难面板成员关系和分割来源清单。
- 五组逐样本预测、逐簇物理真值与预测、掩码、专家或回退使用记录；敏感原始内容可不复制，但索引和哈希必须可审计。
- 每个种子的主次指标、所有预声明配对效应量、等权汇总、样本标准差、双侧区间、族校正单侧同时下界和方向检查。
- 多重比较族定义、有效自助重复数、分析随机种子和次指标 Holm 校正结果。
- `G0` 至 `G3` 每个原子条件的机器可读布尔值、证据路径、失败原因及唯一最终状态。
- 异常增益审计表；未触发时也须明确记录“未触发”及最大观测检测增益。

只提供最佳种子、三种子均值、最优困难面板、`F-P` 单组结果、训练拟合指标或截图，均不构成可裁决证据。

## 11. 既有试验的使用边界

- HGB 空对照和静态 DistilBERT 试验只证明真实物理输入必须胜过置换与随机对照，并提示不能用单种子或静态弱实现代表最终 R2。
- 本合同没有使用既有试验的任何数值来设定非劣界、10% 物理门槛、异常增益线、面板、种子或置信区间方法。
- 既有 HGB、静态 DistilBERT 与本候选实验不得合并样本、合并种子或共同计算置信区间，也不得用其结果替补任何缺失运行。
- 若实际实现与本文任一冻结定义不一致，必须先登记偏差并决定重跑或新建合同版本，不能在结果表脚注中事后豁免。
