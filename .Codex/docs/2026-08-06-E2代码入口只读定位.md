# E2 困难域实验代码入口只读定位

## 结论

E2 不能直接运行现有共享 B0 或 R2 训练入口：前者固定为 GeNIS 训练、TQH 外测，后者固定为旧 R2 物理旁路视图及 18 维旁路。可复用其数据校验、指标、训练循环、SwanLab、检查点和置换逻辑；应新建 E2 专用数据视图、训练器与远程包装器，避免把旧实验合同硬改成新合同。

本定位只读完成，未运行 GPU、未读取最终测试。

## 1. E1 七字段、拆分与指标

### 已完成 E1 制品

- 运行目录：`thesis/experiments/llm_probe/runs/baselines/tqh-c2-v120-e1-hard-protocol-diagnostics-seed42-20260806T094158Z/`。
- 字段清单在 `config_snapshot.json`：`duration`、`orig_bytes`、`resp_bytes`、`orig_pkts`、`resp_pkts`、`orig_ip_bytes`、`resp_ip_bytes`。
- 当前开发协议的训练、校准、验证数量分别为 83,099、26,216、19,212；8 个完整捕获组未分配，E2 不得读取。
- E1 结果和场景指标位于 `summary.json`、`scenario_metrics.csv`、`field_importance.csv`；E1 没有将数据处理逻辑固化为可复用的 `src/` 入口。

### 可复用的候选数据处理模块

- `src/flow_probe/tqh_c2.py`：Zeek `conn.log` 字段解析，包含 `duration`、双向字节与包数处理。
- `src/flow_probe/tqh_c2_candidate.py`：标签合同、字段角色、确定性样本记录和审计写入模式；它的 `MODEL_FEATURE_FIELDS` 是 38 个包序列聚合字段，**不能作为 E2 七字段输入**。
- `src/flow_probe/tqh_c2_candidate_abc.py` 与 `tqh_c2_candidate_abc_fixed.py`：按 `capture_group_id` 进行样本分配、确定性清单和哈希审计；前者只覆盖 A/B/C 且版本为 1.0.1，**不能直接处理 v1.2.0 的 D 组**。
- E2 应从已经冻结的 v1.2.0 开发协议和 E1 的七字段记录生成独立视图，按 `capture_id`、`profile` 和既有 `split_id` 写清主面板 A+B+D→C 与确认面板 A+B→C，不能重新随机抽样。

### 指标代码

- `src/flow_probe/tabular_baselines.py`：`_evaluate()` 已输出宏平均 F1、平衡准确率、校准误差、良性误报率、预测与运行成本；可复用指标语义，不应让树模型接口决定 E2 数据格式。
- `src/flow_probe/shared_b0_distilbert_baseline.py`：`compute_binary_metrics()` 和 `evaluate_split()` 已输出二分类宏平均 F1、两类 F1、恶意召回、良性误报率、平衡准确率、校准误差、Brier 分数及逐样本概率。E2 还需在其上新增捕获组等权、最差捕获组、PR-AUC、MCC、负对数似然和 `TPR@1% FPR` 聚合器。

| 目标 | 现有代码 | 复用结论 |
| --- | --- | --- |
| HGB、XGBoost | `src/flow_probe/tabular_baselines.py` | 可复用模型构建、标准化、预测和基础指标；目前 `SUPPORTED_MODELS` 仅含 `hgb`、`xgboost`。 |
| 随机森林 | 无 | 需在 E2 表格基线模块新增，不能冒充现有支持。 |

| 普通 DistilBERT | `src/flow_probe/shared_b0_distilbert_baseline.py` | 可复用模型加载、混合精度、训练循环、检查点、SwanLab 与逐样本预测；当前 `REQUIRED_SPLITS` 固定为 GeNIS/TQH，数据加载器须抽出或在新模块重写。 |
| 物理旁路 DistilBERT | `src/flow_probe/r2_distilbert_sidecar_probe.py` | 可复用四变体串行调度、线性旁路投影和结构审计；当前输入、样本数和 `T-A/T-P/T-S/T-R` 固定旧 R2 合同，不能直接执行 E2。 |

## 3. E2-A/S/P/X 最小共同入口

建议新增，不修改旧共享 B0 与 R2 运行合同：

1. `src/flow_probe/e2_hard_domain_data.py`
   - 读取冻结 v1.2.0 七字段记录、主/确认面板清单。
   - 只允许七字段及由七字段导出的共同文本；隔离未分配最终测试。
   - 产出 `sample_id`、`capture_id`、`profile`、`split_id`、标签和稳定顺序的 E2 视图。
2. `src/flow_probe/e2_hard_domain_metrics.py`
   - 复用 `compute_binary_metrics()`，补齐捕获组等权、最差组、PR-AUC、MCC、负对数似然、`TPR@1% FPR`、源域等权与置信区间。
3. `src/flow_probe/e2_hard_domain_baselines.py`
   - 统一运行 LogReg、随机森林、HGB、XGBoost、MLP、预注册 GroupDRO 和普通 DistilBERT。
   - 所有方法共享相同面板、字段、源域校准与逐样本预测格式。
4. `src/flow_probe/e2_shared_pinn.py`
   - 同一 DistilBERT 基座实现 `E2-A`、`E2-S`、`E2-P`、`E2-X`。
   - `E2-A` 为普通编码器；`E2-S` 仅增加可微状态头；`E2-P` 再增加共享守恒残差和边界项；`E2-X` 结构和预算同 `E2-P`，只置换物理监督对应关系。
   - 必须记录物理状态误差、无量纲残差、状态头梯度范数、约束违反率与检测指标。
5. `configs/e2_hard_domain_seed{42,43,44}.yaml`
   - 每个配置冻结面板、字段、种子、阈值来源、训练预算、模型与制品哈希。
6. `scripts/run_e2_hard_domain.sh`
   - 只调用新入口，用统一远程启动器以 `uv run --no-sync` 执行，并保存唯一运行目录、状态、日志、SwanLab 与制品清单。
7. `tests/test_e2_hard_domain_data.py`、`tests/test_e2_hard_domain_metrics.py`、`tests/test_e2_shared_pinn.py`、`tests/test_run_e2_hard_domain_wrapper.py`
   - 覆盖最终测试隔离、面板互斥、七字段白名单、置换分层、E2 变体结构等价及指标聚合。
8. `pyproject.toml`
   - 新增对应命令入口。旧命令未注册 `r2_distilbert_sidecar_probe.py`，E2 应显式注册，禁止依赖 `python -m` 的隐式入口。

## 4. 最小服务器验证与时长

首次仅做开发集静态和小样本行为验证，**不读取最终测试、不占用 GPU**：

```bash
cd /root/autodl-tmp/thesis/experiments/llm_probe
uv run --no-sync pytest -q \
  tests/test_e2_hard_domain_data.py \
  tests/test_e2_hard_domain_metrics.py \
  tests/test_e2_shared_pinn.py \
  tests/test_run_e2_hard_domain_wrapper.py
bash -n scripts/run_e2_hard_domain.sh
```

- 预计 1 至 3 分钟；这些是代码交付检查，不是最终测试或 GPU 训练。
- 随后在用户确认 GPU 可用后，先跑种子 42 的 `E2-A/S/P/X` 单主面板；按旧 R2 探针的每变体 192 步和同一张 5090 估计，4 组约 35 至 60 分钟。完成后从同一逐样本预测派生捕获组、校准与效率指标，不另起训练。

## 风险

- E1 七字段与 R2 的 18 维队列旁路不是同一数据合同；没有可观测状态的可微映射前，不能把 R2 旁路直接贴到 E1 数据上并称为 PINN。
- GroupDRO、CORAL、随机森林和 MLP 当前不存在；应由 E2 新模块实现并先固定一种域泛化基线，不能在看到 C 的结果后挑选。
- 旧 `bounded_physics_train.py` 的 E1/E2 命名对应历史有界物理实验，与当前 E2 难域矩阵不是同一合同，禁止复用其“E2”字面名称。
