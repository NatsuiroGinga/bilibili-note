# RWKV-8 ROSA、DeepEmbed 与 DeepEmbedAttention 候选机制综述与实验建议

## 一、结论

**不建议把 ROSA、DeepEmbed、DeepEmbedAttention 直接指定为第三章的两个正式机制。** 当前证据只足以支持候选筛选：RWKV-8 仍是实验性设计线，三者都没有独立、正式、同行评审的 RWKV-8 架构论文；网络安全效果完全未证。

候选关系并不对称：

1. **ROSA 可独立移植。** 官方仓库已有纯 ROSA+FFN、RWKV-7+ROSA 与 1/4 比特 QKV 演示；社区 ROSA-Tuning 还给出挂载到 Qwen 窗口注意力的完整公式。它不依赖原生 RWKV 状态更新。
2. **DeepEmbed 可独立移植。** 它是每层、每 token 的条件前馈网络调制，不依赖 TimeMix；可挂到 Transformer、FT-Transformer、GRU 或 TCN 的前馈/门控支路。
3. **官方 DeepEmbedAttention 不是与 DeepEmbed 独立对称的第二机制。** `rwkv7b` 同时含 DeepEmbed 和 DEA。DEA 另加 token 条件的压缩 K/V 缓存与因果全注意力，随后与 RWKV TimeMix 残差相加；它没有替代 DeepEmbed。
4. **首选严格 2×2 只能暂定为“DeepEmbed × ROSA”，不能用“DeepEmbed × DeepEmbedAttention”。** 前者仍须分别通过真实数据病灶门。若其中任一无适配信号，应淘汰，并从域泛化、未见家族、跨架构对齐、低误报排序、开放集拒识或校准家族选择第二机制。
5. **时间漂移不是必要条件。** 至少需要一个真实泛化轴，但可为时间、未见家族、设备、CPU 架构、协议或采集环境。无时间漂移但有自然长序列、重复事件后缀和组合泛化时，ROSA 与 DeepEmbed 仍可成立为待验证候选。
6. **直接移植不构成创新。** 可主张的任务化差量必须同时包含真实病灶、网络安全语义约束、公式变化、反事实消融和真实泛化证据；源码换名或把模块插入新骨干均不够。

当前状态统一标为：**设计可行，实验待证**。DeepEmbedAttention 因嵌套关系、二次复杂度和证据不足，降为外部对照，不进入首轮正式 2×2。

## 三、官方身份、公式与成熟度

### 3.1 ROSA

**名称。** 官方 `RWKV-v8/README.md` 展开为 **Rapid Online Suffix Automaton**；RWKV wiki 与 ROSA-Tuning 展开为 **RWKV Online Suffix Automaton**。这是来源间真实命名差异，不能擅自统一成唯一“官方全称”。

**离散算子。** 给定当前位置的查询后缀，选择历史键序列中最长、最近的相同后缀，再读取该历史匹配的下一个值。可简写为：

```text
j* = argmax_{j<t} (最长后缀长度, 最近位置)
r_t = v_{j*+1}; 无合法历史后继时 r_t = 0
```

官方 4 比特演示把连续 Q/K/V 以符号位分成每路 4 比特的离散符号，命中后把读出的 V 位映射为 `+e/-e`，未命中为 `0`，再线性投影并作为残差支路加入。`260222_rosa4bitLM_L12.py` 的关键路径是：

```text
q_t,k_t,v_t = Linear(token_shift(x_t))
symbol = pack(sign(q_t/k_t/v_t), 4 bits)
y_t = decode(ROSA(q_symbol, k_symbol, v_symbol))
x_t' = x_t + W_o y_t
```

**版本与代码。** 官方仓库至少包含 `251014_rosa_1bit_train.py`、`251014_rosa_1bit_layer.py`、`251014_rosa_onlyemb_train.py`、`251024_rosaQKV_run.py`、`260212_rosa1bitLM_L12.py`、`260222_rosa4bitLM_L12.py`。前两份训练代码自注“极慢”；最新 4 比特文件仍用 CPU 穷举慢参考，不能据此宣称工程线性复杂度。

**成熟度。** 有算法、源码、合成任务、MiniPile 小模型和社区预印本，故不是空想；但官方 RWKV-8 线没有正式论文、冻结训练实现或网络安全实验。裁决为**工程原型**。

### 3.2 DeepEmbed

**名称与版本。** 官方简称 **DeepEmbed/DE**；`rwkv7a` 表示 RWKV-7 加 DE。它不是输入层再加一次普通 embedding。

**源码公式。** 对层 `l`、位置 `t` 和 token `u_t`，`rwkv_v7a_demo.py` 可归纳为：

```text
z_t = ReLU(K_l shift(x_t))^2
s_t = (x_t W_l,1) E_l[u_t]
g_t = s_t W_l,2 + b_l
FFN_DE(x_t,u_t) = W_l,V (z_t ⊙ g_t)
```

其中 `E_l[u_t]` 在演示中重排为 `32×32` token 专属矩阵。当前隐藏状态选择该矩阵中的调制方向，因而比 wiki 的 `FFN(x) * Emb(token)` 简式更具体。

**目的。** 以稀疏按 token 访问的大表增加静态知识容量，用 RAM/SSD 预取而非让全部参数常驻显存。Engram 全文把它归入“嵌入扩容”近邻，并表明条件查表并不自动等于推理：局部静态模式和动态组合推理应分开承担。

**成熟度。** 有官方推理参考、`rwkv7a` 模型命名与仓库指向，但没有独立论文、完整公开训练合同和网络安全实验。裁决为**较 ROSA 简单、可移植，但科学证据薄弱的工程特性**。

### 3.3 DeepEmbedAttention

**名称与版本。** 官方简称 **DeepEmbedAttention/DEA**；`rwkv7b` 表示 `RWKV-7 + DE + DEA`。

**源码公式。** `rwkv_v7b_demo.py` 先缓存每层低维 K/V，再按历史 token 的 `k_emb/v_emb` 重构和调制：

```text
q_t = LN(W_q x_t)
k_i = LN((W_k2 cache_k_i) ⊙ E^K_l[u_i])
v_i = LN(tanh(W_v2 cache_v_i) ⊙ E^V_l[u_i])
a_ti = softmax_i(64 tanh(q_t^T k_i / 1024)), i≤t
o_t = Σ_i a_ti v_i
x_t' = x_t + TimeMix_l(x_≤t) + o_t
```

随后 ChannelMix 仍运行 DeepEmbed。源码为每 token 保存每层两组低维 K/V，并形成因果 `T×T` 分数矩阵；因此它是**带 token 条件 K/V 重构的压缩缓存全注意力混合支路**，不是无注意力机制。

**成熟度。** 只有低效推理参考和发布宣传；无独立公式文档、正式论文、训练代码或受控消融。所谓“KV cache 为 MLA 的 1/9”缺少本轮可核的正式实验合同，不能作为本课题资源事实。裁决为**外部对照，不进入首轮候选**。

## 四、独立性与可移植性

| 机制 | 可脱离原生 RWKV | 合理挂载点 | 原生依赖 | 当前角色 |
| --- | --- | --- | --- | --- |
| TimeMix/动态衰减 | 部分可移植 | Transformer/TCN 的因果状态支路，GRU 的时间间隔门 | 完整 RWKV-7 广义 Delta 状态依赖其矩阵状态、初始化、参数组与融合内核 | 中性状态基线或另行候选，不因“RWKV”自动成创新 |
| ROSA | **可** | 任意序列骨干的输入前、层间或局部注意力旁路 | 离散 Q/K/V、合法序列边界、后缀索引和训练替代梯度 | 主候选，须先过重复后缀病灶门 |
| DeepEmbed | **可** | Transformer/FT 的 FFN，GRU/TCN 的逐 token 通道门 | 稳定 token 词表、逐层查表、稀疏参数训练/预取 | 主候选，须先过 token 稳定性病灶门 |
| DEA | 算子可拆，官方版本不独立 | Transformer/RWKV 的压缩 K/V 全注意力支路 | 官方 `rwkv7b` 同时包含 DE 和 TimeMix 残差 | 外部对照；不可与 DE 构成对称 2×2 |

普通 Transformer 是检验 DE×ROSA 最干净的中性骨干：FFN 可挂 DE，局部因果注意力旁可挂 ROSA。FT-Transformer 只能作为**每事件的字段编码器**，其输出再进入合法时间序列骨干；不得把独立表格行或字段顺序冒充时间。GRU/TCN 可检验收益是否只来自 Transformer 挂载便利：DE 调制门/通道，ROSA 作为相同维度残差注入。

## 五、数据适配不是“必须时间漂移”

### 5.1 共同数据门

候选进入训练前必须同时满足：

- 自然且唯一的因果顺序、合法前缀读取和明确状态重置键；
- 可重复的离散局部/远程后缀或事件模式，不是任意排序；
- 稳定但稀疏的 token 语义，如字符、系统调用、协议状态、包类型、标志或字段类别；
- 非饱和且公平的强基线，主要评价量仍有可检测错误余量；
- 至少一个真实泛化轴：时间、未见家族、设备、架构、协议或环境。

### 5.2 数据集裁决

| 数据 | ROSA | DeepEmbed | 无时间漂移时是否成立 | 裁决 |
| --- | --- | --- | --- | --- |
| LSPR23/24 | 协议、端口角色、TCP 状态和事件序列可试；连续 Raw83 必须另做量化消融 | 合法字段类别和协议 token 可试；IP/主机身份禁止入表 | 可以，但跨年天然提供更强泛化轴 | 安全任务最贴近；ROSA 先测后缀命中，DE 先测跨年 OOV/捷径 |
| DRIFT-DGA 2026 | **低到中**：只能在单个短域名内部检索既往字符/子词后缀；不能跨域共享状态 | 字符、子词和 n-gram 最适配 | **可以**；未见家族/组合域名即真实轴 | DE 输入合同最干净；ROSA 必须先证明域内可检索位置与信息增量 |
| CIC-YNU-IoTMal 2026 | 系统调用和协议事件长且重复，边界为单次执行 | 系统调用/参数类别/架构 token 稳定 | **可以**；跨 CPU 架构、环境或家族即可 | DE×ROSA 严格 2×2 的结构首选，但必须排除沙箱/架构标签捷径 |
| CESNET-TLS/QUIC | 方向、包类型、版本、扩展可离散；前 20/30 包可能太短 | 协议枚举适配；SNI/IP/ASN 禁止 | **可以**；跨服务、协议、周或环境均可 | 更适合 DE 与开放集/校准；ROSA 仅条件保留 |
| CESNET-TimeSeries24 | 连续聚合值需人为量化 | 缺稳定离散词表 | 长序列不足以弥补 token 缺口 | 不适合作为 DE/ROSA 主证据 |

ROSA 在无时间漂移但有长系统调用序列、重复协议事件或组合泛化时仍有明确问题对象。DeepEmbed 在短序列上也可能成立，只要错误确实集中于可复用的稀疏 token/n-gram；它不需要长期记忆。二者都不能靠“数据有时间戳”或“token 很多”获得资格。

### 5.3 对 DRIFT“ROSA 覆盖”的概念纠正

此前可行性材料若把“某个 T25 域名或公共后缀在 T17 域名集合中出现”称为 ROSA 覆盖，该说法**错误，不能沿用**。官方 ROSA 的对象是一条有序 token 序列：在当前位置寻找**同一序列内**最长的既往匹配后缀，然后读取该历史匹配的后继。DRIFT 每个域名都是独立样本，推理时必须逐域名重置。

因此，DRIFT 的合法 ROSA 量只有：域名内部可检索位置比例、最长域内匹配长度、合法后继比例、后继可预测率，以及相对同预算 n-gram 的信息增量。跨年份域名集合交集、公共 DNS 后缀集合命中和跨域名字符片段命中均不属于原生 ROSA。

若另建跨域名共享自动机，它必须定义自然主体、更新顺序、训练/推理可见性、容量和删除规则，并作为**新的跨样本记忆候选**单独审查；不得借 ROSA 名称获得因果合法性。基于此纠正，DRIFT 对 DeepEmbed 仍为高适配，对原生 ROSA 由“高”降为**低到中、必须先探针**。

## 六、任务化改造与原创边界

### 6.1 ROSA 的网络安全差量

直接把事件 ID 送入 ROSA 不是创新。可检验的任务化版本应做到：

- 以自然实体或单次执行为边界，跨实体强制清空自动机，避免身份污染；
- 将合法离散字段组合成**去身份行为码**，连续包长/间隔的量化器冻结且作为独立消融；
- 输出后缀匹配长度、历史距离、后继分歧和命中置信，而不是把命中值无条件相加；
- 可选让真实时间间隔只调节历史证据可信度或过期，不把时间漂移当必要前提；
- 在固定容量下定义淘汰/过期规则，并与标准 SAM、固定阶 n-gram 和哈希记忆同预算比较。

只有“自然实体约束 + 行为码语义 + 固定容量/过期公式 + 与神经表示的可证伪冲突处理”整体获得证据，才可能形成朱式任务化改造。ROSA、SAM、最长后缀和后继读取本身均已被占用。

### 6.2 DeepEmbed 的网络安全差量

直接把协议或系统调用换成逐层大表同样不是创新。可检验版本应：

- 按字段类型分表或分解为字段原型与取值原型，禁止 IP、域名、主机哈希等身份键；
- 只对训练期稳定词表和可解释 n-gram 开表，未登录项进入共享未知原型；
- 用当前事件上下文、合法历史和可选时间间隔调制查表结果，禁止标签或最终域统计参与寻址；
- 报告 OOV、新生/消失 token、频率分面、表碰撞、查表门活动率和错误集中度；
- 与普通 embedding、参数匹配 FFN、哈希 n-gram/Engram 风格记忆作直接近邻消融。

原创性只能落在“字段语义分解、去身份约束、跨域稳定寻址和病灶驱动门控”的新公式与实验，不落在 DeepEmbed 查表乘法本身。

### 6.3 DEA 的边界

若另行研究 DEA，应把它定义为外部强基线：同一低维 K/V 缓存下比较无 token 条件重构、仅 K 条件、仅 V 条件、K+V 条件和普通全注意力。不得把 `rwkv7b` 的 DE+DEA 整包作为“仅 DEA”。由于它和普通注意力都形成全局 `T×T` 分数，短序列数据上资源优势和性能差量均可能不可测。

## 七、严格非惰性 2×2

### 7.1 推荐计算图

在数据病灶同时通过时，可先以中性因果 Transformer 为基础模型：

```text
合法事件/字符 token
  -> 共享输入编码
  -> 因果骨干层
       -> 基础局部注意力/状态支路
       -> A: DeepEmbed 调制该层 FFN
       -> B: ROSA 从同一层输入生成离散 Q/K/V 并作固定残差注入
  -> 共享分类头/排序头
```

四格定义：

| 单元 | DeepEmbed A | ROSA B | 允许差异 |
| --- | --- | --- | --- |
| C00 | 关 | 关 | 中性基础模型 |
| C10 | 开 | 关 | 仅 DE 的表、投影与门 |
| C01 | 关 | 开 | 仅 ROSA 的 Q/K/V、索引与输出投影 |
| C11 | 开 | 开 | 两条已定义支路同时开启 |

**C11 不得新增融合器、门、损失、层数、宽度或专属调参。** 所有单元预先实例化同一残差槽，关闭机制时输出严格为零；C11 只是 `C10` 与 `C01` 的并集。

协同假设必须可证伪：DeepEmbed 负责稳定、稀疏的局部字段/token 语义；ROSA 负责跨位置的精确重复后缀与历史后继。若二者读的是同一固定 n-gram，联合大概率冗余；只有 C11 同时增加非平凡 ROSA 命中利用率、保持 DE 门选择性，并优于两个单机制，才支持互补。

### 7.2 判据

- 四格使用**单一预冻结种子、相同数据顺序、批次、初始化公共参数、优化步数和选模权限**；不要求多种子训练。
- 统计单位必须是自然独立评价单元：LSPR 实体、DGA 域名/家族、IoT 单次执行或 CESNET 流/服务；在这些单元上做配对 bootstrap 或置换检验。
- 两个单机制分别相对 C00 的预注册主效应必须为正，且效应区间不跨预注册无效区；C11 必须优于 C10 和 C01。
- 若主张协同，交互项 `I=(C11-C10)-(C01-C00)` 的配对区间必须满足预先冻结的正交互条件。
- 同时报绝对效应量、跨年份/家族/设备/协议分面一致性、逐流/事件护栏和机制活动；这些是评价单元证据，不得写成训练随机性证据。
- 任一机制无活动、只在身份字段上获益、只压低源性能制造保持率，或不优于最近邻消融，即在该级淘汰。

## 八、公平比较

### 8.1 骨干

- 主 C00 从普通因果 Transformer、FT事件编码器+时间骨干、GRU、TCN 中以同一开发权限选定，不预设 RWKV 胜出。
- FT-Transformer 只能编码同一事件的字段；跨事件依赖必须由明确时间骨干承担。
- TimeMix/动态衰减作为状态机制对照时，至少比较“时间间隔只作输入”“时间间隔控制衰减”和“完整状态更新”，防止把额外时间特征误归因于状态动力学。
- 原生 RWKV-8 没有稳定正式训练实现，不能作强正式 C00。官方 ROSA 脚本只用于算子一致性测试；原生 RWKV-7 公式只作来源对照，不复活历史训练后端。

### 8.2 参数与计算

- DeepEmbed 的总参数、每步激活参数、训练梯度通信、RAM/SSD 占用和预取字节必须分开报告；不能因不驻显存就称参数“免费”。
- ROSA 报自动机状态数、峰值内存、命中查询数、CPU 时间、CPU-GPU 等待和端到端吞吐；慢参考的二次开销不得冒充优化实现。
- DEA 报 `T×T` 分数、每 token K/V 缓存、重构 FLOP 和峰值显存；与相同低维缓存的普通注意力比较。
- 容量对照至少包括参数匹配、激活 FLOP 匹配和端到端时延匹配三种视角；若无法同时匹配，分表报告，不选择最有利口径。

### 8.3 必要消融

| 候选 | 最近邻和消融 |
| --- | --- |
| ROSA | 固定阶 n-gram、普通哈希表、标准静态 SAM、同容量最近后缀、随机后继、打乱实体内时间、跨实体不清空的泄漏阳性对照 |
| DeepEmbed | 普通输入 embedding、等参数 FFN、共享单表、分字段表、随机 token 表、冻结表、去上下文门、哈希 n-gram/Engram 风格门控 |
| DEA | 普通全注意力、同低维 K/V 缓存、无 token 条件、仅 K、仅 V、K+V、无 DE 的人为拆分版 |
| 联合 | C00/C10/C01/C11；禁止 C11 独有融合器；另报机制活动与两支路梯度/残差尺度 |

## 九、最低成本真实数据证伪

### 9.1 ROSA

**零训练病灶门。** 在训练区与较晚开发区按合法序列边界统计最长后缀命中率、匹配长度、历史距离、后继条件熵、跨域保持率和固定阶 n-gram 覆盖率。

**支持条件。** 非平凡长后缀在错误相关样本中稳定出现；ROSA 相对相同内存的固定阶 n-gram/SAM 降低后继不确定性，且在至少一个真实泛化轴上保持。

**失败条件。** 命中几乎全为单 token/短 n-gram；打乱时间不改变指标；跨实体不清空才有收益；连续量化器决定全部效果；或固定阶表已解释同等信号。

**轻训练。** 单一冻结种子，只训练小投影/注入支路，骨干先冻结；若主效应和活动门同时通过，再解冻共同骨干做四格。最大步数按 C00 实测时延冻结，不写无依据绝对轮数。

**风险。** 当前官方精确反向/慢参考成本高；长序列自动机内存与 CPU-GPU 同步可能超过模型计算；离散符号碰撞会产生伪命中。

### 9.2 DeepEmbed

**零训练病灶门。** 统计合法 token/n-gram 的频率覆盖、跨域 OOV、新生/消失率、标签/实体身份互信息、基线错误按 token 频率和组合稀有度的集中程度。

**支持条件。** 错误显著集中在训练中可复用但组合稀疏的 token/n-gram，且词表在真实泛化轴上稳定；去身份后仍有余量。

**失败条件。** 收益所需键主要是 IP/SNI/主机/家族身份；OOV 主导未来域；普通 embedding 或等参数 FFN 已消除病灶；短序列任务已饱和。

**轻训练。** 在同一中性骨干上只开放 DE 表和投影，保持 C00 公共权重初始化、步数和数据顺序；先比较普通 embedding 与等激活参数 FFN，再支付四格成本。

**风险。** 表参数和优化器状态巨大、访问高度长尾、稀有 token 梯度不足；哈希碰撞和身份记忆可能制造虚假泛化。

### 9.3 DeepEmbedAttention

**最低门。** 先对同一冻结隐藏状态离线核算 K/V 缓存、注意力时延和普通低秩注意力差量；再在最小真实序列上比较“无 token 条件”与“有 token 条件”。

**失败即淘汰。** 若普通注意力达到相同性能、序列太短导致全局关系无额外信号、或 DE 拆除后 DEA 不再成立，则不进入 2×2。

**风险。** 二次注意力掩盖 RWKV/ROSA 的复杂度主张；官方实现嵌套 DE，归因困难；没有正式训练合同。

## 十、跨来源候选配对

两个正式机制不必都来自 RWKV。推荐按两个**独立病灶**配对，而不是按名称凑模块：

| 数据/病灶 | RWKV 系候选 | 非 RWKV 第二机制 | 独立性与四格要求 | 首选意见 |
| --- | --- | --- | --- | --- |
| LSPR：合法事件历史重复 + 跨年/环境退化 | ROSA；仅在后缀门通过时 | 预定义源环境 GroupDRO，或不读最终目标的域泛化 | ROSA 只改表示/检索；GroupDRO 只改样本权重；C11 无新融合器 | **条件推荐**；若后缀弱，改用 DeepEmbed+低误报排序 |
| LSPR：稳定字段语义 + 低误报告警 | DeepEmbed | 独立校准/纽曼-皮尔逊式低误报排序 | DE 只产分数；决策机制只在独立校准区定工作点 | **较自然**；不能把校准收益说成表示收益 |
| DRIFT-DGA：字符/n-gram 稀疏性 + 未见家族 | DeepEmbed | 家族留出训练、GroupDRO 或开放集拒识 | 词表记忆与家族泛化损失独立；同一输出头，无 C11 特有门 | **首选跨来源组合** |
| DRIFT-DGA：重复后缀 + 未见家族 | ROSA | Transcendent 类逐类拒识或严格开放集分数 | ROSA 只改表示；拒识只改决策；短串 ROSA 必须先过活动门 | 条件保留，优先级低于 DE |
| CIC-YNU：长系统调用重复 + 跨 CPU 架构 | ROSA | DANN/CORAL 类跨架构表示对齐 | ROSA 检索与域损失独立；C11 仅两损失/路径并用 | **最适合检验 ROSA 的结构数据**；需防架构标签捷径 |
| CIC-YNU：稳定系统调用语义 + 未见家族 | DeepEmbed | 家族组鲁棒训练或开放集拒识 | DE 查表与组损失独立 | **推荐**，但先核良性生成与沙箱共变 |
| CESNET-TLS/QUIC：协议 token + 未见服务 | DeepEmbed | 能量/梯度拒识或 Transcendent 类拒识 | 表示与拒识分层；阈值只在校准区拟合 | **优于 ROSA 配对**，已有开放集病灶先例 |
| CESNET-TLS/QUIC：短包序 + 周/协议变化 | ROSA | 域泛化或泄漏安全校准 | 两路径独立，但 ROSA 可能因序列短无活动 | 仅零训练门通过后保留 |
| CESNET-TimeSeries24：连续长序列 + 无标签漂移 | TimeMix/时间间隔衰减 | 无标签变化检测/校准诊断 | 状态更新与决策监控独立 | 淘汰 DE/ROSA，改走连续时序机制 |

GroupDRO、DANN、Transcendent、普通校准和开放集拒识本身均已有全文近邻，不能作为新颖性。潜在创新必须来自网络安全任务的病灶映射、合法数据角色、新公式差量以及严格四格实证。

## 十一、可立即实现的最小真实实验规格

**推荐实验：DRIFT-DGA 的 `T17→T25` ROSA 域内可检索位置与 DeepEmbed 未登录率双探针。** 该探针不训练模型、不选择最终机制，只回答两项机制是否有输入层面的活动空间；运行名建议为 `ch3-drift-t17-t25-rosa-deepembed-coverage-probe-v1`。这里的 `coverage` 仅指逐域名重置后的域内可检索位置比例，不指跨年域名集合命中。先做此探针，任何一项失败都不为其支付四格训练成本。

### 11.1 输入冻结

- `T17` 固定为 2017 年来源切片，所有词表、子词器、n-gram 集合与频数只在 `T17` 拟合；`T25` 固定为 2025 年前向复核切片，只转换和计数，不回写词表。
- 主视图采用论文定义的 **eSLD**：小写化，只保留 RFC 1035 的字母、数字、连字符和点，排除含下划线样本，再用论文的确定性规则去除 TLD/ccTLD 与平台后缀噪声。该规则须以 DRIFT 官方实现或发布字段为准，不自行用另一 PSL 库替换。
- 辅助 `raw` 视图保留规范化后的完整域名标签串，只用于判断 TLD/平台后缀是否制造虚假重复或低 OOV；**不得作为主视图选择依据**。若 `raw` 显著优于 eSLD，默认解释为后缀捷径风险，而不是机制支持。
- 每个域名是一条独立因果字符序列，域名开始时强制清空 ROSA 状态。不得跨域名建自动机，也不得按数据文件顺序拼接域名。
- 本实验中的“ROSA 后缀”指**当前位置结束的字符/子词上下文，在同一域名更早位置出现后读取其后继字符**；它不是 DNS 公共后缀、TLD 或 eSLD 的“suffix”。
- 同时冻结字符视图与一个仅由 `T17` 训练的子词/n-gram 视图。字符表若只有固定 DNS 字符且 OOV 为零，只能说明字符覆盖稳定，不能支持 DeepEmbed 的大表容量价值。

### 11.2 确定性探针

- ROSA 对字符和冻结子词分别计算：有合法历史后继的覆盖率、最长匹配长度分布、历史距离、后继一致率，以及按域名长度和 DGA 家族/良性类别的分面。固定阶 n-gram 在相同历史可见性和相同状态预算下同步计算。
- DeepEmbed 对字符、子词和固定 n-gram 键分别计算：位置加权 OOV、含 OOV 的域名比例、`T17` 频数分位在 `T25` 的覆盖质量、新生/消失 token 质量，以及哈希方案的碰撞率。
- `raw` 与 eSLD 使用相同代码路径和样本身份，逐域名配对比较；任何行数差异必须来自预注册的下划线过滤或无有效 eSLD 排除，并单独列出。
- 全部结果写入一个 JSON：输入清单/哈希、规范化规则版本、T17/T25 行数、重复域名去重策略、词表哈希、各视图指标、分面指标和运行时。不得保存逐域名标签或预测数组为长期制品。

### 11.3 必须落盘的观测量

- ROSA 主量：`T25` 非平凡匹配覆盖、相对同预算固定阶 n-gram 的后继负对数似然/准确率效应、匹配长度和后继分歧；评价单元为域名。
- DeepEmbed 主量：T25 子词/n-gram 的位置质量加权 OOV、域名级 OOV 覆盖和 `T17→T25` 词表保持；字符 OOV 单独作为下界对照。
- 泛化分面：已见/未见 DGA 家族、良性/DGA、短/长 eSLD、数字/连字符/字母构成；分面由数据定义，不能看结果后合并。
- 统计：在域名上对 eSLD 与 raw、ROSA 与固定阶 n-gram 的差量做配对 bootstrap 或置换，报告效应量和区间；它度量域名抽样不确定性，不是训练随机性。

### 11.4 裁决

- **ROSA 保留**：eSLD 主视图在 T25 有非平凡长于固定最低上下文的匹配，且相对同预算固定阶 n-gram 的后继预测效应区间为正；未见家族方向不反转。最低上下文长度必须在运行前按“超出对照 n-gram 阶数”定义，不从结果挑值。
- **ROSA 淘汰**：有效命中主要来自点/TLD/平台后缀、跨域拼接、单字符重复，或同预算 n-gram 完全解释；域名短导致多数位置无合法历史后继也直接止损。
- **DeepEmbed 保留**：T17 冻结的子词/n-gram 表在 T25 仍覆盖足够的 token 质量，且基线错误后续被证实集中于表内稀疏组合；字符表 OOV 为零但词表过小不能单独过门。
- **DeepEmbed 淘汰**：主信号只存在 raw 而在 eSLD 消失；T25 质量主要落入 OOV/碰撞；或普通冻结 embedding/哈希 n-gram 已具同等覆盖。
- 探针只裁决输入资格。两项都通过后，才按第七节的 C00/C10/C01/C11 运行单一预冻结种子四格；两项不必捆绑保留。

探针完成后先依据真实信号止损或保留，再决定是否实现训练四格；不在快速实验前增加一轮概念裁决。

## 十二、建议顺序

1. **先实现 DRIFT `T17→T25` 双探针，不先写联合算法。** 主视图固定 eSLD，raw 只作后缀捷径对照。
2. **按数据选机制，不按 RWKV 名称选。** CIC-YNU 若长重复后缀明显，保留 ROSA；DRIFT 或 CESNET 若主要是稀疏 token/OOV，保留 DeepEmbed；无信号即淘汰。
3. **第二机制优先跨来源解决不同病灶。** LSPR 偏低误报/域泛化，DRIFT 偏未见家族/开放集，CIC-YNU 偏跨架构对齐，CESNET 偏开放集拒识/校准。
4. **只对两个单机制均过门的组合运行单种子严格四格。** 四格同种子同数据顺序，以自然评价单元的配对重采样和跨分面一致性裁决；不以多种子训练阻塞候选。
5. **DeepEmbedAttention 暂不进入。** 仅在普通低秩注意力仍有明确错误余量、缓存成本可承受且能从 DE 中干净拆分后，作为外部对照补测。

最终推荐不是“采用 RWKV-8 三件套”，而是：**把 ROSA 和 DeepEmbed视为两个可独立移植、但必须由真实数据病灶竞争资格的候选；把 DEA 降为嵌套外部对照；允许且优先用一个经过病灶门的 RWKV 机制与一个解决第二独立病灶的非 RWKV 机制组成第三章 2×2。**
