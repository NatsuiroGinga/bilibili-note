### 4.3 公式保留门

1. 公式必须对应一个可观测变量、可训练路径、算法步骤、证明步骤或实验统计量。
2. 公式中的标签只能进入训练掩码或监督目标，不能进入输入、路由或推理状态。
3. 生成惊讶度在时刻 `t` 必须来自上一状态对当前窗口的预测，即由 `z_{t-1}` 预测 `x_t`；不得用 `z_t` 重构 `x_t` 后宣称在线异常分数。
4. A 的受序与有界性若不能在同一可行域同时成立，则删除相应理论主张，而不是保留公式数量。
5. B 的闭环收缩若无法由实现监控，则把结论收窄为有限时域递推上界，不宣称几何收敛。
6. 任何未进入实现或没有对应制品的候选公式从最终 34 式中移除，再以有真实责任的统计或边界公式补位；禁止拆式凑数。

## 5. 算法与证明责任

### 5.1 算法 3-1

**规划题目**：基于完成流因果窗口的生成式 RWKV 训练、校准与评价算法。

算法必须在一个连续流程中覆盖：

1. 读取冻结字段白名单、统计单位、时间分区、隔离带、状态重置和样本清单。
2. 只纳入在截止时刻前已经完成的流，按 `1/4/16/32` 步构造因果历史。
3. 实例化冻结提交的官方 RWKV-7 状态核和入选方案结构。
4. 用全部 `train-fit` 样本计算检测损失，只用连续未标红队关联历史与目标计算生成损失。
5. 按连续段递推状态，跨缺口、分区和独立事件强制重置；截断反向传播不能改变推理状态语义。
6. 记录生成头与命名机制的梯度、状态范数、门控或字段交互诊断。
7. 骨干冻结后只在校准区拟合分数组合和阈值；模型选择区、一次性开发验证区和最终封存区职责互斥。
8. 种子 42 只作筛错；通过后执行 42、43、44，输出逐窗口预测、逐事件结果和统计簇标识。

不得为了增加算法数量，把数据预处理、训练和统计检验拆成多个只有数行的算法。

## 8. 共同实验矩阵

### 8.1 所有模型共享的公平合同

1. 数据只使用 LSPR24 G0 后冻结的同一视图；窗口只纳入截止时刻前完成的流。
2. 主输入剔除 IP、主机名、网段、EXPO、端口、流标识、绝对时间、标签派生字段、Suricata 输出和攻击叙事。
3. 所有模型共享统计单位、`train-fit`、模型选择、一次性开发验证、校准、最终封存区、隔离带、样本清单、历史长度、归一化和调参次数。
4. 重叠窗口不是独立统计样本；统计单位为独立正事件与连续阴性时间块。
5. 所有神经模型先运行种子 42；只有预注册筛错门通过者再运行 43、44。
6. 最终测试只在字段、模型、阈值、方案和章节主张冻结后打开一次。

### 8.2 共同基线

| 类别 | 运行 | 责任 |
| --- | --- | --- |
| 树模型 | 当前窗 HGB、当前窗 XGBoost | 判断去身份后是否仍有当期静态信号 |
| 同历史树模型 | 滞后统计 HGB、滞后统计 XGBoost | 防止把“拥有历史”误归因为序列结构 |
| 序列神经基线 | GRU、TCN、因果 Transformer、TimesNet、Mamba | 覆盖循环、卷积、注意力、时序专用和线性状态空间强基线 |
| 普通 RWKV | `C0-P`：参数匹配普通 RWKV-7 | 共同结构基线与 G1 门禁 |
| 计算/状态对照 | `C0-C`：计算与状态预算匹配普通 RWKV-7 | 方案 A 必需；不能用 `C0-P` 同时声称控制全部资源 |
| 共同生成对照 | `C0-G`，即原 `A01/B01` | 普通 RWKV-7 加未标关联状态生成；只训练一次，A/B 共同引用 |
| B 的前端强基线 | 门控多层感知机或门控残差前端加同一 RWKV-7；纯字段 Transformer | 判断收益是否只是复杂前端或普通字段注意力 |

### 8.3 方案 A 主消融

| 编号 | 受序共享内容双状态 | 未标关联状态生成 | 责任 |

| `A00/C0-P` | 否 | 否 | 参数匹配普通 RWKV-7 |
| `A01/C0-G` | 否 | 是 | 共同生成机制的独立作用 |
| `A10` | 是 | 否 | 受序动态记忆的独立作用 |

| `B00/C0-P` | 无 | 无 | 否 | 普通 RWKV-7 |

| `B10-current` | 当前窗口 | 无 | 否 | 普通字段交互的独立作用 |

### 8.5 因果对照

| 对照 | 固定条件 | 检验问题 | 失败解释 |
| --- | --- | --- | --- |
| 时间块置换 | 标签、字段、窗口数、参数和训练预算不变，只在训练区按预注册块共同置换历史 | 收益是否来自真实时间顺序 | 置换后不下降，长历史因果主张不成立 |
| 周期清空状态 | 输入不变，按 `1/4/16/32` 或预注册周期清空递归状态 | 收益是否依赖持续状态 | 长周期与短周期等效，长记忆主张不成立 |
| 当前窗对照 | 只保留 `t` 时刻合法字段 | 历史本身是否增加信息 | 长历史不胜当前窗，停止结构创新 |
| 同历史树模型 | 使用相同截止时刻和历史预算的滞后统计 | 收益是否仅来自窗口展开 | 不胜树模型，不能声称递归状态独特价值 |
| 身份捷径探针 | 身份字段只在审计分栏使用，不进入主轨 | 去身份后信号是否退化、模型是否记忆角色 | 主轨退化则数据合同失败，不把身份字段放回模型 |
| 未来信息哨兵 | 对未来列、跨界状态和错误时间索引实施故障注入 | 因果实现是否真正拒绝未来信息 | 任一哨兵未拒绝，相关运行全部无效 |

### 8.6 历史长度矩阵

主历史集合固定为 `H={1,4,16,32}` 个 1 秒节拍，5 秒窗口只作敏感性分析。若 G0 表明 32 步覆盖不足，不得在看到模型结果后临时换主历史；应先判定原合同失败，再发布新版本合同。

| 历史 | 角色 | 必报比较 |
| ---: | --- | --- |
| 1 | 当前窗口近似与短历史基线 | 判断是否存在可用静态信号 |
| 4 | 短突发 | 对 1 步的增量、短事件召回和延迟 |
| 16 | 中程活动 | 对 4 步的增量、背景漂移和状态稳定性 |
| 32 | 主长历史候选 | 对 16 步的增量、最差事件组与效率扩展 |

每个历史长度必须共享相同截止时刻、数据分区、可见字段和事件定义；不得通过改变正负采样比例制造长度收益。

### 8.7 事件困难面板

所有分组阈值只用 `train-fit` 或 G0 开发可见区的分位数冻结，并把组成员哈希写入清单；不得根据模型误差事后定义困难组。

| 面板 | 预注册定义方向 | 主要指标 | 统计要求 |
| --- | --- | --- | --- |
| 长持续事件 | 按开发训练事件持续时间上分位数 | 固定误报预算下事件召回、首告警延迟 | 合格组至少 10 个独立正事件 |
| 低流量/低占比事件 | 按事件内已完成流数或正流占比下分位数 | 正类 AUPRC、事件召回 | 与高流量组同时报告 |
| 背景漂移/跨日 | 时间前向的后段或跨活动段 | 宏平均 F1、AUPRC、每小时误报 | 以连续时间块为簇 |
| 端点留出 | 整主机或整端点对不跨训练与评价 | AUPRC、事件召回 | 身份只用于分组，不进入模型 |
| 高缺失/稀疏窗口 | 按合法字段缺失率或窗口密度分位数 | AUPRC、校准、误报 | 明确 `ALL_MISSING` 数量 |
| 最差事件组 | `W=min_g Recall_g`，只纳入预注册且事件数合格的组 | `W` 与对两类主对照的差值 | 少于 10 个正事件的组只报告计数与区间，不并入硬门槛 |

## 9. 三种子统计矩阵

### 9.1 每个关键比较的固定输出

| 行 | 列 | 说明 |
| --- | --- | --- |
| 指标行 | 宏平均 F1、正类 AUPRC、最差事件组召回、每小时误报、Brier 分数、P95 延迟、吞吐、峰值显存 | 前四项用于检测/事件裁决，后三项解释校准与效率 |
| 对照列 | 普通 RWKV-7 `C0-P`、最佳参数匹配非 RWKV 序列基线；A 另列 `C0-C`，B 另列最佳前端强基线 | 两类主对照都必须通过，不能挑较弱者 |
| 种子列 | 42、43、44 | 报告原始分数和成对效应，不只报均值 |
| 汇总列 | 三种子等权均值、样本标准差、双侧 95% 区间、族校正单侧 95% 同时下界 | 不对三个种子使用正态检验、配对 t 检验、方差分析或 Wilcoxon 检验 |
| 审计列 | 完成状态、样本/事件数、配置哈希、数据哈希、失败原因、门槛布尔值 | 运行或制品不完整时状态为 `NOT_READY` |

### 9.2 统计程序

1. 使用两层配对自助法，规划重采样 10,000 次，分析种子固定为 `20260805`。
2. 第一层重采样训练种子，第二层在每个种子内配对重采样独立正事件与连续阴性时间块。
3. 共同基线、完整方法和消融共享同一批种子位置、样本与簇索引。
4. 主检测族、困难事件族和效率族分别控制多重比较；不得先看结果再选择困难面板。
5. 三个种子方向一致是硬条件；不补种子、不删除失败种子。
6. 宏平均 F1 或 AUPRC 的绝对增益超过 `0.10` 时先转入泄漏、重复、时间交叉、身份捷径和弱基线审计，不直接宣称突破。

## 10. 综合门槛

### 10.1 朱焱雷参照的正确用法

朱焱雷第三章相对各任务单元最强防御基线的宏平均 F1 提高约 **4.1～5.1 个百分点**。该范围来自不同任务、分层随机拆分和单次点估计，只作为“主效果、消融、困难条件与代价必须共同说明”的论证强度参照，**不是 LSPR24 的硬阈值**。

LSPR24 的主任务是类别不平衡的二元红队关联活动检测，采用流完成因果窗口、时间前向和事件隔离，还要求三种子与簇级同时置信区间。因此综合门槛以正类 AUPRC 为主，同时要求宏平均 F1、最差事件组和效率均不过界，不机械复制 4.1～5.1 个百分点。

### 10.2 分层裁决

| 门禁 | 规划门槛 | 失败后动作 |
| --- | --- | --- |
| **G0 数据门禁** | 核心 Parquet 与叙事大小/哈希通过；时间切点先于标签读取冻结；标签组合、泄漏、缺口、重复、统计单位、事件和 `1/4/16/32` 覆盖通过；分区无流、会话、历史或事件交叉 | 停止监督训练；不能用 UGR'16 失效合同或身份字段补救 |
| **G1 普通 RWKV-7 门禁** | 相对最佳参数匹配神经基线，宏平均 F1 或 AUPRC 至少 `+0.010`；或检测差不超过 `0.005` 且相对注意力基线吞吐至少 1.5 倍或峰值显存降低至少 25% | A/B 同时停止；效率通过只说明架构可继续筛选，不是第三章创新成立 |
| **G2 宏平均 F1** | 完整方法相对 `C0-P` 和最佳非 RWKV 序列基线的三种子等权均值均至少 `+0.010`；三个种子方向一致；事件簇配对的族校正单侧 95% 同时下界均大于 0；1 步简单面板退化不超过 `0.005` | 总体分类平衡收益不足，不能由 AUPRC 或效率抵消 |
| **G2 正类 AUPRC** | 相对上述两类对照均至少绝对 `+0.020` 且相对提高至少 5%；三个种子方向一致；族校正单侧 95% 同时下界均大于 0 | 不得声称改善不平衡正类检出质量 |
| **G2 最差事件组** | 在固定每小时误报预算或基线匹配误报预算下，所有合格预注册组相对两类对照均不得下降超过 `0.020`；`W` 点估计不低于两类对照；族校正单侧 95% 下界大于 `-0.020` | 任一合格组下降超过 2 个百分点即拒绝，不以高频组均值掩盖 |
| **G2 效率边界** | 检测三项先通过；相对 `C0-P` 吞吐不低于 0.80 倍、P95 延迟不高于 1.25 倍、峰值显存不高于 1.25 倍，状态内存对历史长度为常数阶；在 32 步上相对最佳注意力基线满足吞吐至少 1.5 倍或峰值显存降低至少 25% 之一 | 只有效率收益时降为工程观察，不作为检测方法创新 |

完整方案只有同时通过宏平均 F1、正类 AUPRC、最差事件组和效率边界，才可进入扩大验证。四项不得加权求和或互相补偿。强证据目标可记为宏平均 F1 至少 `+0.020`、AUPRC 至少 `+0.030`，但它只是目标，不得据此事后改阈值、事件分组或基线。
