## 架构与参数量

候选固定为四成员、隐藏宽度 186 的两层参数高效集成多层感知机。第一层为 `83→186`，第二层在成员内部执行 CPA 后接收拼接的 `372` 维输入并映射到 `186` 维。每层共享主权重，同时保留成员专属输入缩放、输出缩放和偏置；第一层输入缩放按随机符号初始化，后续缩放初始化为 1。四个成员使用独立 `186→1` 输出头，C11 仅保留一个共享 `p_log`。

精确参数量闭合如下：

- 第一层批量集成线性层：`83×186 + 4×83 + 4×186 + 4×186 = 17,258`。
- 第二层批量集成线性层：`372×186 + 4×372 + 4×186 + 4×186 = 72,168`。
- 四个独立输出头：`4×186 + 4 = 748`。
- 共享 `p_log`：`1`。
- 总计：`17,258 + 72,168 + 748 + 1 = 90,175`，相对 90,242 参数参照差 `-0.074%`，处于 `±1%` 预算内。

训练时每步抽取 64 条不同的训练序列并重排为 `16×4`，四个成员各接收不同序列，`share_training_batches=false`。CPA 只在每个成员内部沿时间轴计算。推理时把同一序列展开到四个成员，对四个 sigmoid 概率取算术平均，再执行实体最大值或共享 ELP，禁止平均 logits 或成员级 ELP。

## 数据与证据合同

- 数据只允许 `X23/y23/I23/M23/E23`，按 `E23` 建立实体不相交三折并映射到序列与逐流索引。
- 每折逐流正类权重和训练序列正类权重均复用共享工具的已修复逻辑，只由 `train_rows` 可达训练流、训练序列标签计算；单元收据记录训练序列数、训练有效流数和两个权重，并标记留出标签未参与权重计算。
- C00 关闭 CPA/ELP，C11 开启成员内 CPA 和单共享 ELP；种子 42，20 轮，每轮 1000 步，批量 64，学习率 0.002，权重衰减 0.01，梯度裁剪 1.0，辅助损失权重 1.0。
- 留出折逐流 AP 继续选择最早最优轮次，仅用于保持 E1 协议的源年筛选。该结果不是无选择偏差的独立折外估计。
- 同折比较冻结 XGBoost-C11。历史 XGBoost 启动器没有持久化五数组逐数组哈希，因此结果必须保留 `historical_xgb_per_array_hash_persisted=false`，不得声称历史 XGBoost 与当前五数组具有密码学同一性。现有证据限于冻结父配置/代码、精确折统计、模型与有效配置哈希、树数和恢复证明；当前五数组身份由多层感知机 E1 输入身份核验。
- 配置和各阶段收据固定 `target_year_arrays_read=0`，源年结果只允许写为 `source_qualified`、`source_rejected` 或运行无效，不是正式论文效果证据。
