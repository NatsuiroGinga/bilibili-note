# 2026-08-20 第三章候选骨干一站式总表

> **用途**：汇总第三章已注册骨干、已尝试扩展与 Hugging Face 外部发现。表中“实验支持”仅指已关联的本课题制品；论文、模型卡和通用排行榜均不替代 LSPR23 到 LSPR24 的冻结实验。

## 口径与边界

- 主指标为协议 A 的 LSPR24 实体平均精确率。XGBoost 采用自身 `max` 聚合的 `0.512899`，不得用借用 Lp 的敏感性读数替代。
- 新骨干不得只比较 XGBoost 的实体 AP。每个候选必须同时报告逐流 AP、实体 AP、`0.1%/0.5%/1%/2%/4%/8%` 六档告警预算曲线和资源开销；必须在同一数据域、同一折分、同一输入与同一训练预算内比较。
- LSPR23 源年实体折外资格结果与 LSPR23 训练至 LSPR24 评价的跨年度结果必须分表、分别裁决，不得混合排名或用源年 AP 声称跨年度胜出。
- 已注册的跨骨干协议 A 参数量卡以普通 MLP `90,242` 为参照；四骨干的实现核验已通过。
- `target_year_arrays_read=0` 仅适用于 ResMLP2 的源年折外运行，不可外推到其他骨干。
- TabPFN、Mamba、TimesFM 是本轮 Hugging Face 只读发现，均未登记为 LSPR23 实验；不存在直接匹配本课题的 Hugging Face 官方排行榜。
