## 一、被量化的问题

形式化第 3.3 节的实体门含指示函数：

```
γ_θ(s_{e,t}) = σ(w_2^⊤ · ReLU(W_1 s_{e,t} + b_1) + b_2) · 𝟙[c_{e,t} ≥ 1]
```

`𝟙[c ≥ 1]` 使**实体首片段的门恒为零**。由零门退化命题（形式化第 4.3 节），门为零时
M-E 的输出与不含 M-E 的基线**逐位相等**。因此该指示函数直接决定 M-E 的作用域：
**门不激活的样本，其分数恒等于 C00。**

形式化只记了「`c` 的中位数为 `0`，超过一半的序列是其实体首序列」，未量化这对
**实体级主指标**意味着什么。本文件补上该量化。第三章主指标是实体 AP，
而作用域的实体侧分布与片段侧分布差异极大，不能互相替代。

## 三、实测结果

### 3.1 全源区

| 量 | 值 |
| --- | --- |
| 实体数 / 片段数 | `150680` / `271815` |
| 门激活片段数 | `121135`（`44.57%`） |
| 门恒零片段数 | `150680`（`55.43%`） |
| **门激活片段覆盖的流份额** | **`93.47%`** |
| 有任一激活片段的实体 | `3345`（`2.22%`） |
| **恶意实体中可被门影响的** | **`117 / 239`（`48.95%`）** |
| 良性实体中可被门影响的 | `3228 / 150441`（`2.15%`） |
| **恶意富集比** | **`22.82` 倍** |

片段侧与实体侧的巨大差异是本节的核心：门激活片段只占 `44.57%`，却覆盖 `93.47%` 的流；
而按实体计，只有 `2.22%` 的实体有任何激活片段。**用片段份额或流份额描述 M-E 的作用域
会严重高估它对实体级指标的影响面。**

### 3.2 按切分分层

| 量 | 训练集 | **验证集** |
| --- | ---: | ---: |
| 序列数 | `208598` | `22444` |
| 实体数 | `121501` | `13529` |
| 恶意实体数 | `165` | **`20`** |
| 门激活序列份额 | `41.75%` | `39.72%` |
| **恶意实体中门可达的** | `80`（`48.48%`） | **`13`（`65.00%`）** |
| 良性实体中门可达的 | `2688`（`2.22%`） | `350`（`2.59%`） |

验证集正实体的门可达比例（`65.00%`）显著高于训练集（`48.48%`）与全局（`48.95%`）。
这是随机按实体划分在 `20` 个正实体上的抽样波动，**不是设计优势，正文不得据此宣称任何倾向**。

### 3.3 门输入的实体级判别力上界

门 `γ_θ(s)` 只依赖 `s = [log(1+c), log(1+Δ)]`。因此「直接把 `c` 或 `Δ` 当分数」
所得的实体 AP，就是**门这条路径能提供的实体级信息的上界**。按与 C00 相同的实体聚合口径
（`maximum_over_validation_flows`）在源年验证集上实测：

| 分数 | 验证集实体 AP | 相对 C00 |
| --- | ---: | ---: |
| `c`（前置片段数） | `0.043332` | `6.3%` |
| `log(1+c)` | `0.043332` | `6.3%` |
| `𝟙[c ≥ 1]`（门指示） | `0.023796` | `3.5%` |
| `Δ`（距上一片段间隔） | `0.023557` | `3.4%` |
| 随机基线（正实体率） | `0.001478` | `0.2%` |
| **C00 实测** | **`0.684392`** | — |

`log(1+c)` 与 `c` 的 AP 逐位相同（`0.04333245521122439`），因为 AP 对单调变换不变——
这是脚本的内部一致性校验。

**判读**：门输入的判别力上界为 C00 的 `6.3%`。它显著高于随机基线（`29` 倍），
说明实体历史确实携带信息；但远不足以解释 C00 的水平，因此「M-E 的增益其实只是门
充当了判别特征」这一替代解释的**上限很低**。该风险由此从推测降为可量化的小量，
但**不等于零**，仍需第 5 节的消融来分离。

## 四、对四格判据的约束

### 4.1 增益空间的上界

源年验证集实体 AP 由 `20` 个正实体与 `13509` 个负实体的排序决定。M-E 能改变分数的是：

- 正实体 **`13` 个**，其余 **`7` 个（`35%`）分数恒等于 C00**
- 负实体 `350` 个，其余 `13159` 个（`97.4%`）分数恒等于 C00

**M-E 在源年的全部增益空间就是这 `13` 个正实体与 `350` 个负实体的重排。** 该上界是
机制定义与数据结构共同决定的，与实现质量、超参数或训练轮数无关，也无法通过调参扩大。

### 4.2 统计分辨力风险

四格判据要求源年 `C10 > C00`。在只有 `13` 个可动正实体的验证集上，单个正实体的排序
变动即可显著改变实体 AP。该风险与恢复卡第八条记载的「源年验证仅 `20` 个正实体，
任何方法都无法解决」同源，但 M-E 的情形更窄：BER 作用于损失，影响全部实体的排序；
M-E 作用于表示且只在门激活样本上生效，作用面小一个量级。

**这不构成否决**：判据本身未变，且 BER 在同一验证集上已通过目标年正增益门。
但它要求本机制的源年结论必须附带可动实体计数，**不得以「实体 AP 提升」这一笼统表述
掩盖增益仅来自 `13` 个正实体的事实**。

### 4.3 由本节实测产生的预注册断言

以下断言在 M-E 实现完成后、源年正式实验前机械执行，结果写入运行收据：

1. **零门退化的实现断言，只在同一组权重内成立**：对同一个 M-E 模型实例，
   把 `γ` 强制置零后的前向输出，必须与该实例移除位移通道的输出**逐位相同**。
   同一实例上，门永不激活样本的输出必须等于该实例移除位移通道后的输出。
2. **可动实体计数收据**：正式运行须落盘源年验证集的
   `malicious_entities_gate_reachable = 13` 与 `benign_entities_gate_reachable = 350`，
   与本文件的数字一致，防止实现引入意外的门激活路径。
3. **梯度可达性**：位移通道 `u^{(j)}_t` 与门参数 `θ` 只应从门激活样本接收梯度；
   在全部样本门为零的构造批次上，二者梯度范数须为零。
4. **逐轮逐流 AP 差值监控**：逐轮记录 C10 与 C00 的源年逐流 AP 差值，持续为负即触发复核，
   实体 AP 上升不予豁免。依据是 CEM 失败诊断第 2.5 节——CEM 在源年 20 轮逐流 AP
   无一轮高于 C00，选中轮只差 `−0.00035` 被 `0.999` 饱和掩盖，跨年后放大为 `−0.1318`。
5. **增益分面归属检查**：若 M-E 取得增益，须核验增益是否集中在多片段实体分面；
   若主要出现在单片段实体（门永不激活），则该增益来自共享骨干的间接效应，
   不是所称的实体门控机制，正文措辞必须相应弱化。

### 4.4 一条已更正的错误断言

本文件首版（提交 `324b492`）曾把断言 1 写成跨模型形式：「源年验证集中那 `7` 个门永不
激活的恶意实体，其 M-E 模型输出分数必须与 C00 **逐位相同**」。**该断言错误，已删除。**

错因：C10 与 C00 是两次**独立训练**，骨干权重不同。零门只切断加性位移项，
**不隔离共享骨干权重被门激活样本改写的间接影响**。训练结束后，C10 在门永不激活样本上的
输出与 C00 并不相等，该差异恰恰是 CEM 从第 1 轮起损害逐流 AP 的传播通道。
若按原断言执行，正式运行会因一个必然失败的检查而中断。

零门退化命题（形式化第 4.3 节）本身没错，它是**架构级**命题，只在同一组权重内成立；
错的是把它当作跨模型的数据侧断言。上述第 1 条已改为同权重形式，第 4、5 条替代了
原断言想要覆盖的间接影响检查。该更正由独立复核发现。

## 五、风险与边界

- **门本身可能是判别信号，但上限已实测且不高**。`c ≥ 1` 在恶意与良性实体上的分布差异达
  `22.82` 倍（`48.95%` 对 `2.15%`），然而第 3.3 节实测其实体级判别力上界只有 C00 的 `6.3%`。
  该替代解释因此不能单独支撑一次显著增益，但仍须由消融分离，不得靠本节数字免除。
- **跨年稳定性未知且不可预先检验**。上述富集比是源年事实；目标年封印，不得读取。
  CEM 的失败正来自源年与目标年的历史密度差异（目标年每链跨段恢复为源年的 `4.95` 倍）。
  M-E 必须在设计上不依赖该先验的跨年稳定，或在正文如实登记这一适用边界。
- 本文件全部为数据刻画，**不含任何关于 M-E 有效性的主张**，也不构成对 M-E 的支持或否决。
  机制的存废只由源年四格与封印后目标年结果裁决。
- 两个诊断脚本是一次性制品，置于会话临时目录，随任务清理；本文件的数字由上述
  三重自校验保证可重算，不依赖脚本留存。
