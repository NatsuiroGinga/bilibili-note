## 一、源码确认的数学形式

以下均为**源码事实**，文件缩写：LOSS = `tools/ch3_ft_entity_ranking_loss.py`，
HOST = `tools/ch3_ft_c00_dual_selection.py`（工作树 `.worktrees/ch4-dtep-pbc-20260819/thesis/experiments/llm_probe/`）。

每步抽 Np=2 个正实体（**不放回轮转**，采样器 173–202 行）、Nn=64 个负实体
（从 N_pop=121,336 均匀不放回）。成对损失 L_pn = softplus(S_n − S_p)（LOSS 158）。
六档整数预算 K ∈ {121, 606, 1213, 2426, 4853, 9706} 经 `effective_budget`
折算 K_eff = K·Nn/N_pop（LOSS 187–203，**浮点返回，不取整**），宿主直接传入浮点值
（HOST 1629–1631）。

**损失（LOSS 161–174）**：

```
r_{p,K} = ξ_{p,K} + (1/K_eff) · Σ_{n=1..Nn} [L_pn − ξ_{p,K}]_+
L_rank  = (1/6) Σ_K (1/Np) Σ_p r_{p,K}
```

关于 `k` 非整数的第一问的直接回答：**k 只作除数**（LOSS 168 `hinge.sum(dim=1) / float(k)`），
训练路径没有 topk、没有取整。`_quantile_init_xi`（LOSS 482–488）确实用 `topk` 取第 K 大值，
但它只被诊断脚本 `main()`（LOSS 610）调用，docstring 自述「仅用于本诊断脚本做单步梯度比较」，
**训练期 ξ 与它无关**。另一处源码矛盾：LOSS 138 docstring 写「K 须满足 1<=K<=Nn」，
而 LOSS 165 的 require 是 `0 < k <= n_neg`——实现放行了 K_eff < 1 的档位，未按文档约束拦截。

**ξ 更新（HOST 1632–1650）**：ξ 是叶张量，`loss_rank.backward()` 后执行
`ξ ← ξ − η_ξ · ξ.grad`，η_ξ = 1e-4（冻结配置 `xi_learning_rate`），即**单步裸 SGD 子梯度**。
初值 0（`CvarThresholdState` 默认，LOSS 216）。每个正实体只在被抽中的步更新自己那一行；
ξ 表实测形状 (165, 6)（**实测**：`runs/diagnostics/ch3-ft-c01-entity-ranking-cuda-formal-v1/checkpoints/inflight.pt`）。

由损失结构得（**数学推导**，relu 在 0 处子梯度取 0，LOSS 167 注释）：

```
∂L_rank/∂ξ_{p,K} = (1/(6·Np)) · (1 − m_{p,K}/K_eff)，  m_{p,K} = #{n : L_pn > ξ_{p,K}}
```

**与 Zhu 2022 SOPA 的逐项对照**（**文献**：原件物理第 5 页算法 1；
`raw/papers/methodology/ft-mechanisms/2022-Zhu-pAUC-DRO-ICML.pdf`）：

| 项 | SOPA（原文） | 本实现 | 判定 |
| --- | --- | --- | --- |
| 活动指示 | p_ij = I(L − sᵢ > 0)（步 4） | pairwise > ξ（严格） | 同 |
| 阈值更新 | sᵢ ← sᵢ − (η₂/n₊)(1 − Σp_ij/(β\|B₋\|))（步 5） | ξ ← ξ − (η_ξ/(6Np))(1 − m/K_eff)；β\|B₋\| = K_eff | **同构**（多预算版） |
| 模型梯度 | (1/(β\|B₊\|\|B₋\|))ΣΣ p_ij ∇L（步 6） | (1/(6·Np·K_eff))Σ_active ∇L_pn（每档） | 同构 |
| 阈值初值 | s¹ = 0（步 1） | init_value = 0 | 同 |
| 整数假设 | p.3 式(6) 要求 nγ 整数；p.4 式(7) 下方假设 n₋β 为正整数 | 总体 K 整数满足；**批内 β\|B₋\|=K_eff 三档 <1，论文未讨论该区间** | 差异 1 |
| 训练协议 | CE 预训练→重置分类头→pAUC 微调（物理 p.8，wiki 笔记核验） | 与逐流 CE **联合训练**（梯度控制器合成） | 差异 2 |
| 阈值步长 | η₂ 独立超参数 | η_ξ 绑定模型 lr=1e-4，且经损失均值结构再除 12 | 差异 3 |

结论：本实现是 SOPA 的忠实多预算逐字面版本；失效不来自「实现错公式」，
而来自把公式搬进了论文假设之外的运行区间（差异 1–3）。

## 二、问题 1：K_eff < 1 时损失的数学行为

**(1) 解析层面无退化**（数学推导）。对任意 K_eff > 0，r_{p,K} 良定义、关于 (θ, ξ)
几乎处处可微；固定 ξ 时估计量无偏：对均匀抽样 S，
E[(1/K_eff)Σ_{n∈S}(L_n−ξ)_+] = (Nn/K_eff)·E[(L−ξ)_+] = (1/β)·E[(L−ξ)_+]，β = K/N_pop。
`effective_budget` docstring（LOSS 192–197）的推导正确。K_eff < 1 **不产生除零、
不产生恒零梯度、不使损失退化为常数**。

**(2) 统计层面是稀有事件估计**（数学推导）。θ 只从活动对（L_pn > ξ）获得梯度，
每个活动对权重 1/(6·Np·K_eff)。在驻点（见问题 2）单对活动概率 = β，
单步活动对数期望 = Np·Nn·β。K=121 档：128×0.000997 ≈ **0.128**——
约 88% 的步该档贡献恰好为零的 θ 梯度，其余步贡献一个被 1/K_eff ≈ 15.67 放大的脉冲。
无偏但方差按 1/β 放大。这与 Zhu 定理 3（**文献**：物理第 6 页）的迭代复杂度
T = O(1/(βε⁴)) 一致：β 进入分母，小 β 本身就要求成比例多的迭代，即使在原论文的
两阶段、平稳分布设定下也是如此。

**(3) 若取整或 topk 会发生什么**（数学推导，回答任务的分支问）。
`ceil(K_eff)=1` 的 top-1 版本把内层最优 ξ 推到批最大值，等价把目标分位数从总体
(1−β)（K=121 档为 99.9%）偏移到批 (1−1/Nn) ≈ 98.4%，且三个低档全部塌缩到同一目标，
档位区分度消失；`floor` 得 0 非法。当前实现不取整，避免了这类偏差，代价即 (2) 的方差。

**小结**：K_eff < 1 的损失**有良定义的无偏梯度**，但它是一个「稀有脉冲估计量」，
批内一般看不到一个尾样本；这是统计分辨率问题，不是解析退化。真正把该档彻底杀死的
是问题 2 的 ξ 动力学。

## 三、问题 2：ξ 动力学、驻点条件与「棘轮」判定

**驻点条件**（数学推导）。随机递推
ξ_{t+1} = ξ_t − (η_ξ/(6Np))(1 − m_t/K_eff)，m_t ≈ Binomial(Nn, P(L>ξ_t))。

```
E[Δξ] = −(η_ξ/12)·(1 − P(L>ξ)/β)   ⇒   驻点：P(L_pn > ξ*) = β
```

即 ξ* = 该正实体成对损失**总体分布**的 (1−β) 分位数。分布平稳时这是标准分位数 SGD
（与 SOPA 的 s 更新同构），以恒定步长在 ξ* 邻域振荡收敛；驻点处步长标准差
≈ (η_ξ/12)/√K_eff（二项方差），K=121 档约 3.3e-5，本身不是问题。

**收敛与漂移的分界**（数学推导）：
- 分布平稳 ⇒ 收敛到 ξ* 邻域（任意 K_eff > 0 都成立）。
- 分布**下移**（联合训练中模型分开正负 ⇒ L_pn 坍缩）⇒ ξ 的追踪速度有硬上界：
  子梯度在 ξ > sup L 区域恒为 +1、**不携带距离信息**，每次被抽最多下行
  η_ξ/(6Np) = 1e-4/12 = **8.333e-6**；而上行单步可达 (Nn/K_eff − 1)·η_ξ/12
  （K=121 档 64 对全活动时 ≈ 8.35e-3，为下行步的 1003 倍）。
  当分布下移速度超过下行上界 × 被抽频率，ξ 必然滞后并冻结在历史分位数上。

**「单向棘轮」判定：字面为伪，实效为真。**
- 字面伪：m=0 的每次被抽必然下行 8.333e-6（严格大于零）；**实测**佐证是
  inflight.pt ξ 表 col4/col5 的最小值为负（−1.51e-6 / −6.59e-6）——只有反复下行
  越过 0 才会出现，高档 ξ 在近零分位数附近是活着的、双向振荡的。
- 实效真：下行速度硬上界 + 上行不对称放大（K=121 档单活动对上行/下行 =
  1/K_eff − 1 = **14.669**）+ 分布坍缩（**实测**：排序损失 epoch1→20 为
  2.578→0.005191，约 500 倍），三者合起来构成实际的棘轮效应。

**实测数字逐项核验**（本地制品见 `notes.md`）：

| 转述数字 | 独立核验 | 判定 |
| --- | --- | --- |
| 每次下行 8.33e-6 | = 1e-4/(6×2) = 8.333e-6 | 一致（推导） |
| 上行/下行 14.7 倍 | = 1/K_eff − 1 = 14.669（K=121） | 一致（推导） |
| 单实体被抽 242.4 次 | = 2×20000/165 = 242.42；轮转采样使各实体几乎精确相等（源码事实） | 一致 |
| 最大下行位移 2.02e-3 | = 242.42 × 8.333e-6 = 2.020e-3 | 一致（推导） |
| 「只有 ξ 自身的 7.7%」 | 2.020e-3/中位数 0.02618 = 7.72%；若对 col0 **最小值** 0.01599 则为 12.6% | **口径修正**：7.7% 对应中位数，不是与其并置的最小值 |
| ξ 最小值 0.0159936（K=121 档） | inflight.pt 实测 0.01599362 | 一致（实测） |
| 「是第 20 轮样本对损失上界 1.57e-3 的 10.2 倍」 | 算术成立（10.19），但 1.57e-3 在本地收据与 launch.log 均无来源（宿主诊断不落 pairwise 字段，HOST 1651–1667） | **转述，本地不可复核**；且见下条方法论修正 |

**对「阈值脱靶」论证的修正**（本报告的主要新增判断）：

1. 用「批内损失上界」当标尺**在最低档不成立**（数学推导）。K=121 档驻点
   ξ* 是总体 99.9% 分位数；64 个均匀样本的批最大值只估计约 98.4% 分位数。
   驻点处本就有 ~88% 的步全批无活动对，「ξ 高于批内一切损失」是驻点的**常态**，
   不是脱靶的证明。低三档的「激活率≈0」与「ξ 正确处于驻点」在现有诊断下不可区分——
   诊断分辨率 1/128 = 0.0078 > β = 0.000997，且 receipts 的 `per_budget_active_rate`
   来自 `last_step_snapshot`（单步快照，非轮均值；源码事实 HOST 1651–1667，
   实测 epoch10 的 0.0078125 恰是最小非零刻度）。
2. 脱靶结论本身仍成立，但正确证据在**高档**（实测 + 推导）：K=9706 档 K_eff=5.12，
   驻点激活率应为 β=8%（期望 10.24 对/步）；epoch 15/17/20 三个快照实测 6、3、3 对，
   累计 12 对 vs 期望 30.7 对（≈3.4σ 低）。K=4853 档同向（4 对 vs 期望 5.12）。
   高档 ξ 系统性高于当前分位数 ⇒ ξ 整体滞后于坍缩分布；结合下行速度上界推导
   （从 col0 中位数 0.0262 降到 1e-3 量级需 ≈3000 次被抽 ≈ 24.7 万步 ≈ 12 倍全程训练），
   低档失配是必然**推论**（直接证明需离线对大负样本池打分测总体分位数，见开放问题 1）。
3. 附带一个被忽视的不对称：θ 用 AdamW（自适应步长），ξ 用裸 SGD 且实际步长再被
   损失均值结构除以 12——即使名义 lr 相同，两个时间尺度也不同（源码事实 + 推论）。

## 四、问题 3：三种候选修法的理论比较

### (a) 增大 n_neg（64→256 或 →1003），使 K_eff ≥ 1

- **对问题 1**：部分解决。驻点单步活动对期望从 0.128 提到 0.51（n=256）或 2.0（n=1003），
  θ 梯度从稀有脉冲变为常规信号；批最大值覆盖的分位数从 98.4% 提到 99.6%/99.9%，
  n_neg=1003 恰好把最低档推到可分辨边界。
- **对问题 2**：**不解决**。ξ 更新规则不变，下行速度上界 η_ξ/12 与 n_neg 无关。
  决定性反证是**实测**：K=4853/9706 档的 K_eff 已是 2.56/5.12（≥1），照样失配
  （epoch20 激活率 3.1%/2.3% vs 驻点 4%/8%）。K_eff ≥ 1 不是失配的充分预防。
- **新问题与代价**：排序批前向成本与负实体数成正比。66 实体（含截断至 8192 流/实体）
  已实测 6403 序列、30.97 GiB 激活、靠梯度检查点才能跑（源码事实：HOST
  `_entity_ranking_bare_forward` docstring 的 2026-08-29 OOM 记录）；1005 实体约 15.7 倍
  计算量，单卡不现实（推论：待实测，量级明确）。n_pos/n_neg 是冻结科学合同字段，
  改动需重新登记依据并重跑。

### (b) 保持 n_neg，改预算网格或折算方式

- 去掉 K_eff < 1 的低档：回避了问题 1 的稀有事件，但**实测已证明高档同样失配**，
  问题 2 原封不动；且 0.1%–1% 标称 FPR 正是「预算感知」机制的部署价值与冻结告警
  合同锚点所在（配置 `budgets_evidence`），删档等于缩小机制的科学主张。
- 改折算（如 ceil 到 ≥1）：见问题 1(3)——目标分位数偏移、三低档塌缩同一目标，
  是把方差换成方向不可控的偏差。
- budgets 同为冻结字段（LSPR23 投影证据链），修改需重新登记。
- **判定：治标不治本，且科学代价最大。**

### (c) 保持网格与采样，改 ξ 更新规则

先排除一个陷阱：**把 `_quantile_init_xi` 直接搬进训练是错的**（数学推导）。
每步令 ξ = 批内第 ⌈K_eff⌉ 大值，在 K_eff<1 时 ⌈K_eff⌉=1 ⇒ ξ = 批最大值 ⇒
所有 hinge = 0（relu 在 0 子梯度为 0）⇒ 该档 θ 梯度**恒等于零**——比现状更彻底地杀死机制。
该函数 docstring 也自述仅用于诊断（LOSS 484–485）。

正确形态：**把 ξ 从「子梯度 SGD 状态」改为「分位数估计量」**。为每 (正实体, 档)
维护跨步的成对损失水库（或流式分位数估计，如 EMA/P² 类），该实体每次被抽时用当步
64 个 L_pn 刷新，ξ 直接取当前 (1−β) 分位数估计并 **detach**（不再对 ξ 反传）。
理论依据：Rockafellar–Uryasev 变分形式下 CVaR 的内层 min 恰在真分位数处取得
（Zhu 定理 1 的 sᵢ 即该阈值，**文献** p.4），把 ξ 钉在分位数一致估计上不改变目标函数值，
只消除内层 min 的追踪滞后；θ 梯度形式不变，仍是 (1/K_eff)Σ_active ∂L/∂θ。

- **对问题 2**：解决。ξ 成为一致估计量，追踪速度由数据刷新决定，不再受 8.333e-6/次
  的硬上界束缚，也不再有 14.7 倍不对称。
- **对问题 1**：部分解决。低档单批仍看不到尾样本，但水库把有效样本扩到 B×64
  （B = 水库覆盖的被抽次数），B=16 即 1024 对，99.9% 分位数达到勉强可估的边界；
  代价是估计滞后 B 次被抽（≈ B×82.5 步）与新鲜度偏差（水库混有旧模型的损失）。
  这是**可调的估计偏差**，不再是结构性死锁。
- 顺带排除另一变体：保留子梯度但调大 η_ξ（两时间尺度）。**在 K=121 档不可行**
  （数学推导）：要在实测 242 次被抽内完成 0.0262→0.001 的迁移需每次下行
  ≥ 1.04e-4，即 η_ξ ≥ 1.25e-3；而驻点处单活动对上行步 = 14.669×1.04e-4 ≈ 1.53e-3，
  已超过目标分位数量级（~1e-3），64 对全活动时上冲 0.104——追踪速度与驻点稳定性
  对常数步长**相互矛盾**，β 越小矛盾越尖锐。
- **新问题与代价**：宿主 `require(xi.grad is not None)`（HOST 1648）需同步改；
  新增水库长度 B 一个超参数（须按魔法数字门禁登记依据）；内存 165×6×B 可忽略。
  关键优势：`xi_learning_rate` 的登记证据本来就写明「若观察到 xi 轨迹不稳定需要
  另行调整」（源码事实：配置 `xi_learning_rate_evidence`）——ξ 更新规则是机制二
  全部超参数中**唯一预留了调整余地、不在冻结证据链上的部件**；budgets、n_neg、
  bag_policy 的冻结依据全部不动。

## 五、问题 4：推荐修法

**推荐：以 (c) 的估计量化形态为主修，分两级推进；(a)(b) 按原样均否决。**

1. **c1（首选，最小改动）**：六档全部改用「跨步水库分位数 + detach」的 ξ。
   不触碰 budgets/n_neg/bag_policy 冻结证据链，只改训练私有状态的更新规则与
   HOST 1648 一处断言。**可证伪验收判据**：修复后每档激活率的轮内累计均值应回到
   β 的置信带（同时把诊断从单步快照改为轮内累计，否则最低档 0.001 与 0 仍不可分辨）。
2. **c2（若 c1 后低三档激活率仍不可用）**：加负实体难例/重要性采样——用周期刷新的
   负实体分数缓存，按提议分布 q 偏向高分负实体抽样，估计量乘 w = p/q 保持无偏。
   这是稀有事件估计的标准解，同时改善 θ 梯度方差与 ξ 水库的尾部样本供给；
   代价是触碰采样合同、需维护分数缓存（中等工程量）。
3. **对照臂建议（需用户裁决，因为动机制故事）**：按 Zhu 原协议做两阶段
   （先 CE 收敛、ξ 冻结或排序零权重，再开启排序相位）。它从根上消除非平稳性——
   本实现失效的三个偏离中最深的一个正是「联合训练把分布坍缩 500 倍」；
   但两阶段改变了「联合训练」的机制叙事，属于机制设计变更而非缺陷修复。

否决理由回指：(a) 被 K_eff=5.12 档同样失配的实测直接反证、且计算不可行；
(b) 删掉的恰是机制的科学主张、且同样不治 ξ 滞后。

## 六、问题 5：预算网格本身是否合理

- 作为**评价网格**合理：六档标称 FPR 是冻结告警合同锚点（配置 `budgets_evidence`，
  含 4% 档的同源经验区域），投影到 LSPR23 训练负实体池的做法避免了目标年读取。
- 作为**单批训练估计目标**，低三档在 Nn=64 下**原理上不可分辨**（数学推导）：
  单批尾样本期望 = K_eff = 0.064/0.32/0.64 < 1；均匀 i.i.d. 抽样估计 (1−β) 分位数
  需要 n ≳ 1/β 个样本（分别为 ~1000/200/100 > 64）。这是估计理论边界，不是实现缺陷；
  任何只改折算公式的做法都等价于偷换目标分位数，绕不过去。
- 正确做法按侵入性排序：
  1. **跨步汇聚**（水库/流式分位数）：把单批估计改为跨批估计——即修法 c1，适合 ξ；
  2. **重要性采样/难例采样**：改抽样分布聚焦尾部 + 权重校正——即 c2，
     同时服务 ξ 与 θ 梯度，是稀有事件模拟的标准答案；
  3. **按分数分层采样**是 2 的配额化特例，同样有效。注意现有
     `stratified_weighting` 按 **log2 链长** 分桶（LOSS 279–287），与分数尾部无关，
     解决不了本问题（源码事实）；
  4. **训练/评价网格解耦**：训练只用 β·Nn ≥ 1 的档，评价仍报六档，依赖档间
     相关性（推论，待验证）——诚实但放弃对低档的直接优化，属于退守方案。

## 七、被推翻或修正的既有判断

1. **「单向棘轮」字面表述被推翻**：存在恒定下行（8.333e-6/次），col4/col5 ξ 最小值
   为负是直接实测证据；正确表述是「下行速度硬上界 + 上行不对称放大 + 分布坍缩」
   的实效棘轮。
2. **「ξ 是批内损失上界 10.2 倍 ⇒ 脱靶」的论证方法被修正**：批最大值只覆盖
   ~98.4% 分位数，不能当 99.9% 分位数目标的标尺；低档「激活率 0」与「正确驻点」
   在现有单步快照诊断下不可区分。脱靶结论保留，但改由高档激活率系统性低于 β
   （3.4σ）加下行速度上界推导支撑；低档为推论、待实验直证。
3. **「7.7%」口径修正**：对应 ξ 中位数 0.02618，不是与其并置的最小值 0.01599
   （对最小值是 12.6%）。
4. **「1.57e-3 批内损失上界」标为不可复核转述**：宿主诊断不落 pairwise 字段
   （HOST 1651–1667），本地收据与 launch.log 均无此值。
5. 其余转述数字（8.33e-6、14.7、242.4、2.02e-3、165×6、0.0159936）全部独立核验一致。
6. **新增源码缺陷登记**：LOSS 138 docstring 与 LOSS 165 require 对 K 下界不一致
   （文档要求 ≥1，实现放行 >0），这是 K_eff<1 静默进入训练的直接闸口。

## 八、无法从源码与推导确定、需实验裁决的开放问题

1. **低档 ξ 是否真高于总体分位数**：用 epoch20 检查点对负实体池（≥1e5 或全池
   121,336）no-grad 打分，算每正实体成对损失的经验 99.9%/99.5%/99% 分位数与 ξ 表
   对比——把第七节第 2 条的推论变成实测，也是对 c1 修复量的直接标定。
2. **水库长度 B 的选择**：需要实测各档分位数随训练的漂移速度，才能在
   「估计方差（B 小）vs 新鲜度偏差（B 大）」之间登记 B 的依据（魔法数字门禁）。
3. **稀疏脉冲 g_rank 与梯度控制器的相互作用**：epoch20 实测 c_scaling 中位 0.381、
   投影触发 27.6%（receipts）；c1 修复后低档脉冲重新出现时控制器的缩放/投影行为未知。
4. **8% 档激活率低于 β 的定量归因**：ξ 滞后与损失分布形状变化各占多少，
   需逐步激活率轮均值（而非单步快照）与分位数曲线共同判定。
5. **联合 vs 两阶段**（Zhu 协议）的机制对照实验：本分析指出非平稳性是 ξ 滞后的
   放大器，但只有对照臂能量化「两阶段能否单独救活低档」。
