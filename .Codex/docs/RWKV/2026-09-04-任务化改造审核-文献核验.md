### (b) `f(x) ∈ [0,1]` 是不是真前提 —— **是，且三处承重**

不是某个推论或例子的设定。它在证明里承重三次：

1. **可行域的合法性**。Eq.(96)–(101)（行 `1428`–`1458`）：方差分解给出 `a* = E[f(x)]`，
   `b* = E[f(x')|f(x')≥η_β]`，并明确「where `a* ∈ [0,1]`」（行 `1437`）、
   「where `b* ∈ [0,1]`」（行 `1449`）；配方得 `γ* = b* − a*`（行 `1458`、`1461`），
   于是才能「constraint `γ` with range `[−1,1]`」。**`f` 无界则这三个箱约束全部失效。**
2. **Prop. 1 的单调性**（行 `1485`–`1493`）：`∂ℓ_-/∂f(x') = 2(f(x') − b + 1 + γ)`，
   原文「Assuming that `f(x') ∈ [0,1]`, then the feasible solution of `b` is nonnegative.
   When `γ ∈ [b−1,1]`, … `≥ 0`」。Remark 14（行 `1495`）随即说明这才使
   「top-ranked losses are equivalent to the losses of top-ranked instances」。
   **没有单调性，「对损失取阈值」≠「对分数取 top-k」。**
3. **`Ω_{s'} = [0,5]` 的来源**（见 Q3）。

### (c) 平方损失是必需还是一个实例 —— **就该定理的陈述与证明而言是必需；另有一条无证明的推广 Remark**

- Eq.(6)（行 `147`）确实用一般 `ℓ` 写出，但行 `150` 立刻特化：
  「In this work, **to simplify the subsequent reformulation**, we will use the most popular
  surrogate squared loss `ℓ(x) = (1 − x)²`.」
- 证明**就是平方的展开**：行 `1419`「Applying the surrogate loss `(1−x)²` to the estimator of OPAUC」，
  Eq.(95) 把 `E[(1−(f(x)−f(x')))²]` 展成两个边缘分布的一、二阶矩；
  全局变量 `(a,b,γ)` 分别来自方差分解 Eq.(96) 与配方恒等式 Eq.(100)。
  **换成非平方损失，成对期望不再按矩分解，`(a,b,γ)` 无从构造。**
- 论文**没有**给出一般代理损失版本的 Thm 1（无对应定理、无证明）。
- **但有 Remark 4（行 `302`）**，全文唯一的推广声明：
  > Our derivations can extend beyond the squared margin loss to a broad family of convex and
  > continuous surrogates (e.g., logistic, exponential). By Bernstein-polynomial approximation [71],
  > such losses can be uniformly approximated while preserving convexity/monotonicity, so the
  > instance-wise minimax structure and linear per-iteration complexity remain intact.

  这是**一条 Remark，无定理、无证明、无收敛率**。引用它只能标为「文献声称、未证」。

### (d) 是否可迁移到 `softplus(S_n − S_p)` —— **不可迁移**

三处独立失败：

| 维度 | 文献要求 | 本课题实况 | 判定 |
| --- | --- | --- | --- |
| 分数值域 | `f(x) ∈ [0,1]`（sigmoid） | `S_e` 为袋聚合后实数，**无界** | **失败** |
| 损失形式 | `ℓ(x) = (1−x)²` | `softplus(S_n − S_p)` | 见下 |
| 结构 | 已消成对，逐样本 | `L_pn` 仍是**显式成对项** | **失败** |

**损失形式这一维有一处对本课题有利的事实，必须如实记录**：
`softplus(S_n − S_p) = log(1 + e^{−(S_p − S_n)})`，令间隔 `m = S_p − S_n`，即 `log(1+e^{−m})`，
**这正是 logistic 损失**——恰是 Remark 4 点名的两个可推广代理之一。
故「代理损失族」本身不构成障碍。**真正的障碍是分数无界**：
Remark 4 依赖的 Bernstein 多项式一致逼近**需要紧区间**，`f(x) ∈ [0,1]` 提供的正是这个紧区间。
分数无界时，Remark 4 这条本就未证的退路也一并断掉。

**结论**：Thm 1 不可迁移。§2.1 表格第二行须删除或改写为
「该行需先把分数压到 `[0,1]` 并换用平方损失才能引用；本课题当前配置两条都不满足，故不引用」。

**但 §二整节没有被打死**，因为 §2.2–§2.6 实际依赖的是 Eq.(10) 而非 Thm 1。
Eq.(10)（行 `182`）原文注明出处是「By **Lem.1 of [68]**」；该引理见附录 A 行 `911`–`923`：
> Lemma 1. $\sum_{i=1}^{k}x_{[i]}$ is a convex function of $(x_1,\cdots,x_n)$ …
> $\mathbb{E}_x[x \cdot \mathbb{1}_{x \geq \eta(\alpha)}] = \min_s \frac{1}{\alpha}\mathbb{E}_x[\alpha s + [x-s]_+]$

**纯实数命题，不要求有界、不要求平方损失、不要求逐样本设定。** 本课题的
`R_K = mean_p[ ξ + (1/K)Σ[L_pn − ξ]₊ ]` 与之同构，文档 §2.1 的这一判断**成立**。

### 多出一层聚合对定理结论的影响

**先纠正一处引用**。主代理简报里的 `Õ(α⁻¹n₊⁻¹ + β⁻¹n₋⁻¹)` 是 **TPAUC** 的界（行 `1937`）。
**OPAUC 的界是 `Õ(n₊⁻¹ + β⁻¹n₋⁻¹)`**（正文行 `452`、附录 E.1 行 `1844`），正类侧**没有** `α⁻¹` 因子。
本课题 BER 只有负侧预算 `β_K`、级二无正侧尾部选择，**对位的是 OPAUC 界**。引用时须换。

**计数单位的三重变化**：

1. **`n₋` 的单位从「样本」变成「实体」**。文献的 `n₋` 是 i.i.d. 负样本数；本课题是负**实体**数 `121336`，

   故有效样本数是实体数而非流数——这对本课题**方向有利**（分母仍是 `121336`，不是流总数的虚高值），
   但**须显式论证实体间独立**，目前无证据，标「待验证」。
2. **覆盖数论证的作用对象错位**。Thm 5（行 `443`）的界建立在**打分函数类 `F` 的覆盖数**上。
   本课题的风险取在**袋级** `S_e = agg({f(x)})` 上，`agg` 是 `max`／尾部聚合，

## Q3 `Ω_{s'} = [0,5]` —— **部分满足（是理论紧集，非实现细节；但本课题不适用，须改写）**

### 出现位置

| 行号 | 语境 |
| --- | --- |
| `193` | Thm 2 正文陈述：`Ω_γ = [b−1,1]`，`Ω_{s'} = [0,5]` |
| `1507`、`1555` | 附录 D.2.2 Thm 2 重述与结论 |
| `1023` | TPAUC 版（附录 B）：`Ω_γ = [max{b−1,−a},1]`，`Ω_s = [−4,1]`，`Ω_{s'} = [0,5]` |

**全文检索未在 §7.3 实现细节或附录 F.1 参数调优中出现 `[0,5]`**，
即它**不是实验超参**，而是定理陈述的一部分。

### 为什么需要有界

**紧性是 minimax 交换的前提**。行 `242` 原文：
> For fixed $(f, a, b)$, the inner domains $\Omega_{\gamma}$ and $\Omega_{s'}$ are **convex and compact**.
> Moreover, $G_{op}^{\kappa,\omega}$ is convex in $s'$ and concave in $\gamma$.
> Applying the minimax theorem [70], we can interchange $\max_{\gamma}$ and $\min_{s'}$:

Eq.(15) 与 Eq.(20) 两次交换都靠它。**去掉紧性，整条 min-max-min → minimax 的路线断掉。**

### 为什么恰是 5

**原件未给出显式推导**（检索命令 `rg -n '0, 5|0,5|\[ 0, 5 \]' <全文md>`，
命中均为陈述与重述，无「因为…所以 5」的段落）。
但由其自身假设可**机械推出**，`ℓ_-(x') = (f(x') − b)² + 2(1+γ)f(x')`：

- `f(x') ∈ [0,1]`、`b ∈ [0,1]` ⟹ `(f(x') − b)² ∈ [0,1]`
- `γ ∈ Ω_γ = [b−1, 1]` ⟹ `1+γ ∈ [b, 2] ⊆ [0,2]` ⟹ `2(1+γ)f(x') ∈ [0,4]`
- 合计 `ℓ_-(x') ∈ [0,5]`

**即 `[0,5]` 恰是 `ℓ_-` 的值域，完全由 `f(x) ∈ [0,1]` 导出。**
最优阈值 `s'*` 是 `ℓ_-` 的 `β` 分位数，必落在值域内，故限制到 `[0,5]` 不改变 `min`。
这也说明它**随 `f` 的值域而变**，不是普适常数。

### 对本课题

`L_pn = softplus(S_n − S_p) ∈ (0, ∞)`，上界由分数尺度决定，**不是 5**。
`【实测·转述】`配对损失均值 `0.0039`（C01 第 `8` 轮 `pair_loss_batch_mean`，
数字取自被审文档 §2.3，本次未独立复算，标「来源待核」）——
比 `[0,5]` 中点小约三个数量级。直接沿用 `[0,5]` 不会算错，但投影约束**形同虚设**，
不提供任何有效的紧性保障。

**改写方式**：`Ω_{ξ}` 必须定义为 `L_pn` 的值域或由实测分位数确定的区间
（例如 `[0, q_{0.999}(L_pn)]`），**关键是它是损失的值域，不是常数 5**。

**缺口（本次未核）**：本课题 `ξ_{p,K}` 当前是否有任何投影／裁剪，需核
`thesis/experiments/llm_probe/tools/ch3_ft_entity_ranking_loss.py`。未核，不下判断。

## Q6 Thm 3 到底给了什么量的 `O(1/κ)` —— **张冠李戴（阻断项 B2）**

**Thm 3 的精确定义（行 `222`–`232`，证明 D.2.3 行 `1557`+）**：
```
Δ_κ^op = min_{f,(a,b)∈[0,1]²} max_{γ∈Ω_γ} min_{s'∈Ω_{s'}} Ê_{z~S}[ G_op^κ(f,a,b,γ,z,s') ]
       − min_{f,(a,b)∈[0,1]²} max_{γ∈Ω_γ} min_{s'∈Ω_{s'}} Ê_{z~S}[ G_op  (f,a,b,γ,z,s') ]
```
附录行 `1562` 加绝对值。行 `228`–`232`：「**For $f(x) \in [0,1]$**, we have the following
convergence result: $\Delta_\kappa^{op} = O(1/\kappa)$.」

**判定**：`Δ_κ^op` 是**平滑目标与原目标两个 min-max-min 最优值之差**，
即**目标函数值的近似间隙（objective gap）**。

- **不是**阈值偏移 `s'_κ − s'`。
- **不是** `β̃ − β`。

**文献对分位数偏移只给定性断言**，行 `220`：
> Nevertheless, we can prove the approximation gap induced by $r_k$ has a finite convergence rate
> $O(1/\kappa)$ by the following theorem. Namely, this gap vanishes when $\kappa \to \infty$,
> and **the quantile deviation will correspondingly diminish**.

「will correspondingly diminish」是定性的，**全文未给分位数偏移的收敛率**。

**故文档 §2.4「文献给出该偏差的收敛率为 `O(1/κ)`（其 Thm 3）」不成立**（该句的「该偏差」
在上下文中指「软化会移动有效预算档」）。**须改写为**：

> Thm 3 给出的是**目标值近似间隙** `Δ_κ^op = O(1/κ)`，且该结果本身要求 `f(x) ∈ [0,1]`；
> 文献只**定性**断言分位数偏移随之减小，**未给该偏移的收敛率**。

**两条派生影响**：

- **对 §2.6.2 有利**。`β̃/β` 的数值扫描（`κ=256` 时 `0.108` 等）是**本课题自己做的**，
  文献没有这个率。故该表是本课题的差量贡献，**但不能说「与文献一致」**——文献没给可比对象。
- **本课题引用 `O(1/κ)` 的任何形式都受 B3 约束**（前提 `f(x)∈[0,1]` 不满足）。

## 附：一条文档完全没提、但直接可用的替代路线

**文献自己认为平滑路线的这个代价不可接受，并给了另一条路。** §4.3.2 开头行 `252`：
> Although the gap $\Delta_{\kappa}^{op}$ vanishes asymptotically as discussed in Thm.3, the smoothness
> of the function will also vanish undesirably when $\kappa \rightarrow \infty$. To make the optimization
> efficient, we must consider a limited value of $\kappa$, for which the asymptotic gap cannot be ignored.

**这与文档 §2.6.3 的实测结论（`κ` 越大越要压 `lr`，三个要求互不相容）方向完全一致**，
是对该节的独立文献支持。

文献给的替代是 **§4.3.2 无偏重构**（Eq.(16)–(19)，行 `254`–`286`）：
```
[x]_+ = max_{c ∈ [0,1]} c · x                                        (16)
min_s (1/β)·Ê[βs + [ℓ_-−s]_+] = min_s max_{c(x)∈[0,1]} (1/β)·Ê[βs + c(x)·(ℓ_-−s)]   (17)
```
每个负样本显式配一个选择权重 `c_j ∈ [0,1]`（行 `268`）。

**关键**：Eq.(16)/(17) 是**纯变分恒等式，不要求 `f(x)∈[0,1]`、不要求平方损失**，
其可迁移性与 Eq.(10) 同级——**远好于 Thm 1**。Remark 3（行 `300`）给出取舍：
平滑法适合训练开销／显存为主要约束时，无偏重构适合必须消除近似偏差时。

**本课题的六档预算有真实告警运营语义、不能漂移**（文档 §2.6.2 自述），
按 Remark 3 的判据**恰好落在「必须消除近似偏差」一侧**。
建议主代理评估这条路线，而非只在 `κ` 与 `lr` 之间找平衡点。
本条为**设计建议，实验待证**，不作既定结论。
