## 二、两个机制的实际数学内容

### 2.1 DS（动态难度调度）＝三个分段函数

全部数学内容是三个手工设计的调度函数：

- 式(3.4) 扰动半径线性 warmup：`ϵ(t) = ϵ_max·t/T_warm`（`t < T_warm`），此后取 `ϵ_max`
- 式(3.5) 攻击步数三段阶梯：`K(t) = 1` → `K_max/2` → `K_max`，切换点在 `T_warm/3` 与 `T_warm`
- 式(3.6) 步长自适应缩放：`α(t) = η·ϵ(t)/K(t)`

第(4)小节「非凸优化曲面的平滑机制」是**文字论证**，无公式：
「有效地规避了……局部极小值或梯度爆炸陷阱」。

### 2.2 RGO（二阶反应梯度优化）＝一个链式法则分解

核心是式(3.12) 的全导数分解：

```
∇_θF = ∂L(x+δ*,y)/∂θ  ＋  [∂L(x+δ*,y)/∂δ*] · [dδ*(θ)/dθ]
       └── Direct ──┘      └──── Indirect (Reaction) Gradient ────┘
```

传统 Min-Max 依 Danskin 定理近似，把 `δ*` 当常数，**只算第一项**；RGO 把内层 PGD 迭代
展开为计算图（unrolled optimization），显式计算第二项。文中称该项「包含博弈的二阶曲率信息」，
并把它比作「前瞻性正则化项」。

### 2.3 「定理 1」的实际深度

3.5.1 有「**定理 1：课程平滑效应**」并附「证明分析」，内容是**一阶泰勒展开**：

```
L(f_θ(x+δ), y) ≈ L(f_θ(x), y) + δᵀ∇_x L(f_θ(x), y)          式(3.24)
```

内层 `max_{‖δ‖≤ϵ} δᵀ∇_x L` 取解析解 `ϵ‖∇_x L‖_*`（对偶范数），代回外层得

```
ρ_ϵ(θ) ≈ L(f_θ(x), y) + ϵ‖∇_x L(f_θ(x), y)‖_*             式(3.25)
```

两行推导，标准技巧。定理陈述本身是描述性的（「近似于平滑版本」「构建了一条连续路径」），
**没有假设条件、没有误差界、没有收敛率**。

## 三、消融设计：一个 2×2 四格，两个骨干各做一遍

表 3-7（印刷页 42）的完整数据，PGD-20 鲁棒准确率 RA：

| 骨干 | 变体 | 组件 | RA | 相对提升 |
| --- | --- | --- | ---: | ---: |
| BUPT-CNN | Baseline | PGD-AT | `55.60%` | — |
| | DS-AT | PGD＋DS | `56.50%` | `+0.90` |
| | RGO-AT | PGD＋RGO | `60.20%` | `+4.60` |
| | DS-RGO | DS＋RGO | `64.90%` | `+9.30` |
| ET-BERT | Baseline | PGD-AT | `63.50%` | — |
| | DS-AT | PGD＋DS | `66.20%` | `+2.70` |
| | RGO-AT | PGD＋RGO | `69.80%` | `+6.30` |
| | DS-RGO | DS＋RGO | `75.80%` | `+12.30` |

**这就是标准的 2×2 四格**：Baseline＝C00，DS-AT 与 RGO-AT 是两个单机制格，DS-RGO＝C11。

### 3.1 交互项（本文件计算，朱原文未显式给出该量）

```
I = 组合增益 − 单机制增益之和
BUPT-CNN：I = 9.30 − 0.90 − 4.60 = +3.80
ET-BERT ：I = 12.30 − 2.70 − 6.30 = +3.30
```

**两个骨干上交互项都为正**，与本课题预注册的 `I = C11 − C10 − C01 + C00 > 0` 同构。

### 3.2 最关键的一条事实

**DS 单独在 BUPT-CNN 上只有 `+0.90`，而它参与的交互项是 `+3.80`——交互贡献是其独立贡献的 4.2 倍。**

朱原文对此的解释是「DS 机制具显著模型特异性……在 BUPT-CNN 上仅增益 0.90%，
在 ET-BERT 上提升达 2.70%，证实渐进式难度引导可保护大模型底层特征分布」。

即：**一个单独效果很弱的机制，凭借与另一机制的正交互，仍然构成有效的第二机制。**

## 四、对本课题的启发

### 4.1 第二机制不必复杂，也不必单独强大

此前主进程以「理论深度不足」质疑 M-E，标准定错了。对照实测：

| 维度 | 朱的 DS | 本课题的 M-E |
| --- | --- | --- |
| 正文篇幅 | 约 2 页 | 待写 |
| 数学内容 | 3 个手工分段函数 | PLE 编码＋门控 MLP＋指示函数 |
| 命题与证明 | 定理 1（一阶泰勒，2 行） | 严格过去性命题（3 段证明）、零门退化命题（含证明） |
| 单独效果 | `+0.90`（CNN） | 未知，零实验 |
| 参数量 | 无新增参数（纯调度） | `124,673` |

**M-E 的形式化程度不低于 DS。** 它缺的不是深度，是**一条说明「机制在数学上做了什么」的近似式**——
朱有式(3.25) 把 DS 的作用写成 `L + ϵ‖∇_x L‖_*`，而 M-E 现有的命题全是正确性核验
（`γ=0` 会怎样、因果边界在哪），没有一条刻画机制的作用。这条可低成本补齐。

### 4.2 判据应当是交互项，不是单机制强度

M-E 的已实测结构性弱点是作用域窄——源年验证集 `20` 个正实体中只能影响 `13` 个。
按 DS 的先例，**这限制的是它的独立增益上限，不构成否决理由**。真正的门槛是
`I = C11 − C10 − C01 + C00 > 0`，这一条本来就已预注册。

### 4.3 但有一条差距是实质性的：两机制是否共享数学框架

> **2026-09-02 更正**：本节原写「DS 作用于内层、RGO 作用于外层，二者是同一个 Stackelberg
> 双层优化问题的两个环节」。经原件逐行核对（行 813–830、901–939、962、982–996），**该判断错误**，
> 已按下文改写。原错误表述曾被用作机制一候选选择的依据，教训记于本节末。

**朱的图 3-1 中「外层循环／内层循环」指的是训练控制流层级**（DS 在外、Stackelberg 博弈在内
被反复调用），**与 Stackelberg 双层优化本身的 Outer(Leader)／Inner(Follower) 是两套不同的
「层」概念，只是用词碰巧重叠**（行 813–830 对比行 901–939）。正确的结构是：

- **DS 不是该双层博弈的任何一层**，而是**调度该博弈参数的外部课程机制**——
  只有 `ε(t)` 直接进入约束集 `S_t` 的定义式(3.8)；`K(t)`、`α(t)` 是内层求解器的
  迭代步数与步长，不属于集合 `S_t` 本身（行 907–917 对比行 862–884）。
- **RGO 是博弈内部 leader 对 follower 解做隐式微分的梯度计算技术**，跨越 inner/outer 两侧。
  另须限定：式(3.12) 理论上写出 `dδ*(θ)/dθ`，但该量**无解析解**，实现为前向展开 K 步递归
  （式 3.13–3.14）后的**单步截断近似**（式 3.15、算法 3.1 第 25 行），
  **不是精确雅可比**（行 982–996）。引用时须加「理论分解式，实现为截断近似」的限定。
- 二者是**嵌套关系：DS 为 RGO 所在的博弈供参数**，不是并列共享同一层。

因此交互为正的机制解释应表述为：**DS 逐轮下发的课程参数决定了内层博弈的难度与求解步数，
内层解越稳定，RGO 的截断反应梯度估计越准**。因果链仍然成立，但方向是「调度器 → 博弈」，
不是「同层并列」。

**另一处遗漏更正**：3.5 节除定理 1、定理 2 外**还有引理 1**（3.5.4 节，式 3.32–3.33，
连续空间扰动对物理离散攻击的理论上限界定），本文件初版漏记，该节共三条形式化论断而非两条。

**教训**：本节的原错误表述被主代理用作「尾部聚合与 BER 构成嵌套 CVaR 共享框架，
对位 DS/RGO 共享 Stackelberg 内外层」这一论证的前提，进而成为机制一候选选择的依据；
而该前提从未回原件核实。**二手理解文档不得作为路线级裁决的唯一依据，
凡涉及候选选择的对位判断必须回原件逐行核对。**

**本课题目前缺这一层。** BER 作用于损失（CVaR-pAUC 多预算实体排序），
M-E 作用于表示（实体门控数值分词），二者**没有共享的数学框架**——
一个改「排序对预算敏感」，一个改「表示对实体历史敏感」，各自可能有效，
但交互为正**没有先验的机制理由**，只能靠实验碰。

**这是当前设计相对参照论文的真实差距，比理论深度重要得多。**

## 四点五、朱如何处理非正面结果（2026-09-02 原件核查）

核查范围：第三章正文行 749–1554。**结论：不是回避，也不是平实承认局限，而是
「呈现弱数据 ＋ 归因转移 ＋ 叙事迁移」的选择性呈现。**

**负面数字写了不少，但主语几乎全是对比基线**：Standard 在 PGD-20 下鲁棒准确率近乎归零
（表 3-5／3-6，行 1401、1405、1407）；PGD-AT 与 FreeLB 在第 10–12 轮峰值后回落 `5%–8%`，
CAT 只缓解未消除（行 1443）；强扰动下 DiffPurify 在 `ε=0.20` 失效、Adv-LoRA 在 `ε=0.15`
降至 `28.5%`（行 1522）。这些负面结果的功能是反衬 DS-RGO，不是承认自身不足。

**涉及 DS-RGO 自身的弱信号只有两处**，且数据未被隐藏：

| 弱信号 | 行号 | 他的处理 |
| --- | --- | --- |
| DS 在 BUPT-CNN 上仅 `+0.90`（ET-BERT 上 `+2.70`） | 1463–1465 表格、1472 正文 | **不称局限，重新定性为「模型特异性」**，解释为渐进式难度引导对大模型底层特征分布更有保护作用；紧接行 1474 把焦点迁移到 ET-BERT 的 `12.30` 超过单模块之和 `9.00` |
| 细粒度类别上「存在局部混淆」 | 1533 | 陈述后立即转向「仍保持 `88%–94%` 极高召回率」的正面总括，无机制层面归因 |

干净样本准确率有损失，但被限定在 `2.1%` 以内（行 1409）。

**全章无「局限性」「不足」「有待进一步」「未达预期」「与假设不符」字样——检索零命中。**
