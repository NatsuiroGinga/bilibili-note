## 二、B 项：DR 口径裁决

### 2.1 一句话裁决

**统一总表的 `DR 0.78989362 @ 实际 FPR 0.03720639` 符合「实际可达 FPR ＋ 实体级」合同，可进正文；制品 `dr_at_fpr.fpr_0.04 = 1.0` 是名义分位索引落入并列块造成的退化读数，其真实假阳率是 100%，即「全部告警」这一平凡点，必须废弃。**

### 2.2 两个工具的源码依据（含行号）

制品侧函数 `dr_at_fpr`，定义在 `tools/ch3_full_mlp_complete_entity_lp_protocol_a_q0.py:824-833`
（bf16 工具 `ch3_full_mlp_complete_entity_lp_protocol_a_q0_bf16.py:26` 以 `import ... as legacy` 整体复用，未重写该函数）：

```
828    negative = np.sort(values[target == 0])[::-1]
832    threshold = negative[min(int(len(negative) * target_fpr), len(negative) - 1)]
833    return float((positive >= threshold).mean())
```

第 832 行只按**名义秩位** `int(N_neg × 0.04)` 取阈值，**不检查该阈值实际产生多少假阳**。
分数存在并列时，`positive >= threshold` 与实际 FPR 完全脱钩。

统一总表侧，`tools/ch3_build_metrics_table.py:868` 自述口径：

```
868    suffix = "；六档DR按realized_fpr不超过名义预算的最接近实际可达点重算"
```

实现在同文件 `882-895` 行：先筛 `actual_fpr <= nominal_budget`（885 行），
再取其中最大的 `closest_fpr`（889 行）并读该点 DR（894 行）。这就是「实际可达 FPR」口径。

### 2.3 实测复核（本机，零远程访问）

在 `complete-alert-budget-curves.npz` 上按两种口径重算，结果如下：

| 格 | 名义秩位 1854 处 realized FPR | 该处 DR | 实际可达重算 FPR | 重算 DR |
| --- | ---: | ---: | ---: | ---: |
| B00 | 0.04078683 | 0.63164894 | 0.03914760 | 0.62765957 |
| B10 | 0.04039859 | 0.71276596 | 0.03998878 | 0.71276596 |
| O01 | 0.04001035 | 0.76462766 | 0.03998878 | 0.76462766 |
| **O11** | **1.00000000** | **1.00000000** | **0.03720639** | **0.78989362** |

重算值 `0.78989362 @ 0.03720639` 与统一总表逐位一致，交叉验证通过。

虚高的机制已定位到具体数量：**O11 的 46,363 个负实体中有 44,638 个（96.28%）分数并列在同一下限值**，
`realized_fpr == 1.0` 的秩位从第 1725 位起一直延续到末位。名义秩位 1854 > 1725，落在并列块内部，
于是「阈值以上」= 全部实体，DR 与 FPR 同时为 1.0。

并列的来源是幂平均实现中的下限截断，`ch3_full_mlp_complete_entity_lp_protocol_a_q0.py:819`：

```
819    np.add.at(numerator, flow_entity[seen], np.clip(flow_scores[seen], 1e-7, 1.0).astype(np.float64) ** p_value)
```

实体内全部流分数低于 `1e-7` 时一律被夹到 `1e-7`，实体分数因而恒等于 `1e-7`。
对照组：取最大路径（同文件 815 行 `np.maximum.at`）不作截断，`maximum_dr_at_fpr.fpr_0.04 = 0.79255319`，未退化。
这解释了为何同一格的 `dr_at_fpr` 崩到 1.0 而 `maximum_dr_at_fpr` 正常。

**另一条同型缺陷**：B00 的名义秩位实际 FPR 为 `4.0787%`，已越过 4% 预算。
即使不发生 O11 那样的极端退化，名义秩位口径也系统性地把读数取在预算之外。四格中只有 B10、O01 恰好落在预算内。
