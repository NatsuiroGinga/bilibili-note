# 全容量多层感知机源年筛选实施报告

- **日期**：2026-08-20
- **路线**：RWKV 第三章
- **状态**：实现完成，本地静态入口已核验，实验待证；未访问服务器，未启动实验
- **实现代理**：`ch3_full_capacity_mlp_screen_impl_sol_high`，`gpt-5.6-sol`，`effort=high`

## 一、实现结论

本轮只实现 LSPR23 的 C00 容量与论文配方筛选，不实现 CPA/ELP 四格，也不生成任何目标年入口。八个训练单元严格按冻结顺序运行：隐藏深度 `2/8`、宽度 `192/512` 与 `paper-log-median/paper-log-q75` 两个配方的笛卡尔积。

`2×192` 在两个论文配方下重新训练，作为同一筛选族的源年锚点。历史协议 A 的 90K 目标年结果只保留身份和参数参照语义，本入口不加载、不重训，也不据此选择候选。

筛选期间 CPA 与 ELP 均关闭并保持 C00。该冻结只约束本轮筛选，后续版本可依据新的开发证据另立合同修订机制。

## 三、输出合同

正式运行必须产出：

- `progress.jsonl`：八个完成单元的幂等进度记录。
- `inflight/<unit>.pt`：在途 epoch 检查点，完成后删除。
- `checkpoints/selected-<unit>.pt`：每单元源年选中权重。
- `receipts/selection-<unit>.json`：每单元源年验证指标、参数与资源收据。
- `first-non-anchor-calibration.json`：首个非锚点第一轮的步时、显存与剩余成本外推。
- `backbone_selection_frozen.json`：唯一骨干/配方封印或源年停止裁决。
- `source-screen-results.json`：八单元源年指标、参数/资源汇总和裁决。
- `resource-receipt.json`、`swanlab-receipt.json`、`manifest.json`、`status.json`。

所有状态、收据、汇总与封印均机械记录 `target_year_arrays_read=0` 和 `downstream_entry_generated=false`。实现中不存在目标年加载函数、目标年数组清单或后续四格启动入口。

## 四、资源估计

冻结设计以现有 90K C00 约 `1.2` 分钟为基准，八单元参数倍率和为 `69.04`，源年训练的线性外推约 `83` 分钟。考虑六次非锚点诊断、六个大模型检查点、六个源数组内容摘要、SwanLab 发布与资源采样，本轮启动前按 **约 1.5 至 2.0 GPU 小时**准备；该区间是工程估计，不是实测承诺。

首个非锚点完成第一轮后，入口以实测轮时和参数倍率重算剩余 GPU 时间。若外推超过冻结设计给出的 `5.0 GPU 小时`上界，入口停止并要求新建资源授权版本，不会静默减少 epoch、步数、序列长度或批量。

参数上界为 `2,144,258`，约为 90K 锚点的 `23.76` 倍。启动器要求至少 `12 GiB` 空闲显存、`40 GiB` 可用控制组主存与 `10 GiB` 可用磁盘；实际峰值由正式运行收据裁决。

## 五、第三方接口核验

本实现未引入新的第三方库或新的接口形态，复用仓库现有且已通过入口检查的同构调用：PyTorch 的模型、AdamW、检查点和随机状态接口，scikit-learn 的 `average_precision_score/roc_auc_score`，以及 SwanLab 的 `init/log/finish`。锁文件当前解析到 PyTorch `2.13.0`、SwanLab `0.9.0`；scikit-learn 按解释器版本解析为 `1.7.2` 或 `1.9.0`。确定性训练接口也已有仓库内同构调用，因此未重复发起 Context7 查询。

## 七、唯一启动入口

在代码、配置和启动器同步并核对摘要，且用户确认 GPU 资源与费用后，唯一初始启动命令为：

```bash
bash scripts/remote_launchers/run_ch3_full_capacity_mlp_source_screen_seed42_v1.sh
```

同一运行身份中断后只能在原输出根使用启动器的 `--resume` 语义恢复，不能创建第二个运行身份或重复已完成候选。

## 八、证据边界

当前只有实现与静态入口证据，所有性能结论均为**实验待证**。源年胜出只表示冻结候选集合在 LSPR23 的单种子验证逐流 AP 上出现选择信号，不表示跨年有效，也不自动授权后续 CPA/ELP 四格或任何目标年评价。源年停止只否决本轮 `2/8×192/512` 与两个论文配方的候选集合，不支持“大 MLP 无效”的外推。
