# 全容量多层感知机统一 BF16 资格实验实施计划

## 目标

复用 LSPR23 源年筛选已封印的唯一胜出配置，不重做容量或配方比较；以统一 `cuda-bf16-amp-fp32-sensitive-v1` 从头训练固定结构，并补齐统一资格合同需要的源年完整多指标、首次告警时延和资源制品。

## 冻结输入

- 父运行：`ch3-full-capacity-mlp-source-screen-seed42-v1`
- 胜出配置：`mlp-depth8-width512-full--paper-log-median`
- 结构：8 层、宽度 512、参数量 2,144,258
- 配方：学习率 `0.0003162277660168379`、权重衰减 `0`、丢弃率 `0.1`
- 选择证据：LSPR23 固定实体不相交验证集逐流 AP `0.9997527228408204`，第 10 轮
- 数据：合法 83 字段、协议 A 固定训练/验证划分；不新增三折或折外流程
- LSPR24：仅在 LSPR23 选择封印后作分表描述性评价，不参与选择

## 实验图

1. 训练格保持现有 `B00/B10/O01/O11`，用于历史 CPA、旧联合 ELP 的强基线与交互对照。
2. 在 `B00/B10` 同一逐流分数上派生 `N01/N11` 完整实体幂平均分支，隔离聚合规则而不重复训练。
3. 组件结果不预设保留；任何分支被全面支配时如实否决。

## 精度与恢复

- 新运行身份，禁止加载 FP32 模型或优化器断点。
- 参数、优化器状态、损失归一化、概率/对数和评价保持 FP32；前向线性与激活使用 BF16 autocast；BF16 不使用 `GradScaler`。
- 有效批、样本顺序、损失分母和优化器更新次数与现协议一致。
- 每 20 个完整优化器步原子保存模型、优化器、轮次、步、最佳轮次、随机状态、精度身份和恢复计数；同身份幂等恢复。

## 指标与制品

- 源年与目标年分表：逐流 AP、实体 AP、最大池化实体 AP、六档实体 DR、完整告警预算曲线。
- 首次告警：六档预算下未告警率、首次告警曝光序号分位数、按时检出曲线；只输出聚合，不持久化逐流或逐实体分数。
- 工程：参数量、权重字节、训练/选择/评价/纯推理/总时间、有效流吞吐、峰值显存、峰值主存、检查点字节、恢复次数和重复计算量。
- 结果必须携带父选择收据、代码/配置/数据/精度摘要以及 `target_year_arrays_read`。

## 文件边界

- 新增 BF16 专用 Python 入口、配置、启动器和实施报告。
- 允许复用现有 `ch3_full_mlp_complete_entity_lp_protocol_a_q0.py` 的纯函数，但不得修改旧 FP32 运行身份或制品。
- 不修改 GRANDE、RWKV、TabM32 或统一总表生成器。

## 验收

1. Python 语法、导入、`--help`、配置核验与 `bash -n` 通过；不运行 `black`。
2. 机械核对胜出配置、参数量、父收据摘要、BF16 敏感区、无 `GradScaler`、原子恢复字段和目标年隔离。
3. 首个真实优化器步输出有限损失、非零有限梯度、精度和显存收据。
4. 真实运行完成后再作科学裁决；静态检查只能标记可启动。
