# CPA 保留与独立实体头机制重构任务计划

## 目标

围绕用户已批准的目标句，形成可直接交给后续实现代理的冻结机制设计与分级实验方案：保留 CPA 的因果历史能力，将 ELP 从共享骨干辅助损失重构为独立实体头；只有独立头在源年出现可归因信号后，才验证受控联合训练。

## 任务边界

- 只新增本目录 `task_plan.md`、`notes.md`、`机制设计与实验方案.md`。
- 不修改现有文档、代码、配置、启动器、运行目录、恢复卡或路线总控。
- 不访问服务器、不启动实验、不派子代理、不补在线文献。
- LSPR24 数值只界定已知病灶和描述性边界，不参与结构、损失、预算、检查点或晋级选择。
- N-16 共同实际首次告警 FP 预算评价是后续 S1/S2 运行的前置门。

## 阶段

- [ ] 阶段一：恢复规则、技能、最新审计、N-16、全容量 MLP 严格结果和候选修订。
- [ ] 阶段二：读取 ForkMerge、Ilse、Pevny、MIDAM、Recon 全文笔记及朱论文对位规则，登记证据等级和禁止外推边界。
- [ ] 阶段三：比较 2–3 种机制构造，裁决独立实体头的公式、S1/S2 实验图、数据与梯度边界。
- [ ] 阶段四：写入证据笔记和正式方案，冻结指标、门槛、资源、制品、恢复及允许/禁止措辞。
- [ ] 阶段五：执行占位符、链接、内部一致性、范围和 Git 差异自审，只提交三份独占文档。

## 关键问题

1. 哪些全容量 MLP 四格差异已由源年和目标年制品证明，哪些成因仍未识别？
2. 五篇全文分别只能支持哪个设计部件，为什么证据仍为 D 级机制启发？
3. 如何使 S1 实体头的梯度绝不进入骨干与原逐流头，并机械证明逐流输出逐位不变？
4. 如何按实体而非流数平衡训练，使长实体不能通过更多流重复支配损失？
5. S1 何时支持进入 S2，S2 三臂如何只改变一个受控变量并保持共同预算？
6. 如何在 N-16 公共实际 FP 预算上同时裁决路径、终端和及时检出，而不由目标年反向选模？

## 已冻结决定

- 用户批准目标句是本任务的设计批准门，不重新询问是否采用。
- 旧 CPA-ELP 保留为强基线，不覆盖、不改名、不事后升级证据等级。
- strict-past CPA 与扩大 `p` 网格均已关闭，不作为本轮候选或补救路径。
- 先执行头部隔离的 S1；S1 无源年信号时停止，不进入联合训练 S2。
- S2 只允许主任务、固定实体辅助、ForkMerge 验证驱动过滤三臂及同容量对照；梯度余弦只作诊断。
