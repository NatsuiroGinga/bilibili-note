## 已冻结的研究边界

- 第三章贡献对象是 CPA 与 ELP 两个机制，不是某个骨干。
- 现有 XGBoost 主口径采用逐实体取最大：实体平均精确率 `51.29%`，`DR@4%FPR=69.28%`。
- `53.19%/81.65%` 来自把现有 XGBoost 分数借用本方法 `p=1.223554` 聚合，不是已注册的无机制基线。
- 告警预算曲线必须与实体平均精确率并列；单个 `4%` 工作点不能代表整条曲线。
- 用户要求尽可能使用 GPU 并并行；四格按两次模型拟合组织，`B0/ELP` 共享原始特征模型，`CPA/CPA+ELP` 共享上下文特征模型。
- 两次 GPU 拟合仅在显存与控制组内存的联合保守上界通过时并行；否则 GPU 串行拟合，并行执行不争用显存的源年 `p` 网格和聚合统计。

## 待核验
