- **研究路线**：`RESEARCH_ROUTE=RWKV`
- **执行代理**：`xgboost_cpa_elp_literature_sol_max → gpt-5.6-sol → effort=max`
- **目标**：为 GPU XGBoost 的 `骨干 × CPA × ELP` 冻结方案划定公式来源、任务特定适配边界、强基线与失败条件；本任务不判断方法有效。

## 一、范围合同

### 研究问题

1. 将 CPA（因果前缀跨流聚合）从神经隐藏表示适配到 XGBoost 原始特征时，哪些组成有全文依据，哪些属于本任务的新适配？
2. 将 ELP 的可学习幂指数改为仅在源年度、以非梯度方式选择时，哪些组成有全文依据，哪些属于本任务的新适配？
3. 2018—2026 年是否存在与“原始流特征的实体内因果前缀聚合＋源年选择幂指数＋树模型”完整同构的公开全文近邻？
4. XGBoost GPU `hist`、`QuantileDMatrix`、直方图近似与数据接口，对冻结设计施加什么实现边界？
5. 外存／迭代式批量输入在 GPU 路径上的官方支持范围是什么；单卡内部并行与“四格并发训练”必须如何区分？

### 概念与检索词

| 概念 | 主检索词 | 同义词或限定词 |
| --- | --- | --- |
| CPA | causal prefix aggregation over flows | connection records, host/entity aggregation, temporal summary, rolling/prefix statistics, audit data, intrusion detection |
| 树模型上下文 | contextual/temporal features for tree-based intrusion detection | XGBoost, random forest, gradient boosting, flow history, host behavior |
| ELP | generalized mean/power mean pooling | Lp pooling, GeM, learnable norm pooling, multiple-instance learning, bag aggregation |

### 纳入标准

- 正式全文可核验，且直接支撑机制、公式语义、评价边界或 XGBoost 实现边界。
- 原论文、作者公开稿、出版社全文、官方文档或官方源码优先。
- 经典来源不限年份；直接近邻重点覆盖 2018—2026。
- 强结论必须给出本地原件或正式全文的页码、章节、公式、表格或源码位置。

### 排除标准

- 仅名称相似，但没有跨流、主机或实体语义。
- 只报告应用效果，没有足以核验的方法细节。
- 只有摘要或二手转述；可保留为线索，但不得进入强结论。
- 把目标年度标签用于选择的工作，不得用来支撑“源年选择”的无泄漏主张。

### 数量与停止条件

- 核心文献目标：6—12 篇。
- 核心覆盖：Lee & Stolfo；Gehri 等；Gülçehre／可学习范数池化；树模型上下文特征；XGBoost 官方 GPU 机制。
- 直接同构检索至少两轮；在最后一次新增核心全文后，再有连续两轮没有新增核心全文，且每个关键部件均已有一份强证据和一份边界证据后停止。
- 付费墙且影响公式或原创裁决时，记录精确题名、DOI、官方页和建议文件名，请用户补充合法全文。

## 五、决策与错误日志

### 已作决策

- 以“部件同源”与“完整组合同构”分开审计，避免把通用公式来源误写为完整方法先例。
- 官方 XGBoost 文档和源码只能支撑实现语义，不能支撑 CPA–ELP 的研究原创性或有效性。
- “未检索到”只作为有范围与查询式限定的检索结论。
- 冻结设计按数据输入分成 `raw` 与 `context` 两次 XGBoost 拟合；ELP 的幂指数仅在源年度预测上作非梯度后处理选择，不把四格误写成四次拟合。
- “尽可能 GPU 与并行”须拆成单次训练的设备内并行、数据构造／评估并行和多拟合并发；只有官方资料明确支持的部分才进入接口建议。
- 核心论文计 11 篇：8 篇有本地原件，3 篇以作者／会议正式开放全文核验；另核验 4 个 XGBoost 官方文档页面和 5 个外围边界来源。
- 当前 XGBoost 稳定文档为 3.4.1；它只能证明该版本的接口语义。正式实现必须先记录目标机安装版本，不能把 `ExtMemQuantileDMatrix` 等实验性接口视为无条件可用。
- `p<1` 仍可称幂平均，但不再属于 Gülçehre 论文所约束的归一化范数；若冻结网格包含该区间，须把范围扩展标为任务特定选择。
- XGBoost 版本不应把非梯度选出的 `p` 写成“端到端可学习参数”；推荐表述为“源年验证选择的实体级幂平均指数”。
- 两个独立拟合在同一张 GPU 上并发没有官方加速保证；只有显存、主存和实际吞吐门禁通过时才可并发，否则按相同 CUDA 配置串行拟合，并行执行不争用显存的聚合与指标计算。

### 错误与阻塞

- 无影响裁决的付费墙阻塞；无需用户补充全文。
- `Hindy 2021`、`Gulrajani 与 Lopez-Paz 2020/2021`、`Chen 与 Guestrin 2016` 已用正式开放全文核验，但本任务按独占输出边界没有写入 `raw/wiki/Zotero`；这不影响本轮全文裁决，后续可由主任务另行入库。
