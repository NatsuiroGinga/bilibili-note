# XGBoost＋CPA-ELP 运营指标回填图件目录

## 决定

本次不生成图件，`figures/` 目录不创建。

## 理由

1. 本次只有一个 C11 系统单元，没有同一评价池的模型或消融比较对象。
2. 主要裁决是制品是否完整、名义 FPR 与实际 FPR 是否区分、首次告警是否超出终端预算语义；精确表格比单曲线图更直接。
3. 完整预算曲线已有 14,519 点 NPZ，首次告警已有六条精确断点曲线 NPZ。新增静态图不会改变“可补齐哪些字段”或“哪些主张禁止”的判断。
4. 资源收据有争用，不能绘制公平效率比较图。

## 后续生成条件

只有出现以下任一情况时，图才具有新的决策价值：

- 同一评价池加入其他模型的完整曲线，需要判断共同实际 FPR 上的曲线支配关系。
- 需要展示多个模型的终端 FPR 与首次告警 FPR 偏离程度。
- 获得真实流可用时刻并冻结真实时延定义，需要比较曝光序号与真实时间轴。

届时应从原 NPZ 机械生成，不从报告表格反向抄数；图件按论文图件合同落到正式 `thesis/figures/第三章/`，本分析目录只保留图件清单与来源说明。
