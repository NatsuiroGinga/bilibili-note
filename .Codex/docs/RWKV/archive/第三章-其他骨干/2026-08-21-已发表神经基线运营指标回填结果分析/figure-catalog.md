# 已发表神经基线运营指标回填图件目录

## 图件裁决

本轮不生成图件。

`results-analysis` 技能通常要求在数据可读时生成真实图，但本任务明确限定“只有确有决策价值才生成图”。本次支配问题已经由 46,364 个假阳预算点和全部首次告警曝光断点的机械枚举直接裁决，精确数表比图形更能承载结论：

1. 一维 CNN 对 GRU 的完整预算曲线反例数为 0。
2. Transformer 对 GRU 有两个精确反向区间，共 2,264 点。
3. 六档端点会漏掉第一个反向区间；按常见图宽绘制完整曲线反而可能把该窄区间压缩到不可见。
4. 首次告警轴是曝光序号而非物理时间，且完整阶梯偏序已经机械比较，绘图不会改变裁决。

因此，任务特定的决策价值门优先；本目录没有 `figures/`，也没有装饰性图件。

## 后续触发条件

只有出现以下新增决策需求时才生成图：

- 需要向论文读者解释 Transformer 在 `0.612557%–0.750599%` FPR 区间的局部反转。
- 新增 LSPR23 同口径完整曲线，需要分年度并列展示而不是外推。
- 用户明确要求出版级图件，并同步调用图表规范工作流。
