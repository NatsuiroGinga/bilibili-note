## 1. 结论

**门槛可满足，A 方案册的 0.005 是按真实基线校准的，不是随手写的数。**

`0.005 / 0.03096512 = 16.15%`，即 `Delta_AP >= 0.005` 恰好等于该基线水平下的**错误相对下降 16.1%**——与朱焱雷第三章的历史参照量级一致。此前担心的"门槛不可满足"不成立。

## 3. 新发现的数据陷阱（三条，均未记录在任何方案册中）

### 3.1 标签是三值，`label=-1` 占六成

| 标签 | 窗口数 | 占比 |
| --- | ---: | ---: |
| `-1`（删失／不可评价） | `4,800,524` | `60.4075%` |
| `0` | `3,018,069` | `37.9779%` |
| `1` | `128,306` | `1.6145%` |

**可评价窗口仅 `3,146,375 / 7,946,899 = 39.59%`。**

未过滤 `-1` 会直接导致训练崩溃或指标错误。首版诊断脚本即因此失败：`ValueError: Invalid classes inferred from unique values of y. Expected: [0 1 2], got [-1 0 1]`，且把 `-1` 当数值算得"正类率 `-0.587`"。**任何消费该视图的实验都必须先做 `np.isin(label, (0, 1))` 过滤。**

### 3.2 训练区与验证区正类率相差 2.15 倍

| 分区 | 可评价窗口 | 正类数 | 正类率 |
| --- | ---: | ---: | ---: |
| `train` | `2,219,080` | `107,455` | `0.048423` |
| `validation` | `927,295` | `20,851` | `0.022486` |

时间前向切分下正类率本身在漂移。**LSPR24 同年任务不是平稳任务**，把它当同分布问题处理站不住；先验漂移会影响阈值冻结与校准设计。

### 3.3 最终区未物化（有利事实）

`dataset-manifest.final_split = "final-not-materialized"`。最终 20% 根本不在视图中，**泄漏风险为零**，无需额外封存机制即可满足最终测试隔离。

## 6. 对方案裁决的影响

1. **流式行为检测（A）的门槛可满足**，此前的否定性怀疑撤销。可用余量 `0.031`，需要拿下其中 `16.1%`。
2. 余量确实不大：任何机制必须在 `0.9690 → 0.9740` 这个区间证明自己，误差空间仅 3 个百分点。方案册要求的"强字段基座 + 有界历史残差"设计与该约束一致。
3. 三条数据陷阱须写入候选登记册的陷阱节，并在所有消费共享视图的任务中强制执行。
