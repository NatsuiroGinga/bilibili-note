# UGR'16 六版本 G0 数据门禁审计笔记

## 已核验来源

- 下载收据：`.Codex/docs/RWKV/2026-08-05-UGR16多版本本机下载收据.md`
- 路线合同：`.Codex/docs/RWKV/2026-08-05-RWKV恶意流量替代路线研究合同.md`
- 本机原始根：`thesis/experiments/llm_probe/data/raw/ugr16-feature-v3/`

## 固定边界

- 六个版本：`v1`、`v2`、`v2noIRC`、`v3`、`v4`、`v3v4`。
- 仅训练区 CSV 可被结构化读取。
- 官方测试区只记录下载收据已核验的文件大小与 SHA-256，不解析。
- v2 与 v2noIRC 四对文件逐字节一致，v2noIRC 暂不作为独立候选。

## 全量统计结论

- 六版训练文件均可解析，X/Y 行数相等、`Row` 分钟键逐行一致且严格递增。
- `v1/v2/v2noIRC/v3/v4` 为 134 维，`v3v4` 为 268 维。
- 六版训练区除 `blacklist` 外，其余七个攻击计数列全部为零。
- `blacklist` 在 v1、v2、v2noIRC 的每一分钟均非零，在 v3、v4、v3v4 的 96.04% 分钟非零。因此八列任一非零不能作为当前训练区的监督式二元攻击标签。
- 所有训练特征均无缺失、无非有限值、无负数；v3 有 7 个常量零列，v4 有 5 个，v3v4 有 12 个。
- 没有非恒定特征与二元标签、总攻击计数或单类计数逐行完全相等；同刻相关性审计未出现绝对相关系数达到 0.95 的字段。
- v1/v2 只有 3 个连续分钟段；v3 系有 851 个连续段，但仍可形成 64,979、58,330、43,620 个历史长度 16、64、256 的“历史到下一分钟”窗口。
- v2 是 v1 的前 98,262 行精确前缀；v2noIRC 与 v2 完全相同；v3/v4 时间键和标签相同、特征不同；v3v4 是 v3 和 v4 特征的逐列精确拼接。
- v3 时间键是 v2 的真子集，删除 25,618 分钟；共同时间上的七个非 `blacklist` 标签一致，`blacklist` 计数在 7,505 分钟发生变化。

## 门禁解释

- 来源、哈希、解析、字段完整性和长序列预算通过。
- 当前监督二分类、多分类、攻击事件与基线困难版本选择失败，因为训练区没有非 `blacklist` 攻击阳性。
- 训练区可继续承担背景密度建模和下一分钟生成预测，但不能独立评价攻击检测效果。
- 官方测试仍未解析。若要继续，必须先修订合同并预注册测试区的盲时间拆分，再读取测试标签。
