# R1 双层尾部风险重构快速实验实施计划

> **执行代理要求：** 使用 `superpowers:subagent-driven-development` 和 `daily-coding`，严格按本计划实现。不得创建人工夹具、单元测试或集成测试；只做一次编译/帮助入口检查，随后直接运行冻结开发区真实实验。

**目标：** 在同一 LSPR23→LSPR24 Q0 数据、字段、成员、标签权限和种子 42 下，比较五种源时间环境风险目标，并验证源锚约束的上下文 EVT 风险分数能否改善固定告警预算召回。

**架构：** 新建独立的 R1 v2 模块、配置和启动器，不改写历史 R1 v1 运行根或制品。五个 M1 变体共享同一模型结构、参数量、训练序列清单、732 步和优化器，仅改变损失聚合；M2 在概率封存后使用源校准良性分数与无标签目标前缀拟合冻结风险映射，目标开发标签仅在所有原始概率和风险分数封存后连接。

**技术栈：** Python、PyTorch、NumPy、SciPy、scikit-learn、SwanLab、Bash、C56 RTX 5090。

## 全局约束

- `screening_only=true`、`formal_paper_evidence=false`、`final_accessed=false`。
- 数据只来自现有 Q0 缓存和阶段 A v2 冻结接收器，不扫描原始数据，不访问最终 20%。
- 目标前缀必须由冻结接收器编码，`labels_read=false`；目标开发标签必须在所有概率与风险分数封存后连接。
- 五个训练变体共享模型、参数量、序列顺序、批量 16、4 轮、732 步、学习率和种子 42；默认最大并发 3，资源允许时自动并行。
- 不在目标开发标签上选择 `beta`、`rho`、`lambda`、尾部起点、上下文桶或预算。
- SwanLab 固定为 `mortiswang/malicious-traffic-llm`，启动前机械断言。
- Q0 主晋级门槛只使用同一数据、字段、成员和标签权限下的共享表格基线：XGBoost `AP=0.038902589823969644`，HGB `0.037147851122101574`，随机森林 `0.015572256018043917`；神经诊断参照 K-DELTA 为 `0.01697727694684599`。Dijk 2026 XGBoost 与 Leoste RF 的既有结果属于论文约束独立复现，不作为原论文严格基线或主晋级门槛；Dijk 2024 作者 8 万行身份哈希示例永久排除。
- 当前比较只能裁决 Q0 候选存废；进入论文正式表前仍须冻结正式数据并运行种子 42/43/44。
