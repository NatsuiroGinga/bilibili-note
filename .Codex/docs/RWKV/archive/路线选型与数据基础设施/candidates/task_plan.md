# 任务计划：RWKV 其他章级候选研究构思

## 目标

在不修改现有总控、候选登记册和实验代码的前提下，形成 3—5 个 C12 之外、文献驱动且可由种子 42 快速消融证伪的完整第三章候选。

## 阶段

- [x] 阶段 1：恢复 RWKV 路线、读取局部规则与指定材料
- [x] 阶段 2：盘点并核验本地全文、既有阅读笔记与数据合同
- [x] 阶段 3：形成候选池并按章级门槛筛选、排序

- [ ] 阶段 5：撰写总览报告并执行一致性、链接、格式自检

## 关键问题

1. 每个候选是否有两个解决不同子问题、可独立消融且可能组合增益的机制？
2. 每个候选是否遵守 `LSPR23→LSPR24` 或 LSPR24 内部合法开发任务，并完全隔离最终 20%？
3. 文献证据是否只支撑机制来源和任务难度，而没有冒充本课题效果证据？
4. 理论义务、工作量和单卡实验成本是否足以支撑第三章且可执行？

## 已作决策

- 采用“总览—设计—实验”三层文档结构：总览只承载状态、排序、证据边界和链接；理论设计与快速实验分别独立维护。
- literature-reviewer 委派因四个并发槽已占满而无法执行；按 research-ideation 降级规则由本代理完成同一六阶段证据流程。
- 不联网补充泛泛论文；优先复用仓库内已下载并有全文笔记的来源。只有本地证据无法支撑关键机制时才联网。
