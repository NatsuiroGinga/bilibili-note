## 2. 共同强基线与快速合同

三个候选必须共享：

- 主锚：共享 XGBoost，不得重新挑选弱版本。
- 公开协议近邻：Dijk 约束 XGBoost。
- 神经基线：一维卷积网络、离散 RWKV；只读引用候选 B/C12/R1 的已有结果，不重复运行。
- 方法基线：与候选机制同预算的普通版本；TL1 为全量 OT/无保护 POT，TL2 为无界残差，TL3 为单调校准/无方向保护谱头。
- 主指标：目标开发 PR-AUC；固定预算为每百万流 100、1000、10000 条告警召回。
- 标签时序：全部变体预测和无标签门禁决定先封存，随后评价器一次性连接目标开发标签；目标标签不参与选型。
- P0 强锚按原参数和成员以 `tree_method="hist", device="cuda"` 重拟合；先真实最小拟合/预测证明 CUDA 生效，失败停止且不回退 CPU。既有共享 CPU XGBoost `0.038902589823969644` 仍是唯一比较锚。
- Q0 整体晋级：PR-AUC 至少 `0.043902589823969644`，三预算至少两项不低于 XGBoost、任一项下降不超过 `0.002`、至少一项提升 `0.005`。
- 若严格高于 XGBoost但增量不足 `0.005`，只记“弱正信号/不晋级”；Q0 结果不能写成论文效果。

## 3. TL1：恶意质量保护的非对称部分传输

### 两个独立机制

1. **M1 排序机制**：在 XGBoost 叶/分数成本上求源/目标非对称部分传输；允许拒绝目标污染和支持外质量，但以源真标签约束最低恶意传输质量。不同目标原型得到不同对数几率修正，因而可非单调改变排序。
2. **M2 安全机制**：只用目标前缀耦合可行性、恶意有效原型数、前缀分半稳定性、未匹配质量和锚排序扰动判断是否应用 M1；失败时完整回滚 XGBoost。

### 理论来源与缺陷响应

- Courty OT、PPOT、WARMPOT、BUOT 提供 OT/POT/UOT 与传输边缘风险解释。
- PROTOCOL 已覆盖渐进质量和少数类再平衡，故这些宽泛构件不能作为原创。
- 普通 OT 强迫全质量匹配；PPOT/WARMPOT/BUOT 没有 LSPR 源恶意真标签质量下限；无标签 EnsV/迁移分数可能被多数良性共识支配。
- TL1 的窄边界是“恶意质量下限 + 非对称支持拒绝 + XGBoost 强锚 + 前缀无标签回滚”的任务特定联合设计。

### 最小可证伪矩阵与门槛

`XGBoost / 全量对称 OT / 非对称 POT 无恶意下限 / 受保护非对称 POT / 受保护 POT+回滚`；源域另测对称受保护版本。M1 相对无保护版本 PR-AUC 至少 `+0.002`；非对称相对对称至少 `+0.002` 或在 PR-AUC 近似不变时显著改善预算/错误传输；M2 在源伪迁移有害网格回滚率至少 80%、误回滚不超过 20%。

详见：[方案设计](transfer-learning/TL1-稀有恶意质量保护的非对称部分最优传输与无标签回滚-方案设计.md)；[快速消融](transfer-learning/TL1-稀有恶意质量保护的非对称部分最优传输与无标签回滚-快速消融.md)。

## 4. TL2：XGBoost 锚定的有界 RWKV 残差

### 两个独立机制

1. **M1 排序机制**：RWKV 不重学主分类器，只从 XGBoost 叶编号和分数学习交叉拟合残差；最终分数始终含冻结树锚。
2. **M2 信任域**：以双曲正切限制残差幅度，并用源高间隔样本对排序保持损失约束翻转；只允许锚近并列区域发生较多重排。

### 理论来源与缺陷响应

- RWKV 和树叶表示、残差学习、成对排序约束都已有先例，均不能单独声称原创。
- 真实 Q0 表明独立小序列模型只有 XGBoost 的约一半 PR-AUC，候选 B 的时间机制还会恶化排序。因此 TL2 把树设为不可移除主预测器，RWKV 只做有界局部修正；不再使用物理时间、频谱或角色分离状态作为主机制。
- 窄边界是“跨年低基率攻击排序中，树叶强锚下可审计的 RWKV 局部残差和顺序翻转预算”。

### 最小可证伪矩阵与门槛

`XGBoost / 独立 RWKV / XGBoost+无界残差 / XGBoost+幅度界 / XGBoost+幅度与顺序界 / 序列打乱`。完整方案总体门槛同上；M1 相对 XGBoost 至少 `+0.005`；M2 相对无界残差保护至少 `0.002` PR-AUC 或显著减少高间隔错误翻转且 PR-AUC 下降不超过 `0.001`。打乱无影响则删去 RWKV 序列主张。

详见：[方案设计](transfer-learning/TL2-XGBoost锚定的有界RWKV残差迁移-方案设计.md)；[快速消融](transfer-learning/TL2-XGBoost锚定的有界RWKV残差迁移-快速消融.md)。

## 5. TL3：恶意方向保护的目标谱分类头修正

### 两个独立机制

1. **M1 目标谱头**：在 XGBoost 叶稀疏表示的高保真线性代理上，惩罚目标前缀预测落入低支持谱子空间。
2. **M2 恶意方向保护**：在源恶意与困难良性样本对上保留排序间隔，防止目标谱投影把稀有恶意方向作为低方差噪声删除。

### 理论来源与缺陷响应

- 标签对齐正则提供分类头谱适应起点，但原实验使用目标标签选正则强度；本任务必须仅由 LSPR23 伪迁移预注册。
- 源恶意方向可能位于目标低奇异值子空间；普通谱校正和纯熵/低秩约束会把它抹除。
- 纯温度、阈值或全局单调变换不改变 PR-AUC/严格前 K 排序，直接淘汰。
- 窄边界是“无目标标签选型、XGBoost 叶代理、目标谱适应与源恶意方向约束的非单调排序修正”。

### 最小可证伪矩阵与门槛

`XGBoost / 叶线性代理 / 仅目标谱 / 仅恶意方向 / 完整组合 / 单调校准负对照`。代理源验证 PR-AUC 至少保留 XGBoost 的 98%；完整方案总体门槛同上；M1/M2 各相对对应消融至少 `+0.002`。若目标排序与 XGBoost 完全一致或只是单调校准，立即淘汰。

详见：[方案设计](transfer-learning/TL3-恶意方向保护的目标谱分类头校正-方案设计.md)；[快速消融](transfer-learning/TL3-恶意方向保护的目标谱分类头校正-快速消融.md)。
