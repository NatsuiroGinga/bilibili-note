# TL1 快速消融：恶意质量保护非对称 POT 与无标签回滚

- **状态**：种子 42 Q0，实验待证
- **数据**：LSPR23 源训练/验证，LSPR24 前 10% 无标签前缀、随后 70% 开发评价；最后 20% 禁入
- **实现合同**：[跨年度泛化任务方案册](../任务方案册-跨年度泛化-LSPR23到LSPR24.md)

## 1. 单一问题

检验普通传输是否因多数良性质量和支持不重叠破坏恶意排序，以及“恶意质量下限”和“无标签回滚”是否分别提供可观测贡献。Q0 不用于论文效果主张。

## 2. 冻结变体

| 变体 | 质量 | 非对称 | 恶意下限 | 回滚 | 作用 |
| --- | --- | --- | --- | --- | --- |
| `B0_XGB_ANCHOR` | 无 | 无 | 无 | 无 | 主锚 |
| `U1_FULL_OT` | 1.0 | 否 | 无 | 无 | 普通全量 OT |
| `U2_ASYM_POT_NO_FLOOR` | 部分 | 是 | 无 | 无 | 去 M1 质量保护 |
| `M1_PROTECTED_ASYM_POT` | 部分 | 是 | 有 | 无 | M1 |
| `M1_M2_SAFE_ROLLBACK` | 部分 | 是 | 有 | 有 | 完整方案 |
| `D1_PROTECTED_SYMMETRIC` | 部分 | 否 | 有 | 无 | 非对称独立诊断 |

`D1` 与其余概率同批封存，但不得提供额外目标调参机会。

## 3. 源域预注册

- LSPR23 源验证按时间前/后半及四连续块轮换构造伪前缀/伪开发。
- 网格：`m={0.6,0.8}`、`epsilon={0.03,0.10}`、`tau_s/tau_t={2,4}`、`rho_plus={0.5,0.8}`。
- 先剔除恶意质量松弛超 5% 的配置，再最大化伪迁移 PR-AUC 中位数；并列按最坏预算召回、较小质量和更强正则依次裁决。
- 有害网格：无恶意下限、交换非对称方向、全量 OT、放大修正。M2 阈值只从该源域网格学习。
- 胜出配置与门禁在读取目标前缀前哈希封存。

## 4. 执行顺序与标签隔离

1. 只读审计缓存、锚概率、哈希和 `final_accessed=false`。
2. 以共享参数和成员、`tree_method="hist", device="cuda"` 源域拟合 XGBoost；先用确定性最小子集真实拟合/预测证明 CUDA 生效并记录设备/显存/耗时，不允许 CPU 回退；对共享 CPU 锚复现 Spearman=`1`、最大绝对差 `≤1e-6`。
3. 完成源域预注册，发布选择/门禁收据。
4. 只读目标前缀，冻结耦合和回滚决定。
5. 为六变体生成目标开发概率、样本顺序和哈希；标签保持关闭。
6. 全部封存通过后一次性连接目标开发标签并评价。

任何变体在打开标签前失败，其他已封存概率仍保留；不得先看完成变体指标再修失败变体。

## 5. 指标与可观测量

- PR-AUC；每百万 100/1000/10000 告警召回；恶意 F1、宏 F1、Brier、ECE。
- 与锚的 Spearman、排序翻转率、Top-K Jaccard、提升/压低数。
- 总/恶意传输质量、松弛、未匹配质量、耦合熵/集中度、恶意有效原型数。
- 前缀分半稳定性、门禁触发率/原因、有害网格回滚率和误回滚率。
- 训练、适应、推理时间，峰值内存/显存，矩阵规模。

## 6. 机械裁决

### 整体

- 晋级：完整方案 PR-AUC `≥0.043902589823969644`；三个预算至少两项不低于锚、任一下降不超过 `0.002`、至少一项提升 `0.005`；输出非单调改变排序。
- 弱信号：严格高于锚但不足 `+0.005`，只允许记“弱正信号/不晋级”。
- 不晋级：不高于锚，或预算超门槛退化。

### M1/M2

- 恶意质量下限：`M1-U2 ≥0.002` PR-AUC 且松弛 `≤5%`。
- 非对称：`M1-D1 ≥0.002`；或 PR-AUC 差在 `[-0.001,0.002)` 内但预算/错误传输达到预注册改善。
- M2：源有害网格回滚率 `≥80%`、误回滚 `≤20%`、平均遗憾相对永不回滚降低 `≥50%`。
- 自然目标上 `M1+M2=M1` 允许；不得伪造组合增益要求。
