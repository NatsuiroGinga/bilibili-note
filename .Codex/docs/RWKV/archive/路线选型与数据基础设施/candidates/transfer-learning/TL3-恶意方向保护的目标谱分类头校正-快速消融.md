## 2. 冻结与标签隔离

- 叶代理、困难对、秩、谱正则和方向权重仅由 LSPR23 时间伪迁移选择。
- 目标前缀只构造谱；不得打开标签、比较多个秩或早停。
- 所有目标开发概率、样本顺序、排序变化先封存，随后一次性评价。

## 3. 前置门禁

- 源验证代理 PR-AUC/XGBoost `≥0.98`。
- 无标签目标预测相对 XGBoost Spearman `≥0.95`，三个预算 Top-K Jaccard `≥0.90`。
- 不满足即不运行谱适应。目标评价后若代理 PR-AUC 低于 XGBoost 的 90%，整条路线停止。

## 4. 指标与机制诊断

- PR-AUC、三预算召回、恶意/宏 F1、Brier、ECE。
- 谱有效秩/谱隙、恶意方向投影、源困难对违反率。
- 相对锚的 Spearman、翻转率、Top-K 替换。
- 单调校准的 PR-AUC和严格 Top-K 必须与其输入分数完全一致；不一致先查实现/样本顺序。

## 5. 裁决

- 完整方案 PR-AUC `≥0.043902589823969644` 且预算不退化才申请正式验证。
- `FULL-M2_ONLY ≥0.002` 检验 M1；`FULL-M1_ONLY ≥0.002` 检验 M2。
- 若完整组合不超过最佳单机制，不能声称协同；可保留真正有独立增益的单机制，但章级候选不晋级。
- 排序不变、只改变校准/阈值、代理失真、恶意方向被谱尾抑制或使用目标标签选参：淘汰或判实验无效。
