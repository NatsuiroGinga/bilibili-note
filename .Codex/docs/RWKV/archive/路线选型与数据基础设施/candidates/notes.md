# 研究笔记：RWKV 其他章级候选

## 证据纪律

- 全文证据只证明任务难度、机制来源、既有方法边界和实验设计依据。
- 所有候选均标记为“待实验”，不得从文献直接推断在 LSPR23→LSPR24 或 LSPR24 开发区有效。
- LSPR24 最终 20% 不读取、不统计、不用于字段、阈值、候选或超参数选择。

## 已确认任务事实

- Dijk 等（2026）在统一 LSPR23→LSPR24 协议中报告，同年选优 XGBoost、GRU、Transformer 的平均精确率保留率分别为 24.16%、17.61%、7.45%；2-IP 的跨年中位退化最小。
- Leoste（2025）报告 LSPR23 训练、LSPR24 直接评价时，一维卷积神经网络和随机森林最佳 F1 均约 18.4%。
- LSPR24 同年开发二分类的现有字段注意力 Transformer 已接近饱和，因此跨年任务更有诊断空间，但这不预设任何候选会成功。

## 待核验机制族

- RWKV-7 广义 Delta 状态、动态状态演化与状态有界性。
- GoldFinch 混合注意力与固定状态容量补偿。
- RADLADS 的注意力到线性注意力蒸馏。
- FRWKV／FRWKV+ 的频域分支、信任门与周期校正。
- RWKV-TS／多尺度 RWKV 的尺度分解与任务提示。
- RWKV-8 ROSA 的精确重复匹配能力（仅官方仓库设计与实现证据）。
- 网络入侵检测跨数据集泛化、评测泄漏与增量检测证据。

## 已核验机制证据

- **RWKV-7**：Peng 等（2025）式（15）—（17）提供向量门控广义 Delta 矩阵状态；证据范围限于架构、复杂度与语言／合成任务。
- **GoldFinch／RWKV-X**：少量全注意力或 Top-k 稀疏注意力可补固定状态的精确检索缺口，但短序列是否需要该能力必须实验裁决；混合机制还可能损害长度外推或增加实际延迟。
- **RADLADS**：逐层隐状态对齐再做输出蒸馏是把注意力骨干转换为 RWKV 状态核的可行流程；跳过逐层对齐的负结果支持该步骤不可省，但没有流量或长上下文效果证据。
- **FRWKV／FRWKV+**：频谱双分支与 RWKV-7 式状态可组合；零初始化、信任门控、幅度上限 `0.20` 的残差校正提供保守注入模板。全部效果来自时间序列预测，不能外推为检测收益。
- **预训练多尺度 RWKV-GCN**：通道独立掩码重建后再引入跨变量图的两阶段顺序，用于避免过早依赖伪相关；其网络安全迁移仍待验证。
- **RWKV-TS+**：有效历史并非越长越好；论文最优批大小不是最大值，且部分任务劣于 RWKV-TS。这与本项目长历史收益反转相容，但不构成因果证明。
- **ROSA／RWKV-8**：只有官方仓库设计和实现，不是同行评议论文。可作为可实验机制来源，不能作为理论效果定律。
- **Dijk 等（2026）**：2-IP 不依赖资产身份输入，最长 128 流；其跨年中位退化最小，但所有构造的跨年中位差距仍为负。
- **Cantone 等（2024）与 Sweet Danger（2025）**：随机同域高分不能替代跨域评价；必须按父组／时间隔离、保持自然测试分布并共享信息预算。
- **Gibbs 与 Candès（2021）**：自适应共形只保证长期平均错覆盖；本任务不把它误写成目标年度逐点或条件保证。

## 冻结候选池

1. **源域解耦掩码预训练与可信字段图**：解决跨年标签稀缺和字段伪相关两个问题。
2. **连续时间频谱状态与有界信任融合**：解决不规则时间间隔和频谱证据失真两个问题。
3. **源域时间环境稳健状态与最坏环境告警校准**：解决源年度时间捷径和固定阈值脆弱两个问题。
4. **行为后缀记忆与正常预测残差协同检测**：解决重复攻击模式精确召回和非重复异常发现两个问题。

四项均使用 `LSPR23→LSPR24` 开发协议；若跨年合同未通过共同字段审计，则只允许在 LSPR24 前 80% 内执行同构的时间前向开发实验，不得读取最终 20%。
