## 1. 最重要的结论：有界缓存不可用于任何跨年度绝对指标主张

同一套 XGBoost 配置（800 树 / lr 0.05 / depth 8 / seed 42），只换数据管线：

| 管线 | 训练行数 | 评价池 | 评价 π | **逐流 AP** |
| --- | ---: | ---: | ---: | ---: |
| 有界缓存 `lspr23-lspr24-bounded-quick-q0-v1` | `142,069` | `261,839` | `0.0077147` | **`0.0377272248`** |
| **全量** | **`16,353,511`** | **`20,227,356`** | `0.0257073` | **`0.2244424863`** |
| Dijk 2026 表 5 参照 | 未报告 | 未报告 | — | `0.2416` |

**AP 相差 `5.95` 倍。** 缓存只用了 LSPR23 的 `0.87%` 训练行与 LSPR24 全量的 `1.29%`。

### 1.1 连带作废的历史结论

以下结论**全部建立在有界缓存上**，其绝对数值不可用于跨年度主张：

- 「跨年度是退化区，19 个自研神经变体 + 7 个文献配置全部低于树模型」
- 共享 XGBoost 跨年度锚 `0.038902589823969644`
- C12（最佳 K-DELTA `0.016977277`）、R1（最佳 GroupDRO `0.012877901`）、候选 B（最佳离散 `0.019205959`）、TL1（最高 `0.038401154`）的**绝对 AP**
- 主进程 2026-08-12 曾据缓存值推出「我方 lift 4.89 高于 Dijk 的 3.42」——**全量实测 lift 为 `8.73`**，该推论作废

**不作废的部分**：这些候选彼此之间在同一缓存下的相对排序仍是同管线比较，但**不得跨管线与全量数值并列**。

## 2. 实体级评价：方向一主门禁通过

同一份逐流分数，实体键 = 2-IP 无向对（`χ(a,b)=sortlex{srcIP,dstIP}`，Dijk §4.1.5 p.14），
**只用于分组，不入模**。

```
逐流    AP = 0.2244424863   AUC = 0.8807393901   π = 0.0257073138
实体    47,115 个   正实体 752   π = 0.0159609467
```

| 聚合 | 实体 AP | DR@1%FPR | DR@4%FPR | DR@10%FPR |
| --- | ---: | ---: | ---: | ---: |
| max（n=1） | `0.523326` | `0.4894` | `0.7500` | `0.9348` |
| n=5 | `0.511424` | `0.4867` | `0.7460` | `0.9136` |
| n=10 | `0.491935` | `0.4468` | `0.7207` | `0.9255` |
| **n=100** | **`0.547484`** | `0.4801` | **`0.8324`** | `0.9202` |

**预注册判据**（方案册 §6.2）：实体级召回 @ ≤`4%` 实体 FPR ≥ `0.50` → 成立；< `0.20` → 作废。
**实测 `0.7207`–`0.8324`，主门禁通过。**

要点：
1. 同一份分数，只换评价单元，**AP 从 `0.2244` 升到 `0.5233`–`0.5475`（2.3–2.4 倍）**。
2. **`n=100` 聚合最优**，不是 max 聚合。与 Gehri 2023 采用阈值 `n∈{1,5,10,100}` 的做法一致。
3. `752` 个正实体，统计上可判。此前有界缓存下只有 `14` 个正实体，召回最小刻度 `1/14=0.0714`，
   无法区分 `0.50` 与 `0.20` 两个阈值——**该阻断已解除**。

## 3. 论文自身的序列建模负结果（对方向选择的直接影响）

表 5（印刷 p.30）全表仅 2 行、13 个数值格，原样：

```
LSPR23→24 | XGB 1.0000 → 0.2416 (-0.7584) | GRU SesH 0.9984 → 0.1758 (-0.8226) | Trans 2-H  longf. 0.9964 → 0.0742 (-0.9222)
LSPR24→25 | XGB 0.9923 → 0.7666 (-0.2257) | GRU 2-IP 0.7577 → 0.0097 (-0.7480) | Trans 2-H  bigbird 0.9897 → 0.7291 (-0.2607)
```

表 5 标题末句：「**XGBoost does not use sequence construction.**」

**在 LSPR23→24 上，论文自己的八种序列构造中最好的（SesH+GRU，`0.1758`）比不用序列的逐流 XGBoost（`0.2416`）低 `27.2%`。**

这与本课题四个 P0 的失败方向一致，提示序列建模在该迁移上本身不占优——**但本课题的四次失败是在有界缓存上跑的，两者不能直接合并为同一证据**。
