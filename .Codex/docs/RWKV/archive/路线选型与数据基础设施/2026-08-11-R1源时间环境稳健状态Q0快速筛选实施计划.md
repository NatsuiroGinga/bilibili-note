# R1 源时间环境稳健状态 Q0 快速筛选实施计划

> **代理实现要求：** 必须使用 `superpowers:subagent-driven-development` 执行；实现代理读取本计划作为唯一需求源，并遵守 `daily-coding`。本任务不创建或运行人工测试，只执行一次 Python 编译、一次 Shell 语法检查和真实 Q0 实验。

**目标：** 在冻结的 LSPR23→LSPR24 Q0 开发合同上，检验源时间环境稳定－私有状态分解与最坏源环境告警校准是否分别产生可观测增益。

**架构：** 复用 C12 阶段 A v2 的 Q0 Python 缓存、冻结接收器检查点和 192 维因果 Transformer 表示，不重新扫描原始数据。环境侧车只读取不入模的 `sequence_id`、`group_key_ref`、`first_available_ns` 和 `last_available_ns`；三个训练任务共享只读表示并使用独立输出与 SwanLab 身份并行运行。B0 与 M2共享连续分数，M1 与 M1+M2共享连续分数，因此四格评价只需要 B0、M1 两个主模型训练；另加同预算 GroupDRO 作为源多环境强基线。

**技术栈：** Python 3.12、PyTorch、NumPy、PyArrow、scikit-learn、SwanLab、Bash、C56 单张 RTX 5090。

## 全局约束

- 仅使用 `runs/data-prepared/lspr23-lspr24-bounded-quick-q0-v1` 和阶段 A v2 冻结表示；禁止访问目标前缀标签和最终 20%。
- 本轮固定 `seed=42`、`epochs=4`、序列批量 `16`、最大序列长度 `128`、隐藏维 `192`，结果均写 `screening_only=true`、`formal_paper_evidence=false`、`final_accessed=false`。
- 时间环境只称为“按 `available_ns` 划分的源时间区间”，不得称为恢复了物化器的严格总序；`start_ns` 和 `source_row_index` 未发布。
- 父组按首次出现时刻整体分配，任何 `group_key_ref` 不得跨环境或跨源验证／校准子区；环境编号、时间和分组标识不得输入模型。
- LSPR24 目标开发标签只在概率封存后由独立评价入口连接；目标标签不得用于环境划分、训练、阈值或超参数选择。
- 预计每个模型峰值显存低于 2 GiB。B0、M1、GroupDRO 在独立输出、独立 SwanLab 运行且三者总保守峰值低于 8 GiB 时默认并行；并发耗时不得作为单模型效率结论。
- 运行目录、状态、日志、检查点、概率、环境收据和指标均须持久化；超过 20 分钟的训练每 20 步或 10 分钟保存可恢复检查点。
- 不执行格式化、人工夹具、单元测试、全仓检查或重复复审。只有划分、标签、指标、因果时序、预算、公平性或不可运行问题允许暂停。

## 固定实验合同

### 源时间环境

1. 从 Q0 `sequence-manifest.parquet` 读取 `source-train` 与 `source-validation` 的完整入选序列。
2. 对每个角色按 `group_key_ref` 聚合父组的最早／最晚 `available_ns`。
3. `source-train` 按父组首次出现时刻的四分位边界形成 `E=4`；同一时间戳不得切开，父组整体归入其首次出现块。
4. `source-validation` 先按父组首次出现时刻的中位边界拆为前半“源验证”和后半“源校准”，再分别按父组首次出现时刻四分位形成 `E=4`。
5. 环境收据记录边界、父组数、序列数、流数、良恶性流数、良恶性序列数、跨界父组处理、成员哈希和标签是否参与选择。边界与成员选择必须满足 `labels_used_for_partition=false`。
6. 若 `source-train` 少于两个环境同时包含良恶两类，或源校准任一环境没有良性样本，失败停止并将结论记为“R1 数据可观测性门禁失败”，不得改用标签选择边界。

### 模型与预算

- **接收因果 Transformer（R1-B0）**：冻结接收器表示加参数匹配分类头，不使用环境损失。
- **源时间环境 GroupDRO（R1-GROUPDRO）**：与 R1-B0 相同模型和训练步数，只把源环境风险用指数权重聚合；它是强基线，不是候选机制。
- **稳定－私有状态分解（R1-M1）**：稳定 RWKV-7 式状态进入分类头；四个环境私有状态只参与重构。联合目标为分类、重构、稳定／私有交叉协方差、稳定状态环境均值／协方差一致性和有效环境类间间隔。
- 三模型使用同一环境×标签序列采样清单、相同批次、轮数、优化器、学习率、早停规则和总优化步；每轮记录各环境、各标签池规模及实际抽取量。
- 固定 M1 权重：`lambda_rec=0.1`、`lambda_diff=0.01`、`lambda_inv=0.01`、`lambda_margin=0.05`、`margin=1.0`。损失先按元素均值归一化再加权，逐项记录原始值和加权值。

### 校准与评价

- 源校准良性分数采用有限样本同分数组分位数；主 `alpha=0.001`，并预注册只读敏感性网格 `{0.0001, 0.0005, 0.001, 0.005}`。
- pooled 阈值从全部源校准良性分数产生；M2 阈值是四个源校准环境阈值的最大值。
- B0 与 M2 的目标连续概率及平均精确率必须逐元素／逐字节一致；M1 与 M1+M2同理。不一致直接判评价实现无效。
- 连续分数指标：目标开发平均精确率、平均精确率／恶意基率、Brier 分数和期望校准误差。
- 阈值指标：每个源校准环境假阳性率、最坏源环境假阳性率、目标开发每百万流假阳性、恶意召回、恶意 F1、固定召回率下假阳性和固定告警预算召回。
- 表征审计：在源训练表示上拟合环境探针，在源验证表示上报告环境宏平均一对多 AUC；B0 使用冻结接收器表示，M1 使用稳定状态表示。探针只作审计，不反向训练主模型。

## 快速裁决门槛

- M1 相对 B0 的目标平均精确率增加至少 `0.010`，且 `M1−GroupDRO` 不低于 `-0.002`；环境探针 AUC 至少下降 `0.05`，同时目标平均精确率不得下降。
- M2 相对 pooled 阈值的最坏源环境假阳性率下降至少 `20%`，目标每百万流假阳性下降至少 `10%`，恶意召回绝对下降不超过 `5` 个百分点。
- M1+M2 相对 M1 的固定告警预算召回增加至少 `3` 个百分点，或固定召回下假阳性下降至少 `10%`。
- 完整组合未超过最强单机制、仅靠极端阈值降低误报、或任何主模型恶意召回仍为零时，R1 不晋级；本轮只记 Q0 弱证据，不写成正式证伪。
