# LSPR24 统一基线路径解析修复计划

## 根因

`dataset-manifest.json` 将制品登记为相对实验工程根目录的路径，`lspr24_screen_dataset.py` 却把所有相对路径都拼到清单所在目录，导致运行根被重复拼接。

## 唯一改动

- 修改 `src/flow_probe/lspr24_screen_dataset.py` 的制品路径解析。
- 明确支持清单目录相对路径与实验工程根目录相对路径；不得放宽到最终测试或任意外部路径。
- 不修改数据、字段、切分、模型、超参数与评价协议。

## 真实验收

1. 对真实 `dataset-manifest.json` 执行加载入口检查，确认四项登记制品均能解析且仍限制在实验工程目录内。
2. 同步唯一修改文件到 A44。
3. 使用新的唯一运行目录 `runs/baselines/lspr24-screen-tabular-seed42-v2` 重启统一基线。
4. 以真实 HGB/XGBoost 日志和指标制品作为最终验证，不运行全仓测试或格式化。
