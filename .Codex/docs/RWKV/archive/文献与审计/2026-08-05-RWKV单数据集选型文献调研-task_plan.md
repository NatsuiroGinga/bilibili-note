# RWKV 单数据集选型文献调研计划

## 目标

在不预设 UGR’16 胜出的前提下，核验 2023—2026 年长时网络安全数据集，并裁决是否存在一个数据集可同时支撑第三章长时生成式状态建模与第四章课程化早期告警决策。

## 边界

- 只读取官方数据页、原始数据论文全文、许可证和实际文件清单。
- 不下载大体量数据，不修改论文正文、恢复文档或实验代码，不启动训练。
- 区分数据采集年份、首次发布年份和后续特征重提取年份。
- 若没有候选满足全部硬门槛，明确裁决“单数据集合同不可行”，并给出最小双数据集替代。

## 阶段

- [x] 阶段一：冻结九项评价合同、硬否决项与唯一推荐规则。
- [x] 阶段二：核验 UGR’16、CESNET-TimeSeries24、GeNIS 2025、WEB-IDS23、5G-NIDD、Gotham 2025 的官方身份、全文、许可证与文件清单。
- [x] 阶段三：扩展筛选 2023—2026 同类候选并去重，记录采集与发布年份。
- [x] 阶段四：逐项建立证据矩阵，核算序列、标签、延迟、拆分、字段、基线、资源与双章适配性。
- [x] 阶段五：给出硬否决、唯一首选、次选及公式、任务单位和基线合同修改。
- [x] 阶段六：写入最终报告，检查链接、数字、允许主张与禁止主张。

## 硬门槛

1. 存在真实、连续且足够长的时间轴，可构造至少 1／4／16／32 步严格因果序列。
2. 存在可用于恶意流量或攻击状态检测的可靠标签，而非只有无标注异常。
3. 能构造二分类、多类或多标签任务，并定义事件级检测延迟与继续观察／告警决策。
4. 能实施无泄漏时间前向拆分及独立统计簇划分。
5. 字段足以定义生成式下一窗口预测，且所有基线共享相同信息预算。
6. 数据公开可得、许可明确、单机物化与单张 RTX 5090 三种子矩阵可行。
7. 单个数据集不依赖第二数据集即可同时承担第三、四章的主要论证。

## 状态

**六阶段均已完成。最终裁决为 LSPR24 条件首选；若主指标坚持真实攻击动作起点时延，则改选 ROSPaCe 并收窄研究对象。**
