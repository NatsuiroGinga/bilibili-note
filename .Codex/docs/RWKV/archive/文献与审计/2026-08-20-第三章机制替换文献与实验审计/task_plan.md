# 第三章机制替换文献与实验审计计划

## 目标

依据现有多层感知机、XGBoost、ResMLP2 与 TabM 实验，以及可定位到章节、页码或公式的全文原论文，判断 CPA、ELP 或二者组合方式是否应按骨干修订或被替换；最多保留三个可证伪候选，并允许最终结论为“没有候选值得替换”。

## 任务合同

- 研究问题：CPA 与 ELP 是否应继续作为跨骨干冻结机制，还是应按骨干适配、重组或替换？
- 预期决策：给出候选优先级、证据等级、最小实验合同及不替换条件，不实现代码、不启动实验。
- 已证病灶：ResMLP2 的 C01 实体 AP 最佳、C10 逐流 AP 最佳、C11 为破坏性组合且仅在约 2.44% FPR 以下局部占优；XGBoost 的 CPA 与 ELP 组合有效。
- 时间范围：机制奠基论文不限年份；近邻查重优先 2021 至 2026 年。
- 核心概念：因果历史聚合、在线集合编码、多示例学习池化、长度偏差、稀疏证据聚合、注意力池化、分位数或尾部池化、集成成员聚合、骨干适配。
- 纳入标准：原论文或官方源码；机制能直接映射到当前可观测量；有明确训练目标或算子；能在共同预算下构造 C00、单机制、组合消融。
- 排除标准：仅摘要、二手综述、博客；需要目标年标签选择；依赖原始 IP 或禁入身份；无法区分机制收益与额外参数/训练预算；只改名称或堆叠公式。
- 目标数量：候选文献不机械凑数；至少核验覆盖表示层、决策层和组合方式的直接近邻。最多输出三个实验候选。
- 证据强度：技术结论只依赖本地全文原件、全文笔记、原论文在线全文或官方源码。题录和摘要仅作召回线索。
- 停止条件：三个候选已具备完整实验合同，或证据不足以支持任何替换候选；近期在线查重与题录核验已完成；所有提及的有用论文均完成 raw、wiki、INDEX 与 Zotero 处理或登记明确阻塞。
- 禁止事项：不访问服务器，不触碰 Claude Code 的 TabM 运行、看板锁或实验代码，不用 LSPR24 标签选候选或调参数。

## 验收命令

- `uv run --project scripts/literature_search --locked python -m scripts.literature_search status --json`：索引必须 `stale=false` 且关键词、向量数均非零。
- `pdfinfo`、`shasum -a 256`：新增 PDF 必须可解析、页数和哈希已记录。
- `rg`：检查四份交付文档无未完成占位，候选不超过 3 个，`target-informed` 与 LSPR24 降级边界存在。
- `git diff --check --cached`：提交前检查空白与补丁格式。
- `git status --short -- <目标路径>`：只暂存独占文档、新增原件、全文笔记和 INDEX 单条入链，不夹带其他代理改动。
