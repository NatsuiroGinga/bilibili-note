## 1. 范围与问题冻结

本任务复现直接使用 LSPR 数据开展模型实验的已发表研究，不再把 `COMMON77/Q0` 桥接结果当作论文外部比较证据。研究对象分为三种，三者不得合并：

1. **论文报告实验**：以论文全文披露的成员、字段、预处理、切分、模型、训练预算和指标为准。
2. **作者后续代码示例**：以固定提交的实际源码为准，只检验该示例能否重跑；若数据规模或协议不同，不得冒充论文报告实验。
3. **本课题论文约束独立复现**：保留论文已披露机制，在本课题合法字段与统一冻结协议下重跑；所有差异逐项披露。

当前可见开发区运行统一标记：

```text
screening_only=true
formal_paper_evidence=false
formal_paper_evidence_candidate=false
final_accessed=false
```

只有方法冻结后，在正式冻结成员、合法字段、标签权限、共同预算和统一指标下以种子 `42/43/44` 重跑，并保留逐样本概率、日志、清单、哈希、资源与统计区间，才可升级为第三章正式基线。作者原始数值只用于协议复现检查；单种子、Q0、可见开发结果不得进入正式结果表。

## 5. 入口与制品合同

计划中的入口：

```bash
python -m flow_probe.lspr_published_protocol_replication audit \
  --config configs/lspr-published-protocol-replication-v1.json \
  --output-dir runs/replications/lspr-published-protocol-audit-v1

python -m flow_probe.lspr_published_protocol_replication run-visible-development \
  --cache-manifest <可见开发缓存清单> \
  --config configs/lspr-published-protocol-replication-v1.json \
  --output-dir <独立运行目录> \
  --protocol leoste-2025-rf-with-packet-iat \
  --seed 42
```

每次运行至少输出：

- `protocol_receipt.json`：协议身份、论文差异、字段、标签权限、正式证据资格。
- `status.json`：运行状态、`screening_only`、`formal_paper_evidence`、`final_accessed`。
- `probability_seal.json` 与逐样本概率：目标标签打开前的概率封存。
- `metrics.json`：源验证、目标可见开发指标和资源指标。
- SwanLab 在线运行标识；在线记录失败则整次运行失败，不伪造本地成功。

## 6. 验收与阻塞

### 开发区门禁

1. 输入清单必须逐字声明 `final_accessed=false`。
2. 输入必须只有可见开发角色；不得发现最终区角色、最终标签或最终路径。
3. 源训练变换冻结后才能评价目标；目标概率先封存，之后才连接目标可见标签。
4. 运行身份必须逐字包含 `screening_only=true`、`formal_paper_evidence=false`。
5. 作者示例身份哈希版与本课题合法字段版分目录、分名称、分表格。

### 正式第三章门禁

1. 方法、字段、成员、切分、标签权限、预算和指标预注册并冻结。
2. 种子 `42/43/44` 全部成功；概率、日志、哈希和资源收据齐全。
3. 同一正式冻结成员与统一合法字段下重跑所有纳入比较的方法。
4. 报告点估计、跨种子区间及预注册统计；不得只挑最好种子。
5. 只有该阶段运行可设 `formal_paper_evidence=true`；当前实现不提供绕过门禁的开关。
