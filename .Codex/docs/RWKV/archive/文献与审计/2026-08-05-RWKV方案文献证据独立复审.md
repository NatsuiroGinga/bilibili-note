# RWKV 方案文献证据独立复审

> 日期：2026-08-05  
> 复审对象：`.Codex/docs/2026-08-05-RWKV网络空间安全双创新点系统方案.md`  
> 范围：2023—2026 年研究为主，必要时纳入经典方法论文  
> 裁决：**修改后保留**

## 一、直接结论

现有一级全文证据足以把 RWKV 路线保留为 PINN／R2 失败后的备选课题，但**不足以按原文“长时加密流＋RWKV 状态检测与漂移校准”的措辞直接冻结选题**。保留必须同时满足四项修改：

1. **任务语义改为长时网络攻击状态检测，并服从后续数据门禁。** UGR’16 分钟特征的论文设计原则上能支持“该分钟是否含已标注攻击流”“攻击类别计数／多标签”和事件级检测延迟，不能支持逐连接恶意定位；但同日 G0 实测表明，当前已下载训练标签除近乎全阳性的 `blacklist` 外其余七类全为零，因此当前文件不能启动监督主基线。后续单数据集审计改以 LSPR24 为条件首选。若最终数据集另有可靠逐流标签，才可恢复“恶意流量检测”；若没有加密协议或密文证据，不得保留“加密流量”限定。
2. **第三章与第四章重新分工。** 第三章研究快慢递归状态和生成式下一窗口预测；第四章研究自步课程与外生轨迹上的约束最优停止。两章共享递归状态、预测分布和异常证据，但优化目标、理论对象和消融均不同。
3. **第四章主线采用监督式最优停止，不采用静态分类上的强化学习。** FIRMBOUND 提供有限时域“继续观察／告警”的直接理论框架。Decision-RWKV、CPO、COPO 只能证明存在相关序列决策方法，不能补造现有数据中不存在的动作、奖励、转移与行为覆盖。
4. **RWKV 代际与先验工作必须降格表述。** RWKV-7 有正式全文，可作为普通骨干和强基线；RWKV-8 没有可核验正式论文或冻结版本，但官方已公开两个早期测试检查点，不能再写成“没有公开权重”。PLM-NIDS、RWKV-TS、NetMamba、MambaNetBurst 均只能分别提供问题邻近或架构邻近证据，不能合并成“RWKV 已证明长时网络攻击检测有效”。

因此，方案的正确身份是：**具备充分方法学依据、具备少量直接网络安全先例、但核心组合仍待数据门禁和先导实验验证的备选研究计划**。它不是已有文献结论的简单复现，也还不是可以跳过数据审计直接训练的冻结合同。

## 二、六阶段审计结果

### 阶段一：问题与门禁冻结

复审问题覆盖 RWKV-7/8、长序列网络攻击状态、生成式下一窗口预测、课程／自步学习、约束强化学习、离线强化学习、最优停止、UGR’16 标签语义和两章创新的非重复性。核心论断只接受原始论文全文、正式数据论文、官方数据页或官方仓库；RWKV 中文生态目录只作发现工具。

### 阶段二：检索与身份核验

- 完整动态枚举 `https://www.rwkv.cn/eco/papers` 的 20 页：前 19 页各 12 项、末页 7 项，共 **235 个唯一题名**。
- 完整枚举“序列／强化”分类 4 页，共 **48 项**。
- 定向闭合 Decision-RWKV、MARWKV、RWKV 多智能体社会推理、AutoGMM-RWKV、PLM-NIDS、RWKV-TS 和异常检测邻近条目到原始入口。
- 定向检索课程、自步强化学习、约束策略、约束离线策略、早期分类与最优停止的原始论文。

### 阶段三：筛选与去重

目录中大量视觉、语言、音频和普通时序论文因任务不相干被排除。进入逐篇证据台账的核心全文为 14 篇；另以 RWKV-X、MambaNetBurst、AgentDojo 和 `arXiv:2607.02292` 作边界全文。AutoGMM-RWKV 与 MARWKV 因公开全文访问受阻，只能进入待补清单，未用于核心论断。

### 阶段四：全文核验

核心全文均记录到页码、章节、公式或表格；关键限制回到原 PDF 复核。新取得的 8 份合法全文已保存到 `raw/papers/`，并在 `wiki/papers/rwkv/` 或 `wiki/papers/datasets/` 建立来源笔记。

### 阶段五：综合与差距识别

文献可以分别支撑递归状态、时间序列建模、网络流量相邻应用、训练课程和有限时域最优停止；**没有一篇全文同时验证“快慢 RWKV 状态＋生成式网络预测＋自步课程＋约束最优停止”**。这一缺口保留了组合创新空间，也意味着效果、可识别性和资源可行性必须由本课题实证。

### 阶段六：裁决

裁决为**修改后保留**。未满足后文 P0 门禁前，不得把方案写成冻结题目、已证明创新或已验证性能。

## 四、现有方案引用与事实核验

### 4.1 已纠正或应纠正

1. 原方案第 63 行称 RWKV-7 PDF 尚未完成，因此未计入全文。当前已取得并核验正式全文，原件为 `raw/papers/rwkv/2025_Peng_RWKV7_Goose_Expressive_Dynamic_State_Evolution.pdf`。该状态应更新，但不能把语言证据升级成安全证据。
2. RWKV-8 仍无可核验正式论文、正式版本标签或冻结代码发布。官方 Hugging Face 仓库 `BlinkDL/rwkv-8-pile` 已公开两个 Apache-2.0 的 `.pth`：1.26 GB 的 `rc00` 与 2.51 GB 的 `rc00-hybrid`，可用提交 `961be5c6a7544e694b9feac5cbce29ad497d743c` 固定；但模型卡明确称其为“早期测试版本”，运行说明指向持续变化的主仓代码，缺少论文级训练与评测合同。因此它们只能称“可下载早期测试检查点”，不能称冻结、论文级可复现基座。
3. PLM-NIDS 是目前最直接的 RWKV 网络入侵检测全文，但它使用 RWKV-4、CIC-IDS-2017、单数据集和有限基线。其“无需深度包检测”不能升级为“已验证现代 TLS／QUIC 加密恶意检测”。
4. RWKV-TS 能证明 RWKV 进入一般时间序列异常检测，但表 7 中 TimesNet 的平均 F1 更高；不得写“RWKV 在异常检测上达到普遍最优”。
5. NetMamba 与 MambaNetBurst 均为 Mamba 系列，不是 RWKV 直接证据。它们适合定义同输入、同预算强基线和字节／序列建模邻近性。
6. RWKV 中文生态目录是发现入口，不是全文证据。目录摘要、分类和发布日期都必须闭合到 arXiv、会议、期刊或机构仓储原件。

### 4.2 `arXiv:2607.02292` 的边界

Duque 等，2026，*One More Time: Revisiting Neural Quantum States from a Reinforcement Learning Perspective* 使用 RWKV-7 1.5B 作为横场伊辛模型的自回归神经量子态，并提出受 PPO 启发的概率比与相位增量裁剪。正文第 2.1、3、5.5 节与附录 C.3、C.4、D.8只支持量子态优化；附录 C.4明确依赖共同支撑、有界和局部假设，不给出全局收敛。该文不能证明静态流量适合 PPO／CPO，也不能证明课程、多尺度网络状态或恶意流量检测。

### 4.3 RWKV-7 官方状态更新与外抽边界

Goose 论文第 3 节和式（15）—（17）采用行向量约定。每个头先归一化移除键，再更新矩阵快权状态：

\[
\widehat{\kappa}_t=\frac{\kappa_t}{\lVert\kappa_t\rVert_2},\qquad S_0=0,
\]

\[
S_t=S_{t-1}\left[\operatorname{diag}(w_t)-\widehat{\kappa}_t^{\top}
\left(a_t\odot\widehat{\kappa}_t\right)\right]
+v_t^{\top}\widetilde{k}_t.
\]

其中 `w_t` 是数据依赖逐通道衰减，`a_t` 是逐通道上下文学习率，`κ̂_t` 与 `k̃_t` 分别承担从状态移除和写入的键，`v_t` 写入值。最小可外抽的“状态演化核”必须保留每头矩阵状态以及 `w、κ̂、a、v、k̃` 的生成和上述对角加秩一更新。若声称完整 RWKV-7 模块，还必须保留输入投影／令牌移位、`r_t` 读出、当前 token bonus、归一化、`g_t` 输出门、PreLN 和残差路径。官方仓库 README 还明确提醒，RWKV-7 的初始化、权重衰减和参数组学习率是整体实现的一部分，不存在可任意拔出的简单官方层。只抽取双时间尺度衰减或指数移动平均时，应称“受 RWKV-7 启发的门控快权模块”，不得称官方 RWKV-7 层。

### 4.4 RWKV-8 当前证据状态

截至 2026-08-05，官方主仓 `BlinkDL/RWKV-LM` 的远端 `HEAD` 为 `952102498e9ed367ea0a59ee64106916d474d30f`；顶层 README 仍称当前代际为 RWKV-7。`RWKV-8.md` 标题是“Improving RNNs (RWKV-8 and beyond)”，末段称作者仍在探索；`RWKV-v8/` 包含 ROSA 演示和小规模实验脚本，远端标签中没有 RWKV-8／Heron 正式标签。故当前状态是“探索文档＋未冻结演示代码＋可固定下载的早期测试检查点”，不是“正式论文＋冻结实现＋完整可复现权重合同”。

## 五、UGR’16：非加密不是硬否决，标签粒度才是边界

### 允许措辞

- “长时网络攻击状态检测”。
- “网络异常／攻击承载时间窗检测”。
- “基于每分钟 134 维统计量预测下一窗口分布，并判断该窗口是否含已标注攻击流”。
- “八类攻击计数／多标签状态预测”。
- 若回到原始逐流标签，可写“攻击流与背景流分类”，同时声明 background 可能含未识别攻击。

### 禁止措辞

- “分钟级逐流恶意流量定位”。
- “所有阳性分钟中的每条流均为恶意流”。
- “背景流量是无污染正常真值”。
- “UGR’16v3 是 2025 年采集的现代网络流量”。
- 未核验协议构成前写“加密恶意流量检测”。

### 实验合同

分钟序列只能在连续片段内构造，不能跨越版本清理形成的缺失分钟。数据须按时间前向划分；所有标准化、难度估计、阈值和课程调度只在训练折内拟合。攻击事件由连续同类阳性分钟或原始攻击时间表预注册，报告事件召回、首次告警延迟、误报时间率和风险—延迟曲线。

### 同日 G0 后续裁决

本地全量统计进一步证明“论文中的标签定义可成立”不等于“当前训练文件可用于监督实验”：六版训练区除 `blacklist` 外其余七类攻击计数均为零，`blacklist` 阳性率约 96% 至 100%。因此当前 UGR’16 训练区对监督分类为 **NO-GO**，只保留正常密度建模与序列物化价值。详细证据见 `.Codex/docs/RWKV/2026-08-05-UGR16-G0数据门禁审计.md`。单数据集替代裁决见 `.Codex/docs/RWKV/2026-08-05-RWKV单数据集选型文献调研.md`：广义网络流任务以 LSPR24 为条件首选；若坚持真实攻击动作起点时延，则改用 ROSPaCe 并收窄研究对象。

## 六、第四章方法裁决

| 候选 | 裁决 | 理由与适用条件 |
|---|---|---|
| 固定窗口静态分类＋强化学习 | **否决** | 没有动作依赖转移、奖励和行为策略，强化学习问题不可识别 |
| 外生轨迹＋监督式最优停止 | **主线采用** | FIRMBOUND 直接覆盖有限时域、继续风险、停止风险与误分类／等待成本 |
| 自步课程＋监督式最优停止 | **主线采用** | 课程只控制训练上下文分布，停止策略只读取当前及历史观测；职责可分离并做消融 |
| 动作集合 `{继续观察, 告警}` | **主线采用** | 两个动作均有可定义代价，且不需要虚构流量因果反馈 |
| 动作集合 `{继续观察, 告警, 拒识}` | **条件采用** | 必须预先定义拒识后的人工升级、覆盖率、延迟和代价；否则“拒识”无可评价后果 |
| CPO 在线约束策略 | **条件采用** | 仅当有模拟器或真实部署动作改变后续状态，并可从当前策略采样轨迹 |
| COPO 离线约束策略 | **条件采用** | 仅当日志真实包含 `s,a,r,s'`、成本预算和行为覆盖 |
| 上下文赌博机 | **否决主线** | 不能表达继续观察后的多步信息价值；最多用于无状态阈值或模型选择旁支 |
| Decision-RWKV | **条件基线** | 有真实回报—状态—动作离线轨迹时可用；不能替代当前监督最优停止 |

### 推荐公式骨架

第三章输出递归状态和下一窗口类条件密度：

\[
z_t = F_{\text{RWKV}}(z_{t-1}, x_t),\qquad
p_\theta(x_{t+1}\mid z_t, y),\qquad
\ell_t=\log\frac{p_\theta(x_{1:t}\mid y=1)}{p_\theta(x_{1:t}\mid y=0)}.
\]

第四章只在训练期改变上下文分布 `q_k(c)`，最终恢复目标分布 `p(c)`；测试期以风险决定是否继续：

\[
R_t^{\text{stop}}=\min_{d\in\{0,1\}}\sum_y L(d,y)P(y\mid x_{1:t}),
\]

\[
R_t^{\text{cont}}=c_{\text{wait}}+\mathbb E[R_{t+1}^*\mid x_{1:t}],\qquad
\tau=\inf\{t:R_t^{\text{stop}}\le R_t^{\text{cont}}\}.
\]

若需要误报约束，应在独立校准集上选取满足上置信界的阈值，而不是把 CPO 名称贴到监督公式上。

## 七、两项创新是否系统连接且不重复

### 创新一：修改后保留

**快慢递归状态＋生成式下一窗口预测。** 快状态负责短时突发，慢状态负责周期背景与长时上下文；生成头预测下一窗口的类条件分布，异常分数来自预测证据而不是仅加一个判别头。该组合尚无直接全文验证，属于可检验的新假设。

### 创新二：修改后保留

**自步课程＋外生轨迹约束最优停止。** 课程按历史长度、攻击信噪比、背景负载或类别稀有度调整训练顺序，最后回到完整目标分布；停止器权衡误报、漏报和等待成本，决定继续或告警。

### 系统连接

创新一输出 `z_t`、预测分布和序贯证据；创新二消费这些量并决定何时证据充分。创新一回答“怎样形成可更新的长时状态与预测”，创新二回答“怎样训练难度与何时作出告警”。两者共享接口但不共享核心目标，因而连接而不重复。

### 防止伪创新的必要对照

- 普通单状态 RWKV 对快慢状态。
- 纯判别头对生成式下一窗口头。
- 固定训练顺序对课程；外生课程对模型自步课程。
- 固定阈值对监督最优停止。
- 无课程最优停止、仅课程固定阈值、完整组合三者必须同时报告。
- HGB／XGBoost、GRU、因果 Transformer、TimesNet、Mamba、普通 RWKV 共享相同历史和字段预算。

## 八、理论与实验门禁

1. **标签门禁：** 明确每个标签属于逐流、逐包、逐分钟还是事件；负类是否只是 background。
2. **序列门禁：** 只用过去和当前窗口；按实体、时间和攻击批次切分后再构造序列，不跨缺口。
3. **生成门禁：** 下一窗口预测必须优于持久性、季节性、GRU、因果 Transformer、TimesNet、Mamba 和普通 RWKV；报告负对数似然、校准和分布漂移。
4. **长历史门禁：** 长度 4／16／32 必须至少在预注册困难面板上优于长度 1，否则长时主张否决。
5. **课程门禁：** 在相同样本、训练步数和计算预算下，完整课程必须优于随机顺序；难度不能使用测试标签或未来窗口。
6. **停止门禁：** 固定阈值、固定时刻和 FIRMBOUND 类停止器比较；报告事件召回、误报时间率、首次告警延迟、贝叶斯风险及三种子置信区间。
7. **约束门禁：** 误报预算必须在独立校准集上满足置信上界；若测试漂移导致违反，报告失败，不宣称理论仍有效。
8. **资源门禁：** 单张 RTX 5090 记录峰值显存、训练时长、每窗口吞吐和状态持久化成本；渐近复杂度不得代替实测。
