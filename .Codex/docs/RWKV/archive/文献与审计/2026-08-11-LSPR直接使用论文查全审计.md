# LSPR23／LSPR24／LSPR25 直接使用论文查全审计

## 结论

**不能声称已经“绝对搜集全”。** 文献数据库存在收录延迟、灰色文献和未公开稿件，LSPR25 又是 2026 年才公开且文件受限。能够负责地给出的结论是：

> 截至 **2026-08-11**，在已列明的数据库、插件、正式载体、数据 DOI、引用链、作者链、大学仓储和别名查询范围内，共确认 **4 个直接处理 LSPR23／24／25 数据的研究工作**。其中 **3 个含模型训练或评价实验**，另 **1 个是 LSPR24 发布与全量描述性分析论文**。两轮反向核查没有发现第 5 个可由全文或正式题录支持的直接使用工作。

这 4 个工作是：

1. Dijk 等 2024：LSPR23 数据发布、Suricata 评价和随机森林复现。
2. Dijk 等 2025：LSPR24 发布与数据活动统计；无机器学习模型评价。
3. Leoste 2025：LSPR23 训练、LSPR24 零重训测试。
4. Dijk 等 2026：LSPR23／LSPR24／LSPR25 的序列构造、同年和跨年评价。

因此，如果“使用论文”严格指**训练或评价模型**，当前数目是 **3**；如果把**数据发布论文中的直接统计分析**也计入，数目是 **4**。此前把 Dijk 2024 仅按摘要处理是不充分的；用户提供正式全文后，该项已升级为全文证据。

## 审计范围与判定规则

- 路线：`RESEARCH_ROUTE=RWKV`。
- 检索日期：2026-08-11。
- 时间范围：各数据库建库起始至 2026-08-11。
- 数据范围：公开 LSPR23、LSPR24、LSPR25，以及 Locked Shields Partners Run／Packet Repository／flow dataset 等别名。
- 研究单位：以一个实质研究工作为单位；预印本、正式版、作者页、机构页和聚合页合并，不重复计数。

分类规则：

- **A-E**：实际读取 LSPR 数据并进行模型训练、验证、测试或检测器定量评价。
- **A-R**：实际读取 LSPR 数据并做发布、统计或质量分析，但不做可比较模型实验。
- **B**：只引用、介绍、列举或复述 LSPR，没有读取它做本研究的分析或实验。
- **C**：同名缩写、旧私有 Locked Shields 数据、索引错误、数据记录、聚合页或重复版本。

## 六阶段流程

1. 恢复 RWKV 路线，核对本地原件、既有结构化笔记、索引和 Zotero。
2. 冻结年度名、全称、自然语言别名、文件名、DOI、题名和作者组合。
3. 执行通用网页、学术索引、插件、数据 DOI、作者链、参考文献链和被引链检索。
4. 以题名、DOI、作者和版本关系去重，对候选逐条判定 A／B／C。
5. A 类全部回到全文；新增且有复核价值的公开全文写入 `raw/`，建立 `wiki/` 笔记并更新 Zotero。
6. 反向核查已知 A 的参考文献、被引者、作者作品表和数据记录，执行可复核停止条件。

### 1. Dijk 等 2024：LSPR23

正式题名：*LSPR23: A novel IDS dataset from the largest live-fire cybersecurity exercise*。

- 论文 DOI：<https://doi.org/10.1016/j.jisa.2024.103847>。
- 数据 DOI：<https://doi.org/10.5281/zenodo.8042347>。
- 全文表 4：总流数 `16,353,511`，良性 `14,708,912`，恶意 `1,644,599`。
- 标签：若源或目的 IP 属于红队基础设施，则派生 `Label=1`。跳板攻击可能被错标为良性；所有红队端点通信又会不论具体意图被标为恶意。
- 字段：第 4.2 节按来源合计 101 列；第 4.4 节另写 94 个特征，正文没有解释差异。
- 表 7：Suricata 签名 P 0.876、R 0.381、F1 0.531；异常检测 P 0.371、R 0.0174、F1 0.033。
- 第 4.6 节／表 8：随机森林、派生二分类标签、4:1 划分；真阳性 326,836、假阳性 69、P 0.999、R 0.994、F1 0.997。

近饱和 F1 只能支持同年派生标签任务。由于没有主机、时间、端点对或连接级隔离证据，不能把它当作跨年部署结果，也不能确认是否完全排除了标签派生和身份字段。

### 3. Leoste 2025：LSPR23→LSPR24

正式题名：*Comparative Analysis of Deep Learning and Machine Learning for Network Intrusion Detection Using Data from the Largest Live-Fire Cyber Defence Exercise*。

- 官方全文：<https://digikogu.taltech.ee/et/Download/694a3db8-fa97-4ca7-8e16-bec4801f8b62>。
- LSPR23 随机 80/20 同年切分；没有时间、主机或端点对隔离。
- 从 101 个初始字段保留 72 个；删除 IP、绝对时间、Expoid、Suricata 和标签列，但 72 字段最终清单不能从正文无歧义重建。
- LSPR23 数值中位数由约 400 万随机样本估计，再以每块 200 万行处理全量；不使用 SMOTE 或其他重采样。
- LSPR24 原始 20,227,356 流；跨年评价前直接删除含 `NaN` 的行。论文没有报告删后总行数；混淆矩阵包含 420,419 个恶意样本。
- RF：128 棵树、最大深度 10、启用自助采样。CNN：两层一维卷积、类别嵌入、约 4080 万参数、Adam、学习率 0.001、验证 F1 早停。
- 有包到达间隔时，CNN 的跨年 P／R／F1 为 12.47%／35.23%／18.42%；RF 为 38.86%／12.06%／18.41%。
- 无包到达间隔时，CNN F1 13.78%，RF F1 2.20%。

本地原件：`raw/papers/datasets/LSPR24/2025_Leoste_Comparative_Analysis_ML_DL_LSPR23_LSPR24.pdf`；SHA-256 `2905780372be5089a7270e6e5ae6437fd4b5dfe1f9fd70f8c385632a038756dd`；Zotero `M8EZZ9S9`。

### 4. Dijk 等 2026：三年度序列构造

正式题名：*Sequence Construction as a Primary Design Factor in Flow-Based Intrusion Detection: A Cross-Year Evaluation on the Locked Shields Datasets*。

- SSRN DOI：<https://doi.org/10.2139/ssrn.6597680>。
- 使用 LSPR23、LSPR24、LSPR25，比较 OP、5-T、1-IP、SesIP、2-IP、Host、SesH、2-H 八种构造和 485 个配置。
- 模型输入为 83 个字段；IP 与主机名用于分组，不直接输入模型。
- 最长序列 128；训练／验证按唯一 `conn_key` 在序列级隔离，受控分层抽样，种子 42。
- 正文未报告训练／验证比例，也未报告跨年评价是否覆盖下一年度全部序列。神经模型每轮最多 1000 批，使会话型大规模序列集合每轮覆盖率很低。
- XGBoost 使用学习率 0.05、深度 8、800 棵树、行／列采样 0.8；神经模型共享隐藏维 384、8 头、6 层、AdamW、最多 50 轮和早停。
- 主指标是平均精确率；另报 AP 提升倍数、F1、ROC 曲线下面积、准确率、精确率和召回率，并用序列级 10,000 次自助法给固定拆分区间。
- 194 个跨年比较中 178 个下降；`LSPR23→LSPR24` 的同年选优 Transformer AP 从 0.9964 降至 0.0742。2-IP 的跨年中位差距最小，为 -0.0675。

LSPR25 Zenodo 页面把该论文称为 *Computer Networks* 伴随论文，但截至审计日 Crossref 和精确题名检索只确认 SSRN DOI；因此当前题录应写“SSRN 预印本／待核验正式版”，不能自行补造期刊 DOI。

本地原件：`raw/papers/datasets/LSPR24/ssrn-6597680.pdf`；SHA-256 `eccb238307cc46a5f500033d1edefea63d53edc2c7adc79b3695d1eeddf78c95`；Zotero `U4ZMBMEK`。

## C 类：同名、旧私有数据、元数据和索引错误

- Känzig 等 2019 的 C2 检测论文和 Gehri 等 2023 的跨年份 C2 泛化论文确实使用 Locked Shields 流量，但所用是公开 LSPR23 之前的私有采集，不属于 LSPR23／24／25。
- Halisdemir 等 2022 的数据质量方案是 LSPR23 的先行方法来源，发表时公开 LSPR23 尚不存在。
- 医学、材料、传感器领域用 `LSPR` 表示“局域表面等离激元共振”，是主要缩写噪声。
- IBM 文档中的 `LSPR` 表示大型系统性能参考，与网络安全无关。
- 三个 Zenodo 条目是数据记录；作者页、机构页、OUCI、OpenAIRE、DBLP 页面是同一论文的题录或聚合版本。
- OpenAlex 把一篇建筑火灾综述接到 Dijk 2024 被引链，但 ScienceDirect cited-by、题名、摘要和全文语义均不支持，按引文索引异常排除。

## 查全局限

1. **不能证明不可见文献不存在**：未公开手稿、企业报告、未被索引的学生项目和非英语仓储可能漏检。
2. **索引延迟**：LSPR25 很新；Crossref 只确认 SSRN，Zenodo 所称 *Computer Networks* 版本尚无可检出的正式 DOI。
3. **数据库故障**：Semantic Scholar 官方接口持续返回 429；本轮以多个独立索引替代，但这不等价于它的完整覆盖。
4. **Google Scholar 边界**：没有直接依赖可复现的 Google Scholar 页面；使用 Sider Scholar 的学术搜索、OpenAlex、DBLP、出版社 cited-by 和通用网页索引替代并交叉核验。
5. **插件漏检**：Consensus、SciSpace 和 Sider Scholar 都漏掉至少一个已知 A，证明插件结果不能被当成全集。
6. **数据引用漏报**：三个 Zenodo 页面显示 0 篇文献引用，但实际已知 Leoste 与 Dijk 2026 使用这些数据；因此 0 不能解释为无人使用。
7. **全文访问**：两篇 B 类只有题录／摘要。现有证据足以将其排除出 A，但不适合做逐句全文主张。
8. **缩写冲突**：`LSPR` 在材料与生物传感器领域高频出现，广检索的原始结果数没有可比意义。
