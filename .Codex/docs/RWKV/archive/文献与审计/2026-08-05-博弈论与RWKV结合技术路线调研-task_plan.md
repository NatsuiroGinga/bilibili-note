# 博弈论与 RWKV 结合技术路线调研计划

## 目标

在攻击者—检测器极小极大博弈、多目标非对称议价、序贯告警风险博弈三条路线中，选择一条能与 RWKV 长时状态形成真实方法连接、可由 LSPR24／ROSPaCe 数据合同检验、且单张 RTX 5090 可执行的第四章路线。

## 边界

- 核心应用证据优先 2023—2026 年一级全文；奠基方法可追溯更早文献。
- 博弈必须给出玩家、策略、收益／风险、信息结构和响应／均衡对象。
- 区分文献原结论、跨域迁移假设和本课题推论。
- 不修改论文正文、恢复文档或实验代码，不启动训练。

## 裁决门槛

1. 玩家和策略不是同一网络内部人为拆分的名称；若是多目标议价，必须有显式不同目标、分歧点和议价解。
2. 至少存在一个可观察的对手响应、分布扰动或停止风险，且能在静态数据上诚实建模。
3. RWKV 提供状态或策略接口，但博弈贡献不能等同于更换骨干。
4. 有普通 RWKV、无博弈、固定权重、简单鲁棒训练或固定阈值等防伪对照。
5. 假设可以被单一主数据集的前向拆分与事件簇统计证伪。
6. 三种子正式矩阵能在单张 RTX 5090 上顺序运行。
