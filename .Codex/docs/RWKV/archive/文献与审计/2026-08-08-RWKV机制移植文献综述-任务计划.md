# RWKV 机制移植文献综述任务计划

## 目标

基于可核验全文，筛选 3 至 6 个可把 RWKV、RWKV-7 或 RWKV-8 机制移植到普通基座模型的第三章候选，并给出快速消融合同、理论公式潜力、数据字段映射和风险边界。

## 任务边界

- 只做文献检索、全文分析、候选综合和知识写回。
- 不修改第三章候选方案登记册或 RWKV 路线总控。
- 不运行实验，不把文献推论写成实验结论。
- 可能有用且在汇报中提及的论文必须保存全文并建立结构化笔记；无法合法获取时登记阻塞。

## 六阶段

- [x] 阶段一：固定研究问题、时间范围、关键词、纳入排除标准和停止条件。
- [x] 阶段二：盘点本地全文与笔记，检索官方生态页、论文数据库和 Zotero，核验并去重候选。
- [x] 阶段三：按核心机制、理论基础、安全应用、混合架构、数据与评价、待补全文分类筛选。
- [x] 阶段四：至少分析 12 篇核心全文，记录公式、算法、实验数字及页码或章节。
- [x] 阶段五：形成机制迁移比较矩阵、研究空白和 3 至 6 个快速消融候选。
- [x] 阶段六：写入论文笔记、资源笔记、索引和最终综述，完成引用与制品自查。
- [x] 独立工作包：核验 2021—2026 年加密恶意流量数据集的处理形态、任务类型、拆分、基线、指标、泄漏风险与单数据集内部多任务设计。

## 研究问题

1. 哪些 RWKV 系列机制可以脱离完整 RWKV 骨干，独立注入 Transformer、BERT、Mamba 或轻量流量模型？
2. 哪些机制能使用 LSPR24 等现有数据字段快速验证，而不要求新增昂贵数据源？
3. 哪些候选既有清晰的理论公式链，又能形成公平的单变量快速消融？
4. 哪些证据只是其他领域的迁移线索，哪些已在网络安全或流量任务中得到直接验证？
5. 在最终论文只使用一个数据集的约束下，哪些候选能共享同一冻结数据合同，并通过内部多任务、困难分面、时间外推、开放集或历史长度形成完整证据？

## 冻结标准

- 时间范围：2023—2026，必要时纳入奠基性 RWKV 原论文与官方设计文档。
- 纳入：全文可核验、机制定义明确、可映射到安全数据与快速消融。
- 排除：仅摘要、机制不可核验、与网络流量完全无关且不可合理迁移。
- 停止条件：至少 12 篇核心全文，且连续两轮引用链无新增高优先机制；否则明确报告证据饱和不足。
- 推荐门槛：输出 3 至 6 个候选；每个候选必须包含普通基座、输入字段、最小消融、理论公式潜力、失败判据和风险。错误相对下降 16.1% 只作朱焱雷第三章历史量级参照，不作硬门槛；实验判断须综合主指标绝对值与增量、错误相对下降、多种子一致性、置信区间、困难分面、效率和独立消融。

## 决策

- 本任务只提高或降低候选优先级，不替代快速消融实验作存废裁决。
- RWKV-8 与 ROSA 可列工程候选，但必须明确其目前缺少正式论文。
- 朱焱雷论文只作为第三章论证完整度和实验门槛参照，不复制其方法。

## 错误与阻塞

- Zotero 本地 API 与连接器可用；本轮五篇缺失核心文献已通过 `--file` 正确导入并完成元数据回查。
- 首次 `--text` 导入因外层命令行引号破坏 BibTeX，产生五个空白父条目；根因已确认，后续一律使用文件导入。当前本地 API 为只读，空白条目须在图形界面移入回收站。
- Zotero 中 RWKV 原论文、Eagle/Finch 与 PLM-NIDS 存在重复条目；笔记已绑定含 PDF 或规范元数据的条目。这不影响本轮全文证据，但后续统一参考文献库时需要人工合并，不能把重复检索结果计作文献数量。
- RWKV-8 ROSA 尚无可核验正式论文，只能引用官方实现与设计说明，不能作为本轮高优先理论来源。
- 本轮实际提及的高优先论文均已有本地全文和结构化笔记；未发现需要用户手动下载才能完成本轮判断的关键全文。
