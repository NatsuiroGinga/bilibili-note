# RWKV 机制移植文献综述

> 日期：2026-08-08  
> 路线：`RESEARCH_ROUTE=RWKV`  
> 任务：从 RWKV 及其生态中提取可移植机制，组合成理论深度、章级工作量与效果验证完整度可对标朱焱雷第三章的候选方案  
> 裁决边界：文献只决定优先级；候选是否有效必须由同一冻结数据、同一基座和同预算快速消融决定

## 1. 结论

这轮文献调研支持把“直接训练一个 RWKV 检测器”改写为更可检验的研究问题：

> **普通因果 Transformer 在恶意流量时序检测中，能否通过 RWKV 的受控状态演化获得跨窗口记忆，同时保留字段交互能力并避免历史噪声破坏原基座？**

围绕这个问题，第一轮值得进入快速消融的章级候选按优先级为：

1. **S1 状态条件字段交互与有界信任校正**：最符合当前数据形态，文献链最完整，也是最可能同时带来准确率和困难分面提升的方案。
2. **S2 连续时间状态演化与正常状态生成**：理论性质最清晰，直接处理不规则流时间与异常检测，但正常生成头是否能给监督检测带来增量仍无实验。
3. **S4 语义字段筛选与递归掩码重构**：适合单一 LSPR24 数据集内做自监督预训练，理论与实验工作量充足，但文献中的直接证据来自加密应用分类而非恶意活动检测。
4. **S3 轴向状态替换与渐进蒸馏**：最适合证明效率与可迁移性，较难保证主指标明显超过强 Transformer，作为效率导向候选保留。
5. **S5 证据触发多尺度与有界周期校正**：只有在冻结训练区的无标签谱审计发现稳定周期后才进入训练；当前先验较弱，不能仅凭时间序列论文启动大规模实验。

第一轮不建议把完整 RWKV-7 骨干替换、RWKV-X 长上下文稀疏检索、GoldFinch 缓存压缩或 RWKV-8 ROSA 直接当成第三章主方案。这些方向或与 LSPR24 的短历史不匹配，或主要优化效率而非检测效果，或尚缺正式论文证据。

## 2. 六阶段调研过程与证据边界

### 2.1 阶段一：问题与纳入标准

本轮只纳入满足以下条件的材料：

- 能明确分离出状态更新、字段交互、门控校正、蒸馏、生成目标或多尺度选择机制；
- 全文或官方实现可核验；
- 能映射到普通 Transformer、BERT、Mamba 或轻量表格模型；
- 能在同一 LSPR24 冻结数据合同内形成公平的快速消融；
- 能说明安全任务中的实质修改，而不是只更换模型名称。

排除仅有摘要、无法核验公式、需要额外数据集才能成立，或只能说明语言模型长上下文能力的方案。

### 2.5 阶段五：研究空白

现有文献没有同时解决以下四点：

1. **状态与字段的分工**：RWKV 文献重时间状态，流量表征文献重字段或字节结构，缺少“历史状态如何条件化当前字段交互”的统一模型。
2. **安全注入边界**：多数混合架构直接相加或替换，没有为端点身份、缺失历史和稀疏窗口设计信任门与扰动上界。
3. **不规则时间**：RWKV 通常按 token 步数衰减，流量事件却按壁钟时间稀疏到达；显式 `delta_t` 与连续时间状态核的区别尚未在恶意流量上验证。
4. **单数据集公平验证**：既有工作常在不同输入、预训练语料和划分上比较。当前研究必须在同一原始 LSPR24、相同样本身份、字段、拆分和预算下比较普通基座、完整 RWKV 与机制移植。

### 2.6 阶段六：综合原则

候选不是按“新颖词汇数量”排序，而按以下链条排序：

> 文献机制可核验 → 数据字段可观测 → 与普通基座有最小接口 → 两机制解决同一总问题的不同环节 → 可写出性质和边界 → 可用严格消融否定 → 再进入快速实验。

## 3. 统一问题、符号和普通基座

设受保护端点在第 `t` 个五秒窗口内有 `m` 个合法字段组：

\[
X_t=\{x_{t,1},\ldots,x_{t,m}\},\qquad y_t\in\{0,1\}.
\]

字段只包含截至流完成时可见的流量、方向、持续时间、到达间隔、速率、标志和协议状态；标签、地址身份、主机名、攻击叙事和可逆场景标识不进入输入。字段专属嵌入为：

\[
e_{t,j}=\phi_j(x_{t,j},q_{t,j})+u_j,
\]

其中 `q_{t,j}` 是缺失或质量标记，`u_j` 是字段类型嵌入。普通小型因果 Transformer 产生基线表示和分类 logit：

\[
z_t^{(0)}=F_\theta(E_{\le t}),\qquad \ell_t^{(0)}=w_c^\top z_t^{(0)}+b_c.
\]

所有候选共享该基座、字段、样本、标签旁车、训练词元数和最大步数。完整 RWKV-7 与参数匹配 Mamba 是外部结构对照，不是候选专属弱基线。

## 4. S1：状态条件字段交互与有界信任校正

### 4.1 章级总问题

普通 Transformer 能处理当前窗口内的字段关系，但它没有固定状态来总结端点历史；直接把递归状态相加又可能把端点指纹、空窗噪声或错误历史强行写入表示。S1 用两个因果互补机制解决：

- **机制一**回答“历史状态如何改变当前字段之间的关系”；
- **机制二**回答“何时以及多大程度允许历史状态修正原基座”。

### 4.2 机制一：状态条件字段交互

先从上一窗口状态提取摘要：

\[
s_{t-1}=P_s\operatorname{vec}(S_{t-1}).
\]

字段 `i` 对字段 `j` 的交互分数同时依赖当前字段与历史状态：

\[
a_{t,ij}=\frac{(W_qe_{t,i})^\top(W_ke_{t,j}+U_ks_{t-1})}{\sqrt d}+b_{ij}.
\]

按行归一化得到 `M_t`，并以状态相关门控制混合强度：

\[
M_{t,ij}=\operatorname{softmax}_j(a_{t,ij}),\qquad
\alpha_t=\sigma(w_\alpha^\top[z_t^{(0)};s_{t-1}]).
\]

\[
\widetilde E_t=(1-\alpha_t)E_t+\alpha_tM_tE_t.
\]

这不是照搬 RWKV-CVM。原文的混合矩阵是静态变量关系；本候选把它改为由端点历史状态条件化的时变字段关系，并加入字段类型和质量掩码。

当前窗口经汇聚得到 `k_t,v_t,a_t,w_t`，再按 RWKV-7 的“衰减—选择性移除—写入”思想更新状态：

\[
S_t=S_{t-1}A_t+v_t\widetilde k_t^\top,
\]

\[
A_t=D(w_t)-\eta_t\widehat k_t\widehat k_t^\top,
\qquad 0\le\eta_t\le 1.
\]

这里的状态沿端点窗口序列更新，不沿窗内字段轴更新；字段交互和时间状态职责明确分离。

### 4.3 机制二：有界信任校正

由历史覆盖率、字段缺失率、流量稀疏度与状态一致性形成质量向量 `r_t`：

\[
\tau_t=\sigma(w_\tau^\top[s_{t-1};z_t^{(0)};r_t]+b_\tau).
\]

候选校正方向为：

\[
\delta_t=\tanh\!\left(W_\delta[s_{t-1};\operatorname{Pool}(\widetilde E_t)]\right).
\]

最终表示只允许受到幅度有界的历史修正：

\[
z_t=z_t^{(0)}+\rho_{\max}\tau_t\odot\delta_t,
\qquad 0\le\rho_{\max}\le\bar\rho.
\]

`W_δ` 的输出层零初始化，使训练初始函数等于普通基座。`ρ_max` 在训练前冻结上界，不能依据最终测试调整。

### 4.4 可形成的理论包

该方案可形成约 27—32 个有实际功能的公式、1 个端到端算法、2 个命题与 1 个边界引理：

- **命题 1：字段混合非扩张性。**当 `M_t` 行随机时，`M_tE_t` 是字段表示的凸组合，在逐字段无穷范数下不放大最大幅值。
- **命题 2：历史校正扰动上界。**由 `tanh`、`τ_t∈(0,1)` 与 `ρ_max≤\barρ` 可得 `||z_t-z_t^(0)||_∞≤\barρ`。
- **引理：有限历史稳定性。**若 `||A_t||_2≤γ<1` 且写入项有界，则 `S_t` 有统一上界；若条件不满足，论文必须把状态爆炸列为失效边界。
- **复杂度**：字段混合每窗 `O(m²d)`，状态递归每窗不随历史长度增长；应同时报告参数、显存、吞吐和延迟。

这些性质只能解释“为何不会无界破坏基座”，不能替代检测效果实验。

### 4.5 快速消融合同

| 变体 | 状态条件字段交互 | 信任门 | 校正上界 | 目的 |
|---|---:|---:|---:|---|
| `S1-0` 普通 Transformer | 否 | 否 | 否 | 神经主基线 |
| `S1-F` 无状态字段交互 | 否，只有当前字段 | 否 | 否 | 测字段交互本身 |
| `S1-S` 状态条件交互 | 是 | 否 | 否 | 测历史是否改变字段关系 |
| `S1-U` 无界状态注入 | 是 | 否 | 否 | 检验无控制注入是否有害 |
| `S1-T` 完整方法 | 是 | 是 | 是 | 测协同收益 |
| `S1-P` 置换状态 | 是，但跨样本置换 | 是 | 是 | 排除参数量或额外通路伪增益 |
| `S1-R` 随机状态 | 随机同分布 | 是 | 是 | 检验真实状态是否具有独特信息 |

第一轮种子 42 只决定是否进入正式验证。正式转正必须有三个预注册种子、配对置信区间、低历史覆盖/稀疏窗口/未见端点/时间前向分面，以及严格 `2×2` 两机制消融。

### 4.6 当前优先级

**最高。**直接理由是 C3 已有有利代理信号，FlowSem-MAE 和 MambaNetBurst 均把字段或局部结构识别为主要信号，而 FRWKV+ 提供了抑制错误历史注入的可核验结构。风险在于现有代理是树模型，不等价于学习型状态条件字段交互。

## 5. S2：连续时间状态演化与正常状态生成

### 5.1 章级总问题

流量事件按壁钟时间不规则到达，按 token 步数衰减会把“十秒内的十个窗口”和“一小时内的十个窗口”视为相同历史。同时，单一监督分类损失不会明确约束状态是否真的描述了正常演化。S2 的两个机制分别解决时间尺度错配与状态语义缺失。

### 5.2 机制一：连续时间状态演化

设相邻有效窗口的间隔为 `Δt_t≥0`，由当前证据估计非负衰减率：

\[
\lambda_t=\operatorname{softplus}(W_\lambda h_t+b_\lambda).
\]

壁钟时间衰减为：

\[
D_t=\operatorname{diag}\left(\exp(-\Delta t_t\lambda_t)\right).
\]

将 RWKV-7 的选择性移除写为受约束投影：

\[
A_t=D_t\left(I-\eta_t\widehat k_t\widehat k_t^\top\right),
\qquad \eta_t=\sigma(u_\eta^\top h_t).
\]

状态更新为：

\[
S_t=S_{t-1}A_t+v_t\widetilde k_t^\top.
\]

显式时间特征基线只把 `Δt_t` 拼到输入；S2 则让时间直接控制状态半衰期。二者必须同时比较，否则不能把“多了一个时间字段”的收益归因于连续时间动力学。

### 5.3 机制二：正常状态生成

只在冻结训练区中经审计的“当前正常且下一窗口正常”配对上学习下一状态分布：

\[
p_\psi(X_{t+1}\mid S_t)=
\prod_{j\in\mathcal J_c}\mathcal N(x_{t+1,j};\mu_{t,j},\sigma_{t,j}^2)
\prod_{j\in\mathcal J_d}\operatorname{Cat}(x_{t+1,j};\pi_{t,j}).
\]

正常生成损失为：

\[
\mathcal L_{gen}=-\sum_t\mathbb I[y_t=0,y_{t+1}=0]
\log p_\psi(X_{t+1}\mid S_t).
\]

异常分数 `a_t=-log pψ(X_t|S_{t-1})` 不单独决定标签，而作为经开发区校准的辅助证据：

\[
\ell_t=\ell_t^{cls}+\beta\,g_\omega(a_t,r_t),
\qquad
\mathcal L=\mathcal L_{cls}+\lambda_{gen}\mathcal L_{gen}.
\]

### 5.4 可形成的理论包

- **命题 1：纯衰减的时间细分不变性。**若区间内 `λ` 固定，则把 `Δt` 分为若干子区间后衰减乘积仍为 `exp(-λΔt)`；按步衰减不具备该性质。
- **命题 2：连续时间状态有界性。**当写入有界且投影项不扩张时，可给出状态范数的几何和上界。
- **引理：正常生成分数的适用边界。**只有训练正常支持集覆盖评测正常分布时，低似然才可解释为偏离正常状态；时间漂移会破坏该解释，因此必须单独报告校准和时间前向结果。
- 预计可形成 26—31 个公式、1 个算法、2 个命题、1 个适用条件引理。

### 5.5 快速消融合同

| 变体 | 状态时间 | 正常生成 | 目的 |
|---|---|---:|---|
| `S2-0` | 无状态 Transformer | 否 | 主基线 |
| `S2-D` | 输入拼接 `delta_t` | 否 | 时间字段控制 |
| `S2-R` | 固定步 RWKV 状态 | 否 | 测递归本身 |
| `S2-C` | 连续时间状态 | 否 | 测壁钟衰减 |
| `S2-G` | 无连续状态，仅普通历史生成 | 是 | 测生成目标本身 |
| `S2-F` | 连续时间状态 | 是 | 完整方法 |
| `S2-P` | 打乱 `delta_t` 或正常配对 | 是 | 排除伪时间/伪生成收益 |

### 5.6 当前优先级

**第二。**其理论性质最清楚，且只需从同一 LSPR24 核心视图派生 `delta_t_seconds` 与正常相邻窗口对。主要风险是五秒窗口可能使多数有效间隔接近固定值，生成损失也可能只学到流量规模而非攻击状态。

## 6. S3：轴向状态替换与渐进蒸馏

### 6.1 方案结构

把普通双轴 Transformer 分为字段轴与时间轴：字段轴注意力完整保留，只把时间轴注意力替换为 RWKV 状态核。这样保留 FlowSem-MAE 所强调的字段结构，并让状态递归只承担跨窗汇聚。

教师为完整双轴 Transformer，学生为“字段注意力＋时间状态”混合模型。训练分两阶段：

\[
\mathcal L_{hid}=\sum_{l\in\mathcal R}
\left\|H_l^{T}-P_lH_l^{S}\right\|_2^2,
\]

\[
\mathcal L_{KD}=T^2\operatorname{KL}
\left(\operatorname{softmax}(z^T/T)\,\|\,
\operatorname{softmax}(z^S/T)\right),
\]

\[
\mathcal L=\mathcal L_{cls}+\lambda_h\mathcal L_{hid}+\lambda_d\mathcal L_{KD}.
\]

第一阶段冻结教师并对齐被替换层的隐状态，第二阶段再做输出分布与标签联合训练。该顺序来自 RADLADS 的实证，不允许跳过层内对齐后把失败归因于 RWKV 状态。

### 6.2 理论与实验潜力

- 可给出层内近似误差向最终 logit 误差传播的 Lipschitz 上界；
- 可推导字段轴 `O(m²)` 与时间轴线性状态递归的复杂度；
- 可比较完整注意力、直接替换、仅隐状态对齐、仅输出蒸馏、完整两阶段五个变体；
- 正式实验应把准确率保持、吞吐、显存和序列扩展作为共同目标。

预计可形成 24—29 个公式、1 个两阶段算法、1 个误差传播定理和 1 个复杂度命题。理论工作量够，但若主目标必须是显著提高检测 F1，而不是效率—效果折中，该方案不如 S1/S2。

### 6.3 当前优先级

**第四。**RADLADS 证明“普通注意力到 RWKV 状态的渐进迁移”可行，但其目标是保留教师能力。若快速实验只显示相同效果、更低显存，可作为系统效率贡献或跨基座验证，不足以单独承担“检测效果提升”主张。

## 7. S4：语义字段筛选与递归掩码重构

### 7.1 方案结构

机制一先在 `train-fit` 内用不含标签的可预测性统计冻结字段集合。设字段 `j` 的边际预测误差为 `R_j^0`，条件重构误差为 `R_j^c`：

\[
q_j=\frac{R_j^0-R_j^c}{R_j^0+\epsilon},
\qquad
\mathcal J_+=\{j:q_j\ge\tau_q\}.
\]

阈值 `τ_q` 只在训练区冻结。随机标识、校验量和不可预测字段不作为重构目标；身份字段无论可预测性多高都永久禁用。

机制二在字段轴保留普通注意力，在时间轴使用 RWKV 状态，并对合法字段做掩码重构：

\[
\mathcal L_{mask}=\sum_{t,j\in\mathcal J_+}
M_{t,j}\,d_j\big(x_{t,j},\widehat x_{t,j}(S_{t-1},E_t^{obs})\big).
\]

预训练与监督微调共享同一原始数据和时间切分，且预训练只能使用 `train-fit`。完整目标为：

\[
\mathcal L=\mathcal L_{cls}+\lambda_m\mathcal L_{mask}.
\]

### 7.2 可形成的理论包

- 在“被排除字段对标签及其他合法字段条件独立”的假设下，排除该字段不提高 Bayes 分类风险，同时移除不可约重构方差；该结论必须明确假设，不能写成普遍定理。
- 字段专属嵌入避免数值相同但语义不同的字段被映到相同类型流形，可用类型条件映射与共享映射作形式化比较。
- 时间轴状态递归与字段轴注意力的复杂度可分解，并能给出掩码率、字段数量与计算量关系。
- 可形成约 25—31 个公式、1 个预训练—微调算法、2 个命题和 1 个数据条件引理。

### 7.3 快速消融合同

`普通监督基线 → 共享嵌入掩码重构 → 字段专属嵌入 → 仅可预测性过滤 → 仅时间状态重构 → 完整方法`，另加随机字段集合和标签泄漏检查。快速实验至少扫描两档掩码率，但调参次数与普通基线保持公平。

### 7.4 当前优先级

**第三。**FlowSem-MAE 的字段过滤、专属嵌入和双轴结构都有强消融证据，且 LSPR24 可在单数据集内重物化。但该证据来自应用/网站分类；是否改善红队关联检测必须重新验证。

## 8. S5：证据触发多尺度与有界周期校正

### 8.1 进入条件

先在 `train-fit` 的无标签聚合序列上做频谱审计，检查不同时间块和端点组中是否出现稳定主峰。周期候选不得由标签、最终测试或模型损失选择。只有主周期在多个训练时间块中重复出现，且随机相位对照不能复现，才启动模型训练。

### 8.2 两个机制

- 用训练区谱峰选择快、慢状态尺度，而不是手工指定；
- 用 FRWKV+ 式零初始化、有界信任门将周期状态作为校正证据。

快速消融包括固定单尺度、手工双尺度、谱峰双尺度、随机周期、无信任门与完整方法。理论上可给出频谱选择、双状态更新、相位稳定性、校正上界与复杂度，章级工作量足够。

### 8.3 当前优先级

**条件候选。**多尺度 RWKV 在强日周期光伏数据上有大增益，但本课题旧 HGB 代理的快慢组合相对最佳单尺度只增加约 0.2%。这不是正式证伪，却足以要求先做廉价无标签谱审计，避免直接消耗 GPU。

## 9. 本轮不进入第一批快速实验的机制

| 机制 | 暂缓原因 | 解锁条件 |
|---|---|---|
| 完整 RWKV-7 替换 Transformer | 测的是整骨干而非可归因机制；输入归纳偏置可能主导结果 | 保留为参数匹配外部基线 |
| GoldFinch / RWKV-X 稀疏检索 | 主要解决长上下文精确召回，LSPR24 主历史暂定 H=4 | 无标签历史诊断证明远程事件召回是主要瓶颈 |
| RWKV-8 ROSA | 当前只有官方实现与设计说明，缺正式论文；流量离散模式定义尚未冻结 | 正式论文或独立理论来源出现，且模式词元无泄漏 |
| RWKV-CVM 静态混合 | 单独只有一个小门控模块，工作量不足；论文增益仅约 1.8% 且有负步长 | 作为 S1 的机制来源，不单独成章 |
| RWKV-TS+ 跨批次提示 | 原文明确指出分类样本独立时跨批提示无意义 | 数据合同证明跨批样本属于同一连续端点轨迹 |

## 10. 统一快速消融实验合同

### 10.1 唯一数据与开发视图

- 唯一候选筛选数据：LSPR24；
- 主任务：基于已完成网络流因果序列的红队关联恶意活动二分类；
- 快速视图：`G0-D-Screen`，只用 `train-fit` 与 `architecture-selection`；
- 采用与标签无关的稳定样本散列抽样；
- 不读取 `dev-validation`、`calibration` 或 `final-test`；
- 所有候选共享样本身份、五秒窗口、H=4 主历史、字段清单、标签旁车和拆分。

### 10.2 公平基线

| 编号 | 模型 | 功能 |
|---|---|---|
| B0-1 | HGB，H=1 | 单窗口非线性基线 |
| B0-2 | HGB，H=4 | 强传统历史基线 |
| B0-3 | XGBoost，H=1/H=4 | 排除单一树模型偶然性 |
| B1 | 小型因果 Transformer，H=4 | 所有机制移植的共同接收基座 |
| B2 | Transformer + 显式 `delta_t` | S2 连续时间必要控制 |
| B3 | 参数匹配的完整 RWKV-7 | 直接换骨干对照 |
| B4 | 参数匹配 Mamba | 线性状态空间对照 |

主要结构对比的可训练参数量控制在约正负 5%，并共享优化器、训练词元数、最大步数、早停数据和调参次数。新增字段、时间或生成目标时，基线必须获得等价输入或设置单独控制变体。

### 10.3 快速筛选门槛

快速实验的目的不是证明论文结论，而是判断是否值得正式训练：

1. 主指标 PR-AUC 相对 B1 方向为正；
2. 宏平均 F1、固定误报率下事件召回和校准误差不能出现明显全面退化；
3. 至少一个预注册困难分面改善；
4. 置换或随机状态不能复现真实状态的全部增益；
5. 不出现标签、端点身份或时间未来泄漏；
6. 增益与训练时间、显存、吞吐代价相称。

快速筛选允许单种子 42。它只能给出“继续正式验证”或“快速消融未见信号”，不能把候选改为“已支持”或“已证伪”。

### 10.4 正式转正门槛

正式方案至少运行三个预注册种子，并同时报告：

- 主指标绝对值与绝对增量；
- 错误相对下降；
- 配对置信区间；
- 时间前向、未见端点、稀疏历史、低阳性先验和未见事件簇分面；
- 基座、仅机制一、仅机制二、完整方法的严格 `2×2` 消融；
- 状态置换、随机状态或随机时间对照；
- 参数量、训练时间、峰值显存、吞吐和每样本时延。

朱焱雷第三章相对最强外部基线约 16.1% 的错误相对下降只作为历史量级参照，不是数据选择、候选保留或快速筛选的硬阈值。

## 11. 与朱焱雷第三章相当的工作量门禁

参考 [朱焱雷第三章候选门槛基准](2026-08-08-朱焱雷第三章候选门槛基准.md)，最终入选方案必须具备：

1. **一个总问题与两个因果互补机制**，不是两个普通模块并列；
2. **统一状态、表示或目标接口**，能写成一个端到端算法；
3. **约 25—35 个有推导功能的公式**，覆盖问题定义、两个机制、统一目标、基座适配、性质和边界；
4. **至少 2 个命题或定理与 1 个条件/边界引理**，且有明确假设和可证伪后果；
5. **约 9—12 幅不同证据功能的图**，涵盖结构、训练轨迹、内部状态、困难分面、敏感性和效率；
6. **约 6—8 张表**，涵盖环境、外部基线、两机制消融、跨基座、统计与资源开销；
7. **最强匹配外部基线与至少一种异构骨干验证**；跨基座验证放在方法收敛后，不阻塞快速筛选。

数字是论证完整度参照，不是凑数指标。若某个候选只能写十余个定义式、没有可检验性质或严格两机制消融，即使单次 F1 有提升，也不能直接升格为第三章方案。

## 12. 建议执行顺序

1. 完成并冻结 LSPR24 `G0-D-Screen`；
2. 冻结 HGB、XGBoost、小型因果 Transformer、完整 RWKV-7 和 Mamba 公平基线；
3. 先把 S1 拆成“字段交互、状态条件化、信任校正”三个单变量快速实验；
4. 并行运行 S2 的“显式时间、固定步状态、连续时间状态、正常生成”四项消融；
5. S1/S2 出现稳定信号后才运行完整两机制组合；
6. 若两者均无信号，运行 S4 的训练区自监督快速实验；
7. S3 作为效率保真候选，S5 先做无标签谱门禁；
8. 只有正式开发区三种子结果满足转正门槛，才冻结第三章方法、名称和标题。

## 14. 最终建议

**第一批只实现 S1 和 S2 的独立机制，不一次性堆成大模型。**S1 最有可能回答“为什么 RWKV 状态能给普通 Transformer 增益”，S2 最有可能形成清晰的理论性质。S4 是单数据集自监督后备方案，S3 是效率后备方案，S5 必须先过周期证据门。
