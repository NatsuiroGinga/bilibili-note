# TQH-C2 安全任务机会矩阵

- **代理名**：`/root/tqhc2_citation_literature_sol_max`
- **模型**：`gpt-5.6-sol`
- **推理强度**：`max`
- **数据对象**：TQH-C2 v1.0.0–v1.2.0，实验可用性以已校验 v1.2.0 制品为主
- **裁决边界**：本矩阵判断“数据能否构造任务”和“冻结协议下是否存在可测余量”，不预判新方法有效；方法有效性只能由真实实验裁决。

## 1. 证据门禁

- **D1 可直接构造**：现有制品已有目标、可观测量和合法分组键；仍需预注册协议和真实实验。
- **D2 需代理标签或弱假设**：需留一成员、合成干预、人工标注、报文前缀重物化或虚拟删除/标注预算；结论必须限定为代理任务。
- **D3 当前不支持**：缺少目标标签、因果时间、干预、稳定实体身份或足够独立事件；不得使用 IP、`capture_id` 或文件名臆造目标。

共同泄漏防护：默认以完整 `capture_id` 为分割原子；地址、端口、绝对时间、捕获/测试床身份、间隔/抖动、标签副本不得进入默认检测输入；通过最终测试选字段、阈值或任务定义属于泄漏。

### 候选机会的两轨裁决

- **同协议直接改进**：不要求候选创造新场景。即使已有论文覆盖同一任务或机制，只要在**同一数据版本、同一划分、同一字段、同一训练/推理预算和同一指标**下仍有可靠余量，就允许研究直接改进。必须与同输入强基线比较，并预注册最小有意义增量、置信区间和资源预算。
- **更严格稳健性验证**：当同协议汇总指标饱和或已有机制强覆盖时，保留完整 capture/成员留出、跨 C、最差组、固定告警预算、风险—覆盖、因果前缀和物理可实现扰动等更严格协议。它检验的是既有结论能否在更安全的评价下成立，不把“换了更严格测试”本身包装为模型原创。
- **既有机制不是否决条件，也不是原创性来源**：领域对抗、组分布鲁棒优化、校准、拒识、流前缀、图交互或上下文聚合已有先例时，应明确列为机制来源/强基线。候选要形成论文方法贡献，必须同时绑定一个可识别的新增机制、强基线、独立机制消融、相同预算和预注册失败门槛；否则只能报告复现、工程组合或稳健性审计。
- **余量先于场景新颖性**：先测强基线在冻结协议下的绝对值、误差结构、最差组和预算曲线；没有可靠余量时否决该协议下的直接改进，但仍可转入更严格稳健性验证。已有论文做过相同任务，不构成自动否决。

## 4. 逐项实验合同

### 4.1 封闭集 C2/非 C2 分类（D1）

- **样本/切分**：逐流样本，`malicious_c2` 为正类；完整 capture 分组，七个共同大小/时序字段为默认输入。
- **强基线**：逻辑回归、随机森林、HGB、XGBoost；类别权重和训练预算一致。
- **指标**：宏 F1、恶意召回率、良性误报率、PR-AUC、最差 capture/成员 F1、推理耗时。
- **饱和/缺陷**：域内 HGB/XGBoost 宏 F1 已为 `0.999618`；流大小本身在 A/B/D 也近乎完美可分。
- **可创新方向**：同协议下如仍有可靠的低误报、最差组、计算/存储或受限字段余量，可直接改进；汇总宏 F1 无余量时转向更严格稳健性验证或作为其他任务的健全基准。
- **最小可证伪实验**：冻结版本、组分、字段、预算和指标，对比 HGB/XGBoost；同时报告汇总、最差组、低误报和效率。若预注册主指标没有超过强基线的不确定区间，或所谓收益只来自字段/预算变化，则否决该同协议改进；不能仅因已有论文做过封闭集分类而否决。

### 4.2 开放集未知攻击（D2）

- **样本/切分**：留一框架或成员完全不参与训练，只作“未见域”；不使用实际为 0 且语义是噪声的 `unknown`。
- **强基线**：最大类概率、能量分数、Mahalanobis 距离、OpenMax、温度缩放后阈值。
- **指标**：未见域 AUROC/AUPR、FPR@95%TPR、已知类宏 F1、开放集风险、逐成员结果。
- **饱和/缺陷**：无原生未知攻击家族；留出域同时改变框架、传输、流生成特征和环境。
- **可创新方向**：开放域拒识与已知 C2 检测的联合风险控制。
- **最小可证伪实验**：仅在开发区进行四次留一成员。若候选对留出 C 不能同时改善未见域检出和已知类性能，或只靠 `profile`/指纹缺失模式识域，即否决。

### 4.3 跨版本/跨环境泛化（D1/D2）

- **样本/切分**：跨环境使用 A/B/D→C、逐成员留出、B↔D；跨版本使用 v1.0.x→v1.1/v1.2，必须按文件指纹去重 A/C 与字节相同包。
- **强基线**：HGB、XGBoost、深度多层感知机；领域对抗、CORAL、组分布鲁棒优化与简单重加权作强适应基线。
- **指标**：目标域宏 F1、恶意召回、良性误报、最差域 F1、源—目标差值、三种子置信区间。
- **饱和/缺陷**：跨 C 宏 F1 仅 `0.128–0.147`，有明确空间；但旧版偏移由数据清理和 B 重采造成，不可泛化为自然环境漂移。
- **可创新方向**：对捕获组和成员不变的表示、困难 C 目标域的最差组风险、B/D 受控对的协议不变特征。
- **最小可证伪实验**：固定七字段、capture 留出、同预算和 3 种子，对比 A+B→C 与 A+B+D→C。候选若不能在不提高良性误报的前提下稳定改善宏 F1 和恶意召回，即否决。

### 4.4 持续学习/概念漂移（D2）

- **样本/切分**：预先冻结成员或版本到达顺序；同一字节相同包只出现一次。
- **强基线**：完全重训上界、只训新数据、固定回放、EWC/LwF、组均衡回放。
- **指标**：平均宏 F1、最差历史域 F1、遗忘量、前向迁移、C 召回、训练耗时/内存。
- **饱和/缺陷**：没有自然连续流；一个捕获组合只有一次，任务顺序会强影响结论。
- **可创新方向**：有限回放预算下保留旧环境并适应 C 困难域。
- **最小可证伪实验**：冻结两种相反到达顺序。若改进只在一种人为顺序成立，或在同等计算下不优于固定回放，即否决“持续学习改进”。

### 4.5 机器遗忘（D2）

- **样本/切分**：人工定义整个 capture、成员或框架为删除请求；保留数据与删除数据严格分开。
- **强基线**：从头重训金标准、检查点重训、影响函数/梯度近似、选择性参数重置。
- **指标**：与重训模型的预测/参数距离、删除集成员推断优势、保留集效用、耗时和显存。
- **饱和/缺陷**：没有真实法律删除请求，数据为实验室合成；只能评估算法性删除。
- **可创新方向**：按完整捕获组的快速删除与跨域效用保持。
- **最小可证伪实验**：删除一个完整 capture，与从头重训盲测对比。若近似遗忘在保留集或删除集上明显偏离金标准，或无时间/内存优势，即否决。

### 4.6 投毒/后门恢复（D2）

- **样本/切分**：只在训练区注入标签翻转、完整污染 capture 或通过 PCAP 重物化可实现的流特征触发器。
- **强基线**：无防御、剪枝/微调、鲁棒损失、样本过滤、干净数据重训上界。
- **指标**：攻击成功率、干净宏 F1、C 召回、良性误报、恢复后攻击成功率、计算成本。
- **饱和/缺陷**：原始数据没有投毒/后门真值；任意改表格字节可能违反协议物理可实现性。
- **可创新方向**：从 PCAP 可实现触发器出发的组级污染恢复。
- **最小可证伪实验**：同时评估一个表格触发器和一个 PCAP 可重现触发器。若攻击只在不可实现的表格触发器上成立，或防御收益来自已知捷径字段，即否决。

### 4.7 选择性预测/拒识（D1）

- **样本/切分**：仅使用冻结校准组选择拒识规则，在未见 capture 和跨 C 上评估。
- **强基线**：最大概率阈值、边际阈值、深度/树集成分歧、分布无关风险控制。
- **指标**：风险—覆盖曲线下面积、固定覆盖率的错误率/恶意召回、固定风险的覆盖率、逐成员拒识率。
- **饱和/缺陷**：域内近完美概率会制造假安全感；重点是跨 C 而不是 pooled 拒识。
- **可创新方向**：组偏移下的有限覆盖检测和风险可证明拒识。
- **最小可证伪实验**：以 A/B/D 为源、C 为目标，预注册 50%、75%、90% 覆盖率。若风险不随拒识单调降低，或达到低风险需几乎拒绝全部 C，即否决。

### 4.8 概率校准/告警预算（D1）

- **样本/切分**：独立 capture 校准区拟合校准器和告警阈值；用 manifest 捕获时长把误报转为每小时告警。
- **强基线**：原始概率、Platt、保序回归、贝塔校准、温度缩放、简单组条件阈值。
- **指标**：NLL、Brier 分数、类别/组 ECE、固定良性误报或每小时告警预算下的恶意召回、最差组校准误差。
- **饱和/缺陷**：域内 ECE 已约 `0.0002`，但这是容易域；尚无跨 C 的冻结校准证据。
- **可创新方向**：跨域校准、最差组校准与有限告警预算联合选择。
- **最小可证伪实验**：保持同一未见 C 评估，对比原始概率和 3 个校准基线。若候选不能同时降低 Brier/NLL 并在同告警预算下提高召回，即否决。

### 4.9 流式早期检测（D2）

- **样本/切分**：从 PCAP 以持续时间、包数或字节比例生成因果前缀；前缀继承完整流标签，整个 capture 不跨分区。
- **强基线**：固定前 N 包 HGB/XGBoost、因果 TCN/GRU、序贯概率比、完整流 oracle。
- **指标**：不同前缀的 PR-AUC/召回、达到决策的时间/包/字节、每小时误报、相对完整流保留率、吞吐。
- **饱和/缺陷**：B 是长连接复用，D 是多个较短 TCP 连接，前缀语义不同；没有攻击任务开始真值。
- **可创新方向**：协议异构下的统一流前缀风险与早停。
- **最小可证伪实验**：只物化 B/D 各两个开发 capture，评估 10%、25%、50% 包前缀和完整流。若 25% 前缀在同误报预算下不能保留至少 80% 的完整流恶意召回，或无决策时间收益，即停止扩大。

### 4.10 攻击链阶段识别/溯源（D3）

- **样本/切分**：当前无合法目标；`malicious_lateral=0`，`malicious_recon` 只在 C 出现 880 条，没有阶段事件 ID/顺序真值。
- **强基线**：不适用；必须先获得杀伤链驱动日志和稳定实体标识才能定义。
- **指标**：当前不定义，避免先选指标后伪造标签。
- **饱和/缺陷**：包明确不含驱动日志，`uid` 只是单连接，IP 不是可用的跨捕获主机身份。
- **可创新方向**：需新数据工程：重跑采集并发布任务事件、阶段和实体链接；不属当前数据集的直接任务。
- **最小可证伪检查**：盘点标签包是否存在任务事件 ID、阶段时间和跨连接实体键。已实测三者均缺失，所以“现有制品可做攻击链溯源”假设已被否决。

### 4.11 异常解释（D1/D2）

- **样本/切分**：只对冻结模型和合法字段做归因；以 capture/成员跨域稳定性而非单点可视化为主。
- **强基线**：置换重要度、SHAP、稀疏规则、特征删除、反事实扰动。
- **指标**：删除忠实度、重复运行稳定性、跨 capture/成员一致性、捷径字段敏感性、局部解释计算成本。
- **饱和/缺陷**：无人工专家解释真值；大小/时序的归因不等于攻击因果。
- **可创新方向**：解释的跨域稳定性与捷径报警，用解释发现而非美化数据偏差。
- **最小可证伪实验**：在 A/B/D 域内与留出 C 对同一模型重复 3 次解释。若排名对种子/捕获高度不稳定，或只能通过恢复禁止捷径得到高忠实度，即否决解释机制。

### 4.12 主动学习/少样本（D2）

- **样本/切分**：以完整 capture 而非单流作标注查询单位；标注预算按组数与流数同时报告。
- **强基线**：随机查询、不确定性、核心集、BADGE；少样本使用线性头/最近原型和完整微调。
- **指标**：宏 F1—标注组曲线下面积、最差成员 F1、C 召回、同等标注流数下性能、三种子差异。
- **饱和/缺陷**：只有 48 个捕获组，每个间隔—抖动—成员组合只有一次；数据已有完整标签，标注成本是模拟的。
- **可创新方向**：目标域 C 的组级少标签适应和预算感知选择。
- **最小可证伪实验**：冻结 C 的 2/4/6 个标注组预算，与随机选组进行 5 次重抽样。若候选在学习曲线上不稳定优于随机，或优势只来自 capture/成员身份字段，即否决。

### 4.13 隐私审计（D1/D2）

- **样本/切分**：D1 盘点 PCAP/日志/JSONL 的地址、SNI、HTTP 主机/URI/用户代理、时间和拓扑；D2 可模拟模型成员推断。
- **强基线**：字段盘点/规则扫描、唯一性/频数分析、删除直接标识后效用基线；模型侧使用黑盒成员推断。
- **指标**：直接/准标识字段数、唯一值比例、最小化前后效用、成员推断优势、制品可复现性损失。
- **饱和/缺陷**：作者声明数据为封闭实验室自动产生，无人类个人数据；外部站点元数据仍需发布最小化审计。
- **可创新方向**：同时保留跨域检测效用的发布字段最小化。
- **最小可证伪实验**：先扫描一个 A/C 开发单元并人工复核所有高唯一字段。若没有现实人类主体可识别数据，即否决“个人隐私防御”主张，只保留制品最小化审计。

### 4.14 捷径/去混杂审计（D1）

- **样本/切分**：对比逐流随机、capture 分组、成员留出；对比全字段、七字段和逐字段。
- **强基线**：HGB/XGBoost 与线性模型；全字段模型只作泄漏上界，不作合法检测基线。
- **指标**：分割协议性能膨胀、逐字段纯度/单字段 F1、跨 C 差值、最差组、模型依赖稳定性。
- **饱和/缺陷**：`resp_h` 取值已与标签集合完全分离；七字段仍存在强大小/时序生成模式。
- **可创新方向**：对捕获和成员不变的特征限制、捷径审计门禁、跨域表示对照。
- **最小可证伪实验**：一次性运行三种分割与三种字段预算。若所谓去捷径方法在域内降分却不改善跨 C/最差组，即否决；不允许为制造提升而削弱 HGB/XGBoost。

## 5. 前三推荐

### 推荐 1：严格分组的跨成员泛化，主目标为 C 困难域

- **为什么第一**：任务是 D1，且现有实验直接暴露巨大缺口：域内宏 F1 `0.999618`，A+B(或 A+B+D)→C 仅 `0.128–0.147`。这比继续优化饱和封闭集更可证伪。
- **最小研究单元**：七字段、capture 分组、A+B→C 和 A+B+D→C、HGB/XGBoost/线性基线、3 种子；同时报宏 F1、恶意召回、良性误报和最差组。
- **可用非 RWKV 方法**：组分布鲁棒优化、领域对抗、条件不变表示、简单重加权、树集成；模型族不应预先锁定。
- **停止条件**：同预算候选不能在多种子稳定改善 C 召回和宏 F1，或改善靠更高良性误报换取，即否决。

### 推荐 2：跨域概率校准、告警预算与选择性拒识

- **为什么第二**：任务是 D1，且能直接回答“在固定告警成本下能发现多少 C2”。域内 ECE 近 0 不证明跨 C 可信，正适合检验过度自信。
- **最小研究单元**：冻结独立校准 capture，对比原始概率、Platt、保序回归和温度缩放；在 C 上报 Brier/NLL、风险—覆盖曲线和固定告警/小时下召回。
- **可用非 RWKV 方法**：树模型后验校准、深度集成、分布无关风险控制、组条件校准。
- **停止条件**：只降低域内 ECE，却不降低跨 C Brier/NLL、不改善同告警预算召回，或靠拒绝几乎全部 C 获得低风险，即否决。

### 推荐 3：协议异构下的流前缀早识别

- **为什么第三**：任务为 D2，但 PCAP、时间戳、完整流标签和 B/D 同框架异传输对使其可以用很小的重物化实验快速否决。
- **允许论断**：只能写“完整流标签下的因果前缀早识别”，不能写“攻击链开始时延”或“任务开始预警”。
- **最小研究单元**：B/D 各两个开发 capture，10%/25%/50% 包前缀，固定前 N 包树模型对比因果序列模型和完整流 oracle。
- **停止条件**：25% 前缀不能在同误报预算下保留 80% 的完整流召回，或指标收益来自不可在线观测的终局字段，即停止。

## 6. 当前不成立或需转轨的主张

- **只在当前七字段域内汇总 F1 上刷分**：现有宏 F1 已饱和，先做同版本/同划分/同字段/同预算余量复核；若最差组、低误报或效率仍有可靠余量，可保留直接改进，否则转入更严格稳健性验证。
- **原生未知攻击检测**：无未知攻击类，`unknown` 又是噪声语义且当前为 0。
- **攻击链阶段识别/溯源**：缺少目标与链接，属 D3。
- **以现有版本当自然概念漂移**：版本变化是工程修正/重采/新增，混杂严重。
- **现实个人隐私保护主线**：数据没有人类主体私密数据，只支持发布制品最小化审计。

以上只否决与数据证据冲突的强主张，不以“已有论文做过任务/场景”为否决理由。同协议直接改进和更严格稳健性验证都可成为研究单元，但方法原创性必须由新增机制、强基线、独立消融和失败门槛共同支持。
