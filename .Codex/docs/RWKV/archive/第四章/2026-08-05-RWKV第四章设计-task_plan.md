# RWKV 第四章设计计划

## 目标

为 RWKV 替代路线建立可证伪的第四章候选方案，明确早期决策问题、课程机制、风险约束、理论性质、公平基线和实验门禁。

## 当前裁决

- 主线采用“目标分布锁定的自步课程＋风险约束监督最优停止”。
- UGR'16 没有真实行为动作和动作依赖转移，CPO、COPO、PPO 与 Decision-RWKV 不作为默认主算法或公平主基线。
- 强化学习只保留为具有真实交互日志或经过独立验证模拟器时的条件扩展。
- UGR'16 只用于方案筛选；最终单一数据集由独立文献调研裁决。

## 下一门禁
