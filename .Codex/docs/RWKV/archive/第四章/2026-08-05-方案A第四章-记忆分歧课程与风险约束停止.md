# 方案 A 第四章：基于记忆分歧课程与风险约束停止的网络攻击早期检测方法

- **状态日期**：2026-08-05
- **前置条件**：方案 A 第三章通过三种子门禁并冻结 `A11` 检查点
- **候选章名**：基于记忆分歧课程与风险约束停止的网络攻击早期检测方法
- **当前状态**：理论与实验合同候选，不启动训练

## 1. 章节责任

第三章解决“怎样同时保存短时突发与长期基线并形成正常生成分数”。第四章解决“在流量尚未完整到达时，模型应继续观察还是告警”。本章不得重新修改快慢状态、RWKV-7 算子或正常生成似然。

两个机制为：

1. **记忆分歧课程**：利用冻结快慢状态的分歧、门控不确定性和正常生成难度安排由易到难的训练顺序，最后严格回到目标训练分布。
2. **风险约束最优停止**：在误报、漏报和观察预算约束下，学习继续观察或终止告警。

```text
冻结 A11 因果状态 → 快慢记忆分歧与生成难度 → 目标锁定课程
                  └→ 停止头 → 继续观察 / 告警
                              └→ 误报、漏报与观察预算约束
```

## 2. 外生轨迹与决策状态

第 \(i\) 条轨迹为

\[
\xi_i=\{(\mathbf{x}_{i,t},b_{i,t})\}_{t=1}^{H_i}.
\]

攻击轨迹的可评价起点必须由数据合同预先定义。若采用 LSPR24，只能把首个可观测恶意流完成时刻作为起点；没有一级证据时不得称为真实攻击动作起点。

冻结第三章输出包括快状态、慢状态、融合状态、检测概率、生成分数和融合门：

\[
(\mathbf{h}^{f}_{i,t},\mathbf{h}^{s}_{i,t},\mathbf{z}_{i,t},
\widehat p_{i,t},s^{\mathrm{gen}}_{i,t},\mathbf{g}_{i,t})
=F_A(\mathbf{x}_{i,1:t}).
\]

记忆分歧为

\[
d^{\mathrm{mem}}_{i,t}=
\frac{\|\mathbf{h}^{f}_{i,t}-\mathbf{h}^{s}_{i,t}\|_2}
{\|\mathbf{h}^{f}_{i,t}\|_2+\|\mathbf{h}^{s}_{i,t}\|_2+\varepsilon}.
\]

可部署停止状态为

\[
\mathbf{s}_{i,t}=
[\mathbf{z}_{i,t};\widehat p_{i,t};s^{\mathrm{gen}}_{i,t};
d^{\mathrm{mem}}_{i,t};H(\mathbf{g}_{i,t});
\Delta\widehat p_{i,t};t/H_i;\mathbf{m}_{i,t}].
\]

它不得读取未来观测、真实起点、标签、攻击叙事标识或测试统计量。

## 3. 机制一：记忆分歧课程

训练轨迹难度定义为

\[
\boldsymbol{\delta}^{A}_i=
[\delta_i^{\mathrm{prefix}},\delta_i^{\mathrm{rarity}},
\delta_i^{\mathrm{signal}},\delta_i^{\mathrm{drift}},
\delta_i^{\mathrm{missing}},\delta_i^{\mathrm{mem}},
\delta_i^{\mathrm{gen}}].
\]

其中 \(\delta_i^{\mathrm{mem}}\) 汇总攻击前缀内的快慢状态分歧与门控熵，\(\delta_i^{\mathrm{gen}}\) 汇总正常生成分数的不确定性。综合难度为

\[
d_i^A=(\mathbf{w}_A)^{\mathsf T}\widetilde{\boldsymbol{\delta}}^A_i,
\qquad \mathbf{w}_A\succeq0,
\quad\mathbf{1}^{\mathsf T}\mathbf{w}_A=1.
\]

第 \(e\) 阶段的自步权重为

\[
v_i^{(e)}=\sigma\!\left(\frac{\kappa_e-d_i^A}{T_e}\right).
\]

实际训练分布必须混入冻结目标分布：

\[
p_e(i)=(1-\alpha_e)p_{\mathrm{easy}}^{(e)}(i)
+\alpha_e p_{\mathrm{target}}(i),
\qquad \alpha_E=1.
\]

课程只改变训练顺序，不改变最终类别比例、风险预算或评价样本。难度权重在查看开发验证结果前冻结。

## 4. 机制二：风险约束最优停止

动作集合为

\[
\mathcal{A}=\{\mathrm{CONTINUE},\mathrm{ALERT}\}.
\]

停止概率为

\[
q_{i,t}=\sigma(g_{\phi}(\mathbf{s}_{i,t})).
\]

时间 \(t\) 前的生存概率与停止概率为

\[
S_{i,t}=\prod_{j=1}^{t-1}(1-q_{i,j}),
\qquad P_{i,t}=S_{i,t}q_{i,t}.
\]

最后一步吸收剩余概率，保证

\[
\sum_{t=1}^{H_i}P_{i,t}=1.
\]

在冻结目标分布上定义误报、漏报、归一化延迟和观察成本 \(C^{\mathrm{FP}}\)、\(C^{\mathrm{FN}}\)、\(C^{\mathrm{delay}}\)、\(C^{\mathrm{obs}}\)。主问题为

\[
\min_{\phi}\;
\mathbb{E}_{p_e}[C^{\mathrm{delay}}+\beta C^{\mathrm{obs}}],
\]

满足

\[
\mathbb{E}_{p_{\mathrm{target}}}[C^{\mathrm{FP}}]\leq\epsilon_{\mathrm{FP}},
\quad
\mathbb{E}_{p_{\mathrm{target}}}[C^{\mathrm{FN}}]\leq\epsilon_{\mathrm{FN}},
\quad
\mathbb{E}_{p_{\mathrm{target}}}[C^{\mathrm{obs}}]\leq B_{\mathrm{obs}}.
\]

课程批次优化延迟目标，独立目标批次估计约束，防止课程过滤困难正常轨迹后虚假降低误报率。当前数据没有动作改变网络转移的证据，因此主线称为监督最优停止，不包装为一般强化学习。

## 5. 理论责任

1. **停止概率完备性引理**：有限时域吸收后停止概率质量为 1。
2. **因果在线命题**：停止决策只依赖已观测前缀与冻结 A11 状态。
3. **课程回归命题**：当 \(\alpha_E=1\) 时，最终训练分布等于冻结目标分布。
4. **目标约束估计命题**：独立目标批次给出目标风险的无偏经验估计；有限样本仍需置信余量。
5. **复杂度**：冻结编码器时，停止头额外开销关于轨迹长度线性；在线只保存 A11 递归状态与当前停止状态。

公平基线包括固定前缀、单阈值最早告警、连续 K 步阈值、双阈值迟滞、普通监督早退、无课程约束停止和经全文核验的监督最优停止方法。所有学习型基线共用同一冻结 A11 检查点、轨迹、风险预算和调参次数。

主指标固定为：事件召回相对完整时域基线下降不超过 0.01、误报预算满足时的平均归一化检测延迟。完整方法必须同时优于 `A4-10` 与 `A4-01`，并相对最佳公平早期基线降低至少 20% 延迟或观察步数。
