# 第四章双改造连贯性审计笔记

## 任务边界

- 候选机制一：冻结 XGBoost 强锚与 C11 源侧时间外折有界局部增量，目标是实体排序质量。
- 候选机制二：多工作点 BBSE 可行先验集、失配继续观察或回退、最坏情形约束停时，目标是部署误报率、检出率与观察量。
- 所有结论须区分文献事实、既有实验事实、设计推论和待证预测。

## 待核证据

- 权威恢复文档中的第三章冻结指标和第四章 v2 结果。
- Q0 失败结果及其对实体重采样路线的约束。
- BBSE 工作点失效比例、目标标签使用边界和 4% 误报率出处。
- 两个并行调研目录中的全文证据、强近邻与研究空白。

## 暂定判断

- “改造已有方法”可以构成创新，但必须改变问题结构、约束或可证明性质；仅把两个已知模块串联不够。
- 两机制是否连贯，取决于机制一输出能否定义机制二唯一消费的实体前缀风险状态，以及机制二能否在不回写或重新训练机制一的前提下施加部署约束。
