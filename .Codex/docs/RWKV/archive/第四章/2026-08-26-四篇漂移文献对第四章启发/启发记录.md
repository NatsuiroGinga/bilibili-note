# 四篇漂移文献对第四章的启发记录

## 结论

用户对第四章“骨架已立”的判断成立，但“只缺两次实验”必须限定为**当前 A 线最近两个源年有效性门**，不能写成完成两次即可证明跨年度有效或完成第四章定稿。

当前可执行边界是：

1. Tong 路径最大已经取得 LSPR23、种子 42、零训练源年 Q0 支持；仍待最终单模型训练、模型专属校准和源年独立评价完成验收。
2. 冻结分数阈值再校准已经两次同模型 Q0 有效否决，保持关闭。跨年度阈值只利用约 38% 经验误报预算的病灶仍存在，但当前没有合格解法。
3. 长度桶诊断支持重复曝光路径存在条件风险；反射累积只获最小 Q0 资格，尚未证明有效，而且它不解决跨年度阈值失配。
4. MADCAT 和 Berruz 分别提供长期漂移动机与评价组织依据。MalMoE 只能启发一个待验证的新问题类，不能直接写入当前方法。

总证据状态仍是：**机制一源年单种子 Q0 支持；反射累积实验待证；跨年度阈值失配无合格机制；第四章双机制算法尚未成立。**

## 二、已实验事实

### 2.1 重复曝光病灶与 Tong 路径最大

重复曝光病灶运行显示，从首曝到全部已记录曝光，实体 FPR 从 `0.0399957458` 升到 `0.0487167727`，DR 从 `0.9707112971` 升到 `0.9874476987`；新增 `1312` 个良性误报实体和 `4` 个恶意检出实体。这证明源年存在迟到检出收益与累计误报成本的联合病灶，不证明任何控制机制有效。

Tong 路径最大 Q0 随后通过预注册门：相对 B0 少 `434` 个 FP、多 `3` 个 TP，且六方向证书全部有效。其有限样本保证只覆盖冻结的 LSPR23 六方向和实体路径支持，不覆盖 LSPR24、无限寿命实体、长度条件子群或另一模型。

### 2.2 跨年度阈值失配与再校准否决

`ch4-drift-v2` 证明源年 4% 阈值迁入 LSPR24 后只达到 `1.53%` FPR，DR=`0.5505`；目标标签事后 4% 参考 DR=`0.6157`。该病灶仍存在，但目标参考只能作事后诊断。

两次同模型再校准 Q0 已关闭当前路线：第一次三方向证书全部失败且候选无 DR 增益；风险余量变体只有一个方向获证，降低 FPR 但 TP 不变。不得把“池化 FPR 仍低于 4%”用来覆盖逐方向证书失败。

### 2.3 长度条件风险与反射累积

M1 的总体 FPR=`3.7111%` 掩盖四个超预算长度桶，最高为 `101-1000` 桶的 `13.3356%`。这是长度条件风险的源年单种子诊断支持。

反射累积计划面向原子逐流中等证据的有界累积，并要求联合事件重新执行一次 Tong 校准。它仍处于最小 Q0 待证状态。四个 M1 漏检实体中只有一个路径最大值接近阈值；不存在“漏检普遍持续次高分”的证据。

**机制分层**：反射累积属于重复曝光时间维度的第二证据通道，不是跨年度阈值再校准的替代方案。把它写成“阈值失配机制二的当前解法”会混淆两个病灶，并可能借壳恢复已否决路线。

## 三、文献启发

### 3.1 MADCAT：动机，不是机制来源

MADCAT 物理 p.3、§4.2 与图 3 以 2012－2014 初训、2015－2018 月度测试展示静态 BinaryMLP 的总体逐步退化，而测试时训练版本保持较稳定表现。图中静态曲线并非单调。

第四章可引用的最窄动机是：**长期漂移下不能只报告单个终端点，应展示按时间展开的性能轨迹与适应成本。** MADCAT 不含实体路径、Tong 风险控制或加密流量，不能支撑当前机制效果。

### 3.2 Berruz：评价依据，不是效果基线

Berruz 物理 p.18、§3.4 用精度增量与重训效率建立帕累托前沿；物理 p.22、§3.5.4 式（13）定义一个可复现的“中位”代表点。该做法支持第四章采用“完整预算/效率前沿＋预注册代表点”的报告结构，避免只挑最好工作点。

边界有两条：

1. 代表点规则必须在源年合同中预注册，不能查看 LSPR24 后选取。
2. Berruz 物理 p.17 明确在测试集调模型超参数并称其为预言机上界，因此其绝对准确率、超参数和最终代表点不能作为本项目基线。

### 3.3 MalMoE：待验证新候选

MalMoE 物理 p.5 式（6）（7）以当前图的均值 readout 为门控输入，物理 p.8 表 III 显示移除图级输入后 Overall 门控准确率从 `0.8419` 降至 `0.8170`。直接证据只到：**图级上下文有助于漂移感知专家路由。**

对第四章的迁移问题可写成：

> 能否用严格因果、无标签的实体或群体上下文统计，选择若干预注册决策策略，同时让最终联合告警事件重新满足实体风险预算？

这是 `D3` 待验证候选，存在四个未决点：上下文统计量、专家/策略集合、门控监督信号、路由后联合事件的风险校准。MalMoE 的 readout 使用完整当前图且门标签来自专家损失，不直接满足本项目严格在线与无目标标签选择要求。

若推进，固定顺序为：`research-ideation → brainstorming → 新研究问题卡/新契约 → 最小可证伪实验`。在此之前不进入恢复卡活动候选、不写公式、不分配阈值、不实现代码。

**禁止借壳再校准**：两次同模型阈值再校准否决继续有效。新门控不得把旧阈值候选改名为“专家”，不得复用旧开发/校准/持出结果选择门，也不得让旧 Tong 证书覆盖路由后的新联合事件。

### 3.4 Wasswa：当前路线的边界

Wasswa 的潜空间对齐需要当前域 VAE 与 MLP 更新，并在预处理阶段删除时间戳。它代表表示层适应的竞争路线，不属于当前冻结 XGBoost 的决策层证据。只有当前决策层路线被真实实验否决且另立训练层合同后，才可重新讨论。
