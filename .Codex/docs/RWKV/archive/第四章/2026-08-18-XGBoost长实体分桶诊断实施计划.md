# XGBoost 长实体分桶诊断实施计划

> **研究路线**：`RESEARCH_ROUTE=RWKV`
>
> **状态**：设计已冻结，实验待证。

## 1. 目标

不重新训练 XGBoost，不重新选择适配器或幂指数，仅复用第三章已冻结的两份 800 树模型和源年折外选择结果，判断 XGBoost 在 LSPR24 长实体上是否出现与神经骨干相同的收益方向翻转。

本诊断只回答一个问题：`semantic168 + ELP` 相对 `raw83 + max` 的实体级收益，是否在 `101–1000` 与 `1001+` 两档转为负值，并伴随良性实体高分尖峰。

## 2. 输入与隔离

- 父运行：`runs/diagnostics/ch3-xgb-cpa-elp-gpu-oof-seed42-v1-rerun1`。
- 父评价：`runs/diagnostics/ch3-xgb-cpa-elp-gpu-oof-seed42-v1-rerun1-eval-continuation2`。
- 冻结模型：`model_raw83.json`、`model_semantic168.json`，每份必须恰为 800 树。
- 冻结选择：适配器 `semantic168`，`p_raw=2.0`，`p_semantic=1.0`。
- 入口必须校验父选择收据、有效配置收据、两份模型及父结果文件的 SHA-256；任一不符立即失败。
- 只在内存重建 LSPR24 的 `raw83` 与 `semantic168`，不得读取 LSPR24 后重新选择模型、适配器、幂指数、字段或分桶。

## 3. 四格与五档分桶

两份逐流分数只各计算一次，并复用为四个实体聚合格：

| 内部键 | 输入与模型 | 实体聚合 |
| --- | --- | --- |
| `raw_max` | `raw83` | `max` |
| `raw_elp` | `raw83` | 冻结 `p_raw=2.0` |
| `semantic_max` | `semantic168` | `max` |
| `semantic_elp` | `semantic168` | 冻结 `p_semantic=1.0` |

实体按完整 LSPR24 流数确定性分为：`1–2`、`3–10`、`11–100`、`101–1000`、`1001+`。每档报告：

- 实体数、正实体数、负实体数和流数；
- 四格实体平均精度；
- `semantic_elp - raw_max`、`semantic_max - raw_max`、`raw_elp - raw_max`；
- 正负实体分数的中位数、P90、P99 与最大值；
- 良性实体分数大于等于 0.9、0.99、0.999 的数量，只作为假阳尖峰诊断。

不得在单档中重新求最佳阈值或选择聚合器。告警预算曲线沿用父结果，不因本诊断重复扫描目标年阈值。

## 4. 机械裁决

- 若 `101–1000` 与 `1001+` 两档的 `semantic_elp - raw_max` 均小于 0，记为“XGBoost 复现长实体方向翻转”。
- 若仅一档小于 0，或任一档正实体少于 10，只记为“混合或低支持信号”，不得据此选择第四章基座。
- 若两档均大于等于 0，记为“XGBoost 未复现该病灶”，DTEP 不应直接以 XGBoost 为默认基座。
- 无论结果如何，本轮均为 `screening_only=true`、`formal_paper_evidence=false`；由于 LSPR24 已被观察，诊断结果只能用于候选筛选，不能冒充独立测试证据。
