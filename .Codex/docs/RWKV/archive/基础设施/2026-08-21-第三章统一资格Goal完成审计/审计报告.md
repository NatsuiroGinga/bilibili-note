- **日期**：2026-08-21
- **审计对象**：第三章“可微骨干与机制统一资格”Goal
- **结论**：**Goal 不能完成，保持 active。**
- **审计边界**：只核验当前已登记的本地制品、统一合同、恢复卡、统一总表实施报告、强基线运营回填报告和全容量 MLP 严格分析；不以本报告替代新的训练、回填或论文结论。

## 二、裁决依据

1. 统一合同要求新实施计划先完成模型/数据适配表和朱论文对位表，未完成不得实现、同步或启动；全容量 MLP 的已完成运行不满足这一实施前门，因此只能保留为实质 S2 信号，不升级为正式论文证据。
2. 当前强基线回填已关闭“无同轴首次告警实现”的旧缺口，但各模型仍未按同一实际 FP 预算共同取点。单个名义预算、不同 `actual FPR` 或空精确交集都不能支持完整运营前沿。
3. 全容量 MLP 的终端曲线并列悬崖和首次告警口径已证明：终端预算内读数不能移植为首次告警预算内读数，且不能拆并列组或插值补点。
4. 所以本轮只可写“源年开发支持保留资格候选”和“关键目标基线已回填”；不得写成“正式替代”“完整运营前沿”或“公平效率更优”。

## 三、最低阻断与非阻断项

**最低阻断项**：执行 N-16“共同实际首次告警 FP 预算包络”，先用既有历史系统作零训练资格核验；随后依据其共同预算裁决确定全容量 MLP 的去向。

**非最低阻断项**：N-12、N-13、N-14、N-15、GRANDE 和 CUDA-RWKV 是可选扩展或独立候选工作，不是当前 Goal 最低完成路径的前置条件。它们仍须遵守各自冻结合同，不能因本审计而被启动、改写或宣称已完成。

## 四、N-16：共同实际首次告警 FP 预算包络

### 任务目的

在不训练、不调参、不改阈值、不持久化逐流或逐实体分数的条件下，对已有系统的在线路径建立统一的实际首次告警 FP 预算包络，替代“空精确交集自动前沿”的错误判据。

### 冻结口径

1. 对每个模型沿其既有在线评分路径，以完整良性实体的 `path-max` 并列组计算全部可达首次告警点。
2. 公共横轴为整数假阳性实体预算 `k`。对每个模型和每个 `k`，只取所有实际 `FP <= k` 的可达点中最后一个阈值；不得拆同分并列组，不得插值，不得构造不可达阈值。
3. 对每个公共 `k` 同时比较终端 DR、首次告警未告警率和按 `exposure_index` 的及时检出阶梯；`exposure_index` 固定为实体内 1 基索引，不改写为秒级时延。
4. 覆盖全容量 MLP、XGBoost＋CPA-ELP、CNN、GRU 和 Transformer。输出只允许配置、输入/模型哈希、分母、完整并列组计数、公共 `k`、聚合指标、缺失原因和裁决；不得持久化分数、逐实体首次告警值或逐流明细。
5. 首先复用现有历史系统完成零训练资格核验。若任何模型缺少可重放在线路径、所需检查点或可在内存中计算的评分来源，明确列为缺失，不以反推、插值或额外训练补齐。

### 后续分支

- 若全容量 MLP 在共同预算包络中仍非支配：先补齐模型/数据适配表和朱论文对位表；将其明确登记为**新的正式身份**后，重跑冻结四格。事后补表不得伪装成旧运行的预注册依据。
- 若全容量 MLP 被共同预算包络支配：裁决当前候选不支持替代，或转入其他具备独立正式 S2 身份的候选；不得以增加扩展骨干、改变预算或回看 LSPR24 来回避该裁决。
