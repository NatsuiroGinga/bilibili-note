# 第三章全模型统一指标总表实施计划（N-09）

> **给执行者**：本计划按 `subagent-driven-development` 或 `executing-plans` 逐任务执行。
> 步骤用 `- [ ]` 复选框跟踪。

**目标**：建立第三章唯一的全模型指标总表，把分散在多个运行根、三套异构 schema 的原始制品，
聚合为 LSPR23 选择表、LSPR24 描述性评价表、资源表三张**相互分离**的表，输出 JSON、CSV 与 Markdown。

**架构**：单一聚合工具 + 独立来源配置。来源配置声明每个模型的运行根、相对路径、schema 类型与键路径映射；
工具只做「读取 → 归一化到统一列 → 分表 → 全精度判最强者 → 输出」，不含任何模型或训练逻辑。

**技术栈**：Python 3，仅标准库加 `numpy`（读 `.npz`）。`uv run --no-sync python` 入口。

**合同来源**：`.Codex/docs/RWKV/2026-08-20-第三章神经骨干跨进程协作看板.md` 第 4.9 节（提交 `6afaaff`）。

## 与技能默认的两处冲突及采纳理由

本计划用 `superpowers:writing-plans` 技能撰写，有两处按仓库规则覆盖技能默认：

1. **技能要求每步 TDD**（写失败测试 → 运行 → 实现 → 通过）。仓库根 `AGENTS.md` 规定
   「实验工程代码不创建或运行人工夹具、单元测试和集成测试。生产代码完成后只执行编译、
   导入或命令入口检查，随后尽快运行真实数据」。**采纳仓库规则**：每个任务的验收步骤替换为
   「入口检查 + 对真实制品运行 + 与已核验数值逐条对账」。真实制品对账比人工夹具更强，
   因为它直接暴露键路径错配与单位错误。
2. **技能要求计划落 `docs/superpowers/plans/`**。仓库约定过程文档落 `.Codex/docs/`。**采纳仓库规则**。

## 全局约束（逐条取自看板 4.9，不得放宽）

- 不修改任何模型训练代码。
- 三表分离：**禁止把不同年度或不同评价池混在同一排名**。
- 数字只从 `JSON`、`NPZ`、`NPY`、`CSV` 与状态收据读取；**禁止从 Markdown 抄数**。
- 缺失项保持空值并写明原因，不得猜测或用邻近值填充。

### 任务 2：读取层与 schema 适配

**文件**
- 新建：`thesis/experiments/llm_probe/tools/ch3_build_metrics_table.py`

**接口**
- 产出：`read_source(root_path, model_entry) -> dict | None`，返回统一字段字典，键为
  `flow_ap`、`entity_ap`、`max_entity_ap`、`dr_curve`（六档 `dict`）、`selected_epoch`、
  `validation_flow_ap`、`selected_p`、`parameter_count`、`training_seconds`、
  `evaluation_seconds`、`gpu_hours`、`peak_gpu_mib`、`peak_rss_mib`。
  取不到的键置 `None`，不抛异常。
- 产出：`CANONICAL_COLUMNS`（列表），三表共用的列顺序来源。

- [ ] **步骤 1：写四个 schema 适配器**

四个适配器逐一对应第一节表格中的 A、B、C、D。关键点是**同名不同义**：
`fairsel_2x2` 的主口径实体 AP 在启用幂平均的格取 `e_lp`、未启用的格取 `e_max`，
不能一律取 `e_max`；`baselines_full` 只有单档检出率，六档中其余五档置 `None` 并记原因。

```python
def _adapt_baselines_full(doc, cell):
    node = doc
    for part in cell.split("."):
        node = node.get(part, {}) if isinstance(node, dict) else {}
    if not node:
        return None
    return {
        "flow_ap": node.get("flow_ap"),
        "entity_ap": node.get("ent_ap_max"),
        "max_entity_ap": node.get("ent_ap_max"),
        "dr_curve": {"fpr_0.04": node.get("dr_at_fpr_max")},
        "dr_curve_note": "该来源只持久化 4% 单档，其余五档不可得",
        "selected_epoch": node.get("sel_epoch"),
        "validation_flow_ap": node.get("val_ap"),
        "selected_p": node.get("p"),
        "parameter_count": node.get("npar"),
        "training_seconds": node.get("tr"),
        "evaluation_seconds": node.get("ev"),
        "gpu_hours": None, "peak_gpu_mib": None, "peak_rss_mib": None,
    }


def _adapt_fairsel_2x2(doc, cell):
    node = doc.get("cells", {}).get(cell)
    if not node:
        return None
    uses_lp = cell in ("C01", "C11")
    return {
        "flow_ap": node.get("fap"),
        "entity_ap": node.get("e_lp") if uses_lp else node.get("e_max"),
        "max_entity_ap": node.get("e_max"),
        "dr_curve": {"fpr_0.04": node.get("dr_main")},
        "dr_curve_note": "该来源只持久化 4% 单档，其余五档不可得",
        "selected_epoch": node.get("sel_epoch"),
        "validation_flow_ap": node.get("val_ap"),
        "selected_p": node.get("p"),
        "parameter_count": node.get("npar"),
        "training_seconds": node.get("tr"),
        "evaluation_seconds": node.get("ev"),
        "gpu_hours": None, "peak_gpu_mib": None, "peak_rss_mib": None,
    }


def _adapt_protocol_a_v1(doc, cell):
    sel = doc.get("source_selection", {}).get("cells", {}).get(cell, {})
    tgt = doc.get("target_evaluation", {}).get("cells", {}).get(cell, {}).get("target", {})
    res = doc.get("resource", {})
    if not tgt:
        return None
    return {
        "flow_ap": tgt.get("flow_average_precision"),
        "entity_ap": tgt.get("entity_average_precision"),
        "max_entity_ap": tgt.get("maximum_entity_average_precision"),
        "dr_curve": dict(tgt.get("dr_at_fpr", {})),
        "dr_curve_note": "",
        "selected_epoch": sel.get("selected_epoch"),
        "validation_flow_ap": sel.get("validation_flow_ap"),
        "selected_p": sel.get("p_at_selection"),
        "parameter_count": res.get("parameter_count") or doc.get("model", {}).get("parameter_count"),
        "training_seconds": res.get("training_wall_seconds_sum"),
        "evaluation_seconds": res.get("evaluation_wall_seconds_sum"),
        "gpu_hours": res.get("gpu_hours"),
        "peak_gpu_mib": res.get("peak_gpu_allocated_mib"),
        "peak_rss_mib": res.get("peak_process_rss_mib"),
    }


def _adapt_xgb_cpa_elp(doc, cell):
    node = doc.get("cells", {}).get(cell)
    if not node:
        return None
    return {
        "flow_ap": node.get("flow_ap"),
        "entity_ap": node.get("ent_ap"),
        "max_entity_ap": node.get("ent_ap") if node.get("p") is None else None,
        "max_entity_ap_note": "该来源未单独持久化取最大聚合读数" if node.get("p") is not None else "",
        "dr_curve": dict(node.get("dr_curve", {})),
        "dr_curve_note": "",
        "selected_epoch": None, "validation_flow_ap": None,
        "selected_p": node.get("p"),
        "parameter_count": None,
        "parameter_count_note": "树集成不适用可训练参数量",
        "training_seconds": doc.get("timing", {}).get("train_seconds"),
        "evaluation_seconds": doc.get("timing", {}).get("eval_seconds"),
        "gpu_hours": None, "peak_gpu_mib": None, "peak_rss_mib": None,
    }


ADAPTERS = {
    "baselines_full": _adapt_baselines_full,
    "fairsel_2x2": _adapt_fairsel_2x2,
    "protocol_a_v1": _adapt_protocol_a_v1,
    "xgb_cpa_elp": _adapt_xgb_cpa_elp,
}
```

- [ ] **步骤 1：写分表与判优**

三表的列**互不重叠**，这是「禁止混排」的机械实现：LSPR23 表只含选择期字段，
LSPR24 表只含目标年字段，资源表只含开销字段。

```python
LSPR23_COLUMNS = ["display_name", "config_type", "differentiable", "run_id",
                  "selected_epoch", "validation_flow_ap", "selected_p",
                  "evidence_level", "source_path"]

LSPR24_COLUMNS = ["display_name", "config_type", "differentiable", "run_id",
                  "flow_ap", "entity_ap", "max_entity_ap",
                  "dr_fpr_0.001", "dr_fpr_0.005", "dr_fpr_0.01",
                  "dr_fpr_0.02", "dr_fpr_0.04", "dr_fpr_0.08",
                  "dr_curve_artifact", "evidence_level", "source_path"]

RESOURCE_COLUMNS = ["display_name", "differentiable", "run_id", "parameter_count",
                    "training_seconds", "evaluation_seconds", "gpu_hours",
                    "peak_gpu_mib", "peak_rss_mib", "evidence_level", "source_path"]


def mark_best(table, columns):
    """同一表内按全精度判最强者；并列全部标 tied_best。缺失不参与。"""
    for column in columns:
        values = [(i, r[column]) for i, r in enumerate(table)
                  if isinstance(r.get(column), float)]
        if not values:
            continue
        top = max(v for _, v in values)
        winners = [i for i, v in values if v == top]
        flag = "best" if len(winners) == 1 else "tied_best"
        for i in winners:
            table[i].setdefault("best_flags", {})[column] = flag
    return table
```

判优只在**同一张表内**进行，且 `LSPR23_COLUMNS` 与 `RESOURCE_COLUMNS` 中
只有 `validation_flow_ap` 参与判优——`selected_epoch`、`training_seconds` 等不是「越大越好」，
不得判优。资源表的时间、显存、参数量一律**不判最强者**，只如实列出。

`provenance.json` 记录每个来源文件的绝对路径、`SHA-256`、字节数与读取时间，
使总表的每个数字可回溯到具体制品。Markdown 中缺失值写 `—` 并在表下逐条列出原因。

```python
def write_outputs(tables, out_dir, provenance):
    import csv, json, pathlib
    out = pathlib.Path(out_dir); out.mkdir(parents=True, exist_ok=True)
    written = []
    for name, (rows, columns) in tables.items():
        (out / f"{name}.json").write_text(
            json.dumps(rows, ensure_ascii=False, indent=2), encoding="utf-8")
        with (out / f"{name}.csv").open("w", newline="", encoding="utf-8") as fh:
            writer = csv.DictWriter(fh, fieldnames=columns, extrasaction="ignore")
            writer.writeheader()
            for row in rows:
                writer.writerow({c: ("" if row.get(c) is None else row.get(c)) for c in columns})
        (out / f"{name}.md").write_text(_render_markdown(rows, columns), encoding="utf-8")
        written += [str(out / f"{name}.{ext}") for ext in ("json", "csv", "md")]
    (out / "provenance.json").write_text(
        json.dumps(provenance, ensure_ascii=False, indent=2), encoding="utf-8")
    written.append(str(out / "provenance.json"))
    return written
```
