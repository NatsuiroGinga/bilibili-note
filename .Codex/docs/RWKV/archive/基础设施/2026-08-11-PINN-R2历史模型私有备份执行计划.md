# PINN/R2 历史模型私有备份执行计划

## 目标

将 C56 上已批准的 13 个历史 PINN/R2 运行目录中允许范围的模型制品安全备份至 Hugging Face 私有模型仓库；仅在远端、本机与 Hub 清单闭合后精确删除这些目录。

## 固定边界

- 允许：模型权重、检查点、LoRA/适配器、配置、核心指标、必要训练日志，以及相对路径、字节大小、SHA-256 清单。
- 排除：原始数据、预测明细、缓存、虚拟环境、凭据。
- 删除：仅 13 个经核验的精确运行目录；不使用通配符，不删除父目录。

## 阶段

- [x] 阶段 1：恢复路线、读取历史备份边界和认证条件。
- [ ] 阶段 2：只读核验 C56 身份、磁盘和 13 个目录，生成允许范围清单。
- [ ] 阶段 3：回传允许制品并复算本机 SHA-256。
- [ ] 阶段 4：创建私有 Hub 仓库、上传并核验文件清单闭合。
- [ ] 阶段 5：精确删除远端目录，核验不存在并记录释放后的磁盘空间。
- [ ] 阶段 6：写入执行收据并向任务负责人报告。

## 验收条件

1. Hub 仓库为私有模型仓库。
2. 本机清单与 Hub 文件列表、大小和 SHA-256 一致。
3. 13 个远端目录均在删除后不存在，且未触及父目录。
4. 记录删除后 `df -Pk /root/autodl-tmp`。

**当前为阶段 2，受阻**：C56 身份与磁盘只读核验通过，当前 `df -Pk /root/autodl-tmp` 可用 `58,037,708 KiB`。历史备份文档只说明“13 个指定目录”，未给出精确路径；远端存在超过 13 个名称相近的 PINN/R2 运行目录，不能据名称推断批准范围。已向任务负责人索取原始精确路径清单；任何失败或范围不明均停止在传输和删除前。
