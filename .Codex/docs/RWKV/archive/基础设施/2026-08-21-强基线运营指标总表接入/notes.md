# 强基线运营指标总表接入笔记

## 现有接口

- `ch3_build_metrics_table.py` 已有完整曲线读取、按实际 FPR 重算六档 DR、首次告警读取、年度隔离和溯源哈希逻辑。
- 旧 `baselines_full` 与 `xgb_cpa_elp` 适配器只保存历史标量，不能直接得到完整曲线。
- 全容量 MLP 适配器包含双年度完整指标，但本次四条回填只有目标年完整曲线，不能照搬为双年度证据。

## 当前裁决

- 使用“目标年运营覆盖层”叠加到旧适配结果，而不是替换旧来源适配器。
- 覆盖层只替换目标年排序与运营指标，不替换源年选择、源年性能和训练资源。
- 缺少源年完整曲线继续作为明确缺失项保留。

## 待核

- 两种回填 NPZ 的成员命名不同，覆盖层须分别适配并映射到统一内部结构。
- XGBoost 最终状态位于启动器状态或 stage 状态，神经回填状态位于运行根，配置须分别明确。
- 后处理资源不应进入模型训练效率支配向量。
