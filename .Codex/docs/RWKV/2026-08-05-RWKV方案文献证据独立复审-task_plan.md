# RWKV 方案文献证据独立复审计划

## 目标

基于可核验的一级全文证据，裁决当前 RWKV 双创新点系统方案是否足以作为 PINN 路线失败后的独立论文备选主题，并明确允许主张、禁止主张、证据缺口与最小下一动作。

## 任务边界

- 研究期：2023—2026；必要的经典理论前置可放宽。
- 主题：RWKV-7/8、长时序恶意流量或网络异常状态检测、状态记忆、入侵检测、课程学习、约束强化学习。
- 核心来源：`raw/papers/rwkv/`、现有三份 RWKV 方案或检索文档、RWKV 官方论文和代码、可核验的论文原始页面。
- 强制发现入口：`https://www.rwkv.cn/eco/papers`；重点复核 Decision-RWKV、MARWKV、多智能体强化学习、课程／自步学习、早期检测和异常检测条目，但目录题录不能替代一级全文。
- 不修改论文正文、恢复文档或实验代码；不启动训练；不虚构 Zotero 导入或全文状态。
- 用户新增边界：UGR'16 非加密不构成否决理由；重点核验分钟级聚合标签能否支撑“恶意流量检测”，并比较“长时恶意流量检测”与“网络异常状态检测”的命名边界。

## 关键问题

1. 当前方案引用的论文身份、全文和具体技术主张是否真实匹配？
2. RWKV 状态记忆用于长时网络安全序列的理论新意，是否超出已有 RWKV、RWKV-TS、PLM-NIDS 和状态空间流量分类工作？
3. “多尺度状态记忆”与“难度感知课程＋约束强化学习”是否责任不同、计算图相连且可独立消融？
4. UGR'16 的分钟级聚合与标签语义究竟允许“恶意流量检测”还是仅允许“网络异常状态检测”？
5. 当前方案能否形成可证伪、单卡可先导验证的实验合同，还是只停留在概念拼接？
6. 固定离线流量数据是否足以定义强化学习环境；若把 RWKV 状态用于“继续观察／告警／拒识”，约束强化学习、离线强化学习、上下文赌博机与最优停止中哪一种设定可识别且可验证？
7. 课程难度分布如何与约束策略联动，哪些可证明性质和实验门槛足以形成独立训练创新？

## 验收标准

- 核心全文至少 8 篇；若不足，列出缺失全文并停止扩大主张。
- 每个核心论断附论文身份、全文证据位置、允许主张和禁止主张。
- 单列课程学习与强化学习融合章节，输出“主线采用／条件采用／否决”，不得仅凭摘要或综述下结论。
- 现有方案中的引用逐项核验；区分全文证据、仅元数据／摘要和二手线索。
- 报告包含候选数、去重数、全文分析数、仅摘要数、纳入数、排除数与缺失清单。
- Markdown 结构与链接可读；路径、论文数和证据位置可复核。
