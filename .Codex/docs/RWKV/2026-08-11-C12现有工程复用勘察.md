- 日期：2026-08-11

## 结论

C12 不能直接裁剪现有 LSPR24 G0 或 5 秒宽表制品，必须先物化新的跨年度流级主产品和 2-IP 序列缓存。最短正确路径是：复用现有 Rust 工具箱的通用确定性排序、规范编码、原子发布能力，新增跨年度 Rust 物化器；在 Python 侧新增 C12 专用统一加载、模型和训练评价入口，并仅复用既有训练入口的运行工程模式。

## 3. 是否可直接裁剪现有制品

**不可以，必须先实现新的 Rust 跨年度物化器。**

依据：

- C12 需要 LSPR23 ZIP/CSV 与 LSPR24 Parquet 的共同主产品；现有 G0 只读取 LSPR24 Parquet。
- C12 的序列单位是无向 2-IP 完整流，排序键为 `available_ns`，而现有制品是由 `External_*` 生成的端点 5 秒窗口。
- 现有宽表已含合同明确禁止的 IP 派生方向统计，列裁剪无法消除这些聚合语义对行、序列和历史关系的影响。
- 现有加载器的最终区防护不能替代 C12 所需的四角色隔离、目标前缀标签不可达与标签旁车连接。
- 规模为 LSPR23 10.59 GB CSV 加 LSPR24 20,227,356 行；按运行合同，新性能敏感物化热路径默认 Rust，且必须具备有界内存与确定性排序收据。

## 4. 阻止真实实验启动的接口缺口

1. 没有可发现两年度主产品、标签旁车、字段清单、2-IP 序列清单、角色切点和语义哈希的跨年度 `experiment-manifest`。
2. 没有从 LSPR23 流式 CSV 与 LSPR24 Parquet 按字段名投影、统一数值类型并拒绝非有限值的物化入口；LSPR23 也没有已实现的 ZIP 流式解析。
3. 没有无向 `2-IP` 受控侧车键、`available_ns` 稳定排序、年度/角色断开和长度 128 非重叠块实现。
4. 没有目标前缀无标签加载接口；现有批对象强制包含标签，无法证明 M2 或评价器不可读取目标前缀标签。
5. 没有 77 个共同字段加 `x_missing`、`padding_mask`、`delta_t_us` 的 Arrow/Parquet 模式及 Python 张量映射。
6. 没有 C12 规定的中位数/IQR 归一化、Protocol 冻结词表与 UNK/MISSING 规则。
7. 没有 C12 的 `B0/M1/M2/M1M2` 模型接口、M1 状态门统计和 M2 停止梯度可信门。
8. 没有源验证阈值冻结、目标开发预测后标签连接、预注册指标和按 2-IP 序列自助区间实现。
9. 没有 C12 运行制品清单、运行名、`final_accessed=false` 运行时断言或最多两进程的远程启动器。
