# 路径最大与反射累积证据候选方案及零训练诊断计划

> **执行要求**：实现代理使用 `subagent-driven-development` 与 `daily-coding`；主进程负责远端同步、启动、监控和结果回读。

- **冻结边界**：本轮只读 LSPR23，复用既有三个折外 XGBoost 模型、六个同模型交叉校准方向和既有阈值，不训练、不调参、不读取 LSPR24、不持久化逐流或逐实体分数。

## 二、推荐方案

第四章候选明确组织为“两个证据机制＋一个统一算法”，而不是把 Tong 次序阈值重复包装为两个机制：

| 层级 | 名称 | 解决的问题 | 当前状态 |
| --- | --- | --- | --- |
| 证据机制一 | 强证据路径保持 | 任意一次强恶意证据不被后续曝光稀释 | LSPR23 单种子 Q0 支持 |
| 证据机制二 | 反射累积证据 | 连续中等证据未达到单次强阈值 | 零训练病灶诊断待运行 |
| 统一算法 | 有限样本风险校准双证据序贯告警 | 将两个证据通道合成一个实体告警事件，并控制假阳率 | 实验待证，名称暂定 |

### 2.1 证据机制一：强证据路径保持

机制一保留任意一次强恶意证据。对实体 `e` 的序贯分数轨迹 `s_{e,j}` 定义路径最大统计量：

```text
Z_e = max_j s_{e,j}.
```

在线端在第一次严格越过阈值时告警，不需要等待实体结束。路径最大值是机制本体；Tong 次序阈值属于后述统一风险校准层，不应被当作第二个证据机制。

### 2.2 证据机制二：反射累积证据

机制二面向“单次分数均未达到强证据阈值，但中等强度证据连续出现”的路径。候选序贯状态应满足：

1. 连续中等强度证据能够累积；
2. 证据转弱时状态自动回落，不永久保存历史噪声；
3. 单个实体只维护有界状态，在线更新不依赖未来总长度；
4. 累积参考值、增量和边界必须由源年独立数据或全文公式确定，禁止凭结果设置常数。

本轮不冻结具体递推公式。先诊断真实漏检轨迹是否具有上述信号，避免在不存在的病灶上增加机制。

### 2.3 统一算法：有限样本风险校准双证据序贯告警

统一算法的暂定执行顺序为：

1. 强证据通道产生路径最大统计量，保存单次强证据；
2. 反射累积通道产生序贯累积轨迹，保存连续中等证据并在证据转弱时回落；
3. 在开发实体上冻结两个通道的尺度与合成规则，形成一个实体级联合统计量；
4. 在与开发实体独立的良性校准实体上，只对该联合统计量执行一次 Tong 次序阈值校准；
5. 在线端对冻结的联合事件首次严格越界时告警。

Tong 是两个证据通道共享的有限样本风险校准层：它不产生反射累积轨迹，也不解释持续弱证据。组合只对一个最终联合事件作风险控制，不把 4% 假阳率预算机械拆给两个分支，也不依赖 LSPR25 才能完成 LSPR23 源年资格。

如果反射累积统计量只是替换原 M1 的路径最大统计量，它只算替代臂。只有它在 M1 漏检实体上新增检出或稳定提前告警，并对 `M1 或反射累积` 的联合事件重新校准，才允许称为互补机制。

禁止先分别校准两个通道，再未经联合校准直接取并集。两个单通道各自满足 4% 假阳率，不能推出其并集仍满足 4%。

### 2.4 输入构造的既有比较与当前冻结理由

当前固定 `semantic168` 不是因为没有尝试其他构造，也不是把它预设为永久最优。既有比较必须按“输入构造、聚合变体、训练变体”分开解释：

| 类型 | 构造或变体 | 已有证据 | 裁决 |
| --- | --- | --- | --- |
| 输入构造 | `raw83` | 83 个冻结合法字段，是无上下文输入基线 | 保留为输入层基线 |
| 输入构造 | `mean166` | `raw83` 加 83 维块内因果前缀均值；与 `semantic168` 使用相同 LSPR23 三折、树预算和实体折外 AP 参与适配器选择 | 未被源年折外选择选中 |
| 输入构造 | `semantic168` | `raw83` 加 76 维数值残差、5 维类别前缀频率、2 维布尔前缀真值率、`log1p_prefix_count` 与 `is_segment_start`；由 LSPR23 实体折外选择冻结 | 当前第三章 XGBoost 输入；不是第四章新机制 |
| 输入构造 | `fixed_dyadic251` | `semantic168` 加固定二进多尺度近期混合；源年三折实体 AP 差值为 `-0.005899/-0.000762/+0.000684`，汇总 `-0.002455` | 未通过预注册方向门，已否决 |
| 聚合变体 | 按实体长度调整 `p(n)` | 即使使用目标标签作不可部署的逐桶上界诊断，两个长桶只追回 `0.44/2.63` 个百分点，拼装总体实体 AP 仍下降 `1.13` 个百分点 | 病灶不在单一聚合指数，降为附属消融 |
| 训练变体 | 实体均匀训练与直接实体 AP | 四格实体 AP 为 `0.456385/0.289224/0.315899/0.423494`，两个尾桶增量为 `-0.107040/-0.071834` | 已否决，不重复运行同义变体 |

当前机制二的零训练诊断**尚未比较不同输入构造**。本轮固定 `semantic168`，只改变实体序贯证据规则，目的是把反射累积证据的作用与输入表示变化分开；否则即使指标变化，也无法判断来自新证据机制还是新特征。

只有满足以下条件之一，后续实验才允许重新打开输入构造：

1. 零训练诊断证明 M1 在长实体或高曝光实体上仍存在条件 FPR 超预算或 DR 下降，但反射累积证据不能解释或修复该病灶；
2. 同一冻结序贯规则下，`raw83` 与 `semantic168` 的配对消融证明主要差异来自逐流评分轨迹而非决策层；
3. 新构造具有明确的可观测量、文献或数据依据、共同预算基线和源年失败门，不依赖 LSPR24 标签选择。

若反射累积病灶成立，下一阶段最小输入消融固定为 `raw83＋路径最大`、`semantic168＋路径最大`、`semantic168＋反射累积联合事件` 三臂。不得在该阶段同时搜索新维度、新窗口和新阈值。

## 三、文献边界

- Huang 与 Veeravalli 的有限时域最快变化检测直接研究有限路径上的假警概率与检测时延权衡，是当前最强 D2 近邻。其独立观测与真实变点假设不能直接迁移到相关的 XGBoost 前缀分数。
- TEASER 提供连续证据确认的强基线，但没有实体假阳率证书，连续次数与检查间隔不能未经选择门直接作为本方法常数。
- 路径难负样本训练与病灶直觉相符，但尚无足够直接的全文支撑且需要解冻模型训练，只保留为备选。
- 当前未发现 D3 完整同构。该结论限于已登记的全文与检索范围，不构成全球首创证明。

详细证据见 [第二机制重构文献证据矩阵](2026-08-19-第四章第二机制重构/文献/证据矩阵.md)。

## 四、第三章残余问题

1. XGBoost 的完整机制格相对原始输入格，在 `101–1000` 与 `1001+` 实体桶的实体 AP 分别下降 `0.073974` 和 `0.018679`。
2. 机制一 M1 只报告总体实体 FPR `0.03711089397172313`、DR `0.9832635983263598`，尚未报告固定五桶的条件 FPR、DR。
3. M1 当前漏检 `4/239` 个正实体，但既有制品不含实体轨迹，无法判断其是否为“持续中等分数、无单次极高分”的路径。
4. 既有逐桶结果说明长实体方向翻转，不等于证明 M1 后仍有同一病灶，也不证明感知机与 XGBoost 具有相同根因。

## 五、零训练快速诊断

### 5.1 输入与比较臂

- 读取既有 LSPR23 七个冻结数组、三个折外 XGBoost 模型、父恢复证明和 M1 `summary.json`。
- 机械重建原三个外折、每折两个确定性半折和六个校准到评价方向。
- 比较臂固定为：`B0` 首次曝光源阈值、`B1` 全曝光固定源阈值、`M1` Tong 路径最大阈值。
- 五个离线诊断桶固定为 `1–2`、`3–10`、`11–100`、`101–1000`、`1001+`。最终总长度只用于封印后的离线分桶，禁止进入在线告警规则。

### 5.2 输出

每个方向、方法和长度桶只输出聚合统计：

- 良性实体数、正实体数、FP、TP、FPR、DR；
- `M1-B0`、`M1-B1` 的 FP、TP、FPR、DR 差值；
- 首次告警曝光序号与原始时间差的描述性分位数、从未告警实体数；
- M1 漏检正实体的路径长度、路径最大值、均值、中位数及上尾分位数相对该方向阈值的描述性摘要；
- 最坏桶 FPR、桶间 FPR 差和长桶支持数；
- 输入哈希、模型哈希、覆盖数、时间顺序、重复覆盖、训练数与目标年读取数。

不落盘实体键、逐流分数、逐实体分数或可反推原始样本的明细。

### 5.3 有效性门

1. 总体 `B0/B1/M1` 的分母、FP、TP、FPR、DR 必须逐项等于既有 M1 `summary.json`；任一不一致即诊断无效并停止科学裁决。
2. 必须覆盖全部 `16,353,511` 条 LSPR23 流，三个模型各加载一次，训练数为 `0`，目标年数组读取数为 `0`。
3. 长度桶必须覆盖全部评价实体且互斥；最终长度不得参与阈值、分数或首次告警计算。

### 5.4 候选裁决

- 若 M1 的两个长桶均不超过冻结主预算 `q=0.04`，且相对 B0 不出现 DR 下降，则“长实体条件风险”不成立。
- 漏检轨迹统计只用于判断是否值得定义反射累积递推，不作为阈值选择。具体累积参考值与校准合同必须在读取诊断结果后根据全文和源年独立角色另行预注册，禁止从 LSPR24 或最终评价结果选择。
- 若长桶条件风险不成立，并且 M1 漏检轨迹未呈现可区分于未告警良性实体的持续次高分结构，则立即否决机制二。
- 若至少一个病灶存在，下一步才建立“路径最大”“反射累积替代臂”“路径最大或反射累积联合臂”三臂源年 Q0，并对联合事件重新做 Tong 校准。
