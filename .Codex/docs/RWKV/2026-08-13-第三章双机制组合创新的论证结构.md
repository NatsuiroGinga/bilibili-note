## 1. 朱焱雷第三章的实际写法（全文核验）

### 1.1 两个机制都不是首创，他自己写明了出处

| 机制 | 出处（他的正文原话） | 位置 |
| --- | --- | --- |
| **DS 课程难度调度** | 「Bengio 等人**[61]** 提出的课程学习理论」<br>「Cai 等人**[62]** 验证了课程机制的有效性，提出了**课程对抗训练（CAT）**」 | §2.3.3 |
| **RGO 二阶反应梯度** | 「Roth**[60]** 等人提出了**展开优化技术**，将下层攻击者的 K 步迭代优化过程视为计算图的一部分」 | §2.3.2 |

**关键观察**：CAT 已经叫「课程对抗训练」——**"课程 + 对抗训练"这个组合本身都是 [62] 的**。
双层优化式 (2.10)、全导数式 (2.11) 是教科书形式。

§2.3.3 的收尾句定了基调：

> 这为本文解决 **ET-BERT 等大模型在对抗训练初期的不收敛问题**提供了重要的理论指导。

**前人工作被写成「解决我这个具体问题的理论依据」，不是写成自己的发明。**

### 1.2 他自己的增量（三样，都具体）

1. **调度的具体形式**：式 (3.4) ϵ(t) 线性热身、式 (3.5) K(t) 阶梯调整、以及攻击步长——**三个维度联动**。CAT 只调强度。
2. **落到本领域**：加密流量分类 + ET-BERT / BUPT-CNN 双骨干，前人是图像。
3. **组合的实测超可加**。

### 1.3 两个机制在结构上正交（§3.3.1）

| | DS（模块一） | RGO（模块二） |
| --- | --- | --- |
| 位置 | **外层循环** | **内层循环** |
| 角色 | 控制中枢——调度 ϵ(t)、K(t) | 计算引擎——算二阶全导数 |
| 管什么 | 训练难度怎么变 | 每步梯度怎么算 |

他的原文：「DS 构建平滑初始优化曲面、RGO 提供后期精准寻优方向」。
**一个管优化路径的形状，一个管每一步走哪。所以能叠加而不冗余。**

### 1.4 组合创新的证明格式（表 3-7，p.42）

```
骨干网络      变体        核心组件        PGD-20 RA    相对提升
BUPT-CNN     Baseline    PGD-AT         55.60%        —
             DS-AT       PGD + DS       56.50%      +0.90%
             RGO-AT      PGD + RGO      60.20%      +4.60%
             DS-RGO      DS + RGO       64.90%      +9.30%    ← 单模块之和 5.50%

ET-BERT      Baseline    PGD-AT         63.50%        —
             DS-AT       PGD + DS       66.20%      +2.70%
             RGO-AT      PGD + RGO      69.80%      +6.30%
             DS-RGO      DS + RGO       75.80%     +12.30%    ← 单模块之和 9.00%
```

他的结论句：

> 完整版 DS-RGO 在 ET-BERT 上总提升 12.30%，**超越单一模块增益总和 9.00%**

**这是 2×2 交互设计**：Baseline / 只有 A / 只有 B / A+B，然后显式比较「组合增益 vs 单模块增益之和」。

## 2. 映射到本课题第三章

### 2.1 我原来的配对是错的

原计划：

- 机制一（表示层）：同一 2-IP 对上的因果前缀聚合
- 机制二（决策层）：同一 2-IP 对上的实体分数聚合

**按朱的正交性标准，这两个不正交**：同一个键、同一份信息、同一种操作，只是在不同层做了两遍。
2×2 的交互项大概率为零——组合会塌。

### 2.2 改用的配对

照朱的「控制 vs 计算」分法：

| | **机制一（计算）** | **机制二（控制）** |
| --- | --- | --- |
| 管什么 | 什么上下文进入表示 | 表示如何跨年度保持稳定 |
| 内容 | 因果前缀聚合：单条流吸收同实体历史 | 有界性 / 在线实例归一化：抑制跨年度分布漂移 |
| 已有证据 | B > A（`0.1848` \~ `0.2879` vs `0.1590`） | D4 vs D5（`0.0675` vs `0.2173`） |
| 待验 | 三种子确认 | 单因子消融 S2/S3（运行中） |

**正交性**：一个决定「看多少历史」，一个决定「看到的东西换了一年之后还成不成立」。
第二条正对着论文的实际主题——跨年度迁移。

**实体级聚合降级为评价协议，不作为创新点**。它本来就是 Gehri 2023 已有做法。

### 2.3 两个机制的谱系（照实写进 §2.x）

| 机制 | 前人来源 | 精确位置 | 本课题改造 |
| --- | --- | --- | --- |
| **一：因果前缀聚合** | Lee & Stolfo 2000, TISSEC | Table VIII, p.243，`past two seconds same-host count` | 定长 2 秒滑窗 → **无界扩展前缀**；手工计数 → **可微表示**；单主机 → **2-IP 无向边** |
| | Vision-RWKV, ICLR 2025 | 式 (5)；Table 5 消融 `71.1 → 75.1` | 双向非因果 → **严格因果** |
| **二：有界性控制** | RevIN, ICLR 2022 | Eq.1–3, p.4；§4.2.2 p.8 Table 3 | 整窗静态统计量 → **实体键上的在线扩展统计量** |
| | RWKV-7 delta 移除键 | 官方实现 | 联想记忆纠错 → **状态封顶**（作用重解释，待 S2/S3 验证） |

**改造与朱同构**：他把 CAT 的「调强度」细化成三维联动；本课题把 RevIN 的「整窗静态统计量」改成「实体键上的在线扩展统计量」。都是把已有机制在本领域具体化，不是发明新机制。

### 2.4 RevIN 的引用边界（代理全文核验，不得越界）

- **支持诊断**：§4.2.2 p.8 Table 3 明确写批归一化 "can not reduce the discrepancy between the training and test data distributions"。本课题用 LSPR23 全局 `mu/sd` 标准化 LSPR24，正是该问题。
- **不支持搬法**：RevIN 的「实例」是**整窗静态**统计量；因果前缀是**逐步扩展的在线**统计量。**原文未定义也未验证后者。**
- 结论：只能写成「受 RevIN 启发的新构造」，不能引 RevIN 当依据。

## 3. 预注册的 2×2 交互实验

### 3.1 设计

| | 无有界性控制 | 有有界性控制 |
| --- | --- | --- |
| **无因果前缀聚合** | A00 | A01 |
| **有因果前缀聚合** | A10 | A11 |

- 三种子 42/43/44，报均值与区间
- 四格**必须同一评价口径**（逐流 AP 先验 `0.0257073138`，实体级先验 `752/47115 = 0.0160`，分母不同不可混排）
- 同 83 字段、同 4000 步、同 BS=64、同 LSPR23→LSPR24 零样本

### 3.2 判据（跑之前写定）

```
组合成立：  (A11 − A10) > (A01 − A00)  且差值超过合并标准差
组合不成立：交互项 ≤ 0，或差值落在噪声内
```

**交互项为零或为负时照实写，不改判据凑超可加。**

### 3.3 当前证据缺口

| 格 | 现状 |
| --- | --- |
| A00 | 逐流 MLP `0.1590128242` |
| A10 | B 档 `0.1848481203` \~ `0.2878764332`（同配置单种子方差 ±0.10） |
| A01 | 只有 XGBoost 分数 + 实体聚合 `0.5233`–`0.5475`，**编码器不匹配，不能用** |
| A11 | **从未跑过** |

四格里没有一组是干净可比的。**2×2 必须重跑全部四格。**

## 4. 不采用朱的两处做法

| 他的做法 | 问题 | 本课题的做法 |
| --- | --- | --- |
| 表 3-7 无误差棒、无多种子 | 本课题实测 B 档同配置单种子 AP 在 `0.1848481203` 与 `0.2878764332` 之间波动，跨度 `0.103` | 三种子起，报均值、标准差、区间 |
| 「二者融合是……的充要条件」 | 从一张单次运行的表得出充要条件，过强 | 写成「在本实验条件下观察到超可加」，给区间 |

**Jacobs CCS 2022（`raw/papers/datasets/data-protocol/2022-Jacobs-AI-ML-Network-Security-Emperor-No-Clothes-CCS.pdf`）列了 9 条评价失效项，本课题今晚已犯两项**：第 6 项「只跑单次运行就报数字」、第 8 项「未检验运行间稳定性」。该文 §8 用 **50 次重复运行**测决策树一致性——三种子是仓库规则下限，不是该文标准。

## 5. 支撑本裁决的实验证据（截至 2026-08-13）

### 5.1 累加式机制阶梯（单种子，`runs/diagnostics/dijk-repro/mech_ladder.log`）

| 档 | 相对上一档的唯一改动 | 跨年度逐流 AP | AUC |
| --- | --- | ---: | ---: |
| B | 因果前缀均值（基线） | `0.1848481203` | 0.941082 |
| D1 | + 标量指数衰减 | `0.2490874595` | 0.958395 |
| D2 | + 逐通道可学衰减 | `0.2210798271` | 0.950328 |
| D3 | + 数据依赖衰减 | `0.2224845029` | 0.946249 |
| D4 | + 外积状态与查询读出 | `0.0674930736` | 0.811437 |
| D5 | + delta 移除键（完整 RWKV-7） | `0.2173232994` | 0.938386 |

**D4 是唯一既无归一化也无 delta 移除键的档，也是唯一崩塌的档。**
→ 假设：状态必须有界（无论靠除以计数还是靠 delta 约束）。

⚠ 阶梯脚本自动打印的「某档相对上一档为正 → 该机制单独有增益」对 D5 是错的：D5 的 `+0.1498` 是补 D4 的坑，不是独立增益。累加式只能读相邻差。

### 5.2 单因子消融（运行中，`mech_ablate.log`，18 次训练 = 6 档 × 3 种子）

每档只对 B 改一处：

| 档 | 唯一改动 | 预注册预测（若「有界性」成立） |
| --- | --- | --- |
| S1 | 只加 数据依赖衰减 | — |
| **S2** | **只去 归一化** | **崩到 0.07 附近** |
| **S3** | **只换 外积状态与查询读出（保留归一化）** | **保持 0.20+** |
| S4 | 只换 外积并加 delta 移除键（保留归一化） | — |
| S5 | 只加 内容相关门控读出（状态仍是向量） | — |

**S2 是决定性档**：相对 B 只删一个除法，别的不动。
