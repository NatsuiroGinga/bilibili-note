## 一、当前候选边界

当前第四章研究对象暂定为“跨年度、重复曝光条件下的实体级预算告警”，不是已经成立的算法名称。章级结构固定为一个总问题和两个已观测子问题：

- **总问题**：第三章冻结的实体分数与静态阈值不能直接满足跨年度、重复曝光的在线实体告警需求。
- **分布维度**：跨年度阈值失配导致目标年度预算利用不足；当前机制二有限样本确认实现已经在源年 Q0 否决，问题仍存在但没有合格解法。
- **时间维度**：重复曝光挽回迟到恶意证据的同时累积良性误报；源年病灶已经通过资格诊断，控制方法实验待证。
- 冻结第三章 XGBoost＋CPA＋ELP 的 `semantic168` 模型、`p=1` 和实体分数定义，不更新树模型、不改变排序。
- 旧 `10%/10%/80%` 双段合同因选择和确认实体均为 0 而不可执行，已关闭；不得通过移动比例或改用完整实体队列追跑。
- 固定二进多尺度 DTEP、无标签 BBSE-PBC 和机制二当前实现不再追调；长实体排序退化只保留为历史诊断，不作为当前第三个章级子问题。

## 三、长实体诊断

### 3.1 感知机分桶

运行 `ch4-entity-length-bucket-diagnostic-seed42-v1` 已以 `finished/complete/exit=0` 完成。四格相对冻结值逐项零差，覆盖 `47,115` 实体、`752` 正实体和 20 个检查点，`seen_all=true`，无逐样本分数。证据仅为 `screening_only=true`、`formal_paper_evidence=false`、`independent_test=false`。

C11-C00 在五个实体流数桶 `1-2/3-10/11-100/101-1000/1001+` 的实体 AP 增量为：

`+0.123948 / +0.239138 / +0.137851 / -0.322915 / -0.302212`。

现有机制在短中实体有利、在长实体显著有害，禁止写成全局提升。`1001+` 桶良性实体在 C11 下出现 `0.9999` 的逐流假阳尖峰，说明感知机上的长实体受损出现在逐流分数和表示层，不在聚合指数。

### 3.2 XGBoost 分桶

XGBoost 冻结 `raw83 + max` 与 `semantic168 + p=1.0` 的五桶实体 AP 增量为：

`+0.028998 / +0.121857 / +0.082025 / -0.073974 / -0.018679`。

两个长桶分别有 `84`、`40` 个正实体，均超过预注册最低支持数 `10`；方向翻转跨越感知机与 XGBoost，但 XGBoost 的 `1001+` 桶没有感知机的良性高分尖峰，不得假设两骨干根因相同。总体实体 AP 仍由 `0.513185` 提高到 `0.565078`，总体均值掩盖长实体退化。

## 七、共享筛选视图陷阱

视图根 `runs/data-prepared/lspr24-screen-wide-v1`，合同 `lspr24-screen-6-2-2-v1`。

1. `label=-1` 占 `60.4075%`，即 `4,800,524` 窗口；`label=0` 占 `37.9779%`，`label=1` 占 `1.6145%`。可评价窗口只有 `3,146,375 / 7,946,899 = 39.59%`，消费前必须过滤到 `{0,1}`。

## 八、当前候选状态与下一动作

- 当前只有机制一取得“病灶存在”资格，控制方法仍为实验待证；机制二当前实现已否决，因此尚不存在可命名的第四章双机制算法。
- 朱焱雷第四章只提供“一个总问题拆成两个互补维度”的组织参照。本课题的两个维度是跨年度阈值失配和重复曝光决策，不借用其过滤、缓存、公式或效果数字。

1. 恢复远程代理通道，回收病灶运行的摘要、完整曝光曲线、清单、状态和日志，并完成结果分析。
2. 文献代理只检索重复查看误报累积、任意时点有效错误控制、序贯纽曼—皮尔逊和实体级早期告警的直接近邻；检索与实验并行，不阻塞快速实验。
3. 根据完整曲线与直接近邻冻结机制一单变量 Q0：固定模型和分数，只比较固定阈值重复观察与曝光感知误报预算控制。
4. 机制一 Q0 仍只使用 LSPR23、种子 42、零训练；实体假阳率不超过 `4%` 且检出率严格高于首曝基线才可晋级。
5. 不重启机制二，不调整旧时间比例，不读取 LSPR24 挽救任何源年候选。只有机制一出现独立正信号后，才讨论第二机制替代方案和章级双机制组合。
