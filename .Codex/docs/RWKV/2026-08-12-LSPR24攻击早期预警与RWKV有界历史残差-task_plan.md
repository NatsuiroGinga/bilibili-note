# LSPR24 攻击早期预警与 RWKV 有界历史残差任务计划

- **路线**：`RESEARCH_ROUTE=RWKV`
- **状态**：设计与数据接口冻结中
- **证据等级**：实验待证
- **唯一数据集**：LSPR24

## 目标

在 LSPR24 严格时间前向 `60%/20%/20%` 合同下，先证明攻击发生前的因果历史具有超过强表格基线的可学习信号，再验证 RWKV 历史状态能否作为强静态风险锚的有界残差产生独立增益。最后 `20%` 在方法、标签、字段、阈值、超参数和统计模板冻结前完全不可访问。

## 阶段

- [x] 恢复 RWKV 路线并核对既有 Q0、完整基线、候选 B、R1、C12 与 C12-R 结果。
- [x] 冻结任务范围：当前状态分类只复用旧结果；新主任务为攻击早期预警；正常行为预测只作为候选第二机制，不独立扩张为另一篇任务。
- [ ] 完成 RWKV 应用迁移、攻击早期检测、正常行为预测和 LSPR 序列构造的全文证据矩阵。
- [ ] 核验 LSPR24 前 `80%` 现有视图能否构造事件、未来风险标签和下一步正常目标；禁止读取最终 `20%` 的值、成员、计数或哈希。

- [ ] 写回专项报告、第三章候选登记册、RWKV 当前恢复卡和路线总控。

## 决策

1. 不再训练纯 RWKV 当前状态分类；现有同年分类接近饱和，跨年神经排序又显著落后树模型。
2. 新任务必须让历史信息成为必要变量。预警样本在当前尚未进入攻击状态时，预测同一因果实体未来固定范围内是否出现攻击起点。
3. 强基座优先采用仅由当前合法字段和训练区历史统计构造的 XGBoost 风险模型；RWKV 只提供零初始化、有界的历史残差。
4. 第二机制候选为正常转移惊异度与历史质量共同形成的可信门；只有正常下一步预测先超过保持、滑动统计和树回归基线时才启用。
5. 所有未来标签、事件划分和正常目标只在当前分区内构造，禁止跨越训练、验证或最终边界。
6. 第一阶段不通过时，结果记为任务不可学习或历史无独立信号，不用增加频谱、ROSA、课程学习或强化学习挽救。

## 待确认问题

1. LSPR24 前 `80%` 现有视图是否保留逐流绝对可用时刻、规范化无向 `2-IP` 关联和逐流标签。
2. 攻击起点应按逐 `2-IP` 标签转变还是按文献支持的固定会话间隔聚合；最终取值只由训练区事件支持度决定。
3. 正常预测目标的稳定连续字段集合及缺失掩码语义。
4. 早期预警范围的候选集合、事件最小数和固定告警预算。
