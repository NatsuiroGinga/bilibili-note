# 博弈论与 RWKV 结合技术路线：全文证据审计

- **状态日期**：2026-08-05
- **角色**：文献复审子代理证据制品
- **研究问题**：博弈论怎样与 RWKV 长时网络恶意流量检测形成真实、可证伪、可在单张 RTX 5090 上实现的第四章技术路线，而不是把损失加权重新命名为博弈。
- **候选路线**：A 攻击者—检测器分布鲁棒／极小极大博弈；B 检测、生成、早期性目标间的非对称纳什议价或梯度协调；C 误报、漏报、等待成本与资源约束下的停止／风险博弈。
- **证据边界**：核心应用证据优先 2023—2026 年；更早论文只用于正式定义或奠基方法；公式、算法、实验效果只接受可读全文并记录页码或节号。

## 直接结论

**推荐主路线是 C 的分布鲁棒版本 C′：在冻结的因果 RWKV 状态上求解风险约束最优停止，并引入一个明确的“事件群组分布对手”形成零和极小极大问题。**第二个玩家是对预注册训练群组混合权重作选择的“自然／分布对手”，不是现实攻击者。纯 C 只有检测器一个决策主体，只能诚实称为最优停止；只有把分布对手的策略集、收益和最佳响应写全以后，C′ 才是博弈。

**备选路线是 B：严格复现非对称广义纳什议价，将检测、生成和早期性视为三个目标玩家。**它在数学上是真正的合作议价，但更像训练优化器，且几乎直接实例化 AuxiNash，章级创新性弱于 C′。它只有在三个目标共享可训练的 RWKV 适配层或末层时才有意义；冻结编码器且各自只训练独立头时，没有可议价的共享更新资源。

**否决字面 A：现实攻击者—检测器的 Stackelberg 扰动博弈。**原因有二：第一，LSPR24 的冻结流量轨迹没有能够验证的攻击者反事实动作、行为策略覆盖或动作依赖转移，不能把特征扰动当成真实网络动作；第二，它与朱焱雷 DS-RGO 在玩家、先后顺序、扰动策略、课程强度和响应梯度上高度重合。ADT 只能证明图像输入邻域内“最坏扰动分布”的方法可行，不能证明其扰动在网络协议和事件语义上有效。

本轮没有发现一篇论文同时实现“RWKV 长时网络流量状态＋事件级早期停止＋群组分布鲁棒零和博弈”。因此，C′ 是由三条分别成立的证据链组成的**项目研究假设**，不是已有论文结论：RWKV 提供因果递归状态，最优停止提供误报／漏报／等待风险，群组分布鲁棒优化提供显式分布对手。

一项方法只有同时给出以下对象，才在本审计中计为“博弈”：

1. 至少两个可区分玩家；
2. 每个玩家可改变结果的策略集；
3. 显式效用、损失或风险；
4. 给定对方策略后的响应映射；
5. 纳什均衡、Stackelberg 解、议价解或极小极大鞍点等明确求解对象。

若只有一个损失函数、多个手调权重或一个停止策略，则分别称为多目标优化、损失加权或最优停止，不称为博弈。

## 五、三条路线的正式机制审计

### 5.1 A：现实攻击者—检测器分布扰动博弈

| 对象 | 若要成立必须写出的内容 | 当前数据能否支持 |
| --- | --- | --- |
| 玩家 | 检测器；能够实施网络动作的攻击者 | 检测器存在；LSPR24 没有可操作攻击者接口 |
| 策略 | 检测器参数 `θ`；协议有效、功能保持、因果可实施的流量变换 `δ` 或其分布 | `θ` 可训练；`δ` 的可行域和反事实结果不可识别 |
| 收益 | 检测器最小化干净风险与逃逸风险；攻击者最大化逃逸收益并支付动作成本 | 可写公式，但动作成本和协议有效性没有真值 |
| 响应 | `δ*(θ)=argmax_δ L_attack(θ,δ)`；检测器预见或对抗该响应 | 只能在特征／嵌入空间模拟，不能等同现实攻击者响应 |
| 解 | 极小极大鞍点或 Stackelberg 解 | 数学上可定义，数据上缺少可识别性 |
| RWKV 接口 | 对令牌、包序列或状态施加可验证扰动 | 聚合流表上的任意数值扰动可能破坏协议和事件语义 |

**裁决：否决为当前主线。**ADT [7] 支持的是连续图像邻域；Kouam [8] 和 Hammar [1] 的真实攻击者会改变环境状态或转移；LSPR24 两者都不具备。若未来建立协议执行器、流量重放仿真器和动作结果真值，可重新评估，但这已超出当前单数据集静态轨迹合同。

### 5.2 B：检测—生成—早期性的非对称议价

严格版本应定义：

- 玩家：检测损失、下一窗生成损失、早期停止风险三个目标代理；
- 共享策略资源：同一个共享下降方向 `d`，限定在紧致单位球中；实际参数更新为 `θ←θ-ηd`；
- 分歧点：`D=0`，即本步不更新共享参数；
- 玩家效用：`u_i(d)=g_iᵀd`，其中 `g_i` 是第 `i` 个目标对共享参数的损失梯度，因此正效用表示一阶损失下降；
- 偏好：`p_i>0` 且 `Σ_i p_i=1`，检测任务优先级由主任务验证损失决定或在实验前冻结；
- 议价解：

\[
d^*=\arg\max_{\|d\|\le 1}
\sum_{i=1}^{3}p_i\log\bigl(g_i^\top d-0\bigr),
\qquad g_i^\top d>0.
\]

令 `G=[g_1,g_2,g_3]`，则 AuxiNash 映射为 `GᵀGα=p/α`、`d=Gα`。这里的“响应映射”是从 `(G,p)` 到议价解 `d*` 的社会选择映射，不是攻击者最佳响应，也不应再称为 Stackelberg 均衡。若学习偏好，则外层对象是 `p*=argmin_p L_det^val(θ*(p))`。

**RWKV 接口条件**：三个损失必须共同作用于一个小型共享适配器、最后一层 RWKV 或共享投影层。若 RWKV 完全冻结且三个头参数互不共享，则 `G` 在共享空间不存在有意义的冲突，议价退化为装饰。

**裁决：保留为备选和强基线，不建议作为章级主创新。**它有完整正式定义，但核心算法已由 [5][6] 给出；本课题的主要新增内容只是更换三个任务。除非实验发现长时生成、检测和早停之间存在稳定且可复现的梯度冲突，并且非对称议价显著改善主任务风险边界，否则不能宣称新的博弈机制。

### 5.3 C：风险最优停止与分布鲁棒版本 C′

**纯 C 的诚实名称是风险约束最优停止。**检测器根据前缀状态选择继续或告警；误报、漏报、等待和观察资源进入风险；没有第二个策略主体。FIRMBOUND [2] 与 Ringel [3] 直接支持这条路线，但均不把它称为博弈。

Hammar [1] 的双玩家停止博弈只有在攻击者也选择停止／继续并改变状态转移时成立。固定 LSPR24 轨迹无法观察“若检测器更早告警，攻击者接下来会怎样改变动作”，因此不能虚构该玩家。

C′ 用一个可审计的分布对手补足第二玩家：

- 玩家 1：基于 RWKV 前缀状态选择继续／告警的检测策略；
- 玩家 2：在预注册训练群组上选择混合分布的自然／分布对手；
- 对手不是现实攻击者，不生成新流量，也不改变事件内部转移；
- 对手只改变哪些训练群组在最坏风险中占更大权重；
- 检测器响应是加权风险最小化，对手响应是将权重推向当前高风险群组；
- 求解对象是零和极小极大鞍点的近似一阶解，不是 Stackelberg 解，也不保证深网全局均衡。

**裁决：条件主线。**前提是 LSPR24 的 G0 审计能够形成有最小支持量、无身份泄漏、只依赖训练区定义的事件／时间群组。若无法定义合法群组，C′ 必须降级为纯 C；此时第四章仍可做最优停止，但不能以“博弈论”为贡献标题。

## 七、推荐 C′ 的公式骨架

### 7.1 因果状态与停止策略

对事件 `i` 的前缀观测 `x_{i,1:t}`，第三章冻结的因果 RWKV 编码器给出：

\[
z_{i,t}=F_{\Theta}(x_{i,1:t}),\qquad
h_{i,t}=\sigma(f_{\phi}(z_{i,t},s^{\mathrm{det}}_{i,t},s^{\mathrm{gen}}_{i,t})),
\]

其中 `Θ` 第一阶段冻结，`φ` 是小型停止头；检测分数和生成惊讶度只能由当前及历史观测计算。停止危险率 `h_{i,t}` 导出：

\[
P_{\phi}(\tau_i=t)=h_{i,t}\prod_{u<t}(1-h_{i,u}),\qquad
P_{\phi}(\tau_i>H_i)=\prod_{u\le H_i}(1-h_{i,u}).
\]

### 7.2 事件风险

对正常事件 `y_i=0`、恶意事件 `y_i=1`；仅为恶意事件定义合法起点 `t_i^*`。先定义归一化延迟

\[
d_i(\tau_i)=
\begin{cases}
\dfrac{(\min(\tau_i,H_i)-t_i^*)_+}{H_i}, & y_i=1,\\
0, & y_i=0,
\end{cases}
\]

再定义期望风险：

\[
r_i(\phi)=
c_{\mathrm{FP}}\,\mathbb{E}[\mathbf 1(y_i=0,\tau_i\le H_i)]
+c_{\mathrm{FN}}\,\mathbb{E}[\mathbf 1(y_i=1,\tau_i>H_i)]
+c_{\mathrm D}\,\mathbb{E}[d_i(\tau_i)]
+c_{\mathrm O}\,\mathbb{E}\!\left[\frac{\min(\tau_i,H_i)}{H_i}\right].
\]

LSPR24 主延迟起点只能使用“同一事件第一条已标恶意流完成”的时刻；只有攻击叙事与流时间、端点和目标能够唯一匹配的子集，才能另报真实红队动作起点。正常事件不定义 `t_i^*`，延迟项按零处理。

### 7.3 分布对手、响应和求解对象

设训练区预注册群组为 `g∈{1,…,G}`，群组风险为 `R_g(φ)`。再预注册有限个约束 `C_k(φ)≤b_k`；最小版本令它们分别表示开发验证参考分布上的误报率上限和漏报率上限。若要约束最坏群组，必须把相应群组约束及最小支持量一并预注册。可行停止策略集为

\[
\Phi_b=\{\phi:C_k(\phi)\le b_k,\ k=1,\ldots,K\}.
\]

首个最小版本令分布对手使用完整群组概率单纯形，并求解约束零和问题：

\[
\min_{\phi\in\Phi_b}\max_{q\in\Delta_G}
V(\phi,q)
=\sum_{g=1}^{G}q_gR_g(\phi).
\]

分布对手的收益是 `V`，检测器的收益是 `-V`，因此这是严格零和形式。双方响应为：

\[
\operatorname{BR}_{\mathrm N}(\phi)
=\arg\max_{q\in\Delta_G}\sum_g q_gR_g(\phi),
\qquad
\operatorname{BR}_{\mathrm D}(q)
=\arg\min_{\phi\in\Phi_b}\sum_g q_gR_g(\phi).
\]

实现时用非负对偶变量求解约束，其拉格朗日函数为

\[
\mathcal L(\phi,q,\lambda)
=\sum_g q_gR_g(\phi)+\sum_{k=1}^{K}\lambda_k\bigl(C_k(\phi)-b_k\bigr),
\qquad \lambda_k\ge 0.
\]

`λ` 只是约束求解变量，不是另一个安全主体；把它单独命名为玩家会虚增博弈主体。

完整单纯形下，自然的精确最佳响应把质量放到最高风险群组；训练用较稳定的指数梯度近似：

\[
q_g^{(k+1)}=
\frac{q_g^{(k)}\exp(\eta_q\widehat R_g(\phi^{(k)}))}
{\sum_j q_j^{(k)}\exp(\eta_q\widehat R_j(\phi^{(k)}))}.
\]

停止头对 `\phi` 作加权风险梯度下降，预算乘子作投影上升。该算法只宣称寻找非凸问题的近似一阶鞍点。Sagawa 等 [4] 的 `O(1/√T)` 结论只适用于其列明的凸、有界、利普希茨条件，不能移植为 RWKV 停止头的全局收敛保证。

### 7.4 群组合同

群组必须在开发训练区内预注册，并满足：

1. 基于合法时间段、上位事件簇、攻击叙事或只依赖历史的难度分层；
2. 不使用 IP、端口、主机身份、最终测试误差或告警后的信息定义群组；
3. 每群有预注册最小事件数，极小群组合并规则在看开发验证前冻结；
4. 一条流、一个事件及其同步上位簇只属于一个分区；
5. 最终测试只用于报告各群组风险，不参与 `q` 更新、群组构造或半径选择；
6. 若 G0 无法形成这些群组，停止 C′，不以随机行分组或标签泄漏补救。

完整单纯形是首个可解释版本；带 KL 半径、上限权重或概率下界的歧义集只能作为后续敏感性分析，必须另行预注册。ADT [7] 的熵正则扰动分布与这里的事件群组混合不是同一个对象，不能混写。

## 八、可证伪假设与最小实验

### 8.1 主假设

**H1：分布鲁棒停止收益。**在同一冻结 RWKV 状态、同一停止头容量、同一误报预算和同一校准区下，C′ 相对普通平均风险最优停止，在所有三个种子满足预算且相对完整时域基线事件召回下降不超过 0.01 时，使最坏合法群组的平均归一化检测延迟至少降低 20%，并且事件上位簇配对自助差值区间下界大于 0。观察比例只作为预注册辅助指标，不替代该主判据。

否证条件：任一正式种子违反预算；召回下降超过 0.01；改善不足 20%；配对区间跨 0；或改善只来自身份字段、测试参与群组构造、极小群组权重塌缩。

**H2：博弈机制而非静态重采样。**C′ 的最坏群组风险应优于固定逆频率重加权，并且训练过程中 `q` 对高风险群组的权重变化与群组风险排序一致。若固定重加权达到相同或更好结果，或 `q` 只跟踪群组样本量而非风险，则“最佳响应”机制没有增量价值。

**H3：RWKV 特异性。**群组分布对手对 RWKV 的增益，应大于其对至少一个参数匹配、历史预算相同的因果序列基线的增益，即方法×编码器的差中之差为正。若只得到编码器无关的相同增益，只能宣称新的鲁棒停止方法，不能宣称博弈与 RWKV 形成特有协同。

### 8.2 最小实验矩阵

第一阶段只训练冻结状态上的停止头：

| 编号 | 编码器 | 决策训练 | 作用 |
| --- | --- | --- | --- |
| `B0` | 冻结 RWKV | 完整时域分类器 | 非早期精度／召回上界 |
| `B1` | 冻结 RWKV | 独立校准固定阈值 | 最简单早期基线 |
| `S0` | 冻结 RWKV | 平均事件风险最优停止 | 隔离“停止”本身的收益 |
| `S1` | 冻结 RWKV | 固定逆频率群组权重 | 隔离静态重采样／重加权 |
| `S2` | 冻结 RWKV | C′ 指数群组响应＋约束对偶 | 主方法 |
| `E0` | 最强参数匹配因果基线 | 平均风险最优停止 | RWKV 特异性对照 |
| `E1` | 最强参数匹配因果基线 | C′ | 方法×编码器交互对照 |

`S0`、`S1`、`S2`、`E0`、`E1` 使用种子 42、43、44，共 15 个学习型停止头运行；`B0`、`B1` 使用相同三份冻结预测和校准结果，不另挑有利种子。若第三章尚无冻结 RWKV 检查点或参数匹配因果基线，实验不得启动。

主指标保持项目既有冻结定义：在事件召回相对完整时域基线下降不超过 0.01 且误报预算满足时的平均归一化检测延迟。辅助报告最坏群组风险、观察比例、漏报率、每小时误报、延迟中位数与尾分位数、群组权重有效样本量，以及三种子等权结果。统计单位是独立事件或上位同步攻击簇，不是流记录行或时间窗。

### 8.3 备选 B 的最小验证

只有 C′ 因群组合同失败且共享适配器具备合法训练条件时，才运行 B：

- 普通固定标量化；
- Nash-MTL 对称议价；
- AuxiNash 非对称议价；
- 三者共享同一小型适配器、三个任务、数据、步数、校准区和三种子。

若 AuxiNash 不能显著改善主检测风险边界，或检测偏好最终压到 1、使其他任务等价于被删除，则 B 只保留为负结果／优化器基线，不升格为创新点。

## 十、研究空白与下一研究方向

### 10.1 主要空白

1. **组合空白**：已有研究分别覆盖群组分布鲁棒、有限时域最优停止和 RWKV 因果状态，但没有全文证据覆盖三者在网络恶意流量上的组合。
2. **响应可识别性空白**：固定流量轨迹没有攻击者针对告警动作的反事实响应，现有双玩家安全停止博弈依赖仿真器、攻击图或真实环境。
3. **群组真实性空白**：Sagawa 假设训练群组已知；LSPR24 的事件映射、独立群组数和去身份后非退化性仍需 G0 数据审计。
4. **RWKV 特异性空白**：RWKV-7 与 PLM-NIDS 只证明状态接口和应用邻接，没有证明极小极大或议价机制在 RWKV 上优于其他因果编码器。
5. **约束泛化空白**：FIRMBOUND 假设训练测试同分布；Ringel 给出独立同分布边际校准保证；二者都不保证末段时间漂移下的群组约束。
6. **非凸求解空白**：群组分布鲁棒和议价论文的强理论条件不能直接覆盖非凸 RWKV 联合训练；本课题应报告最佳响应残差、约束违反和种子稳定性，而不是宣称收敛到全局均衡。

### 10.2 优先级

1. **第一优先**：完成 LSPR24 G0，确认可形成预注册合法群组；随后以冻结状态实现 `S0/S1/S2`。
2. **第二优先**：在同一缓存上完成参数匹配因果编码器的 `E0/E1`，决定能否声称 RWKV 特异性。
3. **第三优先**：若群组合同失败，保留纯 C 为科学主线；若论文题目必须保留博弈论，再以 B 作条件备选，但不得隐藏其 AuxiNash 实例化属性。
4. **远期方向**：另建协议有效的攻击重放仿真器或攻击图环境后，再研究 Hammar 式动态双玩家停止博弈；该方向不是当前静态数据实验的补丁。
