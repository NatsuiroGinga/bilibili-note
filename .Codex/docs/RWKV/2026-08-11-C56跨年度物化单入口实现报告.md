## 幂等与并发行为

1. 每次调用先尝试创建稳定日志根下的原子活动锁 `active.lock`。
2. 未取得锁的调用只写自身尝试目录的 `blocked` 状态，不覆盖活动调用的稳定状态。
3. 正式输出存在时，只读取历史收据必需键子集 `status` 与 `final_accessed`，允许历史收据包含其他字段：
   - `status="succeeded"` 且 `final_accessed=false`，并且没有 `.partial` 或工作根残留时，写入 `already_succeeded` 并退出 `0`；
   - 收据缺失、无法解析、状态不成功或隔离标记异常时，写入精确阻塞路径并非零退出。
4. 正式输出不存在但 `<output_root>.partial` 或配置中的 `temporary_root` 存在时，拒绝启动。脚本不会删除、覆盖或修复这些路径。
5. 活动锁只在本次调用正常收尾后以非递归 `rmdir` 释放；若锁目录出现未知内容则 fail-closed，要求人工核验。

## 预检门禁

脚本使用明确的 `if-else` 分支完成以下检查：

- 固定项目根、冻结配置和唯一日志目录存在且可写；
- `cargo`、`unzip`、`df`、`awk`、`wc`、`dirname` 可用；
- MD5 工具按 `md5sum`、`md5`、`openssl` 顺序选择；
- SHA-256 工具按 `sha256sum`、`shasum`、`openssl` 顺序选择；
- 配置 SHA-256 格式有效；
- 只解析配置中的 `lspr23_zip_path`、`lspr24_parquet_path`、`output_root`、`temporary_root`，且四者必须位于固定项目根内；
- LSPR23 ZIP 与 LSPR24 Parquet 均为普通文件；
- LSPR23 ZIP 大小严格等于 `1,925,103,715` 字节，MD5 严格等于 `f3f5bf9f7cecf2186511eabb38f7accc`；
- `/proc/meminfo` 的 `MemAvailable` 至少为 8 GiB；
- 从 `temporary_root` 向上找到的既有目录所在数据盘，以 `df -Pk` 计算的可用空间至少为 70 GiB。

脚本不解析或访问最终区、攻击叙事、连接信息、凭据、原始 IP、标签值或载荷。

## 唯一生产命令

全部门禁通过后，脚本在固定项目根执行：

```bash
cargo run --release --locked \
  --manifest-path tools/lspr24_g0/Cargo.toml \
  --bin lspr_crossyear_materialize -- \
  --config configs/lspr-crossyear-c12-seed42-v1.json
```

执行前固定 `CARGO_NET_OFFLINE=true`，缺少本地锁定依赖时直接失败，不在正式入口下载、安装或同步依赖。该 Rust 入口不调用 Python 或 `uv`，严格使用任务简报冻结的 Cargo 命令。

## 已知风险

1. 只完成 Bash 语法检查。C56 的实际 Shell、Cargo 输出形态、磁盘挂载、MD5 吞吐和 Rust 业务心跳仍未真实验证。

3. 编译—物化阶段边界依赖 Cargo 标准 `Running ... lspr_crossyear_materialize` 行；若 Cargo 输出格式变化，即使命令退出 `0` 也会因缺少阶段证据拒绝宣告完成。

5. 真实运行前仍须确认 Rust 物化器报告中的 1.5 GiB 估算、60 GiB 临时上限和 96 GiB 总 I/O 与 C56 实际资源一致；本入口的 8 GiB／70 GiB 只是不启动下限，不是实际峰值证明。
