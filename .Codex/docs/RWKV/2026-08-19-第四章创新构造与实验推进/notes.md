## 任务化耦合的判定标准

简单拼装具有以下特征：

- 模块之间没有共享状态、约束、准入条件或失效回退。
- 无法从第三章的真实实验定位必要性。
- 没有独立可证伪预测，只报最终精度。
- 可以无结构性变化地换成其他模块。

可作为应用型硕士论文机制创新的耦合应同时满足：

1. 用真实实验定位第三章的具体失效面。
2. 说明原始方法为什么不能直接解决该失效面。
3. 对既有原理施加新的信息边界、决策单元、因果顺序、预算约束或回退规则。
4. 让机制一的输出成为机制二的状态或准入条件。
5. 给出新公式、算法流程、复杂度或条件性边界，并明确失效条件。
6. 通过共同预算基线、单机制、联合机制、强近邻对照和失败分面验证。

## DTEP 与 PBC 的当前证据

- 感知机组合格相对无机制格的实体平均精确率分桶增量为 `+0.123948 / +0.239138 / +0.137851 / -0.322915 / -0.302212`，长实体出现方向翻转。
- XGBoost 完整格相对原始输入格在两个长实体桶中下降 `0.073974` 和 `0.018679`，表明该现象并非感知机独有，但不支持两骨干具有相同根因。
- E1 源年实体折外增量为 `+0.033872`，三折差值极差为 `0.211731`；只允许粗筛，不支持精细选择单一近期窗长。
- DTEP 因此重构为固定二进尺度族 `{1,2,4,8,16,32,64,128}`，中间尺度固定等权混合，不允许目标标签选优。
- 当前 DTEP 仍是 Q0 筛选构造，只有源折外方向、长实体分面和总体保护门同时通过，才值得冻结章级机制。
- PBC 以网络实体为预算与阈值单元，只在因果先导段估计先验和候选阈值，以失配门决定 BBSE 准入，失败时按预注册规则回退源阈值。
- PBC 已比 DTEP 更接近章级算法形态，但仍是设计可行、实验待证。
- 联合算法需要将 DTEP 定义为实体因果前缀分数过程，再让 PBC 仅消费该过程在先导段内的可用状态。
- 共同目标应使用分层约束：先保护实体排序与长实体证据，再在误报预算下提高检出并降低告警时延。
