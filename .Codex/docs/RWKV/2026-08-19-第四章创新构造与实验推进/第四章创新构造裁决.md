# 第四章创新构造裁决

## 一、核心结论

**基础部件已有先例不等于候选没有创新。**应用型硕士论文可以把新意限定为：针对本任务已实测失效面，对既有原理的状态、约束、时序、决策单元和失效回退进行实质改造，并将两个改造后机制统一为可证伪算法。

朱焱雷第四章本身就是这种创新构造：核心集选择、梯度重要性和扰动复用都有先例；其新增贡献主要发生在加密流量对抗训练的时空冗余建模、两级计算路径耦合、ET-BERT 变长序列适配、统一目标和完整实验。

本论文可以参考朱焱雷的创新组织方式，但不复制 DF-ACR 的具体部件、公式和实验结论。

## 三、双时域证据保持 DTEP

不宣称首创的内容：因果前缀聚合、长短时标建模、多窗统计、以及在 XGBoost 输入中追加派生特征。

可检验的任务化改造：

1. 以第三章因果前缀为不衰减长历史锚。
2. 追加无目标标签选优的固定二进近期证据。
3. 将主要作用面限定为已实测的长实体方向翻转。
4. 同时要求总体排序不退化，防止用局部改善换取总体损失。

当前定位：**Q0 筛选机制，不是已冻结的章级贡献**。如果源折外方向门、长实体门或总体保护门失败，DTEP 直接否决，不逐档调整尺度和权重。

## 四、先导段预算标定 PBC

不宣称首创的内容：BBSE 先验估计、分位阈值、无标签目标标定、先导段和回退的宽泛思想。

可检验的任务化改造：

1. 将预算、先验和阈值单元统一为网络实体。
2. 只在目标因果先导段构造候选校正。
3. 通过可观测失配门限制 BBSE 支路的准入。
4. 失配时执行预注册的源阈值回退，不根据目标标签换规则。
5. 冻结数值阈值后才评价独立后续段。

当前定位：**已具备算法形态，但仍为实验待证**。Q0 需同时报告实际实体误报率、检出率、时延、回退率和排序保护指标。

## 五、联合算法的必要关系

联合算法不能只是两个脚本的顺序调用。候选关系应写为：

1. DTEP 从流序列产生实体因果前缀分数过程。
2. PBC 仅读取该分数过程的先导段，估计先验、实体告警预算和候选阈值。
3. PBC 的失配门决定启用校正或精确回退源阈值。
4. 后续段仅执行已冻结的决策，不再根据目标结果选参。

共同目标使用分层约束，不使用任意权重混合：

- 第一层：实体排序与长实体分面不退化。
- 第二层：冻结阈值的实际实体误报率不超出预注册预算。
- 第三层：在前两层满足时提高检出率并降低告警时延。

只有 DTEP 和 PBC 分别通过 Q0，才允许冻结正式的统一公式和算法名称。一般的“源训练—先导标定—后段评价”只是评价纪律，不作为第三项独立创新。

## 六、理论深度和工作量门槛

若两个 Q0 均通过，正式第四章至少需要：

1. 一个跨年度实体分数过程和告警预算的统一问题定义。
2. DTEP 证据构造、PBC 准入与回退、以及联合决策的明确公式。
3. 一个包含输入、状态、门控、回退和输出的完整算法。
4. 复杂度分析，以及一个只在明确假设下成立的预算或风险边界；失配时给出退化结论。
5. 强基线、两个单机制、联合格、文献直接近邻和等预算对照。
6. 总体实体平均精确率、长实体分桶、实际误报率、检出率、时延、回退率、预算曲线、耗时和内存。
7. 双机制消融、先导比例敏感性、失配诊断和回退消融、长实体作用分面。

该工作量在结构上可与朱焱雷第四章对位。正式结论仍以真实实验为准，不用公式数量或文献数量代替方法有效性。
