# 第三章机制替换直接近邻证据矩阵

## 使用规则

- 证据等级：`E3` 为正式会议/期刊或作者全文，题录与页码已核；`E2` 为可核验预印本全文；`E1` 为题录/摘要。
- 同构等级：`D3` 为候选的全部关键关系同现；`D2` 为至少两个关键关系同现但缺决定环节；`D1` 为单一基础部件；`D0` 为任务或权限冲突。
- 只有 `E2/E3` 全文证据可支撑机制细节；`D2/D3` 只说明近邻程度，不证明本课题有效。
- “本课题关系”严格区分论文原结论、可迁移机制与本课题待验证推论。

## 近邻查重结论

1. **没有 D3。** 未发现一篇全文同时覆盖 2-IP 网络实体、严格过去的学习表示、完整实体/分片一致池化、逐流与实体双目标、源年度实体选择和跨年度冻结评价。
2. **三个候选的最高近邻均为 D2。** 候选 1 是 MIDAM 的大袋随机池化偏差控制；候选 2 是 Lee–Stolfo 的网络安全过去窗统计；候选 3 是 ForkMerge 的验证驱动辅助更新过滤。
3. CPA、可学习 Lp、注意力池化、直接 AP、梯度冲突修正和验证驱动辅助权重均已有明确先例，任何候选都只能主张任务化组合与实验发现，不能把基础算子命名为原创。
4. 2021–2026 年在线查重未发现完整同构。近年命中主要位于医学图像、多示例回归、持续多示例学习或一般辅助任务学习；领域和评价合同不匹配，不用摘要支撑技术结论。
5. 在线统一检索的 OpenAlex 与 Semantic Scholar 返回 HTTP 429，Crossref 正常并核验 ForkMerge DOI。结论应写为“本次检索未命中”，不能写成“全球不存在”。
