# 神经骨干超越 XGBoost 候选筛选计划

## 目标

在不读取 LSPR24 最终目标标签进行候选选择或调参的前提下，依据既有实验、全文文献和官方实现证据，筛出最多两个值得用第三章 CPA/ELP 机制验证、且可承接第四章训练优化的神经骨干候选。

## 边界

- 只研究和写文档，不修改生产代码，不启动实验。
- 不削弱 XGBoost，不围绕 LSPR24 标签选择候选、阈值或超参数。
- LSPR24 已被访问，只能作为探索性评价；正式结论必须转到新的独立域。
- 必须比较 RWKV-7、RWKV-8 式结构、残差/表格多层感知机、FT-Transformer/TabM 类候选。
- 最多推荐两个候选，不以数量填充结论。
