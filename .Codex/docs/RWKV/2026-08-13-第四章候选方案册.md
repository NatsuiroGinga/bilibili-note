## 2. 候选一｜漂移感知的可迁移难度课程

> **裁决前置**：本候选在第 4 节被**否决**。本节保留完整登记，用于记录否决理由与所需证伪实验，避免后续会话重复讨论。

### 2.1 要打的问题

L1。假设源任务解不唯一，跨年度泛化由「源任务未约束住」的那部分样本决定。

### 2.2 机制形式化（设计可行、实验待证）

设末 `K` 个检查点为 `θ_{T-K+1..T}`，对训练流 `f`：

- 预测方差 `v_f = Var_{k=1..K}[ p_{θ_k}(y=1 | x_f) ]`
- 训练后期（切换点 `t_switch` 之后）把样本权重改为 `w_f ∝ g(v_f)`，`g` 单调不减
- 第一阶段：全量训练至 `t_switch`；第二阶段：只在高 `v_f` 子集上继续训练

## 3. 候选二｜实体级早期告警的序列停止决策

> **裁决前置**：本候选在第 4 节被判为**需重构后可用**。原表述（「用 RL 做早期告警」）在文献上已死，重构方向见第 4.3 节。

### 3.1 要打的问题

L3。实体判决当前是「看完整序列再出分」，检测延迟从未被测量，也从未被优化。

### 3.2 原表述的机制形式化（设计可行、实验待证）

对每个 2-IP 实体，按时间到达的流序列 `x_1, x_2, ...`，每来一条流做一次决策：

- 动作空间 `A = {继续观察, 立即告警, 拒识}`
- 状态：第三章冻结表征给出的前缀聚合 `ctx_t` 与前缀实体分数 `S_e^{(t)}`
- 奖励：正确告警随延迟衰减、误报罚、漏报重罚

**第三章的两个机制天然支持前缀计算**：机制一 A 的 `ctx_t = Σ_{i≤t}h_i / Σ_{i≤t}m_i` 由引理 3-1 证明可 `O(D)` 增量更新；机制二 B 的 Lp 池化实测 `p` 收敛到 `0.60`（无 A 时）与 `1.05`（有 A 时），即算术平均附近，故 `S_e^{(t)}` 是现成的运行均值。**这意味着「前缀分数 + 阈值早停」是零成本的非 RL 基线，也意味着 RL 的必要性必须被单独论证。**

### 3.4 仓库 RL 许可范围与门禁（强制）

- **许可范围**：RL 仅允许用于「继续观察 / 告警 / 拒识」构成的序列停止决策。**明令禁止**把 RL 用于生成节点嫌疑排序（Javadpour 2025 SDN Mafia 路线）、用于表征训练调度（SCORER 路线）、或替代检测打分本身。
- **攻击事件门禁**：攻击事件数与决策步门禁失败时禁止启用 RL。当前已知实体级正例仅 `752`，**极可能过不了门禁**。门禁数据由 E2 实验顺带产出（可用正实体数、每 episode 决策步中位数）。
- **框架级绝对禁区**：把「第三章表征 + 第四章 RL」包装成 Stackelberg 主从耦合，已被 SCORER（ICLR 2026 / arXiv:2508.07452v3，式(1)–(6) p.4–5）与 Stackelberg Actor-Critic（arXiv:2109.12286）完整占位；且表征冻结使 `φ*(θ) ≡ φ_frozen`、式(4) 的间接项 `∇_θ f_{φ*(θ)} ≡ 0`，博弈结构在数学上被抽空。SCORER 图6-左对「感知作领导、控制作跟随」另有实测负结果。**不得使用该叙事。**

### 3.5 高风险假设

**⚠ 假设 B1（无文献支撑，主代理自拟）**：「学出来的停止规则相对静态阈值（Prasse 式）与置信度早退（ECHO 式）在本课题上仍有增量」。当前反向证据：`n=1`（max 规则）已达 DR@4%FPR `0.7500`，`n=100` 仅 `0.8324`，可争夺空间 `0.0824` 与种子噪声下界 `0.07` 同量级。

**⚠ 假设 B2（结构性质疑，非假设）**：观测过程是冻结日志回放，完全外生；动作只决定何时截断，不改变后续观测。这类问题的最优策略由前缀后验这个充分统计量决定，最优规则是（时变）阈值，**可用后向归纳精确解出**——正是 FIRMBOUND 的做法。用 RL 去逼近一个能被后向归纳精确算出的东西，不是机制增量。

## 4. 裁决与推荐

> 以下为对抗审查结论，**逐条照录，不软化**。

### 4.1 候选一：否决

四条硬伤，任一条即足以否决作主线。

**(1) 同构工作已发表，且重合的正是候选一的可操作层。** RCS（arXiv:2504.13592v2，§2.3 p.4）已完整发表「先跑一遍完整训练收集逐样本信号 → 用该信号判困难 → 两阶段调度，后期把梯度预算全给未被稳定拟合的子集」，连配比消融（Table 5 p.9，困难:正例 1:2/1:1/2:1/1:0，纯困难 `96.0` 最好）和「纯困难子集不灾难性遗忘」都做完了，其动机原文写的就是 L1（收敛后奖励方差极小、学习信号消失）。Pro-GRPO 的 OVF（arXiv:2512.15347 式(10) p.3）另外发表了「按方差取子集、小的高方差子集优于全集」。候选一剩下的唯一差异是方差轴从空间换成时间，**这是度量替换，不是机制增量**。

**(2) 核心假设与第三章冻结协议直接冲突，且是自相矛盾的。** `.Codex/docs/RWKV/2026-08-13-第三章正文与图件实施计划.md:294,314` 已写明算法 3-1 含「检查点平均」、训练预算 `20000` 步、检查点平均「末5个」。候选一要利用的 `v_f` 恰好就是末 5 个检查点之间的逐样本离散度——**第三章已经把这个量当噪声平均掉了**。候选一等于主张「第三章判为噪声的东西其实是跨年度泛化信号」，却拿不出任何文献或实测支撑。

**(3) 信噪比在实验上不可判。** 同配置换种子实测 `σ = 0.07~0.23`（源 `mech_ablate.log`），`.Codex/docs/RWKV/2026-08-13-超参设置证据台账.md` 明写该 σ 与机制效应（`0.068`）同量级。候选一的效应要在单种子上可辨必须超过 `0.23` AP，而第三章全部机制加起来才把跨年度 AP 从 `0.1590128242` 抬到 `0.2878764332`（`+0.1289`）。要压到噪声以下需多种子配对，而第三章已按用户裁决走单次运行格式。

**(4) 更致命的是选择不可行。** 定理 3-2 及其实测（三种同年度验证划分动态范围 `2.8e-5~1.2e-2`，与跨年度 AP 相关 `−0.40~+0.42`）已确定同年度验证无选择力，`:315` 据此禁用了基于验证集的早停与 epoch 选择。课程方法必须选切换点、K、重加权强度；RCS 与 Scaf-GRPO 都靠验证指标停滞触发，本课题这条路被自己的定理堵死，目标年度又零样本。**即使课程在某个设置下有效，本课题没有合法手段选到那个设置。**

**(5) 谱系归属错误。** 按 Bengio ICML 2009 式(4) 的权重单调不减条件，训练后期给高难样本加权是反课程；论文 p.7 自己把「逐步强调困难样本」归给 boosting，p.3 的 SVM 实验（只用易样本 `16.3%` 优于全量 `17.1%`）是直接反证。

**(6) L1 是数据集性质，不是可修的配置缺陷。** Dijk 表 5 中 XGBoost 同年度 AP `1.0000`、跨年度 `0.2416`；恢复卡记 LSPR24 同年 XGBoost 验证 AP `0.9690`。树模型不训 epoch 也同样饱和，说明「源年度可分性饱和」是标注与特征的性质。**在一个已被完全拟合的任务里重分配梯度预算，造不出原本不存在的信息。修 L1 不构成研究贡献。**

### 4.2 候选二：需重构后可用

问题值得打，形式化可用，但「用 RL 做早期告警」这个标题在文献上已死，且本课题的样本预算和环境结构都不支持 RL。

**(1) 同构工作存在且是直接前作。** EARLIEST（KDD'19，pp.101–110）就是 RNN + RL 联合决定「何时停」与「判什么类」，正是候选二的机制表述。FIRMBOUND（ICLR 2025）把「延迟 vs 准确率」写成有限时域贝叶斯风险（式(3)、定理2.1、式(5)(6)(7)），实验上打败 EARLIEST，附录 E.5 p.25 直接指出 RL 样本效率差、训练不稳、策略梯度方差大。Prasse ECML 2017 已占「实体级在线告警 + 越阈即报 + 按固定精度工作点报 time to detection」（p.6–p.7、表5 p.14，`1.36–1.67 h`）。**候选二不能以现表述立项。**

**(2) 环境结构使 RL 在数学上不必要。** 见 3.5 假设 B2。

**(3) 样本预算不支持。** 实体级只有 `47,115` 个实体 / `752` 个正实体、`π = 0.0159609467`（源 `entity.log`）。98.4% 的实体最优策略是「一直观察不告警」，同一实体在确定性回放下重复 rollout 只有策略随机性，组内奖励方差为零是结构性的。arXiv:2511.03527 的结论也不利：除 CartPole 外所有环境 critic-free 都显著劣于带 critic 的 PPO，且无 prompt 场景「如何构组」是未解问题。仓库硬约束本身还要求攻击事件数与决策步门禁，`752` 正实体极可能过不了。

**(4) L3 至今未测量，当前不满足通过条件。** 而且已有证据提示这个代价可能远小于假设：`entity.log` 的 `n=1`（max 聚合）就是「任一流越阈即告警」的 Prasse 规则，实体 AP `0.523326`、DR@4%FPR `0.7500`；最优的 `n=100` 也只到 `0.8324`。等到第 100 条流最多再多拿 `0.0824` 的 DR，而 max 规则的实际告警时刻还没人量过。**这个上限有可能已经把候选二的可争夺空间压得很薄——`0.0824` 只比种子噪声下界 `0.07` 高一点。**

**(5) 可保留的部分。** 任务本身（实体级早期告警、延迟-准确率曲线、固定 4% FPR 工作点）确实是 L3 留下的真空。可辩护的空白只剩「跨年度零样本漂移 + 2-IP 实体决策单元 + 实体级先验 `0.0160` + 拒识动作」的交集。

### 4.3 推荐主线

**把候选二重构为「跨年度漂移下的实体级约束早停告警」——约束型序贯停止 + 先验漂移鲁棒的停止边界校准，不含 RL。候选一整体否决，不保留。**

**为什么能接住第三章**：机制一 A（`ctx_t = Σ_{i≤t}h_i / Σ_{i≤t}m_i`）本来就是逐前缀在线可计算的（引理 3-1 已证 `O(D)` 增量更新）；机制二 B 的 Lp 池化实测 `p` 收敛到 `0.60/1.05`，即算术平均附近，所以实体分数 `S_e` 在任意前缀 `t` 上都是现成的运行均值。第四章不需要动冻结基座，只在其上加决策规则，完全满足「沿用第三章冻结的主基座、任务、数据协议与评价方法」。

**三层结构**：

1. **风险形式化（引 FIRMBOUND，不算创新）**：实体级有限时域贝叶斯风险 `APR_t = L_FN·(1−π_t) + L_FP·π_t + c·t`，`T` = 实体流数上限，停止时刻 `τ_e = min{t : 停止风险 ≤ 继续风险}`，动作 `{继续观察, 告警, 拒识}`。用后向归纳或凸函数回归离线解出停止边界，**不用 RL**。
2. **约束而非罚项（引 CPO ICML 2017）**：把实体级 FPR ≤ 4% 写成指示型代价约束 `J_C(π) ≤ 0.04`，用拉格朗日乘子上升自动调权。这样 DR@4%FPR 从「事后扫阈值」变成训练期硬约束，口径与第三章完全一致。CPO 图4（p.8）已用实验证明固定罚系数极敏感、会给出大量违约的高回报解，这条负证据直接否决「把误报写进奖励做加权和」的朴素做法。
3. **唯一的机制增量：先验漂移鲁棒的停止边界**。停止边界只能在 LSPR23 上学，但逐流正类先验从 `0.1006`（源）掉到 `0.0257`（目标），差 3.9 倍；前缀后验 `π_t` 会整体下移，源年度学到的边界在目标年度必然系统性推迟告警并同时冲破 FPR 预算。机制是：用冻结合同里那 10% **无标签目标前缀**做 BBSE/EM 式先验估计，把停止边界按估计先验重标定，并用 conformal risk control 给目标年度 FPR 一个分布无关上界。三件工具的原件仓库里都有：`raw/papers/methodology/2018-Lipton-BBSE-Label-Shift.pdf`、`raw/papers/methodology/2024-Angelopoulos-Conformal-Risk-Control.pdf`、`raw/papers/methodology/2024-Farinhas-Nonexchangeable-Conformal-Risk-Control.pdf`。

**为什么不同构**：FIRMBOUND 训练测试同分布、无漂移实验（其 p.30 自陈局限）；Prasse 只跨两个月同一企业网且是静态阈值；ECHO 无漂移无约束，且需为每个出口单训一个分类器；Sun ICML 2024 的弃权是逐样本阈值校准以省掉 cold-start，不是实体序列上何时下结论。「停止边界的无标签先验漂移重标定」在 34 条取证里没有任何一篇做过。

**⚠ 此推荐同样标为「设计可行、实验待证」。** 若 E2 显示延迟-准确率曲线平坦，整条线连同第四章都要换题——那种情况下第四章应改为**纯测量与协议贡献**（把 L3 的结构性代价第一次量化，并给出可部署的固定预算工作点），而不是硬造机制。

### E1｜候选一：`v_f` 独立性证伪（≤1 小时，不额外训练）

- **改什么**：复用 B 档配置（83 字段、2-IP 序列 `L=128`、seed 42、4000 步）的消融入口（当前仓库内为 `thesis/experiments/llm_probe/tools/mech_ablate.py`；`seq_ablation.py` 在仓库内未找到，见第 7 节）。只加一件事：在末 5 个检查点（每 200 步一个）对固定的 20 万条源年度训练流子样本转储预测概率（进程内保存在内存）。
- **算什么**：(a) `v_f` = 该流在 5 个检查点上的预测方差；(b) 最后一个检查点上的逐样本交叉熵损失 `l_f`；(c) 饱和度 `|p_f − 0.5|`。
- **看什么**：`Spearman ρ(v_f, l_f)`、`ρ(v_f, |p_f−0.5|)`，以及 `v_f > 1e-3` 的样本占比与其在总梯度范数中的份额。
- **什么算证伪**（任一成立即否决候选一）：
  - `ρ(v_f, l_f) ≥ 0.80` → `v_f` 只是损失的单调变换，候选一退化为 RCS 的监督版复现；
  - `v_f > 1e-3` 的样本占比 `< 1%` 且梯度份额 `< 5%` → 训练后期根本没有可重分配的预算；
  - `v_f` 的分位数分布在两个不同 seed 之间秩相关 `< 0.3` → `v_f` 本身就是种子噪声（与已实测 `σ=0.07~0.23` 同源），不承载可迁移难度。
- **注意**：三条全部不成立才允许候选一进入下一步，但仍需先解决定理 3-2 带来的**选择不可行**问题。

### E2｜候选二：延迟-准确率权衡是否存在（≤1 小时，纯推断无训练）

- **改什么**：按 `thesis/experiments/llm_probe/src/flow_probe/crossyear_entity_eval_contract.py:223` 的 `aggregate_entity_scores` 增加前缀版本。
- **跑什么**：复用已完成的全量 XGBoost 跨年度评分管线（`runs/diagnostics/dijk-repro/run2.log` 同配置，800 树 / lr 0.05 / depth 8 / seed 42，只跑推断），在 LSPR24 **可见开发区**上：对每个 2-IP 实体按时间排序，对前缀长度 `k ∈ {1,2,4,8,16,32,64,128,256,∞}` 各算一次实体分数（用第三章冻结的 `p≈1` 前缀均值与 max 两种规则）。
- **看什么**：(i) 实体 `AP(k)` 与 `DR@4%FPR(k)` 曲线；(ii) 在 4% 实体 FPR 阈值下，max 规则对被检出正实体的**首次越阈流序号**分布（中位数、P90）；(iii) 顺带出 RL 门禁数据：可用正实体数、每 episode 决策步中位数。
- **什么算证伪**（任一成立即否决候选二及其重构版）：
  - `DR@4%FPR(k=4) ≥ 0.95 × DR@4%FPR(k=∞)` → 四条流就拿到 95% 的准确率，没有可优化的权衡；
  - max 规则的首次越阈序号中位数 `≤ 2` → 已有静态规则事实上已即时告警，学出来的停止规则无处发挥；
  - `DR@4%FPR(k=∞) − DR@4%FPR(k=1) ≤ 0.05`（已知 `n=1` 与 `n=100` 之差为 `0.0824`，属临界，需实测前缀版本确认）→ 权衡幅度小于种子噪声 σ 下界 `0.07`，不可判。
- **RL 门禁**：正实体 `< 752` 或决策步中位数 `< 5` 时，按仓库硬约束**禁止启用 RL**。

### E3｜推荐主线：先验漂移是否真的破坏停止边界（≤1 小时，纯推断）

- **改什么**：沿用 E2 的同一份逐流分数与前缀聚合，走仓库已登记的 `M3-冻结（组合方案+前缀冻结阈值迁移）`（`crossyear_entity_eval_contract.py:407`）。
- **跑什么**：在 LSPR23 源年度上把实体级阈值校准到 4% 实体 FPR，冻结后直接套到 LSPR24 开发区。同时用 10% 无标签目标前缀做一次 BBSE 先验估计。
- **看什么**：目标年度实测实体 FPR、DR@4%FPR、与「用目标年度自身校准的 oracle 阈值」相比的 DR 差；BBSE 估计先验与真值 `0.0257` 的相对误差。
- **什么算证伪**（任一成立即推荐主线的机制增量不成立，第四章降级为纯测量贡献）：
  - 冻结阈值在目标年度的实测实体 FPR 落在 `[0.03, 0.05]` 内且 DR 与 oracle 差 `≤ 0.02` → 源年度阈值本来就迁得过去，不存在需要校正的漂移问题；
  - BBSE 先验估计相对误差 `> 50%` → 无标签先验校正这条工具链在本数据上不可用，机制的输入端就断了。
- **通过条件**：两条都不成立（即阈值确实迁不过去且先验可估）时，主线成立并进入正式设计。

### 执行顺序

`E0 → E2 → E3`（E2 与 E3 共用一次推断）；`E1` 仅在用户明确要求复活候选一时才跑。
