**路线二可行，推荐构造一：实体内尾部聚合（嵌套 CVaR 实体评分结构）。**

## 一、BER 的数学框架与共享槽位的结构分析

### 1.1 BER 是一个两层复合目标［仓库实测］

依据 `2026-08-31-BER机制形式化与复杂度规约.md` 与 CVaR 预算失配分析：

```
S_e      = max_t l_{e,t}                                    （内层：实体聚合）
L_pn     = softplus(S_n − S_p)
R_K(θ,ξ) = mean_p [ ξ_{p,K} + (1/K_eff)·Σ_n [L_pn − ξ_{p,K}]_+ ]   （外层：CVaR_β）
L_rank   = mean_K R_K
```

外层的 R-U 变分形式在真分位数取得内层 min（ξ* ＝ L_pn 的 (1−β) 分位数），
其对偶是容量帽单纯形上的最坏情形重加权：
`CVaR_β(L) = max{ Σ_n q_n L_pn : q ∈ Δ, q_n ≤ 1/K }`，
最优 q* 均匀落在活动集 `A_{p,K} = {n : L_pn > ξ_{p,K}}` 上。

**关键结构事实：`S_e = max_t l` 本身就是同一族算子的极端点。**
`max` 是容量帽单纯形线性最大化在帽＝1 时的特例
（`max_i l_i = max{Σ w_i l_i : w ∈ Δ, w_i ≤ 1}`，最优 w 集中于单点），
也是归一化 Lp 池化在 `p→∞` 的极限（Gulcehre 等 2014，3.2 节，物理页 5［全文核验］）。
即 **C01 现状已经隐式是「聚合 ∘ CVaR-pAUC」的复合结构，只是内层聚合被硬编码为 max**。

### 1.2 与朱焱雷 DS-RGO 组织模式的对位

朱的两个机制是同一 Stackelberg 双层问题的两个环节：DS 改内层约束集
`S_t = {δ: ‖δ‖_p ≤ ϵ(t)}`，RGO 算外层全导数（含 `dδ*/dθ` 反应项）
（`2026-09-01-朱焱雷第三章机制组织与消融的完整理解.md`，提交 `07147ad`）。
对位到本课题：BER 占据「外层目标＋内层重加权」槽位；表示/结构层可占据的、
与之构成**同一复合问题两个环节**的槽位，恰是**内层实体聚合算子**——
把 max 广义化为同族风险测度后，外层 CVaR 梯度经内层聚合的活动集回传，
构成与「DS 塑造内层解、RGO 依赖内层解」同构的复合链。

## 二、候选一（推荐）：实体内尾部聚合——嵌套 CVaR 实体评分结构

### 2.1 构造

把实体评分结构从 max 换成实体内经验 CVaR（top-⌈αm⌉ 均值，ATk 形式）：

```
S_e^{(α)} = (1/k_e) · Σ_{i ∈ A_e} l_{e,i} ,   k_e = max(1, ⌈α·m_e⌉),
A_e = 该实体 m_e 条流中 logit 最大的 k_e 条（实体内活动集）
```

等价的变分／对偶形式（与 BER 完全同族）：

```
S_e^{(α)} = max { Σ_i w_i l_{e,i} : w ∈ Δ_{m_e}, w_i ≤ 1/k_e }        （容量帽单纯形）
          = min_ζ [ ζ + (1/k_e)·Σ_i [l_{e,i} − ζ]_+ ]                 （R-U 变分形式）
```

`α ∈ (0,1]` 为静态尾部水平；`α·m_e ≤ 1` 的小实体连续退化为 max（本轮实测确认，见 2.5）。
z1 开关语义：`z1=0` ⇒ 聚合为 max（现状）；`z1=1` ⇒ 聚合为 `S^{(α)}`，
作用于「BER 排序损失内的 S_e」与「评价期实体得分」两处，训练与评价同构。

### 2.2 与 BER 共享的数学对象（耦合点公式）

联合目标（C11）为**嵌套 CVaR**：

```
L_rank(θ) = mean_K mean_p min_ξ [ ξ_{p,K} + (1/K_eff)·Σ_n [ softplus( S_n^{(α)} − S_p^{(α)} ) − ξ_{p,K} ]_+ ]
              └─────────── 外层：跨实体 CVaR_{β_K}，活动集 A_{p,K} ───────────┘
                                              └─ 内层：实体内 CVaR_α，活动集 A_e ─┘
```

共享的不是「都关心难例」，而是四个可指认的数学对象：

1. **同一 R-U 变分泛函** `ζ + (1/β)E[·−ζ]_+`，在两层各出现一次；
   两层的内层 min 都在经验分位数（VaR）取得——BER 侧该性质已由 Zhu 2022 定理 1
   核验（原件物理页 4［全文核验，`2022-Zhu-pAUC-DRO低误报深度排序.md`］）。
2. **同一容量帽单纯形对偶**：外层不确定集 `{q ∈ Δ, q_n ≤ 1/K}`，
   内层权重集 `{w ∈ Δ, w_i ≤ 1/k_e}`——同一多面体族，只是帽参数不同。
3. **两级活动集复合的梯度链**（RGO 全导数分解的对位物）：

   ```
   ∂L_rank/∂θ = Σ_K Σ_{(p,n)∈A_{p,K}} (1/K_eff)·σ'(S_n−S_p) · [ Σ_{i∈A_n}(1/k_n)·∂l_{n,i}/∂θ − Σ_{i∈A_p}(1/k_p)·∂l_{p,i}/∂θ ]
   ```

   外层活动集选「哪些对进入梯度」，内层活动集选「每对的信号由哪些流承载」。
   `z1=0` 时 `|A_e| ≡ 1`（argmax 单点）；`z1=1` 时 `|A_e| = k_e`。
4. **同一预算/尾部水平参数轴**：α 与 β_K 是同一泛函的同一形参。
   **变体 1b（预算匹配嵌套 CVaR）**：令第 K 档排序项内的实体分数取
   `S_e^{(β_K)}`，即**直接复用已冻结的六档预算网格**，内外两层由字面上同一个 β
   参数化——这是可构造的最深共享，且 α 不再引入新魔法数字
   （代价：评价期单一实体分数需另定 α 档或取档均值，须主进程裁决，见 5.3）。

框架层面的收敛理论已存在：「袋级池化 ∘ 部分 AUC」的耦合复合优化（FCCO）
由 Hu 等 2023 建立（物理页 8 式(8)–(9)，支持均值/平滑最大/注意力池化
［全文核验，`2023-Hu-多示例双向部分AUC.md`］）；CVaR/top-k 池化是同一复合槽位上
换一个池化算子，收敛分析框架同族（该延伸本身［待验证］）。

### 2.3 交互为正的机制理由（全部［待验证］，设计推理）

预注册交互 `I = C11 − C10 − C01 + C00 > 0` 的三条机制通道：

1. **结构性集中**：M1 的训练侧通道**只在 C11 存在**。C10/C00 的训练是逐流 CE，
   训练图中不出现实体聚合；只有 BER 在场时（C01/C11）聚合才进入训练目标。
   因此 M1 的全部训练收益按构造集中于交互项——这比朱的 DS（DS-AT 也改训练）更锐利。
2. **稀有脉冲估计量的密度化**：C01 的外层梯度是稀有事件估计——K=121 档驻点
   单步活动对期望仅 `0.128`，且每个活动对经 max 只落到 1 条流上［仓库实测：
   CVaR 失配分析第二节］。C11 中每个活动对的内层支撑变为 `k_e = ⌈αm_e⌉`
   （排序袋实测可达数千流，截断上限 8192），单脉冲的有效梯度样本量提高 1–2 个
   数量级，直接攻击 BER 已实测的统计瓶颈。对位朱的机制解释：
   「内层解越稳定，外层反应梯度的估计越准」。
3. **内层解的稳定性**：argmax 流在步间跳变时 `∂S_e/∂θ` 不连续（对位不稳定的 δ*）；
   top-k 尾集随 θ 连续小步演化，`L_pn` 分布更平稳，ξ 水库估计的目标分布抖动更小。

判读规则（可证伪）：若通道 2 成立，C11 相对 C01 的低三档轮均活动率应向 β 带回升；
若三个通道的观测量（见 2.4）全部无信号而 C11 仍占优，则共享框架解释不成立，
只能按「经验有效」弱化表述。

### 2.4 可证伪观测量（训练期聚合标量，不落成员表）

| 标量 | 定义 | 证伪判读 |
| --- | --- | --- |
| `nonargmax_grad_share` | 排序梯度范数中由非 argmax 流承载的份额（逐步标量，记轮均值） | 若 C11 中 ≈0，密度化通道（2.3-2）不成立 |
| `per_budget_active_rate` 轮均值 | BER 既有诊断（改轮内累计口径的版本） | 若 C11 低三档相对 C01 无回升，耦合主预测失败 |

| `inner_tail_frac` | `mean_e k_e/m_e`（诊断口径核对，防实现错位） | 偏离 α 超容差 ⇒ 实现缺陷 |

### 2.5 实现代价与本轮实测

- **参数量：0**（α 冻结）。与 BER 推理参数 0 同口径；朱的 DS 亦 0 参数（纯调度）。
  与任务简报「约 10 万级」的张力见第六节。
- **挂载点**：实体评分结构——训练侧在 BER 宿主的 `S_e` 计算处
  （`tools/ch3_ft_entity_ranking_loss.py` 的实体聚合），评价侧在实体得分聚合器；
  分词器、块堆叠、逐流头全部不动。
- **运行时状态：无**。聚合是当前袋上的无状态置换不变算子，无跨片段读写、
  无固定容量队列，CEM 的三条死因（状态机/表示自指/定容）均不沾。
- **torch.compile［本轮实测］**：静态实现（降序 sort ＋ `arange<k` 权重矩阵，
  无动态 topk、无布尔索引）`graph_break_count = 0`，`fullgraph=True` 编译执行成功，
  换形状二次调用成功（torch 2.12.0，CPU，玩具规模；宿主集成与 CUDA inductor 须复核）。
- **实现陷阱［本轮实测］**：R-U「detach 批内分位数 ζ ＋ hinge」写法在 `αm ≤ 1`
  的小袋上梯度支撑为 0（ζ＝批最大值 ⇒ hinge 全零），比 max 更糟——与 BER 分析
  否决「批内第 ⌈K_eff⌉ 大值」的退化同型。**必须用 ATk（top-⌈αm⌉ 均值）形式**：
  实测值与显式 topk 均值逐位一致、梯度支撑恰为 `⌈αm⌉∨1`、小袋连续退化为 max。
- **训练期截断袋偏差**：排序袋截断 8192 流时，抽样袋上的非线性池化不是完整袋
  池化的无偏估计（MIDAM，物理页 4［全文核验］）；现状 max 聚合同样受截断影响，
  须在实验合同中如实登记，评价期用完整袋不受此偏差。
- **α 的魔法数字门禁**：单一 α 须以不读目标标签的源年诊断登记依据
  （首选：源年打分转储后的重聚合敏感性扫描，见 4.1）；或改用变体 1b
  复用冻结预算网格，从根上不新增数字。

## 三、候选二：熵风险（LSE）软聚合——同框架的平滑对偶变体

```
S_e^{(T)} = T · log( (1/m_e) Σ_i exp(l_{e,i}/T) )
          = max { Σ_i w_i l_{e,i} − T·KL(w ‖ unif) : w ∈ Δ_{m_e} }
```

- **共享框架**：内层换成 KL 罚的 DRO 对偶（熵风险测度），外层仍是容量帽单纯形
  CVaR——精确/平滑这对估计量**同在 Zhu 2022 物理页 4 式(7)–(10)**（CVaR 给精确
  非平滑估计、KL 正则给平滑软估计［全文核验］），即候选二与候选一的关系
  正是 BER 来源论文里 SOPA 与 SOTA-s 的关系，框架同源性有直接文献锚点。
- **优点**：处处光滑（无 argmax 跳变）、纯逐元素＋归约实现，编译风险最低；
  MIDAM 对平滑最大池化的复合收敛分析直接适用（物理页 4–6［全文核验］）。
- **缺点**：权重泄漏到袋体（所有流都有非零权重），稀释「低误报只看尾部」的
  语义；softmax 权重对 logit 尺度敏感，跨年 logit 尺度漂移会改变有效锐度
  （无状态，但温度尺度的跨年非平稳性须登记为风险［待验证］）；
  共享对象从「两层同一泛函」放宽为「两层同属 DRO 对偶族」，弱于候选一。
- 参数量 0–1（T 冻结或可学；C10 中无训练路径，须冻结）；观测量与候选一共用，
  另加权重熵比 `H(w)/log m_e`（Ilse 2018 笔记第 5 条建议的诊断口径）。

**排序第二**：实现风险最低，但机制语义与共享强度都比候选一弱一档。
若候选一在宿主集成中出现不可排除的编译或数值问题，候选二是同框架内的直接退路。

## 四、候选三：容量帽单纯形读出注意力（sparsemax/entmax 族 CLS 读出）

把逐流 CLS 读出换成对 84 个字段 Token 的稀疏注意力池化
（sparsemax：`argmax_{q∈Δ} ⟨q,z⟩ − ½‖q‖²`，解为阈值截断 `q_i = [z_i − τ(z)]_+`；
或 α-entmax），可带查询/键投影参数 `2·d² = 73,728`，加值投影约 `1.1×10^5`。

- **优点**：唯一满足「10 万级参数」读数且在 C10 逐流 CE 下可训练的候选；
  阈值截断算子与 CVaR 对偶解同属容量帽单纯形投影族。
- **实质缺陷**：与 BER **没有共享变量、没有复合链**——共享只到「算子族同构」，
  正是任务简报警告的类比级共享；交互为正无先验机制理由。且 Ilse 2018 的校准
  数字（注意力相对均值池化 AUC 增益 +0.003～+0.028，表 2/3 物理页 8
  ［全文核验］）提示参数化池化的独立增益量级小于本课题单种子方差。
- **排序第三，不作为共享框架问题的答案**；仅当主进程把参数量对称性置于框架
  共享之上时才值得考虑。

### 5.2 C10 是纯推理侧变化（最大的叙事张力）

候选一/二在 C10 中不改变训练（逐流 CE 训练图中无实体聚合），C10＝对既有 C00
检查点按新聚合重新选轮＋重新评价。好处：C10 无需新训练、零编译风险、
边际成本极低；坏处：**单独的 M1 不是「训练方法」**，与研究对象「训练方法及
训练系统」的叙事有张力。可用的辩护：机制的训练侧效应在 C11 中真实存在
（聚合进入排序目标的训练图），且朱的先例表明单独效果弱、交互贡献大的机制
成立（DS 单独 +0.90，交互 +3.80）。**是否接受该框架定位，须主进程/用户裁决。**

### 5.3 变体 1b 的评价口径缺口

预算匹配嵌套 CVaR 消除了 α 魔法数字，但实体 AP 需要单一实体分数，
六档 `S^{(β_K)}` 如何折成一个评价分数（取中档／取均值／主指标改按档报告）
是一个设计决定，任何选择都须在实验前登记，不得看结果后选。

### 5.4 新颖性边界（来自全文核验笔记，非本轮新增）

「实体袋＋pAUC」组合已被 Hu 2023 占用（笔记明示），BER 本身已按
「任务化改造」路径辩护；候选一的差量论证必须同样落在：预算匹配的两级同参
嵌套、实体时间因果、封印协议、max→CVaR 的可分离消融。若正文不能把差量
写清楚，候选一会遇到与 BER 相同的新颖性质询。

## 六、参数量口径张力（如实披露）

任务简报要求「参数量与 BER 同量级（约 10 万级）」。两个口径矛盾：
BER 推理参数实测为 **0**（C01 与 C00 state_dict 逐位同形，924,285 元素
［仓库实测］），朱的 DS 也是 0 参数；「10 万级」锚定的是 M-E/CEM。
候选一/二字面满足「与 BER 同量级」（＝0），不满足括号里的 10 万级；
候选三反之。本报告按「框架共享优先于参数对称」排序；若主进程坚持 10 万级
为硬门槛，则本裁决降级为：**路线二仅有类比级共享的构造（候选三），
真共享框架的构造与该参数门槛互斥**。

## 七、证伪路径（按成本升序）

1. **源年重聚合探针（首个实验，无需训练）**：用 C00 已选检查点对 LSPR23
   验证角色做一次打分转储（逐流 logit），离线按 α 网格重聚合算实体 AP。
   本轮已确认现有制品不含逐流分数（`selection.json` 仅轮级指标［本轮实测］），
   故需一次前向转储。产出同时服务：α 的魔法数字登记、C10 预估、
   「低预算误报是否集中于大袋 max 膨胀」假设的直接检验。零训练、零 LSPR24。
2. **C11′ 单种子先导**：BER 宿主中把 S_e 换为 ATk 聚合（约 10 行，静态实现
   已验证），与现 C01 同预算重跑单臂，看 2.4 的四个观测量与实体 AP。
3. **四格补齐**按既有冻结合同执行；封印目标年评价仍按根规则最后进行。

若第 1 步中所有 α 档的源年重聚合实体 AP 均不高于 max 聚合、且第 2 步观测量

## 八、结论重述

- **路线二可行，推荐构造一（实体内尾部聚合，ATk/嵌套 CVaR 形式；
  变体 1b 预算匹配为最深共享）。** 候选二为同框架平滑退路，候选三仅在
  参数对称优先时考虑。
- 三条最关键依据：
  1. BER 现状已是「聚合 ∘ CVaR-pAUC」复合，max 就是同族算子的极端点——
     共享槽位是结构给定的，不是拼凑（第 1.1、2.2 节，公式已列）；
  2. 复合框架与两种内层对偶均有全文核验的已发表来源
     （Hu 2023 物理页 8；Zhu 2022 物理页 4；Gulcehre 2014 物理页 3/5）；
  3. 静态实现三项核验全过（值逐位一致、梯度支撑 `⌈αm⌉∨1`、
     fullgraph 零断裂），并排除了一个会致零梯度的实现陷阱［本轮实测］。
- 全部有效性主张标注［待验证］；本报告不改变 M-E 的任何既有裁决。
