## 一、目标与预期决策

目标是核定机制 A、B、C 的完整组合与各子机制在经典工作及 2016—2026 年直接近邻中的既有占用边界，并回答它们能否作为中文硕士论文第四章的两个核心机制。最终结论必须分成四层：

1. **已有机制**：论文已明确提出或直接实现的机制；
2. **任务化改造**：已有机制迁移到跨年度网络攻击状态检测、实体级决策或固定误报预算后的具体化；
3. **潜在原创耦合**：只有组合、时序合同或回退关系尚未发现直接同构，且已有全文证据足以限定该表述；
4. **尚未关闭的查重缺口**：检索覆盖、全文获取或题录核验仍不足的部分。

不得把“连续检索未命中”写成“世界上不存在”。文献只能裁定机制来源、占用边界和可试性，不能替代本课题实验。

## 二、待核机制的操作化定义

### A：目标前缀决策层适应

使用目标年度时间因果前缀中的少量合法标签或无标签预测，执行实体级阈值或类别先验校正；在固定误报预算下冻结参数，只在后段评价。黑盒标签移位估计仅作条件性支路，失配时回退到不依赖该假设的标定方式。

### B：实体历史的双时间尺度表示

按实体键维护全历史因果前缀统计与有界近期窗口统计两个通道；只在源域按实体分组的折外预测上选择窗口或变体；目标后段不再选优。目标是改善长实体排序和大型良性实体假阳，同时保持总体实体级指标。

### C：统一两阶段算法合同

阶段一在源域训练并按实体分组折外选择机制或超参数；阶段二仅用目标时间前缀标定决策层；随后冻结全部选择与标定参数，在目标后段评价。A、B 的贡献是否能由这一统一合同形成非平凡耦合，是查重重点。

## 三、研究问题

1. A 的“目标前缀标定—固定误报预算—冻结后段—失配回退”完整链条是否已有直接同构？
2. B 的“实体全历史＋有界近期窗口双通道—源域实体分组折外选窗—长实体假阳”完整链条是否已有直接同构？
3. C 的“源域训练与折外选择→目标前缀标定→冻结后段评价”是否已作为统一算法发表？
4. 各子机制分别由哪些经典工作或近年方法占用，哪些仅是任务化改造？
5. 哪些近邻构成反例或边界，例如依赖标签移位、持续在线更新、逐样本而非实体决策、随机划分或使用后段标签？
6. 在不声称“首次”的前提下，最强且可核验的中文硕士论文贡献措辞是什么？

## 四、范围、来源与证据门槛

### 时间与领域

- 经典奠基工作不设年份下限；直接近邻重点覆盖 2016—2026 年。
- 优先级依次为：网络入侵检测、加密流量、主机或实体级告警；时间序列分类、多示例学习；标签移位、在线校准与风险控制。
- 近期性检查须覆盖 2025—2026 年预印本、正式论文和作者项目页。

### 纳入标准

- 明确实现 A、B、C 中至少一个关键关系，而非只在引言提及漂移、校准或多尺度；
- 可核验题录，优先有 DOI、arXiv 标识、正式出版社页面或作者公开版本；
- 核心论文必须取得全文，并能给出页码、章节、公式或算法位置；
- 能明确判断实体键、时间因果性、标签权限、选择域、评价段和回退条件中的至少三项；
- 反例或边界论文即使不改善性能，只要能界定机制适用条件，也可纳入。

### 排除标准

- 仅做通用域适应或测试时适应，但不涉及目标前缀、实体决策、阈值或先验校正；
- 只在目标测试集上事后选阈值、选窗口或调超参数；
- 只做模型级多尺度特征融合，既无实体键也无全历史与近期窗口的因果关系；
- 只有摘要或二手转述且无法取得全文的材料，不用于强结论，只进入待补全文清单；
- 无法核验来源、题录或版本的页面；
- 与本任务无关的传统流量分类器性能堆叠。

### 证据等级

| 等级 | 要求 | 可支持的结论 |
| --- | --- | --- |
| E3 | 正式全文或作者公开全文，题录核验，页码／公式／算法锚点齐全 | 机制占用、方法差异、适用边界 |
| E2 | 可信预印本全文，题录与版本核验，页码锚点齐全 | 同上，但注明预印本状态 |
| E1 | 仅摘要、正式元数据或项目页 | 发现线索与待补全文，不支持方法细节强结论 |
| E0 | 二手综述、搜索摘要或未核验页面 | 仅用于扩展检索式，不进入证据矩阵结论 |

## 五、直接同构分级

| 级别 | 判定 |
| --- | --- |
| D3：完整同构 | 同时覆盖相应机制全部关键关系；若为 C，须明确两阶段时间合同与冻结后段评价 |
| D2：强近邻 | 覆盖两个以上关键关系，但缺一个决定性环节，例如无实体级、无回退或无源域折外选择 |
| D1：子机制占用 | 只占用一个子机制，例如标签移位估计、双时间尺度状态、实体聚合或固定风险控制 |
| D0：边界／反例 | 任务表面相似，但标签权限、时间顺序、选择域或评价单元不同，不能作为同构先例 |
