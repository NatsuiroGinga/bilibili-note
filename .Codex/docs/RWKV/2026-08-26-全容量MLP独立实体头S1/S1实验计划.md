## 四、实体头公式与参数

对 B10 在实体 `e` 第 `t` 次曝光的固定逐流概率 `p_{e,t}`，定义：

\[
m_{e,t}=\frac{1}{t}\sum_{i=1}^{t}p_{e,i},\qquad
q_{e,t}=\max_{i\le t}p_{e,i}.
\]

候选头：

\[
z^{\mathrm{cand}}_{e,t}=b+w_m m_{e,t}+w_q q_{e,t},\qquad
s^{\mathrm{cand}}_{e,t}=\sigma(z^{\mathrm{cand}}_{e,t}).
\]

参数匹配控制头：

\[
z^{\mathrm{ctrl}}_{e,t}=c+v_1 m_{e,t}+v_2 m_{e,t},\qquad
s^{\mathrm{ctrl}}_{e,t}=\sigma(z^{\mathrm{ctrl}}_{e,t}).
\]

两头均恰有两个权重加一个 bias，共 `3` 个可训练 FP64 标量；全零初始化。训练只使用终端 `t=n_e`。在线与首次告警直接把训练出的同一组参数作用于每个前缀，禁止另训在线头或另选阈值语义。

## 五、训练损失与 LBFGS

训练实体正负集合分别为 `P_tr/N_tr`。两头使用相同的确定性类平衡全批量 BCE：

\[
\mathcal L(\theta)=-\frac{1}{2|P_{tr}|}\sum_{e\in P_{tr}}\log s_e
-\frac{1}{2|N_{tr}|}\sum_{e\in N_{tr}}\log(1-s_e).
\]

等价 `pos_weight=|N_tr|/|P_tr|` 只可用于实现校验；正式损失按上式 FP64 直接计算。训练实体不足一类、输入／损失／梯度／参数非有限时立即失败。

PyTorch `torch.optim.LBFGS` 固定：

| 参数 | 值 |
| --- | ---: |
| `lr` | `1.0` |
| `max_iter` | `100` |
| `max_eval` | `125` |
| `tolerance_grad` | `1e-7` |
| `tolerance_change` | `1e-9` |
| `history_size` | `10` |
| `line_search_fn` | `strong_wolfe` |

每头独立从零开始，一次全批量 `step(closure)`；记录 closure 调用数、`n_iter`、`func_evals`、初末损失、末梯度无穷范数、参数和终止上限。达到上限但数值有限可评价，不得续训、换优化器或据验证指标重启。
