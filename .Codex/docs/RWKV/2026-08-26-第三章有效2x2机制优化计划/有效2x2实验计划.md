## 一、目的与禁止项

本实验只回答：在保持既有 `B00/B10` 逐流模型完全不变时，固定实体算子 `0.5×mean+0.5×max` 相对 `max` 是否在 LSPR23 实体运营指标上产生可复核的源年信号。

本轮禁止：

- 读取或评价 LSPR24；
- 训练或写入模型检查点；
- 搜索、拟合或修改 `0.5/0.5` 权重；
- 实现新的分数层 CPA；
- 用逐流 AP 选实体算子；
- 使用 `1×SE=0.036` 或未冻结的显著性门；
- 把 S0 结果写成正式有效性、泛化或原创性结论。

## 四、冻结四格

设 `p^b_{e,t}` 为检查点 `b` 对实体 `e` 第 `t` 次曝光的逐流概率：

\[
m^b_{e,t}=t^{-1}\sum_{j=1}^{t}p^b_{e,j},\quad
q^b_{e,t}=\max_{j\le t}p^b_{e,j},\quad
u^b_{e,t}=0.5m^b_{e,t}+0.5q^b_{e,t}.
\]

| 格 | 冻结定义 |
| --- | --- |
| `C00` | `B00` 逐流输出；在线与终端实体分数用 `q^{B00}` |
| `C01'` | 与 `C00` 同一份 `B00` 逐流输出；在线与终端实体分数用 `u^{B00}` |
| `C10` | `B10` 逐流输出；在线与终端实体分数用 `q^{B10}` |
| `C11'` | 与 `C10` 同一份 `B10` 逐流输出；在线与终端实体分数用 `u^{B10}` |

终端实体分数必须等于对应在线前缀序列的最后一个值。混合公式必须在每个前缀使用同一个 `0.5/0.5`，禁止只在终端混合或先混合全实体后回填前缀。

## 五、逐流同一性硬护栏

每个检查点只执行一次逻辑前向，并在两个实体算子格之间共享只读逐流概率。必须同时满足：

1. `C00` 与 `C01'` 的逐流 logits、概率、行键顺序、有效行数和 SHA-256 逐项相同。
2. `C10` 与 `C11'` 的逐流 logits、概率、行键顺序、有效行数和 SHA-256 逐项相同。
3. 逐流 AP 的同检查点配对差值逐位为零；否则属于实现错误，不是机制结果。
4. 不要求 `B00` 与 `B10` 逐流输出相同，因为它们代表 CPA 的两个处理水平。

任何同一性失败都停止并保留状态、哈希和原退出码；修复前四格指标无效。

## 六、裁决指标与共同预算

主裁决只使用实体层：

- 实体 AP；
- 最大实体 AP；
- 以公共整数假阳性实体预算为横轴的完整终端检测曲线；
- 同一公共实际假阳性预算下的首次告警曲线、未告警率和 1 基曝光序及时检出阶梯。

比较必须在相同 LSPR23 负实体分母、相同整数 FP 预算 `k` 下进行。每格在自身全部可达点中取 `FP≤k` 的最后可达点；不拆并列组、不插值、不用名义 FPR 冒充实际 FPR。六档若沿用既有展示网格，只是完整曲线投影，必须同时写 `nominal_fpr`、`integer_fp_budget` 和 `actual_fpr`。

逐流 AP、逐流输出哈希和行数只作同一性护栏，不参与实体算子优劣裁决。

## 七、S0 信号与停止条件

配对比较为 `C01'−C00` 和 `C11'−C10`；CPA 主效应为 `C10−C00` 与 `C11'−C01'`。交互只报告确定性差值，不报告显著性。

**源年有信号**：至少一个固定混合格相对同检查点 `max` 格在实体 AP、最大实体 AP、共同实际 FP 完整终端曲线或首次告警轴上出现严格改善，且该混合格没有被同检查点 `max` 格在全部主裁决轴上支配。所有改善和退化必须并列披露，不允许只摘最好预算点。

**源年无信号**：两个固定混合格都与同检查点 `max` 格完全相同，或都被对应 `max` 格在主裁决轴上支配。此时结论固定为“LSPR23 S0 不支持固定混合实体算子”；保留现有 O11，停止本方向，不进入 S1，不读取 LSPR24，不改权重或算子救回。

**非支配权衡**：若有严格改善也有退化，只能写“源年非支配权衡”，视为需要用户判断的信号，不得写成全面提升。
