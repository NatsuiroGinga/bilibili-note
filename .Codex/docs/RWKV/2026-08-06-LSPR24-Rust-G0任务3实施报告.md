## 1. 实施边界

本任务只使用人工 JSON 收据、人工制品字节和临时路径。未读取真实 LSPR24、标签、攻击叙事、最终测试或任何全量数据；未修改任务 1/2 模块、Python、正式配置、数据、总控或既有 R2 Rust 包。

实现严格分为三层：

1. 配置与收据执行拒绝未知字段、未知枚举、非法摘要和通配路径。
2. 门禁归约独立验证合同、收据自哈希、输入制品 SHA-256 和固定依赖图。
3. 生产者 `checks` 中的汇总布尔值及生产者顶层 `status` 不作为独立复算结果；缺少可信复算状态时固定为 `NOT_READY`。

任务 5 才负责从真实原始制品复算 A01 至 A14 的逐项机器谓词。本任务不提前读取真实制品，也不把生产者自报结果冒充独立复算。
