# RWKV 固定结构统一 BF16 重训实施计划

> **执行要求：**按 `writing-plans` 与 `daily-coding` 执行；本任务已由主代理分派给独立实现代理。仓库规则禁止人工测试夹具、训练和自动格式化器，因此验证只使用语法、导入、帮助、配置、Shell 与静态精度岛检查。

**目标：**为已由旧 FP32 Protocol A 选择封印的 `R2 + 最终胜出 K` 建立独立 RTX 5090 BF16 从头重训入口，只训练固定结构的 C00/C01/C10/C11，不重复架构搜索。

**架构：**保留旧 FP32 工具和启动器字节不变，新增 BF16 专用 Python 入口、待注入配置模板与独立 Shell 启动器。启动器只读消费旧 FP32 `capacity_selection_frozen.json`，机械注入最终 K、收据路径和摘要；收据缺失、适配器不是 R2 或容量未封印时拒绝启动。BF16 入口复用旧 Protocol A 的数据、切分、指标和目标隔离辅助函数，但以共享精度运行时建立 autocast、FP32 敏感区、无缩放器、等效微批和完整优化步检查点。

**技术栈：**Python、PyTorch 2.13 目标环境、NumPy、Shell、共享 `tools/neural_precision_runtime.py`。

**依据：**`.Codex/docs/RWKV/2026-08-20-RWKV7字段感知输入与协议A四格实施计划.md`、`.Codex/docs/RWKV/2026-08-21-RTX5090神经训练默认精度模式/实施报告.md` 与主代理 2026-08-21 最新裁决。

## 全局约束

- 新运行身份固定为 `ch3-rwkv7-field-aware-protocol-a-2x2-seed42-v1-bf16-v1`。
- 旧 FP32 运行只提供已封印的架构选择证据；不得复用模型、优化器、轮次选择、目标结果或运行目录。
- R2 已封印；BF16 不重训或重比 R0/R1/R2。
- K0/K1/K2 的旧 FP32 容量选择完成后才允许解析最终 K；BF16 不重训容量候选。
- 固定结构的 C00/C01/C10/C11 均使用 `cuda-bf16-amp-fp32-sensitive-v1` 从头训练 20 轮、每轮 1000 步，并各自按 LSPR23 验证逐流 AP 选择最早最佳轮。
- 有效批保持 64 个序列；微批 8 个序列、累积 8 次只作资源实现，流损失与序列损失分别按本有效批真实流数和原冻结加权序列分母归一，禁止混合归一。
- 参数和优化器状态保持 FP32；BF16 不创建 `GradScaler`。
- RWKV 递归状态、衰减与指数、矩阵状态更新、归一化、对数、LP 池化、BCE、归约和指标保持 FP32。
- 无人为时长上限；LSPR24 只在四格源年选择全部封印后加载。
- 本轮不访问服务器、不启动实验。
