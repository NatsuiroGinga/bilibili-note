# 全容量 MLP 统一 BF16 资格实验严格结果分析

- **日期**：2026-08-21
- **路线**：RWKV 第三章
- **运行身份**：`ch3-full-mlp-complete-entity-lp-protocol-a-q0-seed42-v1-bf16-v1`
- **分析代理**：`full_mlp_bf16_results_analysis_sol_high`，`gpt-5.6-sol`，`effort=high`
- **证据等级**：LSPR23 单种子源年开发支持；LSPR24 冻结后描述性评价，不是独立测试
- **统计口径**：描述统计、确定性差值和帕累托偏序；不做加权总分、显著性检验、置信区间或稳定性主张

## 一、核心裁决

1. **源年开发支持保留全容量 MLP 资格，但不支持宣布正式替代。** 在逐流 AP、实体 AP、最大 AP、0–8% 阶梯面积和六档真实可达 DR 的联合向量上，`B10` 与 `O11` 构成六分支源年前沿；`B10` 在该标量向量上支配 `B00/N01/N11/O01`，`O11` 因最大 AP 和完整曲线交叉保持非支配。
2. **目标年 O11 的实体 AP 最高，但它不是全面胜者。** O11 的逐流 AP=`0.1327105943`、实体 AP=`0.5854895986`、最大 AP=`0.5713766131`。实体 AP 高于当前同池登记基线，逐流 AP 却明显低于 XGBoost、门控循环、全注意力、历史 MLP 和 XGBoost＋CPA-ELP；相对 XGBoost＋CPA-ELP，O11 在 0.1%–1% 预算 DR 更高、2% 持平、4%–8% 更低。
3. **必须否决“4% FPR 预算下全检出”。** O11 的名义 `DR@4%=1` 与 `DR@8%=1` 来自阈值索引，不满足实际预算。终端实体曲线在真实 `FPR≤0.04` 时最优可达 `DR=0.7898936170`，对应 `1725/46363` 个假阳性实体、`FPR=0.0372063930`；下一可达点因 `1e-7` 并列直接跳到 `46363/46363`、`FPR=1.0`、`DR=1.0`。同一 4% 标签的首次告警实际为 `36650/46363`、`FPR=0.7905010461`，告警 `732/752` 个正实体。
4. **跨模型完整支配仍不可证。** O11 在共同可达的 `0–3.7206%` FPR 曲线段严格高于 ResMLP2 与 TabM4，但这些基线及随机森林、XGBoost、已发表神经基线和历史 MLP 缺同轴首次告警或完整曲线制品，不能把“现有标量非支配”升级为“已证明完整同池帕累托支配”。
5. **资源只记事实，不作效率排序。** 最终收据明确 `resource_measurement_contended=true`、`fair_efficiency_evidence=false`，且已知与 GRANDE 并发；墙钟、显存、主存、吞吐和 GPU 小时均不能用于公平效率结论。

### 4.3 O11 并列悬崖

- 终端实体预算曲线：最后一个 `FPR≤0.04` 点为 `nFP=1725`、`FPR=0.0372063930`、`DR=0.7898936170`；下一点为 `nFP=46363`、`FPR=1.0`、`DR=1.0`。一次阈值下降增加 `44638` 个假阳性实体和 `0.2101063830` 的 DR。
- 首次告警：4% 与 8% 标签复用阈值 `1.0000000116860974e-7`，实际 `FPR=0.7905010461`，未告警率 `0.0265957447`。该点只能描述“此阈值下”的结果，不能归入 4% 或 8% 预算。
- 精确 4% 首次告警无法补算。运行没有持久化逐流分数、逐实体分数或逐实体首次告警值；现有 NPZ 只有六个已选阈值的聚合按时检出曲线。禁止从终端实体曲线反推首次告警分布。

## 九、决策与下一门禁

1. 保留全容量 MLP 作为可微资格候选；源年代表性前沿分支至少保留 `B10` 与 `O11` 的身份，不得用目标年结果删除 B10 或单选 O11。
2. 所有汇总、统一表和正文候选数字把 O11 的 4%/8% DR 写为真实可达 `0.7898936170`，并登记 3.7206%→100% 的并列悬崖。
3. 若未来需要正式比较首次告警，必须在不使用 LSPR24 调参的前提下另立源年冻结的并列处理与精确预算合同，并保存足以复算相同实际 FPR 的聚合制品；本轮不能事后改阈值补结果。
4. 正文前仍需按冻结正文基线范围补齐同精度、完整曲线和同轴首次告警；当前单种子描述性结果不得直接写成稳定优越性主张。
5. 效率比较必须在无 GRANDE 并发的独占资源条件下另行运行；不需要为本轮科学资格重跑，只在正文确实提出效率主张时补证。
