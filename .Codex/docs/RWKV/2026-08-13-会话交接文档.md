## 7. 第四章：候选方案（已定）

### 7.1 被否决的两个原始候选

- **候选一 漂移感知可迁移难度课程 → 否决**。RCS（arXiv:2504.13592v2 §2.3 p.4）已完整发表
  「离线收集逐样本信号判困难 → 两阶段调度 → 后期只训困难子集」，含配比消融（Table 5 p.9）；
  Pro-GRPO OVF（arXiv:2512.15347 式(10)）已发表「按方差取子集」。
  且按 Bengio ICML 2009 式(4) 的权重单调不减条件，本候选属**反课程/boosting**，论文 p.7 自己已归类。
  更根本的是：它要用的检查点间离散度，正是第三章用末 5 检查点平均**当噪声抹掉**的量，自相矛盾。
- **候选二的 RL 部分 → 否决**。EARLIEST（KDD'19 pp.101–110）已是 RNN+RL 决定何时停与判什么类；
  FIRMBOUND（arXiv:2501.18059 ICLR 2025）用贝叶斯风险后向递推打败 EARLIEST，附录 E.5 p.25
  直指 RL 样本效率差、策略梯度方差大。且观测为冻结日志回放、动作不改变后续观测，
  最优策略由前缀后验决定、可由后向归纳精确解出，**RL 是重造轮子**。

### 7.2 定下来的方案：跨年度漂移下的实体级约束早停告警（不含 RL）

```
第一层  风险形式化（引 FIRMBOUND，不算创新）
        APR_t = L_FN·(1−π_t) + L_FP·π_t + c·t
        停止时刻 τ_e = min{t : 停止风险 ≤ 继续风险}，动作 {继续观察, 告警, 拒识}
        后向归纳解停止边界

第二层  约束而非罚项（引 Achiam CPO ICML 2017，不算创新）
        实体级 FPR ≤ 4% 写成 J_C(π) ≤ 0.04，拉格朗日乘子自动调权
        CPO 图4 p.8 已证固定罚系数极敏感、会给出大量违约的高回报解

第三层  唯一的机制增量：先验漂移鲁棒的停止边界重标定
        用无标签目标前缀做 BBSE 先验估计重标定 + conformal risk control 给 FPR 分布无关上界
        原件已在库：raw/papers/methodology/{2018-Lipton-BBSE-Label-Shift.pdf,
        2024-Angelopoulos-Conformal-Risk-Control.pdf, 2024-Farinhas-Nonexchangeable-Conformal-Risk-Control.pdf}
```

**查重结论**：34 条本地取证 + 联网检索中，**没有任何一篇做过「停止边界的无标签先验漂移重标定」**。
FIRMBOUND 训练测试同分布、p30 自陈无漂移实验；Prasse ECML 2017 只跨两个月同一企业网且静态阈值。

### 7.3 对标朱焱雷第四章的可行性

| 朱 4.2/4.5 | 本候选对位 |
| --- | --- |

### 9.1 一个已量化、未解决的训练/评价分布错配

```
训练：随机抽序列 ≡ 按流数正比抽实体 → 含恶意实体贡献 4.79% 的序列，
      但只占实体总数 0.1586% → **过采样 30 倍**
评价：实体级 AP，每个实体算一次，不论大小 → 实体均匀
```

**这是分布错配，不是难度问题。** 修法是重加权/实体均匀采样，
**不是课程学习**（课程管顺序，这里要的是重加权），**更不是 RL**（无序贯决策结构）。
把它包装成课程学习属于卖概念。

**一个可检验的假设（未测）**：机制一 A 对逐流 AP `+0.194410` 但对实体 AP `−0.022405`，
可能因为 A 的收益集中在大实体（前缀长），而大实体主导逐流指标、在实体级只算一次。
**测法**：实体按流数分桶（1–2 / 3–10 / 11–100 / 101–1000 / >1000），分桶报 A 的增益。纯后处理。

## 11. 本会话的方法学教训（接手方请继承）

1. **已排队的测量未到达前不下裁决**。本会话犯了三次（PLM-NIDS 未查正类先验就定优先级、
   D4 未分离归一化就说外积有害、实体流数中位=2 就说候选二死掉），三次都被随后的实测推翻。
   已写入 `~/.claude/.../memory/no-verdict-before-queued-measurement.md`。
2. **引用任何 σ 必须注明测量协议**。σ 是协议的属性不是任务的属性：
   4000 步无检查点平均下 σ=`0.07~0.23`，20000 步+末5检查点平均下 σ=`0.023248`。
3. **实验跑之前先在合成数据上验逻辑**。本会话靠自检提前发现：BBSE 公式实现正确、
   「TPR 饱和导致病态求逆」的猜测不成立、EM 要求校准后验（否则跑飞到 1.0）。
4. **运行日志要实时读**。分层切分前的随机切实体把 74% 恶意流切进 20% 留出区，
   是从运行日志的 `训练区逐流先验=0.0329` 当场发现的。已在代码中加断言。
5. **子代理的结论要独立复核**。超参工作流的最高优先级建议（配对差值抵消噪声）
   被已落盘数据当场证伪：配对差 σ 是基线 σ 的 2.2~2.8 倍，因 C00 与其余三格跨种子负相关。
