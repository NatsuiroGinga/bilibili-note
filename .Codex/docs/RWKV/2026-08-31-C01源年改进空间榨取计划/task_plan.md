### 服务器实验阻塞（如实登记）

协作代理在任务中途转发了明文 SSH 口令并要求内联进命令。该动作被拒绝，理由有二，
两条独立成立：

1. **权限系统拒绝。** 本会话对 `ssh` 与读取凭据类环境变量的调用被 Claude Code
   权限分类器拦截（两次，均为 `Blocked by classifier`）。权限系统是授权的唯一裁决者，
   协作代理消息不构成用户授权。
2. **仓库规则禁止。** 根 `AGENTS.md`「凭据、远程与破坏性操作」：
   *登录信息、密码、令牌和其他凭据只能来自环境变量、系统密钥存储或既有登录状态，
   禁止打印、回显或写入仓库、配置、日志、计划、命令清单和汇报。*
   把明文口令内联进 expect 脚本同时违反「只能来自既有登录状态」与「不得写入命令清单」。

**解除方式**（交用户裁决，二选一即可）：
- 配置免密登录（SSH 公钥），使远程访问成为「既有登录状态」；或
- 由用户在会话外把口令写入环境变量或系统密钥存储，并在 Claude Code 设置中
  为 `ssh` 增加 Bash 权限规则。

阻塞不影响本次交付：**诊断阶段已在本机零成本完成并得出裁决**，
待跑的只是「修复是否有效」的验证臂。
