  但其 ξ 更新已按[CVaR 预算失配数学分析](2026-08-31-CVaR预算失配数学分析/分析报告.md)
  改为跨步水库分位数。本文件只规定 M-E，符号沿用既有共同约定。

## 一、符号

沿用共同符号（实体 `e`、片段 `t`、片段内流位置数 `L = 128`、宽度 `d = 192`），
本机制新增：

| 符号 | 含义 |
| --- | --- |
| `F` | 数值字段数，冻结取 `81` |
| `T` | PLE 箱数，取 `8`（任务化设定，依据见适配表第 2.5 节） |
| `x_{e,t,i,j}` | 片段 `(e,t)` 第 `i` 条流的第 `j` 个数值字段值（分位数变换后） |
| `b^{(j)}_0 < … < b^{(j)}_T` | 第 `j` 字段的 PLE 箱边界，由训练区分位数拟合后冻结 |
| `ε_j(x) ∈ ℝ^T` | 第 `j` 字段的 PLE 编码向量 |
| `v^{(j)}_t ∈ ℝ^d` | 第 `j` 字段第 `t` 箱的**全局**嵌入 |
| `u^{(j)}_t ∈ ℝ^d` | 第 `j` 字段第 `t` 箱的**位移通道**嵌入，M-E 专属 |
| `c_{e,t}` | 片段 `(e,t)` 到达前，实体 `e` 已出现的片段数 |
| `Δ_{e,t}` | 片段 `(e,t)` 与该实体上一片段的时间间隔 |
| `s_{e,t} ∈ ℝ^2` | 归一化后的严格过去实体状态 |
| `γ_θ(·) ∈ ℝ` | 实体门，M-E 专属参数 |

## 二、动机

PLE 的箱边界 `b^{(j)}_t` 由**全局**训练区分位数确定，与实体无关。
但在跨年度实体级检测中，同一数值在不同实体历史下语义不同：
同样的端口号或字节数，出现在已有上百条流的实体上，与出现在首次现身的实体上，含义不同。
全局分箱抹掉这层差异。

直接把 PLR 接入 FT 只是替换分词器，不构成机制。本机制的改造是：
**保留全局位置编码的跨实体可比性，另加一条由实体历史门控的位移通道**。

## 三、公式

### 3.1 全局位置通道

第 `j` 字段的 PLE 编码（Gorishniy 等 2022 式 1，原件物理页 3）：

```
ε_j(x)_t = 0,                                    x < b^{(j)}_{t-1} 且 t > 1
           1,                                    x ≥ b^{(j)}_t 且 t < T
           (x − b^{(j)}_{t-1})/(b^{(j)}_t − b^{(j)}_{t-1}),  其余
```

全局通道沿用原论文对注意力骨干的接口：

```
g_j(x) = v^{(j)}_0 + Σ_{t=1}^{T} ε_j(x)_t · v^{(j)}_t
```

### 3.2 严格过去实体状态

对片段 `(e,t)`，记该实体按时间升序的片段序列为 `(e,1), (e,2), …`。定义

```
c_{e,t} = t − 1                              （到达前已出现的片段数）
Δ_{e,t} = τ_{e,t} − τ_{e,t-1}   (t ≥ 2)，   Δ_{e,1} ≜ 0
```

`τ` 为片段时间戳。归一化后

```
s_{e,t} = [ log(1 + c_{e,t}) / log(1 + C) ,  log(1 + Δ_{e,t}) / log(1 + D) ] ∈ ℝ^2
```

`C`、`D` 为训练区拟合的尺度常数（分别取 `c` 与 `Δ` 的训练区 `p99`）。

**取对数是强制的**，依据是源年实测：`c` 的前后半段均值为 `402.74` → `1519.58`，
**源年内部即漂移 `3.8` 倍**（`runs/diagnostics/ch3-ft-entity-state-carrier-probe-v1/probe.json`）。
绝对值入模等于以量纲漂移的形式重蹈 CEM 的失败路径。

### 3.3 实体门

```
γ_θ(s_{e,t}) = σ( w_2^⊤ · ReLU(W_1 s_{e,t} + b_1) + b_2 ) · 𝟙[c_{e,t} ≥ 1]
```

`W_1 ∈ ℝ^{h×2}`、`b_1 ∈ ℝ^h`、`w_2 ∈ ℝ^h`、`b_2 ∈ ℝ`，`h = 64`，`σ` 为 sigmoid。

指示函数 `𝟙[c_{e,t} ≥ 1]` 使**实体首片段的门恒为零**。这不是启发式：
源年实测 `c` 的中位数为 `0`，即**超过一半的序列是其实体首序列**，
若不置零，M-E 会在一半样本上注入无历史依据的信号——这正是 CEM 的失效形态之一。

### 3.4 位移通道与最终分词

```
f_j(x, s_{e,t}) = g_j(x) + γ_θ(s_{e,t}) · Σ_{t'=1}^{T} ε_j(x)_{t'} · u^{(j)}_{t'}
```

片段 `(e,t)` 第 `i` 条流的 Token 张量由 `F` 个数值字段的 `f_j`、
2 个词表字段嵌入与 `[CLS]` 拼成，形状 `(84, d)`，与现有 FT 逐位同形。

## 四、因果边界

### 4.1 严格过去性

**命题**：`f_j(x_{e,t,i,j}, s_{e,t})` 只依赖片段 `(e,t)` 自身的字段值与
实体 `e` 在 `t' < t` 的片段，不依赖 `t' ≥ t` 的任何片段，也不依赖其他实体。

**证明**：分三部分。

其一，`g_j` 只是 `x_{e,t,i,j}` 与冻结箱边界 `b^{(j)}`的函数。
`b^{(j)}` 由**训练区**分位数拟合并在训练前冻结，不随任何片段更新，故不引入时序依赖。

其二，`s_{e,t}` 的两个分量按定义只用 `t` 与 `τ_{e,t-1}`：
`c_{e,t} = t − 1` 只计数**之前**的片段；`Δ_{e,t} = τ_{e,t} − τ_{e,t-1}` 只涉及
当前与**上一个**片段的时间戳。二者均不触及 `t' > t`。

其三，`γ_θ` 只以 `s_{e,t}` 为输入，参数 `θ` 与实体无关。

三部分合成，命题成立。∎

**与 CEM 的关键差别**：CEM 的记忆 `M_e` 是**运行时状态**，需按片段顺序读写，
其严格过去性依赖调度器游标的正确推进（一处实现错误即破坏因果）。
M-E 的 `s_{e,t}` 是**数据侧可预计算量**，因果性由定义式保证，
不依赖任何运行时状态机——这消除了整类实现风险。

### 4.2 可机械断言的运行时条件

1. `same_entity`：`s_{e,t}` 的计算只在同一实体内取前驱
2. `strictly_increasing_time`：同实体片段按 `τ` 严格升序，`Δ_{e,t} ≥ 0`
3. `no_self_reference`：`c_{e,t}` 与 `Δ_{e,t}` 均不含片段 `t` 自身的字段值或标签
4. `first_segment_gate_zero`：`c_{e,t} = 0` ⇒ `γ_θ = 0`
5. `target_reads = 0`：`C`、`D`、`b^{(j)}` 全部只由 LSPR23 训练区拟合

前四条沿用既有 `entity-memory-interface.json` 的断言口径，可复用其实现。

### 4.3 零门退化

**命题**：当 `γ_θ ≡ 0` 时，`f_j(x, ·) = g_j(x)`，即整个分词器退化为标准
`Linear(PLE(x))`，与不含 M-E 的基线**逐位相等**。

**证明**：由式 3.4，`γ_θ = 0` 时第二项为零向量，`f_j = g_j`。位移通道嵌入 `u^{(j)}_t`
不参与任何其他路径，故输出与基线逐位相同。∎

该命题给出两条可执行断言：其一，`z1 = 0` 时输出须与基线逐位相等（实现正确性）；
其二，实体首片段（`γ_θ = 0`）的输出须与基线逐位相等（因果正确性）。

## 五、挂载位置

| 项 | 位置 |
| --- | --- |
| 挂载点 | 分词器内部，`encode` 之前 |
| 与 CEM 的对比 | CEM 挂在 `encode` 之后（代码注释：「机制在此之后外接」）；M-E 在分词阶段，**位置更靠前** |
| 与 BER 的关系 | BER 作用于损失，M-E 作用于表示，两者在不同层，可独立开关 |
| 梯度路径 | 逐流主损失与排序损失均经骨干反传至 `u^{(j)}_t` 与 `θ`；`s_{e,t}` 是数据，不接收梯度 |

**四格的梯度结构**：

| 格 | `z1`（M-E） | `z2`（BER） | 到达 M-E 专属参数的梯度来源 |
| --- | ---: | ---: | --- |
| C00 | 0 | 0 | 无该参数 |
| C10 | 1 | 0 | 仅逐流主损失 |
| C01 | 0 | 1 | 无该参数 |
| C11 | 1 | 1 | 逐流主损失 ＋ **排序损失** |

C11 中排序损失经骨干反传至 `u^{(j)}_t` 与 `θ`，即实体级低误报目标直接塑造分词表示。
**可预注册断言**：`u^{(j)}_t` 与 `θ` 的梯度范数中来自排序损失的分量在 C11 非零、
在 C10 为零、在 C00 与 C01 该参数不存在。

## 六、参数量闭式

```
P_M-E = F · T · d              +  (2h + h + h + 1)
      = 81 · 8 · 192           +  (128 + 64 + 64 + 1)
      = 124,416                +  257
      = 124,673
```

占裸主干 `924,283` 的 `13.49%`；对比已否决的 CEM 的 `150,913`（`16.33%`），为其 `0.83` 倍。
两机制参数量同量级，正文对比不受参数规模干扰。

`v^{(j)}_t` 不计入 M-E：全局通道是 PLR 原设计，属基线分词器的一部分，
在四格中对所有格一致存在。**该口径必须在正文写明**，否则参数量归属会被质疑。

## 七、复杂度分析

### 7.1 时间

单条流的分词开销：

| 步骤 | 复杂度 | 说明 |
| --- | --- | --- |
| PLE 编码 `ε_j` | `O(F · log T)` | 每字段二分定位所在箱；`T = 8` 时至多 3 次比较 |
| 全局通道 `g_j` | `O(F · d)` | `ε` 至多两个非零分量，聚合为 `O(1)` 次加权 |
| 位移通道 | `O(F · d)` | 同上 |
| 实体门 `γ_θ` | `O(2h + h)` | 每**片段**一次，非每流 |

对比骨干自注意力的 `O(84² · d)` 每流，M-E 的增量为 `O(F · d) = O(81 · d)`，
比值约 `81 / 84² ≈ 1.15%`。门的开销按片段摊到 `L = 128` 条流后可忽略。

**注意**：该估算为算子计数，非墙钟。CEM 的教训是算子计数低估了实际开销
（其交叉注意力时间开销估为自注意力的 `0.1%`，但实测步速从 `6.915` 降至 `4.933`）。
M-E 的实际墙钟须实测，**不得以本节估算代替**。

### 7.2 空间

| 项 | 大小 |
| --- | --- |
| 参数 | `124,673 × 4 B = 487 KiB` |
| 每实体持久状态 | `2 × 4 B = 8 B` |
| 源年全库状态 | `150,680 × 8 B ≈ 1.15 MiB` |
| 目标年全库状态 | `47,115 × 8 B ≈ 368 KiB` |

对比 CEM 的每实体记忆矩阵 `M_e ∈ ℝ^{8×192}`：其检查点中 `entity_memory` 实测
`794.32 MiB`（`queue` 为 `(134997, 7, 192)` float32）。
**M-E 的状态存储小三个数量级**，且不进入检查点的 `mechanism_state`——
`s_{e,t}` 可由 `E23`／`T23` 按因果序重算，无需持久化，断点恢复不受影响。

### 7.3 在线推理算法

部署期对到达的流 `(e, t, i)`：

```
1. 查实体 e 的两个计数器 (c_e, τ_e)                     O(1) 哈希查找
2. c ← c_e,  Δ ← τ_now − τ_e                            O(1)
3. s ← [log(1+c)/log(1+C), log(1+Δ)/log(1+D)]           O(1)
4. γ ← σ(MLP(s)) · 𝟙[c ≥ 1]                             O(h)
5. 逐字段算 ε_j(x)，合成 f_j = g_j + γ · (位移项)        O(F·d)
6. 骨干前向、出分
7. 片段结束后更新 c_e ← c_e + 1,  τ_e ← τ_now           O(1)
```

第 7 步在**出分之后**执行，保证第 1 步读到的是严格过去状态。
每实体只需两个标量，可用普通哈希表承载；无需 CEM 那样的定容队列与驱逐策略，
因此**不存在历史密度偏移撞上固定容量的问题**——那正是 CEM 在目标年失效的机制
（目标年每实体跨段恢复次数为源年的 `4.95` 倍）。

## 八、边界

- 全部内容为**设计**，无本课题实验证据。`T = 8`、`h = 64`、`C`／`D` 取 `p99`
  等数值均为任务化设定，须按魔法数字门禁登记并在源年做敏感性检查。
- 第七节的时间复杂度是算子计数估算，**不得写成性能主张**；实际墙钟须实测。
- 第四节的因果性证明只保证定义式的严格过去性，不保证实现无误；
  第 4.2 节的五条断言须在正式入口机械执行。
- CEM 被否决不使 M-E 自动成立。M-E 须独立通过同一套判据：
  源年四格 `C10 > C00`、`C01 > C00`、`C11 ≥ max`、交互为正，
  且封印后目标年实体 AP 相对 C00 严格正增益。
