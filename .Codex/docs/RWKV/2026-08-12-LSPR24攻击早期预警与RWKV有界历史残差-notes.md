# LSPR24 攻击早期预警与 RWKV 有界历史残差笔记

## 既有实验硬证据

- 跨年度共享 XGBoost 的目标开发 PR-AUC 为 `0.038902589823969644`，是当前 Q0 最强静态排序锚。
- 完整论文协议尽量复现矩阵中，XGBoost 为 `0.036855901673935376`，一维卷积神经网络为 `0.017699644760456223`，GRU 与三种 Transformer 均接近目标恶意基率。
- 候选 B 最佳离散 RWKV 变体为 `0.019205959409695748`，角色分离物理时间变体为 `0.010123021167351991`；机制信号和晋级门均失败。
- C12 最强既有核 K-DELTA 为 `0.016977277`；C12 完整组合为 `0.00835439568`，未超过单机制。
- R1 最佳 GroupDRO 为 `0.012877901366876719`；完整双层风险未超过最佳单机制。
- C12-R 六格均未超过原始 DREF `0.009274477710716156`，恶意 F1 和冻结源阈值召回均为零。

## 实验解释

1. 当前失败首先发生在跨年度表示与排序层，不是因为阈值、回退、连续时间或状态门数量不够。
2. 树模型保留了明显强于神经序列模型的可迁移静态信号，因此新候选不得先丢弃强表格锚。
3. RWKV 若继续使用，应改为历史辅助证据：只修正强基座无法从当前流获得的信息，并通过零初始化、限幅和回滚控制负增益。
4. LSPR24 单年当前状态分类已有接近饱和的历史结果，不能作为下一章主任务；攻击早期预警更能检验历史状态是否必要。

## 文献迁移框架

- RWKV-TS：把语言序列输入改为实例归一化、分块的数值时间序列，保留时间混合和通道混合，再接任务线性头；支持数值序列适配，不证明安全任务有效。
- RWKV-CVM：在 RWKV 前加入带恒等跳路的轻量跨变量门控；支持保守注入，论文自身增益较小且不普适。
- 预训练多尺度 RWKV-GCN：先做通道独立掩码预训练，再在微调阶段引入图依赖；支持先隔离伪相关、后注入关系结构。
- FRWKV+：用零初始化、有界信任门把外部周期证据作为校正项；可作为“强基座加保守 RWKV 残差”的机制来源，但其周期预测结果不能外推到安全任务。
- RWKV-TS+：历史长度收益不单调，部分分类任务甚至放弃跨批时间机制；支持先证明历史信号再扩展状态长度。
- PLM-NIDS：把协议行为转为语言建模目标，以预测残差或困惑度检测入侵；支持正常行为预测作为辅助证据，不能替代本课题强基线。

## 初步模型

设当前合法字段和训练区滚动统计构成强基座风险对数几率 `b_t`，RWKV 因果历史状态产生残差 `r_t`，正常转移惊异度和历史质量形成可信门 `g_t`：

\[
s_t=b_t+g_t\,\epsilon\tanh(r_t/\epsilon),\qquad 0\le g_t\le 1.
\]

该式保证单次历史修正绝对值不超过 `epsilon`。若基座两样本对数几率间隔大于 `2epsilon`，有界残差不能反转其排序；这只是一项可验证的安全性质，不证明性能提升。
