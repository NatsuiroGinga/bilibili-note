# 统计附录：机制二路径风险长度桶诊断

## 分析单位与比较问题

- 分析单位：LSPR23 源年、`seed=42` 的同一次冻结运行中的实体。
- 主问题：M1 池化 FPR 是否掩盖按实体路径长度分层后的条件 FPR。
- 辅助问题：4 个 M1 漏检正实体的路径最大分数相对阈值，是否提供“持续次高分”的描述性证据。

## 推断统计阻断

不运行显著性检验、置信区间、效应量或多重比较校正。理由如下：

1. 只有一次源年 `seed=42` 运行，没有独立种子、独立年份或独立实验重复。
2. 五个长度桶是同一实体总体的互斥分层，不是五个独立实验单元。
3. 四个漏检正实体仅为同一运行内的失败子集，不能作为独立重复样本。
4. 当前任务是病灶定位，不比较反射累积或其他新机制，因此不存在有效的候选方法比较族。

上述限制阻断“正式支持”“显著差异”“稳定优于”及任何跨年泛化表述；不阻断把条件风险作为最小 Q0 的待证问题。

## 预防误读

- 池化 M1 FPR 低于 4% 不等于每个长度条件均低于 4%。
- 漏检实体最大比值接近 1 不等于存在持续的近阈值轨迹。
- DR 在多个桶较高不证明反射累积会提高检出，也不构成论文结果。
