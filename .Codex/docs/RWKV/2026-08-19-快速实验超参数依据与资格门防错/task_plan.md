## 决策

1. `10%` 不能继续作为“已冻结前代参数”自动迁移；它在现有台账中属于既有运行／人为诊断设定，改变角色语义后必须重新取得资格。
2. 无标签实体资格门是必要条件但不是充分条件。它能证明角色集合非空、互斥和规模上存在可能性，不能证明确认段有足够良性实体；后者必须在边界封印后、模型推理前用允许读取的段内标签做分母门。
3. 当前每预算 `7` 个候选、族错误率 `0.05` 的口径下，零误报仍需至少 `492/245/122` 个良性确认实体，才能分别确认 `1%/2%/4%` 预算。
4. 实体资格预检必须复用生产实体键和边界语义，且在创建运行身份、资源门、SwanLab、模型加载和预测之前完成。
5. 资格失败只阻断受影响的实验身份；不得阻塞无关实验、并行直接近邻检索或已经通过门禁的工作。
