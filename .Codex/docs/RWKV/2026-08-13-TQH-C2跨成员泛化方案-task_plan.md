# TQH-C2 跨成员泛化方案补全计划

## 目标

形成可直接交给独立主进程实现的自包含方案册与单种子 Q0 实施计划，覆盖研究问题、数据合同、理论机制、强基线、消融、指标、失败门槛、工程边界和制品身份。

## 范围

- 数据固定为 TQH-C2，经官方版本与成员身份审计后选择一个主版本。
- 主任务固定为严格分组的跨成员 C2 检测，困难成员 C 为主要外推对象。
- 随机种子固定为 `42`，不追加多种子稳定性主张。
- 不实现代码、不启动实验；本轮只补全方案册和实验实施计划。
- 不把普通领域对抗、CORAL、组分布鲁棒优化、校准或拒识重新包装为原创机制。

## 已冻结决策

- 任务优先级来自既有 TQH-C2 查全审计：跨成员泛化为第一候选。
- 当前开发诊断仅说明域内与跨成员之间存在明显缺口，不支持任何新方法有效性结论。
- 实验规模只使用 `seed=42`；不得声称跨种子稳定性或统计显著性。
- 主指标必须包含困难成员 C 的恶意召回、宏 F1 与固定良性告警预算指标，不能只报汇总准确率。
- 理论深度和实验工作量须对标朱论文第三章：两个独立机制、完整消融、强基线、困难分面、资源与失败分析。
