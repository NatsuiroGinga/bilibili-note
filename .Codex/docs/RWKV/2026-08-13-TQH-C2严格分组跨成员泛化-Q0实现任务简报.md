# TQH-C2 严格分组跨成员泛化 Q0 实现任务简报

> 状态：实现中  
> 日期：2026-08-13  
> 需求来源：[Q0 实验实施计划](./2026-08-13-TQH-C2严格分组跨成员泛化-Q0实验实施计划.md)

## 1. 目标

实现 TQH-C2 v1.2.0 的两个严格跨成员协议：

- `A+B→C`
- `A+B+D→C`

每个协议固定运行 17 个身份，共 34 个身份；总种子固定为 `42`。实现必须支持从五个受控原始输入直接读取、源侧训练与冻结、一次 C 开发评价、聚合收据、机械裁决和聚合 SwanLab 发布。

3. `thesis/experiments/llm_probe/src/flow_probe/tqhc2_strict_crossmember_q0.py`

不得修改、覆盖、导入或调用历史 `tqh_c2_candidate*.py` 的物化入口、旧 `24/8/8` 分组、旧折缓存或旧结果。

## 3. 数据接口

原始根目录默认为 `raw/datasets/TQH-C2-v1.2.0/`。受控输入为：

- `TQH-C2_features_v110.zip`
- `TQH-C2_labels_v110.zip`
- `TQH-C2_features_D.zip`
- `TQH-C2_labels_D.zip`
- `README_v120.md`

实现必须从验收收据与配置核对字节数、SHA-256、ZIP 成员白名单和 CRC。只读取逐捕获 Parquet，禁止叠加成员聚合 Parquet。标签按 `(capture_id, uid)` 一对一连接，`y=1` 当且仅当 `label_raw == "malicious_c2"`；`malicious_recon` 必须作为 0 类单列评价。

模型输入严格限定七字段：

`duration, orig_bytes, resp_bytes, orig_pkts, resp_pkts, orig_ip_bytes, resp_ip_bytes`

成员、捕获、间隔、抖动、时间戳、地址、端口、协议、配置字段、连接状态、标识符及标签派生字段不得进入模型。

## 4. 新划分

构造 12 个公开条件键 `interval_s|jitter_pct`，计算：

`SHA256("tqh-c2-v1.2.0|seed=42|source-condition-split-v1|" + condition_key)`。

按摘要字典序排序：

- 前 8 个条件在 A/B/D 中统一进入 `source_train`；
- 后 4 个条件在 A/B/D 中统一进入 `source_calibration`；
- C 的 12 个捕获只在冻结后进入 `target_development_once`；
- 前 8 个条件按排序序号 `mod 4` 形成源训练四折。

运行收据只能保存算法版本、聚合计数和角色串摘要，禁止保存条件角色明细或逐样本清单。

## 5. 身份矩阵

每协议固定 17 个身份：

1. `T0`：XGBoost 强树锚。
2. `B`：容量匹配残差基座。
3. `M1`：1% 锚带残差排序。
4. `M2`：留一成员经验准入与回退。
5. `M1+M2`：完整方法。
6. `RND`：等准入数量的确定性随机门。
7. `SHUF`：捕获级打乱成员标签。
8. `OPEN`：完整残差始终启用。
9. HistGradientBoosting。
10. 线性部分曲线下面积排序支持向量机。若实现并非 Narasimhan–Agarwal 原始结构支持向量机，展示名、配置和收据必须明确写“成对排名近似”，不得冒充原方法。
11. 源成员 Deep CORAL。
12. 源成员 DANN。
13. GroupDRO。
14. V-REx。
15. 损失条件风险价值。
16. 普通深度集成。
17. SelectiveNet。

普通无监督域适应不得读取 C。CORAL/DANN 中所谓目标批次只能是另一源成员，并通过硬断言拒绝 C。

## 6. 候选机制

强树锚：

`s0 = logit(clip(p_xgb, 1e-6, 1-1e-6))`

残差网络固定为 `7→32→16→1`，ReLU；输入先 `log1p`，再使用源训练中位数和四分位距缩放。残差：

`delta = log(10) * tanh(r / log(10))`

M1 固定 `beta=0.01`、`lambda_rank=1`、`lambda_delta=1e-3`、`temperature=1`，硬负类集合只能由冻结强树锚定义。成对训练不得物化笛卡尔积，每批最多 4096 对。

M2 固定 `lambda_min=-1/K`、`U_ext<=0.005`、`max_delta_e<=0.005`、分歧阈值为源校准 75% 分位数。门关闭时输出必须逐元素精确等于强树锚，不得拒绝样本。

## 7. 隔离与制品

- `training_freeze_receipt.json` 生成前 `C_read_count` 必须为 0。
- C 只能在一个评价进程中逐捕获读取一次，并对全部冻结身份评分。
- 禁止写出 `.parquet`、`.npy`、`.npz`、逐行 CSV、预测 JSONL、逐样本概率、标签、矩阵、折成员表、错误清单、准入位或回退位。
- 允许模型、预处理器、聚合 JSON、状态、日志和资源收据。
- SwanLab 只上传聚合标量与资源曲线。
- 运行根固定为 `runs/candidates/tqhc2-strict-crossmember-low-fpr-residual-admission-q0-seed42-v1`。
- 状态固定包含 `screening_only=true`、`formal_paper_evidence=false`、`formal_final_role_created=false`、`final_accessed=false`。

## 8. 命令接口

总控模块至少提供：

- `audit`
- `train-freeze`
- `evaluate-target`
- `run`
- `swanlab-publish`
- `audit-receipt`

`run` 必须按 `audit → train-freeze → evaluate-target → decision` 顺序执行；只有完全相同冻结哈希的纯运行故障才允许恢复。

## 9. 启动器

启动器必须：

- 使用项目 `uv run --no-sync`，禁止系统 Python。
- 只阻断同名模块、同名运行和同名持久会话，允许无关 GPU 进程。
- 使用锁与独立运行目录，写出结构化状态和退出码。
- 不运行独立测试、夹具或冒烟。
- 不使用内存门禁，不调用 `black` 或其他格式化器。
- 默认串行；仅配置明确且资源允许时最多两个身份并发。
