## 核心问题与裁决

1. 既有 `L=16/32/64/128` 三种子 E5 是否足以回答当前问题？否。它同时改变计算切片、上下文、更新次数和补零率，且不是固定 R2、胜出 K、统一 BF16 的 RWKV 状态实验，只能作历史不确定性证据。
2. 当前是否立即补四档训练型长度消融？否。最小 Q0 固定计算切片 `L_c=128`，先隔离跨片段状态继承；只有该方向通过且正文要主张切片稳健性时，才补 `L_c=64` 的成对 `reset/carry`。
3. 最少训练多少单元？首阶段必须运行 `reset-128` 与 `ordered-carry-128` 两个单元；仅在二者通过方向门后追加 `shuffled-carry-128` 一个归因单元。注册上限三臂，实际训练为两臂或三臂。
4. 如何避免 LSPR24 选点？全部选轮次、停止和归因只读取 LSPR23 固定实体不相交开发划分；本轮 `target_year_paths_enumerated=0` 且 `target_year_arrays_read=0`。

- 历史 E5 的 12 个训练单元和目标年读数不计入新实验，也不用于冻结 `L_c`、R/K、阈值或停止门。
- 同容量逐流无状态臂不进入最小集合：`reset-128` 与 `ordered-carry-128` 已保持参数、递归算子和训练计算一致，二者只改变边界状态；逐流清零回答的是“是否需要任何片段内递归”，不是本轮跨片段问题。
- 顺序破坏臂只作源年离线归因负对照，不是因果部署候选；首对照无正向信号时不运行。
- 当前 BF16 实施仅为静态就绪，绝对 GPU 小时、真实显存和吞吐没有制品，因此资源只按单臂实测量的倍数与状态内存下界登记。
