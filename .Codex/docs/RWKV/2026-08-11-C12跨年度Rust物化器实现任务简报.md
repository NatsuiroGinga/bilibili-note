> **执行方式**：使用 `superpowers:subagent-driven-development` 分派唯一实现代理；实现代理必须应用 `daily-coding` 与 `rust-skills`。本任务禁止人工夹具、单元测试、集成测试、独立复审和远程运行。

## 冻结接口

命令入口：

```bash
cargo run --release --locked \
  --manifest-path tools/lspr24_g0/Cargo.toml \
  --bin lspr_crossyear_materialize -- \
  --config configs/lspr-crossyear-c12-seed42-v1.json
```

生产入口必须满足：

1. 从 LSPR23 ZIP 内 `ls23pr_v1.csv` 流式读取，不在磁盘全量解压；从 LSPR24 Parquet 按字段名读取，不依赖列位置。
2. 只投影冻结合同中的 77 个共同字段，并将标签、原始 IP、端口、绝对时间、年度、角色、路径、行号和 `2-IP` 键隔离在模型输入之外。
3. 以 `mTimestampLast` 作为完整流可用时刻；按年度活动秒秩冻结 LSPR23 `80%/20%` 和 LSPR24 `10%/70%/20%` 角色边界。LSPR24 最后 20% 不得写入开发主产品、统计、计数、成员清单或哈希。
4. 使用密钥化规范无向 `2-IP` 侧车键；每个年度与角色内按 `(pair_key, available_ns, start_ns, source_row_index)` 稳定排序，切成最长 128、非重叠、尾块保留的序列。
5. 只在 LSPR23 `source-train` 拟合中位数、四分位距和 `Protocol` 词表；非法或非有限值转缺失并保存显式掩码。
6. 一次物化开发主产品、标签侧车、分组侧车、字段清单、样本清单、序列清单和四角色共同缓存；不得为四个模型变体重复扫描原始数据。
7. 复用 `canonical.rs`、`external_sort.rs` 和 `output.rs` 的规范编码、稳定外排与 `.partial` 原子发布模式；不得改变现有 G0 5 秒端点宽表语义。
8. 固定 256 个稳定哈希桶、每批最多 65,536 行、每序列最多 128 流；配置和启动日志必须记录每类跨批状态上界、峰值内存估算、临时目录上限 60 GiB、总输入/输出估算和磁盘低水位。
9. 超过 1 分钟的阶段记录开始、结束、跳过、处理量、吞吐、累计耗时和预计剩余时间；日志不得含凭据、原始 IP、载荷或标签泄漏字段。
10. 输出至少包含 `dataset-manifest.json`、`experiment-manifest.json`、`field-manifest.json`、`sample-manifest.parquet`、`sequence-manifest.parquet`、角色分片、标签/分组侧车、输入与语义哈希、隔离计数和 `final_accessed=false` 收据。精确路径应由配置给出并保持项目根内绝对路径语义。

## 实现边界

- 不访问 LSPR24 最终 20%，不解析 `attack_narratives.json`。
- 不使用人工夹具，不新增 `tests/` 文件，不运行 `pytest`、`cargo test` 或全仓检查。
- 不访问服务器，不同步文件，不启动物化或 GPU。
- 不硬编码凭据、服务器地址或令牌。
- 不执行 Git 暂存、提交、推送、回滚或格式化无关文件。
- 你不是独自在仓库工作；不得覆盖或回滚其他代理和用户改动。

2. 对新入口执行一次 `--help`，确认配置参数和中文阶段日志入口可达。
3. 若因本机依赖或资源阻塞，保留完整错误与单一根因，不通过新增夹具规避。
4. 实施报告必须列出修改文件、接口、实际命令与退出码、未运行项、已知风险和服务器真实首批运行的下一命令形态。
