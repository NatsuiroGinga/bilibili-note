# LSPR 直接使用论文查全审计计划

## 目标

截至 2026-08-11，对公开可检索的 LSPR23、LSPR24、LSPR25 直接使用论文进行可复核查全审计，严格区分直接实验使用、仅引用介绍和同名误命中，并给出不能宣称绝对穷尽的覆盖边界与停止条件。

## 六阶段流程

- [x] 阶段 1：恢复 RWKV 路线，读取既有全文笔记、数据集索引、旧综述与 Zotero 工作流规范
- [x] 阶段 2：冻结检索式、别名、纳入排除标准、来源清单与去重键
- [x] 阶段 3：执行通用网页、多学术索引、插件、Zenodo／DOI／作者链／引用链检索并逐轮落盘
- [x] 阶段 4：对候选全文逐篇核验 A／B／C 类别；A 类提取数据版本、样本范围、划分、任务、模型、指标与结果
- [x] 阶段 5：对新增有用论文完成合法全文入库、结构化笔记、索引更新和 Zotero 导入；无法获取全文者登记阻塞
- [x] 阶段 6：合并去重、执行反向核查和停止条件，生成最终审计报告并验证文件、链接、YAML 与 Zotero 状态

## 核心问题

1. 截至检索日，公开渠道能发现多少篇直接使用 LSPR23／24／25 数据做实验或实质统计的研究？
2. 既有仓库覆盖是否遗漏 A 类论文；B 类引用和 C 类误命中分别有哪些代表项？
3. 每篇 A 类论文是否使用官方完整表、是否抽样，怎样划分，任务、模型、指标和结果是什么？
4. 在什么可复核条件下可以停止扩展检索，同时避免声称绝对穷尽？

## 决策

- A 类：实际读取 LSPR23／24／25 数据并完成训练、验证、测试、统计或数据处理实验。
- B 类：只引用、介绍、列举或复述 LSPR；数据集发布论文若仅作描述性发布，单列为 B1，不冒充下游实验。
- C 类：缩写同名、其他领域、搜索噪声、聚合页或重复版本。
- 以 DOI、正式题名、作者、年度和稳定仓储标识联合去重；预印本与正式版合并为一个研究工作并保留版本关系。
- 插件和搜索片段只用于候选发现；A 类判定与方法数字必须回到全文、正式题录、作者页或官方仓储。
- 不访问本课题最终测试，不解析攻击叙事，不修改实验代码，不阻塞正在进行的数据物化。
