## 0. 一句话验收

**逐流 AP 复现落在 `0.2416 ± 0.05`（协议对齐成立）且实体级在 ≤`4%` 实体 FPR 下召回 ≥`0.50` → 方向成立；
实体级召回 < `0.20` → 方向作废。**

## 2. 实现任务分解

一个实现进程独占，禁止并行修改。

### 任务 1：实体键与聚合契约

文件：`src/flow_probe/crossyear_entity_eval_contract.py`

- 冻结实体键定义：首选**源 IP**；`2-IP` 无向密钥化分组作为预注册备选。两者不得混入同一比较表。
- 实体键**只用于分组，不入模**：不得编码、计数、分桶或作为特征。
- 聚合函数 `S_e^(n) = 第 n 大的 {s_f : f ∈ e}`，`n ∈ {1, 5, 10, 100}`，取值集合在看到目标年度结果前冻结。
- 实体级标签 `y_e`：实体内存在任一恶意流即为正；标签只用于离线评价，**不得进入任何输入或阈值选择**。
- 断言：实体键在 LSPR23 与 LSPR24 两年度可一致构造；不可一致即停止并交数据合同任务。

### 任务 2：数据加载与时间无关特征筛选

文件：`src/flow_probe/crossyear_entity_eval_data.py`

- 复用既有跨年度有界缓存，**不重新物化**。
- 强制 `np.isin(label, (0, 1))` 过滤（`label=-1` 占 `60.4075%`）。
- 内存：按 row group 分批读取，禁止整表 Arrow 与 numpy 副本同时驻留（8-12 事故根因）。
- 实现 Gehri 2023 的时间无关特征筛选：RFE + 单特征交叉验证，**只在 LSPR23 上做**，产出冻结特征清单并落盘。
- 记录被剔除的时间依赖特征清单（用于与 Leoste 2025 的 IAT 观察对照）。

### 任务 3：运行与评价

文件：`src/flow_probe/crossyear_entity_eval_run.py`

七个变体，**顺序执行**（见方案册 §5）：`B0`、`B1`、`B2`、`M1`、`M1+B1`、`M3-同期`、`M3-冻结`。

- `B0` 固定复现 Dijk 2026 配置：`lr=0.05`、`max_depth=8`、`800` 树。
- **协议对齐门在 `B0` 之后立即判定**；不通过即写阻断收据并停止，不跑后续变体。
- 逐流分数与逐实体分数**全部封存**后，才允许连接目标开发标签。
- 输出三条曲线：(a) 逐流 AP，(b) 实体级 DR @ 实体 FPR 扫描，(c) 每小时告警预算下的实体召回与检出时延。
- 统计：以**实体为簇**的配对自助 1000 次，报 `Δ` 的 95% 区间；三个种子 `42/43/44`。

### 任务 4：启动器

文件：`scripts/remote_launchers/run_crossyear_entity_eval_q0_v1.sh`

- 先过 `tools/memory_admission_gate.sh`，再 `screen -dmS` 启动。
- 阶段日志含 cgroup 可用量与 `/proc/self/status` 的 `VmRSS`；**禁用 `free`/`psutil`/`/proc/meminfo`**。
- 限频业务心跳含已处理量、总量、吞吐、累计耗时、预计剩余。
- 失败保留状态与退出码，不覆写既有输出。

## 6. 已知风险与强制披露

| 风险 | 实测依据 | 强制动作 |
| --- | --- | --- |
| 实体簇有效样本量小 | 本课题 E1：端点簇自助半宽 `0.2346`，事件簇 `0.0253`，含事件端点仅 `113` | 论文必须显式披露，禁止用流级样本数虚增效力 |
| 阈值冻结迁移失效 | 本课题 E5：前半标定应用到后半，fp 超标 `309` 倍 | M3 必须同时报同期标定与冻结迁移两种口径 |
| 预算分配增益是假的 | 本课题 E5：增益 `95%` 来自阈值标定，分配只贡献 `5%` | 理论命题只作刻画，不得写成"分配带来提升" |
| Känzig §5.A 无误报侧 | 全文核验：只报 `10/12` 检出 | 不得把它写成完整协议或可比基线 |
| Gehri 用私有数据 | LS21B 非公开 | 只作机制先例，不得写成 LSPR23/24 的可比基线数字 |

## 7. 停止条件

1. 协议对齐门不通过 → 停止，先做协议差异审计，不进入 M1/M2/M3。
2. 实体级召回 < `0.20` → 方向作废，写入消融表作负结果，**不追加机制挽救**。
3. 实体键两年度不可一致构造 → 停止，交数据合同任务。
4. 任一运行访问最终封存区 → 运行无效，隔离全部受影响制品。
5. 同一缺陷连续三次修复无进展 → 停止补丁，与用户讨论架构。
