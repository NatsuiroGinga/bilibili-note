## 二、PLR 的挂载面（已回原文核验）

原件 `raw/papers/methodology/2022-Gorishniy-On-Embeddings-for-Numerical-Features.pdf`
（arXiv:2203.05556v4，NeurIPS 2022，`sha256` 前 16 位 `22b97677fec340fc`），
第 3 节，经 `mineru-open-api extract` 保留公式后核对。

分段线性编码（式 1，物理页 3）：

```
PLE(x) = [e_1, ..., e_T] ∈ R^T
e_t = 0,                              x < b_{t-1} 且 t > 1
      1,                              x ≥ b_t 且 t < T
      (x − b_{t-1}) / (b_t − b_{t-1}), 其余
```

箱边界两种构造（3.2.1／3.2.2）：分位数 `b_t = Q_{t/T}({x_i^{j(num)}}_{j∈J_train})`；
目标感知则按标签递归贪心切分，等价于只用该特征与标签生长一棵决策树，取叶区间为箱。

**对注意力骨干的关键接口**（3.2 节「A note on attention-based models」）：

```
f_i(x) = v_0 + Σ_{t=1}^{T} e_t · v_t = Linear(PLE(x))
```

即每个箱 `B_t` 分配一个可训练嵌入 `v_t ∈ R^d`，以 `e_t` 为权重聚合，加偏置 `v_0`。

周期激活（式 2）：`Periodic(x) = concat[sin(v), cos(v)]`，
`v = [2πc_1 x, ..., 2πc_k x]`，`c_i` 可训练、由 `N(0, σ)` 初始化，`σ` 与 `k` 为超参数。
论文命名法：`PLR = ReLU ∘ Linear ∘ Periodic`，`Q-LR = ReLU ∘ Linear ∘ PLE_quantile`（表 2）。

**一条对本课题重要的原文性质**：论文明确 PLE「可视为预处理策略，表示计算一次后
在主优化过程中替代原始标量值使用」。箱边界在训练中不变。

## 三、M-E 的挂载点（设计推论，待裁决）

条件化有三个可能位置，逐一评估：

| 位置 | 做法 | 评估 |
| --- | --- | --- |
| 箱边界 `b_t` | 让边界随实体状态变化 | **不推荐**。破坏 PLE 的预处理性质，且边界漂移会使编码语义在实体间不可比 |
| **箱嵌入 `v_t`** | `v_t → v_t + g_θ(s_e)` | **推荐**。不动编码几何，只调制嵌入；`g_θ` 是清晰的机制专属参数 |
| 周期频率 `c_i` | 让频率随实体状态变化 | 备选。数值敏感性高（`σ` 已是重要超参数），且频率漂移的可解释性弱 |

推荐形式：

```
f_i(x, s_e) = v_0 + Σ_{t=1}^{T} e_t · (v_t + g_θ(s_e))
```

`s_e` 为实体 `e` 的严格过去状态，`g_θ` 为 M-E 专属参数。

## 三点五、改造而非照搬（本章创新性的成立条件）

朱焱雷第三章的两个机制都不是原组件的直接移植：动态难度调度不是照搬课程学习，
而是针对对抗训练重新定义难度；二阶反应梯度优化不是照搬二阶方法，
而是针对鲁棒性重新定义梯度反应。**原组件解决通用问题，改造后解决本任务特有问题。**

直接把 PLR 接进 FT 只是换一个 tokenizer，不构成第三章的机制创新。
M-E 要成立，改造必须落在本任务特有的结构上。

### 本任务特有的问题

PLE 的箱边界由**全局训练区分位数**确定（`b_t = Q_{t/T}(...)`，见第二节），
与实体无关。但在跨年度实体级检测中，**同一数值在不同实体历史下语义不同**：
同样的端口号或字节数，出现在一个已有上百条流的实体上，
与出现在一个首次现身的实体上，含义并不相同。全局分箱抹掉了这层差异。

### 改造的实质

不是给箱嵌入加一个与输入无关的偏置（那只是条件归一化的常见做法），
而是把编码从「值落在全局哪个箱」升级为「**值落在全局哪个箱，且相对该实体历史处于什么位置**」：

```
f_i(x, s_e) = v_0 + Σ_t e_t · v_t          ← 全局位置通道，保持跨实体可比
            + Σ_t δ_t(x, s_e) · u_t        ← 实体相对位移通道，M-E 专属参数
```

其中 `δ` 刻画当前值相对该实体严格过去在该特征上的分布位置
（例如历史箱占用的偏移、或相对历史分位的位移），`u_t` 为该通道的箱嵌入。

**为什么这是改造而非拼接**：全局通道保证跨实体、跨年度的可比性
（这是 PLE 原有的优点，不能丢）；相对通道引入实体历史，
而它编码的是**位移**不是绝对状态——位移对跨年度的分布整体平移天然不敏感，
这正是 CEM 用绝对状态失败的地方。两个通道的分工可由消融独立验证。

### BER 侧的对应问题

C01 的机制来源 Zhu 2022 ICML 使用「CE 预训练 → 重置分类头 → pAUC 微调」两阶段，
而 C01 是**联合训练**。这个差异目前登记在开放问题里，但它本身就是一处改造：
两阶段假设可以先学好表示再优化排序，联合训练则让排序目标从一开始就参与表示学习。
**正文必须把它写成有意的改造并给出理由，而不是留作未说明的偏离**，
否则审阅时会被判为「未复现原方法」。本地笔记已登记「必须将本文作为原组件对照」。

### 判定标准

每个机制在正文里都要能回答三问，缺一不可：

1. 原组件解决什么通用问题，本任务的哪个特有结构使它不能直接用；
2. 改造改了什么，改动如何针对该特有结构；
3. 改造带来的增量能否被独立消融验证——即关掉改造、保留原组件时性能应下降。

第三问要求消融设计中**存在「原组件不改造」这一格**，
否则无法区分「机制有效」与「原组件本来就有效」。

## 四、来自 CEM 尸检的硬约束

依据[CEM 失败根因诊断](2026-08-31-CEM失败根因诊断.md)：

1. **`s_e` 绝不能是「模型自身表示的摘要」。** CEM 的记忆槽存
   `_segment_summary_from_injected` 的输出，构成自指结构；源年训练的交叉注意力
   在源年表示分布上学会检索，目标年输入分布改变后摘要随之改变而权重固定。
   M-E 的挂载点比 CEM 更靠前（tokenizer 对 `encode` 之后），污染面更大。
2. **`s_e` 应取原始可观测量**：当前流到达前的实体流计数、距上一次实体事件的时间、
   由合法 Raw83 字段递推的指数衰减计数／和／均值。这些是数据侧统计量，
   跨年语义稳定。机制一的文献审计早已列出该选项，实现时选了模型表示摘要。
3. **避免固定容量结构。** 目标年每实体跨段恢复次数是源年的 `4.95` 倍
   （`3.263` 对 `0.659`），`R=8` 的环形队列在两种密度下装的内容语义不同。
   `s_e` 若用指数衰减统计量则与窗口容量无关，天然回避该问题。
4. **`s_e` 本身是标量，可走同一套 PLE 编码**，与主特征形式统一，不引入第二套表示体系。

## 四点五、状态载体候选的源年实测（2026-08-31）

第四节确立了「`s_e` 必须用原始可观测量」，但用哪些量此前无数据支撑。本节补上。

工具 `tools/ch3_ft_entity_state_carrier_probe.py`（只读，全向量化，无模型、无前向），
制品 `runs/diagnostics/ch3-ft-entity-state-carrier-probe-v1/probe.json`。
口径：`E23`／`T23` 为逐序列（`271815`），`y23` 为逐流（`16353511`），
经 `I23`／`M23` 把标签聚合到序列级（序列为正当且仅当其有效流中存在正流）。
聚合后有效流 `16353511`，与数据审计一致；正序列 `13025`，正例率 `0.047919`。
严格过去：每个序列的状态只由该实体在它之前的序列计算。`target_reads = 0`。

| 候选量 | 区分力 AUC | 可用比例 | 前半段均值 | 后半段均值 | 中位数 | p99 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `prior_flow_count` | `0.8033483909578008` | `1.0000` | `402.74` | `1519.58` | `0.0` | `16618.86` |
| `gap_since_last_event` | `0.24543449195767822` | `0.4457` | `7.70e8` | `1.09e9` | `3.10e7` | `4.25e10` |

`gap` 的 AUC 低于 `0.5` 是**反向**区分（间隔越小越可能为正），等价强度 `0.7546`。

### 三条设计约束（实测直接推出）

1. **绝对流数不可直接作状态载体。** `prior_flow_count` 区分力强（`0.80`），
   但前后半段均值相差 `3.8` 倍——源年内部就在单调漂移，因为时间越往后实体积累越多。
   跨年后该偏移只会继续。直接喂绝对值等于以**量纲漂移**的形式重蹈 CEM 覆辙。
   必须做对数或分位数归一化，或改用「当前值相对该实体历史分布的位移」。
   这与第三点五节「编码位移而非绝对状态」的改造方向一致，并为其提供了实测依据。
2. **必须为「无历史」设计明确的中性行为。** `prior_flow_count` 中位数为 `0`，
   即超过一半的序列是其实体的首个序列，没有前序历史。
   注意这与 CEM 诊断中的 `no_history_flow_ratio = 0.0109` 不矛盾：
   那是**流**级比例，本节是**序列**级，差异源于恶意实体流多而序列少。
   若不设计中性行为，M-E 会在一半样本上注入无意义信号。
3. **`gap_since_last_event` 比流数稳定。** 前后半段均值只差 `1.4` 倍，
   远小于流数的 `3.8` 倍，且反向区分力可观（`0.7546`）。
   代价是只在 `44.6%` 的序列上可用（首序列无间隔）。
   它更适合作跨年稳定的状态分量，但需与约束 2 的中性行为配套。

### 尚未测的量

指数衰减计数／和／均值本轮未计算：它是组内递推，且 `exp(rate · t)` 在秒级时间戳上溢出，
需分组重标定才能向量化。若后续要纳入 `s_e`，须先补该诊断。

## 五、联动设计与梯度路径

用户 2026-08-31 给出的联动定义：联动必须是可验证的梯度与功能互补，
不能只是把两个模块串起来。落到上述挂载点：

| 格 | `z1`（M-E） | `z2`（BER） | 梯度路径 |
| --- | ---: | ---: | --- |
| C00 | 0 | 0 | 逐流主损失 → 骨干（标准 tokenizer，无 `g_θ`） |
| C10 | 1 | 0 | 逐流主损失 → 骨干 → tokenizer → **`g_θ`** |
| C01 | 0 | 1 | 逐流主损失 ＋ 排序损失 → 骨干（标准 tokenizer，无 `g_θ`） |
| C11 | 1 | 1 | 逐流主损失 ＋ **排序损失 → 骨干 → tokenizer → `g_θ`** |

**联动的实质**：BER 定义「什么样的实体应排进低误报预算」，M-E 提供「感知实体历史状态」
的表示能力。C11 中排序损失的梯度穿过骨干落到 `g_θ`，等于让实体级低误报目标
直接塑造状态编码。这不是模块串联，是一个训练目标重写另一个机制的表示。
若出现超可加交互，机制解释即在此处。

**可预注册的运行断言**（用户已表示将写入第二机制裁决与实验收据）：

- `g_θ` 的梯度范数在 C11 中来自排序损失的部分必须非零；
- 在 C10 中 `g_θ` 只接收逐流主损失梯度；
- 在 C01 与 C00 中 `g_θ` 不存在。

四格的独立开关因此是结构性的，不是配置开关。

## 六、另一条必须监控的断言（来自 CEM 失败）

依据[CEM 失败根因诊断](2026-08-31-CEM失败根因诊断.md)第二点五节：
CEM 在源年 20 轮中逐流 AP **无一轮高于 C00**，但因源年逐流饱和于 `0.999`
而差值仅千分之几，被完全掩盖；跨年后放大为 `−0.1318` 并主导结果。

**建议写入第二机制实验合同**：机制臂在源年训练中，
逐流 AP 相对同预算基线的差值不得持续为负；连续多轮为负即触发复核，
即使实体 AP 上升。本次失败的全部信号在源年可得，当时未监控该差值。

同时[目标年逐流判别方向翻转](2026-08-31-目标年逐流判别方向翻转.md)确立：
裸 FT 目标年逐流 ROC-AUC 为 `0.737832`，两个机制臂分别为 `0.469308` 与 `0.421902`，
**方向翻转是机制引入的，不是数据漂移**。第二机制须一并监控该量。

## 七、BER 侧的并行改进（裁决已更新，见下）

完整数学分析见[CVaR 预算失配数学分析](2026-08-31-CVaR预算失配数学分析/分析报告.md)（提交 `98e793a`）。
本节只记裁决与被推翻的判断。

### 7.1 采纳的修法：跨步水库分位数估计 ＋ detach

理论依据为 Rockafellar–Uryasev 变分形式：内层 `min` 恰在真分位数取得
（Zhu 2022 定理 1，原件物理页 4 已直接核验）。把 ξ 从子梯度 SGD 状态改为
跨步水库分位数估计并 `detach`，**钉住分位数不改变目标，只消除追踪滞后**。

选它还因为它是唯一不触碰冻结证据链的部件——配置的 `xi_learning_rate_evidence`
本就写明该值是借用的、非源年裁决值，预留了调整余地。

可证伪验收判据：修复后各档激活率的轮均值应回到 `β` 邻域。

**但不得照搬 `_quantile_init_xi`**：该函数逐步取批内第 `⌈K_eff⌉` 大值，
在 `K_eff < 1` 时退化为 ξ ＝ 批最大值 ⇒ 所有 hinge 为 0 ⇒ 该档对 θ 的梯度**恒为零**，
比现状更糟。其 docstring 也自述仅限诊断用途。

备选加强 c2：若低档仍不可用，引入难例或重要性采样。这是问题的正解——
`β · n_neg < 1` 时，均匀抽样估计 `(1−β)` 分位数需要 `n ≳ 1/β` 个样本，
这是估计理论边界，改折算公式绕不过去。

### 7.2 已否决的两条修法

**(a) 增大 `n_neg`——被实测反证。** 此前（含主代理与 C01 榨取代理）认为
`K_eff ≥ 1` 是根本修法，但 `K_eff = 2.56 / 5.12` 的 4%／8% 档**同样失配**：
第 20 轮激活率为 `3.1%` / `2.3%`，而驻点应为 `4%` / `8%`，累计约 `3.4σ` 低。
**`K_eff ≥ 1` 不是充分预防条件。** 且 `n_neg → 1003` 意味着约 `15.7` 倍计算量，
而 66 实体时已实测占用 `30.97 GiB`。

**(b) 改预算网格——否决。** 删除低档等于删掉机制的科学主张（六档标称 FPR 是
机制的设计对象），且同样不治 ξ 的追踪滞后。

### 7.4 新登记的源码缺陷

`ch3_ft_entity_ranking_loss.py` 第 138 行 docstring 要求 `K ≥ 1`，
但第 165 行的 `require` 只检查 `K > 0`——**`K_eff < 1` 得以静默进入训练**，
这是失配长期不可见的闸口。

另核验：本实现是 SOPA（Zhu 2022 算法 1，原件物理页 5）的逐字面多预算版本。
失效来自三处运行区间偏离，而非实现错误：
批内 `β|B₋| < 1`（论文明文假设为整数）、联合训练（论文是两阶段，物理页 8）、
