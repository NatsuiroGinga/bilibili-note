## 一、代码与公式：`α` 不可微（**实测否决**）

### 1.1 根因定位（读实现）

`tail_aggregate`，`thesis/experiments/llm_probe/tools/ch3_ft_entity_ranking_loss.py:245`：

```python
k_per_entity = torch.ceil(alpha * m_per_entity).clamp(min=1.0)
```

`torch.ceil` 的反向导数在 PyTorch 中定义为**恒零**（不是未定义、不是报错）。
`k_per_entity` 此后只有两条去向，两条都拿不到 `α` 的梯度：

1. `take = (rank_in_group < k_per_entity[sorted_entity]) & sorted_valid`（行 250）
   ——比较算子输出布尔张量，`torch.where` 的**条件位不参与反传**；
2. `entity_scores = totals / k_per_entity`（行 259）
   ——这条**是**可微路径，`∂(totals/k)/∂k = −totals/k²` 非零，
   但再往上游经 `ceil` 即被乘零。

**故 `α.grad` 不是 `None`（计算图确实连通），而是精确的 `0.0`。**
这比 `None` 更隐蔽：不会报错、不会告警，优化器照常 `step()`，`α` 纹丝不动。

### 1.2 实测收据（`alpha_grad_probe.py`，直接调用生产函数）

合成袋大小取被审文档 §五之一 的实测分位点 `m = [2, 9, 511]`，`α = 0.5`：

| 观测量 | 实测值 |
| --- | --- |
| `k_e = ceil(0.5·m_e)` | `[1, 5, 256]` |
| `entity_scores.grad_fn` | `<DivBackward0>`（图连通） |
| **`α.grad`** | **`0.0`**（`is None` 为 `False`） |
| logit 侧梯度非零数 | `262 / 522`（**反传本身通了，不是图断了**） |

四条独立佐证，方向一致：

| # | 检验 | 结果 |
| --- | --- | --- |
| 1 | `α` 反传 | `α.grad = 0.0` |
| 2 | `S_e(α)` 在 `(0,1]` 细扫 1000 点 | 取值只变 `515` 次；**阶梯函数**，且台阶全部来自 `m=511` 那一个袋 |
| 3 | 中心差分 `dΣS/dα`，`eps=1e-4` | `α=0.10/0.30/0.70` 处**精确为 `0`**（`α=0.50` 处 `eps=1e-4` 跨到台阶边界，读数 `−66.3` 是跳变不是导数） |
| 4 | **Adam `lr=1e-2` 跑 200 步**（MSE 目标，活动率恒 100%） | `α: 0.500000 → 0.500000`，**位移 `0.000000e+00`** |

**检验 4 是判决性的**：给 `α` 一个真实优化器和一个恒有梯度的目标，跑满 200 步，
`α` 一步都没动。「`α` 由反传更新」（§2.1 原文）在当前公式下**不成立**。

### 1.3 裁断

- **§2.1「本框架据此把 `α` 从冻结常量改为可学参数……经 `S_e(α)` 参与前向、由反传更新」——作废。**
  当前公式下 `α` 无论挂在哪个损失后面都收不到梯度。
- 连带作废：**§2.3 的「下界论证（构造性）」**。该论证自己声明「依赖优化能找到该邻域」，
  而实测优化器对 `α` 的位移恒为零，**永远停在初值**，不存在「找到」的可能。

## 二、§2.3「互为前提」：因果链经实测为假

### 2.1 文档主张与它的可证伪推论

§2.3 第一条原文：

> **软化是 `α` 可学的前提。**……实测 `c_scaling_median = 0` 意味着过半的步排序梯度为零
> ——在硬计数下 `α` 有一半时间收不到任何梯度，学不动。**软化使活动集不再恒空，`α` 才有梯度可学。**

可证伪推论：若成立，则在**活动集 100% 非空**的排序损失下，`α.grad` 应非零。

### 2.2 实测（`alpha_grad_vs_softening.py`，调用生产 `cvar_pauc_loss`）

排序批照冻结配置 `n_pos=2 / n_neg=64`，六档预算，`K_eff = K·n_neg/N⁻`。
用 `ξ` 的取值三档调活动率：

| 情形 | 活动集 | `α.grad` | `ξ.grad` 非零 | `logit.grad` 非零 |
| --- | --- | ---: | ---: | ---: |
| A：`ξ=1e4` | 恒空（对应实测 `c_scaling_median=0`） | **`0.0`** | `12/12` | `0/594` |
| B：`ξ=0` | 部分活动（接近实测 C01 工况） | **`0.0`** | `12/12` | `330/594` |
| C：`ξ=−1e4` | **100% 非空**（文档设想的软化后工况） | **`0.0`** | `12/12` | `330/594` |

**情形 C 是判决性的**：活动集全满、排序梯度大量流动（`logit.grad` 330/594 非零、
`ξ.grad` 12/12 非零），`α.grad` 仍然精确为零。

### 2.3 裁断

- **§2.3 第一条的因果链错误。** `α` 学不动的症结是 `ceil`（聚合算子内部），
  **不是**活动集为空（排序损失外部）。软化 BER 对 `α` 的可微性**零作用**。
  这不是「证据不足」，是**方向性错误的归因**。
- **§2.3 第二条（「可学 `α` 是软化的受益者」）是空洞的。**`【推论】`
  该条说的是「改变损失 ⟹ 最优超参数随之改变 ⟹ 需要可学的超参数跟随」。
  这对**任意**（超参数，损失改动）配对都成立，同样可以论证「可学权重衰减是软化的受益者」。
  它没有建立这两个机制之间的**特异**依赖，不足以支撑「互为前提、缺一不可」。
- 故 **§2.3 两条支柱一条为假、一条空洞，「联合而非并列」的论证整体垮掉。**

### 2.4 一处附带的四格自洽问题（`【推论】`，据 `第三章联合算法.md` 伪代码）

按 `thesis/methods/第三章联合算法.md` 伪代码第 16–18 行，**`z2=0` 时函数直接返回，
C10 根本没有阶段二（排序批）**。若照 §2.3 第一条的说法「`α` 由排序损失的梯度更新」，
则 **C10（`z1'=1, z2=0`）里的 `α` 永远无法被学习**——同一个「可学 `α`」机制在
C10 与 C11 两格里是**两种不同的东西**（固定 vs 可学），2×2 消融的可比性随之失效。
文档未讨论这一点。

（此问题在 §2.1 已被否决的前提下暂无实操后果，但若后续改用连续松弛复活「可学 `α`」，
它会立刻变成必须先回答的设计问题：`α` 应挂在共同底座通路还是排序通路。）

## 三、追问：换成连续松弛后，两机制是否退化为同一机制的两个面

用户追问的三点，逐一实测（`alpha_relaxation_probe.py`）。

连续松弛取 **Rockafellar–Uryasev 形式**——这是 top-`α` 均值的标准变分表示：

```
top-α 均值 = min_ξ { ξ + 1/(α·m) · Σ_t [l_t − ξ]_+ }
```

`α` 在其中作为**连续系数 `1/α`** 出现，不再经 `ceil`。

### 3.1 Q1：松弛确实解锁梯度（`【实测】`）

| 实现 | `α.grad` |
| --- | ---: |
| 现行硬 top-`k` | `0.0` |
| RU 连续松弛 | **`−5.5778`** |

### 3.2 Q2：解锁 `α` **不需要** BER（`【实测】`）

上表的 RU 松弛实验中，损失是 `S_e.sum()`——**没有排序、没有 hinge、没有 `ξ_{p,K}`、
没有 `τ_K`，完全没有 BER 的任何成分**，`α.grad` 已非零。

**故 `α` 的可微性是机制一自身改写就能解决的问题，对机制二零依赖。**
这是对 §2.3「互为前提」的第二次独立否决——第一次是 §2.2 的活动率实验证明
软化**不能**解锁 `α`，这一次是证明解锁 `α` **不需要**软化。**两个方向都不成立。**

### 3.3 Q3：松弛打破四格 `z1'=0` 臂的逐位退化契约（`【实测】`，**新增阻断项**）

生产代码有一条硬断言 `assert_tail_aggregation_degenerates_to_max`
（`ch3_ft_entity_ranking_loss.py:408-449`），要求 `α=None` 时与 `prefix_scores` 的 max
**`torch.equal` 逐位相等**；仓库把它称为「四格 `z1=0` 臂的正确性基石——若它不成立，
『关掉机制即回到现状』这句话就不成立，整个 2×2 消融的可解释性随之失效」。

| 实现 | `S_e` | 与 max 逐位相等 | 偏差 |
| --- | ---: | :---: | ---: |
| 参照 max（`prefix_scores`） | `+2.81907773` | — | — |
| 现行 `α=None`（`k≡1`） | `+2.81907773` | **是** | `0` |
| RU 松弛 `α=0.2` | `+1.46017694` | 否 | `1.36e+00` |
| RU 松弛 `α=0.05` | `+2.17051268` | 否 | `6.49e-01` |
| RU 松弛 `α=0.01` | `+2.67479086` | 否 | `1.44e-01` |
| RU 松弛 `α=0.002` | `+2.81962442` | 否 | `5.47e-04` |

**RU 松弛只在 `α→0` 时渐近趋于 max，永远不逐位相等。** 采用连续松弛就必须
同时处置这条断言：或改为容差断言（则「关掉机制即回到现状」从**恒等**降级为**近似**，
四格解释力下降），或为 `z1'=0` 保留硬路径（则两臂走两套算术，退化契约同样不再是恒等式）。
**这是连续松弛路径自带的新阻断项，文档 §五之二 称松弛是「唯一出路」时未计入这一代价。**

### 3.4 对追问的直接回答（`【推论】`）

**是，会退化为「同一个机制的两个面」，而且比文档设想的更彻底。**

- ETA 的 RU 形式：对**实体袋内逐流 logit** 取 `α` 水平的 CVaR；
- BER 的现行形式（`cvar_pauc_loss`，行 465 公式）：对**跨负实体的成对损失** `L_pn`
  取 `K_eff` 水平的 CVaR。

**两者是同一个 Rockafellar–Uryasev 算子，作用在两个嵌套层级上**，
差别只在「对什么取尾部」与「尾部水平叫 `α` 还是 `K_eff`」。
一旦机制一改用 RU 松弛，第三章的两个机制就是**一个算子的两次实例化**，
不是两个独立机制。

**两条必须同时讲清楚的边界**：

1. 「一个算子用在两个层级」本身**不必然**是缺陷——它可以作为一个更强的统一叙事。
   但它**是一个，不是两个**。第三章若要维持「双机制」的章节组织（朱论文对位表要求的
   「双模块或互补维度组织」），这个改动会把两个模块压成一个，须由用户裁决章节定位，
   **这不是实验能回答的问题**。
2. **仓库已有一次同型事故的明确记录**：根 `AGENTS.md` 载明 2026-09-01 曾以
   「与 BER 构成嵌套 CVaR 共享框架」这一**未经验证的优势**作为候选选择的决定性理由，
   机制冻结、实验开跑后才发现该主张三个组成部分有两个撑不住。
   **本节的「同一算子两个层级」是结构观察，不是优势主张**；
   它说明的是两机制会合并这一**代价**，不得再次被当作「统一框架」的**卖点**写入方案。

### B7 展开：分桶方案对 `67.8%` 的实体无效，且与桶边界无关（`【实测】`＋精确推导）

被审文档 §五之一 提出「按袋大小分桶」的 `α_b` 以修复 `67.8%` 实体上的 ETA 惰性。
**该方案在这批实体上数学上不可能生效**，理由是一条精确的整数性质，不需要跑分布扫描：

`k_e = ceil(α·m_e)`，而 §2.1 声明的定义域是 **`α ∈ (0, 1/2]`**。对 `m_e = 2`：

```
α ∈ (0, 1/2]  ⟹  α·m_e ∈ (0, 1]  ⟹  k_e = ceil(α·m_e) ≡ 1
```

**即：在文档自己声明的定义域内，`m_e ≤ 2` 的袋上 `k_e` 恒等于 `1`，ETA 恒等于 max
（＝C00 的聚合口径），对每一个可取的 `α` 都成立。** 实测印证：

| `α` | `k_e`（`m=2`） | `S_e` |
| ---: | ---: | ---: |
| `0.10` / `0.30` / `0.50` | `1` | `−0.375583`（＝`max`） |
| `0.51` / `0.80` / `1.00` | `2` | `−0.687525`（＝`mean`） |

而 `k_e = 1 ⟺ m_e ≤ 2`（`m=3` 时 `ceil(1.5)=2`），与文档所述「`k_e=1` 的实体占 `67.8%`」
互为印证。**结论：分桶给这些实体换任何 `α_b` 都不改变结果，除非把 `α_b` 推出定义域
到 `> 1/2`——而那时 `k_e=2` 即整袋均值，`m=2` 的袋上根本不存在「尾部」这个中间态。**

**故 §五之一 的分桶方案对多数实体无效，且原因不是桶边界没定好，是袋太小。**
（本条只对 `m_e ≤ 2` 给出精确结论；全分布的惰性比例变化未测，补做命令见第五节。）
