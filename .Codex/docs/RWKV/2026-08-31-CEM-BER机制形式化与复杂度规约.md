## 一、共同背景与符号

主载体为 FT-Transformer：83 个合法字段各成一个 Token，加 `[CLS]` 共 `84` 个 Token，
宽度 `d = 192`，`L = 3` 层，`8` 头，裸主干可训练参数 `924,283`。

| 符号 | 含义 |
| --- | --- |
| `e` | 实体，由无向 2-IP 对定义 |
| `t` | 实体 `e` 的第 `t` 个片段（按时间升序） |
| `h_{e,t}` | 片段 `(e,t)` 经骨干末块输出的 `[CLS]` 表示，`∈ ℝ^d` |
| `l_{e,t}` | 片段 `(e,t)` 的逐流 logit |
| `S_e` | 实体 `e` 的路径分数 |
| `R` | 记忆槽数，冻结取 `8` |
| `M_e` | 实体 `e` 的记忆矩阵，`∈ ℝ^{R×d}` |

源年 LSPR23 协议 A 切分实测：实体 `150,680`，训练序列 `208,598`，验证序列 `22,444`，
训练与验证行交集 `0`。

## 二、机制一：因果实体记忆（CEM）

### 2.1 动机

裸 FT 对每条流独立打分，同一实体的历史片段之间没有任何信息通路。
而 `ch3-lspr23-entity-history-availability-v1` 收据实测：`52.05%` 的实体拥有两条以上的流，
这些实体承载 `99.56%` 的流量；恶意实体的流链长度中位数为 `112`，良性实体为 `2`。
即历史长度本身携带判别信息，而裸 FT 结构上无法使用它。

CEM 的作用维度是**结构级**：在不改变逐流输入协议的前提下，为当前片段提供一条
读取本实体严格过去表示的通路。

### 2.2 记忆状态与读写

`M_e` 的槽位语义不同质：

- **槽 0**：跨片段 Welford 在线均值，累积实体的长期表示；
- **槽 1 … R−1**：最近表示的有界队列（环形），保留近期动态。

写入在预测完成之后执行（见第四节），故对片段 `t` 可见的状态只由 `1 … t−1` 构成。
实测检查点中该状态的实际规模：`queue` 为 `(134997, 7, 192)` float32、
`mean` 为 `(134997, 192)` float32，另有 `active_rows`／`count`／`filled` 三个
`(134997,)` int64，合计 `794.09 MiB`；模型权重本身仅 `4.12 MiB`。

### 2.3 交叉注意力与门控

当前片段的 `[CLS]` 表示单向查询记忆，注入方式为标量门控残差：

```
q      = W_Q · LayerNorm(h)                       ∈ ℝ^d
K, V   = W_K · (LayerNorm(M_e) + P_R),  W_V · (…)  ∈ ℝ^{R×d}
c      = W_out · Attention(q, K, V)                ∈ ℝ^d
g      = σ( W_gate · [h ; c] + b )                 ∈ ℝ
h'     = h + g · c
```

`P_R ∈ ℝ^{R×d}` 是角色嵌入，零初始化，只用于区分长期均值槽与最近性槽。
注意力按 `8` 头切分，`head_dim = d / 8 = 24`。

**零门退化**：当实体无严格过去可读时（`memory_valid` 该行全假），
上下文直接置零而不做全掩码 softmax，于是 `c = 0`、`h' = h` 逐位相等，
与 `z1 = 0` 的裸 FT 路径同构。该性质已由运行时断言核验：
关闭记忆开关后模型输出与裸主干在探测片段上逐位相等。

### 2.4 参数量闭式

```
N_CEM(d, R) = 4(d² + d) + (2d + 1) + 2·(2d) + R·d
```

四项依次为：`W_Q`／`W_K`／`W_V`／`W_out` 四个含偏置的 `Linear(d,d)`；
标量门 `Linear(2d,1)`；`norm_query`／`norm_memory` 两处 `LayerNorm(d)`；`R×d` 角色嵌入。

`d = 192` 时：`R=2 → 149,761`、`R=4 → 150,145`、**`R=8 → 150,913`**、`R=16 → 152,449`。
冻结取 `R = 8`，占裸主干 `924,283` 的 `16.33%`，闭式与实测一致。

## 三、机制二：预算感知实体排序（BER）

### 3.1 动机

评价口径是实体级、且运营上只在有限误报预算内看告警，而训练目标是逐流交叉熵。
两者错位的直接证据来自 C00 的选轮实验：逐流 AP 自第 3 轮起饱和于 `0.998` 以上、
末段几乎无区分度，而同期实体 AP 在 `0.3243`–`0.7888` 之间变动；
按逐流指标择优选轮会使实体 AP 损失 `13.49` 个百分点。

BER 的作用维度是**训练级**：不改变模型结构与推理期参数，
把训练目标改写为与部署同构的、实体级的、预算内的排序目标。

### 3.2 实体路径分数

```
S_e = max_t  l_{e,t}
```

与部署同构：运营上只要实体的任一条流越过阈值即告警。
唯一最大值时梯度只回到取得最大 logit 的那条流；并列时按固定稳定顺序取合法子梯度
（实现用 `argmax` 定位加 `gather` 取值，不依赖 `torch.max` 对并列的隐式处理）。

### 3.3 多预算 CVaR-pAUC 目标

```
L_pn      = softplus(S_n − S_p)
R_K(θ,ξ)  = mean_p [ ξ_{p,K} + (1/K) · Σ_n [ L_pn − ξ_{p,K} ]_+ ]
L_rank    = mean_K  R_K(θ,ξ)
```

`p` 遍历正实体、`n` 遍历负实体；`ξ_{p,K}` 是逐正实体逐预算的阈值，
属**训练私有状态**，不进入推理图，因此 C01 的推理期参数量与裸 FT 完全相同（`924,283`）。
该事实已由检查点实物独立佐证：C01 与 C00 的 `state_dict` 条目数与元素总数
逐位相同（`54` 条 / `924,285` 个元素）。

选择 CVaR 形式而非普通成对排序，依据是 `2026-08-28-机制二梯度信号实测裁决.md` 的实测：
收敛模型上普通 RankNet 形式的梯度范数中位为 `6.08e-14`，比逐流梯度低约 12 个数量级、
12 批中 3 批严格为零；CVaR 形式相对普通形式的梯度范数比在收敛模型上为 `16.61`
（随机初始化时仅 `1.30`）。即普通形式在收敛后不再提供有效梯度，CVaR 形式仍提供。

### 3.4 有效预算折算

真实预算 `K` 定义在总体负实体池 `N_-` 上，而每步只抽样 `n_sampled` 个负实体。
按单样本无偏估计量 `r̂ = ξ + (1/β_K)[L_pn − ξ]_+`（`β_K = K / N_-`）推导：

```
K_eff = K · n_sampled / N_-
```

代入后 `(1/K_eff)·Σ_{n∈sampled}[·]_+ = (1/β_K)·mean_{n∈sampled}[·]_+`，
与对单样本无偏估计量取样本均值一致。`K_eff` 一般非整数，按浮点传入。

冻结预算 `[121, 606, 1213, 2426, 4853, 9706]`，由 LSPR23 **训练角色**负实体池
（`121,336`）按六档标称比例 `0.1%/0.5%/1%/2%/4%/8%` 投影得到。
未沿用按 LSPR24 负实体数投影的历史常量——那会把目标年统计量带入训练超参数。

## 四、因果边界与在线算法

两机制共享同一条严格过去约束：**片段 `t` 的任何计算都不得读取 `≥ t` 的信息**。

单步的执行顺序固定为：

```
1. 读记忆      M_e ← state.read(e)        只含片段 1…t−1 的写入
2. 骨干前向    h   ← Backbone(x_{e,t})
3. 注入        h'  ← h + g·c              c 由 M_e 经交叉注意力给出
4. 出分        l_{e,t} ← Head(h')
5. 形成实体分  S_e ← max_{t'≤t} l_{e,t'}   仅用已出分的前缀
6. 排序损失    L_rank 按 §3.3 计算
7. 更新参数
8. 写记忆      state.write(e, summary(h'))  预测与告警完成之后
```

第 8 步必须在第 4 步之后，这是「先读后写」的实现落点。

**训练与验证的状态隔离**：验证扫描每轮起手对验证角色执行 `reset_role`，
保证同一检查点在不同轮次重复评价可复现，不携带上一轮遗留状态。
目标年评价照此办理：记忆从零开始、按目标年实体链顺序重新累积，
不从检查点恢复源年累积的记忆——那是源年实体的状态。

**排序阶段的状态隔离**：机制二抽取的实体袋总是从该实体因果最早的片段开始重放，
若直接读写训练角色的持久记忆，会与链式调度器的游标相互覆盖，
使调度器下次读到「未来」状态。故排序阶段使用宿主专用的第二个记忆实例（scratch），
不写回持久状态。

## 五、挂载位置

| 机制 | 挂载点 | 是否改变推理图 | 推理期参数增量 |
| --- | --- | --- | ---: |
| CEM | 骨干末块之后、分类头之前，作用于 `[CLS]` 表示 | 是 | `+150,913` |
| BER | 训练目标，作用于已出分的 logits | 否 | `0` |

两者作用维度正交：CEM 改变表示如何形成，BER 改变参数如何被优化。
这也是四格 `2×2` 能独立开关的结构基础——`z1` 控制是否构造并调用记忆模块，
`z2` 控制是否加入排序损失，二者在代码路径上无共享分支。

## 六、复杂度分析

设批内片段数 `B`、Token 数 `T = 84`、宽度 `d = 192`、层数 `L = 3`、槽数 `R = 8`。

### 6.1 时间

| 组件 | 复杂度 | 相对骨干 |
| --- | --- | --- |
| 骨干自注意力 | `O(L · B · T² · d)` | 基准 |
| 骨干前馈 | `O(L · B · T · d²)` | 基准 |
| CEM 交叉注意力 | `O(B · R · d)` | 见下 |
| CEM 投影 | `O(B · d²)` | 见下 |
| BER 路径分数 | `O(Σ_e n_e) = O(B)` | 可忽略 |
| BER CVaR 目标 | `O(|P| · |N| · |K|)` | 与批内实体数相关，与 `d` 无关 |

CEM 的注意力部分只对 `R = 8` 个记忆槽做，而骨干自注意力对 `T = 84` 个 Token 做，
且 CEM 只在末块后作用一次而非每层，故其注意力项相对骨干约为
`(R) / (L · T²) = 8 / (3 · 7056) ≈ 0.04%`。投影部分为 `4` 个 `d×d`，
相对骨干每层的 `4` 个 `d×d`（QKVO）加前馈约 `8d²`，占比约 `4 / (3 · 12) ≈ 11%`。

**实测对照**：旧路径（未启用编译）下 C00 步速 `4.757` 步/秒、C10 `4.807` 步/秒，
CEM 未带来速度损失，GPU 利用率反从约 `66%` 升到 `95%`——额外计算填补了原有空档。
编译路径下 C00 `6.915` 对 C10 `4.933`，差异不来自 CEM 本身，
而是 `torch.compile` 只编译 `forward`、C10 走 `encode/inject/predict` 未被编译
（见四格进度文档的口径边界节）。

### 6.2 空间

推理期：CEM 只增加 `R × d` 的每实体状态与固定的模块参数，与序列长度无关。
训练期：记忆状态按已激活实体稀疏保存，实测 `134,997` 个实体条目、`794.09 MiB`。

BER 的排序阶段一次前向覆盖整个实体袋，规模由 `n_pos + n_neg = 66` 个实体乘
每实体至多 `ceil(truncate_length / sequence_length) = 64` 段决定，实测达 `6,403` 个序列。
该批的中间激活在未加梯度检查点时需 `30.97 GiB`，超出 `31.36 GiB` 可用显存而失败；
改用梯度检查点后峰值降至 `15,175 MiB`，代价是步速由 `6.9` 降至 `2.6` 步/秒。
CVaR-pAUC 目标要求全体实体分数同时在同一张图中，无法分批反传，故此处必须重算换显存。

## 七、边界

- 本文件只描述设计与已实测的工程性质，**不含机制有效性结论**。
  四格判据当前 `C10 > C00` 与 `C01 > C00` 成立，`C11 ≥ max` 与交互项因 C11 缺失不可评估。
- 复杂度分析中的相对占比为按结构推导的估算，已用实测步速对照；
  推导与实测不一致处以实测为准并已注明原因。
- `truncate_length = 8192` 与 `n_pos/n_neg = 2/64` 是宿主接线阶段的任务化设定，
  配置内已标注「非封印定论」，袋处置的最终裁决须等源年前缀分数曲线。
