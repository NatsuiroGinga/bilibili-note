## 二、公共研究边界

1. 研究任务是网络攻击状态检测，不宣称逐包、逐连接或泛化的加密流量检测。字段预算对齐 Dijk 附录 A 的 83 字段：端口与协议字段、粗粒度拓扑指示允许入模；原始 IP 只作分组键，演习身份（`Expoid_*`、`Segment_*`）、既有 IDS 输出（`SigID revision`、`Category`、`Severity`、`Anomaly_event`）与标签派生字段禁止入模。实现即 `101 − 18 = 83`。逐项审计见[Dijk 协议逐项审计](2026-08-13-Dijk2026协议逐项审计.md)。
2. 论文最终只使用一个 LSPR 数据集体系。LSPR23 与 LSPR24 是同一基准的跨年度成员，构造源年度训练与目标年度评价；UGR'16 仅作历史筛选证据。第三、四章共享最终冻结的数据合同、样本身份、字段预算和评价协议。
3. RWKV-7 是具有正式论文和官方源码的机制来源与原生对照。RWKV-8/ROSA 可作工程候选但无正式论文；所有效果主张须由本课题独立实验支持。
4. 设计、文献、审查或代理实验只能说明可试性，不能代替绑定数据、配置、共同基线、日志与制品的有效实验。未满足正式条件的结果必须标为「实验待证」或专项文档定义的弱证据。
5. 错误相对下降 `16.1%` 是本课题早期自定门槛，不是朱焱雷论文中的数字。朱第三章表 3-7 报的是 PGD-20 鲁棒准确率绝对百分点：BUPT-CNN `55.60%→64.90%`（`+9.30`）、ET-BERT `63.50%→75.80%`（`+12.30`），且 `12.30` 超过单模块增益之和 `9.00`；全文级主张是较前沿基线鲁棒性提升 `4.2%~8.6%`。引用时须注明绝对百分点而非错误相对下降。

- 论文外部主比较表只能纳入已有论文公开基线方案，并在同一冻结 LSPR 成员、切分、字段预算、标签权限、训练预算和评价指标下重新运行。内部参数匹配公平基线与单种子筛选不得冒充公开基线或论文正式结果。

## 五、服务器与凭据

- 当前服务器为 **B76**（RTX 5090，32.6 GiB），凭据键为 `GPU_SSH_B76` / `GPU_PWD_B76`。C56 与 A44 已停用，仅作历史制品来源。
- **B76 连接默认直连**：`GPU_SSH_B76` 表面可仅为 `ssh -p <端口> <目标>`，但既有 SSH 配置可能隐式指向 `127.0.0.1:7890`。每次使用 B76 前，先设置 `GPU_SSH_ACTIVE="ssh -o ProxyCommand=none -o ProxyJump=none ${GPU_SSH_B76#ssh }"`，再通过正式 `tools/remote_exec/gpu_env_quiet.exp` 执行；不得探测、启动或假设必须使用 Clash Party，也不得将 `7890` 视为必需端口。
- 直连失败时只报告原始且脱敏的 SSH 错误，不得自动切换代理。只有用户明确授权后，才可使用代理路径；凭据仍只可从既有环境变量读取，禁止打印或写入文档、日志与命令回显。
- 远程项目根为 `/root/autodl-tmp/thesis/experiments/llm_probe`，不是 `~/llm_probe` 或 `/workspace/llm_probe`。运行根写作 `<项目根>/runs/diagnostics/<运行名>` 或专项计划冻结的候选路径。
- 主 shell 默认不加载凭据变量，需先 `source ~/.zshrc` 并丢弃输出。远程执行必须用 `tools/remote_exec/gpu_env_quiet.exp`，禁止自建会回显 `spawn ssh` 行的入口。
- 新端口首次连接卡在主机密钥确认时，先停止遗留入口再重连。长任务必须用后台持久入口并轮询日志，不得 `sleep` 死等。
- 启动实验前必须过 `tools/memory_admission_gate.sh <预计峰值GiB> <运行名>`；该门读取 cgroup，退出码 10 表示内存不足、11 表示已有并发、12 表示无法读取上限。
- 服务器可能被回收。正式运行前重新核验身份、项目目录、数据、模型、依赖、GPU、磁盘和 SwanLab，不沿用旧进程或旧资源假设。
