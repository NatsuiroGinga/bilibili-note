# CUDA RWKV 独立资格实验实施计划

## 目标

RWKV 唯一活动训练路径为独立 CUDA 融合实现。该实现仅在合法 Raw83 数据与共享协议门全部通过后，以独立运行身份从头训练；不得复用任何历史训练实现的权重、优化器、断点、代码锚或对照门。

## 当前状态

- CUDA 生产入口提交 `f207f6e` 仅完成本地静态检查，尚未同步、编译或真实运行。
- 当前证据等级为“设计可行、实验待证”。既有历史工程比较不构成本实现的资格或效果证据。
- 在合法 Raw83 数据清单、模式、行数、切分、字段、标签连接与语义哈希收据齐全前，不得启动训练。

## 数据与运行门

1. 使用统一共享加载器消费合法 Raw83 数据，不为 RWKV 建立专属旧格式适配。
2. 启动前机械核验数据清单、模式版本、字段预算、实体不相交切分、标签连接和目标年隔离。
3. 使用独立运行标识、独立检查点根和独立跟踪身份，从随机初始化开始训练。
4. 恢复仅允许同一 CUDA 实现、同一配置摘要和同一数据语义哈希产生的本次独立断点。
5. 编译失败、资源门失败或结果不合格时记录精确失败并停止，不切换其他训练实现。

## 实验与证据

- 源年开发区先完成最小四格因果消融与共同预算强基线比较。
- 报告逐流 AP、实体 AP、最大池化实体 AP、共同实际误报预算曲线、首次告警曲线和资源收据。
- 源年选择封印前目标年数组读取计数必须为 `0`；目标年只执行一次冻结评价。
- 真实 CUDA 编译、训练日志、指标和制品产生前，不得写入论文结论或路线总控的“实验支持”状态。
