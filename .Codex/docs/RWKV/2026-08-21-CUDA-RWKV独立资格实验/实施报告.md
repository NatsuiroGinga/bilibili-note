# CUDA RWKV 独立正式资格实验实施报告

## 结论

已新增 R2/K0 CUDA 融合 WKV 的独立 BF16 Protocol A 四格正式资格入口、冻结配置和唯一启动器。本地静态状态为 **READY，实验待证**。

该路径不是纯 PyTorch 后端的透明替换。既有资格收据显示合成与首批等价通过、整轮加速 `8.668993` 倍，但验证 AP 差 `0.004199787`、reserved 显存比 `1.099476`，透明替换门失败。用户授权允许把它作为独立数值变体采用，不等于效果支持。

## 官方与派生边界

- 官方仓库：`BlinkDL/RWKV-LM`。
- 固定提交：`952102498e9ed367ea0a59ee64106916d474d30f`。
- 许可证：`Apache-2.0`。
- 官方训练路径本身使用 CUDA 融合 WKV、BF16 输入输出和核内 FP32 状态，因此 CUDA WKV 可作为正式主候选。
- 本项目使用 `HEAD_SIZE=16`、`C=112`、`L=128`、R2 字段感知输入适配、单层 TimeMix，且没有完整官方 ChannelMix。它是面向当前任务的派生实现，不是未经修改的官方完整 RWKV。

聚合身份固定记录官方提交、许可证、派生范围、纯 PyTorch 工程锚、后端/源码/基准摘要、失败资格收据摘要与断点兼容边界。

## 实现内容

| 文件 | 作用 |
| --- | --- |
| `tools/ch3_rwkv7_field_aware_protocol_a_2x2_fused_bf16.py` | 融合 TimeMix、后端身份门、仅同变体恢复、聚合与 manifest 身份 |
| `configs/ch3-rwkv7-field-aware-protocol-a-2x2-fused-bf16-seed42-v1.json` | 独立 run_id、固定 R2/K0、四格、精度、指标、来源与披露 |
| `scripts/remote_launchers/run_ch3_rwkv7_field_aware_protocol_a_2x2_fused_bf16_seed42_v1.sh` | 双收据解析、资源门、扩展加载、独立 screen、恢复与发布 |

新入口从种子 `42` 分别全新初始化 `C00/C01/C10/C11`。它不加载纯 PyTorch 模型、优化器、选中轮次或断点。每 `20` 个完整优化步原子保存；恢复时精确比较 CUDA 融合身份和配置摘要。

六个 WKV 输入、输出与梯度为 BF16；CUDA 核内状态为 FP32。参数、优化器、归一化、衰减构造、Lp 池化、损失、指标等敏感计算继续保持 FP32，配置固定 `scaler=null`。

四格源年选择全部写入封印后才允许加载 LSPR24。入口继承并产出源年与目标年的逐流 AP、实体 AP、最大池化实体 AP、六档实际 DR、完整告警预算曲线、`exposure_index` 首次告警聚合、首次完整步和总资源收据。
