# 朱焱雷第三章候选门槛基准

- **日期**：2026-08-08
- **来源原件**：[`朱焱雷.pdf`](../../../raw/papers/attack-detection/朱焱雷.pdf)
- **适用对象**：RWKV 机制迁移到普通基座模型的第三章候选方案
- **用途边界**：只参照单章问题组织、理论深度、实验完整度和提升量级；**禁止复制其课程调度、Stackelberg 二阶反应梯度、公式、算法名称或实验叙事**。
- **候选状态来源**：[`第三章候选方案登记册`](2026-08-08-第三章候选方案登记册.md)。本文不改变 C1—C11 的证据状态，候选存废仍只能由合格实验裁决。

## 1. 核验结论

朱焱雷论文第三章位于 **PDF 第 39—64 页**，对应论文印刷页 **23—48**，共 **26 页**。其工作量不是由某一个复杂公式撑起，而是由一条完整论证链共同形成：

1. 先把一个章级问题拆为两个相互依赖的子问题；
2. 用两个机制分别处理不同阶段或不同层面的矛盾；
3. 给出统一目标、端到端算法和异构骨干适配；
4. 从优化、稳定性、泛化和现实边界四个角度解释方法；
5. 用外部横向比较、训练轨迹、`2×2` 消融、内部表征、敏感性、细粒度和现实约束实验逐层验证。

核验到的章内制品为：**33 个连续编号公式、1 个算法、2 个定理、1 个引理、11 幅图和 7 张表**。这些数量只作为完整度标尺，不是要求当前方案机械凑数。

## 2. 章节标题与组织方式

### 2.1 标题模式

原章标题为“基于动态难度调度与二阶反应梯度优化的抗逃逸训练方法”，采用：

> 基于“机制一”与“机制二”的“目标方法”

可迁移的不是两个机制本身，而是标题背后的组织纪律：标题直接给出两个协同机制和唯一任务目标，使读者在进入正文前即可判断“解决什么问题、依靠哪两项实质改动”。当前 RWKV 路线也应满足这一结构，但机制必须来自经安全语义改造后的 RWKV 原理或其与普通基座模型的原创结合。

## 3. 核心问题与两个协同机制的关系

### 3.1 单章只解决一个总问题

第三章的总问题是：强攻击下模型鲁棒性不足，同时大模型对抗训练容易震荡、难收敛。两个机制分别对应总问题中的两个必要环节：

- 机制一调节训练过程的约束难度，处理训练初期的可优化性与稳定性；
- 机制二改变参数更新方向，处理最终寻优质量与鲁棒性。

其关系不是“两个模块都能提高准确率”，而是：**机制一先提供可进入的优化路径，机制二再沿该路径完成更有效的更新**。外层控制训练阶段，内层完成每批次的参数寻优；两者在统一目标和算法中相遇。该关系由总体框架图和 `2×2` 消融共同支撑，见图 3-1（PDF 41／印刷 25）与表 3-7（PDF 58／印刷 42）。

### 3.2 对当前 RWKV 候选的可迁移要求

候选方案若要达到相同的章级深度，两个机制至少要满足：

1. **解决同一总问题中的两个不同因果环节**，不能只是给同一表示连续叠加两个模块；
2. **存在明确接口**，例如一个机制产生状态、约束或路由信号，另一个机制消费该信号并改变普通基座模型的表示或更新；
3. **能够写成统一目标或统一状态更新**，而不是两项独立损失的简单加权；
4. **每个机制都可单独关闭**，从而形成基座、机制一、机制二、完整方法四个严格变体；
5. **安全领域改造是实质性的**，须说明网络状态、字段语义、时间因果或攻击行为如何改变原 RWKV 机制，不能只改名称。

## 6. 提升幅度的原始表格证据

统一换算：设指标为 `m`，错误率为 `e=1-m`，错误相对下降为：

\[
R_{err}=\frac{m_{method}-m_{base}}{1-m_{base}}.
\]

## 7. 可迁移为候选验收门槛的量化清单

### 7.1 候选进入快速消融前

以下项目全部满足，候选才值得实现：

- [ ] 标题能够写成“基于机制一与机制二的安全任务方法”，且只解决一个章级问题。
- [ ] 两个机制分别对应不同因果环节，并有明确输入、状态、输出和连接接口。
- [ ] 至少形成任务定义、机制一、机制二、统一目标、基座注入、性质或边界六组公式草案；完整章具备扩展为 **25—35 个实质公式**的合理空间。
- [ ] 至少能提出 2 个机制命题和 1 个适用边界，不依赖照抄 RWKV 原论文结论。
- [ ] 现有数据集能够直接提供所需变量，或可通过不读取最终测试标签的重新物化得到；不存在必须凭空补造的字段。
- [ ] 能在普通基座模型上实现同预算的“基座／机制一／机制二／完整方法”四变体。
- [ ] 预计单卡可运行，并可记录参数量、峰值显存、训练时间和推理吞吐。

### 7.2 快速消融门槛

快速实验只在冻结开发区进行，使用种子 42 和共同预算，不访问最终测试集：

1. 固定数据、字段、切分、基座、参数预算、训练步数和评价程序；
2. 同时运行 `B`、`B+M1`、`B+M2`、`B+M1+M2`；
3. 至少报告一个主要检测指标、一个类别不平衡指标、训练稳定性和机制专属诊断量；
4. 若实验存在泄漏、样本捷径、标签时序错误或数据缺失，结果标为无效，不得淘汰候选；
5. **继续进入正式实验的最低信号**：完整方法优于基座，至少一个单机制有正增益，完整方法不弱于最佳单机制，机制专属诊断量沿理论预期变化；
6. 只有在合格设计下，两个单机制和完整方法均无增益，且机制专属诊断量也不变化，才允许把候选推进到正式证伪程序。

快速消融的职责是判断“是否存在可训练信号”，不要求一次就达到 16.1%。这可防止用一个低成本代理实验误杀尚未经过真实训练的候选。

### 7.3 正式方案转正门槛

- [ ] 主困难面板相对最强公平基线的错误相对下降目标约为 **16.1% 或更高**。
- [ ] 至少一个异构基座或模型家族仍有稳定正增益；参照朱文次骨干，错误相对下降达到约 **8%—10%**具有相近说服力。
- [ ] 基础任务主指标损失控制在约 **2.1 个百分点以内**，或给出预先声明且更适合当前任务的代价边界。
- [ ] 两个机制各自有独立正贡献，完整方法优于最佳单机制；至少在主基座上报告交互项 `I=Δ12-Δ1-Δ2`，正交互为优先转正证据。
- [ ] 三个冻结种子报告原始值、均值、离散性和置信区间，不只选最佳种子。
- [ ] 外部比较至少覆盖普通基座、同类安全方法、近期序列或状态空间方法等 **5—6 类强基线**，不能只和自有弱变体比较。
- [ ] 至少两个预先冻结的困难面板，不能根据方法结果重新挑样本或改变数据比例。
- [ ] 完整章最终达到约 **26—30 页、1 个端到端算法、2 个命题或定理、1 个边界引理、9—12 幅图、6—8 张表**的论证规模；数量必须服务于真实证据，不得填充。

## 8. 对当前工作流的直接约束

1. 当前应从 RWKV 原论文和生态论文中提取可迁移机制，但每个机制都必须经过安全语义重构后嵌入普通基座模型；“换骨干”本身不足以构成第三章。
2. 可优先使用现有数据集并重新物化，但物化规则必须在看结果前冻结；快速消融只使用开发区，不能用最终测试结果反向选择候选。
3. 候选先过“理论可成章”门槛，再做低成本 `2×2` 快速消融；有信号后才扩展到强基线、三种子、跨基座和完整图表矩阵。
4. C1—C11 当前仍没有任何一个处于“已支持”或“已证伪”。本文只给出统一衡量尺度，不代替候选登记册中的实验裁决。

## 9. 一句话基准

一个能够进入第三章主线的方案，应当表现为：**围绕一个明确安全问题，把两个经安全语义改造的 RWKV 机制有因果关系地移植到普通基座模型中，用统一公式和端到端算法描述，再以冻结数据上的四变体消融、强外部基线、跨基座、稳定性、机理与边界实验共同证明；最终主困难面板的错误相对下降以约 16.1% 为对标值。**
