## 3. E1：事件定义证伪

门禁：`G=0` 逐位复现 `n_events=1519`、`n_single=1089`，通过。运行 `10.85` 秒，峰值 `VmRSS ≈ 1.41 GiB`。

### 3.1 删失切碎假说被否决

单窗事件的紧邻窗分类（either 侧占比）：

| 类别 | 全部 1519 事件 | 单窗 1089 事件 |
| --- | ---: | ---: |
| `negative` | `86.77%` | `86.32%` |
| `empty`（删失且**无活动**） | `49.18%` | `55.46%` |
| **`censored_active`（删失且**有活动**）** | `2.17%` | **`0.37%`（4/1089）** |
| `boundary` | `1.25%` | `0.18%` |

真正能"切碎长事件"的是 `censored_active`，**只有 4 个**。碎片化确实存在，但**不是删失驱动**，而是普通负类窗与真正空窗共同造成的粒度效应。

### 3.2 容差扫描

| `G` | `n_events` | `n_single` | 比 `G=0` | `single` 误差份额 | 0.01 档事件召回 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | `1519` | `1089` | `1.000` | `57.07%` | `0.5326` |
| 2 | `1157` | `946` | `0.8687` | `49.71%` | `0.4581` |
| 12 | `949` | `738` | `0.6777` | `32.52%` | `0.5216` |
| 24 | `668` | `416` | `0.3820` | `22.83%` | `0.4940` |

预注册判据：判伪影需 `n_single(G=2)/n_single(0) ≤ 0.50`（实测 `0.8687`，不满足）或 censored 邻接 ≥`0.30`（实测 `0.0037`，不满足）；判真实需 `n_single(G=12)/n_single(0) ≥ 0.80`（实测 `0.6777`，不满足）。
**裁决 `partial_artifact`。** 按预注册规则给出 `G=2` 的冻结重述：`n_events=1157`、`n_single=946`（`81.76%`）、`single` 误差份额 `49.71%`。**是否采用 `G=2` 作为正式事件定义待人裁决。**

0.01 档事件召回在各 `G` 下始终停在 `0.45`–`0.53`，说明「仍有大量漏检」这一发现**对事件切分粒度不敏感**。

### 3.3 子判据：「单窗＝历史贫瘠」被直接证伪

`G=0` 的 1089 个单窗事件，`lag1..4` 非空历史窗数分布：

```
{0: 41, 1: 130, 2: 295, 3: 321, 4: 302}      中位数 = 3.0
```

**`623/1089 = 57.2%` 的单窗事件有 3 或 4 个非空历史 lag。** 预注册子判据「中位数 ≥3 则前提被证伪」触发。

**推论（非本实验直接测量）**：单窗事件分数低不是因为没有历史，而是 lag0..4 展平树没有利用好历史。

### 3.4 E3 附带项：事件召回不能作主指标基线

- **分母敏感性**：`ep_hours_all=3213.03` → `ep_hours_evaluable=1287.91`，0.01 档 `allowed_fp` 由 `32` 降至 `12`，事件召回 `0.5326 → 0.4589`，**下降 `0.0737`**（落在 `0.05`–`0.10` 中间态，正文须注明受删失时长膨胀影响）。
- **簇自助 95% 区间**（0.01 档，点估计 `0.5326`，1000 次）：

| 重抽样单元 | 区间 | 半宽 |
| --- | --- | ---: |
| **端点簇**（113 个含事件端点） | `[0.2329, 0.7021]` | **`0.2346`** |
| 事件簇（对照） | `[0.5069, 0.5576]` | `0.0253` |

端点簇半宽是事件簇的 `9.3` 倍。**同端点内事件高度相关，有效独立样本量约 `113` 而非 `1519`。**

**强制结论**：单划分单种子的 `0.5326` **不能作为主指标基线**。任何比较必须改用以端点为簇的**配对**自助，报 `Δ` 的区间下界，而非各自的边际召回。

## 4. E5：决策规则余量（本轮最关键的否决）

只读冻结分数，未重训、未改动 `val_scores.parquet`。运行 `9.5` 秒，峰值 `VmRSS = 0.72 GiB`。
完整性核对：四档阈值与事件召回逐位复现 A1 冻结值（差 `<1e-12`），含事件端点 `113` 个与 E1 一致。

### 4.1 M1 证据累积：**否决**

漏检事件的分数形态：

| 预算 | 漏检 | 单窗 | 多窗 | 多窗成员窗 p50 / **p75** / p90 | 多窗事件 max 的 p75 |
| ---: | ---: | ---: | ---: | --- | ---: |
| `0.01` | `710` | `563` | `147` | `0.00070` / **`0.01944`** / `0.279` | `0.180` |
| `0.1` | `560` | `454` | `106` | `0.00032` / **`0.00142`** / `0.0127` | `0.019` |
| `1.0` | `361` | `312` | `49` | `0.00012` / **`0.00038`** / `0.00079` | `0.00082` |
| `10.0` | `229` | `217` | `12` | `8.2e-6` / **`1.72e-5`** / `5.6e-5` | `7.4e-5` |

0.01 档漏检多窗事件的 `max` 距阈值 `0.9455` 中位数差 **`0.9362`**。

**机制前提被证伪**：不是「多个中等偏高分数没被聚合起来」，而是**模型对这些事件根本没给出任何证据**。`p75 = 0.0194 < 0.1`，触发预注册否决线。

24 个候选规则（连续 `k` 次越界 `k∈{2..5}` / 衰减累积 `ρ∈{0.5,0.7,0.9}` / trailing top-`m` 均值 `m∈{2,3}`）**无一优于现行 max 规则**：

| 档 | max 基线 | oracle 最优候选 | **oracle Δ（配对 95% CI）** |
| ---: | ---: | ---: | --- |
| `0.01` | `0.532587` | `0.213298` | **`−0.3193` `[−0.551, −0.040]`** |
| `0.1` | `0.631336` | `0.570112` | `−0.0612` `[−0.103, −0.034]` |
| `1.0` | `0.762344` | `0.730744` | `−0.0316` `[−0.062, −0.012]` |
| `10.0` | `0.849243` | `0.842001` | `−0.0072` `[−0.016, −0.003]` |

诚实估计（前半选参、后半自标定）0.01 档：`Δ = −0.2143`，配对 CI `[−0.376, −0.044]`，整体在 0 以下。
误报口径不影响结论：同工作点下逐窗 FP=`32`、事件化 FP=`24`，基线与最优候选完全相同。

**加任何累积规则都比现行 max 规则更差。**

### 4.2 M2 预算分配：判据 GO，但内容空心

判据结果：边际斜率 **Gini `0.9516`**（p50=`0`、p90=`0.067`、max=`12.0`）；诚实 Δ = **`+0.1364`**，配对 CI **`[0.0820, 0.2159]`** 下界 >0。按预注册判据 **GO**。

**三条追加证据推翻其实质**：

1. **增益 95% 来自逐端点标定，不是预算分配。** 消融「零配额」（不花任何预算、纯逐端点标定）= `0.551052`，配对 CI `[0.0738, 0.2074]`；完整份额迁移 = `0.558067`。**`16` 个误报的分配只贡献 `+0.007`。** 均匀配额与零配额同值。
2. **只在最紧预算为正。** 0.1 档 `Δ=+0.0499` CI 含 0；**1.0 档 `−0.1208`、10.0 档 `−0.2369`，CI 整体为负。**
3. **不能跨时间冻结。** 只用前半段负窗标定后冻结、应用到后半：**`fp = 4946`**（0.01 档只允许 `16`，**超 `309` 倍**），召回 `0.5908`；后半段同误报数的单一全局阈值反而拿到 `0.7592`。配对 `Δ = −0.168`，CI `[−0.432, +0.037]` 含 0。

**M2 的真实内容是「逐端点阈值标定」而非「条件化预算分配」，且只在「可用被评价时段的自身流量重新标定」这一前提下成立。**

### 4.3 三个意外测出的硬事实

- **零成本可达 `908/1519` 事件**：只把每端点阈值提到其自身负窗最大值之上，**花 `0` 个误报**即得 `0.597103`，高于基线花 `32` 个误报的 `0.532587`。全局阈值极度浪费。
- **阈值高度非平稳**：全局阈值前半冻结应用到后半，0.01 档产生 `459` 个误报（允许 `16`，超 `28` 倍）；1.0 档 `4015`（允许 `1622`）。**基线自身也不稳。**
- **漏检单窗事件的历史比命中的更充足**：严格相邻历史窗数中位数 `2.0`（命中为 `1.0`）；有 4 个相邻历史的占 `194/563` vs 命中 `105/526`。与 E1 的 lag1..4 中位数 `3.0` 一致，**再次证伪「单窗＝历史贫瘠」**。
- 累积规则的原料不缺：全集 `68.86%` 的可评价验证窗有严格 `wri` 相邻前窗，`99.95%` 有同端点前窗。

### 4.4 正交性

oracle 组合在 0.1/1.0/10.0 档正交比 `1.02`–`1.07`，增益近似可加；0.01 档因 M1 单独为负而无法定义比值，组合 `+0.0790` **低于** M2 单独的 `+0.1284`——**加上累积规则反而拖累**。诚实组合 0.01 档 `Δ=+0.048` CI `[−0.024, 0.112]` 含 0，其余三档为负。**M1 对组合无贡献。**

### 4.5 配对与边际的对照

0.01 档基线边际半宽 `0.2110`（与 E1 的 `0.2346` 同量级），配对差半宽 `0.1660`，比值仅 `1.27`；0.1 档比值 `6.28`、10.0 档 `3.39`。
**在 0.01 档端点间共同变异并未被配对充分消掉**——该档只有 `32` 个误报，候选与基线的检出集合差异大，配对相关性弱。**该档的配对 CI 本身也偏宽，引用时须注明。**

### 4.6 已知设计局限

前后对半分极不平衡：前半仅 `236` 个事件、后半 `1283`（与 A 线 facet_4 的 `time_seg5` 占 `94.5%` 一致）。诚实估计的选参半段样本很少。**是否改为按事件数对半分或多折时间切分重测，待人裁决。**

## 5. E2：切分键偏移核验（源码级完成）

### 5.1 A 线不受影响（**A1/E5 全部数字无需重算**）

`tools/lspr24_g0/src/screen/wide.rs` 的三步顺序：

| 行号 | 动作 |
| --- | --- |
| `193`、`413-414` | 扫描期间对**每一条**能分配到受保护端点的流**无条件**插入 `active_window_starts`，此时尚不知其归属切分 |
| `227` | 扫描全部结束后**只算一次** `ActivitySplit::from_active_windows` |

| `740-747` | final 段丢弃发生在**聚合写出阶段，晚于**上述两步 |

结论：`split_name` 字段由**全量 100%** 活动键集合算出，**本身正确**。

A 线消费方式（`src/flow_probe/lspr24_screen_dataset.py:291-312`）是对 `split_name` 做纯字符串相等过滤，`lspr24_rwkv_screen.py:140-147` 亦然，全程无百分位重算路径。E5 的前后对半分（`e5_decision_rule_headroom.py:465,594-599`）是在已正确划出的 validation 子集**内部**用 `np.unique(ns)` 独立算的时间中点，与活动键百分位法无关。

### 5.2 C 线受影响

`scripts/lspr24_pilot/lspr24_early_warning_cpu_gate.py:194-250` 从**已物化的宽表**（仅含真实时间线前 `80%`）重建 `active_starts`，再取 `n_act*40//100`、`n_act*50//100` 作为 `b40_new`/`b50_new`——**用的是被截断的种群**。`0.60 × 0.80 = 0.48`，与实测偏移方向一致。

C 线脚本自身已在真实运行中发现并记录该问题（`核验=失败`），但其"修正"边界 `b40_new`/`b50_new` **仍建立在同一有偏种群上**。

**处置**：`gate_b pass=True` 的方向大概率仍站得住（三段正锚点远超门槛，裕量充足），但 **`b40_new`/`b50_new` 的具体秒数不可信，不得写入任何冻结合同**。

## 6. 综合裁决

### 6.1 已关闭的方向

| 方向 | 关闭依据 |
| --- | --- |
| 路线 C 未来窗风险预测 | 门禁任一口径未过（§2.1）；机制被 FRWKV+ 第 6 页式 16-17 逐项覆盖；有界性—增益二难 |

**决策规则层无可支撑一章的余量。**

### 6.2 唯一尚未测量的方向

**单窗事件子集上的排序质量。**

依据：`AP=0.9808` 是被 `18902` 个平均分 `0.9838` 的 middle 窗主导的**全局**值；单窗事件平均分仅 `0.5414`；而 E1（§3.3）与 E5（§4.3）两次独立测到这些事件**历史充足**（lag1..4 非空中位数 `3.0`；漏检者历史比命中者更充足）。

**待验证假设**：lag0..4 展平树把 5 个窗当 2044 个独立列，未利用时序结构，因而在单窗/孤立事件上排序质量远未饱和。

最小证伪实验（服务器恢复后执行，预计 10 分钟）：在 1089 个单窗事件 + 匹配负样本子集上测 A1 的 AP 与 ROC-AUC。
- 子集 AP >`0.95` → 饱和，该方向亦否决
- 子集 AP 落在 `0.6`–`0.8` → 有空间，值得上序列模型

### 6.3 强制执行的评价口径

1. **事件召回 `0.5326` 不能作为主指标基线**（端点簇半宽 `0.2346`）。
2. 任何规则或机制比较必须用**以端点为簇的配对自助**，报 `Δ` 的 95% 区间下界，不用各自边际召回。
3. 0.01 档配对相关性弱（配对/边际比值仅 `1.27`），该档结论须注明置信区间偏宽。
4. 分母口径（`3213.03` vs `1287.91` 端点小时）必须在正文注明，两者差 `0.0737` 事件召回。
