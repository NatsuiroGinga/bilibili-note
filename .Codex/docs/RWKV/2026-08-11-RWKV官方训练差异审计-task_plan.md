# RWKV 官方训练差异与 C12 适用性审计计划

## 目标

仅依据 BlinkDL 官方源码与官方仓库说明，核对原生 RWKV-7 训练和普通 Transformer 的关键差异，并判断当前 C12 阶段 A 的 K-RWKV7 是否需要采用这些差异。

## 核心问题

1. 官方 RWKV-7 在初始化、优化器、调度、状态、上下文、数值核和数据顺序上有哪些明确要求？
2. 哪些要求属于原生自回归语言模型，哪些可迁移到分类从头训练？
3. 当前 C12 的 K-RWKV7 是完整原生模型还是冻结表示上的小型更新核？其实现遗漏是否会使当前运行无效？

## 决策边界

- 只使用 BlinkDL 官方仓库、固定提交本地快照及官方脚本事实。
- 不修改实验代码，不操作远端，不停止运行进程。
- 发现会使运行无效的阻断项时立即通知主代理。
