# LSPR24 使用论文调研计划

## 目标

系统核验真正使用 LSPR24 数据集的论文，提取任务、数据处理、基线、指标与提升幅度，并形成可追溯综述、原件与中文阅读笔记。

## 阶段

- [x] 阶段 1：读取仓库规则、RWKV 路线文档和文献工作流技能
- [x] 阶段 2：盘点本地 LSPR24 原件、笔记、索引与 Zotero 条目
- [x] 阶段 3：联网检索候选论文，区分真实使用与仅引用/提及
- [x] 阶段 4：下载并逐篇全文核验，记录表格或正文位置与可复算指标
- [x] 阶段 5：生成或更新中文阅读笔记、方向索引与 Zotero
- [x] 阶段 6：撰写综述，执行链接、数字和文件完整性自检

## 核心问题

1. 哪些公开论文实际用 LSPR24 训练、验证、测试或实质分析？
2. 每篇论文采用什么任务定义、样本单位、字段、切分、标签和预处理？
3. 每篇论文比较哪些基线，报告哪些指标，最佳结果相对哪个对象提升多少？
4. 哪些论文仅引用或提及 LSPR24，不能计入数据集使用证据？

## 决策

- 以原始论文、作者仓库、数据集官方页面和论文 PDF 为一级证据。
- 摘要或搜索片段只用于发现，不用于支持确定结论。
- 所有数字必须记录论文页码、表号或章节；可复算时同时报告绝对值、百分点增量与错误相对下降。
- 不访问实验最终测试，不修改实验代码。

## 错误与阻塞

- SSRN 官方 PDF 直链在网页访问返回 403，命令行连接超时；用户随后手动补充 `raw/papers/datasets/LSPR24/ssrn-6597680.pdf`，已完成全文核验。
- 论文公开代码主机 `gitlab.nlda.tech` 在沙箱内外均无法解析，正文未报告的训练／验证比例和实现级缺失值／归一化细节仍不可核验。
- OpenAlex 与 Crossref 对数据 DOI 和学位论文的引用覆盖不足；使用机构库与全文搜索补足。
- 仓库 `P0-NO-PRETTIER` 钩子禁止运行 Prettier，Markdown 格式化命令未执行；改用结构、YAML、链接和 Markdown 静态检查，不绕过仓库门禁。
- 首次 YAML 检查因 Ruby 未加载 `Date` 常量失败；补充 `-rdate` 后 5 个带前言的 Markdown 文件全部解析通过。
