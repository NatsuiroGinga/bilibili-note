# 可微树启发表格神经骨干审计计划

## 目标

依据《可微神经骨干替代 XGBoost 目标合同》，从本地全文与近期一手来源中筛选最多三个更接近 XGBoost 归纳偏置、同时端到端可微且可承受 LSPR23 约 1635 万流训练规模的候选，并为每个候选冻结可证伪的最小实验合同。

## 硬边界

- 只用 LSPR23 开发证据选择候选、容量、配方与机制；不得读取 LSPR24 追调。
- 必须从最终实体目标到骨干参数存在有限、非零梯度；冻结树分数外接神经层不算替代。
- 83 字段输入，不使用演习身份、标签派生字段、既有 IDS 输出或目标年度标签。
- 不写实验代码，不访问服务器，不启动或查询 GPU 任务。
- 技术结论只采用原论文、官方源码、官方模型卡或本地已核全文。
- 最多排序三个候选；不可端到端求导、20M 流不可承受、依赖目标标签或许可证不明者排除。
- 写入范围为本目录及确认有用且仓库缺失论文的 `raw -> wiki -> INDEX -> Zotero` 文献链。

## 核心问题

1. 哪些模型的可学习分裂、条件路由或检索邻域能提供接近提升树的局部、分段和交互归纳偏置？
2. 哪些机制能让实体级 CPA/ELP 或替代聚合的梯度真正回到 83 字段骨干？
3. 在 1635 万源年流与 2023 年实体分布下，候选的时间、显存、内存和吞吐是否可接受？
4. 树蒸馏是否只复制不可微教师，还是学生本身能够独立端到端训练并满足公平比较？
5. 哪些候选已有官方源码与清晰许可证，且可在不依赖目标标签的条件下复现？

## 预定制品

- `notes.md`：查询、全文、源码、许可证与筛选检查点。
- `literature-reviewer-evidence.md`：文献代理独占证据文件。
- `证据矩阵.md`：候选、排除项和证据等级。
- `候选与最小实验.md`：最多三个候选及可证伪实验合同。

## 验收

- 每个候选都有原论文、官方代码、许可证、参数/训练规模、83 字段适配、梯度路径、机制接口、预算、共同基线、完整指标和失败门。
- 明确区分设计可行、实验待证、实验支持与实验否决；本任务只能形成前两类。
- 报告本地查询数、外部查询数、全文数、D2/D3 数量、归档与 Zotero 状态。
- 只提交独占目录及本任务新增文献链，不夹带其他代理改动。

## 决策

- `XGBoost + CPA + ELP` 是性能目标；约 9 万参数仅作效率锚点。
- NODE、FT-Transformer、TabR/现代模型和树蒸馏只作为待筛类别，不预设入选。
- 文献代理模型为 `gpt-5.6-sol`、`effort=max`；主代理为 `gpt-5.6-sol`、`effort=high`。

## 错误与阻塞

- 文献子代理创建返回 `agent thread limit reached`；父代理确认自行执行，不重复分派或升档。
- 本地索引首次离线构建仍访问 Hugging Face 元数据并因 DNS 失败；加入官方离线环境变量后成功。
- arXiv:1907.06870 被外部题录错误映射为 DeepGBM，实际 PDF 为 LMA；按 raw 不可变规则保留并建笔记，正确 DeepGBM 另从 Microsoft Research 下载。
- 文献链提交后、增量重建前，`scripts.literature_search.evaluate` 因并发编辑短暂缺失；未修改或回滚生产代码，入口恢复后重建与自检成功。
