# 可微树启发表格神经骨干候选与最小实验

## 最终排序

1. **GRANDE：硬轴对齐梯度树集成。** 归纳偏置最接近 XGBoost，但原论文规模证据最弱，必须先过资源与直通梯度门。
2. **NODE：可微遗忘树集成。** 已有 1050 万训练样本先例，规模更接近 LSPR23；跨数据集稳健性和官方实现显存是主要风险。
3. **FT-Transformer：字段标记强表格神经回退。** 不称树启发，优势是 83 字段适配清楚、流数线性扩展、官方实现成熟。

三者当前均为**设计可行、实验待证**。没有实验支持或实验否决结论。

## 共同冻结合同

### 数据与权限

- 只读 LSPR23 的 16,353,511 条源年流及冻结实体不相交开发切分。
- 输入严格为 83 个合法字段；原始 IP 只作实体/分组键，不入模。
- 禁止读取 LSPR24 标签、特征统计、阈值或样本难度来选候选、容量、轮次或机制。
- 类别与数值预处理由 LSPR23 训练折拟合，验证折只变换；不做全量目标编码。

### 共同基线

- 性能目标：第三章冻结 `XGBoost + CPA + ELP`。
- 必报对照：XGBoost C00、XGBoost C11、全容量 MLP C00/C11、候选 C00/C11。
- 候选达到 B 级后才补 C01/C10，验证组合是否超过最佳单机制。
- 约 9 万参数只作为轻量效率锚，不压缩候选到相同参数后裁决模型族。

### 梯度与机制接口

- 骨干逐流表示为 `z_t=B_theta(x_t)`；不得先训练不可微树再仅优化外接层。
- CPA 接口为严格过去的因果聚合 `h_t=A_phi(z_1,...,z_t)`，不得读未来流或当前实体的目标标签。
- ELP 接口将逐流概率聚合为完整实体分数 `s_e=P_psi({p_t})`；实体损失必须能回到 `psi -> phi -> theta`。
- 首批真实前向/反向必须记录骨干梯度非零参数比例、有限值比例、梯度范数、树路由/注意力饱和和损失变化。

### 共同计算预算

- 单候选源年资格上限为 **4.5 GPU 小时**，依据当前路线已为 RWKV-7 预留的最高单候选工程预算；不得为新候选临时扩容。
- 峰值显存必须通过既有 `memory_admission_gate`，目标硬件合同为 32.6 GiB；本任务不访问服务器，因此具体安全余量由启动时门禁实测。
- 数据读取、训练、验证与完整源年评价全部计入墙钟；不得只报纯前向时间。
- 若真实批次投影显示完整源年运行超过 4.5 GPU 小时，直接判资源失败，不靠减少源年样本制造通过。

### 完整指标

- 逐流 AP、实体 AP、最大池化实体 AP。
- DR@`0.1%/0.5%/1%/2%/4%/8%` FPR。
- `0%–8%` 完整预算曲线、交叉点和有害区间。
- 参数量、训练时间、评价时间、GPU 小时、峰值显存、峰值内存、吞吐。
- 梯度可达性、非有限梯度次数、路由/注意力饱和、有效树或有效特征数。

## 候选一：GRANDE

### 参数与适配

- 来源参数：当前官方 PyTorch 示例深度 5、1024 棵、批量 256；论文原版与当前版必须用独立实现标签。
- 首选接口：每棵树叶输出和实例权重组成逐流表示，再接 CPA；ELP 对最终概率聚合。
- 不启用论文后新增类别/数值嵌入，避免同时改变骨干和输入表示。

### 最小实验

1. 真实 LSPR23 批次执行官方 1024×深度 5 前向/反向，验证直通梯度到分裂索引、阈值、叶值和实例权重。
2. 测峰值显存与吞吐，投影完整源年墙钟；任一资源门失败即停止，不先调性能。
3. 资源通过后运行 C00 源年资格；只有进入相对全容量 MLP 与 XGBoost 的多指标帕累托前沿才运行 C11。

### 失败门

- 任一核心参数无有限非零梯度；硬路由长期塌缩为常量特征；有效树比例接近零。
- 官方容量无法通过 32.6 GiB 门，或投影完整运行超过 4.5 GPU 小时。
- C11 未达到目标合同 B 级，或优势只来自单一指标而预算曲线存在未披露有害区。

## 候选二：NODE

### 参数与适配

- 论文默认：一层、2048 棵、深度 6、`entmax α=1.5`、QHAdam、5 检查点平均。
- 首选接口：最后一层树输出连接向量作为 `z_t`；CPA 与 ELP 保持同一实现。
- 83 字段无需额外离散化；训练折拟合分位数变换，验证折只应用。

### 最小实验

1. 用论文默认容量执行真实批次显存、吞吐、梯度和 entmax 稀疏度诊断。
2. 若默认容量资源失败，不以任意小模型否决 NODE；记录“官方容量不可执行”，停止本轮。
3. 资源通过后按 C00 -> C11 -> 必要时完整 2×2 的顺序运行。

### 失败门

- entmax 特征选择全密或全零、温度非有限、树叶利用率塌缩。
- 官方默认容量超共同资源门。
- 源年 C11 不进入 B 级，或跨折方向不稳且不能由检查点选择解释。

## 候选三：FT-Transformer

### 参数与适配

- 官方默认：3 块、宽度 192、8 头、注意力随机失活 0.2、前馈扩张 `4/3`、前馈随机失活 0.1、AdamW。
- 83 个字段各自形成 token；端口/协议等合法离散字段用训练折词表，数值字段用独立线性标记。
- `[CLS]` 输出为逐流 `z_t`，CPA 与 ELP 接口无需修改骨干内部注意力。

### 最小实验

1. 按官方默认只用 LSPR23 运行 C00，报告 83 token 固定注意力的吞吐与资源。
2. C00 进入帕累托前沿后运行 C11；若组合达到 B 级，再补完整 2×2。
3. 与现有全容量 MLP、论文配方 TabM 和表格 ResNet 分表比较，不把“Transformer”名称视为树归纳偏置。

### 失败门

- 资源超过共同上限，或逐流 AP、实体 AP 与预算曲线均未进入帕累托前沿。
- C11 只在高 FPR 局部改善、低 FPR 有害区超过 XGBoost 且用户不接受。
- 注意力对字段标记无区分，或最佳配方必须依赖 LSPR24 选择。

## 总停止门

- 连续三个候选均不能在 LSPR23 完整指标上进入相对 XGBoost 的帕累托前沿时，停止扩大树数、层数或模型族。
- 没有 B 级模型时保留 XGBoost，不削弱基线；蒸馏或冻结分数后的决策优化另立合同。
- 只有源年冻结后的最终候选才运行一次 LSPR24 描述性评价。
