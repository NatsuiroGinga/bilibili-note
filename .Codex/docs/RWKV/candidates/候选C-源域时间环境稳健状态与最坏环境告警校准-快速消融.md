# 候选 C：种子 42 快速消融计划

- **状态**：历史 R1 Q0 计划已冻结且不由文献任务追改；文献闭合后的后续消融见第7至10节
- **目标**：R1 Q0 检验源域稳定表示和最坏环境告警阈值；后续检验双层尾部风险状态与上下文尾部风险是否分别改善排序与固定总预算

## 1. 四变体

| 变体 | M1 稳定—私有状态 | M2 最坏环境校准 | 定义 |
| --- | --- | --- | --- |
| B0 | 否 | 否 | 因果 Transformer，源校准 pooled 阈值 |
| M1 | 是 | 否 | 双状态分解，仍使用 pooled 阈值 |
| M2 | 否 | 是 | B0 分数加最坏源环境阈值 |
| M1+M2 | 是 | 是 | 稳定状态加最坏环境阈值 |

该表的历史 M2 不改变连续分数，故 B0 与 M2 的 AP 及严格全局前 K 召回必须完全相同；若不同，说明评价实现或样本清单有错误。它不应再用“固定预算召回提高”作为独立支持门槛。

## 2. 共同合同与强基线

- 共同合同：LSPR23 训练／源验证／源校准，LSPR24 可见开发区冻结评价；2-IP 分组；最终 20% 不可见。
- 强基线：HGB、XGBoost、GRU、因果 Transformer、RWKV-7、Mamba、经验风险最小化、GroupDRO、CORAL／IRM 类源域多环境方法。
- 表征对照：只有环境不变损失、只有私有重构、无正交、随机时间环境。
- 阈值对照：pooled 分位数、平均环境分位数、最坏环境分位数、随机环境划分。

## 3. 指标

- M1 主指标：平均精确率、`AP/π`、宏平均 F1、环境分类器从稳定表示反预测环境的 AUC。
- M2 主指标：最坏源环境假阳性率、LSPR24 每百万流假阳性、固定每小时告警预算召回率、固定召回率下假阳性。
- 共同指标：Brier 分数、期望校准误差、吞吐、峰值显存。
- 困难分面：源环境、目标时间块、序列长度、恶意占比、时间密度和字段缺失率。

## 4. 可证伪门槛

1. M1 相对 B0 的目标开发平均精确率至少增加 `0.010`，且相对 GroupDRO 不低于 `-0.002`；稳定表示的环境反预测 AUC 应低于 B0 至少 `0.05`，但攻击分类 AP 不能因此下降。
2. M2 相对 pooled 阈值将最坏源环境假阳性率降低至少 20%，并在 LSPR24 可见开发区把每百万流假阳性降低至少 10%，召回率绝对下降不超过 5 个百分点。
3. 历史纯阈值 M1+M2 只可在冻结操作点检验告警率、假阳性和召回；其严格全局前 K 召回必须与 M1 相同。文献闭合后的 `M2-risk` 才使用“固定预算召回增加至少3个百分点”门槛。
4. 若组合只通过极端提高阈值获得低误报，或 M1 的环境 AUC 降低同时攻击 AP 明显降低，候选不晋级。
5. LSPR24 结果不得用于重新划分源环境或选择 (alpha,\beta)。

## 5. 算力与时长

- 单张 24—32 GiB GPU，模型 5M—15M 参数，`bf16`。
- 四个主变体各 2—4 GPU 小时；表征对照 6—10 小时；阈值对照只需 CPU 分钟级。
- 总计约 14—26 GPU 小时，加 1—2 CPU 小时完成分位数、自助区间和环境审计。

## 6. 结果解释边界

- 单种子只能改变优先级。
- 源环境有限样本控制不能写成 LSPR24 保证。
- 如果 M2 成功而 M1 失败，只能保留“告警校准”作为辅助实验，不能单独撑起第三章。
- 如果 M1 成功而 M2 失败，可把 M1 留作其他候选的机制部件，但本双机制候选被证伪。

## 7. 文献闭合后的后续四格

本节只定义 R1 Q0 结束后的新实验，不修改当前 `r1-source-environment-q0-seed42-v1` 配置、代码、概率制品或状态。

| 变体 | M1 双层风险状态 | M2 上下文尾部风险 | 连续评价分数 |
| --- | --- | --- | --- |
| N0 | 否 | 否 | 原始 RWKV-ERM 分数 |
| N1 | 是 | 否 | 双层风险训练的原始分数 |
| N2 | 否 | 是 | ERM 分数映射的因果 EVT 尾部风险 |
| N12 | 是 | 是 | M1 分数映射的因果 EVT 尾部风险 |

M1 快速选择器使用共同模型、批次、步数和源验证预算比较：`ERM`、`GroupDRO`、`V-REx`、环境内 `CVaR`、`max_e[(1-λ)R_e+λCVaR_ρ(L|e)]`。不在一个快速运行中同时搜索多组 `β/ρ/λ`；参数网格必须先在 LSPR23 源验证区冻结。

M2 分成两个身份：

- `M2-threshold`：pooled、最坏源环境、NP、目标经验分位、SPOT/DSPOT和置信序列阈值。它不改变排序，用于预算偏差、每百万流假阳性和冻结操作点召回。
- `M2-risk`：输出 `-log` 尾部超越概率或预注册分块预算分数；它改变跨块排序，才能比较固定总预算召回和归一化分数 PR-AUC。

## 8. 强基线和公平门禁

- 相同任务：Dijk 2024 RF 外部参照、Leoste 2025 RF/1D-CNN、Dijk 2026 OP-XGBoost与2-IP GRU/Transformer近协议实现。不得因字段、预算或身份元数据不同削弱它们。
- 神经共同预算：因果 Transformer、普通 RWKV-ERM、GroupDRO。
- 作者后续 Dijk 2024 GitHub 只作8万行示例复跑；固定提交 `496cc558713e8a5f46aa0b276b177a7d8835a217` 晚于论文且无LICENSE，不能称论文表8严格复现或直接复制为生产基线。
- 所有新变体共享样本身份、2-IP隔离、合法字段、步数、参数量级、源验证次数、目标前缀和最终区封存。

## 9. 新支持与失败门槛

1. M1 相对 RWKV-ERM 的目标开发平均精确率至少 `+0.010`，且相对 GroupDRO不低于 `-0.002`；最坏源环境风险不得恶化。
2. 真实时间环境必须优于打乱环境；否则“时间环境”解释被证伪。
3. `M2-threshold` 的 PR-AUC和严格全局前 K 召回必须逐样本一致；不一致先修正评价，不进入科研裁决。
4. `M2-risk` 在至少一个预注册总告警预算上召回绝对提高 `≥3` 个百分点，实际告警数在容差内，其他预算不系统性反向。
5. `N12` 必须超过 `max(N1,N2)` 的对应主指标或在预注册困难分面方向一致；否则不得声称协同。
6. 目标前缀污染使 EVT 参数、预算或排序对小扰动不稳定时，M2不晋级；不得用目标标签重选阈值、窗口或尾部起点。

## 11. 结果解释边界补充
