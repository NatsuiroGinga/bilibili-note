# 候选 D：种子 42 快速消融计划

- **状态**：计划，未运行
- **目标**：验证重复后缀证据和正常预测残差是否覆盖不同错误子集，并产生组合收益

## 1. 前置门禁

1. LSPR23 数据与共同字段合同通过；2-IP 序列冻结。
2. 官方 RWKV-8／ROSA 源码提交、许可证、接口和最小合成复现收据固定。
3. 行为码禁止身份字段；码本利用率、身份反预测 AUC 和年度反预测 AUC 先通过审计。
4. 正常预测训练样本必须来自 LSPR23 训练区的连续正常历史；验证和 LSPR24 不进入训练。

## 2. 四格矩阵

| 变体 | M1 后缀记忆 | M2 正常残差 | 定义 |
| --- | --- | --- | --- |
| B0 | 否 | 否 | 因果 Transformer 分类器 |
| M1 | 是 | 否 | B0 加冻结行为码与 ROSA 后缀监督头 |
| M2 | 否 | 是 | B0 加正常预测残差支路 |
| M1+M2 | 是 | 是 | 两支信任门控噪声或组合 |

诊断对照：固定 n-gram、最近邻后缀、打乱行为码、随机码本、普通自编码残差、用全部源样本训练生成器、线性学习型融合。

## 3. 强基线

- HGB、XGBoost、GRU、一维卷积神经网络；
- 因果 Transformer、普通 RWKV-7、Mamba；
- PLM-NIDS 式正常困惑度；
- 固定 n-gram／哈希后缀和最近邻检索；
- ROSA 单独、正常预测单独与完整组合。

## 4. 分面与指标

- 主指标：平均精确率、`AP/π`。
- 部署指标：每百万流假阳性、固定告警预算召回率、宏平均 F1、校准误差。
- M1 分面：源训练中可见的重复行为后缀、匹配长度、码本频率、罕见码。
- M2 分面：低后缀匹配、正常残差分位数、跨年新码、序列冷启动。
- 互补性：两支真阳性集合的 Jaccard、各自独占检出率、组合误报并集。
- 效率：ROSA 固定状态字节数、码本大小、吞吐、峰值显存。

重复／非重复分面定义必须只由 LSPR23 冻结码本和匹配规则产生，不能依据 LSPR24 标签重定义。

## 5. 可证伪门槛

1. M1 在预登记的高后缀匹配分面相对 B0 和最佳 n-gram 的平均精确率至少增加 `0.020`，总体至少不下降超过 `0.003`。
2. M2 在低后缀匹配或跨年新码分面相对 B0 和普通自编码残差至少增加 `0.010`，并且每百万流假阳性不增加超过 20%。
3. M1 与 M2 的独占真阳性均应占各自真阳性的至少 5%，否则两支高度冗余。
4. M1+M2 总体平均精确率相对 B0 至少增加 `0.015`，相对最强单机制至少增加 `0.005`；固定告警预算召回率必须同步提高。
5. 打乱行为码后 M1 若不下降，说明后缀结构未被使用；用攻击样本训练生成器若反而更好，只能说明 M2 的“正常模型”假设不成立。

## 6. 算力与时长

- 单张 32 GiB 以上 GPU；码本 (K\in\{64,128,256\}) 只在 LSPR23 源验证选择。
- 编码器与码本 4—8 GPU 小时；四格训练 10—18 GPU 小时；诊断对照 6—10 GPU 小时。
- 总计约 20—36 GPU 小时；ROSA 合成复现和码本审计另需 2—4 CPU／GPU 小时。
- 这是四候选中工程不确定性最高的估算，若官方内核不支持当前硬件，应先停止而非重写一个未经等价证明的“近似 ROSA”。

## 7. 停止条件

- 合成 ROSA 官方样例无法复现；
- 行为码身份反预测 AUC 高于预注册阈值 `0.60`；
- 码本有效利用率低于 25%；
- M1 不优于 n-gram，或 M2 不优于普通残差；
- 完整组合不超过最强单机制；
- 任何 LSPR24 最终区访问。

前五项使候选不晋级；最后一项使整次实验无效。
