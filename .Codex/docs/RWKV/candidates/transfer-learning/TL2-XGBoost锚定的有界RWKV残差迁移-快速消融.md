# TL2 快速消融：XGBoost 锚定的有界 RWKV 残差

- **状态**：实验待证，P1 种子 42 Q0
- **前置**：TL1 不晋级；不得与 TL1 并行消耗额外选型机会

## 1. 变体

| 变体 | 树锚 | RWKV 残差 | 幅度界 | 顺序界 | 目的 |
| --- | --- | --- | --- | --- | --- |
| `B0_XGB` | 是 | 无 | 无 | 无 | 主锚 |
| `B1_RWKV` | 无 | 主分类器 | 无 | 无 | 历史弱序列对照 |
| `C0_LEAF_MLP` | 是 | 叶多层感知机 | 有 | 有 | 非序列容量对照 |
| `U1_UNBOUNDED` | 是 | 是 | 无 | 无 | 无界负迁移对照 |
| `M1_MAGNITUDE` | 是 | 是 | 有 | 无 | M1+幅度 |
| `M1_M2_ORDERED` | 是 | 是 | 有 | 有 | 完整方案 |
| `D1_SHUFFLED` | 是 | 是 | 有 | 有 | 打乱合法序列顺序 |

所有变体共享 XGBoost、交叉拟合折、参数量级、训练步数、目标前缀和评价成员。

## 2. 冻结选择

- K 折时间交叉拟合折、叶嵌入维度、RWKV 宽深和训练步数在 LSPR23 固定。
- `B、gamma、gamma'` 只在 LSPR23 时间伪迁移网格选择；主目标是伪目标 PR-AUC，约束高间隔错误翻转率。
- 目标前缀只计算无标签支持/扰动稳定性，不能比较多个配置或早停检查点。
- 目标开发标签在全部变体概率封存后一次性连接。

## 3. 指标

- 目标 PR-AUC、三种固定预算召回、恶意/宏 F1、Brier、ECE。
- 残差幅度/饱和、支持外回退、锚分数分层的翻转率。
- 高间隔方向违反率、近并列重排率、Top-K 替换、打乱前后差异。
- 每变体训练/推理时间、峰值显存、参数量。

## 4. 裁决

- 完整方案 PR-AUC `≥0.043902589823969644` 且预算不退化才申请多种子。
- `M1_MAGNITUDE-B0_XGB ≥0.005`，否则残差没有主贡献。
- `M1_M2_ORDERED-U1_UNBOUNDED ≥0.002` PR-AUC；或高间隔错误翻转下降至少 50%、PR-AUC 不低于无界版 `0.001` 以上。
- `D1_SHUFFLED` 与完整方案逐样本/指标无明显差异时，RWKV 序列主张淘汰；若叶多层感知机相当或更好，优先低复杂度模型。
- 完整方案不高于 XGBoost、预算恶化、残差饱和或目标标签参与选择：不晋级或实验无效。

## 5. 资源与输出

RTX 5090 预计 8–12 GiB、8–16 GPU 小时。每变体独立运行身份、概率封存、输入/模型哈希、翻转诊断和资源收据。结果只允许标“实验待证下的 Q0 不晋级/弱信号/申请正式验证”。
