## 1. 实验问题与结论边界

本实验只回答三个可证伪问题：

1. 漂移触发的单步／累计影响预算、冻结和回退，是否优于无状态控制、普通漂移门值和仅单步裁剪？
2. 隔离双参照及其有效质量晋升，是否优于单一可变正常状态，并在限制污染后果的同时保留困难新正常？
3. 两个机制组合是否超过接收因果 Transformer、最强既有更新核和最佳单机制？

种子 42 的任何正结果只允许表述为“进入多种子验证”或“提高候选优先级”，不能写成实验支持的论文结论。负结果按本文件门槛触发重构或淘汰，不增加公式挽救。

## 3. 接收骨干、更新核与完整方法

### 3.1 核心公平矩阵

| 展示名 | 内部短键 | 接收 Transformer | 既有更新核 | 有界状态控制 | 可信双参照 | 目的 |
| --- | --- | ---: | --- | ---: | ---: | --- |
| 接收因果 Transformer | `RX-TR` | 是 | 无 | 否 | 否 | 无递归适应的接收基座 |
| DeltaNet 更新核 | `K-DELTA` | 是 | DeltaNet | 否 | 否 | 原始／并行 Delta 强对照 |
| 普通 RWKV-7 更新核 | `K-RWKV7` | 是 | RWKV-7 | 否 | 否 | 广义状态演化强对照 |
| 门控 DeltaNet 更新核 | `K-GDELTA` | 是 | Gated DeltaNet | 否 | 否 | 全局遗忘加定向改写强对照；建议完整方法承载核 |
| 仅漂移触发有界状态控制 | `C12-CTRL` | 是 | Gated DeltaNet | 是 | 否 | 机制一独立增量 |
| 仅可信双参照校正 | `C12-DREF` | 是 | Gated DeltaNet | 否 | 是 | 机制二独立增量 |
| 完整漂移触发有界状态控制与可信双参照校正 | `C12-FULL` | 是 | Gated DeltaNet | 是 | 是 | 组合增量与候选主结果 |

DeltaNet、普通 RWKV-7 和门控 DeltaNet只替换更新核，不得在运行名或结论中写成 C12 创新。若源验证预检显示门控 DeltaNet 无法在参数和数值门禁下运行，必须在读取任何 LSPR24 开发标签前，把完整方法承载核一次性改为三个核中源验证最强且可运行者，并形成冻结收据；不得按目标结果挑核。

### 3.2 公平预算

- 第一阶段用共同预算训练一次接收因果 Transformer 与源评分器，随后冻结其表示；所有变体从同一冻结权重开始第二阶段。
- 第二阶段可训练参数差异不超过 1%；接收基座通过参与训练与推理的补偿头匹配更新核和控制器参数，禁止用不可训练空参数伪造匹配。
- 第一阶段和第二阶段各自固定训练步数；第二阶段的优化器、学习率调度、早停规则、混合精度、梯度累积和源训练有效流预算相同。
- 更新核统一使用 6 个头、每头完整 `32×32` 矩阵状态；所有核用相同状态容量和序列重置规则，不以低秩近似削弱既有核。
- 可信信号需要的冻结源评分器对所有适应变体共同提供，并在参数、显存、吞吐和延迟表中单列，不得隐去。
- 所有目标侧适应都只允许读取同一 `target-prefix`；目标前缀结束后冻结全局参照和晋升系数。

## 4. 必做机制消融

下表中的变体均从 `C12-FULL` 做单项或逐级删除，保持同一门控 DeltaNet 承载核与双参照设置；短键只能作为展示名后的附加标识。

| 展示名 | 内部短键 | 与完整方法的唯一差异 | 对应裁决 |
| --- | --- | --- | --- |
| 可信权重更新但无漂移控制 | `ABL-NODRIFT` | 用源侧固定更新预算替代漂移触发预算；保留相同更新次数匹配 | 排除“普通可信门即可”的解释 |
| 仅漂移单步影响预算 | `ABL-STEP` | 只有单步范数裁剪，无累计影响账本 | 检验单步预算 |
| 漂移单步与累计影响预算 | `ABL-STEP-CUM` | 增加累计账本，但无检查点回退 | 检验累计预算独立增量 |
| 有界预算但无冻结回退 | `ABL-NO-ROLLBACK` | 保留两级预算；超过预算时只截断剩余步长，不执行冻结或恢复检查点 | 检验可执行动作而非连续门值 |
| 单正常参照直接校正 | `ABL-SINGLE-REF` | 源正常状态可被目标伪正常直接递归改写，无候选隔离与晋升 | 检验双参照隔离 |
| 双参照但无有效质量 | `ABL-NO-EQ` | 候选样本等权；只保留时间块容量上限 | 检验可信有效质量 |
| 完整漂移触发有界状态控制与可信双参照校正 | `C12-FULL` | 单步＋累计预算、冻结／回退、双参照、有效质量和限量晋升全部启用 | 完整组合 |

为确认两个机制的独立价值，`C12-CTRL` 和 `C12-DREF` 不能由上述梯度阶梯代替。若完整方法未超过两个单机制，则组合主张直接失败。

## 6. 污染、时序与困难新正常控制

### 6.1 五个必做场景

| 场景展示名 | 内部短键 | 构造方式 | 要回答的问题 |
| --- | --- | --- | --- |
| 自然目标前缀 | `SC-NATURAL` | 原始 `target-prefix` 顺序，标签对训练器、校正器和评价器均不可见 | 自然年度冷启动表现 |
| 时间块置换前缀 | `SC-BLOCK-PERM` | 以源侧冻结块长做固定哈希置换，块内顺序不变，不读取标签 | 晋升是否依赖真实跨块持续性 |
| 更新数匹配随机旁路 | `SC-RANDOM-BYPASS` | 从同一前缀用冻结哈希随机选择与完整方法相同数量的候选更新，绕过可信质量排序 | 收益是否只来自降低更新数量 |
| 低熵伪装污染 | `SC-LOW-ENTROPY` | 从 LSPR23 源验证恶意序列中预先选择高源正常概率、低熵且扰动一致的合法共同字段序列，形成只读诊断覆盖层 | 高置信门被绕过时，影响预算能否限制后果 |
| 等总量连续突发污染 | `SC-BURST-EQUAL` | 使用与低熵或随机污染完全相同的恶意序列和总量，只把均匀位置改成连续时间块 | 时间集中是否放大污染及块封顶能否抑制 |

污染覆盖层不得修改共同缓存。注入单元是完整源验证 `2-IP` 序列，不拆流、不复制目标流；以等长度序列替换目标前缀诊断位置，保持总流数、序列长度分布和训练／评价预算不变。相对时间采用被替换位置的合法时间骨架，字段值仍使用冻结的 77 字段变换。每个覆盖层保存来源样本哈希、位置哈希、污染比例和 `final_accessed=false` 收据。

污染比例预注册为 `0%/1%/5%/10%/20%`。低熵、随机和连续突发三类使用相同恶意总量；任何比例不得根据 LSPR24 指标更改。LSPR24 目标前缀原生标签始终不读取，已知污染身份只来自 LSPR23 源验证覆盖层。

### 6.2 低熵和连续突发的状态诊断

每个污染场景至少报告：

- 覆盖层恶意流的平均、95 分位和最大有效质量；
- 恶意有效写入质量占总有效质量的比例；
- 相对 `SC-NATURAL` 干净轨迹的主状态、候选参照和激活参照偏移；
- 单步影响、累计账本、预算触顶率、冻结率、回退次数和检查点年龄；
- 污染段结束后恢复到干净轨迹 95% 包络所需的流数与时间；
- 目标开发 PR-AUC、每小时误报、ECE 和源验证遗忘。

高置信、低熵或扰动一致只作为攻击构造条件，不作为“污染安全”解释。只有实际状态后果受限且主任务指标未被明显牺牲，才允许保留“影响受控”的候选表述。

### 6.3 困难新正常独立分面

目标开发预测全部封存后，评价器才使用标签定义困难新正常：真实良性流同时满足源评分超过源冻结告警阈值，且漂移量高于源验证正常流 95 分位。该定义、阈值和代码在连接 LSPR24 标签前冻结。

必须单列报告：

- 困难新正常正确接纳率和每小时误报；
- 困难新正常在源锚、候选参照和激活参照下的距离分布；
- 救援通道有效质量、保留／拒绝／晋升数量及首次晋升时间；
- 普通目标良性、困难新正常和恶意流三类的状态影响分布。

只降低整体更新率、拒绝率或污染吸收而显著降低困难新正常正确接纳率，不支持双参照机制。

## 7. 训练、预测与评价顺序

1. 只用 `source-train` 训练全部模型；源侧扰动、预算可行性和分类目标使用相同批次。
2. 只用 `source-validation` 完成早停、温度、检测阈值、漂移阈值、预算、块长、有效质量和晋升门槛冻结。
3. 输出冻结收据后，全部变体以相同顺序消费 `target-prefix`。当前流必须先预测、后更新；全局候选参照只在前缀内更新，并只汇总不含身份的质量、违规率和回退率作为年度控制先验。
4. 前缀结束后冻结候选检查点、晋升系数和年度控制先验。目标开发每个 `2-IP` 序列重置矩阵状态、账本和检查点，只用年度先验初始化空质量历史；当前位置的受控状态更新只能影响同块未来位置。
5. 目标开发预测、状态诊断、阈值和运行配置全部持久化并关闭写入后，评价器才连接标签。
6. 污染场景复用已训练模型，不重新训练；每个场景从同一源锚、参数和初始状态开始。
7. 最后 20% 在整个流程中不可寻址。任何运行目录出现最终区路径、成员、计数或哈希均判无效。

## 8. 指标与统计

### 8.1 主任务指标

- **主指标**：目标开发逐流 PR-AUC，也报告 `PR-AUC / prevalence`。
- **阈值指标**：宏平均 F1、恶意类 F1、精确率、召回率、每百万良性流误报、每小时误报、固定 100 次/百万告警预算下召回率。
- **校准指标**：Brier 分数、15 个等频箱的期望校准误差。
- **效率指标**：可训练参数、总驻留参数、训练墙钟、峰值显存、有效流吞吐、每百万有效流推理时间、批量吞吐和单序列延迟。
- **状态指标**：单步／累计影响、恶意有效写入质量、源锚／候选／激活参照偏移、冻结／回退率、恢复时间和候选晋升率。
- **困难分面**：困难新正常正确接纳率、普通良性误报、源验证见过／未见过 `2-IP` 对、序列长度和活动时间分层。

### 8.2 统计

- 按 `2-IP` 序列执行 10,000 次配对非参数自助重采样，统计种子固定为 42。
- 报告 PR-AUC、阈值指标、污染状态指标和困难新正常指标的 95% 分位数区间。
- 同一模型不同污染覆盖层使用相同重采样索引；不同变体使用同一序列清单作配对比较。
- 单种子自助区间只描述样本层不确定性，不能替代种子 42/43/44 的训练随机性。

## 10. 预注册支持、重构与淘汰门槛

### 10.1 进入多种子验证

必须同时满足：

1. `C12-FULL` 相对 `RX-TR` 和三种既有更新核中的最强者，PR-AUC 配对差值均为正，且 95% 自助区间下界大于 0。
2. `C12-CTRL` 与 `C12-DREF` 相对同承载核的 PR-AUC 点估计均为正；每个单机制还至少在每小时误报、ECE、困难新正常正确接纳率或对应状态诊断中有一项 95% 区间方向有利。
3. `C12-FULL` 相对最佳单机制的 PR-AUC 配对差值 95% 区间下界大于 0。
4. 相对 `ABL-NODRIFT` 和 `ABL-NO-ROLLBACK`，完整控制器在低熵伪装与连续突发两种场景中均把最大状态偏移或恶意有效写入质量至少降低 20%，且自然前缀 PR-AUC 不下降超过 0.005。
5. 相对 `ABL-SINGLE-REF`，完整双参照将困难新正常错误拒绝率相对降低至少 10%，同时低熵和突发污染的恶意有效写入质量不增加。
6. 峰值显存不超过 20 GiB；相对同核基线的推理延迟增量不超过 15%。若只因工程实现未达效率门槛，可进入一次工程重构，但不能先宣称方法胜出。

此处“进入多种子验证”不等于“已支持”。正式论文主张还需要冻结种子 42/43/44、置信区间、效率与最终测试。

### 10.2 允许一次重构

满足以下任一情形时标记“快速证据不足，允许一次实质重构”：

- 完整方法和两个单机制点估计方向正确，但任一关键区间跨 0；
- 完整方法超过接收基座但未超过最强既有更新核；
- 影响控制明显降低污染后果，但困难新正常错误拒绝率恶化超过 10%；
- 双参照改善困难新正常，但低熵或突发污染的状态偏移增加；
- 性能门通过但显存或延迟门失败，且可在不改数据、字段、状态维和样本预算的条件下修复。

重构必须由新增运行证据决定，只能调整控制阈值来源、生命周期动作或实现效率；不得改变目标比例、最终区、字段、基线能力或门槛制造提升。

### 10.3 淘汰候选或删除主张

满足以下任一情形即淘汰对应主张：

- `C12-FULL` 的 PR-AUC 点估计不高于最强既有更新核，或不高于最佳单机制；
- 完整控制器不优于“漂移只控制门值”或仅单步预算；
- 双参照不优于单参照，或主要通过普遍拒绝更新降低污染；
- 低熵伪装或等总量连续突发使恶意有效写入、状态偏移或恢复时间没有可观测上限；
- 更新数匹配随机旁路达到相同结果，说明可信有效质量没有独立价值；
- 任何变体读取 LSPR24 前缀标签、未来观测、目标最佳阈值、最终 20% 或不同样本／字段；该运行直接无效，不用于候选存废。
