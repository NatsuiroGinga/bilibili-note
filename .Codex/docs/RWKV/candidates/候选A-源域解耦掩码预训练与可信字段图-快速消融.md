# 候选 A：种子 42 快速消融计划

- **状态**：计划，未运行
- **目的**：只判断 M1、M2 是否各有独立信号以及组合是否值得进入三种子正式矩阵
- **禁止**：不读取 LSPR24 最终 20%；单种子结果不得写成论文结论

## 1. 前置门禁

1. LSPR23 压缩包完成大小、MD5、压缩完整性和内部清单验收。
2. 冻结 LSPR23/LSPR24 共同合法字段、单位、缺失规则和 2-IP 序列清单。
3. 归一化器、词表、掩码分布、早停与阈值全部只由 LSPR23 拟合。
4. 四变体共享同一 `sample_id`、字段预算、序列长度 128、参数上限、监督步数与源验证区。

## 3. 强基线

- HGB、XGBoost；
- 一维卷积神经网络或 GRU；
- 参数匹配的普通因果 Transformer；
- 普通 RWKV-7、Mamba；
- 若成本允许，Hao 式“组独立预训练+静态图”作为最接近方法基线。

全部基线使用相同输入字段和 2-IP 序列；不得因模型不同改变样本或目标年度预处理。

## 4. 指标

- **主指标**：平均精确率、平均精确率提升倍数 `AP/π`。
- **辅助指标**：宏平均 F1、精确率、召回率、ROC-AUC、Brier 分数、期望校准误差。
- **部署指标**：每百万流假阳性、固定每小时告警预算召回率、吞吐、峰值显存、总训练时长。
- **困难分面**：时间密度四分位、序列长度、缺失率、字段环境偏差、恶意占比、源年度罕见模式。
- 置信区间采用序列级 10,000 次自助法；它不替代多种子。

## 5. 可证伪门槛

候选只有同时满足以下条件才进入正式矩阵：

1. M1 相对 B0 的跨年平均精确率绝对增加至少 `0.005`，或在预登记的高环境偏差分面增加至少 `0.010`，且总体不下降超过 `0.002`。
2. M2 相对 B0 在平均精确率或固定告警预算召回率上有正增量；并优于静态图和打乱状态两个诊断对照。
3. M1+M2 的平均精确率相对 B0 增加至少 `0.020`，且相对最强单机制增加至少 `0.005`。
4. 完整模型的序列级自助差值区间下界大于 0；若只差极小量，则保留为弱证据而不晋级。
5. 推理吞吐不得低于 B0 的 70%，峰值显存不得超过 B0 的 1.5 倍；否则需以明显效果换取成本并单独裁决。

任一单机制不满足条件 1 或 2，或组合不满足条件 3，即否决对应机制或组合；不得通过读取 LSPR24 标签重选字段组、阈值或图结构。

## 6. 算力与时长估算

- **硬件**：单张 32 GiB 以上 NVIDIA GPU，`bf16`；CPU 负责 Parquet 列裁剪和序列清单读取。
- **参数量**：目标 5M—15M；序列长 128，隐藏维不超过 384，层数不超过 6。
- **估算**：普通掩码预训练 4—6 GPU 小时；四格监督微调各 2—4 小时；诊断对照 4—8 小时，总计约 16—30 GPU 小时。
- 该时长是基于 Dijk 级模型规模的工程估算，不是当前服务器实测；正式启动前必须用固定批数做吞吐探针。
