# 候选 B：种子 42 快速消融计划

- **状态**：计划，未运行
- **目标**：验证真实时间衰减和可信频谱支路是否提供不同且可组合的跨年信号

## 1. 四格主矩阵

| 变体 | M1 连续时间状态 | M2 可信频谱 | 说明 |
| --- | --- | --- | --- |
| B0 | 否 | 否 | 因果 Transformer，使用离散位置与相同合法字段 |
| M1 | 是 | 否 | Transformer 加连续时间 RWKV-7 状态旁路 |
| M2 | 否 | 是 | Transformer 加因果频谱有界残差 |
| M1+M2 | 是 | 是 | 完整候选 |

诊断对照：普通离散 RWKV-7 状态、Time-LSTM／GRU-D、无信任频谱、打乱频率相位、非因果居中频谱（仅用于证明其违规，不进入主成绩）。

## 2. 共同合同

- LSPR23 训练和源验证；LSPR24 可见开发区只评价。
- 2-IP 分组、最长 128 流，IP 不输入；(Delta t) 由流开始时间计算。
- 四格共享字段、序列、参数量容差 ±5%、监督步数、优化器、源验证调参次数。
- (H\in\{16,32,64\}) 只在 LSPR23 源验证区选择一次；不得用 LSPR24 选择频谱窗口。

## 3. 强基线

HGB、XGBoost、卷积／GRU、Time-LSTM 或 GRU-D、因果 Transformer、普通 RWKV-7、Mamba、FRWKV 式无信任频谱支路。所有模型共享同一序列清单和变换。

## 4. 指标与困难分面

- 主指标：平均精确率、`AP/π`。
- 次指标：宏平均 F1、精确率、召回率、每百万流假阳性、固定告警预算召回率、Brier 分数、期望校准误差。
- 时间困难面：(Delta t) 中位数／方差四分位、序列时间跨度、流量密度跨年比值。
- 频谱困难面：谱集中度、缺失率、抖动、序列长度。
- 效率：每秒流数、峰值显存、每百万流推理秒数。

## 5. 可证伪门槛

1. M1 必须相对 B0 在高时间密度变化分面增加平均精确率至少 `0.010`，且总体平均精确率至少增加 `0.005`；同时优于离散 RWKV 状态。
2. M2 必须相对 B0 在高谱集中、低缺失的预登记分面增加至少 `0.010`，并显著优于相位打乱与固定信任门；总体下降不得超过 `0.002`。
3. M1+M2 必须相对 B0 总体增加至少 `0.015`，相对最强单机制增加至少 `0.003`，且固定告警预算召回率不下降。
4. 若完整模型的增益只来自某一极小分面，或使用频谱后每百万流假阳性增加超过 20%，不晋级。
5. 推理吞吐不得低于 B0 的 65%；若 rFFT 成为主要瓶颈，先淘汰 M2，不用渐近复杂度辩解实测失败。

## 6. 算力与时长

- 单张 32 GiB 以上 NVIDIA GPU，5M—12M 参数，`bf16`。
- 每个主变体预计 2—4 GPU 小时；四格 8—16 小时；诊断对照与密度／频谱分面 4—8 小时。
- 总计约 12—24 GPU 小时；时间序列预处理预计 1—3 CPU 小时。均为估算，正式启动前做固定 200 批吞吐探针。

## 7. 停止条件

- 连续时间分支在源验证与目标开发均不优于离散 RWKV；
- 频谱相位打乱后成绩不降，说明模型未使用有意义的频谱结构；
- 完整组合不超过最强单机制；
- 任一变体访问或间接拟合 LSPR24 最终区。

触发前三项时记录为候选不利证据；触发最后一项时整次实验无效。
