# 跨年度实体级评价与决策层适应 候选方案册

- **日期**：2026-08-12
- **路线**：`RESEARCH_ROUTE=RWKV`
- **状态**：`实验待证`。本文件是后续实现代理的自包含交接包，不是实验结果、论文结论或方法冻结。
- **唯一数据集**：LSPR 体系（LSPR23 源年度 + LSPR24 目标年度）。不得混入 GeNIS、TQH-C2、UGR'16 或任何第三数据集。

  本方案改的是**评价单元与决策粒度层**，依据是三个独立观测（见 §1.2）。

## 1. 结论与范围

### 1.1 一句话

**把 LSPR 跨年度 C2 检测的评价单元从逐流改为受保护实体，主指标改为固定告警预算下的实体级召回与检出时延；
方法上不新造机制，只把 Känzig 2019 与 Gehri 2023 已发表但未形式化的两个做法补完并迁移到公开数据。**

### 1.2 三个指向同一层的独立观测

| 来源 | 逐流 / 逐窗 | 实体级 | 证据等级 |
| --- | --- | --- | --- |
| Känzig 2019 §5.A（LSPR 方法学源头） | 表 IV LS18-tuned P `0.99` / R `0.90` | 30 分钟窗口内识别 `10/12` 台 C&C 服务器 | 全文已核验 |
| Gehri 2023（私有 Locked Shields LS21B） | F1 `0.185`、召回 `0.114` | 检出 `33/39` 台主机，误报 `119/3,185` | 全文已核验 |
| **本课题 A 线实测**（LSPR24 同年） | 窗口召回 `0.9274` | 事件召回 `0.5326` | 本课题制品 |

同一现象出现三次，**其中一次是本课题自己测出来却当成缺陷的**。

| 正确 | 不允许 |
| --- | --- |
| 把源头论文的附加实验形式化为完整评价协议 | 首次提出实体级评价 |

## 2. 任务定义

### 2.1 实体与聚合

令受保护实体 `e` 由冻结的实体键定义（首选源 IP；`2-IP` 无向密钥化分组作为预注册备选，二者不得混入同一比较表）。
逐流分数 `s_f` 由冻结检测器给出。实体分数为预注册聚合：

\[
S_e^{(n)} = \text{第 } n \text{ 大的 } \{s_f : f \in e\},\qquad n \in \{1, 5, 10, 100\}
\]

`n=1` 即 max 聚合。`n` 取值集合沿用 Gehri 2023 的阈值设定，**在看到目标年度结果前冻结**。

### 2.2 主指标

\[
\text{DR}(B) = \frac{|\{e : y_e = 1,\ S_e^{(n)} \ge \eta(B)\}|}{|\{e : y_e = 1\}|}
\]

其中 `η(B)` 由**实体级**误报预算 `B` 确定：单位时间内允许告警的良性实体数。
同时报告检出时延：从实体首个可观测恶意流到该实体首次越界的时间。

**逐流 AP 仍必须报告**，用途是确认协议对齐（见 §6.1），不是主指标。

### 2.3 与已被否决方向的区别

| 已否决 | 否决依据 | 本方案的不同 |
| --- | --- | --- |
| M1 证据累积 | 漏检多窗事件成员窗分数 p75 = `0.0194`，模型根本没给证据 | 不做时序累积，做**跨流的实体内聚合**，聚合对象是不同流而非同一实体的连续窗 |
| M2 预算分配 | 增益 95% 来自阈值标定，冻结迁移 fp 超标 `309` 倍 | 预算分配不作为机制主张；阈值重标定作为**已知的次年小样本适应**单列，并强制报告冻结迁移下的失效 |
| 候选 B / C12 / R1 / TL1 | 均在表示层 | 不改表示，冻结检测器 |

## 4. 候选机制（全部来自他人已发表工作）

### M1：时间无关特征筛选（Gehri 2023）

用 RFE + 单特征交叉验证剔除时间依赖特征，得到跨年度稳定特征子集。

**已发表依据**：Gehri 2023 的 Generic-20 特征模型把跨环境 F1 从 `0.007–0.215` 提升到 `0.638–0.993`（表 V）。
**独立旁证**：Leoste 2025 实测含 IAT 特征时 CNN F1 `18.42%` / RF `18.41%`，去掉后降为 `13.78%` / `2.20%`——
**方向不一致**，说明特征时间敏感性是主导因子而非模型容量。

### M2：实体级聚合与固定告警预算（Känzig 2019 §5.A 形式化）

把 §2.1 的聚合与 §2.2 的预算曲线实现为完整协议，**并补齐源头论文缺失的实体级误报侧**。

### M3：目标前缀无标签阈值重标定（Dijk 2026 自陈未做）

只用 LSPR24 前 `10%` 无标签前缀的分数分布重定阈值，不使用任何目标标签。

**已发表依据**：Dijk 2026 表 4 显示同族配置的次年 AP 在 `0.027` 到 `0.7` 之间震荡，说明选择准则本身有大量空间。
**已知风险**：本课题 E5 实测「冻结迁移」失效（前半标定应用到后半，fp 超标 `309` 倍），
因此 M3 必须**同时报告同期标定与冻结迁移两种口径**，不得只报有利的那个。

所有变体共享字段预算、样本身份、时间切分、训练预算与统计脚本。

| 编号 | 变体 | 作用 |

## 6. 门禁与否决标准（**预注册，实现前写入配置，跑完不得修改**）

### 6.1 协议对齐门（先决条件）

`B0` 的 LSPR23→24 逐流 AP 必须落在 `0.2416 ± 0.05`（Dijk 2026 表 5 的 XGBoost 值）。

**不通过即停止**：说明本课题的数据切分、字段预算或标签口径与 Dijk 2026 不可比，
后续任何"超越"主张都无意义。此时先做协议差异审计，不进入 M1/M2/M3。

### 6.2 主门禁

| 判据 | 阈值 | 结论 |
| --- | --- | --- |
| 实体级召回 @ ≤`4%` 实体 FPR | ≥ `0.50` | 决策粒度层有效，方向成立 |
| 实体级召回 @ ≤`4%` 实体 FPR | < `0.20` | **失效在表示层，Gehri 与 Känzig 机制均不可迁移，方向作废** |
| 落在 `0.20`–`0.50` | — | 部分有效，须报告并缩小主张 |

### 6.3 统计口径（**强制**）

- 一切比较使用**以实体为簇的配对自助**，报 `Δ` 的 `95%` 区间下界，不用各自边际值。
- 本课题 E1 实测：端点簇自助半宽 `0.2346`，事件簇仅 `0.0253`，**有效独立样本量约 `113` 而非 `1519`**。
  论文中必须显式披露该口径，禁止用流级样本数虚增统计效力。
- 三个种子 `42/43/44`，报原始值、均值、离散性与置信区间。

## 7. 理论产出（本方案的原创部分）

机制全部来自他人，**原创性在协议与理论**：

- **定理 A-1**：逐流召回不能确定实体级召回，给出背包型紧界，无分布假设。
  数值自洽已验：`0.01` 档区间 `[0.1435, 0.9961]` 含本课题实测 `0.5326`。
- **命题**：给定实体级告警预算，最优阈值分配与均匀分配的 gap 下界。
- **推论**：检出时延与告警预算的权衡曲线在 `n` 阶聚合下的单调性条件。

**注意**：E5 已实测预算分配的实际增益 `95%` 来自阈值标定而非分配本身，
因此上述命题只能作为**理论刻画**，不得写成"分配机制带来提升"。

| 情形 | 必须动作 |
| --- | --- |
| 协议对齐门不通过（逐流 AP 偏离 `0.2416±0.05`） | 停止，先做协议差异审计 |
