# C12 跨年度种子 42 快速消融实施计划

> **代理实施要求**：使用 `superpowers:subagent-driven-development` 按任务执行；只运行能保护数据隔离和真实训练入口的最小验证，不以全仓检查、格式化或独立复审阻塞实验。

**目标：** 在不访问 LSPR24 最终 20% 的条件下，比较 `B0/M1/M2/M1+M2`，判断 C12 两个机制是否具有独立和组合收益。

**架构：** 一份按年度与时间分区的大而全开发主产品保存合法字段并集；跨年度缓存通过统一清单裁剪 77 个共同字段和 `2-IP` 序列索引。四个变体共享接收基座、样本、参数预算、训练步数、阈值协议和评价脚本。

**技术栈：** Rust 或 PyArrow 流式物化、Parquet、PyTorch、SwanLab 在线跟踪、单卡 GPU。

## 全局约束

- LSPR23 是有标签源年度；LSPR24 前 10% 仅作为无标签目标校正前缀，随后 70% 是可见开发评价区，最后 20% 完全不可见。
- LSPR23 源训练与源验证在 `2-IP` 序列级互斥；精确比例和时间边界以共同字段审计合同为准。
- `2-IP` 只使用密钥化规范无向 IP 对作为分组侧车；IP、端口和侧车键不进入模型。
- 序列按完整流可用时刻稳定排序，最大长度 128，使用非重叠块，跨年度和跨分区强制断开。
- 共同输入为审计冻结的 77 个字段；所有变换只在 LSPR23 源训练区拟合。
- 快速实验固定种子 42；只决定优先级，不构成论文正式结论。
- 预计 GPU 任务启动前必须通知用户开机、预计时长和并行进程数。

## 四组变体

| 变体 | 漂移状态 | 可信正常校正 | 用途 |
| --- | --- | --- | --- |
| `B0` | 无 | 无 | 参数匹配因果 Transformer 接收基座 |
| `M1` | 有 | 无 | 检验定向遗忘旧年度关联 |
| `M2` | 无 | 有 | 检验无标签目标正常校正 |
| `M1M2` | 有 | 有 | C12 完整候选 |

## 评价与裁决

- 主指标：目标开发区 PR-AUC。
- 辅助指标：宏平均 F1、精确率、召回率、每小时误报、期望校准误差。
- 效率指标：参数量、训练墙钟、峰值显存、样本吞吐和单序列推理延迟。
- 阈值只在 LSPR23 源验证区冻结；目标开发区不得重新选阈值。
- `M1M2` 必须超过 `B0` 及两个单机制；`M1` 和 `M2` 至少各自在预注册主指标或困难分面上产生方向一致的独立增量。
- 若可信校正不优于无门控写入或时间块置换控制，不能宣称收益来自可信正常状态。
