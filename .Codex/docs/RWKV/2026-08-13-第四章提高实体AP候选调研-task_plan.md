## 当前唯一实验

按实体总流数分为 `1–2 / 3–10 / 11–100 / 101–1000 / >1000` 五档，在完全相同实体集合上比较 C00、C10、C11：

- 每档实体数、正实体数和基率；
- 实体 AP、`AP/基率`、DR@4%FPR；
- C10−C00、C11−C00、C11−C10；
- 全局结果仅复核现有冻结值，不生成新的模型选择规则。

若某档正实体少于 `20`，只报告描述性指标并标记功效不足。结果出来前不决定是否采用实体均匀重加权。
