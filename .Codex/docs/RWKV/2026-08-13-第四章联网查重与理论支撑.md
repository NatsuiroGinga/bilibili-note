## 1. 查重结论

### 1.1 候选一（课程学习）：**核心假设已被已发表工作占用，应否决其「新机制」立论**

任务简报写「核心假设『检查点漂移方差 = 可迁移难度』是本课题自己提的，尚无任何文献支撑」——**该判断不成立，必须在第四章任何文稿中撤回**。

三处直接占用，按严重性排序：

1. **Dataset Cartography（EMNLP 2020）已定义同一个量并已给出正面实测证据。** 其 variability 定义为逐样本真值标签概率在各 epoch 检查点上的标准差 σ̂_i = sqrt(Σ_e (p^(e) − μ̂)²/E)，与本候选的 v_f 是同族二阶统计量（本候选仅限制在末 K 个检查点）。且它已实测「高 variability 的 ambiguous 样本对 OOD 泛化贡献最大」：WinoGrande 上只取 variability 最高的 33% 训练实例重训，OOD 准确率超过用 100% 数据训练的模型（3 种子平均并报标准差）。**本候选不是「提出一个无人验证的假设」，而是「在新数据集上复现一个已被验证的假设」。**
2. **「末 K 个检查点」这一具体设计有逐字先例。** VoG（CVPR 2022）明确定义 VoG(late-stage) 为最后 3 个检查点上的梯度方差，并已把该分数用于 **OOD 检测排序**；连 K=3 的取法都相同。
3. **「末段加权检查点预测方差」及其方差界已被发表。** Selective Prediction via Training Dynamics（TMLR 2022）用越靠后权重越大的加权检查点预测方差做拒识，并在「收敛到局部极小、学习率极低、权重近似高斯」假设下给出该量的界。这意味着 4.5 若想证「v_f 的集中性 / 方差界」，最自然的那条定理已被占用，不能算自创理论结果。

第四处削弱：**整条「训练动态难度 → 课程 → 分布外泛化」链路已被走通且结果不佳。** arXiv:2310.12118 在 CFQ 组合泛化上做了完全同构的实验，结论是没有任何单一课程一致占优、hard-to-learn 开局反而优于 easy-to-learn（与常规课程学习预期相反）、指数 pacing 导致训练后期停滞。

**剩余新意只有两层，且都不是新机制**：(a) 应用域为跨年度加密流量 83 维表格特征（多轮检索未命中把训练动态方差用于漂移鲁棒 NIDS 的工作，属**负结果，不等于不存在**）；(b) 使用方式为训练后期在线梯度预算重分配而非离线选子集——但 SPL、focal loss、Dynamic Loss-Based Sample Reweighting（ICLR 2025）已覆盖「按难度在训练中动态重加权」这一动作本身。两层合起来是「换域 + 换用法」的工程组合。

### 1.2 候选二（强化学习）：**问题形式已被完整发表，且 4.5 两个最自然的定理已被占用；需重构定位后方可保留**

1. **「延迟-误报权衡下的部分观测最优停止 + RL」在两条独立文献线上都已成熟。**
   - ECTS 线：Martinez 等 EUSIPCO 2018（DQN early classifier）、Martinez 等 KBS 2020（显式 POMDP + DRL，在「现在分类」与「延迟取更多观测」间决策）、EARLIEST（KDD 2019，RL halting policy 与 RNN 判别器联合训练）、Stop&Hop（CIKM 2022，**不规则到达 + POMDP + RL 停止**，等待时还预测等待时长）。
   - QCD 线：Cooper & Meyn（CDC 2024，arXiv:2403.14109）与 arXiv:2512.22347（QCD 即部分观测最优停止，用 RL 求近似最优，并证 Q-learning 在线性函数逼近下收敛）。
   - 本候选的三动作（继续 / 告警 / 拒识）只是在 ECTS 线上加一个终止性拒识动作，而带拒识域的序贯检验（三决策区域、三误差指数）在经典序贯分析中同样是标准对象。
2. **本候选确实部分不落在经典序贯变点检测的最优性覆盖范围内，但不落在的那部分推不出「所以必须用 RL」。** 详见 §4.2。最要命的一条：与本候选设定最接近的**非 RL 方案**已在同类 IDS 数据上发表（arXiv:2510.09619，BOCPD 后验 + 成本最优阈值，UNSW-NB15 与 CIC-IDS2017 时序切分，指标含以事件数计的检测延迟）。
3. **4.5 两个最容易想到的定理都已被占用**：「RL / Q-learning 停止策略的收敛或近似最优」被 arXiv:2512.22347 证过；「延迟惩罚上升则继续观察区单调收缩、停止更早」被 arXiv:2606.23962 证过。
4. **仍未被覆盖的部分只有应用实例化空白，不是理论空白**：多次独立检索均未命中「以实体（2-IP 对 / 主机）为决策单元、以流到达为决策时刻、学习停止策略」的加密恶意流量早期告警工作；也未命中把第三章 L3（实体级 Lp 池化用检测延迟换准确率）显式量化为停止时刻-准确率前沿的工作。注意 p≈1.06 的 Lp 池化接近算术均值，需要全部 n 条流才能算出 S_e，改成前缀停止规则是自然且未见发表的延伸。

### 4.2 候选二的「经典覆盖范围」逐条核对（用户点名要判的关键问题）

结论：**本候选部分不落在经典序贯变点检测的最优性覆盖范围内，但不落在的那部分不足以单独支撑用 RL。**

被违反的四条假设（假设集出自 arXiv:1210.5552 与 Moustakides 1986 / Ritov 1990）：

1. **变后分布 F1 未知且复合**：LSPR23→LSPR24 零样本，攻击分布跨年度改变。Perusquía 等 2021 转述 Tartakovsky 2014：网络安全中变前变后分布都不已知、似然比不可用。
2. **观测非 i.i.d.**：同一 2-IP 实体内的流强相关，83 维特征互相关。
3. **「变化永久持续 + 单流无限期监视」不成立**：实体序列长度有限（L=128，多数实体远短于此），ARL2FA→∞ 制度根本不出现；攻击是间歇性有限时长事件。
4. **评价准则不匹配**：指标是 47,115 实体群体上的 AP / 逐实体误报率（正类先验 0.0160，752 正例），不是单流 ARL2FA 与 ADD。

但四条违反都推不出「所以必须用 RL」：

- 违反 (1) 已有非 RL 的已发表解：score-based 多周期 Shiryaev-Roberts（arXiv:1212.1829，正为 NIDS 设计）、GLR/窗限/密度估计/leave-one-out CUSUM、SPRT + normalizing flow、SPRT-TANDEM。
- 违反 (2) 已有非 i.i.d. QCD 的渐近最优性结果。
- 违反 (3)(4) 说明这**根本不是 QCD 问题，而是带 earliness 的群体分类问题**，于是直接落回 ECTS 框架，而 ECTS 已有 TMLR 2025 综述、9 个 SOTA 算法与开源库。
- 最接近的非 RL 方案已在同类 IDS 数据上发表（arXiv:2510.09619）。

因此「经典不适用所以用 RL」的论证链已被切断。**唯一站得住的定位是：有限时域 + 分布未知 + 非 i.i.d. 的学习式最优停止**，且应优先考虑 FIRMBOUND 式的一致估计后向归纳，而非策略梯度 RL——后者在同一问题上既无一致性保证又有更大梯度方差（arXiv:2403.14109 自己就报告了 actor-critic 梯度方差大）。

### 4.3 候选一 4.5 定理二的缺口性质：结构性，不是检索不足

联网检索确认：**目前不存在任何已证结果把「跨训练检查点的预测方差」与泛化间隙或迁移风险联系起来**。最接近的三支都不是同一个量：

- McAllester 的 PAC-Bayes training-variance bound：关于**假设分布上的方差**，不是检查点方差；原文明确指出没有对应的优化算法、理论后果有待研究。
- 基于梯度方差的轨迹型界：统计对象不同。
- 方差正则化界：**样本上的损失方差**，不是时间轴上的方差。

封闭该缺口需要处理单条 SGD 轨迹上检查点之间的强依赖，现有 i.i.d. 与 PAC-Bayes posterior 工具不覆盖。Dataset Cartography、Toneva 遗忘事件、VoG 全是纯经验方法，无收敛性或泛化保证；唯一带界的 Rabanser 等 TMLR 2022 只在「收敛到局部极小、学习率极低、权重近似高斯」的强假设下界住末段检查点 confidence 的方差，结论是「某测试点被正确分类的概率上界」，既不是泛化界也不是迁移界，且其假设与本课题「2 epoch 完全拟合后无方向漂移」的实测状态不符。

## 5. 裁决

### 5.1 候选一：**否决其作为「新机制」的立论**

依据（全部为查重与理论适配判定，非实验结论）：

1. **核心假设已被已发表工作占用。** 「检查点漂移方差 = 可迁移难度」不是本课题自提且无支撑的假设；Dataset Cartography 已定义同一量并在 4 个数据集上给出正面证据，VoG 已用同样的末 3 检查点设定并已用于 OOD 排序，Rabanser 等已给出末段加权检查点方差的界。
2. **整条链路已走通且结果不佳**（arXiv:2310.12118，CFQ 组合泛化上无单一课程一致占优）。
3. **撑不起两个定理。** 4.5 定理二无可用框架，且缺口是结构性的（§4.3），不能靠继续检索或文字推演补上；三条候选路线分别被「v_f 不是密度比」「Ψ≈0 且损失非凸」「验证损失无模型选择能力（L2 实测）」否决。
4. **三条文献证据与第三章实测相互印证，指向本候选在 LSPR 上根本跑不出信号**：Wild-Time（13 种方法打不过 ERM）、ICLR 2025 表格时间漂移（模型选择是首要问题，对应 L2）、arXiv:2401.01867（逐样本难度分数跨运行方差高，对应 L1 与 σ=0.07~0.23）。RoNLI 另报告类别不平衡时少数类被系统性判为高难度，而 LSPR24 逐流正类先验 0.0257、实体级 0.0160。

**若用户仍要保留，必须先跑三个证伪实验，全部通过才谈重构；不得先写方案。**

- **实验 F1（否决门槛）**：在 LSPR23 上直接复现 Cartography variability / VoG / EL2N / 遗忘次数四种已发表难度分数，检验 v_f 是否与它们高度相关。高度相关 ⇒ 只是换名字，**否决**。
- **实验 F2**：多种子下 v_f 的秩相关。跨种子秩相关低 ⇒ L1 解释成立（测到的是噪声），**否决**。
- **实验 F3**：v_f 与「是否正类」的相关。基本等价于正类指示 ⇒ 机制退化为类别重加权，**否决**。
- **实验 F4（4.2 自身的合格线）**：计算按 v_f 加权前后 disc_L(Q_w, P̂_T) 的经验代理（域判别器误差）是否下降。不降 ⇒ 在候选一自己的优化目标下即被否决。

三关全过后，唯一可行的重新定位是「时间漂移下训练动态难度信号的失效条件与修正」，即以**否定性/诊断性结论**立论——但这与第三章 L1/L2 是同一批诊断，是否够一整章需用户裁决。**在 L2（验证信号无效）被解决之前，候选一的任何 bilevel / meta-reweighting 收敛性定理都不应写入论文。**

### 5.2 候选二：**保留，但必须重构定位与理论目标**

依据：

1. slot 三格可凑齐且每格都有强框架（§3.1）。
2. 但**问题形式与 4.5 两个最自然的定理均已被占用**，因此以下三条必须同时成立才可继续：
   - **定位改写**：不得写成「用 RL 做早期告警」，必须写成「**有限时域 + 变后分布未知 + 非 i.i.d. 观测下的实体级学习式最优停止**」，并显式论证 §4.2 的四条违反，否则会被答辩质疑为在有成熟精确最优解的问题上叠加 RL。
   - **方法优先级改写**：优先 FIRMBOUND 式一致估计后向归纳（有一致性定理、有凹性结构），策略梯度 RL 降为对照或退路。
   - **4.5 避让**：禁止证「RL 停止策略收敛/近似最优」（arXiv:2512.22347 已证）与「延迟惩罚上升则继续区收缩」的连续时间版本（arXiv:2606.23962 已证）。可用组合为「CPO Prop 2 有限时域重证的误报预算违反上界」或「Lorden 型延迟下界的非 i.i.d. 重证」作定理一，「NP 伞式 Proposition 1 的实体级有限样本误报控制 + 跨年度失效的显式刻画」或「延迟惩罚单调比较定理的离散有限时域重证」作定理二。
3. **必须先跑最小可证伪实验再投入整章**：固定第三章 C11 的实体级打分，只比较三种停止规则——固定前缀 k 条流 / score-based SR 或 BOCPD 阈值 / 学习停止策略——在同一延迟预算下的实体级 AP。**若学习策略不能稳定超过阈值规则，候选二应直接否决。**
4. **与新颖性无关但决定成败的实测风险**：正类实体仅 752 个，RL 策略的正样本 episode 极少，而第三章同类配置单种子实测 σ=0.07~0.23；在该方差水平下，RL 停止策略相对 BOCPD 阈值或 score-based SR 的增益极可能不显著。
5. 4.6 八小节的基线清单已由查重确定，不可省略：ECTS 9 个 SOTA（TMLR 2025 基准）、SPRT-TANDEM、score-based 多周期 SR、BOCPD + 成本阈值（arXiv:2510.09619）、Decision Transformer（arXiv:2312.07696）、固定前缀规则、ERM 无停止上界；earliness 指标必须与 arXiv:2201.11628（MNP 型）与 arXiv:2309.01070（比例型 + 时长型）对齐，**不得自创延迟指标**。
