## 总裁定（先给结论）

**§二之六被打死：推荐工作点 `κ = 10⁴`、`c = 1e-5` 的两个常数都不成立，
且 `c = 1e-5` 会让六档预算保真度比现行标量 `lr` 差三个数量级。
§二的其余部分（机制二的文献正解）站得住，不受牵连。**

四条独立结论，任一条都足以停掉 §2.6.4：

1. **`c = 1e-5` 把 `ξ` 冻在初值。** `lr_K = c·β_K` 使最低档步长为 `9.97e-9`。
   `【推导】`分布无关的行程上界：`T` 步内 `|ξ_T − ξ_0| ≤ T·c·(1−β)/(N_p·|K|)`，
   `T = 10⁴` 时为 `8.33e-3`，只有实测工作点 `5.53e-3` 的 `1.51` 倍，
   而该上界要求 `128` 对**每步全部活动**（实测活动率 `0.42%–4.3%`）。
   `【模拟】`最低档活动率落在 `0.944`，是目标 `β = 9.97e-4` 的 **`947` 倍**；
   现行标量 `lr = 1e-4` 在同一模拟下是 `0.44` 倍。**改造使指标变坏，不是变好。**
2. **`κ = 10⁴` 的唯一支撑被真实收据定量否决。** 该值等价于断言配对损失在阈值处的
   局部衰减率 `λ_loc = 1/均值 = 255.7`，这个等式**只在指数分布下成立**。
   `【实测】`逐步批均值标准差是指数模型预测的 `47.2` 倍（方差比 `2227` 倍）。
   `λ_loc` 未测，真实要求可在 `[70, 7331]` 之间（同均值下五族分布的实算跨度）。
3. **§2.6.3 的位移上界少了一个 `1/12`。** `【实测】`直接对生产 `cvar_pauc_loss`
   反传，`∂L/∂ξ = (1/(N_p·|K|))·(1 − n_act/K_eff)`，文档用的 `1/β` 高估 `12.0` 倍；
   连带 §2.6.3 表中「`κ = 10²` 一步跨过」的**判定方向也是反的**。
4. **文献引用张冠李戴。** `【文献】`Thm 3 的 `O(1/κ)` 是两个 min-max-min
   **目标值之差**，不是预算漂移；原件对分位数偏移只给定性断言、未给收敛率
   （子代理核验，见 §三）。`【推导】`本审核实算表明该偏移实际是 `O(1/κ²)`。

**不受影响的部分**：`【文献】`§2.1「BER 不缺阈值重构」成立——Eq.(10) 出自
Lem.1（原件行 `911`），是实数上的 CVaR 变分恒等式，不要求有界、不要求平方损失。
`lr_K = c·β_K` 这条**策略本身**的工程落地也没有障碍（改动 3 处、不动数据结构），
垮的是它的**取值**与**支撑论证**。

### 1.2 `【推导】`把「缺什么」收敛到一个标量

对局部指数尾（衰减率 `λ_loc = −d ln S(t)/dt`，在工作阈值处取值），软化后的
最优阈值条件 `E[σ(κ(L−s̃))] = β` 有闭式：

```
β̃/β = sin(πa)/(πa),   a = λ_loc/κ   （0 < a < 1）
```

`【实测】`该闭式与数值解**在四个 `κ` 上逐位吻合**（脚本 §一，见下表），
说明 `β̃/β` 对真实分布的依赖**全部经由 `λ_loc` 一个标量**。

反解：要 `β̃/β ≥ 0.998`，须 `a ≤ 0.03488`，即 **`κ ≥ 28.67·λ_loc`**。

**文档的 `κ ≥ 10⁴` 等价于断言 `λ_loc = 1/均值 = 255.7`。
这个等式只在分布恰为指数时成立。** 换成别的 `λ_loc`，要求线性平移：

| 若 `λ_loc` = | `1` | `10` | `100` | `256` | `1000` | `5000` |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 则 `κ ≥` | `28.7` | `287` | `2867` | `7340` | `2.87e4` | `1.43e5` |
| 相对文档 `10⁴` | `0.004×` | `0.04×` | `0.39×` | `1×` | `3.9×` | `19.6×` |

**跨度四个数量级。** `λ_loc` 未测之前，`κ = 10⁴` 是**未验证假设**，
不是「按实测损失尺度的扫描」——文档 §2.6.4「每个常数的来源」一栏对 `κ` 的说法不成立。

### 1.3 `【实测】`指数构造本身被真实收据否决

若每步 `N_p×N_n = 128` 个 `L_pn` 是同一指数分布的 iid 抽样，
逐步批均值的标准差应为 `μ/√128`：

| 量 | 值 |
| --- | ---: |
| 实测逐步批均值标准差（第 8 轮） | `1.6312e-02` |
| 指数模型预测 `0.0039/√128` | `3.4568e-04` |
| **实测 / 预测** | **`47.2` 倍**（方差比 `2227` 倍） |
| 实测 `std/mean` | `4.17` |
| 指数模型 `std/mean` | `0.0884` |

`【实测】`同一轮末步批均值 `3.3687e-06`，是轮均值的 **`1/1161`**。
指数模型下 `128` 个样本的均值落到总体均值的千分之一，概率天文数字级地小。

`【实测】`逐轮趋势（同一运行 10 轮）：

| 轮 | `pair_loss_batch_mean` | 逐步批均值 `std` | `std/mean` | 空活动步率 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | `1.2415e-01` | `1.7696e-01` | `1.43` | `0.000` |
| 4 | `1.6458e-02` | `4.8491e-02` | `2.95` | `0.133` |

**`std/mean` 单调上升到 `4.35`，分布越训越尖厚**。
这与「均值 `0.0039` 的指数分布」不是同一类对象。

**裁断：§2.6.5 第一条自陈的边界（「非真实分布」）是对的，但严重低估了偏差程度——
不是「尾部形状会改变 `β̃/β`」，而是构造分布与真实分布连二阶矩量级都对不上。**

### 1.4 取得真实分布的最小方案（不抢 GPU、不动训练）

缺的只有**工作阈值附近的生存函数**。最小做法：

1. **落一个收据键即可覆盖将来**：在 `_ranking_phase`（`ch3_ft_c00_dual_selection.py:2845`
   起的 `diagnostics` 字典）把 `bag_result["policies"][active]["per_budget_mean_xi"]`
   取进收据——该键 `cvar_pauc_loss` 已经算好（`ch3_ft_entity_ranking_loss.py:515`），
   宿主只是没取。**零计算开销**，配合已有的 `per_budget_active_rate` 立即构成
   六个 `(ξ_k, S(ξ_k))` 点对，可直接拟合 `λ_loc`。
2. **要立刻拿到数**：零训练前向一次。载入 C01 已有检查点，
   在 `torch.no_grad()` 下复用 `sampler.sample` + `_entity_ranking_bare_forward`
   跑 `N` 步，把每步 `(N_p, N_n)` 的 `pairwise` 喂进已经存在但当前未被调用的
   `CvarThresholdState.observe()`（环形水库，`reservoir_size=4096`），
   再用同样已存在的 `quantile()` **只落分位数摘要**（如 `1−β_k` 六个分位数
   加 `0.9/0.99/0.999/0.9999` 四个通用分位数），不落逐样本、不落实体 ID。
   `【实测】`成本估计：该运行第 8 轮 `forward` 阶段 `mean_seconds = 0.10230`（CUDA 事件计时），
   `500` 步约 `51` 秒 GPU；`500×128 = 64000` 个配对，足以分辨 `β₁ = 9.97e-4` 分位数
   （期望约 `64` 个超越样本）。
3. **必须跨轮测**：`λ_loc` 随训练推进而变（§1.3 表已显示分布形状逐轮改变），
   一次测量不能冻结 `κ`。至少取早、中、末三个检查点。

**在拿到 `λ_loc` 之前，`κ` 与 `c` 都不得写入实施计划或配置。**

### 1.5 `【实测】`「只缺一个标量」这件事本身经过检验

若 `β̃/β` 还依赖尾部的更多细节，则 §1.4 的最小方案不够。取五族尾部形状完全不同、
**均值统一为实测 `0.00391`** 的分布实算（`lambda_loc_generality.py`，
可疑行另用 `2×10⁷` 样本蒙特卡洛复核 `lambda_loc_mc.py`）：

| 分布（均值同为 `0.00391`） | `λ_loc` | `a = 0.1` 时 `β̃/β` | `a = 0.0333` | `a = 0.01` | 与 `sin(πa)/(πa)` 最大相对差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 指数 | `255.7` | `0.98363` | `0.99817` | `0.99984` | `3.4e-11` |
| 帕累托 `α=2.5` | `67.15` | `0.97684` | `0.99744` | `0.99977` | `6.9e-3` |
| 韦布尔 `c=0.4` | `18.71` | `0.97998` | `0.99778` | `0.99980` | `3.7e-3` |
| 对数正态 `σ=2` | `6.573` | `0.97485` | `0.99721` | `0.99967` | `8.9e-3` |
| 对数正态 `σ=3` | `2.427` | `0.95931` | `0.99661` | `0.99952` | `2.5e-2` |

（对数正态 `σ=3` 一行在数值积分下曾给出 `1.09/1.47/2.22` 的发散值并带
`IntegrationWarning`；`2×10⁷` 样本蒙特卡洛复核为 `0.959/0.997/0.9995`，

两法互证。）

**两条推论**：

1. **`β̃/β` 只经 `λ_loc` 一个标量依赖分布**，§1.4 的最小方案充分。
2. **`1 − β̃/β ≈ (π·λ_loc/κ)²/6 = O(1/κ²)`，不是 `O(1/κ)`。**
   §2.4 把 Thm 3 的 `O(1/κ)` 当成预算漂移的速率，除了张冠李戴（§三）之外，

3. **同一均值下 `λ_loc` 跨 `105` 倍**（`2.43` 到 `255.7`），
   而指数是这五族里 `λ_loc` **最大**的一个。文档等于在只测了均值的情况下
   取了最保守的一端。收据的 `std/mean = 4.17` 指向比指数**更重**的尾，
   即 `λ_loc` 更小、`κ` 要求更低——**方向对方案有利，但仍未测，不得当作已核验。**

## 二、代码

### 2.1 `【实测】`§2.6.3 的位移上界算错了 `12` 倍

生产损失（`ch3_ft_entity_ranking_loss.py:494-517`，`active_policy =
causal_prefix_truncation` 走 `stratified=False` 这一支）：

```
r_k(p) = ξ_{p,k} + (1/K_eff_k)·Σ_n relu(L_pn − ξ_{p,k})
loss   = mean_k mean_p r_k(p)
```

`mean_p` 给 `1/N_p`、`mean_k` 给 `1/|K|`，故

```
∂L/∂ξ_{p,k} = (1/(N_p·|K|))·(1 − n_act/K_eff_k)
```

`【实测】`冻结配置 `n_pos = 2`、六档 ⇒ **前置因子 `1/12`**
（`ch3_ft_c00_dual_selection.py:2501` 注释「`n_pos + n_neg = 66`」，
配置 `ch3-ft-c01-entity-ranking-cuda-formal-v1.json` 的 `n_pos: 2`、`n_neg: 64`）。

直接对生产函数反传实测（脚本 `xi_grad_bound.py` §一），
实测梯度与含前置因子的解析式**比值恒为 `1.0000`**，与不含前置因子的式子差 `12`：

| `K` | `K_eff` | `n_act` | 实测 `∂L/∂ξ` | `(1−n/K_eff)/12` | `1−n/K_eff` |
| ---: | ---: | ---: | ---: | ---: | ---: |
| `121` | `0.0638` | `0` | `8.3333e-02` | `8.3333e-02` | `1.0000e+00` |
| `121` | `0.0638` | `3` | `−3.8338e+00` | `−3.8338e+00` | `−4.6005e+01` |
| `9706` | `5.1195` | `3` | `3.4501e-02` | `3.4501e-02` | `4.1401e-01` |

最坏情形（`ξ = 0`，`128` 对全活动）逐档对比：

| `K` | `1/β` | 实测 `|∂L/∂ξ|` | 实测位移 `lr·|g|` | 文档 `lr/β` | **文档高估** |
| ---: | ---: | ---: | ---: | ---: | ---: |
| `121` | `1002.78` | `83.481` | `8.3481e-03` | `1.0028e-01` | **`12.01×`** |
| `606` | `200.22` | `16.602` | `1.6602e-03` | `2.0022e-02` | `12.06×` |
| `1213` | `100.03` | `8.2525` | `8.2525e-04` | `1.0003e-02` | `12.12×` |
| `2426` | `50.01` | `4.0846` | `4.0846e-04` | `5.0015e-03` | `12.24×` |
| `4853` | `25.00` | `2.0002` | `2.0002e-04` | `2.5002e-03` | `12.50×` |
| `9706` | `12.50` | `0.9584` | `9.5843e-05` | `1.2501e-03` | `13.04×` |

**受影响的具体断言**：

| 文档原话 | 实测 |
| --- | --- |
| §2.6.3「单步位移上界 `1.00e-01`」 | `8.3481e-03` |
| §2.6.3 表「`κ = 10²`：一步跨过」 | **判定反了**：`8.35e-3 < 1e-2`，六档**全部可停** |

| §2.6.4「现行位移跨 `80.2` 倍」 | `87.10` 倍（`80.2 = 9706/121` 漏了 `−1` 项） |

**这不是「保守一点」而已**：`c` 小 `12` 倍直接把最低档步长压到 `9.97e-9`，
而 §2.6.5 第三条自陈「该档收敛速度代价未评估」——**这条代价被这个常数错误放大了 `12` 倍**。

**同一会话内已有正确公式。** 主代理 `15:28` 写的 `xi_lag.py` 第 2 行逐字写着

### 2.2 `【推导】`§2.6.3 的推理形式也有问题

| ---: | ---: | ---: | ---: | ---: | --- |
| `121` | `0.0638` | `0.004203` | `8.33e-06` | `1.2224e-04` | `n ≥ 1` 才跨过 |
| `606` | `0.3196` | `0.009648` | `8.33e-06` | `1.7738e-05` | 都可停 |

### 2.5 `【实测＋模拟】``c = 1e-5` 这个取值被证伪

§2.6.5 第三条自陈「`lr_K ∝ β_K` 使最低档步长降至 `9.97e-09`，该档的收敛速度代价未评估」。
**评估结果是：这条代价不是「慢一点」，是把机制关掉。**

**(A) `【推导】`分布无关的行程上界。** 单步位移
`= lr_K·|∂L/∂ξ| = c·β_K·(1/(N_p|K|))·|n/K_eff − 1| ≤ (c/(N_p|K|))·(1 − β_K)`，
故 `T` 步内 `|ξ_T − ξ_0| ≤ T·c·(1 − β_K)/(N_p·|K|)`，**六档同界**（这正是 `lr_K ∝ β_K` 的本意）。

| `c` | `T = 10⁴` 行程上界 | / 实测工作点 `5.53e-3` | 判定 |
| ---: | ---: | ---: | --- |
| **`1e-5`（文档推荐）** | `8.3250e-03` | `1.51` | **仅在全程满活动才勉强到** |
| `1.2e-4`（`12` 倍修正后） | `9.9900e-02` | `18.06` | 有余量 |
| `1e-2` | `8.3250e+00` | `1505` | 有余量 |

工作点锚定于实测：第 8 轮末步是空活动集步，此时 `r_k = ξ_k` 恒成立，
故收据的 `bag_policy_loss_values = 5.5309e-3` **就是** `mean_{k,p} ξ`。
又因 `β` 越低阈值越高，最低档的 `ξ` 只会**高于**该均值，上界更紧。

**(B) `【实测自洽性】`在已达平衡的活动率下，`c = 1e-5` 维持不住该平衡。**
代入第 8 轮实测活动率：

| `K` | 实测活动率 | 每正实体活动数 | 单步行程 | `T = 10⁴` 总行程 | / 工作点 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| `121` | `0.004203` | `0.269` | `2.67e-09` | `2.67e-05` | `0.48%` |
| `9706` | `0.042539` | `2.723` | `3.12e-08` | `3.12e-04` | `5.6%` |

最低档整程只能走 `2.67e-05`，是工作点的 `1/207`。

**(C) `【模拟】`动力学复刻。** 沿用主代理 `xi_lag.py` 的合成分数与**正确**梯度式，
只换 `lr` 策略，统计后 `1/3` 段：

| 策略 | 最低档活动率 / `β` | 逐档活动率 / `β` |
| --- | ---: | --- |
| 现行标量 `lr = 1e-4` | `0.44` | `0.44 / 0.96 / 1.17 / 1.37 / 1.49 / 1.51` |
| **`c = 1e-5`（文档推荐）** | **`946.9`** | `947 / 189 / 94.5 / 47.3 / 23.7 / 11.9` |
| `c = 1.2e-4`（`12` 倍修正后） | `498.5` | `498 / 99.8 / 50.0 / 25.1 / 12.7 / 6.5` |
| `c = 1e-2` | `10.4` | `10.4 / 2.19 / 1.17 / 0.67 / 0.44 / 0.38` |

> **模拟保真度须如实说明**：该模拟对现行 `lr` 给出的逐档趋势（随档递增）
> 与实测（随档递减：`4.21 / 1.93 / 1.35 / 0.93 / 0.62 / 0.46`）**方向相反**，
> 空活动步率 `0.083` 也低于实测 `0.395`。**它不是真实系统的忠实模型**
> （与 §2.6.5 第二条同一边界）。但 `c = 1e-5` 与现行 `lr` 的差距是**三个数量级**，
> 远超任何保真度缺口；且 (A)(B) 两条不依赖模拟。

**机制解释**：`ξ` 的平衡点是 `L_pn` 的 `(1−β)` 分位数。**`β` 越低、阈值越远、
行程越长**，而 `lr_K ∝ β_K` 恰恰给这一档**最小**的步长（比最高档小 `80.2` 倍）。
**缩放方向对暂态是反的。** 文档援引的 SOPA 定理 3 条件 `η₁ = O(βε²)`
是**渐近收敛率**条件，不保证在 `T = 10⁴` 步内**到达**工作点。

`ξ` 停在初值 `0` 附近时，因 `L_pn = softplus(·) > 0` 恒成立，
最低档活动率趋于 `1`，与目标 `β = 9.97e-4` 差约 `1000` 倍。
**这与已被否决的水库分位数修法是同一类失败（低档预算严重失配），只是方向相反
（那次是 `0/0/0`，这次是接近 `1`）。**

**裁断：`c = 1e-5` 证伪。`lr_K ∝ β_K` 这条策略若要保留，`c` 须重定（模拟指向 `≥ 1e-2`），
且必须先证明它在给定步数预算内能到达工作点，而不只是满足一个渐近条件。**
