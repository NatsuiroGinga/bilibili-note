## 一、职责分层

| 层 | 唯一职责 | 禁止承载内容 |
| --- | --- | --- |
| 活动 Goal | 只定义当前终点、完成条件与任务是否仍为 `active` | 长期执行纪律、公式来源、运行日志、逐项实验状态、历史裁决全文 |
| `AGENTS.md` | 只定义长期有效的恢复、证据、工程、凭据与写回纪律 | 本轮候选公式、当前运行编号、可变指标、活动任务的完整内容 |
| 研究契约 | 只记录本轮机制公式、证据等级、支持/证伪判据和最小可证伪实验 | 长期规则、Goal 全文、未核验运行结论 |
| 第三章恢复卡 | 只索引当前章节的已核验事实、制品、阻断项和下一动作 | Goal 全文、长日志、平行代理的未核验推断 |
| 协作看板 | 只记录任务所有权、并行修改边界、运行状态和交接动作 | 研究公式的权威版本、长期纪律、聊天口述结果 |

## 二、冲突裁决顺序

1. 根目录与局部 `AGENTS.md` 的长期边界优先；近层局部规则优先于上层规则。
2. 活动 Goal 裁决当前任务终点与完成条件，但不得突破前述长期边界。
3. 本轮研究公式、证据和实验判据以研究契约及其链接的冻结合同为准。
4. 已发生的运行事实以原始日志、制品和收据为准；章节状态以恢复卡索引为准；并行所有权与即时运行状态以协作看板为准。
5. 聊天消息、旧 Goal、历史快照和代理口述均不构成权威替代；出现冲突时登记待核，不以猜测覆盖制品。
