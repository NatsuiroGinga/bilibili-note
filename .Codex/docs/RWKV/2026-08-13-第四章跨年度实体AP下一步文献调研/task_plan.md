# 任务计划：跨年度实体排序与约束早停联合改进

## 目标

在不读取、不调参 LSPR24 最终测试区的前提下，基于已核验全文与本地 Q0 证据，裁决下一个同时覆盖实体平均精确率、`DR@4%FPR`、误报率约束违约、告警时延与观察流量的可证伪候选，并判断“冻结 XGBoost 强树锚 + 第三章 C11 表示/分数的源侧交叉拟合安全融合或有界残差”是否值得作为下一个 Q0。

## 任务边界

- 只读：项目规则、RWKV 恢复与证据文档、本地论文原件与 Zotero 条目。
- 允许写入：本任务目录、`raw/papers/`、`wiki/papers/` 及必要索引；Zotero 仅在元数据和去重核验后写入。
- 禁止：修改生产代码、配置、RWKV 恢复文档或路线总控；启动实验；读取或据 LSPR24 最终测试调参。
- 证据边界：文献只能支持机制来源、近邻、空白与可试性；候选有效性一律标为“实验待证”。

## 研究问题

1. 在不使用目标年标签、阈值或超参的前提下，哪类源域排序/模型选择方法有理由改善跨年度实体排序？
2. 如何将实体平均精确率、固定误报率下检出率、约束违约、时延和观察流量纳入同一个非单指标晋级门？
3. 冻结 XGBoost 强树锚与 C11 神经分数/表示的源侧交叉拟合安全融合、有界残差，有哪些直接近邻？其可保证的“安全”是源侧还是未见目标域？
4. 组/包大小、实体长度异质的多实例学习与集合聚合，是否能直接解释 Q0 长实体两桶退化？
5. 多目标梯度博弈/纳什议价、学习器—环境最坏风险博弈、原始—对偶约束博弈，是否实质上超过梯度整形、分布鲁棒优化或拉格朗日约束？

## 检索范围与检索词

- 时间：理论基础不限年份；近年直接方法优先 `2020–2026`。
- 领域：排序学习、异常/检测排序、分布移位、安全集成、多实例/集合学习、固定误报率约束、早停/序贯决策、多目标与鲁棒优化。
- 核心检索词：`learning to rank domain generalization`、`temporal distribution shift ranking`、`safe stacking cross fitting ensemble`、`residual stacking distribution shift`、`partial AUC Neyman Pearson classification false positive rate constraint`、`recall at fixed false positive rate surrogate`、`multiple instance learning bag size shift`、`set learning cardinality shift`、`early classification sequential stopping latency accuracy`、`multi objective gradient game Nash bargaining`、`distributionally robust min max game`、`primal dual constrained learning false positive rate`。

## 纳入标准

- 有可核验全文，且能定位算法、定理、公式、实验设定或局限的页码/章节。
- 至少直接支持一个本地决策：源侧安全融合、未见域模型选择、组大小异质、低误报约束、早停权衡、多目标/博弈原创边界。
- 元数据可通过 DOI、arXiv、出版社页或作者页交叉核验。

## 排除标准

- 仅有搜索摘要、宣传页或二手转述，无法核验细节。
- 只在目标域标签/验证集调参，无法转换为严格源侧协议。
- 仅改善单指标，且不能报告实体平均精确率、固定误报率下检出率、约束违约、时延/观察流量中至少两类权衡，且无法作为其中一个机制的严格近邻。
- 把普通加权损失、拉格朗日乘子或最坏风险目标仅换名为“博弈”，没有不同平衡概念、策略空间、动力学或可验证预测。

## 目标文献数与停止条件

- 目标：候选召回 `20–40` 篇，深度全文 `10–16` 篇，最终核心证据 `8–12` 篇。
- 每个主方向至少一篇全文；候选第一名所需的每个机制至少两个独立证据源（理论/算法与应用/实验）。
- 在一次同义词扩展与一次引用链扩展后，新增命中不再改变候选排序；或者网络/付费墙使全文无法获得，则停止并列人工下载清单。

## 候选统一裁决模板

每个候选必须给出：

1. 全文证据与精确位置；
2. 与 Q0、C11、XGBoost 强基线及长实体桶退化的关系；
3. 原创边界，包括与直接近邻的差异及不得声称的内容；
4. 严格源侧可观测量；
5. 最小对照/消融；
6. 绝对失败门；
7. 多指标晋级门：不得以单指标晋级。至少要求实体平均精确率不下降且 `DR@4%FPR` 提升，或 `DR@4%FPR` 不下降且实体平均精确率提升；同时不得增加误报约束违约，必须报告告警时延与观察流量。
8. 超参证据台账：逐项记录数值、作用、来源、来源位置、是否可用目标年信息、源侧敏感性计划与冻结时点。尤其追溯 `FPR≤4%` 是 Dijk/LSPR、朱论文、业务约束还是本项目人为选择；无文献/业务依据时只能称“预注册工作点”，并在源侧预先报告多个固定预算或敏感性，严禁用目标年标签选值。
