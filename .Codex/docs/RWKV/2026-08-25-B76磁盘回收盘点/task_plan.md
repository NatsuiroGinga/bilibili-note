# B76 磁盘回收只读盘点 task_plan

## 任务边界

- 只读盘点。禁止 `rm`、`mv`、`truncate`、`tar`、`gzip`、`> file`、`dd`。
- 禁止触碰运行中实验的运行根。
- 凭据只来自环境变量，不打印、不写入任何文件。
- 远程执行只用 `expect tools/remote_exec/gpu_env_quiet.exp "<命令>"`，不丢 stderr。
- 报告落 `.Codex/docs/RWKV/2026-08-25-B76磁盘回收盘点/`。

## 步骤

1. 读 2026-08-22 审计报告与 notes，确定哪些结论过期。（已完成）
2. `df -B1` 与 `pgrep -af python` 建立当前基线。（已完成）
3. `du -sb` 逐层测量：`/root/autodl-tmp` 顶层 → `llm_probe` 一级目录 → `runs/` 各子域 → 大子域内部。（已完成）
4. 对每个超过 500 MB 的目录判定：是什么、是否被运行占用、本机有无完整副本、是否唯一副本、可否重建。（进行中）
5. 非 LSPR 数据集单列一节，按内容与引用关系判定，不按目录名。（已完成，已早报 main）
6. 本机副本逐文件比对：文件数 + 精确字节，覆盖 ch4 worktree 与主工作树两处 `runs/`。（进行中）
7. 三档可回收组合：零风险、低风险、需批准，各给精确字节与折合 GiB，以及删后预计可用空间与已用比例。
8. 写 `审计报告.md`、`notes.md`，只暂存本任务三个文件后提交。

## 验收

- 每条判定附实际执行的命令与精确输出。
- 无法确定的项显式标「未确定」并说明缺什么证据。
- 报告数字精确到字节。

## 已知阻塞与风险

- `gpu_env_quiet.exp` 超时 30 秒，全盘 `du` 必须拆小并加 `timeout`。
- 本机 zsh 的 `chpwd` 钩子会让 `cd X && cmd` 短路，命令用换行或 `;` 串联。
- 三个实验并发写入，测量期间 `df` 读数会漂移，需在报告中记录读数时刻。
- `runs/` 受 Git 忽略，本机核验必须走明确路径或 `rg --no-ignore`。
