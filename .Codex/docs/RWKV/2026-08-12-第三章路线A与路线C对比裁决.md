## 二、两条路线的最强反对意见

### 路线 A 最强反对：**靶子在结构上排除了本论文主线机制**
57.1% 的误差质量位于「按定义没有恶意历史可用」的单窗事件上（single 平均分 0.5414 vs middle 0.9838），而 A1 基线已是 lag0..4 展平 2044 列 XGBoost。在该靶子上取胜必须在**一行表格特征**上打败强梯度提升树——不含任何可被状态/序列机制利用的结构；而 A 自己声明「机制不是长历史压缩」，等于放弃与 `RWKV路线总控.md:6,71` 要求的「接收基座 / 基座+移植机制 / 原生 RWKV 对照」三方模板的唯一接口。先验不利：19 个自研神经变体 + 7 个文献基线曾全部低于树模型。

**可否由实验消解：部分可以，但不彻底。**
- 可消解的部分：若 E1 证明单窗事件是删失伪影（G=2 容差下单窗数减半），靶子结构改变，误差重回多窗事件，序列机制重新有接口。
- 不可消解的部分：若单窗事件是真实的，该反对意见成立且无实验出路——这是定义层结论，不是概率性预测。

### 路线 C 最强反对：**有界性—增益二难**
`|s−b| ≤ ε` ⟹ 任意两样本分差最多改变 2ε。ε 小则可翻转对少、增益封顶；ε 大到能产生所需的 +38.8% 相对提升，则「间隔 > 2ε 不反转」这条唯一可证性质退化为空话。二难的退路（历史本身有强信号）已被实测堵死：ΔAP=0.0055078 是 C2(2044 列树) 对 C1(408 列树) 的增量，与 RWKV、有界残差、信任门无关，它反而把 C2 变成 M1 必须再超越 0.005 的更强基线。

**可否由实验消解：不能完全消解，但可以定量收窄。**
最小检验是 ε 敏感性扫描 + 同时报告排序翻转对比例；若存在某个 ε 同时给出显著增益且翻转对占比 <5%，二难被削弱。但 1.8% vs 38.8% 的量级差（RWKV-CVM 笔记:91 明确警告不得外推到加密流量，故此为**量级参照非上界证明**）使成功先验很低。

## 三、必须先做的证伪实验（按优先级）

### E1 — A 线：单窗事件是伪影还是真实？（**最高优先级，零成本**）
- **设计**：读 `runs/diagnostics/lspr24-a1-error-anatomy-v1/result.json` 的 `event_definition.first_window_prev_context` 五项计数与 `ev_len_hist`（脚本 :493-514 已计算并写入）。随后用已落盘 `val_scores.parquet` + `development-labels.parquet` + 宽表元数据列，把 label=-1 拆成 `empty`(has_activity=0) 与 `censored_active`(has_activity=1)；对全部 1519 事件统计前后紧邻窗四分类；用时间容差 G∈{0,1,2,4,8,12,24} 重定义事件，输出 n_events(G)、n_single(G)，并用冻结 score 重算四分面误差份额与四档预算事件召回。
- **通过阈值**：判伪影（任一成立）—— n_single(G=2)/n_single(G=0) ≤ 0.50；或至少一侧紧邻为 `censored_active` 的比例 ≥ 0.30。此时 single 0.5707、事件召回 0.5326 全部作废重算。判真实 —— n_single(G=12)/n_single(G=0) ≥ 0.80 且 censored 紧邻 ≤ 0.05。中间区间判部分伪影，须先冻结 G 再重新发布头条数字。
- **附带子判据**：若 G=0 单窗事件的 lag1..4 非空窗数中位数 ≥ 3，则「历史贫瘠」机制前提被直接证伪。
- **耗时**：读 JSON 字段 <1 分钟；完整版单 CPU、内存 <4 GiB、**5–10 分钟**。无 GPU、无重训。

### E2 — C 线：切分键偏移的机制核验（**次高，只读**）
- **设计**：断言 `active_starts[n_act*75//100] == val_min`（依据：`wide.rs:414` 在丢弃 final 前对所有流插入活动键，`wide.rs:741-747` 使 final 段窗口永不写入宽表，故重建集合 = 真集合前 80%，脚本 `:242` 用 60% 下标实际落在真 48% 处）。成立则按 `b40_fixed=active_starts[n_act*50//100]`、`b50_fixed=active_starts[n_act*625//1000]` 复用脚本已有 `make_seg`/`anchors_for` 重跑三段锚点普查。
- **通过阈值**：修正后 seg2 底率 ≥ 0.00520（进入 seg0 底率 3 倍内）→ 18.3 倍底率差是边界缺陷，全部 AP 与 aux 阈值作废重测；仍 < 0.00312 → 稀疏是数据固有属性，须正面按分布漂移处理，且禁止再用随底率缩放的 5×base 阈值。两种情形都须改 `result.json:721-722` 的错误段描述字符串。
- **耗时**：单 CPU、内存 <8 GiB、**8–15 分钟**。无训练。

### E3 — A 线：预算分母与工作点稳定性（只读）
- **设计**：把 FP 预算分母从 `ep_hours_all=3213.03` 换成 `ep_hours_evaluable=1287.91`（0.01 档 allowed_fp 32→12），重算四档；再以端点为簇做 1000 次自助重算阈值与事件召回，以事件为簇做对照；报告阈值 0.9455 在负样本降序中的位次及 ±10 位次的召回变化。
- **通过阈值**：换基数后 0.01 档事件召回下降 ≤ 0.05 → 保留现口径但正文注明；> 0.10 → 0.5326 是基数膨胀值必须重述。端点簇自助 95% 区间半宽 ≤ 0.05 → 可作基线；> 0.10 → 单划分单种子事件召回不能当主指标基线。
- **耗时**：**3–8 分钟**，可与 E1 合并为同一脚本。

### E4 — C 线：历史增量是否可复现（需重跑，仅在 E2 判定 A 后启动）
- **设计**：改三处后重跑——(a) 边界换成 E2 修正值；(b) seg1 与 seg2 都作正式评价段各自输出完整判据；(c) 新增逐锚点预测落盘 parquet。随后以独立前体簇为单元做 1000 次配对自助，输出 ΔAP 的 95% 区间与 P(ΔAP≤0)；第二轮扩 seed {42,1337,2024}。

**实验待证**

- C 的 g_t 由外生因果惊异度驱动这一唯一机制差异点（M2 的 CPU 门未跑）
- 定理 A-1 与引理 C-1 均为「设计可行 + 数值自洽」，不是性能结论

## 五、门禁判据争议的裁决（本次新增，两份反方报告各执一词且均不完整）
