# 审计结论：FT-Transformer 双机制全文与饱和检索审计

> 状态：全文审计完成；研究状态为“设计可行／实验待证”。本报告不放行代码、训练或 LSPR24 评价。

## 结论

推荐的两个主机制是：

1. **D1 因果实体记忆交叉注意力（结构级）**：保留 FT 对当前流 83 字段加 `[CLS]` 的原生路径，让当前 `[CLS]` 单向查询严格 `t^-` 实体记忆；历史只能作为 K/V，当前流预测完成后才写入记忆。
2. **D2 因果前缀一致的实体均匀低误报排序（训练级）**：实体 AP 选轮只作协议；训练目标使用与部署同构的严格过去前缀实体分数，每实体等权，并只在 LSPR23 冻结的假阳率预算内聚焦高分良性实体。

联合算法 **D3** 共享同一份严格过去实体记忆，执行顺序为：`读记忆→当前流预测→形成前缀实体分数→计算低误报排序目标→更新模型→写入当前流`。这构成显式联合流水线，而不是两个开关并列。

两项主机制都没有 LSPR 实验支持。文献只证明构件、最近邻与未覆盖差量；能否成为论文创新必须由源年共同预算对照和直接差量消融裁决。

## M-A 裁决

### 直接答案

- **精确直接证据不存在**：本轮核心五篇、522 篇本地论文笔记及饱和联网检索均未找到“FT 当前流 `[CLS]` 单向查询严格过去实体记忆”的论文。
- **构件证据充分**：TabFormer、FATA-Trans、Fieldy、STEP、SAINT 与 TabR 已分别覆盖同实体窗口、历史字段、跨行/列注意力、因果事件建模、跨样本注意力和检索增强。
- 因此不能写“首次把实体历史用于 Transformer”，只能写“针对 FT 当前流路径设计严格先读后写的实体记忆交叉注意力”，且仍是待验证候选。

### 可进入记忆的严格因果量

- 当前流到达前的实体流计数；
- 距上一次实体事件的时间；
- 由合法 Raw83 字段递推的指数衰减计数、和、均值；
- 由过去记录用 Welford 等在线算法维护的均值与方差；
- 当前合法字段值相对过去分布的标准化偏差或秩；
- 既有合法类别值的过去频率与转移计数。

这些量必须在预测前读取、预测后更新。禁止未来窗口、全实体离线统计、标签/IDS/演习身份派生量、原始 IP 入模，以及用 LSPR24 选择字段、箱、窗口或衰减参数。

### 身份降级

普通历史字段 token 只算 D1 的信息组件。PLR、周期、KAN、Matérn 或其他 tokenizer 只能用于记忆内容编码或组件对照，不能作为第二个主创新。

## M-B 裁决

### 实体 AP 选轮

把逐流指标换成源年实体 AP 只修复模型选择目标，**是协议，不是机制**。TabTransformer、FT 原论文和 Electronics 已说明按验证任务指标早停属于常规协议。

### 何时才是训练机制

只有实体目标进入反向传播，才构成训练级机制。但基础数学也已发表：

- SOAP 已直接优化 AP/AUPRC；
- pAUC-DRO 已直接优化给定 FPR 区间；
- MIDAM 已直接做多示例 AUC；
- Hu 等 NeurIPS 2023 已直接合并多示例袋与双向部分 AUC。

因此 D2 不能声称首次实体 pAUC。其唯一可保留差量是：严格过去前缀分数、每实体等权、LSPR23 冻结预算、与当前部署评分完全同构，以及与 D1 的共享记忆算法。该差量的新颖性风险高，必须把已发表最终袋 MI-TPAUC 作为直接组件对照。

## M-E 裁决

### 已占用边界

- 原生线性数值 token：FT-Transformer 2021；
- 连续特征单层非线性 embedding：SAINT 2021；
- 周期、分段线性、PLR/PLE：Gorishniy 等 2022；
- 分位数离散 token：TabFormer、FATA-Trans、STEP；
- 静态/动态字段类型与时间感知 embedding：FATA-Trans；
- KAN、Matérn 与矩阵/张量权重 tokenizer：MKAFT 2025；
- 跨行跨列细粒度字段注意力：Fieldy 2024。

上述方法原样替换均为照抄，不得作为创新。Electronics 表 11 的外部 ROC-AUC `0.527226` 只证明字段空间漂移是病灶，不证明任何新 tokenizer 有效。

### 尚可保留的适配

“严格过去实体状态条件化 PLR”在本轮没有精确直接近邻，但按用户裁决只能作为 FT 骨干专属适配或 D1 组件。若实验只证明普通 PLR 有效而状态条件化无额外增益，则不保留我方改造。

## D1 最小实验

### 公式草案

设当前 FT `[CLS]` 表示为 `h_t`，严格过去实体记忆为 `M^-_{e,t}`：

```text
q_t = W_q h_t
K^- = M^-_{e,t} W_k
V^- = M^-_{e,t} W_v
c_t = softmax(q_t K^-T / sqrt(d)) V^-
h'_t = h_t + sigmoid(g([h_t;c_t])) * W_o c_t
```

先用 `h'_t` 预测，再把当前合法字段写入实体记忆。记忆槽数量、统计字段和更新参数在源年诊断后另建数值依据台账；本报告不写魔法值。

### 对照与门

1. 原生 FT；
2. 同样历史信息作为普通字段；
3. 等参数均值读取记忆；
4. D1 交叉注意力；
5. 实体或时间打乱负控。

通过：D1 相对最强原组件的源年实体 AP 或统一 FPR 下 DR 差值，其实体 bootstrap 区间下界大于 0；另一主指标不劣；负控回落；`target_reads=0`；所有记忆时间戳严格小于当前流。

失败：不胜普通历史列/均值记忆、负控不回落、门控退化、记忆无使用信号或任何未来读取。

## D2 最小实验

### 公式草案

令 `u_{e,c}` 为实体 `e` 在冻结源年截止点 `c` 的严格前缀部署分数，`β` 为实验前冻结的假阳率预算。对每个正实体，使用顶部良性实体的 CVaR-pAUC 型排序损失：

```text
L_D2 = mean_{e+} CVaR_beta({ loss(u_{e+,c+} - u_{e-,c-}) : e- in benign entities })
```

实体先等权，再在实体内按冻结观察截止点构造前缀；不得让长实体贡献更多外层权重。具体平滑形式和状态估计器应以 Zhu 2022、Hu 2023 为原组件，不自行声称新优化器。

### 对照与门

1. 等训练步数的 CE 继续训练 + 逐流选轮；
2. CE 继续训练 + 实体 AP 选轮，隔离协议收益；
3. 已发表最终袋 MI-TPAUC 原组件；
4. D2 因果前缀改造；
5. 时间打乱负控。

通过：D2 相对 MI-TPAUC 的源年实体 AP 与统一 FPR 下 DR 至少一项差值区间下界大于 0，另一项不劣；逐流指标不被支配；梯度和状态估计稳定。

失败：只有选轮变化有效、D2 不胜原组件、低误报或逐流性能被支配，或状态估计方差/梯度接管失控。

### 辅助梯度控制

优先遵循 pAUC-DRO 的两阶段方式：相同 CE 起点后，用 pAUC 作为阶段二主目标；C00 运行等步数 CE 继续训练作为计算匹配对照。禁止直接把权重 `1.0` 的实体损失叠加到已饱和逐流损失。若后续确需联合损失，先登记梯度范数、夹角、损失占比和调度依据，并单独做纯 D2 对照。

## D3 最小实验

冻结四格：

- `C00`：原生 FT；
- `C10`：仅 D1；
- `C01`：仅 D2；
- `C11`：D1+D2 共享实体记忆算法。

所有格共享数据、截止时刻、训练步数、调参次数和参数控制。通过门为：`C10>C00`、`C01>C00`、`C11>max(C10,C01)`，均按源年实体 bootstrap 区间裁决；C11 不得依靠更多训练预算。任一单机制非正、联合非最佳、比较预算不公平或因果门失败即否决相应叙事。

## 证据边界

- 检索饱和只表示最后两组查询未再发现直接近邻，不等于数学证明全世界不存在相似工作。
- STEP 是预印本；MKAFT 的性能表受测试集早停污染；二者不能与正式全文同强度支持效果论断。
- Zotero Desktop 本轮未运行，六篇新增强近邻未导入；仓库 PDF、全文笔记与独立索引已经建立。
- 所有新机制结论均为“实验待证”。LSPR24 不得用于候选、结构、公式、字段、阈值或停止门选择。

## 禁止表述

- 禁止以固定 84 token 的二次复杂度作为本项目动机。
- 禁止写“首次使用实体历史”“首次做因果表格 Transformer”“首次做多示例 pAUC”。
- 禁止把普通实体 AP 选轮包装成训练机制。
- 禁止把 PLR、周期、分段线性、KAN、Matérn、矩阵 tokenizer 或普通历史 token 原样替换称为创新。
- 禁止用文献替代 LSPR23 共同预算基线、组件对照、负控、四格消融和统计实验。
- 禁止依据 LSPR24 结果修改记忆内容、排序预算、损失、门槛或候选顺序。
