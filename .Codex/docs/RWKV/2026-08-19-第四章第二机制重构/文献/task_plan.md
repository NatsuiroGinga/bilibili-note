# 第四章第二机制文献调研计划

## 目标

在 30 分钟内从本地 507 篇文献与必要的在线题录中，找到最多 3 个可与“实体路径最大统计量＋Tong 风险控制”互补的 D2 候选，并为每个候选给出全文证据、适配边界和最小可证伪实验。

## 阶段

- [ ] 阶段 1：范围定义与现有合同恢复
- [ ] 阶段 2：本地混合检索与候选收集
- [ ] 阶段 3：纳入、排除与 D1/D2/D3 分类
- [ ] 阶段 4：核心候选全文核验与页码/公式定位
- [ ] 阶段 5：互补性、研究空白与最小实验综合
- [ ] 阶段 6：题录核验、制品自检与交付

## 范围与门禁

- 研究问题：寻找能解决第三章遗留真实病灶、不依赖 LSPR25 目标标签即可完成源年资格实验、且能接收冻结 XGBoost 分数的第二机制。
- 优先方向：早期告警/检测时延约束、首达/最优停止、风险受限序贯检测、实体异质性/长度偏置、分层或条件化阈值、困难实体证据保持。
- 排除：重复 CPA/ELP、纯阈值再校准、需要目标标签的漂移适配、无法适配冻结 XGBoost 分数。
- 证据门禁：摘要与检索结果只作候选；技术结论必须有可读全文及页码、节或公式位置。
- 停止条件：得到最多 3 个 D2 候选且连续两组窄查询无新增 D2/D3，或 30 分钟到时。
- 写入边界：仅修改本目录下 `task_plan.md`、`notes.md`、`证据矩阵.md`；不修改 `raw/`、`wiki/`、Zotero、代码、正文、恢复卡和实验。

## 决策记录

- 仓库规则要求联网新文献落入 `raw/`、`wiki/` 与 Zotero，但任务明确禁止修改这些位置。本轮以更高优先级的任务写入边界为准：在线新文献只作候选或临时全文核验，不声称已正式入库。
