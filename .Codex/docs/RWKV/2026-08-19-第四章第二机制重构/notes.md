# 第四章第二机制重构证据笔记

## 已知事实

- 机制一已在 LSPR23 源年快速实验中支持：路径最大统计量配合 Tong 次序阈值，在实体假阳率不超过 4% 时提高了相对首曝基线的检出率。
- 机制二的经验阈值、同模型确认和风险余量三版均未满足预注册资格门；当前冻结分数上的阈值再校准路线停止。
- LSPR24 已被观察，不能重新包装为未触碰的独立漂移评价域。

## 待核问题

1. 第三章或机制一是否仍存在冷启动、证据稀释、告警时延、实体长度偏置或预算分配不均等真实病灶？
2. 哪一病灶能在现有两年数据中独立验证，而不依赖 LSPR25？
3. 第二机制应作用在分数轨迹、实体状态还是训练过程，才能与路径最大风险控制形成互补而非重复？
4. 若第三章没有新的有效性缺陷，是否存在可量化的训练效率、在线计算、告警时延或低误报预算优化点？

## 2026-08-20 候选裁决

- 机制一保留为“路径最大有限样本风险控制”：保留任何一次强证据，并用 Tong 次序阈值控制整条实体路径的假阳率。
- 机制二条件候选为“反射累积证据”：累积连续中等强度证据，证据转弱时回落，目标是补足路径最大值对持续弱证据不敏感的问题。
- 组合方式不是拆分两个假阳率预算。机制二先产生序贯证据轨迹，机制一再对该轨迹的路径最大值作统一风险校准。
- 只有反射累积分支在 M1 漏检或告警时延上产生增量，并且联合事件重新完成 Tong 校准，才能称为互补机制；若只用反射累积统计量替换 M1，它只是替代臂。
- Huang 与 Veeravalli 的有限时域最快变化检测是当前最强 D2 近邻；TEASER 作为连续证据确认强基线。路径难负样本训练缺少直接全文支撑，只保留为训练层备选。
- 在任何方法实现前，先运行 LSPR23 零训练诊断。若 M1 后长桶条件风险不集中，且漏检轨迹没有可观察的持续次高分信号，则否决机制二。
