# 第四章第二机制重构计划

## 目标

从第三章与机制一的真实实验残余问题或可测优化点出发，提出一个能与实体路径最大风险控制互补、可由现有数据证伪且有全文依据的第二机制。

## 阶段

- [x] 盘点第三章与机制一尚未解决的可观测病灶或效率、风险、时延优化点
- [x] 核验现有文献与直接近邻边界
- [x] 比较两到三个候选机制及最小证伪实验
- [x] 向用户提交推荐设计并取得零训练诊断授权
- [ ] 实现并运行 LSPR23 零训练长度桶与轨迹诊断
- [ ] 根据诊断结果否决或解锁反射累积证据 Q0

## 选择门

候选必须同时满足：问题或优化目标能由真实数据测量；不重复第三章 CPA/ELP；不依赖新的独立年度数据才能完成源年资格；与机制一使用同一骨干和共同预算；有明确基线、消融、指标与失败门。

## 当前状态

当前首选为“路径最大有限样本风险控制＋反射累积证据”的条件候选。机制二尚未获得实验支持；先运行零训练、零 LSPR24 的长度桶与漏检轨迹诊断。诊断不支持长桶条件风险或持续次高分信号时，立即否决机制二，不进入方法实现。
