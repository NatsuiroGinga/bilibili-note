## 根因裁决

1. 预算投影公式没有重复计算当前单元：首轮后按“当前完整单元加后续五个等价单元”投影六单元，符合原执行图。
2. `4.5 GPU 小时`是旧硬件线性外推形成的人为工程预算，不是科学有效性门；用户已明确撤销，不设置替代时长上限。
3. 本次停止是工程合同停止，不是科学失败，不得删减训练、候选、数据或评价制造通过。

## 单一合同修订

- 删除 Python 的累计 GPU 小时投影、首轮投影停止和相关 `BudgetLimit` 分支。
- 删除启动器的 `timeout` 硬门与资源收据中的最长秒数。
- 配置不再声明 `maximum_gpu_hours` 或首轮预算重校准，不设置任何替代时长上限。
- 显存、控制组主存、磁盘、并发准入、每 `20` 步恢复、SwanLab 和失败状态保持不变。

## 恢复与身份

- 旧运行的代码、配置和运行身份与新版本不同，不复用旧 `inflight`，也不伪称恢复。
- 新运行身份使用 `ch3-rwkv7-field-aware-protocol-a-2x2-seed42-v1-rerun1`，从首轮重新计算。
- 新身份内部仍支持同代码、同配置、同数据身份的步级恢复。
