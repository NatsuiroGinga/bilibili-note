## 冻结行为

1. 使用绝对项目根 `/root/autodl-tmp/thesis/experiments/llm_probe`；脚本开始先 `source "$PROJECT_ROOT/tools/env/activate.sh"`，不得只依赖初始 `PATH`。
2. 固定配置为 `$PROJECT_ROOT/configs/lspr-crossyear-c12-seed42-v1.json`，运行身份和日志根具有可读名称 `lspr23-lspr24-crossyear-materialization-v1`。
3. 只检查并使用配置中的 LSPR23 ZIP、LSPR24 Parquet、输出根、临时根；不得解析或访问最终区、攻击叙事、凭据或连接变量。
4. 通过明确 `if-else` 检查：`cargo`、`unzip`、`df`、`md5sum` 或兼容摘要工具；项目根、配置、两个输入存在；LSPR23 ZIP 大小与官方 MD5；可用内存至少 8 GiB；临时根所在数据盘可用空间至少 70 GiB。
5. 若正式输出根存在且 `receipts/materialization.json` 为成功、`final_accessed=false`，写入 `already_succeeded` 状态并退出 0；若输出不完整或存在 `.partial`/工作根，不自动删除，写入精确阻塞路径并退出非零。
6. 预检通过后运行报告中唯一生产命令：`cargo run --release --locked --manifest-path tools/lspr24_g0/Cargo.toml --bin lspr_crossyear_materialize -- --config configs/lspr-crossyear-c12-seed42-v1.json`。
7. 控制台和唯一运行目录同时记录：启动时间、预检各阶段、编译开始/结束、正式物化开始/结束、退出码和恢复动作；不得输出密码、地址、原始 IP、标签值或载荷。Rust 业务心跳直接进入同一日志。
8. 状态文件至少含 `state`、`phase`、`exit_code`、`started_at`、`finished_at`、配置 SHA-256、日志绝对路径、输出根和 `final_accessed=false`。使用 `.partial` 后原子替换，失败也保留最终状态。
9. 不启动 GPU、不调用 SwanLab、不安装依赖、不下载或同步文件、不创建 screen 会话；主代理在真实服务器同步后决定前台或持久会话执行。
