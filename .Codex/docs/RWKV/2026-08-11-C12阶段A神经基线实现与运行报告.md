## 实现内容

### 共享接收与输入边界

- 直接读取统一 Python 缓存，不新增一次性加载器。
- 按 `sequence_id/position/valid_length` 重建非重叠序列，逐序列右侧填充，最长 128。
- 模型输入恰为 77 个 `x_value`、77 个 `x_missing` 和 `log1p(delta_t_us/1e6)`。
- `sample_id`、`sequence_id` 只用于顺序、连接与制品；`group_key_ref`、标签、角色和年份均不进入模型。
- 复用既有 `FieldTokenizer` 和 `FieldAttention`，随后使用共享两层、6 头因果 Transformer。
- 第一阶段只用 `source-train` 训练一次接收器，`source-validation` 选择最佳固定预算轮次；接收表示随后一次落盘，明确排除 `target-prefix`。

### 公平矩阵与文献强基线

阶段 A 更新核公平矩阵固定为：

- `RX-TR`：接收因果 Transformer。
- `K-DELTA`：DeltaNet 更新核。
- `K-RWKV7`：普通 RWKV-7 更新核。
- `K-GDELTA`：门控 DeltaNet 更新核。

额外实现 `GRU`，展示名为“参数匹配 GRU 文献强基线”。它不是更新核公平矩阵成员。Leoste 一维卷积基线留作后续 `P1`，不阻塞首批运行。

三个矩阵核均使用一层 `6×32×32` 完整矩阵状态。四个公平变体及 `GRU` 共享冻结接收表示、融合分类头、隐藏维 192、训练轮数、AdamW、余弦调度、序列批次顺序和种子 42。较小模型使用真实参与训练和推理的非线性参数补偿模块，实测可训练参数均为 `333,569`，差异为 0。

### 既有核与等价边界

- `K-DELTA` 依据 `fla-org/flash-linear-attention` 固定提交 `7843b328b0d3860a66de4eb07ba28bb020ceb1d8`，保留归一化键、旧值读出、`beta` 加权预测残差和外积写回。Q0 未调用 FLA 并行 Triton/CUDA 算子，也未复现语言模型短卷积和完整层封装。
- `K-RWKV7` 依据 `BlinkDL/RWKV-LM` 固定提交 `952102498e9ed367ea0a59ee64106916d474d30f`，保留逐通道衰减、归一化移除键、上下文学习率、独立替换键和值外积的矩阵状态方向。Q0 未调用官方 BF16 融合核，也未复现语言模型令牌移位、跨层值残差、通道混合和专用初始化。
- `K-GDELTA` 依据 `NVlabs/GatedDeltaNet` 固定提交 `b53d6d3a161267432a79c1c04af69fa52bddc921`，保留数据依赖全局遗忘后执行 `beta` 加权 Delta 预测残差写回。Q0 未调用官方块算子，也未复现语言模型短卷积和完整层封装。

三者均明确登记为既有核的纯 PyTorch 顺序参考实现，`official_result=false`。运行结果只能是本课题任务适配结果，不得称为官方实现结果或 C12 原创机制。

### 预测、状态与评价顺序

- 所有递归变体在位置 `t` 先用更新前状态生成上下文和攻击概率，再用当前位置表示更新状态。
- 填充位不产生有效损失、不写入概率制品，也不更新状态。
- 阶段 A 不读取、不编码、不适应 `target-prefix`。
- `train-variant` 只训练源年度并封存 `target-development` 概率、样本标识、序列标识、位置和有效长度，状态转为 `predictions_sealed_evaluation_pending`。
- 独立 `evaluate` 子命令检查概率哈希和 `sample_id/sequence_id` 顺序后才连接目标开发标签。
- 目标阈值只由 `source-validation` 冻结；按唯一概率组累计假阳性和真阳性，严格满足每百万良性流误报不超过 100，并在召回并列时取更高阈值。
