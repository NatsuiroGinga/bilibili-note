# RWKV 机制移植文献综述工作笔记

## 范围检查点

- 研究对象：RWKV、RWKV-7、RWKV-8 的可分离机制，以及向普通基座模型和恶意流量检测的迁移。
- 目标决策：提出 3 至 6 个可快速消融的第三章候选，不直接冻结最终方案。
- 数据优先级：优先复用 LSPR24 与仓库现有数据；允许在冻结合同内重新物化。
- 证据边界：全文支持机制、公式和数字；摘要或网页只能用于发现线索。

## 检索记录

- 本地 `raw/papers/rwkv/` 与 `wiki/papers/RWKV/` 已覆盖 RWKV 原论文、Eagle/Finch、RWKV-7、GoldFinch、RADLADS、RWKV-X、RWKV-TS、FRWKV、FRWKV+、RWKV-CVM、多尺度 RWKV、PLM-NIDS 与 MambaNetBurst。
- 核心机制全文已统一转换为临时纯文本，逐项核验公式、表格、负结果与局限；临时文本不作为长期证据制品。
- 外部资源核验包括 RWKV 论文生态目录和 BlinkDL/RWKV-LM 官方仓库，均已写入 `wiki/resources/`；两者只用于发现和工程核验。
- Zotero 9.0.6、本地 API 与连接器均可用。已用文件方式补入 RWKV-CVM、MSRWKV-2DTCN、MambaNetBurst、FlowSem-MAE 和 netFound，并回查题名、作者、年份与 DOI/网址；正确键分别为 `27UACE87`、`88IP2C9N`、`LHMCT94Z`、`HH8TZ7I4`、`GU8MBF68`。

## 全文证据记录

- RWKV-7 式（15）—（17）支持矩阵状态、逐通道衰减、选择性移除与写入；不含网络安全语义。
- RWKV-CVM 以行随机矩阵和跳连做跨变量混合，仅增加 65 个参数；三种子平均 MSE 0.0435→0.0427，说明机制可训练但收益小且选择性强。
- FRWKV+ 采用零初始化、信任门控和幅度上限 0.20 的有符号校正；Exchange 完整 MSE `0.352±0.017`，移除周期上下文 `0.439±0.034`，移除基础门 `0.389±0.021`。
- RADLADS 的层内隐状态对齐不能省略，直接做输出蒸馏会在更高损失平台停滞。
- GoldFinch 与 RWKV-X 共同说明固定状态在精确召回上有边界，但当前 H=4 流量历史尚未证明需要长程检索。
- FlowSem-MAE 的字段专属嵌入、不可预测字段过滤和双轴建模均有明显消融贡献；没有恶意检测实验。
- MambaNetBurst 的最大单项退化来自早期步幅压缩，状态维度扩大到 128 反而下降，支持“先保护局部字段结构，再讨论状态容量”。
- PLM-NIDS 是 RWKV 直接用于网络入侵检测的邻近证据，但只用 CIC-IDS-2017，攻击先验高且强基线不足。

## 综合发现

- 文献空白不是“没人把 RWKV 用于安全”，而是缺少“历史状态条件化当前字段交互，并以有界信任门限制错误历史”的普通基座移植方法。
- S1“状态条件字段交互＋有界信任校正”证据链最完整；S2“连续时间状态演化＋正常状态生成”理论性质最清楚。
- S4“语义字段筛选＋递归掩码重构”适合单数据集内自监督；S3 更适合效率与保真，S5 必须先做无标签谱审计。
- 最终只能使用一个数据集时，LSPR24 能支持连续状态、字段交互、正常生成和困难分面；不能支持攻击家族、TLS/QUIC 类别或跨加密协议主张。
- 文献只能提高或降低实验优先级；快速消融也只能决定是否进入正式多种子验证。
- 冻结工作流为：登记多个候选 → 对每个候选审查能否达到朱焱雷第三章相当的理论功能与章级工作量 → 在同一冻结开发数据、同一接收基座和同预算下运行种子 42 快速消融 → 只有出现稳定且可解释信号的候选才进入三种子正式验证。效果潜力必须在快速实验中检验，不能由论文数量或公式数量替代。

## 缺失全文

- 本轮最终报告实际依赖的高优先论文均已有本地 PDF 与结构化笔记。
- RWKV-8 ROSA 无正式论文，不属于“缺少可下载全文”，而是当前学术证据尚未形成；因此只保留工程候选。
- 未发现需要用户手动获取才能完成本轮结论的关键论文。
