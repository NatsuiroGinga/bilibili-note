## 一、为什么要预注册这组观测

参照论文的两个机制 DS 与 RGO 是**同一个 Stackelberg 双层问题的内层与外层**：DS 改内层
约束集，RGO 算外层全导数，后者依赖内层解。因此其消融表交互项为正
（BUPT-CNN `+3.80`、ET-BERT `+3.30`）**有机制解释**。

本课题的 BER 作用于损失层。无论机制一最终取哪个候选，都需要回答：
**两机制的正交互（若出现）是有机制解释的互补，还是两个无关模块碰巧叠加？**

交互项 `I = C11 − C10 − C01 + C00 > 0` 只能告诉我们「有没有」，不能告诉我们「为什么」。
本文件冻结一组**可机械判定的观测量**来回答后者。

**这组观测量不构成否决理由。** 即使全部不成立，只要四格判据与目标年正增益门通过，
机制仍然成立——只是「互补有机制解释」这一主张缺证据，正文措辞须相应弱化为
「两机制在本数据上表现出正交互，其机制耦合未获直接证据」。本文件**不新增任何阻断门**，
不得据此暂停或拒绝任何运行（遵循 `llm_probe/AGENTS.md`「默认不新增阻断门」「披露优先于阻断」）。

## 二、通用观测量（与机制一的具体形式无关）

BER 的 CVaR-pAUC 在每步选出**活动负实体集** `A_{p,K} = {n : L_{pn} > ξ_{p,K}}`，
即当前最难分的负实体。以下两个量刻画机制一是否让这一内层结构更稳定。

### 观测量一：CVaR 阈值 `ξ` 的轮内相对波动

**定义**。第 `e` 轮、第 `K` 档内，记该轮所有优化步的 `ξ_{p,K}` 序列，取

```
CV_K^(e) = std(ξ_{p,K}) / |mean(ξ_{p,K})|
```

用变异系数而非方差，因为 C01 与 C11 的损失尺度不同，方差不可直接比较。

**判读**。取第 `15`–`20` 轮（共 `6` 轮）与六个预算档，构成 `6 × 6 = 36` 组配对。
统计 C11 的 `CV` 低于 C01 的配对数 `n_low`。

- **`n_low ≥ 24` 判为支持**：单侧符号检验 `P(X ≥ 24 | n=36, p=0.5) = 0.0326 < 0.05`
- `n_low ≤ 23` 判为不支持（`P = 0.0662`，不显著）

**依据登记**：`24` 这个门槛不是任意取的，是 `n=36` 时单侧符号检验在 `α=0.05` 下的最小
显著计数，由 `scipy.stats.binom.sf(23, 36, 0.5)` 算出。无文献依据，属统计推导。

### 观测量二：活动集的跨轮重合度

**定义**。取每轮**末步**的活动负实体集 `A_{p,K}^(e)`，计算相邻轮的 Jaccard 相似度

```
J_K^(e) = |A_K^(e) ∩ A_K^(e+1)| / |A_K^(e) ∪ A_K^(e+1)|
```

**只在 `K_eff ≥ 1` 的档上计算**。实测六档 `K_eff = [0.0638, 0.3196, 0.6398, 1.2796,
2.5598, 5.1195]`，最低三档 `K_eff < 1`，活动集期望大小小于 1，Jaccard 无定义或退化，
**必须排除**。故有效档为高三档。

**判读**。第 `15`–`20` 轮给出 `5` 个相邻轮对，`3` 档共 `15` 组配对。
统计 C11 的 `J` 高于 C01 的配对数 `n_high`。

- **`n_high ≥ 13` 判为支持**（若扩到 `18` 组）：`P(X ≥ 13 | n=18, p=0.5) = 0.0481 < 0.05`
- 若只有 `15` 组，门槛按同法在运行前重算并记录，**不得在看到数据后调整**

**注意**：`15` 组时的临界值须在首次 C11 运行启动前算定并写回本文件。当前登记为待定，
不得事后补。

## 三、候选专属观测量

机制一的候选尚未裁决，以下按候选分别冻结。**只执行最终采纳候选的那一组。**

### 3.1 若机制一为 M-E（实体门控的分段线性数值分词）

**观测量三：门 `γ` 在活动集实体上的均值比**

```
ρ^(e) = mean{γ(s_e) : e ∈ 活动集对应实体} / mean{γ(s_e) : e ∉ 活动集}
```

预期 `ρ > 1`，即门对准了 BER 最关心的那批实体。

**判读**：第 `15`–`20` 轮共 `6` 轮，要求 **`6` 轮全部 `ρ > 1`** 方判为支持
（`P(X ≥ 6 | n=6, p=0.5) = 0.0156 < 0.05`）。`5/6` 记为弱证据，不作支持结论。

**GPU 前的零成本前置诊断**（采纳文献调研代理建议）：有历史的良性实体
（源年验证集 `350 / 13509`）正是「长得像恶意」的高危误报源。可在训练前用只读诊断
测算「门可激活的良性实体」与「BER 高分良性实体」的重叠率。重叠显著高于随机则耦合
有先验支持；接近随机则应上调替补候选优先级。该前置诊断**不替代**上述训练中观测。

### 3.2 若机制一为实体内尾部聚合（嵌套 CVaR）

**观测量三′：两层活动集的嵌套一致性**

该候选本身是内层 CVaR（实体内 top-`⌈αm⌉`），BER 是外层 CVaR（实体间尾部）。
记内层选出的片段集合为 `B_e`，外层活动实体集为 `A_{p,K}`。观测

```
τ^(e) = mean{|B_e| / m_e : e ∈ A_{p,K}} / mean{|B_e| / m_e : e ∉ A_{p,K}}
```

即外层关注的实体，其内层尾部占比是否系统性不同。

**判读**：同 3.1，第 `15`–`20` 轮要求 `6/6` 同向方判为支持。方向性（`τ > 1` 或 `< 1`）
须在首次运行前预先声明，**不得看到数据后再定方向**。当前登记为待定——该候选若被采纳，
须在其实施计划中补齐方向声明后方可启动。
