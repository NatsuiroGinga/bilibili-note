## 一、为什么要预注册这组观测

参照论文的两个机制 DS 与 RGO 是**同一个 Stackelberg 双层问题的内层与外层**：DS 改内层
约束集，RGO 算外层全导数，后者依赖内层解。因此其消融表交互项为正
（BUPT-CNN `+3.80`、ET-BERT `+3.30`）**有机制解释**。

本课题的 BER 作用于损失层。无论机制一最终取哪个候选，都需要回答：
**两机制的正交互（若出现）是有机制解释的互补，还是两个无关模块碰巧叠加？**

交互项 `I = C11 − C10 − C01 + C00 > 0` 只能告诉我们「有没有」，不能告诉我们「为什么」。
本文件冻结一组**可机械判定的观测量**来回答后者。

**这组观测量不构成否决理由。** 即使全部不成立，只要四格判据与目标年正增益门通过，
机制仍然成立——只是「互补有机制解释」这一主张缺证据，正文措辞须相应弱化为
「两机制在本数据上表现出正交互，其机制耦合未获直接证据」。本文件**不新增任何阻断门**，
不得据此暂停或拒绝任何运行（遵循 `llm_probe/AGENTS.md`「默认不新增阻断门」「披露优先于阻断」）。

## 二、通用观测量（与机制一的具体形式无关）

BER 的 CVaR-pAUC 在每步选出**活动负实体集** `A_{p,K} = {n : L_{pn} > ξ_{p,K}}`，
即当前最难分的负实体。以下两个量刻画机制一是否让这一内层结构更稳定。

### 观测量一：CVaR 阈值 `ξ` 的轮内相对波动

**定义**。第 `e` 轮、第 `K` 档内，记该轮所有优化步的 `ξ_{p,K}` 序列，取

```
CV_K^(e) = std(ξ_{p,K}) / |mean(ξ_{p,K})|
```

用变异系数而非方差，因为 C01 与 C11 的损失尺度不同，方差不可直接比较。

**判读**。取第 `15`–`20` 轮（共 `6` 轮）与六个预算档，构成 `6 × 6 = 36` 组配对。
统计 C11 的 `CV` 低于 C01 的配对数 `n_low`。

- **`n_low ≥ 24` 判为支持**：单侧符号检验 `P(X ≥ 24 | n=36, p=0.5) = 0.0326 < 0.05`
- `n_low ≤ 23` 判为不支持（`P = 0.0662`，不显著）

**依据登记**：`24` 这个门槛不是任意取的，是 `n=36` 时单侧符号检验在 `α=0.05` 下的最小
显著计数，由 `scipy.stats.binom.sf(23, 36, 0.5)` 算出。无文献依据，属统计推导。

### 观测量二：活动集的跨轮重合度

**定义**。取每轮**末步**的活动负实体集 `A_{p,K}^(e)`，计算相邻轮的 Jaccard 相似度

```
J_K^(e) = |A_K^(e) ∩ A_K^(e+1)| / |A_K^(e) ∪ A_K^(e+1)|
```

**只在 `K_eff ≥ 1` 的档上计算**。实测六档 `K_eff = [0.0638, 0.3196, 0.6398, 1.2796,
2.5598, 5.1195]`，最低三档 `K_eff < 1`，活动集期望大小小于 1，Jaccard 无定义或退化，
**必须排除**。故有效档为高三档。

**判读**。第 `15`–`20` 轮给出 `5` 个相邻轮对，`3` 档共 `15` 组配对。
统计 C11 的 `J` 高于 C01 的配对数 `n_high`。

- **`n_high ≥ 13` 判为支持**（若扩到 `18` 组）：`P(X ≥ 13 | n=18, p=0.5) = 0.0481 < 0.05`
- 若只有 `15` 组，门槛按同法在运行前重算并记录，**不得在看到数据后调整**

**✅ 已冻结（2026-09-02，C11 启动前）**：`15` 组配对的临界值为 **`n_high ≥ 12`**。

依据（`/opt/miniconda3/envs/rwkv/bin/python` 精确计算，非近似）：
`P(X ≥ 12 | n=15, p=0.5) = 0.017578 < 0.05`，而前一档
`P(X ≥ 11 | n=15, p=0.5) = 0.059235 > 0.05` 不显著。故 `12` 是 `n=15` 下
单侧符号检验在 `α = 0.05` 的最小显著计数。同一算法复算 `n=18` 得 `13`
（`P = 0.048126`）与本文件原记录一致，`n=36` 得 `24`（`P = 0.032623`）与观测量一一致。

**该值随本次冻结生效，不因后续数据调整。**

## 三、候选专属观测量

机制一的候选尚未裁决，以下按候选分别冻结。**只执行最终采纳候选的那一组。**

### 3.1 若机制一为 M-E（实体门控的分段线性数值分词）

**观测量三：门 `γ` 在活动集实体上的均值比**

```
ρ^(e) = mean{γ(s_e) : e ∈ 活动集对应实体} / mean{γ(s_e) : e ∉ 活动集}
```

预期 `ρ > 1`，即门对准了 BER 最关心的那批实体。

**判读**：第 `15`–`20` 轮共 `6` 轮，要求 **`6` 轮全部 `ρ > 1`** 方判为支持
（`P(X ≥ 6 | n=6, p=0.5) = 0.0156 < 0.05`）。`5/6` 记为弱证据，不作支持结论。

**GPU 前的零成本前置诊断**（采纳文献调研代理建议）：有历史的良性实体
（源年验证集 `350 / 13509`）正是「长得像恶意」的高危误报源。可在训练前用只读诊断
测算「门可激活的良性实体」与「BER 高分良性实体」的重叠率。重叠显著高于随机则耦合
有先验支持；接近随机则应上调替补候选优先级。该前置诊断**不替代**上述训练中观测。

### 3.2 若机制一为实体内尾部聚合（嵌套 CVaR）

**观测量三′：两层活动集的嵌套一致性**

该候选本身是内层 CVaR（实体内 top-`⌈αm⌉`），BER 是外层 CVaR（实体间尾部）。
记内层选出的片段集合为 `B_e`，外层活动实体集为 `A_{p,K}`。观测

```
τ^(e) = mean{|B_e| / m_e : e ∈ A_{p,K}} / mean{|B_e| / m_e : e ∉ A_{p,K}}
```

即外层关注的实体，其内层尾部占比是否系统性不同。

**判读**：同 3.1，第 `15`–`20` 轮要求 `6/6` 同向方判为支持。方向性（`τ > 1` 或 `< 1`）
须在首次运行前预先声明，**不得看到数据后再定方向**。

**✅ 方向已冻结（2026-09-02，C11 启动前）：预期 `τ < 1`。**

**声明理由（推理，非实测）**：`τ` 的分子是外层活动实体的内层尾部占比均值
`|B_e|/m_e = k_e/m_e = ⌈αm_e⌉/m_e`，分母是非活动实体的同一量。
由 `⌈αm⌉/m` 关于 `m` **单调不增**（`m=1` 时为 `1`、`m=2` 时为 `0.5`、
`m→∞` 时趋于 `α`），该比值实质由**袋大小**决定：袋越大占比越小。

故 `τ < 1` 等价于「外层活动实体的袋系统性更大」。而 BER 的活动集选的是
成对损失最大的负实体，即最难分的实体；已实测「攻击实体流链长度中位数 `112`、
良性实体 `2`」，且难分负实体多为「长得像恶意」的多流实体
（[LSPR23 实体历史可用性诊断](2026-08-28-LSPR23实体历史可用性诊断.md)）。
**故预期外层活动实体的袋更大、内层尾部占比更小，即 `τ < 1`。**

**该方向随本次冻结生效。若实测为 `τ > 1` 且 `6/6` 同向，判为不支持——
不得据结果改写方向声明。**

## 四点五、交互项 `I` 偏小的已知结构性解释（2026-09-01 追加，写于 `I` 产出之前）

**`k_e = 1` 时 `α` 在该实体上完全惰性**——`⌈0.5 × 1⌉ = 1`，top-k 逐位退化为 max。
因此机制在袋大小为 1 的实体上**不产生任何作用**，这不是实现缺陷而是定义使然。

实测的作用面（`c11_config_gradient_check_opus`，`torch 2.12.0` CPU，真实训练函数
`bag_policy_diagnostics`，批构成照冻结合同 2 正 ＋ 64 负）：

| 侧 | 袋大小 | `α` 的作用面 |
| --- | --- | --- |
| 源年验证侧 | 中位袋 `m = 2` ⇒ `k = 1` | **约半数实体上 `α` 无作用** |
| 训练侧（`truncate_length = 8192` 截断后） | `mean_bag = 32.9`、`mean_k = 16.8` | 作用面显著更大 |

**梯度可达性已独立证实**（同一实验）：`α = None` 时非零梯度流数 `66`（逐实体恒为 `1`）；
`α = 0.5` 时 `5403`（逐实体恒为 `k_e`，不符 `0` 个），且支撑身份**逐位等于**该实体有效流的
top-`k_e`，闭式 `∂L/∂l = g_e/k_e` 偏差 `0.000e+00`，两种 `α` 的逐流梯度余弦仅 `0.111650`。
**故 `α` 确实进入训练图，C11 不会退化为 C01。**

**预注册的含义**：若交互项 `I = C11 − C10 − C01 + C00` 为正但量级偏小，
上述作用面限制是**已登记的结构性解释**，可在正文引用；
**但它不得用于解释 `I ≤ 0`**——机制在半数实体上惰性，只压缩增益幅度，
不改变增益方向。`I ≤ 0` 时仍按预注册判据处置，不得以本节内容开脱。

本节写于 `I` 产出之前，即为杜绝事后找补。

## 四点八、记号歧义的消解裁决（2026-09-03，实现落地时，**仍在任何 C11 运行之前**）

**本节不改定义、不改门槛、不改方向声明**，只记录实现时遇到的记号歧义如何消解。
实现代理（提交 `574d48d`／`21e95cc`）主动列出四处歧义并拒绝自行拍板，由主代理按本文件原文裁决如下。
**四条裁决均写于任何 C11 运行之前，且此后不得按结果修改。**

### 裁决一：观测量二对正实体 `p` 的池化取**并集**

歧义：第 53 行定义写 `A_{p,K}^(e)`（带 `p` 下标），第 56 行 Jaccard 公式却写 `A_K^(e)`（不带）。

**裁定：`A_K = ∪_p A_{p,K}`，即对至少一个已抽样正实体为活动的负实体全体。**

三条依据：
1. **与梯度语义一致**——一个负实体只要与任一正实体构成活动对，就会拿到梯度。
   本观测量的用途是刻画「外层实际作用到哪些实体」，并集才对应这件事。
2. **交集会退化**——`n_pos = 2`，且低档 `K_eff < 1`，取交集常为空集，Jaccard 无定义，
   使观测量失效，与第 59–61 行「排除 `K_eff < 1` 以避免 Jaccard 退化」的意图相悖。
3. 第 124 行 τ 的说理原文「BER 的活动集选的是成对损失最大的负实体」，
   **该表述本身不带 `p` 下标**，隐含的就是跨 `p` 的合并视角。

### 裁决二：`J` 的落盘轮次以显式字段为准，不靠约定

歧义：`J_K^(e)` 定义为 `A^(e)` 与 `A^(e+1)` 的 Jaccard，但轮末落盘时看不到下一轮。

**裁定：第 `e` 轮的收据里存「第 `e−1` 轮末步 → 第 `e` 轮末步」的 Jaccard，
并由收据内的 `jaccard_transition` 字段显式声明该对应关系。**

这只是落盘时机的必然选择，不改变指标本身；配对总数与判读不受影响。
**分析代码必须读 `jaccard_transition` 字段，不得假定索引对应关系**——
本条正是为防止后续误读而写。

### 裁决三：`τ` 的档位池化取合资格档的**并集**

歧义：`τ^(e)` 不带 `K` 下标，而 `A_{p,K}` 按档定义。

**裁定：外层活动集取全部 `K_eff ≥ 1` 合资格档各自活动集的并集**（与裁决一同构）。

依据：第 124–128 行的方向声明理由是「外层活动实体的袋系统性更大」，
其论证对象是「BER 关注的难分负实体」这一整体，**未区分预算档**；
按并集取，恰好对应该论证所指的实体集合。

### 裁决四：`τ` 的分子分母只在负实体范围内计算

**裁定：是。** 第 106 行原文「外层活动实体集为 `A_{p,K}`」，
而 `A_{p,K} = {n : L_pn > ξ_{p,K}}` 的定义域本就是负实体；
第 112 行「即外层关注的实体，其内层尾部占比是否系统性不同」中的对照组
也只能是同域内的非活动负实体。

### 裁决五（**主代理另行发现，不在代理所报四条之内**）：轮次窗口改用第 `5`–`10` 轮

**冲突**：第 63 行「第 `15`–`20` 轮给出 `5` 个相邻轮对」、第 114 行 τ「第 `15`–`20` 轮要求 `6/6` 同向」，
**均假定 `20` 轮运行**；而本机四格的冻结预算是 **`10` 轮**
（见 `thesis/methods/第三章定案.md`，本机 `d=32`／1 层，`20` 轮不可行）。

**裁定：观测量二与三′ 一律取第 `5`–`10` 轮**（`6` 个轮次）。

- 观测量二：相邻轮对为 `(5,6) (6,7) (7,8) (8,9) (9,10)` = **`5` 对**，
  × `3` 个合资格档 = **`15` 组**，与已冻结临界值 `n_high ≥ 12` 的 `n = 15` **精确吻合**。
- 观测量三′：`6` 个轮次给 `6` 个 `τ` 值，与「`6/6` 同向」的要求 **精确吻合**。

**为什么这不是放宽门槛**：两个门槛（`n_high ≥ 12 of 15`、`6/6`）
都只依赖**计数**，不依赖具体是哪几轮；第 69–75 行的临界值推导也只用 `n = 15`。
原文写 `15`–`20` 的用意是「取运行的后段」，而在 `10` 轮预算下第 `5`–`10` 轮即为对应后段
（与 AP 读数窗口第 `8`–`10` 轮同属后段，口径自洽）。

**边界**：本条是**窗口平移**，不是门槛调整。若将来在 `20` 轮预算下重跑，
应回到原文的第 `15`–`20` 轮，两者结果不得混用。

## 四点九、`nonargmax_grad_share` 的判读门槛（2026-09-04 冻结，**写于 C11 任何结果之前**）

联动主张「ETA 拓宽 BER 的梯度支撑」的观测量是
`ranking.nonargmax_grad_energy_share`：BER 的梯度能量落在**非 argmax 流**上的比例。
此前只写了「接近 `0` 即证伪」，**没有数值**，不可机械判定。本节补齐。

### 关键事实：该量的天花板不是 `1.0`，是 `0.2207`

ETA 在 `α = 0.5` 下每实体只选 `k_e = ⌈m_e/2⌉` 条流。梯度**均匀**摊在选中流上时，
非 argmax 份额恰为 `(k_e − 1)/k_e`；全压在一条上时为 `0`。
故该量的**可达上限由袋大小分布唯一决定**。

本机 2026-09-04 只读实测（源年训练角色，`seed=42`、`validation_fraction=0.10`、
`time_tail_fraction=0.15`，共 `121,501` 个实体、`208,598` 个片段）：

| 量 | 实测 |
| --- | ---: |
| 袋大小 P50／P75／P90／P95／P99 | `2` ／ `3` ／ `9` ／ `30` ／ `511` |
| 袋大小均值／最大 | `98.7` ／ `2,129,920` |
| **`k_e = 1` 的实体占比（ETA 完全惰性）** | **`67.8%`** |
| **可达上限 `(k_e−1)/k_e` 实体加权均值** | **`0.2207`** |
| 仅在 `k_e > 1` 的实体上 | `0.6857` |

排序批按 `n_neg = 64` 均匀采样负实体，故**批级期望可达上限 ≈ `0.2207`**。

该结果独立印证了尾部聚合参数裁决记载的「作用面 `31.6%`」：`1 − 0.678 = 32.2%`。

### 判读（三分，**不得事后修改**）

以第 `8`–`10` 轮的轮级均值 `s` 为准，效应量用归一化的**摊开效率**
`η = s / 0.2207`：

| 条件 | 判读 |
| --- | --- |
| `s ≥ 0.1104`（`η ≥ 0.50`） | **联动成立**——ETA 实现了可达摊开量的一半以上 |
| `s < 0.0500`（`η < 0.23`） | **联动证伪**——梯度仍集中在 argmax 单条流，ETA 未拓宽支撑 |
| 两者之间 | **不确定**，不得单独作为创新点依据，须补独立证据 |

**证据等级声明**：`0.2207` 这个天花板是**本课题实测**；
`0.50` 与 `0.23` 两条分割线是**任务化设定，无文献依据**——
选 `0.50` 是「至少实现一半可达量」的自然中点，`0.23` 是其下的对称留白。
**记为任务化设定，不得写成文献支持。**

### 为什么绝对阈值必然错

主代理曾提议「`s < 0.05` 判证伪」。按上表，`0.05` 已是可达上限的 `23%`，
是相当强的信号，却被当成「接近 `0`」。**凡未除以天花板的绝对阈值都会犯同型错误。**

## 交互项标尺的更换（2026-09-04，**C11 读数尚不存在时写下**）

**合法性凭据**：写下本节时 C11 运行目录刚创建、`selection.json` 尚无任何轮次记录，
C00／C10／C01 三格已完成。**本次更换在 C11 任何 AP 读数产生之前。**

### 事实：加法交互项已算术不可达

三格实测（各按自身配置声明的 `evaluation.entity_aggregation`，见第三章定案 §2.2 之二）：

| 格 | 实体 AP | 错误率 `e = 1 − AP` |
| --- | ---: | ---: |
| C00 | `0.691031` | `0.308969` |
| C10 | `0.796184` | `0.203816` |
| C01 | `0.918431` | `0.081569` |

加法交互 `I = (C11 − C10) − (C01 − C00) > 0` 要求
`C11 > 0.796184 + 0.227400 = 1.023584`——**超过 AP 的上界 `1`，恒不可满足。**

**这是天花板效应，不是机制失败。** C01 单机制已到 `0.918`，加法尺度上没有剩余空间。
**保留该判据等于无论 C11 出什么数都判证伪，那不构成检验。**

### 更换：改用误差尺度的乘性交互

**新判据**（在 C11 读数存在前冻结）：

```
乘性交互成立  ⟺  e11 / e10  <  e01 / e00
```

代入实测：`e01/e00 = 0.264004`，`e10 = 0.203816`，故

| 裁定 | 条件 | 等价的 C11 AP |
| --- | --- | ---: |
| **联动成立** | `e11 < 0.053808` | `C11 > 0.946192` |
| **联动证伪** | `e11 > e10 × 1.0 = 0.203816` | `C11 < 0.796184`（即 C11 不如 C10） |
| **不确定** | 介于两者之间 | `0.796184 ≤ C11 ≤ 0.946192` |

**为什么用误差尺度**：AP 有上界，接近上界时加法差值被压缩，加法交互对「两个都已很强的机制」
系统性不利。误差相对下降不受上界压缩，是本仓库既有惯例——
根 `AGENTS.md` 的效果量级参照里，「错误相对下降 `16.1%`」本身就是误差尺度的门槛。

### 必须披露的边界（不得省略）

1. **本次更换发生在已看到 C00／C10／C01 之后**，只在 C11 之前。
   **属于部分事后**，不是完整预注册。正文与过程文档引用该判据时必须同时说明这一点。
2. 更换的理由是**旧判据算术不可达**，这一点独立于 C11 的任何取值，
   可由上表三个数字机械复核。**不是因为旧判据对结果不利而更换。**
3. **旧判据的读数照常记录**：C11 出数后仍计算并留档加法 `I` 的值，
   不因换尺度而隐藏。两个尺度并列呈现。
4. 门槛 `0.946192` 由 `e10 × (e01/e00)` 机械算得，**不含任何人为选择的余量**；
   C11 出数后不得调整。

## §四点九 的天花板归一化作废（2026-09-04，**C11 第 8–10 轮窗口尚不存在时写下**）

**合法性凭据**：写下本节时 C11 只完成第 `1`、`2` 轮，判读窗口第 `8`–`10` 轮的读数尚不存在。
触发本次复核的是 C11 前两轮实测 `nonargmax_grad_share = 0.3448 / 0.3127`，
**超过 §四点九 声称的"可达上限" `0.2207`**，即观测值越过了假定的最大值。

### 一、`0.2207` 错在哪：两处口径错配

源码闭式（`ch3_ft_entity_ranking_loss.py:372-384`）：

```
share = 1 − (Σ_e g_e²/k_e²) / (Σ_e g_e²/k_e)
```

| 项 | §四点九 用的 | 闭式实际要求的 |
| --- | --- | --- |
| 总体 | 全部 `121,501` 个实体 | **只有 `g_e ≠ 0` 的实体**，即参与违序对的活动实体 |
| 权重 | **实体计数**加权的 `(k_e−1)/k_e` 均值 | **`g_e²/k_e`** 加权 |

活动实体倾向于是袋更大的那些，`k_e` 更大，故其可达份额高于全体实体的计数加权均值。
**这解释了实测为何能超过 `0.2207`。**

### 二、更根本的问题：这个量没有固定天花板，也不是效率

把闭式整理为 `share = 1 − E_w[1/k_e]`（`w_e ∝ g_e²/k_e`）后可见：

**它完全由当前活动实体的 `k_e` 分布决定，不含任何"可达量实现了多少"的余量**——
闭式本身就已假设梯度均匀摊在 `k_e` 条选中流上。故 `share` 是**活动实体袋大小的描述统计**，
**不是摊开效率**。「`η = s / 天花板`」这套框架自始不成立，**不是常数取错这么简单**。

### 三、处置：撤上侧阈值，保留下侧证伪

| 原判据 | 处置 |
| --- | --- |
| `s ≥ 0.1104`（`η ≥ 0.50`）⟹ **联动成立** | **撤销。** 它建立在不存在的天花板上，无法重新标定 |
| `s < 0.0500` ⟹ **联动证伪** | **保留。** `k_e ≡ 1` 时 `share` 恒为 `0`，故 `share ≈ 0` 确实等价于「ETA 完全惰性」，这正是最初「接近 `0` 即证伪」要测的性质 |
| 两者之间 ⟹ 不确定 | 改为：`s ≥ 0.05` 只支持「**ETA 非惰性**」这一条弱结论 |

**本次修改削弱了可声称的强度**（不再能写「实现了可达摊开量的一半以上」），
**不是向有利方向调整**，可由第一、二节的口径分析机械复核。

### 四、连带作废

- `第三章定案.md` 二之二节引用 `0.2207` 与 `η` 三分表的段落须同步改写。
- 复审发现文档中「已修：预注册文档 §四点九 已补门槛，锚定该量天花板 `0.2207`」
  这条裁定**随之失效**，该严重项回到「未关闭」。

### 五、仍然成立的实测

C11 第 `1`、`2` 轮 `share = 0.3448 / 0.3127`，**远高于 `0.05`**，
故「ETA 完全惰性」这一证伪假设在前两轮已不成立。
**但判读窗口仍为第 `8`–`10` 轮，前两轮不作数**，此处只作方向记录。
