# 机制一实体路径最大风险控制正式方法与实验方案

- **日期**：2026-08-19
- **状态**：正式方法与实验预注册草案；尚未完成正式多种子和目标年度实验。
- **代理映射**：`ch4_mechanism1_formalization_sol_max → gpt-5.6-sol → effort=max`
- **方法对象**：冻结模型分数上的实体路径最大风险控制，不更新分类模型，不把同一实体的相关前缀当作独立样本。
- **当前证据等级**：LSPR23、种子 42、三个折外模型、六个交叉校准方向的源年单种子 Q0 实验支持。该等级不是跨年度支持，也不是论文正式结果。

## 一、结论与唯一推荐

1. 机制一把同一实体的因果前缀风险序列压缩为一个路径最大统计量，再用独立良性实体的 Tong 纽曼—皮尔逊次序统计量确定阈值。在线端只维护累计和、曝光数和首次越界状态；在冻结的有限路径合同内，“路径最大值严格大于阈值”与“逐曝光首次严格越界”是同一事件。
2. 当前 Q0 已通过预注册机械门：六个方向的有限样本证书均有效，汇总实体假阳率为 `0.03711089397172313≤0.04`，检出率为 `0.9832635983263598>0.9707112970711297`。该事实仅支持进入正式实验，不支持写成跨年度有效或第四章方法已经成立。
3. 正式部署唯一推荐为：**先预留模型训练之外的独立校准实体和独立评价实体，训练一个不再重训的最终模型，再用该模型在独立校准良性实体上计算自己的路径阈值，并将模型哈希、分数合同、实体路径合同和阈值收据强绑定。**禁止把折模型阈值迁移到全量重训模型。
4. “三个模型各自阈值再组合”在理论上可以另行设计，但必须额外定义组合告警事件、重新分配风险预算并校准组合规则。它增加推理成本和证书复杂度，本任务没有证据证明其优于单模型，因此不作为正式部署方案。
5. 容量算术只能证明校准样本数远高于 Tong 阈值存在条件，不能证明两个训练折中的 `160` 个正实体足以训练最终模型。该承重假设必须由不读取 LSPR24 的真实 LSPR23 单模型实验裁决，本文不把它写成已支持。

## 二、问题定义与可观测量

### 2.1 任务与统计单元

令实体为 `e`，其在冻结观测区间内按稳定时间顺序形成有限曝光路径

```text
P_e = {(x_{e,1}, t_{e,1}), ..., (x_{e,L_e}, t_{e,L_e})},
t_{e,1} <= ... <= t_{e,L_e}.
```

其中 `x_{e,j}` 只包含冻结合法字段；原始实体标识只用于分组、去重和顺序恢复，不作为模型输入。`L_e` 是该实体在预先定义的捕获区间内的已记录曝光数，不是无限寿命。正式方法的统计单元是**实体路径**，不是流、前缀或告警次数。

冻结模型 `f_θ` 对第 `j` 次曝光输出逐流风险 `r_{e,j}`。沿用第三章冻结的 `semantic168`、`p=1` 因果聚合语义，定义路径运行均值

```text
s_{e,j} = (1 / j) * Σ_{u=1}^j r_{e,u}.
```

实现须保持 Q0 的数值合同：逐流分数裁剪到 `[1e-7, 1]`，累计使用 `float64`，再按冻结接口形成前缀分数。不得用标签、未来曝光或最终路径长度改变任一前缀分数。

实体路径最大统计量为

```text
Z_e = max_{1 <= j <= L_e} s_{e,j}.
```

良性实体标签 `Y_e=0` 只在模型训练之外的阈值校准和封印后的评价中使用；在线推理不读取实体标签。攻击标签 `Y_e=1` 不参与 Tong 阈值选择，只用于评价检出率。

### 2.2 可观测量清单

| 阶段 | 可观测量 | 禁止量 |
| --- | --- | --- |
| 模型训练 | 训练实体的合法流字段、时间顺序、训练标签 | 校准实体、源年评价实体、LSPR24 任一数组或标签 |
| 阈值校准 | 已冻结模型对独立校准实体产生的 `r_{e,j}`、`s_{e,j}`、`Z_e`；仅良性标签用于选阈值 | 评价实体分数与标签、LSPR24、候选阈值网格搜索 |
| 在线部署 | 当前实体标识、时间戳、逐流风险、累计和、曝光数、是否已告警 | 当前或未来真实标签、未来曝光、目标年度统计量自适应 |
| 封印后评价 | 预先冻结的模型—阈值对产生的聚合 FP、TP、FPR、DR、首次告警位置与资源收据 | 根据评价结果改模型、阈值、路径范围、比较符或实体集合 |

主预算为 `q=0.04`。其依据是既有 Gehri 2023 全文笔记所核验的 Locked Shields 同源主机聚合经验区域（物理第 13、15 页）；本课题只把它作为标准化比较端点，不称为通用安全运营容忍度。全局违约概率为 `δ=0.05`，与 Tong 2018 算法 1 的默认容忍水平一致。两者的含义不同：`q` 约束总体第一类错误，`δ` 约束校准样本随机性导致该总体错误超过 `q` 的概率。

## 三、Tong 路径最大控制与在线规则

### 3.1 次序统计量和违约概率

固定模型、分数合同和路径定义后，设独立良性校准实体的路径最大统计量为

```text
Z_1, ..., Z_n,
```

升序次序统计量为 `Z_(1) <= ... <= Z_(n)`。对候选次序位置 `k` 定义 Tong 违约概率上界

```text
v_n(k; q) = Σ_{j=k}^n C(n,j) * (1-q)^j * q^(n-j).
```

给定该证书承担的违约概率 `δ_i`，取

```text
k* = min{k in {1, ..., n}: v_n(k; q) <= δ_i},
τ_path = Z_(k*).
```

阈值存在的最低样本条件来自最极端次序位置 `k=n`：

```text
(1-q)^n <= δ_i,
n >= ceil(log(δ_i) / log(1-q)).
```

令冻结总体上的实体第一类错误为

```text
R_0(θ, τ_path) = P(Z_e > τ_path | Y_e=0, θ, 路径合同).
```

在 Tong 2018 命题 1 的独立保留 0 类样本条件下，

```text
P_calibration(R_0(θ, τ_path) > q) <= v_n(k*; q) <= δ_i.
```

该概率对校准实体的随机抽样取值，不是“观测到的评价 FPR 必然不超过 `q`”。连续分数条件使上界达到紧界；存在并列时，本方案坚持严格比较 `>`，阈值并列不会被计为越界，因而只会使规则更保守。收据必须同时记录 `k*`、`v(k*)`、`v(k*-1)` 和阈值并列数，以证明 `k*` 确为最小可行位置。

### 3.2 严格大于首次越界在线规则

在线端定义首次越界曝光

```text
T_e = inf{j >= 1: s_{e,j} > τ_path},
```

若整个冻结路径都不越界，则 `T_e=+∞`。实体只在 `T_e` 时发出一次告警，后续曝光不重复计数。对任意有限已记录路径，有恒等关系

```text
I(T_e < +∞)
= I(存在 j 使 s_{e,j} > τ_path)
= I(max_j s_{e,j} > τ_path)
= I(Z_e > τ_path).
```

因此路径最大统计量只用于校准和离线解释；部署不需要等路径结束，也不需要保存整条分数序列。每个未告警实体只需维护 `sum_score`、`exposure_count` 和最后时间戳，空间复杂度为每个活跃实体 `O(1)`，单次曝光更新为 `O(1)`。

### 3.3 假设边界

Tong 证书在本任务中的有效性同时依赖以下条件：

1. 模型、字段、分数变换、实体键、时间排序、路径终止规则和严格比较符在校准前已经冻结。
2. 校准实体没有参与模型训练或任何候选选择；评价实体也没有反向影响阈值。
3. 良性校准实体路径与所声明总体同分布或至少满足论文所需的独立同分布抽样语义。实体内部前缀可以高度相关，因为它们先被压缩为一个 `Z_e`；实体之间若因同一主机群、演习阶段或攻击活动产生强簇相关，名义证书可能失真。
4. 证书覆盖的是校准分布下的完整有限路径事件。它不覆盖无限实体寿命、任意延长的观察窗口、改变实体终止规则或未来路径长度分布。
5. 源年证书不迁移到 LSPR24。跨年度只能通过冻结后的一次经验评价检验，不能称为仍有 `1-δ` 的 Tong 保证。
6. 证书只控制实体假阳率，不保证检出率、告警时延、校准质量或漂移机制正确。

### 3.4 三模型乘双向源年 Q0 为何使用 `δ/6`

Q0 的三个折外模型分别在另两个实体折上训练，并只给自己的留出折打分。每个留出折再按类别确定性二分为 `half0` 与 `half1`，形成两个方向：`half0` 校准、`half1` 评价，以及 `half1` 校准、`half0` 评价。总计

```text
3 个折模型 * 2 个校准/评价方向 = 6 个阈值证书。
```

令第 `i` 个证书的失败事件为 `E_i={R_{0,i}>q}`。Q0 要同时声称六个阈值证书有效，故预先分配

```text
δ_i = δ / 6 = 0.008333333333333333,
P(任一证书失败) <= Σ_i P(E_i) <= 6*(δ/6) = δ = 0.05.
```

并合界不要求六个事件相互独立，因此三个模型共享训练实体、同一留出折的两半交换角色，都不破坏并合界本身。但**每一个**方向仍须满足：模型未见该留出折、校准半与评价半实体零交集、阈值只由该方向的校准良性实体产生、校准和评价分数来自同一个冻结折模型。`δ/6` 不能修复模型见过校准实体、实体簇相关、路径合同变化或跨年度分布移位。

`δ/6` 是 Q0 六个同时声明的产物，不是方法常数，也不是因为正式方案有六个比较臂。正式单模型若只声明一个主证书可使用 `δ`；正式三种子若要同时声明三个种子各自的主证书，应使用 `δ/3`。若每个种子还要同时声明两个受证书覆盖的统计量，才会再次形成 `3*2=6` 个证书并使用 `δ/6`。

### 5.4 复算命令与局限

实际验证入口为：

```bash
python3 - <<'PY'
import json, math
from pathlib import Path

p = Path('thesis/experiments/llm_probe/runs/diagnostics/'
         'ch4-xgb-entity-path-max-tong-same-model-q0-seed42-v1/summary.json')
d = json.loads(p.read_text())
q, delta, m = d['entity_fpr_budget'], d['global_violation_probability'], d['simultaneous_round_count']
pi, delta_i = 1 - q, delta / m

def tail(n, k):
    log_t = (math.lgamma(n+1)-math.lgamma(k+1)-math.lgamma(n-k+1)
             + k*math.log(pi)+(n-k)*math.log(q))
    term, terms = math.exp(log_t), []
    for j in range(k, n+1):
        terms.append(term)
        if j < n:
            term *= ((n-j)/(j+1))*(pi/q)
    return math.fsum(terms)

def kstar(n):
    lo, hi = math.ceil(n*pi), n
    assert tail(n, lo) > delta_i
    while lo < hi:
        mid = (lo+hi)//2
        if tail(n, mid) <= delta_i:
            hi = mid
        else:
            lo = mid+1
    return lo

for row in d['rounds']:
    receipt = row['path_threshold_receipt']
    k = kstar(receipt['population'])
    assert k == receipt['rank_one_based']
    assert tail(receipt['population'], k) <= delta_i < tail(receipt['population'], k-1)

for arm in ('B0_first', 'B1_all_source', 'M1_path_max_tong_same_model_crosscal'):
    metrics = [row['metrics'][arm] for row in d['rounds']]
    neg = sum(x['negative_entities'] for x in metrics)
    pos = sum(x['positive_entities'] for x in metrics)
    fp = sum(x['false_positive_entities'] for x in metrics)
    tp = sum(x['detected_positive_entities'] for x in metrics)
    assert math.isclose(fp/neg, d['aggregate'][arm]['entity_fpr'], abs_tol=1e-15)
    assert math.isclose(tp/pos, d['aggregate'][arm]['detection_rate'], abs_tol=1e-15)
PY
```

该复算验证聚合制品内部的统计一致性，不能替代逐实体分数重放；Q0 按合同未持久化这些分数，因此无法独立确认具体实体集合、阈值并列实体身份或路径状态更新的逐实体轨迹。

1. **首要安全指标**：实体 FP、良性实体分母和实体 FPR；源年同时报告 M1 的 Tong 证书，目标年只报告经验 FPR 与 `95%` 区间，不声称源证书迁移。
2. **首要效用指标**：实体 TP、正实体分母、实体 DR，以及 `ΔDR=DR(M1)-DR(B0)`。
3. **迟到收益**：`late_TP=TP(M1)-TP(B0)`，并报告新增检出实体的首次告警曝光序号和实际时延分布。
4. **误报代价**：`ΔFP=FP(M1)-FP(B0)`；同时报告 M1 相对 B1 与 B3 的 FP／TP 变化，禁止只报有利差值。
5. **配对不确定性**：同一评价实体上的两臂结果形成二元配对表；FPR 与 DR 差值使用配对比例区间或精确不一致对检验。三个种子逐一报告，不把三种子平均值冒充独立实体样本。
6. **种子汇总**：报告每个种子的原始计数、点估计和区间，再给最小值、最大值和描述性均值。三个种子不被当作足以估计任意训练随机性总体的独立大样本。

正式支持门为：输入与泄漏门全部通过；三个种子的源年 M1 证书按 `δ/3` 同时有效；目标年每个种子的 M1 经验 FPR 均不超过 `q`；每个种子的 `ΔDR` 均为正，且配对 `95%` 区间不跨 `0`。若点估计为正但区间跨 `0`，结论为“实验待证／证据不足”；任一种子超预算或差值非正，不得用种子平均掩盖。

### 7.4 预算曲线

不手工指定一组百分比网格。对每个校准集，以允许的良性实体告警整数 `b` 为横轴，枚举

```text
b = 0, 1, ..., floor(q * n_cal^-),
q_b = b / n_cal^-.
```

在每个可达到的 `q_b` 上按各臂冻结规则产生阈值，并在同一评价集报告实现的 FPR、DR、FP、TP，形成从零预算到主预算 `q` 的完整离散前沿。曲线只作描述性敏感性分析；唯一确认性证书点仍为 `q=0.04`。若要对多个 `q_b` 同时作总体保证，必须另做多重性分配，不能把整条曲线都标成 `1-δ` 证书。

### 7.5 效率与资源

| 维度 | 必报量 | 比较方式 |
| --- | --- | --- |
| 共同模型成本 | 训练墙钟、峰值 RSS、峰值 GPU 显存、模型字节数 | 每个种子报告一次，不重复计入六臂 |
| 校准成本 | 路径状态构造、次序统计量选择墙钟与峰值内存 | B0/B2/B3/B4/M1 分项；输入共享时同时给联合成本 |
| 在线增量成本 | 每流更新时间、每秒流数、每秒实体状态更新数 | M1 相对 B0；排除共同模型推理后另报控制开销 |
| 状态成本 | 活跃实体数、每实体状态字节、状态总峰值 | M1 应为每实体 `O(1)` |
| 告警成本 | 告警实体数、重复告警抑制数、首次告警时延 | 与 B1 的重复查看代价对照 |
| 持久化成本 | 聚合制品和模型字节数 | 禁止逐流／逐实体分数文件 |

效率测量必须在无并发任务的隔离运行中完成。Q0 的 `204.244` 秒和 `16.6 GiB` 只作排程证据，不直接成为正式效率结果。

## 八、三种子正式实验与目标年度泄漏边界

### 8.1 固定阶段

1. **阶段 A：合同封印**。冻结实体三折和半折哈希、合法字段、模型超参数、种子 `42/43/44`、完整路径终止规则、六臂、`q=0.04`、全局 `δ=0.05`、严格 `>`、指标、统计规则和输出白名单。三个种子是本任务预注册的训练随机性检查，不是根据结果选择。
2. **阶段 B：模型训练**。三个种子分别只使用折 0＋折 1 训练。它们是三份独立的最终候选模型，不是运行时集成。不得读取折 2 或 LSPR24 统计量进行早停、标准化、选参或模型选择。
3. **阶段 C：模型专属校准**。每个模型只在折 2 `half1` 的 25,073 个良性实体路径上产生自己的阈值。三个 M1 证书同时声明，故每个使用 `δ/3`。模型和阈值逐一强绑定，不池化阈值。
4. **阶段 D：源年独立评价**。只在折 2 `half0` 评价六臂。任何失败只能导致停止或如实否决；不得交换两半、扩大训练区或改阈值。此阶段不读取 LSPR24。
5. **阶段 E：目标前封印**。写入模型、阈值、配置、代码、实体清单、输入、统计脚本和输出模式哈希；机械断言此前 `target_year_arrays_read=0`。
6. **阶段 F：目标年一次评价**。对 LSPR24 全量 `47,115` 个实体按冻结合同逐种子运行。先生成并封印聚合预测状态，再开放标签计算指标；不得用目标标签选择种子、阈值、预算、路径长度、基线或评价子集。
7. **阶段 G：结果分析**。只运行预注册统计与效率汇总。若结果不支持，否决、缩小或重构方法；任何新方案必须使用新身份，且不能复用已经开放的 LSPR24 作为选择集。

### 8.2 泄漏和无效条件

出现下列任一项，受影响运行记为无效而不是科学失败：

- 模型训练或标准化接触校准、源年评价或 LSPR24 实体；
- 阈值来自另一模型、另一分数合同或另一实体路径定义；
- 在目标标签开放后选择种子、阈值、观察长度、实体子集或比较臂；
- 把同一实体的前缀当成独立校准样本；
- 目标年改变路径终止规则、字段、时间排序或实体键；
- 只报告最好种子、最好预算或最好路径分面；
- 把目标年经验 FPR 写成 Tong 同分布证书。

LSPR24 全量是一次最终跨年度经验评价，不再拆出可供调参的新目标开发集。目标年标签开放后，即使发现失败，也不得在同一论文证据链上修改机制再重测该年度。

## 九、与朱焱雷第四章的深度、工作量和禁止主张
