# B76 磁盘安全清理只读审计计划

## 目标

在不影响活动 CUDA-RWKV 训练、Raw83、Dijk 缓存、虚拟环境或原始数据的前提下，核验历史制品回收完整性并给出精确删除候选。第一阶段只读，不执行删除。

## 边界

- 文档所有权仅限本目录。
- 远端仅通过项目内脱敏直连入口读取 `screen`、进程、磁盘和候选目录元数据。
- 明确保护活动 `ch3-cuda-rwkv-raw83-qualification-seed42-v1` 与 `ch3-grande-lspr24-zero-train-descriptive-eval-bf16-v1`。
- 禁止删除、移动、压缩或修改任何远端或本机运行制品。

## 阶段与状态

- [x] 读取根、实验工程、脚本、RWKV 和过程文档规则，以及协作看板第十节和既有 B76 审计。
- [x] 只读核验 B76 活动会话、相关进程与磁盘。
- [x] 核验四个指定历史目录的远端存在性及本机普通文件数、逻辑字节、逐文件 SHA-256 聚合、检查点可读性。
- [x] 盘点本轮诊断与微批四工程归档目录。
- [x] 形成删除阻断、候选和风险报告。
- [ ] 等待主进程针对精确路径的继续指令；未收到前不得删除。

## 验收

- 每个指定目录均记录远端与本机相对路径、普通文件数、逻辑字节、聚合哈希和检查点证据。
- 报告明确活动和强制保留范围。
- 任何删除候选必须先满足远端存在、本机完整逐项核验和主进程精确路径授权。
