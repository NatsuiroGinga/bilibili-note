# XGBoost 双机制 GPU 冻结方案草案

- **日期**：2026-08-18
- **路线**：`RESEARCH_ROUTE=RWKV`
- **状态**：设计可行；实验待证；用户批准前不实施
- **适用范围**：第三章 CPA、ELP 的 XGBoost 普适性验证，以及第四章、第五章共同基座候选选择
- **执行约束**：只设计，不写代码，不启动资源探针、训练、推理或 LSPR24 评价

## 一、方案结论

本方案把 XGBoost 四格组织为**六次源年折外拟合、两次全量最终拟合和四种实体评价映射**：

1. raw 与 context 分支各做 LSPR23 实体分组三折折外预测，分别选择 `p_raw` 与 `p_ctx`；
2. 选幂后，原始 83 维模型与 168 维上下文模型各在全量 LSPR23 上最终拟合一次；
3. 最终 raw 逐流分数同时服务 `B0` 与 `ELP`，最终 context 逐流分数同时服务 `CPA` 与 `CPA+ELP`，因此四个目标年格只需两路最终分数；
4. CPA 冻结为“语义白名单上的段内含当前位置前缀残差适配器”，不对端口、协议或类别编码作算术平均；
5. 八次拟合均在同一 RTX 5090 上使用 `device=cuda` 和同一 XGBoost 预算；`max_gpu_fits=1`，不安排两个模型同时训练；
6. 主评价为实体 AP，同时报告完整告警预算曲线、`DR@4%FPR`、逐流 AP、前 k 精确率、配对实体自助区间和效率；
7. XGBoost 完整格进入共同基座候选集合，但是否入选要等所有骨干按同一规则完成后决定。

这一方案只说明接口、资源和比较设计可执行。CPA、ELP 及其组合是否有效，均为实验待证。

## 四、CPA 原始特征挂载方案比较

### 4.1 统一分段与前缀定义

无向二 IP 实体记为 `e`，沿用神经 CPA 已冻结的 `I/M` 分段，段记为 `g`，每段长度 `L_{e,g}≤128`。段内按 `(mTimestampStart, 原始行号)` 稳定排序；第 `t` 条流的前缀包含当前位置：

\[
P_{e,g,t}=\{i\mid 1\le i\le t\},\qquad n_{e,g,t}=t.
\]

所有累积器在每个 `I/M` 段首重置，不能跨段继承；当前位置可用，`t` 之后的位置不可用。主协议沿用 `mTimestampStart` 只保证冻结序列上的相对顺序因果，以保持跨骨干可比；既有审计中 LSPR24 有 43.70% 的位置出现前序流结束更晚，因此该口径不等同于严格在线可用性，本方案不把排序键消融作为前置门禁。

### 4.2 三种候选

| 候选 | 数值量挂载 | 离散／布尔挂载 | 总维数 | 优点 | 代价 |
| --- | --- | --- | ---: | --- | --- |
| A：语义前缀均值 | 当前 83 维＋76 个段内前缀均值 | 5 个同值频率＋2 个真值率＋2 个支持量 | 168 | 保留当前值与前缀中心 | 轴对齐树需间接组合两者才能表达偏离 |
| B：语义前缀残差 | 当前 83 维＋76 个当前值减段内前缀均值 | 5 个同值频率＋2 个真值率＋2 个支持量 | 168 | 直接暴露偏离；与 A 等宽；保留原始当前值 | 不再是隐藏表示前缀均值的原样拼接 |
| C：均值与残差双拼接 | 当前 83 维＋76 个段内前缀均值＋76 个残差 | 5 个同值频率＋2 个真值率＋2 个支持量 | 244 | 同时暴露中心与偏离 | 信息冗余，密集矩阵、量化与训练开销更大 |

另一个可想到的方案是把第一棵 XGBoost 的叶索引或分数再堆叠给第二棵模型。它会引入标签训练的中间表示和额外拟合，不再是原始特征 CPA，也破坏 raw／context 共同预算，因此本轮不纳入。

### 4.3 推荐冻结：候选 B

对 76 个数值字段 `j`，定义段内含当前位置的前缀均值与残差：

\[
\mu_{e,g,t,j}=\frac{1}{t}\sum_{i=1}^{t}x_{e,g,i,j},\qquad
\delta_{e,g,t,j}=x_{e,g,t,j}-\mu_{e,g,t,j}.
\]

对 5 个离散字段 `k`，定义当前取值在同一段前缀中的同值频率：

\[
f_{e,g,t,k}=\frac{1}{t}\sum_{i=1}^{t}\mathbf{1}
\left[x_{e,g,i,k}=x_{e,g,t,k}\right].
\]

对 2 个布尔字段 `b`，定义同一段前缀真值率：

\[
r_{e,g,t,b}=\frac{1}{t}\sum_{i=1}^{t}x_{e,g,i,b}.
\]

两个支持量冻结为 `log1p(prefix_count)` 与 `is_segment_start`，即 `log(1+t)` 和 `1[t=1]`。段首残差为 0、离散同值频率为 1、布尔真值率等于当前布尔值，不再使用与含当前位置公式矛盾的冷启动填充值。最终输入为：

\[
z_{e,g,t}=[x_{e,g,t};\delta_{e,g,t};f_{e,g,t};r_{e,g,t};
\log(1+t);\mathbf{1}(t=1)]\in\mathbb{R}^{168}.
\]

维数必须逐项核对为“当前 83＋数值残差 76＋离散同值频率 5＋布尔真值率 2＋支持量 2＝168”，不能简写成“83＋83＋2”。适配器不读取标签、其他实体、后续位置或跨段状态，也不计算目标年度全局统计。

### 4.4 与隐藏表示 CPA 的差异

神经 CPA 先学习隐藏表示 `h_t=f_θ(x_t)`，再在每个最多 128 条的 `I/M` 段内计算包含当前位置的隐藏前缀，并在跨段时重置。XGBoost 适配版与其共享分段、稳定顺序和 `i≤t` 边界，但有四处实质差异：

1. 聚合对象是按语义审计后的原始字段，不是可学习隐藏向量；
2. 推荐方案挂载 76 个当前值相对原始字段前缀均值的残差，不挂载隐藏前缀向量；
3. 离散量使用同值频率，布尔量使用真值率，端口和类别编码不作算术平均；
4. 适配器没有梯度，XGBoost 只在固定的 168 维输入上学习分裂。

因此论文中的准确名称应为“CPA 的 XGBoost 原始特征适配”或“语义前缀残差适配器”。若实验结果提供正向证据，可支持机制具有跨骨干可适配性；不能写成同一隐藏表示公式被原样移植。

## 五、ELP 的源年选择

### 5.1 实体归约公式

对模型给出的实体内逐流概率 `s_i∈[0,1]`，ELP 实体分数采用幂平均：

\[
M_p(e)=\left(\frac{1}{n_e}\sum_{i\in e}s_i^p\right)^{1/p}.
\]

累积使用 `float64`，最终实体分数转换为 `float32`，与既有评价口径一致。CPA 在段界重置上下文，但 ELP 仍对同一无向二 IP 实体跨各段的全部逐流分数归约。由于候选含 `p=0.5`，正文不把它称为 Lp 范数。无 ELP 格使用独立精确分支 `M_∞(e)=max_i s_i`，不用有限大 `p` 近似。

### 5.2 实体分组三折折外预测

LSPR23 的源年选择不再使用约 20 个正实体的单一验证区，而使用实体分组三折折外预测：

1. 无向二 IP 实体标签定义为其流标签最大值；以种子 42 按实体标签分层形成三折；
2. 同一实体的全部流必须留在同一折，raw 与 context 两路共用同一份折号；
3. 第 `k` 次拟合只用另外两折实体训练，对第 `k` 折全部流预测；
4. raw 三次、context 三次，共六次选择阶段拟合；
5. 合并三折后，每条 LSPR23 流恰好有一次由未训练过其所属实体的模型产生的折外分数；
6. `p_raw` 与 `p_ctx` 只在各自汇总后的全量 LSPR23 折外分数上选择，不使用模型对训练实体的原位预测。

context 特征可在拟合前按冻结公式确定性物化，但留出折实体的每个特征只能来自该实体同段 `i≤t` 的无标签原始字段；不得使用训练折实体、标签或模型输出构造上下文。

三折使用全部源年实体，比小验证区提供更多正实体参与选择；它不自动意味着选中的 `p` 稳定，折间变化和重抽样分布仍需如实报告。

### 5.3 有限网格、目标与并列规则

两路分数分别选择：

\[
p_{raw}\in\{0.5,1,2,4,8\},\qquad
p_{ctx}\in\{0.5,1,2,4,8\}.
\]

选择目标仅为汇总折外预测得到的 LSPR23 实体 AP。网格不包含借用 C11 的 `1.223554`，精确最大值只作对应无 ELP 格的比较算子。具体规则为：

1. 分别计算五个候选的汇总折外实体 AP，并保留全精度值；
2. 选择全精度实体 AP 最大的候选，不设置容差或“同档”；
3. 只有全精度 AP 完全相等时，先取 `|log2(p)|` 最小者；仍相等时取较小 `p`；
4. 将折号、折级实体计数、完整网格、汇总实体数、各候选 AP、选中值与六个折模型哈希写入 `selection_frozen.json`；
5. 只有冻结文件原子落盘且哈希通过，才进入两路全量最终重训。

### 5.4 全量重训、不确定性与退化处理

冻结 `p_raw` 与 `p_ctx` 后，raw 与 context 各使用全量 LSPR23 最终重训一次。拟合账本为 raw 三折加一次最终、context 三折加一次最终，共八次；后两次最终模型分别只生成一份 LSPR24 逐流分数，不对三折模型集成或投票。

源年选幂报告每折正负实体数、折级候选 AP、汇总折外候选 AP、相对精确最大值的配对实体区间，以及 2,000 次分层实体重抽样中的选值分布。这些量描述有限正实体下的选择不确定性，不设置正实体数、AP 幅度或重复选中比例的硬门，也不把单次选值表述为稳定最优。

若任一折缺少正类或负类、同一实体跨折、折外覆盖不是恰好一次、标签连接错误，或任一候选 AP 非有限，则该路选幂无效，停止进入目标年 ELP 格。可按冻结的 `p=1` 另报均值诊断，但必须标为降级诊断，不能改称已选 ELP，也不能参与完整格的共同基座主排序；任何情况下都不查看 LSPR24 另选 `p`。

## 六、八次拟合与公平预算

### 6.1 共同 XGBoost 参数

六次折外拟合与两次全量最终拟合只允许分支输入维数、CPA 附加量和折内训练实体不同；同一折的 raw／context 训练实体完全一致，全部八次训练的模型预算一致：

| 参数 | 冻结值 |
| --- | --- |
| `device` | `cuda` |
| `tree_method` | `hist` |
| `objective` | `binary:logistic` |
| `num_boost_round` | 800 |
| `learning_rate` | 0.05 |
| `max_depth` | 8 |
| `subsample` | 0.8 |
| `colsample_bytree` | 0.8 |
| `reg_lambda` | 1.0 |
| `min_child_weight` | 1.0 |
| `max_bin` | 256 |
| `seed` | 42 |
| `eval_metric` | `aucpr`，只作运行日志，不用于早停 |
| `scale_pos_weight` | 不设置 |
| 早停／目标年调参 | 不使用 |

`scale_pos_weight` 保持未设置，是因为现有 Dijk 配置没有该项，且它会改变概率标度，从而同时改变 ELP 归约。训练时不允许自动退回 CPU；GPU 不可用或运行中发生设备回退时，该次运行作废。

### 6.2 共享项

以下对象在对应 raw／context 拟合间逐位一致并写入哈希收据：

- LSPR23 原始行版本、标签、三折实体编号与各折训练／留出行索引；
- 83 个基础字段、字段顺序和非有限值处理；
- XGBoost 参数、树数、随机种子和软件环境；
- 实体键、`I/M` 段号、段内排序键、全量最终训练行和 LSPR24 评价实体；
- 每个折外留出矩阵引用对应折训练 `QuantileDMatrix`，LSPR24 矩阵引用对应全量最终训练矩阵，且 `max_bin=256` 全程一致；
- LSPR24 两路推理的行顺序和覆盖断言。

CPA 的 85 个新增前缀量是唯一有意改变的输入信息，其组成固定为 76 个数值残差、5 个离散同值频率、2 个布尔真值率和 2 个支持量。上下文模型训练开销可以不同，但训练算法与树预算不能随结果调整；折外模型只服务源年选择，最终模型只服务冻结后的目标年四格。

## 七、GPU 调度与内存上界

### 7.1 可确定的密集矩阵体积

按 `float32` 计算，现有行数下的密集输入体积为：

| 矩阵 | 形状 | 体积 |
| --- | --- | ---: |
| LSPR23 原始输入 | `16,353,511 × 83` | `5.06 GiB` |
| LSPR23 上下文输入 | `16,353,511 × 168` | `10.23 GiB` |
| LSPR24 原始输入 | `20,227,356 × 83` | `6.25 GiB` |
| LSPR24 上下文输入 | `20,227,356 × 168` | `12.66 GiB` |
| 单路 LSPR24 逐流分数 | `20,227,356 × float32` | `0.075 GiB` |
| LSPR24 实体索引 | `20,227,356 × int64` | `0.151 GiB` |

这些数值是输入数组本身的确定体积，不把量化矩阵、直方图、梯度、临时拷贝和框架开销误当成零。GPU 训练峰值必须另由准入上界覆盖。

### 7.2 单训练消费者与联合准入

当前设备合同为单张 32.6 GiB RTX 5090，控制组内存上限为 90 GiB。运行前重新读取真实值，并保留 20% 余量：

\[
U_{GPU}=0.8\times M_{GPU,total},\qquad
U_{host}=0.8\times M_{cgroup}.
\]

在当前设备上，计划上界分别约为 `26.0 GiB` 和 `72.0 GiB`。每次拟合根据密集输入、量化矩阵、训练工作区与临时拷贝计算保守上界，最后乘 `1.25` 安全系数；只有单次拟合的 GPU 与主机上界分别不超过 `U_GPU`、`U_host` 才能启动。八次拟合始终遵守 `max_gpu_fits=1`，即使 raw 与 context 的上界之和可容纳，也不承诺或启用双拟合并发。

CPU 可以在 GPU 训练时构造下一折或下一分支缓存，但必须另外满足：当前训练主机上界、待构造缓存上界和其他常驻对象之和不超过 `U_host`。不满足时，缓存构造也改为串行。源年矩阵与目标年矩阵不同时常驻；每一阶段结束即释放量化矩阵和不再需要的密集输入。

配置只声明：

```yaml
device: cuda
max_gpu_fits: 1
max_concurrency: auto
admission:
  gpu_fraction_upper: 0.80
  cgroup_fraction_upper: 0.80
  safety_factor: 1.25
```

`max_concurrency` 只控制缓存构造、分数归约、曲线计算和收据写入等非训练流水，由实时主机内存和任务上界解析，不写死并发数。资源收据同时记录 `max_gpu_fits=1`、非训练流水解析值及其理由。

### 7.3 流水并行

单训练消费者下按以下方式组织流水：

1. GPU 串行完成六个折外模型和两个最终模型；GPU 训练时，CPU在主机内存准入通过后构造下一份折矩阵或上下文缓存；
2. 前一折分数的落盘、模型哈希和收据写入可与下一次 GPU 训练流水并行，但不能占用第二个 GPU 训练槽；
3. 三折齐备后才汇总各路折外分数并选择 `p`；两路全量最终模型均完成后，LSPR24 raw／context 推理各执行一次并保存分数；
4. 告警预算曲线、前 k 精确率和配对自助只复用冻结分数，不再调用模型。

`p` 扫描和实体归约优先使用 GPU 向量化，并避开活跃训练所需的显存。若同一输入上的计时核验显示，计入传输和排序后的 GPU 总时间慢于 CPU，允许把该后处理转到 CPU；训练仍留在 GPU。收据记录数组规模、设备、用时和回退原因，不能只写“性能原因”。

### 7.4 资源收据字段

每次运行至少保存：

- GPU 型号、UUID、驱动、CUDA、XGBoost 版本和可见设备；
- 控制组内存上限、启动时空闲显存与主机可用内存；
- 原始／上下文密集字节数、量化矩阵估计、1.25 安全上界；
- `max_gpu_fits=1`、`max_concurrency` 解析值和准入判据；
- 八次拟合各自的开始／结束时刻、峰值显存、峰值主机内存、GPU 利用率和退出状态；
- 后处理采用 GPU 或 CPU 的计时核验与原因；
- 模型、配置、字段清单、切分、逐流分数和选择文件哈希。

效率报告把六次折外选择成本与两次全量最终训练成本分栏，同时给出同设备顺序推理吞吐、峰值显存、峰值主机内存、累计 GPU 活跃时间和端到端墙钟；CPU 流水重叠只作调度事实，不改变模型预算。

## 九、评价表与告警预算曲线

### 9.1 固定评价单元

LSPR24 自检必须同时满足：

- `20,227,356` 条流；
- `47,115` 个无向二 IP 实体；
- `752` 个正实体、`46,363` 个负实体；
- 逐流正例率 `0.0257073138`；
- 四格实体覆盖逐位一致。

任一数量、标签连接、行顺序或覆盖不一致，四格整体无效，不作效果解释。

### 9.2 必报指标

| 层级 | 指标 | 角色 |
| --- | --- | --- |
| 逐流 | AP、AUROC | 检查 raw／context 基础判别变化；作为共同基座并列信息 |
| 实体 | AP | 双机制与共同基座的主排序指标 |
| 告警预算 | `DR@FPR`：`0.1%/0.5%/1%/2%/4%/8%` | 展示完整工作区间，不以单个 4% 点代替曲线 |
| 顶部排序 | 前 `k=10/25/50/100/250/500/752` 精确率 | 显示有限告警席位下的排序质量 |
| 统计 | 2,000 次种子 42 分层配对实体自助的 AP 主效应、组合差、交互项及六个预算锚点差的 95% 区间 | 表达同一实体集合上的不确定性 |
| 效率 | 训练时间、顺序推理吞吐、模型体积、峰值显存、峰值主机内存 | 共同基座的效率并列信息 |

逐流 AP 与 AUROC 只对应 raw／context 两路模型；`G00/G01` 共享 raw 数值，`G10/G11` 共享 context 数值，不把相同逐流分数重复解释为 ELP 改善。

定义六个预算锚点的平均检出率：

\[
B_g=\frac{1}{6}\sum_{q\in\{0.1,0.5,1,2,4,8\}\%}DR_g(q).
\]

主表同时给出六点原值，`B_g` 只作曲线概括并列报告，不设资格线、不进入共同基座主排序，也不替代曲线。

现有历史 XGBoost 取最大曲线为 `28.46/44.02/48.80/54.39/69.28/91.36%`，前 k 精确率为 `100/100/100/100/83.20/62.20/47.21%`。这些值只作历史参照；新四格使用自身冻结分数重算，不能拿历史曲线补齐新格。

## 十、效果报告与有效性规则

### 10.1 四格估计与证据判读

记四格实体 AP 为 `AP00/AP01/AP10/AP11`，交互项为：

\[
I=AP11-AP10-AP01+AP00.
\]

| 判断对象 | 点估计 | 配对实体区间 | 报告方式 |
| --- | --- | --- | --- |
| CPA 主效应 | `AP10-AP00` | 同一重抽样中的 `AP10-AP00` 95% 区间 | 下界大于 0 才表述为正向证据；跨 0 表述为不确定；上界不大于 0 表述为未获得正向证据。 |
| ELP 条件效应 | `AP01-AP00` 与 `AP11-AP10` | 两个差值各自的 95% 区间 | raw 与 context 分支分别报告，不用一个分支代表另一个。 |
| 完整组合 | `AP11-AP00`、`AP11-max(AP10,AP01)` | 两个差值各自的 95% 区间 | 同时报绝对实体 AP、相对无机制格和相对最佳单机制格的差值。 |
| 交互 | `I=AP11-AP10-AP01+AP00` | 同一重抽样中计算的 `I` 95% 区间 | 只有区间下界大于 0 才写“正交互”；否则只报告交互点值与区间。 |
| 告警预算 | 六个锚点的四格检出率与逐点差 | 每个锚点的配对 95% 区间 | 完整展示曲线；不把某个有利工作点推广为全预算优势。 |

本方案不设置固定百分点的最低效果门，也不设置“同档”容差。固定种子 42 的 2,000 次分层配对实体自助采用同一重抽样索引，以 2.5% 和 97.5% 分位数形成 95% 区间。零差异只用于区分方向性证据；实际幅度、区间宽度、预算曲线、逐流 AP 和效率均按原值并列报告，不合成为后验总分。实验完成前状态始终为“实验待证”。

### 10.2 有效性硬门

以下任一情况使运行无效，需要修复协议后另行申请，而不是解释数值：

- LSPR24 标签、指标或目标分布被用于选择字段、折分、`p`、模型参数或聚合公式；

## 十一、共同基座选择与章节承接

XGBoost 在本方案中同时承担“跨树模型普适性行”和“共同基座候选”两种角色。所有骨干完成后按以下规则一次选择：

1. 候选值为每个骨干完整 `CPA+ELP` 格的实体 AP；
2. 仅纳入通过数据、折外选择、设备和共同预算有效性门的候选，按完整格实体 AP 全精度最高值选择；
3. 不设置同档区间、最低增益线或预算曲线资格线；
4. 六点告警预算曲线、`DR@4%FPR`、逐流 AP、同设备顺序推理吞吐、峰值显存、峰值主机内存和总计算成本作为并列信息完整报告，不合成为替代实体 AP 的总分；
5. 若两个候选的完整格实体 AP 全精度完全相等，则展示上述并列信息并由用户裁决，不增设后验自动排序；
6. 一旦选定，第四章、第五章固定使用该骨干，不因后续章节结果切换。

XGBoost 是否具有最高起点、是否成为共同基座，留待等参数 CNN 等骨干按完整结果共同验收。LSPR24 已被既有研究观察，因此本轮共同基座选择属于开发阶段比较；冻结后不再换骨干，若无新的独立年度，后续不作独立测试泛化结论。

## 十四、文献与证据边界

本节合并 `.Codex/docs/RWKV/2026-08-18-XGBoost-CPA-ELP-GPU冻结方案/文献证据矩阵.md` 的已完成审计。审计覆盖 11 篇核心全文，其中 8 篇为仓库本地原件、3 篇为正式开放全文，另含 5 篇边界来源和 4 组 XGBoost 官方文档；方案只采用可定位到全文页码、章节或官方接口页的论据。

| 方案组成 | 核验来源与位置 | 本方案采用的依据 |
| --- | --- | --- |
| 连接历史统计 | Lee 与 Stolfo，2000，印刷第 238–239 页及表 VIII 第 243 页 | 过去连接的计数、比例和均值可构成当前连接特征；本方案的 2-IP 段内残差仍是任务特定改写。 |
| 聚合原始流后使用树模型 | Bilge 等，2012，第 3–4 页 | NetFlow 聚合统计交给随机森林已有先例；其样本是离线服务器窗口，不是逐流前缀。 |
| 2-IP、排序与 128 流边界 | Dijk 等，2026，第 11–16、24 页 | 支持无向二 IP、开始时刻排序、最大 128 流段和 800 树配置来源；原文 XGBoost 只用原始逐流输入，没有 CPA 或 ELP。 |
| 跨流特征回填边界 | Hindy 等，2021，物理第 6–8 页 | 跨流统计附加逐流行已有近邻，但整束最终统计可含未来流，不能作为本方案前缀因果证据。 |
| 幂平均公式 | Gülçehre 等，2014，第 3–5 页；Revaud 等，2019，第 6 页 | 支持归一化幂池化与可学习幂次；本方案在冻结 XGBoost 概率上离散选 `p`，不是端到端学习，`p<1` 时只称幂平均。 |
| 源年模型选择 | Gulrajani 与 Lopez-Paz，2020／2021，第 3 节及第 3.1 节 | 超参数只由源域验证信息选择，目标域 oracle 不成立；不保证源年选出的 `p` 在目标年最优。 |

1. **CPA 挂载**：是否批准候选 B 的段内 `i≤t`、168 维语义前缀残差适配器；
2. **ELP 选择**：是否批准 LSPR23 实体分组三折折外预测、`{0.5,1,2,4,8}` 有限网格和全精度并列规则；
3. **拟合预算**：是否批准六次折外选择拟合、两次全量最终拟合以及两路最终分数映射四格；
4. **资源合同**：是否批准 `max_gpu_fits=1`、`max_concurrency=auto`、20% 资源余量和 1.25 安全系数；
5. **结果与基座**：是否批准四格点值、交互项和配对实体区间的报告方式，以及完整格实体 AP 最高值主排序。

审阅通过前，本方案停在设计阶段，不编写实施计划、生产代码或实验配置，不启动任何实验。
