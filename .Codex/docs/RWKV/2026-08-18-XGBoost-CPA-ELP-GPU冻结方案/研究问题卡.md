# XGBoost 适配 CPA 与 ELP 的研究问题卡

- **日期**：2026-08-18
- **路线**：`RESEARCH_ROUTE=RWKV`
- **状态**：设计可行；实验待证；停在用户审阅门
- **用途**：定义 XGBoost 双机制实验回答什么、观察什么、如何被证伪，以及其进入第四章、第五章共同基座候选集合的条件。

## 一、核心问题

在保持 83 字段数据口径、XGBoost 训练预算和跨年度评价单元不变的条件下，将 CPA 改写为树模型可消费的段内含当前位置前缀适配器，并以 LSPR23 实体分组三折折外预测选择 ELP 幂指数，能否在 LSPR24 上形成可分解的单机制与组合结果？完整 `CPA+ELP` 格能否作为后续章节共同基座的候选，而不是预先指定的胜者？

本问题拆成四项：

1. **CPA 适配**：语义白名单上的段内 `i≤t` 前缀统计能否改变 XGBoost 的实体排序，而不是对端口和类别编码作无意义算术平均？
2. **ELP 适配**：仅凭 LSPR23 实体分组三折折外预测选择的有限网格幂指数，能否改善实体归约？
3. **双机制组合**：`CPA+ELP` 是否优于无机制格和两个单机制格，并呈现正交互？
4. **共同基座候选**：完成所有骨干后，XGBoost 的完整格是否在冻结的主排序与并列规则下胜出？本卡不提前作出该结论。

## 三、方法候选与当前推荐

CPA 原始特征挂载至少比较以下三种设计，正式实验只实施冻结后的一个版本：

| 候选 | 段内前缀挂载 | 特点 | 当前裁决 |
| --- | --- | --- | --- |
| A：语义前缀均值拼接 | 当前 83 维＋76 个数值前缀均值＋5 个离散同值频率＋2 个布尔真值率＋2 个支持量，共 168 维 | 与隐藏表示前缀均值形式较近，但轴对齐树需要间接学习当前值与前缀中心之差。 | 设计可行，不推荐首轮实施 |
| B：语义前缀残差拼接 | 当前 83 维＋76 个数值残差＋5 个离散同值频率＋2 个布尔真值率＋2 个支持量，共 168 维 | 直接暴露当前值相对前缀中心的偏离，仍保留全部当前原始值。 | **推荐冻结为首轮方案** |
| C：均值与残差双拼接 | 当前 83 维＋76 个数值前缀均值＋76 个数值残差＋5 个离散同值频率＋2 个布尔真值率＋2 个支持量，共 244 维 | 同时保留中心与偏离，但信息冗余、矩阵与量化开销更大。 | 设计可行，首轮不实施 |

三种候选都沿用神经 CPA 的 `I/M` 分段：每段最多 128 条，统计包含当前位置 `i≤t`，跨段不延续。推荐 B 的原因是：它不增加相对 A 的内存，避免对端口和类别编码求均值，并把树模型需要组合多个分裂才能表达的偏离量直接显式化。它只在分段和前缀边界上与神经 CPA 同构；聚合对象是原始字段而非隐藏表示，挂载量是语义残差而非隐藏前缀均值，也没有端到端梯度。

## 四、假设、观测量与对照

令四格的 LSPR24 实体 AP 分别为 `AP00`、`AP01`、`AP10`、`AP11`：

- `G00/B0`：原始模型分数＋取最大；
- `G01/ELP`：同一原始模型分数＋源年冻结的 `p_raw`；
- `G10/CPA`：上下文模型分数＋取最大；
- `G11/CPA+ELP`：同一上下文模型分数＋源年冻结的 `p_ctx`。

定义：

\[
\Delta_{CPA}=AP10-AP00,\qquad
\Delta_{ELP,raw}=AP01-AP00,
\]

\[
\Delta_{ELP,ctx}=AP11-AP10,\qquad
\Delta_{组合}=AP11-AP00,
\]

\[
I=(AP11-AP10)-(AP01-AP00).
\]

| 研究判断 | 主要可观测量 | 直接对照 | 证据判读 |
| --- | --- | --- | --- |
| H1：CPA 对树模型有独立作用 | `Δ_CPA`、raw／context 逐流 AP 差、六点预算曲线差 | `G10-G00` | 报告点值和配对实体 95% 区间；区间下界大于 0 才支持正向作用，区间跨 0 记为证据不确定，区间上界不大于 0 则不支持正向作用。 |
| H2：源年选幂的 ELP 有独立作用 | `Δ_ELP,raw`、`Δ_ELP,ctx`、折外网格全表 | `G01-G00` 与 `G11-G10` | 两个分支分别报告，不用其中一个分支替代另一个；按各自点值与配对区间判读。 |
| H3：组合贡献与交互 | `Δ_组合`、`AP11-max(AP10,AP01)`、交互项 `I` | 四格全体 | 同时报点值与配对区间；只有 `I` 的区间下界大于 0 才表述为正交互，跨 0 时只报告组合结果。 |
| H4：告警预算表现 | 六个固定假阳率锚点的检出率及逐点差 | 四格全体 | 六点曲线完整并列展示，不以单点或均值替代全曲线，也不设置无数据依据的百分点门槛。 |

效果判断不预设固定绝对幅度门。固定种子 42 的 2,000 次分层配对实体自助在同一次重抽样中计算四格全部差值，以 2.5% 和 97.5% 分位数形成 95% 区间；零差异是方向性判读基准，而不是最低实用增益声明。数据泄漏、目标年参与选择、实体折分交叉、覆盖或标签错误、八次拟合合同不符、训练设备或预算不一致属于绝对有效性失败，出现任一项时四格结果不进入科学比较。

## 五、源年三折折外选幂

LSPR23 先按无向二 IP 实体分组，实体标签取该实体流标签最大值；以种子 42 按实体标签分层形成三折，同一实体的全部流只能属于同一折。raw 与 context 共用完全相同的折分：每路分别训练三次，以另外两折训练、对留出折预测，合并后保证每条源年流恰好获得一次未见过其所属实体的折外分数。

`p_raw` 与 `p_ctx` 分别在各自汇总后的全量 LSPR23 折外分数上选择，候选集合固定为：

\[
\mathcal{P}=\{0.5,1,2,4,8\}.
\]

由于网格包含 `p=0.5`，全文统一称“幂平均”，不称 Lp 范数。选择目标只有汇总折外预测得到的实体 AP。取实体 AP 的全精度最大值；只有数值完全相等时，才依次选择 `|log2(p)|` 最小者、再选择较小的 `p`，不使用容差或同档区间。精确最大值 `p=∞` 只作无 ELP 对照，不进入有限网格。`p_raw` 与 `p_ctx` 使用同一算法独立选择，因为两路模型的分数分布不同。

这一步用全量源年的折外预测替代约 20 个正实体的单一验证区，避免在小验证区选 `p` 后又放弃全量重训。仍需报告每折正负实体数、每折候选 AP、汇总折外 AP、配对区间以及自助样本中的选值分布，用于说明选择的不确定性，不设置正实体数、增益幅度或选中频率的任意合格线。

选择完成后，raw 与 context 各在全量 LSPR23 上最终重训一次。因此总拟合数为 `3+3+1+1=8`；目标年四格只使用后两次最终模型产生的两路逐流分数。若任一折缺少正类或负类、实体跨折、折外覆盖不是恰好一次、候选 AP 出现非有限值，选幂合同即失败；可另报固定 `p=1` 的均值诊断，但不得把它记作已选 ELP，也不得让相应完整格参与共同基座主排序。

## 六、共同基座候选规则

所有骨干完成后，在通过数据、折外选择、设备和共同预算有效性门的候选中，以各自完整 `CPA+ELP` 格的实体 AP 全精度最高值选择共同基座，不设置同档带、最低增益或预算曲线资格线。告警预算六点曲线、`DR@4%FPR`、逐流 AP、同设备顺序推理吞吐、峰值显存与峰值主机内存作为并列信息完整报告，不合成为替代主指标的总分。若实体 AP 出现全精度完全相同，由用户结合这些并列信息裁决，不另造后验自动规则。选择完成后，第四章、第五章不再按后续结果更换骨干。

LSPR24 已在既有研究中被观察，因此该规则形成的是开发阶段的共同基座选择；若没有新的独立年度或独立测试集，后续章节不把其结果表述为独立测试上的泛化证明。
