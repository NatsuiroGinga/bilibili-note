# 任务计划：第四章约束早停联合指标文献调研

## 目标

基于本地 `ch4-drift-v2` 原始制品与可追溯全文证据，判断如何在不使用目标标签选点的前提下，联合改善实体平均精确率、`DR@4%FPR`、误报率违约率、观察流量与告警时延；比较三类博弈表述并提出一个最小可证伪候选，最后裁决它是否比继续改训练端实体平均精确率更值得优先。

## 任务边界

- 路线：`RESEARCH_ROUTE=RWKV`。
- 只读对象：恢复文档、实验更正台账、`ch4_v2.py`、`ch4-drift-v2` 原始日志与聚合结果、既有论文原件与结构化笔记。
- 允许写入：本目录的 `task_plan.md`、`notes.md`、`候选裁决.md`；发现新的有效外部论文时，按仓库规则新增 `raw/papers/` 原件、`wiki/papers/` 全文笔记、方向索引与 Zotero 条目。
- 禁止：修改生产代码、配置、恢复文档或论文正文；启动、重跑或远程分派实验；引用 `ch4-drift-v1` 数字；用目标标签选择工作点或敏感性网格中的胜出点。
- 代理映射：`ch4_constrained_earlyalert_literature_sol_max → gpt-5.6-sol → max`。

## 研究问题

1. 在实体级序贯告警中，怎样把排序质量、固定误报预算下检出、约束违约与观察成本放进同一可验证决策合同，而不把不同量简单加权后掩盖违约？
2. 现有 BBSE 九个工作点中六个失效，说明哪些标签移位假设被破坏？能否仅用源标签和无标签目标前缀，预先选择、拒绝或混合工作点？
3. 约束早停／早期分类、风险－覆盖／拒识、Neyman–Pearson 固定误报率、非可交换保形风险控制、多目标排序与序贯决策分别能提供什么现成理论，缺口在哪里？
4. 三类博弈框架中，哪些只是已有方法换名：
   - 检测收益与误报率／时延约束的原始－对偶零和博弈；
   - 源年度与目标漂移／环境对手的分布鲁棒博弈；
   - 平均精确率、检出率与时延间的纳什议价／多目标梯度。
5. 无目标标签的工作点混合或对手选择能否形成一个真正可证伪、且不依赖目标标签选点的新增机制？
6. `FPR≤4%` 来自外部安全需求、LSPR/Dijk 的数据集惯例，还是本项目人为操作点？若没有业务依据，应怎样表述并设计最低成本敏感性网格？
7. 相比已经在 Q0 中不晋级的训练端实体平均精确率候选，决策端候选是否有更直接的失败信号、较低实验成本和更清晰的章级贡献边界？

## 范围与证据标准

- 时间范围：基础奠基工作不限年份；近期查重覆盖至 2026-08-13。
- 目标来源：正式会议／期刊论文、arXiv 作者版本、出版社页面、作者官方项目页、本地 Zotero 与仓库原件。
- 核心主题：约束早停与早期分类；风险－覆盖与拒识；Neyman–Pearson 分类；标签移位与 BBSE；非可交换保形风险控制；多目标排序与序贯决策；约束、分布鲁棒和议价三类博弈。
- 纳入：给出明确问题设定、公式／算法或直接实验，且能约束本候选的可观测量、选择规则、保证或失败模式。
- 排除：仅二手转述、无法核验出处、只有摘要却需要支撑公式／定理／实验细节、动作会改变环境而无法映射到冻结轨迹的强化学习方法、与固定误报预算或早停无关的泛化多目标方法。
- 证据等级：全文原件并定位页码／章节／公式为高强度；正式题录与摘要仅用于召回和人工下载清单；二手网页只作线索。
- 目标数量：优先复用本地原件，全文精读约 14–24 篇；每个核心主题至少有一篇直接原始来源，关键裁决至少由两条独立证据或一条理论证据加本地实验事实支撑。
- 停止条件：六类方法与三类博弈均形成比较矩阵；`FPR≤4%` 追溯完成；候选的可观测量、对照、指标和通过／失败门均能落到现有数据；新增查询连续两组不再改变候选边界。

## 已作决定

- 本任务是研究型可行性探针，不是实现任务；不触发代码实现审批或实验启动。
- `ch4-drift-v1` 的数字与结论全部排除，只使用 v2 原始日志、JSON 和更正台账。
- BBSE 在 `源FPR=0.05` 的最佳结果只能算标签可见的事后诊断；在形成无目标标签选择规则前，不得称为可部署机制。

- `research-ideation` 要求的二次委派不执行：当前身份就是主代理明确分派的 `literature-reviewer`，且本任务不再创建下级代理。
