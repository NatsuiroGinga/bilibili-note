核心逻辑（非占位，直接可用）：

```python
def matched_rows(curves: dict, methods: tuple[str, str],
                 nominal_grid: tuple[float, ...], negative_entities: int) -> list[dict]:
    """在同一整数 FP 预算 k = floor(nominal * negative_entities) 处取两方法 DR。

    N-16 曲线以整数假阳性预算为横轴（每方法向量 fp_budgets / detection_rates），
    同一 k 就是同一实际可达 FPR = k / negative_entities，无插值、无拆并列组。
    """
    rows = []
    for nominal in nominal_grid:
        k = int(nominal * negative_entities)          # 46,363 负实体，来自 N-16 收据
        row = {"integer_fp_budget": k, "actual_fpr": k / negative_entities,
               "nominal_fpr": nominal}
        for method in methods:
            fp = curves[method]["fp_budgets"]          # 升序整数向量
            dr = curves[method]["detection_rates"]
            index = int(np.searchsorted(fp, k, side="right")) - 1   # 最后一个 <= k
            if index < 0:
                raise SystemExit(f"{method} 在预算 {k} 内无可达点")
            row[f"{method}_dr"] = float(dr[index])
        rows.append(row)
    return rows
```

方法键名从 `aggregate-results.json` 实读（N-16 五方法含 `full_mlp_o11` 与
XGB＋CPA-ELP 的注册键），**不得硬编码猜测**；负实体数从 N-16 收据字段实读，
与 `46,363` 断言相等。终端与首告警两组曲线各出一张 `rows`。

```python
def cell_scores(prob, entity_order, entity_bounds, cell, p_frozen):
    """cell ∈ {C00, C01p, C10p, C11p}。entity_order 为按实体稳定排序的行索引，
    entity_bounds 为每实体在排序后的 [start, stop)。返回 (终端实体分数, 在线路径分数)。

    C00  : 终端 = max(prob_e)                      在线 = 前缀 max（路径极大）
    C01p : 终端 = powermean(prob_e, p_frozen)      在线 = 同左的前缀版
    C10p : 终端 = mean(prob_e)  (p=1.0 冻结值)     在线 = 前缀算术均值
    C11p : 终端 = powermean(prob_e, p_frozen)      在线 = 前缀幂平均
    powermean(x, p) = (mean(x ** p)) ** (1.0 / p)，float64 计算。
    前缀版：第 t 条流的在线分数 = 聚合(prob_e[:t+1])，逐实体因果累积，
    用累积和 / 累积幂和向量化，不落 (N, ) 之外的中间数组。
    """
```
