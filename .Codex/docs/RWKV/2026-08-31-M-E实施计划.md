- [ ] **步骤 1：写箱边界拟合**

箱边界取训练区经验分位数。分位数可能重复（常数列或高度离散的字段），
重复会使箱宽为零并在编码时除零，**必须处理**：

```python
def fit_quantile_bin_edges(values: np.ndarray, bin_count: int) -> np.ndarray:
    """按训练区经验分位数拟合逐字段 PLE 箱边界，返回 (F, T+1)。

    重复分位数会产生零宽箱并在编码时除零。逐字段去重后若边界不足 T+1 个，
    在最大值一侧按最小正间隔线性补齐，保证边界严格递增且形状固定。
    """
    if values.ndim != 2:
        raise ValueError(f"训练区取值必须是 n×F，实际 {values.shape}")
    quantiles = np.linspace(0.0, 1.0, bin_count + 1)
    raw = np.quantile(values, quantiles, axis=0).T          # (F, T+1)
    edges = np.empty_like(raw)
    for field in range(raw.shape[0]):
        unique = np.unique(raw[field])
        if unique.size >= bin_count + 1:
            edges[field] = unique[
                np.linspace(0, unique.size - 1, bin_count + 1).round().astype(int)
            ]
            continue
        span = float(unique[-1] - unique[0]) if unique.size > 1 else 0.0
        step = max(span / bin_count, np.finfo(np.float32).eps * 8)
        edges[field] = unique[0] + step * np.arange(bin_count + 1)
    if not np.all(np.diff(edges, axis=1) > 0):
        raise RuntimeError("箱边界未能严格递增，PLE 编码会除零")
    return edges.astype(np.float32)
```

- [ ] **步骤 2：写 PLE 编码**

形式化第 3.1 节的三段定义中，**第一箱不下截、末箱不上截**——原论文保留超出训练区
范围的线性外推。用 `torch.where` 按箱序号分支，不使用原地写入：

```python
def piecewise_linear_encode(x: torch.Tensor, edges: torch.Tensor) -> torch.Tensor:
    """PLE 编码，(n,F) 与 (F,T+1) 进，(n,F,T) 出。

    ε_t = 0            x < b_{t-1} 且 t > 1
          1            x ≥ b_t 且 t < T
          线性插值      其余
    第一箱（t=1）不下截、末箱（t=T）不上截，保留原论文对范围外取值的线性外推。
    """
    lower = edges[:, :-1].unsqueeze(0)                       # (1,F,T)
    width = (edges[:, 1:] - edges[:, :-1]).unsqueeze(0)      # (1,F,T)
    raw = (x.unsqueeze(-1) - lower) / width
    bin_count = width.shape[-1]
    index = torch.arange(bin_count, device=x.device).view(1, 1, -1)
    return torch.where(
        index == 0,
        raw.clamp(max=1.0),
        torch.where(index == bin_count - 1, raw.clamp(min=0.0), raw.clamp(0.0, 1.0)),
    )
```

```python
def entity_gated_ple_parameter_count(
    numeric_field_count: int, bin_count: int, d_token: int, gate_hidden: int
) -> int:
    """M-E 专属参数量：位移嵌入 F·T·d 加门 MLP (2h + h + h + 1)。"""

    gate = 2 * gate_hidden + gate_hidden + gate_hidden + 1
```

- [ ] **步骤 2：写门控分词器**

`base_tokenizer` 以属性方式持有，其参数属于骨干、**不重复计入** M-E，
也不得在此模块内被重新初始化。位移只加到数值 Token，`[CLS]` 与类别 Token 位置补零，
拼接而非原地写入，避免破坏 autograd：

```python
class EntityGatedPLETokenizer(nn.Module):
    """现有线性分词 ＋ 实体门控的分段线性位移通道。

    Token 布局与 base_tokenizer 一致：[CLS] 一列、数值 F 列、类别 C 列。
    位移只作用于数值列；门 γ 由严格过去实体状态给出，实体首片段恒为零。
    """

    def __init__(
        self,
        base_tokenizer: nn.Module,
        bin_edges: torch.Tensor,
        d_token: int,
        gate_hidden: int,
        gate_mode: str,
    ) -> None:
        super().__init__()
        if gate_mode not in {"entity_state", "constant", "binary_indicator"}:
            raise ValueError(f"未知门模式：{gate_mode}")
        self.base = base_tokenizer
        self.gate_mode = gate_mode
        self.numeric_field_count = base_tokenizer.numeric_field_count
        self.category_count = len(base_tokenizer.categories)
        self.register_buffer("bin_edges", bin_edges)
        bin_count = bin_edges.shape[1] - 1
        self.displacement = nn.Parameter(
            torch.empty(self.numeric_field_count, bin_count, d_token)
        )
        nn_init.kaiming_uniform_(self.displacement, a=math.sqrt(5))
        if gate_mode == "entity_state":
            self.gate_hidden_layer = nn.Linear(2, gate_hidden)
            self.gate_output_layer = nn.Linear(gate_hidden, 1)
        else:
            # E1 与 E2 的常数门：可学标量，初始化 0 使 σ(β)=0.5
            self.gate_scalar = nn.Parameter(torch.zeros(1))

    def gate(self, entity_state: torch.Tensor) -> torch.Tensor:
        """返回 (n,1) 的门值。entity_state 的第 0 列是 log 归一化的 c，第 1 列是 Δ。"""
        if self.gate_mode == "entity_state":
            hidden = torch.relu(self.gate_hidden_layer(entity_state))
            value = torch.sigmoid(self.gate_output_layer(hidden))
        else:
            value = torch.sigmoid(self.gate_scalar).expand(entity_state.shape[0], 1)
        if self.gate_mode == "constant":
            return value
        # entity_state 第 0 列由 log(1+c)/log(1+C) 得到，c=0 时该列恰为 0
        has_history = (entity_state[:, :1] > 0).to(value.dtype)
        return value * has_history

    def forward(
        self, x_num: torch.Tensor, x_cat: torch.Tensor | None, entity_state: torch.Tensor
    ) -> torch.Tensor:
        tokens = self.base(x_num, x_cat)
        if entity_state.shape != (x_num.shape[0], 2):
            raise RuntimeError(
                f"实体状态必须是 n×2，实际 {tuple(entity_state.shape)}"
            )
        encoded = piecewise_linear_encode(x_num, self.bin_edges)
        displacement = torch.einsum("nft,ftd->nfd", encoded, self.displacement)
        gated = self.gate(entity_state).unsqueeze(-1) * displacement
        pad_cls = torch.zeros_like(gated[:, :1])
        parts = [pad_cls, gated]
        if self.category_count:
            parts.append(torch.zeros_like(gated[:, :1]).expand(-1, self.category_count, -1))
        return tokens + torch.cat(parts, dim=1).to(tokens.dtype)
```

`E2` 的 `binary_indicator` 与 `E1` 的 `constant` 只差 `has_history` 一项，
这使两臂与 C10 构成嵌套族（形式化第九节）。

- [ ] **步骤 2：写归一化常数拟合**

尺度常数取**训练区** `p99`（形式化第 3.2 节）。归一化必须取对数：源年实测 `c` 的
前后半段均值 `402.74 → 1519.58`，源年内部即漂移 `3.8` 倍，绝对值入模等于重蹈 CEM 路径。

```python
def fit_state_normalizers(
    prior_segments: np.ndarray, gap: np.ndarray, train_rows: np.ndarray
) -> dict[str, float]:
    """尺度常数只由训练区拟合，验证区与目标年零参与。"""
    c_scale = float(np.quantile(prior_segments[train_rows], 0.99))
    gap_scale = float(np.quantile(gap[train_rows], 0.99))
    return {
        "c_scale": max(c_scale, 1.0),
        "gap_scale": max(gap_scale, 1.0),
    }


def normalize_state(
    prior_segments: np.ndarray, gap: np.ndarray, normalizers: dict[str, float]
) -> np.ndarray:
    """s = [log(1+c)/log(1+C), log(1+Δ)/log(1+D)]，c=0 时第 0 列恰为 0。"""
    c_component = np.log1p(prior_segments) / np.log1p(normalizers["c_scale"])
    gap_component = np.log1p(np.maximum(gap, 0.0)) / np.log1p(normalizers["gap_scale"])
    return np.stack([c_component, gap_component], axis=1).astype(np.float32)
```

`c = 0` ⇒ `log1p(0) = 0` ⇒ 第 0 列为 `0`，与任务 2 的 `has_history` 判据一致，
这是形式化第 3.3 节 `𝟙[c≥1]` 的等价实现，**不需要额外传指示列**。

- [ ] **步骤 1：加包装模型类**

```python
def _entity_gated_ple_model_class() -> Any:
    """延迟构造 M-E 整格包装类，仅供 z1=entity_gated_ple 使用。

    绕过 backbone.tokenizer，改用 M-E 分词器产出 Token 后直接进 backbone.blocks，
    因此 base 模块完全不需要修改。
    """
    if _ENTITY_GATED_PLE_MODEL_CACHE:
        return _ENTITY_GATED_PLE_MODEL_CACHE["EntityGatedPLEFTModel"]

    from torch import nn

    class EntityGatedPLEFTModel(nn.Module):
        def __init__(self, backbone: Any, tokenizer: Any) -> None:
            super().__init__()
            self.backbone = backbone
            self.me_tokenizer = tokenizer

        def encode(self, x_num: Any, x_cat: Any, entity_state: Any) -> Any:
            return self.backbone.blocks(self.me_tokenizer(x_num, x_cat, entity_state))

        def predict(self, representation: Any) -> Any:
            return self.backbone.predict(representation)

        def forward(self, x_num: Any, x_cat: Any, entity_state: Any) -> Any:
            return self.backbone.predict(self.encode(x_num, x_cat, entity_state))

    _ENTITY_GATED_PLE_MODEL_CACHE["EntityGatedPLEFTModel"] = EntityGatedPLEFTModel
    return EntityGatedPLEFTModel
```

```python
    config: dict[str, Any], arrays: dict[str, Any], train_rows: Any, view: Any,
    output_root: Path,
) -> dict[str, Any]:
    """拟合 PLE 箱边界与状态归一化常数，全部只用训练区行。

    箱边界在**分位数变换后**的数值特征上拟合——与骨干分词器的输入同一口径。
    结果随运行收据落盘，供复现与哈希核验。
    """
    import numpy as np
    import ch3_ft_entity_gated_ple as gated_ple
    import ch3_ft_entity_segment_state as segment_state

    mechanism = config["mechanism"]["entity_gated_ple"]
    prior_segments, gap = segment_state.compute_segment_state(arrays["E23"], arrays["T23"])
    normalizers = segment_state.fit_state_normalizers(prior_segments, gap, train_rows)
    state_matrix = segment_state.normalize_state(prior_segments, gap, normalizers)

    training_values = _gather_transformed_numeric(view, train_rows, config)
    bin_edges = gated_ple.fit_quantile_bin_edges(training_values, mechanism["bin_count"])

    receipt = {
        "bin_count": mechanism["bin_count"],
        "normalizers": normalizers,
        "bin_edges_sha256": _canonical_sha256(bin_edges.tolist()),
        "state_rows": int(state_matrix.shape[0]),
        "gate_active_segments": int((prior_segments >= 1).sum()),
        "target_reads": 0,
    }
    (output_root / "entity-gated-ple-context.json").write_text(
        json.dumps(receipt, ensure_ascii=False, indent=2), encoding="utf-8"
    )
    return {"bin_edges": bin_edges, "state_matrix": state_matrix, "receipt": receipt}
```

`_gather_transformed_numeric` 复用 `view` 的既有取数接口分块读取训练区行并过
`view.transform.apply`，**不得**一次展开全量 `X23`（内存会爆）。实现时先读
`base._gather_training_column`（第 1716 行）与 `view.gather_sequences` 的既有写法，
沿用同一分块模式，不新造数据通路。

**运行断言**：`receipt["gate_active_segments"]` 必须等于 `121135`——与
`tools/ch3_ft_me_gate_scope_probe.py` 的冻结值一致。不一致说明状态计算口径漂移。

`build_model_optimizer` 相应加参数 `mechanism_context: dict[str, Any] | None = None`，
默认 `None` 使 `z1 = 0` 与 CEM 两条既有路径的调用点**一字不改**。
步骤 2 中的 `mechanism_bin_edges` 即 `mechanism_context["bin_edges"]`。

- [ ] **步骤 2.5：把实体状态接入前向路径**

`forward_bare`（第 799–814 行）是统一前向入口，其注释写明「同一个 forward_bare 被训练、
验证、C01 逐流阶段与零门断言四处调用」。**给它加一个可选参数即可覆盖全部四处**，
不需要像 CEM 那样另写一套 `entity_memory_validation_metrics`——M-E 的状态是数据侧
预计算量，没有运行时调度器。

`entity_state` 是**逐片段**的 `(batch, 2)`，而前向是**逐流展平**的 `(batch × length, F)`，
因此必须沿时间轴广播。同一片段内所有流共享该片段的实体状态，这与形式化第 3.2 节
一致——`s_{e,t}` 定义在片段上，不随片段内流位置变化：

```python
def forward_bare(
    model: Any, numeric: Any, categorical: Any, valid: Any, device: Any, profile: dict[str, Any],
    precision: Any, torch_module: Any, *, site: str = "flow_forward_bare_train",
    entity_state: Any = None,
) -> Any:
    ...
    with precision.autocast_context(profile, device.type, torch_module):
        if entity_state is None:
            logits = model(flat_num, flat_cat).reshape(batch, length)
        else:
            state_t = torch_module.from_numpy(entity_state).to(device)
            flat_state = state_t.unsqueeze(1).expand(batch, length, 2).reshape(batch * length, 2)
            logits = model(flat_num, flat_cat, flat_state).reshape(batch, length)
    return logits, valid_t
```

`entity_state is None` 时**逐字保持原行为**，`z1 = 0` 的数值路径一位不变。

调用侧：`training_step` 与验证函数已持有本批的 `rows`，用它索引任务 3 预计算的
全量 `(271815, 2)` 状态矩阵即可：`state_matrix[rows]`。该矩阵在
`prepare_*_context` 阶段算一次，随运行收据落盘，不在每步重算。

**验收**：`z1 = 0` 时 `forward_bare` 不得进入新分支。用执行路径收据核验——
`site` 参数已存在，收据能分辨四处调用各自进的是编译包装体还是原模块。
