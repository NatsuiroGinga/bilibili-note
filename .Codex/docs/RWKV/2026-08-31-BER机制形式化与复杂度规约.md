## 一、符号

沿用共同约定（实体 `e`、片段 `t`、宽度 `d = 192`），本机制新增：

| 符号 | 含义 |
| --- | --- |
| `S_e` | 实体 `e` 的路径分数 |
| `p` / `n` | 正实体 / 负实体索引 |
| `L_pn` | 正实体 `p` 与负实体 `n` 的配对损失 |
| `K` | 真实告警预算（总体负实体池上的整数） |
| `N_-` | 总体负实体池规模，源年训练角色实测 `121,336` |
| `n_s` | 每步抽样的负实体数，冻结取 `64` |
| `β_K` | 标称假阳率 `K / N_-` |
| `K_eff` | 折算到抽样规模的有效预算 |
| `ξ_{p,K}` | 逐正实体逐预算的阈值，**训练私有状态** |
| `B` | 水库容量，取 `4096` |

## 二、动机

评价口径是实体级、且运营上只在有限误报预算内看告警，而训练目标是逐流交叉熵。
两者错位的直接证据来自 C00 的选轮实验：逐流 AP 自第 3 轮起饱和于 `0.998` 以上、
末段几乎无区分度，而同期实体 AP 在 `0.3243`–`0.7888` 之间变动；
按逐流指标择优选轮会使实体 AP 损失 `13.49` 个百分点。

BER 的作用维度是**训练级**：不改变模型结构与推理期参数，
把训练目标改写为与部署同构的、实体级的、预算内的排序目标。

## 三、目标函数

### 3.1 实体路径分数

```
S_e = max_t  l_{e,t}
```

与部署同构：运营上只要实体的任一条流越过阈值即告警。
唯一最大值时梯度只回到取得最大 logit 的那条流；并列时按固定稳定顺序取合法子梯度
（实现用 `argmax` 定位加 `gather` 取值，不依赖 `torch.max` 对并列的隐式处理）。

### 3.2 多预算 CVaR-pAUC 目标

```
L_pn      = softplus(S_n − S_p)
R_K(θ,ξ)  = mean_p [ ξ_{p,K} + (1/K) · Σ_n [ L_pn − ξ_{p,K} ]_+ ]
L_rank    = mean_K  R_K(θ,ξ)
```

`ξ_{p,K}` 属训练私有状态，不进入推理图，因此 C01 的推理期参数量与裸 FT 完全相同
（`924,283`）。该事实已由检查点实物独立佐证：C01 与 C00 的 `state_dict`
条目数与元素总数逐位相同（`54` 条 / `924,285` 个元素）。

选择 CVaR 形式而非普通成对排序的依据是实测：收敛模型上普通 RankNet 形式的
梯度范数中位为 `6.08e-14`，比逐流梯度低约 12 个数量级、12 批中 3 批严格为零；
CVaR 形式相对普通形式的梯度范数比在收敛模型上为 `16.61`（随机初始化时仅 `1.30`）。

### 3.3 有效预算折算

真实预算 `K` 定义在总体负实体池 `N_-` 上，而每步只抽样 `n_s` 个负实体。
按单样本无偏估计量 `r̂ = ξ + (1/β_K)[L_pn − ξ]_+` 推导：

```
K_eff = K · n_s / N_-  =  β_K · n_s
```

冻结预算 `[121, 606, 1213, 2426, 4853, 9706]`，由训练角色负实体池 `121,336`
按六档标称比例 `0.1%/0.5%/1%/2%/4%/8%` 投影得到。

## 四、阈值 ξ 的最优性与估计

### 4.1 驻点条件

固定 `θ`，对 `ξ_{p,K}` 求子梯度：

```
∂R_K/∂ξ_{p,K}  ∈  1 − (1/K) · |{ n : L_pn > ξ_{p,K} }|
```

令其含零，得驻点条件

```
|{ n : L_pn > ξ_{p,K} }|  =  K
```

即 **`ξ*_{p,K}` 是使恰好 `K` 个负实体的配对损失超过它的值**，
等价于 `{L_pn}_n` 的 `(1 − K/N_n)` 分位数。这是 Rockafellar–Uryasev 变分形式的
标准结论——CVaR 的内层 `min` 在 VaR 处取得。

### 4.2 `K_eff < 1` 时驻点在批内不存在

驻点条件要求超过阈值的负实体**计数**等于 `K_eff`。计数是非负整数，
而折算后

| 标称 FPR | `K` | `K_eff`（`n_s = 64`） |
| ---: | ---: | ---: |
| 0.1% | 121 | `0.0638` |
| 0.5% | 606 | `0.3196` |
| 1.0% | 1213 | `0.6398` |
| 2.0% | 2426 | `1.2796` |
| 4.0% | 4853 | `2.5598` |
| 8.0% | 9706 | `5.1195` |

**最低三档 `K_eff < 1`，驻点条件在单步批内无解**：不存在使整数计数等于
`0.0638` 的 `ξ`。子梯度因此不指向任何固定点，`ξ` 持续漂移。

这与源年实测一致：C01 第 17 轮六档活动率为 `[0, 0, 0, 0.016, 0.023, 0.023]`，
最低三档恒为零。

**样本量下界**：即使跨步累积，估计 `(1 − β)` 分位数至少需要
`n ≳ 1/β` 个样本。最低档 `β_min = 121/121336 = 9.97e-4`，故 `n ≳ 1003`。
这是估计理论边界，**改折算公式绕不过去**。

### 4.3 已否决的两条修法

**增大 `n_s`**——被实测反证。`K_eff = 2.56 / 5.12` 的 4%／8% 档同样失配：
第 20 轮活动率 `3.1%` / `2.3%`，而驻点应为 `4%` / `8%`，累计约 `3.4σ` 低。
`K_eff ≥ 1` 不是充分条件。且 `n_s → 1003` 意味着约 `15.7` 倍计算量。

**删减低预算档**——否决。六档标称 FPR 是机制的设计对象，删掉等于删掉科学主张，
且不治阈值追踪滞后。

### 4.4 采纳的估计器：跨步水库分位数

对每个 `(p, K)` 维护容量 `B` 的环形水库 `𝓡_{p}`，累积历次观测到的 `L_pn`。
阈值直接取分位数而非梯度追踪：

```
ξ_{p,K}  ←  Quantile( 𝓡_p ,  1 − K_eff / n_s )   ，  detach
```

样本不足 `1/(1 − level)` 时退回初值并在诊断中计数，不给出不可靠的极端分位数。

**跨步累积是关键**：单步只有 `n_s = 64` 个负实体，估不出最低档所需的 `1/1003` 分位数；
水库以时间换样本量，`B = 4096` 覆盖 `n ≳ 1003` 的下界并留约 4 倍余量。
**因此不必增大 `n_s`。**

**`ξ` detach 不影响 `θ` 的梯度**：在 `R_K = ξ + (1/K)Σ[L−ξ]_+` 中，
第一项对 `θ` 是常数、第二项经 `L_pn` 仍有梯度。该性质已实测确认——
detach 版与带梯度版的 `dL/dθ` **逐位相等**（`torch.equal` 为真）。

**不得改用「逐步取批内第 `⌈K_eff⌉` 大值」**：`K_eff < 1` 时该式退化为
`ξ = ` 批最大值 ⇒ 所有 hinge 为零 ⇒ 该档对 `θ` 的梯度**恒为零**，比现状更糟。

### 4.5 对既有描述的更正

此前把活动率归零解释为「收敛后 hinge 约束自然满足」**不成立**；
把 `ξ` 的行为描述为「单向棘轮」在**字面上也不成立**——
`inflight.pt` 实测第 4、5 列 `ξ` 最小值为负（`−1.5e-6` / `−6.6e-6`），
是下行越过零的直接证据。正确表述是**实效**棘轮：下行速度有硬上界
（子梯度不携带距离信息）、上行为下行的 `14.669` 倍、
损失分布在第 1→20 轮坍缩 `500` 倍（`2.578 → 0.00519`）。

## 五、因果边界

BER 不引入跨流状态，因果边界比 CEM 与 M-E 简单：

1. `S_e` 只由该实体在**当前批内**的片段 logits 取最大，不跨批携带状态；
2. `ξ` 的水库只累积配对损失数值，**不含标签、不含实体身份之外的信息**；
3. 水库按 `(p, K)` 分桶，不跨正实体混用；
4. 取阈值在写入本步样本**之前**执行——否则本步样本会污染本步阈值，
   破坏「阈值由严格过去样本估计」这一性质。该顺序已实测确认：
   第 20 步注入常数 `1000.0`，当步阈值仍为 `0.9944`，第 21 步才变为 `1000.0000`；
5. `target_reads = 0`：预算网格与 `N_-` 全部由 LSPR23 训练角色拟合。

## 六、在线算法

**推理期 BER 不参与**。`ξ` 与水库都是训练私有状态，不进入推理图；
部署时实体分数仍为 `S_e = max_t l_{e,t}`，与裸主干完全一致。

训练期每步：

```
1. 抽样 n_pos 个正实体、n_s 个负实体                    分层采样
2. 前向得 S_p、S_n，算 L_pn = softplus(S_n − S_p)      O(n_pos · n_s)
3. 取阈值 ξ ← Quantile(水库, 1 − K_eff/n_s)  detach     先取后写
4. 算 L_rank，反传得 g_rank
5. 与逐流主损失梯度合成（控制器）
6. 把本步 L_pn 写入水库                                 后写
```

## 七、参数量与复杂度

### 7.1 参数量

**推理期新增参数为 `0`**。`ξ` 表与水库都是训练私有状态。
这一点与 M-E（新增 `124,673`）形成对照：两机制一个在训练目标层、一个在表示层，
参数量不对称是机制性质决定的，非设计疏漏。**正文须写明该口径**。

### 7.2 时间

| 步骤 | 复杂度 |
| --- | --- |
| 配对损失 `L_pn` | `O(n_pos · n_s)` |
| 水库写入 | `O(n_pos · n_s)` |
| 分位数取值 | `O(n_pos · |K| · B)`，若用排序则 `O(n_pos · |K| · B log B)` |
| 排序阶段前向 | 由袋大小决定，实测单批可达 `6403` 个序列 |

**实测警示**：排序阶段前向是主要开销。C01 在 5090 上单臂 `123.8` 分钟，
是 C00 的 `2.4` 倍，步速由 `6.9` 降至 `2.6` 步/秒——因该阶段需保留全部微批的
反向图供 CVaR 使用，已用梯度检查点把峰值显存由 `30,970 MiB` 压到 `15,175 MiB`。

分位数取值的当前实现是逐正实体逐档的 Python 双重循环，
每次含一次 GPU→CPU 同步。筛选臂实测 GPU 利用率在 `33%`–`99%` 间波动，
低谷与该循环相关。**正式四格重跑前应向量化**，本条为工程优化，不改数值语义。

### 7.3 空间

| 项 | 大小 |
| --- | --- |
| 推理期 | `0` |
| `ξ` 表 | `|正实体| × |K| × 4 B`；源年实测 `165 × 6` |
| 水库 | `|正实体| × B × 4 B`；`165 × 4096 × 4 B ≈ 2.58 MiB` |

水库进入检查点的 `mechanism_state`，须纳入断点恢复；已实测旧检查点
（不含水库三键）可降级加载为空水库而不崩。

## 八、边界

- 机制本身已获目标年正增益支持，但**阈值修法的有效性实验待证**——
  预注册判据为第 15 轮起六档活动率轮均值落入 `[0.5β, 2β]`。
- 第 7.2 节的复杂度为算子计数，实际墙钟须实测。
- `B = 4096`、`n_s = 64`、`n_pos = 2` 均为任务化设定，须过魔法数字门禁。
- 机制来源 Zhu 2022 ICML 使用「CE 预训练 → 重置分类头 → pAUC 微调」两阶段，
  而本实现是**联合训练**。该差异是有意的改造，正文须给出理由，
  不得留作未说明的偏离。
