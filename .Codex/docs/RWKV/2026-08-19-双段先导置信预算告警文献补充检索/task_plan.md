## 二、证据与同构分级

| 等级 | 定义 |
| --- | --- |
| E3 | 正式出版全文或作者正式全文；题录、页码或公式锚点完整 |
| E2 | 可核验预印本全文；版本、题录、页码或公式锚点完整 |
| E1 | 正式题录或摘要；不得支撑正文级机制主张 |
| E0 | 二手线索或未核验材料 |
| D3 | 七项关系在同一工作中全部明确出现，且角色隔离与实体评价单元一致 |
| D2 | 至少两项关键关系同现，但缺少一个决定性环节 |
| D1 | 只覆盖单一基础部件 |
| D0 | 标签权限、时间顺序、评价单元或冻结合同冲突 |
