# 四篇漂移全文对第三章机制优化的审计结论

## 结论

四篇全文**足以支持只开一轮零训练 S0，也足以否决立即进入训练层多算子**；它们**不足以证明** `Lp + max` 并联或 O11 逐流分数上的决策层因果前缀有效。

1. MalMoE 提供同域直接证据：AVG 与 DEG 对两类图漂移表现互补，单算子错配会严重退化。但其成功结构是**分专家＋硬选择门**，而不是在同一表示中直接拼接；`Lp` 与 `max` 又都读取同一逐流分数，不能把 AVG/DEG 的互补性直接搬过来。
2. Pevný 2016 只支持按袋语义选“均值或最大”和把池化放在网络内部，**不支持“均值＋最大双摘要拼接”**。现有文档把它标为该拼接的 `D1` 来源，证据等级过高，应降为 `D3` 任务化构造。
3. 四篇核心论文都没有 O11 分数层因果前缀。MalMoE 用整图均值路由专家，Berruz 用连续批特征统计触发重训，MADCAT 在测试时更新编码器，Wasswa 做潜空间对齐且删除时间戳。它们只能约束“在线量无标签、不可读未来”，不能支撑具体前缀公式或效果。
4. 当前《第三章 MLP 四格消融加固实施计划》的 `C01p` 与 `C11p` 都是同一冻结 `p` 的终端/前缀幂平均。两臂数学相同，修复前不能运行，也不能把结果称为四格、单模块贡献或交互。

最终证据状态：**设计可行、实验待证**。

## 唯一建议的下一轮 S0

### 目的

只回答两个可证伪问题：

1. 同一 O11 逐流分数上，有限 `Lp` 与 `max` 是否在源年不同指标或预注册分面上呈互补，而不是冗余。
2. 对同一算子，严格因果前缀相对终端统计是否改善首次告警，同时不制造低预算退化。

### 四臂约束

- 因子一：`operator ∈ {Lp, max}`。
- 因子二：`time ∈ {terminal, strict-causal-prefix}`。
- 四臂都必须是从同一 O11 分数序列到评价对象的**不同、确定、无参数映射**。
- 不新增融合权重、阈值搜索、`p` 网格或目标年校准。
- 若确切目标是训练一个 `[Lp; max]` 联合头，它不是零训练 S0，必须等 S0 证明互补后进入冻结骨干 S1。

### 机械有效性门

- O11 检查点、逐流分数 SHA、实体键、曝光顺序和有效样本逐臂一致。
- 每个前缀只使用当前及严格过去的流；终端实体标签不得进入前缀特征、排序或阈值构造。
- `C01p` 与 `C11p` 或任意两臂的公式哈希不得相同；相同即配置失败，不是科学结果。
- 源年选择完成并封印前，目标年特征和标签读取计数均为 `0`。
- 不拆完整并列组、不插值；名义 FPR 与实际 FPR 分列。

### 可观测量与停止门

- 必报逐流 AP、实体 AP、最大实体 AP、完整可达假阳性预算曲线、六档实际 FPR、首次告警实际 FPR、未告警率、1 基曝光序阶梯、并列组大小和资源。
- 只有源年出现真实非支配信号、至少一处严格改善且低预算无新退化，才允许 S1。
- `Lp` 与 `max` 没有互补，立即停止联合头。
- 因果前缀没有信号，保留终端 O11；不得用 LSPR24 修改统计量。
- S0 无论正负都只是筛选证据，不进入正文效果表。

## 训练层多算子裁决

**当前不允许直接进入训练层。** 文献只给出两种条件路线：

1. MalMoE 路线：不同算子放在不同专家中，使用图级上下文硬选择。其原文还说明直接 AVG-DEG 拼接受尺度偏置与漂移分量污染影响。
2. 构件路线：先在嵌入级形成单算子摘要，再由袋级头分类。Pevný、Ilse 都没有验证 `Lp + max` 在加密流量漂移下联合训练。

只有 S0 在 LSPR23 证明算子互补后，才允许一个**冻结 O11 的 S1**：单算子头、联合头和同容量对照使用相同源年实体样本与预算。若需要辅助损失进入共享骨干，ForkMerge 只提供更新过滤的训练合同，仍须另做 S2，不得由文献直接放行。

## 正文措辞

### 现在允许

- “MalMoE 在合成图漂移实验中观察到不同节点统计对不同漂移形态具有互补稳健性。”
- “本研究据此把 `Lp` 与 `max` 的互补性登记为待验证假设，并先进行源年零训练消融。”
- “本次核验的四篇近期漂移论文分别采用表示层鲁棒化、潜空间对齐、测试时训练或漂移触发重训，未直接评估逐流分数的实体内因果前缀。”
- “决策层候选只使用无标签、当前及历史可得量；其有效性由本项目实验裁决。”

### 实验前禁止

- “MalMoE 证明了 `Lp + max` 并联有效。”
- “Pevný 提出了均值＋最大或 `Lp + max` 双摘要拼接。”
- “三篇/四篇漂移论文支持分数层 CPA。”
- “因果前缀是近期漂移方法的主流、首创或已验证机制。”
- “训练层多算子提高了 LSPR23→LSPR24 稳健性。”
- “本方法对任意时间跨度均可免重训。”
- 使用 Berruz 的绝对准确率作本项目基线，或使用 Wasswa 的召回率作精确效果参照。

## 研究空白与最佳方向

1. **算子互补缺证**：尚无本轮全文证明同一逐流分数上的有限 `Lp` 与 `max` 对跨年漂移互补。最优下一步是 S0，而不是增加公式。
2. **融合规则缺证**：若两个算子确有互补，仍不知道直接拼接、晚期分数融合还是硬门控更合适。MalMoE 的证据更偏向分支隔离与门控，不支持裸拼接。
3. **分数层因果缺证**：现有工作统计图、特征批或更新损失，没有把实体内逐流分数变成严格前缀告警。该空白只能写成“本次四篇未覆盖”，不能写成全领域空白。
4. **评价必须先于扩模**：首先在共同整数假阳性预算、完整并列组和首次告警轴上验证；没有源年信号时停止，不以训练层扩模替代实验裁决。
