## 4. 论文公式到代码的完整映射

以下记号统一为每头列向量形式，以便与官方 NumPy 和 CUDA 实际内存方向一致。设：

- 批大小为 `B`，序列长度为 `T`，模型维度为 `C`。
- 头数为 `H`，每头宽度为 `N=64`，`C=H×N`。
- 单头矩阵状态为 \(S_t\in\mathbb{R}^{N\times N}\)。
- \(r_t,w_t,\widetilde{k}_t,v_t,\widehat\kappa_t,a_t\in\mathbb{R}^{N}\)。

### 4.1 式（15）：归一化移除键

论文：

\[
\widehat{\boldsymbol\kappa}_t=
\frac{\boldsymbol\kappa_t}{\lVert\boldsymbol\kappa_t\rVert_2}.
\]

代码映射：

1. `src/model.py:612`：`k = self.key(xk)` 生成键前体。
2. `src/model.py:644-649`：调用 `tmix_kk_pre_bf16_v5`。
3. `rwkv7_tmix_kk_pre_bf16_v5.cu:67-79`：先计算 `u=k*k_k`，再按每头 64 通道求二范数，分母下界为 `1e-12`。
4. `rwkv7_tmix_kk_pre_bf16_v5.cu:90-95`：得到 `kk=κ̂`，向 WKV 核传出 `neg_kk=-κ̂` 与 `kka=κ̂⊙a`。
5. 可读等价代码为 `rwkv7_train_simplified.py:170-174` 和 `rwkv_v7_numpy.py:33-39`。

符号对应：`self.k_k` 是论文的学习参数 \(\xi\)，`kk` 是归一化后的 \(\widehat\kappa_t\)，不是替换键 \(\widetilde{k}_t\)。

### 4.2 式（16）：状态初值

论文：

\[
S_0=0.
\]

代码映射：

- 正式训练核 `rwkv7_clampw.cu:25-29` 对每个批样本和每个头建立 FP32 `state[N]` 并置零。
- 单步 NumPy 参照 `rwkv_v7_numpy.py:102-103` 将矩阵状态初始化为 `[L,H,N,N]` 的 FP32 全零数组，同时为 TimeMix 和通道混合的上一步输入建立 `[L,2,C]` 全零数组。
- RNN 演示 `rwkv_v7_demo_rnn.py:284-288,343-347` 同样使用零初值；矩阵状态是 FP32，移位状态使用模型数据类型。

边界：默认 `train_temp` WKV 核不接收外部初始矩阵状态，每次序列调用从零开始。方案 A/B 所需的连续段跨截断状态传递不能假定已经由此核提供，必须使用官方状态传递核或经本报告第 8 节验收的等价适配器。

### 4.3 式（17）：矩阵状态演化

论文的代码一致方向为：

\[
S_t=S_{t-1}\operatorname{diag}(w_t)
-(S_{t-1}\widehat\kappa_t)(a_t\odot\widehat\kappa_t)^{\mathsf T}
+v_t\widetilde{k}_t^{\mathsf T}.
\]

也可写为：

\[
S_t=S_{t-1}
\left[\operatorname{diag}(w_t)-
\widehat\kappa_t(a_t\odot\widehat\kappa_t)^{\mathsf T}\right]
+v_t\widetilde{k}_t^{\mathsf T}.
\]

论文采用行向量排版时出现相应转置；论文在式（17）后明确说明 RWKV-7 已转置 WKV 状态以与代码一致。后续方案证明必须固定上面的列向量和右乘方向，不得省略转置后再凭语义猜测。

代码映射：

- `rwkv_v7_numpy.py:39`：`S = S * w.mT - S @ kk * (kk*a).mT + v * k.mT`。
- `rwkv7_clampw.cu:48-62`：每个线程持有状态的一行；`sa=sum_j state[i,j]*(-κ̂[j])`，随后执行 `S[i,j]=S[i,j]*w[j]+sa*(κ̂[j]a[j])+v[i]k̃[j]`。
- `src/model.py:644-650`：传参顺序为 `r,w,k,v,neg_kk,kka`，其中核参数名 `a` 实际接收 `-κ̂`，核参数名 `b` 实际接收 `κ̂⊙a`。不得把 CUDA 形参 `a/b` 与论文的学习率 \(a_t\) 混淆。
- `rwkv7_clampw.cu:60` 中 `k[j]*vi` 是 \(v_i\widetilde{k}_j\)，因此写入是外积 \(v\widetilde{k}^{\mathsf T}\)，不是 \(\widetilde{k}v^{\mathsf T}\)。

### 4.4 动态衰减

论文式（11）至式（12）：

\[
d_t=\operatorname{loramlp}_d(\tanh,x_t^d),\qquad
w_t=\exp[-e^{-0.5}\sigma(d_t)].
\]

代码映射：

- `src/model.py:517-550`：`x_w,w0,w1,w2` 的分层初始化。
- `src/model.py:599-607`：生成令牌移位输入 `xw`。
- `src/model.py:611`：`w_raw=w0+tanh(xw@w1)@w2`，注释明确软钳制与指数在 WKV 核内完成。
- `rwkv7_clampw.cu:16,42`：`W_SCALE=-exp(-0.5)`，执行 `w=exp(W_SCALE*sigmoid(w_raw))`。

数值范围严格为 \(w\in(\exp(-e^{-0.5}),1)\)，按通道、按时间动态变化。把它替换为固定标量衰减、单头标量衰减或 `exp(-softplus(...))` 的其他范围，都不再是本报告冻结的官方实现。

### 4.5 移除键、上下文学习率与替换键

| 论文量 | 论文式 | 代码符号 | 文件与行号 |
| --- | --- | --- | --- |
| 键前体 \(k_t\) | （5） | `k=self.key(xk)` | `src/model.py:572-574,612` |

| 归一化移除键 \(\widehat\kappa_t\) | （15） | `kk` | `rwkv7_tmix_kk_pre_bf16_v5.cu:76-95` |
| 上下文学习率 \(a_t\in(0,1)\) | （4） | `a`、`a0/a1/a2` | `src/model.py:552-555,631`；`rwkv7_tmix_a_gate_bf16.cu:28-61` |
| 替换键 \(\widetilde{k}_t=k_t\odot\operatorname{lerp}(1,a_t,\alpha)\) | （7） | `new_k`、`k_a` | `src/model.py:568,640,644-649`；`rwkv7_tmix_kk_pre_bf16_v5.cu:84-95` |

### 4.6 值与跨层值残差

论文式（8）至式（10）把第一层值前体与当前层值前体插值：

- `src/model.py:557-560`：初始化 `v0/v1/v2`。
- `src/model.py:613-623`：第一层把 `v_first=v`；后续层调用值残差融合核。
- `rwkv7_tmix_vres_gate_bf16_v3.cu:43-65`：计算 `gate=sigmoid(v0+v12)` 和 `v+(v_first-v)*gate`。

删除跨层值残差、让每层使用完全独立的值而不保留此路径，不能称为本报告冻结的完整官方 RWKV-7。

`self.r_k` 对应论文奖励权重 \(\rho\)，形状为 `[H,N]`，初始化见 `src/model.py:569`。当前步奖励在每头状态读出归一化后加入，再乘输出门；它不写入矩阵状态。删除该项、把它提前写入状态，或将接收向量改为 Sigmoid 门，均改变官方算子。

### 4.8 令牌移位、前置层归一化、残差与通道混合

- `src/model.py:517-522,599-607` 为 `r/w/k/v/a/g` 分别保留静态、可训练的令牌移位比例。
- `src/model.py:738-755` 在 TimeMix 与通道混合之前分别使用 `LayerNorm`，并采用两次残差相加。
- `src/model.py:707-726` 的通道混合是移位输入、两层映射和平方 ReLU，不含旧代际的接收门。
- `src/model.py:741-749` 仅第一块具有 `ln0`。

数值输入适配可以替换词嵌入和语言模型头，但不能以“任务不是文本”为由删除这些块内结构后仍称完整官方 RWKV-7。

## 5. 张量形状、乘法方向与数值合同

### 5.1 形状表

| 张量 | 形状 | 数据类型与说明 |
| --- | --- | --- |
| TimeMix 输入 `x` | `[B,T,C]` | 正式训练通常 BF16 |
| `r,w_raw,k,v,a,g` | `[B,T,C]` | 展平的多头通道 |
| WKV 核输入视图 | `[B,T,H,N]` | `N=64`，`C=H×N` |
| 单步矩阵状态 | `[B,H,N,N]` | 核内 FP32 |
| 反向分块状态 `s` | `[B,H,T/16,N,N]` | FP32，仅为反向保存分块边界 |
| 辅助量 `sa` | `[B,T,H,N]` | FP32，等于 `S_{t-1}(-κ̂_t)` |
| WKV 输出 | `[B,T,H,N]` 后展平为 `[B,T,C]` | 与 `v` 同类型，正式核为 BF16 |
| `v_first` | `[B,T,C]` | 第一层值前体，供后续层值残差使用 |
| RNN 移位状态 | 每层 TimeMix `[C]`、通道混合 `[C]` | 与模型激活类型一致 |
| RNN 矩阵状态 | 每层 `[H,N,N]` | FP32 |

### 5.2 乘法方向

冻结方向如下：

1. 旧状态按列衰减：`S @ diag(w)`，CUDA 表现为 `S[i,j]*w[j]`。
2. 移除项先算列向量 `S @ κ̂`，再与 `(a⊙κ̂)^T` 做外积并相减。
3. 写入项为 `v @ k̃^T`，值是列方向，替换键是行方向。
4. 读出为 `S @ r`。
5. 方案 A 文档若使用 `S_{t-1}G_t+B_t`，则 `G_t` 必须右乘；有序矩阵积也必须按时间向右累积。

任何转置测试只比较数值相等是不够的；收据必须明确张量索引约定，避免方阵在偶然对称输入上掩盖方向错误。

### 5.3 数据类型与稳定性

正式参考核的最低合同为：

- WKV 输入与输出为 BF16；状态、分块状态和 `sa` 使用 FP32。
- 序列长度必须满足 `T % 16 == 0`，否则填充并屏蔽损失，或使用经过单独验收的等价核。
- 当前融合核硬编码 `N=64`；`src/model.py:45` 也断言头宽 64。
- 移除键归一化分母下界为 `1e-12`。
- 每头归一化稳定项固定为 `64e-5`，不是 PyTorch LayerNorm 默认值。
- 衰减必须采用核内钳制范围，不能先在 BF16 中直接计算多层指数。
- 不得把矩阵状态降为纯 BF16 或 FP16；论文第 19 页明确警告 WKV7 对数值精度和不同核敏感。
- 训练入口在选择 FP16 时会警告可能溢出，官方示例使用 BF16。
- CUDA 使用 `--use_fast_math`。因此跨核验收应设置合理的 BF16 容差，同时保留 FP32 单步参照，不应要求不现实的逐位一致。

## 6. 初始化与参数分组冻结

### 6.1 初始化

正式从头训练必须调用 `RWKV.generate_init_weight()`，不能只依赖各模块构造器的临时初值。固定责任如下：

- `src/model.py:914-920`：时间参数和归一化参数保留构造值；`ln_x.weight` 按 `((1+layer_id)/n_layer)^0.7` 缩放。
- `:922-926`：词嵌入使用 `[-1e-4,1e-4]` 均匀初始化。数值适配器可以替代词嵌入，但其初始化必须在 A/B/C0 间完全共享并单独登记。
- `:927-934`：语言模型头使用正交初始化；任务头可替换，但 A/B/C0 的同名任务头须共享初始化规则。
- `:938-949`：TimeMix 输出和通道混合值投影置零；TimeMix 键与门投影使用 `0.1` 增益；其余大矩阵使用正交初始化。
- `:966-969`：保存初始化权重时按冻结精度转换。
- `src/model.py:510-581`：TimeMix 的移位、衰减、学习率、值残差、键缩放和当前步奖励参数具有专用分层初值。

### 6.2 优化器参数分组

`src/model.py:793-831` 冻结三组：

1. 名称含 `att.w0`：无权重衰减，学习率倍率 `2.0`。
2. 至少二维且名称含 `.weight` 的大矩阵：使用配置中的权重衰减，学习率倍率 `1.0`。
3. 其余参数：无权重衰减，学习率倍率 `1.0`。

`src/trainer.py:21-53` 再把基础学习率、预热和 `my_lr_scale` 应用到各组。方案 A/B 新增参数必须明确归入哪一组，不能默认全量权重衰减，也不能让不同方案对共享官方参数使用不同分组。

## 7. `C0`、方案 A 与方案 B 的共享边界

### 7.1 三者必须完全共享

以下内容在同一公平比较中必须来自同一构造函数或同一冻结快照：

- 冻结提交、头宽 64、层数、模型维度、头数和前馈宽度。
- `x_r/x_w/x_k/x_v/x_a/x_g` 令牌移位及其初始化。
- `w0/w1/w2` 动态衰减生成与核内钳制。
- `key/k_k` 移除键、每头二范数归一化和 `1e-12` 下界。
- `a0/a1/a2` 上下文学习率。
- `k_a` 替换键增强。
- `value/v0/v1/v2` 和跨层 `v_first` 值残差。
- `receptance/r_k`、当前步奖励、每头归一化、输出门和输出投影。
- 通道混合、前置层归一化、残差、`ln0`。
- 官方共享参数的初始化、优化器分组、学习率倍率和权重衰减规则。
- 状态重置规则、连续段边界、截断长度、精度、核实现和损失屏蔽规则。

若模型宽度或层数因预算不同，必须作为明确的 `C0-P` 或 `C0-C` 对照登记，不能继续声称是除候选机制外完全相同的共享骨干。

### 7.2 `C0` 的允许差异

`C0` 可以把词嵌入替换为冻结的数值输入投影，把语言模型头替换为检测头或共同生成头。这些任务接口不改变 RWKV-7 跨时间算子身份，但必须满足：

- 简单数值投影在 `C0`、方案 A 和方案 B 的适用对照中共享。
- 不添加字段自注意力、双状态、额外历史池化或未来信息。
- 不删除官方块内组件。
- 报告名称应为“数值输入适配的官方 RWKV-7 骨干”，而不是“未修改官方语言模型”。

### 7.3 方案 B 的允许差异

方案 B 只允许：

- 在每个时间步进入 RWKV-7 之前，用当前字段和上一合法状态摘要生成分钟表示。
- 在 RWKV-7 之后增加共同检测和生成任务头。

它不得改动式（3）至式（24）对应的 TimeMix、通道混合或训练分组。只要状态核、层数、头数、初始化和参数分组与 `C0` 相同，方案 B 仍可描述为“单路官方 RWKV-7 跨时间骨干”。

### 7.4 方案 A 的允许差异

方案 A 明确修改式（17）的旧状态传播项，建立共享内容的快慢双状态。因此：

- `r,w,k,v,κ̂,a,k̃,g` 及当前步奖励应由两路共享。
- 两路只能在冻结层级上增加受序标量保留门和状态副本。
- 写入 `v k̃^T` 必须共享；不能为快慢路分别生成键和值后仍使用“共享内容受序记忆”的证明。
- 方案 A 的实现收据必须同时引用未修改 `C0` 核和修改后的差异补丁。
- 方案 A 整体不是官方原样 RWKV-7，而是“基于官方 RWKV-7 广义差分状态的受序双状态改进”。

### 7.5 会退化为“受 RWKV 启发”的修改

出现任一项，模型不能称为本报告冻结的官方 RWKV-7 骨干，只能称“受 RWKV-7 启发”：

1. 用标量或向量指数移动平均替代每头 `N×N` 矩阵状态。
2. 删除归一化移除键、上下文学习率或替换键解耦。
3. 把写入方向改为 `k̃v^T`，或把旧状态改为左乘转移而未给出严格等价变换。
4. 使用 RWKV-4/5/6 的 WKV 递推、时间首项或分子分母归一化形式冒充 RWKV-7。
5. 删除接收向量、当前步奖励、每头归一化、输出门、值残差、令牌移位、块残差或前置层归一化中的任一项，却仍声称复现完整官方架构。
6. 使用未对齐的第三方核且未通过前向、反向、状态传递和初始化验收。官方根说明特别指出当时 FLA 实现未与参考实现对齐。
7. 改用可训练初始状态但不为所有对照共享，也不单独标记为状态调优变体。
8. 从不同官方提交或 `RWKV/RWKV-LM` 派生仓库混取模型、CUDA 核和训练器而不记录差异。
9. 导入 RWKV-8 探索代码或参数后继续使用 RWKV-7 正式身份。

## 9. 已发现但尚未解决的问题

### 9.1 `P0`：状态传递接口尚未冻结

默认 `train_temp` 正式训练核每次调用从零矩阵状态开始，只为反向传播保存分块状态，不接受外部初值或返回最终状态。方案 A/B 的连续时间段和截断反向传播合同要求跨截断携带状态。后续实现前必须二选一：

2. 基于本提交写最小等价适配器，并通过第 8 节的整段／分段等价测试。

在此问题关闭前，不能声称已有可运行的长连续段官方 RWKV-7 实现。

### 9.2 `P1`：论文与当前参考代码的前馈宽度不同

COLM 同题全文式（23）写前馈隐藏宽度为 `4D`；当前 `src/model.py:781` 默认把 `dim_ffn` 设置为向下对齐 32 的约 `3.5D`，而简化脚本 `rwkv7_train_simplified.py:205` 使用 `4C`。这不影响式（15）至式（17）的状态核映射，但会影响完整模型参数量和公平比较。

本报告冻结规则是：正式实现以提交固定的 `src/model.py` 为运行来源，并在配置中显式记录 `dim_ffn`；A/B/C0 必须共享同一值。论文写作需要说明采用的代码版本，不能把 `3.5D` 实现描述成论文原始 `4D` 配置。

### 9.3 `P1`：正式论文 PDF 未完成字节级复核

OpenReview 正式页面和发表身份已核验，但 PDF 直链受站点验证限制返回 `403`。式（3）至式（24）基于仓库已有同题全文逐页核验。若后续需要引用正式版页码或检查最终排版变更，应从 OpenReview 合法取得正式 PDF，记录 SHA-256，并与本地同题全文进行公式差异比较；本任务不重复写入 `raw/` 或创建第二篇笔记。

- 后续最小一致性测试、命令、冻结张量和 JSON 收据字段。
