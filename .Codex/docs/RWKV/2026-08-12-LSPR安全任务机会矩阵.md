# LSPR 数据族安全任务机会矩阵

<!-- RESEARCH_ROUTE=RWKV -->

- **日期**：2026-08-12
- **性质**：文献与数据合同审计；不包含新实验，不改变路线总控、恢复卡或候选登记册
- **范围**：LSPR23、LSPR24、LSPR25；重点判断 12 类安全任务能否由现有字段与标签合法支撑
- **结论状态**：设计可行性与数据门禁判断；所有方法效果均为“实验待证”
- **代理映射**：`security_application_scenarios_literature_sol_max → gpt-5.6-sol → effort=max`

## 1. 结论

LSPR 最值得研究的不是继续追逐同年闭集二分类的最后几个百分点，而是把同一数据族用于**跨年度泛化问题诊断、固定告警预算下的校准、事件级早期预警**。这三类任务具有明确安全决策含义，任务指标尚未饱和；但这不等于当前项目应继续无条件轮换跨年模型。现有 155 维共同输入上的多轮 Q0 已给出弱不利工程证据，跨年方向必须先通过误差、标签与字段可识别性门，才值得再训练新模型。

按当前数据和证据，12 类任务可分为四档：

1. **原生或接近原生支持**：同年二分类、跨年度泛化、校准与固定告警预算、事件级检测与早期预警。
2. **可在新合同下合法派生**：持续学习与概念漂移、选择性预测、机器遗忘压力测试、投毒或后门恢复压力测试、解释与主动学习。
3. **必须增加可靠语义标注后才成立**：跨攻击留一、开放集未知攻击、攻击阶段与叙事溯源、同年多分类。
4. **当前不能声称**：把 `Label=-1` 当未知攻击；把 `Category` 或 Suricata 告警当攻击家族真值；把 `Steps_submitted_time` 当攻击开始时间；把跨年性能下降直接称为某一种已定位的概念漂移。

### LSPR 优先级

| 排名 | 任务 | 当前判断 | 核心原因 |
| ---: | --- | --- | --- |
| 1 | 校准与固定告警预算 | **研究与实验均优先** | LSPR24 时间前向训练/验证正类率相差 2.15 倍；安全运营关心每小时或每百万流告警，而不是只看 AP，且可复用现有分数、无需先轮换骨干。 |
| 2 | 事件级检测与早期预警 | **推荐，先修复切分口径** | 流结束时间、连续窗口和事件数量门禁已初步通过；任务指标与普通逐窗分类不同，尚未饱和；需先用 CPU 树验证历史是否有增量。 |
| 3 | 跨年度泛化 | **研究价值高；当前模型实验有条件暂停** | LSPR23→24 公开结果证明问题重要且未饱和，但本项目 R1、C12/C12-R、TL1 等 Q0 多轮弱不利，强树在固定预算下只召回极少恶意样本；先做可识别性诊断，不继续盲目换模型。 |
| 4 | 选择性预测与拒识 | **条件推荐** | 跨年失效为拒识提供动机，但必须证明拒识分数在域移位下真的排序风险，而不是只拒绝困难良性流。 |
| 5 | 持续学习与概念漂移 | **条件推荐** | 23→24→25 具有自然顺序，但 LSPR25 受限，且离线标签不等于部署时即时反馈；需要单独的标签延迟合同。 |

机器遗忘、投毒/后门恢复、解释与主动学习可以在 LSPR 上做，但它们目前依赖人工构造请求、攻击或反馈，安全语义弱于前五项。开放集、攻击留一、多分类与攻击阶段溯源当前缺原生标签，不应直接进入模型实验。

## 2. 证据口径

### 2.1 证据标记

- **全文事实**：论文全文或官方数据说明直接报告。
- **项目制品事实**：本项目已有数据合同、诊断日志或运行制品直接报告；不等同论文正式结果。
- **本课题推论**：由全文与数据合同推出的任务设计判断，必须经实验验证。
- **当前不可构造**：现有标签或元数据不足，强行构造会混入身份、未来信息或伪真值。

## 3. 数据能力与不可越过的标签边界

| 能力 | LSPR23/24 当前证据 | 对任务的约束 |
| --- | --- | --- |
| 流级输入 | 两年字段集合均为 101 列；首轮冻结 77 个语义共同、因果合法字段 | IP、端口、主机名、网段、EXPO、绝对时间、IDS 输出、标签及其派生量禁入模型。 |
| 时间 | 有 `mTimestampStart` 与 `mTimestampLast`；完整流统计只在 `mTimestampLast` 后可用 | 所有在线、预警和停止任务按流完成时间排序，不能使用尚未结束流的最终统计。 |
| 主标签 | `Label∈{0,1}` 表示良性或与红队基础设施/跳板活动相关 | 不是攻击家族、阶段、攻击成功或损害真值；不能直接做原生多分类。 |
| LSPR24 筛选标签 | 窗口旁车含 `-1/0/1`；`-1` 占 60.4075% | `-1` 是未标注或删失，不是“未知攻击”；监督评价必须只用 0/1。 |
| 分组 | IP、EXPO、Segment 可在受控侧车用于分组和审计 | 分组键不得编码、计数、分桶或嵌入；身份留出不等于攻击留出。 |
| 攻击叙事 | LSPR24 有 `attack_narratives.json`，但当前时间封存清单发布前禁止解析 | 叙事存在不等于可逐流映射；`Steps_submitted_time` 不是动作开始时间。 |
| 年度成员 | LSPR23 和 LSPR24 已取得；LSPR25 论文全文已核验，但原始数据访问受限 | 当前可执行跨年对为 23→24；24→25 只能作已发表背景，不能启动本课题实验。 |
| 删除、投毒与反馈 | 数据没有原生删除请求、投毒标记、后门触发器、分析员反馈或解释真值 | 相关任务只能作为预注册的训练区压力测试；不能包装为数据原生业务事件。 |

共同字段与时间协议见[跨年度数据合同](2026-08-11-LSPR23-LSPR24共同字段审计与跨年度数据合同.md)。公开与内部基线分级见[完整基线登记册](2026-08-12-LSPR完整基线登记册.md)。

## 5. 逐项任务卡

### 5.1 同年二分类与多分类

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 输入为截至流结束时可见的合法当前流或因果历史；二分类输出 `P(Label=1)`。多分类需输出攻击家族或阶段，但当前不存在相应逐流真值。 |
| 字段与标签支持 | **二分类原生支持**。`Label` 仅表示红队/跳板关联。`Category`、`Severity`、`Anomaly_event` 是 IDS 输出，不可改作真值；叙事也尚未完成逐流映射。因此**多分类当前不可构造**。 |
| 现有论文/强基线 | Dijk 2024：RF `F1=0.997`，但字段、超参和隔离协议不完整；Dijk 2026：LSPR24 同年 XGBoost `AP=0.9923`、最佳 Transformer `AP=0.9897`。项目筛选视图 408 字段 XGBoost 验证 `AP=0.9690`，仅为内部诊断，协议不同。强基线为合法字段的 RF、XGBoost/HGB、GRU、因果 Transformer。 |
| 指标 | AP/精确率—召回曲线、恶意类召回/F1、每百万流假阳性、时间块或序列簇自助区间；不能以准确率为主。 |
| 饱和程度 | **现有同年二分类协议接近饱和**。但高分可能受随机/固定拆分、身份相关字段、窗口派生特征和单种子影响；严格去身份、按活动时间前向的正式协议尚未得到论文级结果。 |
| 主要协议缺陷 | Dijk 2024 未披露分组隔离与实际字段；Dijk 2026 未披露训练/验证比例和完整缺失规则；内部 0.9690 使用 408 个筛选字段、单种子、非正式视图。三者不能混排。 |
| 最小可证伪实验 | 在 LSPR24 开发区固定 77 字段与时间前向切分，比较当前窗 XGBoost、同历史 XGBoost、GRU/因果 Transformer。若强树已在多个时间块和三种子稳定接近上限，且任何时序模型增量小于预注册 `ΔAP=0.005`，否决“以同年二分类作为主要创新任务”。 |
| 适配判断 | 可作工程基线，**不宜单独成为毕业论文主任务**；多分类在新增可靠标签前直接否决。 |

### 5.2 跨年度泛化

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | LSPR23 有标签训练，冻结后在 LSPR24 时间前向数据上输出恶意概率；可选前 10% 无标签前缀，但不得读取其标签清洗或选参。 |
| 字段与标签支持 | 两年均有同名 101 列与二元标签；合同已冻结 77 个共同输入、2-IP 侧车分组、最长 128 流和最终 20% 封存，**原生支持**。 |
| 现有论文/强基线 | Leoste 2025：RF/CNN 跨年最佳 `F1≈18.4%`；Dijk 2026：23→24 的 XGBoost/GRU/Transformer `AP=0.2416/0.1758/0.0742`。项目共同合同 Q0 的强树 AP 约 `0.0369–0.0389`，是不同字段、成员与协议下的筛选结果。正式基线应含冻结模型、RF、XGBoost/HGB、GRU、因果 Transformer及简单无标签先验校正。 |
| 指标 | AP、AP/目标正类率、恶意召回/F1、每百万流假阳性、源→目标绝对/相对退化、源保留、时间分块稳定性、效率。 |
| 饱和程度 | **明确未饱和**。公开论文和项目 Q0 均显示跨年显著退化，但数值协议不同，不能直接比较高低。 |
| 主要协议缺陷 | 公开研究的字段、缺失值、拆分成员和归一化不能完整复现；资产身份分组可能高估同年性能；目标年标签若用于选字段、选构造、阈值或停止即泄漏。 |
| 最小可证伪实验 | 固定 77 字段与 2-IP，LSPR23 训练/验证后一次评价 LSPR24 可见开发段；比较冻结 XGBoost、冻结神经基线、仅先验修正、候选方法。若候选三种子均不超过最强强基线的预注册增量，或以源年遗忘/目标假阳性换取 AP，否决候选。 |
| 适配判断 | **研究问题价值高，但当前项目的下一模型实验优先级受门禁约束**。理论空间在域移位、风险控制和状态更新；现有 Q0 未支持继续轮换模型，只有误差/标签/字段可识别性诊断出现明确靶子后才恢复方法实验。 |

#### 本项目跨年工程证据与停止门

以下都是 `screening_only=true`、`formal_paper_evidence=false`、`final_accessed=false` 的单种子 Q0，属于候选调度证据，不是正式论文结论：

- 共享 XGBoost 锚 `AP=0.038902589823969644`；TL1 的最佳全量最优传输 `AP=0.039087019199325335`，相对锚仅 `+0.000184429375355691`，所有变体恶意召回均为 `1/2020=0.0004950495`，固定每百万流 `100/1000/10000` 告警预算增量均为 0。
- R1 最佳 GroupDRO `AP=0.012877901366876719`，低于共享 XGBoost；Q0 不晋级。
- C12-R 六格最高为 DREF `AP=0.009274477710716156`，其余门控、裁剪、预算、回退与随机匹配对照均未超过 DREF，恶意类 F1/召回为 0。
- 候选 B 的离散对照 `AP=0.019205959409695748`，角色分离物理时间变体 `AP=0.010123021167351991`；机制门失败。

证据路径：[候选登记册的 Q0 汇总](2026-08-08-第三章候选方案登记册.md#2-活动候选)、[TL1 实施与运行报告](2026-08-12-跨年度恶意质量保护部分传输-Q0实施与运行报告.md)、[R1 Q0 报告](2026-08-11-R1双层尾部风险重构Q0实现与运行报告.md)、[C12-R 报告](2026-08-12-C12-R非破坏性双参照回放实现与运行报告.md)、[候选 B 报告](2026-08-12-候选B角色分离物理时间RWKV-Q0实现与运行报告.md)。

因此，下一步不是再加一种适应器或骨干，而是先完成三项最低成本诊断：

1. **标签可识别性**：人工抽查或独立 IDS/叙事证据核验强树漏掉的 2019 个恶意样本是否含系统性错标或不可观测标签语义。
2. **字段可识别性**：比较合法 77 字段、155 维值+缺失表示与论文 83 字段的可用性差异，确认低 AP 不是合同字段语义缺口或预处理错误。
3. **误差靶子**：按时间块、协议、缺失模式、2-IP 见/未见和事件簇分解误差；若没有单一可行动分面贡献至少预注册比例，暂停跨年方法开发。

### 5.3 跨场景或攻击留一

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 训练若干独立场景/攻击，测试完全未见的场景或攻击；输出二元检测或攻击类。 |
| 字段与标签支持 | LSPR 有年度、活动时间块、Segment/Expoid 和 IP 侧车，可做年度或实体留出；但 `Label` 没有攻击家族，Segment/Expoid 是演习身份，不是攻击类型。**可做实体/时间/年度留出，不能称攻击留一。** |
| 现有论文/强基线 | Dijk 2026 是跨年度而非攻击留一；LSPR 直接使用审计没有找到攻击留一实验。强基线应为训练多数场景后的冻结 XGBoost/GRU/Transformer，以及按场景分组的分布鲁棒训练。 |
| 指标 | 留出域 AP、宏平均域 AP、最坏域 AP、域内—域外差值、每域假阳性；若未来有攻击类，再报未知攻击召回。 |
| 饱和程度 | **无法判断**，因为任务协议和原生攻击类别均未闭合。 |
| 主要协议缺陷 | 把年度留出称攻击留一会混淆环境、良性业务、拓扑和攻击变化；把 Expoid/Segment 入模会让场景身份直接泄漏。同步多主机流也不是独立攻击复现。 |
| 最小可证伪实验 | 先做纯数据门禁：在不解析最终区的前提下，统计能否由叙事和流时间唯一形成至少三个互斥、各含足够正事件的攻击组。若不能，否决攻击留一；只保留“年度/时间/实体泛化”的准确命名。 |
| 适配判断 | **当前不适合作为主任务**。可作为跨年度主任务的困难分面，但不能单独声称未知攻击泛化。 |

### 5.4 开放集未知攻击

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 训练已知攻击类别，测试含训练完全未见类别；模型可输出某个已知类或“未知”。 |
| 字段与标签支持 | 二元 `Label` 不能区分已知/未知攻击；窗口 `-1` 是删失而非未知；IDS `Category` 不是可靠攻击真值。**当前不可合法构造。** |
| 现有论文/强基线 | LSPR 直接使用研究没有开放集实验。外部开放集协议要求把原生攻击子类在切分前完全隔离；可用能量/最大对数几率、OpenMax、距离原型与一类检测作未来基线，但必须先有原生子类真值。 |
| 指标 | 未知攻击召回、未知误报率、已知类宏 F1、开放集分类率、AUROC/曲线下面积、良性误报；阈值只能用与最终未知类不同的验证伪未知类。 |
| 饱和程度 | **不可评价**。跨年低 AP 不是开放集结果，不能证明未知类拒识能力。 |
| 主要协议缺陷 | 把下一年度整体当“未知攻击”会把业务与环境漂移混入类别新颖性；把 `-1` 或低置信样本事后改名为未知不构成开放集协议。 |
| 最小可证伪实验 | 只做标签审计：若开发区不能从叙事/独立来源得到至少三组互斥攻击子类，以一组训练已知、一组验证伪未知、一组最终未知，则停止，不训练开放集模型。 |
| 适配判断 | **当前否决**；GeNIS 等有原生多层攻击标签的数据更适合该任务。 |

### 5.5 持续学习与概念漂移

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 按时间顺序接收流与延迟标签，在适应新分布的同时保持旧分布能力；或无标签检测漂移并决定何时更新。 |
| 字段与标签支持 | LSPR23/24 有自然年度与活动时间顺序，适合离线回放；但数据没有真实标签到达时间或线上反馈日志。必须另行冻结标签延迟、更新频率和回放预算。 |
| 现有论文/强基线 | 已有研究只做冻结跨年评价，没有 LSPR 持续学习论文。强基线为完全冻结、周期全量重训、滑窗重训、有限回放、EWC/LwF，以及仅先验修正；所有方法需同标签与计算预算。 |
| 指标 | 预序列 AP、适应延迟、累计遗憾、过去时间块遗忘、最坏时间块 AP、更新次数、标注和算力成本、校准漂移。 |
| 饱和程度 | **未饱和**，但“有性能漂移”不等于已定位概念漂移类型。LSPR24 仅约 31.6 小时，单年内不足以支撑长周期结论。 |
| 主要协议缺陷 | 离线一次性标签若立即用于每批更新，会高估部署能力；随机回放会泄漏未来；自然漂移与恶意投毒可能混杂；LSPR25 原始数据尚不可用。 |
| 最小可证伪实验 | LSPR23 初始化，LSPR24 开发段按活动时间分块，冻结固定标签延迟与每块更新预算；比较冻结、滑窗重训、有限回放和候选。若候选不降低累计损失，或目标改进伴随源验证显著遗忘，否决持续机制。 |
| 适配判断 | **条件推荐**。适合跨年主任务的第二层问题，但必须避免把普通再训练改名为持续学习。 |

### 5.6 选择性预测与拒识

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 模型对部分流给出自动判定，对不可靠样本拒识并交给分析员；输出类别、置信度和是否拒识。 |
| 字段与标签支持 | 二元标签与预测分数足够离线评价风险—覆盖；没有真实分析员处置结果，因此“拒识后安全解决”只能作为成本假设。 |
| 现有论文/强基线 | 无 LSPR 专项研究。强基线为最大概率/边际拒识、熵阈值、深度集成或树集成方差、保形风险控制；必须和随机拒识、仅按正类分数拒识比较。 |
| 指标 | 风险—覆盖曲线、曲线下面积、固定覆盖下错误率、固定风险下覆盖率、恶意漏报、良性误拒、每小时人工队列量。 |
| 饱和程度 | **未知且可能有余量**。跨年模型普遍失效提供动机，但未证明置信度能识别这些错误。 |
| 主要协议缺陷 | 在源验证集选拒识阈值后直接用于目标年可能失校；仅拒绝高熵样本可能漏掉高置信错误；拒识过多可虚假降低自动错误率。 |
| 最小可证伪实验 | 冻结 LSPR23 模型，在 LSPR24 可见开发段比较最大概率、集成方差和保形风险控制，在完全相同覆盖率网格报告风险。若候选不支配简单最大概率基线，或主要拒绝良性而未降低恶意漏报，则否决。 |
| 适配判断 | **条件推荐**，适合作为跨年度泛化的安全决策层，不宜脱离主检测任务单独成章。 |

### 5.7 概率校准与固定告警预算

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 将模型分数变为可解释概率，或在每小时/每百万流固定告警额度下选择阈值；输出概率、告警和预算使用量。 |
| 字段与标签支持 | LSPR24 有严格时间、0/1 标签和流量计数，可原生计算按小时/按流预算。训练与验证正类率 `0.048423` 对 `0.022486`，先验约变为 `2.15` 倍。 |
| 现有论文/强基线 | 无 LSPR 专项论文。强基线为未校准、Platt/逻辑缩放、温度缩放、等距回归、先验移位修正和滚动分位阈值；神经与树模型分别用适合的校准器。 |
| 指标 | NLL、Brier、期望/最大校准误差、可靠性图、固定告警预算下召回/精确率、每小时假阳性、预算超限率。 |
| 饱和程度 | **明显未验证**。高 AP 只表示排序较好，不表示概率或固定运营工作点可靠；时间先验变化直接暴露阈值迁移风险。 |
| 主要协议缺陷 | 温度缩放等经典方法通常假定校准与测试近似同分布；用最终区调阈值会泄漏；按全局行数定阈值会忽略每小时流量变化。 |
| 最小可证伪实验 | 在 LSPR24 开发区按 `0–40%` 训练、`40–50%` 校准、`50–60%` 确认；比较五类校准器和按小时滚动阈值。若候选在确认段不能同时改善 Brier/NLL 与预算召回，或预算超限更高，则否决。最终 20% 保持不可见。 |
| 适配判断 | **强推荐**。理论可围绕移位下校准与风险控制，工程成本低于训练新骨干，且安全解释清楚。 |

### 5.8 事件级检测与早期预警

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 任务 A：从第一条严格阳性流完成后尽早告警；任务 B：在当前严格阴性窗预测未来 `K=4` 个 5 秒窗内是否出现阳性。输出事件告警或未来风险。 |
| 字段与标签支持 | 可从 0/1 连续窗、流完成时间和同实体后继关系派生。修正活动键边界后，任务 B 三段正锚点 `2883/1968/356`、独立前体簇 `1025/753/158`，数量门禁通过；真实攻击动作起点仍不可默认恢复。 |
| 现有论文/强基线 | 无公开 LSPR 早期预警论文。项目已预注册当前窗 XGBoost、因果历史 XGBoost、HGB、纯序列模型、固定阈值、连续 K 次、CUSUM/SPRT 等基线；尚无有效完成结果。 |
| 指标 | 固定误报预算下事件召回、漏报率、每小时误报、从首个阳性完成窗到告警的延迟；未来风险任务用 AP、固定预算召回及首次阳性步分面。 |
| 饱和程度 | **未饱和**。逐窗同年 AP 高不能替代事件召回和时延；现有运行因内存事故中断，不构成科学失败。 |
| 主要协议缺陷 | 共享视图的活动键 60% 边界核验曾失败，必须先复核；`-1` 必须断链或删失；按首次阳性流定义的“早期”晚于真实动作；不能把告警前的未来窗统计输入模型。 |
| 最小可证伪实验 | 先复核切分口径，再在开发前三段运行当前窗与同历史 XGBoost。若历史基线相对当前窗在 A 的事件召回增量 `<0.02`，或在 B 的 `ΔAP<0.005`，停止 GPU 序列模型；若事件映射不足，退回逐窗任务。 |
| 适配判断 | **推荐**，但必须使用准确名称“红队关联阳性窗事件内早期检测”，不得声称预测真实攻击开始。 |

| 项 | 内容 |
| --- | --- |

| 适配判断 | **当前否决**。数据审计成功后可成为高价值扩展，但不能先写方法再寻找叙事真值。 |

### 5.10 机器遗忘

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 收到删除/纠错请求后移除指定训练流、时间块或污染簇对模型的影响，保留其余检测能力；输出更新模型与遗忘证明指标。 |
| 字段与标签支持 | 任意 LSPR23 训练样本可作为人工遗忘集，但数据没有真实删除请求。具有安全语义的候选是“错误红队归因时间块”“被污染传感器区间”或“撤回的端点簇”，必须只在训练区定义。 |
| 现有论文/强基线 | LSPR 查全审计没有遗忘研究。强基线必须含删除后完整重训（金标准）、分片重训/SISA、检查点回滚；树模型还应比较其专用更新方法，神经模型比较微调式遗忘。 |
| 指标 | 与完整重训的预测距离、遗忘集残留攻击成功率/损失、保留集 AP、成员推断优势、更新耗时和内存；不能只报速度。 |
| 饱和程度 | **未知**。同年分类近饱和不意味着删除影响已解决。 |
| 主要协议缺陷 | 随机删 0.01% 行很容易但业务语义弱；相邻/同端点流高度相关，删一行不等于删一个事件；最终测试不能用来选择遗忘强度。 |
| 最小可证伪实验 | 只在 LSPR23 训练区按整个 2-IP 簇或时间块定义遗忘集，比较完整重训、SISA/分片回滚和候选。若候选与完整重训差距超出预注册容差，或速度优势以保留集 AP/跨年 AP 明显下降换取，则否决。 |
| 适配判断 | **可做次选**。算法和评价清楚，但当前缺原生删除语义，且与论文主线“时序检测训练方法”衔接较弱。 |

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 攻击者污染训练数据或在线更新流，使触发模式被定向误判；防御检测污染并从可信快照恢复。 |

| 最小可证伪实验 | 先做攻击有效性门：在 LSPR23 训练区按 `0.1%/1%/5%` 簇级污染，要求候选触发器产生高攻击成功率且干净 AP 下降受限；若攻击门失败，不评价防御。攻击成立后，在相同污染预算比较过滤、回滚、完整重训与候选恢复。 |
| 适配判断 | **可做次选但风险高**。需要可信的流量约束攻击模型，否则容易成为人为玩具任务。 |

### 5.12 解释与主动学习

| 项 | 内容 |
| --- | --- |
| 任务输入/输出 | 解释：说明哪些合法字段/历史导致告警；主动学习：在时间顺序未标注池中选择有限流或事件交给分析员标注。 |
| 字段与标签支持 | 77 个语义字段和时序关系可做模型解释；0/1 标签可离线模拟标签预算。数据没有特征级解释真值、分析员响应时间或标注成本，不能声称真实人机效果。 |
| 现有论文/强基线 | LSPR 无专项研究。解释基线为树 SHAP、置换重要度、时间遮挡/积分梯度；主动学习基线为随机、最大不确定度、类别平衡与核心集/多样性查询。 |
| 指标 | 解释忠实度、删除/插入曲线、跨种子/时间稳定性、物理可行反事实率；主动学习用 AP—标注数曲线、达到目标 AP 所需标签、正事件覆盖、人工队列量。 |
| 饱和程度 | **未知**。高同年 AP 不证明解释可靠，也不证明不确定性采样比随机更省标签。 |
| 主要协议缺陷 | SHAP 相关性不是攻击根因；解释若出现禁入身份代理必须判失败；主动学习随机打乱池会泄漏未来，逐流查询还可能反复标同一事件。 |
| 最小可证伪实验 | 时间前向隐藏 LSPR24 开发标签，以事件簇为查询单位，在相同预算比较随机、不确定度和多样性采样；若查询策略的 AP—预算曲线不优于随机，否决主动学习。解释仅作审计：若遮挡高重要字段不改变输出或解释跨时间不稳定，则不得用于方法主张。 |
| 适配判断 | **条件次选**。更适合作为跨年/预警主任务的辅助评价，不宜把无真值的可视化当独立创新。 |

## 6. 指标与协议不能混用

下列三个结果来自不同数据单位、字段和切分，必须分栏报告：

| 结果 | 协议 | 允许解释 |
| --- | --- | --- |
| Dijk 2026：LSPR24 同年 XGBoost `AP=0.9923` | 83 字段、论文序列拆分、同年 | 该论文协议下同年逐流排序接近上限。 |
| 项目诊断：LSPR24 同年 XGBoost `AP=0.9690348794` | 408 个窗口派生字段、时间前向筛选视图、种子 42、非正式 | 共同筛选视图的强树仍很高，`ΔAP=0.005` 机制门具有数值余量；不得作论文结果。 |
| Dijk/Leoste 及项目 Q0 的 LSPR23→24 结果 | 年度迁移，但字段、成员、缺失处理和模型协议彼此不同 | 跨年任务未饱和；不能把各自绝对数值直接排成方法胜负。 |

尤其禁止用同年 `AP≈0.97–0.99` 断言 LSPR 数据“整体饱和”，也禁止用项目 Q0 `AP≈0.04` 断言公开论文基线不可复现或失效。

## 7. 最小研究路线建议

若只从 LSPR 选择当前最值得验证的安全任务，建议顺序是：

1. **先做安全决策层：移位下概率校准与固定告警预算**。不依赖新的攻击家族标签，可复用已冻结模型分数验证，工程代价最低。
2. **再做时间操作层：事件级检测/早期预警**。先修复共享视图切分口径并完成事件门禁；若因果历史没有超过树基线的最小信号，立即停止。
3. **跨年度检测保留为高价值研究问题，但暂停盲目模型轮换**。固定 77 字段、2-IP、时间因果与最终封存，先通过标签、字段和误差可识别性诊断；只有出现明确靶子才恢复候选实验。

选择性预测可以和第 2 项合并为“预算受限的拒识与告警”，持续学习可作为跨年主任务的后续扩展。机器遗忘和投毒恢复不应与上述主线同时展开，除非论文明确改题为模型更新安全。

## 8. 风险与未关闭项

- LSPR25 原始数据仍受限；当前不能实现 24→25 本课题实验。
- LSPR24 筛选视图切分键曾出现核验不一致；事件任务必须先修复或解释该口径。
- `attack_narratives.json` 尚未在获准的时间封存清单下解析；攻击阶段、真实动作起点和攻击留一均保持关闭。
- LSPR23/24 标签是红队基础设施关联代理，存在跳板漏标和非意图流被标阳性的可能；所有结论须使用准确任务名称。
- 机器遗忘、后门、主动学习和选择性预测均需要新增任务合同；本矩阵只说明可试性，不授权实现或实验。
