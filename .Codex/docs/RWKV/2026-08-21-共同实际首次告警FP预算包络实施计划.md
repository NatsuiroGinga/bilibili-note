### 1.2 三种构造比较

| 构造 | 做法 | 优点 | 缺陷 | 裁决 |
| --- | --- | --- | --- | --- |
| 精确 FPR 交集 | 只比较五方法恰好相同的实际 FPR 点 | 表面上横轴完全一致 | 阶梯同分组不同，交集可能为空或接近单例；会把可比较问题错误改写为缺点问题 | **否决** |
| 名义预算插值或拆同分 | 在六档名义 FPR 上插值，或从同分实体中截取到目标 FP | 表格紧凑 | 构造了系统实际不可达到的阈值，违反完整并列组合同 | **否决** |
| 共同整数 FP 包络 | 每方法按良性 `path_max` 完整同分组生成可达阶梯；对公共整数预算 `k` 取自身 `FP<=k` 的最后可达阈值 | 不要求阈值相同，预算单位相同；完整保留真实可达性；可机械复算 | 及时检出是二维对象，必须限制持久化规模 | **采用**：完整保存 path-budget 与同阈值终端曲线，只在六个预注册公共预算保存及时检出阶梯 |

不采用 `47,115` 个实体乘全部曝光位置的二维稠密矩阵。完整 path-budget 曲线已经保存全部阈值与检测权衡；及时检出曲线只回答预注册六档部署预算下“多早发现”，保存六档足以裁决 N-16，扩展到每个整数 `k` 只会重复相同阈值段并造成不必要的计算与制品膨胀。

## 二、冻结数学定义

### 2.1 共同实体、标签与顺序

对每个实体 `e`，其合法流按冻结逐流数组索引升序排列为 `i(e,1),...,i(e,L_e)`；`j` 同时是 1 基 `exposure_index`。不得按 `t24`、不完整 `available_ns` 或模型分数重排。实体键仍由 `s24/d24` 构造词典序规范化的无向地址对，原始地址只用于分组，不入模、不落派生映射。

实体标签为该实体逐流标签最大值。运行时必须逐项复现：

- 流数 `N=20,227,356`；
- 实体数 `E=47,115`；
- 正实体数 `P=752`；
- 负实体数 `B=46,363`；
- 每条流恰好属于一个实体，每个实体至少一条流。

任一身份或分母不符即失败，不按新分母静默重算六档公共预算。

### 2.2 五种在线分数

设 `q_{m,e,j}` 为方法 `m` 对第 `j` 条曝光输出的冻结逐流恶意概率，设在线分数为 `r_{m,e,j}`。所有概率在进入聚合前只允许转为 FP64 累加，不得裁剪、校准、舍入或以目标标签修改；必须机械断言有限且位于 `[0,1]`。

| 方法 | 逐流概率来源 | 冻结在线分数 `r_{m,e,j}` | 终端分数 |
| --- | --- | --- | --- |
| 一维 CNN | 既有 `scores_cnn_leoste2025.npy` | `max_{1<=u<=j} q_{m,e,u}` | 已发表口径的完整实体最大值 |
| GRU | 既有 `scores_gru_dijk2026.npy` | `max_{1<=u<=j} q_{m,e,u}` | 已发表口径的完整实体最大值 |
| 全注意力 Transformer | 既有 `scores_transformer_dijk2026.npy` | `max_{1<=u<=j} q_{m,e,u}` | 已发表口径的完整实体最大值 |
| XGBoost＋CPA-ELP C11 | 冻结 `semantic168`、800 树模型对 LSPR24 的一次逻辑重打分 | `j^{-1} sum_{u=1}^{j} q_{m,e,u}`，即 `p=1` 运行均值 | 完整曝光算术平均 |
| 全容量 MLP O11 | 冻结 O11 选中检查点的一次 FP32 概率推理 | `(j^{-1} sum_{u=1}^{j} q_{m,e,u}^{p_m})^{1/p_m}` | 完整曝光 `p_m` 幂平均 |

MLP 的 `p_m` 必须从 O11 选中检查点及选择收据读取并以全精度记录，不得使用报告中的舍入值重新构造，也不得重新选择 `p`。O11 的逐流概率保持检查点原输出，幂平均只改变实体在线读法。XGBoost 的 `p=1` 固定为父选择收据的 `semantic168/p=1`，不得切回 `raw83` 或其他格。

每个实体另定义：

```text
path_max_{m,e} = max_j r_{m,e,j}
terminal_{m,e} = r_{m,e,L_e}
```

已发表三模型的在线分数是前缀最大值，因此其 `path_max` 与 `terminal` 相同；XGBoost 和 MLP 的运行均值或运行幂平均可以回落，两者必须分别保存路径读数和终端读数，禁止混成一条曲线。

### 2.3 良性 `path_max` 完整并列组

对每个方法，用全部正负实体的 `path_max` 形成降序唯一阈值。首点阈值为全体最大 `path_max` 的向上相邻浮点数，代表 `TP=FP=0`；其后每个阈值一次纳入该值的完整正负实体同分组。公共预算只由组内良性实体累计数决定，但同一分值的良性实体绝不拆分；纯正实体同分组可以使多个连续阈值共享同一 `path_fp`，因此后续必须取该 FP 下最后可达阈值。

对阈值 `t` 分别计算：

```text
path_fp_m(t)       = # {e: y_e=0 and path_max_{m,e} >= t}
path_tp_m(t)       = # {e: y_e=1 and path_max_{m,e} >= t}
path_dr_m(t)       = path_tp_m(t) / P
terminal_fp_m(t)   = # {e: y_e=0 and terminal_{m,e} >= t}
terminal_tp_m(t)   = # {e: y_e=1 and terminal_{m,e} >= t}
terminal_dr_m(t)   = terminal_tp_m(t) / P
```

`path_fp` 是共同预算轴；`terminal_fp/DR` 只是在完全相同的路径阈值下观察最终时刻状态。完整路径曲线与同阈值终端曲线必须进入不同制品和不同键，不能把终端 FPR 当作路径预算，也不能沿用旧终端曲线的阈值。

### 2.4 公共整数 FP 预算与六档锚点

完整公共轴为所有整数 `k in [0,46363]`。方法 `m` 在预算 `k` 上的阈值索引固定为：

```text
i_m(k) = max {i: path_fp_m(t_i) <= k}
```

即取自身 `FP<=k` 的最后可达完整并列组；不拆同分、不插值、不构造精确 FPR 交集。若同一 `path_fp` 出现重复表示，只保留阈值序中的最后可达点，并在收据登记去重规则。

六档名义预算只用于从公共整数轴选定及时检出曲线。按 `k_b=floor(b*46363)` 得：

| 名义预算 `b` | 公共整数预算 `k_b` |
| ---: | ---: |
| `0.1%` | `46` |
| `0.5%` | `231` |
| `1%` | `463` |
| `2%` | `927` |
| `4%` | `1,854` |
| `8%` | `3,709` |

每方法在每个 `k_b` 仍取自己的最后可达阈值，并记录实际 `path_fp`、`path_fpr`、完整良性同分组大小、下一可达点及其是否超预算。`4%` 仍只是 Gehri 2023 同源经验锚点，不是部署标准或理论门槛。

### 2.5 及时检出阶梯

对每个方法和六个 `k_b`，在对应阈值 `t_{m,b}` 下记录每个实体首次满足 `r_{m,e,j}>=t_{m,b}` 的 1 基 `exposure_index`。持久化内容只包括：

- 固定 `P=752` 分母的正实体未告警率、告警数和首次曝光分位数；
- 由真实首次跨越位置唯一断点编码的右连续及时检出阶梯；
- 良性告警数与实际首次告警 FPR；
- 最大正实体曝光数、曲线点数、阈值和共同整数预算。

必须断言良性首次告警数等于该阈值的 `path_fp`。未告警正实体保留在固定分母中；不得只对已告警子集计算一条“平均时延”。`time_delay_available=false`，不得将曝光序号解释为秒级时延。

## 五、稀疏算法、复杂度与内存上界

### 5.1 单模型顺序算法

1. 一次构造共享实体编号、稳定实体内流序和实体标签，并核验共同分母。
2. 每次只处理一个方法；得到逐流概率后，第一次沿稳定顺序维护每实体常数个状态，计算 `path_max` 和终端分数。
3. 对全部实体 `path_max` 稳定排序并按位级相等值整组累计正负实体；用终端分数的排序搜索生成同阈值终端曲线，并据此冻结六个公共预算的阈值。
4. 在逐流概率仍只驻留一份时第二次沿稳定顺序扫描，计算六档首次跨越位置和及时检出阶梯；这不是第二次模型推理或打分。
5. 将方法级聚合 JSON/NPZ 原子发布后立即释放逐流概率与模型专属临时矩阵，再进入下一方法。
6. 五方法全部完成后，按整数 `k` 投影曲线、执行支配判断并生成最终聚合与清单。

### 5.2 复杂度

设方法数 `M=5`、流数 `N=20,227,356`、实体数 `E=47,115`、固定及时预算数 `Q=6`。共享稳定排序最多一次 `O(N log N)`；每方法在线扫描为 `O(QN)`，实体曲线排序为 `O(E log E)`，公共整数预算投影为 `O(MB)`。不允许对每个阈值重扫全部流。

XGBoost 的 `semantic168` 构造与模型推理、MLP 的检查点推理沿用各自既有生产入口的批处理复杂度；N-16 评价器不得再复制第二份全量特征矩阵。

### 5.3 固定内存形状

评价器允许的全流级数组种类固定为：一份 `int32[N]` 实体编号、一至两份 `int64[N]` 稳定顺序/排序工作区，以及当前方法一份 `float32[N]` 概率。及时检出只保存 `int32[Q,E]` 首次位置和常数个 `float64[E]` 累加器；禁止 `E×L_max`、`E×N`、`B×全曝光` 或任意阈值×流二维矩阵。

按冻结规模，单份 `float32[N]` 或 `int32[N]` 为 `80,909,424` 字节，单份 `int64[N]` 为 `161,818,848` 字节，`int32[6,47115]` 为 `1,130,760` 字节。实现必须在配置中机械断言数组数量和类型，不得以缓存便利突破该上界。对象地址数组、XGBoost 语义矩阵、模型权重和框架临时区属于既有模型专属输入/推理缓冲，仍受下述整体资源门约束。

## 九、资源准入、阶段与失败恢复

### 9.1 资源门

综合既有 XGBoost 与 MLP 生产入口的较严格要求，正式启动前至少满足：

- 单张支持 BF16 的 CUDA GPU，空闲显存不少于 `12,288 MiB`；
- 控制组可用主存不少于 `48 GiB`；
- 项目盘可用不少于 `10 GiB`，占用率低于 `80%`；
- 同身份和同 GPU 计算单元最多一个；
- 不设置墙钟或 GPU 小时硬上限。

已发表神经三模型阶段只用 CPU；XGBoost 和 MLP 阶段串行，不同时保留两种模型及其全量输入缓冲。所有资源数值来自既有真实回填/推理入口的准入合同，只是安全上界，不作为公平效率证据。

### 9.2 原子阶段

1. `validate_shared_identity`：共享数组、实体、分母与配置门。
2. `published_neural_aggregate`：三份现存分数逐模型处理并原子发布聚合。
3. `xgb_rescore_and_aggregate`：同一冻结模型一次逻辑打分，聚合后立即销毁分数和 `semantic168`。
4. `mlp_infer_and_aggregate`：O11 检查点一次逻辑推理，聚合后立即销毁分数和模型缓冲。
5. `common_budget_projection`：投影完整整数 `k`、生成六档及时曲线和支配矩阵。
6. `finalize`：资源/SwanLab 收据、状态、清单和幂等自检。

每个方法级阶段只有在聚合制品、收据、字节数和哈希全部原子发布后才算完成。中断发生在发布前时，从该方法起点重放；禁止保存半程逐流分数换取恢复。恢复时工具/配置/数据/模型/检查点/在线公式任一身份变化即失败，不覆盖旧目录、不换同义运行身份伪装恢复。

缺少三份已发表分数之一、XGBoost 同模型不可加载、MLP O11 检查点不可加载，均记录精确 `unreachable_reason` 并停止完整五方法裁决。资源不足、服务器回收、依赖或身份门失败属于工程失败，不得写成候选科学否决。

## 十、通过、否决与表述门

### 10.1 工程验收

只有同时满足以下条件，N-16 运行才可标记 `complete`：

1. 五方法身份、共享分母和目标访问边界全部通过。
2. 三个已发表方法零推理，XGBoost 恰一次逻辑重打分，MLP 恰一次逻辑推理，训练与调参次数均为零。
3. 每方法完整路径曲线含 `TP=FP=0` 和 `TP=P、FP=B` 边界，FP/TP 单调不减，阈值单调不升，同分组无拆分；同阈值下 `terminal_fp<=path_fp`、`terminal_tp<=path_tp`，已发表最大池化三模型两侧逐位相等。
4. 所有整数 `k` 的索引均指向该方法最后一个 `path_fp<=k` 的真实点；六档公共预算逐项复算通过。
5. 每个及时检出阈值的良性首次告警数严格等于对应 `path_fp`；固定正实体分母、未告警率和曲线终点一致。
6. 路径与终端制品阈值逐位对应但字段、收据和解释分离。
7. 清单只含白名单聚合制品，全部字节数与 SHA-256 复核通过。

任一方法不可达或任一机械断言失败时，状态为 `failed` 或 `incomplete`，不得用其余方法形成“完整五方法非支配”结论。

### 10.2 共同首次告警子向量支配

对任意两方法 A、B，在同一 LSPR24 池中：

- 对全部整数 `k=0..B`，A 的 `path_dr` 与同阈值 `terminal_dr` 均不低于 B；
- 在六个公共预算上，A 的正实体未告警率均不高于 B；
- 对每个预算，将两条及时检出阶梯投影到断点并集后，A 的固定分母及时检出率处处不低于 B；
- 至少一处严格更好；

则称 A 在 N-16 共同首次告警子向量上支配 B。比较使用全精度值，不设容差、不计胜出项、不加权。不同基线的逐轴最好值不能拼成一个不存在的“合成方法”来支配候选。

### 10.3 后续分支

- **O11 非支配**：只可写“全容量 MLP O11 在目标年共同首次告警子向量上保持非支配”。随后先补齐模型/数据适配表与朱论文对位表，把候选登记为新的正式身份，再按冻结合同重跑四格；不得把旧运行事后升级为预注册论文证据。
- **O11 被任一强基线支配**：写“当前 O11 不支持替代”，或转入已有独立正式 S2 候选；不得改预算、改在线公式、回看目标年重选 `p` 或追加模型回避裁决。
- **任一方法不可达或证据不完整**：写“共同五方法包络未闭合”，只报告已完成方法的描述性曲线，不作 O11 存废裁决。

N-16 的非支配只覆盖共同首次告警子向量，不自动覆盖逐流 AP、实体 AP、源年证据、灾备和工程公平性，也不自动完成统一资格 Goal。
