## 核心问题

1. `plain XGBoost` 与 `XGBoost+CPA-ELP` 是否共用同一个 XGBoost 模型与训练预算？
2. 两者各自读取哪些字段、数据视图和历史信息，CPA-ELP 是否改变 XGBoost 训练？
3. 超参数来自同数据集论文逐项复用、项目内源年选择，还是未经明确选择的自行设定？
4. 同数据集论文与本项目在数据集、切分、配置、训练预算四层分别达到什么一致程度？
