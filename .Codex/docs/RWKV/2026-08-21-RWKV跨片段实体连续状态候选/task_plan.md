# RWKV 跨片段实体连续状态候选任务计划

## 目标

在不实现代码、不访问服务器、不读取目标年标签作选择的边界内，设计 LSPR 实体跨 128 片段连续传递 RWKV 状态的待证候选、统一数据接口、资源可行性核验和最小可证伪实验。

## 阶段

- [x] 阶段一：读取路线规则、章节恢复卡、研究规划技能与检索工具合同。
- [x] 阶段二：增量重建文献混合索引，执行跨文档 `scope=all` 混合检索并保存收据。
- [x] 阶段三：读取 LSPR/RWKV 适配性、字段感知计划与工具、第三章算法实验、统一合同及全文证据。
- [x] 阶段四：机械核验序列映射、实体标识、片段顺序、边界与 I23 能力；估算 K0/K1/K2 状态内存。
- [x] 阶段五：形成研究问题卡与实施方案，明确对照、指标、通过门、否决门和资源停止条件。
- [x] 阶段六：执行链接、关键词与差异检查；提交前再核对共享暂存区。

## 关键问题

1. 当前每个 128 片段把 RWKV 状态初始化为零，是否仅构成片段重置基线，而没有利用实体的跨片段因果历史？
2. 现有序列映射是否稳定保留实体标识、实体内片段序号、片段首尾边界及全局因果顺序？
3. 对 K0/K1/K2，逐实体状态的字节数、活跃实体上界和批调度峰值是否能在现有资源合同内运行？
4. `carry` 相对 `reset` 的收益能否由正确实体内顺序解释，而不是容量、输入或未来长度信息造成？
5. 哪些结果足以否决该序列机制，避免把待证候选预先确立为第四章第二机制？

## 冻结边界

- 只使用当前时点之前可观测的同实体历史；禁止跨实体状态、未来实体长度、目标标签和最终实体长度。
- 训练采用截断反向传播，片段边界传状态但切断梯度；推理按实体内时间顺序连续传状态。
- R0/R1/R2 只使用源年封印胜出适配器，最小实验不同时改变输入适配。
- 对照至少包括 `reset`、`carry`、实体内片段时序打乱、同容量无状态控制。
- 资源不可行时否决容量放大，不以拍脑袋截断实体历史规避资源约束。
- 本任务只产出研究设计，所有有效性结论保持“实验待证”。
