# RWKV 跨片段实体连续状态候选证据笔记

## 任务边界

- 研究对象：LSPR 实体跨 128 片段的 RWKV 连续状态候选。
- 当前基线：每个片段独立以零状态开始，记为 `reset`。
- 候选：同一实体的相邻片段按时间顺序传递状态，训练边界切断梯度，推理连续传递，记为 `carry`。
- 结论边界：本轮仅形成可运行、可证伪的候选设计，不宣称机制有效，不预设为第四章第二机制。

## 路线事实

- RWKV 路线是论文主线，但原生 RWKV-7 只作机制来源或必要对照，不预设唯一骨干。
- LSPR23 与 LSPR24 属同一数据集体系；第三、四章共享冻结字段、身份与评价合同。
- 第三章 RWKV-7 当前已完成 R0/R1/R2 输入适配并封印 R2，仍处于源年容量选择，尚无真实效果结论。
- 第四章当前尚不存在可命名的双机制算法；任何新候选都必须从病灶、最小对照和否决门开始。
