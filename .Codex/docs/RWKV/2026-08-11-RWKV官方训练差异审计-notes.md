# RWKV 官方训练差异与 C12 适用性审计笔记

## 证据规则

- 本地事实源：固定提交 `952102498e9ed367ea0a59ee64106916d474d30f` 的 BlinkDL/RWKV-LM 快照。
- 联网事实源：BlinkDL/RWKV-LM 官方 GitHub 仓库及其中官方训练说明、配置和脚本。
- 当前实现事实源：本仓库 C12 阶段 A 的 K-RWKV7 代码、冻结配置和运行合同。

## 已核验证据

- 远程主分支：`git ls-remote https://github.com/BlinkDL/RWKV-LM.git refs/heads/main` 在 2026-08-11 返回 `952102498e9ed367ea0a59ee64106916d474d30f`，与本地固定快照一致。
- 本地快照：`thesis/experiments/llm_probe/artifacts/rwkv-baseline-deps/rwkv-baseline-deps-prefetch-20260806t030118z-attempt3/sources/RWKV-LM-952102498e9ed367ea0a59ee64106916d474d30f.tar.gz`。
- 官方声明 RWKV-7 是完整模型，需要按参数区分初始化、权重衰减和学习率；不存在可脱离训练配方的简单“RWKV-7 层”。
- 官方初始化：各层时间混合、`w0/a0/v0/k_k/k_a/r_k`、低秩分支均有特定层依赖初值；`att.output` 与 `ffn.value` 等置零；`ln_x.weight` 按层缩放；嵌入小均匀初始化，输出头正交初始化。
- 优化器：`att.w0` 是无衰减 `2x` 学习率组；二维及以上 `.weight` 是衰减 `1x` 组；其余为无衰减 `1x` 组。官方所谓层级学习率在该提交的实际训练路径中是按参数类型的 `my_lr_scale`，不是按深度递减。
- 调度：正式路径使用按已处理令牌计数的余弦衰减，从 `lr_init` 到 `lr_final`；热身期从基准学习率的 1% 线性增长。
- 数据：`binidx` 每个样本读取连续 `ctx_len+1` 令牌，通过 `magic_prime` 三次排列选择连续片段起点；片段内顺序不变，目标是下一令牌。`train_stage` 是 Pile 初始权重生成与断点续训调度，不是通用分类阶段。
- 状态：`train_temp` 训练核在每个输入样本内从零状态开始，无外部初始状态或返回状态接口；不跨语料片段传递状态。
- 分块：正式核要求 `T` 不超过 `ctx_len`，特定融合核还要求时间长度满足内部分块约束；简化演示明示 `T % 16 == 0`。这是实现约束，不等于跨块状态语义。
- 梯度检查点：官方对整个块使用 DeepSpeed 激活检查点，官方脚本也明示其为以速度换显存，不改变模型语义。
- 精度：正式示例使用 BF16；递归状态和核内累加保持 FP32，官方警告 FP16 可能溢出。
- 头与完整块：正式训练脚本设置每头 64 维；官方简化小任务演示允许 16 维，但明示标注语言模型使用 64。完整块包括 PreLN、令牌移位、TimeMix、跨层 `v_first`、ChannelMix 和残差。
- 官方状态核先执行当前位置的衰减、移除和写入，再用更新后状态读出；状态读出先做 GroupNorm（`eps=64e-5`），再加当前令牌奖励项。

## C12 核对照

- C12 共同接收器是两层六头因果 Transformer；接收表示训练后冻结落盘。K-RWKV7 仅是接在 `[B,T,192]` 冻结表示后的一层 `6×32×32` 矩阵状态核，不是官方完整 RWKV-7。
- C12 所有变体精确匹配为 333,569 个可训练参数，共享 AdamW、`3e-4`、全参数 `1e-2` 权重衰减、4 轮按轮余弦调度和梯度剪裁 1.0。
- C12 状态显式 FP32，外层使用 BF16 自动混合精度，这一数值边界与官方原则一致。
- C12 每条非重叠组序列重置零状态，序列内时序不变，只在轮次间打乱序列顺序。这与当前数据合同和官方片段级重置语义一致。
- C12 为严格“当前位置先预测，再更新状态”，而官方语言模型是“用当前令牌更新状态，再预测下一令牌”。这是任务语义改写，不是官方等价实现。
- C12 使用 `LayerNorm(32)` 对每头读出加奖励项后归一化；官方对融合状态读出使用按头 GroupNorm，然后加奖励项。
- C12 没有专用 `w0/w1/w2`、令牌移位、`v_first`、ChannelMix、专用初始化或官方参数分组。运行收据已明确 `official_result=false`。

## 裁决

- 无需中止当前运行：若结果只解释为“RWKV-7 风格矩阵状态更新核的任务适配参考”，现有实验合同有效。
- 身份阻断：当前结果不能称为“官方 RWKV-7”、“完整 RWKV-7”或“普通 RWKV-7 模型基线”。主代理已在报告完成前被即时通知。
- 当前轮次不应中途仅为 K-RWKV7 引入官方初始化、参数分组或调度；这会同时改变训练预算与机制，破坏公平矩阵。
