# GRANDE 可微树骨干 Q0 实施报告

## 结论

已按修正计划 `f820ad7` 实现 GRANDE 协议 A 源年 C00 Q0。实现只新增独立工具、配置、启动器、本报告和 `vendor/grande/` 固定官方源码快照。未修改共享依赖、现有模型或实验代码；未访问服务器，未启动实验，效果为**实验待证**。

实现代理：`literature_hybrid_search_eval_sol_high`，模型 `gpt-5.6-sol`，`effort=high`。

## 变更范围

1. `tools/ch3_grande_protocol_a_source_q0.py`
   - 复用协议 A 固定 `208,598/22,444` 训练/验证序列和最早最大周期选择。
   - 实现 `prepare/resource-calibrate/train-unit/aggregate/publish-aggregate` 五阶段。
   - 实现 G-A（深度 4、512 树）与 G-B（深度 5、1024 树），只用 PyTorch 直接 logits 训练。
   - 四个核心参数组使用固定 Adam 学习率：实例权重 `0.001`、分裂索引 `0.01`、分裂值 `0.05`、叶值 `0.05`。
   - R0 以首批 64 条真实训练序列执行正式前向、反向和优化步，核验全部核心组的有限非零梯度与参数改变。
   - 同一首批用独立诊断图验证 logit 因果前缀和实体幂平均目标能向四核心组回传，不更新 C00 权重。
   - R1 以首个完整 1000 步周期的真实墙钟与峰值投影累计 4.5 GPU 小时；恢复不重置用时。
   - 资源、梯度或科学门失败时生成 NODE 回退收据，但不运行 NODE。
   - 报告逐流 AP/ROC-AUC、实体 max AP、六档 DR、完整可达预算曲线、参数组、墙钟、GPU 小时、峰值显存/主存和吞吐。
2. `configs/ch3-grande-c00-protocol-a-source-q0-seed42-v1.json`
   - 冻结两结构、官方后论文 PyTorch 身份、六源年数组、协议 A 预算、梯度门、4.5 GPU 小时上限和零目标年边界。
3. `scripts/remote_launchers/run_ch3_grande_c00_protocol_a_source_q0_seed42_v1.sh`
   - 提供唯一首次启动和同运行 `--resume`，串行执行 G-A R0/R1、G-A 完整周期、G-B R1 资源门、条件 G-B、聚合和发布。
   - 启动前只枚举六个源年数组，目标年字面不可达。
4. `vendor/grande/`
   - 固定上游提交 `07f7278b30ab9ebbbdc544e5f9a91f1b5df7fecb`。
   - 保留未修改的 `upstream_GRANDE.py`、`upstream_setup.py`、MIT `LICENSE` 和逐文件 manifest。
   - `core.py` 是带来源和删减说明的最小 PyTorch 核心提取版，不引入 AutoGluon、pandas 或类别编码数据路径。
5. `.Codex/docs/RWKV/2026-08-20-GRANDE可微树骨干-Q0实施报告.md`
   - 本报告。

- 官方原始实现快照是完整证据；生产路径仅导入最小核心，避免本 Q0 禁止的可选依赖与预处理。
