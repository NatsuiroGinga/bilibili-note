## 分析问题

1. `manifest`、状态、收据、NPZ 和 JSON 是否在文件清单、大小、哈希、运行身份和指标上互相一致？
2. 六档终端预算点的 `nominal_target_fpr`、`actual_reachable_fpr`、DR、FP、负实体分母、阈值和并列组规模是什么？
3. 名义 `4%` 的终端实际可达 FPR 与首次告警实际 FPR 是否被严格区分？
4. 完整并列组预算曲线、首次告警未告警率与曝光分位、资源收据是否完整？
5. 回填是否精确复现旧标量；哪些表述可用，哪些更强表述必须禁用？
