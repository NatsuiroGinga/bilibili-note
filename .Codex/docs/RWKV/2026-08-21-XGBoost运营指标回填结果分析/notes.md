# XGBoost＋CPA-ELP 运营指标回填分析笔记

## 输入与规范

- 唯一原始输入：`thesis/experiments/llm_probe/runs/diagnostics/ch3-xgb-cpa-elp-c11-operational-backfill-v1-rerun2`。
- 规范依据：第三章可微骨干与机制多指标统一合同、第三章机制快速验证分级合同。
- 旧标量比对引用：统一指标总表中的 LSPR24 旧登记行；该表只作既有标量参考，不替代本地回收根的原始制品。
- 证据身份：LSPR24 已被历史实验访问；本次是冻结 XGBoost＋CPA-ELP C11 的零训练描述性回填，不是独立最终测试，不用于选择或调参。

## 制品盘点

- 共 13 个文件：11 个 JSON、2 个 NPZ，总计 292,067 字节。
- `manifest.json` 登记除自身外的 12 个文件；逐项实测字节数和 SHA-256 均匹配。
- `stage-status.json` 为 `stage=complete`；`manifest.complete=true`；资源收据 `finalized=true`；SwanLab 收据 `completed=true`。
- 运行冻结为 `semantic168`、800 棵树、`p=1.0`；模型 SHA-256 在配置、输入核验、运营收据和指标 JSON 中一致。
- `target_retrained=false`、`target_score_calls=1`、`target_scores_persisted=false`；逐流、逐实体和逐实体首次告警明细均未持久化。

## 元数据边界

1. `input-validation-receipt.json` 没有本次 `run_id` 字段；其哈希由 manifest 覆盖，但不能声称“所有 JSON 都独立声明并一致指向本次运行”。其他 10 个 JSON 均声明同一本次运行身份。
2. `manifest.config_sha256=852e98e1...c944` 与物理 `config.json` 的 SHA-256 `893f217a...da2` 不同。前者同时出现在输入核验收据，后者由 manifest 文件项登记并与实测一致。制品未定义二者的规范化映射，因此区分为“声明配置身份哈希”和“物理文件哈希”，不判为损坏，也不把二者等同。
3. 配置中的目标逐流正例率为截断值 `0.0257073138`，指标 JSON 为 `0.02570731439146075`；计数和样本规模一致，该差异按精度表示边界处理。

## 完整告警预算曲线

- 曲线文件：`complete-alert-budget-curves.npz`，SHA-256 `d0890546...7998`。
- 46,363 个负实体，14,519 个真实可达点，含零 FP 边界和全负实体边界。
- 14,518 个非零负并列组；其中 67 个并列组包含多个负实体，最大并列组为 31,769 个负实体，位于最终全覆盖点。
- FP 累计、实际 FPR 和 DR 单调不减；阈值严格递减；每点 `realized_fpr=FP/46363`；相邻 FP 增量与完整负并列组规模逐点相等；无插值、无拆分并列组。
- 六档读数均是各名义预算内最后一个真实可达点，并达到该预算内最大 DR。部分档位存在同 DR 平台，因此该确定性读法不是“同 DR 下最少 FP”读法。
- 名义 4% 主点：FP=1,854，实际 FPR=`0.03998878415978258`，DR=`0.8896276595744681`，阈值=`9.506818514637416e-07`，该点负并列组规模为 1。
- 紧邻下一可达点：FP=1,855，实际 FPR=`0.04001035308327761`，DR 不变，阈值=`9.498813255959249e-07`，负并列组规模为 1。
- 同一 4% 档 DR 最早在 FP=1,808、实际 FPR=`0.03899661367901128` 时已达到；当前冻结读法继续取预算内最后点，因此增加 46 个 FP 而 DR 不变。这不是合同错误，但说明单点不能替代完整阶梯曲线。

## 旧标量复现

- 精确复现：逐流 AP `0.28325771805921907`、实体 AP `0.5650784187138617`，以及 0.1%、0.5%、2%、4%、8% 五档 DR。
- 未复现：旧 1% DR 为 `0.5319148936170213=400/752`；回填严格预算读数为 `0.5305851063829787=399/752`。精确差值为 `-1 TP`、`-1/752 DR`，十进制约为 `-0.001329787234042553`，即约 `-0.132979` 个百分点。
- 完整曲线显示 400/752 最早出现在 FP=464、实际 FPR=`0.01000798050169316`，已超过 1% 预算；因此旧 1% DR 不能继续写作 `DR@actual FPR<=1%`。这支持“旧名义端点发生超预算取点”的解释，但旧结果未在本输入中提供阈值和 FP 收据，根因仍是有曲线支持的推论，不是完整原始复现。

## 当前裁决边界

- 可用：完整曲线与六档真实可达终端读数；首次告警曝光曲线、未告警率和独立实际 FPR；本次零训练回填的资源观察；旧 1% 端点的语义纠正。
- 禁用：独立最终测试、泛化支持、显著性、稳定性、多种子一致性、秒级首次告警时延、首次告警 FPR 等于名义预算、完整帕累托进入或推进、效率优势。
- C11 只有一个系统单元且没有本次同池比较对象；本分析补齐基线运营证据，不形成模型优胜或机制因果结论。
