# XGBoost＋CPA-ELP 运营指标回填统计附录

## 统计身份

本次分析对象是一次冻结模型、固定数据、固定排序和固定阈值语义下的确定性零训练后处理。统计单位包括：

- 20,227,356 条目标年流。
- 47,115 个目标年实体。
- 752 个恶意实体。
- 46,363 个良性实体。

没有重复种子、重复训练、折、受试者或独立年度。因此不进行均值±标准差、置信区间、显著性检验、多重比较校正或随机效应量估计。终端与首次告警之间的差异是同一冻结分数下两个决策定义的确定性计数差，不是随机试验效应量。

## 计算定义

### 终端预算曲线

对完整负并列组按阈值从高到低累计：

```text
actual_reachable_fpr = cumulative_false_positive_entities / 46363
detection_rate = cumulative_true_positive_entities / 752
```

六档端点采用冻结规则：在 `actual_reachable_fpr <= nominal_target_fpr` 的真实可达点中取预算内最后点；该点达到预算内最大 DR。无插值，不拆分并列组。

当前 JSON/NPZ 使用 `nominal_fpr`、`realized_fpr` 和 `realized_first_alert_fpr`。本附录分别按合同语义解释为 `nominal_target_fpr`、`actual_reachable_fpr` 和首次告警独立实际 FPR，不把三者混用。

### 首次告警

每个实体按冻结流索引升序形成 1 基曝光序列。在线 C11 分数为 `p=1` 的前缀算术平均；首次满足 `score>=同档终端阈值` 时告警。

```text
realized_first_alert_fpr = alerted_benign_entities / 46363
unalerted_rate = never_alerted_positive_entities / 752
timely_detection_rate(k) = positives_alerted_by_exposure_k / 752
```

未告警实体保留在分母中。曝光分位数只对已告警恶意实体计算，不能替代未告警率。

## 旧标量差异

8 个旧登记标量中，7 个精确复现。唯一差异为：

```text
旧 DR@1% = 400 / 752 = 0.5319148936170213
新 DR@1% = 399 / 752 = 0.5305851063829787
精确计数差   = -1 TP
精确 DR 差   = -1 / 752
十进制近似   ≈ -0.001329787234042553
百分点近似   ≈ -0.1329787234042553
```

完整曲线中 400 个 TP 的首个点为 FP=464：

```text
464 / 46363 = 0.01000798050169316 > 0.01
```

因此旧值不能解释为“实际 FPR 不超过 1%”的 DR。

## 禁止的统计解释

- 不报告显著性或“统计显著”。
- 不报告稳定性、方差或多种子一致性。
- 不把 47,115 个实体当作独立重复运行来计算模型性能置信区间。
- 不把终端与首次告警的同一实体计数差当作随机处理效应。
- 不把条件曝光分位数当作全部恶意实体的无条件时延分布。
- 不用资源争用观测形成效率排名。
- 首次告警实际 FPR 高于终端 FPR 是在线前缀事件定义产生的精确描述性差异，不得归因于终端完整并列组曲线错误。
