# XGBoost＋CPA-ELP 运营指标回填严格分析报告

## 结论

本次零训练回填的完整告警预算曲线与首次告警聚合制品可以用于补齐 XGBoost＋CPA-ELP C11 在 LSPR24 已访问目标年描述性评价表中的主要运营字段。制品的文件哈希、完整并列组累计、六档端点、首次告警曲线和资源收据在可核字段上互相一致。

承重结论有四项：

1. 名义 4% 档的终端实际可达 FPR 是 **3.998878%**，DR 是 **88.962766%**；紧邻下一真实可达点是 **4.001035%**，DR 不变。不得写成精确 4%。
2. 同一终端阈值用于在线前缀首次告警时，实际 FPR 是 **4.941440%**，未告警恶意实体率是 **8.909574%**。首次告警 FPR 不等于终端 FPR，更不等于名义 4%。
3. 旧登记值中，逐流 AP、实体 AP 和五个六档 DR 精确复现；旧 1% DR `400/752` 未复现。严格预算内读数为 `399/752`，而 `400/752` 最早只在实际 FPR `1.000798%` 时可达。
4. 结果身份最高只能是“LSPR24 已访问目标年描述性运营指标回填”。它不是独立最终测试，不证明跨年度泛化、稳定性、显著性、模型优势或完整帕累托地位。

- 运行：`ch3-xgb-cpa-elp-c11-operational-backfill-v1-rerun2`。
- 模型：冻结 `semantic168` XGBoost，800 棵树，模型 SHA-256 `1805e15d96ac4ebb57df910640a4c5e1af58f692659db2eb80b724851efe42e9`。

- 操作：一次目标评分，无重训，无折外评价，无 raw83 评价，不持久化逐流、逐实体或逐实体首次告警明细。

## 制品有效性

### 完整性

- 本地回收根有 13 个文件；manifest 登记除自身外的 12 个文件。
- 12 个登记文件的字节数与 SHA-256 逐项实测一致。
- `manifest.complete=true`、`stage=complete`、资源收据已封口、SwanLab 聚合收据已完成。
- 两个 NPZ 的成员字段与对应收据完全一致。

### 结构一致性

- 完整预算曲线包含 14,519 个真实可达点，覆盖从 0 FP 到全部 46,363 个负实体。
- 制品字段 `nominal_fpr` 与 `realized_fpr` 分别映射到合同字段 `nominal_target_fpr` 与 `actual_reachable_fpr`；首次告警的独立实际 FPR 使用 `realized_first_alert_fpr`。
- 阈值严格递减，FP、实际 FPR 和 DR 单调不减。
- 每点实际 FPR 等于 `FP/46363`；相邻 FP 增量等于该点完整负并列组规模。
- 六档端点均从同一曲线提取，无插值，无拆分并列组；六个端点的负并列组规模均为 1。
- 首次告警六档累计曲线的曝光序号严格递增，按时检出率单调不减；每档终点与已告警恶意实体数精确一致。

### 元数据限制

- `input-validation-receipt.json` 没有本次运行的 `run_id` 字段。其物理文件哈希由 manifest 覆盖，但不能据此声称所有 JSON 都独立声明相同运行身份。
- 声明配置身份哈希 `852e98e1...c944` 与物理 `config.json` 哈希 `893f217a...da2` 不同。制品没有说明规范化映射；本报告分别保留二者，不判损坏，也不将其等同。

以上两项是收据自描述完整性限制，不改变已直接核验的数组与端点数值。

## 首次告警运营指标

首次告警以 1 基实体内曝光序号为横轴。目标输入没有完整流可用时刻，因此“曝光序号”不得改写成秒级时延。

在线前缀首次跨阈值会捕获一部分终端分数回落到阈值下方的恶意实体，同时也累积更多良性实体告警。4% 档相对终端增加 16 个真阳和 437 个假阳；这是一项精确描述性差异，不是方法效果或因果改善。

六档首次告警实际 FPR 均高于对应名义预算和终端实际 FPR。原因是“任一前缀曾经跨阈值”的告警事件与“终端聚合分数仍在阈值上”的事件不同；这不是终端完整并列组曲线的计算错误。名义 4% 档的首次告警 FPR 比名义预算高约 0.941440 个百分点，比终端实际 FPR 高约 0.942562 个百分点。

六档已告警恶意实体的条件曝光中位数均为 1，但该分位数只在已告警子集上计算。以 4% 档为例，685 个已告警恶意实体的最小值/25%/中位数/75%/90%/95%/99%/最大值为 `1/1/1/1/2/4/31/204`，同时仍有 67 个恶意实体未告警。禁止只写“中位数为 1”而省略未告警率。

## 可补齐与仍缺失

### 可补齐

- 六档名义预算、实际可达 FPR、FP、DR、阈值和完整并列组规模。
- 全部真实可达负并列组预算曲线。
- 首次告警曝光序号轴、定义、六档独立实际 FPR、未告警率和按时检出累计曲线。
- 本次零训练回填的资源观察。

### 仍缺失或不可升级

- 真实秒级首次告警时延。
- 最大池化实体 AP 的独立读数。
- 无资源争用的公平效率证据。
- 同一评价池内其他模型的完整运营曲线，因而不能仅靠本次结果更新完整性能帕累托裁决。
- 独立未见目标年度，因而不能升级为最终泛化证据。

## 最终裁定

**运营回填制品可用，但证据身份受限。** 可以登记为 XGBoost＋CPA-ELP C11 的 LSPR24 已访问目标年描述性运营指标补全；必须纠正旧 1% 端点，必须把 4% 终端实际 FPR 与 4.941440% 的首次告警实际 FPR 分开，且不得形成独立最终测试、秒级时延、显著性、效率优势或帕累托主张。
