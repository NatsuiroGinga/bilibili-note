# XGBoost 与相近树模型结构改造直接近邻证据矩阵

- **日期**：2026-08-19
- **代理映射**：`xgboost_tree_adaptation_literature_sol_max → gpt-5.6-sol → effort=max`
- **状态**：累计 19 篇全文已核验；T1／T2 最高均为 `D2`，尚无 `D3`，正在完成最新 `D2` 后的停止条件查询。
- **用途**：区分树模型结构改造、强基线、基础部件和 DTEP／PBC 原创边界；不用于宣称候选有效。

## 一、判定对象

| 对象 | 完整关系 |
| --- | --- |
| T1：固定二进多尺度实体特征＋XGBoost | 同一实体的严格历史前缀 → 固定二进或等价多分辨率窗口 → 每尺度统计 → 作为 XGBoost 输入 → 尺度合同在源域冻结 |
| T2：树分数＋目标先导段预算／先验校正与回退 | 源域树模型冻结 → 只读目标时间先导段 → 预算或类别先验校正 → 条件失配时回退 → 参数冻结 → 不相交后段评价 |

## 二、证据等级与同构等级

| 标签 | 含义 |
| --- | --- |

## 六、阶段性原创边界裁决

### 6.1 T1／DTEP

- **当前最高为 D2，无 D3。** 不能再把“实体无前视多窗统计＋XGBoost”“固定幂次多尺度实体统计＋冻结 XGBoost”“长度为 2 的幂的区间＋森林”“网络实体在线多尺度统计”或“监督式选区间”单独表述为原创。
- **可能保留的组合边界**：同一网络实体的逐事件严格历史前缀；固定二进尺度的可审计特征合同；尺度或聚合规则只在源实体折外预测上选择并冻结；同一 XGBoost 骨干下跨时间／跨实体评价；长实体和冷启动的预注册回退。
- **证据限度**：这些关系尚未在一篇全文中全部同现，只能说明直接同构未命中，不能据此证明全球首创或实验有效。

### 6.2 T2／PBC

- **当前最高为 D2，无 D3。** Saerens 等已经占用“冻结分类器＋无标签新数据先验估计＋后验修正＋显著性诊断＋不修正回退”；TAP-GPPS 已占用“校准树＋无标签目标先验＋目标约束阈值”；Hung 已占用“网络树分数＋固定假阳率验证阈值＋隔离测试”。因此无标签目标先验校正、约束阈值或固定假阳率树后处理均不能单独表述为原创。
- **可能保留的组合边界**：目标域只允许固定长度的因果先导段；面向实体告警量或假阳性预算而非仅类别比例；把先验失配诊断、预算校准和预注册回退放在同一决策合同；随后冻结所有参数并在时间不相交后段一次评价。
- **证据限度**：若先导段没有标签，只能估计先验或分数分布，不能声称真实假阳率被校准；若使用目标良性标签，则必须单列标签预算并避免与无标签方法混比。
