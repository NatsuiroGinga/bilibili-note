## 一、判定对象

| 对象 | 完整关系 |
| --- | --- |
| T1：固定二进多尺度实体特征＋XGBoost | 同一实体的严格历史前缀 → 固定二进或等价多分辨率窗口 → 每尺度统计 → 作为 XGBoost 输入 → 尺度合同在源域冻结 |
| T2：树分数＋目标先导段预算／先验校正与回退 | 源域树模型冻结 → 只读目标时间先导段 → 预算或类别先验校正 → 条件失配时回退 → 参数冻结 → 不相交后段评价 |

## 二、证据等级与同构等级

| 标签 | 含义 |
| --- | --- |

| E2 | 可核验预印本全文，版本与页码完整 |
