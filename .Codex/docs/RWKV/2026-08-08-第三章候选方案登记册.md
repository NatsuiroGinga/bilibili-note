## 一、状态定义

| 状态 | 最小含义 |
| --- | --- |
| `实现中／实验待证` | 合同已冻结，尚无本轮有效结果 |
| `未筛选` | 尚无针对性合格实验 |
| `弱证据有利／不利` | 只有代理、原子或受限实验，不足以正式支持或证伪 |
| `实验无效／中断` | 结果受泄漏、数据、协议或工程失败影响，不得用于存废 |
| `筛选不晋级` | 只停止当前配置或当前 Q0，不否决模型族或完整研究方向 |
| `已支持／已证伪` | 只有满足冻结正式合同的实验才能使用；当前没有候选处于这两种状态 |
