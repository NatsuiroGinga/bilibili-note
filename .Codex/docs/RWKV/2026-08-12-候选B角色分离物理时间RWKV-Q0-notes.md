# 候选 B 角色分离物理时间 RWKV Q0 记录

## 已确认接口

- 现有 Q0 缓存包含每流精确 `delta_t_us:int64[N]`、序列身份、位置、有效长度和四角色数组，不需要重新物化。
- 阶段 A v2 冻结表示可复用为 `phi:float16[N,192]`，不需要重新训练接收器。
- 冻结 `phi` 的接收器输入已经包含 `log1p(delta_t_us)`，因此离散状态对照仍能看到通用时间表征；实验检验的是“精确时间作为状态控制量”的额外价值。
- 候选 B 状态批次必须同时读取 `phi`、精确 `delta_t_us` 和有效位，不能从 `phi` 反推时间。
- Q0 总规模为 `928188` 条流、`16198` 个序列；四角色行数为 `142069/262136/262144/261839`。
