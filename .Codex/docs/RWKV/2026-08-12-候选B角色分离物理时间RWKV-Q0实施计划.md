# 候选 B 角色分离物理时间 RWKV Q0 实施计划

> **执行代理要求：** 使用 `superpowers:subagent-driven-development` 和 `daily-coding`，严格按本计划实现。项目规则禁止人工夹具、单元测试和集成测试；只执行一次集中编译/入口检查，随后立即运行冻结开发区真实实验。

**目标：** 在冻结的 LSPR23→LSPR24 Q0 数据、成员、字段、表示、训练顺序和种子 42 下，验证“真实时间只控制旧状态保留，内容只控制定向移除与写入”是否比离散状态、普通时间特征和既有跨度控制律产生独立跨年度检测信号。

**架构：** 复用现有冻结内容表示 `phi:[N,192]` 和 Q0 缓存中的精确 `delta_t_us:[N]`，新增独立的候选 B 状态核、训练评价入口、冻结配置和幂等并行启动器。五个变体共享同一分类结构、参数量、序列清单、训练顺序、批量、轮数、优化器和标签权限，只改变真实时间在状态转移中的作用。

**技术栈：** Python、PyTorch、NumPy、scikit-learn、SwanLab、Bash、C56 RTX 5090。

## 全局约束

- 本轮只筛选候选 B 的缩减版 M1，不实现或评价频谱支路，不得声称验证了完整“连续时间＋频谱”方案。
- 固定 `screening_only=true`、`formal_paper_evidence=false`、`final_accessed=false`。
- 数据只来自现有 Q0 Python 缓存和阶段 A v2 冻结表示，不重新物化、不重新训练接收器、不访问最终 20%。
- 冻结 `phi` 已经包含接收器学到的通用时间特征，因此离散状态是“时间作为普通表征特征”的强对照；精确 `delta_t_us` 只能作为五变体约定的显式时间输入，不能混入身份字段。
- 只使用 `sample_id/sequence_id/position/valid_length` 做关联、排序和收据，不作为模型输入；目标开发标签必须在五组原始概率和时间诊断概率全部封存后连接。
- 五变体共享种子 `42`、批量 `16`、4 轮、每轮 `183` 步、总计 `732` 步、学习率、调度器、源验证选择次数和同一个 `training-sequence-order.npy`。
- 五个原始模型先构建，以最大可训练参数量为共同目标，其余模型通过主动参数补偿精确补齐；参数补偿必须参与优化但不得读取输入。
- 时间单位、`log1p` 变换、裁剪上限和源时间分面边界只从 LSPR23 源训练区拟合并写入收据，不得使用 LSPR24 标签或目标统计回选。
- 最大并发固定为 `3`；独立运行目录、锁、日志、SwanLab 运行和状态收据。
- SwanLab 固定为 `mortiswang/malicious-traffic-llm`，只上传聚合指标与协议元数据。

## 五个共同预算变体

| 短键 | 展示名称 | 精确时间作用 |
|---|---|---|
| `B-DISCRETE-RWKV` | 离散步长 RWKV 状态对照 | 精确 `delta_t_us` 不进入状态核；冻结 `phi` 仍保留普通时间表征 |
| `B-DELTA-FEATURE` | 显式流间隔普通特征对照 | 源域归一化 `log1p(delta_t_us)` 只作为内容投影附加特征，不直接控制保留率 |
| `B-DYG-SPAN` | DyG-Mamba 式单调跨度控制对照 | 精确间隔经单调有界函数控制整体旧状态保留；不做物理时间与内容角色分离 |
| `B-LINEAR-CLIPPED` | 线性裁剪时间衰减对照 | 使用无内容依赖的线性裁剪保留率，区分指数半群与简单启发式 |
| `B-ROLE-SEPARATED` | 角色分离物理时间 RWKV | `delta_t_us` 只产生指数半群保留上界；内容只产生定向移除、写入方向和写入强度 |
