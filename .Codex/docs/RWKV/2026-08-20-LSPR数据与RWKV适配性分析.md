# LSPR 数据与 RWKV 适配性分析

- **日期**：2026-08-20
- **状态**：实验待证
- **边界**：本文记录 LSPR 数据结构、当前 RWKV-7 实现和后续可证伪实验的关系；不报告当前运行的效果，不把论文近邻或设计论证当成本课题实验结果。

## 一、结论

> LSPR 数据对 RWKV 是有条件适合，但并不天然适合。RWKV 值得实验，尚不能预设为最佳骨干。

这个结论不是骨干排名，也不构成对 RWKV-7、任何容量档或字段适配器的支持或否决。当前唯一合理状态是：数据存在可由顺序状态利用的信号，同时存在会使这种状态建模无效、浪费或被错误实现掩盖的结构性风险。

## 二、数据为何值得检验

1. **实体内有时间序。** 流以无向 2-IP 实体归组，并按流起始时间升序排序；每个 RWKV 时间步对应一条流，而不是一个字段。当前跨年度合同使用最长 128 流的非重叠片段，因而已提供因果顺序输入。[共同字段审计与跨年度数据合同](2026-08-11-LSPR23-LSPR24共同字段审计与跨年度数据合同.md)；[第三章 3.6 实验设置](../../../thesis/chapters/第三章-CPA-ELP/3.6-实验评估.md)
2. **规模足以覆盖不同实体轨迹。** LSPR23 含 `16,353,511` 条流和 `150,680` 个实体，适合把短实体与长实体分开检验；长实体承载的状态变化不能由单条流的静态表示完全替代。[第三章 3.6 实验设置](../../../thesis/chapters/第三章-CPA-ELP/3.6-实验评估.md)
3. **早期观测已有可用信号。** 既有 CPA-ELP 的受限观测诊断显示，实体前 50 条流只占全量流的 `2.27%`，其实体 AP 已达到同一诊断内全量值的 `95%` 以上。这证明“早期实体前缀”值得作为状态模型的可观测对象，但不证明 RWKV 会优于任何无状态骨干。[第三章 3.6.8 受限观测诊断](../../../thesis/chapters/第三章-CPA-ELP/3.6-实验评估.md)

## 三、数据为何并不天然适合

1. **绝大多数实体极短。** 实体流数中位数为 `2`；长度 128 的批张量会含大量补零位。若多数有效样本不需要跨流记忆，递归状态可能只增加资源成本。[第三章 3.6.6 序列长度敏感性](../../../thesis/chapters/第三章-CPA-ELP/3.6-实验评估.md)
2. **头部实体高度重尾。** 前 `0.1%` 实体占 `76.40%` 流和 `94.43%` 恶意流。任何总体提升都可能主要由极少数长实体贡献，必须按实体长度分桶报告，不能用单一总体 AP 代表所有实体。[第三章 3.6.8 受限观测诊断](../../../thesis/chapters/第三章-CPA-ELP/3.6-实验评估.md)
3. **正实体支持有限且输入是异质表格。** LSPR23 仅有 `239` 个正实体；输入是冻结的 83 个异质表格字段，不是原生语言或离散 token 序列。字段语义、尺度和缺失模式是否适合 RWKV 的输入投影必须单独验证。[路线总控](RWKV路线总控.md)；[可微神经骨干统一合同](2026-08-20-可微神经骨干替代XGBoost目标合同.md)
4. **存在跨年度漂移。** LSPR23 训练与 LSPR24 描述性评价的先验、实体规模和字段分布并不相同；目标年度已被历史访问，不能用它选择 RWKV 表示、容量或机制。[第三章 3.2 问题定义](../../../thesis/chapters/第三章-CPA-ELP/3.2-问题定义.md)；[可微神经骨干统一合同](2026-08-20-可微神经骨干替代XGBoost目标合同.md)

## 四、当前实现的直接限制

当前 RWKV-7 专用配置的 `sequence_length=128`。专用工具的 `rwkv7_op` 在每次片段前向中执行 `state=torch.zeros(...)`，因此状态只在一个 128 流片段内递归，不会跨片段延续到同一长实体的后续片段。故当前实现检验的是“片段内有序状态”而不是“完整长实体的连续状态”。[冻结配置](../../../thesis/experiments/llm_probe/configs/ch3-rwkv7-field-aware-protocol-a-2x2-seed42-v1.json)；[RWKV-7 专用工具](../../../thesis/experiments/llm_probe/tools/ch3_rwkv7_field_aware_protocol_a_2x2.py)；[字段感知实施计划](2026-08-20-RWKV7字段感知输入与协议A四格实施计划.md)

R0/R1/R2 只比较逐流 83 字段进入 RWKV 的输入适配形式，K0/K1/K2 只比较容量与层数。即使这些单元全部完成，也只能回答输入或容量是否合格，不能完成“LSPR 是否适合 RWKV 状态建模”的裁决；后者还需要直接干预顺序和状态连续性，并排除额外容量或计算量解释。[字段感知实施报告](2026-08-20-RWKV7字段感知输入与协议A四格实施报告.md)；[可微神经骨干统一合同](2026-08-20-可微神经骨干替代XGBoost目标合同.md)

## 五、候选改进与待检验假设

候选不再固定为“表示层/决策层”二分。它们仅来自两条数据错配假设，最终可能有 `0`、`1` 或 `2` 个成立：

| 候选 | 数据错配假设 | 最小干预 |
| --- | --- | --- |
| A：字段语义适配 | 83 个异质字段的语义、分组和尺度不能由普通线性投影充分保留 | 保持同一 RWKV 核心和容量，比较字段语义适配与无字段语义的同参投影。 |
| B：跨 128 片段的实体连续状态与截断反向传播 | 长实体中的有效证据跨越当前片段边界，片段重置丢失了可用历史 | 在同一实体内比较 reset 与 carry；carry 路径使用明确的截断反向传播边界，状态不得跨实体或跨因果切分泄漏。 |

两项均须由 LSPR23 开发区的真实对照决定。A 不成立时不保留字段语义模块；B 不成立时不把跨片段状态写成 RWKV 的适配优势；二者均不成立时保留无状态或片段状态基线，不为凑机制继续叠加模块。

## 六、最小可证伪实验

1. **同源 R0/R1/R2 对照。** 固定 RWKV 核心、容量、训练预算、序列和选择规则，只改变输入适配器。
2. **reset 与 carry。** 固定模型与实体顺序，只改变同一实体跨 128 片段的状态是否连续，并记录截断反向传播边界。
3. **正确顺序与实体内打乱。** 固定同一实体成员、字段、容量和训练预算，只破坏实体内时间顺序，以检验顺序信息是否被模型实际使用。
4. **同容量无状态控制。** 与状态模型使用相同或等价容量、输入和训练预算，排除“参数更多或计算更多”对差异的解释。
5. **完整报告。** 五个预冻结长度桶、六档实体 DR、完整告警预算曲线、实体 AP、逐流 AP、首次告警时延和资源。长度桶必须在读取该轮评价数据前按数据合同冻结；不在本文新设桶边界、性能容差或资源阈值。[可微神经骨干统一合同](2026-08-20-可微神经骨干替代XGBoost目标合同.md)

### 6.1 方向性裁决条件

- **支持状态适配的方向性证据**：在同容量和同顺序对照下，carry 相对 reset 的增益集中于长实体；正确顺序优于实体内打乱；并且这一差异不能由无状态控制复现。字段语义适配则必须相对同参无语义投影呈现可归因的完整指标改善或非支配权衡。
- **否决或缩小适用范围的方向性证据**：若 carry 不优于 reset、正确顺序不优于打乱，或无状态控制达到相同表现，则不支持把长实体连续状态作为当前 LSPR-RWKV 的有效机制。若字段语义适配不优于同参无语义投影，则不支持保留该模块。任何结论都以完整性能向量、曲线和资源为准，不使用单点阈值、加权总分或新设魔法容差。
