## 一、机制定位与改造实质

### 1.1 原组件与其通用问题

原组件是 PLR 数值嵌入（Gorishniy 等 2022，arXiv:2203.05556v4，
原件 `raw/papers/methodology/2022-Gorishniy-On-Embeddings-for-Numerical-Features.pdf`，
`sha256` 前 16 位 `22b97677fec340fc`，经 `mineru-open-api extract` 保留公式后核对）。

它解决的通用问题是：表格深度模型把数值特征当标量喂入，表示能力不足。
其分段线性编码（式 1，物理页 3）：

```
PLE(x) = [e_1, ..., e_T] ∈ R^T
e_t = 0,                              x < b_{t-1} 且 t > 1
      1,                              x ≥ b_t 且 t < T
      (x − b_{t-1}) / (b_t − b_{t-1}), 其余
```

对注意力骨干的接口（同节「A note on attention-based models」）：

```
f_i(x) = v_0 + Σ_{t=1}^{T} e_t · v_t = Linear(PLE(x))
```

箱边界由训练区分位数确定：`b_t = Q_{t/T}({x_i^{j(num)}}_{j∈J_train})`。
论文明确 PLE 是**预处理策略**，边界一次算定、训练中不变。

### 1.2 本任务特有的结构

跨年度实体级检测中，**同一数值在不同实体历史下语义不同**：
同样的端口号或字节数，出现在已有上百条流的实体上，与出现在首次现身的实体上，
含义并不相同。PLE 的箱边界是**全局**的、与实体无关，抹掉了这层差异。

直接把 PLR 接进 FT 只是换一个 tokenizer，不构成机制创新。

### 1.3 改造：实体门控的位移通道

```
f_i(x, s_e) = v_0 + Σ_t e_t(x) · v_t        ← 全局位置通道（保持跨实体、跨年可比）
            + γ_θ(s_e) · Σ_t e_t(x) · u_t   ← 实体门控的位移通道（M-E 专属）
```

- `e_t(x)`：全局 PLE 权重，箱边界由 LSPR23 训练区分位数拟合，训练中冻结
- `v_t ∈ R^d`：全局箱嵌入，与 PLR 原设计一致
- `u_t ∈ R^d`：位移通道箱嵌入，**M-E 专属参数**
- `γ_θ(s_e) ∈ R`：实体门，由该实体的严格过去状态 `s_e` 计算，**M-E 专属参数**

**为什么这是改造而非拼接**：全局通道保留 PLE 原有的跨实体可比性；
位移通道由实体历史**门控**而非直接相加，因此当实体无历史时 `γ_θ = 0`，
整个式子退化为标准 `Linear(PLE(x))`——这既是可证伪的零门退化条件，
也直接满足第 2.3 节实测要求的「无历史中性行为」。

**为什么用标量门而非逐字段位移**：逐字段位移需要为每实体存每字段的历史统计
（`134997` 实体 × `81` 字段），这正是 CEM 失败的存储与漂移陷阱
（其 `inflight.pt` 中 `entity_memory` 达 `794.32 MiB`）。
标量门把每实体状态压到 2 个数，全库约 `1 MB`，容量则留在与实体无关的 `u_t` 上。

## 二、数据集－模型适配表

### 2.1 字段

| 项 | 内容 |
| --- | --- |
| 字段预算 | Dijk 附录 A 的 83 字段口径，与四格一致，不新增不删减 |
| 数值 Token | `81` 个（与现有 FT 一致） |
| 词表 Token | `2` 个（`Protocol` 类别数 8、`L3/L4 Protocol` 类别数 6，含越界桶） |
| `[CLS]` | `1` 个，Token 总数 `84`，与现有 FT 一致 |
| 端口字段 | `SrcPort`／`DstPort` 允许入模，走数值 Token；实测 `unique_count` 分别为 `61057`／`6041`，`integer_like=False`（已被分位数变换） |
| 二元粗拓扑 | `Int/Ext Dst IP`、`External_src`、`External_dst` 各 `unique_count=2`，直通不分箱 |
| 原始 IP | `SrcIP`／`DstIP` **只作分组键**，不入模；实体键为无向 `s`\|`d` 地址对 |
| 缺失处理 | 七个受检字段 `missing_fraction` 全为 `0`，两个输入候选一致地不引入缺失指示位 |

### 2.2 变换与拟合

| 项 | 内容 |
| --- | --- |
| 拟合区 | **只用 LSPR23 训练区**。LSPR24 对适配、字段、变换、词表、容量、优化器、检查点与阈值**零参与** |
| 现有变换 | 分位数变换，地标 `1000`，分位数字段 `78`，二值直通 `3`，词表字段 `2`，分块行数 `131072`，训练有效流 `11991315` |
| PLE 箱边界 | `b_t = Q_{t/T}` 在**分位数变换之后**的值域上拟合，随封印变换一同冻结并计入 `transform_state_sha256` |
| 分箱算法 | **分位数分箱**（论文 3.2.1），不用目标感知分箱（3.2.2）——后者用训练标签构造箱边界，会把标签信息编码进预处理，与本课题的泄漏防护边界冲突 |
| 箱数 `T` | `8`。依据见第 2.5 节参数量，非文献给定值，属任务化设定 |

### 2.3 实体历史表示与因果边界

| 项 | 内容 |
| --- | --- |
| 状态载体 `s_e` | 两个严格过去可观测量：`prior_flow_count`（该序列到达前同实体已出现的流数）与 `gap_since_last_event`（距同实体上一序列的时间间隔） |
| 实测依据 | `runs/diagnostics/ch3-ft-entity-state-carrier-probe-v1/probe.json`：序列级区分力 AUC 分别为 `0.8033483909578008` 与 `0.24543449195767822`（后者低于 `0.5` 是反向区分，等价强度 `0.7546`）；样本 `271815` 序列、正例率 `0.047919` |
| **归一化（强制）** | `prior_flow_count` 前后半段均值 `402.74` → `1519.58`，**源年内部即漂移 `3.8` 倍**，绝对值不可直接入模，必须取对数或分位数归一化。`gap` 漂移 `1.4` 倍，相对稳定 |
| 无历史处置 | `prior_flow_count` 中位数为 `0`，即**超过一半序列是其实体首序列**。此时 `γ_θ(s_e)` 必须为 `0`，退化为标准 PLE。注意该比例与 CEM 诊断的 `no_history_flow_ratio = 0.0109` 不矛盾：那是**流**级、本表是**序列**级 |
| 因果边界 | `s_e` 只由该实体在当前序列**之前**的序列计算。排序键为 `(E23, T23)` 升序；实体首序列的状态为中性值。断言：`same_entity`、`strictly_increasing_time`、`no_self_reference`（沿用 `entity-memory-interface.json` 已有的四项因果断言口径） |
| 切片 | `I23`／`M23` 提供序列到流的映射与有效位；序列级标签为其有效流标签的最大值 |
| 存储上界 | 每实体 2 个 `float32`；`150680` 源年实体约 `1.15 MiB`。对比 CEM 的 `794.32 MiB`，小三个数量级 |

### 2.4 输入、输出、状态与梯度接口

| 接口 | 形状与语义 |
| --- | --- |
| 输入 | `x_num (n, 81)`、`x_cat (n, 2)`，与现有 FT 一致 |
| 新增输入 | `s_e (n, 2)`，归一化后的严格过去实体状态 |
| 输出 | Token 张量 `(n, 84, 192)`，与现有 FT 逐位同形 |
| 状态 | `γ_θ` 无持久状态；`s_e` 由数据侧按因果序预计算，不随模型参数更新 |
| 梯度路径 | 逐流主损失与排序损失均经骨干反传至 `u_t` 与 `γ_θ`；`s_e` 是数据不接收梯度 |
| 零门退化 | `γ_θ ≡ 0` 时输出与基线 `Linear(PLE(x))` **逐位相等**，作为实现正确性断言 |

### 2.5 参数量公式

```
M-E 新增 = 位移通道箱嵌入 + 实体门
         = F_num · T · d          +  (2 · h + h + h · 1 + 1)
         = 81 · 8 · 192           +  (2·64 + 64 + 64 + 1)
         = 124,416                +  257
         = 124,673
```

`F_num = 81`、`T = 8`、`d = 192`、门的隐层 `h = 64`。

占裸 FT `924283` 的 `13.49%`；对比 CEM 的 `150913`（`16.33%`），为其 `0.83` 倍——
**两个机制的参数量同量级，正文对比不受参数规模干扰**。

`T = 8` 的选定依据：`T = 4` 仅 `62208`（CEM 的 `0.41` 倍）容量偏小，
`T = 16` 达 `248832`（`1.65` 倍）显著超出 CEM 且无据；`T = 8` 使两机制参数量最接近。
该值为任务化设定，**无直接文献依据**，须在源年做敏感性检查后才可写入正文。

### 2.6 与现有数据视图的缺口

| 缺口 | 满足方式 |
| --- | --- |
| `s_e` 无物化数组 | 由 `E23`／`T23` 按因果序在数据侧预计算，向量化实现已验证正确（`tools/ch3_ft_entity_state_carrier_probe.py`，构造真值逐位一致） |
| 目标年 `E24`／`T24` 不存在 | 按已确立口径从 `I24` 首个有效流推导，只驻内存（该口径已在目标年评价中使用并通过序列合同断言） |
| PLE 箱边界未纳入现有封印变换 | 实现时须扩展 `sealed-input-transform.pkl` 的 schema，并纳入 `transform_state_sha256` |

## 四、待冻结前必须补齐的项

1. **`T = 8` 的源年敏感性检查**：该值目前只有参数量对齐依据，无性能依据。
   须在源年做至少一次 `T ∈ {4, 8, 16}` 的对照，或在正文明确标注为任务化设定。
2. **`s_e` 归一化形式**：对数还是分位数，尚未裁决。分位数归一化需要额外拟合状态，
   对数更简单但压缩程度固定。须做源年小规模对照。
3. **门 `γ_θ` 的输出范围**：是否需要 sigmoid 约束到 `[0,1]`，
   或允许负值以表达「历史越多越不可信」。前者更稳、后者表达力更强，未裁决。
4. **PLE 箱边界与现有分位数变换的复合**：两级分位数是否冗余，须实测箱占用率。
5. 上述每个数值在写入配置前，须按仓库的魔法数字门禁登记用途、依据、
   适用边界与是否接触最终目标标签。
