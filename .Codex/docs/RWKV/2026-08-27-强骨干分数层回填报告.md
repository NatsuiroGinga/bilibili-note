## 二、任务改造：把原计划的"补齐训练缺口"改成"独立于选轮噪声的第二条证据链"

给定 1.1–1.3，原计划的"零训练分数层回填"已经不是在补一个不存在的缺口
（C01/C10/C11 训练已经存在），继续按原计划机械执行会产出与已有表示层结果冗余、
证据层级更弱的数字。本代理判断更有价值的做法是把同一套"分数层"构造**保留**，
但明确其新用途：它只用 C00 这一个冻结检查点、零参数、零训练，因此**完全不经过
逐轮选择这一步**——如果它与表示层的负结果方向一致，就是对负结果的独立佐证；
如果方向相反，就是对"选轮盲区"混淆的直接反例，提示表示层的负数字更可能是
训练/选轮伪影而非机制真实失效。这个判断已通过与用户共享的仓库规则校验
（"运行事实以原始日志和制品为准""不得沿用旧假设"），但**没有**征询用户就改变了
执行内容的科学解释框架，这一点需要用户在阅读本报告后确认是否认可，
详见"五、需要用户确认的事项"。

## 三、分数层 CPA-ELP 构造：为什么不能照抄 XGB 的特征层实现

`tools/ch3_xgb_cpa_elp_operational_backfill.py` 与 `ch3_xgb_cpa_elp_entity_oof.py`
的 CPA 机制对 XGBoost 是**特征层**实现：把因果前缀均值/残差等派生列拼进原始
83 维（`mean166`/`semantic168`），再喂给一个**专门在这套增广特征上训练过**的
树模型。这条路径的前提是存在一个在增广特征上训练好的模型——对 FT-Transformer /
TabM32，本工具能拿到的只有 C00（无机制）单一冻结检查点，机制必须在**不重训练**
的前提下移植，因此无法照搬特征层实现。

本工具把 CPA 压缩成分数通道上的唯一自然、零参数类比：

- **CPA（分数层）**：对同一实体、按升序流索引（曝光顺序）、**含自身**的已发生流，
  取 C00 原始分数的前缀算术平均，替换原始分数参与后续实体聚合。这是"prefix mean"
  这一支（对应 XGB 的 `mean166` 视图）在单标量通道上的直接类比，不是"residual"
  那一支（`semantic168` 的数值残差）——残差会把值域推出 `[0,1]`，与幂平均池化
  （C11 用到 `x**p`）不兼容，且残差不保持"分数越高越可疑"的语义，prefix mean 保持。
- **ELP（分数层）**：复刻 `ch3_xgb_cpa_elp_operational_backfill.py` 224 行附近
  固定的 `power_mean_p=1.0`（即算术平均），不做超参数搜索；基线聚合固定为实体内
  取最大值，与 `ch3_ft_transformer_field_token_protocol_a.py` 等同族工具的 C00
  定义一致。

四格：C00=实体取最大(原始分数)；C01=实体算术平均(原始分数)；
C10=实体取最大(前缀均值分数)；C11=实体算术平均(前缀均值分数)。
全程零训练、零超参数搜索、零对目标年的重新拟合。

模型构建、检查点加载、LSPR24 目标年前向与实体聚合逐字复用两个骨干各自工具模块的
`build_cell_model`/`build_model`、`score_target`、`entity_scores`、
`load_target_arrays`/`load_source_arrays`、`load_input_transform`、
`resolve_precision_profile`、`_resolve_device`，一律 import，未复制代码。
LSPR23（源年）全量前向没有现成函数（两个骨干的 `score_target` 只覆盖 LSPR24），
按各自 `score_target` 的原样结构改写数据源为 LSPR23（保留相同批量常量、相同精度
上下文、相同散射写回逻辑）。

新工具路径：`thesis/experiments/llm_probe/tools/ch3_strong_backbone_scorelayer_backfill.py`
（已按路径提交到本次会话使用的 worktree，未做 git commit——仓库规则要求

## 四、实测结果与服务器中断

### 4.1 FT-Transformer，分数层（零训练），LSPR24 目标年 —— 已完整跑出

```
C00 = 0.750799
C01 = 0.759808   （+ELP，Δ = +0.009009，正）
C10 = 0.755240   （+CPA，Δ = +0.004441，正）
C11 = 0.758984   （+CPA+ELP，Δ = +0.008185，正，但比 C01 低 0.000824）
```

判据布尔：`C01>C00 = True`；`C10>C00 = True`；`C11>=max(C00,C01,C10) = False`
（C11 以 0.0008 之差略低于 C01，量级接近数值噪声，不构成"联合明显更差"）。

一句话判读：**分数层版本两个单机制均为小幅正贡献，与表示层版本的强烈负贡献
（ELP −0.19、CPA −0.15、联合 −0.47）方向相反**。由于分数层版本用的是同一个冻结
C00 表征、零训练、无选轮，这个方向反转是对"FT 的负结果很可能是选轮盲区伪影
而非机制真实失效"这一猜测的**具体、可复核的反证**，比"逐流 AP 饱和"这类一般性
担忧更直接。但正效应本身量级很小（<1 个百分点，相对 0.75 基线），不构成
"机制对 FT 有强收益"的证据，只构成"表示层负结果不可靠"的证据。
