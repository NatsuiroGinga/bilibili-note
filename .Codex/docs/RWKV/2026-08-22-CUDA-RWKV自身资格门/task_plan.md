# CUDA-RWKV 自身资格门实施计划

> **执行技能**：按 `writing-plans`、`subagent-driven-development`、`daily-coding` 的约束实施；当前任务已由主进程分派给唯一实现代理，禁止再次分派实现所有权。

**目标**：为小型容量 CUDA-RWKV 建立不读数据、不训练、不创建跟踪运行的独立自身资格门，并提供静态可验收的配置与持久启动器。

**架构**：单个 Python 工具负责配置门、官方源码身份门、CUDA 扩展加载、确定性与数值门、六输入微扰门、外层掩码门、最小模型单次优化更新门及资源收据。Shell 启动器只建立持久运行身份、锁、日志、状态与失败证据，不访问数据或训练入口。

**技术栈**：Python 3.10、PyTorch `2.13.0+cu130`、CUDA `13.0`、NVCC、Ninja、Bash。

**规范来源**：`.Codex/docs/RWKV/2026-08-22-CUDA-RWKV独立Raw83资格/实施方案.md`（提交 `334ed1d19827ea5eb791f84900a020916e11354a`）。

## 全局约束

- 固定官方提交 `952102498e9ed367ea0a59ee64106916d474d30f`，CUDA 计算核不修改。
- 固定 `B=2`、`T=128`、`C=112`、头大小 `16`、低秩维 `8`，六输入为 BF16、CUDA、连续张量。
- 只执行固定构造输入上的实现资格检查和一个 `optimizer.step()`；不读任何数据，不执行训练循环。
- 不创建 SwanLab 身份，不包含数据路径、训练轮数或目标年度配置。
- 构建根与运行根持久化；相同执行身份幂等返回，失败保留状态、日志和已生成制品。
- 本地只执行 `py_compile`、导入、帮助、配置、`bash -n`、供应商摘要和差异检查、`git diff --check`；CUDA 实测前状态始终为“实验待证”。
- 禁止运行 `black`、人工夹具、单元测试、服务器命令和训练命令。
