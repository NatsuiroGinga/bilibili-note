## 已实测的设计前提（不要重新推导，直接用）

来源：`.Codex/docs/RWKV/2026-08-28-机制二梯度信号实测裁决.md`
与 `2026-08-28-LSPR23实体历史可用性诊断.md`。

1. **梯度控制器无冲突**。`c=min(1,‖g_f‖/‖g_r⁺‖)` 实测在收敛模型上 12 批中 9 批取 `1`，
   不压制排序梯度。**按 spec 5.5 节原形式实现，不要加下限夹紧、不要改基准。**
2. **普通 RankNet 在收敛模型上无信号**。`‖g_r‖` 中位 `6.08e-14`，12 批中 3 批严格为零。
   故普通形式只作对照，不作主损失。
3. **CVaR 恢复信号**。CVaR/普通梯度范数比 `16.61`（收敛）对 `1.30`（随机初始化）。
   主损失用 CVaR 形式。
4. **实体分层采样是硬性前提**。恶意片段仅 `92/271,815 = 0.0338%`，随机 64 片段批
   **零恶意概率 97.86%**。不分层则 97.86% 的步排序损失无定义。
5. **袋规模极端异质**。最大袋 `2,475,228` 条流（恶意最大 `318,176`、P99 `238,024`），
   而单步预算是 8,192 条流。**完整袋不可行**，必须支持截断。
6. **正实体基数小**。源区 `239` 个恶意实体，源年验证仅 `20` 个。采样器须避免同一
   正实体在一轮内被过度重复抽取。

**接口**

    negatives = rng.choice(self._negative_ids, size=self.n_neg, replace=False)

### 任务 2：前缀实体分数与多预算 CVaR-pAUC 损失

**文件**：新建 `thesis/experiments/llm_probe/tools/ch3_ft_entity_ranking_loss.py`

**接口**
- 消费：任务 1 的批字典；逐流 logit `Tensor[B,128]` 与 `valid[B,128]`。
- 产出 `prefix_scores(logits, valid, segment_owner) -> Tensor[E]`：实体路径最大分数
  `S_e = max_t ℓ_{e,t}`，与部署口径一致；唯一最大值时梯度只回到取得最大 logit 的流，
  并列时用固定稳定顺序的合法子梯度。
- 产出 `cvar_pauc_loss(pos, neg, budgets, xi) -> tuple[Tensor, dict]`：多预算 CVaR，
  返回损失与 CVaR 活动率诊断。
- 产出 `bag_policy_diagnostics(...) -> dict`：**同一批上并行计算三种袋处置**
  （完整袋／因果前缀截断／分层加权）的损失与梯度范数，**只回传配置指定的那一种**，
  另两种仅记录数值。这是「跑一臂比较三条曲线」的实现。

- [ ] **步骤 1：实现前缀最大分数**

```python
def prefix_scores(logits: torch.Tensor, valid: torch.Tensor,
                  segment_owner: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
    """实体路径最大分数。

    logits: (B, 128) 逐流 logit；valid: (B, 128) 有效掩码；
    segment_owner: (B,) 每个片段所属实体在本批内的紧凑下标。
    返回 (entity_scores[E], entity_index[E])。
    用 -inf 填充无效位后按片段取 max，再按实体 scatter-max，保证梯度只走最大者。
    """
```

- [ ] **步骤 2：实现多预算 CVaR**

按 spec 5.3 节：对每个正实体 `p` 与预算 `K`，
`R_K = mean_p [ ξ_{p,K} + (1/K)·Σ_n [L_pn − ξ_{p,K}]_+ ]`，`L_pn = softplus(S_n − S_p)`。
`ξ` 是训练私有状态，不进推理模型。`[·]_+` 等号处用固定合法子梯度。
记录 CVaR 活动率（`L_pn > ξ` 的比例）——退化条件之一是活动率为零。

- [ ] **步骤 3：三种袋处置的并行诊断**

截断策略：按 `(片段序号, 列位置)` 因果序保留前 `L` 条流，`L` 由配置给出。
分层加权：按实体链长分桶后按桶均值重加权。三者共享同一份实体分数计算，
只在负实体聚合与实体权重上不同。

- [ ] **步骤 4：真实数据核验**

用第四章已训练检查点 `runs/diagnostics/ch4-mlp-o11-oof-fold-models-seed42-v1/fold-0/checkpoints/selected-O11.pt`
（与 `tools/ch3_gradient_controller_conflict_probe.py` 同一入口）产生真实 logit，
核对：CVaR 损失梯度范数应显著大于普通 RankNet（该探针实测比值 `16.61`）。
不一致则停止并报告。

- [ ] **步骤 5：提交**

### 任务 3：梯度控制器

**文件**：新建 `thesis/experiments/llm_probe/tools/ch3_ft_gradient_controller.py`

**接口**
- 产出 `combine_gradients(g_flow, g_rank) -> tuple[Tensor, dict]`：

  返回合成梯度与诊断（两范数、夹角、投影触发、上限触发）。

- [ ] **步骤 1：按 spec 5.5 节原样实现**

**不要**加下限夹紧、不要改上限基准——该顾虑已被实测推翻（见「已实测的设计前提」第 1 条）。

在真实梯度上断言 `⟨g, g_f⟩ ≥ ‖g_f‖²` 且 `‖c·g_r⁺‖ ≤ ‖g_f‖`。
用任务 2 的真实 logit 产生 `g_f` 与 `g_r`，不用合成张量。
