# UGR'16 六版本 G0 数据门禁审计计划

## 目标

在不读取官方测试内容、不修改原始数据、不训练模型的前提下，完成六个训练版本的数据质量、标签语义、时间连续性、事件划分、序列预算和同源关系审计，给出可物化版本集合与 G0 门禁结论。

## 关键问题

1. 哪些版本满足合法字段、连续时间、二元标签与长序列物化要求？
2. 八类攻击计数是否共现，是否允许直接构成互斥多分类？
3. 哪些字段存在常量、缺失、时间捷径或近标签派生风险？
4. 哪种攻击事件间隔规则适合后续预注册？

## 已定边界

- 官方 `Xtest/Ytest` 只沿用下载收据中的大小和哈希封存结论，不解析内容。
- 只读处理 `thesis/experiments/llm_probe/data/raw/ugr16-feature-v3/`。
- 不训练任何模型，不改动任何原始 CSV。

## 错误记录

- 系统 Python 的默认字节码缓存目录不在可写范围，首次 `py_compile` 因权限拒绝停止，尚未读取数据。后续显式设置 `PYTHONPYCACHEPREFIX=/tmp/pycache` 后重跑。
- 首次控制字符检查因 shell 把十六进制范围展开为无效正则而失败；改用 `rg` 的字面十六进制转义后通过，未发现控制字符。
