# ResMLP2 与 TabM 协议 A 四格重跑实施计划

## 一、目标与边界

- 目标：先把最初的 ResMLP2 与 TabM4 放回第三章原多层感知机的协议 A，使用同一训练预算和四格消融直接比较；并行冻结骨干专属论文配方，另行验证可达能力。
- 取消：宽瓶颈 ResMLP2、源年三折资格门和只跑 C00/C11 的合同不再用于本次重跑。
- 证据等级：单次直接可比实验。LSPR24 已被历史实验访问，本次不得写成新的不可见最终测试或独立泛化证明。
- 不修改原多层感知机、既有 ResMLP2/TabM 三折运行和失败目录；使用全新工具、配置、启动器与运行身份。

## 二、两层证据设计

### 2.1 证据线 A：统一预算协议 A

本线回答「在约 9 万参数和同一训练预算下，两个机制能否稳定迁移到不同神经骨干，以及代价是多少」。它是受控的轻量化比较，不代表 ResMLP2、TabM 或神经模型族的能力上限。

两种骨干都执行四格：

| 单元 | 因果前缀跨流聚合 | 实体级可学幂平均池化 |
| --- | --- | --- |
| C00 | 关闭 | 关闭 |
| C01 | 关闭 | 开启 |
| C10 | 开启 | 关闭 |
| C11 | 开启 | 开启 |

共同协议逐项复用 `tools/ch3_2x2_fairsel.py`：

1. 数据为同一组 LSPR23/LSPR24 的 83 字段缓存、序列索引、掩码与实体键。
2. `seed=42`，序列长 128，批量 64，20 轮，每轮 1000 步，不早停。
3. 学习率 0.002，权重衰减 0.01，丢弃率 0.1，辅助损失权重 1.0。
4. LSPR23 使用原协议 A 的实体不相交训练/验证划分；每格跑满 20 轮，以验证逐流 AP 的最早最大轮次冻结检查点。
5. 四格选择结果全部冻结写盘后，才允许首次加载 LSPR24；每格只评价一次，禁止用 LSPR24 指标改结构、轮次、聚合指数或超参数。
6. ResMLP2 固定为最初结构：隐藏宽度 139、一个预归一化残差块，块内含两个全宽仿射层，参数量 89,796。
7. TabM 固定为四成员、隐藏宽度 186、成员概率算术平均、共享 ELP 指数、参数量 90,175。
8. ResMLP2 与 TabM 使用独立运行根、锁和 SwanLab 身份；资源准入满足时允许两个作业并行，但每个作业内的 `C00/C01/C10/C11` 必须顺序执行。
9. 并行运行的墙钟、吞吐和 GPU 小时标记为 `resource_measurement_contended=true`，只作工程记录，不进入公平效率结论；论文需要的效率比较另以冻结代表单元在空闲 GPU 上串行复测。

### 2.2 证据线 B：骨干专属论文配方

朱焱雷第三章的 ET-BERT 与 BUPT-CNN 没有强制等参数或共用超参数，而是分别使用适合各自骨干的优化器、学习率、批量、训练轮次、权重衰减和调度器。因此，本课题另设骨干专属配方实验，回答「在文献与官方实现支持的合理训练条件下，该骨干能达到什么水平」。

1. ResMLP2 与 TabM 的候选架构和训练范围必须先由全文论文、官方源码或本课题既有真实实验给出依据，禁止凭经验添加魔法数字。
2. 所有候选只允许在 LSPR23 的实体不相交训练/验证账内选择；候选集合、选择指标与并列规则在读取 LSPR24 前冻结。
3. 选择完成后，冻结结构、超参数、检查点和聚合规则；LSPR24 每个最终配置只评价一次，禁止根据目标年结果返回修改候选。
4. 本线使用独立运行身份与结果表，不覆盖证据线 A；证据线 A 失败不能否决本线，证据线 B 胜出也不能删除统一预算结果。
5. 本文件当前六个实现文件只负责证据线 A。证据线 B 在候选冻结文档完成后另建工具、配置、启动器与运行身份。

### 2.3 断点恢复与幂等执行

1. 每轮训练结束后在各自运行目录原子写入在途检查点，至少保存当前单元、已完成轮次、模型、优化器、最佳选择、ELP 参数、随机数状态以及配置、代码和输入清单身份。
2. 同一运行身份只有在上述身份全部一致时才允许 `--resume`；身份不一致时停止并保留旧目录，不得覆盖或静默重算。
3. 已完成训练单元凭检查点与选择收据跳过；LSPR24 仍只能在四格源年选择全部封印后首次加载。
4. 目标年按单元写完成收据；固定检查点和结果收据哈希一致时恢复入口跳过该单元，部分输出不得标记完成。
5. 启动器必须阻止同一运行身份被两个进程同时写入。中断后复用同一启动器并显式传入 `--resume`，不新建伪重跑身份。

## 三、必须输出的统一指标

每格均输出并进入同一结构的聚合结果：

- LSPR23：所选轮次、选择时验证逐流 AP、训练时长与检查点身份。
- LSPR24：逐流 AP、实体 AP、最大池化实体 AP、`0.1%/0.5%/1%/2%/4%/8%` 六档实体检测率、完整可达告警预算曲线的压缩聚合。
- 资源：参数量、训练墙钟、评价墙钟、峰值 GPU 显存、峰值进程内存和总 GPU 小时。
- 隔离：LSPR24 首次加载发生在选择封印之后；四格目标评价调用数必须恰为 4。

源年选择指标、LSPR24 跨年度指标和资源指标必须分表，不得用源年三折实体 AP 替代本次目标年四格结果，也不得只用实体 AP 宣布胜负。

## 五、执行顺序

1. 复用原协议 A 的加载、选择封印、目标一次评价和指标函数；只新增两种骨干适配与完整预算曲线/资源汇总。
2. 只执行 Python 语法、模块导入、命令帮助、配置验证和 Shell 语法检查；不运行格式化器、人工夹具、单元测试或独立冒烟实验。
3. 最小入口检查通过后立即同步生产文件，由主进程启动 ResMLP2 真实四格实验。
4. ResMLP2 第一格稳定后回读实际显存、主存和 I/O；资源仍有安全余量时并行启动 TabM，否则等待 ResMLP2 完成后串行启动。是否启动 TabM 不由 ResMLP2 指标决定。
5. 与证据线 A 运行并行完成 ResMLP2 和 TabM 的论文配方冻结；配方文档完成前不得编写或启动证据线 B。
6. 分别回收原始状态、日志、选择封印、聚合结果和资源收据，再更新恢复卡；工程失败与科学结果必须分开记录。
