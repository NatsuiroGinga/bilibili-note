## 实现内容

- 只从配置声明的 `dataset-manifest.json` 与 `experiment-manifest.json` 发现制品，拒绝相对路径、根目录越界、符号链接越界、哈希不符、未知角色和模式漂移。
- 校验 77 个有序字段、最大序列长度 128、标签与分组键隔离、`final_accessed=false`，并拒绝任何最终区制品或统计。
- 使用 PyArrow 分批列投影写入磁盘映射 NPY 数组；不构造两年度 Parquet 的 Python 对象列表。
- 校验四角色的缓存行数、角色、序列位置、有效长度、序列数、样本标识唯一性和标签侧车一对一连接；目标前缀没有标签制品或标签接口。
- 当快速 `source-validation` 的恶意流少于 200 时，从完整源验证主产品、样本清单、序列清单和源验证标签旁车重建全部源验证序列和全部行。不按源标签或目标标签筛选成员，避免扭曲源验证自然类别分布。
- 重建行严格复用 Rust 的 `Protocol` 缺失/未知/词表编码、各字段 source-train 中位数与 IQR、裁剪界、缺失掩码和相对时间规则。独立收据记录触发计数、前后完整行数和序列数、完整成员哈希、`source_labels_used_for_selection=false` 及 `target_label_used=false`。
- 缓存清单登记源清单哈希、字段、归一化器元数据和哈希、数组路径/模式/形状/数据类型/哈希、角色计数、选择收据哈希及 `final_accessed=false`。发布采用 `.partial.<pid>` 暂存目录和原子替换，成功后设为只读。
