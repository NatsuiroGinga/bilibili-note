## 结论

C12-R 已实现为独立的免重训回放入口。它只加载历史 `C12-DREF` 最佳检查点、同一冻结接收器、源冻结控制合同、阶段 A 冻结表示和无标签目标前缀表示；不创建优化器、不执行反向传播、不保存新权重、不新增可训练参数，也不覆盖历史 C12 目录。

初稿五格无法把资格门与单步裁剪的贡献分开。实现前已按控制变量原则改为六级阶梯：原始 DREF、仅资格门、资格门加裁剪、再加累计预算、再加回退，以及逐 `2-IP` 序列更新数匹配的随机门加裁剪。随机门仅由源合同哈希、DREF 检查点哈希、种子和 `sequence_id` 派生。

## 输入门禁

回放入口在加载模型前验证：

- 历史状态与配置均为 `variant=C12-DREF`，状态为 `finished`，且 `final_accessed=false`。
- 检查点载荷的 `variant` 为 `C12-DREF`。
- 源冻结控制合同只由 `source-train` 与 `source-validation` 选择，目标前缀未参与阈值，目标开发标签未参与合同冻结。
- Q0 缓存、阶段 A 冻结表示、目标前缀表示和共同接收器的哈希链一致。
- 目标前缀清单固定 `labels_read=false`；目标开发概率与状态诊断先封存，独立评价入口随后才连接标签。

## 六级回放语义

| 变体 | 资格门 | 单步裁剪 | 累计预算 | 回退 |
| --- | --- | --- | --- | --- |
| 原始双参照回放 | 否 | 否 | 否 | 否 |
| 双参照加源冻结资格门 | 是 | 否 | 否 | 否 |
| 双参照资格门加单步裁剪 | 是 | 是 | 否 | 否 |
| 双参照资格门加单步裁剪与累计预算 | 是 | 是 | 是 | 否 |
| 双参照资格门加裁剪、累计预算与回退 | 是 | 是 | 是 | 是 |
| 双参照逐序列更新数匹配随机门加单步裁剪 | 随机匹配 | 是 | 否 | 否 |

资格门只使用源冻结的漂移进入／回退区间和可信质量阈值。单步裁剪使用源冻结 `step_budget`。累计预算使用源冻结 `cumulative_decay` 与 `cumulative_budget`；超限时冻结并仅衰减账本。回退只响应非有限提议、状态范数越界或漂移达到源冻结回退阈值。

## 运行制品

每格独立保存：

- 输入、配置、状态、SwanLab 状态和制品清单。
- 目标前缀与目标开发逐流概率。
- 漂移、可信质量、资格门、实际选择、提议范数、应用范数、累计影响、动作、参照距离和晋升系数。
- 双参照块事件、晋升、保留、拒绝和最终晋升系数。
- 概率封存后连接标签得到的 PR-AUC、恶意召回、恶意 F1、Brier、15 箱 ECE 和每百万流固定告警预算召回。

远程启动器先隔离运行 `DREF`，取得真实墙钟和峰值显存；成功后才按可配置的最大并发数运行其余五个互不共享写状态的变体。并发结果不作为单进程效率证据。

- 这是种子 42、Q0 有界缓存上的诊断性回放，不是正式论文证据。
- 与历史 `K-DELTA` 的绝对比较只用于筛选；不同训练路径不能解释为严格机制因果效应。
