## 官方事实与计算口径

### 官方事实

根据 OpenAI 官方 [AGENTS.md 文档](https://learn.chatgpt.com/docs/agent-configuration/agents-md)：

- Codex 在每次运行开始时构建指令链；项目范围从项目根逐层走到当前工作目录。
- 每个目录按 `AGENTS.override.md`、`AGENTS.md`、配置的回退文件名顺序，最多纳入一个非空文件；更近目录的规则后置，因而覆盖更外层规则。
- 默认 `project_doc_max_bytes` 为 `32 KiB`（32,768 字节）；超过时停止继续加入文件。
- 官方建议将专项规则放在最接近专项工作的目录，且规则应简短，避免重复。官方 [GPT-5.6 模型指引](https://developers.openai.com/api/docs/guides/latest-model) 也明确建议“每条规则只陈述一次”，逐组精简后用代表性任务验证。

- 使用 `fdfind` 枚举规则文件，并检查目标路径中是否存在 `AGENTS.override.md`。目标链未发现覆盖文件或配置回退文件。`runs/tools/.../vendor/.../AGENTS.md` 位于第三方依赖树，未列入用户指定关键路径。

## 可确认的重复与可迁移内容

- `AGENTS.md` 中“新增或修改数据视图、物化器、加载器或模型适配器前……”整段连续出现两次，内容逐字相同。这是零行为风险的 P0 删除项，预计净省 **约 900 字节**；所有目标路径同时获益。
- `## 默认搜索排除边界（强制）` 是空标题，预计净省 **约 40 字节**；应删除或补回该标题本应承载的内容，不能保留空壳。
- 根规则的“研究对象固定为加密恶意流量检测”和 `thesis/AGENTS.md` 的同一边界高度重叠。根规则保留全仓生效的一句即可；论文正文仅保留其额外的“两个独立检测器串联”限制和章节专属事实。预计净省 **约 100 至 180 字节**，前提是确认根规则的表述已覆盖论文任务。
- 根规则的“研究证据纪律”与 RWKV 路线的“禁止空想式方案裁决”在证据等级上部分重复。根规则应作为唯一通用定义；RWKV 仅保留数据集、切分、候选登记册和路线特有门禁。预计净省 **约 180 至 300 字节**。

### llm_probe 与 scripts

- `llm_probe/AGENTS.md` 已规定远程操作可用 SSH、持久化脚本或启动器，且禁止 `rsync --delete`；`scripts/AGENTS.md` 再次陈述同一策略。脚本规则可只保留“完整读取远程脚本执行合同”以及 Shell 专属的 `PIPESTATUS`、`uv run --no-sync`、`bash -n` 条目。预计净省 **约 220 至 320 字节**，仅影响脚本路线。
- `llm_probe/AGENTS.md` 的按需合同入口已将服务器、故障、制品枚举、恢复门禁等机械细节路由至三份专题文档。这一做法正确；后续新增事故复盘、命令范式和字段清单应优先迁入相应合同或故障手册，`AGENTS.md` 只保留“何时读哪一节”的触发条件。保守可再省 **约 600 至 1,200 字节**，但需按条目核验专题合同仍可被准确定位。

## P0 / P1 / P2 建议

### P0：先释放所有路线的共同容量

1. 删除根 `AGENTS.md` 中唯一确认的重复数据接口段，并处置空标题。预计总省 **约 940 字节**；脚本路线由 28,887 降至约 27,947 字节，占比由 88.2% 降至约 85.3%。
2. 在改动前以当前八条路径启动一次只读 Codex 指令来源核验，确认没有全局 `AGENTS.override.md`、配置回退文件或未纳入本审计的专项规则改变组合链。

### P1：降低脚本与 RWKV 路线的增长风险

1. 把脚本规则中已由上级覆盖的 SSH/启动器与 `rsync --delete` 说明去重，保留 Shell 专属约束和专题合同入口。预计脚本路线再省 **220 至 320 字节**。
2. 将 RWKV 的事故叙述、字段级收据细节移入故障手册或数据合同；`RWKV/AGENTS.md` 只保留触发条件与不可违反的语义边界。预计 RWKV 路线省 **1,000 至 1,550 字节**。
3. 对每一组删除独立运行固定代表任务：RWKV 恢复、脚本启动、原件入库、论文编辑。验收标准是加载路径正确、关键禁止项仍被复述、没有新增无关专项文档读取。

### P2：按收益排序的后续压缩

1. 将 `llm_probe` 的非普适事故与机械命令细节继续归入已有专题合同，目标省 **600 至 1,200 字节**。
2. 将 raw/wiki 的工具细节迁入已安装技能，保留仓库证据链与文件归属，目标省 **550 至 950 字节**。
3. 把 thesis 中已废弃方案的名称清单迁至恢复文档索引，目标省 **200 至 400 字节**。

P0 与 P1 合计的保守预计节省为 **约 2,160 字节**；脚本路线将降至约 **26,727 字节（81.6%）**。这是本仓库推论，不是官方承诺；每次实际精简后必须按官方建议用代表性任务重新核验。
