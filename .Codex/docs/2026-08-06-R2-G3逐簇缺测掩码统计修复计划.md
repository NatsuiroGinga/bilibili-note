# R2 G3 逐簇缺测掩码统计修复计划

> **执行要求：** 使用 `subagent-driven-development` 管理本任务，并在实现边界内仅执行一次 `test-driven-development` 红绿循环。

**目标：** 在不插补、不删除样本、不改变 G3 阈值的前提下，让逐簇状态指标只统计该簇实际可观测的正式状态维度，同时保留固定长度逐维计数，并继续由跨簇汇总门禁保证每个正式维度总分母大于零。

**修改范围：**

- 修改 `thesis/experiments/llm_probe/src/flow_probe/r2_final_distilbert_probe.py` 中的 `_masked_state_statistics`。
- 修改 `thesis/experiments/llm_probe/tests/test_r2_final_distilbert_probe.py`，新增一个最小结构性缺测用例。
- 不修改数据、配置、G3 阈值、物理方程、QUIC 文件或其他脚本。

- [x] 在测试中构造一个正式状态维度在当前簇计数为零、但训练归一化中仍为正式维度的输入；断言逐维计数保留零值、缺测维不进入当前簇等权均值、固定长度平方和与分母仍被保留。
- [x] 将测试单独同步到旧 GPU 服务器，运行唯一目标测试并确认旧实现以“G3 逐簇状态维度缺少有效观测”失败。
- [x] 最小修改 `_masked_state_statistics`：使用安全除法；当前簇指标掩码为 `metric_state_mask & (counts > 0)`；若当前簇没有任何可观测正式维度则仍失败；返回固定长度逐维分子、分母和覆盖信息。
- [x] 同步生产文件，在服务器仅重跑同一目标测试并确认通过。
- [x] 由于探针源码属于检查点实现绑定，使用新实现重新生成一个新输出根的绑定检查点，不修改旧制品。
- [x] 使用新检查点更新三份 canonical 配置到新的独立输出根，并并行启动 F-A、F-P、F-S；回报 PID、显存、首步指标和 SwanLab 链接。
