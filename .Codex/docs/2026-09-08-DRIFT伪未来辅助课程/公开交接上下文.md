# DRIFT 辅助任务课程公开文献交接上下文

## 公开研究问题

一项公开的 DGA 检测研究 DRIFT 使用字符与子词 Transformer，并以 MTP、TPP、TOV 三个自监督任务等权预训练。当前需要查明：多辅助任务固定等权何时产生可观察的迁移伤害；源侧按恶意家族分组的伪未来验证反馈，能否合法用于调度辅助任务；这种做法与已有验证驱动调权、课程多任务学习、梯度手术和域泛化元验证方法有何不可约差量。
