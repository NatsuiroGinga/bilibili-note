# DRIFT 等权三任务辅助头恢复实施计划

**目标**：按冻结 T17 P0 预训练路径重新生成并持久化 MTP、TPP、TOV 三个训练后辅助头，为后续梯度冲突诊断提供合法源期基准。

**边界**：这是新筛选身份，不冒充原 P0 权重或课程算法；只读 T17 fit，T18–T25 零访问。

## 文件

- 新建 `tools/ch3_drift_t17_equal3_auxheads_gradient_base.py`。
- 新建 `configs/ch3-drift-t17-equal3-auxheads-gradient-base-v1.json`。
- 新建 `scripts/remote_launchers/run_ch3_drift_t17_equal3_auxheads_gradient_base_v1.sh`。

## 步骤

- [x] 核验 P0 配置、代码、tokenizer、T17 两类输入及其 SHA-256。
- [x] 以 P0 相同初始化顺序、Adam、学习率、BF16、批量和单次成员遍历训练字符支路。
- [x] 按既有 32768 样本原子节奏保存完整编码器、三个辅助头、优化器、随机状态、步数、各任务损失和有效监督计数。
- [x] 子词支路在构建相同模型后恢复字符终点随机状态，保持原 P0 的初始化与训练顺序。
- [x] 分别比较恢复编码器与原 P0 `char-backbone.pt`、`token-backbone.pt` 的逐张量一致性；差异如实记录，不把新身份冒充原权重。
- [x] Python 语法、JSON、Shell、命令入口和差异检查后，通过统一启动与回传入口依次运行字符、子词支路。

## 停止条件

- 任一冻结输入或 P0 身份哈希不符。
- 非有限损失或梯度、三个辅助头未进入检查点、恢复身份或随机状态不一致。
- 发现 T18–T25 路径或数据访问。
