# DRIFT 伪未来 family 反馈辅助任务课程研究计划

## 目标

判断 DRIFT 的 MTP、TPP、TOV 等权预训练是否在 T17 内部伪未见 family 或 T17→T18/T19 源期产生可重复任务冲突；只有真实冲突门通过时，才定义以源期伪未来 family 验证反馈调度辅助任务权重的统一课程训练方法。

## 冻结边界

- 不写代码，不运行实验，不读取 T20--T25。
- T17 train/val 优先；T18/T19 仅作冻结后的源期前向确认。
- family 仅是描述标签，不等于生成器；歧义映射必须隔离。
- 不把某个任务组合的单一 F1 更高直接解释为负迁移；同时核对 FPR、FNR、Recall、低误报和任务梯度。
- 机制构思依次执行 `research-ideation` → `source-command-sc-brainstorm` → `superpowers:brainstorming`，分类固定为 architectural。
- 冲突门不过即停止，不为课程、博弈、mHC、强化学习或朱式外观继续造公式。
