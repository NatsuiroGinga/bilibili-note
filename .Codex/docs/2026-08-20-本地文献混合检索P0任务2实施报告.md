## 变更内容

### 论文级聚合与证据解释

- 词法和向量通道分别执行“分块到笔记、笔记到论文”两级聚合，再在论文级执行 RRF。
- 同一 `paper_id` 只占一个结果位置，最佳通道块决定该通道的论文分数。
- 每条结果输出 `paper_id`、`note_views`、`lexical_block`、`vector_block`、`evidence_block`、通道排名、原始分数和 RRF 贡献。
- 混合结果选择 RRF 贡献更大的通道作为最终证据；贡献相同时固定选择词法通道。
- `note_path/source_pdf/page_hint/snippet` 与最终证据块保持一致，不再无条件优先词法片段。
- 实测 NetMamba 同一论文的 3 个笔记视图合并为一个结果；Top-10 论文身份无重复。

### 评估接口

- 支持每条查询多个相关论文路径或显式 `relevant_paper_ids`。
- 报告宏平均和微平均 Recall@5/10、MRR@10、nDCG@10、论文重复数和墙钟延迟。
- 报告相关结果的原件字段、原件实际存在性、页码线索和词法/向量 Top-10 独有覆盖。
- 查询可提供 `relevant_chunk_ids` 或 `relevant_chunk_keys`。没有真实块标注时，块命中率为 `null`，不以相关笔记路径替代块级真值。
- 已标注且相关集合为空的查询才是负例；当前没有可靠拒答门，只报告返回数量。
- 未标注查询标记 `skipped_pending_qrel`，不运行检索、不输出排名、不进入正例或负例分母。

### 双查询集合同

- `curated-regression-v1`：原 16 条来自证据矩阵、全文笔记或已知题录的人工构造查询，角色为 `development_regression`。它不是本会话真实用户提问分布。
- `real-user-query-v1`：只保存本会话 8 条与文献检索直接相关的用户原问，角色为 `independent_acceptance`，禁止据其结果调整 BM25、RRF 或阈值。
- 真实用户规格不包含助手回答、检索结果、答案词、私人或无关会话。
- 真实用户规格当前 `qrel_status=pending_independent_annotation`；`relevant_paths` 和块级真值均为 `null`。
- 两套集合必须分开报告，禁止合并平均。

### 在线合同

- OpenAlex 没有 `OPENALEX_API_KEY` 时直接返回 `skipped_missing_key`，不发普通搜索请求。
- OpenAlex、Semantic Scholar 和 Crossref 并发执行；Crossref 通过进程内锁保持单飞。
- HTTP 429/503 仅在响应提供数值型 `Retry-After` 且不超过调用超时时退避并重试一次；不盲重试。
- 候选按 DOI、arXiv、规范题名加年份依次去重，保留 `providers` 和各来源记录。
- 每个来源状态包含认证、延迟、缓存、限流、HTTP 状态、重试、退避、结果数、去重和降级原因。
- 当前未实现持久缓存，明确报告 `cache_kind=none`；不把缺失功能写成缓存命中。
- `--offline` 将全部在线来源标为 `skipped_offline`；`scope=all` 仍保留本地结果。

## 风险与后续边界

1. `real-user-query-v1` 尚无独立 qrel，不能声称真实用户查询性能，也不能用于调参。
2. 冻结人工集缺少块级 qrel；当前只能核验“最终证据选择与 RRF 贡献一致”，不能宣称证据块语义正确率。
3. 真实在线实测时 Semantic Scholar 匿名接口被限流，未验证其成功响应与 Crossref/OpenAlex 的真实跨来源重复合并。
4. 当前没有持久查询缓存；每次非离线调用都会重新请求可用来源。
5. `paper_id` 仍依赖任务 1 的已核元数据；同一论文某个视图缺年份或身份字段时可能无法自动合并，后续由模板与 lint 暴露，不用检索结果猜身份。
6. 拒答阈值必须另建独立开发集；本轮没有依据两条负例拍阈值。
