# R2 QUIC v4 官方方案检索计划

## 边界

- 只读核验 v3 失败与 v4 合同，不修改生产代码或运行实验。
- 只检索 IETF QUIC 规范、quiche/aioquic 官方源码与文档、权威排队和网络演算资料。
- 回答用户态字节队列、服务与传播时延分离、突发积压、逐事件收据以及 `2 MiB/80%` 门禁的合理性。

## 步骤

1. 核对当前合同、代理实现和两种 QUIC 客户端的发送节奏语义。
2. 核验排队理论对积压上界、缓存容量与传播时延的约束。
3. 下载有直接支撑价值且尚未入库的公开全文，写中文阅读笔记并更新 PINN 索引。
4. 形成合同支持项、否定项、实现陷阱和最小修订建议。

- 所有具体论断带稳定来源、章节或源码位置；无法公开获取的资料明确记录原因。
