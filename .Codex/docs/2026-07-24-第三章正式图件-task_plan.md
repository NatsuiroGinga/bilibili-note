## 图件合同

1. 图 3-1：整体方法框架，展示 GeNIS 生成路径、ns-3 物理监督路径、状态头、九条件词元和四层注入。
2. 图 3-2：四窗口五锚点有限队列示意，展示窗口边界、队列状态和每窗口通量。
3. 图 3-3：双锚点与分段守恒机制，展示平移自由度、内部锚点和四个分段残差。
4. 图 3-4：有界物理条件交叉注意力，展示查询、键值、四头注意力、零门和单层 0.1 相对残差上界。
5. 图 3-5：训练与推理流程，区分训练期特权监督和部署期仅用公共观测的路径。

## 视觉规范

- 画布按论文双栏通栏比例设计，宽度统一为 180 mm，高度按内容控制在 86–112 mm。
- 背景纯白，正文深灰，输入使用蓝系，物理状态使用青绿系，生成路径使用朱红强调，冻结模块使用中性灰。
- 颜色不单独承担语义：同时使用线型、边框、标签和箭头区分路径。
- 源文件为 SVG，最终引用格式为 PDF，验收预览为 PNG。

## 关键问题

1. 现有 PDF 导出工具是否能正确嵌入中文字体？
2. 正文是否应以 PDF 作为论文引用、以 PNG 作为 Markdown 预览？
3. 图 3-3 是否避免将当前 $L^+=0$ 契约画成普遍非零事件？

## 决策

- 结果型图不使用示意数据，只保留待生成名称、证据来源和解锁条件。
- 图 3-3 按当前 `QueueDisc` 契约只画到达、出队和入队前丢弃；非零出队后丢弃作为正文公式契约边界，不在图中暗示已解决。
- 绘图使用独立 `uv` 项目与 Matplotlib；`pubfig` 不提供本任务所需的模型结构组件，因此采用同等的矢量出版规范。
- 正文以 PNG 提供 Markdown 预览，图注同时链接同名 PDF 论文版和 SVG 可编辑版。
- 图 3-1 放在 3.2.4 之后；图 3-2 放在 3.3.1 之后；图 3-3 放在 3.3.5 之后；图 3-4 放在 3.4.4 之后；图 3-5 放在算法 3-1 之后。
- 图 3-1 至图 3-5 统一表述为当前候选机制。E2 的种子 43、44 物理门槛未通过，在主控完成后续裁决前，不将图件或图注写成最终算法结构。

## 错误记录

- `thesis/figures/第三章/` 尚不存在；在创建图件源码时一并建立。
- Fontconfig 缓存目录不可写；绘图脚本将直接注册 `/System/Library/Fonts/Hiragino Sans GB.ttc`，不依赖全局字体缓存。
- `uv sync` 下载 Matplotlib 时长期无进展；改用 `uv.lock` 中固定的官方轮子地址断点续传，安装仍限定在本目录 `.venv/`。
