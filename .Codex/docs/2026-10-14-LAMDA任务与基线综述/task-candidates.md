## C1：零/低标签时间泛化（测试时适应 + 固定 FPR 工作点）

**任务设定**：模型在 `TRAIN+IID`（2013–2014）静态训练后冻结参数上线；此后年份**不给任何新标签**
（或月预算 B∈{0, 50, 200}），模型只能用已到达的未标注流样本自更新（测试时适应）；
评价按年报告 AP、AUROC、F1、FPR、FNR 与固定历史阈值下的工作点；**主对照条件是「同 FPR 下的 FNR」**。

### 逐条判据

**① 指标提升空间（有具体数字）**

- 已发表锚点（全部 LAMDA 或其附录，`E3`）：
  - 静态监督基线 FAR F1 `41.86–47.59`（FNR `64.10–69.93`，FPR `1.14–1.69`）；
  - CITADEL 月预算 400 标签 F1 `77.7±0.1`（FNR `24.0`、FPR `2.3`）；月预算 50 → `70.9±1.2`；
  - CITADEL 同文内**不更新只增强 = F1 `30.9`**；
  - 本课题 screening 探针（`E3` 制品，仅资格用途）：2017 AP `0.3462`、FNR `0.9185`。
- 天花板参照：IID（同分布）F1 `97.49`；带全标签 Joint（Domain-IL）`88.52`。
- ~~**余量**：标签预算 0 → 400 的整条曲线之间没有已发表读数；零标签端
  （`30.9` 与监督静态 `47.59` 之间、以及 FNR@固定FPR 的工作点）是明确空位。~~
  **⚠️ 2026-10-14 实测推翻本行**：改用程序化引用图（OpenAlex）重试后，
  该空间已被 2025–2026 新作占据（SEED 预算半监督、LFreeDA 零标签、MADCAT 零标签 TTA）；
  且 **SEED 实测报 `FPR = 10⁻¹–10⁻⁴` 工作点曲线**，固定 FPR 工作点亦非空位。
  **C1 剩余差量收缩为「LAMDA 宿主 ＋ 4,561 维稀疏二值特征」。**
  完整更正与证据见 [候选任务对照 §五](../../../thesis/methods/第三章-LAMDA候选任务对照（供裁决）.md)。
  LAMDA 原论文与 14 条引用里**没有任何无标签适应工作**（本轮检索）。
- 数据支持边界（强制声明）：**余量不得宣称来自 2024/2025**——恶意样本仅 794/23，
  也不满足 Nguyen 判据的统计可靠性；余量年取 2016–2023（2023 仍有约 1.45 万正例）。
  2020–2022 AP 已贴 0.9986 天花板，改进空间集中体现在 FNR/FPR 工作点与 2016–2017/2023 年。

**② 工作量（能撑起一章）**

- 对照臂：静态 4 基线（LightGBM/MLP/SVM/XGBoost）＋ CADE ＋ TRANSCENDENT ＋
  MADCAT（移植）＋ CITADEL（预算匹配 50/400）＋ DRMD（预算匹配）＋ ER/A-GEM（更新型对照）。
- 消融：pretext 任务形态（掩码重构 vs 特征域对比）、伪标签再平衡策略、适应步长/样本窗口、
  阈值冻结 vs 重校准、适应后 FPR 漂移门。
- 形式化：带误报约束的测试时适应目标（对偶/分位数约束形式已有本地全文：Cotter、Kumar ICO）。

**③ 创新空间（直接近邻是谁、占到哪、剩什么）**

- **直接近邻**：MADCAT（`E3`）——无标签 TTA（MAE 掩码重构 + 伪标签再平衡），**在 APIGraph 特征上、
  无 LAMDA 结果、无 FPR 工作点分析**；CITADEL——LAMDA 上最强读数但**需要月度 400 标签**；
  DREAM/DRMD——都要专家标注；TRANSCENDENT——只拒识不适应用表示。
- **剩什么**：(a) MADCAT 的掩码重构 pretext 面向图特征设计，LAMDA 是 4,561 维稀疏二值词袋
  （无图结构、无自然顺序），pretext 必须重设计；(b) 无标签条件下的 FPR 约束工作点无人做
  （TRANSCENDENT 拒识不更新表示；DRIFT 主线的 BER/CVaR 机制是潜在可迁移部件——**若用须与
  DRIFT 主线协商边界**）；(c) 适应后表示漂移的稳定性分析（本地 E1：良性 P90 `0.025→0.844`
  的全局表征漂移是可复用诊断）。
- 风险：若 pretext 重设计与伪标签门只是「MADCAT 换宿主」，创新强度不足——机制章必须
  在「稀疏二值重构的合理形态」与「FPR 约束下 TTA 的形式化」上给出独立差量。

**④ 实验成本（分钟级一臂）**

- LAMDA 4,561 维稀疏二值 + 59.5 万参数 MLP 全流程 513 秒（MPS，`E3` 制品）；
  TTA 变体每臂预计分钟级（逐批/逐年流式更新，无需从头重训）；本机可跑，服务器同理更快。
- 一天可迭代十几个臂；消融矩阵 3×4×3 ≈ 36 臂也在一天量级。

**⑤ 数据是否支持**

- 支持：时间退化病灶（FAR FNR 64–70%）在 2016–2023 有足量正例；零标签设定与数据合同相容
  （只用已到达未标注流 + 冻结统计）。
- 不支持的部分：2024/2025 只能探索性报告（正例崩塌是数据退化，**不是模型缺口**——
  任何声称在这两年提升 FNR 的方法都是在拟合标签枯竭，不是学得好）。

## C2：标注管线时间退化（量化、建模与标签校正）

**任务设定**：把「VT/AVClass2 标注质量随时间退化」作为一等研究对象：
(任务 a) 用源期可观测信号（家族跨年复现、`vt_count` 轨迹、特征空间新颖度——**不读最终目标标签**）
估计逐年/逐样本标签可靠性并量化退化曲线；(任务 b) 以可靠性为主线加权/校正训练与评价，
在冻结标签版本上验证是否同时改善时间泛化指标。

### 逐条判据

**① 指标提升空间（有具体数字）**

- 病灶数字（本课题本地审计，`E3`，未发表）：单例家族样本质量占比 2013 `3.7%` → 2017 `42.9%` →
  2020 `66.9%` → 2024 `84.7%`；四年抽样跨年复现家族仅 236 个（全复现 11 个）；
  LAMDA 附录 F：2017 年 `5.19%` 原恶意样本当前被判良性（`E3`）。
- 已发表效果锚点：**该任务本身没有已发表读数**（本轮「未发现」）——余量证明方式不同：
  它的「提升空间」体现为用可靠性重加权后在 2016–2023 的 AP/FNR 相对原标签训练的差量，
  这是一个**待实验证实的假设**（不得预写为收益）。
- 可对照的外部效果量级：学习 label noise 文献（Co-teaching 等，未入库，本轮仅登记存在性——
  **不作为基线数字引用**）。

**② 工作量**

- 消融多（可靠性信号×校正方式×阈值），形式化强（时间退化弱标签学习有清晰的统计结构）；
  且自然包含一个数据审计章（可复用家族标签诊断）。
- 风险：贡献偏「数据/协议型」，与参照论文「方法型」章结构（病灶→机制→形式化→对比→消融）
  的匹配度要靠「校正机制作为方法」来补。

**③ 创新空间**

- 直接近邻：Beyond the TESSERACT（`E2`，构建协议×可信性，不做退化过程）；PLCDroid（`E1`，
  校正的是模型自产伪标签，不是标注管线退化）；LAMDA 附录 F（只给现象不给任务）。
- **剩什么**：没人把「标注管线的时间退化」定义成任务、量化它、并检验它对检测器评价的因果影响。
- 风险：若退化曲线只是「年份的替身」，机制贡献会被审稿人读成重加权小技巧；
  且评价循环性风险（用 vt_count 信号校正标签、又用同一 vt 体系标签评价）需要独立评价锚。

**④ 实验成本**

- 与 C1 相同的分钟级基础设施（同数据、同模型规模）；可靠性估计本身是 CPU 级统计。

**⑤ 数据是否支持**

- 支持且**直接命中本数据最大病灶**：正例率崩塌 51.35%→0.05% 很可能主要是标注管线退化
  （推论，未核证）——若实验证实，C2 是唯一能同时解释「正例率崩塌＋单例占比上升＋标签翻转
  ＋FNR 崩塌」四个现象的任务。
- 边界：2024/2025 在该任务里是**研究对象**（退化最重的年份）而非改进对象——这一点与 C1 相反，
  恰好互补。

## C3：Domain-IL 更新中的标签版本感知安全回归

**任务设定**：在 LAMDA Domain-IL 协议（逐年到达流更新）下，利用**标签版本信息**
（`vt_count` 作为元数据合法使用：它决定标签，列为特征即泄漏；用它的离散度/轨迹估计标签可靠性，
只在更新端使用）改进持续更新的安全回归——更新时对「低可靠性历史样本」降权或剔除，
以同时压旧恶意负向翻转与新增误报。

### 逐条判据

**① 指标提升空间（有具体数字）**

- 已发表间隙：Domain-IL 2025 平均 F1 Joint `88.52±0.46` vs Naive `72.71±0.83`（15.8 点，`E3`）。
- 本地实测病灾示警：ER 相对 Naive 只有有限资格增益（FPR/翻转下降、AP/FNR 略差，`E3` 制品）；
  九个任务化实现被源年筛选否决（L2/L3/L4/L5/L7/L8/L9/L11/L28）。
- **判读：间隙是真实的，但「更新策略」空间的近邻密度极高且本课题已高密度开垦——
  该候选的余量必须用「标签版本」这个新信息源来支撑，否则就是已否决路线的换皮。**

**② 工作量**

- 足够（到达流 + 记忆 + 约束 + 逐年评价面板全套既有基础设施可复用）。

**③ 创新空间**

- 直接近邻：Regression-aware（TIFS 2026，安全回归作为一等对象，`E3`）；
  记忆选择六家族（CBRS/GSS/MIR/PBR/MADAR/ECBRS，`E3`）；A-GEM（`E3`）；
  IWMS（延迟标签，`E3`）。
- **剩什么**：没有已发表工作在持续学习更新端使用「历史样本标签版本/可靠性」信息。
  IWMS 用预测类别路由记忆，不用标签可靠性；Regression-aware 不用标签质量。
- 风险：**最高**。九个已否决实现说明「在更新策略上加机制」在本数据上信号普遍微弱；
  标签版本信息与标签本身强相关，使用边界极易滑向泄漏；如果 Joint 间隙主要由
  「更多数据」而非「更新策略」解释，则 15.8 点不是可攻的余量。

**④ 实验成本**

- 分钟级/臂（同 C1 基础设施），服务器与 MPS 均可。

**⑤ 数据是否支持**

- 部分：Domain-IL 协议与数据相容；但 15.8 点间隙的原协议有种子缺陷（循环三次未传 run seed），
  复现后间隙可能变化；且余量年同样受 2024/2025 正例枯竭制约。

## 对照排除说明（为什么不是它们）

- **轴③家族分类**：LAMDA 家族标签 2020 后近似噪声（单例质量占比 84.7%），全家族多分类
  是在学标签噪声；窗口限 2013–2017 后又与 OOD 基准（MalNet 宿主）近邻过近。**降级不推荐。**
- **轴④对抗鲁棒**：LAMDA 上空位但威胁模型论证重、与 SaTML 竞赛线重合，快速迭代性差。**不推荐。**
- **轴⑥主动学习**：CITADEL 已占 LAMDA 强读数（77.7@预算400），预算曲线再挖增量空间小。**不推荐。**
- **轴⑤单独成章**：与 DRIFT 主线机制同源，若独立成章会造成学位论文内部两条主线做同构任务
  ——并入 C1 的「固定 FPR 工作点」条件，作为机制来源而非独立章。

## 最大不确定（诚实登记）

1. **C1 的零标签端可能比预期更空**：`30.9` 是 CITADEL 文内的对照读数而非独立基准，
   它的具体协议（增强方式、评价面板）与我们的设定不会完全一致，复现边界要先冻结。
2. **MADCAT 移植的合法性**：MADCAT 无结果表（数字在图内），移植对照要按其官方代码重跑
   （仓库未核准），工作量与失败风险都在。
3. **C2 的评价循环性**：用 vt 体系信号估计可靠性、又用 vt 体系标签评价，独立锚必须预冻结
   （例如用源期家族复现信号、在封印年只做一次性评价）。
4. **Google Scholar 引用检索受阻**（scholar CLI 需 Chrome 调试端口，本只读会话不可用）；
   「无人在 LAMDA 上做无标签适应」的结论当前边界是 S2 14 条引用 + R1–R11 引用图 + arXiv
   元数据检索 + 本地索引 9 组查询，OpenReview 引用图未抓取。结论一律是「未发现」而非「不存在」。
