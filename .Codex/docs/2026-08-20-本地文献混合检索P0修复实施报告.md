## 变更内容

### 索引对象与 YAML

- 使用 PyYAML 6.0.3 的 `yaml.safe_load` 解析标量、列表、整数和空值，不再用逐行正则模拟 YAML。
- 排除全部 `INDEX.md`、缺少 `source_pdf` 的非论文参考笔记和无法解析的 YAML，并在 `build/status` 中报告数量、原因、路径与简短诊断。
- 当前真实语料排除 17 个对象：14 个 `INDEX.md`、2 个非论文参考笔记、1 个非法 YAML 论文笔记。
- `title_zh/authors/year/aliases/tags/key_finding/tasks/datasets/methods/metrics/supports/cannot_support` 保存为结构化列，并写入单独的可检索元数据分块。
- 兼容旧笔记的单数字段 `task/dataset/method/metric`，统一映射到复数字段。

### 身份与多视图

- 当前论文 DOI 和 arXiv 标识只读取 YAML 的 `doi` 与 `arxiv_id`。
- DOI 规范化为小写标识；arXiv 规范化并去掉版本后缀。
- 正文 DOI 仅写入 `cited_dois`，不再参与当前论文身份。
- `paper_id` 按 DOI、arXiv、规范题名加年份依次生成；`note_id` 固定为仓库相对路径。
- 新增 `paper_id` 索引和 `fetch_note_views` 接口，允许一篇论文保留多个笔记视图。默认论文级聚合由后续任务 2 在 `search.py/ranking.py` 接入，本任务未越界修改这两个文件。

### 稳定分块与增量向量

- 每个分块保存精确文本哈希、稳定分块键和嵌入合同哈希。
- 稳定键包含规范笔记路径、当前标题路径、块位置、文本哈希和嵌入合同哈希。
- 嵌入合同包含模型名、固定修订、查询与文档前缀、分词器修订、解析版本、分块版本和字符预算。
- 旧模式缺少合同哈希，因此迁移时全量重嵌入；新模式只有稳定键与合同同时相等时才复制旧向量 BLOB。
- 复用向量必须是维度一致的 `float32` 字节；复用向量与新生成向量维度不一致时构建立即失败。
- 临时 SQLite 文件提交成功后继续使用 `os.replace` 原子替换目标索引。

### 状态与收据

- `build/status` 输出 `added/changed/deleted/unchanged/excluded`。
- 构建收据输出 `reused/reembedded`、合同变化、排除原因、来源清单哈希、索引 SHA-256、设备与耗时。
- `status` 输出 `stale_reasons`，区分来源新增、修改、删除和嵌入合同变化。
- 旧版模式仍可被 `status` 只读检查，并会明确报告模式迁移和待删除对象。

## 第三方接口核验

- 查询：`npx ctx7@latest library PyYAML "核验 safe_load 返回标量、列表、null 的接口与安全用法"`
- 文档：`npx ctx7@latest docs /yaml/pyyaml "核验 yaml.safe_load 读取 Mapping、Sequence、标量和 null 的官方接口及异常类型"`
- 官方来源：PyYAML 官方 API 文档与源码。
- 核验结论：`safe_load(stream) -> Any` 使用 `SafeLoader`，只构造映射、序列、字符串、数值、布尔和空值等基础对象；不支持的显式标签会抛出构造异常。本实现捕获 `yaml.YAMLError` 并把文件列入排除收据。
