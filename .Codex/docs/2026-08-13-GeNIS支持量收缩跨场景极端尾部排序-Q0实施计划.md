## 可执行统计合同

1. 外层组 `g` 是当前训练可见的七个攻击场景；独立支持量 `n_g` 是该场景去重后的恶意稳定键数。
2. 父组固定为攻击家族：场景 1--5 属于 `disrupt`，场景 6--8 属于 `authtest`。父风险是同家族训练可见场景全部恶意稳定键的折外损失均值。
3. 场景权重 `pi_g=1/G`，禁止按支持量加权后再次淹没稀有场景。
4. 每个外层场景与模型只生成一次两折稳定键交叉拟合分数，并由全部七种方法共享。七个训练可见攻击场景及训练良性都按稳定键哈希分成两折；每一折使用另一折的全部七个训练可见攻击场景与训练良性拟合，再预测当前折。这里不额外留出内部攻击场景，也不改成七折。外层留出场景始终不可用于权重、阈值或方法选择。
5. 令折外恶意分数的对数几率为 `z_i`，训练良性折外分数的 `99.9%` 分位为 `q`。恶意预算边界损失固定为：

   `loss_i = softplus((q - z_i) / tau_score) / log(2)`，其中 `tau_score=1.0`。

6. 场景风险 `R_g` 是该场景恶意稳定键的 `loss_i` 均值。支持量收缩固定为：

   `w_g=n_g/(n_g+lambda_s)`，`lambda_s=median_g(n_g)`，`R_tilde_g=w_g*R_g+(1-w_g)*R_parent(g)`。

7. 平滑尾部权重由 softplus 条件风险价值的梯度给出。场景尾部固定 `alpha_group=0.25`、`tau_group=0.1`；样本尾部固定 `alpha_sample=0.25`、`tau_sample=0.25`。辅助分位 `eta` 用确定性二分求解，权重最后归一到恶意样本均值为 1。
8. 所有方法都先使用与 `corrected-v2` 相同的二分类平衡权重；候选乘子只作用于训练恶意稳定键。XGBoost 与随机森林参数、种子和训练轮数保持不变。

## 七种必要方法

1. `uniform-balanced`：仅二分类平衡权重。
2. `sample-cvar-tail`：仅使用预算边界损失的平滑样本尾部权重。
3. `groupdro-max-scene`：只强调原始 `R_g` 最大的场景。
4. `sagawa-small-group-adjusted`：按 `R_g + C/sqrt(n_g)` 选择最坏场景，`C=sqrt(median_g(n_g))`，作为已发表小组修正对照。
5. `unshrunk-scene-tail`：原始 `R_g` 的平滑场景尾部权重乘平滑样本尾部权重。
6. `support-shrunk-scene-tail`：`R_tilde_g` 的平滑场景尾部权重乘平滑样本尾部权重，为完整候选。
7. `shuffled-scene-support-tail`：保持各场景支持量不变，使用种子 42 对训练恶意稳定键的场景身份作确定性置换，再运行完整候选；用于检验真实场景结构是否必要。

总评价单元为 `7 方法 x 2 模型 x 8 留出场景 = 112`。两折交叉拟合基座在同一外层场景和模型内共享，不计为独立候选单元。

## 指标与机械裁决

- 每个单元使用独立良性校准分区确定 `10/10000` 阈值；外层留出攻击场景与良性测试分区只评价一次。
- 主指标：最坏场景 `recall@10/10000`、最坏场景标准化部分 ROC-AUC（`max_fpr=0.001`）、最坏场景预算阈值宏平均 F1。
- 完整性指标：平均精确率、实际每万良性误报、训练时间、预测时间、峰值内存、支持量、收缩系数、原始/收缩风险和尾部权重。
- 完整候选晋级必须同时满足：
  - 两个模型均无场景预算超限；
  - 相对同模型 `uniform-balanced` 的最坏场景召回绝对提高至少 `0.02`；
  - 最坏场景部分 ROC-AUC 绝对提高至少 `0.005`；
  - 最坏场景预算宏平均 F1 不下降超过 `0.01`；
  - 最小平均精确率不下降超过 `0.001`；
  - 相对最佳单机制的最坏场景召回至少提高 `0.01`，且另一模型不劣于最佳单机制超过 `0.005`；
  - 打乱场景身份后，最坏场景召回相对完整候选下降至少 `0.01`。
- 任一数据隔离、哈希、字段、预算、非有限数值或设备断言失败，则整次运行无效；未达效果门只否决候选，不修改测试数据、指标、阈值或基线。
