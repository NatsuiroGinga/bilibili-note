# R2 UNKNOWN 残差上下文接口修复实施计划

> **代理执行要求：** 使用 `subagent-driven-development` 完成本计划；实现代理只进行一次精确范围的红灯、绿灯周期。

**目标：** 修复协议路由器统一传入 `residual_context` 时，`UNKNOWN` 回退专家因接口签名落后而在训练前崩溃的问题。

**实现原则：** 保持路由器统一调用合同不变，只让 `UNKNOWN` 回退专家接收可选上下文并明确忽略。该专家仍输出零表示、零状态和零物理残差，不增加可训练参数，不改变任何实验配置、数据或科学参数。

**技术栈：** Python、PyTorch、pytest。

## 全局约束

- 只修改 `src/flow_probe/r2_final_experts.py` 与一个覆盖该接口的目标测试文件。
- 不修改 TCP、UDP、QUIC、共享守恒、路由逻辑、配置、数据和训练入口。
- 回归测试必须先在现有代码上复现 `unexpected keyword argument 'residual_context'`，再以同一测试验证修复。
- 只运行该精确目标测试，不运行完整测试集、格式化、重复静态检查或 GPU 冒烟。
- 测试通过后同步两个白名单文件到服务器并直接重新启动原 F-A；独立复审与实验并行，不得阻塞启动。
