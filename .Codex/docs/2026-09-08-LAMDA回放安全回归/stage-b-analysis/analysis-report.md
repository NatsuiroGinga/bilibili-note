# 阶段 B 安全回归保护消融分析

## 分析问题

在同一 LAMDA 发布特征空间、同一训练预算和同一种子下，比较“安全记忆”与“回放＋安全记忆”两臂，判断回放是否在降低旧恶意负向翻转的同时保留当前年度检出能力。该分析是 `screening_only`，不是论文结果段，也不是正式最终测试。

## 制品完整性

- 运行身份：`ch3-lamda-security-regression-ablation-seed42-v1`。
- 状态：`completed`；两臂各有 12 个年度指标文件、34 个逐样本预测文件。
- 评价年份：2020--2025，共 83,420 条 `current_year` 预测；回溯面覆盖 2013、2014、2016--2024。
- 种子数：1。没有多种子方差、置信区间或显著性检验。
- 发布的 4,561 维特征空间使用未来年度训练分片协变量，故结果只能保留 `screening_only`。
- 原始制品索引：[阶段 B 复算 JSON](../stage-b-security-regression-reanalysis.json)、[运行清单](../../../../thesis/experiments/llm_probe/runs/diagnostics/ch3-lamda-security-regression-ablation-seed42-v1/run-manifest.json)。

## 实现审计

阶段 A/B 的本地工具哈希分别为 `f05344592afc72f2b95af08b4431a34c56dcc95f58fd3f53d538e136078cfc74` 与 `e8908bc4a27b989e1b36caaf4daae6399a2d83c3770a0c4233da35f49ba37b0f`，均与服务器对应文件和运行清单一致；训练循环每个批次只有一次 `loss.backward()`。此前分段读取造成的重复显示不是代码缺陷，不触发重训。

配置把安全记忆描述为“上一模型正确判为恶意的训练样本”。但代码 `collect_safety_memory` 在当前年度训练、`current_year` 和 `backward` 评价之后调用，并以当前模型对同一年度训练集的 `score >= 0.5` 筛选（`tools/ch3_lamda_security_regression_ablation.py:122-129`、`:184-194`）。因此本运行不是严格的上一冻结模型 PCT/FD-LM，也不能直接称为文献方法复现。该差异已写入复算 JSON，后续若继续必须先修正定义并保留普通蒸馏对照。

## 结论边界

- **实验支持**：联合臂在汇总 FNR 和全部回溯端点合并翻转率上有小幅下降；2024 年单年 F1/AP/FNR 改善明显。
- **实验不支持**：联合臂全面优于安全记忆臂；FPR 降低；2025 低阳性年度改善；多种子显著性；无泄漏正式结果。
- **研究裁决**：当前实现只保留为安全回归候选筛查，不升级为第三章主机制。下一轮若继续，只实现严格的上一模型正确恶意保护集合，并与普通蒸馏及无保护回放做最小对照；不得凭本轮结果叠加更多模块。
