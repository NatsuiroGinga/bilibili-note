# LAMDA 回放安全回归阶段 A 实施计划

## 目标

本章最终要交付一个有证据支撑的算法/框架；两个机制融合仅作为可能的创新构造，不是必须凑齐的模块数量。

实现并运行 [第三章 LAMDA 经验回放与安全回归约束研究卡](../../../thesis/methods/第三章-LAMDA经验回放与安全回归约束研究卡.md) 冻结的 `Naive` 与标准固定容量 `Replay` 两臂资格筛查。实验身份为 `screening_only`；本计划不设计或实现第二机制。

## 实现步骤

1. 完整读取 `thesis/experiments/llm_probe/AGENTS.md`；修改启动器前继续完整读取 `thesis/experiments/llm_probe/scripts/AGENTS.md`，并按需读取服务器运行合同和神经训练合同。
2. 在配置中逐项固化研究卡的年份顺序、每年 `80/20` 划分、两臂、网络结构、损失、训练预算、优化器、容量 `200` 的单样本 reservoir、更新时点、`seed=42`、评价指标和资格门。
3. 工具从同一冻结起点分别运行 `Naive` 与 `Replay`。Replay 每年使用当前年训练集和更新前的全部缓冲区训练，并仅在该年训练与测试均完成后执行 reservoir 更新。
4. 每年训练完成后，分别写出 `current_year`、`next_year` 和 `backward` 三个评价面，禁止混合。持久化 `AP`、`AUROC`、`F1`、`FPR`、`FNR`、`Brier`、旧恶意负向翻转、墙钟和峰值显存所需的逐样本预测与汇总。
5. 按“实验臂／年份／轮次”保存真实原子断点。断点至少包含模型、优化器、全部随机源状态、Replay 缓冲样本身份与完成状态；恢复时保持同一运行身份并跳过已完成轮次。
6. 启动器在真实服务器按既有环境合同运行，保留配置、代码身份、日志、状态、断点、预测、指标和制品清单。发布 `4561` 维特征空间使用未来协变量的事实须写入配置、控制台披露与报告。
7. 只拼接 `2020-2025` 六个 `current_year` 测试集的逐样本预测生成资格汇总，每个样本仅出现一次；AP、FPR、FNR 从拼接预测重新计算。旧恶意负向翻转按这六次年度更新的翻转事件合并计数并保留逐次分表。机械裁决要求 Replay 汇总 FPR 不提高，且汇总 AP 更高、汇总 FNR 更低、合并旧恶意负向翻转率更低至少一项严格改善。未通过即记录标准回放不获资格，不设计第二机制。
8. 将实现范围、入口检查、真实运行身份、服务器制品路径、全部指标、资格裁决和遗留风险写入现有主题报告。
9. 两项 GPU 运行完成后，将完整实验摘要（配置、数据版本、逐年指标、资格汇总、资源收据和制品路径）交给现有网页深度研究会话；不发送凭据或原始敏感数据，网页结果须经本地制品复核后才能引用。
10. 网页返回的文献候选必须取得原文后入库：原件放入 `raw/`，全文核验与结构化阅读笔记放入 `wiki/`，记录版本、精确位置、实验条件和与 LAMDA 的对应关系；未完成入库与核验不得改变候选排序或实验合同。

## 硬边界

- 不得复用论文混合前向与后向结果的平均 F1。
- 不得读取最终结果后改动年份范围、指标、方向、阈值或训练预算。
- 不创建或运行人工夹具、单元测试、集成测试或独立冒烟实验。
- 不运行 `black` 或其他未经授权的自动格式化器。
- 不将 `screening_only` 结果写成无泄漏正式基线、独立最终测试或机制有效性结论。
- 标准 Replay 不计作创新机制。阶段 B 安全回归消融已获用户明确批准并行运行，但其结果只作候选证据；机制数量和联合形式须由独立源年信号决定，不得为了凑两个模块机械扩展。
