## 一、研究问题与方向依据

### 1.1 病灶轴切换（用户裁决）

- **原病灶轴**：跨年概念漂移（DRIFT 源年 2017–2019 → 目标年 2020–2025 的逐年退化，原论文 FPR `0.032849 → 0.096520`）。该轴上的九个候选臂（M1-v1、M1-v2、M2/J06、R02/R07、N12/G2、固定全局更新专家混合、N14/CARS 等）已陆续止损。
- **新病灶轴（本方向）**：**DGA 检测器在对抗规避下的检出率维持**。攻击者通过字符级扰动把恶意 DGA 域名伪装成良性外观以绕过检测，这是 DNS 侧的真实攻防行为，与时间漂移是**不同的风险轴**。
- **数据复用**：仍使用 DRIFT 域名字符串与官方检测器，但**不依赖跨年结构**——扰动组由同一年的干净域名生成，最小臂在单年内部即可完成，不需要 T20–T25 面板参与。

### 1.2 可机械判定的研究问题

> 在**只使用源年数据、不接触目标年份**的条件下，对冻结的干净训练流程加入离散字符扰动的对抗训练，能否在**不提高干净样本误报**的同时，提高检测器对**扰动变体**的检出率；其中“组相对”结构相对“朴素对抗训练”是否有可分离的增量？

- 可机械判定形式：同一干净基线与同一评价集上，配对比较干净 FPR 与对抗 TPR/F1（判据门结构见 §5.3）。
- 证伪成本：P0 为单年零训练前向与扰动生成；训练臂为单年单种子短训，均可单卡执行。
- 证伪顺序：**病灶复现（P0）→ 朴素对抗训练（臂 B）→ 组相对结构（臂 C）**，逐级止损（§十）。

### 1.3 与既有方向的边界声明

- 本方向**不承接**任何时间漂移臂的读数、失败解释或设计依据（被否决实现的读数只说明其自身为何被否决，根规则）。
- 本方向与 N13（测试时适应）**同属第三章但病灶轴不同**：N13 处理部署期的无标签分布变化，本方向处理训练期的对抗输入分布；TENT 式 T18 源年臂的结果与本方案无关，既不支持也不否决本方向。
- 本方向**不声称“首次在 DGA 上做对抗训练”**——该空间已有先例（§二、§4.2、§4.3），差量主张必须落在组相对结构上。

### 3.2 记号与组构造

- 干净域名 `x`（标签 `y = 1`，DGA 侧），检测器 `f_θ`（干净基线的同一架构与冻结初始化）。
- 扰动生成器 `T`：在**编辑预算** `b`（字符替换／插入／删除的次数上限，先冻结为设计常数）内产生保持标签语义的扰动。两族并行登记：
  - `T_rand`：CharBot 式黑盒随机／启发式替换（不读模型）；
  - `T_grad`：MaskDGA 式代理梯度引导替换（读冻结副本或当前模型的梯度，只用于**构造扰动**，不进入更新路径）。
- 组：`G(x) = {x̃_0 = x, x̃_1, …, x̃_K}`，`x̃_j = T(x; ξ_j)`，`K` 为组大小（冻结值待 P0 后确定；`K` 决定前向成本，属**判定性超参**）。
- 逐样本对抗损失（“被骗程度”的可微代理）：`ℓ_j = ℓ(f_θ(x̃_j), y)`，二分类取 BCE；规避成功的硬判据 `s_j = 1[f_θ(x̃_j) < τ]`（`τ` 为源冻结阈值）。

### 3.3 组相对优势（草案）

```
ℓ̄   = (1/K) Σ_j ℓ_j                       # 组内基线：不使用组内 std
Â_j = ℓ_j − ℓ̄                             # 越大 = 该扰动越能骗过当前检测器
```

- **语义**：`Â_j` 度量的不是“模型有多不确定”，而是“**同一干净域名的各扰动变体之间，哪一个更能骗过当前检测器**”。这是把 GRPO 的“组内相对回报”换成“组内相对被骗模式”。
- **与既有工作的构造差异（如实标注）**：家族盘点的逐页答复已登记——**“批内／组内相对量”在已读来源中没有可直接搬用的构造**，最接近的是 Tan-GTPO 式(14) p.6 的协方差项与命题 2.2 p.5 的零和守恒。因此本机制在报告与正文中的身份是**本课题推论，不是文献结论**。
- **可证伪形式**：若 `Â_j` 与绝对损失 `ℓ_j` 高度共线（组内相对化无增量信息），则本机制无独立价值（判据门 G4-b）。

### 3.4 子集过滤（草案）

- 保留子集 `S = {j : Â_j > 0}`（只让“比组内平均更能骗过检测器”的扰动产生梯度），被拒样本权重为 0。
- 全组同质（`|S| = 0` 或 `|S| = K`）时不产生对抗梯度——对应 DAPO 滤掉全对／全错组、GFPO 只在保留子集内算优势。
- **必须报告的量**：被过滤样本比例，以及被过滤样本与保留样本的干净侧／对抗侧指标分面（防止用极小样本量刷指标）。
- 与家族来源的差异：GFPO 的过滤度量是“目标属性”（长度、token 效率），本方案的过滤度量是“当前检测器是否被骗”——**度量随训练变化**，属任务化改动，须在报告中显式声明。

### 3.5 熵受控项（草案；方向未定前不得实装）

- 候选形式：对扰动组内检测器输出的平均熵 `H̄ = (1/K) Σ_j H(f_θ(x̃_j))` 加权或加门。
- **方向未定（强制前置）**：来源给出两个方向的证据——提示熵**下降**（GMPO §4.4 p.9、DAPO §1／§3.1 p.2、p.4–5）；低熵模型上应**丢弃高熵完成**（Simoni-GTPO 式(10) p.5，`<H>_ini < ln2` 时削减更新）。因此**方向必须由源期诊断先定，不得凭来源直接移植**（与 [N13 TTA 方案](../2026-09-10-DRIFT-TTA任务化方案/task_plan.md) §5.2 机制 2 同一纪律）。
- 任务化目标（若实装）：**防止对抗训练把决策边界塌缩到只克制一种扰动族**，即保持对**未见扰动族**的检出率——这是本方向唯一有判别力的泛化主张，须单列评价。

### 3.6 信任域（草案）

两侧含义，均须独立登记：

1. **攻击侧（扰动可行域）**：`d(x, x̃_j) ≤ b`，编辑预算与字符集约束固定、**不随时间变化**。与朱焱雷第三章的 DS 有本质区别：DS 是训练过程中对攻击难度的时间调度（`ε(t)`、`K(t)`、`α(t)`），本方案不做课程。
2. **更新侧（连续权重）**：用平滑权重 `w(Â_j)` 压低极端组相对量，取代“越界即清零”的硬截断（SAPO 式(6)(8) 的结构思想）；门只读组相对量与符号，不读奖励内部结构。

### 3.7 总目标与开关独立性（草案）

```
L = L_clean + λ · L_adv(组相对优势 + 子集过滤) [+ γ · H̄ 项，方向未定前不加]
```

- 三个候选开关：**组相对优势**、**子集过滤**、**熵受控**（信任域为两侧约束，其中攻击侧预算是构造约束而非开关）。
- **开关独立性要求**：任一开关的关闭必须真的改变优化路径（`λ = 0` 时退化为臂 A 的干净训练；`Â_j → ℓ_j` 时退化为臂 B 的朴素对抗训练）。若某开关只在另一开关开启时才有作用，即惰性开关，不得计入机制数量（根 `AGENTS.md` 因素数量条款）。
- 只有最终自然形成两个独立开关时才做严格 `2×2`；当前不预设机制数量。

### 3.8 与 RL 的边界（强制声明）

本方案**不实现** PPO／GRPO 的策略优化循环：不引入策略分布、重要性比率、裁剪目标或 KL 项，也不把检测器视为策略。“GRPO 家族”在此是**结构思想来源**（组相对基线、子集过滤、熵受控、连续信任域），不是算法移植对象。若后续要引入重要性比率或裁剪目标，须另立方案与理由，不得在本方案内顺带实现。

## 四、边界表

### 4.1 与朱焱雷第三章的边界（必须写扎实）

| 维度 | 朱焱雷第三章（DS-RGO） | 本方案 |
|---|---|---|
| 攻击面 | **连续**扰动：图像式 PGD 谱系；ET-BERT 嵌入空间扰动、BUPT-CNN 像素空间盒约束（印刷第 16–18、27–32 页） | **离散**字符扰动：字符替换／插入／删除（CharBot／MaskDGA 谱系） |
| 训练信号 | 内层攻击轨迹＋外层展开优化：`δ*(θ)` 反应梯度、双层／Stackelberg、Hessian 向量积（印刷第 27–30 页） | **组内相对被骗模式**：无内层轨迹、无二阶项、无展开 |
| 难度控制 | DS 对扰动半径 `ε(t)`、迭代步数 `K(t)`、步长 `α(t)` 做**时间调度**（印刷第 26–27 页） | 无课程：编辑预算 `b` 为固定可行域，不随时间变化 |
| 备用机制维度 | 无熵控制、无子集过滤、无连续信任域 | 熵受控（防过拟合单一扰动族）、子集过滤（只让成功的扰动产生梯度）、连续软门 |
| 病灶同域 | 是（对抗逃逸） | 是（对抗规避） |

**结论**：病灶同域、机制不同族。**不照抄** DS、RGO 的公式、算法、组件数量与调度结构；本方案不写课程公式，不做展开求导。

### 4.2 与 MaskDGA 原法的边界

- MaskDGA 的贡献在**攻击侧**：用**代理模型**的雅可比显著度选位置、按中位数阈值**替换恰好一半**字符（黑盒＋定向，[笔记](../../../wiki/papers/attack-detection/dga/2019-Sidi-MaskDGA规避攻击.md) §3–§4.5，p.3–4）。其**防御消融已全文核验**：对抗重训（从 20 个家族各取 100 条 → **2,000 条**对抗样本并入训练、**加训 2 个 epoch**，§6.2 p.8）对**同攻击**恢复到平均 F1 `0.80–0.96`，但 **①干净 F1 同步下降**（`1.00→0.96`、`0.98→0.95`、`0.98→0.93`、`0.95→0.91`）、**②跨攻击迁移差**（对 DeepDGA 仅 `0.54–0.77`，其中两模型**低于**无防御水平）、**③蒸馏基本无效**（其为一般误分类设计，与本威胁模型的定向设定不匹配，§6.3 p.9）。
- 本方案**不主张扰动生成器的创新**：`T_rand`／`T_grad` 复用已有攻击族；差量只落在**优化结构**（组相对、子集过滤、熵受控、信任域）。
- 若消融显示收益完全来自“加入更多样的扰动样本”而与组相对结构无关，则本方案退化为 §4.4 的既有降级结论，按停止条件 §十.5 处理。

### 4.3 与 CharBot 重训实验的边界（本方案臂 B 的既有对照）

- CharBot 的防御实验（把 CharBot 样本加入训练后重测）**就是“朴素对抗训练”的一种实现**，且论文自述其做法是**一次性静态增广**、把**白盒迭代对抗训练明确列为未做的未来工作**（[笔记](../../../wiki/papers/attack-detection/dga/2019-Peck-CharBot规避攻击.md) §VI-C，p.9 原文引述）。其实测读数（FPR 0.1% 下重训后 LSTM.MI 仅升到 `55.19%`、B-RF `1.69%→1.84%`；干净性能几乎不降，§V 表 V p.8）说明该类防御**未闭合低误报缺口**。
- **本题的直接对照形态**：CharBot 给出“一次性静态增广在低 FPR 下失效”，MaskDGA 给出“同攻击恢复 ↑ 但跨攻击迁移 ↓、干净性能同时下降”，Drichel 2024（§6.4）则给出“迭代式联合 AT 在同攻击与跨网络干净性能上均改善”的第三种读数——三种读数方向不一，**说明权衡是否出现依赖训练方案与数据，不能预设**。
- 因此本方案的臂 B 不是新方法，而是**复现该既有防御形态**；臂 C 相对臂 B 的增量才是本方向要证的东西。若臂 C 不优于臂 B，本方向退化为“已知不足”的防御形态，按 §十.3 止损。

### 4.4 与综述 §8 第三类候选（源侧拼写近邻一致性）的边界（最直接近邻）

- **既有结论**：综述 §8 已把“从源良性域生成受约束拼写近邻、使模型保持良性预测一致”定为**原创性弱、优先作为对照而非正式机制**。
- **差异**：该候选作用于**良性侧一致性**（让良性域不被误报），本方案作用于**恶意侧规避**（让保持 DGA 标签的扰动变体仍被检出）；病灶侧不同，但共享“字符扰动增强”这一表层形态。
- **纪律**：本方案在正文与报告中**不得**把“引入字符扰动”写成创新；差量主张必须指向组相对结构。若组相对结构的增量不成立，本方向**直接接受**该既有降级结论，不作为正式机制。

- **根因**：E-A1 的病灶是 **24.2M 官方 Transformer（全局长程建模）的属性**，proxy 为字符 CNN（制品 `n_params=133,954` ≈ `0.134M`；简报口述与脚本 docstring 的“约 0.4M”**均为口径错误，主代理 2026-09-10 裁决以制品为准**——proxy 实际比口述更小约三倍，**强化“proxy 不继承病灶”的归因**），局部感受野＋池化的平滑效应使它**对 CharBot 2 位替换天然鲁棒**（`adv_AP=1.0`）→ 病灶在小模型上不复现，P2／P3 的“对抗检出改善”判据**没有可测量空间**。
- **判据结构性限制**：P2／P3 判据为严格 `adv_AP >` 比较；当 AP 饱和于 `1.0` 时该判据**无动态范围**，只能输出 `false`，且脚本未设 `indeterminate` 类状态——与 §5.3 的 G5“不可分辨”同族，登记为**无信息**而非机制否决。
- **附带观察（干跑样本量小，不作结论）**：臂 B 干净 `FPR 0.1155` 高于臂 A `0.0555`、臂 C `0.0630`；每类 2000 样本下不足以区分噪声与真实退化，正式全量须复核。

## 六、博弈论定位与求解器差量（主代理 2026-09-10 裁决，定位声明）

> 本节给方向一个**博弈论定位**并说明**求解器层面的差量**。它不新增机制：四个候选组件与 §3.3–§3.6 一一对应，§3.8 的“不实现 PPO／GRPO 策略优化循环”边界不变。

### 6.1 博弈结构与其离散域根本困难

本方向的训练问题可写成一次 min-max 博弈：

```text
min_θ  max_a  L(f_θ, a(x))        # θ = 检测器参数；a = 攻击者的扰动动作
```

- **离散域的根本困难**：域名字符是离散 token，**对字符索引求梯度无定义**，PGD 式内层最大化（沿梯度上升迭代）**不可用**。三条本地全文已核的证据：
  - **MaskDGA** 明写为**黑盒＋定向**规避：靠**代理模型**的雅可比显著度（每域名一次前向＋一次反向）选位置，按中位数阈值**恰好替换一半**字符；梯度来自代理模型，不是目标模型（[笔记](../../../wiki/papers/attack-detection/dga/2019-Sidi-MaskDGA规避攻击.md) §3–§4.5，p.3–4）；
  - **CharBot 完全无梯度**：在良性域名上做**两次随机字符替换**，无排序、无 beam search（[笔记](../../../wiki/papers/attack-detection/dga/2019-Peck-CharBot规避攻击.md) §III，p.4）；
  - **Drichel 2024** 的 PGD／C&W／AutoAttack 也不能直接作用于字符：因嵌入层不可微，攻击只能作用在嵌入之后的层，再经**可控离散化**（LCO／LBF × L2／L∞／余弦）映射回合法 e2LD（[笔记](../../../wiki/papers/attack-detection/dga/2024-Drichel-DGA检测鲁棒分类.md) §4.3.1–§4.3.2，p.5–6）。
- 因此离散域的“内层 max”只能由**采样式动作搜索**近似——这是本方向选择求解器族的出发点。

### 6.2 GRPO 家族＝离散博弈的天然求解器（结构对应）

LLM 后训练 RL 处理的正是**离散 token 上的搜索与信用分配**，在“梯度不可用”这一点上与本问题同型。结构对应如下（出处与核验状态同 §3.1）：

| 博弈角色 | GRPO 家族中的对应 | 本方案任务化 |
|---|---|---|
| 内层 `max_a`（攻击者选择动作） | 同一 prompt 采样 `G` 条输出 | **同一干净域名的 `K` 个离散扰动 = 攻击者的 `K` 次动作尝试** |
| 组内比较（哪些输出更好） | 组内奖励均值作基线（GRPO 原文 arXiv:2402.03300 式(3) p.13） | **哪些扰动骗过了检测器**（`Â_j = ℓ_j − ℓ̄`） |
| 保持探索 / 防坍缩 | 熵受控（Simoni-GTPO arXiv:2508.03772 式(10)(11) p.5；Tan-GTPO arXiv:2508.04349 §2.1 p.2） | 防守方保持对**未见扰动族**的探索与可塑性 |
| 外层 `min_θ`（防守方更新） | 信任域软门（SAPO arXiv:2511.20347 式(6)(8) p.3）＋ 子集过滤（DAPO arXiv:2503.14476；GFPO arXiv:2508.09726 式(2) p.3–4） | 更新侧连续门控 ＋ 只让**骗过检测器的扰动**产生梯度 |

### 6.3 与朱焱雷第三章的边界（博弈定位层）

| 维度 | 朱焱雷第三章 | 本方案 |
|---|---|---|
| 内层动作空间 | **连续**（嵌入／像素扰动），梯度可用 | **离散**（字符替换），梯度不可用 |
| 内层求解器 | PGD 式轨迹 + 展开优化（RGO 把 `δ*(θ)` 反应项纳入外层求导，印刷第 27–30 页） | **组采样 + 组相对聚合**（无轨迹、无展开、无二阶项） |
| 难度控制 | DS 对 `ε(t)`／`K(t)`／`α(t)` 做时间调度（印刷第 26–27 页） | 无课程；编辑预算为固定可行域 |

**结论**：机制族不同，**不是同一方法的换域**。§4.1 保留为实现细节对照，本条给出博弈论层面的理由。

| ④ 耦合方式 | 组相对信用分配改变**有效样本集** → 改变熵受控基线与信任域触发；二者**共享同一对抗生成过程且可分别关闭** | 设计草案；独立性要求见 §3.7（惰性开关不得计数） |
| ⑤ 固定对标锚 | CharBot 在 FPR `0.1%` 下未针对训练 TPR `5.58%`（文献）→ 目标恢复并**量化相对 `55.19%`（CharBot 重训后读数）的差距** | 两者均为文献读数（[CharBot 笔记](../../../wiki/papers/attack-detection/dga/2019-Peck-CharBot规避攻击.md) §V-D 表 V p.8）；**本课题尚无同口径自测**，且模型不同（DRIFT 24.2M vs LSTM.MI），该锚只作**量级参照，不是判据** |

**与朱最关键的共同点**：创新**不在损失函数**，而在**训练过程的组织方式**——“哪些样本驱动更新”（组相对信用分配 ↔ DS 难度调度）与“沿什么方向、多大幅度更新”（熵受控＋信任域 ↔ RGO 展开优化）。

### 7.3 边界声明（三重差异，必须照写）

| 维度 | 朱焱雷第三章 | 本方案 |
|---|---|---|
| 动作空间 | **连续**扰动，PGD 梯度可用，走**轨迹** | **离散**字符域，梯度不可用，走**组采样**（§6.1） |

**相同的是创新层位置（训练过程组织层），不是机制本身**；不得写成“把 DS-RGO 搬来做 DGA”，也不得照抄其公式、算法或组件数量（§4.1）。

## 八、章节规划：第三章／第四章的机制分配策略

### 8.1 分配原则

完整框架是 `P2 → P3 → P3.5 → P4` 的逐级升级（§6.5）。**若完整框架的工作量超过朱焱雷第三章对标线**，则按下列方式分配：

- **第三章只承载主干**：**P2**（朴素对抗训练基线，固定攻击者）＋ **P3**（组相对对抗优化）＝ 统一主方法「**组相对信用分配＋熵受控对抗训练**」（名称见 §7.5）；
- **进阶层整体移入第四章**：**P3.5**（学习型攻击者资格门）＋ **P4**（双侧共演化／league 稳定化）。

### 8.2 承接逻辑（朱式章末边界声明体例）

- 第三章的统一主方法证明“组相对对抗训练有效”，但其**对手是固定的**（CharBot 算子采样，**不学习**）。第三章末按参照论文体例声明该边界：**「固定对手下已达增益，而真实攻击者会适应检测器」**；并按朱的结构同构**追加一句成本边界**——**「组相对信用分配的额外计算成本为已知代价，其优化见第四章」**（登记依据见 §8.6）。
- 第四章据此引入**学习型攻击者与共演化**，解决第三章的“**对手建模深度不足**”。
- **定性（必须随叙述一起写）**：这是**缺陷导向的承接**，不是残次品补救——P3.5／P4 是第三章框架的**自然升级**（同一组构造器、同一数据合同、同一评价口径），不是对一个失败机制的修补。

### 8.6 已知代价的章际分工：组相对训练成本（用户 2026-09-10 追加）

## 十、停止条件

1. **P0 不复现 → 停**：两种扰动族均无显著下降 → 本方向在病灶门止损，不进入训练臂，不调扰动预算重试。
2. **臂 B 无信号 → 组相对不加**：朴素对抗训练相对臂 A 在对抗 TPR 上无改善，或干净 FPR 越界 → **不进入臂 C**（这是本方案的核心止损点：组相对结构的前提是朴素对抗训练本身有效）。
3. **臂 C 不优于臂 B → 只保留已知形态**：组相对增量不成立，或由 G4 控制解释 → 如实登记“朴素对抗训练在本数据上的读数”，本方向不作为正式机制。
4. **护栏越界 → 停**：`ΔFPR > 0`（干净误报增加）、G5 非退化／有限性失败 → 停止，不调参重跑。
5. **退化为既有降级结论 → 停**：若消融表明收益与组相对结构无关、只来自“更多样扰动样本”，按综述 §8 第三类候选的既有降级结论处理（对照而非正式机制）。
6. **不可分辨 → 先修测量**：G5 噪声地板或 G6 操作点冲突触发 → 不追加成本，先解决测量问题（确定性核或 CPU 复跑）再决定是否重开。
7. **禁止**：不得把任何负结果写成“对抗训练对 DGA 无效”；只能写“本方案在本数据、本预算与冻结判据下未获资格”。

## 十一、开放问题（不得在正文当成已证）

1. **扰动族的标签语义**：扰动后“仍是 DGA 域名”的判据（字符集、TLD、长度、合法字符）尚未定义；定义不严会产生“评价的是无效域名”的失真风险。
2. **未见扰动族的定义**：异族评价需要事先注册“族”的划分方式（不同引导信号？不同编辑算子？），否则泛化主张不可判定。
3. **熵受控方向未定**：须先做源期诊断（低熵 vs 高熵），与 N13 方案 §5.2 机制 2 同一纪律；方向证据取得前该开关不得实装。
4. **`K` 与预算**：`K` 属判定性超参，须在冻结前按实测吞吐确定并与臂 B 共享；改变 `K` 即改变机制强度。
5. **与第三章整体方法的关系**：对抗训练是独立主线，还是与现有 C00（官方监督双分支／B-ResNet）组合？本文件不预设；D6 裁决后由主代理改写 Goal。
6. **数据合同适用性**：本方向不依赖跨年结构，但 T20–T25 面板是否、何时进入评价，须另立协议；当前禁止访问。
7. **与 N13 是否共享底座**：默认不共享（不同病灶轴）；若未来合并叙事，须先证明两机制在同一评价下均可分离。
8. **恢复卡 §一 Goal 尚未改写**：§一 当前仍写“跨 family、伪未见 family 与跨年新 eSLD 泛化”，与本方向不一致，属 D1／D6 待裁决事项。
