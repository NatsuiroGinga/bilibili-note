# R3 文献调研过程笔记

## 范围检查点

- 状态：已完成范围定义，进入本地语料筛查。
- 研究方向：确定性与随机网络演算、可微最小加与上确界、不确定性校准、部分可观测队列边界、流量异常检测和生成式检测连接。

- 停止规则：不设机械篇数上限，以证据缺口闭合和连续两个批次证据饱和为准。

## 当前风险

1. 经典网络演算可能只给确定性最坏情况界，直接用于恶意流量检测会过松或不可辨识。
2. 服务曲线依赖链路容量、调度、交叉流量和排队节点，GeNIS/TQH-C2 未必具备这些字段。
3. 学习包络可能通过无限放宽边界形成零损失平凡解。
4. 可微最大值与最小加近似存在温度偏差和长窗口梯度集中的矛盾。
5. 校准只在同分布开发集有效时，不能支持 TQH 跨加密条件主张。

## 关键证据综合

1. Burchard 的有效服务曲线提供违约概率语义，不提供部分观测服务反演。
2. Liebeherr、Lübben、Rizk 与 Fidler 共同要求主动率扫描、重复包列或成对到达－离开观测；当前 GeNIS/TQH 不满足。
3. Bouillard 支持在服务不可辨识时退化为多尺度到达约束异常检测。
4. Cuturi 与 Mensch 只解决有限候选最小或最大运算的可微化；温度偏差和候选数量必须显式报告。
5. Podina、Yu、Stankevičiūtė 与 Gibbs 要求独立校准、整流或整运行分区，并区分边际、长期平均与条件覆盖。
6. Jiang 的分组化反例要求实际包长或明确修正，否决纯连续平均速率保证。
7. TAILING 说明点式时延分位数仍需要历史时延观测，不能从八字段共享视图免费获得。

## 数据可观测性裁决

- GeNIS 的重复 HERA 记录是活动流阶段更新，不能直接当独立控制体；必须从 PCAPNG 重建。
- TQH-C2 已有逐包时间、长度和方向，可重建到达历史，但没有瓶颈服务和队列真值。
- ns-3 有容量、入队、出队、队列和丢弃真值，可验证完整网络演算；现有攻击场景仍不能替代多档率扫描。

## 最终路线裁决

- 否决公开数据上的完整“到达 + 服务 + 积压/时延保证”。
- 允许一次降级筛选：“多尺度条件到达包络 + 组级同时校准 + 不确定性门控物理软令牌”。
- 服务分支只留 ns-3 独立诊断，不进入公开分类器。
- 详细字段、公式、消融、公平基线与否决阈值见 `r3-minimum-experiment-contract.md`。
