# R3 证据缺口与数据可观测性审计

## 1. 直接裁决

**公开数据上的完整服务曲线、积压界和时延界未通过可辨识门禁。** GeNIS 2025 与 TQH-C2 能重建分组到达历史，但没有同一瓶颈的成对到达－离开轨迹、链路容量、调度器、交叉流量和队列真值。现有证据不允许从八字段聚合统计直接学习“保守服务下界”，更不允许把该预测解释为确定性最坏情况保证。

R3 只能分成两个语义不同的部分：

1. **公开数据可用部分**：多尺度条件到达包络、经独立开发分区校准的到达超额风险，以及字段不足时的显式拒用。
2. **ns-3 可验证部分**：在主动率扫描、成对到达－离开、容量、队列和分组真值齐全时，验证有限窗口有效服务下界、积压或时延边界；该结果不能自动迁移为公开数据保证。

因此，完整 R3 不应直接晋级为第三章主理论。允许进入一次有明确终点的**降级筛选实验**，目标是判断“校准到达包络”能否改善跨加密条件误报或检测非劣；完整网络演算只作 ns-3 机制诊断。

### 3.1 GeNIS 重复窗口的限定

历史十秒流表审计得到 1,472,133 行、201,343 个 `FlowID` 会话，其中 1,270,790 行是同一会话的重复阶段记录。HERA 会在活动流持续期间按间隔继续输出记录；这些记录可能累计或重叠。R3 不得把相邻四行直接当作四个互不重叠控制体。合法做法只有两种：

1. 从原始 PCAPNG 按冻结窗口重新提取分组增量；
2. 先用 `StartTime`、`LastTime`、`Rank`、`Trans` 和字段差分验证增量语义，再保留通过连续性和非负性门禁的会话。

主方案选择第一种。第二种只作数据诊断，不进入正式物理结论。

### 3.2 TQH-C2 的限定

TQH-C2 已保留逐包相对时间、到达间隔、方向、网络层长度、传输族和字段掩码，因此可在完整 `parent_session_id` 内重建到达窗口。它仍没有瓶颈队列的出队时间、容量和交叉流量，不能从单端 PCAP 推断完整服务下界。不同 profile、interval 或 jitter 不得混在同一校准单位内，也不得用 profile 名称构造边界。

### 3.3 ns-3 的限定

当前 ns-3 四窗口制品已经提供容量积分、队列规则接收量、队列首尾、入队、出队与丢弃真值，能验证队列守恒和有限窗口服务。但随机服务估计文献要求跨探测速率、跨交叉流量、重复轨迹和足够包列长度；现有 21 个攻击场景不能自动替代主动率扫描。若要验证完整服务曲线，需新增独立的率扫描场景，且不得用于调节公开测试阈值。

## 4. 承重机制证据矩阵

| 承重机制 | 正证据 | 反证与适用边界 | 当前状态 |
| --- | --- | --- | --- |
| 条件到达包络 | Bouillard 等证明多尺度到达约束可在不恢复服务时检测斜率异常 | Paxson 与 Hohn 否决普适泊松或单尺度到达假设 | **通过，需数据条件化和多尺度** |
| 有效服务下界 | Burchard、Lübben 等给出带违约概率的有效服务语义 | Liebeherr、Rizk/Fidler 要求主动探测或成对轨迹；Habib 与 QuASI 揭示部分观测不可辨识 | **仅 ns-3 通过；公开数据否决** |
| 可微边界 | Cuturi、Mensch 支持有限候选上的平滑最小或最大及误差控制 | 平滑只解决梯度，不证明物理输入有效；温度过大有偏、过小梯度集中 | **计算机制通过，物理有效性另验** |
| 不确定性校准 | Podina、Yu 支持独立校准集上的 PINN 边际覆盖；Gibbs 支持长期平均错覆盖控制 | 相邻窗口不交换；跨条件覆盖不自动成立；区间可通过无限变宽维持覆盖 | **允许后处理，必须报告宽度和最差组覆盖** |
| 分组化边界 | Jiang 的反例要求显式分组语义或修正 | 只用平均速率和连续比特流可使服务、积压和时延界失效 | **必须新增包长累计门禁** |
| 任务连接 | Jacobs 说明网络演算状态可作为异常特征 | Helm、Zhang、DeepTMA 均依赖已知拓扑、容量和合法解析模型，未建立公开检测上的物理梯度 | **仅为待验证假设** |
| 时延分位数 | TAILING 证明历史时延可预测未来逐包条件分位数 | 需要到达－离开或往返时延；只给点式分位数，不给样本路径保证 | **当前公开共享视图不满足输入** |

## 5. 已闭合缺口与剩余缺口

### 5.1 已闭合

1. **服务可辨识性**：在当前公开观测下不成立；不再继续寻找能绕过缺字段的“万能学习器”。
2. **可微化**：有限窗口 `log-sum-exp` 或强凸平滑足以形成可导算子，且可给候选数与温度相关的显式近似误差。
3. **校准单位**：完整流、会话或独立仿真运行是交换单位；相邻窗口不能随机打散。
4. **分组语义**：实际包长或可审计的最大包长是完整边界的必要字段。
5. **公平原则**：公开分类视图若增加字段，所有普通基线必须在相同信息预算上重跑。

### 5.2 只能由实验回答

1. 多尺度条件到达包络是否能在 TQH 留一加密条件上降低良性误报，而不是只识别来源或缺失模式。
2. 可微包络的梯度是否真正进入生成式检测表征，且不通过无限放宽包络形成平凡解。
3. 共形修正能否在冻结开发分区上达到目标覆盖，同时保持非退化宽度。
4. ns-3 上学到的服务分支是否只适用于仿真，服务门在公开数据是否长期为零。

## 6. 外部检索饱和检查

- 第一批检索覆盖“服务曲线可辨识性、随机有效服务、可微最小加、网络演算异常检测、共形 PINN”，补齐了服务反演、平滑算子和时序校准三类缺口。
- 第二批检索覆盖“网络演算与共形、可微网络演算、机器学习服务曲线、近期服务模型反例”。新增 TAILING 只补充了逐包时延分位数所需观测；其余结果是特定时间敏感网络服务模型扩展，未新增适用于三源数据的字段或梯度机制。
- 连续两批没有出现能从 GeNIS/TQH 单端流统计恢复可验证服务下界的方法。继续扩展检索不会改变当前数据合同，达到停止条件。

## 7. R3 晋级结论

| 候选 | 裁决 | 允许声称 | 禁止声称 |
| --- | --- | --- | --- |
| 完整“到达包络 + 服务下界 + 积压/时延界” | **否决公开数据晋级；只留 ns-3 诊断** | ns-3 受控条件下的经验有效服务覆盖与有限窗口边界 | GeNIS/TQH 上的链路服务、最坏积压或最坏时延保证 |
| “多尺度条件到达包络 + 校准越界风险” | **降级进入一次筛选实验** | 数据条件下的经验到达超额、覆盖率、检测非劣或跨条件收益 | 完整网络演算、确定性安全保证、服务能力恢复 |

下一步只执行 `r3-minimum-experiment-contract.md` 中的降级筛选。若其公开检测收益、覆盖或梯度门禁任一失败，R3 整体退出第三章主线，不再继续调参。
