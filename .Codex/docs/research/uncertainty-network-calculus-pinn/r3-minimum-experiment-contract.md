# R3 最小实验合同：校准多尺度到达包络 PINN

## 1. 合同状态与边界

- **状态**：`downgraded / ready_for_one_bounded_screening`。
- **筛选对象**：不确定性感知的多尺度条件到达包络，以及其到生成式检测表征的受控连接。
- **不再筛选**：GeNIS/TQH 上的学习服务曲线、积压上界、时延上界或确定性最坏情况保证。
- **完整网络演算用途**：只在 ns-3 独立诊断中验证，不作为公开数据检测输入，不参与本轮路线胜负。
- **终点**：只允许一次候选预算、一个预注册配置、种子 42、最多 200 个优化步。未通过本合同即退出第三章主线，不开展无边界调参。

## 2. 研究假设

在公开流量缺少服务侧观测时，用历史分组到达量预测**同时覆盖多个时间尺度**的条件上包络，并用独立开发分区校准其错覆盖率，再把“当前到达相对校准包络的超额距离”作为受置信门控的物理软令牌，可能降低跨加密条件的良性误报；该收益应超过单纯增加历史字段或普通分位数特征带来的收益。

## 3. 冻结数据合同

### 3.1 样本和窗口

1. 继续使用共享 B0 的候选训练清单：GeNIS `3,973` 条、TQH-C2 `3,606` 条、ns-3 `2,421` 条，总计 `10,000` 条，样本顺序和二分类标签不变。
2. 新建只读的 `r3_arrival_side_view_v1`，以 `sample_id` 一一连接共享 B0，不覆盖现有制品。
3. 每个可用样本从原始包或合法窗口重建连续四个 `0.1` 秒网络层字节控制体。三个历史窗预测第四窗；同时形成 `0.1`、`0.2`、`0.4` 秒三个尾部累计尺度。
4. GeNIS 必须从原始 PCAPNG 重建，不得直接把 HERA 重复行当控制体。TQH-C2 从 `packet_observations.parquet` 按 `parent_session_id` 重建。ns-3 复用连续四窗口真值。
5. 不能唯一连接原始包、跨越标签转换、窗口不连续或包长口径不明的样本置 `physics_available=0`，保留原共享 B0 分类样本但不计算物理损失。
6. 四个相邻窗口必须与完整会话、捕获或仿真运行一起进入同一分区。不得把相邻窗口拆到训练、校准和评价集合。

### 3.2 字段角色

| 字段 | 用途 | 是否进入普通分类提示 | 约束 |
| --- | --- | --- | --- |
| 八个公共字段及八个缺失掩码 | 共享 B0 分类输入 | 是 | 与既有制品逐字节一致 |
| 三个历史窗的网络层字节和包数 | 到达包络头 | 否，先转为物理表征 | 地址、端口、绝对时间、来源名不可见 |
| 三个物理尺度与有效窗掩码 | 包络尺度和缺测门 | 否，先转为物理表征 | 固定为 0.1/0.2/0.4 秒 |
| 第四窗累计字节 | 包络训练与校准目标 | 否 | 推理时只用于计算当前越界，不可预看未来 |

### 3.3 校准与评价划分

1. 模型训练只读候选训练清单；包络校准使用冻结开发分区中的完整独立组，不使用最终测试。
2. 校准组和筛选评价组按 `allocation_group_id` 稳定哈希互斥，比例固定为 1:4。GeNIS 以原始捕获与攻击步骤为组，TQH-C2 以完整 cell/capture 为组，ns-3 以完整运行为组。
3. TQH 留一 profile、GeNIS 未触碰测试、未知攻击、哑铃与停车场拓扑都不用于本轮选温度、覆盖率、阈值或步数。
4. 若任一来源没有至少 20 个独立校准组，则不报告该来源的有限样本覆盖主张，只报告探索性经验覆盖并触发降级标记。

## 4. 方法定义

### 4.1 分组累计量

设第 `t` 个 0.1 秒窗口内观测到的网络层字节增量为 `x_t >= 0`，历史为 `h_t=(x_{t-2},x_{t-1},x_t)`。对尺度集合 `K={1,2,4}`，第四窗结束时的尾部累计到达定义为：

```text
A_t(k) = sum_{j=0}^{k-1} x_{t-j},  k in K.
```

这是有限窗口累计量，不冒充无限时域到达曲线。实际实现同时保留包数、最大包长和空窗掩码，用于分组化审计。

### 4.2 单调条件包络头

历史编码器输出三个实数 `u_1,u_2,u_3`，通过非负增量参数化得到：

```text
d_m = softplus(u_m)
alpha_hat_t(k_m) = sum_{j=1}^{m} d_j,  k_m in {1,2,4}.
```

该参数化保证尺度增大时包络不下降。它只是一种本课题的有限尺度修改，不照抄任何论文中的连续网络演算公式。

训练期包络损失采用预注册分位数 `q=0.9` 的针球损失，并加入宽度与单调退化控制：

```text
L_env = mean_m pinball_q(A_t(k_m) - alpha_hat_t(k_m))
L_sharp = mean_m alpha_hat_t(k_m) / (A_scale(k_m) + eps)
L_env_total = L_env + lambda_sharp * L_sharp.
```

`lambda_sharp` 只用训练和开发组选择一次，禁止根据最终测试调整。`L_sharp` 防止包络无限放宽，但不能单独证明覆盖有效。

### 4.3 多尺度同时校准

冻结模型后，在完整校准组上计算单组非一致分数：

```text
r_g = max_m ((A_g(k_m) - alpha_hat_g(k_m)) / (s_g(k_m) + eps)).
```

其中 `s_g(k_m)=softplus(v_g(k_m))+eps` 是只由历史和缺测掩码预测的非负尺度。取组级拆分共形分位数 `Q_0.9`，得到同时校准包络：

```text
alpha_plus_g(k_m) = alpha_hat_g(k_m) + Q_0.9 * s_g(k_m).
```

该最大分数是本课题对三尺度同时覆盖的修改。覆盖语义只对与校准组交换的完整组成立；跨 profile 只报告经验覆盖，不宣称理论保证。

### 4.4 可微越界距离

对三个尺度的归一化越界 `e_m`，采用有限集合软最大：

```text
e_m = (A_t(k_m) - alpha_plus_t(k_m)) / (A_scale(k_m) + eps)
E_tau = tau * log(sum_m exp(e_m / tau)).
```

对 `M=3` 个候选有：

```text
max_m e_m <= E_tau <= max_m e_m + tau * log(M).
```

因此温度 `tau` 的最坏平滑偏差可显式审计。预注册 `tau=0.1`，只在消融中与硬最大比较，不依据测试重新选择。

### 4.5 不确定性门与物理软令牌

定义确定性可观测门 `g_obs`：四窗口连续、包长口径一致且历史完整时为 1，否则为 0。定义停止梯度的校准门：

```text
g_cal = stop_gradient(exp(-mean_m s_t(k_m) / (A_scale(k_m) + eps)))
g_t = g_obs * clip(g_cal, 0, 1).
z_phys = g_t * W_phys [E_tau, e_1, e_2, e_3, alpha_plus, s, masks].
```

`z_phys` 经零初始化投影成为物理软令牌，并连接到与普通监督 Qwen 相同的生成表征。分类梯度可更新 `W_phys` 和历史编码器，但不能修改共形分位数、可观测门或校准门。服务侧字段不进入 `z_phys`，避免“只有 ns-3 有服务真值”成为来源捷径。

### 4.6 ns-3 完整网络演算诊断

该诊断与公开检测训练分离：

1. 新增多档常速探测、交叉流量、包长和重复种子场景。
2. 用成对累计到达与离开估计有限窗口经验服务下界，并报告目标违约率、置信区间和分组化修正。
3. 验证可微最小加或上确界的数值偏差、梯度与硬算子一致性。
4. 诊断输出不得成为本轮分类特征，也不决定公开数据阈值。

若没有新增率扫描，该诊断标记为“未执行”，不得用现有攻击场景替代。

## 5. 四组消融

| 组别 | 包络 | 校准 | 连接任务表征 | 责任 |
| --- | --- | --- | --- | --- |
| A | 训练组固定经验 0.9 分位包络 | 否 | 固定越界特征 | 确定性弱基线 |
| B | 学习型单调可微包络 | 否 | 是 | 判断学习包络与可微越界是否有效 |
| C | 学习型单调包络 | 是 | 否 | 判断覆盖与紧致度，不允许改变检测输出 |
| D | 学习型单调包络 | 是 | 是 | 完整降级 R3 候选 |

普通监督 Qwen、仅状态监督、标准 PINN、HGB、XGBoost 和 DistilBERT 是外部基线，不计入四组消融。

## 6. 公平比较

1. D 组的物理软令牌含共享 B0 之外的历史到达信息，故**不能直接复用既有 HGB、XGBoost 和 DistilBERT 数字作为同信息预算比较**。
2. 必须增加等信息对照：向 HGB、XGBoost、DistilBERT 和普通监督 Qwen 公开相同的历史累计量、掩码、校准包络与越界向量，但不提供物理损失或受控软令牌。
3. 既有共享 B0 数字仍保留，用于量化新增历史信息本身的收益；只有超过等信息对照的差异才能归因于 R3 的训练与连接机制。
4. 所有模型使用相同训练组、校准组、评价组、标签、早停与阈值。分类阈值只能在开发组冻结。

## 7. 必须记录的诊断

### 7.1 梯度与反事实

- 每个非空物理批次记录 `||grad L_env -> history_encoder||`、`||grad L_task -> W_phys||` 和两者夹角。
- 至少 95% 的可用批次中，上述两个范数必须有限且严格大于数值零阈值；阈值由机器精度和梯度缩放预先固定。
- 对历史最后一窗字节数增加 5% 的反事实扰动，`alpha_hat` 不得下降，越界距离不得反向减小。
- 将 `physics_available` 强制为 0 后，D 组输出必须退化为普通监督 Qwen；不得残留来源、路径或标签信息。
- 分类损失对 `Q_0.9`、`g_obs` 和 `g_cal` 的梯度必须为零。

### 7.2 平凡解

- 包络非负且按尺度单调。
- 包络、尺度和越界均为有限值。
- 校准覆盖改善不能以平均归一化宽度超过 A 组为代价。
- `g_t` 不能在全部公开样本恒为 0 或恒为 1；按来源、标签和缺测模式报告分布。
- 不能用来源名、profile、场景、时间戳、地址、端口或标签预测门值。

## 8. 指标

### 8.1 检测

- 宏平均 F1、良性误报率、攻击召回率、每条件混淆矩阵。
- GeNIS 按攻击家族、时间块和未知子类型报告。
- TQH-C2 按完整 profile/cell 报告，并以留一加密条件为主。
- 组级自助法置信区间，不把窗口当独立样本。

### 8.2 物理与校准

- 三尺度同时经验覆盖率、每尺度覆盖率、最差组覆盖率。
- 平均与 90 分位归一化包络宽度。
- 越界率、正越界幅度、软最大与硬最大偏差。
- 物理可用率、门值分布、梯度范数和反事实单调通过率。

### 8.3 成本

- 训练时间、推理吞吐、峰值显存或内存、每样本物理侧视图构造时间。
- 与普通监督 Qwen 和等信息对照分别比较，不把树模型分类吞吐与自由生成吞吐作无条件等价解释。

## 9. 一次性通过门槛

四项必须同时满足：

1. **检测非劣**：D 相对普通监督 Qwen 的宏平均 F1 组级置信区间下界不低于 `-0.005`。
2. **公开收益**：在预注册的 TQH 留一条件或 GeNIS 未知/时间前向评价中，D 至少满足一项：宏平均 F1 绝对提高 `>=0.01`，或良性误报率绝对降低 `>=0.02`，且组级置信区间不跨零。
3. **覆盖与紧致度**：三尺度同时覆盖的置信区间包含目标 `0.90`，平均归一化宽度不大于 A 组；最差条件覆盖必须单独报告。
4. **机制归因**：D 优于 C，且 D 的检测收益不能被等信息 HGB/XGBoost/DistilBERT 或普通 Qwen 对照完全解释；梯度、反事实和无泄漏门禁全部通过。

若 D 未超过等信息 XGBoost 的主检测指标，只能声称“生成式模型中的校准物理表征收益”，不能声称总体检测性能优于传统强基线。

## 10. 否决规则

出现任一项即停止 R3，不做第二轮结构或学习率修复：

1. GeNIS/TQH 的原始包无法与冻结 `sample_id` 无歧义连接，或有效四窗口覆盖低于 80%。
2. D 的收益在等信息对照中消失，说明增益来自额外历史而非物理机制。
3. 包络通过无限变宽取得覆盖，或校准门在公开数据塌缩为常数。
4. 物理损失有下降但任务表征梯度为零，或越界扰动不改变生成输出。
5. 只在 ns-3 改善服务、队列或边界，公开检测与校准无收益。
6. 任何最终测试、来源名、profile、场景或标签参与包络、门、温度、分位数或阈值选择。
