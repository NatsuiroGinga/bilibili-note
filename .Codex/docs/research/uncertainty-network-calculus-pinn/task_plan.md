# 不确定性校准与可微网络演算边界 PINN 文献核验计划

## 目标

按六阶段文献综述流程判断 R3 是否能形成面向 GeNIS 2025、TQH-C2 与 ns-3 的可实现、可微、可证伪候选方法，并输出升级、降级或否决裁决以及可直接交给实验实现的最小合同。

## 研究问题与预期决策

- 研究问题：在公开流量只提供部分端到端观测、ns-3 才提供队列真值的条件下，能否联合学习条件到达包络、保守服务下界与校准置信度，并通过可微网络演算边界改善生成式恶意流量检测的跨加密条件迁移、良性误报控制或物理状态辨识？
- 升级：服务或等价有效服务状态可辨识，可微边界对物理分支参数有非零梯度，完整方法相对标准 PINN 检测非劣且至少一项预注册边界或泛化指标改善。
- 降级：到达包络可辨识而服务曲线不可辨识时，只保留单边到达超额或经验风险包络，不再称完整网络演算边界方法。
- 否决：公开数据无法提供或可靠预测服务侧信息，边界只由输入离线计算而没有训练梯度，或收益仅来自额外字段、数据源捷径或事后选阈值。

## 纳入标准

1. 确定性、随机或统计网络演算中的到达曲线、服务曲线、积压或时延边界一级来源。
2. 可微最小加卷积、上确界、最大值、分位数、风险包络或平滑近似及误差界一级来源。
3. 部分可观测队列、服务能力或网络性能反演，且明确观测量、隐状态与可辨识条件。
4. 不确定性量化、校准、保序覆盖或分布漂移下的风险控制，且能约束边界置信度而非只输出分类置信度。
5. 网络异常检测、流量建模或 PINN 中把上述机制连接到任务表征的工作。
6. 允许经典基础论文，不设置机械年份下限；近期应用与校准论文优先核验。

## 排除标准

1. 仅题名相似、无网络演算或物理边界实质内容。
2. 只有摘要、宣传页或二手转述，且无法取得全文。
3. 只做离线网络规划或调度，不能迁移到样本级可微训练且不提供理论承重证据。
4. 只讨论分类概率校准，无法约束到达、服务、积压或时延边界时仅作旁证，不作核心方法依据。
5. 公式依赖推理时不可观测且无法由独立真值验证的变量。
6. 与已登记原件或 Zotero 条目重复的版本，保留主版本并记录重复关系。

## 证据要求

- 核心方法必须读取全文，并记录页码、章节、公式、图或表位置。
- 自动提取文本只用于定位；公式、定理、实验数字和失败边界回到原 PDF 复核。
- 论文原结论、本课题推论、可迁移机制、不可直接声称内容和待验证假设分开记录。
- 发现可能有用且仓库缺失的论文，核验标识符后从合法一级来源下载到 `raw/papers/pinn/network-calculus-boundary/`，Zotero 去重导入并关联 PDF，在 `wiki/papers/pinn/network-calculus-boundary/` 写全文笔记。

## 承重问题

1. GeNIS、TQH-C2 和 ns-3 各自能直接观测哪些累计到达、离开、丢弃、方向、时延、容量或队列量？
2. 不知道链路容量、调度器和交叉流量时，服务曲线是否可辨识；若不可辨识，什么收窄形式仍诚实可用？
3. 平滑最大值、最小值、上确界和最小加卷积的近似误差如何随温度和窗口长度变化？
4. 校准对象应是协议置信度、状态预测区间、边界覆盖率还是越界概率；校准集如何避免最终测试泄漏？
5. 物理边界如何进入同一个生成式检测模型，并保证分类损失与物理损失均有清晰梯度路径？
6. 如何区分攻击导致的到达超额、正常突发、服务能力下降和字段缺失？

## 泄漏与公平门禁

- 不得使用攻击标签、数据源名称、采集配置、场景编号、仿真真值或最终测试统计构造包络、服务曲线、置信度或阈值。
- 校准集必须来自冻结训练或开发分区，不能在 GeNIS 未触碰测试或 TQH 留出条件上调温度、覆盖率或越界阈值。
- 若新增字段进入分类器输入，则所有普通检测基线必须在同一信息预算上重跑；若字段只在冻结物理分支内部使用，必须验证分类视图逐字节不变。
- ns-3 隐藏真值只能训练或评价物理分支，不能成为公开数据推理输入。

## 停止条件

- 承重机制与字段均有一级正证据和反证边界。
- 本地全量筛查完成，核心论文均有全文证据位置。
- 针对剩余缺口连续两个外部检索批次不再产生新机制、可观测字段或失败条件。
- 最小数据合同和 A/B/C/D 归因不再变化。
- 若服务曲线可辨识性被否决，立即收窄或否决，不为维持题名继续凑文献。
