# R3 文献综合与路线裁决

## 1. 结论

**R3 的完整原案不能在当前三源协议上成立。** 文献和字段审计共同否决了“从 GeNIS/TQH 的单端聚合流量学习保守服务曲线，再声称积压或时延保证”的路线。服务曲线反演需要主动率扫描、成对到达－离开轨迹或额外拓扑观测；公开数据没有这些信息。

R3 只保留一个有明确终点的降级候选：

> **多尺度条件到达包络 + 组级同时校准 + 不确定性门控物理软令牌**

该候选仍属于物理信息训练，因为模型预测的包络状态进入物理越界残差，物理损失和检测损失都能沿明确路径更新参数；但它只能称为“网络演算启发的有限窗口到达约束”，不能称完整网络演算服务或最坏性能保证。

## 3. 为什么完整 R3 被否决

### 3.1 公开数据只有到达侧

- GeNIS 原始 PCAPNG 和 TQH-C2 包观测能提供分组时间、长度与方向，因此可以形成累计到达序列。
- 两者没有同一瓶颈的累计离开、链路容量、调度器、交叉流量和队列状态。
- 现有共享 B0 进一步压缩为单条流的八个统计量，连连续历史都没有直接保留。

在这种条件下，低服务能力与高突发到达可产生相似流级统计。任何单点“服务率”都可能只是相关性预测，不是可验证服务下界。

### 3.2 文献不能替代缺失观测

- Burchard 等的有效服务曲线给出概率语义，不给部分观测反演方法。
- Liebeherr、Lübben、Rizk 与 Fidler 的服务估计依赖主动包列、率扫描、成对路径观测或网络层析条件。
- Habib 的被动队列反演需要正确输出链路、容量或服务时间。
- QuASI 说明粗粒度计数通常只能确定兼容轨迹集合，不能唯一恢复队列路径。
- DeepTMA 的学习器只在已知合法解析模型中选择；机器学习不能把未知服务预测自动变成有效保证。

### 3.3 分组化进一步收紧主张

Jiang 的两项反例表明，忽略最后一比特和实际包长语义可同时破坏服务、输出、积压、时延和串联边界。当前共享 B0 的 ns-3 行甚至缺少包长极值，因此完整边界必须回到逐包或明确包长真值，不能只用平均字节率。

## 4. 保留下来的理论组合

### 4.1 理论一：多尺度条件到达包络

Bouillard 等的工作支持在没有服务曲线时用多时间尺度到达约束发现突发异常；Paxson 与 Hohn 的反证要求放弃普适泊松和单尺度平均假设。本课题不采用固定令牌桶，而让历史编码器输出按尺度单调的非负包络增量。

### 4.2 理论二：组级同时校准与不确定性门控

Podina、Yu、Stankevičiūtė 和 Gibbs 的证据共同限定了校准方式：

1. 校准在模型冻结后进行；
2. 完整流、会话或仿真运行是分区单位；
3. 用三个尺度最大非一致分数实现同时覆盖；
4. 覆盖率和区间宽度必须一起报告；
5. 跨加密条件只报告经验覆盖，不把总体覆盖写成逐条件保证。

校准宽度形成停止梯度的门值。这样检测损失不能通过操纵置信度来关闭物理约束。

### 4.3 计算桥梁：有限候选软最大

Cuturi 与 Mensch 支持用平滑最小或最大获得可微动态规划。R3 只借用计算原则，并自行使用三个有限尺度的 `log-sum-exp`，其平滑偏差上界为 `tau * log(3)`。这解决梯度问题，不改变到达包络的经验语义。

## 5. 本课题的原创修改边界

以下组合不是对任一论文公式的照抄：

1. 以非负增量参数化三个时间尺度的条件到达包络，显式保证尺度单调。
2. 以“组内三个尺度最大标准化残差”构造单个共形分数，实现有限尺度同时校准。
3. 用校准宽度生成停止梯度的物理可靠性门，防止分类任务操纵置信度。
4. 将校准越界距离压缩为物理软令牌，连接同一个生成式检测表征，并预注册梯度和反事实单调门禁。
5. 对服务侧缺测采用失败关闭：公开数据不产生服务令牌，ns-3 服务诊断不进入分类器，避免来源捷径。

这些内容目前仍是**待实验验证的方法假设**，不能提前写成已经有效的论文贡献。

## 6. 与第三章的关系

### 6.1 不能直接作为第二理论的原因

完整“不确定性校准 + 可微网络演算边界”题名会暗示公开数据具有服务、积压或时延保证，现有证据不支持。若直接写入第三章，会在答辩中暴露三处硬伤：服务真值缺失、仿真到真实外推、连续流公式忽略分组化。

### 6.2 晋级后可承担的工作量

若一次性筛选通过，降级 R3 可以作为第三章中的第二协同机制，理论工作量包括：

- 有限窗口累计量与尺度单调包络定义；
- 三尺度同时校准命题及覆盖适用条件；
- 软最大近似误差界；
- 不确定性门控与梯度阻断；
- 平凡解、缺测退化和无泄漏命题；
- A/B/C/D 消融、等信息强基线、覆盖－紧致度和效率实验。

建议命名应避免“完整网络演算保证”，可用：

> **基于物理一致性与校准到达包络的恶意流量检测训练方法**

若筛选失败，R3 只保留在第二章相关理论、第三章方案否决依据或实验讨论中，不再承担章节标题。

## 7. 一次性实验裁决

执行顺序固定为：

1. 对冻结的 10,000 条候选清单重建 `r3_arrival_side_view_v1`，先过 80% 有效四窗口覆盖和无歧义连接门禁。
2. 不训练模型，先验证固定包络、组级校准、覆盖－宽度和软最大数值误差。
3. 只运行 A/B/C/D 四组、种子 42、最多 200 步。
4. 与普通监督 Qwen 及同信息预算 HGB、XGBoost、DistilBERT、Qwen 对照。
5. 同时通过检测非劣、公开收益、覆盖紧致度和机制归因四个门槛，才晋级正式种子和测试。

详细阈值以 `r3-minimum-experiment-contract.md` 为唯一执行依据。
