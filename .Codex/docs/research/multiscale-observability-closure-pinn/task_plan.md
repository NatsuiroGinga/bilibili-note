# 自适应多尺度与可观测性闭合控制体 PINN 文献核验计划

## 目标

按当前一级证据门禁完成 R1 全文调研，判断“自适应尺度选择、受约束不可观测通量闭合与跨尺度守恒一致性”能否形成可实现、可微、可证伪的候选方法，并输出是否进入约一万条、200 步、种子 42 筛选实验的明确裁决。

## 任务边界

- 原件层只新增，不修改、覆盖、重命名或删除已有 PDF。
- 先检查本地原件、Zotero 和既有笔记，再联网补充一级来源；发现可能有用的论文必须完成真实性核验、合法全文获取、Zotero 去重导入、PDF 附件关联和结构化笔记。
- 每批处理 2 篇；完成笔记、方向索引和 Zotero 回链后立即记录检查点。
- 首轮五批十篇只是核心语料，不是篇数上限；完成后必须系统筛查 `raw/papers/pinn/`、对应 wiki 与 Zotero，再按承重机制缺口补充全文。
- 自动提取文本只作定位辅助；关键公式、实验数字、消融与结论必须回到原始 PDF 页码或章节核验。
- 不修改实验代码、冻结数据、两份恢复文档或服务器环境；本轮只形成研究合同与实验设计输入。

## 冻结研究责任

1. **尺度责任**：根据历史流量变化与字段可用性选择有效时间尺度，门控不得读取标签、场景、来源或仿真真值。
2. **闭合责任**：对公开数据不可观测的离开、丢弃与队列状态建立受非负性、容量、历史因果性和幅度边界约束的预测头，禁止闭合量自由抵消全部残差。
3. **一致性责任**：细尺度状态变化、通量与边界项应能重构粗尺度变化，并明确缺测时的置信度降级。
4. **检测责任**：所有物理状态必须通过可微路径影响同一个生成式检测模型；仅改善离线残差不足以升级为章级方法。

## 每篇强制提取项

1. 准确书目信息、稳定标识符、Zotero 条目键和原件路径。
2. 原文页码或章节、方程语义、状态变量、边界条件与参数梯度路径。
3. 时间或空间尺度如何定义、选择和聚合，是否存在信息泄漏或事后选尺度。
4. 可观测字段、潜在状态、闭合量、训练真值及推理期输入。
5. 闭合项的约束、可辨识性、零空间与自由抵消风险。
6. 跨尺度一致性、量纲和归一化假设。
7. 论文原结论、本课题可迁移机制、不能直接照搬之处和待验证假设。
