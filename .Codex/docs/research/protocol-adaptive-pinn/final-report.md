# R2 协议自适应多动力学 PINN 最终文献综合与执行裁决

日期：2026-07-30  
研究阶段：第一创新点理论筛选  
最终裁决：**NO-GO，不启动 R2 数据重建或主实验。**

## 结论

文献证据已经饱和，R2 的计算图与可证伪消融可以冻结，但现有数据仍不满足启动条件。

- **可冻结的方法**：共享队列守恒常开；TCP/普通 UDP 专属专家受固定硬适用掩码控制；软强度只来自独立校准的协议置信度；攻击分类损失不能更新路由器或校准器；低置信、QUIC 和未知协议回退共享守恒。
- **不可成立的当前实验**：共享 B0 无协议字段；GeNIS 扩展字段尚未一对一回接且部分单位未闭合；TQH-C2 存在协议—标签—采集配置捷径；历史 ns-3 制品只有 UDP，新 TCP/UDP 脚手架没有 TCP 内部状态真值或双构建发布证据。
- **QUIC 裁决**：包长、方向、时序和部分首部位可见，但现行 RFC 允许旋转位禁用与固定位随机化，且不支持被动丢包或关键拥塞状态恢复。第一轮不能建立 QUIC 专属专家。
- **归因规则**：C 是主方法；`C-A` 才是物理路由贡献，`B-A` 是协议直接信息贡献，`D-B` 是同额外信息下的路由增量。若只有 B/D 改善而 C 不改善独立状态真值，R2 必须否决。

## 证据矩阵

| 承重问题 | 一手证据结论 | 对 R2 的约束 |
| --- | --- | --- |
| 条件专家是否可用于 PINN | GatedPINN、MoE-PINN、APINN 等说明条件专家可训练，但自由门控会漂移、坍缩或受初始化影响 | 专家职责先冻结；负载均衡不等于协议适用性 |
| 错误物理能否由优化自动修复 | Physics-Fails、PINN 失败与残差不足性论文显示低残差不保证正确状态 | 错误协议关闭，未知回退；必须报告独立状态误差 |
| 部分观测能否恢复隐藏状态 | Partial-Physics-Neural-ODE、HFM、RPLPO、QuASI 均要求可辨识性、绝对锚点或独立真值 | 八字段流记录不能自动恢复 TCP/QUIC 隐状态 |
| 已知与未知动力学如何组合 | LHM、NMOE、显式闭合支持共享已知部分与学习增量分责 | 共享守恒常开；协议增量先用 ns-3 真值训练并冻结 |
| 离散模式如何保持语义 | Neural Hybrid Automata 证明软混合可拟合轨迹但不能恢复真实模式 | 硬适用掩码固定，分类损失不训练协议路由 |
| TCP 方程能否直接移植 | TCP/AQM、CUBIC、DCTCP 模型绑定容量、反馈时延、丢包和具体拥塞控制状态 | 不从公共聚合字段手写通用 TCP 残差 |
| 队列能否由抓包唯一反演 | Habib 只估计假设条件下的期望等待/队列；QuASI 只判相容性 | 抓包估计不充当真实队列轨迹，ns-3 真值不可省略 |
| QUIC 被动状态是否可见 | RFC 8999/9000/9001/9287/9312 限制线图像，允许旋转位禁用和固定位随机化，并否定被动丢包测量 | QUIC 只作弱识别与未知回退，不建第一轮专家 |
| 同分布校准能否外推 | Guo 2017 支持留出集温度缩放；Ovadia 2019 证明漂移下可失效 | 独立校准、跨源/留配置/开放协议评价与覆盖率—风险必做 |
| 协议字段是否可能是捷径 | QUIC 分类与 VisQUIC 显示握手、地址、网站和时间漂移会显著影响结果；TQH B 配置协议与标签高度相关 | 禁止地址/配置输入，做平衡子集、去握手、置换和留配置负对照 |

## 冻结方法合同

### 协议范围

- 共享守恒：全部样本常开。
- TCP 专属专家：只对可信 TCP 样本开放。
- 普通 UDP 专属专家：只对可信普通 UDP 样本开放。
- QUIC、ICMP、其他、未知与低置信：关闭全部专属专家，只走共享守恒。
- 若 TCP/普通 UDP 不能同时取得同口径状态真值，R2 降级为共享守恒，不再称为协议自适应多动力学。

### 路由与梯度

$$
c_k=\operatorname{stopgrad}\left(P_{\mathrm{cal}}(p=k\mid x_{\mathrm{proto}})\right),
$$

$$
\mathcal L_{\mathrm{phys}}=
\lambda_s\mathcal L_{\mathrm{shared}}+
\sum_{k\in\{\mathrm{TCP},\mathrm{UDP}\}}
m_k(p)c_k\lambda_k\mathcal L_k.
$$

- `m_k` 是不可训练的固定适用掩码；`c_k` 不读取攻击标签、数据源或采集配置。
- 物理阶段只使用协议监督、ns-3 状态真值和守恒；任务阶段冻结路由、校准、共享模块和协议专家。
- 自动门禁要求 `∂L_cls/∂θ_router=0` 且 `∂L_cls/∂θ_conf=0`。

### A/B/C/D

| 组别 | 分类输入 | 物理结构 | 归因 |
| --- | --- | --- | --- |
| A | `x_common` | 同参数量统一残差 | 基准 |
| B | `x_common+x_proto` | 同参数量统一残差 | `B-A`：协议直接信息 |
| C | `x_common` | 共享守恒 + TCP/UDP 硬路由专家 | `C-A`：R2 主证据 |
| D | `x_common+x_proto` | 与 C 完全相同 | `D-B`：同额外信息下路由增量 |
