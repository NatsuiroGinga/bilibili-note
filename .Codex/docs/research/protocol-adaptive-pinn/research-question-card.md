# 研究问题卡：协议自适应多动力学 PINN

## 研究问题

在 GeNIS 2025、TQH-C2 与 ns-3 三源统一数据协议下，能否通过“共享队列守恒约束 + 协议适用性门控 + 可验证的协议专属动力学残差”，改进生成式恶意流量检测模型的物理状态辨识、跨协议泛化或误报控制，而不损害冻结检测指标？

## 预期决策

- **升级候选**：至少两类协议专家具有可靠字段、真值或可验证边界，并能构造公平、可证伪的筛选实验。
- **降级备选**：共享守恒成立，但只有 TCP 或单一协议具有足够证据，协议自适应只保留为后续扩展。
- **否决**：协议覆盖、字段可观测性或物理真值不足，导致专属残差只能依赖不可得变量或标签捷径。

## 当前证据

- 三源共享预算已冻结，但当前共享 B0 只明确包含 8 个公共数值字段及缺失掩码，尚未确认包含传输协议字段。
- 星型 ns-3 的单尺度有限队列 PINN 已改善状态误差和物理残差，但不证明公开数据检测收益。
- TCP、UDP、QUIC 的控制机制不同，不能把 TCP 拥塞反馈无条件施加于全部流量。

## 缺失证据

1. 三源 TCP、UDP、QUIC/其他协议的真实样本覆盖与协议字段来源。
2. 每类协议在公开数据推理时可得的输入，以及 ns-3 可提供的训练状态真值。
3. 协议条件、多方程或物理专家门控的一级文献证据和已知失败模式。
4. 不超过四项的最小消融及明确的通过、否决门槛。

## 支持条件

- 协议字段来自包头或可信元数据，在加密后仍可观测，且不等同于标签、场景或采集单元。
- 至少一个专属残差包含模型预测状态，对可训练参数具有非零梯度。
- 相对共享守恒 PINN，完整方法在冻结验证上保持检测非劣，并改善对应协议的物理指标或误报指标。
- 同一新增输入与缺失掩码同时提供给普通监督 Qwen、BERT 类和树模型基线。

## 证伪条件

- 三源无法形成可信统一协议字段，或主要评测源中协议覆盖不足。
- 专属公式需要公开数据推理时不可观测、且无法通过训练期状态头可靠辨识的变量。
- 协议门控收益来自协议与标签的捷径相关，而非动力学残差。
- 完整方法不优于共享守恒 PINN，或改善物理指标但显著损害检测与校准。

## 最小下一步

完成三源协议覆盖与字段来源审计；随后只对证据支持的专家构造一个种子、同一候选清单、最多四项消融的筛选合同。
