# R2 最小实验合同可执行性中期裁决

日期：2026-07-30  
证据进度：本地 PDF 全文核验 `8/10`

## 直接裁决

**裁决：计算图可条件冻结，但当前数据状态不允许启动 R2 主实验。**

- 八篇全文证据足以规定“共享守恒常开、协议适用硬掩码、协议置信度软强度、分类损失不训练路由器、未知协议回退”的最小计算图。
- 当前冻结 B0 没有协议字段，GeNIS 的协议与 TCP 状态字段已在候选生成前剥离，现有 ns-3 只生成 UDP。此时启动实验无法区分物理路由、额外协议信息与标签捷径。
- 当前只允许规划 **TCP/普通 UDP 双专属专家 + 其他/未知回退** 的筛选实验。QUIC 在可见字段、独立协议真值和协议状态真值补齐前不得建立专属专家，也不得用 TQH-C2 的采集配置 `profile` 代替 QUIC 识别。
- 本轮八篇论文提供架构、梯度和失败模式证据，没有给出可直接用于聚合恶意流量数据的 TCP、UDP 或 QUIC 专属解析方程。协议动力学必须由 ns-3 同口径真值学习或验证，不能凭论文标题补造。

因此，中期状态是：**方法合同可审查，数据合同未通过，实验执行被硬门禁阻塞。**

## 最小字段合同

### 共同任务输入

所有 A/B/C/D 使用完全相同的冻结共同输入：

$$
x_{\text{common}}=[x_1,\ldots,x_8,m_1,\ldots,m_8],
$$

其中 `x_1...x_8` 是当前 B0 的 8 个公共数值字段，`m_1...m_8` 是对应缺失掩码。`sample_id` 和 `stable_order` 只用于连接、排序与审计，不得作为模型输入。

当前研究记录只保存了“8 个公共字段”的数量，没有保存其准确列名与单位。**启动前必须从冻结制品清单写出准确列名、单位、窗口定义和哈希；缺一项即停止。** 任何字段回接后都不得悄悄改写 A/C 的共同输入。

### 路由与物理分支可用字段

路由字段只进入协议识别、硬掩码和协议物理分支；在 C 中不得直接拼接到分类器。

| 数据源         | 可候选字段                                                                                              | 允许用途                                       | 禁止用途                          |
| -------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | --------------------------------- |
| GeNIS 原始数据 | `Proto`                                                                                                 | 生成 TCP、UDP、其他/未知硬掩码；训练协议置信度 | 在 C 中直接进入分类器             |
| GeNIS 原始数据 | `Loss`、`Retrans`、`TcpRtt`、`SrcWin`、`DstWin`                                                         | TCP 状态或物理残差输入；缺失时显式掩码         | 对非 TCP 样本强制填充为有效物理量 |
| TQH-C2         | `tcp_packet_fraction`、`udp_packet_fraction`、`icmp_packet_fraction`、`other_transport_packet_fraction` | 识别传输族及协议置信度                         | 把 UDP 自动认定为 QUIC            |
| TQH-C2         | TCP 标志比例                                                                                            | TCP 物理分支的可观测辅助量                     | 为 UDP/QUIC 构造不存在的 TCP 状态 |
| TQH-C2         | `profile`、采集配置、场景编号                                                                           | 仅审计与分组                                   | 路由、分类或协议置信度输入        |
| 新 ns-3        | 明确的协议真值、时间窗、到达、服务、丢弃、队列及协议内部状态                                            | 物理预训练、状态评价和路由评价                 | 从攻击标签反推协议                |

### B/D 的公平额外输入

若 C/D 的物理分支使用任何协议字段或协议状态字段，则 B/D 的普通监督基线必须获得同一份可观测字段向量 `x_proto`。B/D 可把它直接拼接到分类器，用于估计协议信息本身的收益。A/C 不得直接把 `x_proto` 暴露给分类头。

字段缺失必须以同一掩码编码；不得让“字段是否存在”隐式泄露数据源、采集配置或标签。

## 最小协议范围

### 第一阶段允许

- **共享守恒**：所有样本常开。
- **TCP 专属残差**：只对可信 TCP 样本开放。
- **普通 UDP 专属残差**：只对可信普通 UDP 样本开放。
- **其他/未知回退**：关闭全部专属专家，只保留共享守恒。

### 第一阶段禁止

- **QUIC 专属专家**：TQH-C2 当前只有 UDP 传输族特征，没有 QUIC 可见首部、版本、旋转位、确认关系、在途字节或探测超时；`profile=B` 不是推理时可用协议字段。
- **ICMP、SCTP、DCCP、ESP、GRE/VXLAN 专属专家**：当前没有同时满足样本量、可见字段、状态真值和公平基线的证据。
- **HTTP、HTTPS、TLS、SSH、FTP、MQTT、DNS、CoAP、RTP、AES、IPv4/IPv6 专家**：这些名称不等同于独立传输动力学模式。

若 TCP 与普通 UDP 仍不能形成至少两个有独立状态真值的专家，R2 直接降级为共享守恒方法，不再称为协议自适应多动力学。

## 方程与状态合同

### 共享守恒

所有协议使用同一有限队列守恒关系。以一个时间窗内统一的包数或字节数计量：

$$
q_{t+1}=q_t+a_t-s_t-d_t,
$$

$$
r_{\text{shared},t}=
\frac{q_{t+1}-q_t-a_t+s_t+d_t}
{\max(1,Q)},
$$

其中 `q_t` 是窗起队列占用，`a_t` 是到达量，`s_t` 是成功服务或离队量，`d_t` 是队列丢弃量，`Q` 是队列容量或统一尺度。包数与字节数不得混用；窗口边界与计量单位必须写入制品清单。

共享损失为：

$$
\mathcal L_{\text{shared}}=
\operatorname{mean}_t\rho(r_{\text{shared},t}),
$$

其中 `ρ` 的具体形式在启动前冻结，A/B/C/D 完全相同。

### 协议专属动力学

第一轮不宣称存在可直接照抄的通用 TCP 或 UDP 解析方程。专属专家采用受真值监督的状态转移残差：

$$
\hat s_{t+1}^{(k)}=
F_{\text{shared}}(\hat s_t,u_t)+
\Delta F_k(\hat s_t,u_t;\theta_k),
\qquad k\in\{\text{TCP},\text{UDP}\},
$$

$$
\mathcal L_k=
\operatorname{mean}_t
\left\|W_k\left(
\hat s_{t+1}^{(k)}-s_{t+1}^{\text{truth}}
\right)\right\|_1
+\lambda_{r,k}\operatorname{mean}_t\rho(r_{k,t}).
$$

- `F_shared` 实现共享队列守恒，不因协议关闭。
- `ΔF_k` 只表示由 ns-3 独立状态真值支持的协议增量，不允许把攻击标签作为输入。
- TCP 候选状态至少需要 `cwnd`、往返时延、重传/丢包和发送/确认速率中的可验证子集；具体集合由新 ns-3 制品和 GeNIS 可见字段交集决定。
- UDP 候选状态至少需要发送率或突发计划、到达率、队列与丢弃的可验证子集；没有发送计划或顺序窗口时不得声称恢复 UDP 专属控制动力学。
- `W_k` 只选择该协议具有真值且公开数据有对应观测路径的状态。无真值状态不得写入主要结论。

在新 ns-3 真值证明 `ΔF_k` 对状态误差无增量前，不得把任何手写 TCP Reno、CUBIC 或 QUIC 方程加入主方法。协议实现和拥塞控制变体必须记录，不能用“TCP”泛称。

## 路由合同

对每个样本，硬适用掩码为：

$$
m_k(p)\in\{0,1\},
$$

只由可信协议身份 `p` 和冻结适用表决定。第一阶段：

| 协议身份                       | TCP 专家 | UDP 专家 | 共享守恒 |
| ------------------------------ | -------: | -------: | -------: |
| TCP                            |        1 |        0 |        1 |
| 普通 UDP                       |        0 |        1 |        1 |
| QUIC、ICMP、其他、未知、低置信 |        0 |        0 |        1 |

软强度为经过校准的协议置信度：

$$
c_k=\operatorname{stopgrad}
\left(P_{\text{cal}}(p=k\mid x_{\text{proto}})\right),
\qquad 0\le c_k\le1.
$$

总物理损失为：

$$
\mathcal L_{\text{phys}}=
\lambda_s\mathcal L_{\text{shared}}+
\sum_{k\in\{\text{TCP},\text{UDP}\}}
m_k(p)c_k\lambda_k\mathcal L_k.
$$

硬掩码不能学习，软强度不能接收攻击标签、采集配置或分类损失梯度。低于预注册置信阈值的样本必须走未知回退，而不是按最大概率强制选专家。

## 梯度阻断合同

第一轮筛选采用最强隔离，而不是端到端自由联合训练：

1. **物理阶段**：只用 ns-3 状态真值、守恒与协议监督训练状态编码器、共享模块、协议专家和协议置信度校准器，不读取攻击标签。
2. **任务阶段**：冻结协议识别、硬掩码、置信度、共享物理模块和协议专家；只训练任务模型读取固定物理表示。
3. **可选复核**：只有第一轮通过后，才允许解冻状态编码器或专家，但路由器和置信度仍永久阻断分类梯度。

必须自动检查：

$$
\frac{\partial\mathcal L_{\text{cls}}}
{\partial\theta_{\text{router}}}=0,
\qquad
\frac{\partial\mathcal L_{\text{cls}}}
{\partial\theta_{\text{conf}}}=0.
$$

若任一批次出现非零梯度、硬掩码被优化器注册、未知样本激活专属专家，整次运行无效，不得报告为 R2 结果。

## A/B/C/D 冻结消融

| 组别 | 公共任务输入       | 协议字段直接进入分类器 | 共享守恒 | 协议专家路由                           |
| ---- | ------------------ | ---------------------- | -------- | -------------------------------------- |
| A    | `x_common`         | 否                     | 是       | 否；使用同总参数量的统一残差基线       |
| B    | `x_common+x_proto` | 是                     | 是       | 否；其余与 A 相同                      |
| C    | `x_common`         | 否                     | 是       | 是；`x_proto` 只在冻结物理分支内部使用 |
| D    | `x_common+x_proto` | 是                     | 是       | 是；物理分支与 C 完全相同              |

为避免把更多参数当作路由收益，A/B 的统一残差网络总参数量与 C/D 的 TCP、UDP 专家总参数量匹配，差异不超过预注册容差；优化步数、种子、候选样本、任务头和停止规则完全相同。

归因固定为：

- `C-A`：协议物理路由相对统一残差的贡献，是 R2 的主证据。
- `B-A`：协议字段直接信息的贡献。
- `D-B`：在同一额外信息条件下增加协议路由的贡献。
- `D-C`：协议字段直接暴露给任务头的附加贡献，只作诊断。

若只有 B 或 D 改善而 C 不改善，结论只能是协议信息或标签捷径有效，**R2 否决**。

## 数据门禁

### GeNIS 回接

- 从原始数据重建 `Proto`、`Loss`、`Retrans`、`TcpRtt`、`SrcWin`、`DstWin` 与样本引用的确定性连接。
- 输出字段来源、单位、缺失机制、转换规则、行数、主键唯一性与文件哈希。
- A/B/C/D 使用同一重建候选、同一拆分和同一缺失掩码；B/D 获得 C/D 物理分支使用的全部可观测额外字段。
- 无法证明一对一连接或重建改变标签/分组边界时停止。

### TQH-C2 捷径审计

- `profile`、场景编号和采集配置只作分组，不进入模型。
- 报告协议族 × 攻击标签 × 采集配置列联表；当前 B 配置中 TCP 全良性、UDP/ICMP 全恶意，必须构造协议—标签平衡或匹配评估子集。
- 设置直接协议字段基线 B、协议字段置换/屏蔽负对照和按采集配置留一测试。
- 若性能主要在不平衡原集改善、在平衡或留一测试消失，则判为标签捷径，R2 否决。

### ns-3 多协议真值

- 至少生成 TCP 与普通 UDP 两种协议，使用同拓扑、队列、负载预算和攻击强度网格；协议实现、TCP 拥塞控制变体、随机种子与窗口全部记录。
- 每个时间窗同时保存共同可观测字段、协议身份、队列起止值、到达、服务、丢弃以及专属状态真值。
- 训练输入只暴露公开数据可对应的字段；隐藏状态只用于物理监督和评价。
- 现有 UDP-only 2,421 条四窗口序列不得伪装成多协议验证集。
- 若 TCP 与 UDP 无法在相同观测口径下形成独立状态真值，停止 R2 并降级为共享守恒。

### QUIC 门禁

只有同时满足以下条件才允许在后续版本新增 QUIC 专家：

- 推理时可观测且非采集配置的 QUIC 识别字段；
- 与普通 UDP 可区分的协议置信度及校准评价；
- 真实或可信仿真的确认、在途字节、往返时延或探测超时状态；
- B/D 普通监督基线获得相同额外字段；
- 未知 QUIC 版本或不可识别 QUIC 有明确共享回退。

缺任一项，QUIC 只进入未知回退，不得写入主方法名称或主要结论。

## 评价指标

### 物理与状态

- 队列守恒残差及其分位数。
- 队列占用、到达、服务和丢弃的相对误差。
- TCP、UDP 各自预注册隐藏状态的归一化误差。
- 每个协议的专家利用率、硬掩码违规数和未知回退率。

### 路由与校准

- 协议识别准确率、宏平均 F1、Brier 分数和期望校准误差。
- 已知协议覆盖率与未知拒识率。
- 置信度分箱内的专属状态误差，检查软强度是否真与适用性相关。

### 任务与泛化

- 沿用现有冻结检测主指标，不在看到结果后更换。
- 至少同时报告 AUROC、AUPRC、宏平均 F1、良性误报率和校准指标。
- 按数据源、协议、攻击族和采集配置分层报告，并做跨源及按采集配置留一评价。

RPLPO 的 Wave 结果表明，任务误差和隐藏状态误差可以相互背离；两类指标不得合并为单一分数。

## 通过与停止条件

### 启动前停止

出现任一情况即不得训练 R2：

- B0 8 个公共字段的准确名称、单位、窗口和哈希未冻结。
- GeNIS 协议字段不能确定性回接，或 A/B/C/D 不能共享同一候选和拆分。
- ns-3 仍只有 UDP，或 TCP/UDP 没有同口径独立状态真值。
- 专属残差依赖公开数据推理时不可观测、且无法由训练期状态头验证的变量。
- TQH-C2 只能通过 `profile` 识别 QUIC。

### 运行无效

出现任一情况，当前运行作废并修复合同后重跑：

- 分类损失对路由器或协议置信度产生非零梯度。
- 硬掩码被学习、错误协议专家被激活或未知样本未回退共享守恒。
- A/B/C/D 的输入、候选、参数预算、任务头、训练预算或拆分不一致。
- 专家利用率坍缩，某个有充分适用样本的专家从未激活。
- 状态单位、窗口或计量口径跨数据源不一致。

### R2 通过

C 必须同时满足：

1. 相对 A，在预注册的适用协议隐藏状态误差上有稳定改善；
2. 冻结检测主指标相对 A 非劣；
3. 在预注册的跨协议泛化、良性误报或校准指标中至少一项改善；
4. 改善在 TQH 协议—标签平衡、按采集配置留一和未知回退检查后仍存在；
5. 路由语义、掩码和梯度审计全部通过。

统计方法、非劣界、种子数和置信区间必须在启动前写入运行配置；当前证据不足以事后指定数值门槛。

### R2 否决

出现任一情况即否决本轮 R2：

- `C-A` 不改善独立状态真值，或冻结检测指标显著退化。
- 只有 `B-A` 或 D 改善，C 不改善。
- `D-B` 的收益在平衡协议—标签或留一采集配置后消失。
- 路由只学到攻击标签、数据源或采集配置，而非协议适用性。
- TCP/UDP 双专家不能通过数据门禁，或专属残差没有非零、稳定的物理梯度。

否决后保留共享守恒主线；协议字段可作为普通监督特征单独报告，但不得包装为物理路由创新。

## 当前最小下一步

1. 冻结 B0 8 字段准确清单、单位、窗口和哈希。
2. 回接 GeNIS 的协议与 TCP 状态字段，并生成 A/B/C/D 共用的可审计候选。
