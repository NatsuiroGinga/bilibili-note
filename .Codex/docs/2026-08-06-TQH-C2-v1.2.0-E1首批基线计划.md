# TQH-C2 v1.2.0 阶段 E1 首批基线计划

## 目标

在最终测试保持未分配、不可见的前提下，冻结仅开发区的完整 capture/cell 分配和 `unknown=0` 口径，使用 E0 允许的 7 个共同字段运行同预算 HGB 与 XGBoost。

## 边界

- 输入仅使用 E0 已核验的 48 个逐单元 Parquet，不同时读取测试床聚合表。
- 禁止地址、端口、连接状态、测试床身份、采集身份和标签派生字段进入输入。
- 不读取 PCAP，不等待 QUIC 600，不分配或读取最终测试。
- 优先复用既有入口；若现有入口不能表达本合同，先报告唯一缺口，不修改生产代码。

## 已处理问题

- 首次物化因默认 `uv` 缓存目录受沙箱限制而失败；改用 `/tmp/uv-cache` 后成功。
- 在线跟踪入口因当前环境缺少 `swanlab` 而在拟合前失败；失败目录保留，随后改用同一公共执行器的本地 CPU 入口，不修改生产代码。
- XGBoost 初次导入缺少动态链接的 `libomp`；复用本机既有运行时后成功，没有安装或变更依赖。
- 公共指标函数只识别字面标签 `benign`，本协议负类为 `non_c2`，故其内置良性误报率为空；困难诊断按混淆矩阵补算，并在报告中明确口径。

## 最终裁决

- **域内门禁通过**：数据、入口、共同预算和结果制品可运行。
- **跨域门禁不通过**：困难域 C 上的恶意召回接近 0，禁止据此开启最终测试。
- **存在强数据生成捷径证据**：多个单字段已达到高宏 F1，删除任一字段最大绝对宏 F1 变化仅 `0.0002183`；未发现禁止字段直接泄漏，但不能把合成模式可分性解释为真实泛化。
