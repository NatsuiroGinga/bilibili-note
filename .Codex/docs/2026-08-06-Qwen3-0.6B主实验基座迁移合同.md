# Qwen3-0.6B 主实验基座迁移合同

- **状态**：已冻结，待完成配置与运行环境审计
- **日期**：2026-08-06
- **适用范围**：第一创新点候选通过后开展的生成式正式实验，以及第四章沿用的主基座实验

## 1. 冻结决策

1. 主实验基座固定为官方后训练版 `Qwen/Qwen3-0.6B`。
2. `Qwen3-1.7B` 不再承担完整正式矩阵，只在方法冻结后承担规模提升验证。
3. DistilBERT 继续承担候选机制筛选、故障定位和快速消融；其结果不得替代生成式主基座结论。
4. 方法冻结后保留至少一个非 Qwen 基座的可移植性验证，具体模型在方法收敛后按显存、许可和任务接口确定。

## 2. 公平比较合同

1. `Qwen/Qwen3-0.6B` 的基础方法、R2 完整方法、各消融和必要对照必须使用相同的数据划分、可见字段、训练预算、生成协议、评价脚本和调参次数。
2. 选择较小基座是为降低完整矩阵成本并缓解强基座的性能天花板，不得人为减少基础方法的训练步数、上下文、参数预算或输入信息。
3. 不读取最终测试集选择模型、检查点、学习率、批大小、阈值或候选机制。
4. 旧的 DistilBERT 候选实验和 `Qwen3-1.7B` 历史实验保留为历史证据，不改名、不覆盖，也不与新主实验混算。

## 3. 迁移步骤

- [x] 冻结主基座身份与实验职责。
- [ ] 核验服务器上的官方模型来源、修订版本、权重摘要和 `transformers` 兼容性。
- [ ] 盘点现有 `Qwen3-1.7B` 配置与入口，列出只涉及模型身份、显存和吞吐的最小迁移项。
- [ ] 建立 `Qwen/Qwen3-0.6B` 基础方法与 R2 方法配置，保持数据和评价合同不变。
- [ ] 先执行一个固定预算的运行时测量，记录峰值显存、吞吐和预计完整矩阵时长；该运行只作资源估计，不作效果裁决。
- [ ] 候选获得 `GO` 后启动 `Qwen/Qwen3-0.6B` 正式多种子矩阵。
- [ ] 方法冻结后只对必要对照在 `Qwen3-1.7B` 上做规模验证，并补一个非 Qwen 基座验证。

## 4. 验收条件

1. 模型身份、修订版本、分词器、量化方式、适配器配置和生成参数进入唯一运行清单。
2. 同组比较除方法变量外保持一致，并保存配置差异收据。
3. SwanLab、本地日志、检查点、逐样本预测、资源指标和统计制品齐全。
4. 恢复文档、实验局部规则和实际配置不得再把 `Qwen3-1.7B` 写成完整正式矩阵的主基座。

## 5. 当前边界

本次冻结只改变候选通过后的生成式主实验基座，不改变正在进行的 DistilBERT 候选裁决、R2 数据合同、物理公式、五组对照、统计门槛或最终测试不可见规则。
