## 3. Zotero 阻塞说明

`zotero_find_and_attach_pdfs` 对 `XXQ64ZGX`、`M8EZZ9S9`、`U4ZMBMEK` 均请求 Web API 用户库后返回 `404 Item does not exist`，即本地库能读到父键，但附件修复器指向的 Web API 库没有这些键。切换到本地用户库上下文后仍复现相同错误。

本轮没有采取“按 DOI 再导入一份父项”的规避方式，因为这会制造重复题录；也没有直接修改 Zotero 数据库。解锁动作是让 Zotero 本地条目先同步到附件修复器所用的 Web API 用户库，或由用户明确授权通过桌面界面附加本地 raw PDF。Dijk 2024 已有 PDF 附件，但 Zotero 索引只返回附件元数据，仍需桌面端重新索引全文。
