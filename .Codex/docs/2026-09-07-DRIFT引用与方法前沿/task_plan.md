# DRIFT-DGA 引用与方法前沿调研计划

## 任务边界

- 调研对象：DRIFT-DGA 2026，arXiv `2605.10436`，数据集 `snsec-net/dga-detection-drift26dsn`。
- 输出范围：本目录的 `task_plan.md`、`notes.md`、`文献综述.md`、`入库清单.md`，以及缺失论文所需的 `raw/papers/` 原件、`wiki/papers/` 全文笔记、方向索引和 Zotero 条目/附件。
- 禁止范围：不修改论文正文、Goal、恢复卡、实验代码或实验数据；已有原件只读，不覆盖或改名。
- 截止口径：检索时间为 2026-09-07；所有在线页面记录访问日期与可见版本。

## 分类合同

- A：正文或参考文献真正引用原论文。
- B：实际使用 DRIFT 数据或其明确派生物，但未规范引用原论文。
- C：只研究相似的 DGA 时间漂移、跨年泛化、未见家族或域泛化，不使用 DRIFT 数据且不引用原论文。
- A/B 只有取得全文并定位页码后才能支撑结论；仅题录或摘要不得替代。

## A/B 全文证据字段

每篇必须记录：全文路径或合法全文 URL、PDF 页码、数据版本、年份划分、重复隔离、家族隔离、目标标签权限、基础模型、机制、指标、结果、随机种子、代码链接与可复现性。缺项写“全文未报告”，不得猜测。

## 停止与裁决条件

- 引用网络多源查询均无 A/B 时，允许结论为零，但必须保存查询式和来源状态。
- A/B 极少时保持样本量原貌，不用 C 类论文填充引用或使用证据。
- 无全文的在线命中只进入候选/阻塞表，不进入方法效果比较。
- “性能天花板”必须同时检查未来年错误、低误报率、未见家族与置信精度；仅凭总体 F1 不成立。
