# E2 SwanLab 多运行恢复修复报告

## 结论

E2 种子 42 的失败不是科学失败，也不是持续凭据失效。直接根因是 SwanLab `0.9.0` 在同一 Python 进程完成 `E2-A` 后，第二次 `swanlab.init` 复用失效的客户端状态并返回 HTTP 401；原入口又把四个变体绑定在同一进程中，且没有已完成前缀的安全恢复路径。

修复后，每个 `E2-A/S/P/X` 使用独立 Python 进程。每次在线初始化前执行 `swanlab ping` 和 `swanlab verify`，只允许结构化的初始化 401 在新进程中重试一次。现有 `E2-A` 必须通过完整制品核验后只读跳过，零步失败的 `E2-S` 才能归档并重建；任何已产生训练证据但不具备合法断点恢复合同的目录都会被拒绝。

## 任务边界

- 只修改 E2 困难域训练入口、正式包装器、对应目标测试和故障手册的 SwanLab 小节。
- 保留已完成的 `E2-A`、失败的 `E2-S` 初始化证据及其云端运行，不读取最终测试集。
- 不修改 DistilBERT、正式 TCP/UDP PINN 专家、QUIC 或其他实验线路。

## 事实与鉴别

- 原运行目录：`runs/e2-hard-domain/e2_hard_domain_seed42-20260807T051339Z-1971/`。
- 原启动证据：`runs/launchers/e2-hard-domain-e2_hard_domain_seed42-20260807T051339Z-1971/`。
- `E2-A` 已完成 `200` 个优化步，云端运行 `ubbcokcy` 状态为 `FINISHED`。
- `E2-S` 在 SwanLab 初始化阶段返回 HTTP 401，只产生 SwanLab 初始化目录，没有指标、检查点、预测或完成摘要；`E2-P/X` 未开始。
- 失败后重新执行 `swanlab ping` 与 `swanlab verify` 均成功，因此不属于持续凭据、工作区权限或连通性故障。
- 仓库同版本历史故障已经记录：首运行 `finish` 后，同一进程第二次 `init` 可能复用失效 HTTP 客户端；既有恢复合同同样要求每个变体使用独立进程。

## 变更内容

- `e2_hard_domain_train.py` 改为一次只接收并运行一个显式 `--variant`，同时要求短时有效的 `--swanlab-gate-receipt`。
- 同一进程第二次 SwanLab 初始化会在调用客户端前以 `multiple_swanlab_runs_in_process` 拒绝，避免再次复用客户端状态。
- 首次初始化 HTTP 401 结构化为 `swanlab_init_unauthorized`，并记录 `stage=tracking_init`、变体、尝试编号和可重试属性；其他初始化错误不套用该重试。
- 正式包装器按 `E2-A/S/P/X` 顺序分别启动新 Python 进程。每次尝试先执行 `uv run --no-sync swanlab ping` 与 `uv run --no-sync swanlab verify`，保存独立日志和原子门禁收据。
- 门禁失败立即停止，不消耗初始化 401 的重试机会。只有命令退出非零、`tee` 成功且根失败码恰为 `swanlab_init_unauthorized` 时，才在新进程中执行唯一一次重试。
- 恢复时重新核对配置摘要、输入绑定、归一化、物理绑定和共同初始权重。
- 已完成变体核对摘要模式、冻结预算、最终检查点绑定、模型键/形状/类型/有限性、优化器参数编号/末步/动量张量、三类随机状态、按冻结间隔生成的完整指标步集合，以及逐样本预测顺序、概率和阈值判定；任一不一致都拒绝跳过。
- 仅当失败收据可证明 SwanLab 初始化 401，且变体目录不存在摘要、指标、检查点、预测和其他训练制品时，才把零步目录原子移动到 `failed-attempts/`。根失败状态同时保存在 `failure-history/`。
- 包装器保存每个变体、每次尝试的门禁日志、门禁收据、训练日志和退出收据，并立即保存管道两端的 `PIPESTATUS`。
- 只有四个变体全部完成后才生成最终汇总与完成状态。

## 回归合同

- 伪 SwanLab 客户端覆盖“首运行完成，若同进程第二次初始化则返回 401”；修复后的断言要求第二次调用在到达伪客户端前被拒绝，客户端初始化次数保持为 `1`。
- 独立测试覆盖首次初始化 401 的结构化失败码和可重试阶段。
- 恢复测试使用可反序列化的真实模型检查点、真实 AdamW 优化器状态、RNG 状态、完整指标步集合与逐样本预测，确认完整 `E2-A` 字节不变，只归档零步 `E2-S`。
- 负向测试确认错误优化器步数、非法 NumPy 随机状态、非有限模型参数、缺失中间指标和已有训练证据都会被拒绝。
- 假 worker 恢复测试覆盖已有 `E2-A` 只读跳过，随后执行 `S1、S2、P1、X1` 四个新进程，确认 `E2-S` 失败归档和最终完成状态。
- 门禁失败行为测试确认只执行一次 `ping/verify`，不启动任何 Python 训练进程，并写出 `swanlab_gate_failed`。
- 历史远端 HTTP 401 是修复前失败证据。按任务约束，本机没有执行 `pytest`，因此不把尚未运行的测试报告为绿色。
