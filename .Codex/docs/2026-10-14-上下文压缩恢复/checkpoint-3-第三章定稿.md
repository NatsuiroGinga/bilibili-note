## 四、方法形态（**成品形态，不写迭代过程**）

方法名 **BCMC（Budget-Constrained Memory Configuration，预算约束记忆配置）**，两个配置量：

- **模块一｜预算切分**：比特预算 $B$ 在年度与类别间的分配（式 3.1–3.3）
- **模块二｜复用配置**：史样本在每轮更新中的使用强度 $m$（式 3.4–3.6）

**共享形式对象**：历史权重 $\lambda = mN/(n_t + mN)$（式 3.5）——**两模块的输出合成同一个标量**。

**模块二含两个维度（已写成设计形态，3.3.3）**：
- **年度维度**：按各年度缓冲块的正例数分配复用次数
- **轮次维度**：每轮实测历史梯度与当前梯度的夹角 $\rho_r$，由一阶条件 $\lambda_r=(1-a^*)/(1-\rho_r)$ 反解该轮权重
