# QUIC 完整动力学数据集审查计划

## 目标

核验公开 QUIC 数据源中，哪些能够可靠恢复或直接提供包号空间、确认关系、丢包、往返时延、在途字节和拥塞控制状态，并判断其是否具有恶意/良性标签、能否用于 R2。

## 阶段

- [x] 阶段一：读取审查协议、仓库规则与既有资料，冻结范围和分级标准。
- [x] 阶段二：检索原始论文、官方数据仓库、作者或机构页面及 IETF 标准。
- [x] 阶段三：去重候选，按 A、B、C 级分类并记录纳入或排除理由。
- [x] 阶段四：取得核心候选全文，逐项核验数据字段、许可、规模和下载状态。
- [x] 阶段五：形成证据矩阵、R2 接入代价、研究空白和最小下载建议。
- [x] 阶段六：落盘综述、论文笔记、索引与 Zotero 状态，并完成文件核验。

## 固定范围

- 时间：重点检索 2020—2026 年；标准、奠基性数据集和持续维护的官方归档不限年份。
- 证据来源：只接受原始论文、官方数据仓库、作者或机构页面和 IETF 标准。
- 停止条件：连续三批检索没有新增 A/B 候选，且关键证据缺口已核验。
- 禁止事项：不下载大体量数据；不以摘要冒充全文；不把 PCAP、密钥或被动推断自动等同于端点拥塞真值；不修改实验代码、论文正文或恢复文档。

## 分级标准

- A：公开数据能够直接提供或可靠重建包号空间、确认关系、丢包、往返时延和在途字节；最好还提供拥塞控制器、拥塞窗口、路径状态或端点事件。由于 qlog 字段多为可选项，A 级仍须逐迹线通过字段完整性门禁。
- B：公开数据只能支持包长、方向、到达时间、部分解密字段、部分 qlog 事件或聚合状态，缺少至少一个完整残差所需核心状态。
- C：不含真实 QUIC、无法公开取得、只有与残差无关的聚合流特征、来源或许可不可核验，或没有可用原始数据。

## 已完成裁决

- 条件 A：QUIC-MedNetCom、QUIC Interop Runner、EPIQ 2020。
- B/B+：H23Q、VisQUIC、CESNET-QUIC22、CESNET-QUICEXT-25、QUIC 旋转位数据集、QUIC 隐蔽信道数据集、QUIC 网站指纹集。
- C：QUICsand、RISE Demonstration Experiment 2、MonroeQL 的公开制品。
- 没有发现同时具备 A 级端点状态和恶意/良性标签的单一公开数据集。
- H23Q 已降为条件备选，不作为当前 R2 启动门槛；获批后只承担外部攻击桥接。

## 停止条件记录

- 新增旋转位数据集和 QUIC 网站指纹集后，重新开始计数。
- 第 1 批：检索“公开 QUIC 数据、qlog、RTT、CWND、在途字节”，只命中既有候选。
- 第 2 批：检索 2020—2026 年 qlog 测量制品和机构仓储，只命中既有候选或工具论文。
- 第 3 批：检索 Zenodo DOI、`QLOGDIR`、`metrics_updated` 和互操作制品，只命中无关结果。
- 连续三批无新增 A/B，且许可、容量、恶意标签、字段可选性和访问限制均已核验，满足停止条件。
