## 公平比较原则

- 不直接比较不同数据集的绝对准确率。
- 每个数据集分别构建训练、同域测试、未见攻击测试；另做跨数据集测试。
- 统一输入序列化、标签粒度、样本上限、随机种子、训练步数和生成预算。
- 报告宏平均 F1、每类召回率、误报率、校准误差、跨域下降和单位 GPU 小时收益。

## 清单外补充

- CICIoT2023：官方数据包含 105 台真实 IoT 设备、33 种攻击、7 个攻击家族和正常流量，同时提供 PCAP、CSV 与处理代码。它比清单中的多项“新协议分类集”更符合恶意流量检测任务，因此纳入主数据集。

## 首轮数据组合

1. GeNIS-2025：企业网络与顺序攻击场景。
2. CICIoT2023：多设备、多攻击类型与极端类别不平衡。
3. HIKARI-2021：加密网页攻击。
4. DEDALE-2025：只做长期 APT 和时间外推补充。
5. CSE-CIC-IDS2018：只保留为历史基线，不用于决定最终方案。

## 效率与成本记录原则

- 数据成本分别记录下载体积、本地与服务器存储、预处理 CPU 时间和上传时间。
- 训练成本记录墙钟时间、GPU 小时、峰值显存、训练令牌数、生成令牌数、吞吐率和因内存溢出而失败的运行。
- 推理成本分别报告模型前向与从流量文件到结果的端到端延迟，不得用排除预处理的数字冒充整体部署效率。
- 租用成本按实验当日单价与实际 GPU 小时换算，不在方法未定时写死供应商价格。
