# PINN 应用论文结构编排分析计划

## 目标

基于至少 6 篇代表性 PINN 原始论文的章节与页码证据，形成可直接指导本课题第三章 28 至 35 页组织设计的结构分析报告。

## 阶段

- [x] 阶段一：读取强制恢复文档、PDF 转换技能、PINN 索引与资料清单
- [x] 阶段二：读取现有 PINN 笔记并选择覆盖六类证据的原始论文
- [x] 阶段三：逐篇核验原始 PDF 的目录、章节责任、公式、算法、理论与实验编排
- [x] 阶段四：形成横向比较、回答三个结构问题并设计两套第三章结构
- [x] 阶段五：执行格式化与最小链接检查，完成交付

## 关键问题

1. PINN 应用论文是否通常需要两个理论支柱？
2. 如何把物理模型与训练机制组成一个自主算法，而不是机械拼接损失？
3. 失败实验应放在正文还是附录？
4. 任务十七通过与失败时，本课题第三章分别如何形成 28 至 35 页的完整论证？

## 证据边界

- 关键结构事实必须回到原始 PDF，以印刷页码、PDF 页码或章节号定位。
- 自动提取文本只用于检索，公式、定理、算法、实验数字与章节标题必须核对 PDF。
- 明确区分原文事实、跨论文归纳和本课题建议。
- 不修改实验代码、两份恢复文档、论文正文或现有论文笔记。

## 遇到的错误

- 首次使用绝对路径并尝试删除后重建过程笔记时，补丁工具拒绝删除；改为仓库相对路径的精确更新后成功。
- 一次 `fd -x printf` 使用了错误占位符；改为直接输出文件名后成功。
- 首次在受限环境执行 Prettier 写回时出现 `EPERM`；确认文件权限正常后，以获批的格式化命令在受限环境外完成写回。
- 首次链接检查误用了 zsh 只读特殊参数 `status`；根因确认后仅将局部变量改为 `link_rc`，复跑通过。
