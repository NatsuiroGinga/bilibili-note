# LAMDA 双玩家速率约束 v2 复筛分析（pooled + 配对翻转）

**分析状态：已完成；`screening_only` 层证据，不是论文正文，不构成新算法有效性结论。**

## 分析问题

在固定 LAMDA Domain-IL MLP、总回放容量 200、年度顺序 `2013→2014→2016→2017` 与训练预算下，检验 v2 修正实现（乘子更新与代理定义按 v1 否决理由重做）后：

1. 双玩家速率约束单臂相对经验回放（ER）是否在不牺牲旧恶意保持的前提下改善 FPR 或修复；
2. 缺口修复＋双玩家联合是否把缺口臂的良性误报压回 ER 水平同时保留其恶意修复；
3. 乘子轨迹是否仍存在 v1 的乘子发散（v1：`lambda_benign` 约 `225.14`，pooled FPR=`1.0` 全恶意塌缩）。

## 筛选层判读（对照统一裁决指标）

通过条件（恢复卡第六节第 5 条）：相对 ER 不牺牲 FPR 与旧恶意保持，且在开发层改善 AP/FNR 或正向修复之一。

- **双玩家单臂：无独立信号。** 修复率低于 ER（0.8318 vs 0.8399）、负向翻转率高于 ER（0.0265 vs 0.0183）、FNR +0.0055；仅 FPR/AP 有第三位小数级改善。机制未实际介入（修复候选=0）。
- **缺口＋双玩家：`不通过 FPR 与旧恶意保持门槛`。** ΔFPR +0.1000、负向翻转率 0.0390 vs ER 0.0183；换来 FNR -0.0117、修复率 0.9244。冲突结构与缺口修复单臂相同，只是幅度略减。
- 与缺口修复四臂运行横向对照：该运行的 ER pooled AP 为 `0.987242653`，v2 为 `0.987102496`——**跨运行 ER 臂非逐位一致**（工具实现版本不同），一切比较只在 v2 组内进行。
- 按合同，本判读只作筛选层排序与实现诊断，不启动封印年评价；候选方向取舍由主代理携本报告交网页版深度研究提出外部建议后裁决。
