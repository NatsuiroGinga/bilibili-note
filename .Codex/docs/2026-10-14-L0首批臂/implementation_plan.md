## 二、臂设计（**五臂，唯一差量可分离**）

| 臂 | 无标签适应 | 决策层 | 隔离的成分 |
| --- | --- | --- | --- |
| `NONE` | 否 | 源标定阈值 | **基线对照**（= E1 的 A 组） |
| `THR` | 否 | 目标年自校准阈值 | **决策层单独**（= E1 的 B 组，已有读数） |
| `BN` | **只改 BatchNorm 统计量**（前向一遍目标年无标签数据） | 源标定阈值 | **表征层的最弱形式** |
| `ENT` | **熵最小化**（TENT 式：只更新 BN 仿射参数，最小化预测熵） | 源标定阈值 | **表征层的主形式** |
| `ENT+THR` | 熵最小化 | 目标年自校准阈值 | **两层联合** |

**设计说明**：
- `BN` 与 `ENT` 的差别是「**只统计对齐**」vs「**统计对齐＋目标函数驱动**」，构成表征层内部的强度阶梯。
- `THR` 与 `NONE` 的差即 E1 已测的决策层作用面，**本批复算确认可复现**后才用作对照。
- `ENT+THR` 检验两层**是否互补**；若它 ≈ `ENT`，则决策层在适应后无额外贡献（如实报）。

**所有臂共用**：同一源期模型（同一 seed 训练一次后冻结权重副本）、同一目标年面板、同一阈值约定
（`np.quantile(良性分数, 1-budget, method="linear")`）、同一评价代码。

## 三、预注册判据（**跑前冻结**）

**主判据**：主表年（2016–2023）上、`0.1%` 预算下，各臂相对 `NONE` 的 **FNR**，
**逐样本配对计数**（`own_only_wrong` 两列），不用聚合均值。

| 观察 | 裁定 |
| --- | --- |
| `ENT` 相对 `NONE`：**多数主表年**配对计数显著更少，且**没有任何一年显著变差** | **实验支持** ⇒ 进 L1 |
| `ENT` 在**任一年显著变差**（配对差为负且超出噪声） | **该年是反例，必须并列报告**；若变差年数 ≥ 半数主表年则**否决** |
| `ENT` ≈ `NONE`（不可分辨） | **否决**，记「无标签适应在本任务上无增益」 |
| `ENT+THR` 优于 `ENT` | 两层**互补**，可作联合机制 |
| `ENT+THR` ≈ `ENT` | 决策层在适应后**无额外贡献**，如实报 |

**辅助判据（不单独决存废，须并列报告）**：
- 1% 预算档的同表读数
- AUROC／AP 的纯排序口径（**E1 已证两种协议下病理不同型**，静态协议的 2025 AUROC 仅 `0.5958`）
- 干净侧代价：源期测试良性上的 FPR
- 逐目标年的**阈值迁移量**（自校准阈值 − 源标定阈值）
- 长度／家族分面（若可得）

**噪音门槛**：配对差的主判据门槛取 `±200`（30,000 量级样本上的保守门）；
**该门槛无文献依据，属任务化设定**，登记于此以免事后追认。

## 六、硬性纪律

1. **先 commit 再起进程**；每完成一臂立即写 `run-log.md` 并 commit。
2. **CSR 稀疏输入**（GBDT 相关）＋ **每臂落盘**；低内存时不启动。
3. **单进程串行**；`os.setsid` 脱离会话；启动前后 `ps` 断言 `0 → 1`。
4. **不写长轮询等待循环**（本会话已有两次事故：空转 150 分钟的 shell、600 秒无进展被判死）。
5. 不跑 `black`；凭据一律走环境变量或既有登录状态，**不得写进脚本／命令／日志／汇报**。
6. 每个数字必须能从结果 JSON 复算。

## 七、阻塞条件（遇到即停并报）
数据缺年或缺分片；MPS 不可用；**空闲内存 < 1 GiB**；某臂在目标年上**无法构造**（例如 BN 统计量不足）。

## 八、执行顺序
`NONE` 与 `THR` 先跑（复现 E1，确认可比）→ `BN` → `ENT` → `ENT+THR`。
**每条臂只给它一次机会**，无方向即记录否决，不为某条臂反复调参。
