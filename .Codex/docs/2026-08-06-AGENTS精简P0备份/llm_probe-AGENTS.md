## 按需规则路由

- 修改、同步或运行 `scripts/` 前，读取 `scripts/AGENTS.md` 和 `.Codex/docs/agents-split/remote-script-execution-contract.md`；正式远程操作只用统一启动器。
- 涉及服务器切换、硬件降级、下载、镜像、资源监测、Rust 物化、生成评测加速或检查工具时，读取 `.Codex/docs/agents-split/llm-probe-operational-contract.md` 的匹配章节。
- 涉及外部制品、远程载荷、任务冲突、TQH-C2、SwanLab 故障、包时间与哈希、冻结合同、模型视图、PINN 指标、TCP 配对或 ns-3 故障时，读取 `.Codex/docs/agents-split/llm-probe-failure-prevention-handbook.md` 的匹配章节。
- 新增需注册的机器学习组件才使用 `architecture-design`；版本控制任务才使用 Git 技能。通用规划、调试、审查和提交流程不在本文件重复。
- 同一缺陷、协议合同或外部依赖连续两次修复仍无可验证进展时，必须停止同类补丁并联网检索解决方案；按版本优先核验官方规范、官方文档、官方源码与问题记录，再核验同行评审论文。检索结论和版本证据写入 `.Codex/docs/`，可能支撑论文的资料还须保存原件和中文笔记；第三次修复必须由新证据形成单一可证伪假设，且不得阻塞不相关实验。

## 服务器、GPU 与凭据（强制）

- 本地根为 `/Users/bilibili/personal/note/thesis/experiments/llm_probe`，服务端根为 `/root/autodl-tmp/thesis/experiments/llm_probe`。生成式主实验基座固定为官方后训练版 `Qwen/Qwen3-0.6B`；`Qwen3-1.7B` 只作方法冻结后的规模提升验证。具体显卡不得成为正确性条件。
- 当前服务器凭据只取自 `GPU_SSH_378`、`GPU_PWD_378` 或既有登录状态；缺失时先 `source ~/.zshrc`。旧变量仅在用户明确指定旧服务器可用时使用。不得输出或持久化密码、地址解析结果和令牌。
- 服务器可能离线、切换或被回收。GPU 训练、推理、生成评估、显存兼容或加速测试前，须告知用户任务、预计时长、显存、开机与费用需求；确认可用后才执行。回收、关机或换址时停止自动重试且不计为科学失败，新服务器先只读核验身份、根目录、磁盘、依赖、源码锁、数据和制品。
- 默认本机执行 CPU 开发、复审、物化、哈希、统计、报告和传统基线；服务器只执行 GPU 工作及其必要加载和日志。例外须有用户明确许可，细则见按需运行合同。
- 磁盘达到 80% 或可用不足 10 GiB 时通知用户；达到 90% 或不足 5 GiB 时停止新增大型文件和下载。

## 正式运行、同步与复审

- 取消与当前实现无关的独立目标测试、只读预检、GPU 冒烟和短步恢复检查。精确目标测试绿灯后，不得因完整测试集、重复检查、格式化或独立复审延迟正式实验；审查并行进行并标记 `review_pending`。若审查发现影响有效性的严重或重要问题，立即停止并作废结果。
- 代码、数据、配置、哈希、设备、SwanLab、标签和运行目录检查必须成为正式包装器的运行时断言，失败即保留日志并结束运行。
- 远程同步只用白名单相对路径和 SHA-256，禁止 `rsync --delete`；同步、环境和恢复遵守远程执行合同。服务器不得保存唯一代码或结果副本。
- 长任务使用唯一运行身份、持久化状态、检查点和日志恢复，不依赖 `screen` 套接字。阶段门禁完成后及时回收源码、配置、清单、日志、检查点和结果。
- 删除前列出精确路径并确认已有本机、公开可重下或私有备份；原始数据、冻结数据、检查点和日志须获用户明确授权。禁止通配符、递归上级目录或删除唯一证据，删除后记录路径与空间变化。

## SwanLab、日志与结果写回（强制）

- 正式 GPU 实验使用 SwanLab 在线模式，项目固定为 `mortiswang/malicious-traffic-llm`，禁止旧项目。唯一运行目录保存配置、环境、数据摘要、控制台与 SwanLab 日志、逐步指标、结果、预测和制品清单；失败也保留状态与原因。
- 每次运行都须核对云端运行、指标点和图表，并记录服务端路径、本地回收路径和运行地址；云端日志不能替代本地原始日志。
- 新实验裁决、确定结果、路径和错误先写 `.Codex/docs/` 详细记录，再更新 `output/第一创新点实验总控.md`；章节关系或长期边界变化还须更新 `output/开题改进交接文档.md`。
- 故障完成根因定位和最小验证后，将可复用的触发条件、根因、检查与验证写入故障手册；记录不得阻塞已通过门禁的实验。
