### RWKV 机制适配的软排序纠正

- 2026-09-08 用户纠偏：RWKV 来源机制的自然序列、状态重置与不可约差量是创新空间的**软偏好**，不是数据集硬门。数据存废只由公开可得、数据与划分完整、真实非饱和病灶、单卡可执行和无泄漏评价裁决。
- LAMDA 的 4,561 维静态二值袋特征不适合 ROSA、TimeMix 或序列状态，但其真实多年漂移和巨大错误余量仍使它成为强数据候选；方法应从静态域泛化、持续学习、标签噪声或稳定表示家族构思。
- EMBER2024 与 HiGraph 分别更适合静态特征和图结构方法。RWKV 适配低只限制机制来源，不再直接排除数据。
- CESNET-QUICEXT-25 的前 30 包只支持流内短序列表征，不能证明长状态，但服务分类本身属于允许的网络安全任务。
- CIC-YNU-IoTMal 的沙箱原始序列仍有机制探索价值；当前排除依据改为官方下载不可达、数据许可/哈希缺失、正式划分未核和 Hash 级泄漏风险，而不是“发布宽表无顺序”本身。

### 准确功能、数据条件与创新风险

| 机制家族 | 准确功能 | 必要数据条件 | 已知近邻与创新风险 |
| --- | --- | --- | --- |
| ROSA | 在同一序列内寻找当前位置查询后缀的最长、最近历史匹配，并读取该历史匹配的后继值；官方演示把离散 Q/K/V 的检索输出作为残差支路 | 自然、唯一的因果序列；跨样本强制重置；长于固定阶 n-gram 的重复后缀；历史后继具有额外可预测性 | 标准后缀自动机、固定阶 n-gram、普通哈希表和 SAM Decoding 均是近邻；直接送事件 ID、跨实体共享自动机或仅换名不构成创新 |
| DeepEmbed | 用当前 token 的逐层大表矩阵调制前馈通道；不是普通输入嵌入 | 稳定、稀疏、可解释的 token 词表；错误集中于可复用但组合稀疏的 token/n-gram；去身份后仍有信号 | Engram、普通嵌入、参数匹配 FFN、哈希 n-gram 都是近邻；表容量、碰撞、OOV 和身份记忆可制造虚假增益 |
| Engram | 对局部 n-gram 做 O(1) 哈希寻址，从大容量参数记忆表中稀疏读取，再经上下文门控注入表示 | 稳定局部短语/事件模式；哈希碰撞可控；局部显式记忆与动态组合推理具有可分职责 | 已是成熟条件记忆近邻；直接把系统调用 n-gram 查表属于照搬，任务化差量须包含跨架构稳定寻址、去沙箱/身份约束和病灶驱动门控 |
| TimeMix/广义 Delta 状态 | 用数据依赖衰减和写入/移除规则递推固定大小状态，在线保留历史 | 长程依赖、合法状态边界、前缀推理以及普通窗口在长依赖分面上的退化 | DeltaNet、门控 DeltaNet、Mamba 等已覆盖大量基础形式；仅替换模型层不是创新，表达能力也不等于可学得的长度泛化 |
| DeepEmbedAttention | token 条件重构压缩 K/V，再做因果全注意力，并与 TimeMix 残差相加；官方版本同时包含 DeepEmbed | 足够长序列、普通低秩注意力仍有错误余量、二次复杂度可承受 | 官方仅低效推理参考、无独立论文和训练合同；与 DeepEmbed 嵌套，不能作为对称独立机制 |

### CIC-YNU 当前证据映射

- **已证数据事实**：官方页和沙箱仓库证明一次恶意软件执行内确实产生带时间戳和持续时间的完整 `strace.log`、每秒 `sar.out` 和 `network.pcap`；单次执行是合法重置边界，四种 CPU 架构是真实泛化轴。
- **已证跨架构病灶，但证据等级有限**：一个公开复现项目报告单架构 ARM 训练到 x86 时 F1 约 61%，ARM+MIPS 训练到 x86 约 95%，并称架构特异调用导致迁移失败；这是社区工程收据，不是同行评审全文证据。
- **尚未证明的核心链条**：该跨架构退化目前由系统调用**频数向量**即可观察，尚无证据表明系统调用顺序、长后缀或长状态是不可替代信息。2026 年另一篇同行评审工作在 CIC-YNU 的 39 维 PCAP 流特征上发现卷积-only 与循环编码器均值相当，循环部分主要降低种子方差，反而不能证明长程状态必要性。
- **当前裁决**：CIC-YNU 的 RWKV 适配为低、实验待证；这只影响机制排序。数据集当前不能进入实验的独立原因是下载、许可、文件清单、正式划分和 Hash 隔离均未通过可复核门。

## 2025/2026 候选增量核验

### LAMDA，ICLR 2026

- 原始来源：`https://arxiv.org/abs/2505.18551`、`https://huggingface.co/datasets/IQSeC-Lab/LAMDA`、`https://github.com/IQSeC-Lab/LAMDA`；核验日期 2026-09-08。
- 正式身份：ICLR 2026 接收，arXiv `2505.18551`；2013--2025（缺 2015）共 1,008,381 个 Android APK，1,380 个恶意家族，约 150,000 个无家族标签样本。
- 官方制品：Hugging Face `IQSeC-Lab/LAMDA`，DOI `10.57967/hf/5563`，仓库提交 `ad9614bdd5556767f97ced2fce797c2f06408ebf`；官方 API 实测可列出每年训练/测试 Parquet、NPZ 稀疏矩阵、词表和映射文件。数据卡标 MIT；论文网页标 CC BY 4.0，二者分别对应数据与论文。
- 数据合同：每 APK 为 4,561 维 Drebin 静态二值袋特征，另含 SHA256、二值标签、家族、VirusTotal 检出数和年月。原始词表约 969 万维，阈值筛选在各年训练部分拟合；每年内部 80/20 分层切分。
- 真实时间协议：原论文训练 2013--2014，留出同期末月作 IID；2016--2017 为 NEAR；2018--2025 为 FAR。五次随机运行。
- 余量：LightGBM F1 从 IID `97.49±0.17` 降到 NEAR `59.48±28.20`、FAR `47.24±27.33`；FNR 从 `1.74±0.34` 升到 `50.51±30.82`、`64.10±22.97`。CADE 在 LAMDA 上 F1 `0.4407`、FNR `0.4734`、FPR `0.1729`，明显未饱和。
- 数据风险：平衡采样弱化真实良性基率；标签依赖不断变化的 VirusTotal 与 AVClass2；公开主输入只含静态特征，不含运行轨迹；2024、2025 样本量极少，原文的标签漂移表中 2024/2025 总样本仅 794/23，需核与全数据统计的口径关系。
- **候选裁决：升为 DRIFT 之后的下一主候选，RWKV 适配低。** 它通过公开可得、真实时间轴和非饱和病灶三项；官方已发布 NPZ 稀疏表示，单卡可用流式小批训练。正式使用前必须只以来源年份拟合词表/方差筛选，核对未来年份是否参与全局特征筛选，并把 2018--2025 保持为冻结未来区，避免无标签未来协变量回流。

### CIC-YNU-IoTMal，Information Systems 2026

- 原始来源：`https://doi.org/10.1016/j.is.2026.102722`、`https://www.unb.ca/cic/datasets/ynu-iot-2026.html`、`https://github.com/UNBCIC/CIC-YNU-IoTMal-Sandbox`；核验日期 2026-09-08。
- 补充证据：`https://github.com/manvithaaaaa/Cross-Architecture-IOT-Malware-Detection-Using-SHAP-Analysis`（社区复现，只作病灶候选）与 `https://doi.org/10.1007/s44354-026-00046-x`（同行评审 PCAP 后续工作）。
- 正式身份：DOI `10.1016/j.is.2026.102722`，Information Systems 140:102722；Crossref 与 OpenAlex 均核到 2026 年正式出版、开放获取和 CC BY 4.0。
- 采集：IoTPOT 的 10,000 个恶意二进制在 ARM、MIPS、MIPSEL、x86 的 QEMU/OpenWrt 环境执行；家族包括 Mirai、Gafgyt、DarkNexus、Rudedevil、Agent、Generic、Tsunami；良性程序由大语言模型生成。
- 原始采集能力：官方沙箱代码以单次二进制执行为任务，输出完整 `strace.log`、`sar.out`、`network.pcap` 和 `qemu.log`；系统调用含时间戳和持续时间，SAR 为每秒采样。单次执行可作为合法状态重置。
- **实际发布表示**：官方数据页只列四个架构下的处理后 PCAP、SAR 和 STRACE Parquet。公开复现从真实 Parquet 页脚读出：ARM/MIPS/MIPSEL/x86 的 STRACE 分别约 2,199/2,999/2,762/2,585 万行、130--135 列；列只有 `Call_*` 系统调用特征与 `Hash`、`MalwareFamily`、`Arch` 三项元数据，四架构共同调用列为 90 个。没有时间戳、事件序号、进程/线程或调用参数序列列。
- 因此官方沙箱**能生成**原始序列不等于发布数据**包含**原始序列。处理后 STRACE 是系统调用特征宽表，无法从语义字段恢复调用顺序；Parquet 物理行序也不能充当未声明的事件顺序。
- 公开性：官方下载需填写个人/机构表单；2026-09-08 实测表单页面显示服务器错误，绕过表单访问 `browse.php` 返回 HTTP 403。官网没有公开文件体量、逐文件哈希或数据许可证。论文开放许可不能自动替代数据许可。
- 原论文全文：出版社页面和全文元数据均可达，但 PDF 受 Cloudflare 拒绝；Elsevier 文本挖掘接口无 API key 只返回元数据，完整视图要求有效 API key。Google Scholar CLI 无认证 Cookie。故原论文的完整基线表、内部切分和预处理细节保持“全文未核”。
- 社区跨架构收据：LightGBM 的 ARM→ARM F1 `99.97%`、ARM→x86 `61.33%`、ARM+MIPS→x86 `95.11%`。但脚本先删除 `Hash` 后按行随机划分，同一二进制产生的多行可能跨训练/测试；并把 90 个系统调用频数当静态向量，不能支撑序列机制结论。该数字只证明“可能存在跨架构病灶”，不具正式比较资格。
- 同行评审后续工作 ST-HAE 在 39 维 PCAP 流特征上报告五次训练的准确率 `95.85±0.03%`、AUC `0.9799±0.0015`，但其容量公平消融中卷积-only 在均值上不差于完整循环模型；循环支路主要降低种子方差。这一结果没有使用 STRACE 顺序，不能支撑 RWKV 长状态必要性。
- **硬门裁决：当前仍排除，但理由与 RWKV 无关。** 2026-09-08 官方下载表单报服务器错误且浏览入口 403，数据许可、逐文件哈希、正式划分和 Hash 级主体隔离均未核；现有社区行级随机划分可能把同一二进制泄漏到训练和测试。发布物无调用顺序只把 RWKV 适配降为低，不能单独否决静态跨架构任务。

### CESNET-QUICEXT-25，服务分类专项候选

- 原始来源：`https://zenodo.org/records/17249078`、`https://cesnet.github.io/cesnet-datazoo/`；核验日期 2026-09-08。
- 2025-10-02 发布，采集 2024-06 至 2025-05；Zenodo v1 当前公开，12 个月 ZIP 共 28.2 GB、约 1.94 亿真实 ISP QUIC 流，50 个应用类和 3 个背景类，统一 1:100 抽样。
- 自然序列只有单流前 30 包 PPI 与 `QUIC_PACKETS` 长首部包类型序列；无客户端 IP，不能构造跨流状态。SNI 是标签源，目的主机、SNI、ASN、连接标识和用户代理均有标签捷径风险。
- 可检验的 RWKV 来源差量仅是 **DeepEmbed/Engram 风格的身份安全协议 n-gram 条件记忆**：以 QUIC 版本、长首部包类型、方向和 TLS 扩展类型构造去身份离散键，用上下文门控制记忆注入；它不是长程状态主张。
- 当前缺口：尚无已核同行评审强时间基线，SNI/目的端点的标签捷径必须屏蔽，且没有恶意标签。服务分类已被用户允许，因此“无恶意标签”不是硬排除项；在建立身份安全的严格跨月基线前，它仍低于 LAMDA 和 EMBER2024。

### 纠偏后的 2025/2026 排序

1. **DRIFT-DGA 继续作为当前主数据**。公开数据、2017--2025 时间轴、严格前向角色和未来年 FPR/FNR/未见家族余量均已通过现路线核验；RWKV 机制弱不改变数据资格。
2. **LAMDA 2026 是下一资格候选**。它具有最长且最清楚的恶意软件真实时间轴、显著非饱和退化和公开特征/元数据/代码；但官方发布特征读取未来协变量，当前又未发布原始逐样本 token，来源专属重物化尚不可执行。该阻断解除前不能升为正式主数据。
3. **EMBER2024 是备选**。KDD 2025、超过 320 万文件、六种格式、七类标签、训练后 12 周时间测试和逃逸挑战集提供现实余量；公开输入是静态特征且适合流式训练。正式晋级前补核低误报多次运行、挑战集分面和近重复文件隔离。
4. **CESNET-QUICEXT-25 是服务分类专项候选**。数据真实、公开、2025 年发布且官方提供多种尺寸；强未来窗口结果和标签捷径安全协议仍待证，因此不越过前两项。
5. **CIC-YNU-IoTMal 当前排除**。下载、许可、哈希、正式划分和 Hash 主体隔离未通过，不以 RWKV 弱作为理由。
6. **CipherSpectrum、HiGraph、NETD 和 CESNET-TimeSeries24 暂不推荐**。它们分别受受控短期采集、版本/单卡图规模、人工偏移和攻击真值缺失限制。

该排序衡量数据研究价值，不预设采用哪种骨干或机制。LAMDA 与 EMBER2024 的 RWKV 适配均低，但可以从其他成熟方法家族完成任务化改造。

- **实验支持**：在当前发布方固定的 4561 维转导式特征空间内，LAMDA 的 2016/2017 时间退化、恶意漏检和低假阳性权衡均有巨大可优化余量；它不是性能天花板数据。
