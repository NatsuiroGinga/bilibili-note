# 嵌入模型真实对照计划

## 目标

评估 `intfloat/multilingual-e5-small` 的既有选择依据，并在不修改生产默认值的前提下，对最多三个可在 Apple Silicon 本机运行的多语种嵌入模型执行真实检索对照。

## 边界

- 只新增或修改 `.Codex/docs/2026-08-20-嵌入模型真实对照/`。
- 不修改生产检索默认值，不写入 `raw/`、`wiki/` 或 Zotero。
- 不访问远程服务器，不占用服务器图形处理器。
- 模型缓存限定为项目 `.cache/literature-search/model-cache/`，不写入 `/tmp`。
- 不暂存或覆盖其他代理与用户的改动。

## 执行阶段

- [进行中] 核对既有实现、提交历史、固定模型修订与既有评测证据。
- [待执行] 冻结 `real-user-query-v1` 和新增跨作用域查询的独立相关性标注。
- [待执行] 用 Hugging Face 官方模型卡与接口筛选不超过三个候选并记录固定修订。
- [待执行] 固化统一分块、词法检索与倒数排名融合参数的本机评测驱动。
- [待执行] 先验证 Apple Silicon 的 MPS；不支持时记录原因并回退中央处理器。
- [待执行] 执行真实索引构建与查询，对比向量检索、混合检索、负例拒答和资源代价。
- [待执行] 汇总原始结果、对照表与推荐，不满足非支配优势时保留当前默认值并注明未证明最优。

## 验收制品

- `notes.md`：证据、决策、阻塞项和检查点。
- `frozen_qrels.json`：候选结果加载前冻结的查询与相关性标注。
- `model_manifest.json`：候选模型官方元数据、固定修订与输入合同。
- `run_bakeoff.py`：统一参数的真实评测驱动。
- `raw_results.json`：逐查询结果、指标和资源测量。
- `comparison.csv`：模型与检索模式对照表。
- `评估报告.md`：结论、证据、局限和推荐。

## 验收命令

- `python3 -m py_compile .Codex/docs/2026-08-20-嵌入模型真实对照/run_bakeoff.py`
- 使用 `uv run --project scripts/literature_search` 执行评测驱动的真实数据运行。
- `git diff --check -- .Codex/docs/2026-08-20-嵌入模型真实对照`

## 阻塞条件

- Hugging Face 官方接口不可访问或候选模型修订无法固定。
- 本机磁盘或统一内存不足以在共同合同下完成候选对照。
- 生产检索代码的并发改动导致无法复用稳定接口；此时评测驱动必须固定到已核验提交行为，不能覆盖他人改动。
