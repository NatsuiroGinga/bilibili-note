# 任务计划：近五年网络安全数据集采样实验

## 目标

核验候选数据集的真实性、下载条件和任务兼容性，选择可代表不同采集环境的近五年数据集，构建固定预算子集，并在同一生成式恶意流量检测协议下比较基座与第一创新点候选机制。

## 阶段

- [x] 阶段1：逐项核验清单中的数据集、论文、许可和下载入口
- [x] 阶段2：确定三个主数据集与一个补充数据集及采样预算
- [ ] 阶段3：下载最小样本并审计 PCAP、标签、类别和时间覆盖
- [ ] 阶段4：实现统一流量序列化与数据划分，生成本地训练制品
- [ ] 阶段5：在 RTX 5090 上完成 1.7B 探针和 3B 至 4B 基座比较
- [ ] 阶段6：完成第一创新点消融、统计检验和方案裁决

## 关键问题

1. 清单中的数据集是否真实存在，是否能从官方或作者渠道下载？
2. 哪些数据集包含恶意与正常流量、明确标签和原始 PCAP 或包序列？
3. 如何在不同标签空间下进行公平比较，而不是比较不可比的绝对准确率？
4. 哪个基座与训练机制在域内、未见攻击和跨数据集测试中稳定最好？
5. 哪个方案在训练 GPU 小时、峰值显存、生成令牌数、推理延迟和租用成本上位于性能—成本帕累托前沿？

## 裁决规则

- 数据集只在真实性、许可、下载可达性、标签完整性和任务兼容性全部通过后进入实验。
- 固定每个数据集的类别上限、生成次数、输入长度、输出长度、训练步数和 GPU 小时。
- 效果主指标为宏平均 F1、未见攻击召回率和跨数据集宏平均 F1；效率主指标为训练 GPU 小时、峰值显存、总生成令牌数、推理 P95 延迟和单位 GPU 小时增益。
- 不用单个数据集上的最高准确率决定最终方案。
- 基座和训练方法按性能—成本帕累托前沿裁决，不将准确率与成本粗暴压成一个任意加权分数。
- 第一创新点必须在至少两个数据集和跨数据集测试上稳定优于普通 QLoRA，消融能证明两个机制各自有效，且训练成本增幅不得吞噬性能收益。
- 第三章候选机制应优先设计为仅训练期生效；若推理仍需额外模型、额外前向计算或不可观测的特权变量，默认不进入主方案。

## 错误记录

- 最大 IDS2018 压缩包的全量 CRC 检查因用户将任务转向新数据集筛选而主动停止，未将未完成检查误报为通过。
- 首次创建本计划时，补丁字符串末尾解析失败；拆分为单文件补丁后成功，未产生半写入文件。
- Zenodo 向本地下载 GeNIS-2025 `2-flows.zip` 时速率约为 55 KB/s，已主动中断以避免浪费时间；本地仅有可续传的未完成文件，不得当作完整数据集使用。
- 尝试同时修改章节编排与理论候选文档时，因数学行的上下文不完全匹配导致合并补丁整体拒绝；已改为分文件精确补丁，未产生半写入文件。
- Prettier 对三个有格式差异的 Markdown 文件原地写入时被系统以 `EPERM` 拒绝；已将 Prettier 输出写入临时文件，通过 `apply_patch` 精确应用格式差异，最终 `prettier --check` 全部通过。
