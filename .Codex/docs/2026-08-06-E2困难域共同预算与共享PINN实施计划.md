# E2 困难域共同预算与共享 PINN 实施计划

> **执行要求**：使用 `executing-plans` 按任务顺序实施，明确禁用 `test-driven-development`。实现后只运行一次覆盖当前改动的最小有效验证；复审可以并行，但不得阻塞已通过运行门禁的实验。

## 目标

在不读取 TQH-C2 v1.2.0 最终测试和未分配捕获组的前提下，建立共同七字段下可复现的强基线与 `E2-A/E2-S/E2-P/E2-X` 对照入口，先完成种子 42 的主困难域筛选，再按预注册门槛决定是否扩展三种子。

## 冻结边界

- 主面板：`A+B+D→C`。
- 确认面板：`A+B→C`。
- 输入字段：`duration`、`orig_bytes`、`resp_bytes`、`orig_pkts`、`resp_pkts`、`orig_ip_bytes`、`resp_ip_bytes`。
- 禁止输入：地址、端口、测试床身份、`profile`、`capture_id`、配置、路径、行号、标签派生字段和最终测试身份。
- 传统锚点：HGB、XGBoost；新增随机森林、MLP、普通 DistilBERT、仅源域 GroupDRO。
- PINN 对照：`E2-A` 普通监督；`E2-S` 状态监督；`E2-P` 状态监督加共享守恒残差与边界；`E2-X` 同结构、同预算但按预注册分层置换物理监督。
- ET-BERT、BUPT-CNN、Qwen3-0.6B、TCP/QUIC 专家和路由不进入首轮入口，不阻塞 E2。
- 所有配置、日志、逐样本预测、指标和失败状态必须保存在唯一运行目录；正式 GPU 运行使用 SwanLab 在线模式。

## 路线冻结门槛

- 两个面板上，`E2-P` 相对 `E2-A/E2-S/E2-X` 和预注册域泛化基线的三种子方向全部为正，捕获组等权宏平均 F1 平均绝对增益至少 `0.03`。
- C 最差捕获组宏平均 F1 至少提高 `0.03`，两个捕获组均不低于 `E2-A`。
- 源域 A/B/D 捕获组等权宏平均 F1 相对最佳同输入非物理基线下降不超过 `0.01`。
- C 恶意召回至少 `0.20`，良性误报率不高于 `0.05`，`TPR@1% FPR` 至少提高 `0.10`。
- 状态误差和无量纲残差相对 `E2-S` 均至少下降 `10%`，真实物理优于置换物理，状态头梯度非零。
- ECE 相对 `E2-A` 恶化不超过 `0.02`；推理延迟和峰值显存增幅各不超过 `20%`。
