# QUIC 正式专家 600 连接样本充分性裁决协议

## 1. 目的与边界

本协议回答“600 条独立 QUIC 连接是否足以训练并验证正式 QUIC 物理专家”。`600` 是覆盖性设计，不是先验统计充分性证明。只有完成学习曲线、组级稳定性、物理特异性消融和公开检测任务验证后，才能形成样本充分性结论。

本协议不允许：

- 达到 600 条后直接宣称数据充分；
- 把验证或测试连接并入训练；
- 查看最终测试结果后改变连接、划分、阈值或评价指标；
- 复制同一连接或切分同一连接来虚增独立样本数；
- 用合成 QUIC 数据替代 TQH-C2 v1.2.0 的公开数据检测证据。

## 2. 600 条连接的覆盖设计

正式矩阵沿用已记录的因子设计：

\[
N=2\text{ 种实现}\times30\text{ 组网络条件}\times5\text{ 个采集种子}\times2\text{ 种负载}=600.
\]

30 组网络条件由 5 档时延、3 档丢包率和 2 档链路速率组合而成。每条样本必须具有独立 `connection_id`，并保存实现、网络条件、采集种子、负载、原始物理收据和数据清单。三轮 v8.1 门禁连接不得混入正式 600 条矩阵。

## 3. 冻结划分与隔离

- 总连接数：600。
- 训练集：400 条。
- 开发验证集：100 条。
- 内部测试集：100 条。
- 划分单位：独立连接，并按实现与网络条件分组约束，禁止同一连接的窗口或多视图跨集合。
- 模型、阈值、路由、物理字段、标准化统计和停止条件只使用训练集与开发验证集确定。
- 内部测试集仅在方案冻结后使用一次；TQH-C2 v1.2.0 的正式测试集继续保持独立。

由于 600 是总连接数，学习曲线只能在固定的 400 条训练池内使用嵌套的 `100/200/300/400` 条训练清单。不得把 600 写成训练样本数。若后续需要 600 条训练连接，必须扩充总矩阵并重新预注册保持不变的验证与测试隔离方式。

## 4. 样本充分性实验

### 4.1 学习曲线

在同一训练池中构造严格嵌套的 100、200、300、400 条连接清单。每个规模使用相同的三组训练随机种子、模型结构、优化器、训练预算和固定开发验证集，记录：

- 物理状态的归一化绝对误差与均方根误差；
- 物理残差的归一化误差；
- 下游检测宏平均 F1；
- 最差实现组和最差网络条件组的宏平均 F1；
- 期望校准误差、训练时间和推理时间。

### 4.2 物理特异性消融

在相同数据、基座、参数预算和训练预算下比较：

- 无物理旁路；
- 真实物理旁路；
- 按独立连接置换的物理旁路；
- 与真实旁路同维度、同尺度的随机旁路。

统计单位是独立连接。采用保持实现与网络条件分组的配对簇自助法计算 95% 置信区间。真实物理旁路只有稳定优于无旁路、置换旁路和随机旁路，才能说明模型利用了物理语义，而不是增加参数或随机噪声带来的变化。

### 4.3 公开检测任务验证

QUIC 专家通过内部测试后，仍需在冻结的 TQH-C2 v1.2.0 协议上验证：

- 域内检测；
- 分组外推；
- B 与 D 受控协议差异；
- 困难组和最差组表现；
- 相对共同预算强基线的检测增益、校准和推理成本。

正式效果比较不能只报告最佳种子，必须报告预注册种子的均值、离散程度和置信区间。朱焱雷第三章的提升幅度只作为工作量与结果解释尺度，不作为调整数据或基线以得到指定结果的目标。

## 5. 裁决门槛

600 条总连接可判为当前实验范围内基本充分，必须同时满足：

1. 300 条增加到 400 条训练连接后，下游宏平均 F1 的绝对变化小于 0.5 个百分点。
2. 同一增量下，主要状态误差和物理残差误差的相对改善均小于 2%。
3. 主要检测指标的 95% 配对簇自助置信区间半宽不超过 1.5 个百分点；若内部测试集无法达到该精度，只能扩充独立评估连接，不能重复读取测试集调参。
4. 最差实现组和最差网络条件组没有随训练规模增加而出现系统性下降。
5. 真实物理旁路相对置换与随机旁路的配对差值置信区间下界大于 0。
6. TQH-C2 v1.2.0 上的下游增益方向与 QUIC 内部验证一致，且没有以明显增加良性误报率换取攻击召回率。

这些阈值是本研究预注册的实用裁决标准，不是对所有 QUIC 数据和模型都成立的普遍定理。

## 6. 未通过时的唯一解释与动作

| 观察结果 | 裁决 | 下一动作 |
|---|---|---|
| 学习曲线仍明显上升 | 数据规模可能不足 | 按原因子设计扩充至 900 或 1200 条，不改变测试协议 |
| 置信区间过宽 | 独立评估连接不足 | 只扩充预注册的验证或测试连接池 |
| 学习曲线已饱和但无检测增益 | 方法或表征无效 | 停止以增加数据修补，否决或重构机制 |
| 真实旁路与置换或随机旁路相当 | 缺少物理特异性 | 不得宣称 PINN 或物理专家有效 |
| 仅个别实现或网络条件有效 | 泛化边界不足 | 报告组级边界，不能用总体平均掩盖失败组 |
