## 三处错误（一句话版）

| # | 错误 | 一句话 |
| --- | --- | --- |
| 一 | 用“检验者流程”找路 | 成熟的路在“建构者流程”里：否决 → 回文献库换下一个成熟家族 → 任务化 → 最小实验 |
| 二 | 把“病灶量化最完整”当排序第一优先级 | 空间大只说明天花板高，不说明梯子存在；量化空间大 ≠ 路好走 |
| 三 | 把“文献只能证明可试性”过度矫正为“文献的迁移能力不算证据” | 已验证的正增益家族被永远排在自研机制后面；防空想裁决 ≠ 否认文献先例的迁移效力 |

## 一、错误一：用“检验者流程”找路，而成熟的路在“建构者流程”里

此前实际运行的循环是：

> **oracle 空间 → 自研机制 → 判据 → 否决 → 从失败结构推下一个机制**

每个新机制都诞生于对上一个失败的归因，等于始终在同一个笛卡尔空间里换方向。六代损失项死于同一取舍结构，即该循环的直接症状。

成熟的路存在于另一个循环里：

> **否决 → 回文献库换下一个成熟家族 → 任务化 → 最小实验**

两者的差别在候选的来源：前者从自身失败的形状生成候选，后者从已经发表正增益的成熟家族取件、再任务化到本任务。

## 二、错误二：把“病灶量化最完整”当排序第一优先级

空间大只说明天花板高，不说明梯子存在。route 族因 5,802 oracle 空间被排到第一，而 TTA 这类文献里现成正增益的家族被排在“需协议裁决”之后。

**量化空间大 ≠ 路好走。**

## 三、错误三：把“文献只能证明可试性”过度矫正为“文献的迁移能力不算证据”

过度矫正的结果是：已验证的正增益家族永远排在自研机制后面。

**防空想裁决 ≠ 否认文献先例的迁移效力。**

## 四、修复动作（对后续所有 AI 生效）

1. **取件顺序**：每次机制否决后，下一候选必须优先从“成熟方法家族清单”取件，并做最小证伪实验。
2. **自研门槛**：只有成熟方法家族清单耗尽，才允许自研新机制。
3. **排序键**：候选排序以“离已验证有效干预的距离”为第一键、“oracle 空间大小”为第二键。

上述三条在机制否决后的候选排序与方案落盘中先行执行：先取件、再排序，最后才允许自研。

## 五、工程错误反思与防再犯策略（2026-09-10，TTA／DGA 对抗鲁棒线）

**性质**：以下每条均为 **2026-09-10 实际发生**的事件，不是假想风险。本节只记**工程与论证纪律**教训，不改变任何研究结论；它与前三节（建构者流程、排序优先级、文献迁移效力）并列，供后续 AI 会话开局参考。

1. **批量替换改坏数据流身份**：`sd` 全局替换把主脚本良性侧由 `T18_benign_val` 改为 `T19_benign_val`，源年臂实际跑在**混合源年流**上（console 仍自称"T18 流"）。
   - **根因**：对**代码文件**做全局文本替换后，未检查**数据流身份**（实际读入的 parquet 是否等于冻结协议规定者）。
   - **防再犯**：① 脚本变体一律用 `git cp`／显式 diff 审查，禁止用全局替换生成变体；② 替换后、启动前先核对数据文件路径；③ 运行日志首行必须机械打印**实际读入的全部数据文件路径**，让身份不符无法被 console 文案掩盖。
2. **探针脚本连续 5 次崩溃**（路径笔误 ×2、`stats` 键缺失、变量名残留、广播错误、LR 单类）：
   - **根因**：手写长脚本的**新代码路径未经干跑覆盖**；`py_compile` 只查语法，不查名称绑定与张量形状。
   - **防再犯（部分已机制化）**：① long-task-resume hook（断点恢复四问）与 daily-coding hook 已上线；② **新代码路径必须先小样本干跑**再上全量；③ 语法检查不得当作可运行证明。
3. **`CLAUDE.md` 被多行替换损坏**（68 行 → 16,213 行）：
   - **根因**：把 `sd` 用于**多行结构替换**，超出其"单行、字面量、无歧义"的适用范围。
   - **防再犯**：① 改动超 3 行一律**整文件重写**（既有规则，本次违反）；② 核心配置文件改前**强制备份**（后续代理已实践备份，应固化为动作而非依赖记忆）。
4. **MPS OOM 两次**（batch `1024` 反向、双训练进程竞争）：
   - **根因**：① 带梯度内存随批量**线性增长**未预估（实测约 `0.02 GiB/样本`）；② "重任务同刻一个"执行错位——推理可并行、训练 ×2 不行。
   - **防再犯**：① 反向任务的批量上限按**实测登记**（本线：`128`）；② 并行只限**轻推理 ＋ 文档**，重训练串行；③ 启动前 `pgrep` 与资源实测。
5. **正锚点 lookup 符号翻转**（`−207` ↔ `+713`）：
   - **根因**：MPS 位级非确定 × **单一 cell 承载全部信号**（边际信号）。
   - **防再犯（已落盘）**：① "符号在重跑间翻转的读数不得进入候选排序"；② 归因**精确化**——同模式内两次前向 bitwise 确定、**跨模式／跨批次构成**才非确定，故噪声地板必须按此设计（已写入 TTA 方案 §2.4 C4）。
6. **算法编号幻觉**（SAPO 被给出 `2510.08625`，实为扩散模型论文）：
   - **根因**：把 WebSearch 的摘要输出**当作事实**，未做题录核验。
   - **防再犯（盘点代理已执行）**：算法题录必须经 **arXiv API 直查核验**；本线已纠正为 `2511.20347`，并建立同名冲突表与"引用必须带编号"的纪律。
7. **两处过界表述**（"源年没漂移""适应空间小饱和"）：
   - **根因**：把**干跑／单年便利读数的假象**外推为**结构性结论**。
   - **防再犯**：便利性论断与结构性论断**必须分开表述**；后者需实验支撑，禁止由单次运行或单年流外推。
8. **P0 攻击算子不忠实**（自造四算子 vs CharBot 原文单算子）：
   - **根因**：**设计先于文献核验**。
   - **防再犯**：攻击面／机制算子必须**从原文取**（本线已由文献代理按页码级核验修正）；确需近似或替代时，必须显式标注为近似并给出偏离量。

**收束**：本节与前三节共同构成四条长期纪律——① 取件优先成熟家族；② 排序按"离已验证有效干预的距离"；③ 工程变更必须可核验（数据流身份、批量上限、备份、干跑）；④ 论断强度必须匹配证据强度（禁止假象外推与摘要当事实）。
