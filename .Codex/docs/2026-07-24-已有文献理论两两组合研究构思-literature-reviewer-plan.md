# 已有文献理论两两组合研究构思：文献评审计划

## 目标

仅依据仓库截至 2026-07-24 已存在的论文全文、结构化笔记和文献审查，筛选并排序 8—12 个可在单篇论文或一个创新章节内完成的“理论 A × 理论 B”网络安全研究构思。

## 边界

- 只读来源：`raw/papers/`、`wiki/papers/`、`.Codex/docs/`。
- 不联网，不下载，不新建或修改 Zotero 条目。
- 不改动 `raw/`、`wiki/`、`output/`、`thesis/`。
- 不改动主代理的 `task_plan` 与 `notes` 文件。
- 强结论与公式必须有全文位置；摘要或二手线索降级并列入补全文清单。

## 六阶段

- [x] 阶段一：固定研究问题、范围、纳入排除标准、证据等级与停止条件。
- [x] 阶段二：全量盘点三个来源目录，提取题名、关键词、标签、稳定标识与全文路径，去重形成候选池。
- [x] 阶段三：按理论独立性、机制接口、网络安全缺口、全文可得性和章级可行性筛选分类。
- [x] 阶段四：全文精读不少于 20 篇，覆盖不少于 6 个理论家族，提取机制、假设、公式/章节位置、数据、基线、局限。
- [x] 阶段五：建立理论互补关系和研究空白，形成可证伪假设、最小实验与失败条件。
- [x] 阶段六：生成文献综述与证据矩阵，核验路径、计数、引用对应和证据边界。

## 验收条件

- 8—12 个组合；证据不足时如实少列。
- 每个组合含两项独立理论、清楚接口、单一核心问题、主模型、2—3 个数据集、3—5 个基线、两项单机制消融、完整组合与证伪条件。
- 至少 20 篇全文、至少 6 个理论家族。
- 每个最终组合至少一项理论有全文级核心证据；另一项若仅有笔记则明确降级。
- 输出文件实际存在，Markdown 结构检查通过，路径和计数可复核。

## 决策与错误

- 决策：当前论文主线只作历史证据，不作候选淘汰条件。
- 决策：使用本代理独立命名的计划与工作稿，避免覆盖主代理文件。
- 错误：暂无。
