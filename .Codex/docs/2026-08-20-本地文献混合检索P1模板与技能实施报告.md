## 变更内容

### 模板

`paper-note-search/v1` 示例包含：

- 原文题名、中文题名、作者、年份、日期和出版信息。
- 显式 DOI、arXiv、原件路径和全文核验状态。
- 别名、标签、任务、数据集、方法、指标和关键发现。
- 论文可以支持、论文不能支持、实验结果与负证据、公式页码和关系。
- `related` 双向链接及 `类型/论文` 标签。

示例使用仓库已有且真实存在的 `raw/papers/methodology/2009_Bengio_Curriculum_Learning.pdf`，并明确要求复制后替换全部题录、论断和页码，没有创建虚构论文夹具。

### lint

新增命令：

```bash
uv run --project scripts/literature_search --locked \
  python -m scripts.literature_search lint <笔记.md> --strict --json
```

检查项：

- YAML 可解析性、schema 和字段类型。
- DOI、arXiv 或题名加年份的当前论文身份。
- `source_pdf` 位于 `raw/papers/` 且实际存在。
- `fulltext_verified: true`。
- 印刷页、物理页或 PDF 页锚点。
- 论文可以支持、论文不能支持、实验结果与负证据、与本课题的关系四个正文分区。
- 列表字段、`类型/论文` 标签和 `related` 关系。

`paper-note-search/v1` 自动进入严格模式；`--strict` 可强制旧模板使用严格合同。旧模板默认兼容报告，缺失项为警告；非法 YAML 等基础错误仍失败。输出固定包含 `auto_modified=false`。

### 薄编排技能

新增 `indexed-paper-reading`，只编排：

1. `raw/` 查重与原件落盘。
2. `wiki/` 唯一规范笔记。
3. 方向 `INDEX.md` 更新。
4. Zotero 条目与附件状态。
5. 严格 lint。
6. 增量索引与复用收据。
7. 预先冻结意图的检索自检。

全文读取调用 `document-skills:pdf` 或 `pdf-converter`；Zotero 调用 `zotero:Zotero`；知识库路由调用 `obsidian-project-kb-core`、`obsidian-source-ingestion` 或 `zotero-obsidian-bridge`。技能没有复制通用 PDF 阅读、Zotero 或 Obsidian 方法。

## 边界与风险

1. lint 只检查结构、路径和显式页码锚点，不能判断论文论断是否忠实于全文；真实性仍须人工页级核验。
2. 旧笔记保持兼容警告，不代表满足新 schema。只有主动迁移并通过严格模式后才能登记为 `paper-note-search/v1`。
3. 技能不自动运行 Zotero、下载原件或修改 INDEX；实际入库任务仍须获得相应输入和权限。
4. 严格模式要求非空列表，无法适用的字段应写清适用边界，不能用空列表规避检索合同。
