# LAMDA 双风险梯度投影筛查报告

## 问题与合同

本实验检验 A-GEM 式双风险梯度投影是否比标准 ER 更稳定。只读取 `2013/2014/2016/2017`，开发期汇总 `2016/2017`；封印年 `2018--2025` 未枚举。运行身份为 `ch3-lamda-dual-risk-projection-screening-seed42-v1`，结果保持 `screening_only`。

## 开发期 pooled 结果

旧恶意负向翻转率在 2016/2017 训练终点合并为：ER `2249/43161=0.052107226`，双风险投影 `1380/43147=0.031983684`。

## 投影是否真正触发

- 2013 年无历史保护参考，投影事件为 `0`。
- 2014、2016、2017 年投影事件数分别为 `736`、`734`、`551`；说明新增路径实际改变了部分梯度，不是空跑。
- 投影臂的 FPR 和旧恶意翻转下降，但 FNR、AP、F1 恶化；它保留了安全保持取舍，没有完成恶意修复。

## 裁决

- **实验支持**：双风险投影比阶段 C 的等单位风险损失稳定，满足 FPR 不升和旧恶意负向翻转不升两个安全方向。
- **实验不支持**：双风险投影改善当前恶意识别、降低 FNR、提高 AP/F1，或单独成为第三章主方法。
- **研究定位**：保留为安全保持侧的直接 A-GEM 基线和可能的组成部件；不得进入封印年，不能把“安全信号”写成“全面改进”。下一步需要独立的恶意修复机制，并在不破坏两个安全门的条件下做最小联合消融。
- 单种子、未来协变量特征和开发期小范围使本报告不能支撑正式泛化或统计显著性结论。
