# 网络安全流量检测数据集调研（2025–2026 新发布增量）

你是学术文献与数据集调研助手。请系统性检索并回答：**2025 年至 2026 年 9 月新发布（或新更新）的、可用于"恶意流量/网络攻击检测"监督学习任务的公开数据集**。加密流量优先但不限于——入侵检测、恶意软件 C2、DDoS、僵尸网络、钓鱼/恶意域名、加密隧道滥用等网络安全流量检测任务都在范围内。不要泛化到通用异常检测或 IT 系统日志。

## 检索范围（按优先级）

1. 2025–2026 顶会/好会论文的配套数据集（NDSS、S&P、USENIX Security、CCS、DSN、RAID、IMC、KDD、TIFS/TDSC 等）；
2. Zenodo、Hugging Face Datasets、IEEE DataPort、Kaggle 上的新数据卡（重点是 2025 年后上传或大版本更新）；
3. 经典来源的新年度版本：CIC（Canadian Institute for Cybersecurity）、MAWILab/MAWI、CRAWDAD、CTU-13/Malware Capture Facility、NW-Dataset 等；
4. 数据集聚合目录（如 Papers With Code 的 Datasets 分页、DataZoo）中 2025–2026 新增条目；
5. 已知 2025/2026 数据的衍生或补标注版本（例如有人给 CESNET-QUICEXT-25 或 CESNET-TimeSeries24 补了攻击真值；给既有 PCAP 仓库补了新年份或新标签）。

## 每个候选必须逐项给出（缺一项标注"未确认"）

- 名称与发布方；
- 发布/更新时间（精确到月，给来源 URL）；
- **标签语义**：什么算"恶意"（家族/类别粒度、标注方式：真实攻击流量 vs 合成攻击 vs 沙箱产生）；
- **时间结构**：是否真实采集时间轴、能否做时间前向划分（train 在早、test 在晚）、跨度多长；
- 规模（流/包/样本数、文件大小）；
- 输入形态（原始 PCAP / 流特征表 / 载荷字节序列 / 统计特征）；
- **获取方式与许可**（直下/注册/申请、协议条款）；
- 随附论文的基线数字（未来期/跨时间 FPR、FNR 或错误数——只有同年随机划分高准确率的数据集要明确标出）。

## 硬性排除与特别关注

- 排除：仅同年随机划分、无任何时间结构的"刷准确率"数据集（列出时可标注但不计入候选）；
- 排除：纯良性的加密流量分类集（如纯服务分类）——**除非存在第三方恶意真值补充**；
- **特别关注**：(a) 有真实跨年/跨期结构且恶意标签完整的；(b) 原始 PCAP 可得的（可自提特征）；(c) 有未见攻击类型/家族评价面的；(d) LSPR25（LSPR 基准的 2025 版）现状——官方是否更新了可用版本或替代品。

## 我们已有的基线（用于判断"新"与"增量"，避免重复推荐）

LSPR23/24（加密恶意流量，跨年）、LAMDA（Android 恶意软件静态特征）、DRIFT-DGA（域名跨年）、CESNET-TLS-Year22 / QUICEXT-25 / TimeSeries24（真实 ISP 流量但无恶意真值）、EMBER2024（PE 文件非流量）、CIC-YNU-IoTMal、CipherSpectrum、BODMAS、SOREL-20M。以上不需要你再调研，只作为"已知"排除；推荐它们 2026 年的**新版本或新标注**则有价值。

## 输出格式

按"强推荐（有恶意标签+真实时间轴）/ 有标签无时间轴 / 有时间轴无标签（附补标注可能性）"三档列表；每档内按发布时间倒序。最后给一段"2025–2026 该领域的发布趋势判断"（哪些任务类型在出新数据、哪些在枯竭）。每条信息附来源 URL；无法核实的写"待核"，不要编造。
