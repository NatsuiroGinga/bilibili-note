# ESAT：不扰动全部样本的选择性对抗训练

> Losch 等，ICLR 2024；官方会议论文；21 个物理页。

## 论文实际主张

- 选择性对抗训练把训练集划分为被扰动子集 `A` 与保持干净的子集 `B`，仅对 `A` 生成对抗样本（物理第 3 页，式 (2)）。
- ESAT 先用另行预训练的非鲁棒分类器计算样本熵，并把多个训练快照的熵取平均；随后在**整个训练数据集**范围内排序，而不是逐类或逐小批动态排序（物理第 4、6 页，式 (3) 与 §4.2）。
- 论文比较高熵优先、低熵优先与随机选择；实验中的子集大小是训练前给定的全局数据量，例如 CIFAR 以 5,000 个样本为步长，25,000 个即 50%（物理第 6–7 页）。
- 训练批次仍从训练集随机采样；一个样本只有在属于固定子集 `A` 时才执行攻击。内层最大化默认使用交叉熵，`L_2` 实验用 PGD-7；`L_∞` 的 ESAT 实验用 PGD-10（物理第 13 页，附录 A.1）。

## 方法公式与物理页码

- **物理第 3 页，式 (1)**：标准对抗训练写为 `min_θ E_{(x,y)∈D_train}[max_{||δ||_p≤ε} L(x+δ,y;θ)]`。
- **物理第 3 页，式 (2)**：选择性对抗训练写为 `min_θ E[w_A 1_{(x,y)∈A} max_{||δ||_2≤ε}L(x+δ,y;θ)+w_B 1_{(x,y)∈B}L(x,y;θ)]`。默认 `w_A=w_B=1`；论文也讨论用 `w_B=1,w_A=|B|/|A|` 平衡两部分。
- **物理第 4 页，§3.3 无编号式**：样本熵为 `H(f(x))=-Σ_i σ_i(f(x))log σ_i(f(x))`，是每个原始训练样本的连续标量分数。
- **物理第 4 页，式 (3)**：跨 `M` 个非鲁棒模型快照的平均样本熵为 `H_bar(x)=M^{-1}Σ_e H(f_e(x))`。排序与后续对抗训练分离，评分模型不是正在进行 ESAT 的对抗训练模型。
- **物理第 6 页，§4.2**：ESAT 跨整个训练数据集按平均样本熵排序；高熵优先为降序，低熵优先为升序，另有随机基线。
- **物理第 8 页，§4.3**：迁移实验可提高 `A` 的损失权重，但仍沿用式 (2) 的两支外层目标，不引入候选组或组内中心化。
- **物理第 13 页，附录 A.1**：每批随机抽样后只攻击属于 `A` 的样本；默认攻击目标是交叉熵，`L_2` 用 PGD-7，`L_∞` 下 ESAT 用 PGD-10。

## 与 F 精确运算链的逐项比较

| F 链条部件 | ESAT 判定 | 公式级理由 |
| --- | --- | --- |
| 每源多候选 | **不覆盖** | 每个原始训练样本只被固定划入 `A` 或 `B`；属于 `A` 时才对该样本执行标准 PGD 内层最大化，没有先为同一源生成 `K` 个并列候选再筛选。 |
| 二值组中心化 | **不覆盖** | 评分是原始样本的连续平均熵；没有误分类二值状态、组均值基线或留一中心化。 |
| 跨源统一总配额 | **部分覆盖** | ESAT 在全训练集跨样本排序，并按预设 `|A|` 分配一个全局源样本预算；但这不是每个训练小批内对多源候选池执行固定 top-`q`。 |
| 另一交叉熵评价 | **部分覆盖** | 选择量是预训练模型的平均熵；训练量是 `A` 上的对抗交叉熵与 `B` 上的干净交叉熵。它直接覆盖“按一量选择、按另一量训练”的宽骨架，但没有按熵在多个对抗候选中筛选。 |
| 可变源组份额 | **不覆盖** | 每个源样本只有固定二值成员关系；不存在共享候选配额下的 `N_i∈{0,…,K}` 可变组份额。 |

**总裁决：部分覆盖，不完全同构。** ESAT 直接占用“全数据集跨源样本排序＋固定选择预算”和“熵选择／交叉熵训练分离”的宽结构；当前 F 的可讨论差量进一步收缩到每源多候选、二值组中心化、候选级批内统一配额及由此产生的可变源组份额。该结论不改变现有 38 项分类 `5/19/2/5/7`，`F13` 仍只能称任务化组合差量。

## 排序边界与并列规则

- 论文明确给出高熵降序、低熵升序与随机选择，但**没有说明相同熵值如何打破并列**。
- 因此不能把稳定排序、生成顺序保留或随机并列归入 ESAT；这些规则在本论文证据范围内均为未说明。
- 论文的 `|A|` 是训练前确定的数据集子集预算，不能改写成当前 F 每步跨候选组重新计算的 `q=64`。

## 不能直接声称内容

- 不能声称 ESAT 与 F 完全同构，也不能写成“ESAT 已排除”；准确说法是完成全文核验后判为部分覆盖。
- 不能把 ESAT 的样本熵称为组相对优势或最大交叉熵，也不能把训练集子集预算称为批内候选配额。
- 不能因 ESAT 不含完整链就宣称剩余组合首次提出；本次核验只关闭这一篇 P0 候选，不构成普遍优先权证明。
- 不能用 ESAT 的效果实验替代当前任务的共同预算基线、必要消融、单冻结种子正式训练、配对统计与跨年评价。
