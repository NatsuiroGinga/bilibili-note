## 三、独立数学复核与必须修正的条件

### 3.1 先冻结“当前实现”指什么

E4 的 F 分支明确执行：`base=perturb2(train_d[i],rng)`，随后四次 `perturb2(base,rng)`，按原样本索引缓存；选择时重新评分，以 `fooled-fooled.mean()` 稳定降序取前 64，无 `A>0` 门。良性误报掩码来自当前训练前向，对真良性样本的交叉熵系数取 3，分母仍为当前扩展批总数。

因此需要纠正三处文字，不改生产行为：

1. **留一分数与代码分数只排序等价。** 记代码分数 `a=u−ū`，命题包分数 `A=K/(K−1)(u−ū)`，则 `a=(K−1)A/K`。所有组同一 K 时，排序、并列与入选集合相同；分数值、选择器值函数与所谓七值表不同。当前 K=4 时比例为 `3/4`；不得把留一数值直接作为生产日志断言。若组大小不同，比例也不同，不能继续宣称跨组排序相同。
2. **候选核是两次二位编辑的复合并共享中间 base。** 不能写成从原始域名独立执行一次二位编辑；相对原域名的净编辑数还会因重叠、重改或回改而变化。`F1/F9` 应引用真实生成器及复合核，不在本轮另定预算。条件于已生成 base 可以讨论后续理想独立抽样；仅条件于原域名，共享随机 base 会带来组内相关。伪随机顺序、无去重本身既不证明也不否定统计独立性。
3. **快照须包括前向模式及随机状态。** 恶意筛选在评估模式，交叉熵更新在训练模式；若存在随机失活，二者不能仅凭相同参数就当同一数值函数。代数审计固定候选及评价损失实现；若要把理论四项式数值对应实际训练，须使用同一已声明的前向状态和损失口径。缓存后候选不再是每次更新重新独立采样，渐近论断不能解释整段训练动力学。

### 3.2 `1A`：成立，主文保留精确有限池版本

由 `M_i=Σ_j u_ij`，直接代入留一式：

```text
A_ij = u_ij − (M_i−u_ij)/(K−1)
     = (K u_ij−M_i)/(K−1).
```

故成功者为 `(K−M_i)/(K−1)`，失败者为 `−M_i/(K−1)`。当 `0<M_i<K`，成功分数严格正、失败分数严格负；`M_i=0` 或 K 的整组分数为零。每个正分层、负分层内部均按 `M_i` 递增排序，零分组夹在二者之间。

当前 K=4 时，留一分数可取 `−1,−2/3,−1/3,0,1/3,2/3,1`；**代码实际分数**可取 `−3/4,−1/2,−1/4,0,1/4,1/2,3/4`。这里的数是既定算子的代数结果，不是新增科研设定。

只要 `q≤nK`，降序填充先耗尽正层、再零层、最后负层，因此：

```text
q_+ = min(q,C_+)
q_0 = min(C_0,max(q−C_+,0))
q_- = max(q−C_+−C_0,0).
```

这三式不依赖并列规则；具体 `N_i` 依赖稳定生成顺序。对输入分数加逐组常数再中心化时常数抵消，但若先改变 logit 再阈值化，二值事件可变化；“平移不变”不能用来声称对 logit 校准或分类难度不敏感。E2 式 1.5 的随机并列期望不能描述当前稳定排序。

**数学状态：设计可行，有限池代数已经独立复核；文献优先权仍未关闭。** 它解释资源如何分配，不证明选择优于直接近邻。

### 3.3 `F16`：反例正确，结论只到排序不等价

第一组预测恶意概率全为 0.01，二值全成功、中心分数全零，交叉熵为 `−log(0.01)=4.605170185988091`。第二组为 `(0.49,0.9,0.9,0.9)`，孤立成功者代码分数 0.75、留一分数 1，交叉熵为 `−log(0.49)=0.7133498878774648`。取一个候选时必选第二组，其损失比最大交叉熵低 `3.891820298110626`。

这直接否定“最大 A 就是最大交叉熵”与“该选择算子对所有候选池精确求解交叉熵最大值”。在一般固定配额下，只要正分候选填满配额，零分的高交叉熵候选也可能被排除，原因相同。**反例并不说明当前真实训练已发生相同现象，更不证明它损害检测表现。**

还应删除一个逻辑跨越：有限 q=1 反例本身不能证明某个 `K→∞` 估计量不一致。要否定普遍渐近一致性，应引用满足其抽样与预算条件的 `3C`；固定 K=4 也不是一个渐近一致性陈述。论文不应把“结构反例”“期望偏差”“一致性”三者混写。

### 3.4 `F18/3A`：恒等式成立，属于标准风险记账

必须先补齐 E7 §3.1 的定义：`n≥1,q≥1`，候选提议支持属于合法集合；有关上确界有限；损失非负；`L̂_i` 在 `N_i>0` 时为本组入选交叉熵均值，在 `N_i=0` 时定义为零。空组取零是记账约定，不表示该组安全。`q=0` 时本分解不定义，只保留主批损失。

记合法集合上确界为 `L*_{i,Δ}`，提议分布本质上确界为 `L*_{i,P}`，池内最大损失为 `Z_i`。则：

```text
C_i = L*_{i,Δ}−L*_{i,P}
E_i = L*_{i,P}−Z_i
T_i = Z_i−L̂_i
C_i+E_i+T_i = L*_{i,Δ}−L̂_i.
```

支持关系、采样来自同一提议核、入选均值不超池最大值及非负损失共同保证前三项非负；**单有非负损失不足以保证全部三项非负**。若 CE 的上确界无穷，不能以 `∞−∞` 做该分解；固定有限合法集合、有限 logits 可给此处所需的局部有限性，不等于对所有参数有统一 CE 上界。

令 `R*=Σ_i L*_{i,Δ}/n`、`R_S=Σ_i(N_i/q)L̂_i`，直接加减 `Σ_i L̂_i/n` 得：

```text
R*−R_S
= [R*−Σ_i L̂_i/n]+[Σ_i L̂_i/n−Σ_i(N_i/q)L̂_i]
= Σ_i(C_i+E_i+T_i)/n + Σ_i(1/n−N_i/q)L̂_i.
```

最后一项是等组权重与实际组权重的差，正负均可。纯代数示例取 `n=2,q=3,N=(1,2)`：`L̂=(2,1)` 时该项为 `1/6`，交换两个损失即为 `−1/6`。这些数只用于验算符号，不是实验读数。因全局重加权可能强调高风险组，甚至 `R*−R_S` 本身也未必非负。

**不把此式称为鲁棒风险上界、泛化界或优化误差保证。** 它没有控制任何一项的大小。其价值在于防止把选择偏好、不等组份额与搜索不足混为一谈。实际总损失的变体项还需乘 `q/(B₀+q)`；主批和良性项不属于这个等组变体参照。`F18` 与 `3A` 应合并，不分别计数。

此外，更改空组代表值会在保留项与权重修正间搬移数值而保持总和不变。因此四项不是未经约定就天然唯一的因果分解，不能仅据某项大就断言它造成实验增益。

### 3.5 `1B`：原证明允许边界组，命题包转述需修复

设内部组集合 `I={i:0<p_i<1}` 非空，有限固定组数、固定参数与成功率，组内独立同分布，内部最小成功率唯一为 `p_*`，固定正整数 Q。边界组 `p=0` 或 1 的分数全零，**可以存在**；它们不妨碍具有足够正分候选的内部组占满配额。

有限样本下，须选 `0<ε<min(p_*,1−p_*,Δ/2)`，并满足 `Q/K≤p_*−ε`；`Δ` 是内部最小概率到其余内部概率的最小间隔，只有一个内部组时删掉间隔条件。于是事件 `max_{i∈I}|M_i/K−p_i|≤ε` 保证目的组混合、成功候选至少 Q 个且计数严格最小；逐组 Hoeffding 加并集界给 `Pr(N_*=Q)≥1−2|I|exp(−2Kε²)`。组间独立不是该并集界的必要条件。

因此，E2 的“含边界组时结论不适用”和 E1 相同禁写项应改为“**目的地不得从边界组中选；没有内部组时全池为零分，由并列规则决定**”。不能省略 ε 与 `Q/K` 条件后将概率式当作任意有限 K 的界。若最小内部概率并列，不能保证流向一个指定组。

当前满配额 `Q=64,K=4` 下每组最多四个，至少需要 16 组；单组集中在此设定下不可能。该条件极限只能放附录，用于说明预算制度的边界，不得外推当前训练集中、更高 K 更好或更坏。

### 3.6 `3C`：缺口下界正确，精确概率要绑定并列顺序

E7 的构造用 `v=1−s`，第一组 `v∼U(0.8,0.9)`，第二组 `v∼U(0,0.6)`。第一组全成功、零分；第二组成功概率 `1/6`。计数事件 `E={Q≤M₂≤K−1}` 足以保证全部 Q 个入选来自第二组。因此式 3.7 的二项求和严格等于 **E 的概率**，且是一般固定并列规则下 `Pr(N₁=0,N₂=Q)` 的下界。

如果把第一组全部置于稳定候选顺序的前面，`M₂=0` 或 K 时零分并列先选第一组，且取 `Q≤K`，上述选择事件才与 E 相同；若未声明这条并列顺序，不能写无条件精确相等。式 3.8 的下界仍成立；`Q/K<1/6` 是必要适用条件。

在 E 上，`R*=log 5`、`R_S≤log(5/2)`，所以 `R*−R_S≥log 2`，此处独立复核成立。固定 Q、K 趋于无穷时 E 概率趋于一，因而它能反驳普遍一致性；其结论不是 F 的效果否决。两组、K=4、Q=64 时总池仅八个，全部保留，该反例不直接适用。有限离散版本也只是数学反例，不是 DRIFT 原始样本。

### 3.7 `3D`：条件极限成立，“相变”改为配额极限分配

完整前提应恢复为有限固定 n、同一无限采样序列的前 K 项、固定参数、`0<p₁<…<pₙ<1`、组内独立同分布，以及 `Q_K/K→β`、**`0<β<n`**。后者确保充分大 K 时 `q=Q_K`，且份额分母 β 非零。不得在 β=0 直接套式 3.13，或在 β>n 已全取时仍把实际 `q/K` 写为 β。

大数律使每组最终为混合组且成功计数顺序稳定；先按组号填正分成功容量、再按同序填负分失败容量。将有限池的 `min` 与正部表达式除以 K 并取极限，连续性直接给式 3.10–3.13。若概率并列或含边界组，排序稳定与零分容量必须另处理，现式不能直接沿用。

这是一条依赖强抽样条件的分段配额极限，不能写成当前模型发生了经验“相变”，也不证明任何性能提升。保留附录已经足够，不为把它搬进主文新增预算扫描或模拟实验。

### 3.8 其余必须保持的数学边界

- `F6/F7/2A`：阈值外，`ψ(ℓ)=ℓ+2(ℓ−log2)_+` 的梯度系数是 1 或 3；硬掩码数值与该连续函数相差 `2log2·Σh/D`。阈值处用上端次梯度 3 才对应代码的 `>=`，普通 ReLU 默认导数不能保证逐点相同。该局部关系不保证正式低误报工作点表现。
- `F15/2C`：固定候选、连续预测、所有候选离开阈值时，存在邻域使二值状态和稳定排序不变，选择器值局部常值。若要进一步称“几乎处处”，须说明阈值水平集的测度条件；仅由连续性不能推出阈值集合零测度。主文直接使用阈值外局部结论即可。
