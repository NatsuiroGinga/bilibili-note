## 一、结论

**对已经实施的 CARS/N14，否决成立。对“所有 route/selection 变体均不存在可利用信号”的全称判断，现有证据不足。** 两者不矛盾：当前正锚点不足以支持投入，并不需要以数学上排除整个方法族为前提。

路由方面尚存两个狭窄的证据缺口：**C00→char 的单侧替换是否存在稳定的相对收益，以及连续效用是否被当前分箱抹平。** 这两个缺口至多值得一次封顶的源期低成本审计，不构成恢复 CARS 立项的依据，也不应推迟下一候选的最小实验。

**TTA 的第一臂建议采用“迁移到 DRIFT 现有归一化层的 TENT”，而不是从完整 CoTTA 或自行设计安全博弈开始。** 若本地确认模型使用 LayerNorm，则第一臂只更新已有 LayerNorm 的仿射参数，使用无权重的预测熵损失，先预测、后更新，先在源期做 32 批次证伪。TENT 的原始算法明确区分这种在线顺序与“适应后再预测”的离线方式。([arXiv][1])

**TTA 在 T20–T25 上执行任何参数更新，都必须先获得独立协议授权。** “未使用标签”不等于“仍是静态只评价”：它利用了目标期输入更新模型，必须列为目标输入知情的无监督适应协议，不能并入原静态协议后宣称同条件胜出。TENT 与 CoTTA 本身也明确将目标无标签输入用于适应。([arXiv][1])

## 二、任务一：route 族否决的证据链审查

### 2.1 哪些结论成立，哪些存在外推

| 已报告实测                                            | 足以支持的结论                                                 | 尚不能支持的结论                                                            |
| ----------------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 同一逻辑在两次前向条件下出现 `net=-207` 与 `net=+713` | 当前收益没有通过数值稳定性要求；不能把正值实现单独作为正锚     | 条件化选择收益在所有表示和估计方法下必为零                                  |
| 正效用集中在 10 个候选 cell 中的 1 个，且贴近零       | 当前决策边际不足，符号容易受扰动影响                           | “只有一个有效 cell”本身就意味着无效；单个充分支持、收益稳定的区域也可能有用 |
| BA 为 0.9598，负锚为 0.9555                           | 必须解释相对负锚的 **0.43 个百分点**增量，而不能只展示绝对高值 | 仅凭增量小就判断统计不显著，或凭支路比例失衡就解释全部 BA                   |
| K4 与低阶键输出逐位相同                               | 当前 K4 构造、离散化及查询链路没有带来增量                     | 所有连续联合表示都没有信息                                                  |
| char 独对 97546，subword 独对 9135；挽回 6310 对 37   | 对称的“选哪支”可能不是最合适的动作空间                         | char 一定优于 C00，或整体弃用 subword 一定满足双侧风险门                    |

有一个指标口径必须纠正：**类别不平衡会抬高普通准确率，但不能直接解释标准 balanced accuracy 的高值。** 若 which-branch 任务只包含“char 独对”和“subword 独对”两类，恒选 char 的 balanced accuracy 应为 0.5，而不是接近 0.96。因此，10.7∶1 可以质疑问题设定和样本权重，却不能替代对 BA 定义、评估子集以及相对负锚增量的核查。

另外，本报告接受交接包对 MPS 非确定性的归因作为已报告结果，但没有独立验证其根因。就当前决策而言，**不论噪声来自前向计算还是其他未控制因素，收益符号不稳定这一事实已经足以阻止把它当作稳定正锚。**

### 2.2 单侧弃用 subword：问题确实更简单，但风险冲突没有消失

设 \(h_0(x)\) 为 C00，\(h_c(x)\) 为 char 反事实动作，标签 \(y=1\) 表示 DGA。真正应估计的是：

$$
u_c(x,y)
=
\mathbf 1[h_c(x)=y]
-
\mathbf 1[h_0(x)=y],
$$

而不是“char 是否比 subword 更容易选对”。

这属于已有的 **learning-to-defer／成本敏感选择**问题：评价的是“基础预测器＋选择动作”的系统损失，不是单独的专家识别准确率。Mozannar 与 Sontag 的原始形式化直接以此为目标，不能把这种目标修正本身作为新方法。([Proceedings of Machine Learning Research][2])

支路不对称只说明可以把三动作缩减为 \(\{C00,\text{char}\}\)，并不说明 \(u_c\) 可学习，更不说明它在良性和 DGA 两侧同时有利。特别是，**6310 个挽回必须与同一替换策略造成的 induced errors 配对看**；目前摘要没有给出全局 C00→char 的完整双侧交换表。

还有一个可以零训练验证的结构性边界：

$$
\begin{aligned}
\text{仅允许 }1\rightarrow0\text{ 的替换}
&\Rightarrow \Delta FP\le0,\quad \Delta FN\ge0;\\
\text{仅允许 }0\rightarrow1\text{ 的替换}
&\Rightarrow \Delta FP\ge0,\quad \Delta FN\le0.
\end{aligned}
$$

因此，“只在 char 判良时弃用 subword”可以在决策层面保证 FPR 不增，却不能单靠这类替换改善 FNR；反向替换可以修复漏判，却不能自动保护 FPR。**单侧动作空间更简单，不等于双侧风险问题更容易解决。**

### 2.3 是否遗漏了可行变体

目前的正锚设计没有充分覆盖三种情况，但它们的证据地位不同。

**连续相对效用。** 当前离散键相同，不排除连续变量在分箱内部仍保留相对收益差异。这是估计器覆盖不足，不是已发现收益。

**C00→char 的非对称替换。** 它不再学习哪个支路强，而只学习何时替换基础动作。相比对称路由，标签目标和动作空间都更直接，但必须重新对齐 C00 的修复与伤害。

**重新训练 char-only 或静态再融合。** 冻结反事实动作不等于一个单独训练的字符模型。现有诊断不能否决后者；但后者已经属于架构消融或重新训练基线，不是 CARS 的零训练翻案，预算也不同。

这三个“未覆盖”都不应被表述成“可行性已成立”。

### 2.4 一次封顶的翻案审计，而不是继续搜索路由

建议仅保留如下**源期审计规格**，不自动恢复项目。

| 步骤               | 操作                                                                             | 能回答的问题                                   |
| ------------------ | -------------------------------------------------------------------------------- | ---------------------------------------------- |
| R0：零训练动作审计 | 用已有冻结输出，计算全局 C00→char 的良性/DGA 配对交换表，并分别统计两种翻转方向  | 单侧问题是否连最基本的净收益结构都不存在       |
| R1：有限分箱对照   | 在 T17 上固定同一低阶连续分数，预先限定粗、细两种分箱；不根据 T18 结果继续改边界 | 当前失败是否主要来自分辨率选择                 |
| R2：一个连续估计器 | 只用已有低阶连续量，拟合一个带正则的线性相对效用模型；不增加深网络和新表示       | 分箱是否抹去了平滑的相对收益                   |
| R3：稳定性审计     | 同缓存比较策略，再在预先固定的重复前向条件下比较决策和配对收益                   | 收益是否大于数值不确定性，而不是一次前向偶然值 |

这里的连续模型应预测 \(u_c\)，而不是另训一个高 BA 的 which-branch 分类器。通过条件也不能只是 `net>0`：至少需要**相对 C00 的收益符号稳定、良性误报门不被违反、DGA 修复确有增量，并且不能仅依靠一个贴零的经验均值作决策**。

有限候选的风险检验可以借鉴 Learn then Test 的多重检验框架，但其校准假设不能被外推为跨年漂移下的无条件保证。([arXiv][3])

**T18 已经参与本次诊断，重设计后再看 T18 只能算探索性分析。** 新正锚需要既有、合法且未参与这次重设计的源期预留分区；没有这样的分区，就不能把重复使用 T18 包装成独立确认。

综上，我不建议据此恢复 CARS。这里指出的是“族级否定”的逻辑边界，而不是推翻当前否决。

## 三、任务二：TENT、CoTTA、SAR 的家族机制与 DRIFT 适配性

### 3.1 原始机制对照

| 家族      | 原始机制                                                                                    | 在 DRIFT 中的迁移判断                                                                        |
| --------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **TENT**  | 最小化预测熵；更新归一化层仿射参数，原实验还重新估计 BN 统计；其余参数冻结                  | 组件少、无需数据增强，适合第一证伪臂。但必须核对真实归一化层，不能默认存在 BN                |
| **CoTTA** | 教师—学生一致性；教师参数移动平均；按源模型置信度使用增强平均伪标签；学生参数随机恢复到源值 | 适合讨论长期持续适应，但域名增强的标签保持性尚未建立，且教师、学生、多视图增加实现和计算变量 |
| **SAR**   | 可靠样本筛选＋尖锐度感知熵最小化；以熵移动平均触发模型恢复                                  | 对 LN/GN、动态类别分布、小批量问题有直接方法依据；适合 TENT 后的近邻扩展，但不是双侧风险保证 |

原始出处分别为：Dequan Wang 等，ICLR 2021，TENT §3.1–3.3；Qin Wang 等，CVPR 2022，CoTTA §3.1–3.2、Algorithm 1；Shuaicheng Niu 等，ICLR 2023，SAR §3.1–3.2、§4、Appendix B。上述论文的实验不能直接写成 DRIFT 上的有效性证据。([arXiv][1])

### 3.2 第一处迁移陷阱：LayerNorm 不是 BatchNorm

交接包给出了 Transformer 结构，但没有给出归一化模块清单。若模型采用 LayerNorm：

- 不存在可跨批次更新的 BN running mean/running variance；
- “只更新 BN 统计”不是一个有效实验臂；
- 可更新对象是现有 LayerNorm 的缩放、偏移参数，而不是新插入一个 BN 模块。

LayerNorm 以单个样本内部的激活计算归一化统计，不能把它当作 BN 的目标域统计适应。([arXiv][4])

所以第一臂应明确命名为 **TENT-LN：TENT 在现有 LayerNorm 仿射参数上的迁移实现**，而不是声称逐项复现 TENT 原始 BN 配置。若本地发现实际含 BN，则应另外区分“统计更新”和“仿射参数优化”，不能将二者效果混在一起。

### 3.3 第二处迁移陷阱：删掉增强不一定得到可工作的 CoTTA

CoTTA 的伪标签来自教师，学生拟合其停止梯度的软分布。其增强平均、教师移动平均与随机恢复是不同作用的组成部分。([arXiv][5])

**本报告推导：**设无增强、无随机扰动、教师和学生初始化完全相同，教师输出为 \(q\)，学生输出为 \(p\)。软交叉熵对学生 logit 的梯度为：

$$
\nabla_z \operatorname{CE}(\operatorname{stopgrad}(q),p)=p-q.
$$

初始点 \(p=q\)，梯度为零。此时移动平均和恢复也不能凭空创造有效更新。硬件数值噪声不是一个有依据的增强策略。

因此，不能把“CoTTA 去掉所有域名增强”直接当作最小有效臂；更不能通过任意字符删除、置换或替换来补齐增强，而不证明它们保持检测标签。**从 CoTTA 单独取随机恢复组件是可定义的实验，但必须命名为“TENT＋随机恢复”，不是完整 CoTTA。**

### 3.4 第三处迁移陷阱：SAR 的可靠性不等于分类正确性

SAR 以低于阈值的熵筛选样本，再做尖锐度感知更新；恢复机制使用熵移动平均。原文位置为 §3.2、式（2）—（6）与 Appendix B Algorithm 1。([arXiv][6])

迁移到二分类时必须区分两个阈值：可靠样本阈值与模型恢复阈值。原文的可靠性阈值按类别数缩放，而恢复阈值采用具体的原始熵数值。不能把 ImageNet 配置原封不动搬到高置信二分类器。([arXiv][6])

特别是：**若健康的源模型本就大量输出低于恢复阈值的熵，恢复机制可能持续触发，把适应臂退回 P0。** 反过来，高置信错误也可能通过可靠性筛选。是否存在这些情形，只能用源期诊断确认。

## 四、第一个证伪实验：TENT-LN，32 批次源期演练

### 4.1 实验问题与解释上限

第一个实验只回答：

> **在不改变分类头、分支结构和监督目标的前提下，归一化仿射参数上的在线熵更新，能否产生超出数值噪声的有效变化，而不立即重现双侧风险取舍或源期退化？**

它不负责证明未来漂移适应，也不负责确认论文创新。

还必须区分两种模型起点：

**使用现有 T17–T19 训练的 C00，在 T18 上遮蔽标签演练：**可以证伪稳定性，但 T18 不是该模型的干净“伪未来”。遮住适应器的标签，不会消除基座训练时已经接触该年份的事实。

**使用截止时间正确的源模型，例如仅以 T17 训练、在 T18 演练：**才可以构成源期时间外推证据。是否已有合法的此类本地模型，当前摘要未说明；不能假定存在。

因此，最省预算的第一轮可以使用现有 C00，但结果必须标记为 **source-period stability screening**。若通过，下一阶段再补截止时间正确的源期验证，而不是直接进入 T20。

### 4.2 参数、损失和更新规格

以下是**建议固定的第一轮规格**，不是已验证最优配置。

| 项目         | 第一臂规格                                                             |
| ------------ | ---------------------------------------------------------------------- |
| 基座         | 同一 C00；相同分词、特征处理与分类阈值                                 |
| 更新参数     | 本地确认存在的 LayerNorm 仿射参数 \(\eta=\{\gamma,\beta\}\)            |
| 冻结对象     | embedding、attention、FFN、池化、融合与分类头的其他参数                |
| 运行状态     | 保持原推理行为；不因启用梯度而意外打开 dropout 或更新其他状态          |
| 损失         | 未加权二分类预测熵                                                     |
| 优化器       | SGD，momentum 0.9，学习率 \(10^{-3}\)，weight decay 0                  |
| 批量         | 64；每批一次更新                                                       |
| 初始更新预算 | 32 批次，即 2048 个无标签适应输入                                      |
| 不加入       | 伪标签监督、增强、可靠性筛选、多样性项、恢复、教师模型、路由和风险乘子 |
| 模型选择     | 固定第 32 步终点；不从中间轨迹挑最优检查点                             |

优化器、批量和学习率取自 SAR 文献中针对 ViT/TENT 的参考配置，目的在于从成熟实现附近起步，不代表适合 DRIFT 的参数已经得到证明。([arXiv][6])

令其余冻结参数为 \(W_0\)，模型 DGA 概率为：

$$
p_\eta(x)=f_{W_0,\eta}(x).
$$

批次损失为：

$$
L_H(B;\eta)
=
-\frac{1}{|B|}
\sum_{x\in B}
\left[
p_\eta(x)\log p_\eta(x)
+
(1-p_\eta(x))\log(1-p_\eta(x))
\right].
$$

这是 TENT 的预测熵目标在二分类下的直接形式，不是新损失。([arXiv][1])

设 \(\eta_0\) 为源模型参数，\(v_0=0\)。每批按下列顺序处理：

$$
\begin{aligned}
\text{输出并锁定预测：}\quad&
p_b=f_{W_0,\eta_{b-1}}(B_b),\\
\text{计算更新：}\quad&
v_b=0.9v_{b-1}+\nabla_\eta L_H(B_b;\eta_{b-1}),\\
&\eta_b=\eta_{b-1}-10^{-3}v_b.
\end{aligned}
$$

**当前批次的评价使用第一行输出，不以更新后的重算结果替换。** 这与 TENT §3.3 的默认在线顺序一致。([arXiv][1])

第一臂不加“鼓励类别均衡”的多样性损失。对域名流而言，强迫一个批次接近均衡预测会引入未经证明的类别先验；是否加入此类项必须成为独立消融，而不是默认防坍塌措施。

### 4.3 三个必要控制条件

第一轮不需要八个训练臂，只需要三个条件：

| 条件     | 内容                                       | 作用                                       |
| -------- | ------------------------------------------ | ------------------------------------------ |
| C00      | 原始静态推理                               | 唯一基准                                   |
| Sham-TTA | 相同封装和数据路径，但不改变任何参数或状态 | 排除推理模式、缓冲区、数值路径引入的伪增益 |
| TENT-LN  | 上述 32 步适应                             | 检验最小机制                               |

对于纯 LN 且关闭随机性的模型，Sham-TTA 应与 C00 一致到预先定义的数值容差。**仅令学习率为零，不足以证明是零更新控制**：若实际包含 BN 或其他可变状态，仍可能发生改变。

考虑到本次 CARS 已报告符号级数值脆弱性，若 Sham-TTA 本身就改变硬判定或关键收益符号，第一轮应先停止机制解释，而不是把差异计为适应收益。

### 4.4 数据、评分与预算

建议将已有、合法的源期验证部分预先划为三个不重叠用途：

| 用途             | 建议规模 | 使用方式                           |
| ---------------- | -------: | ---------------------------------- |
| 无标签适应前缀   |     2048 | 按固定顺序组成 32 个批次           |
| 后续源期探针     |     8192 | 第 32 步后仅前向评分，不继续适应   |
| 源模型保持性探针 |     4096 | 对独立的较早源期验证部分仅前向评分 |

这些规模是预算建议，不是对现有数据划分的事实断言。若现有冻结划分不允许这样取样，应遵循原划分，不得为了补足数字混入训练样本并称为验证。

适应器不接触探针标签。适应轨迹固定后，独立评分器才汇总 FPR、FNR、配对翻转，以及源期保持性指标。未见家族指标只有在基座训练截止和家族定义均合法时才有解释力。

预算主要是 **32 次适应反向传播，加上固定探针前向**。只训练少量参数并不意味着不需要经过整个网络的反向路径，不能用参数比例直接宣称同等比例的计算节省。

### 4.5 第一轮停止与晋级条件

**立即停止解释的情况：**出现非有限数值、Sham-TTA 不能对齐、错误更新了参数范围外对象，或者数据流/评分顺序不符合预注册。

**当前臂的负证据：**在固定源期探针上 FPR 恶化；或 FNR 下降但 FPR 上升；或源期保持性违反既有冻结门。不能从中途挑一个未恶化的步骤替换固定终点。

**尚不构成正锚的情况：**参数没有有效变化、全部预测几乎相同、收益落在数值不确定性内，或样本量不足以区分伤害与收益。它们应记为“未获得正证据”，不能视为成功，也不能据此否定整个 TTA 家族。

**足以进入下一轮源期验证的条件：**适应确实改变了预测，配对收益不是噪声，满足既有源期双侧风险门，并在预先指定的漏判指标上出现改善。这里的“进入下一轮”不是授权接触未来年份。

## 五、协议四项建议：必须与静态 DRIFT 分开

### 5.1 到达顺序：先确定观察过程，再讨论适应效果

若存在真实且合法的到达时间，应按该顺序处理。若年度面板只是一组样本，则可以采用预先固定的记录顺序或标签无关排列，但必须称为**年度面板上的在线适应模拟**，不能声称还原了真实到达流。

不能利用目标标签或家族标识组织批次，不能先平衡目标年份的良性/DGA 比例，也不能在看到未来结果后选择最有利的顺序。

所有方法共享顺序和批边界。顺序敏感性可以在 T17–T19 研究，未来顺序不得成为调参变量。SAR 对动态类别分布和批量条件的分析说明这些因素会影响 TTA，但不意味着其具体结论已在 DRIFT 得到确认。([arXiv][6])

### 5.2 无标签接口：目标输入知情，不是目标标签知情

适应器在批次 \(b\) 最多可见已到达输入 \(B_1,\ldots,B_b\) 及内部模型状态。不得看到未来批次、目标标签、家族身份、当年整体类别比例，或基于目标标签计算的“安全评分”。

需要明确披露：

> 本方法在预测后使用已到达目标域无标签输入更新指定参数；超参数、阈值、更新预算和恢复规则全部由源期确定。

这属于 TTA 的信息条件，与完全静态推理不同。([arXiv][1])

**若冻结合同中的“只评价”禁止测试期更新模型，那么 TTA 目前只能停留在源期候选设计。** 必须由本地先批准新的适应协议，不能由外部报告将它解释为已经获准。

### 5.3 更新对象与跨年状态：两种协议不能混用

建议把以下两种状态规则明确区分：

| 协议                 | 年内           | 年界                                         | 主要问题                           |
| -------------------- | -------------- | -------------------------------------------- | ---------------------------------- |
| **年度重置在线适应** | 参数随批次更新 | 每年恢复同一 C00，并清空优化器及其他适应状态 | 每个年度分布内能否安全适应         |
| **跨年持续适应**     | 参数随批次更新 | 从 T20 一直承接到 T25                        | 长期漂移下是否累计错误、遗忘或恢复 |

第一种更适合最初的逐年对照；第二种更接近 CoTTA 的持续适应问题。不能在结果出来后对每年择优选重置或不重置。CoTTA 原文将持续输入上的误差积累与遗忘作为核心问题。([arXiv][5])

授权后，年度正式适应应对当年合法输入**按块单遍处理全部流**，而不是只适应标签评价后挑出的困难样本。第一轮的 2048 输入限制仅用于源期证伪预算。

### 5.4 静态与适应分表

主报告至少区分：

**静态表：**保留原 C00 与原静态协议基线，不改变其信息条件。

**在线适应表：**C00 作为共同参照，同时比较 TENT-LN、SAR 等适应方法，统一批量、顺序、阈值、年界状态和输出时点。

“适应完整个年份，然后重新预测该年份”是另一种离线、传导式评价，应单独列示，不能替换先预测后更新的在线结果。TENT 原文明确区分二者。([arXiv][1])

未来年结束后可以对适应模型进行离线源期保持性审计，但**评分结果不能反馈为下一年的更新选择或停止信号**，否则实际协议又增加了额外监督反馈。

## 六、是否重蹈 M1-v2 与 N12：预判及可证伪检验

### 6.1 反驳一：TTA 只是把约束冲突换了位置

**判断：最小 TENT 臂没有重现 M1-v2 的同一个优化结构，但并未消除同一个风险问题。**

M1-v2 使用多个目标和约束，并出现投影归零。这里首先只有熵目标，不引入双侧乘子或梯度投影，因此不会在算法结构上立即复刻“约束梯度相反→投影为零”。

但设一次实际参数步为 \(d\)，源期良性与 DGA 风险代理梯度为 \(g_b,g_m\)，则局部上：

$$
\Delta L_b\approx g_b^\top d,\qquad
\Delta L_m\approx g_m^\top d.
$$

熵下降与这两个内积的符号没有必然一致关系。

**证伪检验：**在源期的固定诊断批次上，离线比较实际更新方向与两侧风险梯度；再检查固定终点的硬判定变化。若熵下降持续对应某一侧风险上升，TTA 只是改变了更新依据，没有找到双侧改善方向。梯度分析只用于解释，不得偷偷加入新约束训练。

若后续加入 Fisher 正则，正则梯度在源初始点为零，不会必然重现 M1-v2 的初始边界冲突；但参数偏离后仍可能与熵更新对抗、压回近零更新。EATA 的相应形式见 §4.2、式（7）—（9）。([Proceedings of Machine Learning Research][7])

### 6.2 反驳二：它仍然是 N12 的良性/DGA 双侧取舍

**判断：这是最需要防范的经验性反驳。** 换成无标签目标不代表跨越了原来的取舍结构。

令 \(n^{b}_{a\to c}\) 表示良性样本从 C00 判定 \(a\) 变为适应模型判定 \(c\) 的数量，\(n^m\) 类似表示 DGA。则：

$$
\Delta FP=n^b_{0\to1}-n^b_{1\to0},
\qquad
\Delta FN=n^m_{1\to0}-n^m_{0\to1}.
$$

**证伪检验：**使用同一批样本的配对交换表，而不是只比较总损失或 AUROC。若漏判修复被新增误报购买，或者误报降低来自更多恶意样本被判良，就没有跨过本课题要求的门。

N12 的负结果不能演绎证明 TTA 也失败，因为这里改变了输入信息条件与更新子空间；但它足以要求把“双侧交换”保留为首要判据，而不是等主指标好看后再检查。

### 6.3 反驳三：熵越低，可能只是错得越自信

令 \(p=\sigma(z)\)，则：

$$
\frac{\partial H(p)}{\partial z}
=
p(1-p)\log\frac{1-p}{p}.
$$

这是直接求导结果：熵最小化倾向于强化已有预测方向。它并不知道一个高置信预测是否错误。

因此，可能出现良性误报被强化、恶意漏判被强化，或者模型逐步预测成同一类。SAR 的原始失败分析也讨论了熵适应中的类别坍塌。([arXiv][6])

**证伪检验：**在源期把样本按 C00 正确/错误、良性/DGA 分成固定诊断组，离线统计熵变化与决策翻转。若熵下降主要来自原有错误变得更自信，而修复不足，即为“熵陷阱”，不应计为适应进展。

更根本地说，**仅凭无标签输入，不能对任意漂移保证 FPR 不增。** 两个环境可以有相同的 \(P(X)\)、不同的 \(P(Y\mid X)\)；适应器看到相同输入并执行相同更新，却产生不同的误报风险。这是信息不足的反例，不是某个 TTA 家族特有的缺陷。

## 七、通过门、失败门与停止规则

### 7.1 相对静态 C00 的正式评价门

在本地批准适应协议后，对每个未来年 \(t\) 定义：

$$
\Delta FPR_t
=
FPR_t^{\mathrm{TTA}}-FPR_t^{C00}.
$$

核心安全要求保持为：

$$
\forall t\in\{2020,\ldots,2025\},\qquad
\Delta FPR_t\le0.
$$

收益要求是预先指定的 FNR 或未见家族 FNR 改善，且源期保持性通过。**既有合同已定义的指标聚合方式应原样继承。** 若尚未定义，建议本地在解封前指定其中一个为主要收益终点，并固定逐年或年度宏平均口径，不能事后在两个指标中选择较好者。

“源年不塌”的具体数值容忍度没有出现在本轮摘要中。本报告不补写一个宽松阈值替代冻结合同。

同时区分：

- **经验门：**在固定样本上的实际配对 FP/FN 是否满足要求。
- **统计证据：**差异的不确定性有多大，是否受重复域名、同族相关性等影响。

“不显著增加”不能替代“已经证明不增加”。反过来，样本量不足也不应被写成方法族被证伪。

### 7.2 建议预注册的失败形态

| 失败形态           | 读数结构                             | 解释                               |
| ------------------ | ------------------------------------ | ---------------------------------- |
| **误报型熵陷阱**   | 熵下降、FNR 下降、FPR 上升           | 漏判收益以良性伤害为代价           |
| **良性塌缩**       | FPR 下降、FNR 上升，恶意预测显著减少 | 不是真正的安全适应                 |
| **未见家族排斥**   | 总体改善，但未见家族 FNR 恶化        | 可靠性筛选可能只服务已有高置信区域 |
| **源期遗忘**       | 适应域改善，源期保持性不通过         | 不能以目标收益覆盖源风险           |
| **恢复退化**       | 频繁恢复、净更新接近零               | 不能把回到 C00 当作成功机制        |
| **空筛选退化**     | 可靠样本几乎为零                     | 参数或筛选尺度不适配               |
| **评价时序伪增益** | 同批后更新重算有收益，在线输出无收益 | 只支持另一种传导式协议             |
| **数值级伪增益**   | 配对收益符号随重复前向翻转           | 不满足本课题已有稳定性要求         |

未来标签只用于最终评分。任何基于未来 FPR/FNR 的中途停止、恢复或学习率调整，都不属于这里的无监督在线协议，不能事后加入。

## 八、第一臂通过后：第二组件与八臂消融如何衔接

### 8.1 第二组件优先取 SAR 的可靠性筛选

**首选是 SAR 的可靠样本筛选，而不是新的可学习安全路由器。**

理由是它与 TENT 的距离最短：保留同一模型、同一参数集合和同一熵目标，只改变哪些样本参与更新。随后再加入 SAR 的尖锐度感知优化，才能分别回答“样本筛选是否有用”和“优化平滑性是否有用”。SAR 本身已包含这两个机制，必须保留其名称与出处。([arXiv][6])

在后续受控迁移臂中，可写为：

$$
r_i
=
\mathbf 1\!\left[
\frac{H(p_i)}{\log 2}<q
\right],
\qquad
L_R
=
\frac{\sum_i r_iH(p_i)}
{\max(1,\sum_i r_i)}.
$$

空筛选批次跳过更新。归一化阈值 \(q\) 必须源期固定；使用类别数归一化只是避免直接复制多分类熵尺度，**不等于已经完成 DRIFT 阈值校准**。

尖锐度组件则围绕同一个损失计算参数邻域扰动。为隔离组件效果，关闭可靠性筛选时令所有样本权重为 1，关闭尖锐度组件时回到普通梯度步。这自然形成对既有组件的 \(2\times2\) 消融，但**不是两个原创机制**。

### 8.2 上一轮八臂不能直接改标签复用

上一轮八臂是：

**C00、C-H、C-STACK、C-MOE、C-L2D、C-A、C-K、CARS。**

它们分别围绕静态锚点、置信选择、静态再融合、普通门控、绝对正确性、优势头、键结构与完整保护路由展开，是路由机制消融，而非 TTA 消融。

本轮应继承的是“基线→成熟近邻→组件消融”的论证方式，不是继续运行这些已失去立项基础的路由臂。

### 8.3 新的八臂候选清单

以下是**分阶段计划**，不是第一轮全部启动的清单。

| 编号 | 臂                          | 所回答的问题                             |
| ---- | --------------------------- | ---------------------------------------- |
| T00  | C00                         | 静态锚点                                 |
| T01  | TENT-LN                     | 熵适应本身是否有净收益                   |
| T02  | TENT-LN＋可靠性筛选 \(R\)   | 是否由参与更新的样本质量决定收益         |
| T03  | TENT-LN＋尖锐度组件 \(S\)   | 不筛样本时，参数邻域优化是否有增益       |
| T04  | TENT-LN＋\(R+S\)            | SAR 核心组合是否优于两个单组件臂         |
| T05  | T04＋源期校准的恢复机制     | 恢复是否减少长期失败，而不是抹掉全部适应 |
| T06  | TENT-LN＋CoTTA 随机恢复组件 | 显式拉回源参数是否比无恢复更稳定         |
| T07  | TENT-LN＋EATA Fisher 保护项 | 源参数重要性保护是否缓解遗忘             |

T01–T04 是自然的 \(R/S\) 消融。T05 的恢复阈值必须考虑二分类源模型熵分布；T06 不能叫完整 CoTTA；T07 不能叫完整 EATA。EATA 的原方法还包含可靠与非冗余样本选择，Fisher 重要性则由一小组无标签同分布样本及伪标签估计。([Proceedings of Machine Learning Research][7])

为避免把参数范围变化当作算法收益，T01–T04 应使用相同的可更新参数集合。原 SAR 的具体实现还涉及层范围选择，因此“匹配参数范围的 SAR 迁移消融”和“尽量忠实原配置的 SAR 基线”需要明确区分。([arXiv][6])

**这套八臂不等于第三章创新已经成立。** 若 TENT 或 SAR 的成熟组件已经赢过 C00，首先得到的是家族资格与有效基线；要成为机制章，还需要在获得批准的相同适应协议下，与成熟 TTA 近邻比较，并证明任务化改造的独立贡献。不能把“增加目标期无标签信息后胜过静态 C00”直接当作原创机制优越性。

## 十、仍未回答、但会改变实施规格的问题

目前无法由脱敏摘要确定：DRIFT 实际归一化层和可变状态清单；年度面板是否具有真实到达顺序；既有源期验证划分是否允许独立适应前缀与保持性探针；是否存在训练截止时间正确的源模型；“源年不塌”和主要收益终点的冻结数值口径；以及原合同是否允许未来无标签输入驱动参数更新。

这些不是要求提供私有材料，而是本地执行前需要核对的条件。本报告也没有证据证明 TENT-LN、SAR 或 CoTTA 能在 DRIFT 上改善任何指标。

**建议的执行顺序是：维持当前 CARS 不立项；先确认归一化与协议边界，再做 C00／Sham-TTA／TENT-LN 的源期 32 步证伪。只有在得到非零、稳定且满足双侧风险门的源期信号后，再进入 SAR 组件拆分与截止时间正确的源期验证。T20–T25 在此之前不参与设计、选择或试错。**
