## 阅读约定

表 1、7—10、15—16 的数值沿原表百分数尺度；表 12、14 沿原表 0—1 尺度。± 保留作者所报数值，不改称置信区间。监督实验正文说对五次运行及切分内年份汇总，不能把全部标准差视为纯种子方差。

FPR = FP/(FP+TN)，FNR = FN/(FN+TP)。官方监督代码把 `average_precision_score` 输出命名为 PR AUC；本账本保留论文列名，但复核时应注明其实际计算为 AP。

以下不是对所有图点的数字化：图中没有可直接核对的精确点值者列在末尾，不凭视觉补数。
