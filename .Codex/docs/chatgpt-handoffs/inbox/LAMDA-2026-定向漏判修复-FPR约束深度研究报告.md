## 核心判断

1. 没有成熟的单一持续学习算法能够在未知未来分布上数学保证 FNR 下降且 FPR 永不增加；应把 FPR 写成独立、时间一致的已标注良性门控约束，并把恶意漏判修复作为优化目标。
2. 最直接的外部候选是“历史真实恶意漏判定向回放＋Positive-Congruent Training（PCT）／Focal Distillation＋独立 FPR gate”。报告明确说明这是基于已有方法的组合设计，不是 PCT 原论文已经提出的 Android 专用算法。
3. PCT 的保护对象是旧模型正确决策，不能单独承担 FPR 保证；FPR constraint/gate 仍需在独立良性集合上验收。
4. Android 领域的 hierarchical contrastive active learning 可用于决定哪些新样本进入人工复核，但未确认标签不得直接进入修复损失。
5. DGR、TERM、A-GEM、IWMS 和 DREAM 应作为后续增强件或直接对照。它们没有“FPR 不增加”的直接保证；IWMS 还存在把预测为良性的真实恶意样本路由到错误记忆类别的风险。

## 与本地实验的对应

- 阶段 C 等单位风险损失使开发期 FPR 从 `0.013148155` 升到 `0.089252353`，支持停止无差别风险损失。
- 双风险投影使 FPR 从 `0.013148155` 降到 `0.012231661`，但 FNR 从 `0.059478156` 升到 `0.070306038`，支持停止始终投影作为主机制。
- 因此当前 GPU 筛选仍先验证“缺口感知恶意修复＋冲突触发风险门控”的最小四臂；若恶意修复出现独立信号，再取得 PCT 原文并追加 PCT/Focal Distillation 对照，不把网页建议直接当作已验证实现。
