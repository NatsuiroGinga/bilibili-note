# 补充消息：v2 复筛后新增零训练探针结果（对主任务的证据更新与问题聚焦）

（本消息接续 `lamda-dual-player-v2-next-step` 交接包；同一运行、同一评价口径，四臂逐样本预测的独立复算与训练期指标偏差为 0。以下读数全部为来源年/开发年期筛选层证据，封印年 2018-2025 未读取。）

## 新增实测：漏判样本与良性分布的邻接结构（零训练，直接统计 ER 臂与缺口修复臂的开发年逐样本分数，阈值 0.5）

**发现一：ER 的漏判恶意不是被埋没在良性低分区的。**
- 2016：498 个漏判恶意中，96% 分数高于良性中位数，77% 高于良性 P90；漏判分数十分位 [P10,P50,P90]=0.0083/0.1224/0.4413。漏判 vs 全部良性的 hard-pair AUC = 0.903。
- 2017：238 个漏判，87% 高于良性中位，63% 高于 P90；hard-pair AUC = 0.830。

**发现二：拦路的是良性上尾，且阈值路径无解。**
- ER 良性分数分位 [P50,P90,P99]：2016 = 0.0032/0.0252/0.9100；2017 = 0.0017/0.0073/0.2108。良性上尾与漏判区间重叠。
- 把阈值降到能修回一半漏判：新增误报 +611（2016）/+715（2017），是基线误报数（275/102）的 2.2~7 倍；修回全部漏判需移动阈值到最低漏判分数处：新增 +11027/+15049。

**发现三：缺口修复臂的误报爆炸是"波及"，不是"代价交换"。**
- 缺口臂新增 FP 中，判为误报的良性样本有 88%（2009/2282，2016）与 96%（1748/1823，2017）是 ER 臂原本判对的良性——修复训练把原本正确的良性推过阈值。
- 波及是整段良性高分区：缺口臂良性 P90 从 ER 的 0.025 抬到 0.844（2016）、0.007 抬到 0.561（2017）。
- 更糟的是 2017 缺口臂自己漏判反增（451 vs ER 238），修复收益在该年被漂移吞掉。

## 由探针修正的自我判读（请审查此判读是否成立）

此前五代替换式实现（一侧安全记忆 BCE、角色配额双侧、梯度投影、条件门控、双玩家乘子）全部是**被动抑制**——"约束别抬 FPR"。探针提示作用对象选错：受保护的是"上一模型判对良性"的历史参考集合，而实际损伤发生在**当年训练分区中分数最高的那批良性**上（它们被判对，但不在保护参考内或被更新波及）。乘子更新频率、触发条件属于次要参数，作用面错位才是主因；双玩家单臂修复候选恒为 0 是该错位的轻症表现。

## 据此聚焦后的问题（替代/细化主任务 (a)-(d)）

1. **判读核验**：上述"作用面错位"解释与三组数字是否自洽？有没有替代解释（例如该良性高分区本身与漏判恶意在特征上不可分，任何保序更新都必然波及）？若存在替代解释，给出能在来源年零训练区分两者的统计检验设计。
2. **尾锚推回设计**：若按"对当年已到达训练分区内分数最高的 K 个良性样本施加显式推回/锚定约束，与缺口修复损失联合训练"做下一臂——K 的确定、推回强度、锚定目标（固定分数/排序/梯度投影）各自最合理的起始形式与文献出处？PBR、CBRS、ECBRS/PAPA、FreeMOCA 在此问题上的机制区别与可用性逐条对照，不得混述。
3. **分离性判决标准**：如果尾锚臂仍然把良性高分区抬穿阈值（可观测：与 ER 相比良性 P90/P99 位移 + 新增 FP 溯源比例），是否即可判"同一输出头下修复与保护梯度不可分"，从而正当转向表述层改革（分离头、排序目标、表征层）？该推断需要什么附加证据才能成立（防止归因过早）？
4. **硬门槛更新**：在"新增 FP 溯源比例（ER 判对良性被推过的比例）"已可计算的条件下，下一臂的通过门应如何把它与既有 FPR/负向翻转/修复率门槛组合，才能既严格又不重复？
5. 输出继续要求：全部为外部候选建议；每条建议标注支持证据与可证伪实验；涉及文献给原始出处、页码或公式编号。
