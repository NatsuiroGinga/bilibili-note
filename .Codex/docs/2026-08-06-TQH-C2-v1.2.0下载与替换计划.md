## 文件策略

- 复用且重新校验：A 测试床 PCAP、C 测试床 PCAP、脚本包。三者与本机旧版的 SHA-256 完全一致，以硬链接进入新版本目录。
- 重新下载：B 测试床 PCAP、A/B/C 特征包、A/B/C 标签包。
- 新增下载：D 测试床 PCAP、D 特征包、D 标签包。
- 直接下载：`README_v120.md` 与 `SHA256SUMS_v120.txt`。

## 验收与删除门槛

1. 1.2.0 清单中的十个文件全部存在。
2. 全部文件通过官方 SHA-256 校验。
3. 全部 ZIP 通过压缩包完整性检查。
4. 文件清单、版本、来源和校验结果落盘。
5. 满足以上条件后，删除旧版 `raw/datasets/TQH-C2-2026/`；实验工程中冻结的派生视图、配置和历史结果不删除。

## 边界

- 旧版 B 测试床是约 18 GB 的失效单向采集，不复用。
- 1.2.0 的 A/C/脚本虽复用相同字节，但仍必须以 1.2.0 官方清单重新验收。
- 下载、校验和删除均在本机执行，不占用 GPU 服务器。
