# 理论补充筛选笔记

## 证据等级

- **A 级**：已核对原文或详细结构化笔记，可作为方法推导依据。
- **B 级**：理论相关，但需要回到原文核对假设、公式和证明条件。
- **C 级**：只能作为研究动机或相关工作，不能直接支撑本论文方法。
- **排除**：与可观测变量、任务或基座不匹配。

## 筛选标准

1. 理论变量能从选定数据和模型输出中计算。
2. 理论能够进入目标函数、采样策略、奖励或优化过程。
3. 理论作用可以通过对照和消融实验单独验证。
4. 理论假设能够明确陈述，不能把经验现象包装成定理。
5. 理论能够服务第三、四章的问题递进，而不是增加无关公式。

## 待核对方向

- 第三章：约束优化、物理残差、多任务学习、动态权重、表示稳定性。
- 第四章：课程学习、自步学习、样本难度、策略梯度、组相对优势、方差与稳定性、复杂度。
- 模型适配：LoRA/QLoRA、低秩更新、可能的正交或流形约束。
- 排除审查：TCP/AQM 流体方程、缺失拓扑条件下的节点守恒、未经验证的因果表述。

## 已核对论文证据

### A 级：可作为方法推导依据

- **朱焱雷论文第三、四章**：已精读方法、理论和实验组织。可参考“同一基座、问题递进、双机制、完整算法、理论分析、系统实验”的构思方式，不能复用具体方法。
- **Raissi PINN 开山框架**：监督损失、物理残差和边界条件的联合训练，为第三章定义物理一致性约束提供基础形式。
- **课程式对抗训练的在线理论**：原文包含 Wasserstein 距离、Rademacher 复杂度、序贯 Rademacher 复杂度和非平稳分布差异度，可作为第四章课程分布漂移分析的证明模板。
- **课程式 PINN 高斯混合方法**：原文给出加权损失等价、亚线性梯度收敛和带权泛化界，支持“残差分布建模 + 平滑课程”，但其 PDE 结论不能直接迁移到流量检测。
- **GRPO 归一化理论**：原文把组内标准差归一化解释为自适应梯度，并在唯一正确答案、表示正交和有界方差等假设下给出收敛率。可解释组内奖励方差的作用，不能直接照搬定理。
- **Constrained GRPO**：原文使用拉格朗日松弛处理主奖励与行为约束，并证明先标量化再标准化会产生协方差相关的隐式重加权。适合把检测正确性作为主目标、物理一致性与格式合规作为约束。
- **TIC-GRPO**：原文给出 GRPO 类算法的收敛分析，说明轨迹级重要性校正与裁剪对偏差和方差的作用。适合作为理论边界引用，不建议直接加入首轮算法。

### B 级：可作为机制来源，但需针对流量检测重证

- **GRPO-RCS 意图检测**：低分挑战样本课程能提高未见类别泛化，但其两阶段筛选会把全错组与可学习困难组混在一起。本课题应进一步区分奖励均值和组内方差。
- **课程式 PINN 高斯混合方法**：残差可通过高斯混合模型形成潜在难度簇，但需要先检验流量残差是否满足多峰或可聚类结构。
- **INVARLLM**：说明不变量需要“提出后验证”，但其物理过程属于水处理系统，不能直接证明通用流量存在同类物理守恒。
- **PIGCRN**：说明动力学、拓扑和攻击模式可以分层进入损失；网络流量只有在真实拓扑可用时才能采用图守恒。
- **Minerva 可验证奖励**：结构化输出和确定性验证器适合安全任务，但流量检测的可验证项必须重新定义。
- **Stiefel LoRA 与 FoRA**：正交约束和 Fisher 选层可以补充参数高效微调的稳定性理论，只在普通 QLoRA 出现秩退化或物理约束注入层难以选择时启用。

### C 级：仅作背景或反例

- **PI-RF**：物理量只作为额外特征，不属于物理约束训练。
- **PPINN-FDIA**：未明确 governing PDE，适合作为“不能空喊 PINN”的反例。
- **数字孪生约束 LLM**：提供结构化输出和物理过滤的工程先例，但其两级检测架构不是当前论文主线。
- **mHC**：v2 使用 Birkhoff 双随机约束和 Sinkhorn 投影稳定多流残差混合，并在 3B、9B、27B 预训练中验证；它需要修改模型架构，与单卡 QLoRA 主线不匹配。旧笔记中的 Stiefel、Lyapunov 定理、0.6% 开销和 671B 实验均与仓库 v2 原文不符。

## 第三章理论主线候选

### 1. 物理一致性约束经验风险最小化

把检测目标写为带约束的经验风险，而不是固定权重的损失拼接：

\[
\min_\theta \mathbb{E}[\ell_{det}(f_\theta(x),y)],\qquad
\text{s.t.}\ C_k(\theta)=\mathbb{E}[r_k(x;\theta)^2]-\varepsilon_k\le 0.
\]

使用原始—对偶或增广拉格朗日方法学习约束乘子。理论部分可以讨论可行性、乘子更新、平稳点和约束违反上界。

### 2. 约束可靠性与梯度冲突

物理残差可能在某些协议、攻击类型或数据集上不成立。可用残差可靠性和检测梯度—约束梯度夹角控制约束强度，避免错误约束损害分类：

\[
s_k=\frac{\langle \nabla\ell_{det},\nabla C_k\rangle}
{\|\nabla\ell_{det}\|\,\|\nabla C_k\|+\epsilon}.
\]

只有探针实验确认该机制比固定权重和普通正则化稳定增益后，才能作为第一创新算法的第二机制。

### 3. 受约束假设空间的泛化解释

定义满足有效物理约束的假设子集 \(\mathcal H_{phy}\subseteq\mathcal H\)。在约束真实且跨域不变的前提下，可用 Rademacher 复杂度单调性解释约束为何可能降低泛化上界。不能由此直接声称实际误差必然下降。

### 4. 参数高效适配的备用理论

若普通 QLoRA 出现低秩子空间冗余，可考虑 Fisher 选层与 Stiefel 正交约束。该理论属于模型适配，不属于物理理论，不能在没有实验问题时强行加入。

## 第四章理论主线候选

### 1. 学习前沿课程

对样本 \(x_i\) 生成 \(K\) 个结果，定义奖励均值和组内方差：

\[
\mu_i=\frac1K\sum_{j=1}^{K}R_{ij},\qquad
v_i=\frac1K\sum_{j=1}^{K}(R_{ij}-\mu_i)^2.
\]

若奖励近似二元，则 \(v_i\approx p_i(1-p_i)\)：全对组和全错组的方差都接近零，只有成功率居中的样本提供明显组相对信号。因此课程不应只选“低均值难样本”，而应优先选择“物理残差可信且组内有分歧”的学习前沿。

### 2. 课程分布漂移

把每轮采样分布记为 \(q_t\)，用 Wasserstein 距离控制课程变化：

\[
J_{drift}=\sum_{t=1}^{T-1}W_1(q_t,q_{t+1}).
\]

在损失对输入为 Lipschitz 的条件下，相邻课程风险差可以由 \(W_1\) 控制。该结果可解释为什么平滑解锁困难样本比一次性硬过滤更稳定，但需要针对本任务重新陈述假设并证明。

### 3. 带物理约束的组相对策略优化

把检测正确性作为主奖励，把物理违反率和结构化输出错误率作为约束，以可学习拉格朗日乘子替代固定奖励权重。这与课程机制可形成耦合：同一物理残差同时参与样本可靠性判断和策略约束，但不能再回到独立两级检测器。

### 4. 方差、偏差与复杂度

- 解释组内标准化何时提供自适应步长，何时因零方差失去信号。
- 分析课程改变采样分布后带来的离线策略偏差和重要性权重。
- 给出单卡训练复杂度与生成成本：主要开销近似随样本数、每样本生成数和输出长度线性增长。
- 不直接照搬 GRPO 理论论文的全局收敛结论，因为其唯一正确答案、表示正交等假设未必成立。

## 明确排除

- 无路由器队列、拥塞窗口和丢包概率观测时，不采用 TCP/AQM 流体方程。
- 无真实拓扑时，不把节点流入等于流出写成可计算约束。
- 不把经典 PDE PINN 的收敛定理直接改名为流量检测定理。
- 不使用 Stackelberg 均衡、平坦极小值或 Lyapunov 稳定性，除非最终算法确实包含相应结构并满足假设。
- 不把相关性或互信息写成因果性。
