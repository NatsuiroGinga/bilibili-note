# 已有文献理论两两组合研究构思计划

## 目标

基于仓库内已有论文全文、结构化笔记和文献审查报告，筛选可用于网络空间安全的理论二元组合，形成带证据等级、研究问题、可证伪假设、最小实验和优先级的新论文构思清单。

## 任务边界

- 不受当前毕业论文主线、章节结构、既有实验合同或已选方法限制。
- 只组合仓库中已有且可追溯的理论来源，不把关键词并置当作创新。
- 应用场景属于网络空间安全，可覆盖恶意流量检测、漏洞检测、威胁情报、信息物理系统安全和自主防御。
- 每个构思的总工作量以当前毕业论文一个创新章节为上限，约等于整篇论文的一半：只解决一个核心问题，采用两项理论、一个主模型和一套统一实验协议。
- 本轮不运行实验，不修改论文正文、恢复文档、原始论文或知识库笔记。

## 阶段

- [x] 阶段一：读取研究构思技能、委派协议和仓库文献规则。
- [x] 阶段二：盘点已有理论与来源，建立理论—证据—场景矩阵。
- [x] 阶段三：由文献审查代理完成六阶段证据核验与组合空白分析。
- [x] 阶段四：按新颖性、机制互补性、可证伪性、数据可得性和工作量筛选候选。
- [x] 阶段五：生成研究问题卡和论文构思清单，并完成一致性自检。

## 核心问题

1. 哪些理论在已有全文中有足够证据支撑其原始机制？
2. 哪些二元组合在网络空间安全场景中具有明确接口，而不是机械拼接？
3. 每个组合能否形成可证伪假设、最小实验和清晰基线？
4. 哪些组合适合低成本短论文，哪些适合高风险高收益研究？

## 验收条件

- 文献审查代理返回六阶段检查点、来源数量、证据等级、比较矩阵和制品路径。
- 每个入选构思至少包含：两项理论、问题场景、互补机制、研究假设、方法接口、最小实验、主要基线、证伪条件、风险和证据等级。
- 每个入选构思应能在一个章节规模内完成：建议使用 2—3 个数据集、3—5 个主要基线、两项单机制消融与一个完整组合；需要另建数据集、大规模系统平台或三个以上独立机制的构思不列为优先项。
- 最终明确推荐优先级，并区分“优先立项”“值得探索”和“高风险备选”。
- 所有理论来源均能回溯到仓库内全文、论文笔记或已有文献审查报告。

## 决策记录

- 将“已有文献”解释为本仓库 `raw/papers/`、`wiki/papers/` 与 `.Codex/docs/` 中已经留存的论文和文献审查制品。
- 用户已明确要求忽略当前论文主线；现有研究方向和章节边界不作为筛选条件。
- 用户将目标工作量限定为当前论文的约一半，即单个第三章规模；所有候选都按单创新章节可完成性评估。
- 本轮产出是候选研究合同，不是最终研究提案；用户选定单一方向后再做针对性补检索和正式提案。

## 错误与阻塞

- 首次尝试在 `.Codex/docs/` 下新建子目录时受到目录权限限制；改为在既有目录中直接创建带主题前缀的文件，不影响任务内容。
- 首次委派文献审查代理时，运行时拒绝“完整历史继承”和显式代理类型的组合；改用无历史继承并在任务消息中完整传递合同。
- 首次最终链接检查用右括号截断 Markdown 路径，误报两条带括号文件名的原文链接，并把重复引用总数 30 错写成预期 28；改为分别解析普通链接和尖括号包裹链接，以 30 次引用、0 条缺失为验收条件。
