# DRIFT 更新专家混合图件目录

<!-- RESEARCH_ROUTE=DRIFT -->

## 裁决

本轮**不生成图件**。

## 理由

1. 当前只有一个折、一个种子和一个固定块，没有可展示的不确定性或独立重复。
2. 核心裁决由三项精确 BCE 差值和预注册布尔门直接完成；三行数值表比柱状图更准确。
3. 绘制32批轨迹会诱导读者把相依批次误解为独立重复，且不能识别 Adam、非线性与裁剪的因果贡献。
4. 图件不会改变“`passes_no_update=false`，当前固定形式否决”的决策，因此属于装饰性输出。

## 后续图件门

只有未来获得预先批准的多个独立折或种子，并明确独立统计单位后，才考虑带原始点和不确定性区间的比较图。本目录不据此授权新实验。
