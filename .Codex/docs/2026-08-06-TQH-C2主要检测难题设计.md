# TQH-C2 主要检测难题设计

- **状态**：已批准，作为第三章检测证据的当前设计边界
- **日期**：2026-08-06
- **决策**：TQH-C2 跨加密条件与留一采集条件是第三章主要检测难题；GeNIS 不删除，但不再以同分布家族三分类承担主要性能排名

## 1. 研究问题

第三章的主要检测问题是：模型在训练阶段只观察部分加密条件和采集组时，能否在未见的加密条件或完整采集组上保持恶意流量检测能力，并且相对普通监督、状态监督、标准 PINN 和负对照形成稳定收益。

GeNIS 同分布家族三分类已经接近性能上限，只保留为简单域非退化检查。GeNIS 攻击子类、时间前向和未知攻击仍作为辅助泛化证据，不与 TQH-C2 混成按样本量加权的总分。

## 2. TQH-C2 主协议

1. 加密条件固定为 A/TLS、B/QUIC 和 C/HTTP+AES。
2. 主评价采用三折留一加密条件：每一折完整留出一个加密条件，其余条件只能使用冻结训练和校准组。
3. 在每个加密条件内部，采集单元、父组或等价独立组保持完整，不按流记录随机拆分。
4. 除三折平均宏平均 F1 外，必须报告最差折宏平均 F1；不能只选择表现最好的加密条件。
5. 留一采集条件作为第二困难面板，验证同一加密条件内部的采集偏移。
6. 最终测试在模型、字段、提示、阈值、超参数和停止条件冻结前不可见。

## 3. 输入与防捷径边界

所有比较方法共享同一 `sample_id`、公共可观测字段、历史窗口、缺失掩码、训练预算和评价脚本。以下信息不得进入分类输入、提示、归一化或阈值选择：

- A/B/C 配置名称及其直接编码；
- `profile`、场景、采集单元和数据路径；
- 地址、端口和连接标识；
- qlog 路径、端点真值、队列真值和协议专家训练标签；
- 留出折身份、最终测试标签和派生统计量。

协议证据只允许进入停止梯度的物理适用掩码与路由门；如果任何协议派生字段进入分类表示，全部受影响基线必须按相同信息预算重跑。

## 4. 主指标与裁决

1. 主指标为三折留一加密条件的等权平均宏平均 F1。
2. 共同主指标为三折中的最差宏平均 F1，防止平均值掩盖单一条件崩溃。
3. 同时报告准确率、良性误报率、恶意召回率、期望校准误差、训练时间、峰值显存、吞吐和推理延迟。
4. R2 完整方法必须对 `F-A/F-H/F-S/F-R` 以及普通监督 Qwen、仅状态监督和标准 PINN 使用相同留出折。
5. 检测非劣和物理收益分别裁决；ns-3 或 qlog 的状态误差和残差不能替代 TQH-C2 检测收益。
6. GeNIS 同分布家族任务只检查不出现不可接受退化；GeNIS 子类、时间前向和未知攻击单列，不参与 TQH 主指标聚合。

## 4.1 UDP 与 QUIC 专家的待裁决关系

TQH-C2 v1.2.0 明确包含 UDP：B 测试床采用 HTTP/3 over QUIC/UDP。然而，现有公开恶意 UDP 标签主要绑定于 Merlin、HTTP/3、QUIC 和长连接复用，普通非 QUIC UDP 主要属于良性背景或未分类基础设施流量。因此，TQH-C2 本身不足以独立证明一个可迁移的“普通 UDP 恶意流量专家”。

当前登记一个**未冻结候选**：把 UDP 包量、字节量和速率守恒作为 QUIC 专家的底层物理规律，B 样本直接路由到 QUIC 专家；独立 UDP 分支只在 ns-3 普通 UDP 真值上承担底层规律预训练或机制消融，不与 QUIC 分支竞争 B 样本。该候选不会自动替换当前 R2 计算图，也不能据此修改既有实验结论。

升格为正式结构前必须同时满足：加密恶意流量文献综述支持该层级语义；TQH-C2 的协议字段与标签审计闭合；“独立 UDP 专家”和“UDP 规律内嵌 QUIC 专家”在相同输入、参数和训练预算下完成开发集消融。任何一项未完成时，只能称为待验证设计。

## 5. 数据数量边界
