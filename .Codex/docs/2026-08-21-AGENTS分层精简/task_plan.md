# AGENTS 分层精简任务计划

## 目标

在不修改实验、论文、恢复卡和 `CLAUDE.md` 的前提下，将仓库各级 `AGENTS.md` 精简为根级共性边界与子域增量规则，保证典型活动路径的组合指令不超过 `32,768` 字节。

## 文件边界

- 允许修改：仓库内活动路径上的 `AGENTS.md`、本审计目录。
- 禁止修改：实验代码与配置、论文正文、恢复卡、路线总控、`CLAUDE.md`、其他代理文件。
- Git 所有权：只暂存和提交本任务修改的 `AGENTS.md` 与本审计目录。

## 验收命令

- `fd '^(AGENTS\\.override\\.md|AGENTS\\.md)$' . --type f --hidden ...`
- `rg` 检查关键规则、链接目标、哨兵和过期瞬时状态。
- `wc -c` 与加载链脚本统计单文件及组合字节。
- `git diff --check`。
- 模拟根、RWKV 过程文档、`llm_probe/scripts` 三类加载链，并核对每层首选文件语义。

## 决策

- 官方主页面将默认限制表述为组合大小 `32 KiB`；高级配置页又将 `project_doc_max_bytes` 表述为每个文件读取量。验收采用更保守的组合 `32,768` 字节上限，并在报告保留官方口径差异。
- 本机 `~/.codex/config.toml` 未设置 `project_doc_max_bytes` 或回退文件名，按默认值审计。
- 共享暂存区非空，禁止为本任务创建前置快照提交；目标文件当前干净，`HEAD` 作为修改前快照。
