# AGENTS 分层精简审计报告

## 结论

仓库 10 个活动 `AGENTS.md` 已按“根级全仓边界、子域只写增量”重构。总量从 `87,446` 降到 `40,933` 字节，减少 `53.19%`；最深活动链 `thesis/experiments/llm_probe/scripts` 从 `57,133` 降到 `26,315` 字节，低于保守上限 `32,768` 字节并保留 `6,453` 字节余量。

本次只修改 `AGENTS.md` 和独占审计目录；未修改实验、论文正文、恢复卡、路线总控、`CLAUDE.md` 或其他代理文件。

## 官方规则基线

- [OpenAI 开发者文档：Custom instructions with AGENTS.md](https://developers.openai.com/codex/guides/agents-md) 说明：Codex 每次运行或终端会话开始时构建一次指令链；全局层与项目每层优先 `AGENTS.override.md`，否则取 `AGENTS.md`，再取配置的回退名；每层最多一个非空文件；从根向当前目录拼接，近层覆盖上层；默认 `project_doc_max_bytes` 为 `32 KiB`。
- [OpenAI 当前规范页：Custom instructions with AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md) 提供同一发现顺序、验证命令和故障排查说明。
- [OpenAI 高级配置：Project instructions discovery](https://learn.chatgpt.com/docs/config-file/config-advanced#project-instructions-discovery) 将 `project_doc_max_bytes` 描述为每个文件读取量，而主页面描述为组合大小。两处官方表述不完全一致，本仓库按更保守的“项目组合不超过 `32,768` 字节”验收。
- 本机 `codex-cli 0.148.0`，`~/.codex/config.toml` 未显式设置上限或回退名。该本机状态只记录在审计证据，不写进长期规则。

## 已解决冲突

1. 根级默认 RWKV，但旧 `thesis/AGENTS.md` 写第三章固定 PINN。现改为论文层不冻结路线，按根恢复链和当前路线总控裁决。
2. 旧 `output/AGENTS.md` 把 PINN/R2 两份文档称为默认恢复入口。现明确只有用户显式绑定历史路线才读取和更新。
3. 旧章节规则使用 `155 mm/600 dpi`，根规则使用 `165 mm/至少 300 ppi，推荐 400 ppi`。现只在 `thesis/AGENTS.md` 保留实测合同，章节层引用父级，不再重复数值。
4. 根级要求调试回归验证，实验层禁止人工夹具与独立冒烟实验。现根级明确验证形式服从近层实验规则；实验层允许有解析真值的实现正确性验证，但禁止用其得出性能结论。

## 不可删规则

- 全仓：简体中文、`rg`、`fd`、`apply_patch`、过程文档落点、文件所有权、凭据和破坏性操作边界。
- 研究：唯一路线恢复、全文与实验证据分级、魔法数字依据、最终测试隔离、共同预算、公平基线、原始制品优先和禁止事后调参。
- 文档：修改前 Git 快照、共享暂存区不夹带、只提交任务拥有文件。
- 实验：资源上界、百万级状态上界、统一数据接口、阈值复杂度、PyTorch 精度与显存、数学等效微批量、检查点边界、真实运行、日志与 SwanLab 目的地断言。
- 论文：正式章节唯一目录、正文论断台账、全文引用、图件合同、每章六项自审。
- 协作：子代理名称、模型与 `effort` 明示，`terra/sol` 分档、简报交接和基于真实反馈升降级。

这些规则来自用户当轮明确保留清单、仓库长期研究纪律、实际工程有效性要求和 OpenAI 官方加载语义；只做分层与压缩，不删除其行为约束。

## 风险与限制

- OpenAI 两个官方页面对 `project_doc_max_bytes` 的“组合”与“每文件”口径存在表述差异；本次采用更严格的组合上限，避免依赖宽松解释。
