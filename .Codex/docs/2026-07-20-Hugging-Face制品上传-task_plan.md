# Hugging Face 实验制品上传计划

## 目标

将服务器上已完成且通过完整性、敏感信息和许可审计的种子 42、43、44 QLoRA 实验制品上传到默认私有 Hugging Face 仓库，并核验远端文件与提交记录。

## 阶段

- [x] 阶段 1：恢复实验上下文并读取发布审计与 Hugging Face 命令行技能。
- [x] 阶段 2：核验服务器 Hugging Face 账号、命令行可用性与网络状态。
- [x] 阶段 3：盘点已完成种子及其 `artifact_manifest.json`、SHA-256、敏感信息和许可边界。
- [ ] 阶段 4：创建或复用私有仓库并上传审计通过的制品。
- [ ] 阶段 5：通过命令行或接口核验远端文件与提交，写入发布记录并执行格式化检查。

## 关键问题

1. 种子 42、43、44 中哪些运行已完整结束且制品清单状态为完成？
2. 哪些文件可以发布且不包含 Qwen 基座权重、第三方行级数据或凭据？
3. 私有仓库标识、远端文件树与提交哈希能否独立核验？

## 决策

- 默认只创建或使用私有仓库。
- 不上传 Qwen 基座权重。
- 种子未完成时只上传已完成项，不长期等待。
- 第三方处理后数据许可不明确时，只上传脚本、字段模式、统计、哈希和清单。

## 错误记录

- `hf` 最初未进入非交互命令的可用路径；现确认 `/root/miniconda3/bin/hf` 版本 `1.24.0` 可用。
- 首次 `uv tool install --upgrade huggingface_hub` 和身份查询超过 60 秒，已终止残留进程。
- 启用网络加速后的 `uv` 重试在下载 `hf-xet` 时超时，退出码为 `124`；日志保存在服务端发布目录。现有命令行不受影响。
- 使用官方端点并保留代理后，`hf auth whoami` 退出码为 `0`。
- 用户明确批准上传后，租户外发策略仍拒绝启动第三方上传，并要求不得绕过或间接执行；当前任务停止上传重试。
- 首次主进程启动时，任务脚本因 `.bashrc` 在未定义变量检查下读取 `PS1` 而提前退出；修复后的脚本已通过 `bash -n` 并部署，但未获准运行。
- 首次 Prettier 原子写入发布记录时遇到工作区权限错误；按权限规范重试后格式化成功。
