# RWKV 论文检索真实性审计计划

## 目标

逐条核验 `output/RWKV论文检索.md` 中的 10 篇论文，裁定条目真实性、元数据准确性、关键主张的原文支持程度，并判断其与当前生成式恶意流量训练方法的关联强度。

## 边界

- 优先核对出版社、会议、arXiv 和作者公开页面等一手来源。
- 按“可引用、元数据需修正、真实性未确认、真实但关联弱”四类裁定。
- 仅在核验关键主张必需全文时下载 PDF，原文只新增至 `raw/papers/rwkv/`。
- 只对实际下载并精读的论文建立结构化笔记，笔记保存至 `wiki/papers/rwkv/`。
- 不修改总控、`thesis/` 或实验代码。
