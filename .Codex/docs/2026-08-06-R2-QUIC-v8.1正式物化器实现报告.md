## 入口与输出

入口：

```bash
cd thesis/experiments/llm_probe
UV_CACHE_DIR=/private/tmp/r2-quic-materialize-uv-cache \
  uv run --no-sync python scripts/r2_quic_formal_materialize.py \
  --config configs/r2_quic_v8_1_formal_materialization_v1.yaml \
  --project-root "$PWD"
```

固定输入：`runs/data-raw/r2-quic-v8-1-stratified-pilot120-v5`。

固定输出：`runs/data-prepared/r2-quic-v8-1-stratified-pilot120-formal-v1`。

输出制品：

- `physics-targets-quic-v1.parquet`：主表，含公共观测、共享队列真值和 QUIC 真值。
- `quic-window-truth-v1.parquet`：按 `sequence_id`、`source_window_index` 可直接合并的 QUIC 真值伴随表。
- `connection-split-assignments.jsonl`：独立连接级、结果盲的 `80/20/20` 分配。
- `quic-sequence-manifest-v1.jsonl`、`schema.json`、`summary.json`、`artifact-manifest.json`：序列、字段、哈希和发布收据。

## 列合同

- 公共观测：`public_total_packets`、`public_total_l3_bytes`、`public_packet_rate_pps`、`public_byte_rate_Bps`，只从部署 PCAP 聚合。
- 共享队列：队列首尾、接收、入队、出队、丢弃及字节/包守恒残差；由 `proxy-events.jsonl` 重放，并以 `proxy-stats.json` 的汇总收据校验。
- QUIC 真值顺序：`truth_quic_cwnd_start_bytes`、`truth_quic_cwnd_end_bytes`、`truth_quic_bytes_in_flight_start_bytes`、`truth_quic_bytes_in_flight_end_bytes`、`truth_quic_sent_bytes`、`truth_quic_acked_bytes`、`truth_quic_lost_bytes`、`truth_quic_latest_rtt_ms`、`truth_quic_smoothed_rtt_ms`、`truth_quic_min_rtt_ms`。
- 每个 QUIC 字段均有对应 `*_observed` 布尔掩码。缺失值写为 `0` 且掩码为 `false`，不允许将该数值作为已观测真值。
- 序列/路由合同包含 `sequence_id`、`source_window_index`、`split_id`、`route_id=QUIC`、`route_confidence=1.0`、`quic_applicable=true`、`qlog_truth_available=true`、`quic_formal_training_enabled=true`、`window_valid=true`、`final_test_visible=false`。

## 门禁与隔离

- 原始根目录 `run-state.json` 必须为 `status=finished`，且计划、矩阵和完成连接数均为 `120`。
- 全部连接 `status.json` 必须完成、保持 `final_test_visible=false`，并包含客户端 qlog、部署 PCAP、代理事件和代理统计。
- 连接级分配按 `connection_id` 的冻结哈希生成 80 个 `train-fit`、20 个 `calibration`、20 个 `validation`；序列只在同一连接内按非重叠连续四个 100ms 窗口生成。
- 不生成内部最终测试、不读取结果选样本、不写恶意标签。
