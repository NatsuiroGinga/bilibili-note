# DRIFT-DGA 2026 零训练数据可行性报告

## 结论

**可立即作为零训练数据探针和后续快速实验的数据源。** 数据集当前公开、未门控，官方 Dataset Viewer 与 CLI 均可只读访问；版本可固定到 `3b31077020cd1c013d0a75cad51042a2327c4521`。

**四项目标统计均在字段层面可计算，但公开 Viewer 不能完成字符或集合型总体聚合。** 精确结果需对下表所列的最小公开 Parquet 分片做一次流式完整扫描，不需要下载全仓。小样只用于验证模式，未作为总体结论。

## 已核验的公开接口

| 项目 | 已核验事实 |
| --- | --- |
| 可访问性 | Dataset Viewer 的预览、行查询、检索、筛选和列统计均启用；无待处理或失败配置。 |
| 时间配置 | `T17` 至 `T25`，数据集描述声明为 2017--2025；`26` 是 DSN 2026，不是数据年份。 |
| 切分 | 每年 `eSLD` 有 `train`、`validation`、`test`；每年 `raw` 有 `benign`、`dga`。 |
| 模式 | `eSLD`：`domain`、`label`；`raw`：`domain`、`family`、`label`。 |
| 标签语义 | 最小公开行确认 `raw/dga` 的标签为 1，`raw/benign` 为 0；`eSLD` 行包含同名域和二元标签。 |
| 版本 | CLI 返回固定 revision `3b31077020cd1c013d0a75cad51042a2327c4521`，最后修改为 `2026-07-20T06:24:36+00:00`。 |
| 规模 | 共 580,182,195 行，Parquet 7,879,096,861 字节；不要在本机全量物化。 |
| 分片 | `hf datasets parquet` 已返回公开转换分片 URL、切分名和精确字节数。 |

## 立即可用的最小下载清单

以下清单针对**最早年份到最新年份**的单一前向探针（`T17` 源，`T25` 目标）。所有路径相对于仓库根；每个 `eSLD` 训练或测试切分在官方转换层有两个 Parquet 分片，必须成对读取，不能只取其中一个分片后声称是完整切分。

| 目的 | 最小配置与切分 | 最小列 | 完整读取量 | 说明 |
| --- | --- | --- | ---: | --- |
| DeepEmbed 字符与 2--3 元组 OOV | `T17_eSLD/train` + `T25_eSLD/test` | `domain` | 372,289,857 字节，22,559,420 行 | 最小的冻结源训练与未来终测组合；不读标签即可计算字面 OOV。 |
| ROSA 后缀匹配覆盖 | `T17_raw/{benign,dga}` + `T25_raw/{benign,dga}` | `domain` | 611,764,777 字节，48,359,798 行 | 需保留含 TLD 的 `raw` 域名；`eSLD` 已丢失后缀，不能替代。 |
| T17--T25 跨年重复域名与家族隔离 | 同上 | `domain`,`family`,`label` | 611,764,777 字节，48,359,798 行 | `family` 只在 `raw` 可用；恶意家族隔离只对标签 1 计算。 |
| 九年精确跨年重复与家族隔离 | `T17_raw` 至 `T25_raw` 的全部 `benign`、`dga` | `domain`,`family`,`label` | 3,701,856,314 字节，317,508,179 行 | 这是九年总体，不是快速探针；可外部排序或分区哈希，禁止全量入内存。 |
| 标签分布 | `raw` 的 split 行数，加上已核验标签语义 | `label` | 无需下载 | 官方 `/size` 已给每个 `raw/benign`、`raw/dga` 的行数；若需在每一年直接验证标签常量，仅读每个切分 1 行即可。 |

最小文件名模式如下，具体转换分片 URL 与大小已由 `hf datasets parquet` 返回：

```text
T17_eSLD/train/0000.parquet
T17_eSLD/train/0001.parquet
T25_eSLD/test/0000.parquet
T25_eSLD/test/0001.parquet

raw_including_TLD/T17_benign.parquet
raw_including_TLD/T17_dga.parquet
raw_including_TLD/T25_benign.parquet
raw_including_TLD/T25_dga.parquet
```

`raw_including_TLD/` 是仓库原始文件路径；统计执行前应按固定 revision 重新运行 `hf datasets parquet`，以转换分片返回的 URL 与大小为准。不得将公开浮动分支替代上述 revision。

## 统计实现与成本

| 统计 | 流式实现 | 独立评价单元与自然分面 | 成本与边界 |
| --- | --- | --- | --- |
| 字符、2--3 元组 OOV | 源切分逐批规范化域名，建立字符及 n-gram 集合；目标切分逐批累计未见字符或 n-gram 的域名比例、token 比例与计数。 | 单位为去重后的域名；按目标年、标签分层。若需要恶意家族分面，改读 `raw`。 | 读取 372 MB；字符集合很小，2--3 元组上限受字母表约束，内存开销远低于样本数。完整目标切分才是总体结果。 |
| ROSA 后缀匹配覆盖 | 从 `raw/domain` 使用冻结的后缀解析规则得到可注册后缀或 TLD；源侧建集合，目标侧统计命中、未命中及按标签的覆盖。 | 单位为去重后的完整域名；自然分面为目标年、标签和解析后缀。 | 读取 612 MB。后缀解析器版本与公共后缀表快照必须冻结；没有该外部规则不能声称“ROSA 后缀”语义一致。 |
| 跨年重复域名 | 对规范化完整 `domain` 做磁盘分区哈希或外部排序，再求源、目标交集；同时保留标签以检查交集的标签冲突。 | 单位为规范化且去重的完整域名；按目标年、标签和后缀分面。 | 两年探针读取 612 MB；九年总体读取 3.70 GB。集合若超内存必须落磁盘，不得以分页样本代替交集率。 |
| 家族隔离 | 仅过滤 `label=1`；源侧登记 `family` 集合，目标侧标记已见或未见家族，再检查同一家族域名泄漏。 | 单位为恶意域名，按目标年与家族；家族是自然分面。 | 两年探针读取 612 MB；九年总体读取 3.70 GB。`eSLD` 不含 `family`，不能用于此门。 |
| 标签分布 | 使用官方 `raw/benign`、`raw/dga` 行数并记录每切分单行标签核验；或在实际读取时对 `label` 计数交叉检查。 | 单位为域名行；按年、原始切分。 | Viewer 元数据即可得切分规模；不把首行标签外推为未验证切分。 |

## 单一冻结种子的评价支持

该数据集能支持固定训练种子的配对评价，但数据本身不能替代训练随机性评估。最低预测制品应逐行保留：`domain`、`label`、目标年或配置、模型分数或二元预测；恶意分面额外保留 `family`，后缀分面由冻结规则派生。

- 配对 bootstrap：以去重后域名为重采样单位，对两个固定模型在相同目标域名上的预测差异重采样；按目标年、标签、家族或后缀分层时，分层键必须随预测制品保留。
- 置换检验：在相同域名的成对预测差异上交换模型标识，不能跨域名或跨年份任意混合。
- 去重与泄漏门：评估前先运行跨年重复域名和家族隔离统计；重复域名不能同时作为独立样本计入源与目标的无泄漏结论。
- 上述重采样量化的是**固定预测集的评价不确定性**，不评估训练随机性，也不建议多种子训练。

## Viewer 的精确阻塞与合法最小动作

公开 Viewer 可提供行预览、分页、搜索、筛选、列统计和分片清单，但未提供任意表达式的 `GROUP BY`、字符分解、n-gram、后缀解析或两个配置间集合交集聚合。`rows` 端点每页最多 100 行，遍历数千万行既慢又无法构成稳健的总体计算路径。

因此，若要报告上述四类统计的精确总体数，最小合法动作是：以固定 revision 读取上表对应的公开 Parquet 分片，使用批式 Parquet 扫描或远端范围读取，逐批只投影所需列。此动作不要求下载全仓，也不应使用小样推断总体。若当前环境不允许读取 372 MB 或 612 MB，则应把相应统计明确标为“未计算”，而不是填入估计数字。

## 证据来源与未作断言

- 官方只读来源：Hugging Face Dataset Viewer 的 `/is-valid`、`/splits`、`/size`、`/first-rows`、`/rows`，以及 `hf datasets info`、`hf datasets parquet`。
- 未下载全量、未训练模型、未计算 OOV 数值、后缀覆盖率、重复率、家族隔离率或总体标签比例。
- 未把 1 行或 100 行预览当作总体结论；所有待计算量均以上表的完整切分扫描为前提。
