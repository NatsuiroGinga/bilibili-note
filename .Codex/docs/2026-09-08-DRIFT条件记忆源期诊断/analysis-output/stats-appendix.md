# DRIFT 条件记忆源期资格统计附录

## 一、分析单元与样本量

- 频数拟合：T17 `train`，良性 1,500,000 个唯一 eSLD，DGA 1,500,000 个唯一 eSLD。
- 诊断拟合：T17 `val`，每类 150,000 个 eSLD。
- 冻结评价：T18/T19 `val`，每年每类 150,000 个 eSLD。
- 特征总行数：900,000。特征制品 SHA-256 为 T17 `f3b9e3ae…`、T18 `bfd620cf…`、T19 `8f99eff0…`。
- 训练随机性：没有新模型训练；C00 来自一个冻结种子 42。本附录的区间不是训练种子区间。

## 三、统计方法

1. 良性和 DGA 分别在 T17 `val` 拟合无惩罚逻辑回归，因变量为冻结 C00 是否误分。
2. 所有连续特征只使用 T17 经验中秩变换；T18/T19 不重拟合。
3. 主效应是候选诊断模型相对参照模型的逐 eSLD 对数损失差。
4. 标准误为成对差的样本标准差除以样本量平方根；95% 区间使用正态近似 `mean ± 1.96×SE`。
5. “候选更好”的机械定义为损失差区间上界小于 0。
6. 偏秩相关先用 D0 变量最小二乘残差化信号与 C00 损失中秩，再计算皮尔逊相关。
7. family 内中心化数字无区间、且实现包含新 family，只作描述性敏感性。

## 六、假设与统计边界

- 正态近似区间假设 eSLD 对在该评价中可作近似独立单元。共享 family 或未知 generator 会引入相关性，因此区间只是源期资格门，不是正文推断。
- 没有执行多重比较校正。本计划使用所有门必须同时通过的合取止损，不根据某个有利区间声称机制成功。
- 偏秩相关没有报告标准误或区间，只能按预注册符号一致性裁决，不可称为统计显著相关。
- 逻辑回归比较评估“特征是否预测 C00 错误”，不评估“条件记忆是否改善分类”。
- 单种子 C00 不能支持训练随机性稳定主张。
- T20–T25 未访问，本结果不能声称正式未来年性能。
