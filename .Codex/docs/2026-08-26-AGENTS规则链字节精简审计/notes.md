- 官方 OpenAI 文档：[Custom instructions with AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。
- 文档说明 Codex 在会话启动时构造一次规则链；项目范围从 Git 根走到当前工作目录，每层依次检查 `AGENTS.override.md`、`AGENTS.md` 和配置的回退名，每层最多纳入一份非空文件。

### 自动加载与主动读取的区别

- 自动链由会话启动时的当前工作目录决定。如果会话从仓库根启动，自动项目链只有根 `AGENTS.md`。
- 根规则要求处理子域前主动完整读取局部规则；这种后续工具读取不会改变会话启动时已经构造的自动链，也不应冒充 `project_doc_max_bytes` 的自动拼接结果。
- 下文四条“路径链”以 Codex 从目标文件所在目录启动为机械口径，用于评估该目录成为当前工作目录时的最坏常驻链。若从根启动后处理目标文件，适用语义相同，但局部文件来自主动读取而非自动拼接。

## 误差与风险

- 节省值是按当前章节字节减去建议保留路由字节的实施前估算；只有实际编辑后重新运行同一 `wc -c` 组合命令，才能成为验收值。
- 最大风险不是少省几百字节，而是迁移后触发路由不完整，导致关键规则没有被按需读取。每次迁移必须先补全目标合同，再缩短常驻规则，并用关键词门禁验证。
- 自动加载链取决于启动目录；根启动会话中的主动读取不受自动组合限额统计。报告同时保留这一区分，避免将手动读取内容错误计入启动链。
