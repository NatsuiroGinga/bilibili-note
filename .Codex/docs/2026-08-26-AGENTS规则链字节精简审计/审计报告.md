## 规则发现口径

官方规则发现顺序是：全局层取第一份非空规则；项目层从 Git 根走到当前工作目录，每层按 `AGENTS.override.md`、`AGENTS.md`、回退名顺序最多取一份；根到近层以空行拼接；组合达到 `project_doc_max_bytes` 后停止继续加入。

本机 `CODEX_HOME` 未设置，`~/.codex/config.toml` 没有显式的 `project_doc_max_bytes` 或回退名配置，因此按默认 `32 KiB` 计算。本仓库没有 `AGENTS.override.md`。

需要区分两类行为：

- 如果 Codex 从目标目录启动，下表就是自动组合链。
- 如果 Codex 从仓库根启动，自动项目链只有根规则；处理子域时由根规则主动读取局部规则。主动读取不重建启动链，也不应计作 `project_doc_max_bytes` 的自动拼接字节。
