# R2 最终物理旁路正式实验计划

## 目标

停止 2,560 条小样本先导旁路，直接在冻结开发协议上验证“共享守恒通路 + TCP/UDP/QUIC 动力学专家 + 未知协议回退”的最终 R2 计算图是否具有独特增量价值。

## 科学边界

- 路线选择只使用开发训练、校准和开发验证；最终测试保持不可见。
- 不覆盖 `dataset-v1`、`dataset-v1-shared-b0` 或既有 R2 派生物，新建独立版本目录。
- 分类器可见共同输入在所有主比较组中逐位一致；协议字段只进入停止梯度的物理适用掩码和强度门。
- TCP/UDP 专家使用 ns-3 或其他已核验训练期真值；QUIC 专家只有在 qlog 或同等级真值具备 ACK、RTT、丢包/PTO、在途字节和拥塞状态时才启用。
- 普通 UDP 抓包、疑似 QUIC 长首部和 TQH-C2 的采集配置不得冒充 QUIC 动力学真值。
- 不根据模型预测修改样本、标签比例、来源比例或基线能力。

## 正式比较组

| 组别 | 物理输入 | 实验责任 |
| --- | --- | --- |
| `F-A` | 关闭协议专家，仅保留同参数量统一分支 | 标准物理基线 |
| `F-H` | 与物理分支等信息量的原始因果历史 | 排除历史信息本身的贡献 |
| `F-P` | 真实共享守恒与协议动力学专家输出 | R2 主方法 |
| `F-S` | 同层整段置换的物理历史与掩码 | 排除容量和正则化贡献 |
| `F-R` | 仅从开发训练池抽样的随机物理历史 | 排除随机旁路贡献 |

主成功条件是 `F-P` 在种子 42、43、44 上相对 `F-A`、`F-H`、`F-S`、`F-R` 形成稳定的检测或困难域泛化增益，同时未观测状态误差与物理残差均改善至少 10%。

## 数据合同

- 检测监督池：GeNIS 与 TQH-C2 的冻结开发训练、校准和开发验证。
- 物理辅助池：ns-3 TCP/UDP 配对真值；QUIC qlog 数据只有通过来源、许可证、字段和划分审计后加入。
- 候选训练预算沿用 10,000 条量级，不直接支付 59,656 条三种子最终矩阵成本。
- GeNIS 同时保留二分类、攻击家族、攻击子类和未知子类评测；TQH-C2 保留跨加密与留采集条件评测。
- 任何增加的协议字段若进入分类输入，所有受影响基线必须按同一信息预算重跑。
