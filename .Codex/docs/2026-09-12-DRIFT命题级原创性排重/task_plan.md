# DRIFT 第三章命题级原创性排重计划

## 一、目标

对当前 F 形态的形式化链条 `F1–F23`、条件命题 `T1–T5` 及三对象支撑定理逐命题核查直接近邻，区分：已有结论直接覆盖、已有工具的任务化组合、需要缩窄的新推论、当前可保留的原创差量。产出可在第三章中引用的证据矩阵与禁写清单，不用关键词零命中替代原创性证明。

## 二、边界

- 当前唯一研究对象是 F：恶意侧组相对过滤与良性误报加权；不新增机制、不改训练合同、不读取 T20–T25 模型分数。
- 以本地全文、原始论文和代码接口为证据；摘要与在线题录只作候选发现，不能裁决命题所有权。
- 必须区分数学工具已有、具体命题已有、把工具用于本任务的组合差量，以及由真实实现导出的新命题。
- V4 已否决现有生产三档满足共享前缀条件；`T3/T4` 只能作为显式共享流新算子的条件结论，不能据旧实现声称成立。
- 本轮只完成排重与科研裁决，不越过正式评价设计的用户批准门，不实现或运行实验。
