# 研究方向校准笔记

## 已确认事实

- 课题目标是提出一种面向恶意流量检测的新型大模型训练方法。
- PINN、物理残差、课程学习和强化学习只能作为训练机制候选，不能替代恶意流量检测主任务；`GRPO` 不是硬性要求。
- 朱焱雷论文第三章以 ET-BERT 为主要基座、BUPT-CNN 为异构辅助基座，提出提升抗逃逸能力的训练方法。
- 朱焱雷论文第四章沿用第三章的数据、预处理、任务和 ET-BERT 主基座，针对第三章引出的计算开销设计高效训练方法。
- 两章属于问题递进和实验连续，不要求第二个方法机械包含第一个方法的全部公式。
- 朱焱雷的可复用部分是创新构思逻辑：从基座缺陷提出问题、每章组织相互作用的机制、第四章解决第三章的剩余问题，并以理论和完整实验支撑算法。
- 最终每个创新点都必须形成相对基础算法有真实机制增量的新算法；正式名称在消融实验确认有效机制后再确定。

## 当前材料的主要偏差

- `thesis/03-数据集构建.md` 把数据集单独作为第三章，占用了第一个方法章的位置。
- `thesis/04-CI-PRD-创新点1.md` 把物理残差写成独立检测器，不是基座模型的训练机制。
- `thesis/05-PIC-GRPO-创新点2.md` 把强化学习模型写成第二级语义精判器，形成两个独立检测模块。
- 该结构与“训练同一个恶意流量检测大模型”的当前目标不一致。

## 推荐编排

- 第三章：面向恶意流量检测的物理一致性约束训练方法，解决纯数据驱动训练的泛化、少样本或数据偏差问题。
- 第四章：面向困难、长尾和未知攻击的课程优化训练方法，沿用第三章的基座、任务和数据，进一步解决第三章模型的局限。
- 第五章：原型系统或工程验证。
- 数据集构建内容拆入第二章的数据基础、第三章实验设置和附录，不再独占一个创新方法章。

## 仍待实验决定

- 主基座采用流量预训练编码器、生成式大模型还是混合架构。
- 输入采用原始字节序列、流级特征序列还是多模态表示。
- 物理信息通过辅助损失、教师残差、状态重建任务或其他方式进入训练。
- 第二创新点采用非强化课程、强化学习课程控制器、`RLOO`、`GRPO` 或其他方法；由增益、稳定性和计算成本共同决定。
- 两个创新点的正式名称、缩写、公式和贡献表述。

## 写作边界

- 当前只允许写“拟研究”“候选”“待实验验证”，不能写成已提出、已证明或性能已提升。
- 既有 v1-v8 实验只作为探索性证据，不能支撑新章节的最终贡献结论。
- 后续实验应比较普通微调与新训练机制的相对增益，并覆盖跨日期、跨数据集、长尾和未知攻击设置。
- 禁止把未经改进的基础算法重新命名为创新方法，也禁止先确定方法名再筛选与名称相符的结果。
