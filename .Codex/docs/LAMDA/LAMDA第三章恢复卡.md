## 网页与本地实测合并裁决（2026-09-09）

- 网页报告把当前病灶限定为三项取舍：保护旧的正确恶意识别、修复当前仍漏判的恶意样本、限制修复过程新增的良性误报；它明确反对只加强蒸馏、只挑难负例或只提高旧样本权重。
- 网页候选四“双侧风险约束下的修复式 Replay”最有机会形成第三章框架，但目前仍是外部候选；PCT、A-GEM、类别／时间配额、GSS、MIR、PBR、CBRS 等必须作为近邻对照或部件来源，不得改名充当创新。
- 更新后的方法族综述进一步确认：Regression-aware/PCT、MADAR、GSS、MIR、PBR、CBRS、A-GEM、ECBRS/PAPA 和 FreeMOCA 已覆盖安全回归、记忆选择、不平衡和参数保持等成熟路线。当前主候选不再预设“角色记忆＋双风险投影”；先完成缺口修复／条件门控探针，再把 PCT 作为直接基线，必要时比较 MIR/GSS 干扰感知记忆。
- 博弈论候选仅限算法层双玩家约束优化：修复模型玩家最小化恶意漏判损失，安全约束玩家更新 FPR 拉格朗日乘子；不采用缺少攻击者动作与收益证据的攻击者—防守者叙事。该候选待当前四臂完成后再做源年筛选，不能替代真实 FPR gate。
- 阶段 A 实测只证明标准 Replay 取得有限筛查资格：FPR 和旧恶意负向翻转率下降，但 AP/FNR 略差。
- 阶段 B 实测不支持当前一侧安全记忆 BCE 全面有效：联合臂 pooled FNR 与回溯翻转率略降，但 FPR 上升、AP/AUROC/F1 略降；2025 的 23 个恶意样本两臂均 FNR=1。
- 阶段 B 代码实际在当前年度训练和评价后用当前模型分数筛选安全记忆，不是配置所写的上一冻结模型保护集合；因此不能把它当作文献 PCT 复现，必须先修正定义。

## 文献综述更新（2026-09-09）

- **TERM：** 论文第 1 节公式（2）定义指数倾斜损失，第 2 节公式（3）给出按损失重加权的梯度，第 3 节公式（4）扩展层次多目标倾斜。TERM 能强调高损失样本或组，但没有 LAMDA 的 hard FPR 可行性保证；当前只保留为后置风险加权对照，不进入双玩家首轮。
- **IWMS：** NeurIPS 2024 第 3 节算法 1 和第 4 节算法 2 研究显式标签延迟：用当前未标注样本的预测类别与特征余弦相似度选择已标注记忆。当前 LAMDA 合同是年度标签在更新阶段到达，未冻结延迟标签协议，因此 IWMS 不作为当前直接臂；若未来建立延迟标签子协议，必须禁止使用尚未到达的真实标签。
- **DGR：** NeurIPS 2017 第 3 节公式（1）用生成器重建历史输入、旧 solver 生成伪目标。它新增生成器和伪样本误差，改变固定容量真实回放合同；MNIST/SVHN 结果不能转述为 LAMDA 证据，当前不进入直接实验。
- 三篇全文原件、MinerU 提取和结构化笔记已落盘；综述结论只作为候选排序依据，仍需 LAMDA 源年实验验证。

## 下一阶段候选与数据合同

1. **先做来源／开发期筛选（年份边界按用户 D1 裁决，2026-09-09）**：到达流 `2013 → 2014 → 2016 → 2017 → 2018`（2018 的 train 分片标签按到达使用）；开发评价面板为 `2016/2017/2018` 的 test 分片（用于机制选择与硬门槛，如实称"目标知情"性质，不得称独立最终测试）；封印评价收缩为 `2019--2023`，只在合同冻结后作一次性评价；`2024/2025` 因恶意样本枯竭（794/23）不作统计评价基础，只作探索性报告。此前 `2020--2025` 探索性读数不回灌任何选择。2018/2019 此前从未被任何运行枚举（v2 `run-manifest.json` 只列 2013/2014/2016/2017 为证），2018 解封无历史接触污点，2019 起仍完整封印。
2. **冻结记忆因子 M**：总容量仍为 200，在 `B_{t-1}` 与 `D_t^{train}` 内按已允许的标签、到达时间、旧模型决策和当前 margin 区分保护／修复／误报控制角色；不按未来家族或目标期表现配置配额。
3. **冻结更新因子 O**：保护集合只取上一冻结模型已正确判恶意的历史记忆；修复集合只取当前已到达训练区中真实恶意且旧模型漏判或 margin 不足的样本；良性约束只用已到达良性训练样本的误报代理。先实现最小双侧约束，不同时加入排序损失、复杂干扰采样或强化学习控制器。
4. **执行最小 2×2**：ER、ER+M、ER+O、ER+M+O，固定模型、总容量、回放暴露量、训练轮数和阈值；加入原式 PCT、同配额随机角色记忆及 A-GEM 等直接对照。若任一单因子在来源期没有独立信号，立即缩小或停止该因子。
5. **统一裁决指标**：逐年 AP、AUROC、F1、FPR、FNR、Brier；旧恶意负向翻转、当前恶意正向修复、良性新增误报、最差年份和资源开销同时报告。通过条件是相对 ER 不牺牲 FPR 与旧恶意保持，并在来源期至少改善 AP/FNR 或正向修复之一；目标期只作封印评价。

以上为待冻结的实施方向，不是已验证算法；在新增候选全文完成 `raw/` 与 `wiki/` 入库、合同和数值依据登记前，不启动新的正式 GPU 重训。

## 为什么成熟方法移植后未通过（2026-09-09）

- “论文复刻”不能直接推出 LAMDA 增益：原论文的数据规模、漂移形态、标签到达方式和优化目标不同；PCT 的原始目标是保持旧模型决策，不是同时约束 LAMDA 的历史良性 FPR、旧恶意回归和新恶意漏判。
- 当前 PCT 运行是依据原文 FD-LM 公式的 LAMDA 任务化筛选实现，不是原作者代码的逐行复现；`alpha=1`、`beta=5`、`lambda=1` 只是论文起始值，尚未证明适合 LAMDA。
- 阶段 C 的角色记忆实现曾违反“上一冻结模型保护集合”的定义，已按实现偏差作废；该结果不能证明抽象的安全回归约束普遍无效。
- 缺口修复和双侧投影暴露的是 LAMDA 的真实取舍：前者降低 FNR 但大幅增加 FPR，后者降低 FPR 但抑制恶意修复；PCT 联合臂没有消除这一冲突。
- 因此当前证据支持“直接移植的成熟部件不足以解决 LAMDA 病灶”，不支持“这些论文方法在所有任务上失败”。后续候选必须从源年可观测病灶和明确的 LAMDA 目标出发，再做最小可证伪实验，不能靠放宽门槛制造正增益。
