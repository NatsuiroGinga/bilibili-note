## 当前边界

- 当前状态为研究设计待冻结。资格探针只说明数据存在时间退化余量，不能支持新机制、统一算法或无泄漏正式基线已有效。
- 先比较标准固定容量经验回放与朴素逐年更新；只有前者取得预先冻结的正增益，才可研究旧恶意负向翻转安全回归约束，并以该有向依赖形成统一算法。
- 不预设双机制或机械 `2×2`。任何后续机制都须先冻结可观测量、对照、指标、通过与失败门槛。
