```python
def decompose_queue_balance(predicted, scale, capacity, received, dequeued, dropped_before, dropped_after):
    storage = scale[:, None] * (predicted[:, 1:] - predicted[:, :-1]) / capacity
    return {
        "storage": storage,
        "received": -received / capacity,
        "dequeued": dequeued / capacity,
        "dropped_before": dropped_before / capacity,
        "dropped_after": dropped_after / capacity,
        "residual": storage - received / capacity + dequeued / capacity + dropped_before / capacity + dropped_after / capacity,
    }
```

模型加载必须使用基座模型绝对路径、各运行的 `final_adapter/` 和 `state_head.pt`；状态头使用 `strict=True` 加载，并将两个检查点依次加载到 GPU，禁止同时常驻造成无意义显存占用。

- [ ] **步骤1：按预注册问题分析，不根据结果临时改变指标**

1. 零流量或零队列样本是否占据多数，并支配总体均值。
2. M2 是否在容量变化、高负载或攻击工况改善物理残差，但被简单样本稀释。
3. M2 的误差是否集中于某个锚点或某个守恒组成项。
4. M1 是否在绝大多数分组同时具有更低状态误差和残差，从而支持“密集状态标签使物理目标冗余”的候选解释。

- [ ] **步骤2：根据证据只选一条后续路线**

| 诊断结果 | 允许的下一实验 | 禁止行动 |
| --- | --- | --- |
| M2 仅在拥塞、容量变化或攻击工况改善 | 预注册工况均衡采样实验 | 不得只报最优子组 |
