# R2 ns-3 TCP 物理真值 v2 实施计划

> **执行方式：** 使用 `subagent-driven-development` 分任务实现；本任务禁止使用 `test-driven-development`，不新增独立冒烟、预检或全仓测试。正确性断言并入实际数据运行入口。

**目标：** 在不修改公开数据推理输入、不覆盖 attempt5 的前提下，为 R2 TCP 动力学专家生成可审计、无参数、不可零坍缩的训练期物理真值。

**架构：** 保留 `r2_protocol_queue_scenario.cc` 与 attempt5 全部制品不变，新增 v2 场景和独立运行身份。窗口级公共流量与队列守恒仍沿用现有合同；TCP 动力学另按 `physics_group_sha256 × window_index × sender_index` 输出发送者级状态转移，避免把多个 TCP 流先平均后套用 NewReno 方程。

**技术栈：** ns-3.48、C++、Python 运行编排、Shell 持久化包装器。

## 全局约束

- ns-3、qlog 中新增的 ACK、RTT、在途字节、拥塞窗口和拥塞事件只作训练期特权监督及物理评价，不进入 GeNIS、TQH-C2 或最终部署分类输入。
- 不用现有字段猜测缺失真值，不用标签、场景名或攻击类别构造动力学残差。
- attempt5 源码哈希、输出、清单和结论保持不变；v2 使用新的源码文件、参数合同、输出根和运行身份。
- TCP 残差必须为固定方程，残差计算图中可训练参数数为 0，且对预测状态存在非零梯度。
- 正式扩展前只运行最小字段闭合矩阵；没有真实 ACK、RTT、在途字节或拥塞事件时保持 `NO-GO`，不得填零冒充观测。
- 本任务只需 CPU，不申请 GPU。

## 任务 1：核验 ns-3.48 TCP 真值来源

**读取：**

- `/root/autodl-tmp/thesis/ns3/ns-3.48/src/internet/model/`
- `thesis/experiments/llm_probe/ns3/r2_protocol_queue_scenario.cc`

**产出：**

- `.Codex/docs/sdd/task-r2-tcp-truth-v2/trace-source-audit.md`

**动作：**

- 完整核验 `CongestionWindow`、`SlowStartThreshold`、`BytesInFlight`、`RTT`、`CongState` 及 ACK 接收路径的实际 trace 名、回调签名、单位和连接时机。
- 判断累计 ACK、重复 ACK、恢复、丢包和 RTO 能否仅通过公开 trace/包头回调可靠取得；不能取得的字段明确标记不可用，不按名称猜测。
- 给出唯一根因结论和 v2 字段映射。若无法区分必要的 NewReno 驱动事件，先停止实现并提出最小的 ns-3 场景内观测扩展，不修改 ns-3 核心。

## 任务 2：新增发送者级 TCP 状态转移输出

**文件：**

- 新建：`thesis/experiments/llm_probe/ns3/r2_protocol_dynamics_v2_scenario.cc`
- 新建：`thesis/experiments/llm_probe/configs/r2_ns3_tcp_truth_v2_contract.json`

**接口：**

- 主窗口表继续输出公共流量与队列守恒字段。
- TCP 伴随表的主键固定为 `physics_group_sha256`、`window_index`、`sender_index`。
- 至少输出 `window_duration_s`、`cwnd_start_bytes`、`cwnd_end_bytes`、`ssthresh_start_bytes`、`ssthresh_end_bytes`、`bytes_in_flight_start_bytes`、`bytes_in_flight_end_bytes`、`acked_bytes`、`acked_segments`、`rtt_mean_ms`、`rtt_min_ms`、`rtt_max_ms` 及各字段真实观测掩码。
- 只有任务 1 证明可可靠区分时，才输出 `loss_event_count`、`timeout_event_count` 和 NewReno 驱动分解项；否则保持缺失并阻止正式 TCP 动力学门禁通过。

**运行时断言：**

- 主键唯一、窗口连续、状态非负、单位明确、掩码与值一致。
- TCP 每个有效发送者的窗口起点等于上一窗口终点；UDP 行不得出现 TCP 真值。
- 对已观测状态计算固定 NewReno 残差，记录分子、归一化尺度、有效项数和均方误差，不只保存汇总均值。

## 任务 3：最小字段闭合矩阵

**文件：**

- 新建：`thesis/experiments/llm_probe/src/flow_probe/r2_ns3_tcp_truth_v2_runner.py`
- 新建：`thesis/experiments/llm_probe/scripts/run_r2_ns3_tcp_truth_v2.sh`
- 新建：`thesis/experiments/llm_probe/configs/r2_ns3_tcp_truth_v2_field_closure.json`

**动作：**

- 从既有矩阵选取同时覆盖低损失、高损失、容量变化、不同 RTT 和不同发送者数的少量配置，只运行一次字段闭合。
- 输出独立运行状态、配置与源码 SHA-256、原始日志、模式、行数、缺失率、事件覆盖率和物理恒等式收据。
- 至少出现非零 ACK 驱动和非零拥塞收缩事件；否则字段闭合失败，不启动正式矩阵。
- 项目源码与 ns-3 `scratch/` 副本逐项核对相同 SHA-256；运行目录不得复用 attempt5。

## 任务 4：接入固定 TCP 残差并复审

**文件：**

- 修改范围由任务 1 至 3 的冻结字段合同决定，主要位于 `r2_final_experts.py`、`r2_final_physics_fit.py` 和对应配置。

**验收：**

- 残差中可训练参数数为 0。

- 残差对预测的窗口终点状态梯度非零。
- 状态与无量纲残差统一报告逐项平方和、有效项数和均方误差。
