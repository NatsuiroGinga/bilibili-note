# E2 种子 42 强基线首轮结果

## 实验身份

- 面板：`A+B+D→C`，内部标识 `abd_to_c`。
- 数据：TQH-C2 v1.2.0 冻结开发协议，只使用共同七字段。
- 种子：`42`。
- 阈值：只由源域校准集选择，未读取 C 域标签或统计量调参。
- 目标样本：C 域 `2,952` 条，其中恶意 `2,445` 条、非恶意 `507` 条；恶意基准比例为 `0.828252`。
- 输入绑定：五个模型均为 `eaa0c3c49371e46842df32712017a7dbc39f934991eca1507ada84cc0e615459`。

## 当前裁决

1. 五个基线在 C 域的宏平均 F1 均不超过 `0.147025`，恶意召回均不超过 `0.003272`，确认 C 域仍是有效困难面板。
2. 普通源域 GroupDRO 没有改善该问题，其宏平均 F1 和最差组宏平均 F1 均低于 HGB、XGBoost、随机森林和 MLP。该结果只否决当前线性 GroupDRO 配置，不否决全部域泛化方法。
3. 随机森林、HGB 和 XGBoost 的 PR-AUC 高于目标域恶意基准比例，但固定于源域的阈值在 C 域几乎不召回恶意样本，说明排序、概率校准和决策阈值迁移需要分开分析。不能用较高 PR-AUC 掩盖低召回和低宏平均 F1。
4. 当前只有一个种子，不能进行显著性检验、置信区间比较或模型胜者声明；这些基线仅用于种子 42 路线筛选门槛。
5. 本轮没有运行 DistilBERT，也没有运行 `E2-A/S/P/X`，因此不能据此判断 PINN 是否有效。
