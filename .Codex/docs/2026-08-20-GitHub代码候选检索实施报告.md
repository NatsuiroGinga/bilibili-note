## 接口

### GitHub

- 端点：`GET https://api.github.com/search/repositories`
- 可选认证：环境变量 `GITHUB_TOKEN`，只写入 `Authorization` 请求头，不写入输出或错误。
- 匿名公开读取允许；状态记录认证、延迟、HTTP、search 限额、剩余额度、重置时间、重试和退避。
- 输出：规范仓库 URL、`owner/name`、描述、主页、许可证、星数、归档状态、更新时间、默认分支、匹配依据和 `verification_status`。
- 普通命中固定为 `unverified_code_candidate`，按规范 URL 去重，不自动认定为论文官方源码。

### Hugging Face Papers

- 端点：`GET https://huggingface.co/api/papers/search?q=...`
- 作为论文 provider，经 arXiv、DOI、规范题名与其他学术来源合并，进入 `paper_candidates`。
- 普通命中仍是未核全文论文候选，不自动进入本地证据或论文结论。

### Hugging Face Hub

- 端点：`/api/models`、`/api/datasets`、`/api/spaces`。
- 可选 `HF_TOKEN` 只进认证头；公开读取允许无令牌。
- 输出：`repo_id`、类型、URL、任务、下载、点赞、更新时间、门控状态、许可证、arXiv 关联、匹配依据和核验状态。
- 元数据显式带 `arxiv:` 标签时标为 `paper_linked_candidate`；普通命中为 `unverified_hub_candidate`。
- 不自动下载、登录、上传、索引、部署或认领。

### 限流与失败

- GitHub/HF 403、429、503 只有在响应提供有效数值型 `Retry-After` 且不超过本次超时时最多重试一次。
- 没有 `Retry-After` 时直接失败，不盲重试。
- 每个来源单独返回认证、延迟、限流、退避、结果数、去重和降级原因。

## 官方证据

- GitHub 仓库搜索：GitHub REST `GET /search/repositories` 官方端点。
- GitHub 限流：[Rate limits for the REST API](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api?apiVersion=2022-11-28)。官方说明匿名公共请求主额度为每小时 60、认证用户通常为每小时 5000；搜索端点有独立更严格额度；超限返回 403/429，并应遵守 `Retry-After` 或重置头。
- GitHub 许可证：[REST API endpoints for licenses](https://docs.github.com/en/rest/licenses/licenses?apiVersion=2022-11-28)。仓库响应可包含 Licensee 识别的 SPDX 信息，不能当法律意见。
- HF Hub：[Hub API Endpoints](https://huggingface.co/docs/hub/en/api) 与 `huggingface_hub` 0.36.2 `HfApi` 官方源码。实测签名确认 `list_papers(query=...)`、`list_models(search=...)`、`list_datasets(search=...)`、`list_spaces(search=...)`，公开调用可通过 `token=False` 禁用认证。
