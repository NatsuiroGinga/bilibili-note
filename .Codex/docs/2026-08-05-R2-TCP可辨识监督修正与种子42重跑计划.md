# R2 TCP 可辨识监督修正与种子 42 重跑计划

## 目标

修正 TCP 公共观测与发送者级真值一对多、`ssthresh` 哨兵误作连续值两个已确认根因，在不读取最终测试集、不覆盖旧制品的前提下，重新完成 `F-A/F-P/F-S` 种子 42 比较。

## 冻结边界

- 仅处理 TCP 监督合同、状态语义、对应加载与评价；UDP 已确认的合法恒零维处理保持不变，QUIC 继续使用 `UNKNOWN` 回退。
- 不把 `sender_index` 当作可迁移的分类输入，不使用仿真真值构造公开数据推理时不可获得的特征。
- 若所有正式数据视图都存在同粒度、无真值泄漏的发送者级被动观测，则使用发送者级输入与目标；否则将真值聚合为与公共窗口一致的网络级目标，并重新定义可验证的聚合状态和残差。
- `UINT32_MAX` 只表示 `ssthresh` 未设置或无穷阈值：连续状态损失与相关方程必须使用显式有效掩码，另行保留离散语义，不得裁剪后继续当普通连续值。
- 旧种子 42 运行、检查点、日志和指标只读保留；新运行使用新合同版本、独立运行身份与制品目录。

## 执行阶段

- [x] 阶段 1：读取诊断证据和数据字段，使用 `brainstorming` 比较发送者级可观测方案与网络级聚合方案，冻结唯一可迁移合同。
- [x] 阶段 2：写出接口、字段、掩码、状态聚合、残差和数据防泄漏验收条件。
- [x] 阶段 3：针对不可辨识展开和哨兵语义执行一次最小红灯、绿灯周期，实施最小生产改动。
- [x] 阶段 4：只用现有制品执行 CPU 诊断，验证同输入组目标不再一对多、哨兵不进入连续回归、真值代入残差保持可解释。
- [ ] 阶段 5：同步白名单文件，在 SwanLab 在线模式重拟合物理专家并重跑 `F-A/F-P/F-S` 种子 42。
- [ ] 阶段 6：回收配置、日志、检查点、预测和指标，更新第一创新点实验总控。

## 种子 42 验收

1. 公共输入和监督目标的样本粒度一致；不存在未被输入区分却要求恢复多套不同目标的样本组。
2. `ssthresh` 哨兵从连续误差与不适用方程中排除，掩码和离散语义均有制品收据。
3. `F-A/F-P/F-S` 使用同一数据、参数预算、训练步数、归一化、掩码和评价口径。
4. 同时报告检测宏平均 F1、逐协议状态误差、逐方程残差和对照增益；分类提升与物理主张分开裁决。
5. 种子 42 未形成一致物理证据前，不扩展到种子 43、44，也不调阈值追求指定结果。
6. 旧 `F-P` 种子 42 开发验证宏平均 F1 `0.9406325189504068` 作为性能参考。修正版若降低，不因语义一致而直接冻结，也不得恢复不可辨识目标、削弱基线或读取最终测试追分；应在同一开发协议内启用零初始化门控残差，必要时建立“发送者级特权物理教师到网络级学生”的蒸馏合同，再重新验证非退化与物理证据。

## 当前状态

阶段 1 至阶段 4 已完成。发送者级方案因正式视图缺少无泄漏的发送者级被动输入而被否决；当前合同按公共窗口汇总可加状态，以 RTT 样本数加权平均，并将 `ssthresh=UINT32_MAX` 记录为离散未设置发送者数且关闭对应连续掩码。原先每个源窗口固定展开八套目标的结构性一对多已经消失；跨独立场景仍存在相同数值公共历史对应不同隐状态的条件不确定性，后续不得把网络级学生描述为对隐状态的完全可逆恢复。

目标测试最终为 `4 passed`，CPU 诊断得到 TCP 公共窗口 `23,040` 条、发送者后缀 `0` 条、观测哨兵 `0` 条；网络级真值代入四段固定方程的有效项为 `11,144`，残差 MSE 为 `2.993740890443073e-05`。详细证据见 [实现与 CPU 验收报告](./2026-08-05-R2-TCP可辨识监督修正实现与CPU验收.md)。当前等待阶段 5；GPU 重跑前由主代理核对服务器可用性并生成新检查点绑定，旧检查点不得复用。
