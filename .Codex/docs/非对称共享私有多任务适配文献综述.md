# 非对称共享私有多任务适配文献综述

- **完成日期**：2026-07-22
- **服务对象**：第三章唯一修复“冻结 S3 检测 LoRA + 非对称单私有物理 LoRA”
- **证据范围**：20 篇本地全文笔记，其中 11 篇为强制核验清单
- **结论等级**：文献可支持结构设计和理论前提，不能代替当前 GeNIS、DEDALE、ns-3 与跨基座实验

## 1. 直接结论

### 1.1 当前唯一修复有充分的结构先例

文献共同支持以下设计：

1. 多任务迁移不应默认对称。AMTL 与 Deep-AMTFL 均表明，高损失或不可靠任务可能损害成熟任务。
2. 软权重不能消除结构性负迁移。Recon 通过任务专用化高冲突层减少冲突，说明共享位置本身可能是问题来源。
3. 小型专用参数足以承担任务差异。MTLoRA、AdapterFusion 和 MoDULA 分别从共享/专用低秩参数、冻结适配器组合和阶段式通用/专用 LoRA 提供先例。
4. 私有分支必须进入对应任务输出。领域分离网络的私有分支只用于重构，是反例；对抗式多任务文本分类把共享和私有表示共同送入分类器，是正例。
5. PINN 可以使用共享/私有或专家结构。辅助任务 PINN 比较硬共享、软共享、MMoE 和 PLE，但不能证明某一结构必然适合恶意流量。

因此，当前修复不是凭空拼接：冻结 S3 检测适配器，新增一个物理私有 LoRA，只让子类和开放集任务消费该分支，是与现有证据一致的最小结构变更。

### 1.2 文献不支持恢复博弈或继续扫描软协调权重

当前实验的关键事实是任务收益方向相反：

| 指标                  |    S4 相对 S3 |
| --------------------- | ------------: |
| 家族自由生成宏平均 F1 |   `-0.088232` |
| 子类自由生成宏平均 F1 |   `+0.028279` |
| 三种未知攻击召回均值  |   `+0.381111` |
| 开放集良性误报率均值  |   `-0.152222` |
| 未观测状态均方误差    | 改善 `70.17%` |
| 物理残差均方误差      | 改善 `55.44%` |

同时，生成梯度与物理梯度 20/20 个诊断批次为负，G2 至 G5、G4R 和 G4R-A2 已经否决多种博弈与软协调方案。这不是“尚未找到最佳权重”，而是物理更新对任务层级产生不同方向影响。

AMTL 仍通过软有向正则耦合任务，Deep-AMTFL 仍让多个任务共同塑造共享表征，辅助任务 PINN 的余弦筛选仍是软更新规则。它们只能支持“迁移应非对称”的动机，不能保证家族分支零变化。继续调权会重复已经裁决的研究问题。

## 2. 为什么任务级参数隔离更符合当前证据

### 2.1 软协调与硬隔离解决的问题不同

软协调一般把共享参数更新写成

$$
\Delta\theta=\sum_t\alpha_t\nabla_\theta L_t,
$$

无论 $\alpha_t$ 由固定权重、梯度投影、纳什议价还是双层响应产生，只要家族和物理目标仍写入同一参数 $\theta$，家族输出就可能改变。

任务级隔离改为

$$
\theta=\{\theta_0,\Delta^{det},\Delta^{phy},\phi_q\},
$$

其中基座 $\theta_0$ 和 S3 检测 LoRA $\Delta^{det}$ 冻结，只有物理私有 LoRA $\Delta^{phy}$ 与状态头 $\phi_q$ 可训练。家族任务不经过私有分支，因而物理梯度没有写入家族参数的路径。

### 2.2 这是一项优化结构，不是第三条物理定律

双锚点边界约束和有限队列物理一致性仍是第三章的两个理论支柱。非对称私有适配器只规定两个物理信号写入哪个参数子空间，以及哪些检测任务允许消费该增量。

因此不应把“共享私有适配”列为第三个并列物理理论，也不应把第三章标题改成三个机制的堆叠。它更适合放在训练算法与梯度路径小节。

## 3. 家族分支不变性的理论前提

### 3.1 结构定义

令冻结基座和 S3 检测 LoRA 组成第 $l$ 层家族路径：

$$
h^F_{l,t}=h_{l,t}+\Delta^{det}_l(h_{l,t}).
$$

对子类与开放集任务，引入物理私有 LoRA：

$$
h^S_{l,t}=h_{l,t}+\Delta^{det}_l(h_{l,t})
+g_{task}\Delta^{phy}_l(h_{l,t}),
$$

其中家族任务固定 $g_F=0$，子类和开放集任务取 $g_{task}=1$。这里的“开放集”只表示推理任务类型，不表示未知攻击标签进入训练。

### 3.2 家族不变性命题

**命题：** 对任意家族任务输入 $x$，若以下条件全部成立，则修复模型与 S3 对照的家族 logits 相同；在确定性解码下，生成序列和全部家族评价指标相同。

必要条件为：

1. 基座参数、量化权重和量化尺度完全一致且冻结。
2. S3 检测 LoRA 参数完全一致且冻结，未被重新合并或重写。
3. 家族任务在所有相关层都令 $g_F=0$，私有 LoRA 不出现在家族计算图中。
4. 新状态头、物理投影、路由器或融合层均不回写家族 logits。
5. 词嵌入、语言模型头、归一化参数、缓存语义和任何共享缓冲区保持不变。
6. 输入序列化、提示模板、分词器、最大长度、停止条件和后处理保持一致。
7. 确定性生成使用相同数值内核；若使用采样，则只能保证输出分布相同，逐次样本一致还要求随机数状态相同。

证明只需将 $g_F=0$ 代入各层更新，并逐层归纳得到所有隐藏状态与 S3 相同，最终 logits 因此相同。

### 3.3 梯度隔离推论

若家族损失的前向图不含 $\Delta^{phy}$，则

$$
\nabla_{\Delta^{phy}}L_F=0.
$$

若 $\theta_0$ 和 $\Delta^{det}$ 均不在优化器参数组中，则所有训练损失都不能修改 S3 路径。该结论比“梯度余弦非负”或“权重很小”更强。

### 3.4 必须用制品验证的工程条件

理论命题不能替代以下检查：

- 训练前后 S3 检测 LoRA、基座模型标识和配置文件的 SHA-256 一致。
- 优化器参数清单只包含物理私有 LoRA 与新状态头。
- 固定一组家族输入，比较 S3 与修复模型逐样本 logits 或确定性输出哈希。
- 家族推理不初始化或执行会改变共享状态的私有模块。
- 同协议 `eval300` 复核家族宏平均 F1，防止预处理或评估入口变化。

若任一共享参数、提示协议、量化尺度或解码设置变化，就不能引用该不变性命题解释结果。

## 4. 双锚点与队列残差如何进入私有分支

### 4.1 私有状态头

物理私有增强表示预测五个非负队列锚点：

$$
\hat{\boldsymbol q}_i
=\operatorname{softplus}\left(g_{\phi_q}(h_i^S)\right)
=\left[\hat q_{i,0},\ldots,\hat q_{i,4}\right].
$$

状态头必须读取含 $\Delta^{phy}$ 的表示，确保状态监督和物理残差能反向更新私有 LoRA。只从冻结 S3 表示预测状态，会把全部物理梯度限制在状态头，不能塑造私有生成表征。

### 4.2 双锚点稀疏监督

令 $m_{i,k}\in\{0,1\}$ 表示首锚点和一个内部锚点是否可监督，则

$$
L_{anchor}=
\frac{\sum_{i,k}m_{i,k}\left(\hat q_{i,k}-q_{i,k}\right)^2}
{\sum_{i,k}m_{i,k}+\varepsilon}.
$$

双锚点用于限制仅靠差分守恒产生的状态平移自由度。它不依赖未知攻击标签。

### 4.3 有限队列残差

对相邻锚点，使用模型预测状态构造无量纲控制体残差：

$$
r_{i,k}=
\frac{S_i(\hat q_{i,k+1}-\hat q_{i,k})
-A_{i,k}+D_{i,k}+L^-_{i,k}+L^+_{i,k}}
{B_{i,k}},\qquad B_{i,k}>0.
$$

$A$、$D$、$L^-$、$L^+$ 分别表示到达、成功离开、入队前丢弃和出队后丢弃的字节量；$S_i$ 把归一化状态恢复到公共字节尺度；$B$ 是容量预算。$B=0$ 的窗口不进入残差。

物理损失为

$$
L_{queue}=\frac{1}{|\Omega_B|}\sum_{(i,k)\in\Omega_B}r_{i,k}^2.
$$

### 4.4 当前唯一修复的训练目标

按实施计划，私有分支只使用已知子类生成监督、双锚点状态监督和有限队列残差：

$$
L_{private}=L_{subtype}+1.0L_{anchor}+0.01L_{queue}.
$$

基座与 S3 检测 LoRA冻结，梯度只更新 $\Delta^{phy}$ 和 $\phi_q$。未知攻击标签不参与训练或阈值校准；开放集只是评估时激活私有分支的任务模式。

## 6. 物理状态路由适配专家的文献裁决

### 6.1 当前状态

该路线仍是**未验证备选**，不替换或并行干扰当前单私有物理适配器实验，也不得自动启动。

文献支持以下有条件设计：

- 使用序列级路由，而不是完全自由的生成词元级 Top-K。
- 共享冻结 S3 检测 LoRA，家族任务固定关闭全部物理专家。
- 最多三个专家，分别对应平稳传输、队列累积和容量饱和。
- 专家按物理状态定义，禁止按攻击标签、数据集来源或 ns-3 场景编号定义。
- 路由输入只允许公开数据推理可得的包数、字节数、包长、到达间隔和速率等字段。

### 6.2 专家语义的最低定义

候选状态可由训练真值定义为：

1. **平稳传输**：队列变化绝对值较小，到达与服务近似平衡。
2. **队列累积**：连续窗口中 $\Delta q>0$，到达量持续超过成功离开与丢弃后的净服务。
3. **容量饱和**：队列接近有限容量，且出现丢弃或服务受容量上限约束。

公开数据推理没有队列真值和链路容量，路由器只能从公共观测预测这些状态。必须通过状态条件混淆矩阵、路由互信息、专家移除和反事实状态扰动验证语义，不能靠专家名称或二维可视化认定。

### 6.3 当前不具备自动启动条件的原因

任务十七已经证明，四窗口公共五字段的状态估计相对常数下界只改善 `3.017%`，范围外不确定性接收者工作特征曲线下面积为 `0.0811`。这意味着同一公共字段上的物理状态路由当前缺乏足够可辨识性证据。

因此，即使单私有适配器失败，也不能仅凭文献立即启动专家实验。至少还需满足：

- 能在 ns-3 训练真值上构造不依赖攻击标签的三状态监督。
- 公共五字段上的三状态路由显著优于类别先验，并在未见配置上保持稳定。
- 多专家输入不使用容量、队列真值、场景编号或未知标签。
- 用户再次明确批准一次同预算有界验证。

### 6.4 同预算对照与停止条件

若将来获批，只比较冻结 S3、单私有物理适配器、三个专家静态同权组合和三个专家序列级 Top-1 路由。专家总秩之和必须等于单适配器总秩，并报告实际激活秩、峰值显存、吞吐与端到端延迟。

出现下列任一情况即永久停止：家族下降超过 0.01、同总秩不优于单适配器、路由由数据来源或标签捷径支配、专家坍缩、没有状态选择性优势，或效率代价超过检测收益。

## 7. 第三章标题与理论编排建议

### 7.1 标题

当前标题应继续保持：

> **第 3 章 基于双锚点约束与队列守恒的物理一致性训练方法**

理由是双锚点和有限队列守恒才是两个理论支柱。非对称适配是让两个支柱能够安全写入生成式基座的训练结构，不应取代标题中的物理机制。

若唯一修复通过且希望在标题中体现分层任务，可在定稿时考虑：

> **第 3 章 基于双锚点约束与队列守恒的物理一致性分层训练方法**

在正式实验通过前不改标题。多专家备选未经批准和验证，也不得写入章节名。

### 7.2 建议的小节职责

1. `3.2` 问题定义：分层生成任务、S3/S4 负迁移事实、参数集合和威胁模型。
2. `3.3` 双锚点约束：状态平移自由度、监督掩码、边界可辨识条件。
3. `3.4` 有限队列一致性：五锚点非负状态、控制体残差、量纲和梯度路径。
4. `3.5` 非对称物理适配训练：冻结 S3、私有 LoRA、任务门控、完整算法与复杂度。
5. `3.6` 理论分析与实验：家族不变性命题、双锚点可辨识性、残差性质、消融、效率和失败边界。

可形成的理论单元包括：

- 引理：仅有差分守恒时存在状态平移自由度。
- 定理或命题：双锚点在给定观测和残差条件下限制状态平移自由度。
- 定理或命题：固定零门控和参数冻结条件下的家族分支不变性。
- 推论：家族损失对物理私有参数梯度为零。
- 复杂度分析：单私有 LoRA 增加的训练参数、激活显存和子类/开放集推理开销。

这些结论必须使用本项目自主符号和已实现计算图推导，不能照抄文献公式。

## 10. 最终裁决

1. **当前应执行的理论落地**：冻结 S3 检测 LoRA，以任务门控隔离单个物理私有 LoRA；这是任务级参数隔离，不是新博弈权重。
2. **当前可写入第三章的理论**：双锚点边界、有限队列残差、私有分支梯度路径，以及有明确假设的家族分支不变性命题。
3. **当前不能主张的结论**：私有适配器必然提升检测、多专家必然形成物理语义、负载均衡等于物理专门化，或家族指标在未验证工程前天然不变。
4. **多专家路线**：文献链真实且设计可描述，但公共字段可辨识性尚未满足，仍是需再次批准的有条件备选，不自动启动。
