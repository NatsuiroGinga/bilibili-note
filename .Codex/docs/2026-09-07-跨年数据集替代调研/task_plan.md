# 跨年数据集替代调研计划

## 目标

判断最适合研究时间分布漂移且仍有可测改进余量的公开网络安全数据集，并确定其能否替代或补足第三章的 LSPR23/24。候选不限于加密恶意流量，可覆盖服务分类、入侵检测、恶意软件检测和 DNS 威胁检测。

## 冻结边界

- 不下载大型数据，不运行实验，不读取最终目标标签。
- 不修改论文正文、RWKV 路线总控、第三章恢复卡或 Goal。
- LSPR25 按用户裁决记为“题录存在但实际不可用”，排除出可执行推荐。
- 事实只由本地全文、官方数据页、原始论文或官方仓库支持；博客、检索摘要和二次论文只用于发现候选。
- 每个候选核查采集年份跨度、真实或仿真、加密流量、恶意标签、实体键、时间戳、规模、许可与下载、原始包或流、特征兼容、跨年协议、任务匹配和泄漏风险。
- 每个候选新增“已发表可比前沿与天花板余量”：只采纳时间前向或跨期、实体安全、适配类别不平衡且可复现的强结果；同年随机切分高分不得作为饱和证据。
- 科学排序不考虑复用现有 FT 工程是否便利；工程成本只作为资源与工期说明。
- RWKV 结构适配必须有自然唯一顺序、因果前缀、合法重置键和跨窗口依赖证据；禁止把任意表格行排序后称为序列。
- 新近性排序优先 2026 年发布、其次 2025 年发布，但发布日期与实际采集年份分开记录；没有时间切分强基线的最新数据只能列探索候选。

## 评分口径

- `0`：不满足或证据明确反对。
- `1`：部分满足，需高成本重构或关键元数据缺失。
- `2`：明确满足且由原始来源核验。
- 泄漏风险反向记分：`低`、`中`、`高`；同时列出风险来源，不用单一总分掩盖硬门槛。
- 不设置 `0.95` 或 `0.99` 一类任意饱和阈值；优先比较置信区间、测量分辨率、错误数和运营分面。
- 不将现有工程复用成本纳入科学评分。
