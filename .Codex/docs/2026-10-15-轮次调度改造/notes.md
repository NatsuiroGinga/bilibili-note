## §1 离线分析（改码前，/tmp/rho_ema_analysis.py + /tmp/beta_choice.py）

数据：`full_expreplay_m200_rho.log` 与 `full_expreplay_m200_rho_cap8.log` 的 110 个实测 ρ。

1. **repeat 映射复现**：以 ρ→λ→m_r 映射离线复算两份日志的 110 个 repeat，最大误差 0（逐位对上）。
2. **噪声结构**（cap8 跑的 110 个 ρ）：mean +0.115、std 0.350；
   逐年去趋势后 lag-1 自相关平均 **−0.12**（近白噪声）——逐轮 ρ 起伏主要是测量噪声；
   年内存在弱上升趋势（平均斜率 +0.0235/轮）。
3. **β 选择**：相对「年内均值」的平均跟踪误差：raw 0.257、β=0.5 0.158、β=0.7 **0.140**、β=0.9 0.205（U 形，滞后反弹）。
   ⇒ 取 β∈{0.5, 0.7} 两档（β=0.9 起滞后伤害超过降噪收益）。
4. **EMA 仿真与 a\* 重标**（用 cap8 跑的 ρ 序列、cap 8）：
   β=0.5：a\*=0.99091 时均值降到 3.63 → 重标 **a\*=0.990196**（均值 3.99）；
   β=0.7：a\*=0.99091 时均值 3.44 → 重标 **a\*=0.989397**（均值 3.99）。
   机制：m_r(ρ) 对 ρ 凸，平滑降噪同时压低均值，故 a\* 须下调（加大记忆权重）保总量。
5. **cap 重标定**（无平滑、cap8 跑 ρ 序列）：cap=5 → a\*=0.988155（顶格 50%）；cap=6 → a\*=0.989547（顶格 27%）。
6. **既有产物核对**：cap8 实际平均 repeat 3.97≈4（标定迁移有效）；
   **无上界臂实际平均 repeat 4.76（目标 4，超 19%）**——其 a\*=0.99173 的标定序列与该跑不符，
   该臂并非严格等总量，87.38 读数引用时须注意（方向上仍支持「无上界有害」，因其总量还更高）。
7. **逐年平均 repeat（cap8）**：2014:6.2 → 2025:1.5，晚年被系统性低配（n_c 小 ⇒ 同 ρ 下 repeat 低）；
   这是一个与常数臂的既存口径差（调度臂按「记忆份额 λ」分配，常数臂按固定 repeat 分配），不改，只披露。
