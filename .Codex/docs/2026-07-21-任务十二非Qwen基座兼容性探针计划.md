# 任务十二：非 Qwen 基座兼容性探针计划

## 目标

在不更改 PINN 方向、队列残差和稀疏监督协议的前提下，选择一个非 Qwen、1B～3B 的公开权重解码器，验证当前负结果或生成任务退化是否与 Qwen3-1.7B 的表示和优化特性相关。

## 约束

- 候选必须来自官方模型卡或一手发布源，无人工申请门禁，许可证清晰，可由 `AutoModelForCausalLM` 和 PEFT LoRA 加载。
- 优先选择具有官方对话模板的 1B～2B 指令模型，不得为制造增益而故意选择明显过弱或过时模型。
- 基座模型下载到 `/root/autodl-tmp/thesis/models/`，记录完整模型标识、版本修订、许可证、文件清单和占用空间。
- S3/S4 当前运行期间不启动新 GPU 进程；只允许检索、下载、配置和静态兼容性审计。
- 探针使用与 Qwen 完全相同的 GeNIS/ns-3 数据、`q0` 20% 稀疏监督、队列守恒残差、LoRA 学习率、样本顺序和评价指标。
- 先运行 S1/S2 各2步冒烟；兼容后运行各50步探索。只比较同一基座内 S2 对 S1 的相对变化，不直接比较不同分词器的绝对生成损失。
- 探针通过只表示进入 202 步和多随机种子的候选，不替换当前主基座，也不得据此宣称跨基座可迁移。

## 步骤

1. 从官方模型卡核验2～3个候选的参数量、许可证、模型类型、对话模板和 PEFT 兼容性，只选一个。
2. 只读检查服务器剩余空间和已有模型；空间充足后使用 `HF_TOKEN` 下载到独立目录。
3. 执行分词器对话模板、四位量化加载、`output_hidden_states` 和 `all-linear` LoRA 静态兼容性检查。
4. 等待 S3/S4 退出后，启动 S1/S2 各2步冒烟。
5. 冒烟通过后启动 S1/S2 各50步探针，保存 SwanLab 在线记录和完整制品。

## 门禁

- S2 相对 S1 的未观测锚点误差和物理残差必须同时改善，生成损失恶化不超过5%。
- 若两个基座均出现相同的生成退化，则优先修改多目标优化机制，而不继续更换基座。
- 若非 Qwen 通过而 Qwen 失败，则进入各202步单进程复验，并在论文中保留 Qwen 的适用边界。
