## uv 决策

`uv 0.11.17` 可用，平台为 `aarch64-apple-darwin`。但该项目发布的是原生二进制，维护方安装脚本通过 `gh release download` 获取该资产，未提供可核验的 Python 分发包或 `uv tool` 安装入口。为避免将无关包伪装为同一 CLI，未使用 `uv` 管理安装；本仓库混合检索仍通过既有 `uv run --project scripts/literature_search --locked --no-sync` 调用适配器。

该结果证明命令发现和适配器调用链有效，但尚不能声明 Google Scholar 查询成功。没有下载 PDF，也没有写入 `raw/`、`wiki/` 或 Zotero。

## 唯一用户动作

在已登录 Google Scholar 的 Chrome 以远程调试端口启动后，由用户在终端执行：

```bash
scholar auth --port 9222
```

此动作会从 Chrome 调试端口提取认证 cookie。代理未执行认证、未操控浏览器或账号，且未读取或记录 cookie 内容。完成后可重新运行同一来源级查询确认状态。
