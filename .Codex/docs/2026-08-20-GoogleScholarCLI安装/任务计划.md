# Google Scholar CLI 安装计划

## 目标

为混合文献检索的 Google Scholar 来源补齐本机 `scholar` 命令，并验证其真实来源级状态。

## 范围

- 仅安装维护方发布的 Apple Silicon 二进制到用户级命令目录。
- 不修改检索代码、`raw/`、`wiki/`、Zotero 或论文正文。
- 不读取、打印或写入 cookie、密码、令牌等凭据。

## 验收

- [x] 追溯技能实际维护方、CLI 仓库、发布版本和 Apple Silicon 资产。
- [x] 下载并核验 SHA-256 后安装 `scholar`。
- [x] 验证 PATH、帮助页和一次 `machine learning` 来源级调用。
- [x] 记录认证阻塞与用户唯一需执行的动作。

## 决策

该 CLI 只以预编译发布资产提供，未发现可验证的 Python 包或 `uv tool` 入口。因此不伪造 `uv` 安装；采用维护方官方安装器相同的 GitHub Release 资产路径，并记录资产哈希。
