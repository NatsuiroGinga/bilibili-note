# RWKV 网络空间安全双创新点调研计划

## 目标

基于可核验全文，为当前 PINN/R2 最终失败时提出基于 RWKV 的网络空间安全或人工智能安全**替代毕业论文主题**；每条主题给出两个协同创新点和第五章系统。当前 R2 不被修改或停止，本调研不构成转题裁决。

## 固定边界

- PINN、Qwen3-1.7B、共享守恒和 TCP/UDP/条件 QUIC 专家是旧路线资产，而非本调研硬约束；每个主题说明可复用资产和必须放弃的资产。
- 不复制朱焱雷论文的斯塔克尔伯格、二阶反应梯度或其他具体机制，只分析其第三至第五章的组织、机制协同与实验编排。
- 每个候选必须通过四项联合门槛：章节与理论工作量、单张 RTX 5090 可验证性、数据可获得性、相对全部强基线的可证伪提升潜力。

## 研究问题

1. RWKV 的递归状态对哪些真实安全困难任务有最可信的因果匹配？
2. 哪个主题在网络流量、长期安全日志或人工智能系统安全中同时具有数据、基线、单卡成本和论文工作量可行性？
3. 两个机制怎样职责不重叠、计算图连通，并在第五章形成可部署系统？
4. 旧 R2/PINN 数据、代码和评测中哪些可复用，哪些会构成转题成本？

## 六阶段与验收

- [x] 阶段 1 范围定义：完成关键词、时间范围、纳入排除标准、停止条件、证据等级和本地去重盘点。
- [x] 阶段 2 检索收集：核验 RWKV 本体、演进、网络安全直接应用、第二机制支撑、朱焱雷章节组织四个证据簇的标识符与来源。
- [x] 阶段 3 筛选分类：记录每篇纳入或排除理由，区分全文、仅元数据和受限全文。
- [x] 阶段 4 全文分析：精读朱焱雷第三至第五章及核心 RWKV/网络安全全文，记录页码或章节证据。
- [x] 阶段 5 综合空白：形成候选组合、计算图、公式空间、5090 预算、数据合同、基线矩阵与最小先导实验。
- [ ] 阶段 6 候选裁决准备：制品、原文与 wiki 笔记/索引已完成；路线尚未冻结，待 CPU 数据门禁和由主代理协调的 RTX 5090 先导裁决。

## 数据与实验硬门槛

- 对每个候选估算参数量、序列长度、批量、精度或量化、优化器状态、峰值显存、单次训练和三种子总时长；给出单卡降级配置和停止条件。仅推理可行而训练不可行者不得作为主创新。
- 逐项核验 GeNIS、TQH-C2、ns-3、QUIC qlog 与候选补充数据的官方页面或 DOI、许可证、获取状态、标签粒度、协议与时间字段、原始包/流/日志、物理真值、规模和预处理成本。
- 每个候选明确训练、校准、开发验证、最终测试的隔离方式；公开检测数据与仿真/物理辅助数据不得混成可调权总分。
- 强基线矩阵至少含任务适配的传统强基线、轻量 Transformer/编码器、普通 RWKV 和机制消融；若复用旧流量资产，Qwen/R2 仅作为可选历史对照。所有比较共享信息预算、拆分、调参预算和统计程序。
- 开发评价预注册主指标、困难域/时间前向/开放集指标、效率指标和统计检验。相对全部强基线稳定提升仅能作为待证伪门槛。
- 把“困难任务因果匹配”作为候选排序的非硬门槛：优先使用文献与安全场景预先定义的超长流/跨窗口、在线流式、加密不可见、时间前向漂移、开放集、长尾少样本、跨源泛化或有限显存低延迟面板。不得按本方法或基线结果事后挑选。
- 困难面板同时报告简单域非退化、困难域增益、等权均值与最差域；基线共享数据、信息和调参预算。困难域无稳定增益时，候选必须降级，不得改数据挽救。
- 单列人工智能系统安全相邻簇，区分“用人工智能检测网络安全问题”和“保护人工智能系统本身”。覆盖提示注入、越狱、输入输出监测、智能体审计日志、对抗鲁棒性、隐私/投毒、供应链和运行时安全；无 RWKV 直接证据时仅能作为迁移假设。
- 至少一组候选评估网络流量安全与人工智能系统安全的统一流式监测；必须审查其是否偏离恶意流量检测主题、数据能否统一、基线能否公平比较以及单卡成本是否可控。任一条件不成立时降级为后续系统扩展。
- 对人工智能系统安全数据单列官方来源、许可证、标签、强基线和公平提升门槛。
- 强化学习只在存在序列决策、可验证奖励或实际资源约束时进入候选。静态分类不得强加 GRPO；奖励不得读取标签、最终测试或模型预测，并预注册反投机检查。
- 课程学习必须定义可计算难度、调度公式和独立消融，区分于普通重加权或难例挖掘。
- DeepSeekMoE、MLA、MTP、无辅助损失负载均衡和 R1/GRPO 流程逐项适配；引入全注意力、超大 MoE 或不可复现实验成本时直接否决。
- 先完成候选排序，仅对前一至二个候选做 CPU 数据门禁和单卡短预算先导；最终测试不可见。GPU 使用须由主代理与正在运行的 R2 协调。
