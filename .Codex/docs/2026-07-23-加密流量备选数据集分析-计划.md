# 加密流量备选数据集分析计划

## 目标

核验 Osnabrück Dataverse 数据集与 arXiv:2410.03728 的来源关系、数据契约、泄漏风险和实验适配性，形成可执行的数据集角色裁决与防泄漏采样方案。

## 关键问题

1. 两个链接是否属于同一数据集，哪个是规范数据引用，哪个是方法论文？
2. 数据中实际包含哪些加密协议、标签、主机、时间与会话标识？
3. 能否以主机、会话、采集时间或场景做不重叠切分？
4. 其特征能否映射到当前 Qwen 分层生成接口，是否提供 PINN 所需的队列物理量？

## 决策边界

- 不下载大型数据归档，只保存论文 PDF 和小型 README/元数据。
- 官方发布页和 API 是文件级信息的主证据；论文 PDF 是方法、采集、标签和基线的主证据。
- 不修改实验代码、不启动实验、不更新两份高层恢复文档。

## 错误记录

- 首次 `jq` 版本字符串表达式语法错误；改为字符串插值后成功。
- 使用 `awk` 求 VisQUIC 图像数时超过表达式回推限制；改用 `jq` 数组求和。
- VisQUIC Dropbox 页面在 `curl` 下三次均被对端重置，且当前环境无可用浏览器；因而不能核对全量 ZIP 的精确文件名、大小和哈希。
- GitHub API 返回 403；已通过官方 raw README、LICENSE 和浅克隆仓库完成代码级核验。
