# E1 跨域失败与第三章路线裁决分析

## 一、裁决结论

1. **C 跨域失败提供了合理且幅度充足的方法研究空间，但只支持“快捷特征受控的未见测试床分组外推”，不支持“跨加密因果泛化”。** 同一 C 验证集在训练包含 C 时，HGB 与 XGBoost 的宏 F1 都为 `1.0`；训练排除 C 后，宏 F1 降到 `0.128186～0.146574`，恶意召回降到 `0～0.003272`。这不是域内任务已不可改进，而是源域规则几乎不能迁移到 C。
2. **该失败不能直接证明 PINN 是正确解法。** E1 只有 HGB、XGBoost、种子 42 和固定默认预算，没有随机森林、数值神经网络、普通编码器或域泛化基线。C 同时改变测试床、C2 框架、流量行为和类别先验，物理机制是否能提供更稳定表征仍需独立对照。
3. **E1 足以通过“是否存在困难域”的先验闸门，不足以支撑第三章方法工作量。** `leave_profile_C` 与 `A+B+D→C` 是同一次训练和同一组结果；`A+B→C` 是同一 C 外推面板的源域删减变体；当前“最差组”只到测试床级，尚无捕获组级结果。它们不能作为四条独立创新证据重复计数。
4. **E2 应先验证最小共享 PINN，而不是直接展开完整协议专家。** 推荐比较强传统基线、同输入编码器、一个预注册域泛化基线，以及“普通监督、仅状态监督、状态加共享守恒、分组置换物理监督”四组。只有共享 PINN 同时改善 C 检测和独立物理指标后，才增加 TCP/QUIC/UNKNOWN 路由。
5. **域内 `0.999618` 只保留为执行健全性结果。** 第三章主要证据应来自 `A+B+D→C`、`A+B→C`、捕获组等权与最差组结果；B→D、D→B 只作为后续协议栈迁移和负迁移面板。

## 二、E1 证据的有效解释

### 2.1 观察结果

| 训练到验证 | 模型 | 宏 F1 | 恶意召回 | 良性误报率 | ECE | 关键解释 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| A+B+C+D→开发验证全集 | HGB / XGBoost | 0.999618 | 0.999072 | 0 | 0.000277 / 0.000222 | 域内执行健全性，不能证明外推 |
| A+B+C+D→C | HGB / XGBoost | 1.0 | 1.0 | 0 | 0.000024 / 0.000118 | 训练已见 C，说明 C 域内可分 |
| A+B→C | HGB | 0.128186 | 0.001227 | 0.153846 | 0.844413 | 仅检出 3/2445 条恶意流 |
| A+B→C | XGBoost | 0.146574 | 0 | 0 | 0.824185 | 2952 条全部预测为 `non_c2` |
| A+B+D→C | HGB | 0.134645 | 0.002454 | 0.114398 | 0.844075 | 仅检出 6/2445 条恶意流 |
| A+B+D→C | XGBoost | 0.145427 | 0.003272 | 0.037475 | 0.827828 | 仅检出 8/2445 条恶意流 |

最重要的效应不是 `0.999618` 与 `1.0` 的细小差异，而是同一 C 验证集从“训练已见 C 的完全可分”变成“训练未见 C 时几乎漏掉全部恶意流”。加入 D 没有修复 C，说明增加一个源测试床不足以消除该偏移。

### 2.2 类别先验是必须控制的混杂因素

- A+B 训练集为 `5001/64430=7.76%` 恶意；A+B+D 为 `5638/70183=8.03%` 恶意。
- C 验证集为 `2445/2952=82.83%` 恶意，类别先验方向发生反转。
- 在 C 上恒预测 `non_c2` 的宏 F1 为约 `0.1466`，恰好对应 A+B→C 的 XGBoost 结果。
- 在 C 上恒预测 `malicious_c2` 的宏 F1 可达到约 `0.4530`，但良性误报率为 `1.0`。

因此，只提高 C 宏 F1 很容易被“整体提高恶意预测率”伪造。E2 必须同时锁定恶意召回、良性误报、源域非劣和校准，不得用一个阈值后宏 F1 单独裁决。

### 2.3 当前字段审计说明了什么

E1 没有发现 IP、端口、`conn_state`、`capture_id`、`profile` 等直接禁止字段，因而不能把结果写成直接标签泄漏。现有证据更符合**冗余的数据生成捷径**：

- 多个单字段在训练包含 C 时即可得到较高 C 域内宏 F1；`resp_bytes` 与 `resp_ip_bytes` 在两个模型上都超过 `0.95`。
- 删除任一字段造成的最大绝对宏 F1 变化仅为 `0.0002183`，说明多个大小、包数和 IP 字节字段可互相替代。
- 这些单字段和逐字段删除实验的训练仍包含 C，不能据此声称单字段能从 A/B/D 外推到 C。
- 下一轮需要做**跨域字段族审计**，而不是继续只删一个高度冗余字段。至少应分别审计持续时间、包数字段族、字节字段族以及全部允许字段。

### 2.4 统计边界

- E1 只有一个种子，不能做显著性或稳定性结论。
- C 验证集只有两个捕获组，样本数分别为 2745 和 207，占比约为 `92.99%` 和 `7.01%`。当前流级汇总由大组主导，不能替代捕获组等权和最差组结果。
- C 中只有 507 条良性流，单个误报对应约 `0.197%` FPR。`TPR@0.1% FPR` 在该验证集上不可分辨，不应作为 E2 硬门槛；可使用 `TPR@1% FPR`，并同时给出误报计数和二项区间。
- B→D 中 HGB 宏 F1 为 `0.967834`，XGBoost 仅为 `0.378030`；D→B 两者均超过 `0.99`。该不对称和模型差异说明不能从两棵提升树中挑一个结果代替完整强基线闸门。

### 2.5 允许与禁止的主张

**当前允许的表述：**

- 去除直接禁止字段后，C 仍构成明显的未见测试床分布外推失败。
- E1 为域泛化、稳健训练和受控物理辅助提供了可检验的误差空间。
- 大小、包数和持续时间字段存在强冗余数据生成模式，域内高分不能作为创新证据。

**当前禁止的表述：**

- PINN 已经能够改善 C，或 C 的失败由缺少物理约束造成。
- A/B/C/D 只改变加密层，或 E1 证明了普遍跨加密能力。
- C 单字段高分证明相应字段具有跨域不变性。
- E1 已形成第三章完整实验工作量或统计显著结论。

## 三、E1 对第三章工作量的真实贡献

| 当前项目 | 是否独立证据 | 当前作用 | 仍缺什么 |
| --- | --- | --- | --- |
| C 域内 `1.0` | 是，但只属健全性 | 证明 C 并非域内不可分 | 不能承担泛化或方法增益 |
| `leave_profile_C` | 否 | 等同 `A+B+D→C` | 不得与后者重复计数 |
| `A+B+D→C` | 是 | 主困难域面板 | 强基线、多种子、组级结果和方法增益 |
| `A+B→C` | 是，但与上项高度相关 | 源域删减敏感性 | 只能作确认面板，不能包装成第二个研究问题 |
| “最差组” | 尚未形成 | 当前只能说 C 是最差测试床 | 逐 `capture_id`、间隔、抖动的等权与最差值 |
| B→D、D→B | 是 | 受控协议栈迁移与负迁移 | 同框架强基线、路由消融和双向分别报告 |

E1 的 22 套协议和 44 次拟合解决的是**问题选择与协议诊断**，不是方法贡献。第三章仍缺以下互相独立的证据：

1. 强传统、神经网络与域泛化基线，且全部使用相同拆分和信息预算。
2. 普通监督、状态辅助、真实物理残差和置换物理监督之间的因果消融。
3. 三种子原始值、捕获组等权、最差组和源到目标下降。
4. 模型预测状态的误差、无量纲残差、非零梯度与极端条件检查。
5. 物理方程适用条件、可观测性、量纲和检测非劣边界等理论证据。
6. 训练时间、峰值显存、参数量、吞吐和推理延迟。
7. 模型与阈值冻结后的一次性最终测试。当前最终测试继续不可见。

## 四、E2 最小且不膨胀的比较矩阵

### 4.1 固定问题与面板

- **主面板**：A+B+D→C。它对应完整源测试床集合到未见 C 的外推。
- **确认面板**：A+B→C。它只检验去掉 D 后结论是否改变，不与主面板合并成“两个数据集”。
- **同源非退化面板**：A、B、D 的源域捕获组验证，直接从同一轮预测计算，不增加模型拟合。
- **后置机制面板**：只有 E2 通过后，才在 B→D、D→B 上比较入选的非物理基线与 PINN；不在第一轮铺开全部协议专家组合。
- **最终测试**：不参与 E2；C 校准组和未分配组也不得用于阈值、调参或早停。

所有需要随机初始化的方法固定种子 `42/43/44`。确定性基线可只运行一次，但必须保存逐样本预测以计算捕获组指标。预处理器、类别权重、超参数和阈值只能由对应源域训练与源域校准确定。

### 4.2 强基线

| 层次 | 必选方法 | 责任 |
| --- | --- | --- |
| 无技能诊断 | 恒预测两类、分层随机预测 | 暴露 C 类别先验对单一宏 F1 的影响，不作为强模型 |
| 线性诊断 | 标准化 LogReg | 检查七字段的线性边界，不作为复杂方法必须击败的唯一基线 |
| 传统强基线 | 随机森林、HGB、XGBoost | 对齐 README 与文献中的简单模型门槛；E1 的 HGB/XGBoost 保留为固定默认锚点 |
| 数值深度基线 | 同七字段的 MLP | 排除“树模型不适合迁移”这一单一解释 |
| 主基座基线 | 无物理机制的普通 DistilBERT | 与后续物理状态头保持相同编码器、输入、参数预算和训练步数 |
| 域泛化基线 | 预先固定 GroupDRO 或仅源域 CORAL 中的一种 | 检验增益是否只是一般域稳健训练即可获得；不得看 C 结果后在两者间择优 |

ET-BERT 使用原生 PCAP/BURST 视图，不属于严格共同字段 E2 主表。它应在主方法冻结后作为外部强基线单列，不应为追求表格数量阻塞 E2 路线裁决。Qwen3-0.6B 也不进入 E2 主检测选择，只在方法冻结后做跨基座方向验证。

### 4.3 最小 PINN 因果对照

| 组别 | 结构 | 回答的问题 |
| --- | --- | --- |
| `E2-A` | 普通编码器或同参数量中性分支，无状态监督、无物理残差 | 普通监督下限 |
| `E2-S` | 增加可微状态预测头，只做状态监督 | 收益是否只是多任务辅助 |
| `E2-P` | `E2-S` 加共享守恒残差和边界项 | 物理残差是否提供独特增益 |
| `E2-X` | 与 `E2-P` 完全同结构，但在源域、协议和标签分层内按捕获组置换物理监督 | 排除额外参数、缺失模式和数据源标识带来的收益 |

若 `E2-P` 比 `E2-A` 多读取了历史，则必须增加一个同历史、无物理监督的 `E2-H`；若所有组本来就使用完全相同历史，则不增加该组。随机物理 `F-R` 只在 `E2-P` 已优于 `E2-X` 后进入正式消融，避免第一轮无边界扩张。

E2 暂不加入 TCP/QUIC/UNKNOWN 专家路由。共享状态头和守恒残差先证明有效，随后才判断协议专家是否必要。这样可避免 B 的 QUIC、D 的 TCP 与测试床身份高度绑定时，路由直接成为域标识捷径。

### 4.4 拟合量

一个不膨胀的 E2 核心矩阵可控制在约 48 次新拟合：

- LogReg、HGB、XGBoost 等确定性诊断和传统锚点：`3 方法 × 2 面板 = 6` 次。
- 随机森林、MLP、普通编码器、一个域泛化基线：`4 方法 × 2 面板 × 3 种子 = 24` 次。
- `E2-S/E2-P/E2-X`：`3 组 × 2 面板 × 3 种子 = 18` 次；`E2-A` 已由普通编码器覆盖。
- 若物理方法独占额外历史，再增加 `E2-H` 的 6 次；否则不增加。

捕获组、间隔、抖动、源域非退化、校准和效率均从这些运行的逐样本预测与日志派生，不为每个指标另起训练。只有 `E2-P` 通过后，才追加最佳非物理方法与 `E2-P` 的 B→D、D→B 三种子确认，最少 12 次。ET-BERT、完整专家路由、随机旁路和跨基座验证均属于通过后的正式扩展，不进入路线筛选成本。

## 五、预注册指标与通过门槛

### 5.1 指标口径

| 类型 | 预注册指标 | 口径 |
| --- | --- | --- |
| 主要检测指标 | C 捕获组等权宏 F1 | 每个 `capture_id` 先算宏 F1，再等权平均；同时列出两个组原始值 |
| 共同主要指标 | C 最差捕获组宏 F1 | 防止 2745 条的大组掩盖 207 条的小组 |
| 操作指标 | 恶意召回、良性误报率、`TPR@1% FPR` | 部署阈值仅由源域校准冻结；目标域曲线上的 `TPR@1% FPR` 只作阈值无关诊断 |
| 阈值无关指标 | PR-AUC、MCC、平衡准确率 | C 恶意类占多数，PR-AUC 必须与 MCC、平衡准确率共同解释 |
| 校准指标 | ECE、Brier 分数、负对数似然 | E1 的跨域 ECE 超过 0.82，必须审计置信度失效 |
| 泛化指标 | 源到目标宏 F1 下降、A/B/D 源域等权宏 F1 | 防止以破坏源域换取 C 提升 |
| 物理指标 | 状态归一化均方根误差、未观测状态误差、无量纲残差、约束违反率 | 使用 ns-3/qlog 的独立真值；不能代替公开检测收益 |
| 效率指标 | 可训练参数、训练时长、峰值显存、吞吐、单样本延迟 | 与 `E2-A` 在同硬件和批大小下比较 |

### 5.2 推荐的 E2 筛选门槛

以下数值是**运行前的路线筛选合同**，不是由 E1 结果反推的论文结论。若要修改，必须在查看 E2 结果前完成并记录理由。

1. **检测增益**：`E2-P` 相对 `E2-A`、`E2-S`、`E2-X` 和预注册域泛化基线，在 A+B+D→C 与 A+B→C 两个面板上三种子方向全部为正，且捕获组等权宏 F1 的平均绝对增益均至少为 `0.03`。
2. **非退化检测**：源域 A/B/D 的捕获组等权宏 F1 相对最佳同输入非物理基线下降不超过 `0.01`；任何源域不得出现新的类别塌缩。
3. **操作可用性**：在源域校准冻结阈值下，C 恶意召回至少为 `0.20`，良性误报率不高于 `0.05`；`TPR@1% FPR` 相对最佳同输入非物理基线至少提高 `0.10`。该门槛用于排除“全报良性”和“全报恶意”，不是最终部署标准。
4. **最差组稳定性**：两个 C 捕获组均不得低于对应 `E2-A`，且最差组宏 F1 至少提高 `0.03`。不能只靠大组改善通过。
5. **校准非劣**：ECE 相对 `E2-A` 恶化不超过 `0.02`，Brier 分数和负对数似然不得同时恶化。
6. **物理有效性**：`E2-P` 相对 `E2-S` 的状态误差和无量纲残差都至少下降 `10%`，残差对可训练状态头参数的梯度范数非零；真实物理监督还必须优于 `E2-X`。
7. **效率边界**：相对 `E2-A`，推理延迟和峰值显存增幅各不超过 `20%`；超出时不能直接升级为主方法，必须说明检测收益是否值得该成本。

若最强非物理基线已经在 C 捕获组等权宏 F1 和 `TPR@1% FPR` 上都达到 `0.90`，且 `E2-P` 未达到上述增益门槛，应停止扩展复杂 PINN，不能削弱基线、改变拆分或人为制造难度。若 `E2-P` 只改善物理指标而不改善检测，只能写成状态辨识结果，不能写成恶意流量检测创新。

### 5.3 统计报告

- E2 三种子只用于路线筛选。必须报告每个种子的原始值、均值、样本标准差和配对差值，不能报告显著性胜出。
- 捕获组是泛化分析单位，流记录不是独立重复。当前 C 只有两个验证捕获组，不应对 2952 条流做伪重复显著性检验。
- 若正式论文需要显著性措辞，应在模型和门槛冻结后预先扩展到至少 5 个随机种子，并对预注册主要对比做配对区间；多个方法对比使用 Holm 校正。
- 恶意召回和良性误报率同时报告分子、分母及二项置信区间。C 的 `0.1% FPR` 分辨率不足，不作为通过条件。

## 六、避免利用数据捷径的执行规则

1. **白名单输入**：分类器只接收冻结的七个允许字段或所有方法共同拥有的因果历史。`profile`、`capture_id`、间隔、抖动、文件路径、行号、采集月份、协议配置和标签派生字段只用于拆分与审计。
2. **源域拟合**：标准化、缺失填充、词元化配置、类别权重、早停、超参数和阈值全部只从源域训练或源域校准拟合。A+B+D→C 不加载任何 C 校准样本，包含无标签预训练和自监督统计。
3. **组级隔离**：训练、校准、验证和最终测试继续按 `capture_id` 与 `timing_group_key` 隔离。训练批次和损失按捕获组等权，不能让大捕获组决定目标。
4. **字段族审计**：补做 A+B→C、A+B+D→C 下的持续时间、包数、字节三类单族和整族删除审计。E1 的域内单字段与单列删除表继续保留，但不能替代跨域整族审计。
5. **域可预测性审计**：在源域上单独训练测试床或捕获组预测器，量化允许字段中的域标识强度。该预测器只作诊断，不能给主分类器提供域标签。
6. **物理负对照**：`E2-X` 在源域、协议、标签和缺失模式分层内按捕获组置换物理监督，既保留边际分布又破坏样本对应关系。若真实物理不优于该对照，不能把增益归因于物理一致性。
7. **路由后置**：E2 不使用测试床或协议配置路由。后续若加入被动可观察协议证据，所有普通监督、树模型和编码器基线必须获得同一信息预算，并增加无路由和置换路由消融。停止梯度本身不能证明路由没有利用域捷径。
8. **辅助源隔离**：ns-3 和 qlog 只提供训练期状态真值与物理评价，不提供 TQH 标签、测试床身份或最终测试分布。最终测试捕获在任何无标签预训练阶段也保持不可见。
9. **一次性 C 使用**：E1 已使用固定 C 开发验证作路线诊断。E2 的候选、损失权重和停止条件必须预注册，不能反复查看 C 后继续修改；正式最终测试只在方法完全冻结后开启一次。
10. **完整失败记录**：保存所有运行的配置、代码哈希、数据哈希、逐样本预测、捕获组指标和失败状态。不得只保留提高 C 的种子或模型。

## 七、第三章路线的最小升级顺序

1. 先运行 E2 强基线和最小共享 PINN 的 48 次以内核心矩阵。
2. 只有 `E2-P` 同时通过检测、最差组、源域非劣、校准和物理门槛，才加入 B→D、D→B 的双向确认。
3. 只有双向迁移显示共享 PINN 仍有协议相关失败，才实现 TCP/QUIC/UNKNOWN 专家和路由消融。
4. 完整方法冻结后再补 ET-BERT 原生字节视图、Qwen 跨基座验证、正式多种子统计和一次性最终测试。
5. 理论部分只围绕最终通过的状态方程、守恒残差、边界、梯度和非劣条件展开；未通过的专家不进入贡献点名称。

## 九、最终裁决

**保留第三章“有界物理条件下的分组外推与困难域检测”路线，但把 E1 只记为问题选择门禁。** C 的巨大跨域失败说明研究问题真实存在；类别先验反转、两个捕获组高度不均衡和字段族冗余又说明，任何只提高流级汇总宏 F1 的方法都可能再次利用捷径。下一步应以最小共享 PINN 对照证明“真实物理约束相对普通监督、状态辅助、置换物理和一般域泛化具有独特增益”，通过后再扩展协议专家、理论与正式工作量。
