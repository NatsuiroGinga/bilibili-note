# 过程文档与归档规则

<!-- 规则加载哨兵：NOTE_CODEX_DOCS_20260724 -->

本文件适用于 `.Codex/docs/`，并继承仓库根规则。

## 目录职责

- 本目录保存实施计划、任务简报、过程笔记、实验记录、子代理报告、审查报告、公式证据台账和历史备份。
- 新建过程文档默认放在本目录；只有用户明确要求高层交付物或更新既有恢复文档时才写 `output/`。
- 详细文档按两份恢复文档的索引和当前任务需要读取，不得把全部历史材料重新塞入默认恢复上下文。
- `archive/` 保存历史证据。需要核验时用明确路径或 `--no-ignore` 只读访问；不得为了缩短上下文删除、覆盖或搬回当前目录。

## 记录要求

- 计划写明任务边界、文件范围、验收命令、制品路径、状态、决策和阻塞项；新证据改变范围时再更新。
- 子代理实现或审查报告至少记录修改文件、失败与通过的测试命令及结果、格式化和静态检查、运行制品路径、遗留风险。
- 实验详细记录保留唯一运行目录、服务端与本地路径、SwanLab 项目和运行标识、失败原因及复核证据；不得包含密码、令牌或登录命令中的明文凭据。
- PINN 公式证据台账记录来源语义、实质修改、变量可观测性、量纲、梯度路径、极端条件和数值验证，不能用摘要代替证据。
- 文档使用明确日期和主题命名，中文优先；避免无语义的 `notes-final-v2`、重复计划或大段原始日志副本。

## 与恢复文档的关系

- 本目录提供详细证据，不替代 `output/开题改进交接文档.md` 和 `output/第一创新点实验总控.md` 的高层状态。
- 确定裁决、结果、路径或状态变化后，先完善详细记录，再按仓库根和 `output/AGENTS.md` 的规则更新对应恢复文档并建立相对链接。
