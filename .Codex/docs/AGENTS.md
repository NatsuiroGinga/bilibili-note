# 过程文档与归档规则

<!-- 规则加载哨兵：NOTE_CODEX_DOCS_20260724 -->

本文件只规定 `.Codex/docs/` 的增量规则。

## 目录职责

- 本目录保存实施计划、任务简报、过程笔记、实验记录、审查报告、公式或数值依据台账和历史证据；面向论文公开表述写入 `thesis/`，高层确定交付仅在用户指定或局部规则要求时写入 `output/`。
- 新文档使用明确日期和主题命名，中文优先；避免无语义的 `final-v2`、重复计划和大段原始日志副本。
- `archive/` 只保存历史证据。核验时按明确路径或 `rg --no-ignore` 只读访问，不删除、覆盖或搬回活动目录来缩短上下文。
- RWKV 路线材料进入 `.Codex/docs/RWKV/` 前读取其 `AGENTS.md`；其他专题按已有目录和当前任务落点保存，不新建平行恢复入口。

## 最小记录

- 计划记录任务边界、文件所有权、验收命令、制品路径、状态、决策和阻塞项；新证据改变范围时立即更新。
- 实现或审查报告记录修改文件、失败与通过的命令、真实运行或制品路径及遗留风险；不得用编译或文字审查冒充科学验证。
- 实验记录保留唯一运行身份、服务端与本地路径、跟踪平台标识、失败原因和复核证据；日志只链接原始制品，不复制长输出。
- 文档不得包含密码、令牌、连接地址解析值、私有认证参数或未脱敏载荷。
