# 远程脚本规则历史说明

本文件保存 P1 压缩时移出活动规则链的故障背景。常驻门禁以 `thesis/experiments/llm_probe/scripts/AGENTS.md` 为准，完整执行细则以 `.Codex/docs/agents-split/remote-script-execution-contract.md` 为准；完整调研证据见 `.Codex/docs/codex-agents-hook-research.md`。

## 能力探测

服务器曾出现 `fd: command not found`。根因是把本机安装状态、旧实例状态和当前非交互 PATH 混为一谈。固定预检必须先加载 `.bashrc`，再启用严格 Shell 模式，依次检查 `fd`、`rg`、`uv` 的路径和版本；重启或换实例后重新生成持久化能力清单。只有文件枚举可在确认 `fd` 缺失后使用 `rg --files`，`rg` 或 `uv` 缺失不能静默降级。

## 换行与引用

调用端曾把真实换行转成字面量 `\n`，远端 Bash 因而在 `cd` 前解析失败。多行操作必须落到单一持久脚本，白名单同步并核对哈希；动态参数放入 JSON 或 YAML。临时远程载荷只能是短单行，禁止 `JSON.stringify`、嵌套 here-document 和多层字符串拼接。

另一次故障来自给已经处于单引号载荷中的 `$?`、`$status` 和算术展开再加反斜杠，导致远端收到错误字符。规则因此要求按实际 Shell 层级转义，并在正式启动前用最小状态命令验证。

## 管道与日志

已复现 `前序命令 | tee target/log` 在日志父目录不存在时失败，但后续 `wc` 和 `jq` 成功，最终 SSH 仍退出 0 的假成功。防复发合同要求：先创建并验证父目录；启用 `set -Eeuo pipefail`；若暂时关闭 `errexit`，立即复制完整 `PIPESTATUS`；只有前序命令、`tee` 和非空日志均成功才允许后处理。冒烟必须分别覆盖目录创建、不可写目标、管道左右失败和双方成功。

## 重启与启动目录

`screen` 只能抵御 SSH 断线，不能抵御实例关机。长期任务的状态、检查点、日志和恢复命令必须持久化；重启后只在配置、代码、数据、种子和硬件适配项一致时续跑。

`flow-probe-train` 还要求新正式目录在绑定和运行状态出现前为空。启动证据应先放在同文件系统 staging，子进程创建状态后再移动；提前失败则保存全部证据。该特例优先于一般的“计算前向输出目录写快照”规则。

## 压缩边界

P1 只迁移远程启动、同步、能力、Shell、恢复与脚本门禁。数据合同、科学超参数、模型入口、SwanLab、Python 测试策略和生成式评测继续留在实验根，等待各自批准的后续阶段处理。
