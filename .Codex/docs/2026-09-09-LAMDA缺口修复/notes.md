# LAMDA 缺口感知条件风险门控回放证据笔记

## 已有实验事实

- 阶段 C 的固定四角色记忆＋等单位风险损失在开发期将 FPR 从 `0.013148155` 升至 `0.089252353`，AP 从 `0.987242653` 降至 `0.936816545`；该具体实现已否决。
- 双风险梯度投影在开发期将 FPR 从 `0.013148155` 降至 `0.012231661`，旧恶意负向翻转率从 `0.052107226` 降至 `0.031983684`，但 FNR 从 `0.059478156` 升至 `0.070306038`、AP 从 `0.987242653` 降至 `0.985101162`。
- 翻转分解显示，始终投影减少了部分恶意负向翻转，但没有带来足够的恶意正向修复；这支持“仅在安全冲突时投影”的待验证假设。

## 研究假设

1. 只按上一冻结模型的 margin 缺口加权当前恶意修复，能够减少对已正确恶意样本和良性样本的无差别推高。
2. 只在修复梯度与安全参考梯度冲突时投影，能够避免始终投影造成的过度保守。
3. 两者若分别有独立信号，联合版本可能形成可解释的统一算法；没有独立信号则不凑两个机制。

## 待验证项

- 缺口修复是否在来源／开发期改善 FNR 或当前恶意正向修复而不提高 FPR。
- 条件投影是否在保持阶段双风险投影安全信号的同时减少 AP/FNR 损失。
- 联合臂是否具有超出两个单臂的互补收益。

## 2026-09-09 新综述对候选排序的影响

- Regression-aware 文献已核对 NFR 分母、PCT 公式和 ELSA 对照；PCT 是“旧正确决策保护”的直接基线，不是本项目可直接占用的创新名称。它降低负向翻转并不保证当前恶意修复或 FPR 不升。
- MADAR、GSS、MIR、PBR、CBRS、A-GEM、ECBRS/PAPA 和 FreeMOCA 分别覆盖多样性感知回放、梯度多样性、虚拟更新干扰、互信息／原型、不平衡 reservoir、梯度投影、扰动近似和参数插值。它们应承担近邻对照或部件来源，不能把抽样器、投影器或参数插值直接改名为新算法。
- PBR 的公式方向存在文献内部冲突，未解决前不得把其互信息方向写入当前候选或配置。
- 当前运行的“缺口感知修复＋条件双侧风险门控”仍作为最小探针；运行结束后，优先追加 PCT 直接基线和独立 FPR gate 的筛选，而不是继续扩展固定角色配额。
- 如果缺口修复有独立信号、PCT 只改善保持而未修复漏判，则可把二者任务化组合为主候选；若需要更强的记忆侧差量，再比较将固定角色记忆替换为 MIR/GSS 干扰感知选择的最小四臂。FreeMOCA 仅作无回放参数保持对照。
- 任何新增组合都必须在相同 FPR operating point 下比较 FNR、恶意正向修复率和旧恶意负向翻转率，并继续遵守来源／项目开发层筛选、封印年不回灌的合同。

## 九组新增方法证据的任务化映射

| 方法家族 | 已核对内容 | 对 LAMDA 第三章的处理 |
| --- | --- | --- |
| Regression-aware | NFR 分母、PCT 公式、ELSA 对照 | 作为旧正确决策保护的直接基线；报告恶意 NFR/PFR，不把 PCT 改名为创新 |
| MADAR | 历史池与回放预算分离、家族预算 | 作为家族多样性记忆对照；不引入固定角色配额作为默认主方法 |
| GSS | 梯度多样性目标、GSS-Greedy | 可作为记忆选择增强件；先证明优于同容量随机回放，不能直接承担 FPR 约束 |
| MIR | 虚拟更新干扰分数、读写边界 | 可替换固定角色记忆，选择旧正确样本中最易被当前更新干扰者；需控制额外前向成本 |
| PBR | 互信息公式及正文方向冲突 | 方向冲突未裁决前排除出当前配置，只保留文献审计记录 |
| CBRS | 类别内 reservoir 替换公式、实验对照 | 作为不平衡回放直接对照；二元 LAMDA 迁移需重新实测 |
| A-GEM | 梯度投影公式、成本比较 | 当前双风险投影已有安全保持但适应变差的本地证据，只作安全基线或消融 |
| ECBRS/PAPA | 扰动近似、AnoShift 指标、初始校准边界 | 可用于稳健性诊断，但不把 NIDS 指标直接移植成 LAMDA 主指标 |
| FreeMOCA | 逐层参数插值、AZ 结果及 `F/REM` 边界 | 作为无回放参数保持对照；不同数据和任务合同，不与 LAMDA 主表直接排名 |

## 当前主算法候选的收敛形式

在当前筛选完成后，优先比较：

\[
\min_\theta L_{base}+\lambda_rL_{mal\text{-}FN}+\lambda_pL_{PCT}
\quad\text{s.t.}\quad
\widehat{FPR}_{gate}(\theta)\le \widehat{FPR}_{old}.
\]

其中 (L_{mal\text{-}FN}) 只作用于上一冻结模型漏判的当前真实恶意样本，(L_{PCT}) 保护旧模型正确决策，FPR gate 使用独立且时间一致的良性集合。只有缺口修复和 PCT 分别有信号、联合臂在相同 FPR 下有互补收益时，才把它们写成两机制统一框架；否则保留证据更强的单机制。MIR/GSS 只在需要替换记忆侧实现时追加，不作为先验必选组件。
