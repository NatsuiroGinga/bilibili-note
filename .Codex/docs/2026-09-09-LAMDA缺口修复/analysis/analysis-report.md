# LAMDA 缺口修复与条件风险门控筛查分析

**分析状态：已完成；筛选层证据，不是论文正文。**

## 分析问题

在固定 LAMDA Domain-IL MLP、总回放容量 200、年度顺序和训练预算下，检验：

1. 只对上一冻结模型漏判的当前真实恶意样本施加 margin 缺口修复，是否降低开发期 FNR；
2. 只在候选梯度与旧恶意／良性参考梯度冲突时投影，是否保持 FPR 而不过度抑制修复；
3. 两者联合是否产生互补收益。

## 实验身份与协议

- 运行身份：`ch3-lamda-gap-repair-screening-seed42-v1`
- 数据版本：`IQSeC-Lab/LAMDA` revision `ad9614bdd5556767f97ced2fce797c2f06408ebf`
- 枚举年份：来源年 `2013/2014`，项目开发层 `2016/2017`
- 封印年：`2018--2025` 未枚举、未读取、未用于选择
- 特征：发布 `4561` 维视图；因全时期训练分片参与预处理，运行标记为 `screening_only`
- 模型：MLP `[512,384,256,128]`＋`[100,100,1]`，`ReLU`，`Dropout=0.2`
- 训练：种子 `42`、每年 `10` 轮、批量 `1024`、既有 SGD 配置、阈值 `0.5`
- 四臂：ER、ER＋缺口修复、ER＋条件风险门控、ER＋两者联合
- 资源：CUDA；墙钟 `1984.357` 秒；最大分配显存 `163743232` 字节；最大保留显存 `251658240` 字节

## 制品核验

- 四臂各自回收 `2016/2017` 当前年度预测，合计每臂 `41,668` 条；样本身份无重复，跨臂身份集合一致。
- 主脚本 `development-summary.json` 与独立逐样本复算在 AP、AUROC、F1、FPR、FNR、Brier 上一致至浮点误差范围。
- `conditional_risk_gate` 的 pooled 指标和投影事件总数与既有双风险投影报告一致；本实现的条件触发在开发期没有形成不同于始终投影的行为。
- 运行清单：工具 SHA-256 `73f2af12e5b9c7f71e00846708a1756e34324e8cc8a26337bac549948297a015`；配置 SHA-256 `67d8fedda9509f5ffa27088dcbc474cea50fd9fc171d42ee8148baff6d4c3722`。

## 翻转与修复诊断

在 2016 和 2017 当前年度测试集合上，用“上一模型 next-year 预测→本年度训练后 current-year 预测”配对计算：

| 实验臂 | 恶意正向修复率 | 恶意负向翻转率 | 良性新增误报率 |
| --- | ---: | ---: | ---: |
| ER | 0.847736626 | 0.021145468 | 0.006979449 |
| ER＋缺口修复 | 0.951199675 | 0.026845018 | 0.117734146 |
| ER＋条件风险门控 | 0.825127334 | 0.032462878 | 0.006203955 |
| ER＋两者联合 | 0.915662651 | 0.038815490 | 0.066163770 |

缺口修复确实提高了恶意正向修复率，但代价是大量良性新增误报；条件风险门控减少了良性新增误报，却没有保留足够的恶意修复；联合臂仍未达到 FPR 门槛。

## 筛选裁决

- **ER＋缺口修复：`reject_implementation`。** FNR 降低 `0.028573577`，但 FPR 增加 `0.125489090`，AP、AUROC、F1 和 Brier 同时恶化；不能进入下一阶段。
- **ER＋条件风险门控：`reject_implementation` 作为新差量，保留为安全基线。** FPR 降低、但 FNR 和 AP 恶化；且与已有双风险投影在 pooled 结果和投影事件上相同，没有独立新增信号。
- **ER＋两者联合：`reject_implementation`。** 相对 ER 的 FPR 增加 `0.065176777`，没有形成两个单臂的安全—修复互补。
- **封印年不启动。** 本轮没有候选同时满足 FPR、旧恶意保持和恶意修复门槛。

## 统计边界

- 本实验只有一个随机种子；不能估计种子级 95% 置信区间、显著性检验或跨初始化稳定性。
- 逐样本配对计数只作固定运行的描述性诊断，不能把样本行当作独立重复实验。
- 结果使用含未来协变量的发布特征视图，只能支持 `screening_only` 筛选，不支持无泄漏正式泛化结论。

## Claim Candidates

- Claim:
  - Source evidence: 四臂源年逐样本预测和独立复算。
  - Allowed wording: “在本次单种子 screening_only 运行中，缺口修复降低了开发期 FNR，但显著增加了 FPR；条件风险门控降低了 FPR，但未改善 FNR。”
  - Forbidden stronger wording: “缺口修复或条件风险门控在 LAMDA 上有效”“可保证未来 FPR 不升”。
  - Uncertainty: 单种子、未来协变量视图、项目开发层不是最终测试。
  - Next check: 取得 PCT/TFCO 全文后做直接基线和独立 gate 筛选。
  - Decision: keep

- Claim:
  - Source evidence: 条件风险门控与既有双风险投影的 pooled 指标、投影事件和运行制品。
  - Allowed wording: “本实现未显示区别于始终双风险投影的开发期行为。”
  - Forbidden stronger wording: “条件投影在所有批次都等价”或“该机制数学上无效”。
  - Uncertainty: 仅核对本次配置和单种子。
  - Next check: 若未来重构约束触发条件，必须重新运行，不能沿用本次读数。
  - Decision: keep

## 下一步

1. 停止本轮三种候选实现，不读取封印年。
2. 将 PCT 作为直接基线，并在独立时间一致良性 gate 上筛选“定向恶意漏判修复＋旧正确决策保护”。
3. 只有新候选在来源／项目开发层同时通过 FPR、旧恶意保持和恶意修复门槛，才冻结一次 `2018--2025` 封印评价。
