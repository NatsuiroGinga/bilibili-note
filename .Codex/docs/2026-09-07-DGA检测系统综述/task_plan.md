# DGA 检测专项系统综述计划

## 任务边界

- 目标：建立 DGA 检测的数据、模型、评价、分布外泛化与规避风险全景，优先回答第三章目标、C00、最低基线集和两个机制的原创差量。
- 输出：本目录 `task_plan.md`、`notes.md`、`文献综述.md`、`基线证据表.md`；缺失核心全文按 `raw/papers/`、`wiki/papers/`、Zotero 和方向 `INDEX.md` 补齐。
- 禁止：不修改实验代码、Goal、恢复卡、论文正文或候选台账；只把建议交给台账代理。
- 截止时间：2026-09-07；在线题录记录查询日与版本。

## 证据合同

- 方法、数字、限制和原创性只接受合法全文或官方代码；题录、摘要、引用计数只用于发现。
- 每篇记录：题名/年份/稳定 ID、数据、划分、去重、家族隔离、目标标签权限、模型/机制、指标、FPR/FNR/未见家族结果、种子、代码、全文页码、可复现性，以及与 DRIFT、Engram/DeepEmbed、ROSA、跨家族稳健风险的关系。
- 同分布高分不得冒充时间外推或未见家族泛化；默认阈值 F1 不得替代低 FPR 运营证据。
- 无法取得全文的来源只进入阻塞表，不支撑结论。

## 引文雪球流程

1. 完整抽取 DRIFT 原论文 48 条参考文献，按数据、传统词法/统计 DGA、字符深度模型、Transformer/自监督、漂移与持续学习、开放集/未见家族、低 FPR/校准、对抗规避分类。
2. 筛出直接支撑 DRIFT 数据、十个强基线、方法来源和评价设计的核心文献，逐篇取得全文和页码证据。
3. 对核心文献做前向引文追踪，补 2024–2026 的复现、修正和方法近邻。
4. 使用独立关键词查询 Woodbridge LSTM、FANCI、Endgame/CharCNN、MaskDGA、CharBot、EXPLAIN、时间漂移、未见家族、开放集、低 FPR、校准、对抗规避和重复泄漏，检查 DRIFT 引用表之外的缺口。
5. DRIFT 参考文献只作为雪球起点，不能据其缺失断言领域不存在相关工作。
