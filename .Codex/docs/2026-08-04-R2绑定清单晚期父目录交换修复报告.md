# R2 绑定清单晚期父目录交换修复报告

## 结论

第五轮复审发现的绑定清单晚期父目录交换缺陷已完成最小生产修复。发布函数不再在目录刷新和临时名清理完成前报告成功；发布刷新和清理刷新后都会通过固定可信根目录描述符重新核对完整目录链，只有末次复核通过后才把本轮发布标记为完成。

本报告只证明该重要问题已按复审门槛修复。首个正式 `F-*` 运行仍需新的独立复审确认，且仍受 TCP/UDP v2 正式物理数据与合法检查点门禁约束。

## 根因证据

修复前，`_write_immutable_json()` 在硬链接发布后的链路复核之后执行目录 `fsync`，但没有再次复核目录链；随后在临时名清理和最后一次目录刷新之前就设置 `completed=True`。因此，最终父目录可以在最后一个已检查点之后被交换，而函数仍返回与被移走目录中清单对应的摘要。

独立故障注入稳定复现旧行为：

```text
PUBLISH_LATE_SWAP_ACCEPTED True True True True
```

四个布尔值依次表示函数返回成功、词法目标已是注入的不同内容、被移走原目录保留本轮发布清单、函数返回了 64 位摘要。

## 生产修复

修改文件：

- `thesis/experiments/llm_probe/src/flow_probe/r2_final_physics_fit.py`

修改范围仅限 `_write_immutable_json()` 的成功判定与异常清理顺序：

1. 新清单完成硬链接发布或既有同内容清单完成稳定读取后，先刷新固定最终父目录，再调用 `verify_directory_chain()`。
2. 随后只通过同一固定目录描述符删除本轮临时名，再次刷新目录并调用 `verify_directory_chain()`。
3. 只有第二次刷新后的末次目录链复核通过，才设置 `completed=True` 并允许返回摘要。
4. 任一步失败时，只通过固定最终父目录描述符删除本轮临时名；若本轮已发布最终名，则也只通过该描述符删除最终名。
5. 异常清理完成后刷新同一目录，并再次核对目录链。没有按词法完整路径重开、删除或接受替换目录中的内容。

未修改探针加载器、配置、包装器、数据、检查点或既有运行制品。

## 限定验证

### 晚期交换拒绝

分别在发布目录刷新和临时名清理后的最终目录刷新返回时交换最终父目录。两种情况下均结构化拒绝；替换目录中的注入内容保持不变，被移走的原目录不残留本轮最终清单或临时名：

```text
PUBLISH_LATE_SWAP_AFTER_PUBLISH_FSYNC_REJECTED True True True True
PUBLISH_LATE_SWAP_AFTER_CLEANUP_FSYNC_REJECTED True True True True
PUBLISH_LATE_SWAP_ACCEPTED False True False False
```

### 正常与幂等发布

正常首次发布、同内容幂等调用、异内容拒绝、摘要一致性和临时名清理均通过：

```text
NORMAL_IMMUTABLE_PUBLISH_OK True True True True True
```

### 既有安全门禁

```text
NORMAL_PATH_GATE_OK 3 15
SELF_DERIVED_ROOT_REJECTED True True
READ_PARENT_SWAP_REJECTED True True
PUBLISH_LINK_SWAP_REJECTED_AND_CLEAN True True True
```

- 3 份物理拟合配置和 15 份正式探针配置保持可解析。
- 两个加载器继续拒绝从待审配置路径自派生可信根。
- 两个稳定读取器继续拒绝最终文件打开前的父目录交换。
- 发布前父目录交换继续被拒绝，替换目录与被移走原目录均无本轮清单残留。
