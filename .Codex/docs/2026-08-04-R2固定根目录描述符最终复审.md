本轮限定检查外部固定可信根、根锚定目录描述符读取、不可变绑定清单发布与清理、父目录交换拒绝、普通配置解析和两个正式包装器语法。最终计数为 **严重问题 0 项、重要问题 1 项、次要问题 0 项**。

## 重要问题

### 不可变绑定清单在发布后、返回前仍接受父目录交换

位置：

- `thesis/experiments/llm_probe/src/flow_probe/r2_final_physics_fit.py:1357`
- `thesis/experiments/llm_probe/src/flow_probe/r2_final_physics_fit.py:1367`
- `thesis/experiments/llm_probe/src/flow_probe/r2_final_physics_fit.py:1368`
- `thesis/experiments/llm_probe/src/flow_probe/r2_final_physics_fit.py:1399`
- `thesis/experiments/llm_probe/src/flow_probe/r2_final_physics_fit.py:1400`
- `thesis/experiments/llm_probe/src/flow_probe/r2_final_physics_fit.py:1410`

发布器在创建临时文件后复核目录链，再通过同一最终父目录描述符执行非覆盖硬链接；硬链接完成后也再次复核目录链。该部分已经能够拒绝上一轮的“发布前交换”。问题出现在第二次复核之后：代码随后执行目录 `fsync`，把 `completed` 设为真，进入清理并再次执行目录 `fsync`，但在成功返回前不再复核目录链。

独立故障注入在硬链接及第二次目录链复核完成后、第一次目录 `fsync` 返回时交换最终父目录，并在替换目录写入不同内容。函数仍返回预期内容的 64 位摘要；词法目标指向替换目录中的不同文件，真正发布的清单则留在被移走的原目录：

```text
PUBLISH_LATE_SWAP_ACCEPTED True True True True
```

四个布尔值依次表示：发布函数返回成功；词法目标是注入的不同内容；被移走目录保留已发布清单；函数返回了摘要。

冻结摘要门禁会在后续读取时拒绝不同内容，因此该问题当前未证明能够静默改变正式模型语义，故定为重要而非严重。但是，发布函数已经错误报告成功，且返回摘要与固定词法路径不再绑定，不满足本轮“发布和清理期间父目录交换必须拒绝”的明确门槛。

修复门槛：目录发布成功并完成目录 `fsync` 后必须再次执行 `verify_directory_chain()`；故障清理和最后一次目录 `fsync` 完成后，在允许成功返回前还必须执行最终目录链复核。`completed=true` 只能在这些复核全部通过后设置。若末次复核失败，必须继续使用已固定的目录描述符删除本轮发布的最终名称和临时名称，刷新该目录并返回结构化失败；不得按完整路径重新打开、删除或接受替换目录中的内容。

## 已确认通过

### 外部固定可信根与自派生根拒绝

- `load_config` 的 `trusted_root` 在物理拟合和正式探针两个加载器中均为无默认值的必填关键字参数。
- 两个命令行入口均把 `--trusted-root` 声明为必填参数。
- 两个正式包装器均使用固定服务器项目根 `/root/autodl-tmp/thesis/experiments/llm_probe`，并显式传给 `--trusted-root`；未发现 `R2_PROJECT_ROOT` 可改写入口。
- 两个加载器都要求配置是固定根下 `configs/` 的直接文件。把未修改配置复制到任意临时根，再把真实项目根作为可信根时，两个加载器均在解析前拒绝：

```text
TRUSTED_ROOT_REQUIRED True True
SELF_DERIVED_ROOT_REJECTED True True
```

### 根锚定读取与打开前父目录交换

- 两个读取器都先以 `O_DIRECTORY | O_NOFOLLOW` 固定外部可信根，再以单组件名称、上一级 `dir_fd` 和相同标志逐级打开目录。
- 最终文件只通过固定父目录描述符、相对文件名和 `O_NOFOLLOW` 打开；读取期间保留整条目录描述符链，并在读取前后核对文件与父目录身份。
- 在最终文件打开前交换其父目录时，物理拟合读取器和正式探针读取器均结构化拒绝：

```text
READ_PARENT_SWAP_REJECTED True True
```

### 发布前交换与故障清理

- 临时文件创建、硬链接发布、既有文件读取、临时文件删除和失败后最终文件删除均使用同一根锚定最终父目录描述符。
- 在 `os.link` 调用前交换最终父目录时，发布器拒绝；替换目录和被移走目录均未残留最终清单：

```text

```
