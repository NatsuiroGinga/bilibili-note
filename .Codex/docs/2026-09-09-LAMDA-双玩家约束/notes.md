# 双玩家速率约束证据笔记

## 外部依据

- Cotter 等 JMLR 2019：proxy-Lagrangian 处理不可微速率约束，区分模型玩家的可微代理与约束玩家的原始约束反馈。
- Cotter 等 ICML 2019：训练侧与独立验证侧分离，避免 data-dependent constraint 过拟合。
- Kumar 等 ICML 2021：把“固定 FPR 下最小化 FNR”列为典型速率约束目标；本项目不改变固定阈值合同。
- A-GEM ICLR 2019：条件冲突投影提供局部几何对照，但没有 hard FPR 保证。

## 本地依据

- ER 开发期锚点：FPR `0.0131481546758786`、FNR `0.0594781562523498`。
- 始终双风险投影：FPR `0.012231661`、FNR `0.070306038`；说明保护侧有信号但过度保护会损害适应。
- 缺口修复：FNR `0.030904579`、FPR `0.138637245`；说明恶意修复侧确有信号但需要安全约束。
- PCT 预筛：开发期 FPR `0.025097818`、FNR `0.060606061`，不进入 CUDA；仅作为直接基线。

## 待验证问题

- 双玩家的长期乘子压力是否能在不使用测试标签的条件下，把缺口修复的 FPR 代价压回 ER 水平。
- 训练侧平滑代理与独立 hard FPR gate 是否出现方向不一致。
- 良性训练参考与旧恶意保护参考是否有足够样本，约束玩家是否会长期为零或发散。

## v1 失败与 v2 修订

- v1 `ch3-lamda-dual-player-screening-mps-seed42-v1` 的乘子按批次更新，`lambda_benign` 在 2014 年达到约 `225.14`，双玩家与联合臂随后全预测为恶意（开发期 FPR `1.0`、FNR `0.0`）。联合臂的后续缺口候选数为 `0`，因此未形成有效交互消融。
- 该现象是数值／接口实现失败，不是双玩家抽象的 LAMDA 实验否决。v2 改为每个 epoch 用 hard rate residual 更新乘子，模型侧代理改为无 dropout 的 `softplus(logit)` 风险，保留独立 gate 作为最终验收。

## 本地博弈文献复核（2026-09-09）

- Nash-MTL 将多个任务梯度建模为对称合作议价；它适合做“仅按梯度比例协调”的对照，但没有 FPR 或旧恶意回归约束，不能直接替代本候选的安全玩家。
- AuxiNash 取消任务对称性，用主任务验证损失学习辅助任务偏好；它说明“修复目标优先于安全辅助目标”的非对称权重有文献先例，但依赖双层验证元梯度，当前 LAMDA 尚未冻结相应验证合同，因此不并入第一轮。
- SCORER 用停梯度和快／慢双时间尺度近似 Stackelberg 主从学习，但研究对象是强化学习控制与表征网络，没有 LAMDA 的 hard FPR 速率约束。当前方案不应称为 Stackelberg 实现；只有实际引入领导者策略、跟随者响应和双时间尺度更新时才可使用该术语。
- 本地攻防安全博弈论文需要攻击者动作、观测、响应和收益；LAMDA 只有按年份到达的样本与标签，不满足该信息条件，因此不采用攻击者—防守者叙事。

这些文献支持角色分离和非对称更新的理论边界，不提供 LAMDA 本地效果证据；首轮仍只验证 proxy-Lagrangian 双玩家是否通过源年 FPR gate。
