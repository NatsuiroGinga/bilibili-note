# LAMDA 双玩家速率约束源年筛选计划

**状态：v2 待运行；仅用于 `screening_only`，不打开封印年。**

## 目标

检验把恶意漏判修复模型玩家与良性 FPR／旧恶意回归安全玩家分离，是否比单纯缺口修复更能满足“修复恶意漏判且不提高 FPR”。该方案是 L11 候选，不是已验证主方法。

## 固定合同

- 数据 revision：`ad9614bdd5556767f97ced2fce797c2f06408ebf`
- 来源年：`2013/2014`；项目开发层：`2016/2017`；封印年 `2018--2025` 不读取
- 发布 `4561` 维特征空间，运行身份为 `screening_only`
- 种子 `42`、每年 `10` 轮、批量 `1024`、SGD、阈值 `0.5`、总回放容量 `200`
- 四臂：ER、ER＋缺口修复、ER＋双玩家约束、ER＋缺口修复＋双玩家约束
- 训练代理的良性集合只来自此前已到达并确认的训练分片；任何 `test` 标签只用于训练结束后的独立描述性 gate

## 双玩家定义

- 模型玩家：基础当前／回放损失加当前年度真实恶意漏判的 margin 缺口修复损失。
- 安全玩家：对历史训练良性参考的软 FPR 代理、对上一冻结模型正确判恶意参考的回归代理更新非负乘子。
- 模型玩家每个训练批次使用平滑代理；约束玩家每个 epoch 依据独立参考上的 hard 速率残差作上升更新，不设人为上限，若发散或 hard gate 仍违反则失败。
- 旧风险基准在年度更新开始时由冻结旧模型在同一参考集合上计算，不能边训练边更新。

## 数值依据

- FPR 锚点 `0.0131481546758786`、FNR 锚点 `0.0594781562523498`、旧恶意负向翻转锚点 `0.052107226` 来自已有 ER／双风险投影开发期制品。
- 乘子学习率 `1.0` 是每 epoch 更新一次的任务化起始值，无直接文献最优值；进入正式实验前必须在源年冻结并登记，不得用封印年调节。此前 v1 按批次更新导致乘子爆炸，已单独标记为实现失败，不沿用其读数。
- 平滑风险代理采用 `mean(sigmoid(logit))` 与 `mean(softplus(threshold_logit-logit))`；这是可微替代，不是 hard FPR 数学保证。

## 通过与失败门

- 相对 ER，候选 hard FPR 不增加、旧恶意负向翻转不增加，且 FNR 或恶意正向修复率至少一项改善。
- 联合臂必须不劣于两个单臂，且乘子／约束残差／触发统计显示安全玩家确实产生作用。
- 使用测试标签训练、使用未来年份、重调阈值、乘子长期发散或代理满足而 hard gate 违反，立即否决该实现。

## 执行步骤

1. 完成入口配置和设备探测检查；要求本机筛选设备不可用时直接失败，不静默回退。
2. 只运行来源／开发层四臂，保存年度 checkpoint、乘子轨迹、代理残差、逐样本预测和资源收据。
3. 主代理独立复算 pooled 指标、历史良性 gate、恶意正向修复和旧恶意负向翻转。
4. 通过开发期门槛后才可设计一次封印年评价；否则保留 ER，停止该实现。

## v1 实现失败记录（2026-09-09）

- 身份：`ch3-lamda-dual-player-screening-mps-seed42-v1`，实际设备 `mps`，墙钟 `930.0824` 秒。
- 失败证据：2014 年安全玩家的 `lambda_benign` 最大约 `225.14`，随后双玩家和联合臂开发期 pooled FPR 均为 `1.0`、FNR 为 `0.0`；联合臂在 2014/2016/2017 的 `repair_candidates` 为 `0`，没有真正测试“修复＋安全”交互。
- 根因分类：v1 按每个训练批次累加乘子，且用平均概率／softplus 参考差作为代理残差；这不符合 proxy-Lagrangian 的“模型侧平滑代理、约束侧 hard 速率按独立参考更新”分工，故标记为 `reject_implementation`，不作为双玩家候选否决证据。
- v2 修订：每个 epoch 只依据参考集合上的 hard 良性误报率和旧恶意回归率更新乘子，训练损失仍使用无 dropout 的平滑代理；v1 制品只用于说明实现为何失败。
