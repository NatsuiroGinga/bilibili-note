# L1 表示层诊断判读（2026-09-09，路 1 立项依据）

**结论：表示层换血的直接收益被实测否决——源期可学信号与发布视图 MLP 在恶意侧几乎正交（Spearman −0.09）但分离能力差一个数量级，"换表示直接吃到深埋 FN"不成立；路 1 按"表示增强＋决策层联合"的原始形态不立项。**

## 实测（全部本机零/低成本，制品为本文件内数字）

以 2018 年（深埋 FN 438 个，占恶意 7870 的 5.6%）为检验对象，源期（2013/2014 train，150,090 样本）只训不调：

| 探针 | 结果 |
| --- | --- |
| 源期朴素概率比表示 | AUC 0.5984、AP 0.4676、操作点 FPR 0.2475/FNR 0.6722——分离失败 |
| 源期 LogisticRegression（L2，C=0.1） | AUC 0.5601、AP 0.5182；深埋 FN 挽救率 10.3%（45/438）；良性假阳率 4.32% |
| 源期 HistGradientBoosting（150 树） | AUC 0.5627、AP 0.5448；深埋挽救率 8.7%（38/438）；良性假阳率 2.96% |
| 深埋 FN 的 LR 分数分位 [10/25/50/75/90] | −4.72/−4.04/−3.00/−1.33/0.13——**中位 −3.0，与良性中位 −3.79 几乎同区** |
| 恶意侧 ER 分数 × LR 分数 Spearman | **−0.094**（两表示对恶意样本的排序几乎正交） |
| 组合上界（ER ∪ 源期强信号深挖，阈 0.95） | FP 176 vs ER 165、FN 481 vs 481——无净收益 |

## 三条判读

1. **深埋 FN 在源期可学表示里同样不可分**：其中位数位于良性分布的中位区（−3.0 vs −3.79）。它们不是"旧表示看不见、新表示看得见"的样本，而是**特征层面本身接近良性的恶意**（或弱标签噪声）。换表示、换源期、换模型族（线性→GBM）都救不出来。
2. **两表示几乎正交但都不强**：Spearman −0.09 说明源期线性信号与发布 MLP 的错误方向无关——正交性本可提供互补增益，但源期信号太弱（AUC 0.56），组合后无净收益（FP +11 换 FN 0）。
3. **与既有证据闭环**：这解释了 oracle 修复上界（FNR 0.028–0.031）为什么"存在但够不着"——空间在**标签噪声或特征盲区**里，不在任何单一表示的可学信号里。P5 的"漏判卡在良性上尾下方"由此获得终极解释：上尾附近的 FN 与良性共享特征结构。

## 对第三章的影响

- 路线 1（表示层增强）以**当前最小实现形态否决**；若未来重开，必须引入特征层之外的信息源（动态行为、时序上下文），这超出当前数据合同，属路线级决策。
- **第三章机制半章的最优剩余路径收窄为：以九连败+杠杆比+探针证据链构成"漂移下安全—修复取舍的结构性刻画"**，机制主张改为部署侧/评测侧（校准、阈值面、告警预算结构）——这类主张不需要"打败 ER 的 FPR/FNR"，而是"在同 FPR 下给出更好的告警预算曲线/更稳的逐年表现"，与既有 ER 读数兼容。
- 与 L28 审查的判断一致（§7.2 替代表述第 2 行：低 FPR 区域局部排序不足）——现在有实测支撑。
