# 开题方案与初步实验验证记录

## 已知背景

- 当前方向为 CI-PRD 守恒残差检测器与 PIC-GRPO 课程式强化学习的两级架构。
- 现有结果来自初步思考和探索性实验，不能直接视为论文级证据。
- 验证优先检查可复现性、对照设计和结论边界。

## 待记录证据

### 理论证据

- I1 的连续性方程允许源项和汇项。端系统会产生、接收或丢弃业务流量，离散残差必须包含本地产生量、交付应用量、丢包量和队列变化；现有式 (4.2) 缺少本地注入与交付项。
- ns-3 实验以服务端 `|bytesIn-bytesOut|` 作为 I1 残差。服务端本来就是流量汇，该值随接收流量增长，当前结果更接近流量体积检测，而不是质量守恒破坏检测。
- I2 是请求/响应不对称度，不是普适的流双向守恒。正常下载、上传、DNS 和遥测流均可能高度不对称，阈值必须按协议、角色和业务基线确定。
- I3 是 TCP 状态机异常率。正常连接也可能因丢包、拒绝、超时或抓包缺失而没有观测到 SYN-ACK，不能预设残差约等于零。
- Slowloris 通常完成 TCP 握手并发送不完整的 HTTP 请求，将其归为“慢速半连接并打破 I3”缺乏依据。
- I4 是统计平稳性假设，不是守恒律；需要滚动基线、概念漂移处理和独立测试。
- I2-I4 当前直接由观测统计量计算。现有方法章没有说明它们如何由模型输出得到，也没有给出可微计算图，因此不能笼统声称均通过自动微分进入 PINN。

### 脚本审查

- v3 在完整攻击日上用固定极端阈值计算召回和同日正常流误报，没有独立训练、验证或测试划分。该结果只能证明特征关联，不能证明检测器泛化。
- v3 的阈值来源未锁定；此前实验已查看相同数据，存在探索后选阈值风险。
- v4 脚本允许任意未来时刻的 SYN-ACK 匹配初始 SYN，没有超时窗口；恢复的截断抓包可能漏包。无正常日基线、攻击时段标签和召回/误报。
- v5 的 OOD 比较同时改变攻击类型和采集日期，攻击迁移与日期域偏移混杂。硬阈值已在这些数据上探索，不能视为盲测基线。
- v5 同分布检查先用完整训练数据拟合标准化器，再切分测试部分，存在预处理泄漏；模型收敛告警被全局隐藏。
- v6 声明约束为 `max(0, v-p)`，但对逻辑值梯度应包含 `p(1-p)`；实现直接把 `-lambda/n` 加到 `grad_z`，与声明损失不一致。
- v6 只有单次确定性运行，无验证集、重复运行、置信区间或显著性检验；“提升 33%”不能作为已验证结论。
- v7 用已知注入位置定义近区和远区，并以固定倍数判断检测成功；没有无攻击对照、位置盲测、噪声、重复种子和超参数消融。
- v7 的物理损失会压低被同时用作异常分数的残差，检测效果依赖数据拟合与残差约束的冲突，需验证不同权重下是否稳定。
- v8 把星形离散拓扑强行映射为一维坐标，脚本已记录相关性约为零，不能支持真实拓扑上的 PINN 检测。
- v8 将时间归一化后仍沿用原速度系数，连续性方程未按变量变换缩放。
- v8 README 所称“真实数据”实际为 ns-3 仿真数据，应改称可控仿真测试床数据。

### 实验证据

- v2 已复现：572 个一分钟窗口，其中攻击窗口 62、正常窗口 510；极端 I2 占比 38.9% 对 36.4%，单向 SYN 占比均为 2.9%。在同一数据上选出的最佳阈值为 0，召回 100%、误报 98.2%、F1 19.8%，说明窗口级 I3-弱不可分。
- v3 已复现：HOIC 召回 76.1%、LOIC-UDP 召回 100%，同日正常流误报 0.6%；但相同阈值在 2 月 14 日和 15 日正常流上的误报分别为 33.7% 和 35.5%，不具跨日稳定性。
- v4 README 数值已复现。进一步按官方修订攻击时段分组：`172.31.68.6` 攻击/非攻击时段加权 I3 为 17.7%/14.5%，`172.31.68.8` 为 40.7%/21.6%；非攻击时段仍分别有 51 和 101 个 `I3>50%` 窗口。
- v4 的三个恢复 PCAP 主机为 `172.31.64.46`、`172.31.68.6`、`172.31.68.8`，而官方修订文档给出的 GoldenEye/Slowloris 受害主机均为 `172.31.69.25`。现有 PCAP 不能用于验证目标主机上的攻击检测。
- v5 已复现：硬阈值 F1 0.723，学习模型 F1 0.148-0.268。OOD 抽样的 15000 个攻击流由 7687 个 FTP 与 7313 个 SSH 流构成。
- 独立复核论文指出 2 月 14 日 FTP Patator 因目标 21 端口关闭而未真正执行凭证暴力破解，应标为尝试失败；因此 v5 的高分很大程度上识别了失败连接，不是对新攻击的泛化。
- v6 已复现：纯数据逻辑回归 F1 0.257，声明的物理约束模型 F1 0.343，硬阈值 F1 0.723。约束模型误报率仍为约 69.9%，且实现梯度不对应声明损失，不能接受“提升 33%”结论。
- v7 在非受限 MPS 环境复现 README：近区/远区残差为 0.2103/0.0589，倍数 3.6。受限 CPU 环境三次均为 0.1665/0.0692，倍数 2.4，未过三倍判据。结果对计算后端敏感。
- v7 的 MPS 结果证明当前网络能在已知合成注入附近产生更大残差，但检测区域、阈值和数据生成机制均使用了真实注入信息，仍是机制演示而非盲测检测证据。
- v8 在 CPU 与 MPS 均复现失败：近区/远区约 0.9 倍，PINN 残差与脚本定义的 I1 差值相关系数分别为 -0.021 和 -0.023。
- ns-3 数据中核心转发节点 `x=0.5` 在正常 `t=3` 与 DDoS `t=7` 的 I1 差值均为 0；受害服务端 `x=0.7` 的差值随接收流量约增至三倍。这说明攻击流量仍满足转发守恒，服务端差值增长来自其流量汇角色。
- ns-3 数据实际为 7 节点乘 19 个时间步，共 133 行，不是 README 所写的 20 个窗口；`rho=bytesIn/0.5` 的单位是字节每秒，README 的“字节/0.5秒”标签不准确。
- PIC-GRPO 未发现实现脚本、模型检查点、训练日志或结果表，仅有章节提纲。

### 外部核验

- [IDS2018 官方页面](https://www.unb.ca/cic/datasets/ids-2018.html)说明 PCAP 和事件日志按机器记录，CSV 由 CICFlowMeter-V3 提取并按攻击计划、地址、端口和协议标注。
- [Liu 等 2022 年独立复核](https://intrusion-detection.distrinet-research.be/CNS2022/index.html)报告 CSE-CIC-IDS2018 在攻击编排、特征生成、文档和标签方面存在大量错误，并发布修订数据。
- [修订数据说明](https://intrusion-detection.distrinet-research.be/CNS2022/CSECICIDS2018.html)确认 2 月 14 日 FTP Patator 因端口关闭而未实际暴力破解；Slowloris 是完成 TCP 连接后持续发送不完整 HTTP 请求，不是未完成 TCP 握手。
- [RFC 9293](https://datatracker.ietf.org/doc/html/rfc9293)显示 TCP 建连与复位包含多种合法状态路径，因此“每个 SYN 都必须观测到 SYN-ACK”只能作为带超时和抓包完整性前提的异常统计，而不是零残差硬不变量。
- [Raissi 等 PINN 原始论文](https://www.aer.com/siteassets/21data/raissietal2019.pdf)的核心是把由非线性偏微分方程描述的物理定律嵌入神经网络训练；I2-I4 若不依赖模型输出和可微约束，更准确的定位是协议/统计先验，而不是 PINN 物理残差。

### 结论分级初判

- I2 与 IDS2018 特定单向攻击的关联：C级。
- 严格 I3 在恢复 PCAP 上可计算：C级；异常可分性未验证。
- v6 物理约束提升 OOD：当前无效，需修正实现后重做。
- v7 连续场合成机制演示：C级。
- v8 离散拓扑 CI-PRD：反证，当前实现失败。
- PIC-GRPO：D级，仅有设计提纲，无实现与实验。

### 风险与反证

- 若继续把端点流量体积上升写成“打破质量守恒”，开题答辩可能被直接质疑物理定义错误。
- 若以 CI-PRD 阈值作为 PIC-GRPO 的语义正确性奖励，会把第一级误报和偏差传播到第二级；残差只能验证与物理信号一致，不能验证攻击类型、证据链或推理正确。
- v3 使用的三个日文件均恰好包含 1048575 条数据记录，等于常见电子表格行数上限减去表头。需核实官方 CSV 是否存在导出截断或固定分片，否则按日分布未必完整。
