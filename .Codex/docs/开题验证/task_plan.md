# 开题方案与初步实验验证计划

## 目标

独立核验 CI-PRD、PIC-GRPO 与两级架构的理论成立性、实验可复现性和结论强度，明确哪些结论已经获得证据支持，哪些只能作为研究假设，哪些需要补充实验。

## 验证范围

- 理论：守恒不变量的定义、网络场景适用条件、PINN 定位、两级耦合逻辑。
- 实验：数据来源、预处理、标签使用、划分方式、基线、指标、重复运行、统计推断和脚本复现。
- 写作：交接文档、论文章节和实验结果之间是否一致，是否存在超出证据的表述。
- 不包含：修改 `raw/`、替用户确认最终研究结论、在证据不足时撰写确定性论文结论。

## 关键问题

1. I1-I4 是否属于可辩护的网络守恒或稳定性约束，各自需要哪些前提？
2. 当前实现是否真正属于物理信息神经网络，而非基于手工残差的异常评分器？
3. 现有实验能否支持“检测有效”“小样本优势”“跨集泛化”“毫秒级”和“过滤 90% 良性流量”等表述？
4. 实验是否存在标签泄漏、训练测试混用、样本伪重复、阈值后验选择或不公平基线？
5. PIC-GRPO 目前是已验证方法、可实现设计，还是尚待实验的研究假设？

## 证据等级

- **A级**：脚本可复现，数据与划分可追溯，有合理基线、重复运行和统计报告。
- **B级**：脚本与数据可复现，结果方向稳定，但基线、重复运行或统计证据不完整。
- **C级**：单次探索性实验或局部样本观察，只能支持可行性假设。
- **D级**：概念设想、未运行设计或无法追溯的数值，不得写成实验结论。

## 已作决定

- 将现有结论视为待验证假设，不预设 CI-PRD 或 PIC-GRPO 成立。
- 优先复现已有实验，不先增加新模型或改写论文。
- 最终报告保存为 `.Codex/docs/开题验证/独立验证报告.md`。
