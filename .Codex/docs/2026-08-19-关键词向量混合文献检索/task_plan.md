## 已作决策

- 首版只索引 507 篇现有 Markdown 笔记，不扫描 PDF。
- 使用 SQLite 保存元数据、分块、字符 n-gram 词法统计和向量；用 NumPy 做精确余弦检索，不引入外部向量服务。
- 词法通道采用 Unicode 字符 n-gram BM25，规避中文空格分词假设。
- 混合通道采用倒数排名融合，不依据冻结查询结果调权。
- `scope=local` 是默认稳定路径；`online` 返回外部题录或摘要候选；`all` 分区返回本地证据与外部候选，不混合不可比较的分数。
- 在线适配器各发出至多一次请求；失败写明来源、状态和降级原因，不阻塞 `all` 中的本地结果。
- OpenAlex 优先使用 `search.semantic`，但当前官方合同要求 `OPENALEX_API_KEY`；无密钥时回退普通 `search` 并明确 `semantic=false`。
- Codex 入口采用仓库根 `.agents/skills/literature-hybrid-search/SKILL.md`，该位置由官方 Codex 技能文档明确支持；同时在根 `AGENTS.md` 写入关键触发和稳定命令，避免仅依赖隐式技能匹配。
- 仓库规则禁止人工单元测试和 `black`；验收改用真实输入的语法、导入、命令入口、构建与查询检查。
