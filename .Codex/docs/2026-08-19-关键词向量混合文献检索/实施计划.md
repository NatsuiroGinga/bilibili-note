# 关键词与向量混合文献检索实施计划

> **执行要求：** 使用 `daily-coding` 的先读后改、最小变更、类型安全、安全检查和真实运行验证清单执行。父任务已明确分派单一实现代理，本计划不再分派其他代理。

**目标：** 为 `wiki/papers/**/*.md` 建立支持中文关键词、跨语言语义检索和倒数排名融合的轻量本地命令行系统，并以统一范围参数提供可降级的在线候选发现。

**架构：** 构建阶段从 Markdown 提取元数据并按标题边界与字符预算分块，将 SQLite FTS5 Unicode 三字符 BM25 索引和多语种向量写入单个 SQLite 文件。查询阶段分别计算 BM25 和余弦排名，再用倒数排名融合生成笔记级结果。在线阶段并行但独立调用 OpenAlex、Semantic Scholar 和 Crossref，返回题录/摘要候选与来源状态，不和本地全文笔记分数混排。

**技术栈：** Python 3 标准库、SQLite、NumPy、经官方模型卡核验的 Hugging Face 文本嵌入运行时。

**规格：** `.Codex/docs/2026-08-19-关键词向量混合文献检索/task_plan.md`

## 全局约束

- 只读取 `wiki/papers/**/*.md`，首版禁止扫描 PDF。
- 生产文件只写 `scripts/literature_search/`，过程证据只写当前独占任务目录。
- 索引与模型缓存均不可提交 Git，须提供状态、清理和重建说明。
- 所有数值先登记证据或标为任务化设定，不接触论文最终目标标签调参。
- 不运行 `black`，不创建人工单元测试或集成测试。
- 第三方接口在写代码前核验实际版本和官方文档或本地源码。
