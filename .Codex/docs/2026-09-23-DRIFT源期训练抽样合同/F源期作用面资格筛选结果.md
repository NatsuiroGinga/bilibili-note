# F 源期作用面资格筛选结果

## 结论

当前固定哈希源期诊断成员具备 F 的两个可观察作用面，因而**有资格**进入下一步共同预算 F／基线训练筛选：

- 四候选组中混合组为16,193／30,000（53.98%），二值组中心选择的正负层不是全零退化；
- 真良性在 `p_mal≥0.5` 的门限误报为901／30,000（3.00%），良性三倍补偿会被激活。

这不是 F 优于任何基线的证据；只排除了“当前源期选择器或良性补偿完全没有作用面”的前置否决。
