# F 源期作用面资格筛选实施计划

## 目的与边界

本任务不选择目标年度结果，也不训练或冻结正式论文成员。它只在当前固定哈希源期诊断规格上检验：F 的二值组中心选择和良性误报补偿是否有可观察的作用面。若无作用面，F 不应靠更换目标年度数据或事后改成员来维持。

输入限定为 T17–T19 源角色：源训练12个角色各5,000个哈希最小 exact eSLD，源验证6个角色各10,000个；总计源训练60,000、源验证60,000。成员由现有 `candidate-spec-diagnostic-v1.json` 定义，读取仅限原Parquet `domain,label`，不写成员表或攻击数据。

## 固定可观察量

1. 对源训练DGA成员，以当前固定官方检查点的评估模式前向、共享基础的四候选核，记录每组 `M_i=sum_j 1[p_mal<0.5]` 的 `0/1/2/3/4` 聚合直方图；`1≤M_i≤3` 是选择器非零排序层的必要条件。
2. 对源训练良性成员，记录 `p_mal≥0.5` 的聚合数与比例；这是良性三倍补偿在当前门限的激活条件，不等于低误报工作点效果。
3. 记录候选编辑的预算退化／输出重合聚合数；编辑不合法或无法复算即失败。

## 支持与否决

- 三项均存在可观察量，结论为“当前源期具备F作用面”，只允许进入下一步共同预算F／基线源期筛选。
- 混合组为零或良性误报为零，结论为“当前源期该机制未激活”；不得因该结果转看目标年度或更改成员取胜。
- 本筛选不产生F优越性、正式指标或最终成员结论；F是否有效仍由共同预算训练与冻结评价裁决。

## 实现、资源与验收

- 只新建 `thesis/experiments/llm_probe/tools/ch3_drift_f_source_eligibility.py`、对应报告与技能收据；工程代码由 Luna 完成。
- 工具使用当前已核验模型／编码、关闭嵌套张量快路径，按批读取并限频心跳；输出只能是计数、根、时长与资源，不得写域名、成员哈希清单、分数或预测。
- 真实运行用独立 `runs/diagnostics/ch3-drift-f-source-eligibility-20260923/`；本机MPS，预计读取约30,000良性及30,000DGA源训练实体、对DGA产生120,000候选前向。运行前确认无其他MPS任务与磁盘余量；运行后验收所有输入角色完成、候选组总数守恒、无非法编辑、输出脱敏。
