## 错误记录

- 首轮自审发现四处 `\tau_{17}` 被字符串转义为制表符；已用精确补丁恢复 LaTeX，并追加控制字符复检。
- 一次 `rg` 模式在双引号内包含反引号，触发 shell 命令替换并产生两条无害错误；未修改文件，后续检索不在双引号模式中使用反引号。
- 一次 `apply_patch` 将同一文件拆成三个 Update 块，被工具拒绝；未修改文件，已合并为单一 Update 块成功执行。
