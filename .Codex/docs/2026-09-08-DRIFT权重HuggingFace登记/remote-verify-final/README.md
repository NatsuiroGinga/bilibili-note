# DRIFT 路线权重登记

本目录是 DRIFT 路线的本机模型权重登记入口，对应私有 Hugging Face 模型仓库 `Heehobino/drift-route-checkpoints`。

## 收录范围

- 仅收录已完成、身份闭合的训练权重，并以纯 `state_dict` 形式保存。
- 每个权重目录保存最小溯源清单：运行身份、数据 revision、配置/脚本/源检查点 SHA-256、导出文件 SHA-256 和字节数。
- 当前收录的 G0 字符与子词权重均为 `screening_only`，只能用于该诊断谱系的可复现核验，**不能冒充正式模型、不能支撑论文性能结论、不能作为未来期 T20--T25 评测权重**。

## 明确排除

- 不上传原始数据、样本、预测、训练日志、服务器信息、凭据、T20--T25 内容、`.partial` 文件、失败制品或运行中制品。
- G1 检查点含梯度和 family 状态，不是模型权重，只在总登记清单说明排除原因。
- G2 正在运行，除非同一轮直接观察到终态及哈希闭合，否则仅记录为 `pending`；本次不读取或上传其可变检查点。

## 使用限制

下载者须自行核验每个目录的 `provenance.json` 中 SHA-256。任何训练、微调、评价或论文表述均须遵守 DRIFT 路线的数据合同和最终测试隔离；本登记不授予对未公开数据、未来年份数据或训练日志的访问权限。
