# ER 开发期阈值诊断

## 问题

检查标准 ER 在 2016/2017 开发期是否存在仅靠固定阈值移动即可恢复的 FNR/F1 余量。该诊断不重训、不读取封印年，阈值只用于开发期描述，不能改变已冻结的 `0.5` 正式阈值。

## 结果

- ER pooled 开发期基线（阈值 `0.5`）：F1 `0.955538579`、FPR `0.013148155`、FNR `0.059478156`。
- 在 FPR 不超过基线的所有可观测分数阈值中，最优点为阈值 `0.499954879`：F1 `0.955618364`、FPR `0.013148155`、FNR `0.059327769`。
- 该改善仅为 F1 `+0.000079785`、FNR `-0.000150387`，来自紧邻决策边界的单点排序，不构成有意义的机制信号。
- 无约束 F1 最优阈值约为 `0.343698143`，F1 `0.957992733`、FPR `0.016496880`、FNR `0.048274307`；它以增加 FPR 换取召回，不满足安全预算。

## 裁决

固定阈值移动不能解释或修复阶段 C 的主要病灶。阈值调节不作为下一机制，不进入封印年；后续机制必须改变记忆或更新过程，并在同一 FPR 约束下验证恶意正向修复。
