# 阶段 C 统计附录

## 统计单位

- 当前年度比较按 2016、2017 测试分片逐样本汇总，共 41,668 条预测。
- 回溯负向翻转按训练终点统计；同一历史样本可在多个终点重复出现，不能把这些事件视为独立样本。
- 四臂共享样本身份、阈值 `0.5`、模型结构、训练轮数、批量和种子。

## 推断边界

- 只有一个随机种子，结果仅为描述性筛查；不报告置信区间、显著性或跨初始化稳定性。
- 2016/2017 的恶意比例和样本量不同，不能仅凭 pooled 差值推断每个年度均成立。
- 2018--2025 未读取，不能把开发期结果外推为封印期表现。

## 资源

- GPU 墙钟：`1886.728` 秒。
- 峰值显存：`3,238,131,200` 字节分配，`8,921,284,608` 字节保留。
- 资源数字来自运行收据，只描述本次筛查，不用于声称模型效率优势。
