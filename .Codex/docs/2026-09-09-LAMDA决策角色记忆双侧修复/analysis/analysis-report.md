# 阶段 C 来源／开发期 M/O 筛查分析

## 比较问题

在固定总容量 200、相同 MLP、SGD、年度顺序和单一种子下，检验决策角色条件记忆（M）与双侧风险修复更新（O）是否相对标准经验回放（ER）改善 2016/2017 开发期的保持—适应取舍。封印年 `2018--2025` 未枚举、未读取、未用于选择。

- 运行身份：`ch3-lamda-mo-source-dev-screening-seed42-v1`。
- 远端状态：`completed`；四臂各有 4 个年度指标文件和 10 个逐样本预测文件。
- 本地复算：2016/2017 两个 `current_year` 面共 41,668 条预测，AP、AUROC、F1、FPR、FNR、Brier 与服务器 `development-summary.json` 一致。
- 种子数：1；没有种子级置信区间、显著性检验或跨初始化结论。
- 发布 4561 维视图使用未来年度训练协变量，四臂均保持 `screening_only`。
- 复算制品：[JSON 收据](../stage-c-screening-reanalysis.json)、[运行清单](../../../../thesis/experiments/llm_probe/runs/diagnostics/ch3-lamda-mo-source-dev-screening-seed42-v1/run-manifest.json)、[资源收据](../../../../thesis/experiments/llm_probe/runs/diagnostics/ch3-lamda-mo-source-dev-screening-seed42-v1/resource-receipt.json)。

## 机制裁决

- **ER**：保留为开发期基准锚点，不承担创新主张。
- **ER+M**：FPR 略降，但 AP、F1、FNR 和旧恶意负向翻转均恶化，判定 `reject_screening`。当前实现的角色轮转实际形成每角色约 50 条的隐式等配额，不能继续包装为已验证的角色记忆机制。
- **ER+O**：FPR 从 `0.013148` 升至 `0.089252`，AP 和 F1 明显下降，判定 `reject_screening`。等单位修复损失过度推动分数上移，未形成双侧风险控制。
- **ER+M+O**：联合臂 FPR `0.097254`、F1 `0.875096`，不优于任何单因子，判定 `reject_screening`；没有互补证据。

本轮只否决**这一具体实现**（等配额角色轮转＋等单位风险损失），不否决“从源年病灶重新提出其他任务化机制”的可能性。不得进入封印年，不得据本轮结果修改目标期样本、阈值或指标。

## 下一步

1. 停止当前 `M/O` 具体实现，不启动其封印期评价。
2. 将本轮结果写入候选存废台账，保留代码、配置、哈希和完整制品。
3. 新机制必须先从已入库全文和新的源年可观测病灶提出，并通过最小反例设计；优先检查是否能在不增加隐式角色配额、不提高 FPR 的前提下修复恶意正向错误。
4. 若没有新的、可证伪且有文献依据的机制，第三章暂以阶段 A 的 Replay 安全保持结果为基线，不强行凑两个机制。

同一历史测试集合的恶意正向修复、负向翻转及良性新增误报分解见 [开发期历史翻转分解](../../LAMDA双风险梯度投影/transition-flip-diagnostic.md)。

## 阈值排除诊断

无重训阈值搜索见[ER 开发期阈值诊断](threshold-diagnostic.md)。在 FPR 约束下最优阈值仅产生 F1 `+0.000079785` 的边界级变化；无约束阈值虽降低 FNR，却增加 FPR。因此“只调阈值”不作为下一机制。
