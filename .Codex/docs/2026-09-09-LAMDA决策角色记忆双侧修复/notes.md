# 阶段 C 证据笔记

## 2026-09-09

- 网页报告《LAMDA 阶段 A：针对 Replay 安全保持—适应取舍的改造候选》已完整读取。它的实际模式是普通 ChatGPT 对话内只读全文研究，模型自报 GPT-6 Astra Pro，effort 无独立可核验值；结果仍是外部候选。
- 网页报告最重要的纠偏是：低旧恶意负向翻转不等于方法更好，必须同时记录恶意正向修复和新增良性误报。
- 文献近邻边界：Regression-aware/PCT、MADAR、GSS、MIR、PBR、CBRS、A-GEM、ECBRS/PAPA 已被报告列为直接或必要对照；本轮核对确认八组原件和结构化笔记均已入库，具体方法映射仍需主代理按版本复核，不能把它们在其他数据集上的结果直接移植为 LAMDA 结论。
- 本地阶段 A 已确认 Replay 的安全保持—适应取舍；阶段 B 已确认当前一侧安全记忆实现的时序语义与配置声明不一致。两项均支持“先修正定义，再做最小因果消融”，不支持直接强化安全损失。
- 研究假设 H-M：在总容量不变时，按保护／修复／误报控制角色分配记忆，比同配额随机记忆提供独立的历史覆盖信号。状态：待来源期实验。
- 研究假设 H-O：只保护上一冻结模型的旧正确恶意决策，同时对当前漏判恶意提供修复、对高分良性提供误报代理约束，比原始 Replay 提供独立的保持—修复取舍改善。状态：待来源期实验。
- 研究假设 H-MO：风险代理缺口反馈到下一年度角色记忆分配，联合收益不能由最好单因子或 PCT/A-GEM 解释。状态：待来源期实验与直接近邻对照。

## 合同纠偏裁决

- **裁决**：阶段 C 不采用“2013--2019 来源、2020--2025 封印”的临时划分，改用已冻结数据清单的 `source_years=2013/2014`、`development_years=2016/2017`、`sealed_final_years=2018--2025`。
- **理由**：数据 manifest 明确登记了三类角色，并规定封印年份只允许文件级哈希和模式元数据核验；按临时年份重新定义会破坏可复核合同。
- **代价**：开发期只有 2016/2017 两年，机制筛选统计余量较小；若该开发期不足，应如实降低结论强度或重新获得用户批准，不能把封印年标签回灌选择。

## 容量解释

- 全程总容量 `200` 只用于保持 ER 与候选机制的共同记忆预算，隔离“机制效应”和“记忆数量效应”。它不是 LAMDA 文献的最优容量；原文附录 J.1 的“每个 experience 200”口径不同。
- 容量是否适合部署需另做来源／开发期容量敏感性与资源帕累托，不能在当前四臂中同时改变容量。
