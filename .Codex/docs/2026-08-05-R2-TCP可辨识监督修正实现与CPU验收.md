# R2 TCP 可辨识监督修正实现与 CPU 验收

## 结论

已完成种子 42 重跑前的 TCP 监督合同修正，未启动 GPU，也未读取最终测试。旧实现把同一网络级公共窗口固定展开为八条发送者序列，现改为每个公共窗口只生成一个网络级目标。可加状态按发送者求和，RTT 按有效样本数加权平均；`ssthresh=UINT32_MAX` 只记录离散的未设置发送者数，不进入连续状态损失，也不启用依赖无效端点的方程。

该修正消除了人为制造的源样本一对多，但不声称仅凭四项公共历史可以唯一反演所有隐状态。不同独立场景出现完全相同数值历史时仍有条件不确定性，网络级学生学习的是可观测条件下的有效状态摘要。

## 设计裁决

比较了两种方案：

1. 保留发送者级目标。该方案能沿用单连接 NewReno 真值和方程，但所有正式检测视图都只有网络级包数、字节数及对应速率，没有无泄漏的发送者级被动历史。加入 `sender_index` 只会形成仿真身份捷径，因此否决。
2. 网络级聚合目标。该方案与公共窗口一一对应，推理不需要仿真身份。可加状态采用求和而非均值，因为公共包数与公共字节数本身是网络总量；RTT 是强度量，按 RTT 样本数加权平均。该方案被采用。

连续状态包括拥塞窗口、有限慢启动阈值、在途字节、确认字节和事件计数。任一发送者的可加连续量缺失时，该网络总量的监督掩码关闭。慢启动阈值另保存 `start/end_unset_sender_count`；存在未设置发送者时，相应连续阈值置零但掩码为假。增长方程和收缩方程分别检查各自所需字段，避免起点哨兵无关地关闭合法收缩方程，也避免终点哨兵进入收缩关系。

## CPU 验收

输入仅为三个开发划分，`final_test_visible=false`。原始 TCP 伴随表有 `184,320` 条发送者记录，聚合后为 `23,040` 个公共 TCP 窗口；公共源窗口唯一键同为 `23,040`，序列中的 `:sender-` 后缀为 `0`。

| 指标 | 结果 |
| --- | ---: |
| `ssthresh_start` 未设置窗口 | 11,600 |
| `ssthresh_end` 未设置窗口 | 11,688 |
| 未设置窗口仍进入连续监督 | 0 |
| 连续监督中残留 `UINT32_MAX` | 0 |
| 固定方程有效项 | 11,144 |
| 真值残差 MSE | 2.993740890443073e-05 |
| 真值残差 RMSE | 0.005471508832527891 |
| 真值残差绝对值第 95 百分位 | 0.006391400098800661 |

方程有效项包括拥塞避免 `2,435`、丢失 `8,485`、超时 `224`；当前有效窗口中没有慢启动项。该残差表示网络级均场闭合误差，不再冒充发送者级事件方程的严格零残差。

按完整四窗口数值历史统计，训练、校准、验证分别仍有 `112`、`56`、`40` 个跨独立场景的目标碰撞组。这些组不再来自同一源窗口的发送者复制，而是有限公共观测下的隐状态不确定性。该边界必须在论文中作为部分可观测条件说明，不能用仿真身份或最终测试统计消除。

## 性能保护与下一合同

物理旁路融合改为 `0.1 * tanh(parameter)`，参数从零初始化，因此训练起点与关闭旁路完全一致，优化器仍可学习有界的正负残差增量。旧种子 42 `F-P` 开发宏平均 F1 `0.9406325189504068` 是性能参考，不是通过修改数据或最终测试追求的指定值。

修正版若低于该参考，不冻结当前方法，也不恢复 `sender_index`。下一最小合同是发送者级特权物理教师到网络级学生蒸馏：教师只在 ns-3 训练期读取合法发送者观测并使用原始方程，学生和正式推理仍只读取公共网络级历史。该备选尚未实现或验证。

## GPU 交接

旧物理拟合使用发送者展开后训练序列为 `34,560`，耗时 `114.636` 秒，采样显存 `774 MiB`。新合同的训练序列降至约 `7,680`，预计物理重拟合约 `30` 至 `60` 秒，显存不超过 `1 GiB`；实际值必须由正式日志和 SwanLab 核验。

随后 `F-A/F-P/F-S` 的检测训练规模仍为各 `711` 步，时间和显存预算基本不因本修正改变。主代理须先同步上述三个生产源码、新配置和必要测试，使用新物理配置生成全新检查点与不可变绑定清单，再原子生成或更新三份探针配置。旧检查点及旧配置摘要不得复用。
