# 加密恶意流量检测论文实验论证综述

- **检索与核验日期**：2026-08-06
- **研究对象**：加密恶意流量、加密命令与控制流量检测、未知攻击、对抗规避、跨条件泛化、TQH-C2 v1.2.0 与第三章实验论证
- **证据范围**：8 篇核心全文、4 篇补充全文、TQH-C2 官方 Zenodo 记录/API/README/轻量特征与标签制品、仓库内冻结实验事实
- **结论状态**：可用于冻结研究问题与下一轮开发合同；不能替代尚未运行的 TQH-C2 正式实验

## 一、直接结论

1. **第三章不应把宽泛的“跨加密”设为唯一核心问题。** 现有高相关论文通常把研究问题构造成未知恶意家族、时间或场景偏移、对抗规避、持续学习、上下文交互或实时效率，而不是仅改变加密协议。TQH-C2 的 A/B/C 同时改变 C2 框架、协议栈、会话实现与指纹族，留一 A/B/C 只能称为**跨测试床或跨配置泛化**，不能把性能差异归因于加密层。
2. **B/D 是目前最有价值的受控对照，但更准确的名称是“跨协议栈迁移”。** 两者都使用 Merlin、相同杀伤链与同一 C2 目的端；B 为 HTTP/3-over-QUIC/UDP，D 为 HTTP/2-over-TLS/TCP。它们仍有长连接复用与逐信标 TCP 连接等流结构差异，因此只能形成有边界的协议栈迁移证据，不能外推为普遍的跨加密能力。
3. **唯一推荐的第三章主题是“快捷特征受控的加密 C2 分组外推与困难域检测”。** 建议章名为：

   > **第三章　基于有界物理条件专家的加密 C2 分组外推与困难域检测方法**

   主问题是：剔除地址、测试床身份和连接状态等捷径后，模型能否在未见采集单元、未见间隔/抖动条件以及相对困难的 C 测试床上保持检测性能，并在 B↔D 受控协议栈迁移中避免负迁移。B/D 是机制对照，C 是相对困难域，间隔×抖动是扰动轴，三者共同服务于一个“成组分布外推”问题。
4. **TQH-C2 v1.2.0 应冻结为第三章唯一正式公开检测数据集。** GeNIS 不再进入新协议的训练、调参、校准、验证或主测试，也不与 TQH-C2 拼成总分。既有 GeNIS/TQH 混合实验必须原样保留为历史探索事实；GeNIS 至多作为不参与模型选择的档案性附录或预注册外部审计，不具有不可替代的主协议职责。ns-3 与 qlog 是训练期物理监督源，不是第二个公开恶意检测数据集。
5. **主检测基座应改为双向编码器，系统采用“编码器检测器 + Qwen 分析器”的双阶段结构。** 当前同一候选合同下，DistilBERT 的 `F-A/F-P/F-S=0.9290/0.9091/0.8953`，Qwen3-0.6B 为 `0.9231/0.8140/0.7677`。两者的物理旁路都未过门槛，但 Qwen 的退化明显更大。TQH 的固定流表/包序列二分类、数值状态头、残差损失和停止梯度专家路由更适合编码器。Qwen 保留为结构化分析器与跨基座验证，不参与主检测分数生成。
6. **ET-BERT 不能与当前 DistilBERT 混称为同一种输入方案。** ET-BERT 从 PCAP 五元组会话构造同方向连续包的 BURST，使用十六进制双字节词元，并以掩码 BURST 模型和同源 BURST 预测在 30GB 无标签流量上预训练；当前 DistilBERT 是对结构化字段序列化后的通用文本编码。二者只能在“同捕获、同划分、同标签预算”层比较，不能谎称输入信息完全相同。

### 文献整体图景

- **域内检测**常得到接近天花板的结果，但不能回答未知家族、场景迁移或真实规避。
- **更强的问题构造**包括：时间后移验证、家族级留出、外部数据、可执行对抗修改、增量新类、长时运行与固定低误报工作点。
- **简单模型必须保留。** Lichy 等直接证明随机森林可能胜过复杂深度模型；Wang 等的高分又说明来源捷径可把问题做得过易。
- **“跨加密”不是领域通行的默认主问题。** 即使论文覆盖 TLS、QUIC 或多数据集，通常也没有把加密层作为受控独立变量。
- **研究空白**是：在同一 C2 框架与行为下受控改变协议栈，同时使用捕获组级拆分、消除地址捷径，并验证困难行为域。TQH 的 B/D 与 C 可以部分填补该空白，但尚未提供现实网络外部有效性。

### 4.2 A/B/C/D 的可支持语义

| 测试床 | C2 框架 | 协议栈/加密层 | 指纹与被动观察 | 自然实验角色 |
| --- | --- | --- | --- | --- |
| A | Sliver | TLS/TCP | JA4/JA4S、双向流量、包长与时序 | TLS/TCP 域；域内与分组外推 |
| B | Merlin | HTTP/3-over-QUIC/UDP | QUIC-TLS 的 JA4/JA4S；长寿命、复用的 UDP 流 | QUIC/UDP 域；与 D 做受控协议栈迁移 |
| C | Mythic | HTTP/TCP，消息体 AES 加密 | 主要为 JA4H；模拟良性尺寸/时序 | 相对困难域与未见测试床外推 |
| D | Merlin | HTTP/2-over-TLS/TCP | TLS 的 JA4/JA4S；每次信标独立 TCP 连接 | 与 B 做受控协议栈迁移 |

这里的“加密”不是同一层级：A/D 是 TLS，B 是 QUIC 内 TLS，C 是 HTTP 消息体 AES。A/B/C 还更换了框架，因此 A/B/C 留一不能叫“只改变加密条件”。README 关于“三种传输中只有加密/传输配置系统变化”的概括，与实际框架表不完全一致；应以更保守的“跨测试床”表述为准。

### 4.3 网格、标签与样本单位

- 每个测试床都有 `4 个信标间隔 × 3 个抖动水平 = 12` 个独立捕获单元。
- 间隔为 30、300、1800、3600 秒；抖动为 0%、30%、70%。
- A/B/C 共 36 个单元；D 另有 12 个单元。**v1.2.0 的物理单元总数应按 48 理解。** README 总览仍写“3×4×3=36”，而文件表已列出 D，属于版本文字未完全更新。
- 标签粒度是 Zeek `conn.log` 对齐的逐连接/逐流记录，不是逐包标签，也不是逐信标标签。B 将多个信标复用在长寿命 QUIC/UDP 流内，因此“流数”不等于“信标数”。
- 标签字典包括 `malicious_c2`、`malicious_lateral`、`malicious_recon`、`benign`、`benign_external`、`unknown`。检测目标是 `malicious_c2`。
- `unknown` 表示未分类的传输或基础设施流，例如 QUIC 0-RTT/握手状态、mDNS、Docker 网络 ICMP 等；长间隔 B 单元的占比从约 8% 上升到约 26%。**它不是开放集恶意家族标签，也不能直接当负类。**
- 本轮解包核验的 D 标签共有 11,528 条，其中 `benign` 9,564 条、`malicious_c2` 1,964 条；未观察到其他标签。

### 4.4 被动可观测字段与 26/27 不一致

D 的 `labeled.jsonl` 实际记录包含 31 个键，覆盖五元组、双向字节/包数、持续时间、连接状态、TLS/QUIC 指纹、配置与标签。实际 Parquet 元数据核验得到 26 列：

```text
ts, uid, orig_h, resp_h, duration, orig_bytes, resp_bytes,
orig_pkts, resp_pkts, orig_p, resp_p, proto, conn_state, history,
orig_ip_bytes, resp_ip_bytes, missed_bytes, ja4, ja4s, ja4h,
profile, encryption_profile, interval_s, jitter_pct, capture_id, label_raw
```

README 文件表称 D 是“27 列模式”，但实际元数据是 26 列；本轮直接核验的 B 与 D 汇总 Parquet 都是上述 26 列模式。正式数据合同必须从文件模式生成，不得手写“27”。`labeled.jsonl` 的 31 键与 Parquet 26 列是两个不同层次，也不能混为同一个模式。

另有一项复现缺口：README 声称 `TQH-C2_scripts.zip` 包含 `extract_features.py`，但本轮对校验通过的官方脚本压缩包逐项检查后未找到该文件，也未找到 D 的采集脚本。现成 Parquet 和标签仍可用于实验，但“从标签与 `conn.log` 完整重建特征表”的能力需要作者补件或另行确认。

分类推理可安全使用的候选包括持续时间、双向字节/包数、IP 层字节、丢失字节、连接历史的受限编码、JA4 族及包历史。`profile`、`encryption_profile`、`interval_s`、`jitter_pct`、`capture_id` 只能用于分组、审计和条件评价，不能直接作为主分类输入。

### 4.5 UDP/QUIC 的准确边界

TQH-C2 明确包含 UDP：B 的 12 个 PCAP 单元为 Merlin 的 HTTP/3-over-QUIC/UDP，官方包约 4.26GB；每个 B 单元包含 `conn.log`，`quic.log` 只在 B 出现。官方脚本使用 `udp and port 443` 抓取，并按 `proto == "udp"` 选择长寿命 C2 流。

这不等价于存在一个可独立监督的普通非 QUIC UDP 恶意域。DNS/NTP/mDNS 等普通 UDP 多属于良性背景或 `unknown` 基础设施噪声；没有与 B 同框架、同杀伤链、同标签合同的普通 UDP C2 对照。B 同时绑定 Merlin、HTTP/3、QUIC、UDP 和长连接复用。因此：

- 可以研究 **QUIC/UDP 条件专家**；
- 不能仅凭 TQH 声称学习了可迁移的**通用 UDP 动力学专家**；
- 队列、丢包、RTT、在途字节与拥塞窗口等真值仍须来自 ns-3/qlog，并且只能作为训练期特权监督或物理评价。

### 4.6 快捷特征与难度

- **IP 捷径**：每个测试床的 C2 是单一内部目的地址，良性目的地址为外部服务；`orig_h/resp_h` 可完美分离，必须删除。
- **连接状态捷径**：B v1.0.x 的恶意流单向、`resp_bytes=0` 且常为 `S0/OTH`；v1.1.0 已修复为双向且主要为 `SF`。旧版结果不能移植到 v1.2.0。
- **近天花板**：README 自报在删除 IP 与连接状态后，只用尺寸/时序的随机森林对 A/B/D 约为 1.00，C 约为 0.98。
- **C 是相对困难域，不是已证实的绝对难题。** README 说明 C 的模拟服务器刻意接近良性尺寸/时序，但 0.98 的域内 F1 仍很高。第三章必须先做强基线闸门；若组级 C 和 A/B/D→C 都没有足够误差空间，就不能靠“困难”措辞制造创新。
- **B/D 受控对照**：B 中位持续时间约 1477 秒、中位响应约 35.8kB；D 约 31 秒和 6.2kB。两者尺寸/时序仍近完美可分，说明“改变协议栈本身必然让检测更难”不成立。B/D 更适合作为迁移、路由和负迁移诊断，而不是核心难度来源。

## 五、由 v1.2.0 反向设计的第三章候选主题

### 候选一：同框架条件下的跨协议栈迁移

- **研究问题**：在 Merlin 框架与杀伤链保持一致时，B→D 和 D→B 的检测器能否跨 HTTP/3-QUIC/UDP 与 HTTP/2-TLS/TCP 迁移？
- **数据自然支持**：B/D 是唯一共享框架、杀伤链和 C2 目的端的配对；12 组间隔×抖动条件可按条件对齐。
- **划分**：按 `capture_id` 整组；每个方向在源域训练/校准，在目标域全部测试；同时做同间隔/同抖动配对和留一条件。不得按流随机拆分。
- **主要基线**：去地址的随机森林、XGBoost、MLP、DistilBERT 编码器、原生包预算的 ET-BERT；迁移基线增加 CORAL/DANN 或等价域适配。
- **指标**：目标域宏平均 F1、PR-AUC、`TPR@固定FPR`、校准误差、相对源域下降、每单元最差 F1；B/D 等权。
- **与物理专家的连接**：B 路由 QUIC/UDP 专家，D 路由 TCP 专家；共享守恒头不变，检验协议专家是否降低负迁移。
- **不能宣称**：普遍跨加密、普通 UDP 泛化、因果分离所有协议因素、未知恶意家族。
- **工作量**：低到中。最小 `2 个方向 × 4 类基线 × 3 种子=24` 次核心拟合，另加约 24 次路由/物理消融。
- **裁决**：不推荐单独作主线。B/D 域内均近天花板，目标域是否有足够误差空间尚未证实。

### 候选二：间隔与抖动扰动下的加密 C2 检测

- **研究问题**：模型能否在未见信标间隔或高抖动下保持检测，而不记忆固定周期？
- **数据自然支持**：四个间隔和三个抖动水平是所有测试床共有的显式实验轴，且每个组合是独立捕获。
- **划分**：在每个测试床内做留一间隔；以 0%/30% 训练、70% 测试；再做最难组合 `i3600-j70` 留出。阈值只能在训练条件校准。
- **主要基线**：随机森林/XGBoost 尺寸时序、频谱/周期基线、GRU/Transformer、DistilBERT；物理方法与无时序字段消融。
- **指标**：各测试床宏平均 F1、最差条件 F1、PR-AUC、固定误报召回、相对已见条件下降、三种子和捕获单元自举区间。
- **与物理专家的连接**：多时间窗状态头、速率/守恒残差和时间尺度门控可直接对应间隔/抖动；第四章可按条件难度做课程调度。
- **不能宣称**：跨协议、跨框架、开放集或现实时间漂移；网格是实验配置，不是自然时间演化。
- **工作量**：高。完整方案约 `4 测试床 × 5 个留出面板 × 4 基线 × 3 种子=240` 次核心拟合，尚未计消融。
- **裁决**：适合成为重要子面板，但单独作主线可能退化成参数敏感性研究；长间隔还与 `unknown` 比例和捕获长度相关。

### 候选三：快捷特征受控的分组外推与困难域检测

- **研究问题**：删除地址、配置身份和连接状态捷径后，有界物理条件专家能否在未见捕获/时序条件、相对困难 C 域和 B/D 协议栈迁移中稳定提升检测？
- **数据自然支持**：它同时利用 TQH 最独特的四类证据：显式捷径、48 个独立捕获单元、C 的良性模仿、B/D 受控配对。
- **划分**：
  1. **组内基准**：每个测试床按 `capture_id` 划分训练/校准/开发验证/最终测试，建立无泄漏下限；
  2. **时序外推**：留一间隔与 70% 抖动，只作为稳健子面板；
  3. **困难域外推**：A/B/D 训练与源域校准，C 全量整组测试；结果称“未见测试床 C”，不称纯跨加密；
  4. **受控迁移**：B→D、D→B，按间隔/抖动匹配，作为协议专家机制证据；
  5. **最终测试**：模型、字段、阈值、路由和停止条件冻结后一次性开启。
- **主要基线**：去 IP/测试床身份的随机森林、XGBoost、MLP；同共同字段的 vanilla DistilBERT；原生包视图 ET-BERT；无物理头、无专家、共享专家、随机/置换旁路和域适配基线。
- **指标**：主指标为 C 域与全部未见组等权宏平均 F1；共同主指标为最差组 F1；同时报告 PR-AUC、`TPR@0.1%/1% FPR`、MCC、期望校准误差、源→目标下降、训练时间、峰值显存、吞吐和延迟。物理状态误差与无量纲残差单列，不能替代检测收益。
- **与 PINN/TCP-UDP-QUIC 专家的连接**：共享守恒头处理协议无关包/字节边界；A/C/D 进入 TCP 条件专家，B 进入 QUIC/UDP 条件专家；协议路由只使用被动可观察证据并停止梯度。TQH 不提供队列真值，ns-3/qlog 只训练状态头和残差，不进入推理。
- **不能宣称**：普遍跨加密、真实互联网外部有效性、未知恶意家族检测、普通 UDP 专家、因果证明加密层影响、生成式解释的忠实性。
- **工作量**：中到高。建议先执行约 48 次组内强基线、24 次 B/D 迁移和 36—60 次关键消融，总量约 108—132 次核心拟合；不做无边界全组合扫描。
- **裁决**：**唯一推荐主题。** 它把 B/D 的受控性、C 的相对困难、间隔/抖动的扰动和捷径审计组织为一个清楚的分组外推问题。

### 5.1 主线的先验闸门

正式开发前先用冻结拆分运行去 IP、去 `profile/capture_id`、去连接状态的随机森林、XGBoost 和 vanilla 编码器。若 C 域、A/B/D→C 或 B↔D 的强基线都在捕获组级评价上进入统计不可区分的天花板，说明 TQH 当前版本不足以支撑复杂方法的检测增益。此时不得削弱基线或临时改变拆分；只能收窄为“机制与失败边界”论文，或另立经审批的新数据/扰动合同。

### 6.1 为什么不继续混合 GeNIS 与 TQH

- 两者的标签语义、样本单位、字段、采集环境和协议分布不同；混合后难以判断增益来自方法还是来源识别。
- 文献中恶意来自一个数据源、良性来自另一个数据源的高分案例正是应避免的反例。
- 单一 TQH 版本可以统一组、标签、字段、最终测试和主指标，减少论文中的多重解释。
- GeNIS 的时间前向、未知攻击或外部域确有补充价值，但不是不可由其他外部审计替代的主训练角色。其最安全用途是**模型冻结后的附录审计**，不是参与选择的第五个拆分。

### 6.2 历史事实保护

现有 10,000/59,656 条候选、GeNIS/TQH 混合训练视图和已完成 Qwen/DistilBERT 实验仍是有效的历史工程证据，不得删除、改标签或追溯性改称“纯 TQH”。新协议使用新的版本号、索引、哈希与拆分清单；旧结果只从“正式主证据”降级为“历史探索证据”。

## 七、编码器、Qwen 与双阶段系统的基座裁决

### 7.1 ET-BERT 原论文事实

ET-BERT（Lin 等，2022，[论文](https://doi.org/10.1145/3485447.3512217)）的输入与训练合同是：

- 从 PCAP 按五元组形成会话，把时间相邻、方向一致的包组成 BURST；
- 去除 Ethernet/IP 头和 TCP 端口以降低地址/端口偏差；
- 把十六进制 BURST 转成双字节词元，词表 65,536，最大 512 词元；
- 12 层、12 注意力头、隐藏维 768 的 BERT 编码器；
- 在约 30GB 无标签流量上做 500,000 步预训练，其中约 15GB 来自公开数据，约 15GB 来自 CSTNET；
- 预训练目标为掩码 BURST 模型（MBM）与同源 BURST 预测（SBP）之和；
- 下游六数据集按 8:1:1 随机划分；消融中移除预训练后，ISCX-VPN-App 的 F1 从 0.9395 降至 0.5638，下降 37.57 个百分点。

因此，ET-BERT 是**流量专用字节/BURST 预训练编码器**。当前 DistilBERT 是**结构化流字段序列化后的通用文本编码器**。二者共享“双向编码”结构，但不共享数据表示与预训练语义。

### 7.2 三类基座的证据比较

模型族的原始出处分别是 BERT、DistilBERT 与 Qwen3 技术报告。BERT 的双向编码与单分类头微调设计适合固定标签判别；DistilBERT 以预训练期蒸馏压缩 BERT；Qwen3-0.6B 属于 Qwen3 的小规模生成模型。这里比较的是任务适配和证据成本，不把模型规模或“生成式”题目措辞当成先验优势。

| 维度 | 解码式 Qwen3-0.6B 主模型 | 编码器主模型 | 编码器检测 + Qwen 分析双阶段 |
| --- | --- | --- | --- |
| TQH 流表适配 | 数值字段需文本化，因果下一词目标与固定二分类不完全匹配 | DistilBERT 可直接复用当前字段序列；ET-BERT 可用 PCAP/BURST；分类头自然 | 检测端同编码器；Qwen 只读取结构化证据摘要 |
| 流量专用预训练 | 通用语言预训练，需额外流量适配才有领域先验 | DistilBERT 仍无流量预训练；ET-BERT 明确有 MBM/SBP 预训练 | 检测端可选专用预训练，分析端不承担检测学习 |
| 二分类/迁移 | 可通过分类头或答案词实现，但输出格式和提示带来额外自由度 | `[CLS]`/池化分类、域适配和校准更直接 | 检测性能由编码器决定，Qwen 不污染阈值 |
| 物理状态/残差 | 可作前缀、适配器或额外交叉注意力，但数值尺度和生成损失耦合较难 | 可在中间层/晚期融合状态头，残差直接反传；停止梯度路由清楚 | 物理机制全部放检测端；Qwen 只解释已冻结结果 |
| 专家路由 | 自回归词元路径长，路由可解释性和消融成本较高 | TCP/QUIC/UNKNOWN 适配器或专家头易于独立消融 | 同编码器；分析器可展示路由，但不决定路由 |
| 结构化解释 | 原生优势，但生成理由不自动忠实 | 需模板、特征归因或小解码头 | 最强：编码器输出证据包，Qwen 生成分析；必须标为事后解释 |
| 参数与单卡成本 | 约 0.6B；即使能在 5090 上微调，显存、吞吐与自回归延迟均高于 66M DistilBERT | DistilBERT 约 66M、BERT/ET-BERT 约 110M；微调与多种子更经济。ET-BERT 从头 30GB/500k 步预训练仍昂贵 | 训练主成本接近编码器；Qwen 可冻结或低秩适配，但部署是两模型 |
| 公平比较 | 与 DistilBERT 可在相同字段文本上严格比较 | ET-BERT 原生字节视图只能做同捕获/同标签预算比较，不能称完全同输入 | 可把检测主表与解释质量表分开，公平性最好 |
| 创新性 | 仅换 Qwen 不构成创新；需证明生成训练对检测有必要性 | 物理状态头、受控路由和分组外推可形成方法创新 | 检测创新边界清楚；Qwen 分析属于系统能力，不冒充检测增益 |
| 可复现性 | 提示、答案解析、生成参数增加变量 | 固定分类头与数值接口更容易冻结 | 中等；需冻结证据模式和分析提示，但不影响检测复现 |
| 第三/四章工作量 | 最高，物理机制和生成训练同时调试 | 最低到中等，能复用现有 DistilBERT 与物理旁路代码 | 中等；第三章做检测，第四章训练策略，分析器可后置 |

| --- | ---: | ---: | ---: | ---: | --- |
| DistilBERT | 0.9290 | 0.9091 | 0.8953 | `F-P` 下降 1.99 个百分点 | 未过门槛，但退化较小；适合作为主编码器起点 |
| Qwen3-0.6B | 0.9231 | 0.8140 | 0.7677 | `F-P` 下降 10.91 个百分点 | 未过门槛，当前物理接入明显不适配 |

两条路线中 `F-P` 都高于置换旁路 `F-S`，说明旁路可能携带非随机信息；但完整旁路均低于普通监督 `F-A`，所以当前只能声称“信号存在但接入失败”，不能声称 PINN 提升检测。以上目前是种子 42 与既有候选视图证据，不是 TQH v1.2.0 正式结论。

### 7.4 三个可选架构

#### 架构 A：Qwen 主模型 + 编码器类基线

- 优点：原生生成结构化说明；保留端到端生成训练叙事。
- 代价：当前物理旁路退化最大；数值流表和固定二分类适配弱；多种子、消融和在线推理成本高。
- 第三/四章：两章都需同时处理检测、物理接入和生成稳定性，重复调参风险最高。
- 是否推荐：**否。** 现有证据没有证明生成能力对检测主任务必要。

#### 架构 B：编码器主模型 + 生成解释头

- 优点：共享编码表示，可联合训练分类与说明；单一模型接口。
- 代价：解释损失可能反向干扰检测；TQH 没有人工解释真值，容易训练出格式正确但不忠实的理由。
- 第三/四章：第三章还需构造解释监督，显著增加工作量；第四章训练策略与解释损失容易混在一起。
- 是否推荐：**可作为后续扩展，不作当前主线。**

#### 架构 C：编码器检测器 + Qwen 分析器双阶段

- 优点：检测、物理机制、阈值和统计全部由编码器冻结；Qwen 只接收预测、置信度、可观察字段摘要、专家路由和经验证的特征贡献，生成结构化分析。检测主张与解释主张分离。
- 代价：部署两模型；生成分析是事后解释，必须单独验证一致性、覆盖率和幻觉率，不能称因果解释。
- 第三/四章：第三章完成编码器结构与物理建模；第四章在同结构上研究难度感知课程与约束策略；Qwen 分析器在主实验冻结后实现，不阻塞主线。
- 是否推荐：**是。**

### 7.5 最终基座、强基线与跨基座验证

- **主基座**：DistilBERT 类双向编码器，使用共同结构化流历史，外接数值状态头、共享守恒头和停止梯度 TCP/QUIC/UNKNOWN 专家路由。后续可升级为流量专用编码器，但必须先证明输入与预训练收益。
- **强基线组合**：
  1. 去地址/配置/连接状态的随机森林与 XGBoost；
  2. 无物理机制的 vanilla DistilBERT；
  3. ET-BERT 原生 PCAP/BURST 基线。ET-BERT 与前两者共享捕获、组划分、标签和包预算，但单列“原生字节视图”，不放进严格共同字段表冒充同输入。
- **跨基座验证**：在主方法和拆分冻结后，用 Qwen3-0.6B 在与 DistilBERT 完全相同的结构化字段文本、样本顺序、词元上限、训练标签与评价脚本上重跑 `F-A/F-P/F-S` 的 42/43/44 三个种子。Qwen 只验证机制增益的方向是否跨基座保持，不决定主模型。Qwen 分析器的生成质量另表评价。
- **预训练防泄漏**：若在 TQH 上做无标签流量预训练，最终测试捕获也必须在预训练阶段不可见；否则“无标签”仍会泄漏目标域分布。使用公开 ET-BERT 权重时要记录版本与预训练数据边界。

### 7.6 建议同步修改论文题目与章节

- 建议论文题目：

  > **面向加密恶意流量检测的协议条件表征与物理约束稳健训练方法研究**

- 第三章：

  > **基于有界物理条件专家的加密 C2 分组外推与困难域检测方法**

- 第四章：

  > **基于难度感知课程与约束策略优化的加密恶意流量稳健训练方法**

题目不再预设“生成式大模型”。这是一次真实的改题成本，但比为了题目保留证据较弱的 Qwen 主检测路线更安全。编码器仍可达到数千万至亿级参数规模；论文创新应落在流量表征、物理状态与训练方法，而不是仅以参数量或模型品牌定义“大模型”。

## 八、第四章如何复用而不重复包装

第四章复用第三章冻结后的：TQH v1.2.0 索引与最终测试、共同字段预算、编码器、物理状态/残差接口、专家路由和评价脚本。第四章只改变训练策略：

1. 用第三章开发集上预先定义的难度量形成课程顺序，例如 C 域、长间隔、高抖动、B/D 迁移下降和专家低置信；最终测试标签不得参与难度估计。
2. 研究样本调度、长尾权重与约束策略，目标同时限制简单域退化、最差组风险和物理残差。
3. 与随机顺序、固定课程、自步学习和无约束策略比较；报告平均域、最差域、遗忘、成本与约束违反率。
4. 不重新发明第三章的物理公式、状态头或专家；否则两章会把同一机制重复命名。
5. Qwen 分析器可复用第三章/第四章完全相同的证据模式，比较训练策略变化前后的失败类型，但不进入模型选择。

> 主检测器采用双向编码器与数值物理状态侧路。ns-3 与 qlog 的队列、ACK、RTT、丢包、在途字节和拥塞窗口只作训练期特权监督或物理评价，不作为 TQH 推理输入。Qwen 分析器在检测器冻结后根据结构化证据生成事后分析，其输出不参与分类阈值或主要检测指标。

## 十、主张边界与下一步

### 当前可以主张

- 文献支持把未知家族、外部/成组偏移、对抗规避、持续学习和效率作为比随机流域内精度更强的研究问题。
- TQH v1.2.0 提供 48 个捕获单元、间隔×抖动网格、B/D 配对、C 相对困难域和明确捷径，可支持分组外推研究。
- B/D 支持有边界的协议栈迁移；B 提供 QUIC/UDP 恶意 C2 数据。
- 当前证据支持编码器作为主检测基座，Qwen 作为分析器与跨基座验证。

### 当前不能主张

- A/B/C/D 是只改变加密层的因果实验；
- TQH 支持通用普通 UDP 动力学专家、未知恶意家族或真实互联网部署；
- README 的 36 单元、27 列可直接当 v1.2.0 实际模式；
- 当前物理旁路提升了检测；
- Qwen 生成的解释天然忠实；
- “未检得外部论文”等于“从未有人使用”。

### 最小下一步

1. 冻结 TQH-only 48 单元索引、标签映射、26 列模式、地址/配置/连接状态删除清单及最终测试哈希。
2. 在不读取最终测试的前提下完成随机森林、XGBoost、vanilla DistilBERT 的组级强基线闸门。
3. 只在存在稳定误差空间时实现编码器物理状态头与 TCP/QUIC/UNKNOWN 路由，并跑关键消融。
4. 将 ET-BERT 作为原生 PCAP/BURST 外部强基线，明确其视图不等同于共同字段。
5. 主方法冻结后再跑 Qwen3-0.6B 跨基座验证与双阶段分析器；不让生成组件阻塞第三章主证据。
