# 任务十七公共观测与 ns-3 域随机化计划

## 目标

在不修改任务十六既有代码和制品的前提下，构造一次性 ns-3 域随机化数据，建立不含仿真真值泄漏的公共观测接口，并裁决四窗口历史能否辨识队列状态及校准不确定性。

## 阶段

- [x] 阶段 1：完成接口、数据和服务器只读审计。
- [x] 阶段 2：冻结 v5 仿真参数契约、公共原语和四类切分。
- [x] 阶段 3：实现独立的 v5 ns-3 场景、矩阵生成器和制品记录。
- [x] 阶段 4：同步服务器，完成编译和小规模仿真冒烟。
- [x] 阶段 5：运行 210 个独立配置并构造公共观测数据。
- [x] 阶段 6：比较常数、单窗口和四窗口状态估计器，裁决可辨识性与不确定性。
- [x] 阶段 7：更新实验总控和任务十七报告，决定是否进入 C1/C2。裁决为不进入。

## 优先级

- **P0**：消除容量、队列状态、场景标签进入输入的真值泄漏。
- **P0**：让环境参数元组在训练、校准、未见配置和范围外测试之间互不重复。
- **P0**：先超过训练均值常数下界，再讨论物理软令牌。
- **P1**：与 GeNIS 原始论文核验后的字段语义保持一致。
- **P2**：HIKARI 只承担单窗口覆盖诊断，不伪造四窗口时间关系。

## 已冻结决定

- 任务十六 v4 源码、字段角色、四窗口制品和 B0/B1 结果保持不变。
- v5 使用独立源码、独立运行入口、独立输出目录和新模式版本。
- 不使用测试驱动开发；只执行最小编译、冒烟、制品和关键行为验证。
- 210 个独立运行按 `120/30/30/30` 分为训练、校准、未见配置测试和范围外测试。
- 公共输入不得包含容量、队列真值、场景、攻击标签、随机种子或运行标识。
- C1/C2 在任务十七通过前保持阻塞。
- 当前 v5 是唯一一次 ns-3 覆盖扩展；失败后不得继续增加仿真范围、输入字段或辨识模型。

## 失败停止规则

1. 若 v5 四窗口状态估计通过固定门槛，则进入 C1/C2，并在任务十八后冻结“历史辨识与不确定性感知物理表征耦合”。
2. 若 v5 四窗口仍未超过常数下界，或不确定性不能识别范围外配置，则永久否决历史环境辨识、物理软令牌和不确定性门控，不运行 C1/C2。
3. 失败后第三章降级并冻结为“双锚点边界约束 + 有限队列物理一致性”两支柱，不再声称公开流量能够恢复真实队列状态。
4. 降级方案只执行一次 S3/S4 同协议正式检测验证；若检测性能不劣且物理与状态指标显著改善，则贡献限定为物理一致性、稀疏状态监督和可解释性。
5. 若降级方案同时损害检测性能且不能带来可用的未知攻击、校准或状态收益，则必须明确报告 PINN 不足以支撑第一创新点，不能用新名称包装失败方法。

## 关键问题

1. GeNIS 的包数、字节数、包长和到达间隔具体位于哪个协议层、采用何种窗口定义？
2. ns-3 应输出哪些不带真值的原始测量，才能在论文核验后安全派生公共字段？
3. 四窗口估计器能否在未见配置上将全状态均方误差相对训练均值常数降低至少 10%？
4. 四窗口是否显著优于同容量单窗口，且不确定性是否能识别范围外配置？

## 遇到的问题

- 现有 ns-3 只有 7 个环境配置，且容量真值进入状态提示，不能用于公开观测可辨识性结论。
- 当前 B0/B1 的状态误差未超过训练均值常数下界。
- GeNIS 与 ns-3 当前字段在统计对象和协议层口径上不一致，不能仅按名称合并。
- HIKARI 当前汇总表无可靠绝对时间戳，不能构造真实四窗口。
- 首次写入计划时目标子目录不存在；受限执行环境拒绝普通 `mkdir`，经授权创建后恢复。

## 当前状态

**阶段 7**：任务十七工程运行已完成，但三项预注册门槛只通过“四窗口显著优于单窗口”。四窗口相对常数只改善 `3.017%`，范围外不确定性接收者工作特征曲线下面积为 `0.0811`，因此任务十七总体失败。按失败停止规则，禁止进入 C1/C2，并冻结降级方案。
