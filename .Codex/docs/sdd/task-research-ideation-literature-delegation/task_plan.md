# Research-Ideation 文献委派改造计划

## 目标

将 Claude Scholar 的六阶段 `literature-reviewer` 流程迁移为 Codex 专用代理，并让 `research-ideation` 在进入文献调研阶段时显式委派、验收并接回结果。

## 阶段

- [x] 阶段 1：审计现有技能、Claude 代理与 Codex 代理格式
- [x] 阶段 2：完成改造前行为检查并记录缺口
- [x] 阶段 3：新增 Codex 文献综述代理与委派协议
- [x] 阶段 4：修改 `research-ideation` 的文献调研路由
- [x] 阶段 5：执行格式、结构、引用与行为复验
- [x] 阶段 6：形成迁移报告

## 决策

- Codex 原生代理使用 `~/.codex/agents/*.toml` 格式。
- 六阶段详细流程放入专用代理；`research-ideation` 只保留触发条件、任务合同、委派动作和验收门槛。
- Zotero 是条件能力：可用时优先使用，不可用时退回官方网页、本地全文和可追溯证据记录，不得伪造导入结果。
- 主代理负责定义范围和最终研究决策；专用代理负责检索、筛选、全文分析与综合，不替代主代理冻结研究问题。

## 错误记录

- 在创建持久化计划前先进行了必要的格式审计；已补建计划并记录。
- 沙箱中的 `mkdir -p` 对新任务目录返回 `Operation not permitted`；经批准后创建目录，再使用 `apply_patch` 写入文件。
