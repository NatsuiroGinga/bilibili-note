# 任务十六物理表征显式耦合探针报告

## 结论

任务十六已完成接口审计、最小实现、服务器测试、B0/B1 两步在线冒烟、50 步方向探索、SwanLab 云端复核和本地制品回收。

1. **显式连接工程门禁通过。** B0 与 B1 在 50/50 个更新步上均满足 `dL_gen/dq_hat != 0`，且对 `q_hat` 施加固定扰动后，生成 logits 在 50/50 个更新步上均发生非零变化。这证明预测物理状态已经通过同一次可微前向实际影响生成输出，不再只是借助共享 LoRA 间接耦合。
2. **B1 的 QR-Stiefel 约束确实生效。** B1 最终投影正交误差为 `2.3230157353282266e-7`，低于预设 `1e-5` 门槛；B0 对应误差为 `0.010376084595918655`。
3. **当前 QR-Stiefel 投影未形成联合增益。** 相对同结构 B0，B1 的全状态、已观测状态和未观测状态误差分别改善 `5.444766%`、`13.331950%` 和 `1.173243%`，但生成验证损失恶化 `4.370486%`，物理残差恶化 `278.423247%`。因此不启动 B0/B1 的 202 步正式实验。
4. **裁决范围受限。** 本结果只否决当前注入位置、五维薄 QR 投影和现有损失配置下的 QR-Stiefel 增量，不能外推为全部流形方法无效。B0 也不能仅凭 50 步结果冻结为替代支柱 B，因为尚缺同预算无显式耦合基线与跨域 `q_hat` 物理语义证据。

第三章支柱 A 的双锚点有限队列 PINN 保持不变，替代支柱 B 继续保持未冻结。

## 接口审计

[任务十六表征接口审计](task-16-representation-interface-audit.md)确认：

- GeNIS 推理路径只需要原始八个聚合流量特征、分词器、Qwen、状态头和耦合模块，不读取 ns-3 文件、队列锚点、通量真值或物理残差。
- 从第一个监督完成令牌前的提示末令牌隐藏状态预测五维 `q_hat`，避免使用包含答案的完成文本隐藏状态。
- 在监督完成位置、原 Qwen 词表输出层之前注入可靠性门控物理投影，保留原因果语言模型损失。
- GeNIS 缺少链路容量与四窗口通量。接口可执行不等于 `q_hat` 已具备跨域队列物理语义，这一风险仍未解除。

## 最终裁决与后续边界

1. 保留显式物理状态连接作为已经通过工程可微性验证的接口证据。
2. 当前 QR-Stiefel 投影未形成联合增益，不进入 202 步正式实验，也不运行随机种子 43、44。
3. 不把这一结果表述为全部流形方法失败。若后续文献证据提出不同几何对象、注入位置或可证伪机制，必须另立同预算基线和独立消融，不能沿用本轮结果直接下结论。
4. B0 若要成为替代支柱 B，至少还需补充同预算无显式耦合基线、公开数据任务增益与 `q_hat` 跨域物理语义验证。当前不冻结方法名称。
