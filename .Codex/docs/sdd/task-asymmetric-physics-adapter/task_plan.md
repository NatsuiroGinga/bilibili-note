## 方法通过后的学习率调度消融

本节不是当前唯一修复实验的一部分。当前结构没有通过全部固定门槛，因此任务十九的学习率调度消融已经取消；它不得用于挽救失败结构。

- 优化器仍为 AdamW，损失权重、参数组、数据顺序、批量和 202 步预算均保持不变。
- 第 1 至 20 步从 `2e-5` 线性预热至 `2e-4`。
- 第 21 至 202 步采用无重启余弦衰减，从 `2e-4` 降至 `2e-5`。
- 每一步必须在本地逐步指标和 SwanLab 中记录实际学习率。
- 不扫描预热比例、峰值学习率、最低学习率或其他调度器。
- 若当前任一核心门槛失败，该消融自动取消。
- 调度消融必须继续通过当前全部原门槛，并且相对常数学习率至少改善一个子类、未知攻击或校准主要指标，同时家族指标不得下降，才可判为有效。
