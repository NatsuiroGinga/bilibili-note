# 非对称物理适配唯一修复实验报告

## 结论

本次唯一修复实验**未通过固定门槛，永久停止**。冻结 S3 并为子类与开放集任务增加零初始化物理私有 LoRA，确实同时实现了家族路径完全隔离、未观测状态误差下降和有限队列物理残差下降；但是子类宏平均 F1 与未知攻击召回率出现显著且稳定的退化。因此，该结构不能作为第三章最终方法，也不能通过更换学习率调度继续补救。

## 方法与不变量

- 基座固定为服务端 `/root/autodl-tmp/thesis/models/Qwen3-1.7B`。
- S3 检测 LoRA 从已有正式制品加载并全程冻结。
- 新增与 S3 同秩的零初始化私有 LoRA 和状态头，仅二者进入优化器。
- 家族任务只激活 S3；子类与开放集任务激活 S3 和私有物理 LoRA。
- 训练目标固定为子类生成损失、权重为 `1.0` 的双锚点状态损失和权重为 `0.01` 的有限队列守恒残差。
- 数据、种子 42、批量、原始样本调度、AdamW、常数学习率 `2e-4` 和 202 步预算保持不变。
- 未知攻击标签没有进入训练或阈值校准。

训练前，S3 与“零初始化私有 LoRA + S3”的最大 logits 差为 `0.0`。训练后，S3 参数摘要与训练前完全一致，家族单独使用 S3 时的最大 logits 差仍为 `0.0`。这证明家族指标保持不变来自严格路由隔离，而不是偶然抵消。

## 机制解释与停止决定

该实验给出一个明确的否定边界：**把物理监督隔离到子类专用低秩分支，可以保护家族任务并显著降低物理误差，但物理误差下降本身不保证检测收益。** 私有分支学到了容易满足状态与守恒目标的表征方向，却同时改变了子类标签间的生成边界和开放集置信排序。

按照预注册规则，子类宏平均 F1 和未知攻击召回率任一失败都应终止；本次两者同时失败。因此：

- 不再创建第二个不对称适配修复变体。
- 不执行预注册的预热余弦学习率消融。
- 不把该候选纳入第三章最终算法。
- 保留代码和结果作为“物理误差改善但任务效用未转化”的失败消融证据。

## 局限性

- 固定停止规则要求核心门槛失败后不再进行多随机种子重复，因此失败结论来自种子 42 的正式协议与样本级配对统计，而不是跨种子统计。
