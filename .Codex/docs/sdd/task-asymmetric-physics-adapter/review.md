# 非对称物理适配唯一修复实验独立复审

## 结论

**不存在会推翻“该方法失败并永久停止”裁决的严重或重要问题。**

- 严重问题：无。
- 重要问题：无。

## 核验依据

- 训练实现只将物理私有 LoRA 与状态头加入优化器；S3 参数训练前后摘要一致。
- 家族评估只启用 S3，子类与开放集评估启用 S3 和物理私有 LoRA；家族路径最大 logits 差为 `0.0`。
- 本地预测制品复算得到：家族自由生成宏平均 F1 变化 `0.000000`，子类变化 `-0.088946`，未知攻击平均召回率变化 `-0.374444`。
- 子类与未知攻击两项均明显违反固定门槛，且两千次分层配对自助法的 95% 置信区间完全小于零。
- 未观测状态误差、物理残差、良性误报率和校准误差虽有改善，但不能抵消两个核心门槛失败。

## 裁决

当前失败结论有效，应按预注册停止规则永久停止该修复路线，不再运行第二修复变体或学习率补救实验。
