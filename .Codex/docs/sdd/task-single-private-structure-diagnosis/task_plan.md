## 固定决策

- 研究范围只覆盖当前加法式单私有 LoRA，不否定所有单适配器或所有 PINN。
- 第一阶段固定 D1、D2、D3，不新增第四种种子 42 变体。
- D1、D2 只作因果诊断；D3 是唯一可能进入跨种子复现的候选。
- 总正式训练上限为五次。
- 禁止使用测试驱动开发；实现后只运行直接覆盖新接口的最小验证和服务器冒烟。
