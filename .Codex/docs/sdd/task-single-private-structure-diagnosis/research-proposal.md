# 单私有 LoRA 结构与优化归因研究提案

## 提案就绪门禁

- 已选择唯一研究问题：通过固定损失分解与调度干预区分当前单私有 LoRA 的失败来源。
- 当前证据足以证明问题重要且可测量，缺失证据能够通过三次固定实验获得。
- 最小下一步已经具体到 D1、D2、D3 的训练目标、学习率和裁决逻辑。
- 关键动机与边界均关联已有实验制品和全文文献综述。

**裁决**：通过提案就绪门禁，可以进入实现与实验。

## 固定实验矩阵

| 变体 | 子类生成损失 | 双锚点状态损失 | 队列物理损失 | 学习率 | 角色 |
| ---- | -----------: | -------------: | -------------: | ------ | ---- |
| D0   | 开启         | 开启           | 开启           | 常数 `2e-4` | 已完成失败基准 |
| D1   | 开启         | 关闭           | 关闭           | 常数 `2e-4` | 私有结构与子类微调诊断 |
| D2   | 关闭         | 开启           | 开启           | 常数 `2e-4` | 物理梯度与仿真域偏移诊断 |
| D3   | 开启         | 开启           | 开启           | 预热加余弦 | 优化调度诊断与唯一潜在候选 |

D3 第 1 至 20 步从 `2e-5` 线性预热至 `2e-4`，第 21 至 202 步无重启余弦衰减至 `2e-5`。

## 固定不变量

- 基座、S3 检测适配器、私有 LoRA 秩与目标模块不变。
- 家族任务始终只激活冻结 S3；子类与开放集任务激活 S3 和私有 LoRA。
- GeNIS/ns-3 文件、样本顺序生成规则、批量、梯度累积、最大梯度范数和 202 步预算不变。
- D1、D2 使用常数学习率 `2e-4`；D3 只改变预注册学习率轨迹。
- 未知攻击标签不进入训练或阈值校准。
- 全部运行保存配置、环境、输入哈希、样本顺序、逐步指标、预测、统计、SwanLab 日志和制品清单。

## 因果裁决矩阵

| 观察 | 允许的解释 |
| ---- | ---------- |
| D1 保持检测，D2 退化 | 物理梯度或仿真域偏移是主要原因 |
| D1、D2 均保持检测，D0、D3 退化 | 联合目标交互是主要原因 |
| D3 通过全部原门槛 | 常数学习率是主要原因，进入种子 43、44 |
| D1 与 D3 均明显退化 | 当前加法式私有 LoRA 结构受到否定 |
| 结果无法映射上述模式 | 证据不足，停止并如实报告 |

D1、D2 的“保持检测”仅用于归因，采用与正式门槛相同的检测、开放集与校准方向检查，但它们缺少完整双支柱，不得作为最终算法。D3 必须通过家族、子类、未知召回、开放集良性误报、状态、物理和校准全部原门槛，才有资格复现。

## 执行顺序与资源

1. 完成统一训练模式、调度器和运行清单实现。
2. 对 D1、D2、D3 各执行两步冒烟，核验可训练参数、损失开关、学习率轨迹与家族等价性。
3. D1、D2 在 RTX 5090 上并行执行 202 步训练与评测；并行运行的时间和吞吐量不进入效率比较。
4. D3 单独执行 202 步训练与评测。
5. 对三者执行与 D0/S3 相同的配对统计。
6. 仅当 D3 通过全部门槛时，并行运行种子 43、44；否则停止。

## 风险与停止条件

- 若损失开关改变未授权的数据、样本顺序或参数集合，停止并修复契约，不能解释结果。
- 若 D1、D2 并行导致显存不足，改为顺序执行，不改变实验配置。
- 若任一运行缺少逐步指标、预测或 SwanLab 数据，不进行方法裁决，先补齐同一运行制品。
- 第一阶段完成后不增加第四种种子 42 变体。
- 最多五次正式训练；没有通过全部门槛的 D3 时，不启动任务十九。
