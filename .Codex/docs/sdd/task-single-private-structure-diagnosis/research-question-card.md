# 研究问题卡：单私有 LoRA 失败的结构与优化归因

## Research Question Card

**Question**：在固定 Qwen3-1.7B、冻结 S3 检测适配器、GeNIS/ns-3 数据协议、加法式任务路由、低秩参数量、批量与 202 步预算后，当前“子类与开放集启用单私有 LoRA”方法的失败主要来自加法式结构、物理梯度与仿真域偏移、联合目标冲突，还是常数学习率造成的优化问题？

**Type**：确认性机制诊断。

**Hypothesis**：

- `H_private`：即使只使用子类生成损失，私有 LoRA 也会破坏子类或开放集边界，说明当前加法式私有分支本身存在问题。
- `H_physics`：生成单独训练保持检测能力，但物理单独训练导致退化，说明物理梯度或仿真到真实偏移是主要原因。
- `H_interaction`：生成单独训练与物理单独训练均保持检测能力，联合训练失败，说明目标交互是主要原因。
- `H_optimization`：保持联合目标不变，仅采用线性预热与无重启余弦衰减即可通过全部门槛，说明常数学习率是主要原因。

**Why it matters**：第三章固定保留双锚点边界约束与有限队列物理一致性，但现有联合训练与非对称单私有适配均未形成检测、开放集和物理指标的联合收益。若不区分结构与优化原因，继续增加模块会变成无边界试错，也无法形成可辩护的理论边界。

**Current evidence**：

- S3/S4 正式比较证明固定权重共享适配器改善状态、物理、子类和未知召回，但显著损害家族检测与校准。
- 非对称单私有适配器保持家族路径完全不变，未观测状态误差和物理残差分别改善 `79.277%` 与 `74.270%`，但子类宏平均 F1 下降 `0.088946`，未知召回均值下降 `0.374444`。
- 种子 42 的配对自助置信区间证明退化不是评测样本抽样波动，但不能区分结构、损失与优化调度的因果作用，也不能替代训练随机种子复现。

**Missing evidence**：

- 相同私有结构只受子类生成梯度更新时的检测结果。
- 相同私有结构只受双锚点状态与有限队列物理梯度更新时的检测结果。
- 联合目标在固定预热余弦调度下的检测、物理与校准结果。
- 仅当联合调度变体通过全部门槛时，其在随机种子 43、44 上的方向复现。

**What would support it**：D1、D2、D3 的同协议结果符合预注册归因表，且配对统计方向与点估计一致；若 D3 通过全部原门槛，还需种子 43、44 保持同方向。

**What would falsify it**：三个诊断结果彼此矛盾、无法映射到任何预注册归因模式，或者实现未保持数据、参数、路由与评测协议不变。此时只能裁决“证据不足”，不得强行归因。

**Minimal next action**：实现 D1 生成单独训练、D2 物理单独训练和 D3 联合预热余弦三种固定模式，先完成参数更新范围与路由等价性冒烟，再运行正式实验。

**Decision**：运行实验。第一阶段固定三次种子 42；只有 D3 通过全部原门槛才运行种子 43、44，总上限五次。

## 裁决边界

本研究问题只裁决当前“冻结 S3 + 子类/开放集加法式私有 LoRA + 状态头”结构，不外推为所有单适配器、所有参数高效微调方法或所有 PINN 方法无效。
