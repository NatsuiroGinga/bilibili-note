# 第二结构理论候选比较

## 评分规则

每项按 `0` 至 `2` 分：`0` 为不满足，`1` 为条件满足或证据弱，`2` 为明确满足。七项总分只帮助约束选择，不替代实验。

1. 明确的模型结构。
2. 物理条件到生成输出的可微路径。
3. 显式检测保护机制。
4. 能解释 D1/D2/D3。
5. Qwen3-1.7B 与 RTX 5090 可行。
6. 可做四组独立消融。
7. 足以支撑章级理论、算法与复杂度分析。

## 首选理由

### 新计算图

预测队列锚点和有限队列残差先变为多个条件词元，生成隐状态通过交叉注意力选择性读取；不是单物理向量加法，也不是静态私有 LoRA。

### 新梯度路径

物理损失先作用于状态头和条件词元，再通过查询选择的残差影响生成表征。冻结检测主干不直接接受物理梯度。

### 新保护机制

门控从零初始化，原检测表示保留显式恒等旁路；条件残差经过相对范数限制。已有论文支持前两项的结构原理，范数限制是本课题针对 D3 新增的可证伪设计。

### 理论与篇幅承载力

该结构可形成物理词元编码、条件注意力、残差界、初始化恒等命题、梯度隔离命题、复杂度分析、前向干预实验、四组消融和效率表。它足以作为第二结构理论，但前提是一次性实验通过全部门槛。

## 条件备选理由

条件超网络能把物理状态转成样本相关低秩参数，理论上比静态 LoRA 更具选择性。为控制风险，备选只生成低秩基底缩放，不生成完整矩阵。其缺点是超网络训练稳定性证据较弱、推理实现更复杂、缺少严格初始化保护的直接论文证据。

## 两个暂不采用方向

### 稀疏专家

它可以通过内部状态路由形成新计算图，但任务十七的可观测性失败仍未解除；APINN 的初始化敏感性和多流文献的专家坍缩也使一次实验难以区分路由、专家和物理监督三种原因。

### 子空间解耦

Recon 支持冲突层隔离，DSN 和 MTLoRA 支持共享私有结构，但它们没有样本条件物理路径。Stiefel、mHC 和当前单私有 LoRA 已有负结果，再增加正交、流或同类分支无法直接反驳 D2/D3。

## 建议的暂定表述

若首选实验通过，可把第二支柱暂称为“**受限物理条件注意力**”。章节标题可进入候选：

> 基于物理信息神经网络与受限条件注意力的恶意流量检测方法

该名称不是最终冻结名称；实验未通过前不得写入正式贡献句。
