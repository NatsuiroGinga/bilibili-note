# 第二结构理论方向选择笔记

## 已冻结事实

- 非对称单私有适配不是最终方法。
- 失败主因指向物理梯度造成的开放集边界与校准代价，而不是私有 LoRA 容量不足或常数学习率。
- 新方向必须改变物理信息进入生成表征的结构路径，不能只调整损失、学习率或秩。
- 失败裁决作用于已测试的具体实现和假设，不自动否定整个理论家族。改造候选必须满足“新计算图、新梯度路径、新保护机制、新可证伪假设”四项条件。

## 待补证据

- 动态参数生成、条件适配和超网络能否提供样本级物理调制而保留恒等旁路。
- 受限跨注意力或条件残差能否避免直接加法注入破坏语义边界。
- 内部物理状态路由的专家结构是否能够绕开任务十七公共字段可观测性门槛。
- 表示子空间解耦是否具有比参数正交更直接的信息流控制证据。

## 既有证据的使用边界

- 任务十六的普通门控物理投影已经证明“预测状态能够改变生成输出”，但没有形成生成、物理与开放集指标的联合收益，因此不能把简单加法或单门控重新作为新支柱。
- QR-Stiefel 变体只改善部分状态误差，同时恶化生成损失与物理残差；新流形候选必须约束信息交换或检测保护，而不能只约束投影矩阵正交性。
- 完整 mHC 的多流混合只保证数值幅值受限，不能保证物理语义被生成器采用；若借鉴其思想，只能保留可证明有用的受限残差或近恒等性质，不能照搬完整多流结构。
- 物理状态路由专家仍受公开字段可观测性和专家坍缩风险限制；若重新进入，路由监督、计算图和同预算对照必须不同于既有备选草案。
- 当前只形成因果约束，不提前选定动态适配器、受限跨注意力、专家路由或子空间解耦中的任何一个方向。

## 文献阶段一检查点

- 候选 20 篇，去重后 20 篇，均已定位全文；其中 14 篇为本地既有全文，6 篇由文献代理从官方来源新增。
- 暂居首选的是零初始化、恒等旁路的受限交叉注意力或条件残差注入，初步结构证据来自 Flamingo、LLaMA-Adapter 与 ControlNet。
- 条件备选是物理状态条件化低秩超网络，初步结构证据来自 HyperFormer++、HyperLoRA 与 Prototype HyperAdapter；主要风险是样本级参数生成的稳定性和计算开销。
- 上述排序仍须经过全文位置核验、七项决策门槛评分和六阶段制品验收，当前不得写成最终理论或启动正式训练。

## 首选候选的待证伪假设

- 与任务十六的单门控加法投影不同，候选结构应把预测物理状态编码为独立条件键值，并通过选定 Transformer 层的受限交叉注意力进入生成表征。
- 输出投影或残差门在初始化时严格为零，使新增结构在第 0 步与原检测模型函数等价；训练后物理修正仍受有界门控制，主语义通路保持恒等旁路。
- 两步冒烟必须证明初始化等价、门参数获得梯度，并在门离开零点后形成从生成损失到物理条件和状态头的非零梯度。
- 置零、跨样本置换和真值替换物理状态必须导致有方向性的输出变化；若输出不变，则物理信息未被生成器使用。
- 即使物理与状态误差改善，只要未知攻击召回或校准再次未通过原门槛，该结构仍判失败，不能凭零初始化或理论界限改判。

## 六阶段文献代理最终结论

- 20 篇候选、20 篇去重全文、0 篇仅摘要；本任务直接重新解析 10 篇全文，另复用 10 篇既有逐页核验笔记与报告。
- 首选候选为“零初始化范数受限的物理条件交叉注意力”。Flamingo、LLaMA-Adapter 和 ControlNet 共同支持冻结主干、零初始化条件通路与初始化恒等；训练后保护仍须由本课题的残差范数上界和原九项门槛验证。
- 条件备选为“低秩基底缩放的物理条件超网络”。HyperFormer++ 支持条件生成适配器；HyperLoRA 的训练不稳定证据否决当前直接生成完整 LoRA 矩阵的做法。
- 稀疏专家受任务十七可观测性与专家坍缩风险限制；子空间解耦无法提供比已失败 Stiefel、mHC 和单私有 LoRA 更直接的物理前向路径，二者均不进入当前实验。
- 详细证据见 `literature-review.md`、`candidate-comparison.md`、`evidence-table.md` 和 `missing-fulltext.md`。
