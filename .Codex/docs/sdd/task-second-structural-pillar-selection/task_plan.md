在 D1/D2/D3 已否决非对称单私有适配后，选择一个能与物理信息神经网络形成章级协同、可在 Qwen3-1.7B 上实现并可由有界实验裁决的第二模型结构理论。

## 优先级

- **P0**：冻结研究问题、失败归因、候选边界和停止规则。
- **P0**：完成专门文献代理的六阶段证据综述。
- **P0**：只选择一个首选方向和一个条件备选，不继续发散。
- **P1**：为首选方向形成结构接口、核心公式和最小可证伪实验。
- **P2**：首选方向通过最小实验后再规划正式多随机种子验证。

## 禁止事项

- 不新增 D4/D5，不扫描学习率、损失权重、秩或门控超参数。
- 不把课程学习、强化学习、梯度加权或调度器作为第三章第二结构理论；这些属于第四章训练方法或实现细节。
- 不重复已失败的博弈、QR-Stiefel 投影、完整 mHC、多流、历史软令牌、不确定性门控或非对称单私有 LoRA 的原计算图与原实验配置。相关理论家族只有在结构接口、物理信息梯度路径和检测保护机制均发生实质变化，并能直接反驳既有失败原因时，才可作为新候选重新进入。
- 不以“尚未检索到”声称无人研究，不以摘要代替全文证据。

## 失败方向重新进入门槛

改造后的旧理论候选必须同时满足：

1. 计算图不同：新增结构不是原模块换名、增加同类分支或改变秩。
2. 梯度路径不同：物理信息进入生成表征的路径与失败实现不同，且可通过梯度或干预实验验证。
3. 保护机制明确：具有恒等旁路、受限残差、条件注入或其他不强制覆盖检测表征的机制。
4. 因果假设明确：直接针对 D2/D3 的未知攻击召回与校准损害，而不是继续调整学习率、损失权重或门槛。
5. 消融可区分：能够与原失败实现、PINN 单支柱和无物理结构进行同预算比较。

## 决策门槛

候选方向必须同时满足：

1. 属于可清楚定义的模型结构，而不是单纯训练技巧。
2. 物理状态或守恒信息通过可微结构影响生成表征和输出。
3. 存在保护原检测能力的显式恒等、旁路或残差机制。
4. 能解释 D1 保持检测而 D2/D3 损害未知召回与校准的现象。
5. 可在单块 RTX 5090、Qwen3-1.7B 和参数高效微调预算下验证。
6. 能设计“基础模型、PINN 单支柱、结构单支柱、组合方法”四组消融。
7. 足以支撑第三章的公式、算法、理论性质、机制图和实验篇幅。
