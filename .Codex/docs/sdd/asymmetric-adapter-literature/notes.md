# 非对称共享私有多任务适配文献过程笔记

## 当前实验事实

- S4 相对 S3 的家族级自由生成宏平均 F1 下降 `0.088232`，违反不低于 `-0.01` 的预注册门槛。
- S4 的子类级自由生成宏平均 F1 提升约 `0.02828`，三个未知攻击场景平均召回提升约 `0.38111`，范围外良性误报率平均下降约 `0.15222`。
- S4 的未观测状态误差和有限队列物理残差分别改善约 `70.17%` 和 `55.44%`。
- 当前证据不是“物理约束整体无效”，而是物理更新对不同检测层级产生方向相反的收益。

## 证据分类

### A 类：非对称主辅学习

- AMTL：稀疏有向任务图按任务损失形成非对称传递，但只给软正则与局部最优性质。
- Deep-AMTFL：让可靠任务更多地塑造共享特征，仍不能提供家族输出严格不变。

### B 类：共享私有表示与参数隔离

- Domain Separation Networks：私有分支只进入重构，不进入分类，是“私有辅助不等于主输出依赖”的反例。
- 对抗式多任务文本分类：共享与私有表示拼接进入分类器，是私有前向依赖正例。
- Recon：任务专用化高冲突层可从结构源头减少负迁移。

### C 类：任务专用适配器与低秩分支

- AdapterFusion：先独立训练并冻结源适配器，再单独学习目标组合。
- MTLoRA：任务无关与任务专用 LoRA 共存。
- MoDULA：通用 LoRA、领域专用 LoRA 与路由分阶段训练。

### D 类：物理约束多目标训练与结构化隔离

- 辅助任务 PINN：在 PINN 中比较硬共享、软共享、MMoE 和 PLE，直接支持物理任务的共享私有结构。
- APINN：软物理域分解和部分参数共享，但性能强依赖门控初始化。
- 物理硬约束混合专家：专家按明确物理子域分解硬约束，不是自由词元路由。

### E 类：多物理专家与学习型词元级路由

- DeepSeekMoE、MixLoRA、MoLE、LoRA-Flow 支持共享/路由专家与低秩组合的工程可行性，均不保证物理语义。
- Switch、BASE、StableMoE 和稠密反向传播路由共同暴露负载、溢出、路由波动和稀疏梯度风险。
- LoRA-Switch 说明动态低秩适配的真实解码延迟可能远高于参数量和浮点运算量估计。

- 物理硬约束混合专家：OpenReview 核验为 ICLR 2024 海报。

## 引用边界

- 文献可支持结构设计、冻结条件、参数分组、条件路由和负迁移机理。
- 本课题的家族不变性仍必须由具体计算图和实际逐样本输出哈希验证。
- 文献不能替代 GeNIS、DEDALE、ns-3 或跨基座实验，也不能证明私有物理适配器或多专家路由必然提升恶意流量检测。
- 任务十七的公共五字段可辨识性失败仍然有效；多专家备选不得仅凭文献自动启动。
