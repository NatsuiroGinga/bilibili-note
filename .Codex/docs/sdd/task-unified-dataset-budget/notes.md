# 三源统一预算输入契约审计

- 审计日期：2026-07-29
- 审计范围：仅核验 GeNIS、TQH-C2 与 ns-3 的冻结制品和预算输入契约。
- 明确排除：不读取模型指标、预测、检查点或超参数搜索结果，不运行模型，不生成预算清单。
- 路径口径：下文路径均相对于 `thesis/experiments/llm_probe/` 项目根目录。

## 1. 审计结论

三源输入均可由现有冻结或暂定冻结制品直接取得，当前无需返回原始数据处理阶段。三源 `sample_id` 均唯一，跨源冲突为 `0`，因此统一索引可保留原始 `sample_id`，不得改写或增加结果驱动标识。

候选筛选清单固定为 GeNIS `3,973` 条、TQH-C2 `3,606` 条、ns-3 `2,421` 条，总计恰好 `10,000` 条。该分配保留全部物理监督样本，并把剩余 `7,579` 条公开检测样本按正式训练预算 `30,000:27,235` 使用最大余数法分配，不依据任何模型结果。

## 5. 候选配额证明

1. 候选总目标固定为 `10,000`。
2. ns-3 全取 `2,421`，剩余公开检测配额为 `10,000 - 2,421 = 7,579`。
3. 正式公开检测预算为 GeNIS `30,000`、TQH-C2 `27,235`，合计 `57,235`。
4. GeNIS 理论配额为 `7,579 × 30,000 / 57,235 = 3,972.569...`。
5. TQH-C2 理论配额为 `7,579 × 27,235 / 57,235 = 3,606.431...`。
6. 最大余数法先分配整数部分 `3,972/3,606`，剩余一个名额给余数更大的 GeNIS，得到 `3,973/3,606`。
7. 最终总数为 `3,973 + 3,606 + 2,421 = 10,000`。

该组成能覆盖 GeNIS 的全部 `8` 个时间/标签联合层、TQH-C2 的全部 `56` 个采集条件/标签联合层和 ns-3 的全部 `21` 个组。GeNIS 层内按会话轮转后再按稳定哈希选择，优先扩大会话覆盖；TQH-C2 层内按稳定哈希选择。所有配额与顺序在读取任何模型结果前冻结。

- 不允许读取 `metrics`、`predictions`、SwanLab 摘要、检查点或任何模型派生结果参与抽样。
- 两次独立生成必须逐字节一致；发布前状态保持 `review_pending`，通过复现与独立审查后才允许原子发布为 `frozen`。
