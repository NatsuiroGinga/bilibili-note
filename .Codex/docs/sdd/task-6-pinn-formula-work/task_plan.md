# 任务六公式证据审查计划

## 目标

基于正式四窗口序列字段与原始论文证据，给出一个可直接进入 M2 首轮实现的单尺度、量纲一致、输出依赖的队列动力学残差，并规定数值与梯度门禁。

- [x] 阶段二：核验公式台账、理论映射和原始论文依据
- [x] 阶段三：推导残差、归一化、边界条件与梯度路径

## 关键问题

1. 哪个最小残差既符合队列守恒，又不依赖模型不可见的真值输入？
2. 如何保证物理损失对共享生成式参数产生非零梯度？
3. 哪些内容属于可引用的基础规律，哪些属于本研究的实质改写？

## 决策

- 不使用保存的真值残差作为训练损失，仅用其做离线审计。
- M2 首轮只选择一个字节域、单窗口尺度的核心残差，不并行叠加多尺度、包域或自适应加权机制。
- 状态头只预测 5 个队列边界锚点；每条序列用唯一公共尺度 $S=\max_k B_k$，不直接拼接逐窗归一化起止队列。
- 首轮物理损失使用均方残差；Huber 仅作为后续含噪敏感性对照。

## 错误记录

- 首次创建工作目录时受沙箱限制，使用经审核的目录创建命令后恢复；未修改任何实验文件。
- 首次执行 Prettier 时主报告写入受沙箱限制；文件未损坏，改用经审核的同一限定文件命令重试。
