# R2 物理旁路开发集先导实验计划

## 目标与边界

本任务在正式三源数据冻结前，用小规模、确定性的开发集验证物理旁路接口能否产生增量检测信号。结果只决定是否继续完善 R2，不进入论文主表，也不能替代正式三种子实验。

- 不读取 GeNIS、TQH-C2 或其他数据源的最终测试集。
- 不依据标签、模型预测或实验效果选择样本。
- 不修改正式物理旁路包装器的 `prerequisites_pending` 门禁。
- GeNIS 包级物理真值构造已被任务 02T 判为 `NO-GO`；本先导不为 GeNIS 猜测物理真值。
- 不使用 GPU。

## 冻结输入

1. ns-3 使用 attempt3 已通过运行中的首 16 个 TCP/UDP 配对，共 32 条运行。输入清单固定为 `runs/launchers/r2-ns3-protocol-matrix-v0-attempt3/pilot-first16-pairs.manifest.jsonl`，并核对对应 81 项制品摘要。该子集只用于开发诊断，不代表完整矩阵。
2. QUIC 使用修复后双审计通过的候选集合，按内容 SHA-256 升序选取前 16 条。旧的 59 条候选和旧先导清单已经失效，不得消费。
3. 检测样本使用 TQH-C2 已冻结的开发训练与开发验证记录，只按稳定 `sample_id` 哈希确定性截取小规模子集。禁止读取最终测试 cell、留一 profile 或任何测试标签。
4. 物理辅助样本与检测监督样本分池保存，通过共同的被动观测字段、传输族和缺失掩码连接，不把 qlog 或 ns-3 特权真值拼入分类输入。

## 四组对照

- `A`：冻结基础字段。
- `A+P`：真实物理旁路。
- `A+P_shuffle`：在同来源、同传输族、同划分内置换完整旁路向量。
- `A+P_random`：仅由开发训练集估计同维度边际分布后生成的随机旁路。

四组使用相同样本、标签、基础字段、HGB 容量、预处理和种子 42、43、44。

## 执行步骤

1. 组装并核验 ns-3 首 16 配对的窗口级被动观测、状态真值和残差真值。
2. 从修复后的 QUIC 先导 16 条物化窗口级被动观测与特权真值，保留协议空间、字段缺失和不确定性掩码。
3. 从冻结 TQH-C2 开发训练与验证清单按稳定哈希生成先导样本清单，并记录样本数、标签分布和 SHA-256。
4. 只用 ns-3/QUIC 物理辅助池的训练部分拟合状态估计器；验证部分只用于冻结后的诊断。
5. 为 TQH-C2 开发样本生成旁路视图，运行四组 HGB 与三个固定种子。
6. 输出宏平均 F1、平衡准确率、良性误报率、Brier 分数、期望校准误差、状态误差和物理残差，并执行同样本配对比较。

## 裁决纪律

- 正结果只能支持继续 R2；负结果不能单独否决 R2，因为先导规模小且物理辅助来源不完整。
- 真实旁路必须同时优于原始、置换和随机对照，才可称为存在样本级物理增量信号。
- 若只改善状态误差或物理残差，不得宣称提高检测性能。
- 禁止挑种子、看结果后改样本、调整标签比例或削弱基线。

## 物化与复现策略

- 本先导属于探索性诊断，后续新增的 ns-3、TQH-C2 或 QUIC 先导派生物默认只物化一次，并登记输入与代码摘要、模式、行数、样本顺序和语义哈希；不再为了形式完整机械运行第二份副本。
- 只有先导数据准备晋级最终冻结版本、数据语义发生变化，或单次物化暴露不确定性时，才执行第二次独立物化。
- 规范 JSONL 与清单可比较逐文件 SHA-256；大型 Parquet 优先比较模式、行数、`sample_id` 顺序、缺失值和语义哈希，不要求无语义容器元数据逐字节一致。
- 模型训练与推理评价不执行两次运行后逐字节比较；使用固定配置、种子、输入摘要、指标、预测行数和制品哈希完成复现核验。
- 已经完成的 QUIC A/B 双物化和既有比较收据作为历史复现证据保留，不删除、不重跑，也不把该做法继续扩展到本轮其余先导步骤。
