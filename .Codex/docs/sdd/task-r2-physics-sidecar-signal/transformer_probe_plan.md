# R2 物理旁路多模型验证计划

## 目标

区分当前真实旁路未稳定超过负对照的三种原因：随机对照波动、HGB 结构不适配、单窗口动力学信息不足。全部实验只使用冻结开发训练与开发验证，不读取最终测试。

## 阶段一：HGB 负对照分布

- 不重跑基础组和真实旁路组。
- 固定当前样本、HGB 容量、预处理和18维旁路。
- 使用预注册种子 `1000–1049` 运行50份同来源/同协议/同划分置换旁路与50份仅由训练集生成的随机旁路。
- 报告宏平均 F1、良性误报率、Brier、ECE 的均值、标准差、95%区间，以及真实旁路在两类负对照分布中的经验分位数。
- 不调参、不挑随机种子；真实旁路只有同时高于两类负对照的95%经验分位数，才视为 HGB 上存在样本级物理增量。

## 阶段二：DistilBERT 结构适配探针

- 基座固定为已有的 `distilbert/distilbert-base-multilingual-cased`。
- 复用冻结 TQH-C2 训练2,048条、验证512条和相同基础文本视图。
- 用相同的无偏置18维投影与不确定性门控融合旁路；四组参数量、训练预算和优化器一致。
- `T-A` 使用全零并关闭掩码的旁路；`T-P` 使用真实旁路；`T-S` 使用同层置换旁路；`T-R` 使用训练集随机旁路。
- 四组固定种子42、43、44；`T-P` 必须稳定优于其余三组才能进入 Qwen。
- 实现和审查不需要 GPU；实际12组运行前单独告知用户。预计峰值显存3–5GB，5090上总墙钟约15–30分钟。

## 阶段三：唯一一次时序修正

仅在阶段二失败时执行一次：从逐包被动观测构造因果多窗口序列，增加等信息量原始历史 Transformer 基线，再比较真实、置换和随机物理旁路。若仍失败，停止当前 R2 检测增益路径，不再通过学习率、样本比例或最终测试筛选修补。
