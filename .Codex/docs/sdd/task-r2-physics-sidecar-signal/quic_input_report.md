## 3. 窗口协议

- 窗口宽度固定为 100 毫秒，窗口不重叠。
- 每条轨迹以首个数据包为相对时间零点。
- 从首包到末包建立完整时间轴，保留没有数据包的空窗口。
- 不对往返时延、丢包、在途字节或拥塞窗口做前向填充、插值或零值填补。
- 物理真值是否存在由显式掩码表示。

100 毫秒窗口与当前 ns-3 物理真值的 `0.1 s` 采样粒度一致，避免在进入模型前产生额外时间尺度差异。保留空窗口可防止只保留活跃区间所造成的事后选择偏差。

## 4. 字段隔离

### 4.1 部署时可观测输入

`passive-windows.jsonl` 只包含以下类别的信息：

- 数据包相对到达时间；
- 包间隔及其观测掩码；
- 数据包方向；
- 数据包长度；
- 包数、字节数、包速率和字节速率；
- 可被动识别的传输族及其观测掩码；
- 稳定样本标识、轨迹标识和窗口标识。

### 4.2 训练期特权物理真值

`privileged-truth.jsonl` 单独保存以下信息：

- 数据包编号空间；
- 经审计的确认范围及确认关系；
- 端点报告的丢包事件；
- 往返时延；
- 在途字节；
- 拥塞窗口；
- 对应的观测掩码。

特权真值不得拼接到部署分类输入中，只能用于训练期物理残差、旁路诊断或受控消融。当前数据没有可信的探测超时真值，因此其掩码保持为未观测。

## 8. 使用风险与下一步

- 空窗口占 `116006 / 131513`，物理真值也具有明显稀疏性。下游必须使用掩码，不能把缺失值当作零值。
- 当前输出完整保留时间轴。若先导模型需要只采样活跃窗口，必须在读取任何模型结果前冻结确定性采样规则并生成独立派生视图，不能根据结果事后删除窗口。
- 两份构建合计约 772 MiB。它们分别承担规范输入和复现证据作用，未经明确批准不得删除。
- 下一步可以将 `build-a` 与 ns-3、TQH 的规范先导输入按同一窗口键约定接入 A、A+P、A+P_shuffle、A+P_random 开发集诊断。
