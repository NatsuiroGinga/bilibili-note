# R2 TCP/UDP 物理旁路开发集先导报告

## 结论

TCP/UDP 先导四组对照已经完成 `12/12`，其中既有 `A` 三种子没有重跑，本轮只恢复并完成 `A+P`、`A+P_shuffle`、`A+P_random` 的九组运行。

真实旁路 `A+P` 相对 `A` 的宏平均 F1 在种子 42、43、44 上均提高 `0.007993`，但没有通过归因门槛：种子 42 低于置换旁路，三个种子全部低于随机旁路。三种子均值上，`A+P` 的宏平均 F1 为 `0.850010`，低于 `A+P_random` 的 `0.860462`。因此，本先导**不能证明当前 18 维旁路含有基础字段之外的样本级物理增量检测信号**。

该结果也不能单独否决 R2。它只约束当前 TCP/UDP 小规模开发集、当前状态估计器、四窗口稳态伪序列和当前 HGB 接口；不得外推为正式三源数据、困难分区或大模型结构上的最终结论。

当前状态为 `computed / review_pending / swanlab_upload_pending`。本地计算和制品核验已经完成，独立代码复审与 SwanLab 补传尚未完成。

## 架构调整

失败根因为检测视图和旁路原表同时携带 `split_id`、`transport_family`。旧入口直接按 `sample_id` 连接两表，产生带后缀的重复元数据列，后续无法读取规范列名。

经用户批准，本轮只修改隔离先导入口：

1. 检测视图是 `split_id`、`binary_label`、`source_dataset`、`transport_family` 和基础字段的唯一来源。
2. 旁路加载后先按 `sample_id` 对齐，逐样本断言旁路原 `split_id`、`transport_family` 与检测视图一致。
3. 元数据断言通过后，旁路严格投影为 `sample_id + 18` 维冻结旁路，再执行一对一连接。
4. 正式运行时同时断言旁路 18 维均为有限值、连接后没有缺失、样本顺序不变、连接列精确符合单一来源合同。
5. 每个新运行的 `config.json` 记录 `metadata_source`、`sidecar_metadata_asserted` 和 `sidecar_join_projection`。

## 真实旁路差异

下表为同种子宏平均 F1 的直接差值，正值表示真实旁路更高。

| 种子 | `A+P - A` | `A+P - A+P_shuffle` | `A+P - A+P_random` |
| ---: | ---: | ---: | ---: |
| 42 | +0.007993 | -0.006205 | -0.002364 |
| 43 | +0.007993 | +0.009326 | -0.013720 |
| 44 | +0.007993 | +0.002921 | -0.015270 |
| 三种子均值差 | +0.007993 | +0.002014 | -0.010451 |

均值层面的其他差异如下。良性误报率、Brier 分数和期望校准误差均以更低为优。

| 比较 | 良性误报率差 | Brier 分数差 | 期望校准误差差 |
| --- | ---: | ---: | ---: |
| `A+P - A` | -0.004785 | +0.004743 | -0.013448 |
| `A+P - A+P_shuffle` | +0.002392 | -0.012778 | -0.011674 |
| `A+P - A+P_random` | +0.007177 | -0.002152 | -0.003623 |

结果解释：

- `A+P` 相对 `A` 的宏平均 F1、平衡准确率、良性误报率和期望校准误差方向较好，但 Brier 分数变差。
- `A+P` 相对置换旁路的宏平均 F1 仅在两个种子较高，种子 42 较低；良性误报率均值也高于置换旁路。
- `A+P` 相对随机旁路的宏平均 F1 在三个种子全部较低，三种子均值低 `0.010451`；良性误报率均值也高 `0.007177`。
- 因此，真实样本与旁路向量的对应关系没有显示出稳定、独有的检测收益。不能把 `A+P - A` 的提高归因于物理信息本身。

## 裁决边界

1. 事前门槛要求真实旁路同时优于 `A`、置换和随机对照。本轮未满足，当前接口不得晋级为“已证明有样本级物理增量信号”。
2. `A+P` 相对 `A` 的一致提高只构成“增加 18 维输入后模型结果改变”的证据；随机对照更高，排除了把该提高直接归因于真实物理对应关系的可能。
3. 本轮没有最终测试、没有困难开发分区、没有 QUIC 入模、没有正式三源冻结数据，也没有生成式基座。负结果不能单独否决 R2 研究路线。
4. 不允许依据本结果重采样、改标签比例、挑种子、增加 HGB 容量或调整旁路维数后把同一先导改写成正结果。
5. 在独立复审完成前，本报告只能作为暂定诊断。若复审发现影响结果有效性的严重或重要问题，应按工程规则标记本轮结果无效并停止晋级。
