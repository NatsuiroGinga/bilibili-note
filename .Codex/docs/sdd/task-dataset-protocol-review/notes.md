- 检索在新增文献不再改变分组键、样本身份、字段预算或域外套件时停止。

## 综合备忘

- 随机行级划分不能证明跨会话或跨采集泛化；最外层分组必须在窗口化和增强前冻结。
- 约 8:1:1 只约束域内组级样本量目标；开放集、时间前向、留一 profile 和跨拓扑测试各自保持完整域边界。
- 四类模型共享 `sample_id`、`split_id` 与共同可观测语义字段；模型序列化方式可以不同，但不得增加模型专属原始信息。
- ns-3 只提供物理状态、残差和跨拓扑机制证据；GeNIS 与 TQH-C2 承担真实检测外部效度，二者的指标不得合成一个总分。
- TQH-C2 的实际归档版本、GeNIS 独立运行数量、开放集未知类可行性以及训练内截断参数仍需在数据物化阶段通过 P0 检查。
- 最终裁决、12 项 P0 门禁及最小下一步见 `decision-report.md`。
