# 数据集与统一基线协议筛选表

## 分类规则

- **核心**：逐篇提取到证据表，直接影响至少一个协议裁决。
- **数据契约**：不是论文核心计数，但直接约束数据版本、标签、采集单元或文件关系。
- **补充**：用于背景或交叉核验，不单独决定协议。
- **排除**：没有全文、无法核验或不再增加协议信息。本轮没有必须列入缺失清单的关键材料。

## 排除与不可比关系

- 未纳入只给摘要或二手转述的候选；二手材料不支撑技术细节。
- 未把 NetMamba 与 QuASI 扩大为核心，因为新增它们不会改变协议字段或分组边界。
- 未把不同论文在不同数据集上的准确率或 F1 数值直接排序；这些数值的样本单位、标签空间、切分和输入均不可比。
- 未建议新增 CIC、UNSW、CTU 等第四个实验数据集；跨源压力测试只使用 GeNIS 与 TQH-C2，物理机制测试只使用 ns-3。
