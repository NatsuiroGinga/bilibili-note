# 数据集与统一基线协议证据表

## 证据使用规则

- 页码均指 PDF 文件页码，不以论文印刷页码代替。
- “原文证据”只记录作者直接报告的事实；“本项目裁决”是基于证据作出的协议选择。
- **强**表示全文或官方说明直接支撑；**中**表示原文支撑原则，但具体落地细节是本项目推导；任何单篇论文的性能数值都不用于跨论文排序。

## 跨证据综合

### 一致证据

1. **随机行级或逐包切分不足以证明泛化。** C01/C02 记录常见做法，C03/C04 揭示流标识和近重复泄漏，C05 给出先分会话后窗口化的正例。
2. **身份字段应参与分组但不参与预测。** C03、C06、C07 与 C09 均显示 IP、端口、报文头或流生成配置可能成为捷径；本项目保留其审计作用，删除其模型可见性。
3. **域外测试必须是独立轴。** C08 区分训练已知与测试未知，C09/C10 区分来源网络，D01 提供加密条件轴；这些测试不能混回同域随机测试。
4. **物理机制与真实检测承担不同证据角色。** C11 证明残差和守恒需要状态/边界数据，C12 证明仿真和物理测试床互补；两者均不支持用 ns-3 取代 GeNIS/TQH-C2 的检测外部效度。

### 冲突与裁决

| 冲突                                                | 裁决                                                                                       |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| C01/C02 使用随机打乱，C03–C05 反对跨流/会话泄漏     | 以更严格的父组边界为准；随机性只用于组级分配后的训练顺序。                                 |
| C06/C07 的模型输入处理不同                          | 统一到共同语义观测：方向、包长、相对到达间隔、突发和掩码；不比较谁获得更多原始标识或载荷。 |
| 约 8:1:1 与完整留一加密配置、跨拓扑测试无法同时满足 | 8:1:1 仅描述同域组级开发边界；完整条件留出是额外域外套件，不计入该比例。                   |
| PINN 需要物理真值，真实 PCAP 缺少完整队列状态       | 只在 ns-3 训练/诊断标准 PINN；真实 PCAP 只输入共同检测观测，物理真值列在推理时强制不可见。 |

## 尚未被文献直接解决的项目细节

- 统一 `sample_id` 的精确哈希字段、TQH-C2 28/4/4 单元分配和 GeNIS 的攻击步骤/时间块优先级是本项目工程裁决，需要物化后做清单互斥与哈希验证。
- `U_val` 与 `U_test` 的具体原生子类型必须在标签盘点后预注册；文献只支持隔离原则，不替代数据可行性检查。
- 同一语义信息预算并不意味着树模型、DistilBERT 与 Qwen 的分词数、参数量或算力相同；需要分别报告训练成本、推理延迟与调参预算。
