# 数据集与统一基线协议文献审查计划

## 目标

以 8 至 12 篇可读核心全文为证据，形成可直接用于冻结 GeNIS 2025、TQH-C2 2026 与 ns-3 数据处理和统一基线协议的决策报告；不启动实验、不修改实验代码、不改动两份恢复文档。

## 任务边界

- 数据源固定为 GeNIS 2025、TQH-C2 2026 与 ns-3，不建议增加第四个数据集。
- 优先年份为 2020 至 2026；只为数据泄漏、流量表示或 PINN 实验设计的奠基证据纳入更早论文。
- 核心证据必须来自可读全文或官方材料，并记录页码、章节、表格或公式位置。
- 无全文材料只进入缺失清单，不支撑强结论。
- 不把不同论文在不同数据集上的数值直接横向比较。

## 六阶段

- [x] 阶段一：定义研究问题、范围、纳入排除标准、全文门槛与停止条件。
- [x] 阶段二：检索本地论文库、官方来源与公开全文，核验身份并去重。
- [x] 阶段三：按相关性、来源质量、全文可得性和实验可比性筛选分类。
- [x] 阶段四：逐篇全文提取数据、样本单位、划分、预处理、输入视图、泄漏风险、指标和跨域设计。
- [x] 阶段五：综合一致证据、冲突、不可比关系、研究空白与最小验证动作。
- [x] 阶段六：生成综述、决策报告、参考文献、论文笔记和索引更新，并完成格式与链接核验。

## 关键问题

1. 哪一层实体应成为不可拆分分组：会话、双向流、主机、时间块、采集单元还是仿真场景组？
2. PCAP 如何稳定派生流、突发和包序列，同时避免标签、文件名、采集配置与流量方向泄漏？
3. 约 8:1:1 的三级边界如何兼容时间前向、开放集、加密条件留出和跨拓扑测试？
4. 树模型、DistilBERT、Qwen 与标准 PINN 如何由同一 `sample_id` 主记录派生模型视图，并共享公平信息预算？
5. ns-3 仿真真值与 GeNIS、TQH-C2 真实检测数据应如何分工，避免把仿真物理指标替代公开数据检测结果？

## 已作决策

- “约 8:1:1”是三级数据边界的目标比例，不允许为凑精确比例拆分会话、采集单元、时间块或场景组。
- 最终测试边界先冻结；训练域内部再形成训练与验证，测试集不参与调参、阈值选择、选种或标签映射修订。
- 同一 `sample_id` 主记录是跨模型公平比较的唯一抽样入口，不允许各模型独立重采样。
