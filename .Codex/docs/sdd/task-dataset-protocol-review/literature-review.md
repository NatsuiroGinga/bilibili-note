# GeNIS、TQH-C2 与 ns-3 数据协议系统文献审查

## 结论

12 篇核心全文与 TQH-C2 官方数据契约形成了稳定共识：**划分边界必须先于窗口化、突发化、缩放和采样；最小不可拆分实体不是表格行或单包，而是能阻断同源信息的父会话、采集单元、时间块或仿真运行。** 所有检测模型应从同一 `sample_id` 主清单派生语义等价视图。约 8:1:1 只适用于同域组级开发边界；开放集、时间前向、留一加密条件、跨数据源和跨拓扑必须是额外冻结的域外套件。ns-3 负责物理状态与残差监督，GeNIS 和 TQH-C2 负责真实检测外部效度，两类指标不能互相替代。

## 审查方法

本轮按研究问题定义、检索、筛选、全文提取、综合和交付六阶段执行。优先检索 2020–2026 年材料，只为开放集奠基证据纳入 2017 年论文。核心论文必须有可读全文与页码锚点；官方数据说明可作为数据契约，但不计入 12 篇论文。候选材料在本地论文库、Zotero、出版社、会议、arXiv、Zenodo 与作者机构页面间按题名和 DOI 去重。

最终纳入 12 篇核心论文，另纳入 TQH-C2 官方 README 作为数据契约。六份新 PDF 均通过页数、文本提取与 SHA-256 检查，其余全文复用仓库已有原件。检索式、下载哈希、筛选理由和逐篇证据分别见 `search-log.md`、`screening-table.md` 与 `evidence-table.md`。没有关键全文缺失。

## 主题一：随机行级切分为何不足

GeNIS 官方预处理目录把所有场景流合并后打乱、分层为训练集与留出集 [@Silva2025GeNIS]。HIKARI-2021 评估也在全数据特征检验后随机打乱并按 80:20 划分 [@Fernandes2022HIKARI]。这两篇论文准确记录了常见基线，但都没有证明原始捕获、会话、攻击运行或时间被隔离。

后续证据明确展示这种做法的风险。Sweet Danger 证明逐包切分会让同一流的显式五元组和隐式 TCP 序列号、确认号、时间戳同时出现在训练与测试，模型可直接记住流身份 [@Zhao2025SweetDanger]。Bad Design Smells 进一步显示，常用 NIDS 数据含大量近重复流、低多样性、标签依赖特征和错误标签；同一脚本攻击的随机切分会形成虚假的泛化 [@Flood2024BadSmells]。FlowPic 给出正面处理顺序：完整会话先分到训练或测试，再生成带重叠的 60 秒窗口和增强样本，确保同源片段不跨边界 [@Shapira2021FlowPic]。

因此，本项目不能把行数当作独立样本数，也不能为凑精确比例拆开父组。GeNIS 的同一原始捕获、攻击步骤、会话谱系和重叠时间窗必须绑定；TQH-C2 的完整 cell 是最外层组；ns-3 的完整随机种子运行和场景组是最外层组。组级比例偏离 8:1:1 时应报告实际比例，而不是牺牲隔离性。

## 主题二：PCAP 到共同观测的处理边界

ET-BERT 以五元组会话为基础，把同一会话中连续同向报文组成突发 [@Lin2022ETBERT]。YaTC 同时建模包级和流级结构，并在推理前去以太网头、端口归零及替换 IP [@Zhao2023YaTC]。FlowPic 则用包长与到达时间构造流量图 [@Shapira2021FlowPic]。三者共同说明：加密流量仍保留方向、包长、相对时间、突发和顺序结构，地址、端口及链路层身份并非表征的必要条件。

这些论文的具体输入并不完全一致。ET-BERT 使用字节词元，YaTC 对 IP 做随机替换，FlowPic 使用二维聚合。Sweet Danger 又表明，报文头和数据准备差异可能给复杂模型额外捷径 [@Zhao2025SweetDanger]。因此，不能让每个模型沿用原论文私有预处理后直接比较。本项目应先生成一个模型无关的主记录，再派生数值展平、文本序列或 PINN 状态视图。

共同检测观测应限定为可在三类来源一致定义的语义：规范双向方向、网络层包长、相对到达间隔、可见传输协议、必要的 TCP 标志、突发边界及掩码。地址、绝对端口、MAC、绝对时间、文件名、数据源、cell 名称和标签只用于分组、连接与审计。原始载荷字节不进入共同预算。树模型可以使用同一序列的展平值和训练内派生统计，DistilBERT 与 Qwen 使用同一字段的确定性序列化；分词器不同导致的词元数差异不属于额外信息。

## 主题三：开放集与跨域不是普通测试集的别名

开放集入侵识别要求测试阶段出现训练未见的原生类别，并允许模型输出未知 [@Cruz2017OpenSet]。这意味着最终未知子类型不能仅在输出层临时改名，必须在切分前从训练与验证完全删除。为避免阈值使用最终测试标签，本项目还需要一个与最终未知集合不相交的验证伪未知集合；这是基于开放集原则作出的工程扩展，不是原论文直接规定。

XeNIDS 将跨网络评价分解为来源网络、目标网络、环境、时间和流生成配置，并只在共同 NetFlow 字段上交叉评价 [@Apruzzese2022XeNIDS]。Cantone 等人的同研究比较显示，数据集内随机切分可接近完美，而整数据集跨网络时平均性能大幅下降 [@Cantone2024CrossDataset]。其数值不能移植到本项目，但“域内高分不等于域外泛化”的方向结论明确。

TQH-C2 官方说明进一步提供天然域轴：36 个独立 cell 由三种加密配置、四种信标间隔和三种抖动组成；官方用途就是跨加密配置与时序条件评价 [@Jeon2026TQHC2]。因此，TQH-C2 应同时有组级同域边界和三折留一加密配置测试。GeNIS 应有时间前向与未知子类型套件。ns-3 应有固定星型同域边界及哑铃、停车场等跨拓扑外部测试。GeNIS↔TQH-C2 只在共同字段和二元标签交集上做压力测试，不强行建立完整家族一一映射。

## 主题四：公平比较是语义预算相同，不是模型形状相同

Sweet Danger 在相同切分上比较深层与浅层模型，并显示简单模型可以揭示深层表征是否真的增加可迁移信息 [@Zhao2025SweetDanger]。XeNIDS 也要求跨来源使用共同字段 [@Apruzzese2022XeNIDS]。由此可得，本项目的公平性最低要求包括：相同 `sample_id`、相同训练/验证/测试清单、相同原始可观察字段、相同训练内拟合边界、相同标签层级和相同调参次数。

公平不意味着模型参数量、词元数、训练时间或序列化形式相同。树模型需要数值展平，语言模型需要文本或词元序列，PINN 需要损失中的状态与方程位置。只要新增列不能给某个检测器额外部署时信息，编码差异可以存在，但必须报告参数量、训练时长、显存、推理吞吐和延迟。最终测试不得因模型成本不同而独立采样。

## 主题五：PINN、ns-3 与真实 PCAP 的证据分工

交通网络 PINN 同时优化观测误差、PDE 残差、交叉口守恒和连续性，但其数据来自 VISSIM，并且模拟聚合数据本身也可能违反理论守恒 [@Usama2022TrafficPINN]。这说明 PINN 需要把观测、状态、物理系数、残差点和边界条件显式分栏，也说明“模拟数据”不等于无误差真理。

PRED 不是 PINN，但它以 DCTCP/RED 显式队列模型为核心，同时使用 ns-3 大规模仿真和物理 Tofino 测试床验证 [@Du2025PRED]。其方法论价值是仿真与真实测试互补：仿真提供可控状态和广覆盖，物理测试提供实现与外部效度。PRED 的 DCTCP/ECN 假设不能外推到所有互联网流量。

本项目据此限定：标准 PINN 只在 ns-3 域接受状态目标、物理系数和残差监督；这些列在推理和真实 PCAP 上必须不可见。GeNIS 与 TQH-C2 只提供共同检测观测和标签，不被假定拥有队列容量、占用或控制方程真值。PINN 的状态误差和残差只与无物理残差的匹配状态监督对照比较；真实检测宏平均 F1、误报率和未知召回另行报告。

## 冲突、不可比关系与研究空白

### 已裁决冲突

- **随机分层与父组隔离冲突**：选择父组隔离，随机性只用于组分配后的训练顺序。
- **模型私有输入与公平预算冲突**：选择共同语义主记录，私有编码只能是确定性派生。
- **8:1:1 与完整条件留出冲突**：8:1:1 只用于同域边界；条件留出是额外测试套件。
- **PINN 状态需求与真实 PCAP 不可观测冲突**：状态监督只来自 ns-3，真实 PCAP 不补造物理真值。

### 不可比关系

- 12 篇论文的任务、类别、样本单位、切分和输入不同，论文数值不能直接横向排名。
- GeNIS、TQH-C2 和 ns-3 的原生标签与物理含义不同，不合并为一个微平均总分。
- 结构化输出有效率只适用于生成式模型，应单列而非给树模型记零分。

### 仍需最小物化验证

1. GeNIS 每个原生子类型的独立捕获/攻击运行数是否足以同时形成已知类时间测试、`U_val` 与 `U_test`。
2. TQH-C2 36 个 cell 的完整标签连接率、版本 1.0.1 归档哈希及确定性 28/4/4 组分配结果。
3. 三个来源的网络层包长、时间单位、方向和协议字段能否通过同一语义测试。
4. 组间近重复哈希、同源窗口、流谱系和标签映射是否为零交叉。
5. ns-3 真值字段在检测输入路径中是否被结构性阻断，而不是只依赖配置约定。

## 最终回答

文献支持冻结一个“主清单先行、组级边界优先、域外套件分离、物理真值分域”的协议。它不支持直接采用 GeNIS 官方随机留出、不支持逐包或窗口后切分、不支持不同模型各自采样，也不支持把 ns-3 物理指标当作真实数据检测证据。只要下一步物化验证通过，无需增加第四数据集即可形成可审查的统一基线。
