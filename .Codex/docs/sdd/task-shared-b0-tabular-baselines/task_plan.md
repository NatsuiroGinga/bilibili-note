在不修改已发布共享 B0 制品的前提下，安全组合公共数值特征与独立标签视图，启动同一训练清单上的 HGB 和 XGBoost 基线。

## 关键问题

1. 如何保证标签只作为监督目标，不进入 HGB/XGBoost 特征矩阵？
2. 如何证明训练和两个验证视图都保持冻结 `sample_id` 顺序？
3. 如何复用现有树模型评价、成本和 SwanLab 记录，而不复制模型逻辑？

## 已定决策

- 不修改或重建 `dataset-v1-shared-b0`。
- 从 `common_features.parquet` 读取特征，从相应 `bert_*.parquet` 只读取 `sample_id`、`stable_order` 和 `label`。
- 两个视图的样本标识与稳定顺序必须逐行完全一致，否则在训练前失败。
- 正式结果继续标记为 `theory_selection/review_pending`。
