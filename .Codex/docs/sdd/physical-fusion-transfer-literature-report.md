# 物理表征显式融合、共享/私有空间与仿真到真实文献报告

## 任务边界

本报告只处理三个问题：

1. 物理状态或潜在动力学是否真正进入 Transformer、生成器或任务策略的前向路径。
2. 共享/私有空间如何减少负迁移，以及专用分支是否仍影响主任务输出。
3. 仿真监督如何在真实域缺少物理标签时使用，以及物理状态是否可辨识。

未运行 GPU 实验，未修改总控、任务十六过程文档或 `wiki/papers/manifold/INDEX.md`，也未执行 Git 写操作。

## 核验协议

- 正式纳入 10 篇：物理/潜在动力学显式融合 4 篇，共享/私有与负迁移 3 篇，仿真到真实与可辨识 3 篇。
- 每篇均从 DOI、出版社、会议论文集、OpenReview 或 arXiv 原始页面核对题名、作者、年份和标识符。
- 每篇均下载原始 PDF 到 `raw/papers/manifold/`，用 `pdfinfo` 检查页数，以 `pdftotext` 逐页定位公式、表格和局限，并视觉复核 9 个关键架构或实验页。
- PITT 为 43 页，REPA-P 为 23 页。按 PDF 转换技能尝试对 PITT 使用高保真 `mineru-open-api extract`，但本机未配置 API 令牌，命令明确返回认证缺失；随后按规则回退到本地逐页解析和原 PDF 图像核验。MinerU 输出未写入知识库。
- 严格前向依赖定义为：模型预测物理状态 $\hat q$ 被主任务函数消费，即 $\hat y=f(x,\hat q)$ 且结构上 $\partial\hat y/\partial\hat q\neq0$。训练梯度能影响共享参数不等于满足该条件。

## 核心裁决

### 1. 物理辅助损失不等于物理状态耦合

REPA-P 可通过中间层物理残差改变主干参数，但投影头推理时删除，所以部署输出不依赖投影物理场。DSN 的私有表示参与重构却不进入分类头，给出相同反例。若第三章只增加队列状态预测损失、正交损失或中间残差，却仍令生成器只读取原文本表示，则不能写成“物理状态进入生成决策”。

### 2. 最小可靠结构是“先预测，再显式消费”

PhyDNet、NewtonianVAE 与 UP-OSI 的共同结构是：

$$
\hat q=g_\phi(x),
\qquad
\hat y=f_\theta(x,\hat q).
$$

三者分别采用加法解码、动力学转移后解码和条件策略。它们跨视频生成、潜变量生成与控制任务给出一致结构证据。第三章应先验证简单拼接、加法或门控，而不是先引入复杂流形优化。

### 3. 共享/私有分解必须保留任务前向路径

对抗式多任务文本分类将共享与私有表示拼接后分类，满足专用表示到输出的前向依赖；DSN 只让私有表示重构输入，不满足。因而“物理专用分支”只有在最终任务头消费它时才是候选机制。软正交或去相关可帮助分离，但现有论文没有证明它在物理状态融合中必然增益。

### 4. 负迁移先诊断，不应先复制大模型主干

Recon 表明梯度冲突可能集中在少数共享层，但其任务专用化带来的参数增加范围为 0.52% 至 57.25%（PDF 第 7 页），并不总是轻量。对 Qwen3-1.7B，更可控的顺序是先测生成损失与物理状态损失在状态投影头、适配层和主干各层的梯度余弦，再决定是否隔离小型分支；没有证据支持第一步复制 Transformer 层。

### 5. 仿真到真实与状态可辨识是两个不同问题

动力学随机化论文提供实际真实机器人迁移，说明训练时覆盖时延、观测噪声、质量和摩擦等变化很重要；但其循环隐变量没有物理语义。UP-OSI 有显式可解释参数条件，却只在仿真验证。BayesSim 允许多模态参数后验，提醒不同物理参数可能产生相似观测，但部署策略不直接消费后验，且机器人任务仍是模拟。不存在一篇纳入论文同时完整证明“可解释状态、严格前向依赖、无需真实标签、真实域迁移”四项条件。

## 实验接口建议

### 必测前向依赖

不能只报告物理状态均方误差。至少同时报告：

- $\|\partial \ell_{\mathrm{task}}/\partial\hat q\|$ 或生成输出相对 $\hat q$ 的梯度范数。
- 将 $\hat q$ 置零、跨样本置换、替换为真值状态时的主任务指标变化。
- 门控权重的分布及其与场景强度、队列占用或丢包状态的关系。
- 物理头状态误差与主任务增益的相关性，防止状态预测准确但主干完全忽略它。

### 必做结构消融

1. 原始基座。
2. 仅物理状态辅助损失，不把 $\hat q$ 输入生成器。
3. 预测状态显式输入生成器，不加正交或流形约束。
4. 在第 3 项上增加共享/私有去相关或候选流形约束。
5. 真值状态上界、预测状态、置换状态和零状态对照。

该顺序可以区分“多一个训练信号”“状态真正进入决策”和“流形/正交约束带来额外增量”。

### 仿真到真实数据协议

- ns-3 除攻击强度外，应随机化链路容量、队列策略、时间窗、测量噪声、延迟、丢包和流量混合比例。
- 公开数据推理阶段不得使用物理状态标签；只能由可获得的窗口字段或历史预测 $\hat q$。
- 对不可辨识状态，报告置信区间、后验或等价参数组，不把单点误差低直接写成“恢复了真实物理状态”。
- 仿真监督、真实无标签校准和公开数据主性能应分开报告，避免 BayesSim 式“目标模拟器实例”被误写成物理真实域。

## 下一步结构候选

以下候选按现有证据强弱排序，同一时间只应验证一个新增变量。

1. **B0：预测队列状态的简单门控融合。** 令 $\hat q=g_\phi(x)$，再以拼接、加法或单门控令 $\hat y=f_\theta(x,\hat q)$。该结构满足严格前向依赖，证据来自 PhyDNet、NewtonianVAE 和 UP-OSI；它不自动解决仿真到真实，需配合公开数据无标签推理和仿真随机化验证。
2. **B1：共享文本表示 + 物理专用分支 + 显式融合任务头。** 最终任务头必须同时消费共享表示和 $\hat q$，再按梯度冲突诊断决定是否加入软去相关。该结构在正确接入任务头时满足严格前向依赖，证据来自 PhyDNet 与对抗式多任务文本分类；DSN 和 Recon 只支持分离/诊断，不能单独证明增益。
3. **B2：训练期中间物理表征辅助 + 仿真分布适配。** REPA-P 式中间残差、BayesSim 式后验校准和动力学随机化可作为 B0/B1 的外层训练辅助。其中 REPA-P 与 BayesSim **不满足严格前向依赖**，不能独立命名为显式物理耦合；动力学随机化是本组唯一有真实硬件迁移实证的机制，但其隐状态不可解释。该候选主要解决训练约束与仿真到真实，不应先于 B0 验证。

**推荐先做 B0。** 它是唯一能用最小改动直接回答“预测物理状态是否改变主任务输出”的候选，也是后续判断共享/私有分解、流形约束和仿真分布适配是否有额外价值的必要基线。

## 二选一冻结裁决

**当前选择共享/私有动力学耦合，不把隐式环境参数辨识设为第三章必选机制。** 更准确地说，先冻结为“共享文本主干 + 可监督队列状态分支 + 主任务显式消费预测状态”；只有检测到物理任务与主任务梯度持续冲突时，才增加轻量共享/私有去相关。UP-OSI 支持显式参数条件化的结构，但只有仿真实证；动力学随机化有真实迁移证据，却没有可解释状态；BayesSim 处理不可辨识后验，但不满足主输出严格前向依赖。现有证据不足以要求第三章同时承担环境参数隐式辨识。

### 最小可证伪实验

固定同一数据、种子、训练预算和 Qwen3-1.7B 基座，只比较三组：

1. 原始基座。
2. 队列状态辅助预测，但生成器不读取 $\hat q$。
3. 相同状态头，生成器通过单门控读取 $\hat q$。

若第 3 组相对第 2 组在至少两个随机种子上没有稳定主任务增益，或置零/置换 $\hat q$ 后主任务指标不变，同时 $\|\partial\ell_{\mathrm{task}}/\partial\hat q\|$ 接近零，则“显式队列状态耦合”被当前实验否证，不应继续叠加正交、流形或隐式辨识模块。若第 3 组在 ns-3 有效、公开数据显著退化，再单独启动“仿真随机化或环境参数辨识”分支，用以判断跨域失败而不是融合失败。

### 当前不再继续的方向

- 不再扩展通用物理人工智能或机器人候选文献，当前 10 篇已满足范围配额。
- 不以 REPA-P 式训练期投影头单独命名“显式物理耦合”。
- 不在 B0 通过前加入 BayesSim 后验、隐式环境参数辨识或 95 维式大范围随机化。
- 不因 Recon 结果直接复制 Qwen 主干层；先测梯度冲突，再决定是否隔离小型分支。
