## 5. 配置与机制差异核验

S1 与 S2 的 `config_snapshot.yaml` 精确比较只有三处差异：

1. `tracking.run_name`：分别指向 S1 与 S2。
2. `training.output_dir`：分别指向各自独立输出目录。
3. `training.variant`：S1 为 `M1`，S2 为 `M2`。

前两项是制品隔离所需差异，第三项正是 G0 与 G1 要比较的唯一机制差异。其余训练、数据、模型和评价设置一致。

训练实现中的 `build_variant_contract` 规定：

- `M1` 的 `uses_state=true`、`uses_physics=false`。
- `M2` 的 `uses_state=true`、`uses_physics=true`。
- 只有 `uses_physics=true` 时才构造物理损失并把 `lambda_physics * physics_loss` 加入更新目标。

逐步指标与该实现一致：S1 的 202 步物理损失均为零，S2 的 202 步物理损失均非零。
