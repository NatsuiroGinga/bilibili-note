## 3. 现在可运行的 TQH 单源子矩阵

现有 `flow-probe-tabular-baselines` 已在本地与服务器保持同一代码哈希，并且只能选择 `hgb` 或 `xgboost`。它能够直接读取当前 TQH 候选的 `tree_flat_view`、训练清单和验证清单。

最小运行参数为：

```bash
source ~/.bashrc
cd /root/autodl-tmp/thesis/experiments/llm_probe

uv run --no-sync flow-probe-tabular-baselines \
  --protocol-dir runs/data-frozen/dataset-candidate-tqhc2-abc-v0/protocol \
  --stage theory_selection \
  --expected-protocol-version data-protocol-v1.0-rc1 \
  --tuning-trial-index 0 \
  --train-manifest splits/tqhc2_cell_indomain-train.jsonl \
  --evaluation validation=splits/tqhc2_cell_indomain-validation.jsonl \
  --label-field binary_label \
  --model hgb \
  --model xgboost \
  --output-dir runs/baselines/theory-selection/tqhc2-abc-indomain/<唯一运行目录> \
  --seed 42 \
  --run-name tqhc2-abc-indomain-public-default-seed42
```

这只是 TQH 单源、二分类、域内验证子矩阵，不等于合同中的完整 B0。若按合同要求三随机种子，应使用互不复用的种子 42、43、44 输出目录；不得把同一输出目录覆盖重跑。
