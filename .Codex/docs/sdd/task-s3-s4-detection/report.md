# S3/S4 同协议正式检测验证报告

## 1. 结论

S3/S4 同协议正式检测验证已完成，**S4 未通过预注册总门槛，不能冻结为第一创新点的最终算法**。

S4 的有限队列物理一致性确实提供了机制和开放集收益：未观测状态误差改善 `70.17%`，物理残差改善 `55.44%`，三个未知攻击场景的候选评分召回均值从 `0.3756` 提升到 `0.7567`，良性误报率均值从 `0.2433` 降到 `0.0911`。但是，主指标中的攻击家族自由生成宏平均 F1 从 `0.9292` 降至 `0.8410`，点差 `-0.0882`，明显越过预注册的 `-0.01` 非劣门槛；子类测试期望校准误差也恶化 `0.0826`，超过 `0.02` 门槛。

该负结论只否定**当前固定权重、共享适配器的 S4 联合训练实现**，不否定双锚点边界约束和有限队列守恒本身存在物理机制信息。但在现有预注册协议下，机制收益没有转化为全任务一致的检测收益，因此不得把 S4 包装成已验证的论文创新算法，也不得直接进入原任务十九的三随机种子和跨基座扩展。

## 2. 同协议审计

- S3 训练变体为 M1：双锚点稀疏状态监督，不加入物理损失。
- S4 训练变体为 M2：双锚点稀疏状态监督，加入有限队列物理一致性。
- 两组均使用 Qwen3-1.7B、随机种子 42、202 步、`anchor0_plus_one`、`lambda_state=1.0`、`lambda_physics=0.01`、相同 15,000 条生成训练样本和 807 条 ns-3 物理训练样本。
- 两组 `input_sha256.json`、`physics_sample_order.json` 和状态掩码 SHA-256 完全一致；配置差异仅为输出路径、运行名和 M1/M2 变体。
- 两次评估均使用相同 GeNIS 分层样本、每类 300 条、相同自由生成与候选评分实现、相同随机种子和只由 `subtype_validation` 校准的未知拒识阈值。
- `selected_samples_manifest.json` 完全一致；后处理逐行核对 `sample_id` 与真实标签，30 个输入文件 SHA-256 全部通过。
