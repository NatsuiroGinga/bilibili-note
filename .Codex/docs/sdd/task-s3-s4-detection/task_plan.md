# S3/S4 同协议正式检测验证实施计划

> **执行要求**：按 `writing-plans` 与 `subagent-driven-development` 约束执行；本任务禁止使用测试驱动开发。先启动实验，不等待非关键审查。

**目标**：在不改变理论、结构、超参数和数据协议的条件下，对 S3（双锚点无物理）与 S4（双锚点加有限队列物理一致性）完成唯一一次同协议正式检测验证，并据结果冻结第一创新点算法或否定结论。

**实现原则**：优先复用既有 S3/S4 训练适配器与冻结制品；只有现有评估入口不能消费物理训练适配器时，才补充最小评估连接代码。两组必须共享数据划分、初始化、样本顺序、训练预算、解码、阈值校准和评价实现。

**技术环境**：Qwen3-1.7B、QLoRA、PyTorch、Transformers、uv、SwanLab、RTX 5090。

## 全局约束

- 只比较 S3 与 S4，不新增理论、方法变体或超参数搜索。

- 正式输出必须包含域内宏平均 F1、各类召回、未知攻击召回、良性误报率、已知类拒识率、校准指标、状态误差、物理残差、训练和推理耗时、吞吐量及峰值显存。
- 每组必须保存配置快照、输入哈希、逐步日志、结构化摘要、预测、制品清单与 SwanLab 在线记录。

- 本地与服务器仅使用 `rsync` 白名单增量同步，不同步环境、数据、模型或既有运行目录。

## 预注册裁决门槛

- 主指标采用自由生成的 `family_test` 与 `subtype_test` 宏平均 F1；两项 `S4-S3` 点差均须不低于 `-0.01`。
- S3 与 S4 的结构化输出合法率均须不低于 `0.95`。
- 开放集采用候选完成评分：三个未知攻击场景的未知召回率均值差须不低于 `-0.05`，三个未知攻击场景的良性误报率均值增量须不高于 `0.02`，`subtype_test` 已知样本拒识率增量须不高于 `0.02`。
- 只在真值属于候选类的 `family_test`、`subtype_validation` 和 `subtype_test` 计算期望校准误差、Brier 分数和负对数似然；S4 的 `subtype_test` 期望校准误差增量须不高于 `0.02`。未知攻击场景不伪造多分类校准指标。
- 候选评分的域内宏平均 F1 作为重要次指标完整报告，但不替代自由生成主指标。
- 机制门槛沿用既有定义：S4 相对 S3 的未观测状态误差和物理残差均至少改善 `10%`。
- 对同一样本的 S4-S3 差异执行配对自助法并报告 95% 置信区间，供论文使用；本轮是否通过仅依据上述预注册点估计门槛，不事后改变标准。

### 统计口径

- 期望校准误差固定使用 `15` 个 `[0,1]` 等宽置信度箱，按各箱样本占比加权箱内准确率与平均置信度之差的绝对值；置信度采用候选概率最大值。
- Brier 分数固定为每个样本对全部候选标签的平方概率误差之和再取均值；负对数似然固定为真实候选标签概率的负对数均值，概率下限为 `1e-12`。
- 配对自助法固定使用随机种子 `42`、`2,000` 次重复，并在真实标签内分层有放回抽样；每次对 S3 与 S4 使用完全相同的样本索引。
- 自由生成对 `family_test`、`subtype_test` 计算宏平均 F1 点差置信区间；候选评分对上述两个域内分区及三个未知攻击分区计算宏平均 F1、未知攻击召回、良性误报率和已知类拒识率点差置信区间。
