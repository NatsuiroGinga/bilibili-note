# 研究问题

PCAP 提供的包级、流级、双向时序和协议观测，能否让物理信息神经网络学习对加密恶意流量检测有用、可验证且可微的网络动力学状态，并通过明确的结构接口进入 Qwen3-1.7B 的生成检测前向？

## 研究边界

- **对象**：同一个生成式大模型的恶意流量检测方法。
- **数据**：GeNIS 提供公开检测主证据，TQH-C2 提供跨加密协议与节奏条件，ns-3 提供不可直接观测的物理状态真值；PCAP 只提供网络观测，不自动等同物理真值。
- **方法**：比较有限队列、流体动力学、网络演算、TCP/QUIC 动力学、时序点过程和多尺度控制体，不把有限队列设为唯一答案。
- **证据**：优先 2019 至 2026 年原始论文；奠基理论可向前追溯。
- **排除**：无方程或可微残差的“物理启发”命名、纯特征工程、只由输入计算且对模型参数梯度为零的统计惩罚。

## 当前事实

1. 现有有限队列物理残差在稀疏状态监督下可明显降低未观测状态误差，但与生成目标存在稳定梯度冲突。
2. 公开五字段的四窗口状态辨识相对常数基线只改善约 3%，说明当前观测信息不足或状态设定不可辨识。
3. TQH-C2 标签日志具备连接级包数、字节数、持续时间、速率和协议信息；包长序列、方向序列、到达间隔、突发结构及部分 TCP/QUIC 细节可能需要 PCAP。
4. PCAP 无法直接给出交换机内部队列长度、链路容量利用、入队前与出队后丢弃等真值；这些仍需 ns-3、可控测试床或额外遥测。

## 待检验假设

### 主假设

由 PCAP 提取的有方向包长、到达间隔、突发段和协议状态序列，可提高物理潜状态的可辨识性；当这些状态参与可微动力学残差并通过有界条件接口进入生成表征时，完整模型相对同输入监督基线可在加密条件留出上保持检测非劣，并稳定改善物理状态或残差。

### 竞争解释

1. 性能提升只来自更丰富的 PCAP 特征，而不是物理残差。
2. 公开 PCAP 仍不足以辨识内部队列或传输状态，物理头学习的是数据集特有统计捷径。
3. TCP 与 QUIC 的协议异质性使统一动力学残差失配，跨协议条件留出反而恶化。
4. 物理任务梯度继续损害生成检测边界，新增观测不能解决目标冲突。

## 支持标准

1. 在相同 PCAP 字段、相同划分和相同训练预算下，完整 PINN 相对“同状态监督但无物理残差”基线，三个种子的未观测状态误差和物理残差均改善至少 10%。
2. 在 TQH-C2 完整采集单元留出中，检测指标相对同输入普通监督 Qwen 不显著退化，并至少在跨加密协议、长间隔或高抖动条件之一形成有置信区间支持的收益。
3. 残差对参与生成前向的预测状态或可训练参数具有非零梯度；移除残差或打乱物理时序后收益消失。
4. 仅增加 PCAP 字段的监督基线不能解释全部收益。

## 否决标准

1. PCAP 新增字段仍不能使目标物理状态相对常数或简单统计基线改善 10%。
2. 低物理残差伴随更高状态误差，或残差可由常数、复制输入或协议标签捷径最小化。
3. 完整模型在三个种子中任两个违反检测非劣、校准或开放集门槛。
4. 跨 TLS、QUIC 与应用层加密时必须使用互不兼容的标签或场景信息才能成立。
5. 资源成本超出现有 5090 可承受范围，且不能通过离线 PCAP 特征提取与短序列输入控制。

## 最小下一步

完成全文证据筛选后，只实现首选路线的离线字段提取和可辨识性探针；先比较公共五字段、PCAP 时序字段以及状态监督但无物理残差三种条件。可辨识性门槛失败则不进入 Qwen 正式训练。
