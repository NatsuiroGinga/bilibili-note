# PINN 与 PCAP 技术路线文献调研计划

## 目标

在不预设有限队列为唯一物理模型的前提下，基于可核验全文证据比较 PCAP 与物理信息神经网络结合的技术路线，形成一个可在现有 RTX 5090、Qwen3-1.7B、GeNIS、TQH-C2 和 ns-3 条件下执行的首选方案，以及不超过两个实质不同的备选方案。

## 比较路线

1. 有限队列控制体守恒。
2. 宏观或流体流量动力学。
3. 网络演算与容量、时延、突发边界。
4. TCP、QUIC 传输协议动力学。
5. 包到达时序点过程与自激、更新过程约束。
6. 多尺度控制体守恒及其他有可靠理论来源的网络动力学。

## 验收门槛

- 候选文献 15 至 25 篇，核心全文 8 至 12 篇；不足时扩展一次引用链并如实报告。
- 每条首选或备选路线必须给出：PCAP 必要性、字段、状态、方程、边界、可微计算图、数据分工、最小实验、通过与否决门槛、成本。
- 关键论断必须回到全文章节、页码、公式、图或表；仅摘要证据不能支撑公式结论。
- 只有预测状态或可训练参数参与并能反向传播的残差才称为物理信息神经网络残差。
- 不运行 GPU，不修改实验生产代码、第三章正文、实验总控或开题交接文档。
