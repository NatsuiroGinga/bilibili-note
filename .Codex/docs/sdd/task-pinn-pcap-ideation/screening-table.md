## 分类结论

1. **真正可形成 PINN 残差的理论**：有限控制体守恒、TCP/AQM 流体动力学、带已知服务曲线的网络演算不等式。
2. **只提供观测或可辨识性边界的理论**：QuASI、输出链路队列反演、QUIC 被动测量。
3. **只提供统计结构或表征证据的方法**：聚类点过程、ET-BERT、YaTC、NetMamba、RouteNet-Erlang。除非其预测状态进入控制方程残差，否则不能称作物理信息神经网络。
4. **当前数据下的约束**：GeNIS 和 TQH-C2 的普通流表不能提供交换机内部队列真值；TQH-C2 PCAP 可增加有方向包长、到达间隔和突发观测，但仍需 ns-3 提供状态真值与容量、入队、离队和丢弃边界。
