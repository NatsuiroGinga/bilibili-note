## 从证据到自有公式的纪律

1. 文献方程只提供状态变量、守恒关系和适用条件，不直接复制为本课题公式。
2. 本课题候选残差必须同时满足：预测状态参与、对训练参数梯度非零、边界可由 ns-3 或正确观测点验证、在公开数据上不使用仿真真值推理。
3. 多窗口统计一致性、包数求和恒等式、点过程负对数似然和网络演算上界特征，若没有预测物理状态参与，只能称为统计或结构正则。
4. 双向流的上行和下行不是同一个交换机队列的入队与离队，禁止据此写守恒方程。
