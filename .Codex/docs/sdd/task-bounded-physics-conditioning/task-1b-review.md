## 重点核对结果

- **Qwen/Peft 层解析：** 仅接受直接 Qwen 的 `model.layers` 和项目 PeftModel 的 `base_model.model.model.layers`，要求只能命中一条路径，并校验 28 层与隐藏维度 2048。
- **挂钩生命周期：** 构造失败会移除已注册挂钩；公开调用拒绝嵌套会话；普通前向和生成均在 `finally` 中清理会话；`close()` 显式移除全部挂钩。
- **缓存生成：** 只接受单束生成；首次完整提示前向计算一次状态与条件词元，后续单令牌缓存步复用条件，并校验源层、四个目标层、预填充和缓存步计数一致。
- **梯度路径：** 零门时状态头、条件编码器和注入器内部参数被门乘法隔离，门参数仍可获得梯度；门更新后生成损失可到达全部新增结构。非有限状态和注意力输出会在门乘法前失败。
- **保存加载：** 底层 Qwen/PeftModel 使用非注册引用，不进入运行时状态字典；结构状态仅包含状态头、共享编码器和四个注入器；严格加载在写入前检查缺键、多键、形状和非有限门值。
- **旁路恢复：** 旁路会话中源层与目标层挂钩均无动作，不捕获状态、不执行注入；调用异常后会话可恢复，关闭后底层模型仍可直接调用。
