# 共享低秩基底的物理状态编码专家设计

## 1. 研究假设

单一私有 LoRA 把平稳、累积和饱和潜态的物理梯度写入同一个无条件映射，可能造成相互抵消或共同破坏检测边界。若在完全相同的低秩参数预算下，只依据模型预测的潜在物理状态切换低秩通道编码，则不同状态的梯度可以在共享基底中形成可辨识的条件子空间，并可能同时改善子类生成与物理一致性。

该假设只针对种子 42、50 步方向探针。任务十七已经否定“公共字段可可靠恢复真实队列状态”，因此本任务只使用“模型预测潜在物理状态”这一表述，不把路由类别解释为真实网络状态。

## 2. 预算参数化

每个目标层只训练一组秩为 `16` 的共享低秩基底：

\[
\Delta_e(h)=B\,\operatorname{diag}(c_e)Ah,
\quad A\in\mathbb R^{16\times 2048},
\quad B\in\mathbb R^{2048\times 16}.
\]

单适配器对照固定使用全 `1` 通道码。路由候选固定使用 16 阶 Hadamard 矩阵中三个非平凡、满支持、两两正交的行向量，分别对应平稳传输、队列累积和容量饱和潜态。通道码是注册缓冲区，不是参数；每次前向仍计算完整的秩 `16` 下投影与上投影。

因此两个变体在四个目标层上同时满足：

- 每层总学习秩均为 `16`，四层秩和均为 `64`。
- 适配结构可训练参数完全相同。
- 每次前向实际激活全部秩 `16` 参数，激活参数完全相同。
- 路由候选没有三套独立 LoRA，不能描述为完整混合专家或 DeepSeekMoE。

每层残差使用零初始化可训练门和 `0.1` 相对范数上界。共享矩阵使用确定性随机初始化，门初值为 `0`，保证两个变体初始时均与冻结 S3 严格等价。

## 3. 路由状态与物理损失状态

运行时包含两个从同一 S3 状态头权重初始化的五维状态头：

- `router_state_head` 全程冻结，在 Qwen 第 13 层提示末端预测五个非负锚点状态，只用于路由。
- `outcome_state_head` 可训练，在专家注入后的最终隐藏状态上预测五个锚点，用于双锚点监督与有限队列残差。

该拆分避免硬路由阈值随训练共同漂移，同时保证状态损失和物理损失可以沿最终隐藏状态反向到低秩专家。

路由器的唯一函数输入是形状 `[B,5]` 的 `predicted_state`。它内部计算：

- 预测增长量：`q4 - q0`。
- 预测压力：五个预测锚点均值。

阈值只由冻结 S3 在 ns-3 训练提示上的预测状态计算，不读取状态目标、容量、通量、攻击标签、数据集来源、场景号或未知攻击标签。固定使用 `2/3` 分位数，不扫描分位数。路由顺序为：

1. 预测增长量达到增长阈值时选择队列累积专家。
2. 否则，预测压力达到压力阈值时选择容量饱和专家。
3. 其余选择平稳传输专家。

攻击大类样本的专家有效掩码固定为假，即使计算出预测状态也不能注入专家残差。子类样本与物理样本启用专家。

## 4. 训练与比较

两个变体分别从同一冻结 Qwen3-1.7B、同一 S3 检测适配器、同一状态头、同一共享基底随机初始化开始。固定种子 42、50 步、生成批量 `4 x 4`、物理批量 `4`、学习率 `2e-4`、双锚点状态权重 `1.0`、物理权重 `0.01`、梯度裁剪 `1.0`，使用完全相同的生成和物理样本顺序。

训练目标为子类生成损失、双锚点状态损失和有限队列物理残差。攻击大类样本保留在固定样本调度中用于路径审计，但不产生专家梯度。

## 5. 否证指标

### 5.1 无真值泄漏

- 路由纯函数只接收预测状态张量与预测阈值。
- 路由配置保存允许字段和拒绝字段清单。
- 阈值校准中间制品只保存预测压力与预测增长摘要，不保存状态真值、容量、通量或场景号。
- 家族门控、冻结 S3 摘要和训练前后旁路逻辑值必须一致。

### 5.2 使用率与坍缩

- 在物理验证集和子类生成验证集分别报告每专家样本数、使用率及 `H(p)/log(3)` 归一化使用熵。
- 每专家最少使用率必须不低于 `0.05`，归一化使用熵必须不低于 `0.50`。
- 每个专家在 50 步内必须至少一次获得非零梯度或参数更新证据。

### 5.3 专门化

在物理验证集按预测潜态分组，强制每组分别使用三个专家码，形成 `3 x 3` 的条件联合损失矩阵：

\[
L_{c,e}=L_{state}^{(c,e)}+0.01L_{physics}^{(c,e)}.
\]

每个状态组的对角专家必须取得该行最低损失，且相对次优专家的最小优势大于 `0`。另外将对应专家残差置零，要求只在其对应状态组产生正向损失退化。任一状态缺样本、对角不最优或移除无影响均判为没有专门化。

### 5.4 家族保护与联合收益

- 家族专家门控固定为 `0`，训练前后冻结 S3 摘要一致，家族路径最大逻辑值差不超过 `1e-6`。由确定性路径等价可推出同协议家族 F1 下降为 `0`，满足不超过 `0.01`；本探针不另行把验证损失冒充 F1。
- 相对同预算单适配器，路由候选的子类生成验证损失至少改善 `1%`。
- 未观测状态误差和物理残差至少一项改善 `1%`，另一项不得恶化超过 `1%`。
- 上述门槛、使用率、专门化与无泄漏门槛必须全部通过，才能判为有进入正式验证的方向信号。

## 6. 制品与失败边界

每次训练保存配置、环境、输入哈希、样本顺序、路由阈值、通道码及两两内积、逐步指标、训练摘要、结构权重、路由使用、专门化矩阵、冻结路径审计、SwanLab 原始日志和制品清单。比较程序保存预算审计、相对变化、逐项门槛与总裁决。

任一核心门槛失败即停止，不改变阈值、码向量、秩、层位置、学习率、损失权重或专家数，不运行 202 步或种子 43、44。
