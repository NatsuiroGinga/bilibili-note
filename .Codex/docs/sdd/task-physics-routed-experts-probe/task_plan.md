# 物理状态路由适配专家方向探针任务计划

## 目标

在不恢复任务十七已失败的公共字段真值辨识假设、不改变 D0-D3 与 E1/E2 历史合同的前提下，实现并运行一次种子 42、50 步的物理状态路由适配专家方向探针，给出可复核的通过或停止裁决。

## 固定合同

- 用户已明确批准本次有界验证，原“需用户批准”门禁已满足。
- 路由为四窗口序列级路由，只消费推理期可由模型得到的五锚点预测状态及其四个增量。
- 路由不得消费攻击标签、数据集来源、ns-3 场景号、队列真值、容量真值、丢弃真值或未知攻击标签。
- 共享检测适配器冻结；攻击大类任务的物理专家门控固定为 0。
- 三个专家固定解释为平稳传输、队列累积、容量饱和，不扫描专家数、秩、Top-K、损失权重、路由温度或学习率。
- 与单适配器比较时，总秩预算和每次前向实际激活的低秩参数预算必须一致；无法同时满足时不得运行训练。
- 只运行种子 42、50 步方向探针；不得据此宣称显著性、稳定增益、跨种子泛化或效率优势。
- 正式 GPU 运行使用服务器 `uv`、SwanLab 在线模式、唯一输出目录和完整制品清单。
- 若与主进程 GPU 任务并发，不使用运行时间、吞吐量或峰值显存作效率结论。
- 禁止测试驱动开发；按计划实现后运行直接覆盖合同的最小服务器测试和两步真实模型冒烟。
- 不提交 Git，不推送；同步使用 `rsync` 且不带 `--delete`。
- 2026-07-24 用户调整优先级后，当前只完成设计、实现、本地静态检查和独立代码复审；服务器同步、pytest、两步冒烟与 50 步探针均暂停。
- 后续服务器验证的解锁条件是主控先冻结未触碰 GeNIS 测试清单和同协议正式基线；在解锁前不得自行启动实验。

## 预注册否证门槛

1. 无真值泄漏：训练与推理路由输入键空间审计均为零违规；状态干预能改变路由，标签、场景号和真值字段干预不能改变路由。
2. 专家使用：每个专家至少被使用一次；最小使用率不低于 `0.05`；归一化使用熵不低于 `0.50`；每个专家必须获得非零梯度或参数更新证据。
3. 物理专门化：按预测潜态形成 `3 x 3` 强制专家条件损失矩阵，每行对角专家必须最优，且移除对应专家后只在对应状态上产生正向退化。
4. 家族保护：攻击大类路径的专家门控为零，训练前后冻结参数摘要一致，家族验证损失相对冻结检测适配器恶化不超过 `0.01`；50 步探针不把该损失代理写成自由生成 F1。
5. 同预算联合收益：相对同总秩、同激活参数的单适配器，路由专家的子类生成验证损失不更差，未观测状态误差和物理残差至少一项改善且另一项不恶化超过 `1%`；否则停止。

## 关键问题

1. 如何在三专家 Top-1 条件计算下同时满足单适配器的总秩与激活参数预算？
2. 如何使用模型预测状态定义路由目标，而不把 ns-3 队列真值或场景号送入路由器？
3. 50 步协议能提供哪些方向证据，哪些正式检测结论必须明确保留为未验证？

## 已作决定

- 不复用任务十七的历史估计器或不确定性门控；只使用当前模型状态头的预测值和确定性增量。
- 不把路由专家追加为 D4、B2 或 E3；使用独立模块与独立运行目录，保留所有历史语义。
- 三个独立 LoRA 无法同时满足总秩和 Top-1 激活参数预算；经主代理确认，采用“共享低秩基底的物理状态编码专家”，固定正交通道码不增加参数。
- 概念图只在确有必要时制作；实验数值图只由真实运行制品生成并保留可编辑脚本。
