## 失败边界

任一情况出现即停止，不进入 202 步：

- 路由接口读取攻击标签、来源、场景号或物理真值。
- 单适配器与路由候选的总秩、可训练参数或激活参数不相等。
- 任一专家使用率低于 `0.05`，或归一化使用熵低于 `0.50`。
- 任一专家条件梯度为零，发生专家坍缩，或 `3 x 3` 条件损失矩阵没有逐行对角最优。
- 对应专家移除没有在对应预测潜态上造成正向退化。
- 家族路径最大逻辑值差超过 `1e-6`，等价推导的家族 F1 下降不再为 `0`。
- 子类生成验证损失相对同预算单适配器未改善至少 `1%`。
- 未观测状态误差和物理残差没有至少一项改善 `1%`，或另一项恶化超过 `1%`。
