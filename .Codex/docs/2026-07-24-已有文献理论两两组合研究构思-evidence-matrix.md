## 4. 组合机制、证据边界与最小实验

### C1：物理不变量学习 × 可验证奖励强化学习

| 字段 | 内容 |
| --- | --- |
| 独立性 | A 定义“哪些变量关系应保持”；B 定义“如何用外部确定性验证器训练生成器”。一个是领域结构理论，一个是训练反馈理论。 |
| 互补接口 | LLM 生成候选不变量及变量集合；符号检查、文档一致性和历史数据验证器返回可验证奖励；只接受通过验证的轨迹进入更新或蒸馏。 |
| 论文原结论 | P23 支持“LLM 提候选、数据筛不变量”；P22 支持“确定性验证器 + 稀疏反馈自训练”。没有论文验证二者组合。 |
| 本任务映射 | 把 INVARLLM 的离线筛选变成训练期外部奖励，减少幻觉不变量并提高有效候选产率。 |
| 待验证假设 | 在同等生成令牌预算下，完整方法比提示工程、监督微调、普通 GRPO 和二者单机制产生更多跨工况仍成立的不变量，并在匹配攻击召回时降低案例级误报。 |
| 数据 | SWaT、WADI；不新建大型数据集，只复用系统文档与传感器日志。 |
| 主模型 | 单个 1B—7B 级指令模型，输出结构化不变量与变量引用。 |
| 主要基线 | 原始 INVARLLM 提示流程、监督微调、普通 GRPO、RLVR 无不变量数据验证、手工不变量检测。 |
| 两项单机制消融 | 去掉外部验证奖励；去掉物理不变量结构，只保留通用 CTI/CPS 结构化奖励。 |
| 完整组合 | 候选不变量生成 + 多级确定性验证奖励 + 失败样本的已验证轨迹蒸馏。 |
| 证伪条件 | 有效不变量比例、案例级误报或跨工况保持率不优于任一单机制；或模型只学会迎合验证器而样本级 F1/案例覆盖恶化。 |

### C2：奖励课程学习 × 约束 GRPO

| 字段 | 内容 |
| --- | --- |
| 独立性 | A 决定“哪些样本、何时训练”；B 决定“主奖励与漏报、格式、长度等约束如何更新”。 |
| 互补接口 | 每个代码样本的组奖励均值/方差形成难度；课程分配采样预算；约束 GRPO 对检测正确性优化，同时控制漏报率、结构化输出和长度。 |
| 论文原结论 | P21 在意图检测中用奖励反馈课程；P26 给出约束项标准化顺序的协方差重加权分析；P20 证明 GRPO 可用于漏洞检测。 |
| 本任务映射 | 将“低奖励样本”细分为全错无信号、组内有分歧的学习前沿和已掌握样本，避免只按均值硬筛。 |
| 待验证假设 | 固定训练令牌数时，完整方法提高跨数据集宏平均 F1/CWE 覆盖，并达到预注册漏报率和格式违反率上限。 |
| 数据 | BigVul、DiverseVul、CleanVul。 |
| 主模型 | 单个代码语言模型，输出漏洞二元判断、CWE 与简短证据。 |
| 主要基线 | 监督微调、普通 GRPO、RCS-GRPO、Constrained GRPO、固定难度重采样。 |
| 两项单机制消融 | 固定均匀采样，仅保留约束 GRPO；普通 GRPO，仅保留课程采样。 |
| 完整组合 | 奖励均值—方差课程 + 分组件标准化的约束 GRPO。 |
| 证伪条件 | 同预算下完整方法不优于最好单机制；约束满足靠大幅牺牲宏平均 F1；课程导致长尾 CWE 被饿死。 |

### C3：队列 PINN × 贝叶斯仿真校准

| 字段 | 内容 |
| --- | --- |

## 5. 被排除的 8 个组合原型

| 原型 | 排除原因 |
| --- | --- |
| Stiefel-LoRA × FoRA | FoRA 已包含 Stiefel 约束，属于继承/同义机制堆叠，不是两项独立理论。 |
| 动力学随机化 × BayesSim | BayesSim 本身就是自适应域随机化扩展，不能作为两个并列理论；本报告只让 BayesSim 与 PINN 或状态条件化组合。 |
| GRPO × RLVR | GRPO 是更新器，RLVR 是奖励范式；若没有独立的约束、课程或表示机制，只是标准训练配置。 |
| PINN × PITT | 两者均属于物理信息学习家族，且 PITT 注入已知方程；没有第二项独立安全理论时容易成为“物理方法 + 物理方法”的机械拼接。 |
| mHC × Stiefel PEFT | 两者都约束参数/残差几何；本地审查还显示 mHC 近恒等、流坍缩和同预算不如 LoRA 的负面证据，缺少安全语义接口。 |
| Stackelberg × Bayesian Stackelberg | 贝叶斯 Stackelberg 已把攻击者类型不确定性纳入同一理论，不是两项独立理论。 |
| RAG × 多智能体 CTI | 本地未找到同时满足原始全文、机制清楚和可复现实验协议的两条证据链；不以标题或通用常识凑数。 |
| 多智能体 × 自主防御平台 | 需要搭建攻击—防御多代理环境、通信协议和评测平台，明显超过单章工作量；现有本地材料不足以收敛为一个主模型。 |

## 6. 缺失全文与元数据问题

### 阻塞性缺失全文

- **无。** 最终 10 个组合的两项理论均有本地原 PDF。

### 非阻塞性证据缺口

- 本地没有形成可直接纳入的网络安全 RAG 原始全文链，也没有满足单章工作量的多智能体自主防御完整协议，因此相关原型被排除，不请求用户为本轮补全文。
- `wiki/papers/attack-detection/Improving Generalization in Intent Detection- GRPO with Reward-Based Curriculum Sampling.md` 与 `wiki/papers/grpo/Improving Generalization in Intent Detection- GRPO with Reward-Based Curriculum Sampling.md` 的年份、期刊和摘要错误；原 PDF [2504.13592v2 (1).pdf](<../../raw/papers/grpo/2504.13592v2 (1).pdf>) 正确，本任务不使用错误笔记元数据。
- `wiki/papers/grpo/Constrained Group Relative Policy Optimization.md` 的年份字段异常；本任务以原 PDF [2602.05863.pdf](../../raw/papers/grpo/2602.05863.pdf) 和 `arXiv:2602.05863` 为准。
- P16、P19、P22、P26 为 2026 年本地预印本或近期版本，证据可用于提出假设和设计基线，但不宜写成领域定论。

## 7. 证据使用红线

1. 不把“尚未在本地材料中找到”写成“从未有人研究”。
2. 不把 P23 的攻击案例级 100% 精度写成样本级 100%；样本级结果和滑窗调参边界必须同时报告。
3. 不把 Stiefel 权重几何写成物理状态流形，也不把有效秩提高写成检测性能必然提高。
4. 不把 BayesSim 的目标模拟器实例写成真实物理系统；只有 P13 提供有限真实机器人迁移证据。
5. 不把网络演算特征增强写成可微物理约束；C7 必须新增模型预测量参与的约束或边界接口。
6. 不把共享—私有辅助分支写成显式耦合；主任务头必须消费私有/状态表示，并用置零、置换和梯度检查验证。
7. 不把课程论文的 Wasserstein/收敛定理直接改名迁移到 GRPO 或网络安全；必须重新陈述假设并证明或降为解释性命题。
