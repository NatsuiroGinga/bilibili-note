## 核心问题

1. LAMDA 的正式题录、版本关系、数据协议、仓库固定提交与许可证是什么？
2. 数据年份、特征、标签、官方划分、基线与全部实验数字能支持哪些可复用论断？
3. 数据公开性、完整性、泄漏风险、指标饱和与单卡实验性如何？
4. 2023–2026 Android 恶意软件时间漂移工作中，哪些是直接近邻、引用或被引关系？
5. 哪些研究空白可以转成可证伪的任务化算法？RWKV、mHC、课程学习、强化学习和博弈方法分别具备什么资格条件？

## 验收命令

- `rg` 核对稳定标识、来源链接、页码、证据等级和待核标记。
- 解析 YAML 前言，检查 `source_pdf` 指向存在的原件。
- `rg` 检查新增笔记均由方向 `INDEX.md` 或相关综述引用。
- Zotero 精确题名/标识符检索，记录条目键和全文状态。
- `git diff --check` 与本任务路径定向差异审查。

## 决策

- 网页深度研究输出只作候选；正式综述仅提升经本地全文或官方仓库核验的结论。
- 无全文材料只登记题录和阻塞，不创建确定性论文全文笔记。
- 未经真实实验不得声称任务化算法或 RWKV 适配有效。
