# RWKV 替代主题先导实验报告

日期：2026-08-05

## 结论

“面向长时加密流的 RWKV 状态检测与漂移校准”在当前冻结制品上**不值得进入模型先导阶段**。原因是开发数据不具备合法长序列，而非任何模型的性能不足。结论为 `DATA_NO_GO`，不等同于否定 RWKV 在具备真实长时会话数据时的价值。

## 冻结比较合同

- 数据：只允许未来重新物理隔离后的开发训练、校准与开发验证；最终测试完全不可见。
- 输入：同一冻结数值字段、同一训练集拟合的归一化、同一组与样本顺序；不得用标签、模型输出或基线强弱拼接历史。
- 模型：参数匹配的 GRU、轻量 Transformer、普通 RWKV；HGB 仅作 CPU 非序列下界，不参与参数匹配。
- 训练：相同序列长度、训练步数、优化器调参次数和种子 42。单种子只能淘汰，不能构成有效性结论。
- 主指标：预注册困难开发面板宏平均 F1；同时报告简单域、最差域、校准误差、峰值显存、吞吐和延迟。
- 淘汰门槛：普通 RWKV 必须相对最佳参数匹配神经基线提高至少 `0.01` 宏平均 F1；或在性能差不超过 `0.005` 时达到至少 `1.5` 倍吞吐，或降低至少 `25%` 峰值显存。未达到则第一阶段淘汰。
- 漂移校准：只在普通 RWKV 通过上述门槛后，才比较普通 RWKV、仅校准和完整组合。
