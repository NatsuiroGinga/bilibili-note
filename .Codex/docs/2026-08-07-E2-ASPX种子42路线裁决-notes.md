## 固定分析口径

- 主要评价单元：目标 C 的样本级指标与捕获组级指标。
- 阈值：每个变体只在相同源域校准集上按固定候选网格选择；禁止使用目标 C 或最终测试调整阈值。
- 越大越好：宏平均 F1、捕获组等权宏平均 F1、最差捕获组宏平均 F1、恶意召回率、PR-AUC。
- 越小越好：良性误报率、ECE、物理状态归一化均方根误差、无量纲守恒残差、约束违反率和训练时间。
- 物理诊断同时报告最后一步值和最后 `20` 步均值；A 的状态头不受物理监督，其物理数值只作无监督参照。
- 当前 E2 物理诊断来自训练批，不是独立物理验证集；它只能作为机制诊断，不能替代目标 C 检测收益或独立物理泛化证据。
- 单种子不执行显著性检验，也不形成最终论文优越性主张。
