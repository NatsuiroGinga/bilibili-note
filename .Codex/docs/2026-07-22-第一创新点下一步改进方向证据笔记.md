# 第一创新点下一步改进方向证据笔记

## 实验事实

- B0 与 B1 均完成 50/50 步、2,700 条 GeNIS 和 807 条 ns-3 验证，生成损失对预测状态的梯度和状态扰动响应均非零。
- B0 的生成损失、未观测状态误差和物理残差分别为 `0.181829`、`0.429906`、`0.016724`。
- B1 相对 B0 改善全状态、已观测和未观测状态误差 `5.44%`、`13.33%`、`1.17%`，但生成损失恶化 `4.37%`，物理残差恶化 `278.42%`。
- 当前 QR-Stiefel 投影没有联合收益，不进入 202 步；单随机种子、50 步结果不能外推为全部流形方法无效。

## 流形约束与参数高效微调

- Stiefel-LoRA、FoRA 与 StelLA 约束权重子空间的正交性、有效秩或低秩几何，没有预测物理状态到生成输出的直接证据。
- mHC 的 Birkhoff 约束只支持凸混合、乘法闭包和限制数值放大，不保证信息无损或多流语义专门化。
- mHC 后续研究发现近恒等退化、流坍缩和同预算不如普通 LoRA；完整多流结构从主线降级。

## 物理表征显式连接

- PhyDNet、NewtonianVAE 与 UP-OSI 共同支持 `q_hat=g(x)`、`y_hat=f(x,q_hat)` 的严格前向结构。
- PhyDNet 进一步支持物理动力学分支与未知因素残差分支共同解码。
- 领域分离网络和 REPA-P 是直接反例：私有或物理分支只参加辅助损失、重构或推理期被删除时，不能称为主任务显式耦合。
- 共享私有文本多任务学习支持共享表示与专用表示共同进入任务头；Recon 只支持先诊断冲突层，不支持先复制大模型主干。

## 仿真到真实迁移与状态可辨识性

- UP-OSI 支持从历史观测预测环境参数，再由主任务直接消费；训练可使用仿真真值，部署不需要参数标签。
- 动力学随机化表明需要覆盖容量、时延、噪声、队列策略和流量混合等环境变化。
- BayesSim 表明相似观测可能对应多组物理参数，应报告不确定性或等价类，不能把单点估计写成真实物理量恢复。
- 当前 GeNIS 单流统计缺少链路容量、四窗口边界和队列通量，因此任务十六的状态语义存在跨域不可辨识风险。

## 综合裁决

- 支柱 A 继续为双锚点有限队列物理信息神经网络。
- 候选支柱 B 收敛为历史环境辨识、不确定性感知物理软令牌与数据驱动残差通路；不再使用博弈、Stiefel 扫描或完整 mHC。
- 任务十七先验证公共观测下的状态可辨识性与仿真覆盖；失败时只允许一次 ns-3 数据覆盖修正。
- 任务十八比较仅辅助 C0、物理软令牌 C1 和不确定性门控 C2。相对 B0，生成损失需不高于 `0.190921`、未观测状态误差不高于 `0.386915`、物理残差不高于 `0.015051`，且严格前向依赖与门控行为通过。
- 任务十八通过后冻结理论结构；任务十九完成多随机种子与外部验证后冻结结果性结论；任务二十完成跨基座适用范围。
