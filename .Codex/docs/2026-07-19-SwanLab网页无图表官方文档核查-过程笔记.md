## 官方文档证据

- `swanlab.log()` 用于在训练循环中逐步收集指标，并为同名指标递增 `step`；显式 `step` 可以对齐不同频率的指标。
- 指标名前缀用 `/` 分隔是官方支持的图表分组方式。
- `print_to_console` 默认关闭；网页“日志”选项卡记录的是标准输出和标准错误，不等同于标量历史。
- 官方建议不同指标名少于 10000 个，每个标量少于 50000 个点。274 个键没有触发官方硬上限。
- `CoreSettings.section_rule` 默认按第一个 `/` 分割分区和指标名，多层 `/` 有明确配置语义。
- `summary` 是标量的统计摘要和最新值，不等于完整序列，也不等于图表面板列表。

## 当前裁决

1. **确定问题：跟踪粒度错误。** 当前脚本只上传最终静态摘要，没有逐步训练指标，也没有实验阶段控制台日志。
2. **确定事实：云端数据和面板均存在。** 不能再把网页空白解释为上传失败。
3. **最符合证据的网页原因：项目共享看板的分区顺序与面板膨胀。** 用户先看到旧分区的空面板，目标分区位于第三位；项目共 495 个自定义图表，也增加了前端定位和加载成本。
4. **剩余不确定性：浏览器本地状态。** 当前会话无法直接检查用户浏览器是否保留搜索条件、缓存或渲染错误；生产 API 已排除服务端缺数据和缺面板。
