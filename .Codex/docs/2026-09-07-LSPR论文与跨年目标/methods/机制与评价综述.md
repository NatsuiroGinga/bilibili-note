# LSPR 跨年检测的机制与评价综述

## 结论

当前全文证据支持把后续研究收敛为一个**严格源侧的双机制联合框架**，而不是继续叠加目标年再校准、测试时更新或事后聚合：

1. **机制一：有序源环境稳态表示。** 用 LSPR23 内部按时间前向构造的多个源环境训练 FT-Transformer，使逐流表示和风险对已见时间变化保持稳定，并用打乱环境顺序作必要反事实。它对应“逐流打分器跨年退化、同年选优不能预测下一年”这一已获项目与 LSPR 全文共同支持的病灶。
2. **机制二：实体均匀低误报排序。** 以实体袋为原子进入训练图，用可微实体池化与偏 AUC 风险直接压低顶部负实体、提升困难正实体。它对应“源侧逐流代理与目标实体运营目标错位、源阈值迁移后低估可用误报预算”这一已获项目证据支持的病灶。
3. **联合框架：稳态表示驱动的实体低误报学习。** 机制一先减少流级表示随时间环境改变的漂移，机制二再把剩余判别能力定向到实体低 FPR 区域。协同只能由严格 `2×2` 交互项和机制活动诊断确认，不能因两模块挂载位置不同就宣称成立。

这一路线在信息权限上属于 `I0`：候选、模型、公式、超参数、检查点和阈值均只由 LSPR23 冻结；LSPR24 仅作一次性描述评价。MADCAT、潜空间对齐、无监督漂移检测和自适应重训需要无标签或有标签目标流，应作为独立信息预算的竞争基线，不应与 `I0` 主方法合并报告。

当前结论是**设计可行、实验待证**。文献证明机制来源与研究空白，不证明两个机制在 LSPR23→LSPR24 有效。

## 一、病灶证据与可证伪表述

### 1.1 病灶 A：同年选优不能外推到下一年

本项目已有结果显示，源年四格的实体平均精确率排序不能预测目标年排序；LSPR23 时间尾部逐流平均精确率仍近饱和，而 LSPR24 逐流平均精确率明显下降。33 个事后打分聚合算子在目标年的跨度仅 `0.0069`，说明只换后处理聚合不是主要杠杆，至少一个机制必须进入逐流表示或训练目标。

直接 LSPR 全文给出独立同向证据：

- Dijk 等在 LSPR23→LSPR24 上报告同年选中的 XGBoost、GRU 和 Transformer 平均精确率由 `1.0000/0.9984/0.9964` 降为 `0.2416/0.1758/0.0742`，保留率为 `24.16%/17.61%/7.45%`（全文第 31 页，表 5）。
- Leoste 的冻结跨年评价中，随机森林和一维卷积神经网络在 LSPR23 随机同年切分的 F1 约为 `99.8%`，到 LSPR24 的最佳 F1 均约 `18.4%`（全文第 79、84 至 85 页，表 8、10、11）。
- Malekghaini 等在同一运营商两年跨度的真实加密流量上观察到 TLS 头分支和流时序分支的平均准确率降幅分别为 `40.75%` 与 `33.02%`（全文第 6 页，表 6）。这只证明不同特征族的时间稳定性不同，不能把服务分类的准确率降幅换算为 LSPR 恶意检测的平均精确率降幅。

**可证伪病灶假设 A**：LSPR23 内部存在与 LSPR23→LSPR24 方向相关的有序变化，源内有序环境学习能比无序环境正则更好地保留未来逐流判别信息。

**失败条件**：打乱时间环境顺序不使源侧前向留出性能或机制诊断退化，或者有序机制只降低环境可分性却不改善最坏环境任务风险。出现任一项即否决“有序性提供外推信号”的解释。

### 1.2 病灶 B：训练代理与实体低误报目标错位

本项目已有证据显示：源年实体指标在极少正实体的验证集上不稳定；源年阈值迁移到 LSPR24 后，实体 FPR 从源留出的 `0.0400` 变为 `0.0153`，只使用约 `38%` 的经验误报预算，同时检出率低于目标年事后参考工作点。该事后参考使用了目标标签，只证明病灶，不能作为部署方法。

Tong 等的纽曼—皮尔逊分类全文明确限定：由源良性校准分数次序统计量得到的有限样本错误控制只对应校准分布，不能自动外推到目标年（全文第 2 至 4 页）。Zhu 等的 pAUC-DRO 则证明全局 AUC 或交叉熵并不直接优化低 FPR 区域，可用 CVaR/KL-DRO 聚焦顶部负样本（全文第 3 至 6 页）。Hu 等已把多示例袋级预测与双向部分 AUC 结合（全文第 8 至 10 页），所以“实体袋+pAUC”不是新概念；本课题必须靠年度隔离、实体均匀测度、FT 字段 Token 共用编码、源侧前向选择和跨年协同消融证明任务化差量。

**可证伪病灶假设 B**：逐流交叉熵对高分良性实体施加的有效梯度不足，实体均匀的低 FPR 排序目标能在不牺牲流级判别护栏的前提下改善实体运营区。

**失败条件**：完整低 FPR 实体目标不优于普通实体 AUC；打乱实体键后不退化；或者改进只来自降低源年性能而非提高目标年绝对性能。任一项成立即否决该机制解释。

### 1.3 尚未取得跨年资格的病灶

重复曝光导致迟到检出收益与累计误报成本、池化 FPR 掩盖长实体条件风险，目前只有 LSPR23 源年诊断。二者可作为实体机制的源侧分面和训练健康检查，但不能单独承担跨年第二机制的立论。若后续在不改变目标年封印的前提下完成两年同口径诊断，可再决定是否把首次告警停止规则作为第三层扩展；当前不应把 FIRMBOUND 或任意时点风险控制硬塞进双机制框架。

## 三、目标年信息假设

### `I0` 严格源侧，推荐作为主合同

训练、模型选择、阈值、超参数和停止条件只读取 LSPR23。LSPR24 在封印前不读取数组、统计量、标签或预训练适应状态。模型对每条 LSPR24 流只执行冻结前向。机制一与机制二均可在此合同下成立。

### `I1` 因果无标签目标历史，仅作独立扩展

冻结模型可读取当前与严格过去目标流形成确定性状态，不更新参数、不读未来。MalMoE 的当前图 readout 只能作为近似参照，因为它使用完整 30 秒窗口而非严格逐流前缀。若启用这一层，必须与 `I0` 分表报告。

### `I2/I3` 目标适应与重训，只作竞争路线

MADCAT、Wasswa 对齐和无监督漂移检测属于 `I2`；漂移后有标签重训、主动学习或真值平衡属于 `I3`。这些路线回答的是“允许部署期适应时能否恢复”，不能用来证明源侧泛化机制有效。

### `I4` 目标 oracle，只作病灶上界

任何目标标签选阈值、选模型、选停止点或调超参数均属 `I4`。本项目已有目标年事后 `4%` FPR 参考阈值只用于量化可恢复余量。Berruz 等在测试集上调分类器超参的做法虽被作者明示为 oracle 上界，仍不能作为部署数字。

## 四、FT-Transformer 的任务化改造空间

当前实现以 83 个字段各自形成数值 Token，并含一个 `[CLS]` Token；共享 Transformer 产生逐流表示和分类对数几率。适合改造的位置不是“再加一列时间”或“换一个更大骨干”，而是以下两个明确接口。

### 4.1 机制一接口：字段 Token 与 `[CLS]` 之间的稳态/私有分解

设 LSPR23 按严格时间前向划成有序环境 `e=1,...,E`，FT 编码器产生 `h_i`。用两个轻量投影得到稳定表示 `z_i^s=P_s(h_i)` 和环境私有表示 `z_i^p=P_p(h_i)`。最终恶意分类头只读取 `z^s`；`z^p` 只用于环境诊断和防止稳定分支把所有变化强行抹掉。

可审查的候选目标为：

```text
L_task = mean_e L_e^BCE
L_rex  = Var_e(L_e^BCE)
L_adj  = sum_{e=1}^{E-1} D(z^s_e, z^s_{e+1})
L_sep  = || (Z^s)^T Z^p ||_F^2
L_M1   = L_task + beta L_rex + lambda_adj L_adj + lambda_sep L_sep
```

`D` 可选类别条件均值距离或核距离，必须只用源标签；`beta` 与各 `lambda` 没有直接文献给出适用于 LSPR 的数值，均标为“无直接文献依据”，只能在 LSPR23 的前向开发协议中冻结。正式实现前应先比较两种最小版本：仅 V-REx 与“相邻环境稳定+私有分解”；不要一开始同时加入潜在域发现、专家门控和测试时状态。

FT 专属差量有三点：逐字段 Token 可分别记录环境敏感度；稳定/私有分支位于字段交互后的 `[CLS]` 表示，不把环境编号当预测捷径；最终分类路径不依赖目标年批统计。若只在 BCE 后加一个通用 V-REx 系数，贡献应如实称为“在 LSPR/FT 上的任务化应用”，不能冒充新泛化理论。

### 4.2 机制二接口：逐流头之后的实体袋低 FPR 风险

对实体 `g` 的源年流袋 `B_g`，逐流对数几率为 `a_{gj}`。一个可微、长度归一化的候选实体分数是：

```text
s_g(tau) = tau * log[(1/|B_g|) * sum_{j in B_g} exp(a_gj/tau)]
```

它在温度较低时接近最大值，在温度较高时接近均值；形式属于已有平滑池化范畴，不主张原创。`tau` 只能用 LSPR23 冻结。普通均值、最大值、注意力池化与随机池化应作为同预算基线。

对每个正实体 `g+` 与负实体 `g-` 定义排序损失 `ell(s_g- - s_g+)`。低 FPR 顶部负实体风险可写为 CVaR 形式：

```text
R_beta(g+) = min_xi [xi + (1/(beta * N-)) * sum_g- relu(ell_g-,g+ - xi)]
L_M2 = mean_g+ R_beta(g+)
```

`beta` 表示预注册运营 FPR 区域，不应在看到 LSPR24 后调整。若采用双向部分 AUC，还需对低分正实体增加对称尾部项；是否需要双向项由 LSPR23 源侧最低证伪实验裁决。逐流 BCE 可先用于预训练，或作为防止流级崩塌的护栏；不得在没有尺度分析时把 BCE 与 pAUC 损失简单等权相加。

FT 专属差量是共享同一个逐字段 Token 编码器，让实体低 FPR 梯度回到字段表示；它不是在预测后换聚合，也不是重新训练一个独立实体分类器。实体必须作为采样原子，使长实体不会因流数多而支配梯度。

### 4.3 不推荐的接法

- 不把绝对年份、演习段、资产身份或可逆实体 ID 作为 Token，避免学习年份/身份捷径。
- 不把完整 LSPR24 无标签分布用于门控器训练、温度选择或停止点选择后仍称为零目标泛化。
- 不复活已否决的固定 DTEP、BBSE-PBC、阈值再校准或反射累积实现；这些结果只能说明原实现为何被否决。
- 不把实体 pAUC、普通多示例学习、V-REx、域对抗或专家混合单独称为原创。原创性只能落在经实验支持的 LSPR 问题定义、信息合同、FT 挂载和联合协同差量上。

## 五、最低证伪实验

### 5.1 数据与选择协议

LSPR23 内部按实体互斥和时间前向形成训练、开发、校准与最终源侧前向留出角色。所有预处理、字段词表、归一化、实体池化温度、环境数、损失权重、训练预算和检查点规则只在这些源侧角色上冻结。源年尾部逐流平均精确率近饱和，不能单独承担选轮；应以跨多个源时间环境的实体运营指标和最坏环境指标选择。

LSPR24 在四格、强基线、代码哈希和阈值全部封印后一次性运行。目标年结果不允许触发新超参、重选检查点或追加“救回”实验；失败即否决、缩小或重构候选。

### 5.2 机制一最小实验

| 臂 | 目的 |
| --- | --- |
| 普通 FT | 共同预算基线 |
| 无序静态环境正则 | 检查收益是否只来自正则化 |
| 打乱时间顺序的相邻环境机制 | 反事实检验“有序性” |
| 有序环境完整机制 | 候选 |

源侧通过条件必须在看 LSPR24 前冻结：有序完整机制应改善源前向留出的最坏环境实体指标，且优于打乱顺序；环境风险方差下降时，任务风险不得同时恶化。否则机制一停止。

### 5.3 机制二最小实验

| 臂 | 目的 |
| --- | --- |
| 逐流 BCE | 共同预算基线 |
| 普通实体袋全 AUC | 区分“实体训练”与“低 FPR 训练” |
| 实体袋低 FPR pAUC | 候选 |
| 打乱实体键的低 FPR pAUC | 检验实体结构是否真实贡献 |

候选必须在源侧前向留出上改善实体低 FPR 指标并保持逐流平均精确率护栏；普通实体 AUC与打乱实体键均不能解释全部增益。否则机制二停止。

### 5.4 联合 `2×2`

| 四格 | 机制一 | 机制二 | 解释 |
| --- | --- | --- | --- |
| C00 | 关 | 关 | 同预算 FT 基线 |
| C10 | 开 | 关 | 有序源环境稳态表示 |
| C01 | 关 | 开 | 实体均匀低误报排序 |
| C11 | 开 | 开 | 联合框架 |

最终协同判据为：

```text
Delta_1 = metric(C10) - metric(C00)
Delta_2 = metric(C01) - metric(C00)
I = [metric(C11) - metric(C10)] - [metric(C01) - metric(C00)]
```

目标年主指标上需同时满足 `Delta_1>0`、`Delta_2>0`、C11 为四格最佳且 `I>0`。C11 若只靠牺牲源年绝对性能提高“保持率”，或只有某一机制的活动诊断非零，不得称为协同。此判据用于封印后的裁决，不用于看过 LSPR24 后调参。

### 5.5 必要强基线

- 同字段、同切分、同调参预算的 XGBoost。
- 普通 FT-Transformer 逐流 BCE。
- V-REx 与 DIVERSIFY/AIRL 风格源侧泛化基线中至少一个轻量和一个强实现。
- 普通实体 AUC、普通 pAUC-DRO、多示例 TPAUC 或随机池化的最近邻实现。
- Tong 源良性实体校准阈值。
- `I2` 预算允许时，MADCAT 式测试时适应只作独立上界，不参与 `I0` 胜负。

## 六、指标与统计设计

### 6.1 指标层级

**主指标**：LSPR24 实体平均精确率的四格配对差值。平均精确率与实体正例率一起报告，避免跨粒度误读。

**运营指标**：预注册的六档实体 FPR 预算下检出率、源阈值迁移后的实际实体 FPR、每百万流或每万个实体的假阳数量、首次告警曝光位置或时延。若某预算处存在分数并列，按冻结的并列组整体处理。

**机制一诊断**：各源时间环境 BCE/实体风险、风险方差、相邻环境稳定表示距离、稳定表示的环境可预测性、字段 Token 环境敏感度。

**机制二诊断**：有效正负实体袋数、实体长度分布、顶部负实体对损失贡献、困难正实体贡献、可微池化温度、逐流平均精确率护栏、各长度桶实际 FPR/DR。

**跨年描述**：目标绝对性能为主；跨年保持率和源到目标差值为辅。保持率可通过故意降低源年性能变好，不能单独作为成功指标。

**时间曲线**：若 LSPR24 可按合法时间片评价，可按 TESSERACT 的点估计原则报告实体平均精确率或 DR 的时间曲线与归一化曲线面积；时间片粒度必须在看目标结果前冻结，且不可与不同粒度的曲线面积直接比较。

### 6.2 不确定性与检验

- 评价重采样单位必须是实体而不是流，保持同一实体内流的相关性。分面指标在实体层分层重采样。
- 四格使用相同实体、相同拆分和相同随机种子，报告相对 C00 的配对效应与置信区间，而不是四个独立区间目测重叠。
- 对非线性的实体平均精确率、预算 DR 和交互项 `I`，使用配对实体簇自助法；重采样次数由预先设定的蒙特卡洛误差精度决定，不凭习惯填写魔法数字。
- 随机种子数量在 LSPR23 源侧先导的方差估计后冻结。每种子报告原始值；种子足够时再做“种子—实体”分层自助。种子很少时只报告描述统计和实体条件区间，不宣称跨训练随机性的总体显著性。
- 主要假设族包含 `C10-C00`、`C01-C00`、`C11-C00` 和交互项 `I`。若报告显著性检验，应预先采用族错误率控制；效应量与置信区间优先于单独 p 值。
- 源侧通过门、目标年最终裁决和机制诊断是三类不同证据。源侧通过只证明值得封印测试，不能写成跨年支持。

### 6.3 公平性与资源

四格应共享字段、数据角色、检查点数、优化器搜索空间、训练步数或等价计算预算。新增投影或实体损失带来的参数、显存和墙钟时间单独报告，并设置参数匹配或计算匹配对照。Dijk 等只用一个随机种子且其自助区间不覆盖训练随机性，本课题不能重复这一统计缺口。

## 七、研究空白与原创边界

在本轮已检索和全文核验的文献中，尚未发现同时满足以下四项的工作：

1. 明确采用 LSPR23 训练、LSPR24 封印评价的跨年合同；
2. 仅用有序源环境训练 FT-Transformer 的稳定逐流表示；
3. 让实体均匀低 FPR 排序梯度回传到同一 FT 字段 Token 编码器；
4. 用严格 `2×2` 验证两个单机制正增益及联合正交互。

这是**本轮语料范围内的研究空白**，不是全领域不存在证明。各组件本身已有强近邻：有序非平稳域泛化、潜在环境发现、风险外推、pAUC-DRO、多示例 TPAUC、NP 阈值和测试时适应都不能单独作为原创。可主张的贡献应限定为：在 LSPR 年度隔离和实体运营目标下，对 FT-Transformer 做两个有因果信息边界的任务化机制，并由真实跨年四格证据证明两者各自与协同作用。

## 八、推荐的下一研究方向

**P0：先验证病灶映射，不写实现计划。** 用现有 LSPR23 折外预测检查源内部时间环境是否存在稳定、可重复的风险方向；同时重算实体级顶部负样本与逐流 BCE 梯度贡献。两个检查都不读取 LSPR24。

**P1：先轻后重。** 机制一先跑 V-REx 与时间顺序打乱对照，机制二先跑固定池化的实体 pAUC 与普通实体 AUC 对照。只有两条最小臂都产生源前向信号，才进入稳定/私有分支和双向部分 AUC的完整实现。

**P1：冻结信息预算。** 主结论采用 `I0`；任何无标签目标适应放到独立表中。这样可以正面回答 MADCAT 与潜空间对齐的竞争路线，而不污染零目标跨年结论。

**P2：重复曝光暂作扩展。** 若两年同口径诊断确认迟到检出与累计误报的跨年持续性，再以 FIRMBOUND 或序贯风险方法扩展首次告警停止规则；当前不把它纳入双机制以避免未经证据的范围膨胀。

## 九、与朱焱雷第三章的组织层次对位

“同层次”只约束研究组织、工作量与论证深度，不迁移其攻击任务、模块内容或效果数字。当前候选达到同层次所需的最小结构如下。

| 对位维度 | 本任务要求 | 可验收制品 |
| --- | --- | --- |
| 总问题拆分 | 把跨年退化拆成逐流稳态表示与实体低误报目标错位两个有证据的维度 | 病灶收据、信息权限表、双机制公式 |
| 机制一 | FT 字段 Token/`[CLS]` 的有序源环境稳态学习 | 普通、无序、顺序打乱、完整机制四臂与活动诊断 |
| 机制二 | 实体均匀池化与低 FPR 偏 AUC 风险回传 | BCE、实体 AUC、实体 pAUC、实体键打乱四臂与梯度诊断 |
| 联合算法 | 共享同一 FT 编码器，稳定表示输出进入实体低 FPR 目标 | C00/C10/C01/C11 完整 `2×2` 与交互项 |
| 理论深度 | 明确源环境风险、相邻稳定项、私有分解、实体池化与 CVaR 风险；列出假设与失败条件 | 公式、变量定义、适用边界、数值依据台账 |
| 任务化改造 | 改动 FT 的字段表示接口和训练图，不只是更换分类头或后处理 | 数据集—模型适配表、参数量与计算量分解 |
| 证据层次 | 源侧病灶与 Q0、跨年最终评价、机制消融、多随机种子、资源统计 | 配置、日志、预测、实体级指标与配对区间 |
| 结果表达 | 两个单机制各有独立作用面，联合机制由正交互而非总分最高证明 | 主表、分面表、交互图、失败时的否决记录 |

朱焱雷第三章表 3-7 的 PGD-20 变化是绝对百分点，只作章节体例与效果量级参照；不得把本项目早期 `16.1%` 门槛归因于该论文，也不得把“需要两个机制”解释为无论实验结果如何都必须保留两个有效机制。若任一机制被跨年四格否决，正确处置是记录否决并重构病灶映射，而不是弱化基线或改变目标年判据。
