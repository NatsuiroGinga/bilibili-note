## 0. 目的与停止规则

本计划只回答一个问题：在冻结 corrected-v2 数据、`10/10000` 良性误报预算和目标场景零访问的条件下，M1“极低误报边界有界残差排序”和 M2“纯源场景留一二值准入”是否分别必要，并能否组成跨 XGBoost、随机森林且非单场景贡献的新候选。

本计划不是旧候选的调参轮次。旧 `support-shrunk-scene-tail` 已由 [真实 Q0 结果](2026-08-13-GeNIS支持量收缩跨场景极端尾部排序-Q0实验结果报告.md) 否决；不得修改其门槛、追加种子或把其测试结果用于选择本候选超参数。随机森林 sample-CVaR 只作为已发表强基线诊断。

Q0 完成后只允许三种机械结论：

1. `candidate_advanced=true`：所有有效性门、M1 门、M2 门和完整候选绝对门全部通过，才允许设计下一阶段；仍不能作正式论文或稳定性主张。
2. `candidate_advanced=false`：运行有效，但任一科学门失败；停止该固定候选，不追调、不改门槛、不追加种子。
3. `experiment_valid=false`：出现泄漏、错误划分、指标错误、比较不公平、实现不可运行或数学条件不成立；只修复无效原因后按同一冻结合同重跑。

## 2. 运行身份与矩阵

### 2.1 外层评价单元

外层原子单元为 `(model, outer_scene)`：

- 模型族：`xgboost`、`random_forest`。
- 目标恶意场景：`1..8`。
- 原子单元数：`2*8=16`。
- 每个单元使用七个源恶意场景、同一良性训练集、独立良性校准集和良性测试集。
- 目标恶意场景只在所有训练、选择、配对和准入位冻结后读取一次。

### 2.2 报告身份

每个外层原子单元必须生成以下 12 个报告身份，共 `16*12=192` 个聚合结果单元：

| 序号 | 身份 | 类型 | 是否新增主干拟合 |
|---:|---|---|---|
| 1 | `base-empirical-budget` | 充分调优 uniform 基座，经验 `K=5` 阈值 | 是 |
| 2 | `base-np-threshold` | 同一基座分数，NP 次序统计量阈值 | 否 |
| 3 | `sample-cvar` | sample-CVaR 强基线 | 是 |
| 4 | `np-cost-sensitive` | NP 风格代价敏感分类加 NP 阈值 | 是 |
| 5 | `direct-pauc-style-ranking` | 无锚直接部分曲线下面积风格局部排序 | 是，线性 |
| 6 | `groupdro-tree` | GroupDRO 树模型适配 | 是 |
| 7 | `vrex-tree` | V-REx 树模型适配 | 是 |
| 8 | `m1-always` | M1 总是启用，禁用 M2 | 是，复用基座加线性残差 |
| 9 | `m2-only-identity` | 无 M1 提案的 M2 恒等退化 | 否，必须等于身份 1 |
| 10 | `m1-m2-source-admitted` | 完整候选 | 否，按源准入选择身份 1 或 8 的分数 |
| 11 | `scene-shuffled-admission` | 保持支持量的伪场景准入 | 是，完整复制六源嵌套选择与重训 |
| 12 | `matched-random-admission` | 与真实门接受数相同的随机门 | 否，选择身份 1 或 8 的分数 |

这里的“否”只表示不新增完整树模型主干；M1 和折外准入仍包含线性残差求解。伪场景门必须用相同树网格和嵌套预算重新训练，不能复用见过其伪留出成员的锚。不得把共享分数复制成新的训练成功数。

### 2.3 强基线超参数预算

基础配置与选择规则完全采用方案册第 3、7 节。额外强基线预算固定如下：

| 方法 | 候选数 | 每候选折内工作 |
|---|---:|---|
| XGBoost 基座 | 8 | 七源场景留一；M2 内层为六源场景留一 |
| 随机森林基座 | 8 | 七源场景留一；M2 内层为六源场景留一 |
| sample-CVaR | 4 | `alpha_cvar` 与 `tau_cvar` 的 `2*2` 网格，七折选择 |
| NP 代价敏感 | 4 | `rho` 的 4 值网格，七折选择 |
| GroupDRO | 2 | `eta` 两值，每值固定 3 次权重更新/重训，七折选择 |
| V-REx | 2 | `beta` 两值，每值固定 3 次权重更新/重训，七折选择 |
| M1 | 1 | `gamma_0=0.5`、`beta=0.01`，不调参 |
| 直接局部排序 | 1 | 与 M1 同容量、配对、求解器和正则，不调参 |

选择先看最坏源折 `spAUC@0.001`，再看平均源折 `recall@budget`、平均 `spAUC`、预声明训练轮数和规范化配置字符串。实测拟合时间不参与选择。任何最终校准或目标指标都不能参与超参数选择。

### 2.4 四格与随机化解释

四格不允许换成名称相近但职责不同的实现：

| 四格 | M1 | M2 | 必须验证的身份关系 |
|---|---|---|---|
| `base` | 关 | 关 | 独立基础分数 |
| `m1-always` | 开 | 关 | 固定残差始终生效 |
| `m2-only-identity` | 无提案 | 开 | 分数摘要、阈值和所有指标逐字段等于 `base` |
| `m1-m2-source-admitted` | 开 | 开 | 每外层任务精确选择 `base` 或 `m1-always` |

`scene-shuffled-admission` 必须按方案册的固定哈希排序和连续切片真正破坏场景成员，同时保持七个支持量。仅置换场景名称无效。`matched-random-admission` 在得到真实门的模型内接受数后，按冻结哈希排序选择相同数量的随机接受任务，且不能读取目标指标。

## 3. 单元内执行顺序

每个 `(model, outer_scene)` 是一个不可拆分的数据隔离单元。树模型、分数、标签、配对和权重在该进程内复用；单元训练结束只允许保存最终模型和聚合收据，其他内存对象立即释放，不能用落盘样本缓存换取恢复速度。

### 3.1 阶段 A：全局数据门

1. 直接从原始 ZIP 流式读取八个场景，不生成中间 CSV 或 Parquet。
2. 按冻结稳定键全局去重，复核标签一致性、恶意键不跨攻击场景、良恶意键不相交。
3. 只在内存中构造 67 字段 `float32` 矩阵与标签。
4. 用冻结哈希域形成良性训练、校准、测试掩码；收据只保存数量、集合摘要和交集计数。
5. 对每个外层源集合执行方向无关单字段泄漏门；任一字段达到 `0.98` 即在任何训练前全局停止。
6. 记录 `raw_rows=544585`、`stable_rows=368555`、字段摘要、归档摘要和峰值 RSS。

全局完整性门可以读取所有场景以核对模式、摘要、标签一致性和支持量，但完成后必须把每个外层目标的特征与标签封装为只读密封视图；在阶段 G 前，训练函数、指标函数和准入函数都不能取得该视图。文中的“目标访问”特指将外层目标用于评分、选择或模型计算，不把确定性数据完整性核验伪装成完全未读原始字节。

### 3.2 阶段 B：最终基础模型

对每个外层目标场景 `o`：

1. 源集合为除 `o` 外的七个恶意场景；良性训练键按 `genis-low-fpr-source-fold-v1` 分为七折并映射到源场景。
2. 对八个基础配置逐一生成七个整场景折外指标；折外分数仅驻留内存。
3. 按冻结词典序选择一个配置。
4. 用全部七源恶意行和全部良性训练行重训 `base_final`。
5. 生成全部训练折外分数，供最终 `phi_all` 的配对使用。
6. 在读取独立校准与目标数据前冻结配置摘要、模型摘要、良性参考分布摘要和配对规则摘要。

随机森林非有限值的中位数填充只能从当前训练折估计；XGBoost 的缺失值路径沿用 corrected-v2。不得跨折共享填充值。

### 3.3 阶段 C：M2 的七个严格源留一证据

对每个源场景 `h` 单独执行：

1. 从模型选择、训练、标准化、配对和权重中移除恶意场景 `h` 与良性折 `h`。
2. 只在其余六个源场景内，对八个基础配置做六折留一选择。
3. 用所选配置在六个源场景上生成六折分数，依方案册构造困难对并训练 `phi_minus_h`。
4. 再用全部六个源场景重训 `base_minus_h`。
5. 冻结六场景良性训练分数参考分布，在从未参与上述步骤的恶意场景 `h` 和良性折 `h` 上计算基础与固定 M1 的 `Delta A_h`、`Delta R_h`。
6. 立即丢弃 `base_minus_h`、折外分数和逐样本残差，只保留聚合计数、指标和摘要。

七折完成后按方案册第 5.2 节一次性计算 `A_o`。不允许先看某折结果再跳过其他折，也不允许用目标场景或最终良性校准集补充门禁样本。

### 3.4 阶段 D：最终 M1 与必要性门

1. 用阶段 B 的七折分数定义每场景困难良性与近边界漏检恶意集合。
2. 每场景最多选择 `64` 个最高分困难良性和 `128` 个最接近操作边界但仍在其下的恶意稳定键，最多形成 `8192` 对。
3. 依固定 `tau=0.25`、`lambda=1e-3`、`gamma_0=0.5` 训练 `phi_all`。
4. 断言参数维度、有限性、边界外零修正、最大 logit 修正不超过 `0.5+1e-12`。
5. 保存参数数组的 SHA-256、分位摘要、求解器终止码和支持量；不得保存参数对应的训练样本、键或分数。
6. 用相同折与容量训练 `direct-pauc-style-ranking`；它不能复用基础 logit 作为输入或偏置，也不能在近邻全文未补齐前标成某篇论文的精确复现。
7. 用伪场景成员完整重复阶段 C：每个伪留出组都只在其余六组内重新选择基础配置、生成六折分数、训练残差和重训六组锚，形成 `scene-shuffled-admission`；最终提案仍使用同一个 `phi_all`，只替换准入位。

近边界漏检恶意少于 `8`、困难良性少于 `16` 或有效对少于 `128` 的场景不进入活动集。最终七源 M1 的活动场景少于 `4` 或未覆盖两个父族，或者任一六源 M2 残差的活动场景少于 `3` 或未覆盖两个父族时，真实 M1 标记退化，完整候选精确回退；该结果属于冻结机制的科学失败，不得扩大边界带或用易检恶意补数。

### 3.5 阶段 E：强基线

强基线必须在读取目标场景前全部完成选择和最终拟合：

- `sample-cvar`：复用基础折外分数计算局部逻辑损失，四个参数组合各自重训，按七折指标选一个。
- `np-cost-sensitive`：四个恶意类系数各自做七折评价；最终模型使用独立 NP 阈值。
- `groupdro-tree`：每个 `eta` 从均匀场景质量开始，执行恰好三次 `q_e <- q_e exp(eta R_e)` 与重训；风险、权重和有效样本质量均保存聚合值。
- `vrex-tree`：每个 `beta` 执行恰好三次场景风险梯度权重更新、投影到非负单纯形并重训；保存投影前负权重数和投影后权重。
- 每个方法的类别总质量先归一，再令各场景权重和的平均值为一，避免改变优化器的全局学习率尺度。

GroupDRO 与 V-REx 是已发表目标的树模型交替适配，不得在报告中称为原论文训练算法的逐行复现。若投影、权重或风险非有限，该基线实现无效，不能删除它后继续裁决候选。

### 3.6 阶段 F：全局冻结点

阶段 A 至 E 必须先覆盖全部 16 个外层单元。每个单元只保存最终基础、强基线、直接排序和残差模型，不读取任何目标恶意行、独立良性校准行或良性测试行。全部单元训练完成后：

1. 汇总每个模型八个真实 M2 准入位。
2. 按外层场景号与 `seed=42` 的固定哈希排序，在每个模型内选择与真实门接受数完全相同的随机接受任务。
3. 冻结 `training_freeze_receipt.json`，其中包含 16 个单元的模型摘要、准入位、随机门位、配置摘要和完成时间。
4. 将 `target_access_allowed` 从 `false` 原子切换为 `true`；此后任何训练、模型选择、配对或准入重算都必须由代码硬阻断。

若训练阶段中断，允许跳过已经有完整模型和聚合收据、且摘要匹配的单元；不完整单元必须从头重跑。不得保存折外分数以恢复到单元内部步骤。

### 3.7 阶段 G：独立校准与一次目标访问

仅当阶段 A 至 E 的所有训练身份、配置摘要和 M2 准入位均冻结后，才允许评分：

1. `5478` 个独立良性校准键。
2. `5405` 个良性测试键。
3. 当前外层唯一目标恶意场景。

每个独立评分生成器先产生内存分数，再生成经验 `K=5` 阈值及指标。`base-np-threshold` 与 `np-cost-sensitive` 另按本地纽曼–皮尔逊全文的次序统计量实现：对 `n` 个良性校准分数升序排列，取满足

\[
v(k)=\sum_{j=k}^{n}{n\choose j}(1-\alpha)^j\alpha^{n-j}\le\delta
\]

的最小 `k`，其中 `alpha=0.001`、`delta=0.05`。阈值和严格/非严格比较必须与全文定义一致，并单独记录等于阈值的良性数量；不能把经验 `K=5` 阈值冒充 NP 阈值。

完整候选、伪场景门和随机门只在内存中选择已经冻结的 `base` 或 `m1-always` 分数。所有身份评价完成后立即删除逐样本数组，只写聚合结果。

### 3.8 阶段 H：机械裁决

聚合器按方案册第 9 节顺序执行：

1. 有效性门。
2. M1 必要性门。
3. M2 必要性门。
4. 完整候选绝对门。

不能用平均值补偿任何最坏场景硬门，不能忽略失败场景，也不能在裁决脚本之外人工覆写 `candidate_advanced`。每个布尔门都要同时输出实际值、比较符、门槛和通过位。

## 7. 资源与调度预算

### 7.1 工作量上界

按冻结网格保守计算：

- 最终基础模型选择和重训约 `912` 次树拟合。
- M2 的七折六源嵌套选择、六折分数和六源重训约 `6160` 次树拟合。
- sample-CVaR 与 NP 代价敏感各约 `464` 次树拟合。
- GroupDRO 与 V-REx 各约 `720` 次树拟合。
- 保持支持量的伪场景门完整复制 M2 嵌套流程，额外约 `6160` 次树拟合。
- 总树拟合上界约 `15600` 次；共享同一折中完全相同的基础拟合可以在内存中复用，但收据必须记录逻辑次数、实际次数和复用摘要。
- M1、伪场景门与直接排序合计不超过 `512` 次 69 参数线性求解。
- 聚合报告固定为 `192` 个结果单元。

上述是工程估算，不是实验结果。不得为缩短时间减少场景、数据行、强基线、内层折或配置网格。

### 7.2 调度规则

- 最大并发外层单元为 `2`：同时最多一个 XGBoost 单元和一个随机森林单元。
- XGBoost 每单元 `nthread=8`，GPU 上同一时间只运行一个训练任务。
- 随机森林每单元 `n_jobs=4`。
- 总 CPU 线程预算为 `12`；不得在内层折上再套进程并行。
- `L-BFGS-B` 单线程，避免底层 BLAS 超额并行。
- 已完成单元可按模型 SHA、配置 SHA 和聚合收据原子恢复；单元内部失败从头重跑。
- 正常运行估计 `36` 至 `72` 小时；最长墙钟保护为 `84` 小时。超时属于工程未完成，不是候选科学失败。

### 7.3 启动资源门

启动前必须只读核验当前 RWKV 总控指定的服务器身份和实验根；不得沿用旧服务器假设。最低资源门：

- 可用系统内存不少于 `16 GiB`。
- 可用 GPU 显存不少于 `16 GiB`，且无其他受管实验占用本任务计划的设备。
- 运行根可用磁盘不少于 `30 GiB`。
- 依赖导入成功，原始归档可读且摘要匹配。
- 持久会话与同名运行不存在；不得重复启动。

运行保护值：单进程 RSS 达到 `12 GiB`、GPU 已用显存达到 `12 GiB` 或运行根达到 `24 GiB` 时停止新单元并写诊断。资源不足时改为串行调度，不改变科学合同。

## 8. 失败分类与处理

| 事件 | 分类 | 动作 |
|---|---|---|
| 数据摘要、字段、稳定键、分区或泄漏门失败 | 实验无效 | 训练前停止，保留诊断，不裁决候选 |
| 目标、校准或测试参与选择 | 实验无效 | 全运行作废，修复后同合同重跑 |
| 指标、阈值、并列或模型身份错误 | 实验无效 | 修复实现，不改变科学参数 |
| 强基线缺失或预算不公平 | 实验无效 | 补齐后才允许裁决 |
| 求解器非有限、配对支持不足 | 科学退化 | 该外层按冻结规则回退，计入候选裁决 |
| M2 全关、全开或随机门匹配 | M2 未建立 | 完整候选不晋级 |
| 任一模型、场景或父族门失败 | 科学否决 | `candidate_advanced=false`，停止候选 |

| 禁止制品被发现 | 实验无效 | 状态不得写为成功；停止并审计原因 |

任何科学失败都不能触发参数扫描、门槛修改、场景删除或新种子。只有无效实验允许修复后重跑。
