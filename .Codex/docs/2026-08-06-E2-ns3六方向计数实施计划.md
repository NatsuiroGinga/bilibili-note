# E2 ns-3 六方向计数实施计划

## 目标

在不改变冻结 512 项场景参数、划分和运行顺序的前提下，为 ns-3 主窗口增加与 Zeek `conn.log` 一致的六个方向字段，并让旧版 `main.csv`、旧收据和旧复用目录被明确拒绝。

## 边界

- `orig` 固定为发送端到受害端，`resp` 固定为受害端到发送端。
- 观测点固定为路由器的瓶颈 IPv4 接口：发往受害端的 `Tx` 为 `orig`，从受害端收到的 `Rx` 为 `resp`。
- `orig_pkts/resp_pkts` 统计观测到的 IPv4 包；`orig_ip_bytes/resp_ip_bytes` 包含 IPv4 首部。
- `orig_bytes/resp_bytes` 只统计传输层有效载荷。TCP 按四元组和序列区间去重，UDP 按数据报载荷累加。
- 禁止按总量比例拆分、用 ACK 字节或计划发送量代替方向真值、按行号关联或修改冻结配置。
- 本任务只实现与做最小代码检查，不运行本机 `pytest`、格式化、SSH 或 512 项矩阵。

## 执行项

1. 更新 ns-3 场景的观测、窗口计数和主 CSV 模式。
2. 更新公共运行器的模式、方向语义验证和新版收据。
3. 更新并行运行器的复用门禁，拒绝旧收据和旧主模式。
4. 更新正式物化器，使新版六字段进入物理目标 Parquet 并参与模式/收据校验。
5. 增加旧主模式拒绝和方向字段约束的最小测试。
6. 仅运行一次 C++ 结构检查与 Python 语法级检查，结果写入实施报告。
