# 任务十四 G0–G5 同预算训练设计

## 1. 目标

在 `Qwen3-1.7B`、随机种子 42、相同数据、状态掩码、样本顺序和 202 次有效模型更新下比较 G0–G5，裁决第三章最终采用普通合作议价、物理可靠性与生成否决，还是显式主从响应协调。

本任务只进行单随机种子机制裁决。通过门槛的方法才进入三个随机种子、公开数据检测性能、效率与跨基座验证。

## 2. 固定协议

- 生成训练与验证数据沿用 `physics_sparse_seed42.yaml`。
- 物理训练、验证与测试数据固定为 `ns3-queue-sequences-h4-seed-split-20260721-v2`。
- 状态监督固定为 `anchor0_only`，物理残差仍使用完整五锚点预测状态。
- 有效模型更新固定为 202 次；生成批大小、梯度累积、物理批大小、学习率和 LoRA 参数保持任务十一设置。
- G0/G1 只有在输入散列、状态掩码散列、样本顺序、训练预算和评价代码与任务十一 S1/S2 全部一致时才复用；任一项不一致则重新运行。
- 所有新运行必须在线记录 SwanLab 逐步指标，并保存本地逐步日志、训练汇总、最终适配器、状态头、样本顺序和制品清单。

## 3. 共享梯度契约

令生成、稀疏状态和物理损失在共享 LoRA 参数上的梯度分别为

\[
g_g=\nabla_\theta \mathcal L_g,\qquad
g_s=\nabla_\theta \mathcal L_s,\qquad
g_p=\nabla_\theta \mathcal L_p.
\]

非零梯度严格归一化为 `u_i=g_i/||g_i||_2`；零范数目标标记为当前批次不可参与，不用任意小常数伪造方向。Gram 矩阵与方向边际定义为

\[
C_{ij}=u_i^\top u_j,\qquad
d(w)=\sum_iw_i u_i,\qquad
m_i(w)=u_i^\top d(w).
\]

共享 LoRA 参数使用协调方向，并以生成梯度范数恢复更新尺度。状态头是任务私有参数，不参与三目标议价；它根据当前被接受的状态和物理目标单独更新，避免生成目标在状态头上的结构性零梯度污染博弈定义。

## 4. 变体定义

### G0：稀疏状态基线

生成损失加 `q0` 状态监督，不使用物理残差。对应任务十一 S1。

### G1：固定权重直接联合

沿用 `lambda_state=1.0`、`lambda_physics=0.01` 的直接联合更新。对应任务十一 S2，用于复现生成性能受损。

### G2：对称合作议价

在分辨率 0.02 的确定性单纯形网格上，从所有 `m_i>0` 的方向中最大化

\[
U_2(w)=\sum_{i\in\{g,s,p\}}\log m_i(w).
\]

若不存在严格共同下降方向，退化为纯生成方向并记录退化次数。

### G3：固定非对称合作议价

使用议价权 `p=(0.6,0.2,0.2)`，最大化

\[
U_3(w)=\sum_i p_i\log m_i(w).
\]

它只验证软性主辅区分，不含生成硬保护。正式论文若保留该参数，必须补充议价权敏感性实验。

### G4：物理可靠性与生成否决

物理可靠性只由当前物理批次的有效样本比例和状态—物理梯度一致性构成：

\[
\rho_p=v_p\frac{1+\cos(g_s,g_p)}{2},\qquad 0\leq\rho_p\leq1.
\]

其中 `v_p` 是容量分母严格为正、输入有限且边界锚点有效的样本比例。协调器枚举 `{状态}`、`{物理}`、`{状态,物理}` 三种辅助活跃集合，在以下约束下选择可靠性加权议价效用最大的方向：

\[
m_g\geq0.95,\qquad m_i>0\quad(i\text{ 为活跃辅助目标}).
\]

若双辅助不可行，允许只接受一个辅助目标；若所有辅助集合都不可行，退化为纯生成方向。逐步记录生成否决、状态拒绝、物理拒绝、可靠性、权重和边际。

### G5：独立协调器的主从响应

G5 必须设置独立协调器参数，不能把三个共享损失直接命名为三个玩家。协调器作为主导方输出辅助参与权或门控，模型参数作为跟随方执行训练更新；主导方使用独立验证批次评价跟随更新对生成、未观测状态和物理残差的响应。

正式实现前必须完成以下数学门禁：

1. 明确主导变量、跟随变量和双方效用；
2. 写出一次跟随更新及其对协调器参数的非零全导数；
3. 说明采用一阶展开、截断展开还是隐式微分；
4. 证明或数值验证反应项不是普通动态权重的改名；
5. 保留与 G4 相同的逐步制品和生成保护失效率指标。

G5 的数学门禁与 G2–G4 正式训练并行完成，不阻塞已经定义完整的变体运行。

## 5. 裁决门槛

候选方法相对 G0 必须同时满足：

- 生成验证损失恶化不超过 5%；
- 未观测状态误差改善至少 10%；
- 物理残差改善至少 10%。

G4 还必须通过去除物理可靠性、去除生成否决的消融；G5 还必须通过停止反应梯度的消融。没有候选通过时，不改弱基座制造增益，而是重新检查协调约束或 G5 响应定义。

## 6. 执行顺序

1. 审计 S1/S2 是否可严格复用为 G0/G1。
2. 实现 G2–G4 的纯数学协调器和统一训练入口。
3. 服务器运行最小目标测试与 2 步在线冒烟。
4. 立即按最多两个并行进程启动 G2–G4 的 202 步运行。
5. GPU 运行期间完成 G5 数学门禁和实现。
6. G5 冒烟通过后启动 202 步运行。
7. 汇总 G0–G5，执行门槛裁决并更新第三章候选公式。
