## 已实现门禁

### 数据与比较公平性

- 检测输入和物理批模型输入都必须精确采用冻结七字段及其顺序。
- TQH-C2 只从 E1 冻结开发视图构造 `A+B+D→C`；训练、校准和 C 目标域样本标识必须互斥。
- 物理数据只允许配置中的训练划分，且 `final_test_visible` 必须全部为假。
- 检测训练批必须由冻结源域清单通过 `E2DetectionSourceBinding.bind_batch` 签发，C 域样本无法进入训练批。
- 物理特征和监督通过显式复合样本键生成稳定 `physics_sample_id`，每个批次通过 `build_e2_physics_feature_binding` 绑定样本顺序、七字段张量和监督，禁止只靠行位置关联。
- 四组共享同一检测采样计划和独立的物理采样计划，不要求 TQH-C2 与 ns-3 一一配对。

### 四组共同预算

- 四组固定使用 `E2NumericEncoder`、相同检测头和状态头。
- 四组固定 `max_steps=200`、检测批与物理批均为 `128`、相同优化器参数和相同采样计划；训练前调用 `assert_shared_training_budget` 同时核对结构、步数、双批量与实际初始权重。
- 先建立单份初始状态，再严格加载到四组；保存初始状态哈希并逐组复核。
- `E2-X` 的物理批按来源、协议、场景和缺失模式成对采样；每批只通过 `permute_e2_physics_supervision` 构造确定性无固定点置换，并保存签名收据。禁止手工改写监督来源或复用完整物理池的全局置换。

### 物理梯度与状态合同

- 状态通道配置为队列三层字节和队列包数，每条物理样本使用起点与终点两个锚点。
- 只监督起点状态，同时评价起点与终点；终点提供未观测状态误差。
- 守恒残差使用接收量、离开量和入队前后丢弃量；状态与通量按物理训练池统计量无量纲化。
- 边界上限来源明确登记为物理训练池观测最大值，不冒充未提供的队列容量。
- 逐步直接记录真实训练反向传播产生的共享编码器和状态头梯度范数，不再额外重复一次梯度计算；`E2-P/E2-X` 任一梯度为零即失败。

### 基础模型与运行证据

- 外部 DistilBERT 基线固定到修订 `45c032ab32cc946ad88a166f7cb282f58c753c2e`。
- 运行前核对模型清单、校验清单和权重哈希；只接受允许的基础架构和 `safetensors` 权重，发现序列分类头、适配器、优化器、训练状态或旧检查点即拒绝。
- 包装器固定使用 `uv run --no-sync python -m flow_probe.e2_hard_domain_train`，直接从当前源码树启动模块，避免新增 `pyproject.toml` 命令入口尚未安装时出现 `No such file`；不执行依赖同步、冒烟或独立导入预检。
- 每个运行使用唯一输出和启动证据目录；保存配置快照、环境、代码配置哈希、输入绑定、物理绑定、状态、控制台日志、逐步指标、逐样本预测、每 20 步检查点、SwanLab 在线日志和制品清单。

- `device=auto` 在无 CUDA 时降级到 CPU；`precision=auto` 只在 CUDA 支持时启用 `bfloat16`，否则降级为 `float32`，不改变科学参数。
