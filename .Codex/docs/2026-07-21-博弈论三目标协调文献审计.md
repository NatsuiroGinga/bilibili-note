# 博弈论三目标协调文献审计

## 结论

当前生成、状态和物理三目标冲突可以采用博弈论建模。**非对称合作议价**可以直接处理共享参数梯度冲突；**斯塔克尔伯格双层协调**在新增独立协调变量后也具备可行性。两者应通过同协议实验裁决，不能仅凭理论复杂度预先选定。

## 当前问题映射

当前模型包含一个主任务和两个辅助任务：

- 主任务：生成恶意性、攻击类别和证据文本，决定最终检测能力。
- 状态辅助任务：估计连续队列状态，提供可解释中间变量。
- 物理辅助任务：约束相邻队列状态满足有限队列控制体守恒关系。

任务十一表明，物理目标能显著改善未观测队列状态和物理残差，但会使生成验证损失恶化 36.5465% 至 43.8336%。因此需要解决的是**辅助目标如何在不伤害主任务的前提下提供增量信息**，而不是攻击者与防御者之间的策略对抗。

## 本地论文审计

### Stackelberg Actor-Critic

来源：`raw/papers/game/2109.12286v1.pdf`。

该文把策略网络和价值网络建模为一般和主从博弈。跟随方使用普通梯度，主导方通过隐函数定理计算全导数，其中包含逆海森矩阵向量积。论文实现采用共轭梯度近似：10 次迭代时主导更新约为普通梯度的 15 倍，5 次迭代仍约为 7.5 倍。

它不能直接套入当前三个损失，原因如下：

1. 策略网络与价值网络具有不同参数和天然层级，当前三个损失主要作用于同一组共享参数。
2. 当前生成输出不依赖状态头。若直接把生成器与状态头设为主从双方，生成损失对状态头的偏导为零，主导方全导数中的反应项会退化。

计算时间、显存开销以及朱焱雷是否使用过同类理论不作为否决依据。只要建立不同且合理的玩家、策略和效用定义，并由实验验证，斯塔克尔伯格方法可以保留。

### 攻击者—防御者安全博弈论文

目录中的贝叶斯安全博弈、部分可观测安全博弈、蜜罐部署、移动目标防御和恶意节点检测论文，玩家是攻击者与防御者，输出是防御资源分配、响应动作或混合策略。这些文献可用于第四章的攻击威胁背景或原型系统响应策略，但不能作为第三章梯度协调公式的直接依据。

## 网络检索的相关方法

### 对称纳什议价

[Multi-Task Learning as a Bargaining Game](https://proceedings.mlr.press/v162/navon22a.html) 将每个任务视为合作玩家，以各任务梯度在共同更新方向上的投影作为效用，通过纳什议价得到比例公平的共同方向。它直接处理共享参数上的梯度冲突，是必要基线。

局限是所有任务地位对称，而当前生成任务必须优先于辅助状态和物理任务。

### 非对称纳什议价

[Auxiliary Learning as an Asymmetric Bargaining Game](https://proceedings.mlr.press/v202/shamsian23a.html) 允许主任务与辅助任务具有不同议价权，并根据辅助任务对主任务验证性能的贡献更新偏好。该结构与当前问题最接近。

局限是原方法没有物理可观测性、边界锚点、守恒残差可靠性和生成任务硬保护条件，不能原样改名作为创新点。

### 双时间尺度主从学习

[Stackelberg Coupling of Online Representation Learning and Reinforcement Learning](https://arxiv.org/abs/2508.07452) 将控制网络作为慢更新主导方、表示网络作为快更新跟随方，用双时间尺度近似双层优化。若后续把生成头与物理状态头拆成明确的两组参数，它可以作为备用机制；当前不优先采用。

### PINN 多目标优化

[A Multi-Objective Optimization Framework for Adaptive Weighting in Physics-Informed Machine Learning](https://ojs.aaai.org/index.php/AAAI/article/view/39900) 与 [Auxiliary-Tasks Learning for Physics-Informed Neural Network-Based Partial Differential Equations Solving](https://arxiv.org/abs/2307.06167) 共同说明，数据损失与物理损失竞争可以通过多目标优化或辅助任务梯度筛选处理。它们支持问题设定，但没有解决生成主任务保护与恶意流量可观测性问题。

## 建议的自主改造方向

当前保留两条并行候选，只作为实验方案，不提前确定算法缩写。

### 候选一：物理可靠性感知的非对称议价协调

核心约束如下：

1. 生成目标拥有否决权：候选共同方向必须满足生成梯度的一阶下降条件。
2. 状态与物理目标只在可观测字段完整、边界锚点有效且对应梯度非零时参与议价。
3. 议价权不直接由损失大小决定，而由辅助梯度对生成验证目标的历史贡献与物理可靠性共同决定。
4. 三目标只在共享参数上议价，任务私有参数分别更新，避免不必要的全模型梯度存储。
5. 若三个目标不存在严格共同下降方向，退化为生成方向，并记录该批次的物理约束拒绝率。

### 候选二：物理约束驱动的斯塔克尔伯格双层协调

1. 设置独立协调器参数 `ψ` 作为主导策略，输出状态与物理目标的参与权重或接受门控。
2. 模型参数 `θ` 作为跟随策略，在训练批次上执行一次或少量内层更新，形成响应 `θ'(ψ)`。
3. 主导效用由生成验证损失、未观测状态误差和物理残差约束共同构成，必须保证其对 `ψ` 的全导数包含非零跟随响应项。
4. 用一阶展开、截断展开或隐式微分分别形成反应梯度基线；最终实现由实验裁决，不以计算成本直接排除。
5. 与普通元权重方法比较，本文增量必须来自队列边界可辨识性、物理可靠性和生成保护约束，而不是仅将损失权重改为可学习参数。

## 最小实验矩阵

| 变体 | 机制 | 目的 |
| --- | --- | --- |
| G0 | 稀疏状态监督，不加物理项 | 生成与状态基线 |
| G1 | 固定权重直接联合 | 复现任务十一冲突 |
| G2 | 对称纳什议价 | 判断合作博弈本身是否有效 |
| G3 | 非对称纳什议价 | 判断主辅任务区分是否必要 |
| G4 | 物理可靠性 + 生成否决约束 | 验证本文候选增量 |
| G5 | 斯塔克尔伯格双层协调 | 判断显式跟随响应是否优于梯度议价 |

所有变体必须使用相同数据、掩码、随机种子、有效模型更新次数和评估脚本。G4 或 G5 只有同时满足以下条件才进入多随机种子正式实验：

- 生成验证损失相对 G0 恶化不超过 5%；
- 未观测状态误差相对 G0 改善至少 10%；
- 物理残差相对 G0 改善至少 10%；
- 相对 G2、G3 的差异能由消融证明来自生成否决、物理可靠性或非零跟随响应。

## 章节命名影响

在 G4 通过前，第三章保持：

**第3章 基于物理一致性与目标协调的恶意流量生成式训练方法**
