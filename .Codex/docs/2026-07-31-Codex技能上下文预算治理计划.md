# Codex 技能上下文预算治理计划

## 目标

在不删除技能原件、不触碰论文研究资料的前提下，核验 Codex 0.144.5 支持的技能和插件启停机制，完成 P0/P1 去重和用户已批准的 P2 毕业论文仓库作用域裁剪，并保留受控 `rsync` 规则。

## 边界

- 只处理 Codex 配置、插件或技能启用状态、命令允许规则及本任务报告。
- P0/P1 和 P2 已获批准；P3 及以后只记录建议，不实施。
- 修改前备份受影响配置。
- 不删除技能目录、插件缓存、论文、数据、模型或实验制品。
- 不运行格式化工具。

## 验收

- `config.toml` 可由标准 TOML 解析器读取。
- `default.rules` 可由 Codex 当前版本检查或通过最小实际命令验证。
- 技能/插件治理不删除任何原件，可通过备份或配置恢复。
- `rsync` 规则仅允许合理的可执行前缀，不包含服务器地址、密码或令牌。
- 报告列出变更文件、停用项、保留项、回滚方法和重启要求。
