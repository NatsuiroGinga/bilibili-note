## 中间结论（随写随记）

- **复算协议与对表**（脚本 /tmp/qstar-recompute-20261013.py，制品 measurements.json）：
  - 成员集：6 角色×5000，candidate_digest top-K 确定性复现，6/6 candidate_root 哈希与
    `ch3-drift-f-source-eligibility-20260923/f-source-eligibility.json` 一致 ⇒ 同一成员集。
  - 长度 6 占 **24.18%**（7,254/30,000）✓；其后 26（9.6%）、16（8.8%）、25（7.3%）、15（5.6%）✓。
  - **修正简报**：`len(body)<4` 仅 **0.09%**（27 个成员）⇒ 训练核零层退化是小头；
    **评价侧 q_actual ≤ 3 占 28.5%**（众数 q=3，7,694 个成员）才是「预算极小区」的主体。
  - B 核编辑位数 hist {0:27, 2:29,973} ⇒ 条件于非退化恰为层 2 均匀（层-2 验证）。
  - 复合核（D/F）每候选编辑位数 hist {1:168, 2:4,011, 3:35,966, 4:79,744}，均值 **3.628**：
    **层支持实为 {0,1,2,3,4}**，1 层来自「第二阶段把 base 已改位改回原字符」的**字符回弹**
    （续篇层-3 的 {0,2,3,4} 需修正），均值 ≈ 3.6 与超几何预测吻合，**不恒为 4**。
  - 同长对距离（本协议 14,990 对）：min=0、median=14、P(<16)=**57%**；
    简报口径（7,600 对）：min=2、median=21、P(<16)=36%。两个口径 P(d_H≥2q) 都远非 0
    ⇒ **层-12 充分条件失败不受配对协议影响**，`W_1 = q` 只能得上界 `W_1 ≤ q`。
- **q*(θ) 定义结论（数学攻坚）**：
  - 逐样本 argmax 版定义**失败**（唯一性失败 + 无平滑性，反例见主文档 §2.1）。
  - **最小成功预算版定义成立**：`q*(θ;x,y) := min{q: 攻击成功}`，失败时取 n+1。
    存在（有限集 min 存在）、唯一（min 唯一）、可计算（链上逐档前向 ≤ n+1 次）三关全过，
    且**不需要难度单调假设**（min 对任意二值成功序列良定义）。
  - 「课程调度 = 跟踪 q*(θ_t)」可形式化为跟踪窗口条件 + CE 梯度信号窗口论证；
    朱焱雷式「反应梯度进泛化界」的串联**接不上**（离散反应梯度无恒等式 + Shi&Liu 泛化界无离散重证）。
- **估计器章结论（2026-10-13 主代理改向「能用比能证重要」后新增）**：
  - **零误差可用**：单点侧界 `p<1/2 ⟺ q*≤q`（严格，min 定义性质的纯逻辑推论）；
    两点夹逼（区间宽度确定）。训练循环免费或 +1 前向。
  - **可进循环的近似**：反馈调度 F-1（bang-bang，状态量 = 当前档置信度 p_t，零额外成本）；
    无收敛保证（非平稳+离散），增量主张 H-F 待实验。
  - **只可离线诊断**：轨迹差分 E-1 / Pogančić 差分——误差量级**给不出**
    （真值 dq*/dθ 几乎处处为零且翻转处无定义 ⇒ 比较对象缺失；BiGrad/Pogančić 原文无
    「解映射为整数标量」情形的误差界条款）。
  - **straight-through 对位（BiGrad 式 9，ar5iv 原文核对）= 现状实现**：
    朱焱雷实现（主代理核实：外层把 δ* 当常数）在实现层与式(9) 等价
    ⇒ 实现层不落后于参照论文，理论叙事不以反应梯度为卖点。
  - **P0 剖面实证**：对抗训练臂（B/D/F/UQ）在 fpr_0_01 工作点的成功率随档位**反向单调**
    （k1 0.061 → random_half 0.045），A 臂单调升，剖面形状随误报工作点翻转
    ⇒ E2/层-8 的聚合实证；二分/跳步估计器排除；「固定课程隐含非单调难度轴」。
