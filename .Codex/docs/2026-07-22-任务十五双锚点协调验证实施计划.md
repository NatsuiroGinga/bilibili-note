# 任务十五：双锚点物理协调验证实施计划

> **执行方式**：使用子代理完成配置与静态核对，主进程负责服务器同步、在线冒烟、正式训练和裁决。禁止使用测试驱动开发；只运行与新增配置直接相关的最小验证。

## 目标

验证 `q0 + 一个内部锚点` 能否消除单锚点状态漂移，同时由 G4 的物理可靠性、生成否决和受约束议价保护生成目标。实验别名为 `G4R-A2`，训练入口仍使用既有 `--variant G4R`，不新增算法分支。

## 单变量原则

- 基座固定为 `Qwen3-1.7B`。
- 数据、随机种子 42、样本顺序、有效批量、学习率、LoRA、物理残差、202 次更新和评价协议保持不变。
- 唯一配置变化：`state_supervision_mode` 从 `anchor0_only` 改为 `anchor0_plus_one`。
- 每个组始终监督 `q0`，并按既有 `seed + group_id` 哈希规则在 `q1` 至 `q4` 中确定性选择一个内部锚点。
- G4R 的共享 LoRA 解继续沿用 G4；私有状态头持续接收状态锚点梯度；私有物理梯度继续受物理接受状态和可靠性缩放控制。

## 裁决基线与门槛

以相同双锚点监督、无物理项的 S3 为基线：

| 指标 | S3 | G4R-A2 通过门槛 |
| --- | ---: | ---: |
| 生成验证损失 | `0.029337` | `<= 0.030804`，恶化不超过 5% |
| 物理残差 | `0.108131` | `<= 0.097318`，改善至少 10% |
| 未观测状态误差 | `0.139720` | `<= 0.125748`，改善至少 10% |
| 已观测状态误差 | `0.096511` | `<= 0.101337`，恶化不超过 5% |

四项必须同时满足。不得因结果接近而修改门槛。
