## 修订实现要点

- `formal-v1` 约运行 8 分钟后被主代理中断，退出码为 130，堆栈停在 `T17 dga` 的 ROSA 扫描。其 DeepEmbed 已完成但原实现只在末尾原子写，未留下可用制品；这不是科学结果。
- 正式抽样改为按 `revision/year/label/path` 派生种子的 SplitMix64 行号向量化选择。批内只对入选 Arrow 行转换 Python 字符串，避免对全部行逐条 SHA256。
- DeepEmbed 完成即写入 `status=running, completed_stage=deepembed` 检查点；每完成一个 ROSA 分面再原子更新。中断不捕获，已写阶段制品保留。
- ROSA 收据新增扫描行、选中行、唯一域名、重复选中行、实际抽样率与吞吐；重复域名风险只披露，机制统计仍按行加权。
- 每百万扫描行和每个分面完成向 stderr 输出心跳，含阶段、分面、扫描量、选中量与耗时。

- 配置改为四个显式输入对象 `path/year/role/label`；输出 `T17/T25×benign/dga` 分面与由计数合并的总体，不从文件名推断语义。
- PyArrow `ParquetFile.iter_batches` 仅投影 `domain` 列，不全量载入字符串。
- DeepEmbed 统计 T17 字符、2-gram、3-gram 频数；T25 输出位置级 OOV、含 OOV 域名率、已见 token 源频数质量、唯一键数、完整频数长尾、新生/消失键数和词表摘要。
- 哈希碰撞统计不预设桶数或网格。配置中的桶数为 `null`，输出保留唯一键数和固定摘要算法；未来比较普通嵌入、DeepEmbed 与 Engram 时，只能在冻结单一桶数后重跑实际碰撞量。
- ROSA 按官方在线后缀自动机逐域名重置，输出 eligible/predictable/coverage、完整匹配长度、历史距离和后继命中；同一前缀合同下输出所有实际可达固定阶的覆盖、命中、状态条目与内存代理曲线。
- 默认 ROSA 半宽为 `null`，无 `--pilot-domains` 时机械拒绝扫描；pilot 只测真实域名吞吐，不裁决机制。主代理冻结半宽后，样本量按 95% 最坏二项比例公式推导并输出实际半宽。DeepEmbed 正式模式仍全量扫描。
- 正式哈希抽样按四个分面分别用元数据行数计算 `min(公式样本量, 分面行数)` 和 SHA256 阈值；每个分面独立报告请求、实际样本数、实际最坏半宽与哈希偏差，整体数不替代分面半宽。
- pilot 在四个分面分别输出 `sampled_domains`、`elapsed_seconds` 与 `domains_per_second`，并标记为不可用于机制裁决。
- 所有 `Exception` 均尽力原子写失败收据，保留可解析的配置摘要、运行身份、revision 和错误；不捕获 `KeyboardInterrupt` 或 `SystemExit`。
- ROSA 总体的匹配长度、历史距离、按匹配长度后继命中、后继命中总数和命中率均由四个分面的计数相加得到，不平均分面率；实际运行收据记录 Python 版本、解释器路径与 PyArrow 版本。
- `raw.enabled=true` 机械拒绝，避免未验 SQLite 逐行查询路径启动。
- 正常或失败均原子写单一 JSON；输出含 revision、输入 SHA256/字节/行数、配置摘要、过滤规则和心跳。
