## 背景（不要求你检索这部分，仅供你理解问题）

我们研究 **Android 恶意软件检测的 Domain-IL（域增量持续学习）**：年份即任务，共 12 个任务
（2013–2025，缺 2015），模型在 **LAMDA 数据集**（100 万样本、4,561 维稀疏二值静态特征）上逐年更新。

官方 benchmark 的持续学习基线把**回放缓冲固定为 200 条样本**（这个 200 是 `argparse` 默认值，
论文未论证、无消融）。我们已复现官方三臂：

| 臂 | 我们的实测 | 官方 |
| --- | --- | --- |
| Naive（只用当年） | 0.7244 | 0.7271±0.0083 |
| Experience Replay（200 条） | 0.7805 | （未给单值） |
| Joint（全量历史） | 0.8791 | 0.8852±0.0046 |

我们另测了**回放容量 → 性能**曲线（同一协议，只改容量）：

| 回放样本数 | 存储 | avg_f1 |
| ---: | ---: | ---: |
| 50 | 28 KB | 0.7752 |
| 200 | 111 KB | 0.7805 |
| 400 | 223 KB | 0.8061 |
| 800 | 445 KB | 0.8192 |
| 18,854 | 10.3 MB | 0.8503 |
| 全量 | 438.6 MB | 0.8791 |

同时我们移植了 **FreeMOCA**（arXiv 2605.09664，无样本回放、用 warm-start 后逐层参数插值保持历史）
到同一协议，初步读数**低于 Replay(200)**，而它占用的存储是 200 条样本的约 **94 倍**。

**我们正在考虑的理论框架**：把「固定比特预算 $B$ 在**样本侧**（存历史样本）
与**参数侧**（存参数副本/Fisher 等）之间如何分配」形式化为一个**受约束优化**问题，
用 **KKT / 率失真 / 比特分配（water-filling）** 给出最优性条件。

## 请你回答以下六个问题，逐条给出可核验出处

1. **有没有工作把「持续学习中的记忆/回放容量」显式当作一个受约束优化问题**（预算约束下的记忆分配、记忆选择的最优化）？
   关键词候选：budget-constrained continual learning、memory budget allocation、fixed memory budget CL、replay budget optimization。

2. **有没有工作把「率失真理论（rate-distortion）」用在持续学习或记忆回放上**？
   例如把「保留多少比特的历史信息」与「遗忘造成的性能损失」建立失真-率关系。

3. **有没有工作做过「样本回放」与「参数保持（EWC / LwF / 参数插值 / 无记忆方法）」在等存储预算下的对照**？
   即：**同一个比特/字节预算，两种存储类型谁更有效**。

4. **water-filling / 边际收益均等化** 在机器学习资源分配（尤其持续学习、记忆管理、模型压缩）中的应用有哪些？
   请给出经典出处（如 Boyd & Vandenberghe《Convex Optimization》§5.5.3 Water-filling）**以外的**、将该方法用于学习系统的具体论文。

5. **持续学习中的「记忆预算」研究**：有哪些代表性工作研究「容量固定时，记忆里放什么、放多少」？
   请给出方法名、会议/年份、以及各自把预算当作**固定常数**还是**优化变量**。

6. **有没有工作质疑过「回放容量取某个固定值」的合理性**——即对回放容量做过消融或敏感性分析、并报告「容量收益曲线」的？

## 硬性要求

- **每条结论必须给出**：论文标题、作者、年份、会议/期刊或 arXiv 编号、DOI 链接；
  并且**明确标注你的证据到达了什么程度**——「已读全文」／「仅摘要」／「仅题录」。
- **引用原文句子时给出章节号或页码**；不要把摘要转述当成全文结论。
- **若某一问确实查不到，就写「未发现」，并说明你检索了哪些库、用了哪些关键词。不要用猜测填补。**
- **若发现我们的框架已被别人完整做过，请直接、明确地说出来**，并给出那篇工作的全文链接——
  这对我们比找到支持证据更有价值。
- 优先给 **2020 年之后**的工作，但问题 4、5 的经典源头不限年份。
- 请给出每篇关键工作的 **PDF 可获取链接**（arXiv / OpenReview / 作者主页 / 出版社开放版），
  不要只给 DOI。
