## 2. 当前课题边界

1. 研究对象是**同一个生成式大模型的恶意流量检测训练方法**，不是传统分类器课题，不是恶意流量生成，也不是物理检测器与语义检测器串联。
2. 主基座为 `Qwen3-1.7B`。方法冻结后必须增加一个 1B 至 3B 非 Qwen 基座验证；不得为制造增益临时更换弱模型。
3. 第三章研究**模型结构与物理建模**，第四章研究**训练策略**。两章不能同时围绕同一损失权重或同一优化器形成重复创新。
4. 第三章固定保留物理信息神经网络方向，但最终公式、边界条件、状态尺度、结构接口、算法名称和正式章名尚未冻结。
5. 第三章不再强制拼接两个互不相关的结构。一个 PINN 方法只要含两个理论责任清楚、可微、可独立消融且有组合收益的内部机制，也足以支撑“基于 X 与 Y”的组织形式。
6. 第四章暂定使用**难度感知课程学习**与**约束强化学习**两种训练理论，处理困难样本、长尾攻击和未知攻击；具体强化算法须在第三章结构冻结后确定。
7. 最终方法必须在基础算法上有实质性修改并自主命名，不能只改名称、符号、秩、损失权重或学习率。

## 3. 第三、四章关系

### 3.1 第三章

- **当前占位题目**：基于物理信息神经网络的恶意流量检测方法。
- **候选题目**：基于队列物理约束与有界条件注意力的恶意流量检测方法。
- 候选题目只保留为工作文件名；有界物理条件注意力尚未通过多种子物理门槛，不能写成已冻结理论。
- 最终标题应采用“基于 X 与 Y 的恶意流量检测方法”句式，但 X、Y 必须来自胜出方法的真实机制。
- R2 当前冻结为第三章优先验证结构：共享守恒通路负责协议无关的包、字节和队列边界，TCP、UDP、QUIC 三个动力学专家负责各自适用状态，并由协议适用掩码与不确定性控制进入生成表征；具体公式、组合名称和最终章名仍须由数据门禁与物理旁路实验裁决。
- 三个专家的部署输入只能来自被动可观测字段。ns-3 的队列/拥塞真值和 QUIC qlog 的 ACK、RTT、丢包、在途字节、拥塞窗口等只作为训练期监督；不得要求实际检测时提供仿真内部状态、TLS 密钥或端点 qlog。
- 执行顺序固定为“候选数据合同冻结 → 分协议动力学相容性审计 → 最终数据与掩码原子冻结 → 物理旁路增量信号实验 → R2 结构训练与消融”。任一步保持 `NO-GO` 时不得跳到后续大模型训练。
第三章固定编排：

1. `3.1` 引言。
2. `3.2` 问题定义与威胁模型。
3. `3.3` 方法框架与物理状态建模。
4. `3.4` 关键机制与联合算法。
5. `3.5` 理论性质、复杂度与适用边界。
6. `3.6` 实验评估。
7. `3.7` 本章小结。

### 3.2 第四章

- **候选题目**：基于难度感知课程与约束强化学习的恶意流量检测方法。
- 第四章复用第三章冻结后的模型结构、数据协议和评价协议，不重新设计 PINN 公式或表示接口。
- 第四章只研究样本难度调度、长尾训练和约束策略优化，不用第三章失败的博弈或适配结构凑篇幅。
- 第三、四章必须复用同一份冻结的分层数据底座：GeNIS 域内已知攻击保留为简单域和非退化检查，GeNIS 时间前向/留一子类作为中等域，TQH-C2 跨加密与留一采集条件、经来源和标签核验的 QUIC 攻击数据作为困难域；无恶意标签但含完整 qlog 的 QUIC 数据与 ns-3 只进入物理辅助池。
- 提高困难域覆盖率是为了覆盖真实部署偏移，并为第四章的难度感知课程、长尾训练和约束强化学习提供可分级样本，不是为了看见基线结果后人为降低基线。训练来源比例只能在开发训练/验证阶段按预注册候选选择一次，第三、四章及所有基线共享；各来源最终测试完整保留并分域报告。
- 第四章必须同时报告简单域非退化、困难域增益、等权域平均和最差域性能。若算法只靠牺牲 GeNIS 简单域换取困难域收益，必须明确报告性能权衡，不能用混合样本总分掩盖。

4. 第三、四章可以模仿“基于 X 与 Y”的标题句式，但不得复制斯塔克尔伯格博弈、二阶反应梯度、章节内容或实验结论。
5. 每个写入标题或贡献点的机制都必须有理论来源、独立消融、组合收益和失败边界。

## 5. PINN 理论纪律

1. 构造公式前回读 `raw/papers/pinn/`、`wiki/papers/pinn/` 和对应恶意流量论文；检索线索必须回到原始全文核验。
2. 守恒律只能作为起点。公式必须针对恶意流量可观测性、时间尺度、稀疏状态监督、边界闭合和生成梯度路径作实质修改。
3. 禁止照抄公式，禁止仅改符号、下标或机械拼接损失后宣称创新。
4. 每个公式都要记录来源语义、原式不适用原因、本课题修改、量纲、归一化、可观测性、梯度路径、极端条件和对应消融。
5. 物理残差必须包含模型预测状态并对可训练参数产生非零梯度；只由输入计算的常数残差不能称为 PINN 约束。
6. 仿真真值只用于训练监督或物理评价，不能作为公开数据推理输入；标签、场景名称和采集单元编号不得泄漏。
7. 理论分析优先证明本课题特有的状态非负性、边界闭合、离散控制体守恒、残差零空间、扰动有界性和梯度通路，不照搬条件不一致的通用收敛定理。
8. “使用 PINN”本身不是创新。创新证据链必须包含失败诊断、专用物理建模、结构或训练机制修改、理论性质、因果消融、公开数据价值和失败边界。
9. 若方法只降低状态误差或物理残差而不改善或保持检测性能，只能声称提高物理一致性。
10. 公式与证据逐项登记在[PINN 公式证据台账](../.Codex/docs/PINN公式证据台账.md)。

## 7. 已核验的当前证据

1. TQH-C2 A/B/C 两次独立物化均产生 35,235 条流、2,475,729 条包和 12 份划分清单；26 个文件逐一哈希无差异，候选协议已发布至本地和服务器。
2. GeNIS 候选协议已在服务器原子发布，登记制品哈希通过；它仍是三源上层组合的输入组件，不是完整 `dataset-v1`。
3. TQH 域内 HGB/XGBoost 三种子已完成。HGB 宏平均 F1 为 `0.871808`、良性误报率为 `0.117109`；XGBoost 分别为 `0.863688` 和 `0.125631`。三次运行号为 `niz6hmv8`、`6r0d3vxm`、`tw82edgq`。
4. 上述树模型结果只建立路线筛选门槛，不是最终公开测试结果；协议状态仍为 `provisional/review_pending`。
5. 星型 ns-3 三种子同协议基线表明，标准 PINN 相对仅状态监督的状态均方误差、未观测状态均方误差和物理残差分别下降 `68.27%`、`82.40%` 和 `88.79%`；这证明物理状态辨识收益，不证明公开数据检测收益或跨拓扑泛化。
6. 有界物理条件注意力 E2 的检测收益在三个种子上方向稳定，但物理收益只在种子 42 同时过门槛，因此仍是条件候选。

## 8. 当前唯一执行顺序

1. **上层组合**：复用已发布的 GeNIS、TQH-C2 和 ns-3 制品，建立唯一主记录、字段可用掩码与共享模型视图；不重新扫描原始 PCAP。
2. **统一预算冻结**：确定性生成正式约 6 万条清单、候选约 1 万条清单和公开测试清单；独立生成两次并逐字节比较，保存统计、泄漏审计和 SHA-256。
3. **同协议基线**：在同一清单上运行 HGB、XGBoost、DistilBERT 或 BERT、普通监督 Qwen、仅状态监督和标准 PINN。
4. **技术路线筛选**：只比较 R1 多尺度控制体、R2 TCP 流体和 R3 网络演算边界；候选固定约 1 万条、200 步和种子 42。
5. **正式验证**：唯一胜者进入约 6 万条正式训练、种子 42/43/44、独立消融、外部强基线、跨加密条件、跨拓扑、跨基座和效率验证。
6. **章节冻结**：全部门槛通过后，才冻结 PINN 公式体系、算法名称、正式章名和最终主表。

按当前进度，预计 **8 至 12 小时**进入 R1/R2/R3 技术路线筛选；该时间取决于三源上层组合、共享视图和双生成验收是否一次通过。

## 9. 方法冻结门槛

1. 三个种子的家族与子类宏平均 F1、未知召回、良性误报、已知类拒识、校准和结构化输出通过预注册门槛。
2. 三个种子的未观测状态误差和物理残差均相对同分区监督基线改善至少 `10%`。
3. 相对普通监督 Qwen 和外部强基线形成可解释的检测或性能－成本优势，不能只与自己的消融比较。
4. 每个写入名称或贡献点的机制都有独立移除消融，完整方法优于相应删减版本并报告置信区间。
5. 公开检测证据来自 GeNIS 和 TQH-C2；物理机制证据来自 ns-3；三者不能互相替代。
6. 最终结果报告种子 42、43、44 的全部结果、均值、标准差和失败项；不得根据最终测试选择最好种子。
7. 任一核心门槛失败时，不降低阈值、不挑种子、不在最终测试调参；只能形成计算图实质不同的新合同或收窄主张。

## 10. 历史方向压缩结论

- G2-G5、G4R、G4R-A2：双层响应生效但没有联合收益，原博弈方案停止。
- B0/B1：证明物理状态可以进入生成前向，但 QR-Stiefel 未形成联合收益。
- S4 与 D0-D3：物理指标可改善，但开放集误报、未知召回或校准不满足总门槛。
- 任务十七：四窗口历史相对常数仅改善 `3.017%`，范围外不确定性曲线下面积为 `0.0811`；历史软令牌路线停止。
- Stiefel-LoRA 与 mHC：只能约束参数几何或残差混合，不能保证物理语义进入生成输出。
- 淘汰方向不得改名、调权重或换学习率重跑；只有新计算图、新梯度路径、新检测保护机制和新可证伪假设同时成立时，才可重新立项。
