## 1. 当前裁决

1. 第三章固定保留 PINN，R2“共享守恒与协议自适应多动力学”是当前唯一活动的章级候选；公式、算法名和正式章名尚未冻结。
2. R2 计算图固定包含共享守恒、TCP、UDP、条件启用的 QUIC 专家和 `UNKNOWN` 回退。ICMP、低置信协议、其他协议及未就绪 QUIC 只走共享守恒与回退，不为标题完整性新增无真值专家。
3. 静态 18 维旁路已经因种子 42 的 `T-P<T-A` 被否决；该结论只否决静态直接注入，不否决当前因果多窗口最终 R2。
4. ns-3 与 qlog 只提供训练期特权物理监督。推理不得使用队列真值、ACK 真值、RTT 真值、丢包/PTO 真值、在途字节、拥塞窗口、端点 qlog、TLS 密钥或最终测试统计量。
5. 现有 59 条 qlog 只允许字段、掩码、路由、残差和种子机制验证，`formal=false`、训练权重为 0；不能启用正式 QUIC 专家，不能进入硬门槛、置信区间或 QUIC 效果主张。
6. 修正版 DistilBERT 种子 42 的 `F-A/F-P/F-S` 均完成 711 步：开发宏平均 F1 分别为 `0.9290/0.9091/0.8953`；`F-P` 比 `F-S` 高 `1.37` 个百分点，但比 `F-A` 低 `1.99` 个百分点。`F-P` 相对 `F-A` 的物理残差改善 `9.47%`，未达到 10% 门槛，状态误差恶化 `2.05%`。该线路判定为未通过且已终止，不补种子 43/44；制品只保留为历史诊断证据。
7. 官方后训练版 `Qwen/Qwen3-0.6B` 从开发候选筛选起直接作为主基座，不再以 DistilBERT 结果作为升级前置条件。先在冻结 10,000 条候选清单上运行种子 42 的 `F-A/F-P/F-S`，有效后补齐 `F-H/F-R` 和种子 43/44；胜出配置不改机制地迁移到 59,656 条正式视图。`Qwen3-1.7B` 只验证冻结方法随基座规模提升时能否保持有效。

## 5. 统计门槛

### 5.1 统计程序

- 主裁决不使用三个种子做正态检验、配对 t 检验、方差分析或 Wilcoxon 检验。
- 固定两层配对自助法：10,000 次重采样，分析种子 `20260804`；第一层重采样训练种子，第二层在每个种子内按 `evaluation_cluster_id` 配对重采样。
- 五组共享同一批种子位置和簇索引；报告每个种子的原始指标与效应、三种子等权均值、样本标准差、双侧 95% 区间和族校正单侧 95% 同时置信下界。
- 常规检测族、困难检测族和物理族分别做族内多重比较控制；不得先看结果再挑困难面板或用次指标挽救主门槛。

### 5.2 硬门槛

| 门槛 | 必须同时满足 |
| --- | --- |
| `G0` 完整性 | 15 个运行完成；代码、配置、数据、拆分、种子、样本、参数预算、路由和最终测试不可见收据齐全 |
| `G1` 常规非劣 | GeNIS 与 TQH-C2 上，`F-P` 对四个对照的三个种子、等权汇总及族校正同时下界均严格大于 `-0.021` |
| `G2` TQH-C2 主要难题 | 三折留一加密条件的平均与最差宏平均 F1 中，`F-P` 对四个对照的三个种子、等权汇总及同时下界均严格大于 0；留一采集条件与协议标签匹配面板对 `F-A` 也必须严格为正 |
| `G3` 物理收益 | 未见状态误差与无量纲物理残差分别相对 `F-A` 三个种子为正、等权改善至少 10%、同时下界为正，并稳定优于 `F-H/F-S/F-R` |

- TCP 与 UDP 分协议报告；只有两者的两项物理指标均满足方向和区间条件，才能声称“跨协议稳定”。

- 互斥最终状态为 `NOT_READY`、`AUDIT_REQUIRED`、`INVALID`、`NO_GO`、`GO_TO_FORMAL_R2_NARROW`、`GO_TO_FORMAL_R2_BROAD`；缺少正式 QUIC 时，任何 `GO` 必须附加 `_TCP_UDP_ONLY`。
- 禁止挑种子、降低阈值、看最终测试调参、按预测选样本、改变标签或来源比例、删除基线擅长样本，以及事后改变面板、主指标或置信区间方法。

1. 15 个运行各有唯一运行标识、组别、种子、状态、退出码、检查点、日志和资源记录；不得只保留最好种子或截图。
2. 每个运行在线记录主次指标、训练时间、峰值显存、吞吐、延迟和失败状态，并保存服务器本地 SwanLab 日志；云端状态、标量和本地制品必须一致。
3. 运行包绑定代码版本、正式配置、数据与拆分清单、五组视图、随机/置换制品、检查点和统计合同的内容哈希。
4. 保存逐样本预测、逐簇物理真值与预测、掩码、专家与回退使用记录、`sample_id`、`evaluation_cluster_id` 和困难面板成员关系。
