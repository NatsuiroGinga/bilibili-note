# 守恒不变量物理公式（论文理论部分用）

> CI-PRD 的"物理"= 守恒不变量。本文给出 I1-I5 的严格数学定义与 PINN 残差形式，可直接写入论文第 3/4 章理论部分。
> **物理合法性分层**：I1 是**基本物理律**（质量守恒/连续性方程，Kirchhoff 类比）；I2-I4 是**领域/协议不变量**（协议状态机、统计平稳性）；I5 为对比消融。写作时如实区分，勿将 I2-I4 过度宣称成基本物理。

## 网络流量的连续介质建模（I1 的物理基础）

将网络流量视作图 $G=(V,E)$ 上的连续流。对链路 $e \in E$，定义：
- $\rho_e(x,t)$：流量密度（单位长度字节数/包数）
- $u_e(x,t)$：传播速度
- $J_e = \rho_e u_e$：流量通量（单位时间字节数）

**连续性方程（质量守恒，Traffic Continuity Equation）**：
$$\frac{\partial \rho_e}{\partial t} + \frac{\partial J_e}{\partial x} = s_e(x,t) \tag{I1-PDE}$$
其中 $s_e$ 为源/汇（流量产生/丢弃）。这是流体力学连续性方程在网络流量上的直接对应，**与 PINN 在流体力学中所解的 PDE 同构**——这是 CI-PRD 最有物理合法性的约束。

## I1 节点流量守恒（离散 KCL 形式，质量守恒）

对节点 $v \in V$、时间窗 $\Delta$，式 (I1-PDE) 在节点处离散为 Kirchhoff 电流定律：

$$\mathcal{R}_{I1}(v,\Delta) = \sum_{i \in \mathrm{in}(v)} B_i^{in}(\Delta) - \sum_{j \in \mathrm{out}(v)} B_j^{out}(\Delta) - B^{drop}(v,\Delta) - \Delta q(v,\Delta) \tag{I1}$$

- $B$ 为窗口内字节计数，$B^{drop}$ 丢弃字节，$\Delta q$ 队列变化。
- **正常**（稳态转发节点）：$\mathcal{R}_{I1} \approx 0$（残差在 $\varepsilon$ 内）。
- **DDoS 受害节点**：流入 $\gg$ 流出，$\mathcal{R}_{I1}$ 显著为正。
- **可算性**：需多节点 per-port 字节计数 → 自构造测试床可算，IDS2018 端点不可算。

## I2 流双向守恒（协议交互不变量）

对客户端-服务端流 $f$，请求-响应字节应满足协议规定的有界比：

$$\mathcal{R}_{I2}(f) = \frac{B_{fwd}(f)}{B_{fwd}(f) + B_{bwd}(f) + \varepsilon} \in [r_{\min}, r_{\max}] \tag{I2}$$

- 正常服务：请求/响应双向，$\mathcal{R}_{I2} \in [r_{\min}, r_{\max}]$（协议相关，如 HTTP 约 $[0.3,0.7]$）。
- **单向洪泛/扫描**：$B_{bwd} \approx 0$，$\mathcal{R}_{I2} \to 1$（或 $\to 0$），违反区间。
- 残差形式：$\mathrm{res}_{I2}(f) = \max(0,\, r_{\min} - \mathcal{R}_{I2},\, \mathcal{R}_{I2} - r_{\max})$。
- **物理定位**：协议交互不变量（非基本守恒律），但可由会话对称性论证。
- **可算性**：`TotLen Fwd/Bwd Pkts`、`Down/Up Ratio` → IDS2018 流级可算。**实验已证对单向 DDoS 洪泛有效**（召回 76-100%，误报 0.6%）。

## I3 TCP 状态守恒（协议状态机不变量）

TCP 连接须遵循状态机：每个 SYN 应有匹配 SYN-ACK 完成握手。对时间窗 $\Delta$：

$$\mathcal{R}_{I3}(\Delta) = \frac{\#\mathrm{SYN}_{unanswered}(\Delta)}{\#\mathrm{SYN}(\Delta) + \varepsilon} \tag{I3}$$

- $\#\mathrm{SYN}_{unanswered}$：窗口内无匹配 SYN-ACK 的 SYN 数。
- **正常**：$\mathcal{R}_{I3} \approx 0$（握手基本都完成）。
- **SYN flood / Slowloris 半开**：$\mathcal{R}_{I3} \to 1$。
- **物理定位**：协议状态机守恒（状态转移须闭合），属形式化协议律。
- **可算性**：严格形式需逐包 TCP 标志 → PCAP 可算（已恢复真实 pcap）；流级弱近似用 `SYN Flag Cnt` 与反向包数。

## I4 熵平稳性（统计不变量）

对窗口 $\Delta$，目的端口/IP 分布的香农熵：

$$H_{dst}(\Delta) = -\sum_{p} P(p|\Delta)\log P(p|\Delta), \quad \mathcal{R}_{I4}(\Delta) = \frac{|H_{dst}(\Delta) - \bar H_{dst}|}{\bar H_{dst} + \varepsilon} \tag{I4}$$

- **正常**：$H_{dst}$ 平稳（$\bar H$ 为稳态均值），$\mathcal{R}_{I4} \approx 0$。
- **DDoS**：目的高度集中，$H_{dst}$ 骤降，$\mathcal{R}_{I4}$ 增大。
- **端口扫描**：目的高度分散，$H_{dst}$ 骤升，$\mathcal{R}_{I4}$ 增大。
- **物理定位**：统计平稳性假设（最弱，属随机过程不变量）。
- **可算性**：`Timestamp`+`Dst Port` → IDS2018 可算。

## I5 TCP/AQM 流体 ODE 残差（对比消融，方案 A）

Misra 型流体方程（窗口 $W$、队列 $q$、RTT $R$、丢包概率 $p$）：

$$\dot W(t) = \frac{1}{R(t)} - \frac{W(t)W(t-R)}{2R(t-R)}p(t-R), \quad \dot q(t) = N\frac{W(t)}{R(t)} - C \tag{I5}$$

- 残差 = 模型预测与该 ODE 的偏差（自动微分）。
- **物理定位**：基本动力学律（但为 TCP 专属聚合模型）。
- **可算性**：$W$ 可由 seq/ack 推断、$R$ 可观测，但 **$q(t)$、$p(t)$ 为路由器内部状态，端点 PCAP 不可观测** → IDS2018 不可算，仅测试床消融对比。

## CI-PRD 的 PINN 物理损失

CI-PRD 用 NN 逼近流量场 $\hat\rho_\theta$，将可计算的不变量残差作软约束：

$$\mathcal{L}_{CI\text{-}PRD} = \underbrace{\mathcal{L}_{data}}_{\text{数据拟合}} + \lambda_1 \mathrm{res}_{I1} + \lambda_2 \mathrm{res}_{I2} + \lambda_3 \mathrm{res}_{I3} + \lambda_4 \mathrm{res}_{I4} \tag{loss}$$

- 测试床数据上启用 I1（连续性方程，强物理）；IDS2018 上启用 I2/I3/I4（协议/统计不变量）。
- 异常得分 = 物理残差幅值 $\|\mathrm{res}\|$；PINN 让模型在"物理一致"子空间预测，攻击打破物理 → 残差升高。

## 论文写作建议

1. **理论核心写 I1（连续性方程）**——这是真正的质量守恒，与流体 PINN 同构，理论合法性最强。明确"网络流量服从连续性方程"这一前提。
2. **I2-I4 作为数据可算的操作化不变量**——如实标为"协议/统计不变量"，不冒充基本物理。
3. **I5 作消融**——证明守恒不变量（I1-I4）优于 TCP 流体残差（I5），且 I5 在真实端点数据不可算。
4. **诚实边界**：守恒不变量对传输层洪泛/扫描有效（实验背书），应用层 DoS 由第二级 LLM 语义覆盖（两级分工）。
