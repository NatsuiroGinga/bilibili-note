# 学位论文章节工作区

王童童《（待定题：面向恶意流量检测的新型大模型训练方法研究）》学位论文章节草稿。

> 方向校准日期：2026-07-16。当前权威说明见 [[当前研究定位与第三四章编排]]，理论候选见 [[第三四章理论补充候选]]。

## 当前研究定位

- **研究对象**：同一个恶意流量检测基座模型及其新型训练方法。
- **研究目标**：通过新的训练机制提高恶意流量检测效果、跨域泛化、困难与长尾攻击识别能力或训练稳定性。
- **方法边界**：PINN、物理残差、课程学习和强化学习均为候选训练手段；`GRPO` 只是强化学习候选之一，不能替代恶意流量检测主任务。
- **架构边界**：不再以“CI-PRD 初筛 + PIC-GRPO 精判”的两个独立检测器作为论文主线。
- **证据边界**：基座模型、输入模态、物理约束形式和第二创新点的训练算法，必须由竞速实验决定。

## 设计原则

- **单一研究主线**：第三、四章必须围绕同一个基座模型、同一个检测任务和一致的数据划分展开。
- **递进式创新**：第三章先解决基础检测训练的效果或泛化问题；第四章解决第三章模型在困难、长尾、未知攻击或训练优化上的剩余问题。
- **分章独立文件**：每章一个 `.md`，按需单独读取，避免一次性加载全文。
- **参考边界**：参考朱焱雷如何从基座缺陷提出问题、设计递进创新和组织方法章，但不复用其方法、公式或实验结论。
- **真实算法增量**：第三、四章最终都必须提出相对基础算法有明确机制改进的新算法，不能直接使用原始算法，也不能只改名称或机械拼接损失项。
- **先实验后命名**：在基座与训练机制探针实验完成前，章节名均为工作标题；确认有效机制后，再为改进算法命名并核查是否重名。
- **引用必核实**：所有参考文献以原论文或官方元数据为准。

## 朱焱雷编排参照

1. **先找一个可测量的问题**：第三章解决基座模型的主要缺陷，第四章解决第三章方法暴露或仍未解决的问题。
2. **每章形成完整方法链**：问题定义、两个相互作用的机制、完整算法、模型适配、理论分析和系统实验缺一不可。
3. **保持实验连续**：第三、四章使用同一主基座、任务、数据处理和评价协议，使第四章增益能够直接归因。
4. **用实验决定机制**：先用探针实验筛选有效机制，再组织公式、算法名称和贡献表述，禁止先定名称再拼结果。
5. **参考工作量而非凑数量**：朱焱雷第三章约 26 页、33 个编号公式、1 个算法、2 个定理、1 个引理、11 幅图和 7 张表。本课题以论证完整性为目标，不机械照搬数量。

## 第三、四章关系

```text
待选恶意流量基座模型
    → 第三章：通过物理信息或一致性约束改进基础训练
    → 第四章：通过课程优化或强化训练改进困难、长尾和未知攻击学习
    → 最终恶意流量检测模型
```

第四章应沿用第三章的主基座、任务、数据处理和评价协议。生成式基座可比较 `RLOO`、`GRPO` 和离线偏好优化；编码器基座可比较强化学习课程控制器、可微课程、对抗训练和对比训练。强化学习是否必要由相对增益与计算成本共同决定。
