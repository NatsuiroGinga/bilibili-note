# Codex 技能上下文治理计划

日期：2026-07-30

状态：P0/P1 已完成，P2 等待用户批准。

## 目标

降低默认会话中技能元数据的重复占用，同时保留显式调用能力、技能文件和插件功能。

## 边界

- 只处理逐字节相同、已有规范副本的重复技能。
- 不删除、移动或改写任何 `SKILL.md`。
- 不处理内容不同的同名技能。
- 不禁用插件，不修改代理注册，不修改论文与实验文件。
- P2 仅形成建议，等待用户批准。

## 执行步骤

1. 核验官方技能发现、禁用、插件与配置档案机制。
2. 复核现有 P0/P1 清单、哈希、活动索引和私有备份。
3. 保存本轮修改前用户配置及脱敏恢复清单。
4. 将 13 个逐字节相同旧副本的禁用项加入用户默认配置。
5. 使用新的独立 Codex 进程复核默认活动技能数、重复项、显式调用和 `AGENTS.md` 累计字节。
6. 输出 P0/P1 结果和需要用户批准的 P2 清单。

## 执行结果

- 官方机制核验完成。
- 默认配置的逐字节相同副本去重完成。
- 独立 Codex 进程验收完成。
- 详细结果见 `2026-07-30-skills-context-governance-report.md`。

## 验收条件

- 技能文件数量与哈希保持不变。
- 默认活动技能由 134 个降为 121 个。
- 20 组逐字节相同技能均只保留一个活动来源。
- 17 组内容不同的同名技能状态保持不变。
- 三个代表性技能可显式解析到 `~/.agents/skills`。
- 插件启用状态与市场集合不变。
- 根目录启动时的全局与仓库 `AGENTS.md` 累计字节有明确测量值且未超限。

## 回滚

使用本轮私有备份恢复 `~/.codex/config.toml`，重启 Codex。仓库内只记录备份目录，不保存用户配置正文。
